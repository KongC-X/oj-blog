# 二分答案模板

## 整数二分（左闭右开）

```cpp
// 在 [L, R] 范围内查找满足条件的最小值
int L = 0, R = 1e9; // 根据题目调整范围
while (L < R) {
    int mid = L + (R - L) / 2;
    if (check(mid)) {
        R = mid;      // mid 可行，尝试更小
    } else {
        L = mid + 1;  // mid 不可行，必须更大
    }
}
return L; // 最小可行值
```

## 浮点数二分

```cpp
double L = 0.0, R = 1e9;
for (int i = 0; i < 100; i++) { // 迭代100次保证精度
    double mid = (L + R) / 2.0;
    if (check(mid)) {
        R = mid;
    } else {
        L = mid;
    }
}
return L;
```
