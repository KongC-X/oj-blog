3893 - 数位之和

题目描述

小杨有 $n$个正整数，他认为一个正整数是美丽数字当且仅当该正整数每一位数字的总和是 $7$ 的倍数。

小杨想请你编写一个程序判断 $n$ 个正整数哪些是美丽数字。

输入

第一行包含一个正整数 $n$ ，代表正整数个数。

之后 $n$ 行，每行包含一个正整数。

输出

对于每个正整数，如果是美丽数字则输出 Yes，否则输出 No。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main(){
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    for(int i = 0; i < n; i++){
        long long s;
        cin >> s;
        int x = 0;
        while(s != 0){
            x += s % 10;
            s /= 10;
        }
        cout << (x % 7 == 0 ? "Yes\n" : "No\n");
    }
    return 0;
}
