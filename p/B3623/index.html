B3623 枚举排列（递归实现排列型枚举）

洛谷 | 普及- | C++14 | 提交时间: 2026-10-09

算法标签：深度优先搜索 DFS

题目描述

今有 nnn 名学生，要从中选出 kkk 人排成一列拍照。

请按字典序输出所有可能的排列方式。

输入格式

仅一行，两个正整数 n,kn, kn,k。

输出格式

若干行，每行 kkk 个正整数，表示一种可能的队伍顺序。

样例

样例输入 #1

3 2```

**样例输出 #1**

1 2
1 3
2 1
2 3
3 1
3 2```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int n, k;          // n: 学生总数, k: 需要选出的人数
int a[15];         // a: 存储当前正在构造的排列
bool used[15];     // used[i]: 数字 i 是否已经被选入当前排列

/*
 * 深度优先搜索，按字典序生成所有排列。
 * pos 表示当前正在填充的位置（从 0 开始，共填 k 个位置）。
 * 当 pos == k 时，说明一个完整的排列已经填好，输出它。
 * 否则，从 1 到 n 依次尝试每个数字 i：
 *   如果 i 还没有被使用，就把它放到当前位置 a[pos]，
 *   标记 used[i] = true，然后递归填充下一个位置。
 *   递归返回后，取消标记 used[i] = false，以便其他分支使用。
 * 因为循环是从 1 到 n 递增，所以生成的排列自然满足字典序。
 */
void dfs(int pos) {
    if (pos == k) {
        // 输出当前排列
        for (int i = 0; i < k; i++) {
            if (i) cout << ' ';
            cout << a[i];
        }
        cout << endl;
        return;
    }
    // 从 1 到 n 枚举当前位置的数字
    for (int i = 1; i <= n; i++) {
        if (!used[i]) {
            used[i] = true;      // 标记数字 i 已被使用
            a[pos] = i;          // 放入当前位置
            dfs(pos + 1);        // 递归填下一个位置
            used[i] = false;     // 回溯：取消标记
        }
    }
}

int main() {
    cin >> n >> k;
    dfs(0);   // 从第 0 个位置开始填充
    return 0;
}
