3891 - 小杨购物

题目描述

小杨有 $n$ 元钱用于购物。商品 $A$ 的单价是 $a$ 元，商品 $B$ 的单价是 $b$ 元。小杨想购买 相同数量 的商品 $A$ 和商品 $B$ 。

请你编写程序帮小杨计算出他 最多 能够购买多少个商品 $A$ 和商品 $B$ 。

输入

第一行包含 $1$ 个正整数 $n$ ，代表小杨用于购物的钱的金额。

第二行包含 $1$ 个正整数 $a$ ，代表商品 $A$ 的单价。

第三行包含 $1$ 个正整数 $b$ ，代表商品 $B$ 的单价。

输出

输出一行，包含 $1$ 个整数，代表小杨 最多 能够购买的商品 $A$ 和商品 $B$ 的数量。

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;
int n,i,x,a,b;
int main() {
    cin >> n >> a >> b;
    cout << n / (a + b) << endl;
}
