3891 - 小杨购物

题目描述

小杨有 nnn 元钱用于购物。商品 AAA 的单价是 aaa 元，商品 BBB 的单价是 bbb 元。小杨想购买 相同数量 的商品 AAA 和商品 BBB 。

请你编写程序帮小杨计算出他 最多 能够购买多少个商品 AAA 和商品 BBB 。

输入

第一行包含 111 个正整数 nnn ，代表小杨用于购物的钱的金额。

第二行包含 111 个正整数 aaa ，代表商品 AAA 的单价。

第三行包含 111 个正整数 bbb ，代表商品 BBB 的单价。

输出

输出一行，包含 111 个整数，代表小杨 最多 能够购买的商品 AAA 和商品 BBB 的数量。

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;
int n,i,x,a,b;
int main() {
    cin >> n >> a >> b;
    cout << n / (a + b) << endl;
}
