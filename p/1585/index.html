1585 - 马里奥找中等的银币

题目描述

勤劳的马里奥存了很多银币之后，担心自己坐吃山空，于是他决定好好学习，不断充实自己。这天马里奥学到了平均值的概念，在数学中，我们用所有数的总和 / 所有数的总个数得到平均数；比如说，数字 3,6,123 ,6 ,123,6,12 三个整数，平均值 = (3+6+12)/3(3 + 6 + 12 ) / 3(3+6+12)/3 = 777 ；而数字 3,103, 103,10 两个整数，平均值 = (3+10)/2(3 + 10) / 2(3+10)/2 = 6.56.56.5 。

学会平均值的概念之后，马里奥想要知道，他所有的银币中，最接近所有银币金额平均值的银币，金额是多少？

比如：假设马里奥存有的银币金额分别为 8,5,2,8,2,48, 5, 2, 8, 2, 48,5,2,8,2,4 ，那么这几个银币的平均值是 4.833334.833334.83333 ，最接近这个平均值的银币的金额，应当是 555 。

输入

第一行是一个整数 nnn 代表马里奥有 nnn 个银币；（n≤1000n \leq 1000n≤1000）

第二行有 nnn 个整数，用空格隔开，代表马里奥每个银币的金额。

输出

一个整数，代表最接近所有银币总金额平均值的那个银币的金额（所有数据保证，最接近平均值的银币的金额是唯一的，也就是说答案只有 111 个。

不存下面这种情况，比如，有 222 个银币，金额分别是 444 和 555 ，平均值是 4.54.54.5 ，金额 444 和金额 555 ，都是最接近的）。

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    int i,n,s = 0,x;
    double p,q,min = INT_MAX;
    int a[1010];
    cin>>n;
    for(i = 0;i < n;i++){
        cin>>a[i];
        s += a[i];
    }
    p = s*1.0/n;
    for(i = 0;i < n;i++){
        if(a[i] < p){
            q = p-a[i];
        }else{
            q = a[i]-p;
        }
        if(q < min){
            min = q;
            x = i;
        }
    }
    cout<<a[x];
}
