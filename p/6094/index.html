6094 - 画画

题目描述

输入一个正整数 nnn，你需要绘制一个 nnn 行 nnn 列的正方形，绘制规则如下：

  • 正方形的四个顶点使用 + 绘制；

  • 除顶点外，第 111 行与第 nnn 行使用 - 绘制；

  • 除顶点外，第 111 列与第 nnn 列使用 | 绘制；

  • 正方形内部使用 * 绘制。

输入

一行，一个正整数 nnn。

输出

输出共 nnn 行，表示对应的正方形。

解题思路

AC代码

#include <bits/stdc++.h>
using namespace std;

string s,s1,s2;
long long x,y;
int main(){
    cin>>s;
    //123*45=
    int p = s.find("*");
    s1 = s.substr(0,p);
    s2 = s.substr(p+1,s.size()-1-p-1);
//	cout<<s1<<endl<<s2;
    
    //转换整数
    x = atoll(s1.c_str());
    y = atoll(s2.c_str());
    cout<<x*y; 
    return 0;
}
