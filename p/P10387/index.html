P10387 [蓝桥杯 2024 省 A] 训练士兵

洛谷 | 普及- | C++14 | 提交时间: 2026-09-30

算法标签：贪心、2024、蓝桥杯省赛

题目描述

在蓝桥王国中，有 nnn 名士兵，这些士兵需要接受一系列特殊的训练，以提升他们的战斗技能。对于第 iii 名士兵来说，进行一次训练所需的成本为 pip_ipi​ 枚金币，而要想成为顶尖战士，他至少需要进行 cic_ici​ 次训练。
为了确保训练的高效性，王国推出了一种组团训练的方案。该方案包含每位士兵所需的一次训练，且总共只需支付 SSS 枚金币（组团训练方案可以多次购买，即士兵可以进行多次组团训练）。
作为训练指挥官，请你计算出最少需要花费多少金币，才能使得所有的士兵都成为顶尖战士？

输入格式

输入的第一行包含两个整数 nnn 和 SSS，用一个空格分隔，表示士兵的数量和进行一次组团训练所需的金币数。
接下来的 nnn 行，每行包含两个整数 pip_ipi​ 和 cic_ici​，用一个空格分隔，表示第 iii 名士兵进行一次训练的金币成本和要成为顶尖战士所需的训练次数。

输出格式

输出一行包含一个整数，表示使所有士兵成为顶尖战士所需的最少金币数。

样例

样例输入 #1

3 6
5 2
2 4
3 2```

**样例输出 #1**

16```

AC 代码

#include <bits/stdc++.h>
#define int long long
using namespace std;

struct Node {
    int p, c;   // p: 单次训练的成本, c: 需要训练的次数
};

// 按需要的训练次数 c 升序排序
bool cmp(Node x, Node y) {
    return x.c < y.c;
}

signed main() {
    /*
     * 题目：P10387 [蓝桥杯 2024 省 A] 训练士兵
     * 题意：n 个士兵，士兵 i 单独训练一次花 p_i，需要 c_i 次训练。
     *       可以买组团训练，一次组团让每个士兵都训练一次，共花 S，可多次购买。
     *       求让所有士兵都达到需要次数的最小总花费。
     *
     * 贪心思路：
     *   1. 把士兵按需要次数 c_i 从小到大排序。
     *   2. 设当前已经买了 tk 次组团训练。
     *      对于士兵 i，他还差 (c_i - tk) 次训练。
     *   3. 用变量 a 记录「从当前士兵到最后一个士兵，每个单独训练一次的总花费」。
     *      初始时 a = Σp_i（所有士兵各单训一次的总价）。
     *   4. 对于每个士兵 i（从前往后）：
     *        - 若 c_i <= tk，说明他已经通过组团训练达标了，
     *          从 a 中移除他（a -= p_i），跳过。
     *        - 否则，他还需要 (c_i - tk) 次训练，有两种选择：
     *            选项A：组团训练，每次花 S，让所有未达标士兵都 +1。
     *            选项B：让士兵 i 单独训练，每次花 p_i。
     *          比较 a 和 S：
     *            - 若 a >= S：组团一次比让所有剩余士兵各单独训练一次更便宜（或相等），
     *              果断组团。花费 (c_i - tk) * S，tk 更新为 c_i。
     *            - 若 a < S：组团不划算，让士兵 i 单独训练。
     *              花费 (c_i - tk) * p_i。
     *        - 处理完后，士兵 i 达标，从 a 中移除（a -= p_i）。
     *   5. 输出累计花费 res。
     *
     * 为什么 a >= S 就可以放心组团？
     *   因为 a 只会随着士兵达标而减小，一旦 a < S，后面只会更小，
     *   所以「a >= S 就组团」的贪心策略是正确的。
     *
     * 时间复杂度：O(n log n)（排序） + O(n)（一次扫描），n ≤ 1e5。
     */

    int n, S;
    cin >> n >> S;

    Node a[100005];
    int sumP = 0;   // sumP: 所有士兵单独训练一次的总花费 Σp_i

    for (int i = 1; i <= n; i++) {
        cin >> a[i].p >> a[i].c;
        sumP += a[i].p;
    }

    sort(a + 1, a + n + 1, cmp);   // 按 c_i 升序排序

    int ans = 0;   // ans: 总花费
    int tk = 0;    // tk: 当前已买的组团训练次数

    for (int i = 1; i <= n; i++) {
        // 若该士兵已通过组团达标，直接从 sumP 中移除
        if (a[i].c <= tk) {
            sumP -= a[i].p;
            continue;
        }

        // 比较组团（每次 S）与让所有剩余士兵各单独训练一次（sumP）
        if (sumP >= S) {
            // 组团划算：把该士兵缺的次数全部用组团补齐
            ans += (a[i].c - tk) * S;
            tk = a[i].c;   // 组团次数更新到 a[i].c
        } else {
            // 单独训练划算：让该士兵自己补满
            ans += (a[i].c - tk) * a[i].p;
        }

        // 该士兵处理完毕，从 sumP 中移除
        sumP -= a[i].p;
    }

    cout << ans << endl;
    return 0;
}
