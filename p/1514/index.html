1514 - 数根

题目描述

数根是这样定义的：对于一个正整数 nnn ，将它的各个数位上的数字相加得到一个新数，如果这个数是一位数，我们就称之为 nnn 的数根，否则重复处理直到它成为一个一位数。

例如，n=34n=34n=34，3+4=73+4=73+4=7， 777 是一位数，所以 777 是 343434 的数根。

再如，n=345n=345n=345，3+4+5=123+4+5=123+4+5=12，1+2=31+2=31+2=3，333 是一位数，所以 333 是 345345345 的数根。

对于输入数字 nnn ，编程计算它的数根。

输入

一个正整数。（）

输出

一个整数，代表 nnn 的数根。

解题思路

AC代码

AC代码

#include <iostream>
#include <cmath>
using namespace std;

// 求数位的和
int digitSum(int n) {
    int sum = 0;
    while (n > 0) {
        sum += n % 10;
        n /= 10;
    }
    return sum;
}

int main() {
    int n;
    cin >> n;
    while(n >= 10) {
        n = digitSum(n);
    }
    cout << n << endl;
}
