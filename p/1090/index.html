1090 - 同因查找

题目描述

求出 101010 至 100010001000 之内能同时被 2、3、72、3、72、3、7 整除的数，并输出。

每行一个。

输入

无

输出

按要求输出满足条件的数，每行 111 个。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
 
int main() {
    int i;
    //遍历范围为10到1000 
    for(i=10;i<=1000;i++){
        //能同时被2、3、7整除的i输出 
        if(i%2==0&&i%3==0&&i%7==0){
            cout<<i<<endl;
        }
    }
    return 0;
}
