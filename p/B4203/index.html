B4203 [常州市赛 2021] 鸡羊同栏

洛谷 | 普及- | C++14 | 提交时间: 2026-07-22

算法标签：数学、2021、江苏、枚举、科创活动、小学活动

题目背景

搬运自 http://czoj.com.cn/p/439。数据为民间数据。

题目描述

小 X\text{X}X 是 CZ\text{CZ}CZ 市著名的牧场主。他把 AAA 只鸡和 BBB 只羊圈养在一个围栏中。
一只正常的鸡有 000 只角、 222 条腿；一只正常的羊有 222 只角、 444 条腿。
某一天，一道神秘的宇宙射线击中了牧场，导致其中的至多一个动物发生了变异。
变异的动物角的只数与腿的条数中至少有一个数量变化了。例如，一只正常的鸡变异成了 333 只角 222 条腿。注意：变异以后动物也不可能有负数个数的角或腿。
小 X\text{X}X 只知道鸡和羊的数量、以及笼子中的动物一共有 CCC 只角 DDD 条腿。他想请你帮忙搞清楚变异的情况是什么。

输入格式

一行 444 个整数 A,B,C,DA,B,C,DA,B,C,D ，含义见问题描述。

输出格式

输出共 222 行。
第一行：如果可能是一只鸡变异了，输出它变异后角的只数与腿的条数；否则输出 -1。
第二行：如果可能是一只羊变异了，输出它变异后角的只数与腿的条数；否则输出 -1。

样例

样例输入 #1

2 2 3 15```

**样例输出 #1**

-1
1 7```

样例输入 #2

2 2 4 12```

**样例输出 #2**

-1
-1```

AC 代码

#include <iostream>
using namespace std;

int main() {
    /*
      思路：
      正常的鸡：0角 2腿，正常的羊：2角 4腿。
      至多一只动物变异（鸡或羊），变异后角/腿至少一个变化，且非负。
      已知总只数：鸡 a 只，羊 b 只；总角 c，总腿 d。
      分别检查两种可能：
        1. 假设一只鸡变异（如果鸡的数量 > 0）
        2. 假设一只羊变异（如果羊的数量 > 0）
      若可能，输出变异后该动物的角数和腿数；否则输出 -1。
    */
    long long a, b, c, d;         // a:鸡数, b:羊数, c:总角, d:总腿
    cin >> a >> b >> c >> d;
    
    // ----- 检查鸡变异 -----
    // 正常总角 = 2*b（只有羊有角），正常总腿 = 2*a + 4*b
    // 若鸡变异：变异鸡角 x = 总角 - 正常总角 (因为正常鸡0角)
    //           变异鸡腿 y = 总腿 - (正常总腿 - 2) (因为原正常鸡贡献2腿被替换为y)
    if (a > 0) {
        long long x = c - 2 * b;               // 变异鸡的角数
        long long y = d - (2 * a + 4 * b) + 2; // 变异鸡的腿数
        // 检查是否合法：非负，且不能是正常鸡(0角2腿)
        if (x >= 0 && y >= 0 && !(x == 0 && y == 2))
            cout << x << " " << y << endl;
        else
            cout << -1 << endl;
    } else {
        cout << -1 << endl;                   // 没有鸡，自然不可能鸡变异
    }
    
    // ----- 检查羊变异 -----
    // 若羊变异：正常总角 = 2*b，其中一只羊原本贡献2角，变异后贡献 x 角
    //           所以 x = 总角 - (正常总角 - 2) = c - 2*b + 2
    //           同理，腿 y = 总腿 - (正常总腿 - 4) = d - (2*a + 4*b) + 4
    if (b > 0) {
        long long x = c - 2 * b + 2;           // 变异羊的角数
        long long y = d - (2 * a + 4 * b) + 4; // 变异羊的腿数
        // 检查是否合法：非负，且不能是正常羊(2角4腿)
        if (x >= 0 && y >= 0 && !(x == 2 && y == 4))
            cout << x << " " << y << endl;
        else
            cout << -1 << endl;
    } else {
        cout << -1 << endl;
    }
    
    return 0;
}
