2231 - 最简真分数

题目描述

给出 nnn 个正整数，任取两个数分别作为分子和分母组成最简真分数，编程求共有几个这样的组合。

输入

第一行是一个正整数 n（n≤600n（n \le 600n（n≤600）。

第二行是 nnn 个不同的整数，相邻两个整数之间用单个空格隔开。

整数大于 111 且小于等于 100010001000 。

输出

一个整数，即最简真分数组合的个数。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

//计算2个数的最大公约数
int fun(int x, int y)
{
    int t;
    while (x % y != 0)
    {
        t = x % y;
        x = y;
        y = t;
    }

    return y;
}

int n, a[610], c = 0;

int main()
{
    cin >> n;
    for (int i = 1; i <= n; i++)
    {
        cin >> a[i];
    }

    //穷举所有的两个数之间的组合
    for (int i = 1; i <= n; i++)
    {
        for (int j = 1; j <= n; j++)
        {
            if (i != j && a[i] < a[j] && fun(a[i], a[j]) == 1)
            {
                c++;
            }
        }
    }

    cout << c;
    return 0;
}
