P1271 【深基9.例1】选举学生会

洛谷 | 普及- | C++14 | 提交时间: 2025-08-26

算法标签：排序

题目描述

学校正在选举学生会成员，有 $n$（$1 \le n\le 999$）名候选人，每名候选人编号分别从 $1$ 到 $n$，现在收集到了 $m$（$1 \le m \le 2000000$）张选票，每张选票都写了一个候选人编号。现在想把这些堆积如山的选票按照投票数字从小到大排序。设第 $i$（$1 \le i \le m$）张选票上的数字为 $a_i$，则保证有 $1 \le a_i \le n$。

输入格式

输入 $n$ 和 $m$ 以及 $m$ 个选票上的数字。

输出格式

求出排序后的选票编号。

样例

样例输入 #1

5 10
2 5 2 2 5 2 2 2 1 2```

**样例输出 #1**

1 2 2 2 2 2 2 2 5 5```

AC 代码

#include<bits/stdc++.h>
using namespace std;
int a[20000005];
int main()
{
    int n,m;
    cin>>n>>m;
    for(int i=1;i<=m;i++)
    {
        cin>>a[i];//输入
    }
    sort(a+1,a+1+m);//stl排序
    for(int i=1;i<=m;i++)
    {
        cout<<a[i]<<" ";
    }
    return 0;
}
