洛谷 | 入门 | C++14 | 提交时间: 2026-07-20

算法标签：四川、2025、分支结构、科创活动、小学活动

题目描述

平面上两个圆的位置关系有 6 种，每种情况两圆的公切线条数也不同。

设两圆半径分别为 r1,r2r_1, r_2r1​,r2​，两圆圆心距离为 ddd，则 6 种情况分别为：

  • 内含：∣r1−r2∣>d|r_1 - r_2| > d∣r1​−r2​∣>d，公切线条数为 000；
  • 内切：∣r1−r2∣=d|r_1 - r_2| = d∣r1​−r2​∣=d，公切线条数为 111；
  • 相交：∣r1−r2∣<d<r1+r2|r_1 - r_2| < d < r_1 + r_2∣r1​−r2​∣<d<r1​+r2​，公切线条数为 222；
  • 外切：r1+r2=dr_1 + r_2 = dr1​+r2​=d，公切线条数为 333；
  • 外离：r1+r2<dr_1 + r_2 < dr1​+r2​<d，公切线条数为 444；
  • 重合：∣r1−r2∣=d=0|r_1 - r_2| = d = 0∣r1​−r2​∣=d=0，公切线条数为无穷多。注意：重合是一种特殊情况，如果满足重合关系，就不再计其他关系。给出两圆的情况，求公切线条数。

输入格式

一行三个整数 r1,r2r_1, r_2r1​,r2​（0≤r1,r2≤1000 \leq r_1, r_2 \leq 1000≤r1​,r2​≤100）和 ddd（0≤d≤1000 \leq d \leq 1000≤d≤100）。

输出格式

输出一个整数，表示公切线条数；如果公切线有无穷多条，输出 inf。

样例

样例输入 #1

1 1 0```

**样例输出 #1**

inf```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // a, b: 两圆半径；d: 圆心距
    int a, b, d;
    cin >> a >> b >> d;

    // 先判断重合：半径相等且圆心距为 0
    if (a == b && d == 0) {
        cout << "inf" << endl;
        return 0;
    }

    int diff = abs(a - b);
    int sum = a + b;

    if (diff > d) {
        cout << 0 << endl;          // 内含
    } else if (diff == d) {
        cout << 1 << endl;          // 内切
    } else if (diff < d && d < sum) {
        cout << 2 << endl;          // 相交
    } else if (sum == d) {
        cout << 3 << endl;          // 外切
    } else if (sum < d) {
        cout << 4 << endl;          // 外离
    }

    return 0;
}
