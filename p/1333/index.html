1333 - 兴趣班的排班

题目描述

暑假来了，有n名同学都参加了暑假兴趣班（ $n \lt 10$ ），不同的兴趣班都是从同一天开始上课， $n$ 个同学的上课频率（每隔几天上一次课，如每隔 $3$ 天上一次课，上课频率就是 $3$ ）不同，请问除了第一天，最少要等到第几天这 $n$ 个同学会在同一天一起上课？

比如：有 $2$ 位同学，同学甲 $3$ 天上 $1$ 次课，同学乙 $2$ 天上一次课，他们的上课时间分布就如下表所示， $2$ 位同学除了第 $1$ 天，至少要等到第 $7$ 天才能一起上课。

`第一天  第二天  第三天  第四天  第五天  第六天  第七天
 甲                     甲                      甲
 乙              乙              乙             乙
`

输入

第一行一个整数 $n$ 代表学生的数量;

第二行 $n$ 个数代表每位同学的上课频率。

输出

接下来到第几天所有人会在同一天上课。（本题测试数据确保答案 $ \le 10^5$ ）

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int main()
{
    int n,a[10],d=1;
    cin >> n;
    for(int i=1;i<=n;i++)
    {
        cin >> a[i];
    }
    for(int i=1;i<=999999;i++)
    {
        d=1;
        for(int j=1;j<=n;j++)
        {
            if(i%a[j]!=0)
            {
                d=0;
            }
        }
        if(d==1)
        {
            cout << i+1;
            break;
        }
    }
}
