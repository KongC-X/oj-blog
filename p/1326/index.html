1326 - 需要安排几位师傅加工零件

题目描述

某工厂有 nnn 个零件加工的师傅，每位师傅每天能够加工出不同数量的零件。

现有 mmm 个零件要求一天加工完，请问该工厂最少需要派几个师傅来完成这次零件加工任务，如果安排所有的师傅都参与加工也不能在一天内完成任务，请输出 NO。（4.2.71）

输入

第一行有两个整数，用空格隔开；

第一个整数代表要加工的总零件个数 mmm （m≤106m \le 10^6m≤106），第二个整数代表工厂的零件加工师傅的数量 nnn（n≤100n \le 100n≤100）。

第二行有 nnn 个整数，分别代表每个师傅每天能够加工出来的零件数量（每个师傅每天加工的零件数量≤104\le 10^4≤104）。

输出

输出工厂在 111 天时间内加工所有零件需要的师傅数量，或者输出 NO。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int a[110],i,s,n,m,c;
int main(){
    cin>>m>>n;
    for(i=1;i<=n;i++){
        cin>>a[i];
    }
    sort(a+1,a+n+1);
    for(i=n;i>=1;i--){
        s=s+a[i];
        c++;
        if(s>=m){
            cout<<c;
            break;
        }
    }
    if(s<m){
        cout<<"NO";
    }
}
