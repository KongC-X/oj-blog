P17457 [GESP202609 六级] 数组划分

洛谷 | 普及| C++14 | 提交时间: 2026-09-18

算法标签：动态规划 DP、前缀和、2026、GESP

题目描述

给定 $n$ 个整数构成的数组 $A=[a_1,a_2,\ldots,a_n]$。

你需要将数组 $A$ 划分为若干非空连续子段。对于划分得到的某个子段，它的偏差值定义为子段内整数和的平方。划分方案的偏差值定义为所有子段偏差值之和。

你需要最小化划分方案的偏差值。

形式化地，你可以将 $A$ 划分为若干非空连续子段 $A_1,A_2,\ldots,A_k$，使得 $A=A_1+A_2+\ldots+A_k$，这里的 $+$ 代表数组的连接。对于 $1\le i\le k$，设数组 $A_i=[a_1^{(i)},\ldots,a_{m_i}^{(i)}]$ 包含 $m_i$ 个整数。你需要最小化 $\sum_{i=1}^{k}\left(\sum_{j=1}^{m_i}a_j^{(i)}\right)^2$。

输入格式

第一行，一个正整数 $n$，表示数组 $A$ 的长度。

第二行，$n$ 个整数 $a_1,a_2,\ldots,a_n$，表示数组 $A$。

输出格式

一行，一个整数，表示划分方案偏差值的最小值。

样例

样例输入 #1

4
1 2 -3 4```

**样例输出 #1**

6```

样例输入 #2

6
-1 -1 4 -5 -1 4```

**样例输出 #2**

0```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P17457 [GESP202609 六级] 数组划分
     * 题意：将数组 A 划分为若干非空连续子段，每个子段的偏差值为子段和的平方，
     *       总偏差值为所有子段偏差值之和，求最小总偏差值。
     *
     * 思路：动态规划
     * 1. 设 dp[i] 表示前 i 个元素划分后的最小偏差值。
     * 2. 转移：枚举最后一段的起点 j+1（j < i），
     *    最后一段的和为 s[i] - s[j]（s 为前缀和），
     *    则 dp[i] = min(dp[j] + (s[i] - s[j])^2)。
     * 3. 初始条件：dp[0] = 0（前 0 个元素偏差值为 0）。
     * 4. 答案：dp[n]。
     *
     * 数据范围：n ≤ 2000，a_i ∈ [-100, 100]。
     * 前缀和及平方和用 long long 存储，避免溢出。
     * 时间复杂度：O(n^2)，n=2000 时约 4e6 次运算，完全可行。
     */
    int n;
    cin >> n;

    int a[2005];          // a: 原数组（1-based）
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    long long s[2005] = {0};   // s[i]: 前 i 个元素的前缀和
    for (int i = 1; i <= n; i++) {
        s[i] = s[i - 1] + a[i];
    }

    long long dp[2005];        // dp[i]: 前 i 个元素的最小偏差值
    dp[0] = 0;                 // 初始条件：0 个元素偏差为 0

    for (int i = 1; i <= n; i++) {
        dp[i] = 1e18;          // 初始化为一个很大的数
        for (int j = 0; j < i; j++) {
            long long d = s[i] - s[j];          // 最后一段的和
            long long val = dp[j] + d * d;       // 当前划分的偏差值
            if (val < dp[i]) {
                dp[i] = val;
            }
        }
    }

    cout << dp[n] << endl;     // 输出答案
    return 0;
}
