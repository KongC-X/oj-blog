2000 - 两个数相邻吗？

题目描述

同学们在操场上排成了一个 nnn 行 mmm 列的队形，假设这个队形中所有人年龄都不同，那么给定 222 个年龄后，请你编程判断，这 222 个年龄对应的同学是否相邻？

相邻的定义是：如果两个同学在上下左右的位置是挨在一起的，那么就算是相邻的。

比如：如下是一个 333 行 444 列的队形，这个队形中每个数字代表了每个同学的年龄。

`8 2 3 4
5 6 7 1
9 10 11 12
`

那么这个队形中，年龄 666 和年龄 101010 两个值就是相邻的。

输入

第 111 行有 222 个整数 nnn 和 mmm ，分别代表队形的行和列的值（ 2≤n,m≤2002 \le n,m \le 2002≤n,m≤200）

接下来 nnn 行，每行有 mmm 个整数，代表每个同学的年龄（每个同学的年龄的值在 1∼400001 \sim 400001∼40000 之间）

最后一行输入 222 个整数，代表 222 个不同年龄的值。

输出

如果两个年龄的值是相邻的，请输出字符 Y ，否则请输出字符 N 。

AC代码

AC代码

#include<iostream>
using namespace std;
int main(){
int i,j,m,n,t1,t2,t1i,t1j,t2i,t2j,a[201][201];
cin>>n>>m;
for(i=1;i<=n;i++)
   for(j=1;j<=m;j++)
        cin>>a[i][j];			    
cin>>t1>>t2;
for(i=1;i<=n;i++)
   for(j=1;j<=m;j++)
   {
         if(a[i][j]==t1)  {t1i=i;t1j=j;}
      if(a[i][j]==t2)  {t2i=i;t2j=j;}	   	
   }
if((t1i-t2i==-1||t1i-t2i==1)&&(t1j-t2j==0)||(t1j-t2j==-1||t1j-t2j==1)&&(t1i-t2i==0)){
    cout<<'Y'<<endl;
}else{
    cout<<'N'<<endl;
}		    		    		  	
}
