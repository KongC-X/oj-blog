1074 - 小青蛙回来了

题目描述

关于小青蛙爬井的故事，你应该早就听过了：井深 $10$ 尺，小青蛙从井底向上爬，每个白天向上爬 $3$ 尺，每个晚上又滑下来 $2$ 尺，然后问你第几天它能爬上来。

答案是第 $8$ 天。

现在，那只著名的小青蛙又回来了，它现在每个白天已经可以向上爬 $m（2 \le m \le 10$ ）尺了，当然，晚上还是要下滑 $n（1 \le n \lt m $）尺的。

如果告诉你井深 $h（10 \le h \le 200$ ）尺，请计算一下，现在，它第几天可以爬上来。

输入

有三个整数，分别表示 $m、 n、 h$ 。

输出

只有一个整数，表示第几天可以爬上来。

AC代码

AC代码

#include<iostream>
using namespace std;

int main() {
    int m,n,h,s = 0,day = 0;
    cin >> m >> n >> h;
    while(s < h) {
        day++;
        s += m;
        if(s < h) {
            s -= n;
        }
    }
    cout << day << endl;
    return 0;
}
