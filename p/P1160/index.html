P1160 队列安排

洛谷 | 普及| C++14 | 提交时间: 2026-05-15

算法标签：模拟、线性数据结构、构造、链表

题目描述

一个学校里老师要将班上 NNN 个同学排成一列，同学被编号为 1∼N1\sim N1∼N，他采取如下的方法：

  1. 先将 111 号同学安排进队列，这时队列中只有他一个人；

  2. 2∼N2\sim N2∼N 号同学依次入列，编号为 iii 的同学入列方式为：老师指定编号为 iii 的同学站在编号为 1∼(i−1)1\sim(i-1)1∼(i−1) 中某位同学（即之前已经入列的同学）的左边或右边；

  3. 从队列中去掉 MMM 个同学，其他同学位置顺序不变。

在所有同学按照上述方法队列排列完毕后，老师想知道从左到右所有同学的编号。

输入格式

第一行一个整数 NNN，表示了有 NNN 个同学。

第 2∼N2\sim N2∼N 行，第 iii 行包含两个整数 k,pk,pk,p，其中 kkk 为小于 iii 的正整数，ppp 为 000 或者 111。若 ppp 为 000，则表示将 iii 号同学插入到 kkk 号同学的左边，ppp 为 111 则表示插入到右边。

第 N+1N+1N+1 行为一个整数 MMM，表示去掉的同学数目。

接下来 MMM 行，每行一个正整数 xxx，表示将 xxx 号同学从队列中移去，如果 xxx 号同学已经不在队列中则忽略这一条指令。

输出格式

一行，包含最多 NNN 个空格隔开的整数，表示了队列从左到右所有同学的编号。

样例

样例输入 #1

4
1 0
2 1
1 0
2
3
3```

**样例输出 #1**

2 4 1```

AC 代码

#include <bits/stdc++.h>
using namespace std;

/*
【题目思路与解题过程】
题意：n 个同学，按规则插入到队列中，后续删除 m 个同学，输出最终队列。
核心操作：在指定同学 k 的左边或右边插入新同学，以及根据编号删除同学。
链表非常适合这种频繁的中间插入和删除。

思路：
- 使用 list（双向链表）模拟队列。
- 用一个数组 pos[i] 保存编号 i 的同学在 list 中的迭代器（位置），
  这样就能 O(1) 时间找到要操作的节点。
- 插入时通过 pos[k] 直接定位，然后：
  - p=0: 插入到 k 的左边，lst.insert(pos[k], i)。
  - p=1: 插入到 k 的右边，先将迭代器后移一位（++it），再插入。
- 删除时用一个标记数组 del，防止重复删除，然后 lst.erase(pos[x])。
- 最后遍历 list 输出结果。
*/

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n;                           // n: 同学总数
    cin >> n;
    
    list<int> lst;                   // lst: 模拟当前队列
    vector<list<int>::iterator> pos(n + 1); // pos[i]: 编号 i 的同学在链表中的位置
    vector<bool> del(n + 1, false);  // del[i]: 标记 i 是否已被删除
    
    // 1 号同学初始化入队
    lst.push_back(1);
    pos[1] = lst.begin();
    
    // 依次插入 2 ~ n 号同学
    for (int i = 2; i <= n; ++i) {
        int k, p;                    // k: 基准同学编号, p: 0 左 / 1 右
        cin >> k >> p;
        if (p == 0) {                // 插入到 k 的左边
            pos[i] = lst.insert(pos[k], i);
        } else {                     // 插入到 k 的右边
            list<int>::iterator it = pos[k]; // 先拿到 k 的迭代器
            ++it;                            // 向后移动一位，即 k 的右边位置
            pos[i] = lst.insert(it, i);
        }
    }
    
    int m;                           // m: 删除次数
    cin >> m;
    while (m--) {
        int x;                       // x: 要删除的同学编号
        cin >> x;
        if (del[x]) continue;        // 已删除则跳过
        del[x] = true;               // 标记为已删除
        lst.erase(pos[x]);           // 从链表中移除
    }
    
    // 输出最终队列，数字间空格分隔
    list<int>::iterator it = lst.begin();
    while (it != lst.end()) {
        cout << *it;                 // 输出当前同学编号
        ++it;                        // 移动到下一位
        if (it != lst.end()) cout << ' '; // 非末尾则输出空格
    }
    cout << '\n';
    
    return 0;
}
