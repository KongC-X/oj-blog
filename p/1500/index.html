1500 - 数组存数

题目描述

今有 NNN 个数组，初始时，NNN 个数组均为空。共有 MMM 次操作，每次在第 XXX 个数组中加入数字 YYY。问最终各数组中有多少数，并将它们排序输出。

比如，输入如下数据：

`3 5
1 3
1 2
1 1
2 1
3 1
`

表示有 333 个数组，共有 555 次操作，分别向第 111 个数组存入 333，第 111 个数组存入 222 ，第 111 个数组存入 111，第 222 个数组存入 111，第 333 个数组存入111。

输出如下：

`3 1 2 3
1 1
1 1
`

第 111 行表示：第 111 个数组中有 333 个数，排序结果为111 222 333；

第 222 行表示：第 222 个数组中有 111 个数，排序结果为 111；

第 333 行表示：第 333 个数组中有 111 个数，排序结果为 111；

输入

第一行两个整数 N、MN、MN、M（N≤100000,M≤3000N≤100000,M≤3000N≤100000,M≤3000）。

接下来 MMM 行，每行两个整数 X、YX、YX、Y，含义见试题描述。（1≤X≤N，Y≤1091≤X≤N，Y≤10^91≤X≤N，Y≤109）

输出

共 NNN 行；

第 iii 行第一个数 SUMSUMSUM，表示第 iii 个数组数的个数，接下来 SUMSUMSUM 个数，为排序之后的数组。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 定义二维的vector
// vector<vector<int> > a(100100);
// 定义vector类型的数组，数组中的每个元素都是一个vector
vector<int> a[100100];
int n,m,i,j,x,y;
int main() {
    cin >> n >> m;
    // 读入m组指令
    for(i = 0;i < m;i++) {
        cin >> x >> y; // 向第x个数组中，存入元素y
        a[x-1].push_back(y);
    }
    // 输出每个数组中的元素
    for(i = 0;i < n;i++) {
        cout << a[i].size() << " ";
        sort(a[i].begin(), a[i].end()); // 对每个数组进行排序
        for(j = 0;j < a[i].size();j++) {
            cout << a[i][j] << " "; // 输出每个数组中的元素
        }
        cout << endl;
    }
}
