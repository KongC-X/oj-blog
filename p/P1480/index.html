P1480 A/B Problem（高精度除法Ⅰ）

洛谷 | 普及- | C++14 | 提交时间: 2026-07-24

算法标签：模拟、高精度

题目描述

输入两个整数 a,ba,ba,b，输出它们的商。

输入格式

两行，第一行是被除数，第二行是除数。

样例

样例输入 #1

10
2```

**样例输出 #1**

5```

AC 代码

#include <iostream>
#include <string>
using namespace std;

/*
  高精度除以低精度（模拟竖式除法）
  参数：
    s1 : 被除数字符串（高精度）
    b  : 除数（低精度，范围 1 ~ 10^9）
  返回：
    商字符串（整数部分）
  思路：
    从被除数的最高位开始，逐位处理。当前余数 r 初始为 0，
    每次将下一位数字加入 r 后除以 b，商的一位保存下来，r 更新为余数。
    最后去掉前导零，但至少保留一位。
  时间复杂度 O(len(s1))。
*/
string chu(string s1, long long b) {
    // 如果除数为0，按题目保证不会出现
    int len = s1.size();
    string ans = "";          // 存放商的结果
    long long r = 0;          // 当前余数

    for (int i = 0; i < len; i++) {
        r = r * 10 + (s1[i] - '0');   // 将当前位加入余数
        ans += char(r / b + '0');     // 商的一位
        r %= b;                       // 更新余数
    }

    // 去除前导零，但至少保留一位数字
    int pos = 0;
    while (pos < (int)ans.size() - 1 && ans[pos] == '0') {
        pos++;
    }
    return ans.substr(pos);
}

int main() {
    string a;                // 被除数（高精度）
    long long b;             // 除数（低精度，≤10^9）
    cin >> a >> b;

    cout << chu(a, b) << endl;
    return 0;
}
