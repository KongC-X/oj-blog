B2174 完全背包

洛谷 | 普及- | C++14 | 提交时间: 2026-10-22

算法标签：动态规划 DP、背包 DP

题目描述

你有一个容量为 VVV 的背包，以及 nnn 种物品。第 iii 种物品的体积为 wiw_iwi​，价值为 valival_ivali​。

每种物品都有无限件，你可以选择任意多件放入背包，但总容量不能超过 VVV。

请你求出在不超过背包容量的前提下，能获得的最大总价值。

形式化题意：设第 iii 种物品选择 xix_ixi​ 件（xix_ixi​ 为非负整数），则需要满足：

∑i=1nxi⋅wi≤V,xi≥0\sum_{i=1}^{n} x_i \cdot w_i \le V,\quad x_i \ge 0i=1∑n​xi​⋅wi​≤V,xi​≥0

最大化目标：

max⁡∑i=1nxi⋅vali\max \sum_{i=1}^{n} x_i \cdot val_imaxi=1∑n​xi​⋅vali​

输入格式

第一行两个整数 n,Vn, Vn,V，表示物品种类数与背包容量。

接下来 nnn 行，每行两个整数 wi,valiw_i, val_iwi​,vali​，分别表示第 iii 种物品的体积与价值。

输出格式

输出一个整数，表示最大总价值。

样例

样例输入 #1

3 10
2 3
3 4
4 5```

**样例输出 #1**

15```

AC 代码

#include<bits/stdc++.h>
#define int long long
using namespace std;
const int N=1e4+5,M=1e7+5;
int n,V,dp[M],w[N],v[N];
signed main(){
    cin>>n>>V;
    for(int i=1;i<=n;i++){
        cin>>w[i]>>v[i];
    }
    for(int i=1;i<=n;i++){
        for(int j=w[i];j<=V;j++){
            dp[j]=max(dp[j],dp[j-w[i]]+v[i]);
        }
    }
    cout<<dp[V]<<endl;
    return 0;
}
