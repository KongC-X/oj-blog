1084 - 因子求和

题目描述

已知一个正整数 NNN（ 20≤N≤80000000020 \le N \le 80000000020≤N≤800000000 ），请你编写程序求出该数的全部因子（不包括 111 和 nnn ）的和。

输入

一个正整数 nnn 。

输出

一个整数代表 nnn 的因子和。

解题思路

AC代码

AC代码

#include<bits/stdc++.h> 
using namespace std;

int fun(int n) {
    int r=0;
    for(int i=2;i<=sqrt(n);i++) {
        if(n%i == 0) {
            if(i == sqrt(n)) {
                r+=i;
            } else {
                r=r+i+(n/i);
            }
        } 
    }
    return r; 
}
int main() {
    int n;
    cin>>n;
    cout<<fun(n);
    return 0; 
}
