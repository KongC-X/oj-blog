P11962 [GESP202503 六级] 树上漫步

洛谷 | 普及- | C++14 | 提交时间: 2026-05-14

算法标签：2025、广度优先搜索 BFS、深度优先搜索 DFS、二分图、树的遍历、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1178

题目描述

小 A 有一棵 $n$ 个结点的树，这些结点依次以 $1,2,\cdots,n$ 标号。

小 A 想在这棵树上漫步。具体来说，小 A 会从树上的某个结点出发，每一步可以移动到与当前结点相邻的结点，并且小 A 只会在偶数步（可以是零步）后结束漫步。

现在小 A 想知道，对于树上的每个结点，从这个结点出发开始漫步，经过偶数步能结束漫步的结点有多少个（可以经过重复的节点）。

输入格式

第一行，一个正整数 $n$。

接下来 $n-1$ 行，每行两个整数 $u_i,v_i$，表示树上有⼀条连接结点 $u_i$ 和结点 $v_i$ 的边。

输出格式

一行，$n$ 个整数。第 $i$ 个整数表示从结点 $i$ 出发开始漫步，能结束漫步的结点数量。

样例

样例输入 #1

3
1 3
2 3```

**样例输出 #1**

2 2 1```

样例输入 #2

4
1 3
3 2
4 3```

**样例输出 #2**

3 3 1 3```

AC 代码

#include <iostream>
#include <vector>
using namespace std;

// 问题核心就一句话：
// 树上的结点可以分成 两组（像棋盘黑白格一样），相邻的结点必须不同组。
// 在同一组里的任意两个结点之间，距离一定是偶数步（因为走一步就到另一组，再走一步就回到自己组，两步一个循环）。
// 所以，从某个结点出发，偶数步能结束的地方，就是和它同组的所有结点（包括它自己）。
// 做法：
// 随便从1号结点开始，DFS 遍历整棵树。
// 用一个变量 walk 记录当前走了多少步，偶数步的归为一组，奇数步的归为另一组。
// 统计每组有多少人。
// 最后每个结点的答案 = 它所在组的人数。
// 复杂度: O(n) 时间，O(n) 空间。

const int N = 200010;

vector<int> a[N];   // 邻接表，a[u] 存储与 u 相连的所有结点
int b[3];         // b[1] = 组1的结点数，b[2] = 组2的结点数
int c[N];         // c[u] = 1 或 2，表示结点 u 属于哪个组

// 从 u 出发，已经走了 walk 步
void dfs(int u, int walk) {
    if (walk % 2 == 0) {
        c[u] = 2;       // 偶数步到达 → 组2
        b[2]++;
    } else {
        c[u] = 1;       // 奇数步到达 → 组1
        b[1]++;
    }
    for (int i = 0; i < a[u].size(); i ++) {
        int v = a[u][i];
        if (!c[v]) {            // 没染色才继续走
            dfs(v, walk + 1);     // 步数 +1
        }
    }
}

int main() {
    int n;
    cin >> n;

    // 读入 n-1 条边，建双向邻接表
    for (int i = 1; i < n; i ++) {
        int u, v;
        cin >> u >> v;
        a[u].push_back(v);
        a[v].push_back(u);
    }

    // 从结点1出发，步数0（偶数），开始DFS染色
    dfs(1, 0);

    // 输出：每个结点所属组的结点总数
    for (int i = 1; i <= n; i ++) {
        cout << b[c[i]] << " ";
    }

    return 0;
}
