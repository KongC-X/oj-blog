1927 - 最短的通路时间

题目描述

某市新规划了 NNN 个村庄（村庄编号为 1∼N1 \sim N1∼N ），现准备在这 NNN 个村庄之间修建 MMM 条道路，每条公路的连着两个村庄。

已知这 MMM 条道路每条路连接了哪两个村庄，以及什么时候这条路能修好。请问：最早什么时候任意两个村庄能够通车，即最早什么时候任意两条村庄都存在至少一条修完的道路（两个村庄之间可能有多条路）。

输入

第 111 行两个正整数 N,MN,MN,M。

下面 MMM 行，每行 333 个正整数 x,y,tx,y,tx,y,t，告诉你这条公路连着 x,yx,yx,y 两个村庄，在时间 ttt 时能修完成这条公路。

数据范围：

N≤1000,M≤100000N≤1000,M≤100000N≤1000,M≤100000，x≤N,y≤N,t≤100000x≤N,y≤N,t≤100000x≤N,y≤N,t≤100000。

输出

如果全部公路修完仍然存在两个村庄无法通车，则输出 −1-1−1 ，否则输出最早什么时候任意两个村庄能够通车。

AC代码

#include<bits/stdc++.h>
using namespace std;

//存储一条路连接的两端的编号 以及 修好的时间 
struct node{
    int x,y,t;
}a[100100]; 

int f[1100];//存储村庄之间是否有路的关系描述 

//查:查询元素的根 
int find(int x){
    return f[x]==x?x:f[x]=find(f[x]);
} 

//排序辅助函数:按时间升序 
bool cmp(node n1,node n2){
    return n1.t < n2.t;
} 

int main() {
    int n,m,i;
    cin>>n>>m;
    for(int i = 1;i <= m;i++){
        cin>>a[i].x>>a[i].y>>a[i].t;
    }
    
    //所有数据，按时间升序
    sort(a+1,a+1+m,cmp);
    
    //初始化
    for(int i = 1;i <= n;i++){
        f[i] = i;
    } 
    
    //合并（修路）
    int fx,fy,c = 0;
    for(int i = 1;i <= m;i++){
        fx = find(a[i].x);
        fy = find(a[i].y);
        
        //如果两者之间没有路
        if(fx != fy){
            f[fx] = fy;
            c++;
        } 
        
        if(c == n - 1){
            cout<<a[i].t;
            return 0;
        }
    } 
     
    cout<<-1;
    return 0;
}
