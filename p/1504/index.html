1504 - 约瑟夫问题

题目描述

约瑟夫问题来源于公元 111 世纪的犹太历史学家Josephus。问题描述，有 nnn 个人（分别以编号 1，2，3…n1，2，3 \dots n1，2，3…n 表示）围成一个圆圈，从编号为 111 的人开始进行 1∼m1 \sim m1∼m 正向报数，报到 mmm 的那个人出列；他的下一个人又从 111 开始报数，数到 mmm 的那个人又出列；如此重复下去，直到所有的人全部出列，求最后一个出列人的编号

输入

输入文件仅有一行包含二个用空格隔开的整数 NNN，MMM （ 2≤N≤1000002 \le N \le 1000002≤N≤100000，M≤109M \le 10^9M≤109）。

输出

输出文件仅有一行包含一个整数表示一个整数，表示最后一个人在队列中的编号。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int main()
{
    int n,m,i,a=0;
    while(scanf("%d%d",&n,&m)&&n!=0&&m!=0)
    {
        a=0;
        for(int i=2;i<=n;i++)
            a=(a+m)%i;
        printf("%d\n",a+1);
        return 0;
    }
}
