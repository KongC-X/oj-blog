1092 - aabb

题目描述

查找形如" $aabb$ "的四位完全平方数，也即前两位数字相同，后两位数字也相同。

输入

无。

输出

若干行，每行一个符合条件的四位数（从小到大）。

AC代码

AC代码

#include<iostream>
#include<cmath>
using namespace std;

int main(){
    int n,i,k = 0,a,b,c,d;
    for(i = 1000;i <= 9999;i++){
        a = i/1000;
        b = i/100%10;
        c = i/10%10;
        d = i%10;
        if(a == b & c == d & a != c) {
            if(sqrt(i) == int(sqrt(i))) {
                cout<<i<<endl;
            }
        }
    }
    
}
