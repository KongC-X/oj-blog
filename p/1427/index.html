1427 - 有趣的折扣

题目描述

新华书店准备举办一个周末打折活动，活动打折方案如下：

（1）客户买的书中最贵的那本书先打 999 折；（如果有多本最贵的书，那么只有 111 本可以打 999 折）

（2）在此基础上，按照客户购买书的总价再打 999 折；（最后的总价保留 111 位小数）

比如：张芳同学买了 555 本书， 555 本书的价格分别为： 109109109 989898 109109109 252525 303030 ，那么按照书店的折扣方案，张芳同学应付的总金额 = (109×0.9+98+109+25+30109 \times 0.9 + 98 + 109 + 25 + 30109×0.9+98+109+25+30) ×0.9\times 0.9×0.9 = 324.09324.09324.09 ，保留 111 位小数的结果为 324.1324.1324.1 元。

请你编写一个程序，帮助书店计算客户最后应付的金额。

输入

第 111 行是一个整数 nnn ，代表客户购买的书的数量（ n≤100n \le 100n≤100）。

第 222 行是 nnn 个整数，代表 nnn 本书的单价。

输出

客户最后应付的金额。

解题思路

AC代码

AC代码

#include<iostream>
#include<iomanip>
using namespace std;
int a[110],n;
double s=0;

int main() {
    cin>>n;
    for(int i=0; i<n; i++) {
        cin>>a[i];
    }
    int max = a[0];
    for(int i=0; i<n; i++) {
        if(a[i]>max) {
            max = a[i];
        }
        s += a[i];
    }
    //(总和-最贵的书价+最贵的书价*0.9)*0.9
    s = (s-max+max*0.9) * 0.9;
    cout<< fixed << setprecision(1) << s << endl;

}
