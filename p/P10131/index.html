P10131 [USACO24JAN] Majority Opinion B

洛谷 | 普及- | C++14 | 提交时间: 2026-08-24

算法标签：数学、USACO、2024、O2优化

题目描述

Farmer John 有一项重要的任务——弄清楚要为他的奶牛们购买什么类型的干草。

Farmer John 的 NNN 头奶牛（2≤N≤1052\le N\le 10^52≤N≤105）编号为 111 到 NNN，每头奶牛喜欢恰好一种类型的干草 hih_ihi​（1≤hi≤N1\le h_i\le N1≤hi​≤N）。他希望他的所有奶牛都喜欢同一种干草。

为了实现这一目标，Farmer John 可以主持焦点小组访谈。一次焦点小组访谈为让编号从 iii 到 jjj 的连续范围内的所有奶牛聚集在一起参加一次访谈。如果有一种干草是小组中超过一半的奶牛喜欢的，则此次焦点小组访谈结束后，所有奶牛最终都会喜欢这种干草。如果不存在这种类型的干草，那么奶牛们不会改变她们喜欢的干草类型。例如，在由 161616 头奶牛组成的焦点小组访谈中，需要有其中 999 头或更多的奶牛具有相同的干草喜好，才能使其余奶牛改变其喜好以与之一致。

Farmer John 想知道哪些类型的干草有可能变为同时受到所有奶牛的喜爱。他一次只能主持一个焦点小组访谈，但为了使所有奶牛都喜欢同一类型的干草，他可以根据需要任意多次地主持焦点小组访谈。

输入格式

输入的第一行包含一个整数 TTT，为独立的测试用例的数量（1≤T≤101\le T\le 101≤T≤10）。

每一个测试用例的第一行包含 NNN。

第二行包含 NNN 个整数，为奶牛们喜爱的干草类型 hih_ihi​。

输入保证所有测试用例的 NNN 之和不超过 2⋅1052\cdot 10^52⋅105。

输出格式

输出 TTT 行，对于每个测试用例输出一行。

如果可能使所有奶牛同时喜欢同一种干草，则以升序输出所有可能的此类干草的类型，否则输出 −1-1−1。在同一行内输出一列整数时，相邻的数用空格分隔，并确保行末没有多余空格。

样例

样例输入 #1

5
5
1 2 2 2 3
6
1 2 3 1 2 3
6
1 1 1 2 2 2
3
3 2 3
2
2 1```

**样例输出 #1**

2
-1
1 2
3
-1```

AC 代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P10131 [USACO24JAN] Majority Opinion B
     * 题意：给定奶牛喜欢的干草类型序列，每次可以选择一个连续区间，
     *       若区间内有超过半数的奶牛喜欢同一种类型，则区间内所有奶牛都会变成该类型。
     *       问最终有可能让所有奶牛统一成哪些类型，按升序输出，若无则输出 -1。
     *
     * 核心观察：
     * 一种类型 x 有可能成为最终统一类型，当且仅当序列中存在两个 x 相距不超过 2 个位置。
     * 换句话说，要么存在相邻的 x（即 x, x），要么存在中间隔一个的 x（即 x, ?, x）。
     *
     * 为什么？
     * 1. 如果序列中有两个 x 相邻（位置 i 和 i+1），则区间 [i, i+1] 中 x 占一半（2/2），
     *    但需要超过半数，所以单独这俩不够。但我们可以向右扩展：若 i+2 不是 x，
     *    区间 [i, i+2] 中有两个 x，占 2/3 > 1/2，所以 x 可以传播到 i+2，
     *    然后区间 [i, i+3] 中有三个 x（占 3/4）…… 这样 x 就能一直向右传播。
     *    同理也可以向左扩展。所以相邻的 x 可以扩展到整个序列。
     *
     * 2. 如果序列中有两个 x 中间隔一个位置（即 x, y, x），则区间 [i, i+2] 中有两个 x，
     *    占 2/3 > 1/2，所以中间的 y 会变成 x，形成相邻 x, x，然后就可以继续扩展。
     *
     * 3. 如果所有 x 之间距离都 ≥ 3，则任何区间内 x 的数量最多为区间长度的一半（或更少），
     *    不可能超过半数，因此 x 无法传播。
     *
     * 因此，我们只需扫描序列，检查每种类型是否存在相邻相同或隔一个相同，
     * 即可确定哪些类型有可能成为最终统一类型。
     */

    int T;
    cin >> T;
    while (T--) {
        int N;
        cin >> N;
        vector<int> h(N);
        for (int i = 0; i < N; i++) cin >> h[i];

        // 标记哪些类型可能可行，编号 1~N
        bool b[100005] = {false};

        for (int i = 0; i < N; i++) {
            // 检查当前元素与下一个是否相同（相邻）
            if (i + 1 < N && h[i] == h[i + 1]) {
                b[h[i]] = true;
            }
            // 检查当前元素与下下个是否相同（间隔一个）
            if (i + 2 < N && h[i] == h[i + 2]) {
                b[h[i]] = true;
            }
        }

        // 收集所有可行类型并按升序输出
        vector<int> a;
        for (int x = 1; x <= N; x++) {
            if (b[x]) a.push_back(x);
        }

        if (a.empty()) {
            cout << -1 << endl;
        } else {
            for (int i = 0; i < a.size(); i++) {
                cout << a[i] << ' ';
            }
            cout << endl;
        }
    }
    return 0;
}
