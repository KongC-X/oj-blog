1565 - 成绩（score）

题目描述

牛牛最近学习了 C++C++C++ 入门课程，这门课程的总成绩计算方法是：

总成绩=作业成绩 ×\times× 20%20\%20% + 小测成绩 ×\times× 30%30\%30% + 期末考试成绩 ×\times× 50%50\%50%。

牛牛想知道，这门课程自己最终能得到多少分。

输入

三个非负整数 A、B、CA、B、CA、B、C ，分别表示牛牛的作业成绩、小测成绩和期末考试成绩。

相邻两个数之间用一个空格隔开，三项成绩满分都是 100100100 分。

输出

一个整数，即牛牛这门课程的总成绩，满分也是 100100100 分。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int main(){
    double a,b,c;
    cin>>a>>b>>c;
    cout<<a*0.2+b*0.3+c*0.5;
    return 0;
}
