1577 - 游戏

题目描述

上了半天的物理数学课，大家的脑子有点转不动了，下午的课表似乎看透了同学们的心思，第一节就安排了体育课，CZCZCZ 中学的课表真是太有爱了，赞一个！

午间休息后，文体委员小 SSS 喊大家到教室外的走廊上排队，队形整好后小 SSS 带着大家走到了大操场上，体育老师早就在那等着了，他先安排同学们做了五分钟的准备活动，接下来让大家玩一个有趣的游戏，在这个游戏里，全班同学先散开站在操场上，同学们轮流玩这个游戏，从 111 号同学开始，然后是 222 号 333 号等等 （只要这个同学仍然参与这个游戏）。

每次轮到玩的同学，就选择一个目前离他最近的同学，走过去拍他一下，然后回到原来的位置，那个被拍到的同学就被排除在游戏之外了，必须立刻离开操场。当操场上只剩下一个同学时，游戏即告结束，最后站在操场上的那个同学就是赢家。

RRR 老师 正和隔壁班的 FFF 主任津津有味地在场边看着同学们做游戏，为了添加一点乐 趣，RRR 老师就和 FFF 主任打赌哪个同学会赢？所以他想事先知道谁是赢家。RRR 老师希望你写 一个程序，读入同学们相互之间的距离，模拟出哪个同学最终会获胜。

输入

输入数据第一行为一个正整数 NNN， 表示在操场上玩游戏的人数，其中 1≤N≤10001≤N≤10001≤N≤1000；

接下来共有 NNN 行数据，每行有 NNN 个用空格隔开的整数，其中第 iii 行第 jjj 列的数据表示操场上编号为 iii 的同学与编号为 jjj 的同学之间的距离。

输入数据保证第 iii 行第 iii 列（主对角线上的位置）的数据均为 000，其余数据均为正整数，且第 iii 行第 jjj 列的数据一定等于第 jjj 行 第 iii 列的数据，这意味着同学甲到同学乙的距离等于同学乙到同学甲的距离；操场上任意两对同学之间的距离均不相同，也就是说上三角部分的正整数互不相同。

输出

输出数据仅有一行包含一个正整数表示获胜的同学的编号。

AC代码

AC代码

#include <iostream>
using namespace std;

int n, d[1005][1005];
bool out[1005];

int main() {
    cin >> n;
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= n; ++j)
            cin >> d[i][j];

    int cur = 1, left = n;
    while (left > 1) {
        // 找到离 cur 最近的未出局同学
        int nearest = 0, minDist = 1e9;
        for (int i = 1; i <= n; i++) {
            if (!out[i] && i != cur && d[cur][i] < minDist) {
                minDist = d[cur][i];
                nearest = i;
            }
        }
        out[nearest] = true;   // 被拍的同学出局
        left--;

        // 找到下一个存活的同学（按编号循环）
        do {
            cur = cur % n + 1;
        } while (out[cur]);
        
        // cur = cur % n + 1;          // 先移动到下一个编号
        // while (out[cur]) {          // 如果该编号已出局，继续循环
        //     cur = cur % n + 1;
        // }
    }

    // 输出最后剩下的同学
    for (int i = 1; i <= n; ++i)
        if (!out[i]) cout << i << endl;

    return 0;
}
