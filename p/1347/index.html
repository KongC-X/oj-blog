1347 - 游览动物园

题目描述

动物园有很多游览区，小红已经在动物园的一个游览区游览，突然接到电话，要半个小时内到动物园外面跟一个朋友见面。半个小时小红只够游览完当前区域之后，游览一个最近的景区。

已知从一个游览区域只能沿着地图（地图的长宽均小于 100100100 ）中的直线走（上下左右四个方向），请问离小红当前游览区的最近的一个游览区的坐标是多少，如果有多个点离小红的位置都很近，请输出离出口最近的那个点的坐标（不存在多个点距离出口一样近）？

例如：假设小红在孔雀区（ 3,23,23,2 ），离小红最近的 222 处游览区分别是猴山（ 2,02,02,0 ）和虎山（ 5,35,35,3 ），但猴山离入口更近，因此输出猴山的坐标。

输入

第一行 222 个变量，为小红所在的游览区的坐标

第二行一个整数 nnn ，为该动物园内游览区的数量（ n≤100n \le 100n≤100 ）

接下来的 nnn 行，每行 222 个数，代表动物园的 nnn 个游览区的坐标（本题所有的坐标值都在 1∼10001 \sim 10001∼1000 的范围内）

输出

离小红最近的游览区的坐标

解题思路

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int s1,s2;//小红的位置 
int r1,r2;//存储结果
int mi = INT_MAX;//表示离小红最近的距离 
int n;

int dis(int x1,int y1,int x2, int y2){
    return abs(x1-x2)+abs(y1-y2);
} 

int main() {
    cin>>s1>>s2>>n;
    
    //读入n组数据 
    int x,y;
    for(int i = 1;i <= n;i++){
        cin>>x>>y;
        if(x == s1 && y == s2) continue;
        
        //如果该点离小红更近，或者一样近且距离出口更近
        int d = dis(x,y,s1,s2);
        if(d<mi || d==mi&&dis(x,y,0,0)<dis(r1,r2,0,0)){
            r1 = x;
            r2 = y;
            mi = d;
        }
    }
    
    cout<<r1<<" "<<r2;
    return 0;
}
