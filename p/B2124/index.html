B2124 判断字符串是否为回文

洛谷 | 入门 | C++14 | 提交时间: 2026-07-12

算法标签：字符串（入门）

题目描述

输入一个字符串，输出该字符串是否回文。回文是指顺读和倒读都一样的字符串。

输入格式

输入一行字符串，长度小于 100100100。

输出格式

如果字符串是回文，输出 yes；否则，输出 no。

样例

样例输入 #1

abcdedcba```

**样例输出 #1**

yes```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    string a;
    getline(cin, a);          // 读取整行，防止空格
    string b = a;
    reverse(a.begin(), a.end());
    if (a == b) cout << "yes" << endl;
    else        cout << "no" << endl;
    return 0;
}
