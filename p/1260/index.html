1260 - 三色球问题

题目描述

一个口袋里有 121212 个球，其中有三个红球，三个白球，六个黑球

从其中取 888 个球，问有多少种颜色搭配？

输入

无

输出

输出搭配种类个数

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    //i,j,k分别代表红，白，黑球
    //s用作计数器 
    int i,j,k,s=0;
    
    //遍历取出的8个球中，红色球可能的个数 
    for(i=0;i<=3;i++){
        //遍历取出的8个球中，白色球可能的个数 
        for(j=0;j<=3;j++){
            //遍历取出的8个球中，黑色球可能的个数 
            for(k=0;k<=6;k++){
                //三种颜色的球个数总和要等于8 
                if(i+j+k==8){
                    s++;
                }
            }
        }
    }
    
    cout<<s;
    return 0;
}
