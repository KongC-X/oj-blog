1953 - 新生舞会

题目描述

新生舞会开始了。

nnn 名新生每人有三个属性：姓名、学号、性别。其中，姓名用长度不超过 202020 的仅由大小写字母构成的字符串表示，学号用长度不超过 101010 的仅由数字构成的字符串表示，性别用一个大写字符 F 或 M 表示。任意两人的姓名、学号均互不相同。换言之，每个人可被其姓名或学号唯一确定。

给出 mmm 对两人的信息（姓名或学号），判断他们是否能共舞。两人能共舞的充要条件为两人性别相异。

输入

第一行一个整数 nnn（2≤n≤10002 \le n \le 10002≤n≤1000），表示学生人数。接下来的 nnn 行每行依次包含一名新生的姓名、学号、性别，分别用一个空格隔开。

之后的一行是一个整数 mmm (1≤m≤10001 \le m \le 10001≤m≤1000)，表示询问的数目。

接着的 mmm 行每行包含两个信息（姓名或学号），保证两个信息不属于同一人，中间用一个空格隔开。

输出

对于每个询问输出一行，如果两人可以共舞，输出一个大写字母 Y，否则输出一个大写字母 N。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int n; //人员数量
struct person
{
    string name;
    string num;
    char c;
}a[1005];

char findp(string s)
{
    for(int i = 0; i < n; i++)
    {
        if(a[i].name == s || a[i].num == s) return a[i].c;
    }
    return '0';
}

int main()
{

    cin >> n;
    for(int i = 0; i < n; i++)
    {
        cin >> a[i].name >> a[i].num >> a[i].c;
    }
    int m;
    cin >> m;
    for(int i = 0; i < m; i++)
    {
        string x, y;
        cin >> x >> y;
        if(findp(x) != findp(y)) cout << "Y" << endl;
        else cout << "N" << endl;
    }
    return 0;
}
