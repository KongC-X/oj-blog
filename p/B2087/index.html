B2087 与指定数字相同的数的个数

洛谷 | 入门 | C++14 | 提交时间: 2026-07-02

题目描述

输出一个整数序列中与指定数字相同的数的个数。

输入格式

输入包含三行：

第一行为 nnn，表示整数序列的长度（n≤100n\le100n≤100）；

第二行为 nnn 个整数，整数之间以一个空格分开；

第三行包含一个整数，为指定的整数 mmm。

输出格式

输出为 nnn 个数中与 mmm 相同的数的个数。

样例

样例输入 #1

3
2 3 2
2```

**样例输出 #1**

2```

AC 代码

#include<bits/stdc++.h>
using namespace std;
int main(){
     int n,a[105],m,cnt=0;
     cin>>n;
     for(int i=1;i<=n;i++)
         cin>>a[i];
     cin>>m;
     for(int i=1;i<=n;i++)
         if(a[i]==m)
             cnt++;
     cout<<cnt<<endl;
     return 0;
}
