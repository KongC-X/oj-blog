1477 - 字符串出现次数

题目描述

一个字符串中任意个连续的字符组成的子序列为该字符串的子串。给定子串 s1s_1s1​ 和它的一个字符串 s2s_2s2​ ，求 s1s_1s1​ 在 s2s_2s2​ 中出现的次数。

输入

第一行，表示字符串 s1s_1s1​ ， 第二行，表示字符串 s2s_2s2​ 。

输出

一个整数，代表 s1s_1s1​ 在 s2s_2s2​ 中出现的次数。

AC代码

AC代码

// find()方法：
#include<iostream> 
#include<bits/stdc++.h> 
using namespace std;
int main(){
    string s,s1;
    int p,k = 0;
    getline(cin,s1);
    getline(cin,s);
    p = s.find(s1);
    while(p != -1) {
        k++;
        p = s.find(s1,p + 1);
    }
    cout << k << endl;
}
