1351 - 买公园门票

题目描述

某公园门票价格为：成人票 888 元 /// 张，儿童票 333 元 /// 张；某旅游团来公园游玩，该团内有成人和儿童（成人和儿童都有），共花了 404040 元买门票。

请你分别计算出成人和儿童可能的人数，按照成人从少到多，儿童从多到少的规律数出结果。

（ 7.27.27.2 ）

输入

无

输出

若干行，每行 222 个整数用空格隔开，分别代表成人和儿童可能的人数。（成人从少到多，儿童从多到少）

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int x,y; // x表示成人票，y表示儿童票
    for(x = 1;x <= 5;x++) {
        for(y = 1;y <= 14;y++) {
            if (x * 8 + y * 3 == 40) {
                cout << x << " " << y << endl;
            }
        }
    }
}
