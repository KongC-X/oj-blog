B4192 [海淀区小学组 2023] 分数线

洛谷 | 普及- | C++14 | 提交时间: 2026-07-22

算法标签：2023、北京、前缀和、科创活动、小学活动

题目背景

2023 年海淀区中小学生信息学竞赛小学组复赛题目，数据为洛谷自造。

为更好区分不同做法，本题时限下调到 500 毫秒。

题目描述

一次比赛中，所有参加比赛的选手都获得了一个分数 sss。已知有 c1c_1c1​ 个同学得 111 分，c2c_2c2​ 个同学得 222 分，……，cmc_mcm​ 个同学得 mmm 分。

请你划定一个分数线 kkk，使得不低于分数线 kkk 的人数 n1n_1n1​ 和低于分数线 kkk 的人数 n2n_2n2​ 均在给定的一个范围 [x,y][x, y][x,y] 之内，即 x≤n1≤yx \leq n_1 \leq yx≤n1​≤y，x≤n2≤yx \leq n_2 \leq yx≤n2​≤y。

保证 sss 和 kkk 一定是整数，且 1≤s≤m1 \leq s \leq m1≤s≤m，1≤k≤m1 \leq k \leq m1≤k≤m。

输入格式

第一行仅有一个正整数 mmm；第二行包含 mmm 个整数 c1,c2,…,cmc_1, c_2, \ldots, c_mc1​,c2​,…,cm​，两两之间以空格分隔，数据保证至少有一个 cic_ici​ 大于 000；第三行包含两个用空格分隔的整数 xxx 和 yyy。

输出格式

如果不存在满足条件的分数线，输出 000。否则，输出一个分符合题目要求的分数线。如果有多个答案，输出符合条件的答案中最小的那一个。

样例

样例输入 #1

5
3 4 3 2 1
6 8```

**样例输出 #1**

3```

样例输入 #2

5
0 3 3 4 2
3 10```

**样例输出 #2**

3```

样例输入 #3

2
2 5
3 6```

**样例输出 #3**

0```

AC 代码

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const int MAXM = 100005;
int m;
ll c[MAXM];          // c[i] 表示得 i 分的人数（1‑based）
ll s[MAXM];          // 前缀和，s[i] = c[1]+...+c[i]，s[0]=0

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> m;
    for (int i = 1; i <= m; i++) {
        cin >> c[i];
    }
    ll x, y;
    cin >> x >> y;

    // 计算前缀和
    s[0] = 0;
    for (int i = 1; i <= m; i++) {
        s[i] = s[i - 1] + c[i];
    }
    ll total = s[m];                     // 总人数

    int ans = 0;                         // 记录最小的 k，0 表示未找到
    for (int k = 1; k <= m; k++) {
        ll lower = s[k - 1];             // 低于 k 的人数
        ll upper = total - lower;        // 不低于 k 的人数

        if (lower >= x && lower <= y && upper >= x && upper <= y) {
            ans = k;
            break;                       // 找最小，找到即退出
        }
    }

    cout << ans << "\n";
    return 0;
}
