B4240 [海淀区小学组 2024] 最短字符串

洛谷 | 普及- | C++14 | 提交时间: 2026-07-27

算法标签：2025、北京、双指针 two-pointer、科创活动、小学活动

题目背景

2024 年海淀区中小学生信息学竞赛小学组复赛题目，数据为洛谷自造。

题目描述

给定一个仅由大小写字母构成的长度为 nnn 的字符串 SSS，求字符串 SSS 的一个子串 TTT，使得字符串 TTT 中包含字符串 SSS 中所有种类的字母（区分大小写），输出子串 TTT 的最小长度。例如，如果 S=aabCceS = \tt{aabCce}S=aabCce，则 SSS 中包含的不同种类的字母有 a\tt aa，b\tt bb，C\tt CC，c\tt cc，e\tt ee，要子串中包含全部的这五类字母，则子串的索引区间为 [2,6][2, 6][2,6]，即 SSS 中的第 222 个字符到第 666 个字符，即字符串 abCce\tt{abCce}abCce。

输入格式

第一行仅有一个整数 nnn，第二行包含一个符合题目要求的长度为 nnn 的字符串 SSS。

输出格式

仅有一个不超过 nnn 的正整数，表示符合题目要求的子串的最小长度。

样例

样例输入 #1

3
AaA```

**样例输出 #1**

2```

样例输入 #2

7
bcAAcbc```

**样例输出 #2**

3```

样例输入 #3

6
aaBCCe```

**样例输出 #3**

5```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
      思路：
      1. 读入字符串长度 n 和字符串 S。
      2. 统计 S 中不同字母的总数 total（大小写区分，共52种可能）。
      3. 使用滑动窗口（双指针）求最短子串长度：
         - 右指针 r 向右移动，将 S[r] 加入窗口，更新计数。
         - 当窗口内包含了全部 total 种字母时，尝试右移左指针 l 缩小窗口，
           更新最短长度，直到窗口不再包含全部字母。
         - 重复直到 r 遍历完整个字符串。
      4. 输出最短子串长度。
    */

    int n;                     // 字符串长度（其实用不到，但读入）
    string s;                  // 输入的字符串
    cin >> n >> s;

    // 统计不同字母总数
    bool vis[52] = {false};    // 标记每种字母是否出现过（0-25大写，26-51小写）
    int total = 0;             // 不同字母的总类数
    for (int i = 0; i < n; i++) {
        int id;                // 字母对应的索引
        if (s[i] >= 'A' && s[i] <= 'Z')
            id = s[i] - 'A';          // 大写字母 0~25
        else
            id = 26 + (s[i] - 'a');   // 小写字母 26~51
        if (!vis[id]) {
            vis[id] = true;
            total++;
        }
    }

    int cnt[52] = {0};         // 当前窗口内各字母的数量
    int l = 0;                 // 窗口左边界
    int kind = 0;              // 当前窗口内不同字母的种数
    int ans = n;               // 最短长度，初始最大可能值

    for (int r = 0; r < n; r++) {
        // 将 s[r] 加入窗口
        int id;
        if (s[r] >= 'A' && s[r] <= 'Z')
            id = s[r] - 'A';
        else
            id = 26 + (s[r] - 'a');

        if (cnt[id] == 0) kind++;   // 新出现一种字母
        cnt[id]++;

        // 当窗口包含了全部种类，尝试缩小左边界
        while (kind == total) {
            // 更新最短长度
            if (r - l + 1 < ans) ans = r - l + 1;
            // 移动左边界，将 s[l] 移出窗口
            int lid;
            if (s[l] >= 'A' && s[l] <= 'Z')
                lid = s[l] - 'A';
            else
                lid = 26 + (s[l] - 'a');
            cnt[lid]--;
            if (cnt[lid] == 0) kind--; // 该字母在窗口中消失
            l++;
        }
    }

    cout << ans << endl;
    return 0;
}
