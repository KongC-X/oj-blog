P17829 [CSP-J 2026] 按位与 / and（民间数据）

洛谷 | 普及| C++14 | 提交时间: 2026-11-01

算法标签：贪心、O2优化、进制、位运算、2026、CSP-J 入门级

题目描述

小 R 有 nnn 个非负整数 a1,a2,…,ana_1,a_2,\ldots,a_na1​,a2​,…,an​。

小 X 给了小 R 一个正整数 mmm，并要求小 R 从这 nnn 个非负整数中选出恰好 mmm 个，使得选出的 mmm 个数的二进制按位与的值最大。

你需要帮助小 R 求出，他能选出的 mmm 个数的按位与的最大值。

输入格式

从文件 and.in 中读入数据。

输入的第一行包含两个正整数 n,mn,mn,m。

输入的第二行包含 nnn 个非负整数 a1,a2,…,ana_1,a_2,\ldots,a_na1​,a2​,…,an​，依次表示小 R 的 nnn 个非负整数。

输出格式

输出到文件 and.out 中。

输出一行一个非负整数，表示小 R 能选出的 mmm 个数的按位与的最大值。

样例

样例输入 #1

4 2
3 15 12 12```

**样例输出 #1**

12```

样例输入 #2

5 3
31 3 1 15 7```

**样例输出 #2**

7```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int a[200005];   // a[i]: 第 i 个非负整数

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) cin >> a[i];

    int ans = 0;                    // 已经确定下来的答案
    for (int k = 29; k >= 0; k--) { // 从最高位往低位贪心
        int t = ans | (1 << k);     // 假设第 k 位也能取到 1
        int cnt = 0;
        for (int i = 1; i <= n; i++)
            if ((a[i] & t) == t) cnt++;   // 这个数能提供 t 里全部为 1 的位

        if (cnt >= m) ans = t;      // 至少 m 个数能提供，这一位就保住
    }

    cout << ans << endl;
    return 0;
}
