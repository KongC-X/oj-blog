1262 - 该存多少钱

题目描述

假设银行一年整存零取的月息为 $0.63 %$。现在某人手中有一笔钱，他打算在今后的五年中的年底取出 $1000$ 元，到第五年时刚好取完，请算出他存钱时应存入多少。

输入

无

输出

第一年年初要存入多少钱，结果保留 $2$ 位小数。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    //存的钱m 
    double m = 0;
    
    for(int i=1;i<=5;i++){ 
        m = (m+1000) / (1+0.0063*12);
    }
    cout<<fixed<<setprecision(2)<<m<<endl;
    return 0;
}
