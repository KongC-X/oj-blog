1267 - 完全平方数

题目描述

一个非负整数 nnn ，加上 100100100 是得到的 n+100n+100n+100 一个完全平方数，在加 100100100 的基础上再加上 168168168 得到的 n+100+168n+100+168n+100+168 又是一个完全平方数，请问该数最小是多少？

输入

无

输出

符合条件的最小的数

AC代码

AC代码

#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int i = 0;
    while(++i) {
        if(sqrt(i + 100) == int(sqrt(i + 100)) && sqrt(i + 268) == int(sqrt(i + 268))) {
            cout << i << endl;
            break;
        }
    }
}
