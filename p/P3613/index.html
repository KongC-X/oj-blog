P3613 【深基15.例2】寄包柜

洛谷 | 普及- | C++14 | 提交时间: 2026-05-15

题目描述

超市里有 $n(1\le n\le10^5)$ 个寄包柜。每个寄包柜格子数量不一，第 $i$ 个寄包柜有 $a_i(0\le a_i\le10^5)$ 个格子，不过我们并不知道各个 $a_i$ 的值。对于每个寄包柜，格子编号从 1 开始，一直到 $a_i$。现在有 $q(1 \le q\le10^5)$ 次操作：

  • 1 i j k：在第 $i$ 个柜子的第 $j$ 个格子存入物品 $k(0\le k\le 10^9)$。当 $k=0$ 时说明清空该格子。
  • 2 i j：查询第 $i$ 个柜子的第 $j$ 个格子中的物品是什么，保证查询的柜子有存过东西。

已知超市里共计不会超过 $10^7$ 个寄包格子，$a_i$ 是确定然而未知的，但是保证一定不小于该柜子存物品请求的格子编号的最大值。当然也有可能某些寄包柜中一个格子都没有。

输入格式

第一行 2 个整数 $n$ 和 $q$，寄包柜个数和询问次数。

接下来 $q$ 个行，每行有若干个整数，表示一次操作。

输出格式

对于查询操作时，输出答案，以换行隔开。

样例

样例输入 #1

5 4
1 3 10000 118014
1 1 1 1
2 3 10000
2 1 1```

**样例输出 #1**

118014
1```

AC 代码

#include <bits/stdc++.h>   // 万能头文件
using namespace std;

/*
【题目思路与解题过程】
题意：n 个寄包柜，每个柜子的格子数 a[i] 未知但总和不超过 1e7。
     q 次操作：1 i j k 表示在第 i 个柜子的第 j 个格子存物品 k (k=0 清空)；
              2 i j 表示查询第 i 个柜子的第 j 个格子中的物品。

解题思路：
1. 若对每个柜子直接开 a[i] 个格子的数组，总格子数 ≤ 1e7，实际存储所有格子是可行的！
   题目说“超市里共计不会超过 1e7 个寄包格子”，也就是 ∑a[i] ≤ 1e7。
2. 因此我们可以用 vector<int> 的动态数组，为每个柜子维护一个 vector，
   当需要访问第 j 个格子时，若当前 vector 的长度不够，就 resize(j+1, 0)，
   其中 0 表示空格子。这样所有柜子的 vector 实际长度之和 ≤ 1e7。
3. 存入操作：a[i][j] = k；查询操作：直接输出 a[i][j]。
4. 时间复杂度：每次 resize 可能复制元素，但每个柜子的 vector 长度最多扩展到 a[i]，
   总复制开销与 ∑a[i] 同阶，即 O(1e7)，可轻松通过。
*/

int main() {
    ios::sync_with_stdio(false); // 加速 cin/cout
    cin.tie(0);
    
    int n, q;                     // n: 柜子个数, q: 操作次数
    cin >> n >> q;
    
    // a[i] 表示第 i 个柜子的格子数组，下标 j 对应格子编号
    vector<vector<int>> a(n + 1); // 0 号下标不使用
    
    while (q--) {
        int op;                   // op: 操作类型
        cin >> op;
        if (op == 1) {
            int i, j, k;          // i: 柜子编号, j: 格子编号, k: 物品编号（0 表示清空）
            cin >> i >> j >> k;
            if (a[i].size() <= j) {
                // 格子编号从 1 开始，需要至少 j+1 的长度才能用下标 j
                a[i].resize(j + 1, 0);
            }
            a[i][j] = k;          // 存入或清空
        } else {
            int i, j;             // 查询第 i 个柜子的第 j 个格子
            cin >> i >> j;
            cout << a[i][j] << '\n'; // 题目保证该格子一定存过东西，所以必然已 resize
        }
    }
    
    return 0;
}
