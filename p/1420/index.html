1420 - 已知正方形的周长求面积

题目描述

已知一个正方形的周长为整数 nnn ，请问该正方形的面积是多少？

输入

一个整数 nnn 代表正方形的周长。

输出

一个小数，代表正方形的面积（保留 222 位小数）。

解题思路

AC代码

AC代码

#include <iostream>
#include <iomanip>
using namespace std;

int main(){
    //定义整数变量n作为周长 
    int n;
    //输入n
    cin>>n;
    //定义小数变量l作为边长，根据正方形边长=周长/4.0 
    double l = n/4.0;  
    //正方形面积=边长*边长，输出结果保留2位小数 
    cout<<fixed<<setprecision(2)<<l*l<<endl;
    return 0;
}
