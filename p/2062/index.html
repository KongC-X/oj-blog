2062 - 倒水

题目描述

在一个桌子上摆放了 nnn 个杯子，每个杯子中有一定量的水。小 AAA 同学负责向杯子中倒水，他总共倒了 kkk 次，每次会向从第 LLL 个杯子到第 RRR 个杯子中添加 PPP 毫升的水（注意：水只可能增加，不可能减少）。

请问小 AAA 同学倒了 kkk 次水之后， nnn 个杯子每个杯子有多少毫升的水。

输入

第一行包含两个整数 nnn 和 kkk。

第二行包含 nnn 个整数，表示一开始每个杯子中水的毫升数。

接下来 kkk 行，每行包含三个整数 L,R,PL,R,PL,R,P，表示一次操作。

数据范围

1≤n,k≤1000001≤n,k≤1000001≤n,k≤100000。

1≤L≤R≤n1≤L≤R≤n1≤L≤R≤n，0≤P≤10000≤P≤10000≤P≤1000。

杯子中水的初始量在 [0,1000][0,1000][0,1000] 的范围内。

本题数据上保证所有的杯子在加水之后，水量值仍然在 int 范围内。

输出

共一行，包含 nnn 个整数，表示最终 nnn 个杯子每个杯子有多少毫升的水。

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
using namespace std;

// 解法二：读入时直接求差分数组
const int N = 100010;
int a[N], b[N]; // a是原数组，b是差分数组
int n,k,l,r,p;

int main() {
    cin >> n >> k;
    for(int i = 1; i <= n; i++) {
        cin >> p; // 读入时直接求差分数组
        // 求差分数组
        b[i] = b[i] + p;
        b[i+1] = b[i+1] - p;
    }
    // k次操作
    for(int i = 1; i <= k; i++) {
        cin >> l >> r >> p;
        b[l] = b[l] + p;
        b[r+1] = b[r+1] - p;
    }
    // 求b数组的前缀和
    for(int i = 1; i <= n; i++) {
        b[i] = b[i - 1] + b[i];
        cout << b[i] << " ";
    }
}
