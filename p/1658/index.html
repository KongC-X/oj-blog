1658 - 游乐设施

题目描述

游乐场引进了一个新的游乐设施，可以两人一组开动该设施，但设施设计上有一个缺陷，必须一个人的体重在 606060 公斤以上（包含 606060 公斤），另一个人体重在 606060 公斤以下，才能启动该设施。

请你编程从键盘读入两个游客的体重，判断一下设施能否启动，如果能启动输出 green，不能启动输出 red 。

比如输入：65.265.265.2 28.528.528.5，就可以启动设施，输出 green 。

再比如输入：28.528.528.5 56.756.756.7，就不能启动设施，输出 red 。

输入

两个小数，代表两位游客的体重。

输出

如果能启动输出 green ，不能启动输出 red 。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    double a,b;
    cin>>a>>b;
    
    if((a>=60&&b<60)||(a<60&&b>=60)){
        cout<<"green";
    }else{
        cout<<"red";
    }
    return 0;
}
