2183 - 求二叉树的深度及遍历结果

题目描述

从键盘读入一棵二叉树，请问这棵二叉树的深度是多少？这棵二叉树如果后序遍历的结果是什么？

输入

第 111 行输入一个整数 nnn ，代表读入的数据数量。（n≤100n≤100n≤100）

第 222 行读入 nnn 个非负整数，代表读入的数据，读入的整数中，如果值大于 000 ，代表的是二叉树的结点，如果值等于000 ，代表当前结点为空。（根结点的深度为 111 ）

二叉树的构造按照层次顺序（即第 111 层 111 个整数，第 222 层 222 个，第 333 层 444 个，第 444 层有 888 个.........，如果某个结点不存在以 000 代替）。

样例数据确保读入的第 nnn 个整数 >0>0>0。

输出

输出有 222 行；

第 111 行输出该二叉树的深度；

第 222 行输出后序遍历二叉树得到的序列，数字之间用空格隔开；

AC代码

#include <bits/stdc++.h>
using namespace std;

/*
用数组读入二叉树
i号结点的左孩子一定是：2*i
i号结点的有孩子一定是：2*i+1 
*/
const int N = 110;
int a[N];
int n; 

//后序遍历
void dfs(int x){
    if(x*2<=n&&a[x*2]) dfs(x*2);
    if(x*2+1<=n&&a[x*2+1]) dfs(x*2+1);
    cout<<a[x]<<" ";//左右根 
} 

int main(){
    cin>>n;
    for(int i = 1;i <= n;i++){
        cin>>a[i];
    }
    
    //int(log2(n)) + 1
    cout<<(int)log2(n) + 1<<endl;
    //后序遍历的结果 
    dfs(1);//从下标（编号）为1的点开始深搜 
    return 0;
}
