B4260 [GESP202503 二级] 时间跨越

洛谷 | 普及- | C++14 | 提交时间: 2025-03-28

算法标签：模拟、2025、分支结构、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1174

题目描述

假设现在是 $y$ 年 $m$ 月 $d$ 日 $h$ 时而 $k$ 小时后是 $y'$ 年 $m'$ 月 $d'$ 日 $h'$ 时，对于给定的 $y, m, d, h, k$，小杨想请你帮他计算出对应的 $y', m', d', h'$ 是多少。

输入格式

输入包含五行，每行一个正整数，分别代表 $y, m, d, h, k$。

输出格式

输出四个正整数，代表 $y', m', d', h'$。

样例

样例输入 #1

2008
2
28
23
1```

**样例输出 #1**

2008 2 29 0```

AC 代码

#include <iostream>
using namespace std;
int main()
{
    int y, m, d, h, k;
    cin >> y >> m >> d >> h >> k;
    h += k;
    if (h >= 24)
    {
        h -= 24;
        d += 1;
        int days = 0;
        if (m == 1 || m == 3 || m == 5 || m == 7 || m == 8 || m == 10 || m == 12)
        {
            days = 31;
        }
        else if (m == 4 || m == 6 || m == 9 || m == 11)
        {
            days = 30;
        }
        else if (m == 2)
        {
            if ((y % 4 == 0 && y % 100 != 0) || (y % 400 == 0))
            {
                days = 29;
            }
            else
            {
                days = 28;
            }
        }
        if (d > days)
        {
            d -= days;
            m += 1;
            if (m > 12)
            {
                m = 1;
                y += 1;
            }
        }
    }
    cout << y << " " << m << " " << d << " " << h << "\n";
    return 0;
}
