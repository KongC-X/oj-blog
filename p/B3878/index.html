B3878 [信息与未来 2015] 连续数的和

洛谷 | 普及- | C++14 | 提交时间: 2025-06-18

算法标签：2015、江苏、枚举、信息与未来

题目描述

给出两个整数 $n$ 和 $k$，求出 $1\sim n$ 中连续 $k$ 个数的和为完全平方数的个数。

输入格式

一行两个整数 $n,k$。

输出格式

一行一个整数，即 $1\sim n$ 中连续 $k$ 个数的和为平方数的个数。

样例

样例输入 #1

10 3```

**样例输出 #1**

1```

AC 代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

const int N = 100010;
int c = 0, i, n, k, x;
int a[N], qz[N];
int main() {
    cin >> n >> k;
    for (i = 1; i <= n; ++i){
        qz[i] = qz[i - 1] + i;
    }
    for (i = k; i <= n; ++i) {
        x = qz[i] - qz[i - k];
        if (int(sqrt(x)) * int(sqrt(x)) == x){
            c++;
        }
    }
    cout << c << endl;
}
