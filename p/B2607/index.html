题目描述

一只小猴买了若干个桃子。第一天他刚好吃了这些桃子的一半，又贪嘴多吃了一个；第二天他也刚好吃了剩余桃子的一半，贪嘴多吃了一个；第三天他又刚好吃了剩下的桃子的一半，并贪嘴多吃了一个。第四天起来一看，发现桃子只剩下一个了。请问小猴买了几个桃子？

输出格式

输出一个整数表示答案。

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】逆推模拟
     * 【核心思路】
     * 1. 设 t = 1，表示第四天早上剩下的桃子数。
     * 2. 往前逆推 3 天（第三、二、一天）：
     *    - 每天逆推公式：前一天桃子数 = (当前桃子数 + 1) * 2
     * 3. 输出最终 t。
     *
     * 【时间复杂度】O(1)
     */

    int t = 1;          // t: 当前早上的桃子数（从第四天开始）
    for (int i = 1; i <= 3; i++) {
        t = (t + 1) * 2;   // 逆推前一天
    }

    cout << t << endl;
    return 0;
}
