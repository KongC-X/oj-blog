P1044 [NOIP 2003 普及组] 栈

洛谷 | 普及- | C++14 | 提交时间: 2026-02-12

算法标签：动态规划 DP、数学、递推、2003、NOIP 普及组、Catalan 数、栈

题目背景

栈是计算机中经典的数据结构，简单的说，栈就是限制在一端进行插入删除操作的线性表。

栈有两种最重要的操作，即 pop（从栈顶弹出一个元素）和 push（将一个元素进栈）。

栈的重要性不言自明，任何一门数据结构的课程都会介绍栈。宁宁同学在复习栈的基本概念时，想到了一个书上没有讲过的问题，而他自己无法给出答案，所以需要你的帮忙。

题目描述

宁宁考虑的是这样一个问题：一个操作数序列，1,2,…,n1,2,\ldots ,n1,2,…,n（图示为 1 到 3 的情况），栈 A 的深度大于 nnn。

现在可以进行两种操作，

  1. 将一个数，从操作数序列的头端移到栈的头端（对应数据结构栈的 push 操作）
  2. 将一个数，从栈的头端移到输出序列的尾端（对应数据结构栈的 pop 操作）

使用这两种操作，由一个操作数序列就可以得到一系列的输出序列，下图所示为由 1 2 3 生成序列 2 3 1 的过程。

（原始状态如上图所示）

你的程序将对给定的 nnn，计算并输出由操作数序列 1,2,…,n1,2,\ldots,n1,2,…,n 经过操作可能得到的输出序列的总数。

输入格式

输入文件只含一个整数 nnn（1≤n≤181 \leq n \leq 181≤n≤18）。

输出格式

输出文件只有一行，即可能输出序列的总数目。

样例

样例输入 #1

3

样例输出 #1

5

AC 代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int f[20][20];  
// f[x][y]: 还有x个数等待入栈，当前栈里有y个数时，最终能得到的出栈序列总数
int n;

int main() {
    cin >> n;
    
    /**
     * 状态定义：
     *   x: 还剩多少个数字没有入栈
     *   y: 当前栈里面有多少个数字
     *   f[x][y]: 在这种状态下，最终能产生的出栈序列总数
     * 
     * 初始状态：f[n][0] -> 还有n个数没入栈，栈是空的，这就是我们要求的答案
     * 
     * 边界条件：
     *   1. 当 x = 0 时：没有数字可以入栈了，只能不停地出栈，直到栈空
     *      此时只有1种方式（按顺序弹出栈内所有元素）→ f[0][y] = 1
     *   
     *   2. 当 y = 0 时：栈是空的，只能进行入栈操作
     *      从剩余数字中取一个入栈，状态变为 (x-1, 1) → f[x][0] = f[x-1][1]
     * 
     * 一般情况 (x > 0 且 y > 0)：
     *   当前状态 (x, y) 有两种选择：
     *   (1) 入栈：从等待队列中取一个数字压入栈顶
     *       剩余数字减少1个，栈内数字增加1个 → (x-1, y+1)
     *   (2) 出栈：从栈顶弹出一个数字到输出序列
     *       剩余数字不变，栈内数字减少1个 → (x, y-1)
     *   
     *   所以递推公式：f[x][y] = f[x-1][y+1] + f[x][y-1]
     *   
     * 这个DP的本质是：在二维网格 (x,y) 上，从 (n,0) 走到 (0,0) 的路径计数，
     * 但路径必须满足 y ≤ x 的约束（栈内元素不能超过剩余未入栈数），
     * 这正是卡特兰数的几何意义！
     */
    
    for(int x = 0; x <= n; x++) {          // x: 剩余未入栈的数字个数
        for(int y = 0; y <= n; y++) {      // y: 当前栈内的数字个数
            if(!x) {
                // 情况1：没有数字可以入栈了，只能全部弹出，只有1种方式
                f[x][y] = 1;
            }
            else if(!y) {
                // 情况2：栈为空，只能入栈
                f[x][y] = f[x-1][y+1];
            }
            else {
                // 情况3：既可以入栈，也可以出栈
                f[x][y] = f[x-1][y+1] + f[x][y-1];
            }
        }
    }
    
    // 初始状态：还有n个数没入栈，栈是空的
    cout << f[n][0] << endl;
    
    return 0;
}
