1173 - 求子序列的个数

题目描述

给定一串整数数列，求出所有的递增和递减子序列的数目。

如数列 7，2，6，9，8，3，5，2，17，2，6，9，8，3，5，2，17，2，6，9，8，3，5，2，1 可分为 （7，2），（2，6，9），（9，8，3）（7，2），（2，6，9），（9，8，3）（7，2），（2，6，9），（9，8，3）， （3，5），（5，2，1）（3，5），（5，2，1）（3，5），（5，2，1） 555 个子序列，答案就是 555 ， 我们称 2，9，3，52，9，3，52，9，3，5 为转折元素。

输入

第一行，一个整数 NNN ( 2≤N≤102 \le N \le 102≤N≤10 )；

第二行，NNN 个整数，任意两个相邻的数都不相等。

输出

一个整数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int i,c=1,n,a[20];
int main(){
    cin>>n;
    for(i=1;i<=n;i++){
        cin>>a[i];
    }
    //如果a[i]是转折元素，则计数器加1
    for(i=2;i<n;i++){
        if((a[i]>a[i+1] && a[i]>a[i-1])||(a[i]<a[i+1] && a[i]<a[i-1])) c++;
    }
    cout<<c;
    return 0;
}
