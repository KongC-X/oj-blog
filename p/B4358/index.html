B4358 [GESP202506 三级] 奇偶校验

洛谷 | 普及- | C++14 | 提交时间: 2025-07-14

算法标签：2025、进制、循环结构、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1183

题目描述

数据在传输过程中可能出错，因此接收方收到数据后通常会校验传输的数据是否正确，奇偶校验是经典的校验方式之一。

给定 $n$ 个非负整数 $c_1, c_2, \ldots, c_n$ 代表所传输的数据，它们的校验码取决于这些整数在二进制下 1 的数量之和的奇偶性。如果这些整数在二进制下共有奇数个 1，那么校验码为 1；否则校验码为 0。你能求出这些整数的校验码吗？

输入格式

第一行，一个正整数 $n$，表示所传输的数据量。

第二行，$n$ 个非负整数 $c_1, c_2, \ldots, c_n$，表示所传输的数据。

输出格式

输出一行，两个整数，以一个空格分隔：

第一个整数表示 $c_1, c_2, \ldots, c_n$ 在二进制下 1 的总数量；

第二个整数表示校验码（0 或 1）。

样例

样例输入 #1

4
71 69 83 80```

**样例输出 #1**

13 1```

样例输入 #2

6
1 2 4 8 16 32```

**样例输出 #2**

6 0```

AC 代码

#include <iostream>
using namespace std;

int countOnes(int num) {
    int count = 0;
    while (num > 0) {
        if (num % 2 == 1) {
            count++;
        }
        num /= 2;
    }
    return count;
}

int main() {
    int n;
    cin >> n;
    int total = 0;
    for (int i = 0; i < n; i++) {
        int num;
        cin >> num;
        total += countOnes(num);
    }
    cout << total << " " << (total % 2) << endl;
    return 0;
}
