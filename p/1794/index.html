1794 - 最长不下降子序列（LIS）

题目描述

设有由 nnn 个不相同的整数组成的数列，记为: a1a_1a1​、a2a_2a2​、…\dots…、ana_nan​ 且 ai≠aja_i \neq a_jai​=aj​ (i≠ji \neq ji=j)。

例如 333，181818，777，141414，101010，121212，232323，414141，161616，242424。

若存在 i1<i2<i3<⋯<iei_1 \lt i_2 \lt i_3 \lt \dots \lt i_ei1​<i2​<i3​<⋯<ie​ 且有$a

i1i1i1

\lt a

i2i2i2

\lt \dots \lt a
$ieieie，则称为长度为 eee 的不下降序列。

如上例中 333，181818，232323，242424 就是一个长度为 444 的不下降序列，同时也有 333，777，101010，121212，161616，242424 长度为 666 的不下降序列。

程序要求，当原数列给出之后，求出最长的不下降序列。

输入

第一行为 nnn，表示 nnn 个数（10≤n≤1000010 \le n \le 1000010≤n≤10000）；

第二行 nnn 个整数，数值之间用一个空格分隔（1≤ai≤n1 \le a_i \le n1≤ai​≤n）；

输出

最长不下降子序列的长度。

解题思路

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int a[10010],n,i,j;
int dp[10010];
int ma,s;

int main() {
    cin >> n;
    for(i = 1;i <= n;i++) {
        cin >> a[i];
    }

    // 状态转移方程：
    // dp[i] = max(dp[j] + 1, dp[i])
    // 其中 0 <= j < i 且 a[j] < a[i]
    // 求以每个数结尾的最长上升子序列的长度
    for(i = 1;i <= n;i++) {
        dp[i] = 1;
        // 将a[i]尝试续到每个数后面，看dp[i]能否增加
        for(j = 1;j < i;j++) {
            if(a[j] < a[i]) {
                dp[i] = max(dp[j] + 1, dp[i]);
            }
        }
        ma = max(ma, dp[i]);
    }

    cout << ma << endl;
}
