P1028 [NOIP 2001 普及组] 数的计算

洛谷 | 普及- | C++14 | 提交时间: 2026-02-12

算法标签：动态规划 DP、递推、2001、递归、NOIP 普及组

题目描述

给出正整数 nnn，要求按如下方式构造数列：

  1. 只有一个数 nnn 的数列是一个合法的数列。
  2. 在一个合法的数列的末尾加入一个正整数，但是这个正整数不能超过该数列最后一项的一半，可以得到一个新的合法数列。

请你求出，一共有多少个合法的数列。两个合法数列 a,ba, ba,b 不同当且仅当两数列长度不同或存在一个正整数 i≤∣a∣i \leq |a|i≤∣a∣，使得 ai≠bia_i \neq b_iai​=bi​。

输入格式

输入只有一行一个整数，表示 nnn。

输出格式

输出一行一个整数，表示合法的数列个数。

样例

样例输入 #1

6

样例输出 #1

6

AC 代码

#include <iostream>
using namespace std;
    
    /**
     * 思路解析：
     * 
     * 1. 问题转化：
     *    题目要求的是以n为第一个数的所有合法数列个数
     *    合法数列定义：后一个数 ≤ 前一个数的一半
     *    
     * 2. 状态定义：
     *    f[i] = 以数字i作为第一个数（或者说数列的第一项）时，能构造出的合法数列总数
     *    
     * 3. 递推关系：
     *    对于数字i，它可以自己单独成为一个数列（长度为1）
     *    也可以在后面接一个数字j，其中1 ≤ j ≤ i/2
     *    当后面接了数字j后，剩下的部分就是以j为第一个数的合法数列
     *    
     *    所以：f[i] = 1 + f[1] + f[2] + ... + f[i/2]
     *          加的那个"1"是数列[i]本身
     *    
     * 4. 边界条件：
     *    f[1] = 1  (只有[1]这一个数列)
     *    
     * 5. 计算顺序：
     *    从小往大计算，因为f[i]依赖于所有f[1]~f[i/2]
     */

int f[1010];  // f[i]表示以数字i开头的合法数列个数

int main() {
    int n;
    cin >> n;

    // 初始化
    f[1] = 1;  // 数字1只能构造[1]
    
    // 递推计算f[2]到f[n]
    for (int i = 2; i <= n; i++) {
        int sum = 1;  // 数列[i]本身
        for (int j = 1; j <= i / 2; j++) {
            sum += f[j];  // 数列[i, ..., 以j开头...]
        }
        f[i] = sum;
    }
    
    cout << f[n] << endl;
    
    return 0;
}
