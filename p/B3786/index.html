B3786 [信息与未来 2023] 幸运数字

洛谷 | 入门 | C++14 | 提交时间: 2026-04-11

算法标签：模拟、2023、江苏、循环结构、信息与未来

题目描述

如果把一个数字十进制表示的奇数位和偶数位分别相加得到的和相同，小小就认为它是一个幸运的数字。例如：

  • 123451234512345 奇数位相加 1+3+5=91 + 3 + 5 = 91+3+5=9、偶数位相加 2+4=62 + 4 = 62+4=6，因此 123451234512345 不是幸运数字；

  • 233223322332 奇数位相加 2+3=52 + 3 = 52+3=5、偶数位相加 3+2=53 + 2 = 53+2=5，因此 233223322332 是幸运数字。

对于给定的 aaa 和 bbb，小小希望你求出 a,a+1,a+2,…,ba,a + 1, a + 2,\dots, ba,a+1,a+2,…,b 中幸运数字的数量。

输入格式

输⼊数据仅一行，包含空格分隔的两个整数 aaa 和 bbb。

输出格式

输出一行一个整数，代表 a,a+1,a+2,…,ba, a + 1, a + 2,\dots, ba,a+1,a+2,…,b 中幸运数字的数量。

样例

样例输入 #1

1 100```

**样例输出 #1**

9```

样例输入 #2

4096 65536```

**样例输出 #2**

3454```

AC 代码

#include <iostream>
#include <string>
using namespace std;

bool isLucky(int n) {
    string s = to_string(n);
    int oddSum = 0, evenSum = 0;
    for (int i = 0; i < s.length(); i++) {
        int digit = s[i] - '0';
        if (i % 2 == 0) { // 奇数位（第1、3、5...位），索引从0开始
            oddSum += digit;
        } else {
            evenSum += digit;
        }
    }
    return oddSum == evenSum;
}

int main() {
    int a, b;
    cin >> a >> b;
    int cnt = 0;
    for (int i = a; i <= b; i++) {
        if (isLucky(i)) cnt++;
    }
    cout << cnt << endl;
    return 0;
}
