1104 - 字符串解压

题目描述

输入压缩后的字符串，输出压缩前的字符串。

压缩的方法是把连续的相同字母压缩为"长度+字母"的形式，在本题中，单个的字母不需要压缩。

例如：3a5bx3a5bx3a5bx，解压后的结果为：aaabbbbbxaaabbbbbxaaabbbbbx；

例如：12ab10c2ax12ab10c2ax12ab10c2ax 解压后的结果为：aaaaaaaaaaaabccccccccccaaxaaaaaaaaaaaabccccccccccaaxaaaaaaaaaaaabccccccccccaax 。

输入

压缩后的字符串。

输出

解压后的字符串。

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s,s1;
    cin >> s;
    int i,j,k;
    for(i = 0;i < s.size();i++) {
        if(isdigit(s[i])) {
            s1 += s[i];
        } else {
            if(s1 == ""){
                cout << s[i];
            } else {
                // cout << s1 << " " << s[i] << endl;
                k = stoi(s1);
                for(j = 0;j < k;j++) {
                    cout << s[i]; // 输出当前不是数字的那个字符
                }
                s1 = "";
            }

        }
    }
}
