2069 - 重建电路

题目描述

小A同学所在的城市遭受了洪灾，城市中的电路受到了严重的破坏。政府部门一方面要救灾，一方面要用最小的代价来重建电路系统。

现在已知该城市有若干个村庄（编号为 0∼n−10 \sim n-10∼n−1），并已知村庄之间如果重建电路所需要的花费，请你编程帮助该城市计算出，如果要使得该城市恢复电路系统，最少的花费是多少？

请注意：只需要保证任意两个村庄之间至少存在一条通路，电路系统即可恢复。

输入

输入的第一行为一个整数 TTT（1≤T≤501 \le T \le 501≤T≤50），表示有 TTT 组测试数据。

每组输入第一行是两个正整数 NNN，EEE（2≤N≤500，N≤E≤N×(N−1)/22 \le N \le 500，N \le E \le N \times (N-1)/22≤N≤500，N≤E≤N×(N−1)/2），分别表示该城市村庄个数和原有电力线路的个数。

接下来的 EEE 行，每行包含三个整数 A,B,KA,B,KA,B,K（0≤A,B<N0 \le A,B \lt N0≤A,B<N，0≤K<10000 \le K \lt 10000≤K<1000）。

AAA 和 BBB 分别表示电力线路的起始村庄代号。

如果 K=0K=0K=0，表示这条线路仍然正常；如果 KKK 是一个正整数，表示这条线路需要花费 KKK 的代价来重建。

题目保证输入中没有重边，也没有起始村庄相同的边；本题的数据确保一定能重建电路系统。

输出

对于每组输入，输出重建电力系统所需的最小花费，以此来保证任意两个村庄之间至少存在一条通路。

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

/*
  1. 读入数据，将数据存入结构体数组；
  2. 对结构体数组按照建网络的长度，从小到大排序；
  3. 选出n-1条边，不能构成回路，长度的和就是最小长度；
  4. K=0 表示线路正常，可以直接连通（花费0），先处理这些边。
  5. K>0 的边存入结构体，用于后续 Kruskal 选边。
  6. 由于有多组数据，注意数组下标和变量重置。
*/

const int MAXN = 510;            // 村庄数最大 500，多开10个
const int MAXE = 125000;         // 最大边数 500*499/2 ≈ 124750

int f[MAXN];                     // 并查集数组
struct Node {
    int x, y, len;               // x,y:村庄编号, len:重建花费
} a[MAXE];                       // 存储需要重建的边

int n, e, k;                     // n:村庄数, e:总边数, k:需要重建的边数

bool cmp(Node a, Node b) {
    return a.len < b.len;
}

int find(int x) {
    return x == f[x] ? x : f[x] = find(f[x]); // 路径压缩
}

int main() {
    int T;                       // T: 测试数据组数
    cin >> T;
    while (T--) {
        cin >> n >> e;
        // 初始化并查集，村庄编号 0~n-1
        for (int i = 0; i < n; i++) f[i] = i;
        k = 0;                   // 需要重建的边数置零

        // 读入 e 条边
        for (int i = 0; i < e; i++) {
            int u, v, w;
            cin >> u >> v >> w;
            if (w == 0) {
                // 正常线路，直接合并，不算花费
                int fx = find(u);
                int fy = find(v);
                if (fx != fy) f[fx] = fy;
            } else {
                // 需要重建的边，存入数组
                k++;
                a[k].x = u;
                a[k].y = v;
                a[k].len = w;
            }
        }

        // 对需要重建的边按费用从小到大排序
        sort(a + 1, a + k + 1, cmp);

        // Kruskal 选边
        int s = 0;               // 重建总花费
        int c = 0;               // 已连通的边数（正常线路未统计，这里重新统计）
        // 先统计当前已有的连通分量？不，我们直接选边时统计。
        // 我们需要达到 n-1 条边连通。因为正常线路已经合并，我们只需在需要重建的边中选。
        // 设置 c 为已选中的重建边数，最后选够 (n-1 - 已合并的正常线路数) 条。
        // 但我们可以在选边时直接判断 find(u)!=find(v) 即可，无需单独计数正常线路。
        // 最终所有村庄连通时，循环结束，输出 s。
        for (int i = 1; i <= k; i++) {
            int fx = find(a[i].x);
            int fy = find(a[i].y);
            if (fx != fy) {
                f[fx] = fy;
                s += a[i].len;   // 累加重建费用
                c++;             // 可选，用作调试
            }
        }
        cout << s << endl;
    }
    return 0;
}
