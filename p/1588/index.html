1588 - 奇怪的车牌号

题目描述

汽车的车牌号是一个 888 位数，最高位可以为 000 ，所以车牌号范围为 000000000000000000000000 到 999999999999999999999999 。

有一辆汽车出了事故，司机驾车逃跑，有三位目击者向警方提供线索。

甲：车牌号的前 444 位是递增的自然数，如 000 111 222 333 ，或111 222 333 444 ，…\dots… 最多为 666 777 888 999。

乙：车牌号的后 444 位也是递增的自然数

丙：车牌号的数字和是某个整数的平方

例如：000 111 222 333 111 222 333 444就是满足上面的三个条件

000 111 222 333和 111 222 333 444 均为递增的自然数，其数字和 161616 为 444的平方。

当然，满足上面的三个条件的车牌号还有许多，你的任务求出所有满足条件的车牌号个数。

输入

无。

输出

一个整数，即满足条件的车牌号的个数。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
/*
1.前4个数递增，如果前4个数的第1个数是i，那么前四个数的和一定是4*i+6
2.后四个数同前四个数的规律
3.因此本题只要循环前4个数的第一个数的范围：0~6，后四个数的第1个数的范围0~6
  然后判断总和是否是平方数就可以了 
*/
int main(){
    int c=0,i,j;
    for(i=0;i<=6;i++){
        for(j=0;j<=6;j++){
            int x = sqrt(4*i+4*j+12); 
            if(x * x == 4 * i + 4 * j + 12){
                c++;
            }
        }
    }
    cout<<c<<endl;
    return 0;
}
