3349 - 找素数

题目描述

小明刚刚学习了素数的概念：如果一个大于 111 的正整数，除了 111 和它自身外，不能被其他正整数整除，则这个正整数是素数。现在，小明想找到两个正整数 AAA 和 BBB 之间（包括AAA 和 BBB）有多少个素数？

输入

输入 222 行，第一行包含正整数 AAA，第二行包含正整数 BBB。约定 2≤A≤B≤10002 ≤ A ≤ B ≤ 10002≤A≤B≤1000。

输出

输出一行，包含一个整数 CCC，表示找到 CCC 个素数。

解题思路

AC代码

AC代码

#include <iostream>

bool isPrime(int x) { // 根据方法2判断是否为质数
    if (x < 2) return false;
    for (int i = 2; i * i <= x; ++i)
        if (x % i == 0) return false;
    return true;
}

int main() {
    int A, B, ans = 0; std::cin >> A >> B;
    for (int i = A; i <= B; ++i) {
        if (isPrime(i)) ans++;
    }
    std::cout << ans;
    return 0;
}
