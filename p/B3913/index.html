B3913 [语言月赛 202401] 装满葡萄汁的酒杯

洛谷 | 入门 | C++14 | 提交时间: 2026-09-21

算法标签：2024、O2优化、分支结构、语言月赛

题目描述

小 H 有五个酒杯可供选择，它们的容量分别为 100mL100\text{mL}100mL、150mL150\text{mL}150mL、300mL300\text{mL}300mL、400mL400\text{mL}400mL 和 1000mL1000\text{mL}1000mL。

现在，小 H 想要在这五个酒杯中选择一个来喝葡萄汁。小 H 打算喝 a mL(a≤1000)a\text{ mL}(a \leq 1000)a mL(a≤1000) 的葡萄汁。请问，小 H 至少需要选择多大容量的酒杯，才能装下 a mLa\text{ mL}a mL 的葡萄汁（葡萄汁不能溢出）。

输入格式

输入一行共一个整数 aaa，表示小 H 打算喝的葡萄汁的量（以  mL\text{ mL} mL 为单位）。

输出格式

输出一行共一个整数，表示小 H 至少需要选择的酒杯容量（以  mL\text{ mL} mL 为单位），以确保能够装下 a mLa\text{ mL}a mL 的葡萄汁。

样例

样例输入 #1

50```

**样例输出 #1**

100```

样例输入 #2

112```

**样例输出 #2**

150```

样例输入 #3

300```

**样例输出 #3**

300```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3913 [语言月赛 202401] 装满葡萄汁的酒杯
     * 题意：有五种酒杯容量：100、150、300、400、1000（单位 mL）。
     *       给定需要装的葡萄汁量 a（a ≤ 1000），求能装下 a 的最小酒杯容量。
     * 思路：按容量从小到大依次判断，第一个 ≥ a 的容量即为答案。
     *       因为容量种类固定且很少，直接用 if-else 即可。
     */
    int a;          // a: 需要装的葡萄汁量
    cin >> a;

    if (a <= 100) {
        cout << 100 << endl;
    } else if (a <= 150) {
        cout << 150 << endl;
    } else if (a <= 300) {
        cout << 300 << endl;
    } else if (a <= 400) {
        cout << 400 << endl;
    } else {
        cout << 1000 << endl;
    }

    return 0;
}
