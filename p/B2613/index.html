题目描述

小A 每分钟输入 120120120 个字符，UIM 每分钟输入 808080 个字符，UIM 比小A 先开始打字 121212 分钟，请问小A 开始打字多少时间后能赶上 UIM 的进度？

输出格式

请输出一个数字表示答案。这个数字是一个整数。

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】追及问题
     * 【核心思路】
     * UIM 先打 12 分钟，每分钟 80 字，领先 960 字。
     * 小A每分钟比UIM多打 120-80=40 字。
     * 追上所需时间 = 领先字数 ÷ 速度差 = 960 ÷ 40 = 24 分钟。
     *
     * 【时间复杂度】O(1)
     */

    int lead;      // lead: UIM 先打领先的字数
    int diff;      // diff: 小A比UIM每分钟多打的字数
    int ans;       // ans: 追上所需分钟数

    lead = 80 * 12;              // 80字/分钟 × 12分钟 = 960字
    diff = 120 - 80;             // 120 - 80 = 40字/分钟
    ans = lead / diff;           // 960 ÷ 40 = 24

    cout << ans << endl;         // 输出 24
    return 0;
}
