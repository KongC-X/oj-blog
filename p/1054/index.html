1054 - 编程求1平方+2平方+...+n平方

题目描述

编程求 111 平方+ 222 平方+ …\dots… + nnn 平方。

输入

输入一行，只有一个整数 n(1≤n≤200)n(1 \le n \le 200)n(1≤n≤200) 。

输出

输出只有一行（这意味着末尾有一个回车符号），包括 111 个整数。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
 
int main() {
    //定义整数变量n作为输入的数，i用作循环 
    int n,i;
    cin>>n;
    //sum作为和 ，初始值为0 
    int sum=0;
    for(i=1;i<=n;i++){
        //每次加上i的平方 
        sum=sum+i*i;
    }
    //输出sum 
    cout<<sum;
    return 0;
}
