B2038 奇偶 ASCII 值判断

洛谷 | 入门 | C++14 | 提交时间: 2026-06-26

题目描述

任意输入一个字符，判断其 ASCII 是否是奇数，若是，输出 YES，否则，输出 NO 。

例如，字符 A 的 ASCII 值是 65，则输出 YES，若输入字符 B(ASCII 值是 666666)，则输出 NO。

输出格式

如果其 ASCII 值为奇数，则输出 YES，否则，输出 NO。

样例

样例输入 #1

A```

**样例输出 #1**

YES```

样例输入 #2

B```

**样例输出 #2**

NO```

AC 代码

#include<bits/stdc++.h>
using namespace std;
char n;
int main(){
    cin>>n;
    if(n%2) cout<<"YES";
    else cout<<"NO";
    return 0;
}
