B3978 [信息与未来 2024] 幸运数字

洛谷 | 普及- | C++14 | 提交时间: 2026-04-14

算法标签：2024、江苏、枚举、进制、信息与未来

题目描述

如果一个正整数的二进制表示中，每个比特（000 或 111）的左边或右边都至少有一个相同的比特，Dr. X 就认为它是一个“幸运数字”。例如:

  • (1)2=(1)10(1)_2=(1)_{10}(1)2​=(1)10​ 有落单的 111，它不是幸运数字。

  • (110111)2=(55)10(110111)_2=(55)_{10}(110111)2​=(55)10​ 有落单的 000，它不是幸运数字。

  • (111110011)2=(499)10(111110011)_2=(499)_{10}(111110011)2​=(499)10​ 是幸运数字。

  • (110011001100)2=(3276)10(110011001100)_2=(3276)_{10}(110011001100)2​=(3276)10​ 是幸运数字。

对于给定的 aaa 和 bbb，Dr. X 希望你求出 a,a+1,a+2,…,ba, a + 1, a + 2, \dots, ba,a+1,a+2,…,b 中幸运数字的数量。

输入格式

输入空格分隔的整数 aaa 和 bbb。

输出格式

输出一行一个整数，代表 aaa 和 bbb 之间幸运数字的数量。

样例

样例输入 #1

1 100```

**样例输出 #1**

14```

样例输入 #2

4096 65535```

**样例输出 #2**

1364```

AC 代码

#include <iostream>
#include <string>
using namespace std;

// 判断整数 x 是否为幸运数字
bool isLucky(int x) {
    // 将 x 转换为二进制字符串（无前导零）
    string s = "";
    while (x > 0) {
        s = char('0' + (x % 2)) + s;  // 取余数拼接到前面
        x /= 2;
    }
    // 注意：x=0 的情况不会出现，因为 a≥1

    // 检查每一位是否落单
    int len = s.length();
    for (int i = 0; i < len; i++) {
        // 左边有相同的吗？ 右边有相同的吗？
        bool left = (i > 0 && s[i] == s[i - 1]);
        bool right = (i < len - 1 && s[i] == s[i + 1]);
        if (!left && !right) {
            return false;  // 左右都没有相同的，落单了
        }
    }
    return true;
}

int main() {
    int a, b;
    cin >> a >> b;

    int cnt = 0;
    for (int i = a; i <= b; i++) {
        if (isLucky(i)) {
            cnt++;
        }
    }

    cout << cnt << endl;
    return 0;
}
