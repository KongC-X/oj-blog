P8697 [蓝桥杯 2019 国 C] 最长子序列

洛谷 | 普及- | C++14 | 提交时间: 2026-09-30

算法标签：贪心、2019、蓝桥杯国赛

题目描述

我们称一个字符串 SSS 包含字符串 TTT 是指 TTT 是 SSS 的一个子序列，即可以从字符串 SSS 中抽出若干个字符，它们按原来的顺序组合成一个新的字符串与 TTT 完全一样。给定两个字符串 SSS 和 TTT，请问 TTT 中从第一个字符开始最长连续多少个字符被 SSS 包含？

输入格式

输入两行，每行一个字符串。第一行的字符串为 SSS，第二行的字符串为 TTT。两个字符串均非空而且只包含大写英文字母。

输出格式

输出一个整数，表示答案。

样例

样例输入 #1

ABCDEABCD
AABZ

样例输出 #1

3

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P8697 [蓝桥杯 2019 国 C] 最长子序列
     * 题意：给定字符串 S 和 T，求 T 从第一个字符开始的最长前缀，
     *       使得该前缀是 S 的子序列。
     *
     * 思路：双指针扫描。
     *   1. 读入 S 和 T。
     *   2. 用指针 i 遍历 S，j 遍历 T，j 从 0 开始。
     *   3. 当 S[i] == T[j] 时，说明 T 的第 j 个字符在 S 中找到了匹配，
     *      j 向后移一位（继续找 T 的下一个字符）。
     *   4. i 每次循环都向后移一位。
     *   5. 当 i 到达 S 末尾或 j 到达 T 末尾时停止。
     *   6. 输出 j，即 T 中从第一个字符开始连续匹配的字符个数。
     *
     * 时间复杂度：O(|S| + |T|)，|S|, |T| ≤ 1000。
     */
    string s, t;
    cin >> s >> t;

    int i = 0, j = 0;   // i: S 的下标, j: T 的下标
    int n = s.size(), m = t.size();

    while (i < n && j < m) {
        if (s[i] == t[j]) {
            j++;   // 匹配成功，T 的下一个字符
        }
        i++;       // S 继续向后
    }

    cout << j << endl;   // j 就是 T 中连续匹配的字符数
    return 0;
}
