B2017 打印 ASCII 码

洛谷 | 入门 | C++14 | 提交时间: 2026-06-24

题目描述

输入一个除空格以外的可见字符，输出其 ASCII 码。

输入格式

一个除空格以外的可见字符。

输出格式

一个十进制整数，即该字符的 ASCII 码。

样例

样例输入 #1

A```

**样例输出 #1**

65```

AC 代码

#include<iostream>
using namespace std;
int main(){
     char c;//定义
     cin>>c;//输入
     cout<<int(c);//强制类型转换并输出
     return 0;
}
