1312 - 看完动漫要几天？

题目描述

一部完整的动漫共有 mmm 分钟（ m≤1000m \le 1000m≤1000 ）。

为了保护视力，妈妈决定让小明同学每天从 xx:xxxx:xxxx:xx 分看到 xx:xxxx:xxxx:xx 分，请问小明同学需要几天才能看完这部完整的动漫。（4.1.154.1.154.1.15 ）

输入

333 行 :

第 111 行是一个整数 mmm 代表动漫的总分钟数，

第 222 行表示每天看动漫的开始时间，

第 333行表示每天看动漫的结束时间。（确保输入的开始时间 <\lt< 结束时间）

输出

一个整数，代表小明看完动漫至少需要花的总天数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
using namespace std;

int main(){
    char a[10],b[10];
    int n,c,d;
    cin >> n >> a >> b;
    c = (a[0] * 10 + a[1]) * 60 + (a[3] * 10 + a[4]);
    d = (b[0] * 10 + b[1]) * 60 + (b[3] * 10 + b[4]);
    // 向上取整
    if (n % (d - c) != 0) {
        n = n / (d - c) + 1;
    } else {
        n = n / (d - c);
    }
    cout << n;
}
