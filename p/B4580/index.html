B4580 [GESP202609 四级] 有序网格

洛谷 | 普及- | C++14 | 提交时间: 2026-09-18

算法标签：排序、2026、GESP

题目描述

小 A 有一个 $n$ 行 $m$ 列格子组成的二维网格，从上到下依次是第 $1$ 行到第 $n$ 行，从左到右依次是第 $1$ 列到第 $m$ 列。每个格子里有一个数字，第 $i$ 行第 $j$ 列的格子里的数字是 $a_{i,j}$。

小 A 想让二维网格变得有序，因此他先对每一行从左到右按升序排序，再对每一列从上到下按升序排序。以下是一个先完成行排序再完成列排序的例子：

$$
\begin{array}{|c|c|c|c|}\hline 1&3&2&5\\hline 6&2&4&4\\hline 5&4&1&3\\hline\end{array}\xrightarrow{\text{每行升序排序}}\begin{array}{|c|c|c|c|}\hline 1&2&3&5\\hline 2&4&4&6\\hline 1&3&4&5\\hline\end{array}\xrightarrow{\text{每列升序排序}}\begin{array}{|c|c|c|c|}\hline 1&2&3&5\\hline 1&3&4&5\\hline 2&4&4&6\\hline\end{array}
$$

小 A 想知道二维网格经过以上排序后的结果。你能编写程序帮助他吗？

输入格式

第一行，两个正整数 $n,m$，分别表示二维网格的行数与列数。

接下来 $n$ 行，每行 $m$ 个整数 $a_{i,1},\ldots,a_{i,m}$，表示二维网格中的数字。

输出格式

输出 $n$ 行，每行 $m$ 个整数，表示二维网格先完成行排序再完成列排序后的结果。

样例

样例输入 #1

3 2
6 5
4 3
2 1```

**样例输出 #1**

1 2
3 4
5 6```

样例输入 #2

3 4
1 3 2 5
6 2 4 4
5 4 1 3```

**样例输出 #2**

1 2 3 5
1 3 4 5
2 4 4 6```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B4580 [GESP202609 四级] 有序网格
     * 题意：给定 n 行 m 列的网格，先对每一行升序排序，再对每一列升序排序，输出结果。
     * 数据范围：2 ≤ n,m ≤ 10，数字 1~100，直接模拟即可。
     *
     * 思路：
     * 1. 读入 n, m 和矩阵 a。
     * 2. 对每一行 i，使用冒泡排序将 a[i][0..m-1] 升序排列。
     * 3. 对每一列 j，使用冒泡排序将 a[0..n-1][j] 升序排列。
     * 4. 输出最终的矩阵。
     *
     * 时间复杂度：O(n*m^2 + m*n^2)，n,m ≤ 10，完全可以忽略。
     */
    int n, m;
    cin >> n >> m;

    int a[15][15];   // a: 存储网格

    // 读入网格
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> a[i][j];
        }
    }

    // 对每一行升序排序（冒泡）
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m - 1; j++) {
            for (int k = 0; k < m - 1 - j; k++) {
                if (a[i][k] > a[i][k + 1]) {
                    int t = a[i][k];
                    a[i][k] = a[i][k + 1];
                    a[i][k + 1] = t;
                }
            }
        }
    }

    // 对每一列升序排序（冒泡）
    for (int j = 0; j < m; j++) {
        for (int i = 0; i < n - 1; i++) {
            for (int k = 0; k < n - 1 - i; k++) {
                if (a[k][j] > a[k + 1][j]) {
                    int t = a[k][j];
                    a[k][j] = a[k + 1][j];
                    a[k + 1][j] = t;
                }
            }
        }
    }

    // 输出结果
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cout << a[i][j] << ' ';
        }
        cout << endl;
    }
}
