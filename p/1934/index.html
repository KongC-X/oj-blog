1934 - 数字游戏（number）

题目描述

小 K 同学向小 P 同学发送了一个长度为 888 的 01 字符串来玩数字游戏，小 P 同学想要知道字符串中究竟有多少个 1。

注意：010101 字符串为每一个字符是 000 或者 111 的字符串，如 “101101101” （不含双引号）为一个长度为 333 的 010101 字符串。

输入

输入文件只有一行，一个长度为 888 的 010101 字符串 sss。

输出

输出文件只有一行，包含一个整数，即 010101 字符串中字符 1 的个数。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int ans = 0;
    for (int i = 0; i < s.size(); ++i) {
        if (s[i] == '1') ans++;  // 判断是否是 1
    }
    cout << ans << '\n'; // 输出答案
    return 0;
}
