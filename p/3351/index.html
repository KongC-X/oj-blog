3351 - 春游

题目描述

老师带领同学们春游。已知班上有 NNN 位同学，每位同学有从 000 到 N−1N − 1N−1 的唯
一编号。到了集合时间，老师确认是否所有同学都到达了集合地点，就让同学们报出自己的编号。到达的同学都会报出自己的编号，不会报出别人的编号，但有的同学很顽皮，会多次报出。你能帮老师找出有哪些同学没有到达吗？

输入

输入包含 222 行。第一行包含两个整数 NNN 和 MMM，表示班级有 NNN 位同学，同学们
共有 MMM 次报出编号。约定 2≤N,M≤10002 ≤ N, M ≤ 10002≤N,M≤1000。

第二行包含 MMM 个整数，分别为 MMM 次报出的编号。约定所有编号都在合理范围
内。

输出

输出一行。如果所有同学都到达，则输出NNN；否则由小到大输出所有未到达的同学编号，空格分隔。

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int n,m,a[1010],i,x,s;
int main() {
    cin >> n >> m;
    for(i = 0;i < m;i++) {
        cin >> x;
        a[x]++;
    }
    for(i = 0;i < n;i++) {
        if(a[i] != 0) {
            s++;
        }
    }
    if(s == n) {
        cout << n << endl;
        return 0;
    }
    for(i = 0;i < n;i++) {
        if(a[i] == 0) {
            cout << i << " ";
        }
    }
}
