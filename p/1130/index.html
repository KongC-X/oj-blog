1130 - 简单a+b

题目描述

张晓菲同学做了简单的 ababab 求和的问题。

但是，如果要求输入的情况不是 aaa 和 bbb ，而是整个加法表达式呢？ 请想办法，计算加法表达式的结果。

输入

输入一个加法表达式，如 1+2=1+2=1+2=，或者 23+58=23+58=23+58= 。（注意：做加法的 222 个整数都在 $0 \sim 10
$999 的范围内）

输出

计算出输入表达式的正确结果。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int main(){
    char s[50];
    int p=0;
    cin>>s;
    long long a=0,b=0,t=1;
    for(int i=0; i < strlen(s) && s[i] != '+';i++){
        a=a*10+(s[i]-'0');
        if(s[i+1]=='+'){
            p=i+1;
        }
    
    }
    for(int i=p+1; i < strlen(s) && s[i] != '=';i++){
        b=b*10+(s[i]-'0');
    }
    cout<<a+b;
}
