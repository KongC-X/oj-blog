4984 画布裁剪

4984 - 画布裁剪

题目描述

小 AAA 在高为 hhh 宽为 www 的矩形画布上绘制了一幅画。由于画布边缘留白太多，小 AAA 想适当地裁剪画布，只保留画的主体。具体来说，画布可以视为 hhh 行 www 列的字符矩阵，其中的字符均为 ASCII 码位于 333333 ~ 126126126 之间的可见字符，小 AAA 只保留画布中由第 x1x_1x1​ 行到第 x2x_2x2​ 行、第 y1y_1y1​ 列到第 y2y_2y2​ 列构成的子矩阵。

小 AAA 将画布交给了你，你能帮他完成画布的裁剪吗？

输入

第一行，两个正整数 h，wh，wh，w，分别表示画布的行数与列数。

第二行，四个正整数 x1，x2，y1，y2x_1，x_2，y_1，y_2x1​，x2​，y1​，y2​，表示保留的行列边界。

接下来 hhh 行，每行一个长度为 www 的字符串，表示画布内容。

输出

输出共 x2−x1+1x_2-x_1+1x2​−x1​+1 行，每行一个长度为 y2−y1+1y_2-y_1+1y2​−y1​+1 的字符串，表示裁剪后的画布。

解题思路

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int n,m,i,j,a1,a2,b1,b2;
char a[110][110];
int main() {
    cin >> n >> m;
    cin >> a1 >> a2 >> b1 >> b2;
    for(i = 1;i <= n;i++) {
        for(j = 1;j <= m;j++) {
            cin >> a[i][j];
        }
    }
    for(i = a1;i <= a2;i++) {
        for(j = b1;j <= b2;j++) {
            cout << a[i][j];
        }
        cout << endl;
    }
}
