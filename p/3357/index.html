3357 - 画正方形

题目描述

输入一个正整数 nnn，要求输出一个 nnn 行 nnn 列的正方形图案（参考样例输入输出）。

图案由大写字母组成。其中，第 111 行以大写字母 A 开头，第 222 行以大写字母 B 开头，以此类推；在每行中，第 222 列为第 111 列的下一个字母，第 333 列为第 222 列的下一个字母，以此类推；特别的，规定大写字母 Z 的下一个字母为大写字母 A。

输入

输入一行，包含一个正整数 nnn。约定 2≤n≤402 ≤ n ≤ 402≤n≤40。

输出

输出符合要求的正方形图案。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>

int n;

int main() {
    std::cin >> n;
    for (int i = 0; i < n; ++i) { // 遍历每一行
        for (int j = 0; j < n; ++j) { // 遍历每一列
            std::cout << (char)((i + j) % 26 + 'A'); // 不要忘记要加上 'A'
        }
        std::cout << std::endl;
    }
    return 0;
}
