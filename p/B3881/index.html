B3881 [信息与未来 2015] 拴奶牛

洛谷 | 普及- | C++14 | 提交时间: 2026-04-14

算法标签：2015、二分、江苏、信息与未来

题目描述

有 $n$ 头奶牛，有 $k$ 个木桩，每个木桩有一个位置，一个木桩上只能拴一头奶牛。由于奶牛好斗，所以在拴奶牛的时候，要求距离最近的奶牛的距离尽可能大。

例如 $n=4,k=6$，木桩的位置为 $0,3,4,7,8,9$，此时为下图。
$$
\begin{aligned}
\underline{\text{\qquad O\quad l\quad l\quad O\quad O\quad l\quad l\quad O\quad O\quad O\qquad}}\
\text{\qquad 0\quad\ \quad\ \ \quad 3\ \quad 4\quad\quad\quad\quad 7\quad\ 8\quad\ 9\qquad}
\end{aligned}
$$
有许多种拴牛方案，例如：

  • $0,3,4,9$：此时最近距离为 $1$（$3,4$ 之间）；
  • $0,3,7,9$：此时最近距离为 $2$。

输入格式

三个整数 $n,k,p_1$，其中 $p_1$ 为第 $1$ 个木桩的位置，其他木桩 $p_i(i\ge2)$ 的位置由下面公式给出：

$p_i = p_{i-1} + ((p_{i-1}\times2357+137) \bmod 10)+1$。

输出格式

一个整数，即奶牛间最近距离的最大值。

样例

样例输入 #1

25 70 99```

**样例输出 #1**

12```

AC 代码

#include <iostream>
using namespace std;

const int MAXK = 1000005;
int pos[MAXK];      // 存放所有木桩的位置
int n, k, p1;

// 检查在最小距离为 d 的情况下，能否选出至少 n 个木桩
bool check(int d) {
    int cnt = 1;                // 选了第一个木桩
    int last = pos[0];          // 上一个选的木桩位置
    for (int i = 1; i < k; i++) {
        if (pos[i] - last >= d) {
            cnt++;
            last = pos[i];
            if (cnt >= n) return true;  // 已经选够了
        }
    }
    return cnt >= n;
}

int main() {
    cin >> n >> k >> p1;

    // 生成所有木桩位置（递推公式保证严格递增）
    pos[0] = p1;
    for (int i = 1; i < k; i++) {
        // int add = ((pos[i-1] * 2357LL + 137) % 10) + 1;
        int add = (( (long long)pos[i-1] * 2357 + 137) % 10) + 1;
        pos[i] = pos[i-1] + add;
    }

    // 二分答案：范围是 [0, 最大距离]
    int l = 0, r = pos[k-1] - pos[0];
    int ans = 0;
    while (l <= r) {
        int mid = l + (r - l) / 2;  // 防止溢出
        if (check(mid)) {
            ans = mid;      // mid 可行，记录答案并尝试更大的
            l = mid + 1;
        } else {
            r = mid - 1;    // mid 太大，尝试小一点的
        }
    }

    cout << ans << endl;
    return 0;
}
