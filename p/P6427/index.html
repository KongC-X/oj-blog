P6427 [COCI 2008/2009 #1] PTICE

洛谷 | 普及- | C++14 | 提交时间: 2026-08-17

算法标签：2008、COCI（克罗地亚）

题目描述

Adrian 、Bruno 和 Goran 想加入鸟类爱好者俱乐部。然而，他们并不知道所有的申请者都必须通过加入俱乐部的考试。考试由 nnn 道题组成，每道题有三个可能的答案：A、B 和 C。

不幸的是，他们不能区分各种鸟类，所以他们试图猜测正确的答案。每一个男孩都有一套关于哪一种答案序列最有效的理论：

Adrian 声称最好的顺序是：A，B，C，A，B，C，A，B，C，A，B，C……

Bruno 确信这样更好：B，A，B，C，B，A，B，C，B，A，B，C……

Goran 嘲笑他们，并使用这个序列：C，C，A，A，B，B，C，C，A，A，B，B……

写一个程序，根据给出的正确答案，确定三个人中谁对的题目最多。

输入格式

第一行一个整数 nnn，表示考试的题目数量。

第二行一个长度为 nnn 的字符串（只包含A、B、C三种字符），表示考试的正确答案。

输出格式

第一行输出一个整数 mmm，表示三个人中做对题目最多的数量。

从第二行开始，输出答对题目数最多的人的名字（每行一个，按照字典序输出）。

样例

样例输入 #1

5
BAACC```

**样例输出 #1**

3
Bruno```

样例输入 #2

9
AAAABBBBB```

**样例输出 #2**

4
Adrian
Bruno
Goran```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P6427 [COCI 2008/2009 #1] PTICE
     * 题意：给定 n 道题的正确答案（A/B/C），三个人各有自己的固定答题序列，
     *       求出答对题数最多的人（可能多人），按字典序输出名字。
     *
     * 固定序列：
     *   Adrian:  A B C 重复（周期3）
     *   Bruno:   B A B C 重复（周期4）
     *   Goran:   C C A A B B 重复（周期6）
     */
    int n;
    string s;
    cin >> n >> s;

    // 定义三个人的猜测模式字符串
    string adrian = "ABC";
    string bruno = "BABC";
    string goran = "CCAABB";

    int a = 0, b = 0, g = 0;   // 分别统计三人答对题数

    for (int i = 0; i < n; i++) {
        // 正确答案是 s[i]
        if (s[i] == adrian[i % 3]) a++;
        if (s[i] == bruno[i % 4]) b++;
        if (s[i] == goran[i % 6]) g++;
    }

    int mx = max(a, max(b, g));   // 最高答对数

    cout << mx << endl;
    // 按字典序输出所有达到最高分的人名
    if (a == mx) cout << "Adrian" << endl;
    if (b == mx) cout << "Bruno" << endl;
    if (g == mx) cout << "Goran" << endl;

    return 0;
}
