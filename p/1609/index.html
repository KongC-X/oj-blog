1609 - 四位数的计算

题目描述

小丽在编程课上学会了拆位运算，她已经可以拆出一个四位整数的千位、百位、十位和个位了，她想知道这个整数的前两位和后两位如果分别组成两个新的整数 xxx 和 yyy 的，那么x+yx+yx+y 和 x/yx/yx/y 的计算结果分别是多少，请编程帮她实现？（请注意，除法运算的计算结果要保留 111 位小数）。

比如：整数 120812081208 如果将前两位和后两位分别组成两个新数，那么这两个新数分别是 x=12x = 12x=12 和 y=8y = 8y=8，计算结果分别为：

x+y=12+8=20x + y = 12 + 8 = 20x+y=12+8=20 。

x/y=12/8=1.5x / y = 12 / 8 = 1.5x/y=12/8=1.5 。

输入

读入一个四位整数 nnn（nnn 的十位和个位不可能同时为 000 ，也就是，读入的整数不可能是类似 120012001200 这样的整数）。

输出

按题意要求输出计算结果，分两行输出：

第 111 行输出前两位和后两位组成新数的和。

第 222 行输出前两位和后两位组成新数相除的结果，计算结果保留 111 位小数。

解题思路

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
#include<iomanip>
using namespace std;

int main() {
    int n,x,y,a,b,c,d;
    cin >> n;
    a = n/1000;
    b = (n%1000)/100;
    c = ((n%1000)%100)/10;
    d = ((n%1000)%100)%10;
    x = a * 10 + b;
    y = c * 10 + d;
    cout << x + y << endl;
    cout << fixed << setprecision(1) << x * 1.0 / y << endl;
}
