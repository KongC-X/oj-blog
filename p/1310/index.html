1310 - 至少要买几瓶止咳糖浆？

题目描述

花花生病了，妈妈去给花花买儿童止咳糖浆。一瓶儿童止咳糖浆的规格及用法如下所示，一般花花咳嗽需要 555 天才能痊愈。

止咳糖浆规格：每瓶 120120120 毫升，每日 333 次， 101010 岁以上儿童：每次 252525 毫升，7∼107 \sim 107∼10 岁儿童：每次 151515 毫升， 3∼63 \sim 63∼6 岁儿童：每次 555 毫升。

请根据止咳糖浆的规格以及花花的年龄计算，写一个程序计算如果花花要痊愈，妈妈至少要买几瓶止咳糖浆？（4.1.7）

输入

一个整数，代表花花的年龄（花花的年龄在 222 岁以上）。

输出

一个整数，代表妈妈最少需要购买的糖浆瓶数。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    if (n >= 3 && n <= 6) {
        cout << (5 * 3 * 5 / 120) + 1 << endl;
    } else if (n >= 7 && n <= 10) {
        cout << (15 * 3 * 5 / 120) + 1 << endl;
    } else if(n > 10) {
        cout << (25 * 3 * 5 / 120) + 1 << endl;
    }
}
