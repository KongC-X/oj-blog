B2153 求阶乘的和

洛谷 | 入门 | C++14 | 提交时间: 2026-07-05

题目描述

给定正整数 nnn，求不大于 nnn 的正整数的阶乘的和（即求 1!+2!+3!+⋯+n!1!+2!+3!+\dots+n!1!+2!+3!+⋯+n!），输出阶乘的和。

阶乘定义为 n!=n×(n−1)×(n−2)×⋯×1n!=n\times (n-1)\times (n-2)\times \cdots \times 1n!=n×(n−1)×(n−2)×⋯×1。例如，5!=5×4×3×2×1=1205! = 5 \times 4 \times 3 \times 2 \times 1=1205!=5×4×3×2×1=120。

输入格式

输入一行，包含一个正整数 n(1<n<12)n(1 < n < 12)n(1<n<12)。

输出格式

输出一行，表示阶乘的和。

样例

样例输入 #1

5```

**样例输出 #1**

153```

AC 代码

#include<iostream>
using namespace std;
int main(){
    int a, b = 1, i, s = 0;
    cin >> a;
    for(i = 1; i <= a; i++){
        b = b * i;
        s = s + b;
    }
    cout << s << endl;
    return 0;
}
