1177 - 统计字母出现次数

题目描述

输入一串小写字母（以 . 为结束标志），统计出每个字母在该字符串中出现的次数(若某字母不出现，则不要输出，题目保证每个字母出现的次数$ \lt 10$)。

输入

输入只有一行，包括若干个字符。

输出

输出只有两行，第一行为出现的小写字母，第二行为字母的出现次数。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    char a[200];
    int b[200] = {0};
    int i,k;
    char c;
    cin >> a;
    for(i = 0;i < strlen(a);i++){
        k = a[i];
        b[k]++;
    }
    for(i = 97;i <= 97 + 25;i++) {
        if(b[i] != 0) {
            c = i;
            cout << c;
        }
    }
    cout << endl;
    for(i = 97;i <= 97 + 25;i++) {
        if(b[i] != 0) {
            cout << b[i];
        }
    }
}
