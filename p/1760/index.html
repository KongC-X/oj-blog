1760 - 整理抽屉

题目描述

期末考试即将来临，小T由于同时肩负了学习、竞赛、班团活动等多方面的任务，一直没有时间好好整理他的课桌抽屉，为了更好地复习，小T首先要把课桌抽屉里的书分类整理好。

小T的抽屉里堆着 NNN 本书，每本书的封面上都印有学科名称，学科名称用一个字符串表示，如语文学科的书封面上都印有“chinese”。现在，你的任务是帮助小T找出哪个学科的书最多？

输入

第一行包含一个自然数 NNN（0＜N≤10000＜N≤10000＜N≤1000）表示抽屉中书的总数。

接下来 NNN 行每行包含一本书的学科名称，学科名称是一个长度不超过 151515 的由小写英文字母组成的字符串。

输出

仅有一行包含一个字符串，表示最多的那种书的学科名称。

数据保证答案一定是唯一的。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

string s[1020];
int main(){
    int n;
    cin >> n;
    for(int i = 0; i < n; i++){
        cin >> s[i];
    }
    sort(s, s + n);

    string s1 = s[0];
    int d = 1, c = 0;
    string s2 = s1;
    for(int i = 1; i < n; i++){
        if(s1 == s[i]){
            d++;
        } else {
            if(d >= c){
                c = d;
                s2 = s1;
            }
            s1 = s[i];
            d = 1;
        }
    }
    if(d >= c){
        c = d;
        s2 = s1;
    }
    cout << s2 << endl;
    return 0;
}
