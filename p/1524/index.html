1524 - BMI

题目描述

小Ｘ经过刻苦训练获得了 NOIP 的国一，并参加了 NOI，获得了保送资格，被保送到南都大学学习，进入大学以后，小Ｘ觉得中学编程太辛苦了，应该好好犒劳一下自己，刚好南都大学周边美食如云，吃不胜吃，小Ｘ不到一个学期就长了 303030 多斤，四年下来已经胖得不成样子，体重一举飙升到了 118kg118kg118kg，同时血压也升到了 128mmHg128mmHg128mmHg，离正常血压的上限也不远了，数字都很吉祥，但身体状况已呈险兆，上个楼梯就心慌气促，于是下定决心要减重，正所谓胖子不是一天就能吃成的，瘦下来也不可能饿几天就达到，小Ｘ的短期目标就是减到像 Q 老师那么瘦，尽管也从没有人夸过 Q 老师瘦！当然小Ｘ的最终目标是减到正常体重，正常体重怎么算呢？国际通用的标准是 BMI 指数，以下科普一下 BMI 指数：BMI 指数=体重/(身高^2)，正常范围在 181818 到 242424 之间，小于 181818 过轻，大于 242424 过重。这里体重的单位为公斤(kg)，身高的单位是米(m)。如费德勒的身高为 185185185 厘米，体重为 858585 公斤，其 BMI=85/(1.85\*1.85)≈24.8356。

输入

输入数据包含两个用空格隔开的正整数，分别表示身高和体重，身高的单位是厘米(cm)，体重的单位为公斤(kg)，111 米等于 100100100 厘米。

输出

输出数据第一行为一个字符串，“Good!”表示正常，“Too fat!”表示过重，“Too thin!”表示过轻，双引号不需要输出，感叹号都是英文字符。

如果体重正常则不用输出第二行，否则第二行输出一个正整数 w，表示此人离正常体重的最小整数差值，假如此人过重，则他要减去 w 公斤才能使得 BMI 指数小于等于 242424，如果太轻则要增加 w公斤才能使得BMI 指数大于等于 181818。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    int h,w;//身高、体重
    cin>>h>>w;
    double r = w / (h * h * 1.0 / 100 / 100);
    if(r >= 24){
        cout<<"Too fat!"<<endl;
        cout<<w - (int)(24 * (h * h * 1.0 / 100 / 100))<<endl;
    }else if(r <= 18){
        cout<<"Too thin!"<<endl;
        cout<<(int)ceil((18 * (h * h * 1.0 / 100 / 100)) - w)<<endl;
    }else{
        cout<<"Good!"<<endl;
    }
}
