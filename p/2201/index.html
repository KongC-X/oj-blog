2201 - 二叉树结点查找

题目描述

给定一颗二叉树，请问，如果中序遍历这棵二叉树，那么值为 xxx 的结点，是中序遍历这棵二叉树结果中的第几个结点？

比如：如下图所示的二叉树，中序遍历序列为：29、12、8、15、23、5、1029、12、8、15、23、5、1029、12、8、15、23、5、10，假设 x=15x=15x=15 ，那么值 xxx 是该二叉树中序遍历结果中的第 444 个结点。

输入

第一行 nnn 为二叉树的结点个数，n≤100n \le 100n≤100 ；

第二行 xxx 表示要查找的结点的值；

以下第一列数据是各结点的值（均不相等），第二列数据是左儿子结点编号，第三列数据是右儿子结点编号。

注意：读入的第 111 个结点是树的根结点。

输出

输出一个数即查找的结点编号。

AC代码

#include<bits/stdc++.h>
using namespace std;
const int N = 110;
struct node {
    int lc, rc;
    int  val;
} a[N];

int n, v, cnt;//cnt：每个结点是遍历的第几个结点

//中序遍历：左根右
void dfs(int x) {
    if(a[x].lc) dfs(a[x].lc);

    cnt++;//x是中序遍历第几个结点
    //找到值为v的结点
    if(a[x].val == v) {
        cout << cnt;
        return ;
    }

    if(a[x].rc) dfs(a[x].rc);
}
int main() {
    cin >> n >> v;
    for(int i = 1; i <= n; i++) {
        cin >> a[i].val >> a[i].lc >> a[i].rc;
    }

    //中序遍历
    dfs(1);
    return 0;
}
