1815 - 最后一次出现该数的位置

题目描述

从键盘输入一个整数 NNN ，输入 NNN (5≤N≤1005 \le N \le 1005≤N≤100)个元素，输入一个整数，判断这个数组中最后一次出现该数的位置，如果没有请输出−1-1−1。

输入

第 111 行读入一个整数 NNN。（5≤N≤1005 \le N \le 1005≤N≤100）

第 222 行读入 nnn 个整数用空格隔开。

第 333 行读入 111 个整数，代表要找的数。

输出

输出 111 个整数，代表最后一次出现整数的位置，如果数组中不存在这样的数，请输出 −1-1−1。

解题思路

AC代码

AC代码

#include<iostream>
using namespace std;

int a[110],n,s = -1,x;

int main() {
    cin>>n;
    for(int i = 0;i < n;i++){
        cin>>a[i];
    }
    cin >> x;
    for(int i = 0;i < n;i++){
        if(a[i] == x){
            s = i + 1;
        }
    }
    cout << s << endl;
}
