2344 - 奖项划分

题目描述

【具体要求】

一年一度的朗诵杯比赛又开始了，该比赛分为初赛和复赛两轮，每轮采取满分 $100$ 分制。

关于该比赛的奖项划分规则如下：

初赛和复赛都是满分则被评为 Top1 ;

初赛和复赛都在 $90$ 分以上（包含 $90$ 分）且不是 Top1，则被评为一等奖，输出 Gold；

初赛和复赛分数均在 $80 \sim 90$ 分之间（包含 $80$ 分，不包含 $90$ 分）则被评为二等奖，输出 Silver；

初赛和复赛总分在 $140 \sim 160$ 分之间（包含 $140$ 分，不包含 $160$ 分），且每轮分数不低于及格分数 $60$ 分，则被评为三等奖，输出 Bronze ；

其他分数不参与评奖，输出 -1 。

现在要求你帮大赛组委会写一个自动评判程序，根据每位参赛选手两轮分数划分对应奖项。

输入

输入两个正整数 $n、m（0 \lt n, m \le 100）$， $n$ 代表初赛成绩，$m$ 代表复赛成绩，中间用空格隔开。

输出

输出该选手的对应奖项，如： Top1 、 Gold 、Silver 、 Bronze 和 -1 。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int main(){
    int n,m;
    cin>>n>>m;
    if(n==100&&m==100){
        cout<<"Top1";
    }else if(n<100&&n>=90&&m<100&&m>=90){
        cout<<"Gold";
    }else if(n<100&&m<100&&n>=80&&m>=80){
        cout<<"Silver";
    }else if(n<100&&m<100&&n+m>=140&&n+m<160&&n>=60&&m>=60){
        cout<<"Bronze";
    }else{
        cout<<"-1";
    }
    return 0;
}
