3860 - 计数

题目描述

小杨认为自己的幸运数是正整数 $k$ （注：保证$ 1 \le k \le 9$）。小杨想知道，对于从 $1$ 到 $n$ 的所有正整数中，$k$ 出现了多少次。

输入

第一行包含一个正整数 $n$。

第一行包含一个正整数 $k$。

输出

输出从 $1$ 到 $n$ 的所有正整数中，$k$ 出现的次数。

AC代码

AC代码

#include <iostream>
using namespace std;

int main() {
    int n,i,a,b,k,s = 0;
    cin >> n >> k;
    for(i = 1; i <= n; i++) {
        a = i; // 不能在循环里修改i的值，把i保存下来
        // 经典的while循环短除法问题
        while(a != 0) {
            b = a % 10;
            if(b == k) {
                s++;
            }
            a = a / 10;
        }
    }
    cout << s;
}
