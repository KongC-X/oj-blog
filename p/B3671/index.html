B3671 [语言月赛202210] 配餐

洛谷 | 入门 | C++14 | 提交时间: 2026-08-26

算法标签：2022、O2优化、数组、语言月赛

题目描述

午饭时间，喵喵喵幼儿园的 nnn 位小朋友从左到右排成一列等待领取自己的午餐。我们将这些小朋友从左到右依次标号为 1,2,⋯ ,n−1,n1, 2, \cdots , n - 1, n1,2,⋯,n−1,n。

负责配餐的老师已经拿到了所有人的午饭餐食，餐食同样也是从左到右排成一排。

老师手里拿到了一份序列 r1⋯rnr _ 1 \cdots r _ nr1​⋯rn​，代表编号为 iii 的小朋友应该拿到从左向右数第 rir _ iri​ 份午餐餐食（1≤ri≤n1 \leq r _ i \leq n1≤ri​≤n 且 rir _ iri​ 两两不同）。

按照上面的序列分发完成后，老师又拿到了一个序列 a1⋯ana _ 1 \cdots a _ na1​⋯an​，其中 aia _ iai​ 代表未分发前从左向右数第 iii 份餐食的一个参数。

老师想要知道，对每个小朋友，他们所拿到的午餐的这个参数的值是多少。但是这个任务对于老师来说太难了，所以喵喵喵幼儿园找到了万能的你。

输入格式

共三行。

第一行一个整数，代表 nnn。

第二行 nnn 个整数，代表 r1⋯rnr _ 1 \cdots r _ nr1​⋯rn​。

第三行 nnn 个整数，代表 a1⋯ana _ 1 \cdots a _ na1​⋯an​。

输出格式

一行，nnn 个整数。第 iii 个整数代表编号为 iii 的小朋友所拿到的午餐的这个参数是多少。

样例

样例输入 #1

4
4 1 3 2
7 4 2 9```

**样例输出 #1**

9 7 2 4```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3671 [语言月赛202210] 配餐
     * 题意：第 i 个小朋友拿第 r[i] 份午餐，第 j 份午餐的参数是 a[j]，
     *       输出每个小朋友拿到的参数，即 a[r[i]]。
     */
    int n;
    cin >> n;
    int r[100005], a[100005];
    for (int i = 1; i <= n; i++) cin >> r[i];
    for (int i = 1; i <= n; i++) cin >> a[i];

    for (int i = 1; i <= n; i++) {
        cout << a[r[i]] << ' ';
    }
    cout << endl;
    return 0;
}
