P5019 [NOIP 2018 提高组] 铺设道路

洛谷 | 普及| C++14 | 提交时间: 2026-02-08

算法标签：贪心、2018、NOIP 提高组、差分

题目背景

NOIP2018 提高组 D1T1

题目描述

春春是一名道路工程师，负责铺设一条长度为 $n$ 的道路。

铺设道路的主要工作是填平下陷的地表。整段道路可以看作是 $n$ 块连续的区域，一开始，第 $i$ 块区域下陷的深度为 $d_i$ 。

春春每天可以选择一段连续区间 $[L,R]$ ，填充这段区间中的每块区域，让其下陷深度减少 $1$。在选择区间时，需要保证，区间内的每块区域在填充前下陷深度均不为 $0$ 。

春春希望你能帮他设计一种方案，可以在最短的时间内将整段道路的下陷深度都变为 $0$ 。

输入格式

输入文件包含两行，第一行包含一个整数 $n$，表示道路的长度。 第二行包含 $n$ 个整数，相邻两数间用一个空格隔开，第 $i$ 个整数为 $d_i$ 。

输出格式

输出文件仅包含一个整数，即最少需要多少天才能完成任务。

样例

样例输入 #1

6   
4 3 2 5 3 5

样例输出 #1

9```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int d[100005];  // 道路下陷深度

int main() {
    int n;  // 道路长度
    cin >> n;
    
    // 读入深度
    for (int i = 1; i <= n; i++) {
        cin >> d[i];
    }
    
    // 贪心计算最少天数
    long long ans = d[1];  // 第一天至少需要d[1]天
    
    for (int i = 2; i <= n; i++) {
        if (d[i] > d[i-1]) {
            // 当前深度大于前一个，需要额外天数
            ans += d[i] - d[i-1];
        }
        // 如果d[i] <= d[i-1]，在填充前一个位置时已经一起填充了
    }
    
    cout << ans << endl;
    
    return 0;
}
