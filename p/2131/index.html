2131 - 计算税金

题目描述

对一批货物征收税金。价格在 111 万以上（含一万元）的货物征税 5%5\%5% （征税 5%5\%5% 指的是用货物的价格 ×0.05\times 0.05×0.05 ），在 500050005000 元以上（含 500050005000 元），一万元以下的货物征税 3%3\%3%，在 100010001000 元（含 100010001000 元）以上，500050005000 元以下的货物征税 2%2\%2% ， 100010001000 元以下的货物免税。

编程序，读入货物的价格，计算并输出应缴的税金。

输入

货物价格。

输出

税金，要求保留小数点后两位小数。

AC代码

#include <bits/stdc++.h>
using namespace std;
 
int main(){
    //x代表货物价格 
    double x;
    //输入货物价格 
    cin>>x;
    //s代表税金 
    double s;
    if(x>=10000){
        s = x*0.05;
    }else if(x>=5000){
        s = x*0.03;
    }else if(x>=1000){
        s = x*0.02;
    }else{
        s = 0;
    }
    cout<<fixed<<setprecision(2)<<"Tax="<<s<<"yuan";
    return 0;
}
