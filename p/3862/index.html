3862 - 寻找倍数

题目描述

小杨有一个包含 nnn 个正整数的序列 A=[a1,a2,…,an]A=[a_1,a_2,\dots,a_n]A=[a1​,a2​,…,an​]，他想知道是否存在 i(1≤i≤n)i (1 \le i \le n )i(1≤i≤n) 使得 aia_iai​ 是序列 AAA 中所有数的倍数。

输入

第一行包含一个正整数 ttt，代表测试用例组数。

接下来是 ttt 组测试用例。

对于每组测试用例，一共两行。其中，第一行包含一个正整数nnn；第二行包含 nnn 个正整数，代表序列 AAA 。

输出

对于每组测试用例，如果存在 i(1≤i≤n)i (1 \le i \le n )i(1≤i≤n) 满足对于所有 k(1≤k≤n)k (1 \le k \le n)k(1≤k≤n) aia_iai​ 是 aka_kak​ 的倍数，输出 Yes，否则输出 No。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int n,m,i,j;
int a[100010];

int main() {
    cin >> m;
    for(i = 0;i < m;i++) {
        cin >> n;
        bool flag = true;
        for(j = 0;j < n;j++) cin >> a[j];
        sort(a,a+n);
        for(j = 0;j < n;j++) {
            if(a[n-1] % a[j] != 0) {
                flag = false;
                break;
            }
        }
        if(flag) cout << "Yes" << endl;
        else cout << "No" << endl;
    }
}
