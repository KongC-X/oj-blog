P17455 [GESP202609 五级] 哥德巴赫猜想

洛谷 | 普及- | C++14 | 提交时间: 2026-09-18

算法标签：数论、枚举、素数判断、2026、GESP

题目描述

众所周知，哥德巴赫猜想是说，任何大于 222 的偶数都能写成两个质数（素数）之和。例如：

  • 4=2+24=2+24=2+2
  • 6=3+36=3+36=3+3
  • 8=3+58=3+58=3+5
  • 10=3+7=5+510=3+7=5+510=3+7=5+5

聪明的你肯定想知道，对于大于 222 的偶数 nnn，它有多少种写成两个质数之和的方法。例如 444、666 和 888 都只有一种方法，101010 有两种方法。请你编写程序计算这个问题的答案。

在本题中，我们认为两种方案不同，当且仅当两种分解方案包含的素数互不相同；即 10=3+710=3+710=3+7 和 10=7+310=7+310=7+3 是同一种方案，不能重复计数。

输入格式

一行，一个大于 222 的偶数 nnn。

输出格式

一行，一个整数，表示将 nnn 写成两个质数之和的方法数。

样例

样例输入 #1

4```

**样例输出 #1**

1```

样例输入 #2

10```

**样例输出 #2**

2```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P17455 [GESP202609 五级] 哥德巴赫猜想
     * 题意：给定大于 2 的偶数 n，求将 n 写成两个质数之和的方案数（不计顺序）。
     * 数据范围：n ≤ 10^6。
     *
     * 思路：
     * 1. 用埃氏筛预处理 2 到 n 的所有质数，存入 isPrime 数组。
     * 2. 枚举第一个质数 i 从 2 到 n/2（保证 i ≤ n-i，避免重复计数）。
     * 3. 若 i 和 n-i 都是质数，则方案数加 1。
     * 4. 输出方案数。
     *
     * 时间复杂度：O(n log log n) 筛法 + O(n) 枚举，n ≤ 10^6，完全可行。
     */

    int n;                      // n: 输入的偶数
    cin >> n;

    // isPrime[i] 表示 i 是否为质数
    bool isPrime[1000005];

    // 初始化：先全部假设为质数
    for (int i = 0; i <= n; i++) {
        isPrime[i] = true;
    }
    isPrime[0] = false;         // 0 不是质数
    isPrime[1] = false;         // 1 不是质数

    // 埃氏筛
    for (int i = 2; i * i <= n; i++) {
        if (isPrime[i]) {
            for (int j = i * i; j <= n; j += i) {
                isPrime[j] = false;
            }
        }
    }

    int ans = 0;                // ans: 方案数

    // 枚举第一个质数 i，只需到 n/2，避免 (i, n-i) 与 (n-i, i) 重复
    for (int i = 2; i <= n / 2; i++) {
        if (isPrime[i] && isPrime[n - i]) {
            ans++;
        }
    }

    cout << ans << endl;        // 输出方案数
    return 0;
}
