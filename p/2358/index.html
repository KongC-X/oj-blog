2358 - A+B 问题

题目描述

【具体要求】

一张白纸上被调皮的小蓝写上了若干个整数数字，你需要快速的算出这些数字之和是多少。

输入

输入若干行，每行有若干个整数数字。

输出

输出所有输入整数数字之和。(-263≤数字和≤263-1)

AC代码

AC代码

#include <iostream>
using namespace std;
 
int main(){
    string s;
    long long sum = 0;
    while(cin >> s){
        sum += stoll(s);
    }
    cout << sum << endl;
}
