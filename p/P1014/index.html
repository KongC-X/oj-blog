P1014 [NOIP 1999 普及组] Cantor 表

洛谷 | 普及- | C++14 | 提交时间: 2026-05-24

算法标签：模拟、数学、1999、NOIP 普及组、枚举

题目描述

现代数学的著名证明之一是 Georg Cantor 证明了有理数是可枚举的。他是用下面这一张表来证明这一命题的：

我们以 Z 字形给上表的每一项编号。第一项是 1/11/11/1，然后是 1/21/21/2，2/12/12/1，3/13/13/1，2/22/22/2，……。

输入格式

输入一个整数 NNN（1≤N≤1071 \le N \le 10^71≤N≤107）。

输出格式

输出表中的第 NNN 项。

样例

样例输入 #1

7

样例输出 #1

1/4```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // ---------- 思路 ----------
    // Cantor 表的编号是 Z 字形：
    // 第 1 条斜线: 1/1
    // 第 2 条斜线: 1/2, 2/1
    // 第 3 条斜线: 3/1, 2/2, 1/3
    // 第 4 条斜线: 1/4, 2/3, 3/2, 4/1
    // ...
    //
    // 规律：
    // - 第 k 条斜线有 k 个数。
    // - 前 k 条斜线的总数是 1+2+...+k = k*(k+1)/2。
    // - 方向：k 为奇数从下往上（分子减小，分母增大），
    //         k 为偶数从上往下（分子增大，分母减小）。
    //
    // 模拟方法：
    // 1. 从 k=1 开始累加，找到 N 所在的斜线编号 k。
    // 2. 用 N 减去前 k-1 条斜线的总数，得到在斜线上的位置 pos。
    // 3. 根据 k 的奇偶性写出分数。
    // -------------------------

    int n;
    cin >> n;

    int k = 1;                     // 斜线编号
    int s = 0;                     // 前 k 条斜线的元素总数
    while (s + k < n) {            // 还没到 N 所在的那条斜线
        s += k;
        k++;
    }

    int pos = n - s;               // 在斜线上的位置（从 1 开始）

    int x, y;                      // 分子 x，分母 y
    if (k % 2 == 1) {              // 奇数斜线：左下 → 右上
        x = k - pos + 1;           // 分子从 k 递减到 1
        y = pos;                   // 分母从 1 递增到 k
    } else {                       // 偶数斜线：右上 → 左下
        x = pos;                   // 分子从 1 递增到 k
        y = k - pos + 1;           // 分母从 k 递减到 1
    }

    cout << x << '/' << y << '\n';
    return 0;
}
