1302 - 是否适合晨练？

题目描述

夏天到了，气温太高，小明的爷爷每天有晨练的习惯，但有时候温度不适合晨练；小明想编写一个程序，帮助爷爷判断温度是否适合晨练。

输入温度 ttt 的值，判断其是否适合晨练，适合晨练输出 OK ，不适合输出 NO 。( 20≤t≤3020 \le t \le 3020≤t≤30 ,则适合晨练 OK ，否则不适合 NO )。

输入

一个整数代表当天的温度。

输出

OK 或者 NO 。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    //定义变量t表示温度 
    int t;
    //输入温度 
    cin>>t;
    //如果20<=t<=30,输出"OK",否则输出"NO" 
    if(t>=20 && t<=30){
        cout<<"OK";
    }else{
        cout<<"NO";
    }
    return 0;
}
