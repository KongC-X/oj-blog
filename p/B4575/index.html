B4575 [GESP202609 二级] 直角三角形

洛谷 | 入门 | C++14 | 提交时间: 2026-09-15

算法标签：2026、循环结构、GESP

题目描述

小双刚学会勾股定理，得知直角三角形的斜边的平方等于两直角边的平方和。

小双创造了直角三角形数列：数列前两项由小双指定，从第三项开始，数列中的每个数字的平方等于前两项的平方和。

例如，第一项是 3.03.03.0，第二项是 4.04.04.0，则第三项是 3.02+4.02=5.0\sqrt{3.0^2+4.0^2}=5.03.02+4.02​=5.0。

其中 x\sqrt{x}x​ 表示 xxx 的算术平方根，可以使用 C/C++/Python 标准库中对应函数计算。

小双给定了数列的前两项，并给定一个数列上限，想让你算算数列的第几项会超过小双给定的数列上限？

输入格式

输入三行，第一行一个浮点数是数列第一项，第二行一个浮点数是数列第二项，第三行一个浮点数表示数列上限。

输出格式

输出一个正整数，表示第几项开始会超过小双给定的数列上限。

样例

样例输入 #1

3.0
4.0
10.0```

**样例输出 #1**

6```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B4575 [GESP202609 二级] 直角三角形
     * 题意：给定数列前两项 a1, a2，从第三项开始，每一项的平方等于前两项的平方和。
     *       给定上限 limit，问第几项开始超过 limit。
     * 思路：数列严格递增（因为 a1 < a2 且都是正数），所以从第一项开始逐个检查，
     *       一旦当前项 > limit，输出其索引即可。
     */
    double a, b, lim;
    cin >> a >> b >> lim;

    // 检查第一项
    if (a > lim) {
        cout << 1 << endl;
        return 0;
    }
    // 检查第二项
    if (b > lim) {
        cout << 2 << endl;
        return 0;
    }

    int i = 3;              // 当前项索引
    double p = a, c = b;    // p: 前一项, c: 当前项
    while (true) {
        double n = sqrt(p * p + c * c);   // 计算下一项
        if (n > lim) {
            cout << i << endl;
            break;
        }
        p = c;
        c = n;
        i++;
    }

    return 0;
}
