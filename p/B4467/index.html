B4467 [山西编程未来星 2025] 分摊水费 / bill

洛谷 | 入门 | C++14 | 提交时间: 2026-07-20

算法标签：2025、O2优化、山西、分支结构、科创活动、小学活动

题目描述

小山和小西合租了一套公寓，需共同分摊每月的自来水费用。水费采用阶梯计价方式，具体规则如下：

  1. 每月总用水量不超过 $10$ 立方米（含 $10$ 立方米）的部分，每立方米收费 $4$ 元。
  2. 每月总用水量超出 $10$ 立方米的部分，每立方米收费 $5$ 元。

小山每月用水量为 $a$ 立方米，小西每月用水量为 $b$ 立方米。

他们约定了一套分摊总费用的规则：

  1. 若总用水不超过 $10$ 立方米，平均分摊。
  2. 若总用水超过 $10$ 立方米，$10$ 立方米的部分平均分摊，超过的部分由用水量（$a$ 或 $b$）更多的人全额支付。

输入格式

一行，包含两个整数 $a$ 和 $b$，分别表示小山和小西贡献的用水量（单位：立方米），保证 $a$ 不等于 $b$。

输出格式

一行，包含两个整数，用空格隔开，分别表示小山和小西最终应支付的水费（单位：元）。

样例

样例输入 #1

5 4```

**样例输出 #1**

18 18```

样例输入 #2

5 6```

**样例输出 #2**

20 25```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;                    // a: 小山用水量, b: 小西用水量
    cin >> a >> b;

    int t = a + b;               // 总用水量
    int x, y;                    // 小山、小西应付水费

    if (t <= 10) {
        int s = t * 4;           // 总水费：每立方米4元
        x = s / 2;
        y = s / 2;               // 平均分摊
    } else {
        // 10立方米部分：每人20元
        int more = t - 10;       // 超出10立方米的部分
        if (a > b) {
            x = 20 + more * 5;   // 小山用水多，承担超额部分
            y = 20;
        } else {
            x = 20;
            y = 20 + more * 5;   // 小西承担超额部分
        }
    }

    cout << x << ' ' << y << endl;
    return 0;
}
