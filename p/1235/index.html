1235 - 过河的最短时间

题目描述

在漆黑的夜里，NNN 位旅行者来到了一座狭窄而且没有护栏的桥边。如果不借助手电筒的话，大家是无论如何也不敢过桥去的。

不幸的是，NNN 个人一共只带了一只手电筒，而桥窄得只够让两个人同时过。

如果各自单独过桥的话，NNN 人所需要的时间已知；而如果两人同时过桥，所需要的时间就是走得比较慢的那个人单独行动时所需的时间。

问题是，如何设计一个方案，让这 NNN 人尽快过桥，计算成绩这 NNN 个人的最短过桥时间。

比如：有四个人甲乙丙丁，他们过河需要的时间分别为，甲：111，乙：222，丙：555，丁：101010。

第一种办法：最快的 222 个人先过桥，然后让跑的最快的人来回去接剩下的人：

先让甲乙过去（222 分钟），甲回来（111 分钟），甲丙过去（555 分钟），甲回来（111 分钟），甲丁再过去（101010 分钟），总共需要 191919 分钟就可以让四个人都过去。

第二种办法：让最慢的地 222 个人一起过桥，减少最慢的人在桥上的次数。

先让甲乙过去（222 分钟），甲回来（111 分钟），丙丁过去（101010 分钟），乙回来（222 分钟），甲乙再过去（222 分钟），总共需要 171717 分钟可以让四个人都过去。

那么最慢的时间就是需要 171717 分钟！

输入

每组测试数据的第一行是一个整数 NNN (1≤N≤10001 \le N \le 10001≤N≤1000)，表示共有 NNN 个人要过河。

每组测试数据的第二行是 NNN 个整数 SiS_iSi​,表示这 NNN 个人过河所需要花时间。(0<Si≤1000 \lt S_i \le 1000<Si​≤100)

输出

所有人过河的最短时间。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int a[1005]; //每个人所需时间

int main() {

    int n;//n个旅行家
    int sum=0;//过桥用的总时间
    cin>>n;

    //输入每个人的过桥时间
    for(int i=0; i<n; i++)
        cin>>a[i];

    //过桥时间排序
    sort(a,a+n);

    //如果超过4人
    while(n >= 4) {
        //当方案1优于方案2
        if((a[0]+a[n-2]) < (2*a[1])) {
            //将用时最长的2个人送到河对面
            sum += a[n-1]; //用时最短和用时最长的一起过去
            sum += a[0]; //用时最短的回来
            sum += a[n-2]; //用时最短的和用时第二长的过去
            sum += a[0]; //用时最短的回来
        } else {
            //同样也是将用时最长的2个人送到河对面
            sum += a[1]; // 最短和第二短的人过去
            sum += a[0]; //最短的回来送手电
            sum += a[n-1]; //最长的和第二长的过去
            sum += a[1]; //第二短的回来
        }

        //人数减少2人 ：用时最长的2人已经被送过河了就不动他们了
        n -= 2;
    }

    //如果n==3，用时最短的和用时最长的一起过去，然后用时最短的回来，再和剩下的一个人过去 ；
    if(n == 3)
        sum += a[1] + a[0] + a[2];
    else if(n == 2)
        sum += a[1];
    else
        sum += a[0];

    cout<<sum<<endl;

}
