B4271 [蓝桥杯青少年组省赛 2023] 四叶玫瑰数

洛谷 | 入门 | C++14 | 提交时间: 2026-08-08

算法标签：2023、循环结构、蓝桥杯青少年组

题目描述

四叶玫瑰数是指一个四位数，其各位上的数字的四次方之和等于本身。

给定两个正整数 NNN 和 MMM ，请将 N∼M(1≤N≤M≤1 000 000)N\sim M(1\leq N\leq M\leq 1\,000\,000)N∼M(1≤N≤M≤1000000) 之间（含 NNN 和 MMM）的四叶玫瑰数按从小到大的顺序输出。

例如：N=1234N=1234N=1234，M=2345M=2345M=2345 时，有一个四叶玫瑰数 163416341634，因为 14+64+34+44=16341^4 + 6^4 + 3^4 + 4^4 = 163414+64+34+44=1634，故输出 163416341634。

输入格式

第一行输入两个正整数 N,M(1≤N≤M≤1 000 000)N,M(1\leq N\leq M\leq 1\,000\,000)N,M(1≤N≤M≤1000000)。

输出格式

输出一行，包含若干个用一个空格隔开的正整数，表示 N∼MN\sim MN∼M 之间的四叶玫瑰数按从小到大的顺序的输出结果。

题目数据保证给定的 N∼MN\sim MN∼M 范围内至少有一个四叶玫瑰数

样例

样例输入 #1

1234 2345```

**样例输出 #1**

1634```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】模拟 / 枚举
     * 【核心思路】
     * 四叶玫瑰数只可能是四位数（1000~9999），因为四位数的四位四次方和最大为 4 * 9^4 = 26244，
     * 仍然在四位数范围内，超过9999的数的四次方和不可能等于本身。
     * 所以我们只需在区间 [max(N, 1000), min(M, 9999)] 内枚举每个数，
     * 计算其各位数字的四次方之和，若等于原数则输出。
     * 题目保证至少有一个解，所以输出不会为空。
     *
     * 【时间复杂度】O(区间长度)，最多约 9000 次，很快。
     */

    int n, m;
    cin >> n >> m;

    int start = max(n, 1000);   // 左边界至少为1000
    int end = min(m, 9999);     // 右边界至多为9999

    bool first = true;          // 控制空格输出

    for (int x = start; x <= end; x++) {
        // 拆出四个数字
        int a = x / 1000;
        int b = (x / 100) % 10;
        int c = (x / 10) % 10;
        int d = x % 10;

        // 计算四次方和（9^4=6561，不会溢出）
        int sum = a*a*a*a + b*b*b*b + c*c*c*c + d*d*d*d;

        if (sum == x) {
            if (!first) cout << ' ';
            cout << x;
            first = false;
        }
    }

    cout << endl;
    return 0;
}
