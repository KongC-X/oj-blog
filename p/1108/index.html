1108 - 正整数N转换成一个二进制数

题目描述

输入一个不大于 327673276732767 的整数 nnn ，将它转换成一个二进制数。

输入

输入只有一行，包括一个整数 nnn (0≤n≤327670 \le n \le 327670≤n≤32767)。

输出

输出只有一行。
