P10250 [GESP样题 六级] 下楼梯

洛谷 | 普及- | C++14 | 提交时间: 2026-05-30

算法标签：动态规划 DP、递推、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1106

题目描述

顽皮的小明发现，下楼梯时每步可以走 111 个台阶、222 个台阶或 333 个台阶。现在一共有 NNN 个台阶，你能帮小明算算有多少种方案吗？

输入格式

输入一行，包含一个整数 NNN。

输出格式

输出一行一个整数表示答案。

样例

样例输入 #1

4```

**样例输出 #1**

7```

样例输入 #2

10```

**样例输出 #2**

274```

AC 代码

#include <iostream>
using namespace std;

int main() {
    // 题目：每次走1、2或3步，求走n级台阶的方案数。
    // DP思路：设dp[i]表示走到第i级台阶的方案数。
    // 边界：dp[0]=1（站在地面一种方式），dp[1]=1，dp[2]=2。
    // 状态转移：dp[i] = dp[i-1] + dp[i-2] + dp[i-3] （i>=3）
    // 因为n <= 60，用 long long 数组防止溢出。
    int n;
    cin >> n;

    long long dp[65] = {0};   // dp[i] 存储 i 级台阶的方案数
    dp[0] = 1;                // 地面
    dp[1] = 1;                // 1级：1步
    dp[2] = 2;                // 2级：1+1 或 2

    for (int i = 3; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2] + dp[i-3];
    }

    cout << dp[n] << endl;
    return 0;
}
