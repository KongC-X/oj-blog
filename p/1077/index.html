1077 - 桐桐去购物

题目描述

桐桐周末陪妈妈到市场购物。她和妈妈来到一个买鸡的摊位，发现鸡的价格有三种：公鸡每只 555 元钱，母鸡每只 333 元钱，小鸡 333 只 111 元钱。

妈妈就给桐桐出了一道计算题：如果用 nnn 元钱买 mmm 只鸡，问公鸡、母鸡和小鸡可以各买多少只？

注意：必须把 nnn 元钱正好用完，且买的各种鸡的只数为大于等于 000 的整数。

桐桐回到家里便拿起笔来认真计算，算了好久还没得出答案。

聪明的你通过编写程序帮助桐桐找出结果好吗？

输入

只有 111 行，两个数 nnn 和 mmm ( 0<n,m≤200000 \lt n,m \le 200000<n,m≤20000 ) 。

输出

有若干行，每行三个数，分别为公鸡、母鸡和小鸡的只数，用空格隔开，按照公鸡只数升序排列。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    //定义整数变量n,m  分别代表n元钱,m只鸡 
    int n,m; 
    //输入n,m
    cin>>n>>m;
    
    //循环公鸡的范围 
    for(int g=0;g<=n/5;g++){
        //循环母鸡的范围 
        for(int h=0;h<=(n-5*g)/3;h++){
            // 小鸡的只数 
            int x = (n-5*g-3*h)*3;
            if(g+h+x==m){
                cout<<g<<" "<<h<<" "<<x<<endl;
            }
        }
    } 
    return 0;
}
