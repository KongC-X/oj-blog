1060 - 判奇偶求和

题目描述

输入一个正整数 nnn ，如果 nnn 是奇数，则求 1∼n1 \sim n1∼n 之间所有的偶数之和；如果 nnn 是偶数,则求 nnn 所有的约数之和(包括 111 和本身)。

输入

一行，一个整数 nnn （ 1<n<50001 \lt n \lt 50001<n<5000)

输出

一行，一个整数。

AC代码

AC代码

#include<iostream>
#include<cmath>
using namespace std;

int main(){
    int n,i,s = 0;
    cin >> n;
    if(n % 2 != 0) {
        for(i = 1;i <= n;i++) {
            if(i % 2 == 0) {
                s += i;
            }
        }
    } else {
        for(i = 1;i <= n;i++) {
            if(n % i == 0) {
                s += i;
            }
        }
    }
    cout << s << endl;
}
