B4181 [厦门小学生 C++ 2024] 有趣子序列

洛谷 | 普及| C++14 | 提交时间: 2026-07-21

算法标签：字符串、2024、福建、前缀和、科创活动、小学活动

题目背景

本试题为 2024 年厦门市小学生 C++ 语言复赛试题，数据为洛谷自造。

初赛为笔试。

题目描述

小唐最近在研究一个长为 nnn 的 010101 字符串 SSS（下标从 111 开始）。

他很喜欢其子区间和子序列，例如：如下表的 010101 字符串 S=01011010S = \tt{01011010}S=01011010。

S1S_1S1​ S2S_2S2​ S3S_3S3​ S4S_4S4​ S5S_5S5​ S6S_6S6​ S7S_7S7​ S8S_8S8​
000 111 000 111 111 000 111 000
  • 子区间 [2,4][2,4][2,4] 即为：S2,S3,S4S_2, S_3, S_4S2​,S3​,S4​ 这样一个在原 SSS 串中连续的一段序列；
  • 子序列即类如：S2,S4,S6,S7S_2, S_4, S_6, S_7S2​,S4​,S6​,S7​ 这样一个按原 SSS 串顺序的，可连续、可不连续的序列。

所以，子区间肯定是子序列，但子序列不一定是子区间。

小唐会询问你 QQQ 次，每次询问给出一个 SSS 的子区间 [l,r][l,r][l,r]，他想知道是否存在 SSS 的一个“有趣子序列”，其满足：

  1. “有趣子序列”和询问的子区间 [l,r][l,r][l,r] 相同；
    例：如果询问的子区间是 [2,4][2,4][2,4]，其中，子序列 S2,S6,S7S_2, S_6, S_7S2​,S6​,S7​ 和询问的子区间 S2,S3,S4S_2, S_3, S_4S2​,S3​,S4​ 中的字符按顺序一一对应相同;

  2. “有趣子序列”不是从 SSS 中选出的一段子区间。
    例：子序列 S2,S6,S7S_2, S_6, S_7S2​,S6​,S7​ 并不是原 SSS 串中连续的一段序列，即不是原 SSS 串的一段子区间。

请对于每次询问 [l,r][l,r][l,r]，输出 Yes\tt{Yes}Yes 或 No\tt{No}No，分别表示存在或不存在这样的 “有趣子序列”。

输入格式

本题有多组数据。

  • 第一行一个非负整数 TTT，表示数据组数。
  • 接下来 TTT 组数据，对于每组数据：
    • 第一行两个非负整数 nnn 和 qqq，表示字符串长度和询问数。
    • 第二行一个 010101 字符串 sss。
    • 接下来 qqq 行，每行两个正整数 l,rl,rl,r，表示询问的子区间。

输出格式

对于每组数据：

  • 对于每个询问，输出一行 Yes\tt{Yes}Yes 或 No\tt{No}No 表示答案。

样例

样例输入 #1

2
6 3
011100
2 4
1 3
3 5
5 2
11111
1 5
2 3```

**样例输出 #1**

No
Yes
Yes
No
Yes```

AC 代码

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
int n, q;
char s[MAXN];
bool pre[MAXN], nxt[MAXN];   // pre[i]: s[i]左侧有相同字符, nxt[i]: s[i]右侧有相同字符

int main() {
    int T;
    cin >> T;
    while (T--) {
        cin >> n >> q;
        cin >> (s + 1);      // 字符串下标从1开始

        // ----- 预处理 pre -----
        bool first[2] = {false, false};   // 记录字符'0'和'1'是否已经出现过
        for (int i = 1; i <= n; i++) {
            int c = s[i] - '0';
            pre[i] = first[c];            // 之前是否出现过相同的字符
            first[c] = true;
        }

        // ----- 预处理 nxt -----
        bool last[2] = {false, false};
        for (int i = n; i >= 1; i--) {
            int c = s[i] - '0';
            nxt[i] = last[c];
            last[c] = true;
        }

        // ----- 回答询问 -----
        while (q--) {
            int l, r;
            cin >> l >> r;

            // 特判：长度为1的子序列无法变成“不是子区间”
            if (l == r) {
                cout << "No\n";
                continue;
            }

            // 长度 >1：只需检查是否能替换第一个字符或最后一个字符
            if (pre[l] || nxt[r]) {
                cout << "Yes\n";
            } else {
                cout << "No\n";
            }
        }
    }
    return 0;
}
