1394 - 恐龙园买玩具？

题目描述

小明暑假来到恐龙园游玩，在恐龙园的礼物店里，有一些形形色色的小恐龙玩偶，小明想购买其中霸王龙和三角龙玩偶送给自己的 555 位好朋友。

店员告诉小明，霸王龙玩偶一只需要 xxx 元，三角龙玩偶一只需要 yyy 元。 小明有 nnn 元，希望两种恐龙都能购买，购买的霸王龙的数量 ≥\ge≥ 三角龙的数量，购买的总数要在 555 个或者 555 个以上（这样才够分），而且不能有钱剩下。

请你编程帮助小明输出所有可能的购买方案，每组方案占 111行，先输出霸王龙的数量，再输出三角龙的数量（霸王龙的数量从少到多，三角龙的数量从多到少）

输入

三个整数 nnn xxx yyy，分别代表总金额、霸王龙的单价、三角龙的单价。

输出

所有满足条件的购买方案，每组购买方案占 111 行，用空格隔开 222 个数分别代表霸王龙的数量和三角龙的数量。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int n,x,y,i,j;
    cin >> n >> x >> y;
    for(i = 1;i <= n/x;i++){
        for(j = 1;j <= n/y;j++){
            if(i*x+j*y==n && i >= j && i + j >= 5){
                cout << i << " " << j << endl;
            }
        }
    }
    return 0;
}
