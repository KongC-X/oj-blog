1923 - 躲避拥堵的最佳路线

题目描述

小明所在的城镇有 $m$ 条路连接了 $n$ 个区（ $n$ 个区的编号在 $1 \sim n$ 的范围内），每条大道将两个区相连接，每条大道有一个拥挤度。

小明想要开车从 $s$ 区去 $t$ 区，请你帮他规划一条路线，使得经过道路的拥挤度的最大值最小。

输入

第一行有四个用空格隔开的 $n,m,s,t$ ，其含义见题目描述。

接下来 $m$ 行，每行三个整数 $u,v,w$ ，表示有一条大道连接区 $u$ 和区 $v$ ，且拥挤度为 $w$ ，道路为双向道路，两个方向都可以走。

两个区之间可能存在多条大道。

数据规模与约定
对于 $30%$ 的数据，保证 $n \le 10$ 。

对于 $60%$ 的数据，保证 $n \le 100$ 。

对于 $100%$ 的数据，保证 $1 \le n \le 10^4$，$1 \le m \le 2 \times 10^4$, $w \le 10^4$,$1 \le s,t \le n$。

且从 $s$ 出发一定能到达 $t$ 区。

输出

输出一行一个整数，代表最大的拥挤度。

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

// 经过道路的拥挤度的最大值最小（二分答案）
// 解题思路：
// 1.二分最大拥挤度，l=min(拥挤度)，r=max(拥挤度)
// 2.check(mid):检验如果最大拥挤度为mid,能否从s区到t区
// 检验方法：
// (1)将所有道路中，拥挤度值<=mid的道路修起来（合并）
// (2)查询s和t是否在一个集合
// 3.求二分的左边界

int n,m,s,t;
int fa[10010];
int l = INT_MAX,r = INT_MIN,mid;

// 存储从x区到y区有道路，道路的拥挤度为len
struct city {
    int x,y,len;
} a[20010];

int find(int x) {
    if(fa[x] == x) return x;
    return fa[x] = find(fa[x]); // 路径压缩
}

void merge(int x,int y) {
    int fx = find(x);
    int fy = find(y);
    if(fx != fy) fa[fx] = fy;
}

bool check(int mid) {
    // 初始化并查集
    for(int i = 1; i <= n; i++) {
        fa[i] = i;
    }
    // 合并所有道路中，拥挤度值<=mid的道路
    for(int i = 1; i <= m; i++) {
        if(a[i].len <= mid) {
            merge(a[i].x,a[i].y);
        }
    }
    if(find(s) == find(t)){ // s和t在一个集合
        return true;
    }
    return false;
}

int main() {
    cin >> n >> m >> s >> t;
    for(int i = 1; i <= m; i++) {
        cin >> a[i].x >> a[i].y >> a[i].len;
        // 求最大拥挤度的上下界
        l = min(l,a[i].len);
        r = max(r,a[i].len);
    }
    // 二分答案
    while(l <= r) {
        mid = (l + r) >> 1;
        // 检验如果最大拥挤度为mid,能否从s区到t区
        if(check(mid)) {
            r = mid - 1;
        } else {
            l = mid + 1;
        }
    }

    // 拥挤度的最大值最小为l
    cout << l << endl;
}
