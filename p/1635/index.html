1635 - 预算够吗

题目描述

一个工厂的总支出预算是 nnn 万元，实际原材料需要用 aaa 万元，发工资和福利需要用 bbb 万元，其他情况需要用 ccc 万元。

编程求这个工厂的预算够用吗？如果预算够，请输出还能剩余多少万元，以及输出 YESYESYES 。

比如：输入 100100100 232323 535353 212121 ，表示总支出预算有 100100100 万元，实际需要支出的各项总和 =a+b+c=23+53+21=97= a + b + c = 23 + 53 + 21 = 97=a+b+c=23+53+21=97 （万元），由于 100≥97100 \ge 97100≥97 ，因此预算是够的，还能剩余 333万元，因此输出为： 333 YES。

如果预算不够，请输出还需要多少万元才够，再输出 NONONO 。

再比如：输入 101010 222 888 555，表示总支出预算有 101010 万元，实际需要支出的各项总和 =2+8+5=15= 2 + 8 + 5 = 15=2+8+5=15 （万元），由于 10<1510 \lt 1510<15 ，显然预算不够，还需要 555万元，因此输出为： 555 NO 。

输入

一行，输入 444 个整数 n,a,b,cn,a,b,cn,a,b,c 。

输出

一行，先输出预算差额 sss ，如果够再输出 YES ，不够输出 NO ，中间用空格隔开。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;
 
int main(){
    int n,a,b,c,s;
    cin>>n>>a>>b>>c;
    s=a+b+c;
    if(n>=s){
        cout<<n-s<<" "<<"YES";
    }else{
        cout<<s-n<<" "<<"NO";
    }
}
