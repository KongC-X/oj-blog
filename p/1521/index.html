1521 - 计算分数加减表达式的值

题目描述

编写程序，输入 nnn 的值，求 1/1−1/2+1/3−1/4+1/5−1/6+1/7−1/8+…1/1 - 1/2 + 1/3 - 1/4 + 1/5 - 1/6 + 1/7 - 1/8 + \dots1/1−1/2+1/3−1/4+1/5−1/6+1/7−1/8+… 前 nnn 项的和。

输入

输入一个正整数 nnn 。( 1≤n≤10001 \le n \le 10001≤n≤1000 ) 。

输出

输出一个实数，为表达式的值，保留到小数点后四位。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin>>n;
    double s =0;//定义小数变量代表n项的和 
    //循环遍历1到n 
    for(int i=1;i<=n;i++){
        //如果i是奇数用加法,i是偶数用减法 
        if(i%2==0){
            s-=1.0/i;
        }else{
            s+=1.0/i;
        }
    } 
    //结果保留4位小数 
    cout<<fixed<<setprecision(4)<<s;
    return 0;
}
