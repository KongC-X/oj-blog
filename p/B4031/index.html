B4031 [语言月赛 202409] 始终

洛谷 | 入门 | C++14 | 提交时间: 2026-08-15

算法标签：2024、O2优化、排列组合、字符串（入门）、语言月赛

题目描述

如果一个只包含小写的字符串首字母与尾字母相同，那么字符串是“好的”。

给出一个由小写字母组成的字符串 $s$，请你求出它有多少子串是“好的”。

子串：一个字符串中，任意连续的字符构成的子字符串称为子串。
例如，字符串 abc 一共包含 7 个子串，分别为：空串（不包含任何字符)，a，ab，abc，b，bc，c。注意，字符串 ac 不是 abc 的子串。

输入格式

输入共一行，一个字符串 $s$。

输出格式

输出共一行，表示 $s$ “好的”子串的个数。

样例

样例输入 #1

abc```

**样例输出 #1**

3```

样例输入 #2

abcba```

**样例输出 #2**

7```

样例输入 #3

bbcdaadcba```

**样例输出 #3**

18```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B4031 [语言月赛 202409] 始终
     * 题意：统计字符串中首尾字符相同的子串个数。
     *
     * 核心思路：
     * 一个子串由起点 i 和终点 j（i ≤ j）决定，首尾字符相同即 s[i] == s[j]。
     * 因此，对于每种字符 c，它出现在字符串中的位置有 cnt 个，
     * 那么以该字符作为首尾的子串数量 = 选择两个位置（可相同）的组合数：
     *   cnt 个位置中任选一个作为起点和终点（可相同），
     *   方案数 = cnt * (cnt + 1) / 2。
     * 累加所有字符的贡献即为答案。
     *
     * 时间复杂度：O(|s|)
     */
    string s;
    cin >> s;
    long long cnt[26] = {0};
    int len = s.size();
    for (int i = 0; i < len; i++) {
        cnt[s[i] - 'a']++;
    }
    long long ans = 0;
    for (int i = 0; i < 26; i++) {
        ans += cnt[i] * (cnt[i] + 1) / 2;
    }
    cout << ans << endl;
    return 0;
}
