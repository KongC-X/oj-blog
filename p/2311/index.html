2311 - 爬楼梯

题目描述

已知楼梯的数量，可以每次走2级或者3级，求不同的走法数

例如：楼梯一共有7级，一共3种方法：2 2 3或者 2 3 2 或者 3 2 2。

输入

输入包含若干行，每行包含一个正整数N，代表楼梯级数，1 <= N <= 50。 最后一行为0，表示测试结束。

输出

不同的走法数，每一行输入对应一行输出

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int a[55]={0,0,1,1},t;
int main()
{
    for(int i=4;i<=50;i++) a[i]=a[i-2]+a[i-3];
    while(cin>>t&&t!=0)
    {
        cout<<a[t]<<endl;
    }
    return 0;
}
