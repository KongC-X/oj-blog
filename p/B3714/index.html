题目描述

下面程序想要实现的功能为：

输入 nnn 和 nnn 个数，统计其中奇数的个数。

#include <iostream>
using namespace std;

int main() {
  int n, ans = 0;
  cin >> n;
  for(int i = 1, x; i <= n; i++) {
    cin >> x;
    if(x % 2 == 1) ++ans;
  }
  cout << ans << endl;
}

但是这个程序存在一些问题，请你提交一个程序，你提交的程序应当输出一组这道题的输入数据，使得上面的程序输出错误的结果。

输出格式

你提交的程序输出的输入数据应当符合下面的格式：

nnn

a1 a2 ⋯ ana_1\ a_2\ \cdots \ a_na1​ a2​ ⋯ an​

第一行为一个整数 n(1≤n≤1000)n(1 \le n \le 1000)n(1≤n≤1000)。

第二行为 nnn 个整数 ai(−106≤ai≤106)a_i(-10^6 \le a_i \le 10^6)ai​(−106≤ai​≤106)，每两个整数之间由一个空格隔开。

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3714 [语言月赛202302] 牵连的世界 (Easy Version)
     * 要求：输出一组输入数据，使得给定程序（统计奇数个数）输出错误结果。
     *
     * 给定程序中判断奇数的条件是 x % 2 == 1。
     * 在 C++ 中，负数取模结果可能为负，例如 -1 % 2 = -1，不等于 1。
     * 因此负数奇数会被漏掉。
     *
     * 我们只需构造一个包含负数奇数的输入，例如 n=1, a[1]=-1。
     * 正确的奇数个数是 1，但程序会输出 0，结果错误。
     */
    cout << 1 << endl;
    cout << -1 << endl;
    return 0;
}
