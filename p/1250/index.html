1250 - 马克思手稿的问题

题目描述

马克思手稿中有一道趣味数学题：有 303030 个人，其中可能有男人、女人和小孩，在一家饭馆里吃饭共花了 505050 先令。

假设每个男人各花 333先令，每个女人各花 222 先令，每个小孩各花 111先令。

问男人、女人和小孩各有几人？（注意：不一定男人、女人、小孩都有）

输入

无

输出

每行 333 个数，按照男人、女人、小孩的顺序，由小到大依次输出所有可能的人数方案（男人、女人、小孩其中某些人的数量可以为 000 ）

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int i,j,k;
    for(i = 0;i <= 50/3;i++){
        for(j = 0;j <= 50/2;j++){
            for(k = 0;k <= 50/1;k++) {
                if(i * 3 + j * 2 + k * 1 == 50 && i + j + k == 30) {
                    cout << i << " " << j << " " << k << endl;
                }
            }
        }
    }
}
