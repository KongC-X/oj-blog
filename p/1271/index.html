1271 - 高精度整数除法

题目描述

求 a/ba/ba/b 的结果。

已知 aaa，bbb 为 10810^8108 范围内的非负整数，求 a/ba/ba/b 保留前 nnn 位小数商的结果。

输入

读入三个整数 aaa bbb nnn。

输出

输出一行数字。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
using namespace std;

int main(){
    // 高精度除法
    int a,b,i,n,t;
    cin >> a >> b >> n;
    cout << a / b << '.';
    t = a % b;
    for(i = 1;i <= n;i++) {
        t = t * 10;
        cout << t / b;
        t = t % b;
    }
}
