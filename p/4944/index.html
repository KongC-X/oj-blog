4944 - 汤姆的日记

题目描述

小男孩汤姆在家里的旧柜子里发现了一本古老的日记。日记中记录了一个失落王国的秘密和一条通往宝藏的路径。好奇心驱使他按照日记的指引，找到了一扇隐藏在树林深处的石门。打开石门后，他进入了一个神秘的地下世界，里面充满了奇珍异宝。回到家后，汤姆把日记放回柜子，从此期待每一次新的探索与发现。

小男孩汤姆家的柜子是一个长方体，由很多小柜子组成。汤姆一共有 nnn 次操作，分为两种类型：

【第一种类型】M i j k：汤姆往第 iii 行第 jjj 列的柜子里存入日记，并在日记上面写下编号 kkk。

【第二种类型】N i j：汤姆取出第 iii 行第 jjj 列柜子里的日记，输出日记的编号(保证取出的柜子里有日记)。

输入

输入一共 n+1n+1n+1 行:

第一行只有一个整数 nnn，表示操作次数;

接下来 nnn 行，每行表示一次操作，M 代表第一种类型，N 代表第二种类型，具体操作如题目描述所示。

输出

对于每次查询操作，输出答案，以换行符隔开。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int n,i,j,k,x,y;
int a[1010][1010];
char c;
int main(){
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> c >> x >> y;
        if(c == 'M') {
            cin >> k;
            a[x][y] = k;
        } else {
            cout << a[x][y] << endl;
        }

    }
}
