1246 - 请输出n行的9*9乘法表

题目描述

请从键盘读入一个整数 $n$ ，代表有 $n$ 行，输出 $n$ 行的 $9 *9$ 乘法表。

比如，假设 $n=5$ ，则输出如下： 

`1*1=1
2*1=2 2*2=4
3*1=3 3*2=6 3*3=9
4*1=4 4*2=8 4*3=12 4*4=16
5*1=5 5*2=10 5*3=15 5*4=20 5*5=25
`

输入

一个整数 $n（n \le 9$ ）

输出

$n$ 行的 $9\times 9$ 乘法表。

AC代码

#include <iostream>
using namespace std;

int main() {
    int n,i,j;
    cin >> n;
    // 九九乘法表
    for(i=1;i<=n;i++){
        for(j=1;j<=i;j++){
            cout << i << "*" << j << "=" << i*j << " ";
        }
        cout << endl;
    }
    return 0;
}
