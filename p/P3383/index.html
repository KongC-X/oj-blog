P3383 【模板】线性筛素数

洛谷 | 普及- | C++14 | 提交时间: 2026-05-22

算法标签：数学、数论、O2优化、素数判断、线性筛法、模板题

题目背景

本题已更新，从判断素数改为了查询第 kkk 小的素数。

提示：本题输入输出、运算数据量较大。

  • 对于 C++ 语言，如果你使用 cin 来输入输出，建议使用 std::ios::sync_with_stdio(0) 来加速，同时使用 '\n' 换行输出。
  • 对于 Java 语言，使用线性筛并且优化输入输出，也可以在规定时限内通过本题，但是时限可能较紧张。
  • 对于 Python 语言，语言性能差异较大，需要使用到 numpy 库的数组以替代列表，且使用埃氏筛法，依然可以在合适的时间和内存消耗下通过本题。

题目描述

如题，给定一个范围 nnn，有 qqq 个询问，每次输出第 kkk 小的素数。

输入格式

第一行包含两个正整数 n,qn,qn,q，分别表示查询的范围和查询的个数。

接下来 qqq 行每行一个正整数 kkk，表示查询第 kkk 小的素数。

输出格式

输出 qqq 行，每行一个正整数表示答案。

样例

样例输入 #1

100 5
1
2
3
4
5```

**样例输出 #1**

2
3
5
7
11```

AC 代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

const int N = 100000000;          // 数据范围 1e8
bool f[N + 5];                    // false 表示素数，true 表示合数
int primes[6000000];              // 存储素数，1e8 内约有 576 万个
int k, n, q;                      // k: 素数个数，n: 范围，q: 询问次数

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);                   // 读入加速
    
    cin >> n >> q;
    
    // 0 和 1 不是素数
    f[0] = true;
    f[1] = true;
    k = n - 1;                    // 初始假设除了 0,1 都是素数
    
    // 埃氏筛
    for (int i = 2; i * i <= n; i++) {
        if (!f[i]) {              // i 是素数
            // 将 i 的倍数标记为合数
            for (int j = i * i; j <= n; j += i) {
                if (!f[j]) {      // 避免重复计数
                    f[j] = true;
                    k--;          // 素数个数减一
                }
            }
        }
    }
    
    // 收集所有素数
    int cnt = 0;
    for (int i = 2; i <= n; i++) {
        if (!f[i]) {
            primes[++cnt] = i;    // 下标从 1 开始
        }
    }
    // 此时 cnt 与 k 相等，都是素数总数
    
    // 回答 q 次询问
    while (q--) {
        int x;
        cin >> x;
        cout << primes[x] << '\n';
    }
    
    return 0;
}
