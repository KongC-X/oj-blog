1737 - 奇怪的数？

题目描述

小明最近刚刚学习数学，回家后老师布置了一道题目：要求小明找出满足条件的奇怪整数：

AAA 、该数为四位数

BBB 、该数的千位和十位对调，百位和个位对调后，仍然等于本身

CCC 、该数为奇数。

你能帮助小明找到满足以上条件的奇怪整数吗？

输入

输入一个整数 n(n≥1000)n(n \ge 1000)n(n≥1000) 。

输出

nnn 以内的奇怪整数，每行一个。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
 
int main() {
    int n,q,b,s,g,m;
    cin>>n;
    int i;
    //遍历所有4位整数 
    for(i=1000;i<=n;i++){
        //对i进行拆位 
        q=i/1000;
        b=i/100%10;
        s=i%100/10;
        g=i%10;
        //千位和十位对调，百位和个位对调 
        m=s*1000+g*100+q*10+b;
        //对调后仍然等于本身且该数为奇数
        if(i==m&&i%2==1){
            cout<<i<<endl;
        }
    }
    return 0;
}
