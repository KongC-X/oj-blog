1349 - 植树的人数

题目描述

某班学生分 $2$ 组参加植树活动，甲组有 $17$ 人，乙组有 $25$ 人，后来由于需要，从甲组抽调了部分学生去乙组，结果乙组的人数是甲组的 $2$ 倍，请问从甲组抽调了多少人去乙组？

（7.1）

输入

无

输出

甲组抽调去乙组的人数。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main(){
    int i,j,n,x,y;
    // cin >> n >> x >> y;
    for(i = 1;i <= 17;i++) {
        if((17-i) * 2 == (25 + i)) {
            cout << i;
        }
    }
}
