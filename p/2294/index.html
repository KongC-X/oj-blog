2294 - 数的输入和输出

题目描述

输入一个整数和双精度浮点数，先将浮点数保留 222 位小数输出，然后输出整数。

输入

一行两个数，分别为整数 NNN （不超过整型范围），双精度浮点数 FFF ，以一个空格分开。

输出

一行两个数，分别为保留 222 位小数输出的 FFF ,以及整数NNN ，以一个空格分开。

解题思路

AC代码

AC代码

#include <iostream>
#include <iomanip>
using namespace std;
int main(){
    int n;
    double f;
    cin>>n>>f;
    cout<<fixed<<setprecision(2)<<f<<" ";
    cout<<n; 
    return 0;
}
