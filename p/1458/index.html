1458 - 粉碎数字

题目描述

小鱼同学得到了 nnn 个数字，他想知道，如果把这 nnn 个数字扔到粉碎机粉碎一下，能组成的最大数是多少？小鱼的同学们完全不明白粉碎机怎样粉碎数字，小鱼就数字粉碎做了一个定义：把数字完全打碎，比如有 222 个数 198198198 和 636363 ，那么粉碎后有数字 1、9、8、6、31、9、8、6、31、9、8、6、3 ，那么能够组成的最大数就是 986319863198631 。请你编写程序，帮助小鱼同学实现这个奇特的想法。

输入

第一行是一个整数 nnn （ nnn 是 1∼10001 \sim 10001∼1000 之间的整数)。

第二行有 nnn 个整数（每个整数都是 0∼99990 \sim 99990∼9999 之间的整数）。

输出

nnn 个整数粉碎后能够组成的最大的整数。

解题思路

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

bool cmp(int a,int b) {
    return a > b ? true : false;
}

int main() {
    int n,i;
    cin >> n;
    string s,s1;
    for(i = 0;i < n;i++) {
        cin >> s1;
        s += s1;
    }
    sort(s.begin(),s.end(),cmp);
    cout << s;
}
