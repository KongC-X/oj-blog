1453 - 橘子排队

题目描述

秋天到了，同学们去橘子园摘橘子。

张老师要求同学们把摘好的橘子去掉一个最大的，再去掉一个最小的的橘子，求出剩余的橘子的平均重量，并将剩余的橘子按照由轻到重排序。

输入

第一行是橘子的数量 nnn。（3≤n≤2003≤n≤2003≤n≤200）

第二行是 nnn 个正整数，表示这些橘子的重量。

输出

第一行输出剩余橘子的平均重量，结果保留 111 位小数。

第二行输出剩余橘子按照由轻到重排序后的结果。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int main()
{
    int n, i, a[205], s = 0;
    cin >> n;
    for(i = 1; i <= n; i++){
        cin >> a[i];
        s += a[i];
    }
    sort(a+1, a+n+1);//先处理排序
    s = s - a[1] - a[n];//再处理最大值和最小值
    printf("%0.1f\n",s * 1.0 / (n - 2));
    for(i = 2; i < n; i++){
        cout << a[i] << ' ';
    }
    return 0;
}
