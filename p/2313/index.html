2313 - 数列

题目描述

用以下方式构造数列 数列的第一个和第二个数都为 111，接下来每个数都等于前面 222 个数之和。

给出一个正整数 aaa，要求数列中第 aaa 个数对 100010001000 取模的结果是多少?

输入

第1行是测试数据的组数 nnn，后面跟着 nnn 行输入。每组测试数据占1行，包括一个正整数 a(1≤a≤1000000)a(1 \le a \le 1000000)a(1≤a≤1000000)。

输出

nnn 行，每行输出对应一个输入。输出应是一个正整数，为数列中第aaa个数对 100010001000 取模得到的结果。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int a[30];//存储数列的值
int n, x;
int main()
{
    cin >> n;
    for (int i = 1; i <= n; i++)
    {
        cin >> x; //求第x项的值
        a[1] = 1;
        a[2] = 1;
        //从第3项开始推导
        for (int j = 3; j <= x; j++)
        {
            a[j] = a[j - 1] + a[j - 2];
        }
        cout << a[x]%1000 << endl;
    }
    return 0;
}
