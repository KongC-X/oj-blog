B3876 [信息与未来 2015] 中间值

洛谷 | 入门 | C++14 | 提交时间: 2026-04-11

算法标签：数学、2015、江苏、信息与未来

题目描述

给出一个正整数 nnn，生成长度为 nnn 的数列 aaa，其中 ai=i(1≤i≤n)a_i=i(1\le i\le n)ai​=i(1≤i≤n)。

  • 若 nnn 为奇数，则输出 aaa 的中间数（位于 aaa 正中位置的数）；
  • 若 nnn 为偶数，则输出位于 aaa 中间两个数的和。

输出格式

一个正整数。若 nnn 为奇数，则输出其中间值；若 nnn 为偶数，则输出两个中间值的和。

样例

样例输入 #1

9```

**样例输出 #1**

5```

样例输入 #2

10```

**样例输出 #2**

11```

AC 代码

#include <iostream>
using namespace std;

int main() {
    long long n;
    cin >> n;
    if (n % 2 == 1) {
        cout << (n + 1) / 2 << endl;
    } else {
        cout << n + 1 << endl;
    }
    return 0;
}
