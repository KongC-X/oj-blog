1473 - 去掉x个最高最低分后的平均分

题目描述

期末考试结束了，黄老师需要计算一下，本班同学们的语文成绩，如果去掉 xxx 个最高分和 xxx 个最低分，剩余同学的平均分是多少分，请你编程计算一下？

输入

第一行有两个整数 nnn 和 xxx ，nnn 代表分数的总数， xxx 代表要去掉的最高分和最低分的数量（10≤n≤1000010 \le n \le 1000010≤n≤10000，x<n/4x \lt n/4x<n/4）；

第二行有 nnn 个整数，代表 nnn 个同学的分数。

输出

nnn 个分数去掉 xxx 个最高分和 xxx 个最低分后的平均分，结果保留 111 位小数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int main()
{
    int i,j,x,n,sum=0,a[10010];
    cin>>n>>x;
    for(i=1;i<=n;i++)       
   cin>>a[i];
   for(i=1;i<=n-1;i++)
   for(j=1;j<=n-i;j++)
       if(a[j]>a[j+1]) swap(a[j],a[j+1]);
    for(i=x+1;i<=n-x;i++)
        sum=sum+a[i];
    cout<<fixed<<setprecision(1)<<(sum*1.0)/(n-x*2)<<endl;
return 0;
}
