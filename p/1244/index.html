1244 - 请问一个正整数能够整除几次2

题目描述

请问一个正整数 $n$ 能够整除几次 $2$？

比如： $4$ 可以整除 $2$ 次 $2$ ，$100$ 可以整除 $2$ 次 $2$ ， $9$ 可以整除 $0$ 次 $2$ 。

输入

从键盘读入一个正整数 $n$ 。

输出

输出一个整数，代表 $n$ 能够整除 $2$ 的次数。

AC代码

AC代码

# include <iostream>
using namespace std;

int s;
void fun(int n) {
    if(n % 2 == 0) {
        s++;
        fun(n / 2);
    }
}

int main() {
    int n;
    cin >> n;
    fun(n);
    cout << s << endl;
}
