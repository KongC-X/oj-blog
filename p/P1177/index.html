P1177 【模板】排序

洛谷 | 普及- | C++14 | 提交时间: 2025-08-26

算法标签：排序、模板题

题目描述

将读入的 NNN 个数从小到大排序后输出。

输入格式

第一行为一个正整数 NNN。

第二行包含 NNN 个空格隔开的正整数 aia_iai​，为你需要进行排序的数。

输出格式

将给定的 NNN 个数从小到大输出，数之间空格隔开。

样例

样例输入 #1

5
4 2 4 5 1```

**样例输出 #1**

1 2 4 4 5```

AC 代码

#include<bits/stdc++.h> 
#include<iostream> 
using namespace std;

int a[100010];

int main() {
    int n;
    cin >> n;
    for(int i = 0;i < n;i++) {
        scanf("%d", &a[i]);
    }
    sort(a,a+n);
    for(int i=0; i<n; i++) {
        printf("%d ", a[i]);
    }
}
