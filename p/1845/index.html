1845 - s01串

题目描述

s01 串初始为 "0"，按以下方式变换：

  • 将字符串中的 0 转换为 1。

  • 将字符串中的 1 转换为 01。

请计算出，s01 串从初始的 "0"，开始，经过 $N$ 次变换后的结果是什么？

输入

输入 $1$ 个整数 $N$ ($N$ 在 $0 \sim 19$ 的范围内)。

输出

输出经过 $N$ 次变换后 s01 串的结果。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    string s = "0";
    int n;
    cin>>n;
    for(int i = 0;i < n;i++){
        string t = "";
        for(int j = 0;j < s.size();j++){
            if(s[j] == '0') t = t + '1';
            else if(s[j] = '1') t = t + "01";
        }
        s = t;
    } 
    
    cout<<s;
    return 0;
}
