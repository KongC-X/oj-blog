1563 - 植树

题目描述

StarStarStar 为了参加编程选拔考试已经做好了非常充分的准备，但是他有个最重要的毛病就是他十分的粗心，为了能在考试中不犯低级错误，拿到比较好的成绩， starstarstar 决定做件好事来增加他的 rprprp 。

做什么好事呢？starstarstar 想到了常州好多道路刚修好，路边的绿化还没有好，于是 starstarstar 决定为一条刚修好的马路两旁种上树木。当然这一定是 starstarstar 亲自抄手（挖坑，种树，浇水 …\dots…工程量好大，为了 rprprp ，starstarstar 豁出去了，再累再苦也干），道路每隔5米种一棵树，正常情况下 starstarstar 种一棵树需要 161616 分钟（这么快，因为我们的 starstarstar 身强力壮）但是由于有部分位置的土壤质地不一样，所以 starstarstar 种树的时间有时会和正常情况不一样，质地软的就种得快，质地硬的就种得慢，当然不一样的土壤是预先知道的，所以 starstarstar 想统计他种完一条路上的树需要多少时间。

输入

第 111 行：两个整数 mmm 和 nnn , mmm 表示道路有 mmm 米，（ mmm 保证是 555 的倍数）， nnn 表示有 nnn 段不同质地的土壤； m≤100,n≤100m \le 100,n \le 100m≤100,n≤100 ；

第 2..n+12..n+12..n+1 行：每行 333 个整数 a,b,ka,b,ka,b,k 表示从第 aaa 米开始到 bbb 米结束这段道路的质地是一样的，(a≤ba \le ba≤b)在这些地上每种树需要耗费 kkk 分钟时间，道路起始位置为 000 ，起始位置当然也是要植树的。

输出

一行：一个整数（保证在 longintlongintlongint 范围）， starstarstar 种完一条道路上的树需要的总时间。（注意道路的两边都要植树）

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

/*
关键信息： 
1.正常情况下种一棵树需要16分钟
2.道路每隔5米种一棵树
3.种树的时间有时会和正常情况不一样
4.道路起始位置为0（下标为0有树的，下标为m也是有树的） 
5.道路的两边都要植树

思路：
1.将所有的点值都设置为16
2.将读入的道路范围，设置为读入的种树时间 
3.将5的倍数的点，求和 * 2 
*/ 

long long a[110];//存储每个点的种树时间
long long s;//种树时间的和 
long long x,y,z;
int m,n; 

int main() {
    cin>>m>>n;
    
    long long i,j;
    
    //初始化
    for(i = 0;i <= m;i++) a[i] = 16; 
    
    //读入n种不同的土壤 
    for(i = 1;i <= n;i++){
        cin>>x>>y>>z;//从x到y之间的种树时间是z
        for(j = x;j <= y;j++){
            a[j] = z;
        } 
    } 
    
    //计算5的倍数的点的种树时间的和
    for(int i = 0;i <= m;i++){
        if(i % 5 == 0){
            s = s + a[i];
        }
    } 
    
    cout<<s * 2;
}
