2661 - 差为给定的数

题目描述

给定一组整数，再另外给定一个整数 $T$，请编程计算出，这组整数中，两数之差为 $T$ 的数对，有多少组？

请注意：不同位置的数字一样的数对算不同的数对。

输入

输入共两行。

第一行，两个整数 $N, T$。

第二行，$N$ 个整数，用空格隔开。

输出

一个整数，表示数组中包含的满足 $A - B = T$ 的数对的个数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h> 
using namespace std;
int a[200100];
int n,x,m;
long long q;
int z(int x){
    int left=1,right=n;
    while(left<=right){
        int mid=left+(right-left)/2;
        if(a[mid]>=x){
            right=mid-1;
        }else{
            left=mid+1;
        }
    }return left+1;
}int y(int x){
    int left=1,right=n;
    while(left<=right){
        int mid=(left+right)/2;
        if(a[mid]>x){
            right=mid-1;
        }else{
            left=mid+1;
        }
    }return left+1; 
}
int main(){
    cin>>n>>m;
    for(int i=1;i<=n;i++){
        scanf("%d",&a[i]);
    }sort(a+1,a+1+n);
    for(int i=1;i<=n;i++){
        int w=a[i]+m;
        int s=z(w);
        int e=y(w);
        q+=e-s;
    }cout<<q;
}
