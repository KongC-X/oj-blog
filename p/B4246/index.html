B4246 [语言月赛 202503] 环形游走

洛谷 | 入门 | C++14 | 提交时间: 2026-08-01

算法标签：2025、数组、语言月赛

题目描述

有 nnn 个小朋友排成一圈，按照顺时针顺序依次被编号为 1∼n1\sim n1∼n，每个小朋友衣服上都有一个数字，第 iii 个小朋友的数字是 aia_iai​。

老师想要选出一个小朋友，于是他先站在 111 号小朋友旁边，然后以如下方式移动 mmm 次：

  • 逆时针走过「当前小朋友衣服上的数字」数量的小朋友。

你需要求解，老师最后会站在哪位小朋友旁边。

我们在样例解释处提供了图片说明，可以参照辅助理解。

输入格式

输入共两行。

第一行两个整数 n,mn, mn,m，分别代表小朋友的数量和老师移动的次数；
第二行 nnn 个整数 a1,⋯ ,ana_1, \cdots, a_na1​,⋯,an​，代表每个小朋友衣服上的数字。

输出格式

输出共一行一个整数，代表 mmm 次移动后老师站在哪位小朋友旁边。

样例

样例输入 #1

6 3
2 1 4 5 2 3

样例输出 #1

5

样例输入 #2

8 3
10 5 1 10 3 7 2 3

样例输出 #2

2

样例输入 #3

1 100
100

样例输出 #3

1

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】模拟
     * 【核心思路】
     * 1. 将位置从 1~n 映射到 0~n-1，方便取模。
     * 2. 初始 pos = 0（对应 1 号）。
     * 3. 每次移动：逆时针走 a[pos] 步，
     *    等价于 pos = (pos - a[pos]) mod n（保证非负）。
     *    用公式：pos = (pos - a[pos] % n + n) % n。
     * 4. 最后输出 pos+1。
     *
     * 【时间复杂度】O(m)
     */

    int n, m;
    cin >> n >> m;

    int a[5005];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int pos = 0;  // 0 对应 1 号小朋友
    for (int i = 0; i < m; i++) {
        // 逆时针走 a[pos] 步
        pos = (pos - a[pos] % n + n) % n;
    }

    cout << pos + 1 << endl;
    return 0;
}
