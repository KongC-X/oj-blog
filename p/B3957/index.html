B3957 [GESP202403 三级] 完全平方数

洛谷 | 入门 | C++14 | 提交时间: 2024-11-13

算法标签：2024、数组、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1143

题目描述

小杨同学有一个包含 nnn 个非负整数的序列 AAA，他想要知道其中有多少对下标组合 ⟨i,j⟩\langle i,j\rangle⟨i,j⟩（1≤i<j≤n1 \leq i < j \leq n1≤i<j≤n），使得 Ai+AjA_i + A_jAi​+Aj​ 是完全平方数。

如果 xxx 是完全平方数，则存在非负整数 yyy 使得 y×y=xy \times y = xy×y=x。

输入格式

第一行一个非负整数 nnn，表示非负整数个数。
第二入行包含 nnn 个非负整数 A1,A2,…AnA_1, A_2, \dots A_nA1​,A2​,…An​，表示序列 AAA 包含的非负整数。

输出格式

输出一行一个整数表示答案。

样例

样例输入 #1

5
1 4 3 3 5```

**样例输出 #1**

3```

AC 代码

#include<bits/stdc++.h>
#include<iostream>
using namespace std;

int z,x,c,v,b,n,m,i,j,a[1100];
int main(){
    cin>>n;
    for(i=0;i<n;i++){
        cin>>a[i];
    }
    for(i=0;i<n;i++){
        for(j=i + 1;j<n;j++){
            int x = a[i] + a[j];
            if(sqrt(x) == int(sqrt(x))){
                c++;
            }
        }
    }
    cout<<c;
}
