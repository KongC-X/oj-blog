1999 操场换位置

东方博宜 入门 二维数组

1999 - 操场换位置

题目描述

同学们在操场上排成了一个 $n$ 行 $m$ 列的队形，请将这个队形中，年龄最大的同学和年龄最小的同学交换位置，并输出交换的结果（本题数据保证年龄最大的同学和年龄最小的同学在矩阵中是唯一的）。

比如：如下是一个 $3$ 行 $4$ 列的队形，这个队形中每个数字代表了每个同学的年龄。

`8 10 18 9
15 12 10 6
17 3 12 15
`

这个队形中，年龄最大的同学在第 $1$ 行第 $3$ 列，年龄最小的同学在第 $3$ 行第 $2$ 列，将他们交换位置后输出结果为：

`8 10 3 9
15 12 10 6
17 18 12 15
`

输入

第 $1$ 行有 $2$ 个整数 $n$ 和 $m$ ，分别代表队形的行和列的值（$2 \le n,m \le 200$）。

接下来 $n$ 行，每行有 $m$ 个整数，代表每个同学的年龄（每个同学的年龄的值在 $1 \sim 100$ 之间）

输出

输出 $n$ 行 $m$ 列，代表交换位置后的结果，每行的 $m$ 个数之间用空格隔开。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int a[210][210];

int main() {
    //注意：y1不能定义到main外面会和系统函数同名
    //x1 y1：最大数下标
    //x2 y2：最小数下标
    int n,m,x1,y1,x2,y2;
    cin>>n>>m;

    //设定初始值
    x1 = 1;
    y1 = 1;
    x2 = 1;
    y2 = 1;

    for(int i = 1; i <= n; i++) {
        for(int j = 1; j <= m; j++) {
            cin>>a[i][j];
            if(a[i][j] > a[x1][y1]) {
                x1 = i;
                y1 = j;
            }

            if(a[i][j] < a[x2][y2]) {
                x2 = i;
                y2 = j;
            }
        }
    }

    //交换
    swap(a[x1][y1],a[x2][y2]);

    //输出
    for(int i = 1; i <= n; i++) {
        for(int j = 1; j <= m; j++) {
            cout<<a[i][j]<<" ";
        }
        cout<<endl;
    }

    return 0;
}
