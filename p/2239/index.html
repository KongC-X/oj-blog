2239 - 成绩排序

题目描述

给出班里某门课程的成绩单，请你按成绩从高到低对成绩单排序输出，如果有相同分数则名字字典序小的在前。

输入

第一行为 nnn ()，表示班里的学生数目； 接下来的 nnn 行，每行为每个学生的名字和他的成绩，中间用单个空格隔开。名字只包含字母且长度不超过 202020，成绩为一个不大于 100100100 的非负整数。

输出

把成绩单按分数从高到低的顺序进行排序并输出，每行包含名字和分数两项，之间有一个空格。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

/*
采用结构体数组排序
*/
struct node{
  string name;
  int score;
};

node a[30];
int n;

//排序比较函数
bool cmp(node n1,node n2){
  if(n1.score>n2.score||(n1.score==n2.score&&n1.name<n2.name)) return true;
  else return false;
}

int main(){
  cin>>n;
  for(int i = 1;i <= n;i++){
    cin>>a[i].name>>a[i].score;
  }
  
  sort(a+1,a+n+1,cmp);//排序
  
  //输出
  for(int i = 1;i <= n;i++){
    cout<<a[i].name<<" "<<a[i].score<<endl;
  }
  return 0;
}
