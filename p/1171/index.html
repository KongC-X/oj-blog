1171 - 数字交换

题目描述

有一组数（设有 NNN 个），编一程序交换这组数中任意指定的两段。(两段不重合，且这两段的数字个数一样)

输入

第 111 行，输入一个整数 NNN（不超过 202020 个）；

第 222 行，输入一行 NNN 个数，由空格分开；

第 333 行，输入两个空格分开的数（表示要交换的其中一段）；

第 444 行，输入两个空格分开的数（表示要交换的其中另一段）。

输出

交换后的一行数（中间用空格隔开）。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main(){
    int a[30],n,x1,x2,y1,y2,i,j;
    cin>>n;
    for(i=1;i<=n;i++) cin>>a[i];
    cin>>x1>>x2;
    cin>>y1>>y2;
    for(i=x1,j=y1;i<=x2,j<=y2;i++,j++){
        swap(a[i],a[j]);
    }
    for(i=1;i<=n;i++) cout<<a[i]<<" ";
    return 0;
}
