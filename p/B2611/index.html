B2611 【深基1.习3】竞赛得分

题目描述

小 A 和 UIM 程序设计竞赛中得分之和是 480480480，UIM 的得分是小 A 的 1.41.41.4 倍，请问小 A、UIM 分别得了多少分？

输出格式

请输出两个数字表示答案，均为整数，中间用空格隔开。

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】和倍问题
     * 【核心思路】
     * 设小A得分为 x，UIM得分为 1.4x。
     * x + 1.4x = 480 → 2.4x = 480 → x = 200
     * 所以小A=200，UIM=480-200=280。
     *
     * 【时间复杂度】O(1)
     */

    double x;          // x: 小A的得分
    int a, u;          // a: 小A得分, u: UIM得分

    x = 480 / 2.4;     // 解方程求小A得分
    a = (int)x;        // 转整数
    u = 480 - a;       // UIM得分

    cout << a << " " << u << endl;   // 输出 200 280
    return 0;
}
