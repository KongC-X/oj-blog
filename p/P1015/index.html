P1015 [NOIP 1999 普及组] 回文数

洛谷 | 普及- | C++14 | 提交时间: 2026-06-14

算法标签：模拟、高精度、1999、NOIP 普及组、进制

题目描述

若一个数（首位不为零）从左向右读与从右向左读都一样，我们就将其称为回文数。

例如，给定一个十进制数 565656，将 565656 加 656565（即把 565656 从右向左读），得到的 121121121 是一个回文数。

又如，对于十进制数 878787：

STEP1：87+78=16587+78=16587+78=165
STEP2：165+561=726165+561=726165+561=726
STEP3：726+627=1353726+627=1353726+627=1353
STEP4：1353+3531=48841353+3531=48841353+3531=4884

在这里，一步是指进行一次 NNN 进制加法，上例最少用了 444 步得到回文数 488448844884。

请编写程序，给定一个 NNN 进制数 MMM，求最少经过几步可以得到回文数。如果在 303030 步以内（包含 303030 步）不可能得到回文数，则输出 Impossible!。

其中，2≤N≤102\le N\le 102≤N≤10 或 N=16N=16N=16，MMM 的长度不超过 100100100 位，且只包含数字或大写字母。

输入格式

输入共两行。

第一行包含一个整数 NNN。

第二行包含一个 NNN 进制数 MMM。

输出格式

如果能在 303030 步以内得到回文数，输出格式形如 STEP=ans，其中 ans\text{ans}ans 为最少得到回文数的步数。

否则输出 Impossible!。

样例

样例输入 #1

10
87

样例输出 #1

STEP=4

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 字符转数值（支持0-9, A-F）
int val(char c) {
    if (c >= '0' && c <= '9') return c - '0';
    return c - 'A' + 10;               // 'A'~'F' -> 10~15
}

// 数值转字符（0-15）
char chr(int v) {
    if (v < 10) return '0' + v;
    return 'A' + v - 10;
}

// N 进制高精度加法，返回 s1 + s2 的字符串
string add(const string &s1, const string &s2, int N) {
    const int L = 250;                 // 最大长度（题目保证100位，足够）
    int a[L] = {0}, b[L] = {0}, c[L] = {0};

    // 逆序存入数组，高位在后
    for (int i = 0; i < s1.size(); i++) {
        a[i] = val(s1[s1.size() - 1 - i]);
    }
    for (int i = 0; i < s2.size(); i++) {
        b[i] = val(s2[s2.size() - 1 - i]);
    }

    int len = max(s1.size(), s2.size());
    // 逐位相加
    for (int i = 0; i < len; i++) {
        c[i] = a[i] + b[i];
    }
    // 处理进位
    for (int i = 0; i < len; i++) {
        if (c[i] >= N) {
            c[i + 1] += c[i] / N;
            c[i] %= N;
        }
    }
    if (c[len] != 0) len++;            // 最高位进位

    // 逆序输出为字符串
    string res;
    for (int i = len - 1; i >= 0; i--) {
        res.push_back(chr(c[i]));
    }
    return res;
}

// 判断字符串是否为回文
bool isPal(const string &s) {
    int len = s.size();
    for (int i = 0; i < len / 2; i++) {
        if (s[i] != s[len - 1 - i]) return false;
    }
    return true;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int N;                             // 进制
    string M;                          // 输入的 N 进制数
    cin >> N >> M;

    int step = 0;
    while (step <= 30) {
        if (isPal(M)) {
            cout << "STEP=" << step << '\n';
            return 0;
        }
        if (step == 30) break;         // 已达30步，不可能
        // 将 M 反转作为第二个加数
        string rev = M;
        reverse(rev.begin(), rev.end());
        M = add(M, rev, N);
        step++;
    }

    cout << "Impossible!\n";
    return 0;
}
