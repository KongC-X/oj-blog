2342 - 高斯求和

题目描述

【具体要求】

高斯（1777-1855），德国数学家、物理学家、天文学家，他和牛顿、阿基米德被誉为有史以来的三大数学家，有“数学王子”之称。传闻高斯上小学时就能快速的计算出老师布置的作业，求 1+2+3+...+99+100 的和，他运用了“和=（首项+末项） * 项数/2”的原理。

先给出一个正整数 n，请你编程求出 1+2+...+n 的累加和。

输入

输入一个正整数 n（3 < n <=100)。

输出

输出从 1 到 n 相加的和。

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n,i,s = 0;
    cin >> n;
    for(i = 1;i <= n;i++) {
        s += i;
    }
    cout << s << endl;
}
