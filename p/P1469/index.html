P1469 找筷子

洛谷 | 普及- | C++14 | 提交时间: 2026-05-18

算法标签：数学、O2优化、位运算

题目描述

经过一段时间的紧张筹备，电脑小组的“RP 餐厅”终于开业了，这天，经理 LXC 接到了一个定餐大单，可把大家乐坏了！员工们齐心协力按要求准备好了套餐正准备派送时，突然碰到一个棘手的问题：筷子！

CX 小朋友找出了餐厅中所有的筷子，但遗憾的是这些筷子长短不一，而我们都知道筷子需要长度一样的才能组成一双，更麻烦的是 CX 找出来的这些筷子数量为奇数，但是巧合的是，这些筷子中只有一只筷子是落单的，其余都成双，善良的你，可以帮 CX 找出这只落单的筷子的长度吗？

输入格式

第一行是一个整数，表示筷子的数量 $n$。

第二行有 $n$ 个整数，第 $i$ 个整数表示第 $i$ 根筷子的长度 $a_i$。

输出格式

输出一行一个整数表示答案。

样例

样例输入 #1

9
2 2 1 3 3 3 2 3 1

样例输出 #1

2```

## AC 代码

```cpp
#include <cstdio>   // scanf, printf

int main() {
    // ---------- 思路 ----------
    // 所有筷子中只有一只落单（出现奇数次），其余都是成双（出现偶数次）。
    // 利用异或运算的性质：
    //   1. a ^ a = 0     （自己和自己异或得 0）
    //   2. 0 ^ a = a     （0 和任何数异或等于那个数）
    //   3. 满足交换律和结合律
    // 把所有的长度都异或起来，成对的会两两抵消变成 0，
    // 最后剩下的就是那只落单筷子的长度。
    // 空间复杂度 O(1)，不会超过 8MB 的限制。
    // -------------------------

    int n;              // n: 筷子总数
    scanf("%d", &n);

    int ans = 0;        // ans: 异或结果，初始为 0（0 ^ a = a）

    for (int i = 0; i < n; ++i) {
        int x;           // x: 当前读入的筷子长度
        scanf("%d", &x);
        ans ^= x;        // 一边读入一边异或，不需要数组存储
    }

    printf("%d\n", ans);  // ans 就是落单筷子的长度

    return 0;
}
