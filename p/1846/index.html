1846 - 阿尔法乘积

题目描述

计算一个整数的阿尔法乘积。对于一个整数 xxx 来说，它的阿尔法乘积是这样来计算的：如果 xxx 是一个个位数，那么它的阿尔法乘积就是它本身；否则的话，xxx 的阿尔法乘积就等于它的各位非 000 的数字相乘所得到的那个整数的阿尔法乘积。

例如：401822431240182243124018224312 的阿尔法乘积等于 888 ，它是按照以下的步骤来计算的：

401822431240182243124018224312 → 4×1×8×2×2×4×3×1×24 \times 1 \times 8 \times 2 \times 2 \times 4 \times 3 \times 1 \times 24×1×8×2×2×4×3×1×2 → 307230723072 → 3×7×23 \times 7 \times 23×7×2 → 424242 → 4×24 \times 24×2 → 888；

编写一个程序，输入一个正整数（该整数的值在 int 范围内），输出它的阿尔法乘积。

输入

输入只有一行，即一个正整数。

输出

输出相应的阿尔法乘积。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int main() {
 int x;
 cin>>x;
 //当这个数各个位的乘积不是⼀位数时,对它的乘积继续求解
 while(x>=10){
 int t=1;
 //计算整数⾮0位的乘积
 while(x!=0){
 //判断尾数不等于0就累乘
 if(x%10!=0){
 t = t*(x%10);
 }
 //去掉尾数
 x = x/10;
 }
 x = t;
 }
     cout<<x;
 return 0;
}
