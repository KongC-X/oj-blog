1804 - 统计直角、锐角、钝角的个数？

题目描述

输入 $n$ 个整数，代表角的度数，请编程计算出这些角中直角（$90$ 度的角）、锐角（$ \lt 90$ 度的角）、钝角（$ \gt 90$度的角）分别有多少个？

输入

第 $1$ 行有一个整数 $n$，代表有 $n$ 个角的度数。（$n \le 100$）

第 $2$ 行有 $n$ 个整数，代表角的度数（角的度数是$ \ge 1$且$ \lt 180$的整数）。

输出

输出 $3$ 个整数，用空格隔开，分别代表直角的个数、锐角的个数、钝角的个数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

/*
读入每个数，逐个判断是直角、锐角还是钝角 
*/ 
int n,a[110];
//统计直角、锐角、钝角的数量 
int c1=0,c2=0,c3=0; 

int main() {
    cin>>n;
    for(int i = 0;i < n;i++){
        cin>>a[i];
        
        //判断角的类型 
        if(a[i] == 90){
            c1++;
        }else if(a[i] < 90){
            c2++;
        }else{
            c3++;
        }
    }
    
    cout<<c1<<" "<<c2<<" "<<c3;
    return 0;
}
