1804 - 统计直角、锐角、钝角的个数？

题目描述

输入 nnn 个整数，代表角的度数，请编程计算出这些角中直角（909090 度的角）、锐角（<90\lt 90<90 度的角）、钝角（>90\gt 90>90度的角）分别有多少个？

输入

第 111 行有一个整数 nnn，代表有 nnn 个角的度数。（n≤100n \le 100n≤100）

第 222 行有 nnn 个整数，代表角的度数（角的度数是≥1\ge 1≥1且<180\lt 180<180的整数）。

输出

输出 333 个整数，用空格隔开，分别代表直角的个数、锐角的个数、钝角的个数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

/*
读入每个数，逐个判断是直角、锐角还是钝角 
*/ 
int n,a[110];
//统计直角、锐角、钝角的数量 
int c1=0,c2=0,c3=0; 

int main() {
    cin>>n;
    for(int i = 0;i < n;i++){
        cin>>a[i];
        
        //判断角的类型 
        if(a[i] == 90){
            c1++;
        }else if(a[i] < 90){
            c2++;
        }else{
            c3++;
        }
    }
    
    cout<<c1<<" "<<c2<<" "<<c3;
    return 0;
}
