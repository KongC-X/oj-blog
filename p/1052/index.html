1052 - 行李托运费

题目描述

车站行李托运费标准是： 101010 千克或 101010 千克以下，每千克收费 1.51.51.5 元，超过 101010 千克的行李，按每超过 111 千克 2.52.52.5 元进行收费。

试编一程序，输入行李的托运费，算出行李的重量。

输入

读入一个小数，表示行李的托运费。

输出

一个小数，即行李的重量，保留两位小数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    //定义变量n代表托运费 
    double n;
    //输入托运费
    cin>>n;
    //定义变量w代表行李重量 
    double w;
    //如果托运费小于等于15元,重量=n/1.5
    //否则重量大于10千克 
    if(n<=15){
        w = n/1.5;
    }else{
        w = (n-15)/2.5+10;
    } 
    //输出行李重量,保留2位小数 
    cout<<fixed<<setprecision(2)<<w;
    return 0;
}
