1611 - 求六位整数的各个位

题目描述

从键盘读入一个 666 位整数 nnn，请求出这个 666 位整数各个位分别是多少？

从高位到低位依次输出，每行一个。

输入

一个 666 位整数 nnn 。

输出

第 111 行输出 666 位数的十万位

第 222 行输出 666 位数的万位

第 333 行输出 666 位数的千位

第 444 行输出 666 位数的百位

第 555 行输出 666 位数的十位

第 666 行输出 666 位数的个位

解题思路

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
#include<iomanip>
using namespace std;

int main() {
    int n,a,b,c,d,e,f;
    cin >> n;
    a = n / 100000;
    b = (n % 100000) / 10000;
    c = (n % 10000) / 1000;
    d = (n % 1000) / 100;
    e = (n % 100) / 10;
    f = n % 10;
    cout << a << endl;
    cout << b << endl;
    cout << c << endl;
    cout << d << endl;
    cout << e << endl;
    cout << f << endl;
}
