1724 - 采摘活动

题目描述

王老师的班级组织了一次活动，去桃园摘桃子。同学们摘了很多很多桃子，王老师出了一个问题，想考考聪明的同学们，如果我们将所有桃子中最重的桃子留下（如果最重的有多个，多个最重的要全部留下），最轻的桃子也留下（如果最轻的有多个，多个最轻的也要全部留下），剩余的桃子带走，那么我们总共带走了多重的桃子，平均一个桃子多重（平均值保留 $1$ 位小数）？

比如，假设班上同学们采摘了 $8$ 个桃子，重量如下：

$9$ $9$ $8$ $5$ $6$ $5$ $9$ $8$

按照王老师的要求，留下重的桃子，也就是值为 $9$ 的桃子，最轻的桃子，也就是值为 $5$ 的桃子，因此同学们带走桃子的总重量 = $8 + 6 + 8$ = $22$ ，平均一个桃子的重量 = $22 / 3$ = $7.3$ （保留 $1$ 位小数）。

输入

输入有 $2$ 行：

第 $1$ 行有一个整数 $n$ （ $n$ 是 $6 \sim 1000$ 之间的整数），代表同学们采摘桃子的总个数；

第 $2$ 行有 $n$ 个整数（这些整数都是 $1 \sim 100$之间的整数），代表每个桃子的重量，数字之间用空格隔开。

输出

输出有 $2$ 行：

第 $1$ 行有一个整数，代表同学们按照王老师的要求，最终带走的桃子的总重量；

第 $2$ 行有一个小数（保留 $1$ 位小数），代表同学们带走的桃子，平均一个桃子有多重。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int a[1010],n,r;
int ma=INT_MIN;
int mi=INT_MAX;
int s = 0;//总和 
int main() {
    cin>>n;
    r=0;
    int i;
    for(i=0; i<n; i++) {
        cin>>a[i];
        s=s+a[i];
        if(a[i]>ma) ma=a[i];
        if(a[i]<mi) mi=a[i];
    }
    
    //去掉所有的最大最小，同时统计有几个 
    for(i=0; i<n; i++) {
        if(a[i]==ma) {
            s=s-a[i];
            r++;
        }
        if(a[i]==mi) {
            s=s-a[i];
            r++;
        }
    }
    //求平均 
    cout<<s<<endl<<fixed<<setprecision(1)<<s*1.0/(n-r);
}
