1168 - 歌唱比赛评分

题目描述

四（111） 班要举行一次歌唱比赛，以选拔更好的苗子参加校的歌唱比赛。评分办法如下：设 NNN 个评委，打 NNN 个分数（ 0≤0 \le0≤ 每个分数 ≤10\le 10≤10 ），去掉一个最高分，去掉一个最低分，剩下的评委的平均分即为该选手的最后得分。

但是选手太多了，靠人工计算每个选手的得分太慢太麻烦。你能不能帮帮他们，设计一个程序让计算机来算出选手的最后得分呢？（ 4.1.534.1.534.1.53 ）

输入

第一行为一个整数 NNN （5≤N≤105 \le N \le 105≤N≤10）；

第二行为 NNN 个整数 AiAiAi （0≤Ai≤100 \le Ai \le 100≤Ai≤10 ）。

输出

选手的最后得分（保留两位小数）。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int a[20],n;
//将最大数设置为整数的最小值
//最小数，设置为整数的最大值 
int ma=INT_MIN,mi=INT_MAX; 
double s;
int main() {
    int i;
    cin>>n;
    for(i=0; i<n; i++) {
        cin>>a[i];
        //打擂台求最大、最小 
        if(a[i] > ma) ma = a[i];
        if(a[i] < mi) mi = a[i];
        
        s = s + a[i];//求和 
    }

    cout<<fixed<<setprecision(2)<<(s - ma - mi)/(n-2);
}
