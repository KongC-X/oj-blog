1774 - 链表操作

题目描述

给定一个 NNN 个数的数组，MMM 次操作，每次操作为下列操作之一。求最后的数组。

操作 111 ：在第 XXX 个数之后插入一个数 YYY。

操作 222 ：删除第 XXX 个数。

操作 333 ：对区间 [X，Y][X，Y][X，Y] 进行排序。

操作 444：对区间 [X，Y][X，Y][X，Y] 进行翻转。

操作 555：删除区间 [X，Y][X，Y][X，Y] 中值为 ZZZ 的数。

输入

第一行两个整数 NNN，MMM（N，M≤100000N，M \le 100000N，M≤100000）含义见试题描述。

第二行 NNN 个整数，表示原来的数组。

接下来 MMM 行，每行第一个数 OPTOPTOPT ，表示操作类型。

对于操作 111 ，接下来两个数 XXX，YYY，含义见题面描述，保证 0≤X≤0 \le X \le0≤X≤ 当前数的个数，若 X=0X=0X=0，表示在数组开头插入。

对于操作 222，接下来一个数 XXX，含义见题面描述，保证1≤X≤1 \le X \le1≤X≤ 当前数的个数。

对于操作 333，接下来两个数 XXX，YYY，含义见题面描述，保证 1≤X≤Y≤1 \le X \le Y \le1≤X≤Y≤ 当前数的个数，保证操作 333 不超过 101010 个。

对于操作 444 ，接下来两个数 XXX，YYY，含义见题面描述，保证 1≤X≤Y≤1 \le X \le Y \le1≤X≤Y≤ 当前数的个数，保证操作 444 不超过 101010 个。

对于操作 555，接下来三个数 XXX，YYY，ZZZ，含义见题面描述，保证 1≤X≤Y≤1 \le X \le Y \le1≤X≤Y≤ 当前数的个数，保证操作 555 不超过 101010 个。

输出

输出若干个数，表示最后的数组。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

vector<int> v;
int n,m,op;
int x,y,z;

int main() {
    cin >> n >> m;
    for(int i = 1;i <= n;i++) {
        scanf("%d",&x);
        v.push_back(x);
    }
    while(m--) {
        scanf("%d",&op);
        if(op == 1) {
            cin >> x >> y;
            v.insert(v.begin() + x,y);
        } else if(op == 2) {
            cin >> x;
            v.erase(v.begin() + x - 1);
        }else if(op == 3) {
            cin >> x >> y;
            sort(v.begin() + x - 1,v.begin() + y);
        } else if(op == 4) {
            cin >> x >> y;
            reverse(v.begin() + x - 1,v.begin() + y);
        } else if(op == 5) {
            cin >> x >> y >> z;
            int c = 0; // 讨论数字的个数
            int i = x - 1;
            while(i <= y - 1 && c < (y - x + 1)) {
                if(v[i] == z) {
                    v.erase(v.begin() + i);
                } else {
                    i++;
                }
                c++;
            }
        }
    }
    for(int i = 0;i < v.size();i++) {
        printf("%d ",v[i]);
    }
    return 0;
}
