1493 - 放大的Z

题目描述

打印 $n$ 行放大的 $Z$ 。
比如：
$n=3$ ，打印图形如下

`***
 *
***
`

$n=4$ ，打印图形如下

`****
  *
 *
****
`

$n=5$，打印图形如下

`*****
   *
  *
 *
*****
`

输入

一个整数 $n（n \lt 10$ ）

输出

n行放大的Z。

AC代码

AC代码

#include <iostream>
using namespace std;

int main() {
    int i,j,n;
    cin>>n;
    //控制输出n行
    for(i = 1; i <= n; i++) {
        //第1行和第n行有n个星
        if(i == 1 || i == n) {
            for(j = 1; j <= n; j++) {
                cout<<"*";
            }
        } else {
            //其他行，第i行有n-i个空格，1个星
            for(j = 1; j <= n - i; j++) {
                cout<<" ";
            }
            cout<<"*";
        }

        cout<<endl;
    }
}
