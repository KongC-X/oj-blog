B4038 [GESP202409 三级] 平衡序列

洛谷 | 普及- | C++14 | 提交时间: 2024-12-03

算法标签：2024、前缀和、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1159

题目描述

小杨有一个包含 $n$ 个正整数的序列 $a$。他认为一个序列是平衡的当且仅当存在一个正整数 $i$（$1 \leq i < n$）使得序列第 $1$ 到第 $i$ 个数字的总和等于第 $i + 1$ 到第 $n$ 个数字的总和。

小杨想请你判断序列 $a$ 是否是平衡的。

输入格式

本题单个测试点内包含多组测试数据。第一行是一个正整数 $t$，表示测试用例组数。

接下来是 $t$ 组测试用例。对每组测试用例，一共两行。

第一行包含一个正整数 $n$，表示序列长度。
第二行包含 $n$ 个正整数，代表序列 $a$。

输出格式

对每组测试用例输出一行一个字符串。如果 $a$ 是平衡的，输出 $\texttt{Yes}$，否则输出 $\texttt{No}$。

样例

样例输入 #1

3
3
1 2 3
4
2 3 1 4
5
1 2 3 4 5```

**样例输出 #1**

Yes
Yes
No```

AC 代码

#include<bits/stdc++.h>
using namespace std;
int s,s1[10010],s2[10010],s3,s4;
int i,j,n,m,q,w;
int main(){
    cin>>n;
    for(i=1;i<=n;i++){
        cin>>m;
        for(j=0;j<m;j++){
            cin>>s1[j];
            s+=s1[j];
        }
        for(j=0;j<m;j++){
            q+=s1[j];
            if(q*2==s){
                w=1;
                break;
            }
        }
        if(w){
            cout<<"Yes"<<endl;
        }else{
            cout<<"No"<<endl;
        }w=0;
        s=0;
        q=0;
    }
}
