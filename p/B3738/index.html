B3738 [信息与未来 2018] 素数方阵

洛谷 | 普及- | C++14 | 提交时间: 2026-04-13

算法标签：模拟、2018、江苏、素数判断、信息与未来

题目描述

把前 n2n^2n2 个素数从左上角开始按右、下、左、上、右、下、左、上……的顺序填入 n×nn×nn×n 的方阵就得到了蛇形素数方阵。以下是 n=4n = 4n=4 和 n=5n = 5n=5 的蛇形素数方阵：

给出 nnn，你的任务是求出 n×nn × nn×n 的蛇形素数方阵，并输出其中某个方格中的数值。

素数，又称质数，是指除 111 和其自身之外，没有其他约数的大于 111 的正整数。

输入格式

输入一行三个正整数 n,x,yn,x,yn,x,y。

输出格式

输出一行一个整数，表示 n×nn×nn×n 蛇形素数方阵第 xxx 行第 yyy 列中的数字。

样例

样例输入 #1

5 1 4```

**样例输出 #1**

7```

样例输入 #2

5 4 3```

**样例输出 #2**

79```

AC 代码

#include <iostream>
using namespace std;

// 判断素数
bool isPrime(int num) {
    if (num < 2) return false;
    for (int i = 2; i * i <= num; i++) {
        if (num % i == 0) return false;
    }
    return true;
}

int main() {
    int n, x, y;
    cin >> n >> x >> y;

    // 1. 生成前 n*n 个素数
    int primes[405];        // 最多 400 个，开大一点
    int cnt = 0;            // 已经找到的素数个数
    int num = 2;            // 从2开始判断
    while (cnt < n * n) {
        if (isPrime(num)) {
            primes[cnt] = num;
            cnt++;
        }
        num++;
    }

    // 2. 螺旋填充矩阵
    int a[25][25] = {0};    // 矩阵初始化为0，0表示未填
    int idx = 0;            // 当前使用的素数索引

    // 方向顺序：右(0,1)、下(1,0)、左(0,-1)、上(-1,0)
    int dx[4] = {0, 1, 0, -1};
    int dy[4] = {1, 0, -1, 0};
    int dir = 0;            // 当前方向

    int r = 1, c = 1;       // 当前行、列（从1开始）
    for (int k = 0; k < n * n; k++) {
        a[r][c] = primes[idx++];   // 填入素数
        // 计算下一个位置
        int nr = r + dx[dir];
        int nc = c + dy[dir];
        // 如果下一个位置出界或已经填过，就转弯
        if (nr < 1 || nr > n || nc < 1 || nc > n || a[nr][nc] != 0) {
            dir = (dir + 1) % 4;    // 换下一个方向
            nr = r + dx[dir];
            nc = c + dy[dir];
        }
        r = nr;
        c = nc;
    }

    // 3. 输出指定位置的数
    cout << a[x][y] << endl;

    return 0;
}
