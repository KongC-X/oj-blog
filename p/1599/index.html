1599 - 米老鼠偷糖果

题目描述

米老鼠发现了厨房放了 $n$ 颗糖果，它一次可以背走 $a$ 颗，请问米老鼠背了 $x$ 次之后还剩多少颗？（假设 $x$ 次之后一定有糖果剩下）。

输入

三个整数 $n、a、x$ 分别代表总共有 $n$ 颗糖果，米老鼠一次背走 $a$ 颗糖果，总共背了 $x$ 次。

输出

一个整数，代表剩余的糖果数量。

解题思路

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n,a,x;
    cin >> n >> a >> x;
    cout << n - (a * x) << endl;
}
