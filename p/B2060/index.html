B2060 满足条件的数累加

洛谷 | 入门 | C++14 | 提交时间: 2026-07-01

题目描述

将正整数 mmm 和 nnn 之间（包括 mmm 和 n)n)n) 能被 171717 整除的数累加，其中，0<m<n<10000<m<n<10000<m<n<1000。

输入格式

一行，包含两个整数 mmm 和 nnn，其间，以一个空格间隔。

输出格式

输出一行，包行一个整数，表示累加的结果。

样例

样例输入 #1

50 85```

**样例输出 #1**

204```

AC 代码

#include<bits/stdc++.h>
using namespace std;
int m,n,sum=0;
int main(){
    cin>>m>>n;
    for(int i=m;i<=n;i++){
        if(i%17==0) sum+=i;
    }
    cout<<sum<<endl;
}
