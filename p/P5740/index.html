P5740 【深基7.例9】最厉害的学生

洛谷 | 普及- | C++14 | 提交时间: 2025-08-07

题目描述

现有 NNN 名同学参加了期末考试，并且获得了每名同学的信息：姓名（不超过 888 个字符的仅有英文小写字母的字符串）、语文、数学、英语成绩（均为不超过 150150150 的自然数）。总分最高的学生就是最厉害的，请输出最厉害的学生各项信息（姓名、各科成绩）。如果有多个总分相同的学生，输出靠前的那位。

输入格式

第一行输入一个正整数 NNN，表示学生个数。

第二行开始，往下 NNN 行，对于每一行首先先输入一个字符串表示学生姓名，再输入三个自然数表示语文、数学、英语的成绩。均用空格相隔。

样例

样例输入 #1

3
senpai 114 51 4
lxl 114 10 23
fafa 51 42 60```

**样例输出 #1**

senpai 114 51 4```

AC 代码

#include<iostream>
using namespace std;
const int N=1005;
int n;
struct node
{
    string name;
    int x,y,z,sum;
}a[N];
int main()
{
    ios::sync_with_stdio(false);
    cin.tie(0);cout.tie(0);
    cin>>n;
    for(int i=1;i<=n;i++)
    {
        cin>>a[i].name>>a[i].x>>a[i].y>>a[i].z;
        a[i].sum=a[i].x+a[i].y+a[i].z;
    }
    for(int i=1;i<=n;i++)
        for(int j=i+1;j<=n;j++)
            if(a[i].sum<a[j].sum)
                swap(a[i],a[j]);
    cout<<a[1].name<<' '<<a[1].x<<' '<<a[1].y<<' '<<a[1].z<<endl;
    return 0;
}
