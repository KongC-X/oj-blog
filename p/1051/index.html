1051 - 填数

题目描述

由于小星同学上课不专心，今天老师布置了几道数学题目他不会解答了。怎么办呢？这下他可发愁了！请热心的你来帮帮他。

题目是给你一组有规律序列的前面 333 个整数，请你给出它后面跟着的 333 个整数，如：1,2,4,___,___,___。这个是等比数列，后面应该是 8,16,328,16,328,16,32 。（等比数列可以简单理解为相邻两项的比值（商））

如果是1,2,3,___,___,___。这是个等差数列，后面应该是4,5,64,5,64,5,6 。（等差数列可以简单理解为相邻两项的差值一定）

现在小星已经知道这串序列要么是等比数列，要么是等差数列。

输入

一行： 333 个整数 a1，a2，a3a1，a2，a3a1，a2，a3 。（ 0≤a1≤a2≤a3≤1000 \le a1 \le a2 \le a3 \le 1000≤a1≤a2≤a3≤100 ）

输出

一行： 333 个整数，之间用一个空格隔开。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    int a1,a2,a3;
    cin>>a1>>a2>>a3;
    //如果a-b等于b-c就是等差数列,否则是等比数列 
    if(a1-a2==a2-a3){
        int m = a1-a2;
        cout<<a3-m<<" "<<a3-2*m<<" "<<a3-3*m;
    }else{
        int n = a2/a1;
        cout<<n*a3<<" "<<n*n*a3<<" "<<n*n*n*a3;
    } 
    return 0;
}
