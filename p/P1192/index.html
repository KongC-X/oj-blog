P1192 台阶问题

洛谷 | 普及- | C++14 | 提交时间: 2025-05-07

算法标签：递推、Fibonacci 数列、线性递推

题目描述

有 NNN 级台阶，你一开始在底部，每次可以向上迈 1∼K1\sim K1∼K 级台阶，问到达第 NNN 级台阶有多少种不同方式。

输入格式

两个正整数 N,KN,KN,K。

输出格式

一个正整数 ans(mod100003)ans\pmod{100003}ans(mod100003)，为到达第 NNN 级台阶的不同方式数。

样例

样例输入 #1

5 2```

**样例输出 #1**

8```

AC 代码

#include<bits/stdc++.h>
using namespace std;
int f[100005],n,k;
int main()
{
    cin>>n>>k;
    f[0]=1;
    for(int i=1;i<=n;i++)
    {
        for(int j=1;j<=min(i,k);j++)
            f[i]=(f[i]+f[i-j])%100003;
    }
    cout<<f[n];
    return 0;
}
