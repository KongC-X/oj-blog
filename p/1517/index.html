1517 - 将n拆成2个数的乘积

题目描述

将 $n$ 拆成 $a \times b$ 的形式，比如：$10=2 \times 5$ ，请注意，此处 $10=5 \times 2$ 和 $10=2 \times 5$，认为是同一个方案。

输入

一行，一个整数 $n$ 。（ $n \le 1000$）

输出

若干行算式，每行 $1$ 个。

解题思路

AC代码

AC代码

#include<iostream>
#include<cmath>
using namespace std;
int main()
{
    int n;
    cin >> n;
    //因子成对出现，遍历范围1到n的平方根
    for(int i = 1; i <= sqrt(n); i++){
        //判断n能否被i整除，能整除则i就是因子
        if(n%i == 0){
            cout << n << "=" << i << "*" << n/i << endl;
        } 
         
    } 
    return 0;
}
