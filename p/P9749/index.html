P9749 [CSP-J 2023] 公路

洛谷 | 普及- | C++14 | 提交时间: 2025-10-16

算法标签：模拟、贪心、2023、O2优化、前缀和、CSP-J 入门级

题目描述

小苞准备开着车沿着公路自驾。

公路上一共有 nnn 个站点，编号为从 111 到 nnn。其中站点 iii 与站点 i+1i + 1i+1 的距离为 viv_ivi​ 公里。

公路上每个站点都可以加油，编号为 iii 的站点一升油的价格为 aia_iai​ 元，且每个站点只出售整数升的油。

小苞想从站点 111 开车到站点 nnn，一开始小苞在站点 111 且车的油箱是空的。已知车的油箱足够大，可以装下任意多的油，且每升油可以让车前进 ddd 公里。问小苞从站点 111 开到站点 nnn，至少要花多少钱加油？

输入格式

输入的第一行包含两个正整数 nnn 和 ddd，分别表示公路上站点的数量和车每升油可以前进的距离。

输入的第二行包含 n−1n - 1n−1 个正整数 v1,v2…vn−1v_1, v_2\dots v_{n-1}v1​,v2​…vn−1​，分别表示站点间的距离。

输入的第三行包含 nnn 个正整数 a1,a2…ana_1, a_2 \dots a_na1​,a2​…an​，分别表示在不同站点加油的价格。

输出格式

输出一行，仅包含一个正整数，表示从站点 111 开到站点 nnn，小苞至少要花多少钱加油。

样例

样例输入 #1

5 4
10 10 10 10
9 8 9 6 5```

**样例输出 #1**

79```

AC 代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 贪心策略：如果我们在某个站点加油，应该尽量利用这个油价来覆盖后面所有油价更贵的路段，直到遇到更便宜的油价站点。

const int N = 100010;
long long n, d, a[N], v[N], sum[N], k, ans, t; // t表示当前油箱剩余的油量

int main() {
    // 输入处理
    cin >> n >> d;
    for (int i = 1; i < n; i++) cin >> v[i];  // 站点间的距离
    for (int i = 1; i <= n; i++) cin >> a[i]; // 各站点的油价
    
    /**
     * 核心思路：贪心策略
     * 1. 将整个路程划分为若干"油价区间"
     * 2. 每个区间内使用该区间的最低油价来加油
     * 3. 在区间起点加足够跑完整个区间的油
     */
    
    long long min_price = a[1];  // 当前区间的最低油价
    k = 1;  // 当前最低油价对应的站点编号
    
    // 第一步：路段分组
    // 将连续的路段按照"当前能使用的最低油价"进行分组
    for (int i = 1; i < n; i++) {
        if (a[i] >= min_price) {
            // 当前站点油价不低于区间最低价，将该路段归入当前区间
            sum[k] += v[i];  // 在k站点代表的区间累加距离
        } else {
            // 发现更低的油价，开始新的区间
            k = i;           // 更新最低油价站点
            min_price = a[i]; // 更新最低油价
            sum[i] += v[i];  // 新区间从当前路段开始
        }
    }
    
    // 输出检查
    // for (int i = 1; i <= n; i++) {
    //     cout << sum[i] << " ";
    // }

    /**
     * 分组完成后：
     * sum[i] 表示需要在站点i加油来覆盖的总路程
     * 如果sum[i] = 0，说明不需要在站点i加油
     */
    
    // 第二步：计算加油方案
    for (int i = 1; i <= n; i++) {
        if (sum[i] == 0) continue;  // 跳过不需要加油的站点
        
        // 当前区间需要跑的总距离
        long long need_km = sum[i];
        
        // 如果剩余油量不够跑完当前区间，需要加油
        if (t < need_km) {
            long long extra_km = need_km - t;  // 需要额外跑的公里数
            long long liters = (extra_km + d - 1) / d; // 向上取整计算需要买的油量，也可以用ceil函数
            // long long liters = ceil(extra_km * 1.0 / d);  // 向上取整计算需要买的油量
            
            ans += liters * a[i];  // 累计花费
            t += liters * d - need_km;  // 更新剩余油量
        } else {
            // 剩余油量足够跑完当前区间，直接消耗油量
            t -= need_km;
        }
    }
    
    cout << ans << endl;
    return 0;
}
