1530 - 小X与机器人

题目描述

小X的老师很喜欢围棋。众所周知，围棋的棋盘有 191919 行 191919 列，共有 361361361 个交叉点。

为方便起见，我们把这些行列按顺序编号为 1∼191 \sim 191∼19 ，并用 (x,y)(x, y)(x,y) 表示第 xxx 列第 yyy 行的位置。例如下图中，AAA 用 (16,4)(16,4)(16,4) 表示，BBB 用 (14,3)(14, 3)(14,3) 表示。

小X在做一个机器人的项目，他正思考这样一个问题：如果一个小机器人从 (x1,y1)(x_1, y_1)(x1​,y1​) 这个位置出发，沿直线移动到 (x2,y2)(x_2, y_2)(x2​,y2​) 这个位置，它一共经过了多少个交叉点？

注意起点和终点也算作经过，因此至少经过了 222 个交叉点。

输入

输入数据仅有一行包含 444 个用空格隔开的正整数，分别表示 x1,y1,x2,y2x_1, y_1, x_2, y_2x1​,y1​,x2​,y2​。

输出

输出一行包含一个小于 202020 的正整数，表示从 (x1,y1)(x_1, y_1)(x1​,y1​) 沿直线移动到 (x2,y2)(x_2, y_2)(x2​,y2​) 经过的交叉点的个数。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    int x1,y1,x2,y2;
    cin >> x1 >> y1 >> x2 >> y2;
    cout << __gcd(abs(x1 - x2),abs(y1 - y2)) + 1 << endl;
}
