1506 - 订单结算

题目描述

某购物网站进行优惠活动，每个商品当天第一个订单可以打 757575 折（ 757575 折的意思是用原价 ×0.75\times 0.75×0.75 ）。

这天网站先后依次收到了 NNN 个订单，订单的数据形式是：商品名 价格（单价 ×\times× 数量），商品名是长度不超过 202020 的字符串（商品名不含空格）。

请按商品名的字典顺序，输出当天每种商品名和其售出的总价。

输入

第一行是一个整数 NNN（N＜100000N＜100000N＜100000），代表了订单的数量；

接下来有 NNN 行，每行第一个数据是商品名的拼音（没有空格），第二行是商品价格（最多包含 111 位小数）。

输出

若干行，按照商品名的字典顺序，输出当天每种商品名和其售出的总价（总价保留 111 位小数）

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
map<string,double> m;
int main(){
    int n,i;
    string name;
    double val;
    
    //读入
    cin>>n;
    for(i = 0;i < n;i++){
        cin>>name>>val;
        //如果名字没出现过，也就是第一次出现 
        if(m.count(name) == 0){
            m[name] = val * 0.75;
        }else{
            m[name] = m[name] + val;
        }
    }
    
    //遍历
    for(map<string,double>::iterator j = m.begin();j != m.end();j++){
        cout<<j->first<<" "<<fixed<<setprecision(1)<<j->second<<endl;
    } 
    
}
