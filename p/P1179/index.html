P1179 [NOIP 2010 普及组] 数字统计

洛谷 | 入门 | C++14 | 提交时间: 2025-06-11

算法标签：模拟、2010、NOIP 普及组

题目描述

请统计某个给定范围 $[L, R]$ 的所有整数中，数字 $2$ 出现的次数。

比如给定范围 $[2, 22]$，数字 $2$ 在数 $2$ 中出现了 $1$ 次，在数 $12$ 中出现 $1$ 次，在数 $20$ 中出现 $1$ 次，在数 $21$ 中出现 $1$ 次，在数 $22$ 中出现 $2$ 次，所以数字 $2$ 在该范围内一共出现了 $6$ 次。

输入格式

$2$ 个正整数 $L$ 和 $R$，之间用一个空格隔开。

输出格式

数字 $2$ 出现的次数。

样例

样例输入 #1

2 22

样例输出 #1

6

样例输入 #2

2 100```

**样例输出 #2**

20```

AC 代码

#include<bits/stdc++.h>    //万能头文件
using namespace std;

int L,R,x,ans;           
int main()
{
scanf("%d%d",&L,&R);//输入
for(int i=L;i<=R;i++)	//从L到R这个范围中找数字2
{
    x=i;		//用x来装i的值
    while(x>0)	//只要x大于0就运行下面的程序
    {
        if(x%10==2)ans++;	//如果i某一位的数字是2，ans++
        x/=10;	//准备好下一位数字的判断
    }
}
printf("%d",ans);//输出

    return 0;           
}
