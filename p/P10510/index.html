题目描述

小洛正在学习三进制。他定义三进制数为每一位只包括 0,1,20,1,20,1,2 三种数的无穷长的数字串 aaa。

与一般的三进制数不同的是，小洛的三进制数从左往右书写。例如，在常规表述下，444 的三进制表示为 (0000 0011)3(0000\ 0011)_3(0000 0011)3​，而在小洛的三进制数表示下为 (1100 0000⋯ )3(1100\ 0000 \cdots)_3(1100 0000⋯)3​。

小洛特别喜欢从 000 开始计数，因此他规定三进制的第 000 位为最左侧的那一数位。

下表给出了小洛的三进制数表示下，数字 373737 的最低的 888 位数位以及位权：

三进制数表示 111 000 111 111 000 000 000 000
位数 000 111 222 333 444 555 666 777
位权 303^030 313^131 323^232 333^333 343^434 353^535 363^636 373^737

现在小洛有一个十进制正整数 VVV（显然，需要将其转化为小洛的三进制数表示），并且给定三种操作：

  • 操作一，将第 iii 位上的数进行操作：000 变为 111，111 变为 222，222 变为 000。
  • 操作二，将第 iii 位上的数进行操作：000 变为 222，111 变为 000，222 变为 111。
  • 操作三，将第 iii 位上的数进行操作：111 变为 222，222 变为 111，000 不变。

小洛一共要进行 qqq 次操作。每次操作后，小洛需要得到三进制串代表的数值。请你告诉他。

如果对题意有不清晰之处，请查看样例解释。

输入格式

第一行输入两个正整数 V,qV,qV,q。

接下来 qqq 行，每行一个操作，形如 op i。

请注意，你需要将 VVV 转化为三进制串并作为初始的三进制串。

输出格式

输出共 qqq 行，第 iii 行表示第 iii 个操作后的答案。

样例

样例输入 #1

4 3
1 1
2 0
1 2```

**样例输出 #1**

7
6
15


## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    /*
     * 题目：P10510 进制
     * 题意：给定十进制数 V，将其转换为“小洛的三进制数”表示（低位在左，高位在右，第0位是最低位）。
     *       然后进行 q 次操作，每次操作修改某一位的数字，并输出修改后三进制数对应的十进制值。
     *
     * 操作定义：
     *   操作一：0->1, 1->2, 2->0 （即数字加1模3）
     *   操作二：0->2, 1->0, 2->1 （即数字加2模3）
     *   操作三：1->2, 2->1, 0不变 （即非0数字变为 3 - 原数字）
     *
     * 思路：
     *   1. 将 V 转换为三进制，低位在前存入数组 d，d[0] 是小洛的第0位。
     *      同时维护当前十进制值 cur = V。
     *   2. 每次操作：
     *        - 记录旧数字 old = d[i]。
     *        - 根据操作类型计算新数字 nw。
     *        - 更新 d[i] = nw。
     *        - 现场计算 3^i（用循环累乘）。
     *        - cur += (nw - old) * 3^i。
     *        - 输出 cur。
     *
     * 时间复杂度：O(q * 位数)，q ≤ 10^5，位数 ≤ 40，总运算约 4e6，非常快。
     * 空间复杂度：O(位数)。
     */

    long long V;          // V: 初始十进制数
    int q;                // q: 操作次数
    cin >> V >> q;

    int d[100] = {0};     // d[i]: 三进制第 i 位的数字（低位在前）
    long long cur = V;    // cur: 当前十进制值

    // 将 V 转为三进制，低位在前
    long long temp = V;
    int pos = 0;
    while (temp > 0) {
        d[pos++] = temp % 3;
        temp /= 3;
    }

    // 处理每次操作
    while (q--) {
        int op, i;
        cin >> op >> i;

        int old = d[i];    // 旧数字
        int nw;            // 新数字

        if (op == 1) {
            nw = (old + 1) % 3;           // 0->1, 1->2, 2->0
        } else if (op == 2) {
            nw = (old + 2) % 3;           // 0->2, 1->0, 2->1
        } else { // op == 3
            if (old == 0) nw = 0;         // 0 不变
            else nw = 3 - old;            // 1->2, 2->1
        }

        d[i] = nw;

        // 现场计算 3^i
        long long p = 1;
        for (int j = 0; j < i; j++) {
            p *= 3;
        }

        cur += (long long)(nw - old) * p;   // 更新当前值
        cout << cur << endl;                 // 输出答案
    }

    return 0;
}
