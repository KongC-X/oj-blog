3484 - 田忌赛马（race）

题目描述

你要和田忌赛马。你们各自有 NNN 匹马，并且要进行 NNN 轮比赛，每轮比赛，你们都要各派出一匹马决出胜负。

你的马匹的速度分别为 u1,u2,...,uNu_1,u_2,...,u_Nu1​,u2​,...,uN​，田忌的马匹的速度分别为 v1,v2,...,vNv_1,v_2,...,v_Nv1​,v2​,...,vN​。田忌会按顺序派出他的马匹，请问你要如何排兵布阵，才能赢得最多轮次的比赛？巧合的是，你和田忌的所有马匹的速度两两不同，因此不可能出现平局。

输入

第一行一个整数 NNN。保证 1≤N≤5×1041 \leq N \leq 5 \times 10^41≤N≤5×104。

接下来一行 NNN 个用空格隔开的整数，依次为 u1,u2,...,uNu_1,u_2,...,u_Nu1​,u2​,...,uN​，表示你的马匹们的速度。保证 1≤ui≤2N1 \leq u_i \leq 2N1≤ui​≤2N。

接下来一行 NNN 个用空格隔开的整数，依次为 v1,v2,...,vNv_1,v_2,...,v_Nv1​,v2​,...,vN​，表示田忌的马匹们的速度。保证 1≤vi≤2N1 \leq v_i \leq 2N1≤vi​≤2N。

输出

输出一行，表示你最多能获胜几轮。

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
using namespace std;

int n,a[50010],b[50010],ans;
int main(){
    cin >> n;
    // 输入
    for(int i = 1;i <= n;i++) cin >> a[i];
    for(int i = 1;i <= n;i++) cin >> b[i];
    // 从小到大排序
    sort(a+1,a+1+n);
    sort(b+1,b+1+n);
    // 双指针
    int j = 1;
    for(int i = 1;i <= n;i++){
        if(a[i] >= b[j]){
            j++; 
            ans++;
        }
    }
    cout << ans << endl;
}
