1446 - 人口增长问题

题目描述

我国现有 xxx 亿人口，按照每年 0.1%0.1 \%0.1% 的增长速度，nnn 年后将有多少人？

输入

一行，包含两个整数 xxx 和 nnn ，分别是人口基数和年数，以单个空格分隔。

输出

输出最后的人口数，以亿为单位，保留到小数点后四位。(1≤x≤100,1≤n≤100)(1 \le x \le 100, 1 \le n \le 100)(1≤x≤100,1≤n≤100) 。

解题思路

AC代码

AC代码

#include <iostream>
#include <iomanip>
using namespace std;
 
int main(){
    int n;
    double x;
    cin>>x>>n;
    //循环n次 
    for(int i = 1;i <= n;i++){
        x = x * 1.001;
    }
    cout<<fixed<<setprecision(4)<<x<<endl;
}
