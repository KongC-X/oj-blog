2196 - 最优二叉树

题目描述

现在有 NNN 个正整数，每一次去掉其中 222 个数 aaa 和 bbb ，然后加入一个数 a×b+1a \times b+1a×b+1，这样最后只剩下一个数 ppp 。

要求求出最大的 ppp 记为 maxpmaxpmaxp ，最小的 ppp 记为 minpminpminp ，和他们的差 K=maxp−minpK=maxp-minpK=maxp−minp 。

对于给定的数列，编程计算出它的 maxmaxmax , minminmin 和 KKK 。

输入

第一行是数列的长度 nnn（），第二行共 nnn 个正整数（值）。

输出

输出一共三行，每行一个整数，依次为 maxmaxmax,minminmin,KKK。

注意：本题的计算结果可能会超过231−12^{31}-1231−1，但不超过263−12^{63}-1263−1。

AC代码

#include <bits/stdc++.h>
using namespace std;

typedef long long LL;

// 哈夫曼树的构建 
// 大根堆每次取出当前最大的两个数进行合并，而不是为了让最终结果最大。恰恰相反，这个策略会让最终结果最小。
// a * b + 1里的 +1 就像一个“放大项”：它后面被谁乘，就会被放大多少。
// 想让结果最大 → 让 +1 被大数乘 → 先合并小数，把大数留到最后乘
// 想让结果最小 → 让 +1 被小数乘 → 先合并大数，把小数留到最后乘
priority_queue<LL> q1; //大根堆
priority_queue<LL,vector<LL>,greater<LL> > q2; //小根堆 

LL n,x,minp,maxp; 
int main() {
    cin>>n;
    for(int i = 1;i <= n;i++){
        cin>>x;
        q1.push(x);
        q2.push(x); 
    }
    
    LL a,b;
    while(q1.size()!=1){
        a = q1.top();
        q1.pop();
        b = q1.top();
        q1.pop();
        q1.push(a*b+1); 
    }

    // 最小值
    minp = q1.top();
    
    while(q2.size()!=1){
        a = q2.top();
        q2.pop();
        b = q2.top();
        q2.pop();
        q2.push(a*b+1); 
    }
    
    //最大值
    maxp = q2.top();
    
    cout<<maxp<<endl;
    cout<<minp<<endl;
    cout<<maxp-minp<<endl;
    return 0;
}
