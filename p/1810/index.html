1810 - 最贵商品和最便宜商品分别有几个

题目描述

小明去超市买商品，买了 $N$ 件，每件商品的价格都是整数（价格不会全都一样），小明想知道这 $N$ 件商品中，最贵商品和最便宜商品分别有几个（最贵和最便宜分别可以有多个）？请你编写程序帮忙小明计算。

输入

第 $1$ 行有一个整数 $n$（$n \le 1000$）。

第 $2$ 行有 $n$ 个整数，用空格隔开。

输出

输出 $2$ 个整数，用空格隔开，第 $1$ 个整数代表最贵的商品有几个，第 $2$ 个整数代表最便宜的商品有几个。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int main()
{
    int n,a[2000],sum1=0,sum2=0,max=INT_MIN,min=INT_MAX;
    cin>>n;
    for(int i=0;i<n;i++)
    {
        cin>>a[i];
        if(a[i]>max) max=a[i];
        if(a[i]<min) min=a[i];
    }
    for(int i=0;i<n;i++)
    {
        if(a[i]==max) sum1++;
        if(a[i]==min) sum2++;
    }
    cout<<sum1<<" "<<sum2; 
    return 0;
}
