B2097 最长平台

洛谷 | 入门 | C++14 | 提交时间: 2026-07-08

题目描述

对于一个数组，其连续的相同段叫做一个平台，例如，在 111，222，222，333，333，333，444，555，555，666 中 111，2−22-22−2，3−3−33-3-33−3−3，444，5−55-55−5，666 都是平台。

编写一个程序，接收一个数组，找出最长的平台。在上面的例子中 3−3−33-3-33−3−3 就是最长的平台。

输入格式

第一行有一个整数 nnn，为数组元素的个数。（1≤n≤1001 \le n \le 1001≤n≤100）

第二行有 nnn 个整数，整数之间以一个空格分开，整数 kkk 范围（0<k<20000<k<20000<k<2000）。

样例

样例输入 #1

10
1 2 2 3 3 3 4 5 5 6```

**样例输出 #1**

3```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 平台就是连续相同的一段数字。我们需要找到最长平台的长度。
    // 做法：
    // 1. 读入 n 和数组 a。
    // 2. 设置 cur 表示当前平台的长度，ans 表示已发现的最长平台长度，初始值都是 1。
    // 3. 从第二个数开始遍历：如果当前数与上一个数相等，则 cur++；否则，当前平台结束，
    //    用 cur 更新 ans，然后将 cur 重置为 1。
    // 4. 最后再用 cur 更新一次 ans，防止数组结束时还是连续平台导致漏记。
    // 5. 输出 ans。
    
    int n;                           // n: 数组元素个数
    cin >> n;
    
    int a[110];                      // 存储数组元素，多开10个
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    
    int ans = 1;                     // ans: 最长平台长度，至少为1
    int cur = 1;                     // cur: 当前连续相同段的长度
    
    for (int i = 1; i < n; i++) {
        if (a[i] == a[i - 1]) {
            cur++;                   // 与上一个数相同，平台延长
        } else {
            if (cur > ans) ans = cur; // 平台结束，更新最长长度
            cur = 1;                  // 开始新的平台
        }
    }
    if (cur > ans) ans = cur;        // 处理末尾的平台
    
    cout << ans << endl;
    return 0;
}
