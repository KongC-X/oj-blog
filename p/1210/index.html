1210 - 马鞍数

题目描述

求一个 n×mn \times mn×m 数阵中的马鞍数，输出它的位置。所谓马鞍数，是指在行上最小而在列上最大的数。

如下： n=5n=5n=5 m=5m=5m=5

`5 6 7 8 9
4 5 6 7 8
3 4 5 2 1
2 3 4 9 0
1 2 5 4 8
`

则 111 行 111 列上的数就是马鞍数。

输入

共 n+1n+1n+1 行，第一行： nnn mmm (n,m<10n,m \lt 10n,m<10)；

第 222 到 n+1n+1n+1 行：每行 mmm 个整数；

输出

输出若干行：如果存在马鞍数，则输出所有马鞍数，每行一个，为行和列以及马鞍数，马鞍数按照读入的顺序输出，也就是说，如果有多组马鞍数，先读入的先输出。

如果不存在马鞍数，则输出not exist。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

/*
由于本题的数据量不大，我们可以依次判断每个点是否是本行最小，且是本列最大 
*/
int n,m,mi,ma;
int a[20][20];
bool f;

int main() {
    cin>>n>>m;
    for(int i = 1;i <= n;i++){
        for(int j = 1;j <= m;j++){
            cin>>a[i][j];
        }
    }
    
    //求每行的最小数
    for(int i = 1;i <= n;i++){
        mi = INT_MAX;
        for(int j = 1;j <= m;j++){
            if(a[i][j] < mi) mi = a[i][j];
        }
        
        //逐个判断是否是本行最小
        for(int j = 1;j <= m;j++){
            if(a[i][j] == mi){
                //如果a[i][j]是第j列的最大数
                ma = INT_MIN;
                for(int k = 1;k <= n;k++){
                    if(a[k][j] > ma) ma = a[k][j];
                } 
                
                if(a[i][j] == ma){
                    cout<<i<<" "<<j<<" "<<a[i][j]<<endl;
                    f = true;
                }
            }
        } 
    } 
    
    if(f == false) cout<<"not exist";
    return 0;
}
