P17010 [GESP202606 五级] 排排坐

洛谷 | 普及- | C++14 | 提交时间: 2026-06-30

算法标签：数学、贪心、排序、前缀和、2026、GESP

题目描述

老师正在和小朋友们分糖果。

小朋友们先在自己的手上写一个数字，然后坐成一排。

老师分发糖果的规则是：每个小朋友获得自己以及左侧所有小朋友的手上数字之和个糖果。

现在小朋友们都已经在自己手上写上了数字。

请帮小朋友们安排合适的座位顺序，使得小朋友们分到的糖果总量最大，输出这个最大值。

输入格式

输入 $2$ 行，

第一行为一个正整数 $n$，表示小朋友的个数；

第二行为 $n$ 个正整数 $a_1, a_2, \cdots, a_n$，表示小朋友们手上的数字，整数之间以空格分隔。

输出格式

输出一个整数，表示小朋友们可能分到的最大糖果总数量。

样例

样例输入 #1

5
7 5 8 9 3```

**样例输出 #1**

111```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;                         // n: 小朋友人数
    cin >> n;
    
    int a[1005];                   // a[i]: 第 i 个小朋友手上的数字
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    
    // 降序排序：数字大的坐左边，乘的系数大
    sort(a, a + n, greater<int>());
    
    long long ans = 0;             // 糖果总量，可能较大，用 long long
    for (int i = 0; i < n; i++) {
        ans += (long long)(n - i) * a[i];   // 第 i 个（从0开始）系数为 n-i
    }
    
    cout << ans << endl;
    return 0;
}
