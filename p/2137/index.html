2137 - 质因子2

题目描述

任意输入一正整数 $N$，求出它的所有质因子。

如：$10＝2\times5$，$20＝2\times2 \times 5$。

输入

输入只有一行，包括 $1$ 个整数 $n$ ($1 \lt n \le 10^9$)。

输出

输出若干行，按从小到大的顺序给出这个数的所有质因子，每行一个。

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n,i = 2;
    cin >> n;
    for(i = 2;i <= sqrt(n);i++) {
        while(n % i == 0) {
            cout << i << endl;
            n /= i;
        }
    }
    if(n != 1) {
        cout << n << endl;
    }
}
