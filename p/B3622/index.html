B3622 枚举子集（递归实现指数型枚举）

洛谷 | 普及- | C++14 | 提交时间: 2026-10-09

算法标签：深度优先搜索 DFS

题目描述

今有 $n$ 位同学，可以从中选出任意名同学参加合唱。

请输出所有可能的选择方案。

输入格式

仅一行，一个正整数 $n$。

输出格式

若干行，每行表示一个选择方案。

每一种选择方案用一个字符串表示，其中第 $i$ 位为 Y 则表示第 $i$ 名同学参加合唱；为 N 则表示不参加。

需要以字典序输出答案。

样例

样例输入 #1

3```

**样例输出 #1**

NNN
NNY
NYN
NYY
YNN
YNY
YYN
YYY```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int n;              // n: 同学数量
char s[15];         // s: 存储当前选择方案，s[i] 为 'Y' 或 'N'

/*
 * 深度优先搜索，按字典序生成所有选择方案。
 * pos 表示当前正在决定第 pos 位同学（从 0 开始）。
 * 当 pos == n 时，说明一个完整方案已经确定，输出它。
 * 否则，先尝试 'N'（不参加），再尝试 'Y'（参加）。
 * 因为 'N' < 'Y'，所以这样自然满足字典序。
 */
void dfs(int pos) {
    if (pos == n) {
        // 输出当前方案
        for (int i = 0; i < n; i++) {
            cout << s[i];
        }
        cout << endl;
        return;
    }
    // 先尝试不参加
    s[pos] = 'N';
    dfs(pos + 1);
    // 再尝试参加
    s[pos] = 'Y';
    dfs(pos + 1);
}

int main() {
    cin >> n;
    dfs(0);   // 从第 0 位开始决定
    return 0;
}
