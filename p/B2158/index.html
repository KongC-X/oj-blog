B2158 谁考了第 k 名

洛谷 | 入门 | C++14 | 提交时间: 2026-06-28

算法标签：排序、结构体

题目描述

在一次考试中，每个学生的成绩都不相同，现知道了每个学生的学号和成绩，求考第 kkk 名学生的学号和成绩。

输入格式

第一行有两个整数，分别是学生的人数 n(1≤n≤100)n(1\le n\le100)n(1≤n≤100) 和需要求的学生的名次 k(1≤k≤n)k(1\le k\le n)k(1≤k≤n)。

其后有 nnn 行数据，每行包括一个学号（整数）和一个成绩（浮点数），中间用一个空格分隔。

输出格式

输出第 kkk 名学生的学号和成绩，中间用空格分隔。（注：请用 %g 输出成绩）

样例

样例输入 #1

5 3
90788001 67.8
90788002 90.3
90788003 61
90788004 68.4
90788005 73.9```

**样例输出 #1**

90788004 68.4```

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 学生信息结构体
struct Stu {
    int id;              // 学号
    double score;        // 成绩
};

// 排序规则：按成绩从高到低（降序）
bool cmp(Stu a, Stu b) {
    return a.score > b.score;
}

int main() {
    int n, k;                     // n: 学生人数, k: 所求名次
    cin >> n >> k;

    Stu a[105];                   // 最多 100 人，开 105 安全
    for (int i = 0; i < n; i++) {
        cin >> a[i].id >> a[i].score;
    }

    // 按成绩降序排序，第一名成绩最高
    sort(a, a + n, cmp);

    // 输出第 k 名（下标 k-1）的学号和成绩
    // 使用 %g 按题目要求输出成绩（自动去除尾随零）
    printf("%d %g\n", a[k - 1].id, a[k - 1].score);
    return 0;
}
