2166 - 子树的大小及深度

题目描述

现在有一棵 nnn 个结点的树，结点 111 为这棵树的根，结点 111 的深度为 111，求出每棵子树的大小及每个结点的深度。

比如，有如下图所示的树：

该树中：

结点 111 对应的子树大小为 666，深度为 111。

结点 222 对应的子树大小为 555，深度为 222。

结点 333 对应的子树大小为 111，深度为 333。

结点 444 对应的子树大小为 111，深度为 333。

结点 555 对应的子树大小为 222，深度为 333。

结点 666 对应的子树大小为 111，深度为 444。

输入

输入有 nnn 行。

第 111 行有一个整数 nnn，代表结点的数量，结点的编号为1∼n1 \sim n1∼n。（1≤n≤1001≤n≤1001≤n≤100）

接下来有 n−1n-1n−1 行，每行有 222 个整数 x,yx,yx,y，表示结点 xxx 和 yyy 之间有一条边。（不保证 xxx 是 yyy 的父）

输出

输出有 nnn 行。

第 iii 行输出 222 个整数，分别是以编号 iii 为根的子树的大小，以及编号 iii 对应的结点的深度。

AC代码

#include <iostream>
#include <cstring>
using namespace std;

/*
 * 思路：
 * 用邻接矩阵存储树（无向图）。
 * 从根结点 1 开始深度优先遍历（DFS），计算每个结点的深度和子树大小。
 * 深度：根深度为 1，向下每走一步深度 +1。
 * 子树大小：包含自身和所有后代。递归时先设 b[u] = 1，然后累加每个孩子的子树大小。
 */

int n;                     // 结点数量
bool a[105][105];          // 邻接矩阵，a[i][j] = true 表示 i 和 j 之间有边
int b[105], dep[105];     // b[i]：结点 i 的子树大小，dep[i]：结点 i 的深度

// x：当前结点，f：父结点（防止往回走），d：当前深度
void dfs(int x, int f, int d) {
    dep[x] = d;            // 记录深度
    b[x] = 1;             // 子树至少包含自己

    // 尝试所有可能的相邻结点
    for (int i = 1; i <= n; ++i) {
        if (a[x][i] && i != f) {   // 如果有边且不是父结点
            dfs(i, x, d + 1);      // 递归孩子，深度 +1
            b[x] += b[i];        // 累加孩子的子树大小
        }
    }
}

int main() {
    cin >> n;
    memset(a, 0, sizeof(a));   // 邻接矩阵清空

    // 读入 n-1 条边，建立无向图
    for (int i = 1; i < n; ++i) {
        int x, y;
        cin >> x >> y;
        a[x][y] = a[y][x] = true;  // 双向标记
    }

    // 从根结点 1 开始遍历，父结点设为 0（不存在），深度为 1
    dfs(1, 0, 1);

    // 输出每个结点的子树大小和深度
    for (int i = 1; i <= n; ++i) {
        cout << b[i] << " " << dep[i] << endl;
    }

    return 0;
}
