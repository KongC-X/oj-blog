1057 - 能被5整除且至少有一位数字是5的所有整数的个数

题目描述

找出 $1 \sim N$ 中能被 $5$ 整除且至少有一位数字是 $5$ 的所有整数的个数。（ $N \lt 32767$）。

输入

输入只有一行，只有 $1$ 个整数 $N$ 。

输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

AC代码

AC代码

#include <iostream>
using namespace std;
int main(){
    int N,i,w,q,b,s,g,x=0;
    cin>>N;
    for(i=1;i<=N;i++){
        w=i/10000;
        q=i/1000%10;
        b=i/100%10;
        s=i%100/10;
        g=i%10;
        if(i%5==0){
            if(w==5||q==5||b==5||s==5||g==5){
                x++;
            }
        }
    }
    cout<<x;
}
