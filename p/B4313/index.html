B4313 [语言月赛 202504] 洛谷月赛

洛谷 | 入门 | C++14 | 提交时间: 2026-07-29

算法标签：2025、分支结构、语言月赛

题目背景

为了简化问题，本题中的资质要求和真实资质要求略有区别，请以本题为准。

请入门选手注意，CCF 程序设计能力等级并不是 GESP 等级。

题目描述

小 M 最近想出一场洛谷 div. 2 小月赛。他已经出好了一些题，并想要再找一个有出题经验的工作人员合作。（你可以认为整个团队只有他们两人。）

洛谷月赛对工作人员的 CCF 程序设计能力等级（简称“等级”）有所要求，具体如下：

  • 至少一个工作人员获得了 ≥8\ge 8≥8 级，或 ≥6\ge 6≥6 级且有出题经验，称为该比赛的负责人。
  • 所有工作人员至少需要 333 级。

给出小 M 的等级、是否有出题经验，判断他找的合作者至少要获得几级，或报告两人无法满足资质要求。

输入格式

输入一行两个自然数 l,el,el,e，分别表示小 M 的等级以及是否有出题经验（111 表示有，000 表示没有）。

输出格式

输出一行一个自然数，表示小 M 找的合作者所需的最低等级。

特别地，如果两人无法满足资质要求，输出 Impossible。

样例

样例输入 #1

8 0

样例输出 #1

3

样例输入 #2

5 1

样例输出 #2

6

样例输入 #3

2 0

样例输出 #3

Impossible```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int l, e;   // l: 小M的等级, e: 是否有出题经验(1有0无)
    cin >> l >> e;

    // 小M自己必须满足等级 >= 3，否则无论如何都不符合“所有工作人员至少3级”
    if (l < 3) {
        cout << "Impossible" << endl;
        return 0;
    }

    if ((l >= 8) || (l >= 6 && e == 1)) {
        // 小M已经是负责人，合作者只需要满足等级 >= 3 且必须有出题经验
        // 合作者一定有经验（题目要求找有出题经验的人），所以只需输出最低等级 3
        cout << 3 << endl;
    } else {
        // 小M不能当负责人，合作者必须担任负责人
        // 合作者有出题经验，要成为负责人最低需达到等级 6（满足≥6且有经验）
        // 并且合作者等级至少为 3，6 >= 3 满足
        cout << 6 << endl;
    }

    return 0;
}
