P2524 Uim的情人节礼物·其之弐

洛谷 | 入门 | C++14 | 提交时间: 2026-08-14

算法标签：模拟、数学、2015、洛谷原创、康托展开、洛谷月赛

题目描述

前传：详见洛谷 P2525

Uim 成功地按照顺序将礼物送到了 NNN 个妹子的手里并维持她们的和谐。

现在 Uim 想知道，他最终选择的顺序是所有给 NNN 个妹子送礼顺序中，字典序第几小的。送礼顺序可以看作 1,2,⋯ ,N1,2,\cdots,N1,2,⋯,N 的一个排列。

输入格式

第一行一个整数 NNN，表示有 NNN 个数。

第二行一个整数 XXX，表示给出的排列。

输出格式

一个整数，表示是第几小的字典序。

样例

样例输入 #1

3
231```

**样例输出 #1**

4```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P2524 Uim的情人节礼物·其之弐
     * 题意：给定1~N的一个排列，求它在所有排列中的字典序排名（从1开始）。
     * 数据：N≤9，直接枚举所有排列。
     *
     * 思路：
     * 1. 从最小的排列（1,2,3,...,N）开始，用 next_permutation 不断生成下一个排列。
     * 2. 每生成一个排列，排名加1。
     * 3. 直到生成的排列与输入相同时，输出排名。
     * 4. 最坏情况：要枚举到最后一个排列，最多 N! ≤ 362880 次，完全可行。
     */
    int n;          // n: 数的个数
    cin >> n;

    string s;       // s: 输入的排列（字符串形式，如 "231"）
    cin >> s;

    // 目标排列（数字数组，下标从0开始）
    int target[15];
    for (int i = 0; i < n; i++) {
        target[i] = s[i] - '0';
    }

    // 当前排列（初始为最小的排列：1,2,3,...,n）
    int a[15];
    for (int i = 0; i < n; i++) {
        a[i] = i + 1;
    }

    int ans = 1;    // 排名，从1开始（因为最小的排列是第1个）
    while (true) {
        // 判断当前排列是否为目标排列
        bool ok = true;
        for (int i = 0; i < n; i++) {
            if (a[i] != target[i]) {
                ok = false;
                break;
            }
        }
        if (ok) {
            cout << ans << endl;
            break;
        }

        // 生成下一个排列
        next_permutation(a, a + n);
        ans++;
    }

    return 0;
}
