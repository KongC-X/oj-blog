3669 - 字母求和

题目描述

小杨同学发明了一种新型密码，对于每一个小写英文字母，该小写字母代表了一个正整数，即该字母在字母顺序中的位置，例如字母 aaa 代表了正整数 111，字母 bbb 代表了正整数 222；对于每一个大写英文字母，该大写字母代表了一个负整数，即该字母的 ASCII 码的相反数，例如字母 AAA 代表了正整数 −65-65−65。

小杨同学利用这种方式对一个整数进行了加密并得到了一个由大写字母和小写字母组成的字符串，该字符串中每个字母所代表数字的总和即为加密前的整数，例如 aAcaAcaAc 对应的加密前的整数为 1+(−65)+3=−611+(-65)+3=-611+(−65)+3=−61。

对于给定的字符串，请你计算出它对应的加密前的整数是多少。

输入

第一行一个正整数 nnn ，表示字符串中字母的个数。

第二行一个由大写字母和小写字母的字符串 TTT，代表加密后得到的字符串。

输出

输出一行一个整数，代表加密前的整数。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int n, i, sum;
char a[100010];
int main() {
    cin >> n;
    cin >> a;
    for(i = 0;i < n;i++) {
        int s = 0;
        if(a[i] >= 'a' && a[i] <= 'z') {
            s = a[i] - 'a' + 1;
        } else if(a[i] >= 'A' && a[i] <= 'Z') {
            s = 0 - int(a[i]);
        }
        sum += s;
    }
    cout << sum << endl;
}
