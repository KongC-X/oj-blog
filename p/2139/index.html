2139 - 乘积的约数和

题目描述

给定 nnn 个正整数 aia_iai​，请你输出这些数的乘积的约数和，答案对 109+710^9+7109+7 取余数。

输入

第一行包含整数 nnn。

接下来 nnn 行，每行包含一个整数 aia_iai​。

数据范围
1≤n≤100,1≤ai≤2×1091≤n≤100, 1≤a_i≤2 \times 10^91≤n≤100,1≤ai​≤2×109。

输出

输出一个整数，表示所给正整数的乘积的约数和。

解题思路

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 将四位的二进制转换为1位的十六进制
char num(string s) {
    // 1101，从最低位开始展开，先转换为10进制
    // 再转换为16进制
    int n,x = 0;
    for(int i = s.size() - 1; i >= 0; i--) {
        n = (s[i] - '0') * pow(2, s.size() - 1 - i);
        x += n;
    }
    char c;
    if(x >= 10) {
        c = x - 10 + 'A';
    } else {
        c = x + '0';
    }
    return c;
}

int main(){
    string s;
    cin >> s;
    // 补0
    if(s.size() % 4 == 1) {
        s = "000" + s;
    } else if(s.size() % 4 == 2) {
        s = "00" + s;
    } else if(s.size() % 4 == 3) {
        s = "0" + s;
    }
    // 四位截取输出对应的十六进制
    for(int i = 0;i < s.size();i += 4) {
        cout << num(s.substr(i, 4));
    }
}
