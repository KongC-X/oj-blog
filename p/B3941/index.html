B3941 [GESP样题 五级] 小杨的锻炼

洛谷 | 普及- | C++14 | 提交时间: 2025-06-04

算法标签：数论、最大公约数 gcd、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1105

题目描述

小杨的班级里共有 nnn 名同学，每位同学都有各自的锻炼习惯。具体来说，第 iii 位同学每隔 aia_iai​ 天就会进行一次锻炼（也就是说，每次锻炼会在上一次锻炼的 aia_iai​ 天后进行）。某一天，班上的 nnn 名同学恰好都来进行了锻炼。他们对此兴奋不已，想要计算出下一次所有同学都来锻炼，至少要过多少天。但他们不会计算，你能帮帮他们吗？

输入格式

第一行一个整数 nnn，表示同学的数量。
第二行 nnn 个用空格隔开的正整数，依次为 a0,a1,…,an−1a_0, a_1, …, a_{n-1}a0​,a1​,…,an−1​。

输出格式

输出一个整数，表示下一次所有同学都来锻炼，至少要过多少天。

样例

样例输入 #1

3
1 2 3

样例输出 #1

6```

**样例输入 #2**

4
2 4 8 16


**样例输出 #2**

16```

样例输入 #3

4
2 4 6 8

样例输出 #3

24```

## AC 代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

long long n,a[11],t,i;

//辗转相除法求最大公约数
long long gcd(long long x, long long y){
    if(y == 0) return x;
    else return gcd(y,x % y);
}

int main(){
    cin >> n;
    for(i=1;i<=n;i++){
        cin >> a[i];
    }
    t=a[1]; // 初始化最小公倍数为第一个数
    // 最小公倍数=两数乘积/最大公约数
    for(i=1;i<=n;i++) {
        t=t*a[i]/gcd(t,a[i]);//依次计算最小公倍数
    }
    cout << t << endl; // 输出最小公倍数
    return 0;
}
