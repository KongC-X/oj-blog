1382 - 蛇形填充数组

题目描述

用数字 1,2,3,4,…,n×n1,2,3,4, \dots ,n \times n1,2,3,4,…,n×n 这 n2n2n2 个数蛇形填充规模为 n×nn \times nn×n 的方阵。

蛇形填充方法为：对于每一条左下-右上的斜线，从左上到右下依次编号 1,2,…,2n−11,2, \dots ,2n-11,2,…,2n−1 ；按编号从小到大的顺序，将数字从小到大填入各条斜线，其中编号为奇数的从左下向右上填写，编号为偶数的从右上到左下填写。

比如 n=4n=4n=4 时，方阵填充为如下形式：

`    1    2    6    7
    3    5    8   13
    4    9   12   14
   10   11   15   16
`

输入

输入一个不大于 101010 的正整数 nnn ，表示方阵的行数。

输出

输出该方阵，数字场宽为 555 。

AC代码

AC代码

#include <iostream>
#include <iomanip>
using namespace std;

int a[20][20];

int main() {
    int n, id = 1;
    cin >> n;
    for(int i = 2; i <= 2 * n; i++) {
        if(i % 2 == 1) {
            for(int j = 1; j <= n; j++) {
                for(int k = 1; k <= n; k++) {
                    if(j + k == i) {
                        a[j][k] = id++;
                    }
                }
            }
        } else {
            for(int j = n; j >= 1; j--) {
                for(int k = 1; k <= n; k++) {
                    if(j + k == i) {
                        a[j][k] = id++;
                    }
                }
            }
        }
    }
    for(int i = 1; i <= n; i++) {
        for(int j = 1; j <= n; j++) {
            cout << setw(5) << a[i][j];
        }
        cout << endl;
    }
    return 0;
}
