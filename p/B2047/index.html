B2047 分段函数

洛谷 | 入门 | C++14 | 提交时间: 2026-06-27

题目描述

编写程序，计算下列分段函数 y=f(x)y=f(x)y=f(x) 的值。

当 0≤x<50 \le x<50≤x<5 时，y=−x+2.5y=-x+2.5y=−x+2.5。

当 5≤x<105 \le x<105≤x<10 时，y=2−1.5(x−3)(x−3)y=2-1.5(x-3)(x-3)y=2−1.5(x−3)(x−3)。

当 10≤x<2010 \le x<2010≤x<20 时，y=x/2−1.5y=x/2-1.5y=x/2−1.5。

输出格式

输出 xxx 对应的分段函数值：f(x)f(x)f(x)。结果保留到小数点后三位。

样例

样例输入 #1

1.0```

**样例输出 #1**

1.500```

AC 代码

#include <bits/stdc++.h>
using namespace std;
double x;
int main(){
    cin >> x;
    if (x >= 0 && x < 5){
        cout << fixed << setprecision(3) << -x + 2.5 << endl;
    }
    else if (x >= 5 && x < 10){
        cout << fixed << setprecision(3) << 2 - 1.5 * (x- 3) * (x - 3) << endl;
    }else{
        cout << fixed << setprecision(3) << x / 2 - 1.5 << endl;
    }
}
