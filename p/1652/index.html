1652 - 跳格子2

题目描述

地面上有一排长度为 $n$ 的格子 $1 \sim n$，每个格子上都有一个数 $x_i$，开始时你在位置 $0$，每次你可以向前跳 $1 \sim 2$ 格，然后取走格子上的数，直到跳到位置 $n+1$。

取走的数的和就是你的得分，现在你想知道你可能的最小得分是多少。

输入

一行四个整数 $n,A,B,C$($n≤100000$，$0≤A,B,C≤10000$)，其中 $n$ 表示格子的数量。$x[i]$ 由如下方式生成。

`    for (int i = 1; i

## 输出

一行一个整数 $ans$ 表示可能的最小得分。

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int dp[100005],x[100005];
int main(){
    int n,a,b,c;
    cin>>n>>a>>b>>c;
    for (int i = 1; i <= n; i++){
        int tmp = ((long long)a * i * i + b * i + c) % 20000;
        x[i] = tmp - 10000;
    }
    
    dp[0] = 0;
    dp[1] = x[1];
    
    for(int i=2;i<=n+1;i++){
        dp[i] = min(dp[i-1],dp[i-2]) + x[i]; 
    }
    
    cout<<dp[n+1];
    return 0;
}
