1659 - 是否含有数字5

题目描述

请从键盘读入一个五位整数 nnn，判断其是否含有数字 555，如果含有数字 555 ，请输出这个 555 位数各个位的和；如果不含数字 555 ，请直接输出这个 555 位数。

比如：输入：123451234512345，就是含有数字 555 ，因此输出 15（1+2+3+4+5=15）15（1+2+3+4+5=15）15（1+2+3+4+5=15）。

再比如：输入：121881218812188 ，就不含数字 555，那么直接输出121881218812188 。

输入

一个五位正整数 nnn 。

输出

输出一个整数，代表按要求计算的结果。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int n,a,b,c,d,e;
    cin >> n;
    // 12345
    a = n / 10000;  // 1
    b = n % 10000 / 1000;   // 2
    c = n % 1000 / 100;  // 3
    d = n % 100 / 10;  // 4
    e = n % 10;  // 5
    if (a == 5 || b == 5 || c == 5 || d == 5 || e == 5) {
        cout << a+b+c+d+e << endl;
    }else {
        cout << n << endl;
    }
    return 0;
}
