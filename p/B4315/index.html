B4315 [语言月赛 202504] 地铁停靠

洛谷 | 入门 | C++14 | 提交时间: 2026-08-01

算法标签：2025、数组、语言月赛

题目描述

一路地铁依次经过 nnn 个站点，编号依次为 1∼n1\sim n1∼n。地铁从第 iii 个站点到第 i+1i+1i+1 个站点需要用 tit_iti​ 秒，而地铁到第 iii 站时会停 sis_isi​ 秒。

小 M 想从第 xxx 站坐地铁到第 yyy 站。那么他在地铁上的最长时间是多少？

注：最长时间，即地铁刚到第 xxx 站就上地铁，地铁即将离开第 yyy 站才下地铁的情况下，小 M 在地铁上的时间。单位为秒。

输入格式

第一行有一个正整数 nnn，表示经过的站点数目。

第二行有 n−1n-1n−1 个正整数 t1,t2,…,tn−1t_1,t_2,\ldots, t_{n-1}t1​,t2​,…,tn−1​，表示地铁在相邻两站之间的用时。

第三行有 nnn 个正整数 s1,s2,…,sns_1,s_2,\ldots,s_ns1​,s2​,…,sn​，表示地铁在每一站的停靠时间。

最后一行有两个正整数 x,yx,yx,y，表示小 M 想从第 xxx 站坐到第 yyy 站。

输出格式

输出一行一个正整数，表示小 M 在地铁上的最长时间，单位为秒。

样例

样例输入 #1

4
150 180 170
35 32 33 34
2 4

样例输出 #1

449

样例输入 #2

5
300 300 300 300
40 40 40 40 40
2 4

样例输出 #2

720

样例输入 #3

4
150 180 170
35 32 33 34
1 4

样例输出 #3

634```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】简单模拟
     * 【核心思路】
     * 1. 读入 n，t[1..n-1]，s[1..n]，x, y。
     * 2. 累加停靠时间：for i = x to y: sum_s += s[i]
     * 3. 累加行驶时间：for i = x to y-1: sum_t += t[i]
     * 4. 输出 sum_s + sum_t
     *
     * 【时间复杂度】O(n)
     */

    int n;          // n: 站点数
    cin >> n;

    int t[55];      // t[i]: 从 i 到 i+1 的行驶时间
    int s[55];      // s[i]: 第 i 站的停靠时间

    for (int i = 1; i <= n-1; i++) {
        cin >> t[i];
    }
    for (int i = 1; i <= n; i++) {
        cin >> s[i];
    }

    int x, y;       // x: 起点站, y: 终点站
    cin >> x >> y;

    int sum_s = 0;  // 停靠总时间
    int sum_t = 0;  // 行驶总时间

    for (int i = x; i <= y; i++) {
        sum_s += s[i];
    }
    for (int i = x; i <= y - 1; i++) {
        sum_t += t[i];
    }

    int ans = sum_s + sum_t;
    cout << ans << endl;

    return 0;
}
