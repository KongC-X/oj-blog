1767 - 等差对

题目描述

给定 $N$ 个数 $A_i$，以及一个正整数 $C$，问有多少对$A_i,A_j$，满足$A_i-A_j=C$。

输入

第 $1$ 行输入两个空格隔开的整数 $N$ 和 $C$。

第 $2$ 至 $N+1$ 行每行包含一个整数 $A_i$。

输出

输出一个数表示答案。

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
#include<set>
using namespace std;

int n,ans,m;
multiset<int> s;
int x;

int main() {
    cin>>n>>m;
    for(int i=1; i<=n; i++) {
        cin>>x;
        s.insert(x);
    }
    multiset<int>::iterator it;
    for(it = s.begin();it != s.end();it++){
        ans += s.count(m+*it); // 这里必须使用s.count()，count函数作用是统计元素出现的次数
        // 如果使用s.find(m+*it)，则只能找到第一个匹配的元素，无法统计重复元素
        // if(s.find(m+*it) != s.end()) {
        // 	ans++;
        // }
    }
    cout<<ans<<endl;
    return 0;
}
