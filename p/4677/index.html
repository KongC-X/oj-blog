4677 - 等差矩阵

题目描述

小 AAA 想构造一个 nnn 行 mmm 列的矩阵，使得矩阵的每一行与每一列均是等差数列。小 AAA 发现，在矩阵的第 iii 行第 jjj 列填入整数 i×ji \times ji×j ，得到的矩阵能满足要求。你能帮小 AAA 输出这个矩阵吗？

输入

一行，两个正整数 n，mn，mn，m 。

输出

共 nnn 行，每行 mmm 个由空格分割的整数，表示小 AAA 需要构造的矩阵。

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    int n,m,i,j;
    cin >> n >> m;
    for(i=1;i<=n;i++){
        for(j=0;j<m;j++){
            cout << i + i * j << " ";
        }
        cout << endl;
    }
}
