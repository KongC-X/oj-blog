1704 - 整数乘法算式

题目描述

输入两个整数，以算式的形式输出它们的相乘过程。

输入

两个整数，在一行输入，中间用空格隔开。

输出

一行输出结果与过程。

解题思路

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    //定义两个变量
    int x,y;
    //输入x,y
    cin>>x>>y;
    //按要求格式输出 
    cout<<x<<'*'<<y<<'='<<x*y; 
    return 0;
}
