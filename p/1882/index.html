1882 - 循环输出100~1之间的每个数

题目描述

请循环输出 $100 \sim 1$ 之间的每个整数，输出时每行输出 $1$ 个数，比如，输出结果的前 $10$ 个数是这样的：

$100$

$99$

$98$

$97$

$96$

$95$

$94$

$93$

$92$

$91$

$ \dots $

输入

无。

输出

按要求输出 $100~1$ 之间的每个数。

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int i = 100;
    while (i >= 1) {
        cout << i << endl;
        i--;
    }
}
