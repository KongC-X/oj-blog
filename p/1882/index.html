1882 - 循环输出100~1之间的每个数

题目描述

请循环输出 100∼1100 \sim 1100∼1 之间的每个整数，输出时每行输出 111 个数，比如，输出结果的前 101010 个数是这样的：

100100100

999999

989898

979797

969696

959595

949494

939393

929292

919191

…\dots…

输入

无。

输出

按要求输出 100 1100~1100 1 之间的每个数。

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int i = 100;
    while (i >= 1) {
        cout << i << endl;
        i--;
    }
}
