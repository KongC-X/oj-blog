1523 - 斗地主

题目描述

到了嬉戏谷，同学们坐了过山车，看了 4D 电影，玩了 VR(虚拟现实)游戏，吃过饭有一段自由活动时间，小Ｘ拿出两幅扑克牌，叫上 333 个小伙伴斗起了地主，斗地主俗称三打一，即三个农民共同对付一个地主，若地主获胜，则三个农民都要输给地主相同数量的积分，反之如地主输则三个农民赢得相同数量的积分。

积分分为三档，分别为 111 分, 222 分, 333 分，如地主输了一个三档，则他要输给三家农民各 333 分，共计输掉 999 分积分，开始时，四家积分均为零，小Ｘ座在 111 号位置，其余三个小伙伴分别在 2,3,42,3,42,3,4 号位置，每一局用地主的位置和档数及胜负状况表示，如第一局为 1,3,11,3,11,3,1，表示地主为 111 号位，档数为 333 ，第 333 个数 111 表示地主赢了，第一局之后 444 家的积分依次为 9,−3,−3,−39,-3,-3,-39,−3,−3,−3 ，第二局为 3,2,23,2,23,2,2 ，表示地主为 333 号位的小伙伴，档数为 222 第 333 个数 222 表示地主输了，即 333 号位的小伙伴输掉了 666 个积分，小Ｘ和另外两个小伙伴各赢了2 分，第二局之后四家积分依次为 11,−1,−9,−111,-1,-9,-111,−1,−9,−1 。

现在小Ｘ请你来当裁判给大家计分，要你根据每局的输入数据计算四家的最终得分。

输入

输入数据第一行包含一个正整数 nnn，表示斗地主共进行了 nnn 局。

接下来 nnn 行每行有 333 个用空格隔开的正整数，第一个数表示地主在几号位，第二个数表示地主的档数，第三个数表示胜负，111 表示地主方获胜，222 表示农民方获胜。

输出

输出数据仅有一行包含四个整数，依次表示四个小伙伴的最终得分，第一个数表示小Ｘ(座 111 号位)的积分，后三个数依次为 222 号位, 333 号位, 444 号位的积分，相邻两数之间严格用一个空格隔开。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    int score[5] = {0}; // 下标1-4分别表示1-4号位

    for (int i = 0; i < n; ++i) {
        int landlord, level, result;
        cin >> landlord >> level >> result;

        if (result == 1) { // 地主赢
            score[landlord] += 3 * level;
            for (int j = 1; j <= 4; ++j) {
                if (j != landlord) {
                    score[j] -= level;
                }
            }
        } else { // 农民赢，result == 2
            score[landlord] -= 3 * level;
            for (int j = 1; j <= 4; ++j) {
                if (j != landlord) {
                    score[j] += level;
                }
            }
        }
    }

    cout << score[1] << " " << score[2] << " " << score[3] << " " << score[4] << endl;
    return 0;
}
