B4138 [信息与未来 2016] 洗牌

洛谷 | 普及- | C++14 | 提交时间: 2026-04-13

算法标签：模拟、2016、江苏、信息与未来

题目描述

小明把 nnn（nnn 为偶数）张牌按编号顺序 1,2,3,…,n1,2,3,\dots ,n1,2,3,…,n 排成一堆，然后开始洗牌。一次洗牌的过程如下:

  1. 对于一堆编号为 a1,a2,…,ana_1,a_2,\dots,a_na1​,a2​,…,an​，首先将牌分成均匀的两堆：a1,a2,…,ama_1,a_2,\dots,a_ma1​,a2​,…,am​ 和 am+1,am+2,…,ana_{m+1},a_{m+2},\dots,a_nam+1​,am+2​,…,an​（其中 m=n2m=\frac{n}{2}m=2n​）。

  2. 然后按顺序交叉插入：a1,am+1,a2,am+2,…,am,ana_1,a_{m+1},a_2,a_ {m+2},\dots,a_m,a_na1​,am+1​,a2​,am+2​,…,am​,an​。

洗牌过程总共重复了 kkk 次，请你编程帮助小明模拟洗牌的过程。

例如 n=6n=6n=6，初始时，牌堆中牌的编号为 1,2,3,4,5,61,2,3,4,5,61,2,3,4,5,6。

首次洗牌时，会将牌分成 1,2,31,2,31,2,3 和 4,5,64,5,64,5,6 两堆，交叉插入后的结果为 1,4,2,5,3,61,4,2,5,3,61,4,2,5,3,6。

再次洗牌，会将牌分成 1,4,21,4,21,4,2 和 5,3,65,3,65,3,6 两堆，交叉插入后，得到 1,5,4,3,2,61,5,4,3,2,61,5,4,3,2,6。

输入格式

一行，正整数 n,k,in,k,in,k,i，分别代表牌的数量、洗牌的次数、和牌的位置。

输出格式

nnn 张牌洗牌 kkk 次后，牌堆中第 iii 张牌的编号。

样例

样例输入 #1

6 2 5```

**样例输出 #1**

2```

样例输入 #2

400 300 200```

**样例输出 #2**

368```

AC 代码

#include <bits/stdc++.h>
using namespace std;
int n, k, p, a[1010], t[1010], x;

int main()
{
    cin >> n >> k >> p;
    for(int i = 1; i <= n; i++)
    {
        a[i] = i;
    } 
    //洗牌k次
    for(int i = 1; i <= k; i++)
    {
        //前半部分，从后往前依次插入奇数位
        x = n - 1;
        for(int j = n / 2; j >= 1; j--)
        {
            t[x] = a[j];
            x -= 2;
        }
        //后半部分，从前往后依次插入偶数位
        x = 2;
        for(int j = n / 2 + 1; j <= n; j++)
        {
            t[x] = a[j];
            x += 2;
        }
        //将洗好的牌，更新到a数组中
        for(int j = 1; j <= n; j++)
        {
            a[j] = t[j];
        }
    }
    cout << a[p];
    return 0;
}
