1429 - 奖学金评级

题目描述

某大学在学年结束时，要根据同学们各个学科的考试成绩评定奖学金，根据同学们这学期所有科目的考试成绩来进行统计。

奖学金评级方法如下：

只要有不及格的科目（成绩 <60\lt 60<60 分为不及格），就不能参评奖学金。
如果有 555 个及以上的科目优秀（成绩 ≥90\ge 90≥90 分为优秀）那么能够获取一等奖学金。

如果有 333 个或者 444 个科目优秀，那么能够获取二等奖学金。

如果有 222 个科目优秀，那么能够获取三等奖学金。

请编写一个程序从键盘读入某同学 nnn 门科目的考试成绩，输出该同学获得奖学金的情况（一等奖学金输出 $1$ ，二等奖学金输出 $2$ ，三等奖学金输出 $3$ ，不能获得奖学金输出$no$）。

输入

第 111 行是一个整数 nnn ，代表有 nnn 个考试科目（ 5≤n≤155 \le n \le 155≤n≤15 ）；

第 222 行是 nnn 个整数，代表该同学 nnn 门考试的成绩。

输出

输出该同学获得奖学金的情况。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int a[25],n,i;
//c1统计优秀科目数量
//c2统计不及格的科目数量 
int c1 = 0,c2 = 0; 
int main() {
    cin>>n;
    for(i = 0;i < n;i++){
        cin>>a[i];
        
        //统计优秀及不及格科目数量
        if(a[i] >= 90){
            c1++;
        } else if(a[i] < 60){
            c2++;
        }
    }
    //如果有不及格，则不能参评奖学金
    if(c2 != 0){
        cout<<"no";
    }else{
        if(c1 >= 5){
            cout<<1;
        }else if(c1 == 3 || c1 == 4){
            cout<<2;
        }else if(c1 == 2){
            cout<<3;
        }else{
            cout<<"no";
        }
    } 
}
