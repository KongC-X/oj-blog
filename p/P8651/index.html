P8651 [蓝桥杯 2017 省 B] 日期问题

洛谷 | 普及- | C++14 | 提交时间: 2026-10-07

算法标签：2017、枚举、蓝桥杯省赛

题目描述

小明正在整理一批历史文献。这些历史文献中出现了很多日期。小明知道这些日期都在 1960 年 1 月 1 日至 2059 年 12 月 31 日。令小明头疼的是，这些日期采用的格式非常不统一，有采用年/月/日的，有采用月/日/年的，还有采用日/月/年的。更加麻烦的是，年份也都省略了前两位，使得文献上的一个日期，存在很多可能的日期与其对应。

比如 02/03/04，可能是 2002 年 03 月 04 日、2004 年 02 月 03 日或 2004 年 03 月 02 日。

给出一个文献上的日期，你能帮助小明判断有哪些可能的日期对其对应吗？

输入格式

一个日期，格式是 AA/BB/CC。(0≤A,B,C≤90\le A, B, C\le 90≤A,B,C≤9)

输出格式

输出若干个不相同的日期，每个日期一行，格式是 yyyy-MM-dd。多个日期按从早到晚排列。

样例

样例输入 #1

02/03/04```

**样例输出 #1**

2002-03-04
2004-02-03
2004-03-02 ```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int d[13] = {0, 31, 28, 31, 30, 31, 30, 31, 31, 30, 31, 30, 31};  // 每月天数

// 判断闰年
bool leap(int y) {
    return (y % 4 == 0 && y % 100 != 0) || (y % 400 == 0);
}

int main() {
    /*
     * 题目：P8651 [蓝桥杯 2017 省 B] 日期问题
     * 题意：给定 AA/BB/CC 格式的日期，可能是年/月/日、月/日/年、日/月/年三种格式之一。
     *       年份省略前两位，范围在 1960~2059。求所有可能的合法日期，按从早到晚输出。
     *
     * 题解思路：
     *   不枚举三种排列再排序去重，而是直接枚举 1960~2059 年之间的每一个合法日期
     *   (year, month, day)，检查它是否与输入的 AA, BB, CC 匹配。
     *   匹配条件（满足任一即可）：
     *     - AA == year % 100 且 BB == month 且 CC == day   （年/月/日）
     *     - AA == month 且 BB == day 且 CC == year % 100   （月/日/年）
     *     - AA == day 且 BB == month 且 CC == year % 100   （日/月/年）
     *
     *   这样做的好处：
     *     1. 年份从 1960 到 2059 递增枚举，月份和日期也递增，输出顺序天然有序。
     *     2. 每个日期只被访问一次，不会重复。
     *     3. 不需要排序和去重。
     *
     * 时间复杂度：O(100 * 12 * 31) ≈ O(4e4)，常数时间。
     */

    int a, b, c;
    scanf("%d/%d/%d", &a, &b, &c);

    // 枚举 1960 到 2059 年
    for (int y = 1960; y <= 2059; y++) {
        d[2] = leap(y) ? 29 : 28;   // 根据闰年调整二月天数

        for (int m = 1; m <= 12; m++) {
            for (int day = 1; day <= d[m]; day++) {
                // 判断三种格式是否匹配
                if ((a == y % 100 && b == m && c == day) ||
                    (a == m && b == day && c == y % 100) ||
                    (a == day && b == m && c == y % 100)) {
                    printf("%d-%02d-%02d\n", y, m, day);
                }
            }
        }
    }

    return 0;
}
