2316 - 勾股数（gougu）

题目描述

勾股定理指直角三角形的两条直角边的平方和等于斜边的平方。中国古代称直角三角形为勾股形，并且直角边中较小者为勾，另一长直角边为股，斜边为弦，所以称这个定理为勾股定理。

勾股弦的长度分别为 a,b,ca,b,ca,b,c，有：a2a^2a2 +++ b2b ^2b2 === c2c^2c2 。
当 a,b,ca,b,ca,b,c 均为正整数时，我们称( a,b,ca,b,ca,b,c )为勾股数。
如：

3,4,53,4,53,4,5

5,12,135,12,135,12,13

7,24,257,24,257,24,25

9,40,419,40,419,40,41

…\dots…

均为勾股数。

当然，这只是一部分勾股数，现在的问题是：按这样的方法列下去，第 nnn 组勾股数是什么？

输入

一个单独的整数 nnn。

输出

三个空格隔开的整数，表示第 nnn 组勾股数。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int main(){
    long long n,a,b,c;
    cin >> n;
    a = n * 2 + 1;
    b = a * n + n;
    c = b + 1;
    cout << a << " " << b << " " << c;
}
