1314 - 仰卧起坐成绩统计

题目描述

四年级二班女同学在体育课上进行了一轮仰卧起坐测试。成绩计算表如下。

`一分钟内做仰卧起坐的个数  成绩
   =60个                  A
`

请从键盘读入 nnn 位同学的在一分钟内做仰卧起坐的数量，计算出每个成绩区间的人数，按照人数降序排序，如果有多个成绩区间人数一样多，那么先输出成绩较好的区间。（ 4.1.444.1.444.1.44 ）

输入

第一行是一个整数 nnn 代表同学的人数（ n≤100n \le 100n≤100 ）;

第二行是 nnn 个同学一分钟完成仰卧起坐的数量。

输出

输出 666 行为 666 个成绩区间的人数，每行按照“成绩:人数”的格式输出，按照人数降序输出。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

struct node {
    int cnt;
    char grade;
}a[10];

bool cmp(node n1,node n2) {
    if(n1.cnt>n2.cnt||(n1.cnt==n2.cnt&&n1.grade<n2.grade)) {
        return true;
    } else {
        return false;
    }
}

int main() {
    int n,x;
    cin>>n;
    string t="0ABCDEFG";
    for(int i=1; i<=6; i++) {
        a[i].grade=t[i];
        a[i].cnt=0;
    }
    for(int i=1; i<=n; i++) {
        cin>>x;
        if(x>=60)a[1].cnt++;
        else if(x>=50)a[2].cnt++;
        else if(x>=40)a[3].cnt++;
        else if(x>=30)a[4].cnt++;
        else if(x>=20)a[5].cnt++;
        else a[6].cnt++;
    }
    sort(a+1,a+6+1,cmp);

    for(int i=1; i<=6; i++) {
        cout<<a[i].grade<<":"<<a[i].cnt<<endl;
    }
    return 0;
}
