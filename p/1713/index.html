1713 - 输出满足条件的整数3

题目描述

有一个数列，该数列的前 444 个数是： 111 444 777 101010 ；

请从键盘读入一个正整数 nnn ，请通过观察前 444 项的规律，输出 1∼n1 \sim n1∼n 之间所有满足该规律的数字。

输入

在一行输入一个整数 nnn 。

输出

输出满足题目要求的整数，每行 111 个。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int i = 1,n;
    cin >> n;
    while(i <= n) {
        cout << i << endl;
        i += 3;
    }
}
