1741 - 求出1~n中满足条件的数的个数和总和？

题目描述

请求出 $1 \sim n$ 之间所有满足 $2$ 的倍数但不是 $3$ 的倍数的数，有多少个，总和是多少？

输入

读入一个整数 $n（n \le 100000）$ 。

输出

输出有 $2$ 行，每行 $1$ 个整数；

第 $1$ 行输出满足条件的数有几个；

第 $2$ 行输出满足条件的数的总和。

AC代码

AC代码

# include <iostream>
using namespace std;

int main(){
    int n,i,s = 0,sum = 0;
    cin >> n;
    for(i = 1;i <= n;i++) {
        if(i % 2 == 0 && i % 3 != 0) {
            s++;
            sum += i;
        }
    }
    cout << s << endl;
    cout << sum << endl;
}
