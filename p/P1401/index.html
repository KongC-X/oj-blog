P1401 [入门赛 #18] 禁止在 int 乘 int 时不开 long long

洛谷 | 入门 | C++14 | 提交时间: 2026-06-03

算法标签：模拟、数学、2023、O2优化、语言月赛

题目描述

在比赛中，根据数据范围，分析清楚变量的取值范围，是非常重要的。int 类型变量与 int 类型变量相乘，往往可能超出 int 类型可以表示的取值范围。

现在，给出两个 int 类型变量 $x,y$ 及其取值范围，请问 $x\times y$ 的值是否可能超过 int 类型可以表示的范围？

提示：int 类型可以表示的范围为 $[-2147483648, 2147483647]$，即 $[-2^{31},2^{31}-1]$。也就是，int 类型可以表示的最小值为 $-2147483648$，最大值为 $2147483647$。

输入格式

输入共两行。

输入的第一行为两个整数 $x_l,x_u$，表示变量 $x$ 的取值范围为 $x_l \le x \le x_u$。

输入的第二行为两个整数 $y_l,y_u$，表示变量 $y$ 的取值范围为 $y_l \le y \le y_u$。

输出格式

输出一行一个字符串：

  • 若会超过，则输出 long long int；
  • 若不会超过，则输出 int。

样例

样例输入 #1

1 5
1 5```

**样例输出 #1**

int```

样例输入 #2

-2147483647 2147483647
-2147483647 2147483647```

**样例输出 #2**

long long int```

AC 代码

#include <iostream>
#include <algorithm>
using namespace std;

typedef long long ll;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    ll xl, xr, yl, yr;          // 区间 [xl, xr] 和 [yl, yr]
    cin >> xl >> xr;
    cin >> yl >> yr;

    // ---------- 思路 ----------
    // x*y 的可能最大值和最小值必然在四个端点组合中产生，
    // 因为线性函数在矩形上的极值在顶点取得。
    // 计算四个乘积，注意用 long long 防止溢出。
    // 然后判断最小值是否 < INT_MIN 或最大值 > INT_MAX，
    // 若是则输出 "long long int"，否则输出 "int"。
    
    ll p1 = xl * yl;
    ll p2 = xl * yr;
    ll p3 = xr * yl;
    ll p4 = xr * yr;

    ll mn = min({p1, p2, p3, p4});
    ll mx = max({p1, p2, p3, p4});

    // int 范围常数
    const ll INT_MIN_VAL = -2147483648LL;
    const ll INT_MAX_VAL = 2147483647LL;

    if (mn < INT_MIN_VAL || mx > INT_MAX_VAL)
        cout << "long long int\n";
    else
        cout << "int\n";

    return 0;
}
