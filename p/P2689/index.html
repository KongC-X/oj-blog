P2689 东南西北

洛谷 | 入门 | C++14 | 提交时间: 2026-08-09

算法标签：模拟、搜索、洛谷原创

题目描述

给出起点和终点的坐标，及接下来 TTT 个时刻的顺风方向（东南西北），每个时刻可以选择顺风偏移 111 个单位或者不移动。求到达终点的最少移动步数。

坐标采用平面直角坐标系，xxx 轴正向为东，yyy 轴正向为北。

如果无法偏移至终点，输出 −1-1−1。

输入格式

第一行两个正整数 x1,y1x_1,y_1x1​,y1​，表示起点坐标。

第二行两个正整数 x2,y2x_2,y_2x2​,y2​，表示终点坐标。

第三行一个整数 TTT，表示 TTT 个时刻。

第四至第 T+3T+3T+3 行，每行一个字符，表示顺风方向，即东（E\verb!E!E）南（S\verb!S!S）西（W\verb!W!W）北（N\verb!N!N）的英文单词的首字母。

输出格式

一行一个整数，表示最少移动步数。

1 1
2 2
5

N

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 更直接的贪心：对每个时刻，看风向是否指向终点方向，
     * 如果是就走一步，否则不动。
     */
    int sx, sy, ex, ey, T;
    cin >> sx >> sy >> ex >> ey >> T;

    int cx = sx, cy = sy, ans = 0;

    for (int i = 0; i < T; i++) {
        char d;
        cin >> d;

        // E：如果终点在当前位置的东边，就走
        if (d == 'E' && cx < ex) { cx++; ans++; }
        // W：如果终点在西边，就走
        else if (d == 'W' && cx > ex) { cx--; ans++; }
        // N：如果终点在北边，就走
        else if (d == 'N' && cy < ey) { cy++; ans++; }
        // S：如果终点在南边，就走
        else if (d == 'S' && cy > ey) { cy--; ans++; }

        if (cx == ex && cy == ey) {
            cout << ans << endl;
            return 0;
        }
    }

    cout << -1 << endl;
    return 0;
}
