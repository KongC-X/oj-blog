B4184 [中山市赛 2024] 除法运算

洛谷 | 普及- | C++14 | 提交时间: 2026-07-21

算法标签：数学、2024、枚举、科创活动、小学活动

题目描述

Jimmy 开始学习除法啦！一开始他学习了余数为 000 的除法（也就是我们常说的整除），后来又学习了余数不为 000 的除法，所以 Jimmy 对被除数、除数、商、余数这些概念都已经了如指掌了。

有一天，他忽然思考起一个问题——给一个正整数 nnn 作为被除数，除数 kkk 可以取任意正整数，那么会有多少互不相同的商呢？

例如：被除数 n=5n = 5n=5，无论除数 kkk 如何变化，商最多也只有 444 个不同的值，分别为 0,1,2,50, 1, 2, 50,1,2,5。这是因为：

  • 5÷6=0…55 \div 6 = 0 \dots 55÷6=0…5
  • 5÷5=1…05 \div 5 = 1 \dots 05÷5=1…0
  • 5÷4=1…15 \div 4 = 1 \dots 15÷4=1…1
  • 5÷3=1…25 \div 3 = 1 \dots 25÷3=1…2
  • 5÷2=2…15 \div 2 = 2 \dots 15÷2=2…1
  • 5÷1=5…05 \div 1 = 5 \dots 05÷1=5…0

Jimmy 作为一个天才，对这么简单的问题自然是手到擒来，于是他拿着这个问题向你发起了挑战。你能回答这个问题吗？

输入格式

本题输入有多组测试数据。

第一行一个整数 TTT，表示测试数据的组数。

接下来 TTT 行，每行一个整数 nnn，表示被除数。

输出格式

输出共 2×T2 \times T2×T 行，对于每组测试数据输出 222 行：

第一行输出一个整数 mmm，表示商有 mmm 个不同的值；

第二行输出 mmm 个整数，分别表示 mmm 个不同的商，按从小到大的顺序输出。

样例

样例输入 #1

2
5
11```

**样例输出 #1**

4
0 1 2 5
6
0 1 2 3 5 11```

AC 代码

#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const int MAXS = 70000;           // 2*sqrt(1e9) ≈ 63245，足够存放所有商
ll arr[MAXS];                     // 存储商，从大到小

int main() {
    int T;
    cin >> T;
    while (T--) {
        ll n;
        cin >> n;

        // 数论分块：枚举所有不同的商 q = n / l (l从1到n)
        int cnt = 0;               // 计数器
        ll l = 1;
        while (l <= n) {
            ll q = n / l;
            arr[cnt++] = q;        // 记录商 q
            l = n / q + 1;         // 跳到下一段
        }

        // arr 中商从大到小排列（q依次递减），现反转得到从小到大
        reverse(arr, arr + cnt);

        // 输出答案：总个数 = cnt + 1（因为商0总是存在）
        cout << cnt + 1 << "\n0";
        for (int i = 0; i < cnt; i++) {
            cout << " " << arr[i];
        }
        cout << "\n";
    }
    return 0;
}
