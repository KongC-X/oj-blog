P1888 三角函数

洛谷 | 入门 | C++14 | 提交时间: 2025-08-01

算法标签：数学、排序、最大公约数 gcd

题目描述

输入一组勾股数 a,b,c（a≠b≠c）a,b,c（a\neq b\neq c）a,b,c（a=b=c），用分数格式输出其较小锐角的正弦值。（要求约分。）

输入格式

一行，包含三个正整数，即勾股数 a,b,ca,b,ca,b,c（无大小顺序）。

输出格式

一行，包含一个分数，即较小锐角的正弦值。

样例

样例输入 #1

3 5 4```

**样例输出 #1**

3/5```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int a[4];

int main() {
    cin >> a[1] >> a[2] >> a[3];
    sort(a + 1, a + 4);
    cout << a[1] / __gcd(a[1], a[3]) << '/' << a[3] / __gcd(a[1], a[3]) << '\n';
    return 0;
}
