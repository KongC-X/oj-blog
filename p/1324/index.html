1324 - 扩建鱼塘问题

题目描述

有一个尺寸为 m×nm \times nm×n 的矩形鱼塘，请问如果要把该鱼塘扩建为正方形，那么它的面积至少增加了多少平方米？（4.2.54）（4.2.54）（4.2.54） 。

输入

两个整数 mmm 和 nnn 。

输出

一个整数，代表鱼塘面积增加的值。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int m,n;
    cin >> m >> n;
    if(m > n) {
        cout << m * (m - n) << endl;
    } else {
        cout << n * (n - m) << endl;
    }
}
