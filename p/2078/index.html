2078 - 起止位置

题目描述

有 nnn 位同学按照年龄从小到大排好队。

王老师想要查询，年龄为 xxx 的同学，在队伍中首次出现的位置和最后一次出现的位置；如果队伍中不存在年龄为 xxx 的同学，请输出 −1-1−1。

由于人数太多，一个一个数，太慢啦，请你编程求解。

请注意：本题中王老师查询年龄 xxx 出现的起止位置，并不是查询了 111 次，而是查询了 qqq 次。

比如：

假设有 666 位同学的年龄为：111 222 222 222 333 333，王老师查询了 444 个年龄，分别是 222 111 333 888 ，那么：

年龄为 222 的同学首次和最后一次出现的位置分别是：222 444；

年龄为 111 的同学首次和最后一次出现的位置分别是：111 111；

年龄为 333 的同学首次和最后一次出现的位置分别是：555 666；

年龄为 888 的同学首次和最后一次出现的位置分别是：−1-1−1 −1-1−1；

输入

第一行包含整数 nnn 和 qqq ，表示队伍中的总人数和询问个数。

第二行包含 nnn 个整数（整数的值均在 1∼100001 \sim 100001∼10000 范围内），表示队伍中每个人的年龄。

接下来 qqq 行，每行包含一个整数 xxx ，表示一次询问的值。

输出

共 qqq 行，每行包含两个整数，表示所求年龄在队伍中的起始位置和终止位置。

如果数组中不存在该元素，则返回 -1 -1。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

const int N = 100010;
int a[N];
int n,q,x;

// 左边界
int fun1(int x) {
    int l = 1,r = n,mid;
    while(l <= r) {
        mid = (l + r) >> 1;
        if(x <= a[mid]) r = mid - 1;
        else if(x > a[mid]) l = mid + 1;
    }
    if(a[l] == x) return l;
    else return -1;
}

// 右边界
int fun2(int x) {
    int l = 1,r = n,mid;
    while(l <= r) {
        mid = (l + r) >> 1;
        if(x < a[mid]) r = mid - 1;
        else if(x >= a[mid]) l = mid + 1;
    }
    if(a[r] == x) return r;
    else return -1;
}

int main() {
    cin >> n >> q;
    for(int i = 1;i <= n;i++){
        scanf("%d",&a[i]);
    }
    while(q--) {
        scanf("%d",&x);
        printf("%d %d\n",fun1(x),fun2(x));
    }
}
