1165 - 下载电影

题目描述

放暑假了，陈谱想上网下载一些电影看，但是缓慢的网速令他无法忍受。

他了解到了接下来的 NNN 个小时中的网速情况，想找一段连续的 MMM 个小时来下载电影，并且希望这 MMM 个小时的平均网速尽可能的大，你能编一个程序帮助他实现愿望吗？

输入

输入第一行包含两个整数 NNN、MMM，1≤M≤N≤1001≤M≤N≤1001≤M≤N≤100；

第二行包含 NNN 个整数，表示第 NNN 个小时的网速（0≤0≤0≤网速值≤1000≤1000≤1000），相邻两数之间用空格隔开。

输出

输出最大的平均网速，结果保留两位小数。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;


int n,m;
int a[110];
int main() {
    cin>>n>>m;
    for(int i = 1;i <= n;i++){
        cin>>a[i];
    }

    //求从每个数开始的连续m个数的和
    //最多循环到倒数第m个数才能保证有m个数
    int s;
    int ma = 0;//最大的和
    for(int i = 1;i <= n - m + 1;i++){
        //求连续m个数的和
        s = 0;
        for(int j = i;j <= i + m - 1;j++){
            s = s + a[j];
        }

        if(s > ma){
            ma = s;
        }
    }

    cout<<fixed<<setprecision(2)<<ma * 1.0 / m;
    return 0;
}
