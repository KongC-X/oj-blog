1837 - 报时助手

题目描述

给定当前的时间，请用英文的读法将它读出来。

时间用时 hhh 和分 mmm 表示，在英文的读法中，读一个时间的方法是：

如果 mmm 为 000 ，则将时读出来，然后加上 “o′clock”“o'clock”“o′clock” ，如 3:003:003:00 读作 “threeo′clock”“three o'clock”“threeo′clock” 。

如果 mmm 不为 000 ，则将时读出来，然后将分读出来，如5:305:305:30 读作 “five“five“five thirty”thirty”thirty” 。

时和分的读法使用的是英文数字的读法，其中 0∼200 \sim 200∼20 读作：

0:zero,1:one,2:two,3:three,4:four,5:five,6:six,7:seven,8:eight,9:nine,10:ten,11:eleven,12:twelve,13:thirteen,14:fourteen,15:fifteen,16:sixteen,17:seventeen,18:eighteen,19:nineteen,20:twenty0:zero, 1: one, 2:two, 3:three, 4:four, 5:five, 6:six, 7:seven, 8:eight, 9:nine, 10:ten, 11:eleven, 12:twelve, 13:thirteen, 14:fourteen, 15:fifteen, 16:sixteen, 17:seventeen, 18:eighteen, 19:nineteen, 20:twenty0:zero,1:one,2:two,3:three,4:four,5:five,6:six,7:seven,8:eight,9:nine,10:ten,11:eleven,12:twelve,13:thirteen,14:fourteen,15:fifteen,16:sixteen,17:seventeen,18:eighteen,19:nineteen,20:twenty 。

303030 读作 thirtythirtythirty ，404040 读作 fortyfortyforty ， 505050 读作fiftyfiftyfifty 。

对于大于 202020 小于 606060 的数字，首先读整十的数，然后再加上个位数。如 313131 首先读 303030 再加 111 的读法，读作“thirty“thirty“thirty one”one”one” 。

按上面的规则 21:5421:5421:54 读作 “twenty“twenty“twenty oneoneone fiftyfiftyfifty four”four”four”， 9:079:079:07 读作 “nine“nine“nine seven”seven”seven” ， 0:150:150:15 读作 “zero“zero“zero fifteen”fifteen”fifteen” 。

输入

输入包含两个非负整数 hhh 和 mmm ，表示时间的时和分。非零的数字前没有前导 000 。hhh 小于 242424 ，mmm 小于 606060 。

输出

输出时间时刻的英文。

#include<bits/stdc++.h>
using namespace std;
string a[21]={"zero", "one" ,"two", "three", "four" ,"five", "six", "seven" ,"eight" ,"nine" ,"ten", "eleven" ,"twelve" ,"thirteen", "fourteen" ,"fifteen", "sixteen" ,"seventeen" ,"eighteen" ,"nineteen" ,"twenty"};
string b[6]={"","","twenty","thirty","forty","fifty"};
int main(){
    int h,m;
    cin>>h>>m;
    //小于20小时 
    if(h<=20){
        cout<<a[h];
    }else{
        cout<<b[h/10]<<" "<<a[h%10];
    }
     
    if(m==0){
        cout<<" o'clock";
    }else{
        if(m<=20){
            cout<<" "<<a[m];
        }else{
            if(m%10==0)
            {
                cout<<" "<<b[m/10];
            }
            else
            {
                cout<<" "<<b[m/10]<<" "<<a[m%10];
            }
        }
    }
    return 0;
}
