1334 - 扑克牌组合

题目描述

小明从一副扑克牌中（没有大小王， JJJ 认为是数字 111111 ， QQQ 是 121212 ， KKK 是 131313 ， AAA 是 111 ）抽出 222 张牌求和，请问能够组合出多少个不相等的数，按照由小到大输出这些数。（5.1.98）

输入

第一行是一个整数 nnn 代表（ n≤52n \le 52n≤52 ）扑克牌的总数量；

第二行的 nnn 个整数分别代表扑克牌的数值。

输出

第一行是一个整数 mmm 代表组合出不相等的数字个数；

第二行 mmm 个数用空格隔开代表这 mmm 个由小到大排序的不相等的数。

解题思路

AC代码

AC代码

#include<iostream>
using namespace std;
int a[62]; // 存储数组
int b[30]; // 计数数组
int main() {
    int n,i,j,s = 0;
    cin >> n;
    for(i = 0; i < n; i++) {
        cin >> a[i];
    }
    for(i = 0; i < n; i++) {
        for(j = i + 1; j < n; j++) {
            b[a[i] + a[j]]++;
        }
    }
    for(i = 0; i <= 26; i++) {
        if(b[i] != 0) {
            s++;
        }
    }
    cout << s << endl;
    // 因为是相加，所以最大是13+13=26
    for(i = 2; i <= 26; i++) {
        if(b[i] != 0) {
            cout << i << " ";
        }
    }
}
