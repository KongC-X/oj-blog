1234 - 任意输入一正整数N，要求把它拆成质因子的乘积。

题目描述

任意输入一正整数 $N$，求出它的所有质因子。如：$10＝（2 \times 5）$ ； $20＝（2 \times 2 \times 5）$ ，并求出该整数 $N$ 有多少个质因子。

输入

输入只有一行，包括 $1$ 个整数 $n（n≤10^5）$ 。

输出

输出第 $1$ 行，按题目要求的格式输出 $n$ 的质因子。

第 $2$ 行，输出 $n$ 的质因子的数量。

AC代码

AC代码

//teacher Yu 
#include <iostream>
using namespace std;
int main (){
    int n,cnt=0;
    cin>>n;
    int t=2;//从2开始判断是否为因子 
    while(n!=1){
        while(n%t==0){//只要当前t为因子，那么循环重复判断 
            cout<<t<<" ";
            n/=t;
            cnt++;
        }
        t++;
        //内层while循环结束后，说明当前t已经不能整除了，那么继续判断下一个数字 
    }
    cout<<endl<<cnt;
    return 0;
}
