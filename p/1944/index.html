1944 - 集合 Subset Sums

题目描述

对于从 111 ∼ nnn 的连续整数集合，能划分成两个子集合，且保证每个集合的数字和是相等的。举个例子，如果 nnn=333，对于{111,222,333} 能划分成两个子集合，每个子集合的所有数字和是相等的：

{333} 和 {1,21,21,2} 是唯一一种分法（交换集合位置被认为是同一种划分方案，因此不会增加划分方案总数）

如果 n=7n=7n=7，有四种方法能划分集合{1,2,3,4,5,6,71,2,3,4,5,6,71,2,3,4,5,6,7}，每一种分法的子集合各数字和是相等的:

1,6,7{1,6,7}1,6,7 和 2,3,4,5{2,3,4,5}2,3,4,5

2,5,7{2,5,7}2,5,7 和 1,3,4,6{1,3,4,6}1,3,4,6

3,4,7{3,4,7}3,4,7 和 1,2,5,6{1,2,5,6}1,2,5,6

1,2,4,7{1,2,4,7}1,2,4,7 和 3,5,6{3,5,6}3,5,6

给出nnn，你的程序应该输出划分方案总数。

输入

输入文件只有一行，且只有一个整数 nnn

输出

输出划分方案总数。

AC代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;

    // ---- 问题转化 ----
    // 将 1..n 划分成两个和相等的子集，即选取若干个数使其和为总和 S 的一半。
    // 如果总和 S 是奇数，不可能平分，直接输出 0。
    // 否则，问题变为：从 n 个数字中选出一些，使它们的和恰为 T = S/2 的方案数。
    // 这是典型的 0/1 背包计数问题（子集和计数）。

    int S = n * (n + 1) / 2;         // 1~n 的和
    if (S % 2 != 0) {
        cout << 0 << '\n';
        return 0;
    }

    int T = S / 2;                   // 每个子集的目标和

    // ---- DP 数组定义与初始化 ----
    // dp[j] 表示从当前已考虑的数中选出若干个数，和为 j 的方案数。
    // 初始状态：不选任何数时，和为 0 有一种方案（空集），其余方案数为 0。
    long long dp[800] = {0};         // T 最大为 39*40/4 = 390，开 800 足够
    dp[0] = 1;

    // ---- 0/1 背包计数 ----
    // 依次考虑每个数 i（1..n），倒序更新 dp[j]，保证每个数只用一次。
    // 转移方程：dp[j] = dp[j] + dp[j - i]
    // 含义：和为 j 的方案，可以是不选 i（继承原来的 dp[j]），
    //       也可以是选 i（之前和为 j-i 的方案数加上 i）。
    for (int i = 1; i <= n; i++) {
        for (int j = T; j >= i; j--) {
            dp[j] += dp[j - i];
        }
    }

    // ---- 答案计算 ----
    // dp[T] 是选取和为 T 的子集方案总数。
    // 但每个子集划分 (A, B) 会被计数两次（A 被选为和为 T 的子集，B 也是）。
    // 因为所有数字互异且 T>0，子集 A 和它的补集 B 不会相同，直接除以 2 即可。
    long long ans = dp[T] / 2;
    cout << ans << '\n';

    return 0;
}
