1160 - 打折优惠

题目描述

商场周末大优惠，规定凡购物超过 100100100 元时，超过 100100100 元那部分便可打 999 折。

小雄同妈妈一起购买了一大批物品，你能帮他算出最终的应付款吗？

输入

第一行一个整数 NNN ，表示所买物品的个数。 （N≤100N \le 100N≤100）

第二行 NNN 个空格隔开的整数，表示 NNN 件物品要付的元数。

输出

最终的应付款。（保留两位小数）

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    int n,a[110],i;
    double s = 0;
    cin>>n;
    for(i=1; i<=n; i++){
        cin>>a[i];
        s = s + a[i]; 
    }
    if(s>100){
        s = 100 + (s - 100)*0.9;
    }
    cout<<fixed<<setprecision(2)<<s;
    return 0;
}
