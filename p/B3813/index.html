B3813 [语言月赛 202308] 四个人的排名加起来没有小粉兔高

洛谷 | 入门 | C++14 | 提交时间: 2026-08-16

算法标签：2023、O2优化、分支结构、语言月赛

题目背景

众所周知，洛谷著名管理员品客瑞比特选手在 NOI2020 中以第 515151 名的成绩获得了金牌并进入国家集训队。这常带来一个有趣的事实：清华大学一些四人寝室四个人的 NOI 排名加起来还没有小粉兔高。

题目描述

又是一年 NOI 结束了。小 A，小 B，小 C 和小 D 作为正式选手，在 NOI3202排名分别是第 aaa 名，第 bbb 名，第 ccc 名和第 ddd 名。

现在，小 A，小 B，小 C 和小 D 都被保送到清华大学，并住进同一间寝室。

如果四个人的 NOI 排名之和小于 515151，则我们称『四个人的排名加起来没有小粉兔高』；反之，如果四个人的 NOI 排名之和大于或等于 515151，我们称『四个人的排名加起来不比小粉兔低』。

现在，扶苏知道了四个人的 NOI 排名，她想请你判断是否『四个人的排名加起来没有小粉兔高』。

输入格式

输入只有一行四个整数，依次表示四个人的 NOI 排名 a,b,c,da,b,c,da,b,c,d。

输出格式

输出一行一个字符串表示答案：

  • 如果『四个人的排名加起来没有小粉兔高』，输出 Rabbit wins。
  • 如果『四个人的排名加起来不比小粉兔低』，输出 Rabbit lose。

样例

样例输入 #1

1 2 3 4```

**样例输出 #1**

Rabbit wins```

样例输入 #2

1 1 5 4```

**样例输出 #2**

Rabbit wins```

样例输入 #3

50 49 48 47```

**样例输出 #3**

Rabbit lose```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3813 [语言月赛 202308] 四个人的排名加起来没有小粉兔高
     * 题意：给定四个人的NOI排名，若总和小于51，输出 "Rabbit wins"，
     *       否则输出 "Rabbit lose"。
     */
    int a, b, c, d;
    cin >> a >> b >> c >> d;
    int sum = a + b + c + d;
    if (sum < 51) {
        cout << "Rabbit wins" << endl;
    } else {
        cout << "Rabbit lose" << endl;
    }
    return 0;
}
