P3131 [USACO16JAN] Subsequences Summing to Sevens S

洛谷 | 普及- | C++14 | 提交时间: 2026-07-23

算法标签：动态规划 DP、2016、USACO、前缀和

题目描述

Farmer John's NNN cows are standing in a row, as they have a tendency to do from time to time. Each cow is labeled with a distinct integer ID number so FJ can tell them apart. FJ would like to take a photo of a contiguous group of cows but, due to a traumatic childhood incident involving the numbers 1…61 \ldots 61…6, he only wants to take a picture of a group of cows if their IDs add up to a multiple of 7.

Please help FJ determine the size of the largest group he can photograph.

输入格式

The first line of input contains NNN (1≤N≤50,0001 \leq N \leq 50,0001≤N≤50,000). The next NNN lines each contain the NNN integer IDs of the cows (all are in the range 0…1,000,0000 \ldots 1,000,0000…1,000,000).

输出格式

Please output the number of cows in the largest consecutive group whose IDs sum to a multiple of 7. If no such group exists, output 0.

样例

样例输入 #1

7
3
5
1
6
2
14
10```

**样例输出 #1**

5```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 求最长的连续子数组，使得子数组的和是7的倍数。
    // 利用前缀和模7的余数：子数组[l, r]的和是7的倍数
    // 等价于 (前缀和[r] - 前缀和[l-1]) % 7 == 0，
    // 即 前缀和[r] % 7 == 前缀和[l-1] % 7。
    // 因此只需记录每个余数第一次出现的位置，遍历时用当前位置减去第一次位置更新答案。

    int n;                    // n: 奶牛数量
    cin >> n;

    int f[7];                 // f[k]: 余数 k 第一次出现的位置（下标从0开始，0表示还未出现）
    for (int i = 0; i < 7; i++) f[i] = -1;
    f[0] = 0;                 // 前缀和为0（还未选任何牛）在位置0出现

    int s = 0;                // 当前前缀和模7的余数
    int ans = 0;              // 最大连续奶牛数量

    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        s = (s + x) % 7;      // 更新前缀和模7

        if (f[s] == -1) {     // 该余数第一次出现，记录位置
            f[s] = i;
        } else {
            // 之前出现过相同的余数，计算区间长度，更新答案
            int len = i - f[s];
            if (len > ans) ans = len;
        }
    }

    cout << ans << endl;
    return 0;
}
