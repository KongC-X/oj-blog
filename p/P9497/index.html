P9497 「RiOI-2」weight

P9497 「RiOI-2」weight

洛谷 | 普及- | C++14 | 提交时间: 2026-08-04

算法标签：贪心、二分、洛谷原创、O2优化、排序、洛谷月赛

题目背景

在小树林间坐落着一个幻想的城堡。这里是 E 国的领地，而小 E，则是 E 国之王。

树木，是 E 国抵挡袭击的法宝。树木越高，越能蒙蔽敌人的视线。

可是，随着自然条件的退化，小 E 却不知怎么处理。怎么办呢？

题目描述

给定一个 nnn 行 nnn 列 的矩阵 aaa。

有 qqq 组询问，每次给定一个 vvv，请将矩阵每一行任意重排（可以不重排），最大化最大值不小于 vvv（也就是说，至少有一个不小于 vvv 的数）的列数。请输出这个列数。

询问之间相互独立。换言之，每次询问前可以重新排列。

输入格式

第一行两个正整数 n,qn, qn,q。

第 2∼n+12\sim n+12∼n+1 行，每行 nnn 个正整数，表示矩阵 aaa。

接下来 qqq 行每行一个正整数 vvv，表示一次询问。

输出格式

对于每次询问，输出一行一个整数表示答案。

样例

样例输入 #1

3 3
9 9 8
2 4 4
3 5 3
5
9
10```

**样例输出 #1**

3
2
0```

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 结构体：存储一个询问的数据
struct Query {
    int v;      // 询问的值 v
    int id;     // 这个询问是第几个（原始顺序）
};

// 比较函数：用于将询问按 v 从大到小排序
bool cmp(Query a, Query b) {
    return a.v > b.v;   // 返回 true 表示 a 应该排在 b 前面
}

// 全局数组：最多 n*n = 1000*1000 = 1e6 个元素
int all[1000005];

// 全局数组：最多 q = 5e5 个询问
Query qs[500005];

int main() {
    /*
     * 【题目类型】离线 + 排序 + 扫描
     * 【核心思路】
     * 1. 把所有矩阵元素放在 all 数组里，按值从大到小排序。
     * 2. 把所有询问按 v 从大到小排序，同时记住每个询问原来的编号。
     * 3. 用一个指针 p 从 all 数组开头向后扫。
     *    对于当前询问 v，把 all 中所有 >= v 的元素都加进计数 sum。
     *    此时 sum 就是矩阵中 >= v 的元素总数。
     * 4. 答案 = min(n, sum)，因为最多只有 n 列。
     * 5. 最后按原始顺序输出答案。
     */

    int n, q;
    cin >> n >> q;

    int total = n * n;  // 矩阵元素总数

    // 读入矩阵，存入 all 数组
    for (int i = 0; i < total; i++) {
        cin >> all[i];
    }

    // 将 all 数组按值降序排序
    sort(all, all + total, greater<int>());

    // 读入 q 个询问
    for (int i = 0; i < q; i++) {
        cin >> qs[i].v;
        qs[i].id = i;   // 记录原始编号
    }

    // 将询问按 v 降序排序（使用自定义比较函数 cmp）
    sort(qs, qs + q, cmp);

    int ans[500005];   // 存放每个询问的答案（按原始编号）
    int sum = 0;       // sum: 当前已经统计的、>= 当前 v 的元素个数
    int p = 0;         // p: all 数组中下一个待检查的位置

    // 按 v 从大到小依次处理每个询问
    for (int i = 0; i < q; i++) {
        int v = qs[i].v;
        int id = qs[i].id;

        // 把 all 中所有 >= v 的元素都加进来
        while (p < total && all[p] >= v) {
            sum++;
            p++;
        }

        // 最多只能有 n 列，所以答案不能超过 n
        ans[id] = (sum < n) ? sum : n;
    }

    // 按原始顺序输出答案
    for (int i = 0; i < q; i++) {
        cout << ans[i] << endl;
    }

    return 0;
}
