1562 - 加数

题目描述

给出一个正整数n（1≤n≤100000）。在n的右边加入n的一半，然后在新数的右边再加入n的一半的一半，一直进行，直到不能再加为止。

例如  n=37         37的一半为18（取整数）加到n的右边成为

        3718         18的一半为9，加到新数的右边成为

        37189        9的一半为4，加到新数的右边成为

        371894       4的一半为2，加到新数的右边成为

        3718942      2的一半为1，加到新数的右边成为

        37189421     1的一半为0，加数结束，最后得到的数是一个8位的数

输入

整数n

输出

加数结束后新数的长度。

AC代码

AC代码

#include <iostream>
using namespace std;

// 计算数字 x 的位数
int cnt(int x) {
    int res = 0;
    while (x) {
        x /= 10;
        res++;
    }
    return res;
}

int main() {
    int n;
    cin >> n;

    int ans = cnt(n);  // 先加上初始数字 n 的位数

    // 不断除以2，直到为0
    while (n / 2 > 0) {
        n /= 2;
        ans += cnt(n);
    }

    cout << ans << endl;
    return 0;
}
