6321 - 棋盘上的奖赏

题目描述

相传古印度舍罕王为了奖赏宰相西萨发明国际象棋，西萨提的任何要求舍罕王都愿意满足。西萨只求在棋盘第 111 格放 111 粒麦子，第 222 格放 222 粒麦子，之后每一格都放前一格两倍的麦子，以此类推直到第 646464 格。国王觉得这奖赏微不足道，立刻命人取粮。

然而麦子的数量飞速增长：到第 202020 格已需上百万粒，到第 404040 格就耗尽了全国库存，而后面仍有 242424 格。最终国王发现，即便倾尽天下粮食也填不满棋盘。

聪明的你知道前 nnn 格总共需要多少粒麦子吗？

输入

一行，一个整数 nnn。

输出

一行，一个整数，表示前 nnn 格总共需要的麦子粒数。

AC代码

#include<iostream>
using namespace std;
int main(){
    long long i,n,sum=0,f=1;
    cin>>n;
    for(i=1;i<=n;i++){
        sum=sum+f;
        f=f*2;
    }
    cout<<sum;
}
