B4278 [蓝桥杯青少年组国赛 2023] 简单算术题

洛谷 | 普及- | C++14 | 提交时间: 2026-08-17

算法标签：字符串、2023、栈、蓝桥杯青少年组

题目描述

给定一道没有括号的四则混合运算算术题（可能包含多余的空格），请编程计算出结果。运算规则如下：

  1. 既有乘、除法又有加、减法的，要先算乘除法，再算加减法；
  2. 同级运算时，要从左往右按顺序计算；
  3. 所有除法运算的结果都只保留整数部分（直接舍弃小数部分）。

例如：当算术题为 $\tt{2 + 34 - 10/6 + 1/24}$ 时：

  • 优先计算乘除法，有 $\tt{34=12}$，$\tt{10/6=1}$，$\tt{1/24=0}$；
  • 然后计算加减法，$\tt{2+34-10/6+1/24} = \tt{2+12-1+0} = \tt{13}$，故输出 $13$。

输入格式

输入一个字符串，表示算术题：

  • 字符串长度 $5 \leq$ 长度 $\leq 100000$；
  • 字符串中只包含数字字符以及 $\tt{+}$，$\tt{-}$，$\tt{*}$，$\tt{/}$ 运算符；
  • 不含括号，可能包含空格；
  • 算式中的运算数范围：$1 \leq$ 运算数 $\leq 200$。

输出格式

输出一个整数，表示算术题的计算结果。题目数据保证算式的每一步运算的结果都在 $-2 \times 10^9 \sim 2 \times 10^9$ 之间。

样例

样例输入 #1

2+3*4-10/6+1/2*4```

**样例输出 #1**

13```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * ======================================================================
     * 题目：B4278 [蓝桥杯青少年组国赛 2023] 简单算术题
     * 题意：计算无括号四则运算，先乘除后加减，同级从左到右，除法向零取整。
     *
     * 算法：用栈保存待加的数（带符号），遇到乘除时弹出栈顶立即计算。
     * 步骤：
     *   1. 去除表达式中的空格。
     *   2. 解析第一个数，压入栈 st。
     *   3. 从左到右扫描后续运算符和数字：
     *      - 遇到 '+' 或 '-'：将当前数字（带符号）压入栈。
     *      - 遇到 '*' 或 '/'：弹出栈顶数，与当前数字进行乘除，结果压回栈顶。
     *   4. 最后栈中所有数相加即为结果。
     *
     * 为什么用栈？
     *   因为乘除优先级高，必须先算。当遇到乘除时，它只影响它左边的那个数，
     *   所以从左到右扫描时，遇到乘除就立即取出左边的数（栈顶）计算，再放回去。
     *   而加减只是把数（带符号）存起来，等所有乘除算完后再统一求和。
     *
     * 变量说明：
     *   s: 原始字符串（去空格后）
     *   st: 栈，存储待相加的数（带符号）
     *   n: 字符串长度
     *   i: 当前扫描位置
     *   x: 临时解析的数字
     *   op: 当前运算符
     *   ans: 最终答案
     *
     * 时间复杂度：O(|s|)
     * ======================================================================
     */
    string s;
    getline(cin, s);   // 读取可能包含空格的整行

    // 去除空格
    string t;
    for (int i = 0; i < (int)s.size(); i++) {
        if (s[i] != ' ') t.push_back(s[i]);
    }
    s = t;

    stack<long long> st;   // 用 stack 存储待相加的数
    int n = s.size();
    int i = 0;

    // 解析第一个数
    long long x = 0;
    while (i < n && s[i] >= '0' && s[i] <= '9') {
        x = x * 10 + (s[i] - '0');
        i++;
    }
    st.push(x);

    // 扫描后续运算符和数字
    while (i < n) {
        char op = s[i++];   // 读取运算符
        x = 0;
        while (i < n && s[i] >= '0' && s[i] <= '9') {
            x = x * 10 + (s[i] - '0');
            i++;
        }

        if (op == '+' || op == '-') {
            // 加减号：将数（带符号）压入栈，留到最后求和
            if (op == '+') st.push(x);
            else st.push(-x);
        } else if (op == '*') {
            // 乘法：弹出栈顶，乘当前数，结果压回
            long long a = st.top();
            st.pop();
            st.push(a * x);
        } else if (op == '/') {
            // 除法：弹出栈顶，除以当前数（向零取整），结果压回
            long long a = st.top();
            st.pop();
            st.push(a / x);   // C++ 整数除法向零取整，符合要求
        }
    }

    // 对栈中所有数求和（逐个弹出）
    long long ans = 0;
    while (!st.empty()) {
        ans += st.top();
        st.pop();
    }
    cout << ans << endl;

    return 0;
}
