P1009 [NOIP 1998 普及组] 阶乘之和

洛谷 | 普及- | C++14 | 提交时间: 2025-08-11

算法标签：数学、高精度、1998、NOIP 普及组

题目描述

用高精度计算出 S=1!+2!+3!+⋯+n!S = 1! + 2! + 3! + \cdots + n!S=1!+2!+3!+⋯+n!（n≤50n \le 50n≤50）。

其中 ! 表示阶乘，定义为 n!=n×(n−1)×(n−2)×⋯×1n!=n\times (n-1)\times (n-2)\times \cdots \times 1n!=n×(n−1)×(n−2)×⋯×1。例如，5!=5×4×3×2×1=1205! = 5 \times 4 \times 3 \times 2 \times 1=1205!=5×4×3×2×1=120。

输出格式

一个正整数 SSS，表示计算结果。

样例

样例输入 #1

3

样例输出 #1

9```

## AC 代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int a[1000] = {1};
// k代表a数组中元素的个数，代表2的n次方高精度的整数位数
// k2代表了高精度的总和的位数
int r[1000];
int n,i,j,k = 1,k2 = 1,len;
int main() {
    cin >> n;
    // 第一层循环是这个数要乘多少次
    for(i = 1; i <= n; i++) {
        // 第二层是每次有几位要乘
        for(j = 0;j < k;j++) {
            a[j] = a[j] * i;
        }
        // 处理进位
        for(j = 0;j < k + 2;j++) {
            if(a[j] >= 10) {
                a[j + 1] += a[j] / 10;
                a[j] = a[j] % 10;
            }
        }
        // 判断a数组是否多出一位还是两位
        if(a[k + 1] != 0) {
            k += 2;
        } else if(a[k] != 0) {
            k++;
        }
        
        // 求出了2的i次方，结果为k位
        // 将k位的2的i次方，加到k2位的总和r上
        len = k;
        if(k2 > k) len = k2;
        for(j = 0;j < len;j++) {
            r[j] += a[j];
            if(r[j] >= 10) {
                r[j + 1] += r[j] / 10;
                r[j] = r[j] % 10;
            }
        }
        // 判断r数组是否多了1位
        if(r[len] != 0) {
            len++;
        }
    }
    // 逆序输出
    for(i = len - 1;i >= 0;i--) {
        cout << r[i];
    }
}
