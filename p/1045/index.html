1045 - 判断能否构成三角形

题目描述

输入三个整数，表示 333 条线段的长度，判断这三条线段能否构成三角形。能构成就输出 Yes ，否则输出No 。

三角形的判断标准是：任意两边之和要大于第三边，比如有一个三角形的三条边分别为： 333 、 555 、777 ，这个三角形的三条边就满足 3+5>73 + 5 \gt 73+5>7 且 3+7>53 + 7 \gt 53+7>5 ，且 5+7>35 + 7 \gt 35+7>3，因此这三条边能够构成三角形；

再比如，一个三角形的三条边为 333 、 888 、 555 ，那么因为 3+53+53+5 不满足大于 888 ，就不能构成三角形。

输入

三个整数。

输出

Yes ororor No 。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;

int main(){
    //定义变量a,b,c表示三条边 
    int a,b,c;
    //输入3条边长 
    cin>>a>>b>>c;
    //如果任意两边之和大于第三边，就可以构成三角形 
    if(a+b>c && a+c>b && b+c>a){
        cout<<"Yes";
    }else{
        cout<<"No";
    }
    return 0;
}
