B3652 [语言月赛202208] 渡荆门送别

洛谷 | 入门 | C++14 | 提交时间: 2026-08-20

算法标签：2022、数组、语言月赛

题目背景

渡荆门送别

李白

渡远荆门外，来从楚国游。

山随平野尽，江入大荒流。

月下飞天镜，云生结海楼。

仍怜故乡水，万里送行舟。

题目描述

李白喜欢飞，也喜欢天鹅。

现在给出一排共 $n$ 只鹅的身高，李白想知道最高的鹅比其他所有鹅高多少、最矮的鹅比其他所有鹅矮多少。

请输出这两行信息。

输入格式

输入共两行。

第一行一个整数 $n$ 表示鹅的数目。

第二行共 $n$ 个整数 $a_i(i=1,2,3...n)$，表示第 $i$ 只鹅的身高。

输出格式

输出共两行。

第一行共 $n$ 个空格隔开的整数，第 $i$ 个整数表示序列中第 $i$ 只鹅比最高的那只鹅要矮多少。

第二行共 $n$ 个空格隔开的整数，第 $i$ 个整数表示序列中第 $i$ 只鹅比最矮的那只鹅要高多少。

样例

样例输入 #1

6
4 7 8 6 3 2```

**样例输出 #1**

4 1 0 2 5 6
2 5 6 4 1 0```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3652 [语言月赛202208] 渡荆门送别
     * 题意：给定 n 只鹅的身高，输出每只鹅比最高矮多少，比最矮高多少。
     * 思路：先读入所有身高，同时求出最大值和最小值，再分别输出差值。
     * 输出：每行末尾有空格不影响结果。
     */
    int n;
    scanf("%d", &n);
    long long a[1000005];
    long long mx = 0, mn = 4e18;

    for (int i = 0; i < n; i++) {
        scanf("%lld", &a[i]);
        if (a[i] > mx) mx = a[i];
        if (a[i] < mn) mn = a[i];
    }

    // 第一行：最高 - 每只鹅身高
    for (int i = 0; i < n; i++) {
        printf("%lld ", mx - a[i]);
    }
    printf("\n");

    // 第二行：每只鹅身高 - 最矮
    for (int i = 0; i < n; i++) {
        printf("%lld ", a[i] - mn);
    }
    printf("\n");

    return 0;
}
