P17011 [GESP202606 五级] 晚宴

洛谷 | 普及- | C++14 | 提交时间: 2026-06-30

算法标签：数学、枚举、最大公约数 gcd、2026、GESP

题目描述

小明去参加晚宴。晚宴中有 nnn 个菜肴，每个菜肴都有一个美味度，第 iii 个菜肴的美味度为 viv_ivi​。

晚宴规定小明只能恰好选取两道菜肴，并且这两道菜肴的美味度必须要互质（即最大公约数为 111）。

请帮助小明选取两道菜肴，使得两道菜肴美味度之和最大。

输入格式

输入 222 行，

第一行为一个正整数 nnn，表示菜肴的个数；

第二行为 nnn 个整数 v1,v2,⋯ ,vnv_1, v_2, \cdots, v_nv1​,v2​,⋯,vn​ 表示菜肴的美味度，整数之间以空格分隔。

输出格式

输出一个整数，表示两道互质菜肴美味度之和的最大值。

样例

样例输入 #1

5
3 5 7 35 105```

**样例输出 #1**

38```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;                         // n：菜肴个数
    cin >> n;
    int a[1005];                   // a：存储美味度，下标从0开始
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    // 思路：枚举所有菜肴对(i, j)，若美味度互质（gcd==1），则用它们的和更新答案。
    // 数据保证至少有一对互质，n ≤ 1000，双重循环O(n^2)完全可行。
    int ans = 0;                   // ans：最大美味度之和
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (__gcd(a[i], a[j]) == 1) {
                int sum = a[i] + a[j];
                if (sum > ans) ans = sum;
            }
        }
    }

    cout << ans << endl;
    return 0;
}
