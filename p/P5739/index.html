P5739 【深基7.例7】计算阶乘

洛谷 | 入门 | C++14 | 提交时间: 2025-08-07

题目描述

求 n!n!n!，也就是 1×2×3⋯×n1\times2\times3\dots\times n1×2×3⋯×n。

挑战：尝试不使用循环语句（for、while）完成这个任务。

输入格式

第一行输入一个正整数 nnn。

输出格式

输出一个正整数，表示 n!n!n!。

样例

样例输入 #1

3```

**样例输出 #1**

6```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int f(int x){
    if (x == 0)
        return 1;
    return f(x - 1) * x;
}

int n;

int main(){
    cin >> n;
    cout << f(n) << endl;
    return 0;
}
