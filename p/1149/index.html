1149 - 回文数个数

题目描述

一个正整数，正读和反读都相同的数为回文数。

例如 222222， 131131131， 244224422442， 370733707337073， 666，…\dots… 所有 111 位数都是回文数。

给出一个正整数 nnn （ 1≤n≤100001 \le n \le 100001≤n≤10000 ），求出 1,2,…,n1,2, \dots ,n1,2,…,n 之中（包括 111 和 nnn ）的回文数的个数。

输入

任意给定一个正整数 nnn （ 0<n≤100000 \lt n \le 100000<n≤10000 ）

输出

一个正整数，表示 [1,n][1,n][1,n] 之间的回文数的个数。

AC代码

AC代码

#include <iostream>
using namespace std;

// 倒数
int reverse(int n) {
    int s = 0;
    while(n != 0) {
        s = s * 10 + n % 10;
        n = n / 10;
    }
    return s;
}

int main(){
    int i,a,n,s,sum = 0;
    cin >> n;
    for(i = 1;i <= n;i++) {
        a = i;
        s = reverse(a);
        // 如果是回文数则相等
         if(s == i) {
            sum++;
        }
    }
    cout << sum << endl;
}
