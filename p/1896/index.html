1896 - 二分查找满足条件的数

题目描述

请在一个有序不递减的数组中（数组中的值有相等的值），采用二分查找，找到第 111 个大于或等于元素 xxx 的位置，如果不存在，请输出 -1。

请注意：本题要求出 qqq 个 xxx ，每个 xxx 在数组找到第 111 个大于或等于 xxx 的元素的位置。

比如有 666 个数，分别是：111 222 222 222 666 666，那么如果要求 333 个数：555 888 222，在数组中找到第 111 个大于或等于他们的位置，答案是：555 −1-1−1 222。

输入

第一行，一个整数 nnn，代表数组元素个数（n≤105n \le 10^5n≤105）

第二行，nnn 个整数，用空格隔开，代表数组的n个元素（1≤1 \le1≤数组元素的值≤108\le 10^8≤108）

第三行，一个整数 qqq，代表有要查询 qqq 个数（q≤105q \le 10^5q≤105）

第四行，qqq 个整数，用空格隔开，代表查询的数（1≤1 \le1≤要找的数≤108\le 10^8≤108）

输出

按题意输出位置或者 −1-1−1。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

const int N = 100100;
int a[N];
int n,q; // n个数，q次查询

int fun(int x) {
    int l = 1,r = n,mid;
    while(l <= r) {
        mid = (l + r) >> 1; // 右移运算符，相当于/2
        if(x < a[mid]) r = mid - 1;
        else if(x > a[mid]) l = mid + 1;
        else if(x == a[mid]) r = mid - 1;
    }
    if(a[l] >= x) return l;
    else return -1;
}

int main() {
    scanf("%d", &n);
    for(int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }
    scanf("%d", &q);
    int x;
    for(int i = 1; i <= q; i++) {
        scanf("%d", &x);
        // 求x在数组中首次出现的位置
        // cout << fun(x) << " ";
        printf("%d ", fun(x));
    }
}
