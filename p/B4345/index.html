B4345 [语言月赛 202506] 卷积画图

洛谷 | 入门 | C++14 | 提交时间: 2025-06-21

算法标签：2025、数组、语言月赛

题目描述

给定一张 n×mn \times mn×m 的画布（每个格子里有一个数字），以及一个 k×kk \times kk×k 的“模板”。我们要把这个模板放在画布的左上角，然后一点一点向右、向下移动。每次移动的时候，把模板里的数字和画布上对应的数字相乘，然后加起来，得到一个新数字。这样，我们就会得到一张新的、稍小的画布。这个过程叫“卷积”。

例如，假设我们有这样一张 3×33 \times 33×3 的画布：

[123456789],\begin{bmatrix} 1 & 2 & 3 \\ 4 & 5 & 6 \\ 7 & 8 & 9 \end{bmatrix},​147​258​369​​,

及这样一张 2×22 \times 22×2 的模板：

[3215],\begin{bmatrix} 3 & 2\\ 1 & 5 \\ \end{bmatrix},[31​25​],

执行“卷积”后，我们可以得到以下结果：

[abcd]=[36476980],\begin{bmatrix} a & b \\ c & d \\ \end{bmatrix} = \begin{bmatrix} 36 & 47 \\ 69 & 80 \\ \end{bmatrix} ,[ac​bd​]=[3669​4780​],

其中：

现在给定画布和模板，请你算出卷积之后的画布内容。

输入格式

输入共 n+k+1n + k + 1n+k+1 行。

第一行三个整数 n,m,kn, m, kn,m,k，分别表示画布的大小和模板的大小；
接下来 nnn 行，每行 mmm 个整数，表示原始画布；
接下来 kkk 行，每行 kkk 个整数，表示模板内容。

输出格式

输出 n−k+1n - k + 1n−k+1 行，每行 m−k+1m - k + 1m−k+1 个整数，代表一张大小为 (n−k+1)×(m−k+1)(n - k + 1) \times (m - k + 1)(n−k+1)×(m−k+1) 的卷积结果。

AC 代码

#include <iostream>
using namespace std;

const int MAX = 105;
long long a[MAX][MAX], b[MAX][MAX];  // 使用long long防止溢出

int main() {
    int n, m, k;
    cin >> n >> m >> k;
    
    // 读取画布数据（0-based索引）
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> a[i][j];
        }
    }
    
    // 读取模板数据（0-based索引）
    for (int i = 0; i < k; i++) {
        for (int j = 0; j < k; j++) {
            cin >> b[i][j];
        }
    }
    
    // 计算并输出卷积结果
    for (int i = 0; i <= n - k; i++) {
        for (int j = 0; j <= m - k; j++) {
            long long sum = 0;  // 必须使用long long
            
            // 计算卷积
            for (int x = 0; x < k; x++) {
                for (int y = 0; y < k; y++) {
                    sum += a[i + x][j + y] * b[x][y];
                }
            }
            
            cout << sum;
            // 行内元素间加空格，行末不加空格
            if (j < m - k) {
                cout << " ";
            }
        }
        cout << endl;  // 每行结束换行
    }
    
    return 0;
}
