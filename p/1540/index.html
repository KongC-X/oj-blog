1540 - 小X数字母

题目描述

小 X 喜欢研究字符串。

这天，小 X 随手在草稿纸上写下了一个大写字母字符串。此时，班长把成绩报告单发到了每位同学的手中。小 X 看到自己每门都是 A （优秀），非常高兴，灵光一闪想到一个问题：
在刚刚写下的字符串中，字母 A 最多连续出现了多少次呢？

小 X 立刻数了起来，但这个字符串实在是太长了，希望你帮帮他。

输入

第一行包含一个整数 NNN ，表示字符串长度。

第二行包含一个字符串。

输出

第一行包含一个整数，表示该字符串中字母 A 最多连续出现的次数。

AC代码

AC代码

#include <iostream>
using namespace std;

int n,c,mx;
string s; // 输入的字符串
int main(){
    cin >> n;
    cin >> s; // getline(cin,s);
    for(int i = 0;i < s.size();i++) {
        // 如果是A则计数器+1
        if(s[i] == 'A') c++;
        if(i == s.size() - 1 || s[i + 1] != 'A') {
            if(c > mx) mx = c;
            c = 0;
        }
    }
    cout << mx << endl;
}
