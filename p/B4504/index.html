B4504 [语言月赛 202603] 优惠票

洛谷 | 入门 | C++14 | 提交时间: 2026-11-03

题目背景

错过比赛可以在入门赛结束后继续参加语言月赛同步赛，【赛后补题】也请从同步赛中进入：https://www.luogu.com.cn/contest/316039

题目描述

小 R 是一名在校大学生，她要购买火车票。

只有在乘车区间符合规定时才能购买学生优惠票。一学年内最多购买四次学生优惠票。

小 R 告诉你她本学年已经购买学生优惠票的次数，以及本次购买的乘车区间是否符合规定，请你判断她本次是否可以购买学生优惠票。

输入格式

一行两个整数 a,ba,ba,b。其中 aaa 表示小 R 本学年已经购买学生优惠票的次数，bbb 表示本次购买的乘车区间是否符合规定。b=1b=1b=1 表示乘车区间符合规定，b=0b=0b=0 表示乘车区间不符合规定。

输出格式

一行，一个字符串 Yes 或 No。如果本次可以购买学生优惠票，输出 Yes，否则输出 No。

样例

样例输入 #1

3 1```

**样例输出 #1**

Yes```

样例输入 #2

4 1```

**样例输出 #2**

No```

样例输入 #3

2 0```

**样例输出 #3**

No```

AC 代码

#include <iostream>
using namespace std;

int main() {
    int a, b;                   // a: 已购次数, b: 区间是否符合规定(1符合,0不符合)
    cin >> a >> b;

    // 可以购买的条件：已购次数小于4次，且乘车区间符合规定
    if (a < 4 && b == 1) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }

    return 0;
}
