B4076 [CSP-X2019 山东] 随机数

洛谷 | 入门 | C++14 | 提交时间: 2026-08-10

算法标签：2019、山东、CSP-X 小学组

题目描述

光头强和熊大熊二在玩随机数比大小的游戏。具体规则如下：平板电脑会提供三个 $1\sim 6$ 范围内的数字，分别交由熊大、熊二和光头强，数字大的人获胜。现在熊大和熊二已经拿到了随机数，请问光头强取得哪几个数字，才能获胜？

注意：如果光头强的数字与熊大熊二的数字相同，也算光头强获胜。

输入格式

一行，两个正整数 $x,y$，中间用空格隔开，表示熊大熊二的数字。

输出格式

一行，若干个整数，表示光头强的数字。按照从小到大的顺序输出，相邻的数之间用一个空格隔开。

样例

样例输入 #1

4 2```

**样例输出 #1**

4 5 6```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：简单判断
     * 思路：
     * 光头强要获胜，其数字必须不小于熊大和熊二中的最大值（相等也算获胜）。
     * 所以取 m = max(x, y)，输出 m 到 6 的所有整数。
     */
    int x, y;
    cin >> x >> y;
    int m = max(x, y);
    for (int i = m; i <= 6; i++) {
        cout << i << ' ';
    }
}
