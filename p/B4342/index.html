B4342 [语言月赛 202506] 火车优惠

洛谷 | 入门 | C++14 | 提交时间: 2025-06-21

算法标签：2025、循环结构、语言月赛

题目描述

小明准备坐火车旅行。这种火车票的价格规则有点特别：

  • 前 111 到 101010 公里，每公里 202020 元；
  • 超过 101010 公里但不超过 505050 公里的部分，每 555 公里 808080 元；
  • 超过 505050 公里的部分，每 101010 公里 120120120 元；
  • 在第二、第三条价格规则中，如果不满 555 公里或 101010 公里，也要算成 555 公里或 101010 公里来收费。

小明准备旅行 xxx 公里，他可以最多买两张票来覆盖它旅行的全程。如果他决定购买两张票，那么这两张票的距离可以不同，两张票的收费会分别基于它们的距离计算。

请你帮他计算，在他购买的一张或两张票的总距离不少于旅行的距离的前提下，最少需要花费多少元，才能完成他想要旅行的距离。

输入格式

输入一行一个整数 xxx，表示小明要旅行的总距离（单位：公里）。

输出格式

输出一行一个整数，表示最少需要花费多少元。

样例

样例输入 #1

63

样例输出 #1

1020

样例输入 #2

5

样例输出 #2

100

样例输入 #3

5000

样例输出 #3

60240

AC 代码

#include <iostream>
#include <climits>
#include <algorithm>
using namespace std;

long long cost(int d) {
    if (d == 0) 
        return 0;
    if (d <= 10) {
        return d * 20;
    } else if (d <= 50) {
        long long c = 200;
        int extra = d - 10;
        int blocks = (extra + 4) / 5;
        c += blocks * 80;
        return c;
    } else {
        long long c = 200 + 640;
        int extra = d - 50;
        int blocks = (extra + 9) / 10;
        c += blocks * 120;
        return c;
    }
}

int main() {
    int x;
    cin >> x;
    long long ans = LLONG_MAX;

    // 枚举第一张票的距离d1（0到x）
    for (int d1 = 0; d1 <= x; ++d1) {
        // 计算第二张票的最小距离（不小于0）
        int min_d2 = max(0, x - d1);
        
        // 枚举第二张票的距离d2（min_d2到x）
        for (int d2 = min_d2; d2 <= x; ++d2) {
            long long total_cost = cost(d1) + cost(d2);
            if (total_cost < ans) {
                ans = total_cost;
            }
        }
    }

    cout << ans << endl;
    return 0;
}
