6059 - 整数分类

题目描述

给定 $n$ 和 $t$，将 $1$ 到 $n$ 之间的所有正整数分为两类: A 类数可以被 $t$ 整除(也就是说是 $t$ 的倍数)，而B类数不能。

请输出这两类数的和。

输入

一行，两个正整数 $n$ 和 $t$。

输出

一行，两个正整数，分别表示 A 类数的和、B 类数的和，两者用空格间隔。

AC代码

#include <iostream>
using namespace std;

int main() {
    int n, t;
    cin >> n >> t;

    long long s1 = 0, s2 = 0;   // 用 long long 防止溢出
    for (int i = 1; i <= n; i++) {
        if (i % t == 0) {
            s1 += i;
        } else {
            s2 += i;
        }
    }
    cout << s1 << " " << s2 << '\n';
    return 0;
}
