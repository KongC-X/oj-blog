B4063 [GESP202412 一级] 奇数和偶数

洛谷 | 入门 | C++14 | 提交时间: 2025-03-28

算法标签：数学、2024、分支结构、循环结构、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1165

题目描述

小杨有 $n$ 个正整数，他想知道其中的奇数有多少个，偶数有多少个。

输入格式

第一行包含一个正整数 $n$，代表正整数个数。

之后 $n$ 行，每行包含一个正整数。

输出格式

输出两个正整数（英文空格间隔），代表奇数的个数和偶数的个数。如奇数或偶数的个数为 $0$，则对应输出 $0$。

样例

样例输入 #1

5
1
2
3
4
5```

**样例输出 #1**

3 2```

AC 代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;
int n,i,x,a,b;
int main() {
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> x;
        if(x % 2 == 1) {
            a++;
        } else {
            b++;
        }
    }
    cout << a << " " << b << endl;
}
