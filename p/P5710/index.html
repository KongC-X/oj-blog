P5710 【深基3.例2】数的性质

洛谷 | 入门 | C++14 | 提交时间: 2025-08-01

算法标签：模拟

题目描述

一些整数可能拥有以下的性质：

  • 性质 1：是偶数；
  • 性质 2：大于 444 且不大于 121212。

小 A 喜欢这两个性质同时成立的整数；Uim 喜欢这至少符合其中一种性质的整数；小 B 喜欢刚好有符合其中一个性质的整数；正妹喜欢不符合这两个性质的整数。现在给出一个整数 xxx，请问他们是否喜欢这个整数？

输入格式

输入一个整数 x(0≤x≤1000)x(0\le x \le 1000)x(0≤x≤1000)

输出格式

输出这 444 个人是否喜欢这个数字，如果喜欢则输出 1，否则输出 0，用空格分隔。输出顺序为：小 A、Uim、小 B、正妹。

样例

样例输入 #1

12```

**样例输出 #1**

1 1 0 0```

AC 代码

#include <iostream>
using namespace std;
int main() {
    int x; cin >> x;
    bool p1 = x%2 == 0, p2 = x>4 && x<=12;
    cout << (p1&&p2) << " " << (p1||p2) << " " << (p1!=p2) << " " << (!p1&&!p2);
    return 0;
}
