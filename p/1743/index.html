1743 - 五位回文偶数

题目描述

请求出 m∼nm \sim nm∼n 之间所有的 555 位回文偶数，有多少个，总和是多少？

回文偶数指的是既是回文数又是偶数的数，比如：23432、6686623432、6686623432、66866 等。

输入

两个整数 mmm 和 nnn 用空格隔开（m≤nm \le nm≤n，且 mmm 和 nnn 一定都是 555 位数）。

输出

第 111 行输出一个整数，代表 m∼nm \sim nm∼n之间的回文偶数有多少个。

第 222 行输出一个整数，代表 m∼nm \sim nm∼n 之间的回文偶数总和是多少

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    int m,n;
    cin>>m>>n;
    int i,sum=0,x=0;
    //遍历m~n之间所有的5位数 
    for(i=m;i<=n;i++){
        //万位等于个位，千位等于十位，且是个偶数 
        if(i%2==0&&i/10000==i%10&&i/1000%10==i%100/10){
            x++;//统计符合条件的数的个数 
            sum=sum+i;//对符合条件的数求和 
        }
    }
    cout<<x<<endl<<sum;
    return 0;
}
