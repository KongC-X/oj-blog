1164 - 字符统计

题目描述

输入一串小写字母(以.为结束标志)，统计出每个字母在该字符串中出现的次数(若某字母不出现，则不要输出)。

要求：每行输出 $5$ 项，每项以空格隔开。

输入

输入一行以 . 结束的字符串（字符串长度$≤105$）。

输出

输出相应小写字母的个数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int a[200];
char s[200];
int i,x;
int main(){
    cin>>s;
    for(i=0;i<strlen(s)-1;i++){
        a[s[i]]++;
    }
    char c;
    for(i=97;i<=122;i++){
        if(a[i]!=0){
            c=i; 
            cout<<c<<":"<<a[i];
            x++;
            if(x%5==0){
                cout<<endl;
            }
            else{
                cout<<" ";
            }
        }
    }
}
