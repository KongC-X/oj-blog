5945 - 建造

题目描述

小 AAA 有一张 MMM 行 NNN 列的地形图，其中第 iii 行第 jjj 列的数字 aija_{ij}aij​ 代表坐标 (i,ji,ji,j ) 的海拔高度。

停机坪为一个 3×33 \times 33×3 的区域且内部所有 999 个点的最大高度和最小高度之差不超过 HHH。

小 AAA 想请你计算出，在所有适合建造停机坪的区域中，区域内部 999 个点海拔之和最大是多少。

输入

第一行三个正整数 M,N,HM,N,HM,N,H，含义如题面所示。

之后 MMM 行，第 iii 行包含 NNN 个整数 ai1,ai2,...,aiNa_{i1},a_{i2},...,a_{iN}ai1​,ai2​,...,aiN​ ，代表坐标 (i,ji,ji,j ) 的高度。

数据保证总存在一个适合建造停机坪的区域。

输出

输出一行，代表最大的海拔之和。

AC代码

#include <iostream>
using namespace std;

int a[1010][1010];

int main() {
    int M, N, H;
    cin >> M >> N >> H;
    
    for (int i = 1; i <= M; ++i) {
        for (int j = 1; j <= N; ++j) {
            cin >> a[i][j];
        }
    }
    
    int max_sum = 0;  // 修改这里
    
    for (int i = 1; i <= M - 2; ++i) {
        for (int j = 1; j <= N - 2; ++j) {
            int local_max = a[i][j], local_min = a[i][j], local_sum = 0;
            
            for (int x = 0; x < 3; ++x) {
                for (int y = 0; y < 3; ++y) {
                    int height = a[i + x][j + y];
                    local_sum += height;
                    if (height > local_max) local_max = height;
                    if (height < local_min) local_min = height;
                }
            }
            
            if (local_max - local_min <= H) {
                if (local_sum > max_sum) {
                    max_sum = local_sum;
                }
            }
        }
    }
    
    cout << max_sum;
    return 0;
}
