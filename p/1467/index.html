1467 - 等比数

题目描述

将 111,222,333,444,555,666,777,888,999 共 999 个数分成 333 组，分别组成 333 个三位数，且使这 333 个三位数构成 1:2:31:2:31:2:3 的比例，试求出所有满足条件的 333 个三位数，按照从小到大输出。(1∼91 \sim 91∼9每一位数只出现一次)

比如：192192192 384384384 576576576 就是满足条件的第一组解。

输入

无

输出

若干行，每行 333 个数。按照从小到大输出每组解。

AC代码

AC代码

// 循环第1个数的可能范围，由于第2个数是第1个数的2倍，第3个数是第1个数的3倍，因此第1个数的范围最小是100，最大是333。
// 第1个数有了，第2个和第3个数就有了，将3个数组合成一个9位数，判断这个9位数各个位分别用到了数字1~9，那么这3个数就是符合条件的数。

#include<bits/stdc++.h>
using namespace std;

int main() {
    int x,y,z;
    //第1个3位数 
    for(int i = 100;i <= 333;i++){
        x = 2 * i;//第2个 
        y = 3 * i;//第3个 
        z = i * 1000000 + x * 1000 + y;//9位数
        
        //如果z用到了1~9的每个数
        int a[10] = {0};
        while(z != 0){
            a[z % 10]++;
            z = z / 10;
        } 
        
        //判断1~9是否出现了一次
        bool f = true;//假设都出现了一次
        for(int j = 1;j <= 9;j++){
            if(a[j] != 1){
                f = false;
                break;
            }
        } 
        
        if(f == true){
            cout<<i<<" "<<x<<" "<<y<<endl;
        }
    }
    return 0;
}
