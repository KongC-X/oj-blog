P1029 [NOIP 2001 普及组] 最大公约数和最小公倍数问题

洛谷 | 普及- | C++14 | 提交时间: 2026-05-22

算法标签：数学、2001、NOIP 普及组、枚举、最大公约数 gcd

题目描述

输入两个正整数 x0,y0x_0, y_0x0​,y0​，求出满足下列条件的 P,QP, QP,Q 的个数：

  1. P,QP,QP,Q 是正整数。

  2. 要求 P,QP, QP,Q 以 x0x_0x0​ 为最大公约数，以 y0y_0y0​ 为最小公倍数。

试求：满足条件的所有可能的 P,QP, QP,Q 的个数。

输入格式

一行两个正整数 x0,y0x_0, y_0x0​,y0​。

输出格式

一行一个数，表示求出满足条件的 P,QP, QP,Q 的个数。

样例

样例输入 #1

3 60

样例输出 #1

4

AC 代码

#include <bits/stdc++.h>
using namespace std;
long long m, n, ans;

int main() {
    cin >> m >> n;
    if (m == n) ans--;          // 修正 i == n/i 时的重复计数
    n *= m;                     // 现在 n 存的是 P * Q

    // 枚举 P * Q 的所有因子 i（i 看作 P）
    for (long long i = 1; i * i <= n; i++) {
        if (n % i == 0 && __gcd(i, n / i) == m)
            ans += 2;           // 每一对符合条件的 (P,Q) 和 (Q,P) 各算一种
    }

    cout << ans;
    return 0;
}
