B4004 [GESP202406 三级] 寻找倍数

洛谷 | 普及- | C++14 | 提交时间: 2024-11-08

算法标签：数学、2024、枚举、数组、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1151

题目描述

小杨有一个包含 $n$ 个正整数的序列 $A=[a_1,a_2,\dots,a_n]$，他想知道是否存在 $i(1\leq i\leq n)$ 使得 $a_i$ 是序列 $A$ 中所有数的倍数。

输入格式

第一行包含一个正整数 $t$，代表测试用例组数。

接下来是 $t$ 组测试用例。对于每组测试用例，一共两行。

其中，第一行包含一个正整数 $n$；第二行包含 $n$ 个正整数，代表序列 $A$。

输出格式

对于每组测试用例，如果存在 $i(1\leq i\leq n)$ ，满足对于所有 $k(1\leq k\leq n)$ $a_i$ 是 $a_k$ 的倍数，输出 Yes，否则输出 No。

样例

样例输入 #1

2
3
1 2 4
5
1 2 3 4 5```

**样例输出 #1**

Yes
No```

AC 代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int n,m,i,j;
int a[100010];

int main() {
    cin >> m;
    for(i = 0;i < m;i++) {
        cin >> n;
        bool flag = true;
        for(j = 0;j < n;j++) cin >> a[j];
        sort(a,a+n);
        for(j = 0;j < n;j++) {
            if(a[n-1] % a[j] != 0) {
                flag = false;
                break;
            }
        }
        if(flag) cout << "Yes" << endl;
        else cout << "No" << endl;
    }
}
