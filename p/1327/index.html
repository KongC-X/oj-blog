1327 - 鲜花方阵

题目描述

光明小学艺术节快要来了，老师要求同学们布置一个 n×nn \times nn×n 的花盆方阵（ nnn 是奇数， n≤9n \le 9n≤9 ）；

如果 n=5n=5n=5 ，那么方阵的形状如下图所示：

如果 n=7n=7n=7 ，那么方阵的形状如下图所示：

请读入一个整数 nnn （奇数），输出如图所示的方阵，为了方便输出，用 111 表示黄色的花盆，000 表示红色花盆，输出时数字场宽设置为333 。

例如： n=5n=5n=5 ，那么实际要输出的方阵的结果如下：

n=7n=7n=7 ，那么实际要输出的方阵的结果如下：

（ 4.2.14.2.14.2.1 ）

输入

一个整数 nnn

输出

如图所示的图形

解题思路

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    int a[10][10];
    int i, j, n;
    cin >> n;
    //赋初值
    for(i = 0; i < n; i++) {
        for(j = 0; j < n; j++) {
            a[i][j] = 1;
        }
    }

    //赋0
    for(i = 0; i <= n / 2; i++) {
        a[i][n / 2 - i] = 0;//上半部分左边的0
        a[i][n / 2 + i] = 0;//上半部分右边的0

        a[n - 1 - i][n / 2 - i] = 0;//下半部分左边的0
        a[n - 1 - i][n / 2 + i] = 0;//下半部分右边的0
    }
    a[n / 2][n / 2] = 0;//最中间的0

    for(i = 0; i < n; i++) {
        for(j = 0; j < n; j++) {
            cout << setw(3) << a[i][j];
        }
        cout << endl;
    }

    return 0;
}
