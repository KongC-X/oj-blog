1584 - 马里奥花银币

题目描述

马里奥有很多银币，他决定去集市逛逛，他想把自己金额最小的银币全部花光，金额最大的银币花掉 111 个，请你编程帮助马里奥计算一下，如果按照他的计划去消费，他花掉了多少钱，还剩多少钱？

比如：假设马里奥存有的银币金额分别为 888 555 222 888 222 444 ，那么按照他的计划消费之后，他会花掉 111 个金额为 888 的银币， 222 个金额为 222 的银币；因此，他总共花掉了金额为 8+2+28+2+28+2+2 = 121212 的银币，还剩金额为 171717 的银币。

输入

第一行是一个整数n代表马里奥有 nnn 个银币；（n≤1000n \le 1000n≤1000）

第二行有 nnn 个整数，用空格隔开，代表马里奥每个银币的金额。

输出

第一行输出马里奥花掉的银币金额；

第二行输出马里奥还剩的银币金额。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

/*
最小金额花光、最大金额花1个
消费 = 最小值 * 最小值个数 + 最大值 
1、求最大、最小数、总和 
2、求最小数有几个 
3、计算消费金额，剩余金额 
*/
//s:总和 c:最小数有几个 
int n,a[1010],ma = INT_MIN,mi = INT_MAX,s = 0,c = 0;
int main() {
    int i;
    cin>>n;
    for(i = 0;i < n;i++){
        cin>>a[i];
        s = s + a[i];//求和 
        if(a[i] > ma) ma = a[i];
        if(a[i] < mi) mi = a[i];
    } 
    
    //计算最小数的个数
    for(i = 0;i < n;i++){
        if(a[i] == mi){
            c++;
        }
    } 
    //输出消费金额 
    cout<<ma + mi * c<<endl;
    cout<<s - (ma + mi * c)<<endl;
}
