4978 - 幂和数

题目描述

对于正整数 nnn，如果 nnn 可以表为两个 222 的次幂之和，即 n=2x+2yn=2^{x}+2^{y}n=2x+2y （ x,yx,yx,y 均为非负整数），那么称 nnn 为幂和数。

给定正整数 l,rl,rl,r，请你求出满足 l≤n≤rl \le n \le rl≤n≤r 的整数 nnn 中有多少个幂和数。

输入

一行，两个正整数 l,rl,rl,r ，含义如上。

输出

输出一行，一个整数，表示 l,rl,rl,r 之间幂和数的数量。

AC代码

AC代码

#include <iostream>
using namespace std;
int main(){
    int l, r, a, b, n, cnt = 0;
    cin >> l >> r;
    a = 1;
    while(a<=r){
        b = a;
        while(b<=r) {
            n = a+b;
            if(n>=l && n<=r) cnt++;
            b *= 2;
        }
        a *= 2;
    }
    cout << cnt <<endl;
    return 0;
}
