1063 - 素数的个数

题目描述

编程求正整数 $M$ 与 $N$ 之间的所有素数的个数。（ $1 \le M \le N \le 30000$ ）

输入

输入只有一行，包括 $2$ 个整数 $M,N$ ，之间用一个空格分开。

输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int main(){
   int m,n,c,s=0,i,j;//s:素数的个数 
   cin>>m>>n;
   //m~n 范围内寻找
   for(i=m;i<=n;i++){
        //对每次循环的i进行判断是不是素数
        //每次判断i时，c=0
        c = 0; 
        //j:循环其实是 i可能的因子 
        for(j=2;j<=i-1;j++){
            if(i%j==0){
                c++;
                break;
            }
        } 
        //如果条件成立，那么当前的i就是素数 
        if(c==0 && i>=2){
            s++; 
        }   
   } 
   cout<<s;
    return 0;
}
