B4468 [山西编程未来星 2025] 符号选择 / opt

洛谷 | 入门 | C++14 | 提交时间: 2026-07-20

算法标签：2025、O2优化、排序、山西、数组、科创活动

题目描述

给定一个包含 nnn 个自然数的序列 x1,x2,...,xnx_1,x_2,...,x_nx1​,x2​,...,xn​。

现在要对序列中的每个数 xix_ixi​ 赋予一个正号（+xi+x_i+xi​）或负号（−xi-x_i−xi​），然后求和。

特别的，在 nnn 个数中，必须 恰好 有 kkk 个数使用正号，其余 n−kn-kn−k 个数使用负号。

求这种操作下，得到的 最大总和 是多少。

输入格式

第一行包含两个整数 nnn 和 kkk，分别表示序列的长度和必须选择加号的次数。

第二行包含 nnn 个自然数 x1,x2,...,xnx_1,x_2,...,x_nx1​,x2​,...,xn​，表示给定的序列，保证 x1≥x2≥...≥xnx_1\ge x_2\ge...\ge x_nx1​≥x2​≥...≥xn​。

输出格式

一行，包含一个整数，表示能够得到的最大总和。

样例

样例输入 #1

3 2
5 2 1```

**样例输出 #1**

6```

AC 代码

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100010;          // 最大 n 为 1e5，多开10
long long a[MAXN];                // 存储序列（降序）

int main() {
    int n, k;                     // n: 序列长度, k: 正号个数
    cin >> n >> k;

    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    // 题目虽然保证序列降序，但实际数据未遵守，因此主动排序确保降序
    sort(a + 1, a + n + 1, greater<long long>());

    // 要使总和最大，应将正号赋予最大的 k 个数，负号赋予剩余的数
    long long ans = 0;
    for (int i = 1; i <= k; i++) {
        ans += a[i];              // 正号：加
    }
    for (int i = k + 1; i <= n; i++) {
        ans -= a[i];              // 负号：减
    }

    cout << ans << endl;
    return 0;
}
