1791 - 火车编组

题目描述

货运火车要在编组站根据挂靠车厢到达目的地重新分组，如果一列火车有 444 节车厢，经过编组后，车厢的编组顺序为 3,2,4,13,2,4,13,2,4,1；您知道编组站是怎么编组的吗？

小明到编组站参观后发现编组站的铁路有很多岔道，火车在岔道上来来回回地开动，最后列车编组就完成了。小明想到学习过的栈操作，发现火车编组的过程就是由若干进栈，出栈操作构成的。于是小明编了一个程序，只要知道最后的编组要求，就能将编组方案输出。

比如，有 444 辆火车，初始的顺序是 111 222 333 444 ，最后编组的结果是 333 222 444 111，那么只需要准备一个栈，让这 444 辆火车按照：进栈、进栈、进栈、出站、出站、进栈、出站、出站的顺序进行栈的操作就可以得到 333 222 444 111 的编组结果。

输入

第 111 行 111 个正整数 nnn，n≤100n \le 100n≤100。

第 222 行 nnn 个小于或等于 nnn 的正整数，表示有 nnn 节车厢，编号为 1,2,3,…,n1,2,3, \dots ,n1,2,3,…,n ；编组时按照编号进栈，第 222 行表示列车经过编组后的车厢编号顺序；

输出

一行一个由大写字母 AAA 和 BBB 构成的字符串， AAA 表示进栈，BBB 表示出栈。表示编组时进栈出栈的操作序列；

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main(){
    stack<int> s;
    int n;
    cin>>n;
    int c=1;
    for(int i=1;i<=n;i++){         // 1 2 3 4
        int x;
        cin>>x;              // 3 2 4 1
        if(x>=c){          //假设输入的是3，就先将前三个数压入 结束后 开始弹出 
            while(x>=c){
                s.push(c);  //把c推进去栈 
                c++;       //计数器同步更新 
                cout<<"A"; 
            }
        }
        else{
            s.pop();
        } 
        cout<<"B";   //每一轮都得往外弹出元素 
    }
    return 0; 
}
