2090 - 片区划分

题目描述

A 市有 nnn 个村庄（村庄编号为 1∼n1 \sim n1∼n ），现准备将 nnn 个村庄划分为 kkk 个区（一个区中要有至少 111 个村庄），同一个区中的村庄要求有道路可以互相到达（不一定要直达，比如：A 村要去 C 村，可以先先去 B 村，再去 C 村）。

为了节约成本，在划分之前，相关规划部门调研了村庄之间修路的成本，本次调研，共调研到了 mmm 条道路的建设成本。

假设所有村庄之间目前没有任何道路，如果要将 nnn 个村庄划分为 kkk 个区，请求出最少的修路成本？

输入

第一行有三个数n,m,kn,m,kn,m,k(1≤n≤1000,1≤m≤10000,1≤k≤101≤n≤1000,1≤m≤10000,1≤k≤101≤n≤1000,1≤m≤10000,1≤k≤10)

接下来m行每行三个数 x,y,lx,y,lx,y,l，表示编号为 xxx 村到编号为 yyy 村修路的费用。()

测试数据保证 xxx 村到 yyy 村的道路只有 111 条。

输出

输出一个整数，代表最少的修路成本。

如果按照当前的调研数据，无法将 nnn个村庄划分为 kkk 个区，请输出No Answer。（比如，假设有 555 个村庄，只有 222 条道路的建设数据，是无法将 555 个村庄划分为 222 个区或者 111 个区的）。

AC代码

#include <bits/stdc++.h>
using namespace std;
 
/*
n个点，m个已知关系，要组成k个集合，最小代价是多少 
*/
struct node{
    int x,y,len;
}; 
 
node a[10010];
int f[1010];
int n,m,k;
 
bool cmp(node n1,node n2){
    return n1.len < n2.len;
}
 
int find(int x){
    return x == f[x]?x:f[x] = find(f[x]);
}
 
int main(){
    cin>>n>>m>>k;
    for(int i = 1;i <= m;i++){
        cin>>a[i].x>>a[i].y>>a[i].len;
    }
     
    sort(a+1,a+1+m,cmp);
     
    for(int i = 1;i <= n;i++){
        f[i] = i;
    }
     
    //修路
    int s = 0,c = 0;
    for(int i = 1;i <= m;i++){
        int fx = find(a[i].x);
        int fy = find(a[i].y);
        if(fx != fy){
            f[fx] = fy;
            c++;
            s = s + a[i].len;
        }
         
        if(c == n - k){
            cout<<s;
            return 0;
        }
    } 
     
    cout<<"No Answer";
    return 0;
}
