1372 - 活动选择

题目描述

学校在最近几天有 nnn（n≤100n≤100n≤100）个活动，这些活动都需要使用学校的大礼堂，在同一时间，礼堂只能被一个活动使。由于有些活动时间上有冲突，学校办公室人员只好让一些活动放弃使用礼堂而使用其他教室。

现在给出 nnn 个活动使用礼堂的起始时间 beginibegin_ibegini​ 和结束时间 endiend_iendi​ (beginibegin_ibegini​ endiend_iendi​)，请你帮助办公室人员安排一些活动来使用礼堂，要求安排的活动尽量多。请问最多可以安排多少活动？

请注意，开始时间和结束时间均指的是某个小时的 000 分 000 秒，如：333 555，指的是 3:003:003:00~5:005:005:00 ，因此 333 555 和 555 999 这两个时间段不算冲突的时间段。

输入

第一行一个整数 nnn (n≤100n≤100n≤100)。

接下来的 nnn 行，每行两个整数，第一个 beginibegin_ibegini​ ，第二个是 endiend_iendi​ (beginibegin_ibegini​ endiend_iendi​ ≤≤≤ 327673276732767)。

输出

输出最多能安排的活动数。

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

struct Node {
    int begin;
    int end;
}a[110];

bool cmp(Node a, Node b) {
    if(a.end < b.end) {
        return true;
    } else {
        return false;
    }
}

int main() {
    int i,j,n,c = 0,e;
    cin >> n;
    for (i = 0; i < n; i++) {
        cin >> a[i].begin >> a[i].end;
    }
    sort(a,a + n,cmp);
    c = 1; // 第一个活动必须选
    e = a[0].end;
    for(i = 1;i < n;i++) {
        if(a[i].begin >= e) {
            c++;
            e = a[i].end;
        }
    }
    cout << c << endl;
}
