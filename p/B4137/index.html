B4137 [信息与未来 2016] 幸运数字

洛谷 | 入门 | C++14 | 提交时间: 2026-04-11

算法标签：2016、江苏、枚举、信息与未来

题目描述

小明认为，如果以下条件之一成立，则正整数 $x$ 就是一个幸运数字：

  1. $x$ 是 $4$ 的倍数。
  2. $x$ 是 $7$ 的倍数。
  3. $x$ 转换为字符串后，包含子串 44 或 77。

例如，$105$（$7$ 的倍数）、$442$（包含44）、$1284$（$4$ 的倍数）都是幸运数字，而 $474$ 则不是。编程统计 $1$ 到 $n$ 中幸运数字的数量。

输入格式

一行，一个整数 $n$。

输出格式

一行，一个整数，$1,2,3,\dots n$ 中幸运数字的数量。

样例

样例输入 #1

32```

**样例输出 #1**

11```

样例输入 #2

987654```

**样例输出 #2**

406754```

AC 代码

#include <iostream>
#include <string>
using namespace std;

int main() {
    int n;
    cin >> n;
    int cnt = 0;
    for (int i = 1; i <= n; i++) {
        if (i % 4 == 0 || i % 7 == 0) {
            cnt++;
        } else {
            string s = to_string(i);
            if (s.find("44") != -1 || s.find("77") != -1) {
                cnt++;
            }
        }
    }
    cout << cnt << endl;
    return 0;
}
