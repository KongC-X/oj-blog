1445 - 找亲戚

题目描述

数字王国中，数字们也有亲戚关系。有一个 111 位数 xxx，他想找到自己的亲戚，他是这样判断对方是不是自己的亲戚的，如果对方的那个数的各个位中含有和自己一样的数，就认为对方是自己的亲戚。

比如： 333 和 635635635 就算亲戚，因为 635635635 中有数字 333 。

请从键盘读入一个一位的整数 xxx ，找出从 m∼nm \sim nm∼n 中有多少个数是 xxx 的亲戚。

输入

第一行，一个一位整数 x（xx（xx（x 是 1∼91\sim 91∼9 之间的整数）

第二行，两个整数 mmm 和 n（mn（mn（m 和 nnn 也是 0∼99990 \sim 99990∼9999之间的整数，且 m≤nm \le nm≤n）。

输出

一个整数，代表 xxx 的亲戚有多少个数。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main(){
    int i,x,m,n,a,s = 0;
    cin >> x >> m >> n;
    for(i = m;i <= n;i++) {
        a = i; // 不要直接使用i，否则会出现错误
        while(a != 0) {
            if(a % 10 == x) {
                s++;
                break;
            }
            a = a / 10;
        }
    }
    cout << s;
}
