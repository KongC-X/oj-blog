1811 - 买不买

题目描述

小明去超市买商品，已经买了 NNN 件，每件商品的价格都是整数，小明发现今天买的东西太多了，决定如果购买商品的总金额大于 100100100 元，就把最贵的商品放回去（如果有多个商品价格一样，且都是最贵的，只要放回一件就可以）。

请编程帮助小明计算一下，是否要放回一件商品，最终小明付了多少钱？

输入

第 111 行有一个整数 nnn （n≤100n \le 100n≤100）。

第 222 行有 nnn 个整数，用空格隔开。

输出

第 111 行输出小明是否需要放回最贵的商品，如果要放回，请输出Yes，否则请输出No。

第 222 行输出小明最终应该付款的金额。

解题思路

AC代码

AC代码

#include<iostream>
using namespace std;

int a[110],n,s = 0;

int main() {
    cin>>n;
    for(int i = 0;i < n;i++){
        cin>>a[i];
    }
    int max = a[0];
    for(int i = 0;i < n;i++){
        if(a[i] > max){
            max = a[i];
        }
        s += a[i];
    }
    if(s > 100) {
        cout << "Yes" << endl;
        cout << s - max;
    } else {
        cout << "No" << endl;
        cout << s;
    }
}
