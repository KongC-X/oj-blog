3859 - 平方之和

题目描述

小杨有 nnn 个正整数 a1,a2,...ana_1,a_2,...a_na1​,a2​,...an​ ，他想知道对于所有的 i(1≤i≤n)i (1 \le i \le n )i(1≤i≤n)，是否存在两个正整数 xxx 和 yyy 满足 x×x+y×y=aix \times x + y \times y=a_ix×x+y×y=ai​。

输入

第一行包含一个正整数 nnn ，代表正整数数量。

之后 nnn 行，每行包含一个正整数，代表 aia_iai​ 。

输出

对于每个正整数 aia_iai​，如果存在两个正整数 xxx 和 yyy 满足 x×x+y×y=aix \times x + y \times y=a_ix×x+y×y=ai​，输出 Yes，否则输出 No。

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n,i,j,a,k;
    bool flag = false;
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> a;
        flag = false;
        for(j = 1;j * j < a;j++) {
            for(k = 1;k * k < a;k++) {
                if(j * j + k * k == a) {
                    flag = true;
                }
            }
        }
        if(flag) {
            cout << "Yes" << endl;
        } else {
            cout << "No" << endl;
        }
    }
}
