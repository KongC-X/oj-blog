2249 - 含k个3的数

题目描述

输入两个正整数 mmm 和 kkk，其中 1<m<1000001 \lt m \lt 1000001<m<100000，1<k<51 \lt k \lt 51<k<5 ，判断 mmm 能否被 191919 整除，且恰好含有 kkk 个 333，如果满足条件，则输出 YES，否则，输出 NO。

例如，输入：438334383343833 333。满足条件，输出 YES。

如果输入：393313933139331 333。尽管有 333 个 333，但不能被 191919 整除，也不满足条件，应输出 NO 。

输入

mmm 和 kkk 的值，中间用单个空格间隔。

输出

满足条件时输出 YES，不满足时输出 NO。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int m,k,c=0;
    cin>>m>>k;
    if(m%19==0) {
        while(m!=0) {
            if(m%10==3) {
                c++;
            }
            m=m/10;
        }
        if(k==c) {
            cout<<"YES";
        } else {
            cout<<"NO";
        }
    } else {
        cout<<"NO";
    }
    return 0;
}
