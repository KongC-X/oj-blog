1413 - 切割绳子

题目描述

有 nnn 条绳子，每条绳子的长度已知且均为正整数。绳子可以以任意正整数长度切割，但不可以连接。现在要从这些绳子中切割出 mmm 条长度相同的绳段，求绳段的最大长度是多少。

输入

第一行是一个不超过 100100100 的正整数 nnn 。

第二行是 nnn 个不超过 10610^6106 的正整数，表示每条绳子的长度。

第三行是一个不超过 10810^8108 的正整数 mmm 。

输出

绳段的最大长度，若无法切割，输出 Failed。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

/*
思路：
1.从最长可能切出的长度（max(a[i])），逐个向下尝试（最小是1）
2.如果在长度为i的情况下能够切割出>=m根绳子，这个值i就是最大值
*/

int n,a[110],m,c;
int ma = INT_MIN;//ma代表最长的绳子的长度

int main() {
    cin>>n;
    for(int i = 1; i <= n; i++) {
        cin>>a[i];
        ma = max(ma,a[i]);
    }
    cin>>m;

    //从最长的绳子长度向下尝试，找到第1个满足条件的长度
    for(int i = ma; i >= 1; i--) {
        //计算在长度为i的情况下，能切割出多少根绳子
        c = 0;
        //循环所有绳子的长度
        for(int j = 1; j <= n; j++) {
            c = c + a[j] / i;

            //如果切割出来的绳子的数量>=m，找到解了
            if(c >= m) {
                cout<<i;
                return 0;//函数遇到return 0立刻结束
            }
        }
    }

    cout<<"Failed";
    return 0;
}
