B4471 [厦门小学生 C++ 2025] 数字糖果

洛谷 | 入门 | C++14 | 提交时间: 2026-07-20

算法标签：2025、数组、小学活动

题目描述

彩虹糖果机里装着 $ n $ 个糖，每个糖都印着一个 $ -500 $ 到 $ 500 $ 之间的整数 $ c_i $。

小精灵眨眼说：“要是印着某个数字的糖的个数‘超过一半’，我就把印着这个数字的糖全送给你；要是没有，你就只能空手回家啦！”

作为程序员的你，立刻掏出键盘，“喀嗒嗒”地写出一行魔法代码，替小朋友们快速找出有没有“幸运数字”！

输入格式

第一行包含一个整数 $ n $，表示糖的个数；

第二行包含 $ n $ 个整数 $ c_i $，分别是每个糖上印着的整数（$ -500 \leq c_i \leq 500 $），相邻两个元素之间用单个空格隔开。

输出格式

如果存在这样的数，输出这个数（最多 $1$ 个），否则输出 no。

样例

样例输入 #1

3
2 9 2```

**样例输出 #1**

2```

样例输入 #2

8
7 -9 50 60 50 50 50 -19```

**样例输出 #2**

no```

AC 代码

#include <cstdio>                  // 用 scanf/printf 加快读写
using namespace std;

const int MAXC = 1005;           // -500~500 映射到 0~1000
int cnt[MAXC];                   // 计数数组，全局默认初始化为 0

int main() {
    int n;
    scanf("%d", &n);

    int half = n / 2;            // 一半的数量
    for (int i = 0; i < n; i++) {
        int x;
        scanf("%d", &x);
        cnt[x + 500]++;          // 统计出现次数
    }

    // 找出现次数超过一半的数
    for (int i = 0; i <= 1000; i++) {
        if (cnt[i] > half) {
            printf("%d\n", i - 500);
            return 0;
        }
    }

    printf("no\n");
    return 0;
}
