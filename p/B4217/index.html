B4217 [常州市赛 2023] 奶牛农场

洛谷 | 普及- | C++14 | 提交时间: 2026-07-25

算法标签：贪心、2023、江苏、Special Judge、科创活动、小学活动

题目背景

搬运自 http://czoj.com.cn/p/674。数据为民间数据。

题目描述

小 X 是 CZ 市著名的农场主，他拥有着 CZ 市最大的奶牛农场。农场里有一排牛棚，一共 $n$ 个牛棚，从左到右依次编号为 $1,2,\cdots,n$ 。目前有些牛棚里住着奶牛，有些牛棚还是空的。

每个奶牛有一个高度，其中第 $i$ 个牛棚里的奶牛的高度为 $H_i$，如果第 $i$ 个牛棚里没有奶牛的话，$H_i=0$，为了使小 X 的牛棚变得美观，他打算去市场上买一些奶牛放到空着的牛棚里（假设市场上能买到任意多个高度在 $1$ 到 $10^9$ 之间的任意正整数的奶牛），使得每个牛棚里都有一头奶牛，并且高度从左往右严格递增。

请你告诉小 X 是否能让他的牛棚变得美观，如果可以请给出一个任意合法的方案。

输入格式

第一行 $1$ 个正整数 $n$，表示牛棚个数。

第二行 $n$ 个非负整数 $H_i$，如果 $H_i=0$ 说明第 $i$ 个牛棚是空的，否则说明第 $i$ 个牛棚里面有一个高度为 $H_i$ 的奶牛。

输出格式

第一行输出一个字符串 YES 或 NO。如果让他的牛棚变得美观，则输出 YES，否则输出 NO。

如果第一行输出 YES，再输出第二行 $n$ 个正整数 $1\leq H'_i\leq 10^9$ ，你需要保证对所有
$1\leq i\leq n-1$ 满足 $H'_i<H'_{i+1}$ ，并且如果 $H'_i>0$ ，那么 $H'_i=H_i$ ，如果有多种合法的
方案，输出任意一种即可。

样例

样例输入 #1

3
0 0 0```

**样例输出 #1**

YES
4 5 6```

样例输入 #2

4
0 2 0 4```

**样例输出 #2**

YES
1 2 3 4```

样例输入 #3

4
0 0 0 2```

**样例输出 #3**

NO```

样例输入 #4

2
1000000000 0```

**样例输出 #4**

NO```

AC 代码

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;           // n 最大 1e5，多开 5 个
int a[MAXN];                       // 牛棚的奶牛高度

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    /*
      思路（贪心填数）：
      从左到右遍历每个牛棚，维护前一个牛棚的最终高度 pre（初始为 0）。
      对于第 i 个牛棚：
        - 如果已有奶牛（a[i] > 0）：检查 a[i] > pre 是否成立，不成立则无解。
        - 如果是空棚（a[i] == 0）：填入能填的最小值 pre + 1。
          如果 pre 已经达到 10^9，则无法填入 > 10^9 的数，无解。
      因为填入的是可能的最小值，如果这样都无法满足后面的已有奶牛，
      那么任何更大的填入值更不可能满足。因此贪心是正确的。
      时间复杂度 O(n)。
    */

    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    int pre = 0;                     // 前一个位置的最终高度，初始为 0
    for (int i = 1; i <= n; i++) {
        if (a[i] > 0) {
            if (a[i] <= pre) {       // 不满足严格递增
                cout << "NO\n";
                return 0;
            }
            pre = a[i];
        } else {                     // 空棚
            if (pre == 1000000000) {  // 无法填入 >10^9 的数
                cout << "NO\n";
                return 0;
            }
            a[i] = pre + 1;          // 填入可能的最小值
            pre = a[i];
        }
    }

    cout << "YES\n";
    for (int i = 1; i <= n; i++) {
        cout << a[i] << (i < n ? " " : "\n");
    }

    return 0;
}
