1886 - 连胜统计

题目描述

在篮球比赛中，连胜是一件让球迷非常兴奋的事情。现给出 nnn 场比赛的获胜队伍编号，请输出每个球队连胜的场数，要求至少连胜 222 场才能列入统计范围。

比如，输入获得胜利的球队编号为：999 999 111 222 222 222 999 999 333 333 333 222，那么输出结果如下：

`9 2
2 3
9 2
3 3
`

输出的含义是： 999 号球队连胜 222 场、 222 号球队连胜 333 场、 999 号球队连胜 222 场、 333 号球队连胜 333 场。

输入

第 111 行有一个整数 nnn ，代表比赛的场数。（ 5≤n≤1005≤n≤1005≤n≤100 ）

第 222 行有 nnn 个整数，分别代表了每场比赛获得胜利的球队的编号。（球队编号在 [1,109][1,10^9][1,109] 范围内）

输出

输出若干行，每行 222 个整数，按照读入的顺序输出获得连胜的球队的编号以及连胜的场次。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

//统计连续相等的数出现的次数 
int n,a[110],c;

int main() {
    cin>>n;
    for(int i = 0; i < n; i++) {
        cin>>a[i];
    }

    for(int i = 0; i < n; i++) {
        c++;//连续相等的数至少有一个
        //如果连续相等的数结束了：两个标记
        //到了最后，或者当前数!=下个数 
        if(i == n - 1 || a[i] != a[i+1]) {
            //1个数，不输出 
            if(c > 1) cout<<a[i]<<" "<<c<<endl;
            c = 0;//计数器清零 
        }
    }
    return 0;
}
