1003 - 编程求1+3+5+...+n

题目描述

编程求 $1+3+5+ \dots +n$ 。

输入

输入一行，只有一个整数 $n (1 \le n \lt 10000)$ 这里 $n$ 为奇数。

输出

输出只有一行。

解题思路

AC代码

AC代码

#include<iostream>
using namespace std;
int main(){
    int sum=0,n;
    cin>>n;
    for(int i=1; i<=n; i++){
        if(i%2!=0){
            sum+=i;
        }
    }
    cout<<sum<<endl;
    return 0; 
}
