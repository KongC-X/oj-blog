B3952 [GESP202403 一级] 小杨买书

洛谷 | 入门 | C++14 | 提交时间: 2025-03-28

算法标签：数学、2024、顺序结构、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1141

题目描述

小杨同学积攒了一部分零用钱想要用来购买书籍，已知一本书的单价是 $13$ 元，请根据小杨零用钱的金额，编写程序计算可以购买多少本书，还剩多少零用钱。

输入格式

输入一个正整数 $m$，表示小杨拥有的零用钱数。

输出格式

输出包含两行，第一行，购买图书的本数；第二行，剩余的零用钱数。

样例

样例输入 #1

100

样例输出 #1

7
9

样例输入 #2

199

样例输出 #2

15
4```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int m,i;
    cin >> m;
    cout << m / 13 << endl;
    cout << m % 13;
}
