1075 - 寻找2的幂

题目描述

数学上把 222 的 KKK 次方叫 222 的 KKK 次幂，如 4、8、324、8、324、8、32 等。

给定一个整数 nnn ，请输出距离它最近的那个 222 的幂是多少。

如果有两个距离相同，输出那个小的。

输入

只有一个整数 n（10≤n≤2×109n（10 \le n \le 2 \times 10^9n（10≤n≤2×109 ）。

输出

只有一个整数，表示距离最近的那个 222 的幂。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    long long n,x;
    cin>>n;
    x = 2;//起始值
    //当x<=n的时候循环，循环停止x就一定是比n大的2的次方
    while(x <= n){
        x = x * 2;
    } 
    
    //如果较大数x离n更近 
    if(x - n < n - x / 2){
        cout<<x;
    }else{
        cout<<x / 2;
    }
    
    return 0;
}
