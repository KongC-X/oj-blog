B3754 [信息与未来 2019] 鸡兔同笼

洛谷 | 普及- | C++14 | 提交时间: 2026-04-14

算法标签：数学、2019、江苏、不定方程、信息与未来

题目描述

有三种动物被关在笼子里，它们分别是：

  • 鸡，每只鸡有一个头、两只脚；
  • 三脚猫，每只三脚猫有一个头，三只脚；
  • 兔子，每只兔子有一个头，四只脚。

现在知道笼子中一共有 xxx 个头、yyy 只脚，但这个信息并不足以推导出鸡、兔和三脚猫的准确数量。这时候就需要编程来帮忙了——请你求出笼子里分别至少、至多有几只兔子。

输入格式

你需要在一个测试数据中处理多个鸡兔同笼问题。输入第一行 TTT 表示问题的数量。

接下来 TTT 行，每行两个用空格分隔的正整数 x,yx,yx,y，表示头和脚的数量。

输出格式

对于每个问题，输出一行两个空格分开的整数，表示笼子里至少和至多有几只兔子。输入数据保证每个问题至少有一种鸡、三脚猫和兔子的合法组合。

样例

样例输入 #1

4
6 12
6 21
6 24
12345 40000```

**样例输出 #1**

0 0
3 4
6 6
2965 7655```

AC 代码

#include <iostream>
using namespace std;

int main() {
    int T;
    cin >> T;
    while (T--) {
        long long x, y;
        cin >> x >> y;

        // 设鸡 a 只，三脚猫 b 只，兔 c 只
        // 方程组：
        // a + b + c = x          (1)
        // 2a + 3b + 4c = y      (2)
        // (1)×2:  2a + 2b + 2c = 2x
        // (2) - (1)×2:  b + 2c = y - 2x   →  令 S = y - 2x
        // 于是 b = S - 2c
        // 因为 b ≥ 0，所以 S - 2c ≥ 0  →  c ≤ S / 2  (最大值)
        // 又因为 a = x - b - c = x - (S - 2c) - c = x - S + c ≥ 0
        // 所以 c ≥ S - x  (最小值)
        // 同时 c ≥ 0
        // 因此 c 的范围是 [ max(0, S - x),  floor(S / 2) ]

        // 结论：先算 S=y-2x，兔子最少是 S-x 和 0 中较大的那个，兔子最多是 S 除以 2 的商。

        long long S = y - 2 * x;
        long long c_min = max(0LL, S - x);
        long long c_max = S / 2;    // 整除自动向下取整

        cout << c_min << " " << c_max << endl;
    }
    return 0;
}
