1172 - 寻找第K大数

题目描述

NNN 个小朋友在一起做游戏。 每个小朋友在自己的硬纸板上写一个数，然后同时举起来。 接着，小 yyy 老师提一个问题，看哪个小朋友先抢答出来。

问题是，在这 NNN 个数中，第 KKK 大的是哪个数？请你编程完成。

输入

输入文件的第一行为 222 个整数，依次为 NNN 和 KKK ( K≤N≤1000K \le N \le 1000K≤N≤1000 )；

下面 NNN 行，每行为一个整数，表示从第 111 个小朋友到第 NNN 个朋友分别写的数（假设这些小朋友只知道 −32768∼32767-32768 \sim 32767−32768∼32767 之间的数）。

输出

输出文件只有一行，就一个数，为第 KKK 大的那个数。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;
int main() {
    //数组大小按照题目的要求定义，最好多定义10个
    int a[1010],n,i,j,t,k;
    cin>>n>>k;
    for(i=0; i<n; i++) {
        cin>>a[i];
    }

    for(i=1; i<=n-1; i++) {
        for(j=0; j<=n-i-1; j++) {
            //按照从大到小排序
            if(a[j]<a[j+1]) {
                t=a[j];
                a[j]=a[j+1];
                a[j+1]=t;
            }

        }
    }

    //第1大的数，下标是0，第2大的数下标是1，第3大的数下标是2
    //第k大的数，下标是k-1
    cout<<a[k-1];

    return 0;
}
