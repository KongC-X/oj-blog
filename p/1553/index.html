1553 - 数列求和

题目描述

小明写出了一个数列，第 iii 项 aia_iai​ 的值为 i2i^2i2 。数列从第一项( i=1i = 1i=1 )开始如下:

1,4,9,16,25,…1, 4, 9, 16, 25, \dots1,4,9,16,25,…

编程求出这个数列前 nnn 项的和。

输入

整数 n(1≤n≤1,000)n (1 \le n \le 1,000)n(1≤n≤1,000)

输出

一个整数: a1+a2+⋯+ana_1 +a_2 + \dots +a_na1​+a2​+⋯+an​ 的值。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int main() {
 int n,s=0;//s代表n项的和
 cin>>n;
 //遍历1到n的整数
 for(int i=1;i<=n;i++){
 s+=i*i;//每次加上i的平⽅
 }
 cout<<s;//输出和
 return 0;
}
