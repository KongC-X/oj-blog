B2057 最高的分数

洛谷 | 入门 | C++14 | 提交时间: 2026-07-01

题目描述

孙老师讲授的《计算概论》这门课期中考试刚刚结束，他想知道考试中取得的最高分数。因为人数比较多，他觉得这件事情交给计算机来做比较方便。你能帮孙老师解决这个问题吗？

输入格式

输入两行，第一行为整数 nnn（1≤n<1001 \le n<1001≤n<100），表示参加这次考试的人数。第二行是这 nnn 个学生的成绩，相邻两个数之间用单个空格隔开。所有成绩均为 000 到 100100100 之间的整数。

输出格式

输出一个整数，即最高的成绩。

样例

样例输入 #1

5
85 78 90 99 60```

**样例输出 #1**

99```

AC 代码

#include<iostream>
using namespace std;

int main(){
    int n, ma = 0;
    cin >> n;
    for(int i = 1; i <= n; i++){
        int t;
        cin >> t;
        if(t > ma) ma = t;
        //或者写成  ma = max(ma, t); 
    }
    cout << ma << endl;
}
