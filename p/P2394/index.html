P2394 yyy loves Chemistry I

洛谷 | 入门 | C++14 | 提交时间: 2026-08-13

题目背景

从前，有个人叫 yyy，他特别喜欢化学，尤其是一些很危（zuo）险（si）的实验。

这一天，他开始研究起了一个神奇又有趣的方程式：

2Na + 2H2O == 2NaOH + H2↑\text{2Na + 2H}_{2}\text{O == 2NaOH + H}_2\uparrow2Na + 2H2​O == 2NaOH + H2​↑

题目描述

现在 yyy 将一块质量为 x gx\ \text{g}x g 的钠投入很多（过量）的水中，然后开始收集氢气。

最终，我们知道，这块钠在水中游动着消失了。而 yyy 很厉害，把氢气全收集起来了。

已知每投入 23\bm{23}23 克的钠，就会生成 1\bm11 克的氢气。

那么现在 yyy 收集了多少克氢气呢？

形式化题意：输入一个实数 x\bm xx，输出 x23\bm{\frac{x}{23}}23x​ 的前 8\bm88 位小数值，要求四舍五入。

输入格式

一行一个实数 xxx，代表 yyy 将投入了水中的钠的质量（单位：g\text{g}g）。

输入文件行末一定不会有一只回车啦。

输出格式

一行一个实数（四舍五入精确到 888 位小数），代表生成了多少克氢气。

样例

样例输入 #1

0.23```

**样例输出 #1**

0.01000000```

AC 代码

#include <cstdio>
int main() {
    long double s;              // 使用 long double，精度约 18 位有效数字
    scanf("%15Lf", &s);         // 读取最多 15 位有效数字（含小数点）
    s = s / 23;                 // 计算质量
    printf("%.8Lf", s);         // 输出 8 位小数，自动四舍五入
    return 0;
}
