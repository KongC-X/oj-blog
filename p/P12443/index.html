P12443 [NERC2023] LOL Lovers

洛谷 | 普及- | C++14 | 提交时间: 2026-08-17

算法标签：2023、Special Judge、ICPC、NERC/NEERC

题目描述

There are nnn food items lying in a row on a long table. Each of these items is either a loaf of bread (denoted as a capital Latin letter L\texttt{L}L with ASCII code 76) or an onion (denoted as a capital Latin letter O\texttt{O}O with ASCII code 79). There is at least one loaf of bread and at least one onion on the table.

You and your friend want to divide the food on the table: you will take a prefix of this row (several leftmost items), and the friend will take the rest. However, there are several restrictions:

  • Each person should have at least one item.
  • The number of your loaves should differ from the number of your friend's loaves.
  • The number of your onions should differ from the number of your friend's onions.

Find any correct division and print the number of items you take or report that there is no answer.

输入格式

The first line contains one integer nnn (2≤n≤2002 \le n \le 2002≤n≤200) --- the number of food items on the table. The second line contains a string of length nnn consisting of letters L\texttt{L}L and O\texttt{O}O. iii-th symbol represents the type of the iii-th food item on the table: L\texttt{L}L stands for a loaf of bread, and O\texttt{O}O stands for an onion. It is guaranteed that this string contains at least one letter L\texttt{L}L and at least one letter O\texttt{O}O.

输出格式

Print one integer --- a number kkk such that, if you take kkk leftmost items and your friend takes the remaining n−kn - kn−k items, each of you and your friend get at least one item, your number of loaves is different from your friend's, and your number of onions is different from your friend's. If there are several possible answers, print any of them. If there are no possible answers, print the number −1-1−1.

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P12443 [NERC2023] LOL Lovers
     * 题意：给定一个只含 L 和 O 的字符串，找一个分割点 k（1≤k≤n-1），
     *       使得前 k 个中 L 的数量 ≠ 后 n-k 个中 L 的数量，
     *       且前 k 个中 O 的数量 ≠ 后 n-k 个中 O 的数量。
     *       输出任意一个满足条件的 k，否则输出 -1。
     *
     * 数据范围：n≤200，直接暴力枚举分割点即可。
     * 对于每个 k，统计前缀 L 数、前缀 O 数，再计算后缀数，检查条件。
     *
     * 时间复杂度：O(n^2)，完全可行。
     */
    int n;
    string s;
    cin >> n >> s;

    // 统计整个字符串中 L 和 O 的总数
    int tl = 0, to = 0;   // total L, total O
    for (int i = 0; i < n; i++) {
        if (s[i] == 'L') tl++;
        else to++;
    }

    // 枚举分割点 k，表示拿走前 k 个
    for (int k = 1; k < n; k++) {
        // 统计前缀中 L 和 O 的数量
        int pl = 0, po = 0;   // prefix L, prefix O
        for (int i = 0; i < k; i++) {
            if (s[i] == 'L') pl++;
            else po++;
        }
        // 后缀数量 = 总数 - 前缀数量
        int sl = tl - pl;
        int so = to - po;

        // 检查条件：两边 L 不同 且 两边 O 不同
        if (pl != sl && po != so) {
            cout << k << endl;
            return 0;
        }
    }

    cout << -1 << endl;
    return 0;
}
