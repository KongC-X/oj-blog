4682 - 二阶矩阵

题目描述

小 AAA 有一个 nnn行 mmm列的矩阵 AAA 。

小 AAA 认为一个 2×22 \times 22×2 的矩阵 DDD 是好的，当且仅当 D1，1×D2，2=D1，2×D2，1D_{1，1} \times D_{2，2}=D_{1，2} \times D_{2，1}D1，1​×D2，2​=D1，2​×D2，1​ 。其中 DDD 表示矩阵 Di，jD_{i，j}Di，j​ 的第 iii 行第 jjj 列的元素。

小 AAA 想知道 AAA 中有多少个好的子矩阵。

输入

第一行，两个正整数 n，mn，mn，m 。

接下来 nnn行，每行 mmm 个整数 Ai，1，Ai，2，...Ai，mA_{i，1}，A_{i，2}，...A_{i，m}Ai，1​，Ai，2​，...Ai，m​。

输出

一行，一个整数，表示 AAA 中好的子矩阵的数量。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int i,j,n,m,s;
int a[510][510];
int main() {
    cin >> n >> m;
    for(i=1;i<=n;i++) {
        for(j=1;j<=m;j++) {
            cin >> a[i][j];
        } 
    }
    for(i = 1;i <= n - 1;i++) {
        for(j = 1;j <= m - 1;j++) {
            if(a[i][j] * a[i + 1][j + 1] == a[i + 1][j] * a[i][j + 1]) {
                s++;
            }
        }
    }
    cout << s << endl;
}
