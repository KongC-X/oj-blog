1518 - 多项式求和

题目描述

输入一个正整数 nnn，求 1!−2!+3!−4!+⋯+N!1!-2!+3!-4!+ \dots +N!1!−2!+3!−4!+⋯+N! 的结果。

比如：n=3n=3n=3，则结果 =1−(1∗2)+(1∗2∗3)=5= 1-(1*2)+(1*2*3) = 5=1−(1∗2)+(1∗2∗3)=5。

n!=1∗2∗3∗4∗...∗nn! = 1 * 2 * 3 * 4 * ... * nn!=1∗2∗3∗4∗...∗n，也就是 1∼n1 \sim n1∼n 之间所有数的积，比如：5!=1∗2∗3∗4∗5=1205!=1*2*3*4*5=1205!=1∗2∗3∗4∗5=120。

输入

一个正整数 n（n≤10n（n \le 10n（n≤10 ）

输出

一个整数，代表运算结果。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;

int main() {
    int n,i,j,s = 0,c;
    cin >> n;
    for(i = 1;i <= n;i++) {
        c = 1;
        for(j = 1;j <= i;j++) {
            c = c * j;
        }
        i % 2 == 0 ? s -= c : s += c;
    }
    cout << s;
}
