B4089 [CSP-X2020 山东] 勇敢的津津

洛谷 | 普及- | C++14 | 提交时间: 2026-08-10

算法标签：动态规划 DP、贪心、2020、山东、CSP-X 小学组

题目描述

津津是个勇敢的孩子，总是做一些挑战自己的事情。一天津津来到一条宽为 $L$ 米的小河边，河道的一边到另一边需要途径 $N$ 块较大的石墩，每块石墩到这一边岸边之间距离 $d_i$ 米（石墩不占距离，只考虑石墩的中间点到这一边岸边之间距离）。津津想踩着这些石墩从小河的这一边跳到另一边（不落入水中），一次可以跳过几块石墩。已知津津每次最多跳 $M$ 米的距离，那么津津最少跳几次就能从这一边跳到另一边？

输入格式

第一行包含三个整数 $L,N,M$，分别小河的宽度、石墩数和津津跳的最远距离。

接下来 $N$ 行，每行一个整数，第 $i$ 行的整数 $d_i(0\lt d_i \lt L)$，表示第 $i$ 块石墩与这一边岸边的距离，保证石墩之间的距离和最靠边的石墩到这一边岸边的距离小于等于 $M$。这些石墩按与起点距离从小到大的顺序给出，且不会有两个石墩出现在同一个位置。

输出格式

一个整数，即最少的跳跃次数。

样例

样例输入 #1

10 4 2
2
4
6
8```

**样例输出 #1**

5```

样例输入 #2

25 5 10
2
11
14
17
21```

**样例输出 #2**

4```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：贪心（每次跳到最远可达石墩）
     * 思路：
     * 当前位置为 cur（初始为岸边，距离0），每次跳跃最远距离为 M。
     * 在 cur+M 范围内，选择距离最远的石墩作为下一次落脚点，这样能保证跳跃次数最少。
     * 如果 cur+M >= L，则可以直接跳到对岸，结束。
     *
     * 步骤：
     * 1. 读入 L, N, M。
     * 2. 读入 N 个石墩距离 d[0..N-1]（已按升序给出）。
     * 3. 模拟跳跃过程：
     *    - cur = 0（当前位置），ans = 0（跳跃次数），i = 0（下一个待考虑的石墩下标）。
     *    - 当 cur < L 时循环：
     *        a. 若 cur + M >= L，则 ans++ 并退出。
     *        b. 在 d 中从 i 开始，找到所有 d[j] <= cur + M 的最远那个，设为 nxt。
     *           同时将 i 移动到该石墩之后（因为之前的石墩已经不可能再被使用）。
     *        c. 若 nxt == cur（没有找到石墩），理论上不会发生（题目保证有解）。
     *        d. cur = nxt，ans++，继续循环。
     * 4. 输出 ans。
     *
     * 时间复杂度：O(N)
     */

    int L, N, M;            // L: 河宽, N: 石墩数, M: 最大跳跃距离
    cin >> L >> N >> M;

    int d[505];             // d[i]: 第 i 个石墩到岸边的距离
    for (int i = 0; i < N; i++) {
        cin >> d[i];
    }

    int cur = 0;            // 当前位置（距离起点）
    int ans = 0;            // 跳跃次数
    int i = 0;              // 指向下一个待考虑石墩的下标

    while (cur < L) {
        // 如果当前位置能直接跳到对岸
        if (cur + M >= L) {
            ans++;
            break;
        }

        // 在可跳范围内找到最远的石墩
        int nxt = cur;      // 初始化为当前，表示没有找到
        // 从 i 开始，因为前面的石墩（距离 <= cur）已经无法再作为落脚点
        while (i < N && d[i] <= cur + M) {
            nxt = d[i];     // 因为 d 是升序，最后停留在最远的
            i++;
        }

        // 此时 nxt 是 cur+M 范围内最远的石墩
        // （如果 nxt == cur，说明没有合适的石墩，但题目保证有解，不会发生）
        cur = nxt;          // 跳到该石墩
        ans++;              // 跳跃次数加1
        // 注意 i 已经指向了下一个更远的石墩，所以下次循环直接从 i 开始
    }

    cout << ans << endl;
    return 0;
}
