1498 - 宇宙总统？

题目描述

地球历公元 603660366036 年，全宇宙准备竞选一个最贤能的人当总统，共有 nnn 个非凡拔尖的人竞选总统，现在投票已经结束，获得选票最多的人将荣登总统的宝座，如果有多个候选人获得票数一致，那么编号较大的候选人将就任总统的职位。请你编程计算出谁能够胜任总统的职位。

比如，有 555 位候选人参加竞选，他们的编号分别是 111 222 333 444 555 ，有 101010 个人为他们投票，投票结果是：111 111 111 111 111 222 222 333 444 555 ，那么 111 号候选人当选为宇宙总统。

输入

第 111行是一个整数 nnn，代表投票的总数。（n≤1000n \le 1000n≤1000）

第 222 行有 nnn 个整数，代表这些选票投给了哪些编号的候选人（候选人编号都是 1∼1001 \sim 1001∼100之间的整数）。

输出

输出一个整数，代表获得总统职位的候选人的编号。

AC代码

AC代码

/*
    1498 - 【入门】宇宙总统？
*/ 

#include <iostream>
using namespace std;

int main(){
    int n,a[101]={0},x,i;
    cin>>n;
    
    // 统计每个编号票数 
    for(i=0;i<n;i++){
        cin>>x;
        a[x]+=1;
    }
    
    // 计算1-100编号票数最大值，最大值相等，则取编号最大数 
    int ma=1;
    for(i=1;i<=100;i++){
        if(a[i]>a[ma] || (a[i]==a[ma] && i>ma)){
            ma=i;
        }
    }
    cout<<ma<<endl;
    
    return 0;
}
