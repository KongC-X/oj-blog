1033 - 判断奇偶数

题目描述

输入一个整数，判断是否为偶数。是输出 y e s ，否则输出n o。

输入

输入只有一行，包括 $1$ 个整数（该整数在 $1 \sim 10000$ 的范围内）。

输出

输出只有一行。（注意输出格式，具体请看下方提示）。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;

int main(){
    //定义一个整数变量n 
    int n;
    //输入n 
    cin>>n;
    //判断n是否是偶数，需要看n能否被2整除 
    if(n%2 == 0){
        cout<<"y e s";
    }else{
        cout<<"n o";
    }
    return 0;
}
