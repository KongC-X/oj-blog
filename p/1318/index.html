1318 - 队形数量求解

题目描述

同学们表演团体体操，排列的队形必须是长方形或正方形（且该长方形或者正方形的变长要求 >1\gt 1>1）。

原来有 mmm 排，每排有 nnn 个人，现在想要变换队形，请问在人数不变的情况下，队形有多少种不同的变换方法。

如：原有 333 排，每排 101010 个人。那么可以有 222 种变换队形，分别是 2×152 \times 152×15 和 5×65 \times 65×6 （ 15×215 \times 215×2 以及 6×56 \times 56×5 算作重复的队形）。（ 4.1.1014.1.1014.1.101 ）

输入

两个整数 mmm 和 nnn ，分别代表有 mmm 排以及每排有 nnn 个人。（ 1<m,n≤3×1041 \lt m,n \le 3 \times 10^41<m,n≤3×104 ）

输出

一个整数，代表可以变换的队形的方案。

解题思路

AC代码

AC代码

#include<iostream>
#include<cmath>
using namespace std;

int main() {
    int i,s,sum = 0;
    long long m,n;
    cin >> m >> n;
    s = m * n;
    for(i = 2;i <= sqrt(s);i++) {
        if(s % i == 0) {
            sum ++;
        }
    }
    cout << sum - 1 << endl;
}
