2170 - 树的高度

题目描述

一棵树有 nnn 个结点，结点编号为 111~nnn，其中 111 号结点为根结点，根结点的深度为 111 ，请问树的高度是多少。

输入

第一行是整数 nnn，表示结点数。（1≤n≤1001≤n≤1001≤n≤100）

后面若干行，每行两个整数aaa bbb，表示 bbb 是 aaa 的子结点。

本题测试数据保证所有结点能构建为一棵树。

输出

求这棵树的高度。

AC代码

#include <bits/stdc++.h>
using namespace std;

int a[110][110];//邻接矩阵存储树
int n,ma = 0;//ma表示最大深度 

//深搜求每个结点的深度
void dfs(int x,int dep){
    ma = max(ma,dep);
    //讨论x结点可以去哪些结点
    for(int i = 1;i <= n;i++){
        //有边表示可行 
        if(a[x][i]==1){
            dfs(i,dep+1); 
        }
    } 
}  
 
int main(){
    cin>>n;
    //边：父子关系
    int x,y; 
    for(int i = 1;i <= n - 1;i++){
        cin>>x>>y;
        a[x][y] = 1;//有向图 
    }
    
    //从根开始深搜，默认深度为1 
    dfs(1,1); 
    
    cout<<ma;
    return 0;
}
