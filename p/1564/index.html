1564 - 洗牌2

题目描述

魔术师刘谦要洗牌了，请你写个程序来模拟洗牌的过程。

洗牌分弹牌和切牌两个操作：

弹牌——将牌组等分成两份，然后交错相插，如当前牌为 111 222 333 444 555 666 ，现在开始弹牌，先将牌分成 111 222 333 和 444 555 666 ，然后交错相插，变成 111 444 222 555 333 666 。

切牌——从牌堆里面拿出连续的一段，然后放到顶端。如当前牌为111 222 333 444 555 666，切完 222～555 之间的 444 张牌后变成 222 333 444 555 111 666 。

输入

第一行为两个正整数 NNN 和 MMM ，NNN 表示牌堆里面有 NNN 张牌，MMM 表示共进行 MMM 次洗牌的操作。

第二行有 NNN 个正整数，代表 NNN 张牌上的数字，刘谦用的牌其实就是标有数字的卡片。

接下来 MMM 行，每行一个整数或者三个整数。

如果第一个数为 000 ，那么这一行就这只有一个数，表示弹牌。

如果第一个数为 111 ，那么后面跟着两个正整数 bbb 和 eee ，表示把 bbb～eee 这段牌切到顶端。

输出

输出 MMM 次操作后从第一张开始的每张牌上的数字。

相邻两数严格用一个空格隔开。

解题思路

#include<iostream>
#include<algorithm>
#include<cmath>
using namespace std;
long long a[1000000],b[1000000],c[1000000];
bool cmp(int x,int y){
    return x>y;
} 
int main(){
    int n,m;
    cin>>n>>m;
    for(int i=1;i<=n;i++){
        cin>>a[i];//总牌张数
    }
    int f,r,t;
    for(int i=1;i<=m;i++){
        cin>>f;
        if(f==0){
            //弹牌1次 
            int x=1;
            for(int i=1;i<=n/2;i++){   //前半堆 
                b[x]=a[i];
                x+=2;
            }
            int y=2;
            for(int z=n/2+1;z<=n;z++){  //后半堆 
                b[y]=a[z];
                y+=2;
            }
            for(int i=1;i<=n;i++){
                a[i]=b[i];
            } 
        }else{
            cin>>r>>t;
            //切牌1次
            int v=1;
            for(int i=r;i<=t;i++){
                b[v]=a[i];
                v++;
            } 
            for(int i=1;i<=r-1;i++){
                b[v]=a[i];
                v++;
            }
            for(int i=t+1;i<=n;i++){
                b[v]=a[i];
                v++;
            }
            for(int i=1;i<=n;i++){
                a[i]=b[i];
            } 
        } 
    }
    for(int i=1;i<=n;i++){
        cout<<b[i]<<" ";
    }

    return 0;
}
