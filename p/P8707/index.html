P8707 [蓝桥杯 2020 省 AB1] 走方格

洛谷 | 普及- | C++14 | 提交时间: 2026-08-07

算法标签：动态规划 DP、2020、蓝桥杯省赛

题目描述

在平面上有一些二维的点阵。

这些点的编号就像二维数组的编号一样，从上到下依次为第 111 至第 nnn 行，从左到右依次为第 111 至第 mmm 列，每一个点可以用行号和列号来表示。

现在有个人站在第 111 行第 111 列，要走到第 nnn 行第 mmm 列。只能向右或者向下走。

注意，如果行号和列数都是偶数，不能走入这一格中。

问有多少种方案。

输入格式

输入一行包含两个整数 nnn，mmm。

输出格式

输出一个整数，表示答案。

样例

样例输入 #1

3 4```

**样例输出 #1**

2```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】动态规划（DP）
     * 【问题描述】
     * 从 (1,1) 走到 (n,m)，只能向右或向下走，不能走入行号和列号都是偶数的格子。
     * 求方案总数。
     *
     * 【状态定义】
     * dp[i][j]：从起点 (1,1) 到达 (i,j) 的方案数。
     *
     * 【转移方程】
     * 如果 (i,j) 是“偶数格”（i%2==0 && j%2==0），则 dp[i][j]=0（不可进入）。
     * 否则，dp[i][j] = dp[i-1][j] + dp[i][j-1]（从上方或左方来）。
     *
     * 【边界条件】
     * dp[1][1] = 1（起点）。
     * 对于第一行或第一列，若该格不是偶数格，则只能从左边或上边来，故转移仍然成立。
     *
     * 【答案】
     * dp[n][m]
     *
     * 【时间复杂度】O(n*m)，n,m≤30，非常快。
     */

    int n, m;          // n: 行数, m: 列数
    cin >> n >> m;

    long long dp[35][35] = {0};   // dp[i][j] 方案数，用 long long 防止溢出
    dp[1][1] = 1;                 // 起点方案数为 1

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (i == 1 && j == 1) continue;   // 跳过起点，保持为1
            if (i % 2 == 0 && j % 2 == 0) {
                dp[i][j] = 0;                 // 偶数格不可进入
            } else {
                dp[i][j] = dp[i-1][j] + dp[i][j-1];
            }
        }
    }

    cout << dp[n][m] << endl;   // 输出方案数
    return 0;
}
