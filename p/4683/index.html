4683 - 平均分配

题目描述

图片中的内容是一个关于物品分配的问题。

小 $A$ 有 $2n$ 件物品，小 $B$ 和小 $C$ 想从小 $A$ 手上买这些物品。

对于第 $i$ 件物品，小 $B$ 会以 $b_i$ 的价格购买，而小 $C$ 会以 $c_i$ 的价格购买。为了平均分配这 $2n$ 件物品，小 $A$ 决定小 $B$ 和小 $C$ 各自只能买走恰好 $n$ 件物品。

问题是求出小 $A$ 卖出这 $2n$ 件物品所能获得的最大收入。

输入

第一行，一个正整数 $ n $。

第二行，$ 2n $ 个整数 $ b_1, b_2, \ldots, b_{2n} $。

第三行，$ 2n $ 个整数 $ c_1, c_2, \ldots, c_{2n} $。

输出

一行，一个整数，表示答案。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

long long b[200010],c[200010],d[200010];
int i,j,n;
long long s;

int main() {
    cin >> n;
    for(i=1;i<=2*n;i++){
        cin >> b[i];
        s = s + b[i];
    }
    for(i=1;i<=2*n;i++){
        cin >> c[i];
    }
    for(i=1;i<=2*n;i++){
        d[i] = b[i] - c[i]; // -1 2 -4 1
    }
    sort(d+1,d+2*n+1); // -4 -1 1 2
    for(i =1;i <= n;i++) {
        s = s - d[i];
    }
    cout << s << endl;
}
