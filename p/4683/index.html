4683 - 平均分配

题目描述

图片中的内容是一个关于物品分配的问题。

小 AAA 有 2n2n2n 件物品，小 BBB 和小 CCC 想从小 AAA 手上买这些物品。

对于第 iii 件物品，小 BBB 会以 bib_ibi​ 的价格购买，而小 CCC 会以 cic_ici​ 的价格购买。为了平均分配这 2n2n2n 件物品，小 AAA 决定小 BBB 和小 CCC 各自只能买走恰好 nnn 件物品。

问题是求出小 AAA 卖出这 2n2n2n 件物品所能获得的最大收入。

输入

第一行，一个正整数 nnn。

第二行，2n2n2n 个整数 b1,b2,…,b2nb_1, b_2, \ldots, b_{2n}b1​,b2​,…,b2n​。

第三行，2n2n2n 个整数 c1,c2,…,c2nc_1, c_2, \ldots, c_{2n}c1​,c2​,…,c2n​。

输出

一行，一个整数，表示答案。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

long long b[200010],c[200010],d[200010];
int i,j,n;
long long s;

int main() {
    cin >> n;
    for(i=1;i<=2*n;i++){
        cin >> b[i];
        s = s + b[i];
    }
    for(i=1;i<=2*n;i++){
        cin >> c[i];
    }
    for(i=1;i<=2*n;i++){
        d[i] = b[i] - c[i]; // -1 2 -4 1
    }
    sort(d+1,d+2*n+1); // -4 -1 1 2
    for(i =1;i <= n;i++) {
        s = s - d[i];
    }
    cout << s << endl;
}
