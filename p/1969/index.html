1969 - 求下一个字母

题目描述

从键盘读入一个字母，可能是大写字母，也可能是小写字母，请输出该字母的后一个字母是什么？

如果到了字母表的最后一个字母，那么输出第一个对应的字母。

比如：'aaa' 的下一个字母是 'bbb'，'XXX' 的下一个字母是 'YYY'，'zzz' 的下一个字母按照题意应该输出 'aaa'。

输入

输入一个字母，可能是大写，也可能是小写字母。

输出

输出该字母的后一个字母，如果是 'zzz' 请输出 'aaa'，如果是 'ZZZ' 请输出 'AAA'。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int main(){
    char ch;cin>>ch;
    if(ch=='z'||ch=='Z'){
        ch=ch-25;
    }else{
        ch=ch+1;
    }
    cout<<ch;
    
    return 0;
}
