1830 - 算面积2

题目描述

gshgshgsh给了你 NNN 个正方形，请你算出这 NNN 个正方形的面积和。

输入

第一行一个 NNN 。 （N≤100N \le 100N≤100）

下面 NNN 行，每行一个整数表示一个正方形的边长。

输出

一个整数，表示面积和。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int a[101];
int main()
{
    int n,sum = 0;
    cin >> n;
    for(int i = 1;i <= n;i++)
    {
        cin >> a[i];
        sum += a[i] * a[i];
    }
    cout << sum << endl;
    return 0;
}
