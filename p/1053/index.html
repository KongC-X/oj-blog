1053 - 求100+97+……+4+1的值。

题目描述

求 100+97+⋯+4+1100+97+ \dots +4+1100+97+⋯+4+1 的值。

输入

无。

输出

输出一行，即求到的和。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    int i,s=0;
    for(i=100;i>=1;i-=3){
        s+=i;
    }
    cout<<s;
    return 0;
}
