2308 - 找和为K的两个元素

题目描述

在一个长度为n（n<1000）的整数序列中，判断是否存在某两个元素之和为k。

输入

第一行输入序列的长度n和k，用空格分开。

第二行输入序列中的n个整数，用空格分开。

输出

如果存在某两个元素的和为k，则输出yes，否则输出no。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int a[1010];
int main(){
    int n,k;
    cin>>n>>k;
    for(int i=1; i<=n; i++){
        cin>>a[i];
    }
    sort(a+1, a+n+1);
    
    int l=1;
    int r=n;
    while(l<r){
        if(a[l]+a[r]>k){
            r--;
        }else if(a[l]+a[r]<k){
            l++;
        }else{
            cout<<"yes";
            return 0;
        }
    }
    cout<<"no";
    
    return 0;
}
