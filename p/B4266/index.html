B4266 [朝阳区小学组 2019] factorization

洛谷 | 普及- | C++14 | 提交时间: 2026-07-25

算法标签：2019、北京、素数判断、科创活动、小学活动

题目描述

Adleman 非常喜欢数学，最近他遇到了一个棘手的问题：对于一个正整数 AAA，Adleman 发现一些自然数的质因子分解式中没有大于 AAA 的因子，这样的自然数非常的特殊。Adleman 想知道对于给定的正整数 AAA，一个区间 [N, N+M][N, N+M][N, N+M] 内所有满足上述条件的自然数的个数。

输入格式

333 个用空格分开的整数 N,M,AN,M,AN,M,A。

输出格式

一个整数，表示对于给定的正整数 AAA，区间 [N,N+M][N, N+M][N,N+M] 内特殊自然数的个数。

样例

样例输入 #1

30 10 5```

**样例输出 #1**

4```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int a; // 全局变量：质因子上限 A

// 判断一个正整数 x 的所有质因子是否都不超过 a（即没有大于 a 的质因子）
bool ok(int x) {
    if (x == 1) return true;          // 1 没有质因子，满足条件
    for (int i = 2; i * i <= x; i++) {
        if (x % i == 0) {
            if (i > a) return false;  // 发现大于 a 的质因子，直接不满足
            while (x % i == 0) x /= i; // 去掉所有该质因子
        }
    }
    if (x > 1 && x > a) return false; // 剩下的最后一个质因子也要检查
    return true;
}

int main() {
    int n, m;               // n:区间左端点, m:区间长度
    cin >> n >> m >> a;     // a 直接存入全局变量

    int ans = 0;            // 满足条件的个数
    for (int i = n; i <= n + m; i++) {
        if (ok(i)) ans++;   // 逐个判断
    }

    cout << ans << endl;
    return 0;
}
