1926 - 立方体积木Cube Stacking

题目描述

约翰和贝茜在玩一个方块游戏。编号为 111…nnn的nnn(1≤n≤300001 ≤ n ≤ 300001≤n≤30000)个方块正放在地上，每个构成一个立方柱。

游戏开始后，约翰会给贝茜发出 PPP(1≤P≤1000001 ≤ P ≤ 1000001≤P≤100000)个指令。指令有两种：

移动（M）：将包含 XXX 的立方柱移动到包含 YYY 的立方柱上。

统计（C）：统计含 XXX 的立方柱中，在 XXX 下方的方块数目。

写个程序帮贝茜完成游戏。

输入

第 111 行输入 PPP，之后 PPP 行每行输入一条指令，形式为 M X Y 或者 C X。

输入保证不会有将立方柱放在自己头上的指令。

输出

输出共 PPP 行，对于每个统计指令，输出其结果。

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

const int N = 30010;
int f[N];//表示关系
int dis[N];//表示每个元素离根的距离
int len[N];//表示第i列有几个立方块
int p;

// 查询
int find(int x){
    if(f[x] == x) return x;
    else{
        int t=f[x];//记录当前父节点的编号
        f[x]=find(f[x]);//递归找根
        dis[x] = dis[x] + dis[t]; //回溯的时候，更新dis的值
        return f[x];
    }
}

// 合并
void merge(int x, int y){
    int fx = find(x);
    int fy = find(y);
    if(fx != fy){
        f[fx] = fy;
        //更新dis
        dis[fx] = dis[fx] + len[fy];
        //更新该列中方块的数量
        len[fy] = len[fy] + len[fx];
        len[fx] = 0; //合并后，fx的列没有立方块了
    }
}

int main(){
    cin>>p;
    //初始化
    for(int i = 1;i<=30000;i++) {
        f[i]= i;
        len[i]=1;// /默认每一列有1个元素
    }
    //读入指令
    char c;
    int x,y;
    for(int i=1;i<=p;i++) {
        cin>>c>>x;
        //如果是查询
        if(c == 'C'){
            find(x);//更新dis的值，做路径压缩
            cout<<dis[x]<<endl;
        }else{
            //移动  
            cin>>y;
            merge(x, y);
        }
    }
    return 0;
}
