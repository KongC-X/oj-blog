1021 - 求数II

题目描述

在 $1 \sim 500$ 中，找出能同时满足用 $3$ 除余 $2$ ，用 $5$ 除余 $3$ ，用 $7$ 除余 $2$ 的所有整数。

输入

无。

输出

若干个数

每行一个

题解

题解（解法二）

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    int i;
    //循环i的范围1-500 
    for(i=1;i<=500;i++){
        //满足用3除余2，用5除余3，用7除余2  则输出i 
        if(i%3==2&&i%5==3&&i%7==2){
            cout<<i<<endl;
        }
    }
    return 0;
}
