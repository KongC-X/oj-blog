1021 - 求数II

题目描述

在 1∼5001 \sim 5001∼500 中，找出能同时满足用 333 除余 222 ，用 555 除余 333 ，用 777 除余 222 的所有整数。

输入

无。

输出

若干个数

每行一个

题解

题解（解法二）

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    int i;
    //循环i的范围1-500 
    for(i=1;i<=500;i++){
        //满足用3除余2，用5除余3，用7除余2  则输出i 
        if(i%3==2&&i%5==3&&i%7==2){
            cout<<i<<endl;
        }
    }
    return 0;
}
