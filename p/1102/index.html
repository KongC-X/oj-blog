1102 - 字符串中的空格移位

题目描述

输入一个字符串，将其中的所有空格都移到最前面，然后输出。

输入

一个字符串。如：a□b□c（为了能看清空格，□代表一个空格，但实际测试数据中不用□表示空格）

输出

空格全部移到了串前的字符串。如：□□abc

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    string s,s1;
    int i;
    getline(cin, s);
    for(i = 0;i < s.size();i++) {
        if(s[i] == ' ') {
            s1 = s[i] + s1;
        } else {
            s1 = s1 + s[i];
        }
    }
    cout << s1 << endl;
}
