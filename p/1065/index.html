1065 - 字符图形1-星号矩形

题目描述

打印字符图形。

输出 $n$ 行 $n$ 列 *

输入

一个整数 $n(0 \lt n \lt 10)$ 。

输出

一个矩形字符图形。

AC代码

# include <iostream>
using namespace std;

int main() {
    int i,j,n;
    cin >> n;
    for(i = 0;i < n;i++) {
        for(j = 0;j < n;j++) {
            cout << "*";
        }
        cout << endl; // 记得加换行符
    }
}
