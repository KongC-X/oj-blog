1967 - 输出字符的ascii码

题目描述

从键盘读入一个字符，请计算并输出该字符的 ascii 码。

比如：字符 'AAA' 的 ascii 码输出是 656565 ，'aaa' 的 ascii 码输出是 979797 ，'000' 的ascii码输出是 484848 。

输入

一个字符。

输出

一个整数，代表字符对应的 ascii 码。

AC代码

AC代码

#include<iostream>
using namespace std;

int main(){
    char a;
    cin >> a;
    int x = a;
    cout << x << endl;
}
