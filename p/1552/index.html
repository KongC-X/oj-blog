1552 - 基因组分析

题目描述

乌龟得到了他的基因组，一个只包含 ATCG 四种字母的字符串。乌龟想起科学家说，基因组中很多片段都多次重复出现，而且这种重复是很有意义的，于是他想计算一下自己基因组里片段的重复情况。

给定一个基因组，其中一个长度为 kkk 的子串称为一个“kkk - 片段”。乌龟希望你计算出基因组中不同的 kkk - 片段数量。例如，基因组 TACAC 的 222 - 片段有 TA ，AC，CA，AC ，其中不同的片段数量有 333 个。

输入

整数 nnn，kkk，R1R_1R1​，表示基因组的长度，片段的长度和数列生成的首项。基因组第 iii 个字符在 Rimod  4R_i \mod 4Ri​mod4 的值为 0,1,2,30,1,2,30,1,2,3 时分别为 A， T，C，G。

试题中使用的生成数列 RRR 定义如下：整数 在输入中给出。对于 i>1i>1i>1 ，$R_i = (R

i−1i-1i−1

\times 6807 + 2831) \mod 201701$ 。

输出

一个整数，表示不同的 kkk - 片段的数量

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

// 思路：截取所有的k片段，逐个判断在字符串数组a中是否存在k片段。

int n,k,r;
string t = "ATCG";
string s = "";
string a[30];//存放不相同的k片段
int len = 0;//代表a数组长度 
bool f;

int main() {
    cin>>n>>k>>r;
    //计算出每个字母 
    for(int i = 1;i <= n;i++){
        s = s + t[r%4];
        r = (r*6807+2831)%201701;
    }
    
    //从每个位置开始截取k片段
    for(int i = 0;i <= s.size() - k;i++){
        string w = s.substr(i,k);
        //判断w在a数组中是否存在 
        f = false;//假设不存在
        //循环a数组
        for(int j = 0;j < len;j++){
            if(a[j] == w){
                f = true;
                break;
            }
        } 
        
        //如果a数组没有w，存入
        if(f == false){
            a[len] = w;
            len++;
        } 
    } 
    
    cout<<len;
    
    return 0;
}
