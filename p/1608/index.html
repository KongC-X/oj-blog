1608 - 三位数运算

题目描述

小丽在编程课上学会了拆位运算，她已经可以拆出一个三位整数的百位、十位和个位了，她想知道这个整数的（百位 +++ 十位） /// （十位 +++ 个位）的结果是多少，请编程帮她实现？（请注意，计算结果要保留 222 位小数）。

比如：整数 135135135 的（百位 +++ 十位）/// （十位 +++ 个位）的计算结果 =（1+3）/（3+5）=4/8=0.50= （1+3）/（3+5） = 4 / 8 = 0.50=（1+3）/（3+5）=4/8=0.50 。

输入

读入一个三位的正整数 nnn（nnn 的各个位中都不含数字 000）。

输出

输出这个三位正整数（百位 +++ 十位）除以（十位 +++ 个位）的计算结果，保留 222 位小数。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int main()
{
    int a,b,c,n;
    double s;
    cin>>n;
    a=n%100%10; // 个
    b=n%100/10; // 十
    c=n/100; // 百
    s=(c+b)*1.0/(b+a);
    cout<<fixed<<setprecision(2)<<s;
    
    
}
