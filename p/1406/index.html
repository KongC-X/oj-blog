1406 - 石头剪刀布？

题目描述

石头剪刀布是常见的猜拳游戏。石头胜剪刀，剪刀胜布，布胜石头。如果两个人出拳一样，则不分胜负。一天，小 aaa 和小 bbb 正好在玩石头剪刀布，假设 111 代表石头， 222 代表剪刀， 333 代表布。小 aaa 和小 bbb 一共玩了 nnn 轮，请问最后的比赛结果是小 aaa 赢了还是小 bbb 赢了，还是平局？

注意：最终输赢按照小 aaa 和小 bbb 赢的总次数计算。例如：共比赛 777 局，小 aaa 赢了 444 局，小 bbb 赢了 333 局，那么输出“ a$ $win ”。

输入

第一行，是一个整数 nnn （ n≤100n \le 100n≤100 ）

接下来 nnn 行，每行有 222 个数，分别代表每轮比赛中小 aaa 和小 bbb 的出拳。

输出

如果小 aaa 赢了，输出字符串“ a win ”，如果小 bbb 赢了，输出字符串“ b win ”，如果平局则输出字符串“ tie ”。（请注意：输出的字符串全部是小写）

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    //aw代表a赢的局数,bw代表b赢的局数 
    int n,i,j,a[101][3],aw=0,bw=0;
    cin>>n;
    //读入二维数组
    //先循环行 
    for(i=0;i<n;i++){
        //再循环列 
        for(j=0;j<2;j++){
            cin>>a[i][j];
        }
        //判断比赛结果谁输谁赢 
        if((a[i][0]==1&&a[i][1]==2)||(a[i][0]==2&&a[i][1]==3)||(a[i][0]==3&&a[i][1]==1)){
            aw++;
        }else if((a[i][0]==1&&a[i][1]==3)||(a[i][0]==2&&a[i][1]==1)||(a[i][0]==3&&a[i][1]==2)){
            bw++;
        }
    }
    
    if(aw>bw){
        cout<<"a win";
    }else if(aw<bw){
        cout<<"b win";
    }else{
        cout<<"tie";
    } 
     
    return 0;
}
