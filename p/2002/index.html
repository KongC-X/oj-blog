2002 - 投篮(b.cpp)

题目描述

小 X 刚把猜先的程序交给少年宫的小朋友就接到了健身教练的电话，教练要求他马上到中天体育馆练习投篮，之所以选择投篮这个项目，主要目的是要在帮助小 X 减肥的同时还能预防颈椎病。

小 X 每次必须投满规定的积分才能结束投篮，积分规则是这样的：小 X 每投中一个球得 111 分，如果没投中但球碰到了篮框、篮板或篮网则既不得分也不扣分，如果球啥也没碰到(俗称三不沾)则倒扣 111 分，作为奖励小 X 如能连续投中 333 球则额外加 111 分，如连续投中 444 球则额外加 222 分，依次类推，即连续投中 KKK 球(K≥3K \ge 3K≥3)则额外加 K−2K-2K−2 分。

教练每次给小X 计分都很辛苦，于是他要求小 X 设计一个能自动计分的程序，小 X 觉得这个程序也很简单，于是他把这个任务又交给了你！

输入

输入数据共有两行，第一行为一个正整数 nnn，表示小 X 共进行了 nnn 次投篮。

第二行为一个由 nnn 个字符组成的字符串，该字符串只包含三种字符，分别是大写字母 V,T,X，其中 V 表示投中了， T 表示没投中但不用扣分， X 表示要扣 111 分。

输出

输出一行仅有一个整数为小 X 的得分。

解题思路

AC代码

#include<iostream>
#include<algorithm>
#include<cmath>
using namespace std;
char a[1000000];
int b[1000000];
int main(){
    int n;
    cin>>n;
    for(int i=1;i<=n;i++){
        cin>>a[i]; 
    }
    int sum=0,k=0;
    /*
    8
    VVVTTXVV
    3+1 -1 +2=5
    */
    for(int i=1;i<=n;i++){
        if(a[i]=='V'){
            k++;
            sum++;
        }
        if(i==n || a[i+1]!='V'){
            if(k>=3){
                sum=sum+k-2;
            }
            k=0;
        }
        if(a[i]=='X'){
            sum--;
        }
    }
    cout<<sum;
    return 0;
}
