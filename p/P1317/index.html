P1317 低洼地

洛谷 | 入门 | C++14 | 提交时间: 2026-05-27

算法标签：模拟、洛谷原创

题目描述

一组数，分别表示地平线的高度变化。高度值为整数，相邻高度用直线连接。找出并统计有多少个可能积水的低洼地？

如图：地高变化为 [0,1,0,2,1,2,0,0,2,0][0,1,0,2,1,2,0,0,2,0][0,1,0,2,1,2,0,0,2,0]。

输入格式

两行，第一行 n,n,n, 表示有 nnn 个数。第 222 行连续 nnn 个数表示地平线高度变化的数据，保证首尾为 000。(3≤n≤10000,0≤(3 \le n \le 10000,0 \le(3≤n≤10000,0≤ 高度 ≤1000)\le 1000)≤1000)。

输出格式

一个数，可能积水低洼地的数目。

样例

样例输入 #1

10
0 1 0 2 1 2 0 0 2 0

样例输出 #1

3```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;                         // 数据个数
    cin >> n;
    int a[10005];                  // 存放高度，下标从0开始
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int ans = 0;                   // 低洼地个数
    int down = 0;                  // 标记是否处于下降之后的状态，1 表示经历过下降

    // 遍历数组，寻找“下降后上升”形成的谷底
    for (int i = 1; i < n; i++) {
        if (a[i] > a[i - 1]) {     // 当前上升
            if (down) {            // 之前有下降，则形成了一个谷底
                ans++;
                down = 0;          // 重置标记，避免重复计数
            }
        } else if (a[i] < a[i - 1]) { // 当前下降
            down = 1;              // 记录经历了下降
        }
        // 相等时不做任何改变，保持 down 状态，从而将连续平坦的底部视为一个低洼地
    }

    cout << ans << '\n';
    return 0;
}
