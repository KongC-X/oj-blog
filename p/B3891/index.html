B3891 [语言月赛 202311] 基因

洛谷 | 普及- | C++14 | 提交时间: 2026-07-29

算法标签：2023、O2优化、字符串（入门）、语言月赛

题目描述

有一个长度为 $n$ 的字符串 $S$。其只包含有大写字母。

小 A 将 $S$ 进行翻转后，得到另一个字符串 $S'$。两个字符串 $S$ 与 $S'$ 对应配对。例如说，对于 $S=\tt{ATCGT}$，则有 $S'=\tt{TGCTA}$，$S$ 与 $S'$ 进行配对。

对于两个字符串 $S,S'$ 的第 $i$（$1 \leq i \leq n$）个字母，配对规则如下：

  • 定义 $\tt A$ 与 $\tt T$，$\tt C$ 与 $\tt G$ 为可以配对的字母。
  • 如果 $S_i$ 与 $S_i'$ 为可以配对的字母，那么该字符串的稳定性增加 $i$。
  • 如果 $S_i$ 或者 $S_i'$ 中任意一方出现非 $\tt A,\tt T,\tt C,\tt G$ 的字母，则整个字符串的稳定性将直接为 $0$。

现在给定 $T$ 个字符串 $S$，对每一个字符串，询问若用其翻转再进行配对，其稳定性将如何。

输入格式

第一行输入一个正整数 $T$，表示给定多少个字符串。对于每一个字符串：

  • 第一行输入一个正整数 $n$，表示字符串的长度；
  • 第二行输入一个字符串 $S$，表示该字符串。

输出格式

对于每个字符串，输出一行一个整数，表示若用其翻转再进行配对，其稳定性将如何。

样例

样例输入 #1

3
5
ATCGT
6
ACATGT
5
ATCGU```

**样例输出 #1**

6
21
0```

AC 代码

#include <iostream>
#include <string>
using namespace std;

// 判断两个字符是否为可配对的碱基对 (A-T 或 C-G)
bool match(char x, char y) {
    return (x == 'A' && y == 'T') || (x == 'T' && y == 'A') ||
           (x == 'C' && y == 'G') || (x == 'G' && y == 'C');
}

int main() {
    int T;                    // T: 测试数据组数
    cin >> T;
    while (T--) {
        int n;                // n: 字符串长度
        string s;             // s: 输入的字符串
        cin >> n >> s;

        // 检查是否含有非法字符（非 A,T,C,G）
        bool ok = true;
        for (int i = 0; i < n; i++) {
            char c = s[i];
            if (c != 'A' && c != 'T' && c != 'C' && c != 'G') {
                ok = false;
                break;
            }
        }
        if (!ok) {
            cout << 0 << endl;
            continue;
        }

        long long ans = 0;   // 稳定性总和，可能超过 int，用 long long
        // 遍历每个位置 i（1‑based），检查 s[i-1] 与 s[n-i] 是否配对
        for (int i = 1; i <= n; i++) {
            if (match(s[i - 1], s[n - i])) {
                ans += i;
            }
        }

        cout << ans << endl;
    }
    return 0;
}
