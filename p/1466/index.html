1466 - 等差数

题目描述

PeterPeterPeter 同学刚刚在学校学习了等差数列的概念。

等差数列，指的是一组数，这些数连续 222 个数的差值是相等的，比如：123，135，8521 2 3，1 3 5，8 5 2123，135，852，这些数的连续两个数的差值都是相等的。

PeterPeterPeter 根据等差数列的概念，自己定义了一个等差数的概念，这种数如果连续 222 位的差值相等，PeterPeterPeter 就认为它是等差数，比如：123,159,1357,852123,159,1357,852123,159,1357,852 等这些数都是等差数。

请你编程帮助 PeterPeterPeter 同学找出从 m∼nm \sim nm∼n之间，有哪些等差数？

输入

两个整数 mmm 和 n（m≤nn（m \le nn（m≤n，且 mmm 和 nnn 都是100∼9999100 \sim 9999100∼9999 之间的数）

输出

输出 m∼nm \sim nm∼n 之间的等差数，每行 111 个。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    //m,n为输入的两个整数
    //q,b,s,g为千位,百位,十位,个位 
    int i,q,b,s,g,m,n;
    cin>>m>>n;
    //遍历m到n的整数 
    for(i=m;i<=n;i++){
        //对i拆位 
        q=i/1000;
        b=i/100%10;
        s=i%100/10;
        g=i%10;
        //判断是三位数还是4位数 
        if(q==0){
            if(b-s==s-g){
                cout<<i<<endl;
            }
        }else{
            if(q-b==b-s&&b-s==s-g){
                cout<<i<<endl;
            }
        }
    }
    return 0;
}
