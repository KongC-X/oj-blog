1135 - 歌德巴赫猜想

题目描述

任一个大于等于 444 的偶数都可以拆分为两个素数之和。

从键盘读入一个整数 nnn，请将小于等于 nnn 的偶数拆分为 222 个质数之和，列出所有方案。

输入

一个整数 nnn (4≤n≤2004 \le n \le 2004≤n≤200）；

输出

将小于等于 nnn 的偶数拆分为 222 个质数之和，列出所有方案，输出格式请参考样例输出。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

//素数判断 
bool prime(int n){
    if(n <= 1) return false;
    for(int i = 2;i <= sqrt(n);i++){
        if(n % i == 0){
            return false;
        }
    } 
    
    return true;
} 

int main() {
    int n;
    cin>>n;
    //循环4~n之间的偶数
    for(int i = 4;i <= n;i += 2){
        //将i拆成2个素数的和
        for(int j = 2;j <= i / 2;j++){
            if(prime(j)==true && prime(i-j)==true){
                cout<<i<<"="<<j<<"+"<<i-j<<endl;
            }
        } 
    } 
    return 0;
}
