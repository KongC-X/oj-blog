P17458 [GESP202609 六级] 分树规划

洛谷 | 普及- | C++14 | 提交时间: 2026-09-18

题目描述

老师有一棵有 nnn 个结点的树，结点依次以 1,2,…,n1,2,\ldots,n1,2,…,n 编号。

老师想将这棵树作为奖品分给两位同学。具体而言，老师会选择一条边并从树上删去它，从而将这棵树分为两个连通块。两位同学分别可以得到其中一个连通块。

如果有同学拿到的连通块结点数明显小于另一位同学，那么这位同学会不太高兴。为了避免这种情况出现，老师想知道两个连通块结点数之差的绝对值最小是多少。

输入格式

第一行，一个正整数 nnn，表示结点数量。

接下来 n−1n-1n−1 行，每行两个正整数 ui,viu_i,v_iui​,vi​，表示一条连接结点 uiu_iui​ 和结点 viv_ivi​ 的边。

输出格式

输出一行，一个整数，表示答案。

样例

样例输入 #1

4
1 2
2 3
3 4```

**样例输出 #1**

0```

样例输入 #2

6
1 2
1 3
1 4
1 5
5 6```

**样例输出 #2**

2```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int n, c = 0;            // n: 结点数, c: 边计数器
int h[20005];            // h[u]: 结点 u 的第一条边
int e[40005];            // e[i]: 第 i 条边的终点
int ne[40005];           // ne[i]: 第 i 条边的下一条边
int s[20005];            // s[u]: 以 u 为根的子树大小

// 添加一条从 u 到 v 的边
void add(int u, int v) {
    e[++c] = v;
    ne[c] = h[u];
    h[u] = c;
}

// 深度优先搜索，计算子树大小
void dfs(int u, int f) {
    s[u] = 1;            // 自身算一个结点
    for (int i = h[u]; i; i = ne[i]) {
        int v = e[i];
        if (v == f) continue;   // 不往回走
        dfs(v, u);
        s[u] += s[v];           // 累加子树的结点数
    }
}

int main() {
    /*
     * 题目：P17458 [GESP202609 六级] 分树规划
     * 题意：一棵 n 个结点的树，删去一条边分成两个连通块，
     *       求两个连通块结点数之差的最小绝对值。
     *
     * 思路：
     * 1. 任选 1 为根，DFS 求出每个结点的子树大小 s[u]。
     * 2. 对于每个非根结点 u（u=2..n），它与父结点之间的边被删除后，
     *    一个连通块是 u 的子树（大小 s[u]），另一个是剩余部分（大小 n - s[u]）。
     *    差值绝对值为 |n - 2 * s[u]|。
     * 3. 遍历所有非根结点，取差值绝对值的最小值即为答案。
     *
     * 时间复杂度：O(n)，n ≤ 20000，完全可行。
     */
    cin >> n;
    for (int i = 1; i < n; i++) {
        int u, v;
        cin >> u >> v;
        add(u, v);
        add(v, u);
    }

    dfs(1, 0);               // 从 1 开始 DFS，父结点为 0

    int ans = n;             // 答案初始为 n（最大差值）
    for (int i = 2; i <= n; i++) {
        int d = abs(n - 2 * s[i]);   // 差值绝对值
        if (d < ans) ans = d;
    }

    cout << ans << endl;
    return 0;
}
