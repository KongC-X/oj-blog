2297 - 特殊求和

题目描述

如果一个数能够被 $7$ 整除或者十进制表示中含有数字 $7$ ，那么我们称这个数为幻数，比如 $17$ ， $21$ ， $73$ 是幻数，而 $6，59$ 不是。

对于给定的 $N$ ，求出 $1 \sim N$ 中所有幻数的和。

输入

一个整数 $N（1 \lt N \lt 10000）$ 。

输出

一个整数，表示 $1 \sim N$ 中所有幻数的和。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int main(){
    int n,t,s=0;
    cin>>n;

    for(int i=1; i<=n; i++){
        t = i;
        while(t!=0){
            if(t%10==7||i%7==0){
                s = s + i;
                break;
            }
            t=t/10;
        }
    }
    cout<<s;
    return 0;
}
