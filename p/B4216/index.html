B4216 [常州市赛 2023] 矩形纸片

洛谷 | 普及- | C++14 | 提交时间: 2026-07-25

算法标签：数学、2023、江苏、科创活动、小学活动

题目背景

搬运自 http://czoj.com.cn/p/673。数据为民间数据。

题目描述

小 X 有一个 $10^9$ 行 $10^9$ 列的网格纸，每个格子都是一个单位长度的正方形。

现在小 X 还有两个矩形纸片，矩形的边长都是单位长度的整数倍。第一个矩形纸片的长为 $a$，宽为 $b$，第二个矩形纸片的长为 $c$，宽为 $d$。

小 X 把第一个纸片放在了整张网格纸的左上角，再把第二个纸片的左上角放在第 $x$ 行第 $y$ 列的格子的左上角上，并且不旋转或者翻转纸片。

小 X 想知道两张纸片覆盖网格纸的总面积。

例如，当 $a=2,b=4,c=5,d=3,x=2,y=3$ 时，覆盖情况如下图所示，覆盖的总面积为 $21$ 单位面积。

输入格式

一行 $6$ 个正整数 $a,b,c,d,x,y$。

输出格式

输出两张纸片覆盖网格纸的总面积。

样例

样例输入 #1

2 4 5 3 2 3```

**样例输出 #1**

21```

样例输入 #2

4 5 2 8 1 1```

**样例输出 #2**

26```

样例输入 #3

5 5 5 5 2 3```

**样例输出 #3**

38```

AC 代码

#include <iostream>
#include <algorithm>
using namespace std;

int main() {
    int a, b, c, d, x, y;
    cin >> a >> b >> c >> d >> x >> y;

    // 计算两个矩形重叠部分的行（即高度）区间和列（即宽度）区间
    int r1 = max(1, x);          // 重叠部分起始行（较大的起始行）
    int r2 = min(a, x + c - 1);  // 重叠部分结束行（较小的结束行）
    int s1 = max(1, y);          // 重叠部分起始列（较大的起始列）
    int s2 = min(b, y + d - 1);  // 重叠部分结束列（较小的结束列）

    int t = 0;                   // 重叠面积
    if (r1 <= r2 && s1 <= s2) {
        t = (r2 - r1 + 1) * (s2 - s1 + 1);
    }

    int ans = a * b + c * d - t; // 总面积 = 两矩形面积和 - 重叠面积
    cout << ans << endl;

    return 0;
}
