1400 - 补发礼物？

题目描述

学校组织了一次晚会，小明负责为晚会准备 nnn 种不同类型的小礼品，学校对于礼品数量的要求是每种至少 101010 个，而且每种礼品的数量必须是 444 的倍数。小明在准备时由于粗心，很多礼品的数量准备得都不能满足要求。

请你编程帮小明把每种礼品的数量补充到刚好满足要求，并按照由多到少排序输出各种礼物的数量。当然补充的数量越少越好；比如：有一种礼品小明准备了 888 个，小明至少要准备到 121212 个才能满足要求；另一种物品小明准备了 161616 个，就不需要补充了。

输入

第一行一个整数 nnn ，代表礼物的种类（ n≤100n \le 100n≤100 ）；

第二行 nnn 个整数，分别代表小明目前准备的各类礼物的数量。

输出

111 行，nnn 个数，空格隔开，代表 nnn 种礼物补充到正好满足要求的数值，按照从大到小排序。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int a[110];
int main(){
int n,k=0;
cin>>n;
for(int i=1;i<=n;i++){
    cin>>a[i];
}
for(int i=1;i<=n;i++){
    if(a[i]<10 || a[i]%4!=0){
        for(int j=0;;j++){
            if((a[i]+j)%4==0&&(a[i]+j)>=10){
                a[i]=a[i]+j;
                break;
            }
        }
    }
}
sort(a+1,a+n+1);
for(int i=n;i>=1;i--){
    cout<<a[i]<<" ";
}

return 0;

}
