P2234 [HNOI2002] 营业额统计

洛谷 | 普及- | C++14 | 提交时间: 2026-05-15

算法标签：2002、二分、各省省选、湖南、排序

题目描述

Tiger 最近被公司升任为营业部经理，他上任后接受公司交给的第一项任务便是统计并分析公司成立以来的营业情况。

Tiger 拿出了公司的账本，账本上记录了公司成立以来每天的营业额。分析营业情况是一项相当复杂的工作。由于节假日，大减价或者是其他情况的时候，营业额会出现一定的波动，当然一定的波动是能够接受的，但是在某些时候营业额突变得很高或是很低，这就证明公司此时的经营状况出现了问题。经济管理学上定义了一种最小波动值来衡量这种情况：当最小波动值越大时，就说明营业情况越不稳定。

而分析整个公司的从成立到现在营业情况是否稳定，只需要把每一天的最小波动值加起来就可以了。你的任务就是编写一个程序帮助 Tiger 来计算这一个值。

我们定义，一天的最小波动值 = $\min{|\text{该天以前某一天的营业额}-\text{该天营业额}|}$。

特别地，第一天的最小波动值为第一天的营业额。

输入格式

第一行为正整数 $n$（$n \leq 32767$） ，表示该公司从成立一直到现在的天数，接下来的 $n$ 行每行有一个整数 $a_i$（$|a_i| \leq 10^6$) ，表示第 $i$ 天公司的营业额，可能存在负数。

输出格式

输出一个整数，即每一天最小波动值的和，保证结果小于 $2^{31}$。

样例

样例输入 #1

6
5
1
2
5
4
6

样例输出 #1

12```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
【题目思路与解题过程】
题意：有 n 天的营业额，第 i 天的最小波动值定义为：
     min( |当天的营业额 - 之前某天的营业额| )
     特别地，第一天的最小波动值就是第一天的营业额（本身，不是绝对值）。
     求这 n 天最小波动值的总和。

解题思路：
1. 我们需要一个能动态插入并快速查询前驱和后继的数据结构。
   set（有序集合）基于红黑树，能自动排序，并提供 O(log n) 的插入和查找。
2. 对于每天营业额 x：
   - 在 set 中查找不小于 x 的第一个元素（后继），用 lower_bound。
   - 若存在后继，计算差值；若存在前驱（即该迭代器不是 begin()），
     将迭代器前移一位得到前驱，计算差值。
   - 取所有可能差值的最小值作为当天的最小波动值，累加到答案中。
   - 将 x 插入 set，供后续使用。
3. 边界情况：
   - 第一天直接取 x（注意不是 |x|）作为波动值，并插入 set。
   - 如果 set 为空（仅第一天），直接处理。
   - 注意 x 可能为负数，差值的绝对值要用 abs。
*/

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n;                        // n: 天数
    cin >> n;
    
    set<int> s;                   // s: 维护之前所有营业额的平衡树
    long long ans = 0;            // ans: 最小波动值的总和（可能超 int）
    
    for (int i = 1; i <= n; ++i) {
        int x;                    // x: 当天营业额
        cin >> x;
        
        if (i == 1) {             // 第一天，波动值就是 x 本身（题目规定，不能加绝对值）
            ans += x;
            s.insert(x);
            continue;
        }
        
        // 查找后继：第一个 >= x 的元素
        set<int>::iterator it = s.lower_bound(x);
        int best = 2147483647;    // best: 当前找到的最小差值，初始化为极大值
        
        if (it != s.end()) {      // 存在后继
            best = min(best, abs(*it - x));
        }
        if (it != s.begin()) {    // 存在前驱
            --it;                 // 回退一位就是小于 x 的最大元素
            best = min(best, abs(*it - x));
        }
        
        ans += best;              // 累加当天波动值
        s.insert(x);              // 将当天营业额加入集合
    }
    
    cout << ans << '\n';
    return 0;
}
