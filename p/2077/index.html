2077 - 奖品采购

题目描述

为了迎接班级的元旦晚会，班主任王老师特批了 mmm 元请你帮忙采购物品，并给你一张清单，注明了王老师调研小卖部中出售的 nnn 个待选物品的价格、价值（价值越高，同学们越喜欢）、以及最多能买到的数量。

请你编程计算出，mmm 元最多能够采购到的物品的最大价值是多少？注意，mmm 元不一定都要花完。

输入

第 111 行两个数 nnn (n≤500n \le 500n≤500)，mmm (m<6000m \lt 6000m<6000)，其中 nnn 代表清单中待选物品总数，mmm 表示王老师的拨款金额。

接下来 nnn 行，每行 333 个数，ppp、vvv、sss 分别表示第 iii 种物品的价格、价值和能够买的最大数量（买 000 件到 sss 件均可），其中 p≤100,v≤100,s≤10p \le 100,v \le 100,s \le 10p≤100,v≤100,s≤10 。

输出

输出一个整数，表示能够采购到的最大价值。

AC代码

#include <bits/stdc++.h>
using namespace std;

const int M = 6005;            // 最大预算 +5
int f[M];                      // dp[j] 表示花费 j 元能获得的最大价值

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, m;                  // n:物品种类, m:预算
    cin >> n >> m;

    // ---------- 思路 ----------
    // 多重背包问题：每种物品有限定数量。
    // 状态定义：f[j] 表示花费 j 元可获得的最大价值。
    // 初始条件：f[0] = 0，其余为0。
    // 状态转移：对于第 i 种物品（价格 p，价值 v，数量 s），
    //   枚举容量 j 从 m 到 0（倒序避免重复使用），
    //   再枚举该物品选取数量 k（0..s），
    //   若 j >= k*p，则 f[j] = max(f[j], f[j - k*p] + k*v)
    // 复杂度 O(n * m * s)，n=500,m=6000,s=10 → 约 3e7，可过。

    for (int i = 1; i <= n; i++) {
        int p, v, s;           // 价格、价值、数量限制
        cin >> p >> v >> s;
        // 多重背包倒序枚举容量
        for (int j = m; j >= 0; j--) {
            // 枚举该物品选取 k 件
            for (int k = 0; k <= s; k++) {
                if (j >= k * p) {
                    f[j] = max(f[j], f[j - k * p] + k * v);
                }
            }
        }
    }

    cout << f[m] << '\n';
    return 0;
}
