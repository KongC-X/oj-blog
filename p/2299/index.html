2299 - 苹果和虫子2

题目描述

你买了一箱 nnn 个苹果，很不幸的是买完时箱子里混进了一条虫子。虫子每 xxx 小时能吃掉一个苹果，假设虫子在吃完一个苹果之前不会吃另一个，那么经过 yyy 小时你还有多少个完整的苹果？

输入

输入仅一行，包括 n，xn，xn，x 和 yyy （均为整数）。

输出

输出也仅一行，剩下的苹果个数。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    int n,x,y;
    cin>>n>>x>>y;
    
    int m; //吃掉的苹果数量
    if(y%x==0){
        m = y/x;	
    }else{
        m = y/x+1;
    }
    if(m>=n){
        cout<<0;
    }else{
        cout<<n-m;
    }
    return 0;
}
