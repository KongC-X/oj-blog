1457 - 子数整除

题目描述

于一个五位数 abcdeabcdeabcde ，可将其拆分为三个子数：

sub1=abcsub1=abcsub1=abc

sub2=bcdsub2=bcdsub2=bcd

sub3=cdesub3=cdesub3=cde

例如，五位数 202072020720207 可以拆分成
sub1=202sub1=202sub1=202

sub2=020sub2=020sub2=020 (也就是 202020)

sub3=207sub3=207sub3=207

现在给定一个正整数 KKK ，要求你编程求出 100001000010000 到300003000030000 之间所有满足下述条件的五位数，条件是这些五位数的三个子数 sub1,sub2,sub3sub1,sub2,sub3sub1,sub2,sub3 都可被 KKK 整除。

输入

一个正整数 K（0<K<1000）K（0 \lt K \lt 1000）K（0<K<1000） 。

输出

每一行为一个满足条件的五位数，要求从小到大输出。

不得重复输出或遗漏。如果无解，则输出 No。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    //num计数满足条件的数的个数 
    int k,sub1,sub2,sub3,num=0;
    cin>>k;
    //遍历10000到30000之间的五位数 
    for(int i=10000;i<=30000;i++){
        sub1=i/100;
        sub2=i/10%1000;
        sub3=i%1000;
        if(sub1%k==0&&sub2%k==0&&sub3%k==0){
            cout<<i<<endl;
            num++;
        }
    }
    // 如果无解，则输出“No”
    if(num==0){
        cout<<"No";
    }
     
    return 0;
}
