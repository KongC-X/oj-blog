P1548 [NOIP 1997 普及组] 棋盘问题

洛谷 | 入门 | C++14 | 提交时间: 2026-06-05

算法标签：1997、NOIP 普及组、枚举

题目背景

NOIP1997 普及组第一题

题目描述

设有一个 N×MN \times MN×M 方格的棋盘 (1≤N≤100,1≤M≤100)(1≤N≤100,1≤M≤100)(1≤N≤100,1≤M≤100)

求出该棋盘中包含有多少个正方形、多少个长方形（不包括正方形）。

例如：当 N=2,M=3N=2, M=3N=2,M=3 时：

正方形的个数有 888 个：即边长为 111 的正方形有 666 个；边长为 222 的正方形有 222 个。

长方形的个数有 101010 个：

即

  • 2×12 \times 12×1 的长方形有 444 个：

  • 1×21 \times 21×2 的长方形有 333 个：

  • 3×13 \times 13×1 的长方形有 222 个：

  • 3×23 \times 23×2 的长方形有 111 个：

输入格式

一行两个整数 N,MN,MN,M。

输出格式

一行两个整数，表示正方形的个数与长方形的个数。

样例

样例输入 #1

2 3```

**样例输出 #1**

8 10```

AC 代码

#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n, m;
    cin >> n >> m;
    
    long long sq = 0;    // 正方形个数
    long long rect = 0;  // 长方形个数（不含正方形）
    
    // 枚举左上角 (i, j)，1‑based
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            // 枚举右下角 (p, q)，右下角的行和列必须 ≥ 左上角
            for (int p = i; p <= n; p++) {
                for (int q = j; q <= m; q++) {
                    // 计算矩形的高度和宽度
                    int h = p - i + 1;
                    int w = q - j + 1;
                    // 判断是否为正方形
                    if (h == w) {
                        sq++;
                    } else {
                        rect++;
                    }
                }
            }
        }
    }
    
    cout << sq << ' ' << rect << '\n';
    return 0;
}
