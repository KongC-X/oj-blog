1782 - 字符图形2-星号倒直角

题目描述

请打印 $n$ 行的星号倒直角三角形。

输入

一个整数 $n$（ $n \le 10$ ）。

输出

输出如下方图所示 $n$ 行的星号倒直角三角形。

AC代码

# include <iostream>
using namespace std;

int main() {
    int i,j,n;
    cin >> n;
    for(i = 0;i < n;i++) {
        for(j = n;j > i;j--) {
            cout << "*";
        } 
        cout << endl;
    }
}
