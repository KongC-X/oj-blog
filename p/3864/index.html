3864 - 宝箱

题目描述

小杨发现了$n$个宝箱，其中第 $i$ 个宝箱的价值是 $a_i$ 。

小杨可以选择一些宝箱放入背包并带走，但是小杨的背包比较特殊，假设小杨选择的宝箱中最大价值为 $x$，最小价值为$y$，小杨需要保证 $x-y \le k$，否则小杨的背包会损坏。

小杨想知道背包不损坏的情况下，自己能够带走宝箱的总价值最大是多少。

输入

第一行包含两个正整数 $n，k$ ，含义如题目所示。

第二行包含 $n$ 个正整数 $a_1, a_2 ,...a_n$，代表宝箱的价值。

输出

输出一个整数，代表带走宝箱的最大总价值。

AC代码

AC代码

#include<bits/stdc++.h>

using namespace std;

int main(){ 

    int n,k;

    cin>>n>>k;

    int a[n];

    for(int i=0;i<n;i++){

        cin>>a[i];

    }

    sort(a,a+n);

    int ans=0;

    

    for(int i=0;i<n;i++){

        int s=0;

        // 修改这里：j>=0 而不是 j>=1

        for(int j=i;j>=0;j--){  

            if(a[i]-a[j]<=k){

                s=s+a[j];

            }

            else{

                break;

            }

        }

        ans=max(ans,s);

    }

    cout<<ans;

    return 0;

}
