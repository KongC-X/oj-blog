P17828 [CSP-J 2026] 回文串 / string（民间数据）

洛谷 | 普及- | C++14 | 提交时间: 2026-11-01

算法标签：O2优化、2026、CSP-J 入门级

题目描述

小 R 有一个长度为 $L$ 的字符串 $S=s_1\ldots s_L$，其中只包含小写英文字母。小 R 发现，虽然 $S$ 可能很长，但它可以分成 $n$ 个连续的段，其中第 $i\ (1\le i\le n)$ 段由 $a_i$ 个小写英文字母 $c_i$ 构成。把这 $n$ 段依次拼接起来便得到 $S$，因此 $L=\sum_{i=1}^{n}a_i$。相邻两段中的字符可以相同。

小 X 喜欢回文串。若一个字符串反转后与原字符串相同，就称它是回文串，例如 aba、abba 都是回文串，而 aabbc 不是。也就是说，字符串 $S$ 是回文串，当且仅当对于所有 $i\ (1\le i\le L)$，均有 $s_i=s_{L+1-i}$。

小 X 想让小 R 把 $S$ 改成回文串。小 R 可以将 $S$ 中任意一个位置的字符修改成任意小写英文字母。他想用尽量少的修改满足小 X 的要求。

你需要帮助小 R 求出，他最少需要修改多少个位置的字符，才能将 $S$ 改成回文串。

输入格式

从文件 string.in 中读入数据。

输入的第一行包含一个正整数 $n$。

输入的第 $i+1\ (1\le i\le n)$ 行包含一个正整数 $a_i$ 和一个小写英文字母 $c_i$。

输出格式

输出到文件 string.out 中。

输出一行一个整数，表示小 R 最少需要修改多少个位置的字符，才能将 $S$ 改成回文串。

样例

样例输入 #1

3
2 a
2 b
1 c```

**样例输出 #1**

2```

样例输入 #2

2
2 a
3 a```

**样例输出 #2**

0```

样例输入 #3

6
1000000000 a
1000000000 a
1000000000 a
1000000000 b
1000000000 b
1000000000 b```

**样例输出 #3**

3000000000```

AC 代码

#include <bits/stdc++.h>
using namespace std;

long long a[200005];     // a[i]: 第 i 段的长度
char c[200005];          // c[i]: 第 i 段的字符

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i] >> c[i];

    long long ans = 0;
    int l = 1, r = n;                  // 左段编号、右段编号
    long long cl = a[1], cr = a[n];    // 左右两段当前还没配对完的字符个数

    while (l < r) {
        long long t = min(cl, cr);     // 这一次能批量配对 t 对
        if (c[l] != c[r]) ans += t;    // 字符不同，这 t 对每对都得改一个位置
        cl -= t;
        cr -= t;
        if (cl == 0) { l++; cl = a[l]; }   // 左段用完，换下一段
        if (cr == 0) { r--; cr = a[r]; }   // 右段用完，换上一段
    }
    // 结束时若 l == r，中间剩下的都属于同一段，字符全相同，不用改

    cout << ans << endl;
    return 0;
}
