P17828 [CSP-J 2026] 回文串 / string（民间数据）

洛谷 | 普及- | C++14 | 提交时间: 2026-11-01

算法标签：O2优化、2026、CSP-J 入门级

题目描述

小 R 有一个长度为 LLL 的字符串 S=s1…sLS=s_1\ldots s_LS=s1​…sL​，其中只包含小写英文字母。小 R 发现，虽然 SSS 可能很长，但它可以分成 nnn 个连续的段，其中第 i (1≤i≤n)i\ (1\le i\le n)i (1≤i≤n) 段由 aia_iai​ 个小写英文字母 cic_ici​ 构成。把这 nnn 段依次拼接起来便得到 SSS，因此 L=∑i=1naiL=\sum_{i=1}^{n}a_iL=∑i=1n​ai​。相邻两段中的字符可以相同。

小 X 喜欢回文串。若一个字符串反转后与原字符串相同，就称它是回文串，例如 aba、abba 都是回文串，而 aabbc 不是。也就是说，字符串 SSS 是回文串，当且仅当对于所有 i (1≤i≤L)i\ (1\le i\le L)i (1≤i≤L)，均有 si=sL+1−is_i=s_{L+1-i}si​=sL+1−i​。

小 X 想让小 R 把 SSS 改成回文串。小 R 可以将 SSS 中任意一个位置的字符修改成任意小写英文字母。他想用尽量少的修改满足小 X 的要求。

你需要帮助小 R 求出，他最少需要修改多少个位置的字符，才能将 SSS 改成回文串。

输入格式

从文件 string.in 中读入数据。

输入的第一行包含一个正整数 nnn。

输入的第 i+1 (1≤i≤n)i+1\ (1\le i\le n)i+1 (1≤i≤n) 行包含一个正整数 aia_iai​ 和一个小写英文字母 cic_ici​。

输出格式

输出到文件 string.out 中。

输出一行一个整数，表示小 R 最少需要修改多少个位置的字符，才能将 SSS 改成回文串。

AC 代码

#include <bits/stdc++.h>
using namespace std;

long long a[200005];     // a[i]: 第 i 段的长度
char c[200005];          // c[i]: 第 i 段的字符

int main() {
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i] >> c[i];

    long long ans = 0;
    int l = 1, r = n;                  // 左段编号、右段编号
    long long cl = a[1], cr = a[n];    // 左右两段当前还没配对完的字符个数

    while (l < r) {
        long long t = min(cl, cr);     // 这一次能批量配对 t 对
        if (c[l] != c[r]) ans += t;    // 字符不同，这 t 对每对都得改一个位置
        cl -= t;
        cr -= t;
        if (cl == 0) { l++; cl = a[l]; }   // 左段用完，换下一段
        if (cr == 0) { r--; cr = a[r]; }   // 右段用完，换上一段
    }
    // 结束时若 l == r，中间剩下的都属于同一段，字符全相同，不用改

    cout << ans << endl;
    return 0;
}
