1153 - 查找“支撑数”

题目描述

在已知一组整数中，有这样一种数非常怪，它们不在第一个，也不在最后一个，而且刚好都比左边和右边相邻的数大，你能找到它们吗？

输入

第一行为整数 $m$，表示输入的整数个数。（ $3 \le m \le 100$ )

第二行为 $m$ 个整数。

输出

若干个支撑数，每行一个。

解题思路

AC代码

AC代码

#include<iostream>
using namespace std;

int main(){
    int m,a[105];
    cin>>m;
    for(int i=0; i <= m - 1; i++){
        cin>>a[i];
    } 
    for(int i=1; i <= m - 2; i++){
        if(a[i]>a[i-1]&&a[i]>a[i+1]){
            cout<<a[i]<<endl;
        }
    }
    return 0; 
}
