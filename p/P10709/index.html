P10709 [NOISG 2024 Prelim] Party

洛谷 | 普及- | C++14 | 提交时间: 2026-08-05

算法标签：数学、贪心、2024、排序、NOISG（新加坡）

题目背景

翻译自 NOI SG 2024 Prelim B.Party。

题目描述

James 有 $n$ 个朋友，他想选择其中的 $0$ 个或者更多朋友来参加他的聚会。第 $i$ 个朋友如果参加了他的聚会，会产生 $a_i$ 点快乐值。注意：有些朋友并不想参加聚会，所以他们的 $a_i$ 会是负的。

然而，他家只有一排 $n$ 个座位，而且因为社交距离，两个人不能坐在相邻的座位上。现在 James 想知道，如果他按照最优方案邀请朋友，这些朋友的快乐值的和最大为多少。

输入格式

第一行，一个整数 $n$。

第二行 $n$ 个整数，表示 $a$。

输出格式

一行一个整数，表示答案。

样例

样例输入 #1

5
3 2 -1 4 5```

**样例输出 #1**

12```

样例输入 #2

1
10```

**样例输出 #2**

10```

样例输入 #3

6
1 -3 2 10 -4 9```

**样例输出 #3**

21```

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 比较函数：用于降序排序（从大到小）
bool cmp(long long p, long long q) {
    return p > q;   // 如果 p > q 返回 true，说明 p 排在 q 前面
}

int main() {
    /*
     * 【题目类型】贪心 + 排序
     * 【核心思路】
     * 1. 因为两个人不能坐相邻座位，所以最多能邀请的人数 = (n + 1) / 2（即 ceil(n/2)）。
     * 2. 我们只关心快乐值，座位可以任意分配，因此可以从所有朋友中任选不超过最大人数的朋友。
     * 3. 为了让快乐值和最大，肯定只会选正数（负数会降低总和），而且选最大的若干正数。
     * 4. 步骤：
     *    - 读入每个数，如果是正数就存入数组 pos 中，同时记录正数个数 cnt。
     *    - 如果 cnt <= 最大可坐人数，则全部正数相加即为答案。
     *    - 否则，将 pos 数组降序排序，取前 maxPeople 个正数相加。
     * 5. 如果没有任何正数，答案就是 0（因为可以选择 0 个朋友）。
     *
     * 【时间复杂度】O(n log n)（最坏情况所有数都是正数，需要排序）
     * 【空间复杂度】O(n)
     */

    int n;
    cin >> n;

    long long pos[200005];   // 存放所有正数（最多 n 个）
    int cnt = 0;             // cnt: 正数的个数

    // 读入所有快乐值，只保留正数
    for (int i = 0; i < n; i++) {
        long long x;
        cin >> x;
        if (x > 0) {
            pos[cnt] = x;
            cnt++;
        }
    }

    // 最多能邀请的人数
    int maxPeople = (n + 1) / 2;   // 相当于 ceil(n/2)

    long long ans = 0;   // 最终答案

    if (cnt <= maxPeople) {
        // 所有正数都能邀请，直接求和
        for (int i = 0; i < cnt; i++) {
            ans += pos[i];
        }
    } else {
        // 正数太多，只能选最大的 maxPeople 个
        sort(pos, pos + cnt, cmp);   // 降序排序
        for (int i = 0; i < maxPeople; i++) {
            ans += pos[i];
        }
    }

    cout << ans << endl;
    return 0;
}
