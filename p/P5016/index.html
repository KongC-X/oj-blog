P5016 [NOIP 2018 普及组] 龙虎斗

洛谷 | 普及- | C++14 | 提交时间: 2026-08-07

算法标签：模拟、2018、NOIP 普及组、枚举

题目背景

NOIP2018 普及组 T2

题目描述

轩轩和凯凯正在玩一款叫《龙虎斗》的游戏，游戏的棋盘是一条线段，线段上有 nnn 个兵营（自左至右编号 1∼n1 \sim n1∼n），相邻编号的兵营之间相隔 111 厘米，即棋盘为长度为 n−1n-1n−1 厘米的线段。iii 号兵营里有 cic_ici​ 位工兵。下面图 1 为 n=6n=6n=6 的示例：

轩轩在左侧，代表“龙”；凯凯在右侧，代表“虎”。 他们以 mmm 号兵营作为分界， 靠左的工兵属于龙势力，靠右的工兵属于虎势力，而第 mmm 号兵营中的工兵很纠结，他们不属于任何一方。

一个兵营的气势为：该兵营中的工兵数×\times× 该兵营到 mmm 号兵营的距离；参与游戏一方的势力定义为：属于这一方所有兵营的气势之和。

下面图 2 为 n=6,m=4n = 6,m = 4n=6,m=4 的示例，其中红色为龙方，黄色为虎方：

游戏过程中，某一刻天降神兵，共有 s1s_1s1​ 位工兵突然出现在了 p1p_1p1​ 号兵营。作为轩轩和凯凯的朋友，你知道如果龙虎双方气势差距太悬殊，轩轩和凯凯就不愿意继续玩下去了。为了让游戏继续，你需要选择一个兵营 p2p_2p2​，并将你手里的 s2s_2s2​ 位工兵全部派往兵营 p2p_2p2​，使得双方气势差距尽可能小。

注意：你手中的工兵落在哪个兵营，就和该兵营中其他工兵有相同的势力归属（如果落在 mmm 号兵营，则不属于任何势力）。

输入格式

输入文件的第一行包含一个正整数 nnn，代表兵营的数量。

接下来的一行包含 nnn 个正整数，相邻两数之间以一个空格分隔，第 iii 个正整数代 表编号为 iii 的兵营中起始时的工兵数量 cic_ici​。

接下来的一行包含四个正整数，相邻两数间以一个空格分隔，分别代表 m,p1,s1,s2m,p_1,s_1,s_2m,p1​,s1​,s2​。

输出格式

输出文件有一行，包含一个正整数，即 p2p_2p2​，表示你选择的兵营编号。如果存在多个编号同时满足最优，取最小的编号。

样例

样例输入 #1

6 
2 3 2 3 2 3 
4 6 5 2 ```

**样例输出 #1**

2```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】模拟 + 枚举
     * 【思路】
     * 1. 读入 n 和 c[1..n]。
     * 2. 读入 m, p1, s1, s2。
     * 3. 计算龙方气势（i<m）和虎方气势（i>m）。
     * 4. 加上 s1 的影响（若 p1<m 则加给龙，若 p1>m 则加给虎）。
     * 5. 枚举 p2 从 1 到 n：
     *    - 若 p2<m，s2 加给龙。
     *    - 若 p2>m，s2 加给虎。
     *    - 若 p2==m，不影响任何一方。
     *    计算差值，取绝对值，与最优比较，取更小或相等时更小编号。
     * 6. 输出最优 p2。
     *
     * 【时间复杂度】O(n)
     */

    int n;                  // n: 兵营数
    cin >> n;
    long long c[100005];    // c[i]: 第 i 个兵营的工兵数
    for (int i = 1; i <= n; i++) {
        cin >> c[i];
    }

    int m, p;               // m: 分界点, p: 神兵出现位置
    long long s, t;         // s: s1, t: s2
    cin >> m >> p >> s >> t;

    long long l = 0, r = 0; // l: 龙方气势, r: 虎方气势

    // 计算初始气势
    for (int i = 1; i < m; i++) {
        l += c[i] * (m - i);
    }
    for (int i = m + 1; i <= n; i++) {
        r += c[i] * (i - m);
    }

    // 加上 s1 的影响
    if (p < m) l += s * (m - p);
    else if (p > m) r += s * (p - m);

    long long ans = 1;          // 最优 p2
    long long best = 1e18;      // 最优差值绝对值

    for (int i = 1; i <= n; i++) {
        long long L = l, R = r;
        if (i < m) {
            L += t * (m - i);
        } else if (i > m) {
            R += t * (i - m);
        }
        long long dif = L - R;
        if (dif < 0) dif = -dif;   // 绝对值
        if (dif < best) {
            best = dif;
            ans = i;
        }
        // 如果 dif 相等，因为 i 从小到大，所以不需要更新
    }

    cout << ans << endl;
    return 0;
}
