4622 - 外观数列

题目描述

外观数列是一个整数序列，给定该数列的第一项数据之后，从第二项开始，每一项都是对前一项数据的描述。

例如：

  • 给定外观数列的第一项为 111；

  • 接下来第二项是对第一项数据的描述，即“一个 111”，记作 111111；

  • 第三项是对第二项数据的描述，即“两个 111”，记作 212121；

  • 第四项是对第三项数据的描述，即“一个 222，一个 111”，记作 121112111211；

  • 第五项是对第四项数据的描述，即“一个 111，一个 222，两个 111”，记作 111221111221111221；

以此类推......

给定外观数列的第一项 xxx 以及一个整数 nnn，请计算出该外观数列第 nnn 项的值。

例如：x=2x = 2x=2，n=3n = 3n=3，外观数列为：

`2
12
1112
3112
132112
......
`

外观数列第 333 项为 111211121112。

输入

输入两个整数 x（1≤x≤100）x（1 \le x \le 100）x（1≤x≤100）和 n（1≤n≤30)n（1 \le n \le 30)n（1≤n≤30)。

输出

输出一个整数，表示外观数列第 nnn 项的值。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 生成外观数列的第n项
string fun(int x,int n) {
    string result = to_string(x); // 将x转为字符串作为第一项
    for(int i = 1;i < n;i++) { // 从第二项开始循环生成
        string next = ""; // 用于存储下一项
        int count = 1; // 计数器，记录连续相同数字的个数
        for(int j = 1; j < result.size(); j++) { // 遍历当前字符串
            if(result[j] == result[j - 1]) {
                count++; // 如果当前数字与前一个相同，计数器加1
            } else {
                next += to_string(count) + result[j - 1]; // 否则，将计数和数字添加到下一项
                count = 1; // 重置计数器
            }
        }
        next += to_string(count) + result[result.size() - 1]; // 添加最后一组数字
        result = next; // 更新结果为下一项
    }
    return result; // 返回生成的外观数列的第n项
}

int main() {
    int x,n;
    cin >> x >> n; // 输入x和n
    string result = fun(x, n); // 调用函数生成外观数列的第n项
    cout << result << endl; // 输出结果
    return 0;
}
