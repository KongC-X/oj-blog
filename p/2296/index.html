2296 - 大写字母的判断

题目描述

输入一个字符，判断是否是英文大写字母，即是否是 A∼ZA \sim ZA∼Z 中的一个。

输入

一个字符。

输出

如果是英文大写字母，则输出 YES，否者输出 NO 。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int main(){
    char c;
    cin>>c;
    if(c>='A'&&c<='Z'){
        cout<<"YES";
    }else{
        cout<<"NO";
    }
    return 0;
}
