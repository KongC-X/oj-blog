1884 - 求n个数中每个数出现的次数

题目描述

从键盘读入 nnn 个整数（n≤100n \le 100n≤100），这 nnn 个数都是 111 ~ 101010 之间的数，请从小到大输出每个出现过的数，以及统计出每个数出现的次数？

比如：假设读入 555 个数，分别为 111 222 333 333 555 ，统计结果如下：111 出现 111 次，222 出现 111 次，333 出现 222 次，555 出现 111 次。

输出格式如下：

`1 1
2 1
3 2
5 1
`

输入

第 111 行输入一个整数 nnn 。

第 222 行输入 nnn 个整数，用空格隔开。

输出

输出若干行，每行 222 个数，用空格隔开，按照从小到大的顺序，输出每个数以及每个数出现的次数。

解题思路

AC代码

AC代码

#include<iostream>
using namespace std;
int a[20]; // 统计数组
int main() {
    int n,i,m;
    cin >> n;
    for(i = 0; i < n; i++) {
        cin >> m;
        a[m]++;
    }
    for(i = 1;i <= 10; i++) {
        if(a[i] != 0) {
            cout << i << " " << a[i] << endl;
        }
    }
}
