B4061 位运算 2

洛谷 | 普及- | C++14 | 提交时间: 2026-09-28

题目描述

给定正整数 aaa 和整数 bbb。我们定义正整数 aaa 的 二进制的第 bbb 位 为将 aaa 转化为二进制后，从右往左数的第 bbb 位，且规定最右侧位是第 000 位。

例如，假设 a=11a=11a=11，则对应表如下，此时我们称 111111 的二进制的第 222 位为 000。

位数 444 333 222 111 000
对应数位 000 111 000 111 111

现在需要你依次输出下列 666 个计算结果，一行输出一个整数：

  • a×2ba\times 2^ba×2b；
  • a÷2ba\div 2^ba÷2b，除法向下取整；
  • aaa 的二进制的第 bbb 位；
  • 将 aaa 的二进制的第 bbb 位设置为 000 后得到的十进制结果；
  • 将 aaa 的二进制的第 bbb 位设置为 111 后得到的十进制结果；
  • 将 aaa 的二进制的第 bbb 位取反后得到的十进制结果；

输入格式

输入正整数 aaa 和整数 bbb。

输出格式

输出六行，一行一个整数表示一个问题的答案。

样例

样例输入 #1

11 2```

**样例输出 #1**

44
2
0
11
15
15```

AC 代码

#include <iostream>
using namespace std;

int main() {
    /*
     * 题目：B4061 位运算 2
     * 题意：给定 a 和 b，输出六种位运算结果：
     *   1. a * 2^b  （即 a 左移 b 位）
     *   2. a / 2^b 向下取整（即 a 右移 b 位）
     *   3. a 的二进制第 b 位（0 或 1）
     *   4. 将 a 的第 b 位设置为 0
     *   5. 将 a 的第 b 位设置为 1
     *   6. 将 a 的第 b 位取反
     *
     * 数据范围：1 ≤ a ≤ 2^20，1 ≤ 2^b ≤ a，所以 b 是非负整数。
     * a * 2^b 最大约 2^40，需要用 long long。
     */
    long long a;   // a: 正整数
    int b;         // b: 位编号（从 0 开始）
    cin >> a >> b;

    cout << (a << b) << endl;              // 1. 左移 b 位，相当于乘 2^b
    cout << (a >> b) << endl;              // 2. 右移 b 位，相当于除以 2^b 向下取整
    cout << ((a >> b) & 1) << endl;        // 3. 取第 b 位
    cout << (a & ~(1LL << b)) << endl;     // 4. 第 b 位清零
    cout << (a | (1LL << b)) << endl;      // 5. 第 b 位置 1
    cout << (a ^ (1LL << b)) << endl;      // 6. 第 b 位取反

    return 0;
}
