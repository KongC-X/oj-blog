1718 - 闯关大冒险？

题目描述

晶晶参加学校组织的闯关大冒险的游戏，游戏中有一关是这样的，选手要计算出正确的密码，才能凭该密码进入下一关。

密码计算方式是这样的：给每位选手 111 个 444 位的整数nnn ，只要计算出这个整数 nnn 各个位中的最大数，就是该关卡的密码。

请你编程帮助晶晶，快速计算出该关卡的密码。

比如，假设 nnn 的值为整数 125612561256 ，那么这个数的千位为111 、百位为 222 、十位为 555 、个位为 666 ，各个位中的最大数是 666 ，因此密码就是数字 666 。

输入

111 个 444 位整数 nnn 。

输出

一个整数，代表该关卡的密码。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;
 
int main(){
    int n;
    cin>>n;
    int q,b,s,g,x;
    q=n/1000;
    b=n/100%10;
    s=n%100/10;
    g=n%10;
    x=q;
    if(x<b){
        x=b;
    }
    if(x<s){
        x=s;
    }
    if(x<g){
        x=g;
    }
    cout<<x;
}
