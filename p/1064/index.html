1064 - 求出N以内的全部素数，并按每行五个数显示

题目描述

求出 NNN 以内的全部素数，并按每行五个数显示。

输入

输入一个整数 NNN。（ N≤1000N \le 1000N≤1000 ）

输出

依题意，输出满足条件的数！222 333 555 777 111111
……\dots \dots……

解题思路

AC代码

AC代码

#include<iostream>
#include<cmath>
using namespace std;

//素数判断 
bool prime(int n){
    if(n <= 1) return false;
    for(int i = 2;i <= sqrt(n);i++){
        if(n % i == 0){
            return false;
        }
    } 
    return true;
} 

int main() {
    int n,i,s = 0;
    cin >> n;
    for(i = 2;i < n;i++) {
        if(prime(i)) {
            cout<< i << " ";
            s++;
            if(s % 5 == 0) {
                cout << endl;
            }
        }
    }
}
