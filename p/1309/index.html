1309 - 最多能倒多少杯水

题目描述

花花所在的学校引入了电水箱为同学们烧开水。

已知电水箱的容量为 nnn 升（ n≤10Ln \le 10 Ln≤10L ），同学们带的杯子平均容量为 xxx 毫升（ xxx 在 100∼300100 \sim 300100∼300 之间），请问烧一箱开水，最多能倒多少杯（不足 111 杯算 111 杯）。（4.1.2）

输入

222 个整数 nnn 和 xxx 。

nnn 代表电水箱的总容量（单位为升 LLL）， xxx 代表平均 111 个杯子的容量（单位为毫升mlmlml ）。

输出

一个整数，代表最多能够倒多少杯水（不足 111 杯算 111 杯）。

解题思路

AC代码

AC代码

#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    //定义变量n代表水箱容量，x代表杯子平均容量
    int n,x;
    //输入n，x
    cin>>n>>x;
    //把升转换为毫升
    n = n*1000;
    //判断能否正好装完，不能需要+1
    if(n%x==0) {
        cout<<n/x;
    } else {
        cout<<n/x+1;
    }
    return 0;
}
