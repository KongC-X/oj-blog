题目描述

这里有 101010 个苹果，小 A 拿走了 222 个，Uim 拿走了 444 个，八尾勇拿走剩下的所有的苹果。我们想知道：

  1. 小A 和 Uim 两个人一共拿走多少苹果？
  2. 八尾勇能拿走多少苹果？

现在需要编写一个程序，输出两个数字作为答案，中间使用空格分开。

输出格式

输出两个数字作为答案，中间使用空格分开。

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 直接输出两个数，中间用空格隔开
    cout << 6 << " " << 4 << endl;
    return 0;
}
