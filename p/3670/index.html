3670 - 完全平方数

题目描述

小杨同学有一个包含 $n$ 个非负整数的序列 $A$，他想要知道其中有多少对下标组合 $\langle i,j\rangle$（），使得 $A_i + A_j$ 是完全平方数。

如果 $x$ 是完全平方数，则存在非负整数 $y$ 使得 $y \times y = x$。

输入

第一行一个非负整数 $n$ ，表示非负整数个数。

第二行包含 $n$ 个非负整数 $A_1,A_2,...,A_n$，表示序列 $A$ 包含的非负整数。

输出

输出一个非负整数，表示和是完全平方数的非负整数对数。

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
using namespace std;

int z,x,c,v,b,n,m,i,j,a[1100];
int main(){
    cin>>n;
    for(i=0;i<n;i++){
        cin>>a[i];
    }
    for(i=0;i<n;i++){
        for(j=i + 1;j<n;j++){
            int x = a[i] + a[j];
            if(sqrt(x) == int(sqrt(x))){
                c++;
            }
        }
    }
    cout<<c;
}
