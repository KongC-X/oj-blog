1488 - 论坛帖子

题目描述

你是一个论坛的站长,你们论坛有约 101010 万个帖子,每个帖子编号为 1−1000001-1000001−100000。每个帖子里面又有若干个回复。现在告诉你每个帖子下面的回复人的ID(ID的范围为 1−1000001-1000001−100000)

现在你要写一个程序,支持插入操作,即 ADD x y 代表编号为xxx 的帖子有一个ID为 yyy 的人回复。支持查询操作，即QUERY x y 代表查询编号为 xxx 的帖子第 yyy 个回复的人的ID。

输入

第 111 行一个整数 NNN，代表有 NNN 次询问（1≤N≤1000001 \le N \le 1000001≤N≤100000）

第 222 行到第 N+1N+1N+1 行代表 NNN 次询问的内容，每行为以下 222 种格式之一：

ADD x y 新增加了一个回复，代表编号为 xxx 的帖子有一个ID为 yyy 的人回复

QUERY x y 代表查询编号为 xxx 的帖子第 yyy 个回复的人的ID

保证 1≤x≤1000001 \le x \le 1000001≤x≤100000,1≤y≤1000001 \le y \le 1000001≤y≤100000

输出

对于每个 QUERY 的查询,每次输出占一行,代表编号为 xxx 的帖子第 yyy 个回复的人的ID，如果编号为 xxx 的帖子总的回复数小于 yyy，则输出 -1。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int main(){
    int n,m,temp,x,y;
    string s;
    vector<int> v[100000];
    cin >> n;
    for(int i=1;i<=n;i++){
        cin >> s;
        if(s=="ADD"){
            cin >> x >> y;
            v[x].push_back(y);
        }else{
            cin >> x >> y;
            if(y > v[x].size()){
                cout << -1 <<endl;
            }else{
                cout << v[x][y-1]<<endl;
            }
        }
    }
    return 0;
}
