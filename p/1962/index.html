1962 - 数值计算

题目描述

给出一个不多于 555 位的非负整数 （非 000 结尾），要求:

1、1、1、 求出它是几位数

2、2、2、 分别输出每一位数字

3、3、3、 按逆序输出各位数字，例如原数为 321321321 ,应输出 123123123 。

输入

一个不大于 555 位的正整数。

输出

三行

第 111 行 555 位数。

第 222 行 用空格分开的每个数字。

第 333 行 按逆序输出这个数。

AC代码

AC代码

#include <iostream>
using namespace std;

int main(){
    int n,s = 0,sum = 0,a;
    cin >> n;
    while(n != 0) {
        s = s * 10 + n % 10;
        n = n / 10;
        sum++;
    }
    cout << sum << endl;
    a = s;
    while(a != 0) {
        cout << a % 10 << " ";
        a = a / 10;
    }
    cout << endl;
    cout << s << endl;
}
