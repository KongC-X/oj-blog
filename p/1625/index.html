1625 - 谁的年龄大

题目描述

甲乙两个人在公园相遇，甲说我今年 nnn 岁了（ nnn 是一个两位的整数，个位和十位不相等），乙说，太巧了，你的年龄倒过来，就是我的年龄，请问两个人谁的年龄更大， 请输出那个更大的年龄？

比如，假设甲今年 121212 岁，那么乙就是 212121 岁，乙的年龄更大，应当输出乙的年龄 212121 岁。

输入

输入一个整数 nnn ，代表甲的年龄。

输出

输出两个人年龄的较大值。

解题思路

AC代码

AC代码

# include <iostream>
# include <iomanip>
using namespace std;

int main() {
    int n,a,b,m;
    cin >> n;
    a = n / 10;
    b = n % 10;
    m = b * 10 + a;
    if (m > n) {
        cout << m << endl;
    } else {
        cout << n << endl;
    }
}
