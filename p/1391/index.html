1391 - 公交卡充值问题？

题目描述

小明去公交卡充值中心为自己的公交卡充值，公交充值中心搞了一个充值优惠活动，活动详情如下：

（1）（1）（1） 充值 200200200 元∼299\sim 299∼299 元，赠送 505050 元余额到卡中；

（2）（2）（2） 充值 300300300 元∼499\sim 499∼499 元，赠送 100100100 元余额到卡中；

（3）（3）（3） 充值 500500500 元及 500500500 元以上，赠送 200200200 元余额到卡中；

（4）（4）（4） 充值 200200200 元以下，则没有赠送活动；

比如：小明如果充值 350350350 元，那么实际卡中到账的金额将会是 450450450 元（ 350350350 元充值 +100+ 100+100 元赠送）。
请编程帮助公交卡充值中心，根据客户的充值金额，计算实际应当到账的金额？

输入

一个整数 nnn ，代表小明的充值金额（nnn 是 1∼92991 \sim 92991∼9299 之间的整数）。

输出

一个整数，代表实际到账的金额。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main()
{
    int n;
    cin >> n;
    if (n >= 200 && n <= 299)
        n += 50;
    else if (n >= 300 && n <= 499)
        n += 100;
    else if (n >= 500)
        n += 200;
    cout << n;
    return 0;
}
