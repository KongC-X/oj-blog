P1634 禽兽的传染病

洛谷 | 入门 | C++14 | 提交时间: 2026-06-05

算法标签：模拟、数学、递推、洛谷原创

题目描述

禽兽患传染病了。一个禽兽会每轮传染 xxx 个禽兽。试问 nnn 轮传染后有多少禽兽被传染？

输入格式

两个非负整数 xxx 和 nnn。

输出格式

一个整数，即被传染的禽兽数。

样例

样例输入 #1

10 2```

**样例输出 #1**

121```

AC 代码

#include<iostream>
using namespace std;
int main(){
 long long x,n,sum=1,i;//long long定义大点
 cin>>x>>n;
 for(i=0;i<n;i++){
   sum+=sum*x;//这里是关键,一轮后感染总数为原来总数+新感染的总数                             
  }   
 cout<<sum;   
 return 0;   
}
