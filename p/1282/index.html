1282 - 简单背包问题

题目描述

有一个背包能装的重量 $maxw$ (正整数，$0 \le maxw \le 20000$)，同时有 $n$ 件物品($1 \le n \le 100$)，每件物品有一个重量 $w_i$ (正整数)和一个价值 $p_i$ (正整数)。要求从这 $n$ 件物品中任取若干件装入背包内，使背包的物品价值最大。

输入

第 $1$ 行：背包最大载重 $maxw$，物品总数 $n$ ；

第 $2$ 行到第 $n+1$ 行：每个物品的重量和价值；

输出

一个数字即背包内物品最大价值；

解题思路

AC代码

AC代码

#include <iostream>
#include <algorithm>
using namespace std;

// 这是一个经典的0-1背包问题，我们使用动态规划的方法来解决
// 思路：
// 1. 定义一个二维数组dp，dp[i][j]表示前i个物品放入容量为j的背包中所能获得的最大价值
// 2. 初始化dp数组，dp[0][j] = 0，表示没有物品时，无论背包容量是多少，价值都为0
// 3. 对于每个物品i，我们遍历背包容量j从0到maxw
//    - 如果物品i的重量大于当前背包容量j，那么不能放入该物品，dp[i][j] = dp[i - 1][j]
//    - 否则，我们有两种选择：放入物品i或者不放入物品i，取两者中价值较大的情况
//      dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - w[i]] + p[i])
// 4. 最终dp[n][maxw]就是我们所求的结果，即前n个物品放入容量为maxw的背包中所能获得的最大价值

int main() {
    int maxw, n;
    cin >> maxw >> n;
    int w[101], p[101];
    // 读取每个物品的重量和价值
    for (int i = 1; i <= n; i++) {
        cin >> w[i] >> p[i];
    }
    int dp[101][20001] = {0};
    // 动态规划计算最大价值
    for (int i = 1; i <= n; i++) {
        for (int j = 0; j <= maxw; j++) {
            if (w[i] > j) {
                dp[i][j] = dp[i - 1][j];
            } else {
                dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - w[i]] + p[i]);
            }
        }
    }
    cout << dp[n][maxw] << endl;
    return 0;
}
