1132 - 保留整数

题目描述

输入一个字符串 str1str1str1，把其中的连续非数字的字符子串换成一个*，存入字符数组 str2str2str2 中，所有数字字符也必须依次存入 str2str2str2 中。输出 str2str2str2。

输入

输入为一行字符串 str1str1str1，其中可能包含空格。字符串长度不超过 808080 个字符。

输出

输出处理好的字符串 str2str2str2。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s,s1;
    getline(cin,s);
    int i,j,k;
    for(i = 0;i < s.size();i++) {
        if(!isdigit(s[i]) && isdigit(s[i+1])) {
            cout << "*";
        }
        if(isdigit(s[i])) {
            cout << s[i];
        }
    }
    if(!isdigit(s[s.size()-1])) {
        cout << "*";
    }
}
