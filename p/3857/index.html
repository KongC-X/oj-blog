3857 - 休息时间

题目描述

小杨计划在某个时刻开始学习，并决定在学习 kkk 秒后开始休息。

小杨想知道自己开始休息的时刻是多少。

输入

前三行每行包含一个整数，分别表示小杨开始学习时刻的时 hhh 、分 mmm 、秒 sss （ h，m，sh，m ，sh，m，s 的值符合 1≤h≤12,0≤m≤59,0≤s≤591 \le h \le 12,0 \le m \le 59,0 \le s \le 591≤h≤12,0≤m≤59,0≤s≤59）。

第四行包含一个整数 kkk，表示小杨学习的总秒数（注： kkk 的值符合 1≤k≤36001 \le k \le 36001≤k≤3600 ）。

输出

输出一行，包含三个整数，分别表示小杨开始休息时刻的时、分、秒。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;

int main() {
    int h,m,s,k,sum;
    cin>>h>>m>>s>>k;
    sum = h*3600 + m*60 + s + k; // 算出总时间
    h = sum/3600; // 时
    m = (sum%3600)/60; // 分
    s = (sum%3600)%60; // 秒
    cout<<h<<" "<<m<<" "<<s;
}
