1789 - 双向队列

题目描述

想想双向链表……双向队列的定义差点儿相同，也就是说一个队列的队尾同一时候也是队首。两头都能够做出队，入队的操作。

如今给你一系列的操作。请输出最后队列的状态；

命令格式：

LIN X 表示一个整数，命令代表左边进队操作；

RIN X 表示右边进队操作；

ROUT 表示右边出队操作；

LOUT 表示从左边出队操作。

输入

第一行包括一个整数 MMM(M≤10000M \le 10000M≤10000)，表示有 MMM 个操作；

下面 MMM 行每行包括一条命令；

命令可能不合法，对于不合法的命令，请在输出中处理；

输出

输出的第一行包括队列进行了 MMM 次操作后的状态。从左往右输出，每两个之间用空格隔开。

下面若干行处理不合法的命令（假设存在）；

对于不合法的命令。请输出一行 X ERROR。

当中 XXX 表示是第几条命令；

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
        LIN X  命令代表左边进队操作；
        RIN X  表示右边进队操作；
        ROUT  表示右边出队操作；
        LOUT  表示从左边出队操作。
    */
    string s;
    vector<int > v; // 记录错误的时间
    deque<int > d; // 双端队列

    int n,x;
    cin >> n;
    for(int i = 1;i <= n;i++) {
        cin >> s;
        if(s == "LIN") {
            cin >> x;
            d.push_front(x);
        }
        if(s == "RIN") {
            cin >> x;
            d.push_back(x);
        }
        if(s == "LOUT") {
            if(d.size() == 0) {
                v.push_back(i);
            } else {
                d.pop_front();
            }
        }
        if(s == "ROUT") {
            if(d.size() == 0) {
                v.push_back(i);
            } else {
                d.pop_back();
            }
        }
    }
    for(int i = 0;i < d.size();i++) {
        cout << d[i] << " ";
    }
    cout << endl;
    for(int i = 0;i < v.size();i++) {
        cout << v[i] << " ERROR" << endl;
    }
}
