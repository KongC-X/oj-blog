P1219 [USACO1.5] 八皇后 Checker Challenge

洛谷 | 普及| C++14 | 提交时间: 2026-02-12

算法标签：搜索、USACO、深度优先搜索 DFS

题目描述

一个如下的 $6 \times 6$ 的跳棋棋盘，有六个棋子被放置在棋盘上，使得每行、每列有且只有一个，每条对角线（包括两条主对角线的所有平行线）上至多有一个棋子。

上面的布局可以用序列 $2\ 4\ 6\ 1\ 3\ 5$ 来描述，第 $i$ 个数字表示在第 $i$ 行的相应位置有一个棋子，如下：

行号 $1\ 2\ 3\ 4\ 5\ 6$

列号 $2\ 4\ 6\ 1\ 3\ 5$

这只是棋子放置的一个解。请编一个程序找出所有棋子放置的解。
并把它们以上面的序列方法输出，解按字典顺序排列。
请输出前 $3$ 个解。最后一行是解的总个数。

输入格式

一行一个正整数 $n$，表示棋盘是 $n \times n$ 大小的。

输出格式

前三行为前三个解，每个解的两个数字之间用一个空格隔开。第四行只有一个数字，表示解的总数。

样例

样例输入 #1

6

样例输出 #1

2 4 6 1 3 5
3 6 2 5 1 4
4 1 5 2 6 3
4

AC 代码

#include <iostream>
using namespace std;

const int MAXN = 15;        // n ≤ 13，多开一点空间
int n;
int col[MAXN];             // col[i] 表示第 i 列是否有皇后
int d1[2 * MAXN];          // 主对角线(row, col)，其主对角线编号为 row - col（行-列）是否被占，范围 -(n-1) ~ (n-1)，通过加上偏移量 n-1 映射到非负下标。
int d2[2 * MAXN];          // 副对角线row + col（行+列）是否被占，范围 0 ~ 2n-2
int ans[MAXN];            // 记录当前解，ans[i] 表示第 i 行的皇后放在第几列
int total = 0;            // 解的总数

// 搜索策略
// 按行逐层放置皇后，保证每行恰好一个。
// 对于当前行 row，依次尝试每一列 c，检查是否满足列、对角线未被占用
// 若满足则放置，递归处理下一行；否则回溯。
void dfs(int row) {
    if (row == n) {        // 找到一个解
        total++;
        if (total <= 3) { // 只输出前三个解
            for (int i = 0; i < n; i++) {
                if (i > 0) cout << ' ';
                cout << ans[i] + 1;   // 列号从 1 开始
            }
            cout << endl;
        }
        return;
    }

    for (int c = 0; c < n; c++) {
        // 检查列、主对角线、副对角线是否被占用
        if (col[c] || d1[row - c + n - 1] || d2[row + c]) continue;

        // 放置皇后
        col[c] = 1;
        d1[row - c + n - 1] = 1;
        d2[row + c] = 1;
        ans[row] = c;

        // 递归下一行
        dfs(row + 1);

        // 回溯
        col[c] = 0;
        d1[row - c + n - 1] = 0;
        d2[row + c] = 0;
    }
}

int main() {
    cin >> n;

    // 初始化标记数组
    for (int i = 0; i < n; i++) col[i] = 0;
    for (int i = 0; i < 2 * n; i++) {
        d1[i] = 0;
        d2[i] = 0;
    }

    dfs(0);

    cout << total << endl;

    return 0;
}
