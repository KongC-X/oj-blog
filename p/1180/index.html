1180 - 数字出现次数

题目描述

有 505050 个数（ 0∼190 \sim 190∼19），求这 505050个数中相同数字出现的最多次数为几次？

输入

505050 个数字。

输出

111 个数字（即相同数字出现的最多次数）。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int a[50]={0};
    int n,x,max = 0;

    for(int i = 1;i<= 50;i++) {
        cin >> x;
        a[x]++;
    }
    for(int i = 0;i <= 19; i++) {
        if (a[i] > max) {
            max = a[i];
        }
    }
    cout << max;
}
