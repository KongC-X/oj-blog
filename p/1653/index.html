1653 - 取数

题目描述

设有 NNN 个正整数（1≤N≤501 ≤ N ≤ 501≤N≤50），其中每一个均是大于等于 111、小于等于 300300300 的数。

从这 NNN 个数中任取出若干个数（不能取相邻的数），要求得到一种取法，使得到的和为最大。

例如：当 N=5N=5N=5 时，有 555 个数分别为：13,18,28,45,2113,18,28,45,2113,18,28,45,21；

此时，有许多种取法，如：

13,28,2113,28,2113,28,21 和为 626262；

13,4513, 4513,45 和为 585858；

18,4518, 4518,45 和为 636363；

…\dots…

输入

第一行是一个整数 NNN；

第二行有 NNN 个符合条件的整数。

输出

一个整数，即最大和。

解题思路

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int a[100],n,i,x;
int dp[100];
int ma,s;

int main() {
    cin >> n;
    for(i = 1;i <= n;i++) {
        cin >> a[i];
    }
    // 交代边界的值
    dp[1] = a[1];
    dp[2] = max(a[1],a[2]);
    // 递推
    for(i = 3;i <= n;i++) {
        dp[i] = max(dp[i - 1],dp[i - 2] + a[i]);
    }
    cout << dp[n];
}
