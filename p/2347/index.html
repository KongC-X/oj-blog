2347 - 冰雹猜想

题目描述

【具体要求】
$70$ 年代中期，美国各所名牌大学校园内，人们都废寝忘食地玩一种数学游戏：冰雹猜想。

这个游戏十分简单，任意写出一个正整数 $n$，并且按照以下的规律进行变换，直到数字变为 $1$：

如果是个奇数，则下一步变成 $3n+1$。

如果是个偶数，则下一步变成 $n/2$。

程序要求输入一个正整数 $n$，输出整数 $n$ 变换到 $1$ 的处理过程。

例如当 $n = 5$ 时，变换过程分别为：$16，8，4，2，1$ 。

输入

输入一个正整数 $n（1 \lt n \lt 1000$ )。

输出

输出若干行，顺序输出整数 $n$ 变换到 $1$ 的处理过程，每行输出一步变换的表达式。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n;
    cin >> n;
    while(n != 1) {
        if(n % 2 == 0) {
            cout << n << "/" << 2 << "=" << n / 2 << endl;
            n = n / 2;
        } else {
            cout << n << "*" << 3 << "+1=" << 3 * n + 1 << endl;
            n = 3 * n + 1;
        }
    }
}
