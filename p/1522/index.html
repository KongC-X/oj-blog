1522 - 春游

题目描述

小Ｘ就读的 CZ 中学今年又取得了小高考的空前佳绩，全校师生都很开心，于是大家希望找个地方去春游，在广泛征集了全校师生的意见后，最终决定前往嬉戏谷游玩一天。出行方案为租用大巴，可供租用的大巴有两种，一种是 494949 座的，一种是 333333 座的，494949 座的大巴每辆租金为 330033003300 元，333333 座的大巴每辆租金为 190019001900 元，全校师生共有 nnn 人，现在学校希望找到一种最省钱的租车方案，这个任务学校交给了擅长编程的小Ｘ同学，而小Ｘ同学最近太忙了，他觉得这么简单的任务交给你就行了！

输入

输入数据仅有一行包含一个正整数 nnn，表示 CZ 中学出游的总人数

输出

输出数据仅有一行包含一个正整数，表示租车所需的最少费用。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;
int main() {
    long long n,s=0;
    cin>>n;
    if(n<33) {
        s=1900;
    } else if(n%33==0) {
        s=(n/33)*1900;
    } else if(n%33+33<=49) {
        s=(n/33-1)*1900+3300;
    } else {
        s=(n/33+1)*1900;
    }
    cout<<s<<endl;
    return 0;
}
