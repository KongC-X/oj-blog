B4360 [GESP202506 四级] 画布裁剪

洛谷 | 入门 | C++14 | 提交时间: 2025-07-07

算法标签：2025、字符串（入门）、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1184

题目描述

小 A 在高为 hhh 宽为 www 的矩形画布上绘制了一幅画。由于画布边缘留白太多，小 A 想适当地裁剪画布，只保留画的主体。具体来说，画布可以视为 hhh 行 www 列的字符矩阵，其中的字符均为 ASCII 码位于 33∼12633 \sim 12633∼126 之间的可见字符，小 A 只保留画布中由第 x1x_1x1​ 行到第 x2x_2x2​ 行、第 y1y_1y1​ 列到第 y2y_2y2​ 列构成的子矩阵。

小 A 将画布交给了你，你能帮他完成画布的裁剪吗？

输入格式

第一行，两个正整数 h,wh, wh,w，分别表示画布的行数与列数。

第二行，四个正整数 x1,x2,y1,y2x_1, x_2, y_1, y_2x1​,x2​,y1​,y2​，表示保留的行列边界。

接下来 hhh 行，每行一个长度为 www 的字符串，表示画布内容。

输出格式

输出共 x2−x1+1x_2 - x_1 + 1x2​−x1​+1 行，每行一个长度为 y2−y1+1y_2 - y_1 + 1y2​−y1​+1 的字符串，表示裁剪后的画布。

样例

样例输入 #1

3 5
2 2 2 4
.....
.>_<.
.....```

**样例输出 #1**

_<```

样例输入 #2

5 5
1 2 3 4
AbCdE
fGhIk
LmNoP
qRsTu
VwXyZ```

**样例输出 #2**

Cd
hI```

AC 代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int n,m,i,j,a1,a2,b1,b2;
char a[110][110];
int main() {
    cin >> n >> m;
    cin >> a1 >> a2 >> b1 >> b2;
    for(i = 1;i <= n;i++) {
        for(j = 1;j <= m;j++) {
            cin >> a[i][j];
        }
    }
    for(i = a1;i <= a2;i++) {
        for(j = b1;j <= b2;j++) {
            cout << a[i][j];
        }
        cout << endl;
    }
}
