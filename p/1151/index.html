1151 - 桐桐数

题目描述

桐桐很喜欢研究数字，特别喜欢研究质数。

一天，桐桐发现有一些数字可以表示成两个质数相乘的形式，比如，10=2×510=2 \times 510=2×5，222、555 都是质数，所以 101010 是一个“桐桐数”。

所以桐桐决定考考你，她告诉你一个数 nnn ，请你判断 nnn 是不是“桐桐数”。

输入

一个数 nnn (1≤n≤231−11 \le n \le 2^{31} -11≤n≤231−1)。

输出

输出一行，如果 nnn 是一个“桐桐数”，则输出 It's a Tongtong number.，否则输出It's not a Tongtong number.。

AC代码

AC代码

#include<iostream>
#include<cmath>
using namespace std;

//素数判断 
bool prime(int n){
    if(n <= 1) return false;
    for(int i = 2;i <= sqrt(n);i++){
        if(n % i == 0){
            return false;
        }
    } 
    return true;
} 

int main() {
    int n;
    bool flag = false;
    cin>>n;
    for(int j = 2;j <= sqrt(n);j++){
        if(n % j == 0 && prime(j)==true && prime(n/j)==true){
            flag = true;
            break;
        }
    }
    if(flag == true) {
        cout<<"It's a Tongtong number."<<endl;
    } else {
        cout<<"It's not a Tongtong number."<<endl;
    }
}
