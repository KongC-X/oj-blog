1176 - 素数问题

题目描述

编一个程序，计算 1∼n1 \sim n1∼n 范围内素数的个数。

输入

包括多组数据（不超过 100100100 组），每组数据仅有一个整数 nnn （ 1≤n≤1001 \le n \le 1001≤n≤100 ），输入以 000 结束。

输出

对于每组数据输入，输出一行，为 1∼n1 \sim n1∼n （包括 nnn ）之间的素数的个数。

AC代码

AC代码

#include <bits/stdc++.h> // 万能头文件
#include <iostream>
using namespace std;

int main() {
    while(1) {
        int n,s = 0;
        cin >> n;
        if(n == 0) {
            return 0; // 输入为0时结束
        }
        for(int i = 1;i <= n;i++) {
            // 判断1～n中有几个素数
            bool flag = true;
            for(int j = 2;j <= sqrt(i);j++) {
                if(i % j == 0) {
                    flag = false;
                    break;
                }
            }
            if(i <= 1) flag = false;
            if(flag) {
                s++;
            }
        }
        cout << s << endl;
    }

}
