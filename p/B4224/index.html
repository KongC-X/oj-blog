B4224 [常州市赛 2024] 最小值

洛谷 | 普及- | C++14 | 提交时间: 2026-07-25

算法标签：2024、江苏、素数判断、分支结构、科创活动、小学活动

题目背景

搬运自 http://czoj.com.cn/p/950。数据为民间数据。

题目描述

素数是指一个大于 $1$ 的自然数，除了 $1$ 和它本身外，不能被其他自然数整除，换句话说就是该数除了 $1$ 和它本身以外不再有其他的因数。比如 $2,3,5,7,11,13\cdots$ 都是素数，而 $4,6,8,9,10\cdots$ 都是合数（有 $3$ 个以上因数）。特别地，$0$ 和 $1$ 既不是素数，也不是合数。

小 Y 想知道最小的素数，那当然是 $2$。不过他加上了一些限制，就是只通过某些数字构成的素数最小是多少？比如只通过 $3$ 构成的最小的素数是 $3$，只通过 $1$ 构成的最小的素数是 $11$，只通过 $8$ 和 $9$ 构成的最小的素数是 $89$ 等等。另外需要特别指出的是：给出的数字无须全部用到，比如只通过 $3$ 和 $5$ 构成的最小的素数是 $3$，而不是 $53$。

输入格式

第一行一个正整数 $n$，表示可以使用的数字的个数。

第二行 $n$ 个个位数字，表示可以使用哪些数字。

输出格式

一行一个素数表示构成的素数最小是多少，若是无法通过给出的数字构成素数，则输出 -1。

样例

样例输入 #1

2
3 5```

**样例输出 #1**

3```

样例输入 #2

1
1```

**样例输出 #2**

11```

样例输入 #3

3
8 0 9```

**样例输出 #3**

89```

样例输入 #4

4
2 3 4 5```

**样例输出 #4**

2```

AC 代码

#include<bits/stdc++.h>
#define int long long  // 用 long long 防止数据溢出
using namespace std;

int n;
map<int, bool> mp; // 用来标记某个数字是否可以使用的哈希表

signed main() {
    // 加速输入输出
    ios::sync_with_stdio(0);
    cin.tie(0); cout.tie(0);

    // 读入数字个数
    cin >> n;
    // 读入每一个可用的数字，存入 map
    for (int i = 1; i <= n; i++) {
        int x;
        cin >> x;
        mp[x] = true; // 标记该数字可以使用
    }

    /*
      核心思路（分类讨论，逐级筛选最小素数）：
      
      素数除了 2 和 5 本身，个位必须是 1、3、7、9（否则会被 2 或 5 整除）。
      所以我们只需要从小到大枚举可能的数字组合，第一个找到的就是答案。
      
      枚举顺序：
        1. 单个数字本身是素数：2, 3, 5, 7
        2. 包含数字 1：能组成的最小素数是 11（1 单独不是素数）
        3. 同时包含 8 和 9：能组成的最小素数是 89
           （8 开头、9 结尾，89 是素数，且没有更小的组合）
        4. 同时包含 4 和 9：以 4 开头、9 结尾的最小素数
           - 如果有 0：409（比 449 小）
           - 如果没有 0：449
        5. 以上都不满足：无法构成素数，输出 -1
      
      为什么不需要检查更多组合？
        - 个位必须是奇数，所以只能用 1,3,5,7,9 作个位
        - 3,5,7 作为个位时，如果十位是其他数字，组合出来的两位数
          要么是合数，要么比已有答案大，不需要考虑
        - 9 作为个位时，十位从可用数字中选最小的非零数字，
          4 和 8 是常见的最小选择
        - 更高位数的情况同理，最小的素数一定在两位数或三位数中产生
      
      时间复杂度 O(1)，仅需几次条件判断。
    */

    // 1. 检查单个数字中是否包含素数 2, 3, 5, 7
    if (mp[2]) cout << 2 << "\n";          // 2 是最小的素数
    else if (mp[3]) cout << 3 << "\n";     // 3 是素数
    else if (mp[5]) cout << 5 << "\n";     // 5 是素数
    else if (mp[7]) cout << 7 << "\n";     // 7 是素数

    // 2. 检查是否包含数字 1
    //    如果包含 1，能构成的最小素数就是 11（因为 1 单独不是素数）
    else if (mp[1]) cout << 11 << "\n";

    // 3. 检查是否同时包含 8 和 9
    //    如果能用 8 和 9，那么能组成的最小的素数是 89
    else if (mp[8] && mp[9]) cout << 89 << "\n";

    // 4. 检查是否同时包含 4 和 9
    //    如果没有更小的素数，但能用 4 和 9，则寻找以 4 开头、9 结尾的最小素数
    else if (mp[4] && mp[9]) {
        if (mp[0]) cout << 409 << "\n";   // 如果还能用 0，则 409 比 449 小
        else       cout << 449 << "\n";   // 否则只能输出 449
    }

    // 5. 所有情况都不满足，无法构成任何素数
    else cout << -1 << "\n";

    return 0;
}
