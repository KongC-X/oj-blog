5378 - 数字选取

题目描述

给定正整数 $n$，现在有 $1，2，……，n$ 共计 $n$ 个整数。你需要从这 $n$ 个整数中选取些整数，使得所选取的整数中任意两个不同的整数均互质（也就是说，这两个整数的最公因数为 $1$ ）。请你最大化所选取整数的数量。

例如，当 $n=9$ 时，可以选择 $1,5,7,8,9$ 共计 $5$ 个整数。可以验证不存在数量更多的选取整数的案。

输入

一行，一个正整数 $n$ ，表示给定的正整数。

输出

一行，一个正整数，表示所选取整数的最大数量。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 如果要让所有选取的数两两互质且选取的数量最多，很容易就想到，可以选 1 和所有小于 n 的质数。
// 接下来证明一下这样选出的数一定是最多的。
// 假设现在已经选了一个质数 p，要让所有选出的数两两互质，则 p 的所有倍数中只能选择一个。
// 我们不妨假设选择了这个质数 p。那么除 p 外，这个质数 p 的倍数都不能再选了。
// 换句话说，一个数如果是某个质数的倍数，那么这个数就不能再选了。
// 又因为一个合数一定能分解为若干个质数的乘积，所以合数是不能选的。那么最多能选的数个数就是小于等于 n 的质数个数加 1。
// 当然，如果我们没有选择质数 p，而是选择了其他 p 的倍数，那么含有质因子 p 的数中只能选一个，这种情况与我们前面讨论的情况是等效的，所以假设选择了 p 是不影响最后结果的。
// 这样就证明了最多能选的数个数就是小于等于 n 的质数个数加 1，那么代码实现也很简单了。

int n,s;
int main(){
    cin >> n;
    for(int i = 1;i <= n;i++){
        bool flag = true;
        for(int j = 2;j * j <= i;j++){
            if(i % j == 0){
                flag = false;
                break;
            }
        } 
        if(flag || i == 1){
            s++;
        }
    }
    cout << s <<endl;
    return 0;
}
