3483 - 小杨的字典

题目描述

在遥远的星球，有两个国家 AAA 国和 BBB 国，他们使用着不同的语言：AAA 语言和 BBB 语言。小杨是 BBB 国的翻译官，他的工作是将 AAA 语言的文章翻译成 BBB 语言的文章。

为了顺利完成工作，小杨制作了一本字典，里面记录了 NNN 个 AAA 语言单词对应的 BBB 语言单词，巧合的是，这些单词都由地球上的 262626 个小写英文字母组成。

小杨希望你写一个程序，帮助他根据这本字典翻译一段 AAA 语言文章。这段文章由标点符号 !()-[]{}\|;:'",./?<> 和一些 AAA 语言单词构成，每个单词之间必定由至少一个标点符号分割，你的程序需要把这段话中的所有 AAA 语言单词替换成它的 BBB 语言翻译。特别地，如果遇到不在字典中的单词，请使用大写 UNK 来替换它。

例如，小杨的字典中包含 222 个 AAA 语言单词 abc 和 d ，它们的 BBB 语言翻译分别为 a 和 def ，那么我们可以把 AAA 语言文章 abc.d.d.abc.abcd. 翻译成 BBB 语言文章 a.def.def.a.UNK. ，其中，单词 abcd 不在词典内，因此我
们需要使用 UNK 来替换它。

输入

第一行一个整数 NNN，表示词典中的条目数。保证 N≤100N \leq 100N≤100。

接下来 NNN 行，每行两个用单个空格隔开的字符串 A,BA,BA,B，分别表示字典中的一个 AAA 语言单词以及它对应的 BBB 语言翻
译。保证所有 AAA 不重复；保证 AAA 和 BBB 的长度不超过 101010。

最后一行一个字符串 SSS，表示需要翻译的 AAA 语言文章。保证字符串 SSS 的长度不超过 100010001000 ，保证字符串 SSS 只包含小写字母以及标点符号 !()-[]{}\|;:'",./?<> 。

输出

输出一行，表示翻译后的结果。

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int i,n;
string s,s1,s2;
string a[110],b[110];
int main() {
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> a[i] >> b[i];
    }
    cin >> s;
    for(i = 0;i < s.size();i++) {
        if(isalpha(s[i])) {
            s1 = s1 + s[i];
        } else {
            bool flag = false;
            for(int j = 0;j < n;j++) {
                if(s1 == a[j]) {
                    s2 += b[j];
                    flag = true;
                    break;
                }
            }
            // 这里需要判断s1是否为空,因为s1可能为空,但是s[i]不是字母.
            if(!flag && s1 != "") {
                s2 += "UNK";
            }
            s2 += s[i]; // 还需要加上当前的符号.
            s1 = ""; // 清空s1
        }
    }
    // 万一s最后是一个单词，无法判断，所以需要再判断一次
    if(s1 != "") {
        bool flag = false;
        for(int j = 0;j < n;j++) {
            if(s1 == a[j]) {
                s2 += b[j];
                flag = true;
                break;
            }
        }
        if(!flag) {
            s2 += "UNK";
        }
    }
    cout << s2 << endl;
}
