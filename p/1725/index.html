1725 - 声音识别

题目描述

学校王老师研发了一套新的声音识别系统，该系统预先将每位同学的学号和声音录入之后，只要同学一说话，就知道是哪个学号的同学在说话（不同的同学声音是完全不一样的）。

王老师将系统装在了教室，系统收集到了一节英语课中同学们说话的 nnn 个片段，并转换为了同学们的学号，请你编程帮助王老师计算出，有多少个同学在英语课中发过言，并按照学号由小到大，输出每位同学的学号及该学号的同学发言的次数。

比如，假设经过系统分析，得到如下的 888 个同学的学号分别是：888 111 666 111 888 666 777 222，表示同学们的发言顺序分别是：888 号、111 号、666 号、111 号、888 号、666 号、777 号、222 号，那么一共有 555 位同学发过言，按照学号由小到大输出发言次数如下：

`1 2
2 1
6 2
7 1
8 2
`

分别代表 111 号同学发言 222 次、222 号同学发言 111 次、666 号同学发言 222 次、777 号同学发言 111 次、888 号同学发言 222 次。

输入

输入有 222 行，第 111 行有一个整数 nnn（3≤n≤100003≤n≤100003≤n≤10000）；

第二行有 nnn 个数字（这些整数都是 111~100100100 之间的整数，含 111 和 100100100），数字之间用空格隔开，代表同学们的学号。

输出

第 111 行输出 111 个整数，代表总共有多少名同学说过话。

接下来输出若干行，每行 222 个整数，用空格隔开，表示按照学号由小到大输出发言同学的学号及每位同学发言的次数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int a[110];// 用a[1]~a[100]记录1~100出现的次数
int n,t,c = 0;
 
int main() {
    int i;
    cin>>n;
    for(i = 1; i <= n; i ++) {
        cin>>t;
        //t:出现过的数字
        a[t] ++;
        //如果t是第一次出现
        if(a[t] == 1) c++; 
    }
    
    cout<<c<<endl;
    for(i = 1; i <= 100; i++) {
        if(a[i] > 0) {
            cout<<i<<" "<<a[i]<<endl;
        }
    }
    return 0;
}
