1066 - 字符图形2-星号直角

题目描述

打印字符图形。

输入

一个整数（ 0<n<100 \lt n \lt 100<n<10 ）。

输出

一个字符图形。

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    //输入n 
    cin>>n;
    int i,j;
    for(i=1;i<=n;i++){
        //每行循环i次输出* 
        for(j=1;j<=i;j++){
            cout<<"*";            
        }
        cout<<endl;
    }
    return 0;
}
