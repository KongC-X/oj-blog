B3657 [语言月赛202209] 公园门票

洛谷 | 入门 | C++14 | 提交时间: 2026-08-16

算法标签：2022、O2优化、分支结构、语言月赛

题目描述

小 A 一家人一起来逛公园，门票价目表如下：

小 A 家里共有 xxx 个成人，yyy 个儿童，请问至少需要花费多少钱购买门票。

输入格式

共一行，包含两个数字 xxx 和 yyy，表示小 A 家里共有 xxx 名成人，yyy 名儿童。

输出格式

共一行，包含一个数字，表示至少需要花费多少钱购买门票。

样例

样例输入 #1

1 1```

**样例输出 #1**

90```

样例输入 #2

2 1```

**样例输出 #2**

150```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3657 [语言月赛202209] 公园门票
     * 题意：有 x 个成人，y 个儿童，成人票 60 元，儿童票 40 元，
     *       一大一小套票 90 元，求最低总花费。
     *
     * 思路：
     * 1. 套票比单独买便宜（90 < 60+40），所以尽量多用套票。
     * 2. 套票最多用 min(x, y) 张。
     * 3. 枚举套票数量 k（0 到 min(x, y)），计算对应总花费，取最小值。
     */
    int x, y;       // x: 成人数量, y: 儿童数量
    cin >> x >> y;

    int maxK = min(x, y);   // 最多能买多少套一大一小套票
    int ans = 1e9;          // 答案初始为一个很大的数

    for (int k = 0; k <= maxK; k++) {
        // k 张套票，剩余 x-k 个成人单独买，y-k 个儿童单独买
        int cost = k * 90 + (x - k) * 60 + (y - k) * 40;
        if (cost < ans) ans = cost;
    }

    cout << ans << endl;
    return 0;
}
