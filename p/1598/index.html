1598 - 文具店的折扣

题目描述

花花去文具店买了 111 支笔和 111 块橡皮，已知笔 xxx元/// 支，橡皮 yyy 元 /// 块，文具店今天有活动，可以给顾客打 999 折（用购买总价 ×0.9\times 0.9×0.9 ），花花付给了老板 nnn 元，请问老板应该找给花花多少钱？

输入

三个整数 x、y、nx、y、nx、y、n ，分别代表了笔的单价、橡皮的单价和花花付给老板的钱（已知花花付给老板的钱 n≥x+yn \ge x+yn≥x+y）。

输出

一个小数（保留 111 位小数），代表老板应该找给花花的钱。

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
#include<iomanip>
using namespace std;

int main() {
    int x,y,n;
    double s;
    cin >> x >> y >> n;
    s = n - (x + y) * 0.9;
    cout << fixed << setprecision(1) << s << endl;
}
