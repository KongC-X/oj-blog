题目背景

第二届四川省青少年 C++ 算法设计大赛小学 4-5 年级组全省总决赛试题。数据为洛谷自造。

题目描述

n!n!n!（nnn 的阶乘）表示从 111 开始连乘到 nnn 的结果。现在想要知道 n!n!n! 从个位数开始向前数，有多少个连续的 000。

例如：

  • 3!=1×2×3=63!=1\times 2\times 3=63!=1×2×3=6，末尾连续 000 的个数为 000；
  • 5!=1×2×3×4×5=1205!=1\times 2\times 3\times 4\times 5=1205!=1×2×3×4×5=120，末尾连续 000 的个数为 111；

输出格式

一个整数，表示 n!n!n! 尾部 000 的个数。

样例

样例输入 #1

5```

**样例输出 #1**

1```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：n! 末尾的零由因子10的个数决定，10 = 2 × 5。
    // 由于质因子2的个数总是多于5的个数，所以零的个数等于质因子5的个数。
    // 计算 n! 中质因子5的个数：不断除以5并累加即可。
    long long n;                  // n: 求阶乘的数
    cin >> n;

    long long ans = 0;            // ans: 末尾零的个数
    while (n > 0) {
        n /= 5;                   // 每除以5，得到5的倍数个数
        ans += n;                 // 累加
    }

    cout << ans << endl;
    return 0;
}
