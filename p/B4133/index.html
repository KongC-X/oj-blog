B4133 [信息与未来 2014] 最大连续部分和

洛谷 | 普及- | C++14 | 提交时间: 2026-04-13

算法标签：动态规划 DP、递推、2014、江苏、信息与未来

题目描述

有 nnn 个整数排成一排，求其中的最大连续部分和。

至少要选一个数。

输入格式

第一行一个整数，表示 nnn。

第二行 nnn 个整数 x1,x2,⋯ ,xnx_1,x_2,\cdots,x_nx1​,x2​,⋯,xn​，相邻两数之间有一个空格。

输出格式

一个整数（即最大的连续的部分和）。

样例

样例输入 #1

7
-2 13 12 9 14 -10 2```

**样例输出 #1**

48```

AC 代码

#include <cstdio>    // 使用 scanf 和 printf 快速读入输出
using namespace std;

int main() {
    int n;
    scanf("%d", &n);   // 读入数字个数

    long long cur, ans;
    int x;

    // 先读入第一个数，作为初始值
    scanf("%d", &x);
    cur = ans = x;

    // 处理剩下的 n-1 个数
    for (int i = 2; i <= n; i++) {
        scanf("%d", &x);
        // 如果之前的和加上 x 比 x 本身大，就接上；否则从 x 重新开始
        if (cur + x > x) {
            cur = cur + x;
        } else {
            cur = x;
        }
        // 更新最大和
        if (cur > ans) {
            ans = cur;
        }
    }

    printf("%lld\n", ans);  // 输出 long long 用 %lld
    return 0;
}
