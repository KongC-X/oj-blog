小 F 回到班上，面对自己 28 / 110 的物理，感觉非常凉凉。他准备从最基础的力学学起。

如图，一个可以视为质点的小球在点 A(x0,y0)A(x_0, y_0)A(x0​,y0​) 沿 xxx 轴负方向以某速度抛出，无视除重力外的所有阻力，最后恰好以速度 vvv 砸到 B(0,0)B(0, 0)B(0,0) 点。

给定 vvv 的大小与方向，你的任务是求出 (x0,y0)(x_0,y_0)(x0​,y0​)。

给定的速度单位为 m⋅s−1m \cdot s ^ {-1}m⋅s−1，重力加速度 g=10 (m⋅s−2)g = 10 \ (m \cdot s ^ {-2})g=10 (m⋅s−2)，请输出以 mmm 为单位的答案。

如果你没有学过相关内容也没有关系，你可以从样例和提示里理解该题所求内容。

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P4710 「物理」平抛运动
     * 题意：小球从 A(x0, y0) 沿 x 轴负方向抛出，最终以速度 v 砸到 B(0,0)。
     *       给定 v 的大小和方向 a（弧度制），重力加速度 g = 10，求 x0, y0。
     *
     * 物理分析：
     *   将落地速度 v 分解：
     *     水平分速度 vx = v * sin(a)
     *     竖直分速度 vy = v * cos(a)
     *   落地时间 t = vy / g = v * cos(a) / g
     *   水平位移 x0 = vx * t = v^2 * sin(a) * cos(a) / g
     *   竖直位移 y0 = 1/2 * g * t^2 = v^2 * cos^2(a) / (2g)
     *
     * 时间复杂度：O(1)
     */
    double v, a;   // v: 落地速度大小, a: 速度与竖直方向的夹角（弧度）
    cin >> v >> a;

    double g = 10.0;
    double x = v * v * sin(a) * cos(a) / g;
    double y = v * v * cos(a) * cos(a) / (2 * g);

    cout << fixed << setprecision(10) << x << " " << y << endl;
    return 0;
}
