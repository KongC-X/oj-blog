B4457 [合肥市小学组 2025 T1] 整理书架

洛谷 | 普及- | C++14 | 提交时间: 2026-07-25

算法标签：贪心、2025、安徽、小学活动

题目描述

小 H 在大科学城开了一家书店，书架上都摆满了 $n$ 本书，书的编号从 $1$ 到 $n$。由于读者经常将书的顺序弄乱，小 H 购置了一个机器人用来整理书架。机器人每次操作只能选取书架中相邻的两本书，然后交换它们的位置。注意：书架上的位置从左至右编号为 $0$ 到 $n-1$。

小 H 想知道机器人将编号为 $1$ 的书移到书架的最左端，且将编号为 $n$ 的书移到书架的最右端的最小操作次数。

输入格式

第一行包含一个正整数 $n$，表示书架上书的数量。

第二行包含 $n$个互异的正整数：$x_0, x_1, x_2, ..., x_{n-1}$，其中 $x_i$ 表示书架的第 $i-1$ 个位置上放着编号为 $x_i$ 的书。

输出格式

输出一行一个非负整数，表示将编号为 $1$ 的书移到书架的最左端，且将编号为 $n$ 的书移到书架的最右端，机器人的最小操作次数。

样例

样例输入 #1

4
2 4 1 3```

**样例输出 #1**

3```

样例输入 #2

5 
1 4 3 2 5```

**样例输出 #2**

0```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 找到 1 和 n 的位置 p1, pn（0‑based）。
    // 将 1 移到最左端需要 p1 次交换，将 n 移到最右端需要 (n-1-pn) 次交换。
    // 如果 p1 > pn，说明移动 1 向左时会经过 n，相当于免费帮 n 向右移动了一次，
    // 所以总次数要减 1。
    // 如果 p1 <= pn，则相互独立，直接相加即可。

    int n;
    cin >> n;
    int p1, pn;                  // 记录 1 和 n 的初始位置
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (x == 1) p1 = i;
        if (x == n) pn = i;
    }

    int ans = p1 + (n - 1 - pn);
    if (p1 > pn) ans--;          // 一次免费的右移

    cout << ans << endl;
    return 0;
}
