2232 - 全排列

题目描述

给定一个由不同的小写字母组成的字符串，输出这个字符串的所有全排列。 我们假设对于小写字母有'a' < 'b' < ... < 'y' < 'z'，而且给定的字符串中的字母已经按照从小到大的顺序排列。

输入

输入只有一行，是一个由不同的小写字母组成的字符串，已知字符串的长度在1到6之间。

输出

输出这个字符串的所有排列方式，每行一个排列。要求字母序比较小的排列在前面。字母序如下定义： 已知S = s1s2...sk , T = t1t2...tk，则S < T 等价于，存在p (1 <= p <= k)，使得 s1 = t1, s2 = t2, ..., sp - 1 = tp - 1, sp < tp成立。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;


string s;
char a[10];//存储全排列的结果
bool f[10];//标记哪些字母使用过

//将全排列的结果填写到a数组
void dfs(int k)
{
    for (int i = 0; i < s.size(); i++)
    {
        //如果第i个字符没有被使用过
        if (f[i] == false)
        {
            a[k] = s[i];//填写字符
            f[i] = true;//标记占用
            if (k == s.size() - 1) cout << a << endl; //填满了，打印
            else dfs(k + 1); //没有填满，继续填写下一个位置
            f[i] = false;//回溯，撤销对于第i个字符的占用
        }
    }
}

int main()
{
    cin >> s;
    dfs(0);//从a数组的下标为0的位置开始填值
    return 0;
}
