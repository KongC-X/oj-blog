B3739 [信息与未来 2018] 整数乘方

洛谷 | 普及| C++14 | 提交时间: 2026-04-17

算法标签：模拟、高精度、2018、江苏、信息与未来

题目描述

定义 $a$ 的 $n$ 次幂 $a^n = a × a × \cdots × a$（共 $n$ 个 $a$ 相乘）。记 $a^n$ 的十进制表示转换为字符串后奇数字符（阿拉伯数字 $1, 3, 5, 7, 9$）的个数为 $A$，偶数字符（阿拉伯数字 $0, 2, 4, 6, 8$）的个数为 $B$，求 $A-B$ 的数值。

例如，$a = 3, n = 12, a^n = 3^{12} = (531441)_{10}$。

奇数数位用方框标出：$\boxed{5}\boxed{3}\boxed{1}44\boxed{1}$，故 $A = 4$；

偶数数位用方框标出：$531\boxed{4}\boxed{4}1$, 故 $B = 2, A-B = 2$。

输入格式

输入一行两个整数 $a, n$。

输出格式

输出一行一个整数，代表 $A − B$ 的值。

样例

样例输入 #1

3 12```

**样例输出 #1**

2```

样例输入 #2

5 18```

**样例输出 #2**

-1```

AC 代码

#include <iostream>
#include <string>
using namespace std;

// 高精度乘法函数
string cheng(string s1, string s2) {
    int a[5010] = {0}, b[5010] = {0}, c[10010] = {0};
    int i, j, p = 0;
    string s3 = "";
    // 逆序存储
    for (i = s1.size() - 1; i >= 0; i--) {
        a[i] = s1[s1.size() - 1 - i] - '0';
    }
    for (i = s2.size() - 1; i >= 0; i--) {
        b[i] = s2[s2.size() - 1 - i] - '0';
    }
    // 乘法累加
    for (i = 0; i < (int)s1.size(); i++) {
        for (j = 0; j < (int)s2.size(); j++) {
            c[i + j] += a[i] * b[j];
            if (c[i + j] >= 10) {
                c[i + j + 1] += c[i + j] / 10;
                c[i + j] %= 10;
            }
        }
    }
    // 找最高位
    for (i = s1.size() + s2.size() - 1; i >= 0; i--) {
        if (c[i] != 0) {
            p = i;
            break;
        }
    }
    // 逆序拼接结果
    for (i = p; i >= 0; i--) {
        s3 += to_string(c[i]);
    }
    return s3;
}

int main() {
    int a, n;
    cin >> a >> n;
    string sa = to_string(a);        // 底数的字符串形式
    string res = "1";                // a^0 = 1，但题目 n>=1，所以直接乘

    // 计算 a^n
    for (int i = 0; i < n; i++) {
        res = cheng(res, sa);
    }

    // 统计奇数位与偶数位
    int A = 0, B = 0;
    for (int i = 0; i < (int)res.size(); i++) {
        int digit = res[i] - '0';
        if (digit % 2 == 1) A++;
        else B++;
    }

    cout << A - B << endl;
    return 0;
}
