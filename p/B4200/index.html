B4200 [常州市赛 2020] 重点单词

洛谷 | 普及- | C++14 | 提交时间: 2026-07-22

算法标签：模拟、字符串、2020、江苏、哈希 hashing、科创活动

题目背景

搬运自 http://czoj.com.cn/p/448。数据为民间数据。

题目描述

回家后，小 X\text{X}X 望着自己打瞌睡时写的英语笔记陷入了迷茫。由于太困了，他会时不时地把一个字母多写几次：比如可能把 she\texttt{she}she 写成 shhe\texttt{shhe}shhe，也可能写成 ssshee\texttt{ssshee}ssshee。
但他依稀记得这堂课只讲了一个重点单词。为了找到这个单词，他想先把每个单词中连续重复的字母压缩起来：把 coool\texttt{coool}coool 压缩为 col\texttt{col}col，把 aabbaa\texttt{aabbaa}aabbaa 压缩为 aba\texttt{aba}aba。接下来找到压缩后出现次数最多的单词，这样就能找到重点单词了。
由于工作量太大，小 X\text{X}X 希望你帮助他找到重点单词。他向你保证压缩后的单词出现次数最多的一定唯一。

输入格式

第一行一个整数 nnn 表示笔记上共写了 nnn 个单词。
接下来 nnn 行，每行一个字符串，表示一个单词。

输出格式

输出数据只有一行，包含一个字符串，表示压缩后出现次数最多的单词。

样例

样例输入 #1

3
qaaqqq
qwwwwq
qqqqaq```

**样例输出 #1**

qaq```

AC 代码

#include <bits/stdc++.h>
using namespace std;

string a[10010];                      // 存储原始单词，最多1e4个
string b[10010];                      // 存储压缩后的单词

int main() {
    int n;                            // n: 单词数量
    cin >> n;

    // 1. 读入并压缩每个单词
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        // 压缩：遍历每个字符，如果与上一个不同就保留
        string t = "";
        for (int j = 0; j < a[i].size(); j++) {
            if (j == 0 || a[i][j] != a[i][j - 1]) {
                t += a[i][j];
            }
        }
        b[i] = t;
    }

    // 2. 统计出现次数最多的压缩单词
    string ans;                       // 答案单词
    int mx = 0;                       // 出现的最多次数

    for (int i = 0; i < n; i++) {
        int cnt = 0;                  // b[i] 出现的次数
        for (int j = 0; j < n; j++) {
            if (b[j] == b[i]) cnt++;
        }
        if (cnt > mx) {
            mx = cnt;
            ans = b[i];
        }
    }

    cout << ans << endl;
    return 0;
}
