B3773 [信息与未来 2022] 完美字符串

洛谷 | 普及| C++14 | 提交时间: 2026-04-21

算法标签：2022、江苏、双指针 two-pointer、信息与未来

题目描述

你可能见过下面这一句英文：

"The quick brown fox jumps over the lazy dog."

短短的一句话就包含了所有 262626 个英文字母！因此这句话广泛地用于字体效果的展示。更短的还有：

"The five boxing wizards jump quickly."

所以你很好奇：还有没有更多这样包含所有 262626 个英文字母的句子？于是你用爬虫在互联网上爬取了许多英文文本，并且提取出了其中的单词。你现在希望从一个很长的单词序列中找出一段连续出现的单词，它满足：

  • 所有 262626 个英文字母都至少出现一次；
  • 长度尽可能短，即包含的字母总数尽可能少。

输入格式

输入的第一行包含一个整数 nnn，代表单词序列的长度，即单词的数量。

输入的第二行包含 nnn 个空格分隔的英文单词（单词仅由小写字母构成）。输入数据保证每个小写英文字母都至少出现一次。

输出格式

输出一行一个整数，是你找到的单词序列中的字母总数。

样例

样例输入 #1

13
there is a quick brown fox jumping over the lazy dog and cat```

**样例输出 #1**

37```

AC 代码

#include <iostream>
#include <string>
using namespace std;

// 我们使用滑动窗口（双指针）解决这个问题。核心思想是：
// 维护一个包含所有26个字母的窗口，并在保证包含所有字母的前提下，尽可能缩小窗口长度（字母总数）。
// 具体步骤如下：
// 预处理：读入所有单词，存储到字符串数组中。
// 滑动窗口：
// 右指针 r 逐个将单词加入窗口，更新字母计数 cnt[26] 和不同字母数 t，并累加窗口内字母总数 sum。
// 当 t == 26 时，说明窗口已包含所有字母，尝试右移左指针 l 缩小窗口：
// 如果移除单词 l 后仍然包含所有字母，则移除并更新计数和 sum，直到不能移除为止。期间用 sum 更新答案。
// 输出答案：遍历结束后输出最小的 sum。

int n;
string w[100010];
int a[26];          // 各字母在窗口内的出现次数
int t = 0;                  // 窗口内不同字母数

// 向窗口添加单词
void add(int n) {
    for (int i = 0; i < w[n].length(); i++) {
        char c = w[n][i];
        int m = c - 'a';
        if (a[m] == 0) t++;
        a[m]++;
    }
}

// 从窗口移除单词
void remove(int n) {
    for (int i = 0; i < w[n].length(); i++) {
        char c = w[n][i];
        int m = c - 'a';
        a[m]--;
        if (a[m] == 0) t--;
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    cin >> n;
    for (int i = 0; i < n; i++) cin >> w[i];

    int l = 0, sum = 0, ans = 1e9;
    for (int r = 0; r < n; r++) {
        add(r);
        sum += w[r].length();
        while (t == 26) {          // 窗口满足条件，尝试缩小
            if (sum < ans) ans = sum;
            sum -= w[l].length();
            remove(l);
            l++;
        }
    }
    cout << ans << endl;
    return 0;
}
