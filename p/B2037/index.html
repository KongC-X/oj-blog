B2037 奇偶数判断

洛谷 | 入门 | C++14 | 提交时间: 2026-06-26

题目描述

给定一个整数，判断该数是奇数还是偶数。如果 nnn 是奇数，输出 odd；如果 nnn 是偶数，输出 even。

输入格式

输入仅一行，一个整数 nnn。

输出格式

输出仅一行，如果 nnn 是奇数，输出 odd；如果 nnn 是偶数，输出 even。

样例

样例输入 #1

5```

**样例输出 #1**

odd```

样例输入 #2

10```

**样例输出 #2**

even```

AC 代码

#include<bits/stdc++.h>
using namespace std;
int n;
int main(){
    cin>>n;
    if(n%2) cout<<"odd";
    else cout<<"even";
    return 0;
}
