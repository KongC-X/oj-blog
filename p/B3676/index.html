B3676 [语言月赛202211] Winner

洛谷 | 入门 | C++14 | 提交时间: 2026-08-16

算法标签：2022、O2优化、分支结构、语言月赛

题目描述

在网易非对称对抗游戏《第五人格》中，玩家分为 监管者 与 求生者 两个阵营。

一局标准模式游戏由一名监管者玩家和四名求生者玩家组成。游戏的胜利判定与求生者逃脱人数 KKK 有关：

  • K>2K>2K>2，求生者获胜（Survivor Win\texttt{Survivor Win}Survivor Win）
  • K=2K=2K=2，平局（Tie\texttt{Tie}Tie）
  • K<2K<2K<2，监管者获胜（Hunter Win\texttt{Hunter Win}Hunter Win）

现在给出一局游戏的求生者逃脱人数，请问获胜阵营（或平局）。

输入格式

输入一行一个整数 KKK，代表求生者逃脱人数。

输出格式

输出一行一个字符串，代表游戏结果：

  • 若求生者阵营获胜，输出 Survivor
  • 若监管者阵营获胜，输出 Hunter
  • 若平局，输出 Tie

样例

样例输入 #1

2```

**样例输出 #1**

Tie```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3676 [语言月赛202211] Winner
     * 题意：给定求生者逃脱人数 K（0~4），判断游戏结果。
     * 规则：K>2 → 求生者获胜；K=2 → 平局；K<2 → 监管者获胜。
     */
    int K;
    cin >> K;
    if (K > 2) cout << "Survivor" << endl;
    else if (K == 2) cout << "Tie" << endl;
    else cout << "Hunter" << endl;
    return 0;
}
