1174 - 求和

题目描述

输入 nnn （ 1≤n≤50001 \le n \le 50001≤n≤5000 ）个正整数，每个数都在 111 到 200002000020000 之间；要求对这 nnn 个数中的奇数和偶数分别求和。

输入

第一行，一个正整数 nnn （ 1≤n≤50001 \le n \le 50001≤n≤5000 ）。

第 2∼n+12 \sim n+12∼n+1 行，每行一个正整数，每个数都在 1到200001到200001到20000 之间。

输出

输出文件共有二行，每行包含一个整数，第一行为所有奇数之和，第二行为所有偶数之和。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;

int main(){
    //读入n个数，将这n个数中的奇数和偶数分别求和
    int n,a[5010],i,s1 = 0,s2 = 0;

    cin>>n;
    for(i = 0;i < n;i++){
        cin>>a[i];
        if(a[i] % 2 == 1){
            s1 = s1 + a[i];
        }else{
            s2 = s2 + a[i];
        }
    }
    cout<<s1<<endl<<s2;
    return 0;
}
