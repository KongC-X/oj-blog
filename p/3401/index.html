3401 - 小杨的X字矩阵

题目描述

小杨想要构造一个 N×NN \times NN×N 的 XXX 字矩阵（NNN 为奇数），这个矩阵的两条对角线都是半角加号 + ，其余都是半角减号 - 。例如，一个 5×55 \times 55×5的 XXX 字矩阵如下：

+---+
-+-+-
--+--
-+-+-
+---+

请你帮小杨根据给定的 NNN 打印出对应的“ XXX 字矩阵”。

输入

一行一个整数 NNN （5≤N≤495 \leq N \leq 495≤N≤49，保证 NNN 为奇数）。

输出

输出对应的“XXX 字矩阵”。

请严格按格式要求输出，不要擅自添加任何空格、标点、空行等任何符号。你应该恰好输出 NNN 行，每行除了换行符外恰好包含 NNN 个字符，这些字符要么是 + ，要么是 - 。

在常规程序中，输入、输出时提供提示是好习惯。但在本场考试中，由于系统限定，请不要在输入、输出中附带任何提示信息。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main()
{
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            if (i == j || i + j == n + 1) {
                cout << "+";
            } else {
                cout << "-";
            }
        }
        cout << endl;
    }
    return 0;
}
