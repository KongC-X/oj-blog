1127 - 整数的拼接

题目描述

设有 nnn 个整数(3≤n≤1003≤n≤1003≤n≤100)，将这些整数拼接起来，可以形成一个最大的整数。

例如：n=3n=3n=3，三个整数分别为 212121 777 343434， 拼接后最大的整数为： 734217342173421。

再比如：n=3n=3n=3，三个整数分别是 111 101010 110110110 ，拼接后最大的整数是：111010111010111010。

输入

第一行一个整数 nnn ，表示有 nnn 个整数。

第二行 nnn 个整数，数与数之间用一个空格分隔。

输出

一个拼接后的最大的整数。

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

bool cmp(string a, string b) {
    if(a + b > b + a) {
        return true;
    } else {
        return false;
    }
}

int main(){
    string s[110];
    int i,n;
    cin >> n;
    for(i = 0; i < n; i++) cin >> s[i];
    sort(s, s + n, cmp);
    for(i = 0; i < n; i++) cout << s[i];
}
