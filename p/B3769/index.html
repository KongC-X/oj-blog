B3769 [语言月赛202305] 制糊串

洛谷 | 入门 | C++14 | 提交时间: 2026-09-23

算法标签：2023、O2优化、字符串（入门）、语言月赛

题目背景

在这个问题中，我们用 s[x,y]s[x,y]s[x,y] 表示从字符串 sss 的第 xxx 个字符到第 yyy 个字符连起来构成的字符串。例如，若 s=abcdefs = \texttt{abcdef}s=abcdef，则 s[2,4]=bcds[2,4] = \texttt{bcd}s[2,4]=bcd。

题目描述

给出两个字符串 sss 和 ttt，有 qqq 次询问。

每次给出 l1,r1l_1, r_1l1​,r1​ 和 l2,r2l_2, r_2l2​,r2​，请判断 s[l1,r1]s[l_1, r_1]s[l1​,r1​] 和 t[l2,r2]t[l_2, r_2]t[l2​,r2​] 谁的字典序更小。

输入格式

第一行是一个字符串 sss。
第二行是一个字符串 ttt。
第三行是一个整数，表示询问次数 qqq。
接下来 qqq 行，每行四个整数 l1,r1,l2,r2l_1, r_1, l_2, r_2l1​,r1​,l2​,r2​，表示一次询问。

输出格式

对每次询问，输出一行一个字符串：

  • 如果 s[l1,r1]s[l_1, r_1]s[l1​,r1​] 的字典序更小，请输出 yifusuyi\texttt{yifusuyi}yifusuyi。
  • 如果 t[l2,r2]t[l_2, r_2]t[l2​,r2​] 的字典序更小，请输出 erfusuer\texttt{erfusuer}erfusuer。
  • 如果两者的字典序一样大，请输出 ovo\texttt{ovo}ovo。

样例

样例输入 #1

Yifusuyi
yifusuYi
3
1 2 7 8
1 2 1 2
7 8 7 8```

**样例输出 #1**

ovo
yifusuyi
erfusuer```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    string s, t;
    cin >> s >> t;

    int q;
    cin >> q;

    while (q--) {
        int l1, r1, l2, r2;
        cin >> l1 >> r1 >> l2 >> r2;

        // 提取子串（注意题目中下标从 1 开始，substr 第二个参数是长度）
        string a = s.substr(l1 - 1, r1 - l1 + 1);
        string b = t.substr(l2 - 1, r2 - l2 + 1);

        if (a < b) {
            cout << "yifusuyi" << endl;
        } else if (a > b) {
            cout << "erfusuer" << endl;
        } else {
            cout << "ovo" << endl;
        }
    }

    return 0;
}
