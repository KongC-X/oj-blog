B2159 成绩排序

洛谷 | 入门 | C++14 | 提交时间: 2026-06-28

题目描述

给出班里某门课程的成绩单，请你按成绩从高到低对成绩单排序输出，如果有相同分数则名字字典序小的在前。

输入格式

第一行为 $n (0 < n < 20)$，表示班里的学生数目；

接下来的 $n$ 行，每行为每个学生的名字和他的成绩, 中间用单个空格隔开。名字只包含字母且长度不超过 $20$，成绩为一个不大于 $100$ 的非负整数。

输出格式

把成绩单按分数从高到低的顺序进行排序并输出，每行包含名字和分数两项，之间有一个空格。

样例

样例输入 #1

4
Kitty 80
Hanmeimei 90
Joey 92
Tim 28```

**样例输出 #1**

Joey 92
Hanmeimei 90
Kitty 80
Tim 28```

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 学生结构体
struct S {
    string x;          // 姓名
    int y;             // 成绩
};

// 排序规则：成绩降序，成绩相同则姓名字典序升序
bool cmp(S a, S b) {
    if (a.y != b.y) return a.y > b.y;
    return a.x < b.x;
}

int main() {
    int n;             // n: 学生人数
    cin >> n;

    S a[25];           // 最多 20 人，开 25 安全
    for (int i = 0; i < n; i++) {
        cin >> a[i].x >> a[i].y;
    }

    sort(a, a + n, cmp);

    for (int i = 0; i < n; i++) {
        cout << a[i].x << " " << a[i].y << endl;
    }

    return 0;
}
