B4130 [信息与未来 2014] 连续非素数子序列的最大长度

洛谷 | 普及- | C++14 | 提交时间: 2026-04-13

算法标签：2014、江苏、枚举、素数判断、信息与未来

题目描述

给出一个正整数 nnn，求在数列 {2,3,⋯ ,n}\{2,3,\cdots,n\}{2,3,⋯,n}
中，连续非素数子序列的最大长度。

输出格式

一个整数，表示连续非素数子序列的最大长度。

样例

样例输入 #1

12```

**样例输出 #1**

3```

样例输入 #2

30```

**样例输出 #2**

5```

AC 代码

#include <iostream>
#include <cmath>
using namespace std;

const int MAXN = 5000005;  // 最大数据范围
bool isPrime[MAXN];        // true 表示是素数，false 表示不是素数
int n;

int main() {
    cin >> n;

    // 1. 埃氏筛法：标记素数
    // 初始化：假设所有数都是素数
    for (int i = 2; i <= n; i++) {
        isPrime[i] = true;
    }
    // 筛掉非素数
    for (int i = 2; i * i <= n; i++) {
        if (isPrime[i]) {
            for (int j = i * i; j <= n; j += i) {
                isPrime[j] = false;
            }
        }
    }

    // 2. 统计最长连续非素数长度
    int maxLen = 0;  // 记录最大长度
    int curLen = 0;  // 当前连续非素数长度

    for (int i = 2; i <= n; i++) {
        if (!isPrime[i]) {       // 如果是非素数
            curLen++;
            if (curLen > maxLen) {
                maxLen = curLen;
            }
        } else {                 // 如果是素数，中断连续
            curLen = 0;
        }
    }

    cout << maxLen << endl;

    return 0;
}
