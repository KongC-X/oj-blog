B3687 [语言月赛202212] 数字口袋

洛谷 | 入门 | C++14 | 提交时间: 2026-08-30

算法标签：2022、O2优化、循环结构、语言月赛

题目描述

小 A 有一个口袋，里面可以装整数。他从 111 开始，按从小到大的顺序，依次将每个整数装入口袋。

但是口袋是有限的，大小为 nnn，这就是说，口袋里所有的数字的和不能够超过 nnn。

输入格式

输入只有一行一个整数，表示整数 nnn。

输出格式

输出若干行，每行一个整数，按从小到大的顺序输出口袋里的数字。

样例

样例输入 #1

15```

**样例输出 #1**

1
2
3
4
5```

样例输入 #2

9```

**样例输出 #2**

1
2
3```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3687 [语言月赛202212] 数字口袋
     * 题意：从1开始依次放入整数，直到总和超过n，输出已放入的整数。
     * 思路：从1开始累加，当总和 + 下一个数 <= n 时，放入并输出。
     */
    long long n;
    cin >> n;
    long long sum = 0;
    int i = 1;
    while (sum + i <= n) {
        sum += i;
        cout << i << endl;
        i++;
    }
    return 0;
}
