1764 - 统计数字

题目描述

某次科研调查时得到了 nnn 个自然数，每个数均不超过150000000015000000001500000000（1.5×1091.5 \times 10^91.5×109）。

已知不相同的数不超过 100001000010000 个，现在需要统计这些自然数各自出现的次数，并按照自然数从小到大的顺序输出统计结果。

输入

包含 n+1n+1n+1 行；

第一行是整数 nnn ，表示自然数的个数；

第 222~n+1n+1n+1 每行一个自然数。

输出

包含 mmm 行（ mmm 为 nnn 个自然数中不相同数的个数），按照自然数从小到大的顺序输出。

每行输出两个整数，分别是自然数和该数出现的次数，其间用一个空格隔开。

AC代码

AC代码

#include <iostream>
#include <map>
using namespace std;

int main() {
    int n;
    cin >> n;
    map<int,int> m;
    for(int i = 0;i < n;i++) {
        int num;
        cin >> num;
        m[num]++;
    }
    map<int,int>::iterator it;
    for(it = m.begin();it != m.end();it++) {
        cout << it->first << " " << it->second << endl;
    }
}
