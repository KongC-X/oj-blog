B4239 [海淀区小学组 2024] 拜访朋友

洛谷 | 普及- | C++14 | 提交时间: 2026-07-27

算法标签：贪心、2025、北京、排序、科创活动、小学活动

题目背景

2024 年海淀区中小学生信息学竞赛小学组复赛题目，数据为洛谷自造。

题目描述

陶陶有 nnn 个好朋友，他们的住所都分布在同一条笔直的街道旁，如果把这条街道看作一个数轴，选定一个点作为坐标原点（坐标为 000），则这 nnn 个好朋友的住所的坐标分别为 x1,x2,…,xnx_1, x_2, \dots, x_nx1​,x2​,…,xn​。一天，陶陶要去朋友们的住所去拜访朋友们，陶陶初始位置的坐标为 x0x_0x0​，他希望至少拜访到 n−1n - 1n−1 个好朋友，请你确定陶陶要最少要行走的总距离。

输入格式

第一行包含两个整数 nnn 和 x0x_0x0​，第二行包含 nnn 个整数 x1,x2,…,xnx_1, x_2, \dots, x_nx1​,x2​,…,xn​。

输出格式

仅有一个正整数，表示最小的总行走距离。

样例

样例输入 #1

3 10
1 7 12```

**样例输出 #1**

7```

样例输入 #2

2 0
11 -10```

**样例输出 #2**

10```

样例输入 #3

5 0
0 0 1000 0 0```

**样例输出 #3**

0```

AC 代码

#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 100005;
long long x[MAXN];

// 计算从起点 x0 出发，访问坐标在 [L, R] 区间内所有点的最短总距离
long long dist(long long x0, long long L, long long R) {
    if (x0 <= L) return R - x0;          // 起点在区间左侧，一路向右走到 R
    if (x0 >= R) return x0 - L;          // 起点在区间右侧，一路向左走到 L
    // 起点在区间内部，先走到较近的一端，再走完整段区间
    return (R - L) + min(x0 - L, R - x0);
}

int main() {
    /*
      思路：
      所有朋友在数轴上，需要访问至少 n-1 个朋友。
      将坐标排序后，选择的 n-1 个朋友一定是连续的一段（跳过最左或最右的一个点，或者不跳过）。
      因此答案只有三种可能：
        1. 访问全部 n 个点；
        2. 跳过最左边的点，访问其余 n-1 个；
        3. 跳过最右边的点，访问其余 n-1 个。
      计算这三种情况的最短路径，取最小值即可。
      特别地，当 n=1 时，至少访问 0 个点，距离为 0。
    */
    int n;
    long long x0;
    cin >> n >> x0;
    for (int i = 0; i < n; ++i) {
        cin >> x[i];
    }
    sort(x, x + n);

    long long ans;
    if (n == 1) {
        ans = 0;                      // 只有一个朋友，至少访问0个，可以不去
    } else {
        ans = dist(x0, x[0], x[n-1]);                // 情况1：访问全部
        ans = min(ans, dist(x0, x[1], x[n-1]));      // 情况2：跳过最左
        ans = min(ans, dist(x0, x[0], x[n-2]));      // 情况3：跳过最右
    }

    cout << ans << endl;
    return 0;
}
