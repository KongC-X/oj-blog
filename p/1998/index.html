1998 找朋友

东方博宜 入门 二维数组
二维数组

1998 - 找朋友

题目描述

小 TTT 喜欢和自己同龄的人交朋友，现在他排在了一个 nnn 行 mmm 列的队伍中。

请问在小 TTT 所在的行和小 TTT 所在的列中，他一共能交到几个朋友？

比如：一个 666 行 666 列的矩阵如下，该矩阵中每个数字代表了一个同学的年龄。

`8  9  7  9  5  3 
2  9  15 9  9  12 
21 3  4  6  7  9
10 10 8  2  3  6
5  4  2  9  5  10
9  11 2  9  5  7 
`

假设小 TTT 在第 222 行第 444 列对应的位置，也就是他的年龄是 999 岁，他所在的第 222 行除了小 TTT 还有 222 个人是 999 岁，他所在的列除了小 TTT 有 333 个人是 999 岁，因此他可以交到 555 个朋友。

输入

第 111 行有 222 个整数 nnn 和 mmm ，分别代表队形的行和列的值（ 2≤n,m≤2002 \le n,m \le 2002≤n,m≤200 ）

接下来 nnn 行，每行有 mmm 个整数，代表每个同学的年龄（每个同学的年龄的值在 1∼1001 \sim 1001∼100 之间）

接下来最后一行有 222 个整数，代表小 TTT 在第几行第几列

输出

输出一个整数，代表小 TTT 可以交到的朋友的数量。

解题思路

AC代码

AC代码

# include<bits/stdc++.h>
using namespace std;

/*
思路：
1.小T的年龄是a[t1][t2]
2.统计出第x行有多少个值是a[t1][t2]
  第y列有多少个值是a[t1][t2]
  答案 = 统计出来的总数 - 2（包括了2次自己） 
*/ 

int main() {
    int a[210][210];
    int i,j,n,m,t1,t2,sum = 0; 
    cin>>n>>m;
    for(i = 1;i <= n;i++){
        for(j = 1;j <= m;j++){
            cin>>a[i][j];
        }
    }
    //读入小t的位置 
    cin>>t1>>t2;
    //循环第t1行（本质上是循环m列的每个数） 
    //为了好理解，我们用j来循环列 
    for(j = 1;j <= m;j++){
        if(a[t1][j] == a[t1][t2]){
            sum++;
        }
    }
    //循环第t2列（本质上是循环n行的每个数）
    for(i = 1;i <= n;i++){
        if(a[i][t2] == a[t1][t2]){
            sum++;
        }
    } 
    cout<<sum - 2 << endl;
}
