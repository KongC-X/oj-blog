B4333 [中山市赛 2023] 同质

洛谷 | 入门 | C++14 | 提交时间: 2026-07-19

算法标签：模拟、2023、科创活动、小学活动

题目描述

给定一个仅由小写字母组成的字符串 $s$，求 $s$ 中最长的子串的长度，满足子串中所有字母均相等。

输入格式

一行一个字符串 $s$。

输出格式

一行一个整数，表示答案。

样例

样例输入 #1

aabaaaccdd```

**样例输出 #1**

3```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;                     // s: 输入的字符串
    cin >> s;
    int n = s.size();
    int ans = 1;                  // ans: 最长连续相同子串长度，至少为1
    int cur = 1;                  // cur: 当前连续相同段的长度

    for (int i = 1; i < n; i++) {
        if (s[i] == s[i - 1]) {   // 与前一个字符相同，延续当前段
            cur++;
            if (cur > ans) ans = cur; // 更新最大值
        } else {                  // 遇到不同字符，重新开始计数
            cur = 1;
        }
    }

    cout << ans << endl;
    return 0;
}
