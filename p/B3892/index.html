B3892 [语言月赛 202311] 方程求解

洛谷 | 普及- | C++14 | 提交时间: 2026-09-29

算法标签：模拟、2023、O2优化、字符串（入门）、语言月赛

题目描述

小 A 有 nnn 个关于 xxx 的方程，第 iii 个方程形如 aixi+bi=cia_ix_i+b_i=c_iai​xi​+bi​=ci​。方程的解 xxx 均为正整数，例如下面几个方程都是符合要求的方程：

2x+4=10
-3x+13=10
4x-8=16

其中，第一组方程的解为 x1=3x_1=3x1​=3，第二组方程的解为 x2=1x_2=1x2​=1，第三组方程的解为 x3=6x_3=6x3​=6。

小 A 想要知道，给定 L,RL,RL,R，在 L≤x≤RL\leq x\leq RL≤x≤R 的范围内，有多少个正整数 xxx 满足 xxx 是其中至少一个方程的解。为了防止你欺骗他，他会询问你 QQQ 次。

输入格式

第一行输入两个正整数 n,Qn,Qn,Q，分别表示小 A 有的方程数，以及小 A 想要向你询问的次数。

第二行开始，往下 nnn 行，每行一个字符串，描述一个方程。

第 (n+2)(n+2)(n+2) 行开始，往下 QQQ 行，每行两个正整数 L,RL,RL,R，表示一次询问，即给定 L,RL,RL,R，询问在 L≤x≤RL\leq x\leq RL≤x≤R 的范围内，有多少个正整数 xxx 满足 xxx 是其中至少一个方程的解。

输出格式

对于每次询问，输出一行一个整数，表示有多少个在 L≤x≤RL\leq x\leq RL≤x≤R 的范围内的正整数 xxx，满足 xxx 是其中至少一个方程的解。

样例输入 #1

3 4
2x+4=10
-3x+13=10
4x-8=16
1 6

**样例输出 #1**

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3892 [语言月赛 202311] 方程求解
     * 题意：给定 n 个形如 "aix+bi=ci" 的方程，解均为正整数。
     *       有 Q 次询问，每次给出 L, R，问在 [L, R] 内有多少个正整数 x
     *       是至少一个方程的解。
     *
     * 思路：
     *   1. 用 bool 数组 mark[1005] 标记哪些 x 是某个方程的解（x ≤ 1000）。
     *   2. 逐个解析方程字符串，提取 a, b, c，计算 x = (c - b) / a。
     *      因为题目保证解为正整数，直接整除即可。
     *   3. 若 x 在 1~1000 内，则 mark[x] = true。
     *   4. 对每个询问 [L, R]，遍历 1~1000，统计 mark[i] 为 true 且在区间内的个数。
     *
     * 时间复杂度：O(n * |s| + Q * 1000)，n, Q ≤ 1000，完全可行。
     */

    int n, Q;
    cin >> n >> Q;

    bool mark[1005] = {false};   // mark[x]: x 是否为某个方程的解

    for (int i = 0; i < n; i++) {
        string s;
        cin >> s;

        // 找到 'x' 和 '=' 的位置
        int p1 = s.find('x');
        int p2 = s.find('=');

        // 解析 a
        string a_str = s.substr(0, p1);
        int a;
        if (a_str == "" || a_str == "+") a = 1;
        else if (a_str == "-") a = -1;
        else a = stoi(a_str);

        // 解析 b
        string b_str = s.substr(p1 + 1, p2 - p1 - 1);
        int b;
        if (b_str == "") b = 0;
        else b = stoi(b_str);

        // 解析 c
        string c_str = s.substr(p2 + 1);
        int c = stoi(c_str);

        // 计算解 x
        int x = (c - b) / a;

        // 标记在 1~1000 内的解
        if (x >= 1 && x <= 1000) {
            mark[x] = true;
        }
    }

    // 处理询问
    while (Q--) {
        int L, R;
        cin >> L >> R;
        int ans = 0;
        for (int x = L; x <= R; x++) {
            if (mark[x]) ans++;
        }
        cout << ans << endl;
    }

    return 0;
}
