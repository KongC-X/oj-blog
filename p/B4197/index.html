B4197 [常州市赛 2020] 欢迎

洛谷 | 入门 | C++14 | 提交时间: 2026-07-17

算法标签：模拟、2020、江苏、字符串（入门）、科创活动、小学活动

题目背景

搬运自 http://czoj.com.cn/p/445。数据为民间数据。

题目描述

欢迎参加 202020202020 年常州市“程序设计小能手”比赛！小 X\text XX 想为你献上一张贺卡，不过……你得自己打印出来。

贺卡由三行组成。其中第二行为 *Welcome,ContestantNo.A!*，其中 AAA 是选手的编号。第一行和第三行相同，是和第二行字符数量相同的 * 组成。你可以通过样例来理解。

输入格式

输入数据只有一行，包含一个正整数 AAA，表示选手的编号。

样例

样例输入 #1

1```

**样例输出 #1**

Welcome,ContestantNo.1!
*************************```

样例输入 #2

233```

**样例输出 #2**

Welcome,ContestantNo.233!
***************************```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 1. 读入选手编号 A。
    // 2. 构造第二行字符串：*Welcome,ContestantNo.A!*，其中 A 替换为实际编号。
    // 3. 计算该字符串的长度 len。
    // 4. 输出 len 个 '*' 作为第一行。
    // 5. 输出第二行。
    // 6. 再次输出 len 个 '*' 作为第三行。

    int A;                        // A: 选手编号
    cin >> A;

    string mid = "*Welcome,ContestantNo." + to_string(A) + "!*";
    int len = mid.size();         // 第二行长度

    // 第一行星号
    for (int i = 0; i < len; i++) cout << '*';
    cout << endl;

    // 第二行
    cout << mid << endl;

    // 第三行星号
    for (int i = 0; i < len; i++) cout << '*';
    cout << endl;

    return 0;
}
