1320 - 时钟旋转（1）

题目描述

时钟上面的时针从 mmm 时走到 nnn 时旋转了多少度？（m≤nm \le nm≤n，且 mmm 和 nnn 都是1∼121 \sim 121∼12之间的整数）。（4.2.4）

输入

222 个整数 mmm 和 nnn。

输出

111 个整数代表时针旋转的度数。

解题思路

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int main() {
    int m,n;
    cin >> m >> n;
    cout << (n - m) * 30 << endl;
    return 0;
}
