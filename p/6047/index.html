6047 - 判断数字出现了几次

题目描述

给定一个正整数 nnn，判断从 111 到这个数本身的所有数中，一共出现了多少次数字 kkk。

输入

输入共 111 行，包括一个正整数 nnn 和一个正整数 kkk。(0<n<327670 \lt n \lt 327670<n<32767，0<k<100 \lt k \lt 100<k<10）

输出

输出共 111 行，一个整数，表示 111 到 nnn 之间的所有数 (包括 nnn)，一共出现了几次 kkk。

AC代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, k;                     // n: 上限，k: 要统计的数字（1~9）
    cin >> n >> k;

    // ---------- 思路 ----------
    // 题目要求统计 1 到 n 之间所有整数的十进制表示中，数字 k 出现的总次数。
    // 由于 n ≤ 32767，可以直接遍历每个数，提取每一位判断是否等于 k，累加即可。
    // 时间复杂度 O(n * log10(n))，完全可接受。

    int ans = 0;                  // 答案：k 出现的总次数
    for (int i = 1; i <= n; i++) {
        int x = i;                // 临时变量，避免破坏 i
        while (x > 0) {
            if (x % 10 == k) ans++; // 末位是 k
            x /= 10;               // 去掉末位
        }
    }
    // 注意：如果 k=0 需要特别处理，但题目 k>0，所以没问题。

    cout << ans << '\n';
    return 0;
}
