P3156 【深基15.例1】询问学号

洛谷 | 入门 | C++14 | 提交时间: 2026-05-15

题目描述

有 n(n≤2×106)n(n \le 2 \times 10^6)n(n≤2×106) 名同学陆陆续续进入教室。我们知道每名同学的学号（在 111 到 10910^9109 之间），按进教室的顺序给出。上课了，老师想知道第 iii 个进入教室的同学的学号是什么（最先进入教室的同学 i=1i=1i=1），询问次数不超过 10510^5105 次。

输入格式

第一行 222 个整数 nnn 和 mmm，表示学生个数和询问次数。

第二行 nnn 个整数，表示按顺序进入教室的学号。

第三行 mmm 个整数，表示询问第几个进入教室的同学。

输出格式

输出 mmm 个整数表示答案，用换行隔开。

样例

样例输入 #1

10 3
1 9 2 60 8 17 11 4 5 14
1 5 9

样例输出 #1

1
8
5```

## AC 代码

```cpp
#include <cstdio>
#include <vector>
using namespace std;   // 使用标准命名空间，方便直接使用 vector、scanf、printf

/*
【题目思路与解题过程】
题意：有 n 名同学按顺序进入教室，我们按顺序得到他们的学号。
     接下来有 m 次询问，每次询问给出一个整数 x，表示想知道第 x 个进入教室的同学的学号。
     你需要按顺序输出 m 个答案，每个答案占一行。

解题思路：
1. 问题的关键在于“按顺序”存储学号。第 1 个进入的同学的学号存在位置 1，第 2 个存在位置 2，以此类推。
2. 询问时，直接读取 x，然后输出位置 x 的学号。
3. 因为 n 最大可达 2×10^6，使用数组或 vector 都可以。这里使用 vector 来动态分配内存，
   大小为 n+1，从下标 1 开始使用，更加直观。
4. 学号范围在 1 ~ 10^9，int 类型足够存储。
5. 输入输出量较大，使用 scanf/printf 效率更高。
*/

int main() {
    int n, m;                     // n: 学生个数, m: 询问次数
    scanf("%d%d", &n, &m);
    
    vector<int> a(n + 1);         // a[1..n] 存储学号，下标 i 表示第 i 个进入教室的同学
    
    // 读入 n 个学号，按进入教室的顺序存入 a[1] 到 a[n]
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }
    
    // 处理 m 次询问
    for (int i = 0; i < m; i++) {
        int x;                    // x: 询问第 x 个进入教室的同学
        scanf("%d", &x);
        // 直接输出 a[x] 即可，因为数组下标和进入顺序一一对应
        printf("%d\n", a[x]);
    }
    
    return 0;
}
