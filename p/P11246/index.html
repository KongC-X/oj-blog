P11246 [GESP202409 六级] 小杨和整数拆分

洛谷 | 普及- | C++14 | 提交时间: 2026-06-03

算法标签：动态规划 DP、2024、广度优先搜索 BFS、深度优先搜索 DFS、记忆化搜索、背包 DP、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1162

题目描述

小杨有一个正整数 $n$，小杨想将它拆分成若干完全平方数的和，同时小杨希望拆分的数量越少越好。

编程计算总和为 $n$ 的完全平方数的最小数量。

输入格式

输入只有一行一个正整数 $n$。

输出格式

输出一行一个整数表示答案。

样例

样例输入 #1

18

样例输出 #1

2```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 问题类型：完全背包求最小物品数（每种平方数无限使用）
// 要将 n 拆成若干个完全平方数（1,4,9,16,...）的和，求最少需要几个。
// dp 数组定义：dp[i] 表示凑出整数 i 所需的最少完全平方数个数。
// 初始条件：dp[0] = 0，表示凑出 0 需要 0 个。
// 状态转移：对于每个 i 从 1 到 n，枚举最后一个平方数 j*j（j*j <= i），
//           则 dp[i] = min(dp[i], dp[i - j*j] + 1）。
// 最坏情况：全是1相加，需要 i 个，所以 dp[i] 初始化为 i。
// 时间复杂度 O(n * sqrt(n))，空间 O(n)，对于 n <= 1e5 可以接受。

int dp[100010];
int n;
int main() {
    cin >> n;
    dp[0] = 0; // 初始化 dp[0] 为 0，表示凑出 0 需要 0 个。
    for (int i = 1; i <= n; i++) {
        dp[i] = i; // 最坏情况就是全是1相加，需要 i 个，所以 dp[i] 初始化为 i。
        // 尝试所有的平方数 j*j 作为最后一项
        for (int j = 1; j * j <= i; j++) {
            // 如果使用 j*j 能减少个数，更新 dp[i]
            dp[i] = min(dp[i], dp[i - j * j] + 1);
        }
    }
    cout << dp[n] << endl;
    return 0;
}
