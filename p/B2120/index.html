B2120 单词的长度

洛谷 | 入门 | C++14 | 提交时间: 2026-07-12

算法标签：字符串（入门）

题目描述

输入一行单词序列，相邻单词之间由 $1$ 个或多个空格间隔，请对应地计算各个单词的长度。

注意：如果有标点符号（如连字符，逗号），标点符号算作与之相连的词的一部分。没有被空格间开的符号串，都算作单词。

输入格式

一行单词序列，最少 $1$ 个单词，最多 $300$ 个单词，单词之间用至少 $1$ 个空格间隔。单词序列总长度不超过 $1000$。

输出格式

依次输出对应单词的长度，之间以逗号间隔。

样例

样例输入 #1

She was born in 1990-01-02  and  from Beijing city.```

**样例输出 #1**

3,3,4,2,10,3,4,7,5```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 1. 用 getline 读入整行（因为单词之间可能有多个空格）。
    // 2. 遍历字符串，遇到非空格字符则计入当前单词长度。
    // 3. 遇到空格且之前有非空格时，说明一个单词结束，输出其长度，并用逗号分隔。
    // 4. 特别注意：最后一个单词后面可能没有空格，循环结束后单独输出最后一个单词的长度。

    string s;                              // 输入的整行单词序列
    getline(cin, s);

    int n = s.size();                      // 字符串总长度
    int len = 0;                           // 当前单词的长度
    bool first = true;                     // 标记是否是第一个输出的单词

    for (int i = 0; i < n; i++) {
        if (s[i] != ' ') {
            len++;                         // 遇到非空格，单词长度加 1
        } else {
            if (len > 0) {                 // 遇到空格且之前有单词，说明一个单词结束
                if (!first) cout << ',';   // 不是第一个单词，先输出逗号
                cout << len;
                len = 0;
                first = false;
            }
        }
    }
    // 处理最后一个单词（字符串末尾没有空格的情况）
    if (len > 0) {
        if (!first) cout << ',';
        cout << len;
    }
    cout << endl;

    return 0;
}
