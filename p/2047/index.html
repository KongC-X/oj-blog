2047 - 最短距离和路径问题

题目描述

有 nnn 个城市（编号为 1∼n1 \sim n1∼n），mmm 条道路（)，每条道路有个长度（道路是双向的，两个方向都能走），请找到从起点 sss 到终点 ttt 的最短距离和经过的城市名。

输入

第一行输入四个数，分别为 n,m,s,tn,m,s,tn,m,s,t。（）

接下来 mmm 行，每行三个数 x,y,lenx,y,lenx,y,len ，分别为两个城市名和距离。（1≤x,y≤n，1≤len≤500001≤x,y≤n，1≤len≤500001≤x,y≤n，1≤len≤50000）

输出

每组输出占两行。

第一行输出起点到终点的最短距离。

第二行输出最短路径上经过的城市名，如果有多条最短路径，输出字典序最小的那条。若不存在从起点到终点的路径，则输出can't arrive。

请注意：本题两个相同的城市之间可能存在多条路径。

解题思路

AC代码

#include <iostream>
#include <cmath>
using namespace std;

int main() {
    // 完全平方数：数字开根号之后得到是一个整数
    // sqrt(n) == int(sqrt(n))
    int i = 1;
    while(true) {
        if(sqrt(i+100) == int(sqrt(i+100)) && sqrt(i + 268) == int(sqrt(i + 268))) {
            cout << i << endl;
            break;
        }
        i++;
    }
}
