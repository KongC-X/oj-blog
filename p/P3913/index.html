P3913 车的攻击

洛谷 | 普及- | C++14 | 提交时间: 2026-05-22

算法标签：数学、排序

题目描述

N×NN \times NN×N 的国际象棋棋盘上有 KKK 个车，第 iii 个车位于第 RiR_iRi​ 行，第 CiC_iCi​ 列。求至少被一个车攻击的格子数量。

车可以攻击所有同一行或者同一列的地方。

输入格式

第 111 行，222 个整数 N,KN,KN,K。

接下来 KKK 行，每行 222 个整数 Ri,CiR_i,C_iRi​,Ci​。

输出格式

111 个整数，表示被攻击的格子数量。

样例

样例输入 #1

3 2
1 2
2 2```

**样例输出 #1**

7```

AC 代码

#include <iostream>
#include <algorithm>  // sort, unique
using namespace std;

const int MAXK = 1000000;    // 最大车数
int r[MAXK + 5];             // 存放所有车的行坐标
int c[MAXK + 5];             // 存放所有车的列坐标

int main() {
    // ---------- 思路 ----------
    // 车的攻击覆盖整行和整列。
    // 设被占用的不同行数为 A，不同列数为 B。
    // 则被攻击的格子总数 = 所有被占行的格子 + 所有被占列的格子 - 行列交叉重复计算的部分
    //                    = A * N + B * N - A * B。
    //
    // 步骤：
    // 1. 读入所有车的行、列，分别存入数组 r 和 c。
    // 2. 分别对 r 和 c 排序，然后 unique 去重，得到不同行数 A 和不同列数 B。
    // 3. 用 long long 计算答案并输出。
    // -------------------------

    long long n;              // n: 棋盘大小 (最大 1e9，用 long long)
    int k;                    // k: 车的数量
    cin >> n >> k;

    for (int i = 0; i < k; ++i) {
        cin >> r[i] >> c[i];
    }

    // 对行坐标排序并去重，A 为不同行的数量
    sort(r, r + k);
    int A = unique(r, r + k) - r;   // unique 返回去重后末尾迭代器，相减得长度

    // 对列坐标排序并去重，B 为不同列的数量
    sort(c, c + k);
    int B = unique(c, c + k) - c;

    // 计算答案：A*N + B*N - A*B
    long long ans = A * n + B * n - (long long)A * B;
    cout << ans << endl;

    return 0;
}
