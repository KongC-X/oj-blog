1266 - 求最大数

题目描述

问 $555555$ 的约数中最大的三位数是多少？

输入

无。

输出

约数中最大的三位数。

AC代码

#include<bits/stdc++.h>
using namespace std;
 
int main() {
    int i;
    //遍历所有三位数 ，从大的数开始 
    for(i=999;i>=100;i--){
        //如果能整除 555555就输出i，跳出循环 
        if(555555%i==0){
            cout<<i;
            break;
        }
    }
}
