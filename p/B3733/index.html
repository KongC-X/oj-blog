B3733 [信息与未来 2017] 基因组分析

洛谷 | 普及- | C++14 | 提交时间: 2026-04-13

算法标签：字符串、2017、江苏、信息与未来

题目描述

乌龟得到了他的基因组，一个只包含 ATCG\tt{ATCG}ATCG 四种字母的字符串。乌龟想起科学家说，基因组中很多片段都多次重复出现，而且这种重复是很有意义的，于是他想计算一下自己基因组里片段的重复情况。

给定一个基因组，其中一个长度为 kkk 的子串称为一个“kkk-片段”。乌龟希望你计算出基因组中不同的 kkk-片段数量。例如，基因组 TACAC\tt{TACAC}TACAC 的 222-片段有 TA,AC,CA,AC\tt{TA,AC,CA,AC}TA,AC,CA,AC，其中不同的片段数量有 333 个。

试题中使用的生成数列 RRR 定义如下：整数 0≤R1<2017010\leq R_1\lt 2017010≤R1​<201701 在输入中给出。

对于 i>1,Ri=(Ri−1×6807+2831)mod  201701i\gt 1,R_i=(R_{i−1}\times 6807+2831)\mod 201701i>1,Ri​=(Ri−1​×6807+2831)mod201701。

输入格式

整数 n,k,R1n,k,R_1n,k,R1​，表示基因组的长度、片段的
长度和数列生成的首项。基因组第 i(1≤i≤n)i(1\leq i\leq n)i(1≤i≤n) 个字符在 Ri mod 4R_i \bmod 4Ri​mod4 的值为 0,1,2,30,1,2,30,1,2,3 时分别为 A,T,C,G\tt{A,T,C,G}A,T,C,G。

输出格式

一个整数，表示不同的 kkk-片段的数量。

样例

样例输入 #1

20 2 37```

**样例输出 #1**

10```

AC 代码

#include <iostream>
#include <algorithm>  // 为了使用 sort 函数
#include <string>
using namespace std;

int n, k, r;
string t = "ATCG";
string s = "";
string b[100010];   // b 数组用来存放所有的 k 片段（包括重复的）

int main() {
    cin >> n >> k >> r;

    // 1. 生成基因组字符串 s
    for (int i = 1; i <= n; i++) {
        s += t[r % 4];
        r = (r * 6807 + 2831) % 201701;
    }

    // 2. 截取所有的 k 片段，存入数组 b
    int m = 0;  // m 记录 b 中元素个数
    for (int i = 0; i <= n - k; i++) {
        b[m] = s.substr(i, k);
        m++;
    }

    // 用set可以更方便地统计不同的片段数量
    // set<string> st;
    // for (int i = 0; i <= n - k; i++) {
    //     st.insert(s.substr(i, k));
    // }
    // cout << st.size() << endl;

    // 3. 对 b 数组排序（相同的子串会排在一起）
    sort(b, b + m);

    // 4. 统计不同的片段数量
    int cnt = 1;  // 第一个片段肯定是一个新的
    for (int i = 1; i < m; i++) {
        if (b[i] != b[i - 1]) {
            cnt++;
        }
    }

    // 注意特殊情况：如果根本没有 k 片段（即 n < k），答案是 0
    if (n < k) cnt = 0;

    cout << cnt << endl;

    return 0;
}
