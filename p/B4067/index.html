B4067 [GESP202412 三级] 打印数字

洛谷 | 普及- | C++14 | 提交时间: 2025-03-28

算法标签：字符串、2024、分支结构、循环结构、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1167

题目描述

小杨为数字 0,1,20,1,20,1,2 和 333 设计了一款表示形式，每个数字占用了 5×55\times 55×5 的网格。数字 0,1,20,1,20,1,2 和 333 的表示形式如下：

..... ****. ..... .....
.***. ****. ****. ****.
.***. ****. ..... .....
.***. ****. .**** ****.
..... ****. ..... .....

小杨想请你将给定的数字 nnn 转换为对应的表示形式。

输入格式

第一行包含一个非负整数代表 nnn。

样例

样例输入 #1

12230```

**样例输出 #1**

**.....................
..**....
.................*.
...********...
****.....................```

AC 代码

#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

string s;
int i,j,k;
char num[10][30] = {
    "..... ****. ..... .....",
    ".***. ****. ****. ****.",
    ".***. ****. ..... .....",
    ".***. ****. .**** ****.",
    "..... ****. ..... ....."
};

int main() {
    cin >> s;
    for(i = 0;i < 5;i++) {
        for(k = 0;k < s.size();k++){
        // cout << s[k] << " ";
            if(s[k] == '0') {
                for(j = 0;j < 5;j++){
                    cout << num[i][j];
                }
            } else if(s[k] == '1') {
                for(j = 6;j < 11;j++){
                    cout << num[i][j];
                }
            } else if(s[k] == '2') {
                for(j = 12;j < 17;j++){
                    cout << num[i][j];
                }
            } else if(s[k] == '3') {
                for(j = 18;j < 23;j++){
                    cout << num[i][j];
                }
            }
        }
        cout << endl;
    }
}
