B3658 [语言月赛202209] 口算练习

洛谷 | 入门 | C++14 | 提交时间: 2026-08-22

算法标签：数学、2022、O2优化、顺序结构、语言月赛

题目描述

在课堂上，同学们经常需要进行口算练习。

老师出了一道练习题：计算 ⌊xy⌋\bigg\lfloor \dfrac{x}{y} \bigg\rfloor⌊yx​⌋ 的值，请你问答这个问题。

其中 ⌊a⌋\lfloor a \rfloor⌊a⌋ 代表不超过 aaa 的最大整数，如 ⌊1.1⌋=1,⌊4⌋=4,⌊−2.2⌋=−3\lfloor 1.1 \rfloor = 1, \lfloor 4 \rfloor = 4, \lfloor -2.2 \rfloor = -3⌊1.1⌋=1,⌊4⌋=4,⌊−2.2⌋=−3。

提示：

在 C++ 中，int 类型变量 x, y，语句 x/y 计算得到的是 xy\dfrac{x}{y}yx​ 向零取整的值。例如：

int x = -3, y = 2;
cout << x / y;

上面的代码会输出 -1。

floor 函数，其功能是“向下取整”，比如：floor(-1.5) = -2.0

输入格式

输入共一行两个整数 x,yx,yx,y，保证 y≠0y \neq 0y=0。

输出格式

输出一行一个整数，代表 ⌊xy⌋\bigg\lfloor \dfrac{x}{y} \bigg\rfloor⌊yx​⌋。

样例

样例输入 #1

2 1```

**样例输出 #1**

2```

样例输入 #2

-3 2```

**样例输出 #2**

-2```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long x, y;
    cin >> x >> y;
    cout << (long long)floor(1.0 * x / y) << endl;   // 直接调用向下取整函数
    return 0;
}
