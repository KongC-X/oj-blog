1087 - 两个数M和N的最小公倍数

题目描述

求两个正整数 MMM 和 NNN 的最小公倍数。

（ 5.1.445.1.445.1.44 ）

输入

输入一行，包括两个正整数。

输出

输出只有一行，包括 111 个正整数。

解题思路

AC代码

AC代码

#include<iostream>
using namespace std;

long long fun(long long a,long long b) {
    if(a % b != 0) {
        return fun(b, a % b);
    } else {
        return b;
    }
}

int main() {
    long long a,b;
    cin>>a>>b;
    cout << a / fun(a, b) * b;
}
