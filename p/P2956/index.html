P2956 [USACO09OCT] The Robot Plow G

洛谷 | 入门 | C++14 | 提交时间: 2026-08-09

算法标签：2009、USACO

题目描述

农夫约翰购买了一台新的自动耕地机器人，以将自己从日复一日犁地的繁重劳动中解脱出来。这台机器人确实能完成耕地任务，但有一个小缺点：它只能犁出各边长度均为整数的完美矩形地块。

由于约翰的田地中分布着树木和其他障碍物，他需要设定机器人犁耕多个不同的矩形区域，这些区域可能会有重叠。他很好奇，在按照各种耕地指令（每个指令通过给出矩形的左下角和右上角 x、y 坐标来描述）编程后，田地里实际被犁过的方格数量究竟有多少。

和往常一样，田地被划分为若干方格，这些方格的边与 x 轴和 y 轴平行。整块田地的宽度为 XXX 个方格，高度为 YYY 个方格 (1≤X,Y≤240)(1\le X,Y \le 240)(1≤X,Y≤240)。共有 III 条耕地指令 (1≤I≤200)(1\le I \le 200)(1≤I≤200)，每条指令包含四个整数：Xll、Yll、Xur 和 Yur (1≤Xll≤Xur≤X;1≤Yll≤Yur≤Y）Xll、Yll、Xur \text{ 和 } Yur\text{ (}1 \le Xll \le Xur \le X;1 \le Yll \le Yur \le Y）Xll、Yll、Xur 和 Yur (1≤Xll≤Xur≤X;1≤Yll≤Yur≤Y），分别表示待犁矩形的左下角和右上角坐标。机器人会犁耕区间 (Xll…Xur,Yll…Yur)(Xll \dots Xur, Yll \dots Yur)(Xll…Xur,Yll…Yur) 内的所有田地方格——根据不同的理解方式，这个区间可能比初始设想的多一行或一列（当然，具体取决于你如何理解）。

以一块宽 6 格、高 4 格的田地为例。当约翰发出两条耕地指令（如下所示）时，田地的犁耕情况如 * 和 # 所示（通常犁过的田地看起来相同，这里用 # 表示最近犁过的区域）：

......             **....             #####. 
......  (1,1)(2,4) **....  (1,3)(5,4) #####. 
......             **....             **.... 
......             **....             **....

最终共有 14 个方格被犁过。

得分：25 分

输入格式

共 I+1I+1I+1 行

第一行，三个空格分隔的整数：X、Y 和 IX、Y\text{ 和 }IX、Y 和 I

第二行到第 I+1I+1I+1 行：第 i+1i+1i+1 行包含第 iii 条耕地指令，由四个整数描述：Xll、Yll、Xur 和 YurXll、Yll、Xur \text{ 和 } YurXll、Yll、Xur 和 Yur

输出格式

一行，一个整数，表示被犁过的方格总数

样例

样例输入 #1

6 4 2 
1 1 2 4 
1 3 5 4

样例输出 #1

14

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：二维标记模拟
     * 思路：
     * 1. 读入 X（宽，列数）, Y（高，行数）, I（指令数）。
     * 2. 用 bool vis[245][245] 标记被犁过的格子。
     * 3. 对于每条指令，读入 Xll, Yll, Xur, Yur，将范围内所有格子标记为 true。
     * 4. 最后统计 true 的个数并输出。
     * 注意：X是列数，Y是行数，但这里我们直接按坐标循环，不区分行列。
     */
    int x, y, i;
    cin >> x >> y >> i;

    bool vis[250][250] = {false};

    for (int k = 0; k < i; k++) {
        int x1, y1, x2, y2;
        cin >> x1 >> y1 >> x2 >> y2;
        for (int r = y1; r <= y2; r++) {
            for (int c = x1; c <= x2; c++) {
                vis[r][c] = true;
            }
        }
    }

    int ans = 0;
    for (int r = 1; r <= y; r++) {
        for (int c = 1; c <= x; c++) {
            if (vis[r][c]) ans++;
        }
    }

    cout << ans << endl;
    return 0;
}
