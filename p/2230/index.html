2230 - 数字方格

题目描述

如上图，有 $3$ 个方格，每个方格里面都有一个整数 $a1，a2，a3$ 。已知 $0 \le a1$, $a2$ , $a3 \le n$ ，而且$a1 + a2$ 是 $2$ 的倍数，$a2 + a3$ 是 $3$ 的倍数， $a1 + a2 + a3$ 是 $5$ 的倍数。

你的任务是找到一组 $a1，a2，a3$ ，使得 $a1 + a2 + a3$ 最大。

输入

一行，包含一个整数 $n (0 \le n \le 100$ )。

输出

一个整数，即 $a1 + a2 + a3$ 的最大值。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int n, ma = 0;

int main()
{
    cin >> n;
    for (int i = 0; i <= n; i++)
    {
        for (int j = 0; j <= n; j++)
        {
            for (int k = 0; k <= n; k++)
            {
                if ((i + j) % 2 == 0 && (j + k) % 3 == 0 && (i + j + k) % 5 == 0)
                {
                    if (i + j + k > ma) ma = i + j + k;
                }
            }
        }
    }

    cout << ma;
    return 0;
}
