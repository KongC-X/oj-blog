B2140 二进制分类

洛谷 | 入门 | C++14 | 提交时间: 2026-07-15

算法标签：函数与递归

题目描述

若将一个正整数化为二进制数，在此二进制数中，我们将数字 111 的个数多于数字 000 的个数的这类二进制数称为 AAA 类数，否则就称其为 BBB 类数。

例如：

(13)10=(1101)2(13)_{10}=(1101)_2(13)10​=(1101)2​，其中 111 的个数为 333，000 的个数为 111，则称此数为 AAA 类数；

(10)10=(1010)2(10)_{10}=(1010)_2(10)10​=(1010)2​，其中 111 的个数为 222，000 的个数也为 222，称此数为 BBB 类数；

(24)10=(11000)2(24)_{10}=(11000)_2(24)10​=(11000)2​，其中 111 的个数为 222，000 的个数为 333，则称此数为 BBB 类数；

程序要求：求出 1∼n1\sim n1∼n 之中（1≤n≤10001 \le n \le 10001≤n≤1000），全部 A,BA,BA,B 两类数的个数。

输出格式

一行，包含两个整数，分别是 AAA 类数和 BBB 类数的个数，中间用单个空格隔开。

样例

样例输入 #1

7

样例输出 #1

5 2

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 函数：判断一个正整数是否为 A 类数（二进制中 1 的个数 > 0 的个数）
bool isA(int x) {
    int c1 = 0, c0 = 0;               // c1:1的个数，c0:0的个数
    while (x > 0) {
        if (x % 2 == 1) c1++;         // 最低位是 1
        else            c0++;         // 最低位是 0
        x /= 2;                       // 去掉已处理的最低位
    }
    // 注意：上述统计不包含前导零，因为循环只到 x 变为 0
    return c1 > c0;
}

int main() {
    int n;                            // n: 范围上限
    cin >> n;

    int a = 0, b = 0;                 // a: A类数个数，b: B类数个数
    for (int i = 1; i <= n; i++) {
        if (isA(i)) a++;
        else        b++;
    }

    cout << a << ' ' << b << endl;
    return 0;
}
