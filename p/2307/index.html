2307 - 苹果消消乐

题目描述

有100个苹果和香蕉排成一条直线，其中有N个香蕉，你可以使用至多M次魔法道具将香蕉变成苹果，最后“最长的连续苹果数量”即为你本次苹果消消乐的得分，给定苹果和香蕉的排列，求你能获得的最大得分。

输入

第一行是一个整数T(1 <= T <= 10)，代表测试数据的组数。 每个测试数据第一行是2个整数N和M(0 <= N, M <= 100)。第二行包含N个整数a1, a2, ... aN(1 <= a1 < a2 < ... < aN <= 100)，表示第a1, a2, ... aN个位置上摆放的是香蕉。

输出

对于每组数据，输出通过使用魔法道具后你能获得的最大得分。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

//计算最大长度
void fun(int n, int m, int a[]){
    int ma = 0;
    if(m>=n){
        ma = 100;
    }else{
        int s = 0;
        for(int i=m+1; i<=n+1; i++){
            s = a[i] - 1 - a[i-m-1];
            if(s>ma){
                ma = s;
            }
        }
    }
    cout<<ma<<endl;
}

int main(){
    //n个香蕉，m个道具，t组数据
    int t,n,m,i,j;
    cin>>t;
    for(i=1; i<=t; i++){
        cin>>n>>m;
        int a[110]={0};//香蕉的位置
        for(j=1; j<=n; j++){
            cin>>a[j];
        }
        //在最前面和最后面添加一个香蕉
        a[0]=0;
        a[n+1]=101;
        fun(n,m,a);
    }
    return 0;
}
