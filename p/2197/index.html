2197 - 二叉树高度

题目描述

现给定一棵二叉树的先序遍历序列和中序遍历序列，要求你计算该二叉树的高度。

输入

首先给出正整数 NNN（N≤50N≤50N≤50），为树中结点总数。

下面 222 行先后给出先序和中序遍历序列，均是长度为 NNN 的不包含重复英文字母（区别大小写）的字符串。

输出

输出一个整数，即该二叉树的高度。

AC代码

#include <bits/stdc++.h>
using namespace std;

// 根据二叉树的先序找到根，再到中序中找到根所在的位置，从而划分左右子树，递归访问左右子树。
// 每次递归深度+1，打擂台求出最大深度。

int n,ans; 
string s1,s2;

//传递当前树（子树）前序遍历和中序遍历的下标范围 
void dfs(int l1,int r1,int l2,int r2,int dep){
    ans = max(ans,dep);
    int mid = s2.find(s1[l1]);//求根在中序遍历中的位置
    //如果有左子树
    if(mid > l2) dfs(l1+1,l1+mid-l2,l2,mid-1,dep+1);
    //如果有右子树
    if(mid < r2) dfs(l1+mid-l2+1,r1,mid+1,r2,dep+1);
} 
 
int main() {
    cin>>n>>s1>>s2;
    
    dfs(0,n-1,0,n-1,1);
    cout<<ans;
    return 0;
}
