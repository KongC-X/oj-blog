1389 - 数据分析

题目描述

某军事单位为了保证信息的安全性，决定采用特殊的加密方法来传递信息。

该方法的操作方式为，如果要传递 222 个数字信息给友军，会直接传递给友军一个整数 n（nn（nn（n 是一个 101010 位以内的整数），该整数的长度代表要传递的第一个数字信息，分解出该整数的每一位，如果该位是偶数，那么将这一位加到总和上去，代表要传递的第二个数字信息。

请你编写一个程序，从接收到的数字 nnn 中获取这 222 个数字信息。

比如：军事单位传递的数字为 123456781234567812345678 ，则希望向友军传递的 222 个数字就是 888 （共有 888 位）和 20（2+4+6+8=20）20（2+4+6+8=20）20（2+4+6+8=20） 。

输入

一个整数 n（n≤109）n（n \le 10^9）n（n≤109） 。

输出

两个整数，用空格隔开。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;

int main(){
    int n,s = 0,sum = 0;
    cin >> n;
    while(n != 0) {
        if(n % 10 % 2 == 0) {
            s += n % 10;
        }
        n = n / 10;
        sum++;
    }
    cout << sum  << " " << s << endl;
}
