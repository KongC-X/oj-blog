B4234 [四川青少年 C++ 算法设计大赛 2024] 4-5 年级组第 5 题

洛谷 | 入门 | C++14 | 提交时间: 2026-07-18

算法标签：四川、2024、循环结构、科创活动、小学活动

题目背景

第二届四川省青少年 C++ 算法设计大赛小学 4-5 年级组全省总决赛试题。数据为洛谷自造。

题目描述

小 X 制定了一个为期 nnn 天的训练计划。通过合理的规划，预定对于第 iii 天，他可以通过训练获得 aia_iai​ 的学习值。

但是计划往往赶不上变化，小 X 发现他每天所获得的学习值与他该天的学习状态产生着关联，我们用一个专注度 SSS 和认真阈值 mmm 来描述小 X 的学习状态：

  • SSS 的初值为 000；
  • 对于任意一天，如果 SSS 的值大于等于认真阈值 mmm，那么小 X 将会在该天获得双倍的学习值（即 ai×2a_i\times 2ai​×2），并使得专注度 SSS 减半（向下取整）；
  • 对于任意一天，如果 SSS 的值小于认真阈值 mmm，那么小 X 只能在该天获得一半的学习值（向下取整，即 ⌊ai2⌋\lfloor \frac{a_i}{2} \rfloor⌊2ai​​⌋），并增加相当于 aia_iai​ 的专注度。

小 X 想知道 nnn 天后，他一共可以获得多少学习值。

输入格式

第一行两个整数 n,mn,mn,m 分别表示训练为期的天数和认真阈值。

第二行 nnn 个空格隔开的数 aia_iai​，第 iii 个数表示预期的第 iii 天的学习值。

输出格式

一行一个整数，表示 nnn 天后小 X 一共可以获得多少学习值。

样例

样例输入 #1

5 50
70 30 60 40 50```

**样例输出 #1**

230```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：模拟每天的专注度和学习值累积。
    // 初始 S = 0，遍历每一天：
    //   若 S >= m：获得 2*a_i 学习值，S 减半（向下取整）；
    //   若 S < m：获得 ⌊a_i/2⌋ 学习值，S 增加 a_i。
    // 最后输出总学习值。

    int n, m;                     // n: 天数, m: 认真阈值
    cin >> n >> m;

    long long total = 0;          // 总学习值，用 long long 防止溢出
    long long S = 0;              // 当前专注度

    for (int i = 0; i < n; i++) {
        long long a;              // 第 i 天的预期学习值
        cin >> a;

        if (S >= m) {             // 专注度达到阈值
            total += a * 2;       // 获得双倍学习值
            S /= 2;               // 专注度减半（向下取整）
        } else {                  // 专注度不足
            total += a / 2;       // 获得一半学习值（向下取整）
            S += a;               // 专注度增加 a_i
        }
    }

    cout << total << endl;
    return 0;
}
