B2005 字符三角形

洛谷 | 入门 | C++14 | 提交时间: 2025-07-31

题目描述

给定一个字符，用它构造一个底边长 555 个字符，高 333 个字符的等腰字符三角形。

输入格式

输入只有一行，包含一个字符。

输出格式

该字符构成的等腰三角形，底边长 555 个字符，高 333 个字符。

样例

样例输入 #1

*```

**样例输出 #1**

*****```

AC 代码

#include<bits/stdc++.h>
using namespace std;
char c;
int main(){
    cin>>c;
    cout<<"  "<<c<<"  \n "<<c<<c<<c<<" \n"<<c<<c<<c<<c<<c;
    return 0;
}
