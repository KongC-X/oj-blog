1695 - 阿克曼（Ackmann）函数

题目描述

阿克曼（ AckmannAckmannAckmann ）函数 AAA ( m，nm，nm，n )中， m，nm，nm，n 定义域是非负整数，函数值定义为：

写出计算 Ack(m，n)Ack(m，n)Ack(m，n) 的递归算法程序。

输入

两个非负整数 mmm 和 nnn 。

输出

阿克曼函数 A(m,n)A(m,n)A(m,n) 的值。测试数据保证结果不超过 intintint 范围，直接用递归不超时。

（提示：阿克曼函数的值增长速度非常高，仅是对于 A(4,2)A(4,2)A(4,2) 的输出就有 197291972919729 位，而 A(4,3)A(4,3)A(4,3) 则即使是位数也不易估计。）

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int ack(int m,int n){
    if(m == 0) return n + 1;
    else if(m != 0 && n == 0) return ack(m-1,1);
    else if(m != 0 && n != 0) return ack(m-1,ack(m,n-1));	
}

int main()
{
    int m,n;
    cin>>m>>n;
    cout<<ack(m,n); 
    return 0;
}
