1695 - 阿克曼（Ackmann）函数

题目描述

阿克曼（ $Ackmann$ ）函数 $A$ ( $m，n$ )中， $m，n$ 定义域是非负整数，函数值定义为：

写出计算 $Ack(m，n)$ 的递归算法程序。

输入

两个非负整数 $m$ 和 $n$ 。

输出

阿克曼函数 $A(m,n)$ 的值。测试数据保证结果不超过 $int$ 范围，直接用递归不超时。

（提示：阿克曼函数的值增长速度非常高，仅是对于 $A(4,2)$ 的输出就有 $19729$ 位，而 $A(4,3)$ 则即使是位数也不易估计。）

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int ack(int m,int n){
    if(m == 0) return n + 1;
    else if(m != 0 && n == 0) return ack(m-1,1);
    else if(m != 0 && n != 0) return ack(m-1,ack(m,n-1));	
}

int main()
{
    int m,n;
    cin>>m>>n;
    cout<<ack(m,n); 
    return 0;
}
