1214 - 在最大数后面插入一个数

题目描述

在一个不重复数组的最大数的后面插入一个新的数 yyy。

输入

三行：

第一行有一个整数 nnn ( 5≤n≤1005 \le n \le 1005≤n≤100 ）；

第二行有 nnn 个整数；

第三行有一个整数 yyy，为要插入的数。

输出

更新后的数组。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int a[110],n,i,p,ma=INT_MIN,y;
int main(){
    cin>>n;
    //找出最大的数的下标 
    for(i=1;i<=n;i++){
        cin>>a[i];
        if(a[i]>ma){
            ma=a[i];
            p=i;
        }
    }
    cin>>y;
    //从最大的数开始所有的数后移一位 
    for(i=n;i>p;i--){
        a[i+1]=a[i];
    }
    //插入这个数 
    a[i+1]=y;
    n++;
    //输出结果 
    for(i=1;i<=n;i++){
        cout<<a[i]<<" ";
    }
}
