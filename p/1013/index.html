1013 - 一个六位数

题目描述

有一个六位数，其个位数字 777 ，现将个位数字移至首位（十万位），而其余各位数字顺序不变，均后退一位，得到一个新的六位数，假如新数为旧数的 444 倍，求原来的六位数。

输入

无

输出

原来的六位数。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int t,x;
    for(int i=100007; i<=999997; i+=10) {
        int x=i/10;//去掉个位
        t=7*100000+x;//新数
        //如果新数是原数的4倍 
        if(t%i==0&&t/i==4) {
            cout<<i;
            break;
        }
    }
    return 0;
}
