B2148 再求 f(x,n)

洛谷 | 入门 | C++14 | 提交时间: 2026-07-15

算法标签：函数与递归

题目描述

已知

f(x,n)=xn+x(n−1)+x(n−2)+⋮⋯+x1+xf(x,n)=\dfrac{x}{n+\dfrac{x}{(n-1)+\dfrac{x}{(n-2)+\dfrac{\vdots}{\cdots+\dfrac{x}{1+x}}}}}f(x,n)=n+(n−1)+(n−2)+⋯+1+xx​⋮​x​x​x​。

用递归函数求解。

输入格式

第一个数是 xxx 的值，第二个数是 nnn 的值。（xxx 为实数，nnn 为整数）

输出格式

函数值，保留两位小数。

样例

样例输入 #1

1
2```

**样例输出 #1**

0.40```

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 递归函数：计算 f(x, k) = x / (k + f(x, k-1))，边界 k=1 返回 x/(1+x)
double f(int k, double x) {
    if (k == 1) return x / (1.0 + x);           // 最内层：x/(1+x)
    return x / (k + f(k - 1, x));               // 当前层：x/(k + 内层结果)
}

int main() {
    double x;                                    // x：给定的实数
    int n;                                       // n：层数（整数）
    cin >> x >> n;
    cout << fixed << setprecision(2) << f(n, x) << endl;
    return 0;
}
