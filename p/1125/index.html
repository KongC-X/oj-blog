1125 - 删除字符串中间的*

题目描述

输入一个字符串，将串前和串后的*保留，而将中间的*删除。

输入

一个含*的字符串。

输出

删除了串中的*的字符串。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    string s1,s2,s3,s;
    getline(cin,s);
    int k,i = 0,j = s.size() - 1; // 双指针
    while(s[i] == '*') {
        s1 = s1 + '*';
        i++;
    }
    while(s[j] == '*') {
        s2 = s2 + '*';
        j--;
    }
    for(k = i;k <= j;k++) {
        if(s[k] != '*') {
            s3 = s3 + s[k];
        }
    }
    cout << s1 + s3 + s2;
}
