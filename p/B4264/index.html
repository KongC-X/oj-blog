B4264 [GESP202503 四级] 二阶矩阵

洛谷 | 入门 | C++14 | 提交时间: 2025-03-28

算法标签：2025、枚举、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1176

题目描述

小 A 有一个 nnn 行 mmm 列的矩阵 AAA。

小 A 认为一个 2×22 \times 22×2 的矩阵 DDD 是好的，当且仅当 D1,1×D2,2=D1,2×D2,1D_{1,1} \times D_{2,2} = D_{1,2} \times D_{2,1}D1,1​×D2,2​=D1,2​×D2,1​。其中 Di,jD_{i,j}Di,j​ 表示矩阵 DDD 的第 iii 行第 jjj 列的元素。

小 A 想知道 AAA 中有多少个好的子矩阵。

输入格式

第一行，两个正整数 n,mn, mn,m。

接下来 nnn 行，每行 mmm 个整数 Ai,1,Ai,2,…,Ai,mA_{i,1}, A_{i,2}, \ldots, A_{i,m}Ai,1​,Ai,2​,…,Ai,m​。

输出格式

一行，一个整数，表示 AAA 中好的子矩阵的数量。

样例

样例输入 #1

3 4
1 2 1 0
2 4 2 1
0 3 3 0```

**样例输出 #1**

2```

AC 代码

#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int i,j,n,m,s;
int a[510][510];
int main() {
    cin >> n >> m;
    for(i=1;i<=n;i++) {
        for(j=1;j<=m;j++) {
            cin >> a[i][j];
        } 
    }
    for(i = 1;i <= n - 1;i++) {
        for(j = 1;j <= m - 1;j++) {
            if(a[i][j] * a[i + 1][j + 1] == a[i + 1][j] * a[i][j + 1]) {
                s++;
            }
        }
    }
    cout << s << endl;
}
