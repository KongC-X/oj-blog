2044 - 城市之间的最短路

题目描述

小丁同学准备去A国旅游，他买了一张A国的地图，地图标出了A国著名的 nnn 个旅游热门城市，并标注了这 nnn 个城市之间有 mmm 条双向路线相连以及每条双向路线的长度。

请你编程帮助小丁求出其中两个城市之间的最短距离。

输入

输入第一行为两个正整数 nnn（n≤10n \le 10n≤10）和 mmm（m≤n×(n−1)/2m \le n \times (n-1)/2m≤n×(n−1)/2），nnn 表示城市个数，mmm 表示线段个数。

接下来 mmm 行，每行输入三个整数 a,ba,ba,b 和 lll ，表示 aaa 市与 bbb 市之间存在一条线段，线段长度为 lll 。（ aaa 与 bbb 不同，且本题的数据中两个城市之间最多只有一条路）

每组最后一行输入两个整数 xxx 和 yyy ，表示问题：xxx 市与 yyy 市之间的最短距离是多少。（xxx 与 yyy 不同）

城市标号为 1∼n1 \sim n1∼n， 1≤l≤201 \le l \le 201≤l≤20 。

输出

输出 xxx 市与 yyy 市之间的最短距离，如果 xxx 市与 yyy 市之间非连通，则输出 No path。

解题思路

AC代码

#include <iostream>
using namespace std;

// 求一个数的各位数字之和
int numSum(int num) {
    int sum = 0;
    while(num != 0) {
        sum += num % 10;
        num = num / 10;
    }
    return sum;
}

int main(){
    int i,n,s,a,sum = 0;
    cin >> n;
    for(i = 1;i <= n; i++) {
        s = 0;
        a = i;
        s = numSum(a);
        if(s == 13) {
            sum++;
        }
    }
    cout << sum << endl;
}
