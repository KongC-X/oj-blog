B4191 [海淀区小学组 2023] 回文时间

洛谷 | 入门 | C++14 | 提交时间: 2026-07-17

算法标签：模拟、2023、北京、科创活动、小学活动

题目背景

2023 年海淀区中小学生信息学竞赛小学组复赛题目，数据为洛谷自造。

题目描述

陶陶习惯用 24 小时制来表达时间，例如 16:4516:4516:45，表示现在的时间是 161616 时 454545 分。在信息科技课上，陶陶学到了回文数，如果一个数从左往右看和从右往左看是相同的，那么就称这个数为回文数，陶陶发现有很多时间表示从左往右看和从右往左看也一样的，于是陶陶把这样的时间点定义为回文时间。例如 14:4114:4114:41 就是一个回文时间。已知现在的时间是 hhh 时 mmm 分，陶陶请你请求出在此之后（不包含此时刻）的第一个回文时间。特别提醒：回文时间是指对于一个 24 小时制时间表示的合法字符串 ab:cdab:cdab:cd，一定有 a=da = da=d，b=cb = cb=c。

输入格式

仅有一行，给出一个表示时间的合法字符串，表达格式为 HH:MM，表示一个 242424 小时制时间的字符串。

输出格式

按题目要求输出一个回文时间。

样例

样例输入 #1

12:21```

**样例输出 #1**

13:31```

样例输入 #2

23:59```

**样例输出 #2**

00:00```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int h, m;
    char c;
    cin >> h >> c >> m;              // 读入当前时间

    while (true) {
        m++;                          // 下一分钟
        if (m == 60) {                // 到60分则进位
            m = 0;
            h++;
            if (h == 24) h = 0;       // 到24时则归零
        }

        int a = h / 10;               // 小时的十位
        int b = h % 10;               // 小时的个位
        int d = m / 10;               // 分钟的十位
        int e = m % 10;               // 分钟的个位

        if (a == e && b == d) {       // 满足回文条件
            // 输出时间，手动补前导零
            if (h < 10) cout << '0';
            cout << h << ':';
            if (m < 10) cout << '0';
            cout << m << endl;
            break;
        }
    }

    return 0;
}
