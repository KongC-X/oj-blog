1468 - 小鱼的航程

题目描述

有一只小鱼，它上午游泳 $150$ 公里，下午游泳 $100$ 公里，晚上和周末都休息（实行双休日)，假设从周 $x(1 \le x \le 7)$ 开始算起，请问这样过了 $n$ 天以后，小鱼一共累计游泳了多少公里呢？

输入

输入两个整数 $x$ , $n$ (表示从周 $x$ 算起，经过 $n$ 天，$x$ 是 $1 \sim 7$之间的整数，$n$ 是 $0 \sim 1000$ 之间的整数）。

输出

输出一个整数，表示小鱼累计游泳了多少公里。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    int n,x,s=0;
    cin>>x>>n;
    //从周x开始，周x也要算一天，所以范围到x+n-1号 
    for(int i=x;i<=x+n-1;i++){
        //7天是一周，周六周日休息 
        if(i%7!=6&&i%7!=0){
            s+=250;
        }
    }
    cout<<s;
    return 0;
}
