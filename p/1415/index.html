1415 - 10进制转D进制

题目描述

十进制整数 NNN 和其他 DDD（DDD的值为 2到162到162到16）进制数的转换是计算机实现计算的基本问题，其解决方法很多，其中一个简单算法基于下列原理：NNN === (NNN divdivdiv ddd) ×\times× ddd +++ NNN modmodmod ddd (其中：divdivdiv 为整除运算，modmodmod 为求余运算)。简单来说，就是除 DDD 取余，然后倒过来得到 DDD 进制的数。

例如：

(1348)10=(10101000100)2(1348)10 = (10101000100)2(1348)10=(10101000100)2

(1348)10=(2504)8(1348)10 = (2504)8(1348)10=(2504)8

(1000)10=(3E8)16(1000)10 = (3E8)16(1000)10=(3E8)16

（请注意：转 161616 进制时，用 AAA 代表余数 101010 ，BBB 代表余数 111111 ……）

假设现要编制一个满足下列要求的程序：对于输入的任意一个非负十进制整数（n≤1,000,000,000n≤1,000,000,000n≤1,000,000,000），打印输出与其等值的 DDD 进制数。

输入

有两个整数 NNN 和 DDD，NNN 表示要转换的十进制非负整数， DDD 代表要转换的进制（2到162到162到16）

输出

NNN 进制转 DDD 进制的结果。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int n,d;
stack<char> s;
string t = "0123456789ABCDEF";
int main() {
    cin >> n >> d;
    if(n == 0) {
        cout << "0" << endl;
        return 0;
    }
    while(n != 0) {
        s.push(t[n%d]);
        n /= d;
    }
    while(s.size() != 0) {
        cout << s.top();
        s.pop();
    }
}
