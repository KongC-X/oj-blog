5384 - 菱形

题目描述

小 AAA 想绘制一个菱形。具体来说，需要绘制的菱形是一个 nnn 行 nnn 列的字符画， nnn 是一个大于 111 的奇数。菱形的四个顶点依次位于第 111 行、第 111 列、第 nnn 行、第 nnn 列的正中间，使用 # 绘制。相邻顶点之间也用 # 连接。其余位置都是 . 。例如，一个 555 行 555 列的菱形字符画是这样的：

`..#..
.#.#.
#...#
.#.#.
..#..
`

给定 nnn，请你帮小 AAA 绘制对应的菱形。

输入

一行，一个正整数 nnn 。

输出

输出共 nnn 行，表示对应的菱形。

AC代码

AC代码

#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int n;
    cin >> n;
    int mid = n / 2;
    
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (abs(i - mid) + abs(j - mid) == mid) {
                cout << "#";
            } else {
                cout << ".";
            }
        }
        cout << endl;
    }
    
    return 0;
}
