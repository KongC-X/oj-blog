P1838 三子棋I

洛谷 | 入门 | C++14 | 提交时间: 2026-06-09

题目描述

小 a 和 uim 喜欢互相切磋三子棋。三子棋大家都玩过是吗？就是在九宫格里面 OOXX（别想歪了），谁连成 333 个就赢了。

由于小 a 比较愚蠢，uim 总是让他先。

我们用 999 个数字表示棋盘位置：

123456789\def\arraystretch{1.5} \begin{array}{|c|c|c|}\hline 1 & 2 & 3 \\\hline 4 & 5 & 6 \\\hline 7 & 8 & 9 \\\hline \end{array}147​258​369​​

所有的棋谱都是已经结束的棋局，要么一方获胜，要么平局。

今天，他们下了一下午的棋，小 a 为了提高技术，录下了很多棋谱。他想知道，一盘棋结束时，到底是谁赢。

输入格式

一行，一串数字，表示落子的地点。小 a 总是先下。

输出格式

一行，如果小 a 赢，输出 xiaoa wins.。如果 uim 赢，输出 uim wins.。如果平局，输出 drew.。

样例

样例输入 #1

5237649

样例输出 #1

xiaoa wins.

样例输入 #2

539128647```

**样例输出 #2**

drew.```

AC 代码

#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string s;                    // 落子序列
    cin >> s;

    int a[10] = {0};             // 棋盘，1~9，0表示空，1表示小a，2表示uim
    int win = 0;                 // 0:未结束 1:小a赢 2:uim赢

    for (int i = 0; i < s.size(); i++) {
        int p = s[i] - '0';      // 当前落子位置
        int player;
        if (i % 2 == 0) player = 1;   // 小a先手，偶数步（0,2,4..）
        else            player = 2;   // uim后手，奇数步
        a[p] = player;

        // 检查所有三连情况（8种）
        int b[8][3] = {
            {1,2,3}, {4,5,6}, {7,8,9},   // 横
            {1,4,7}, {2,5,8}, {3,6,9},   // 竖
            {1,5,9}, {3,5,7}             // 斜
        };
        for (int j = 0; j < 8; j++) {
            if (a[b[j][0]] != 0 &&
                a[b[j][0]] == a[b[j][1]] &&
                a[b[j][1]] == a[b[j][2]]) {
                win = a[b[j][0]];
                break;
            }
        }
        if (win != 0) break;     // 已分出胜负，停止模拟
    }

    if (win == 1)      cout << "xiaoa wins.\n";
    else if (win == 2) cout << "uim wins.\n";
    else               cout << "drew.\n";

    return 0;
}
