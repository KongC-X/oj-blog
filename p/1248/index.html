1248 - 求数列的第n项的值是多少？

题目描述

请问如下数列 1，2，2，3，3，3，4，4，4，4…1，2，2，3，3，3，4，4，4，4 \dots1，2，2，3，3，3，4，4，4，4… 请问这个数列的第 nnn 项是多少？

输入

从键盘读入一个整数 nnn ，代表要求的项数。

输出

一个整数 nnn 代表该项的值是多少？

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int main(){
 int n;
 cin>>n;
 int i,s=0;
for(i=1;i<=n;i++){
 s+=i;
 if(s>=n){
 cout<<i;
 break;
 }
 }
 return 0;
}
