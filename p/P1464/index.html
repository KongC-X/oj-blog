P1464 [PacNW 1999] Function

洛谷 | 普及- | C++14 | 提交时间: 2026-02-12

算法标签：搜索、1999、递归、记忆化搜索、ICPC

题目描述

对于一个递归函数 $w(a,b,c)$

  • 如果 $a \le 0$ 或 $b \le 0$ 或 $c \le 0$ 就返回值 $1$。
  • 如果 $a>20$ 或 $b>20$ 或 $c>20$ 就返回 $w(20,20,20)$
  • 如果 $a<b$ 并且 $b<c$ 就返回 $w(a,b,c-1)+w(a,b-1,c-1)-w(a,b-1,c)$。
  • 其它的情况就返回 $w(a-1,b,c)+w(a-1,b-1,c)+w(a-1,b,c-1)-w(a-1,b-1,c-1)$

这是个简单的递归函数，但实现起来可能会有些问题。当 $a,b,c$ 均为 $15$ 时，调用的次数将非常的多。你要想个办法才行。

注意：例如 $w(30,-1,0)$ 又满足条件 $1$ 又满足条件 $2$，请按照最上面的条件来算，答案为 $1$。

输入格式

会有若干行。

并以 $-1,-1,-1$ 结束。

输出格式

输出若干行，每一行格式：

w(a, b, c) = ans

注意空格。

样例

样例输入 #1

1 1 1
2 2 2
-1 -1 -1```

**样例输出 #1**

w(1, 1, 1) = 2
w(2, 2, 2) = 4```

AC 代码

#include <iostream>
using namespace std;

const int N = 25;  // 只需要处理0~20的范围
long long f[N][N][N];  // 记忆化数组，存储已经计算过的w(a,b,c)的值

/**
 * 递归函数 w(a,b,c)
 * 使用记忆化优化，避免重复计算
 */
long long w(long long a, long long b, long long c) {
    // 条件1：如果任意一个 ≤ 0，返回1
    if (a <= 0 || b <= 0 || c <= 0) {
        return 1;
    }
    
    // 条件2：如果任意一个 > 20，转化为w(20,20,20)
    if (a > 20 || b > 20 || c > 20) {
        return w(20, 20, 20);
    }
    
    // 如果已经计算过，直接返回记忆化数组中的值
    if (f[a][b][c] != 0) {
        return f[a][b][c];
    }
    
    // 条件3：如果 a < b 并且 b < c
    if (a < b && b < c) {
        f[a][b][c] = w(a, b, c-1) + w(a, b-1, c-1) - w(a, b-1, c);
    } 
    // 条件4：其他情况
    else {
        f[a][b][c] = w(a-1, b, c) + w(a-1, b-1, c) + w(a-1, b, c-1) - w(a-1, b-1, c-1);
    }
    
    return f[a][b][c];
}

int main() {
    long long a, b, c;
    
    // 初始化记忆化数组为0
    for (int i = 0; i < N; i++) {
        for (int j = 0; j < N; j++) {
            for (int k = 0; k < N; k++) {
                f[i][j][k] = 0;
            }
        }
    }
    
    // 循环读入，直到遇到 -1 -1 -1
    while (true) {
        cin >> a >> b >> c;
        
        // 结束条件
        if (a == -1 && b == -1 && c == -1) {
            break;
        }
        
        // 计算并输出结果
        long long ans = w(a, b, c);
        
        // 按照格式输出：w(a, b, c) = ans
        cout << "w(" << a << ", " << b << ", " << c << ") = " << ans << endl;
    }
    
    return 0;
}
