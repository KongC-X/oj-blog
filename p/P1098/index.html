P1098 [NOIP 2007 提高组] 字符串的展开

洛谷 | 普及- | C++14 | 提交时间: 2026-02-10

算法标签：模拟、字符串、2007、NOIP 提高组

题目描述

在初赛普及组的“阅读程序写结果”的问题中，我们曾给出一个字符串展开的例子：如果在输入的字符串中，含有类似于 d-h 或者 4-8 的字串，我们就把它当作一种简写，输出时，用连续递增的字母或数字串替代其中的减号，即，将上面两个子串分别输出为 defgh 和 45678。在本题中，我们通过增加一些参数的设置，使字符串的展开更为灵活。具体约定如下：

  1. 遇到下面的情况需要做字符串的展开。在输入的字符串中，出现了减号 -，减号两侧同为小写字母或同为数字，且按照 ASCII 码的顺序，减号右边的字符严格大于左边的字符。

  2. 参数 $p_1$：展开方式。$p_1=1$ 时，对于字母子串，填充小写字母；$p_1=2$ 时，对于字母子串，填充大写字母。这两种情况下数字子串的填充方式相同；$p_1=3$ 时，不论是字母子串还是数字字串，都用与要填充的字母个数相同的星号 * 来填充。

  3. 参数 $p_2$：填充字符的重复个数。$p_2=k$ 表示同一个字符要连续填充 $k$ 个。例如，当 $p_2=3$ 时，子串d-h 应扩展为 deeefffgggh。减号两边的字符不变。

  4. 参数 $p_3$：是否改为逆序。$p_3=1$ 表示维持原来顺序；$p_3=2$ 表示采用逆序输出。注意这时候仍然不包括减号两端的字符。例如，当 $p_1=1$、$p_2=2$、$p_3=2$ 时，子串 d-h 应扩展为 dggffeeh。

  5. 如果减号右边的字符恰好是左边字符的后继，只删除中间的减号。例如：d-e 应输出为 de，3-4 应输出为 34。如果减号右边的字符按照 ASCII 码的顺序小于或等于左边字符，输出时，要保留中间的减号。例如：d-d 应输出为 d-d，3-1 应输出为 3-1。

输入格式

共两行。

第 $1$ 行为用空格隔开的 $3$ 个正整数，依次表示参数 $p_1,p_2,p_3$。

第 $2$ 行为一行字符串，仅由数字、小写字母和减号 - 组成。行首和行末均无空格。

输出格式

共一行，为展开后的字符串。

样例

样例输入 #1

1 2 1
abcs-w1234-9s-4zz```

**样例输出 #1**

abcsttuuvvw1234556677889s-4zz```

样例输入 #2

2 3 2
a-d-d```

**样例输出 #2**

aCCCBBBd-d```

AC 代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 大模拟，有点恶心

int main() {
    int p1, p2, p3;
    cin >> p1 >> p2 >> p3;
    string s;
    cin >> s;
    
    string result;
    int n = s.length();
    
    for (int i = 0; i < n; i++) {
        // 如果当前字符不是减号，直接加入结果
        if (s[i] != '-') {
            result += s[i];
            continue;
        }
        
        // 处理减号的情况
        // 减号在开头或结尾，直接输出减号
        if (i == 0 || i == n - 1) {
            result += '-';
            continue;
        }
        
        char left = s[i - 1];
        char right = s[i + 1];
        
        // 检查减号两侧字符是否满足展开条件：
        // 1. 同为数字或同为小写字母
        // 2. 右侧字符ASCII码严格大于左侧字符
        bool flag = false;
        if (isdigit(left) && isdigit(right)) {
            flag = true;
        } else if (islower(left) && islower(right)) {
            flag = true;
        }
        
        if (flag && right > left) {
            // 特殊情况：右侧字符恰好是左侧字符的后继
            if (right == left + 1) {
                // 删除减号，不输出任何内容
                continue;
            }
            
            // 生成填充字符串
            string s1;
            
            // 根据p3决定顺序（1:顺序，2:逆序）
            if (p3 == 1) {
                // 顺序：从左到右
                for (char c = left + 1; c < right; c++) {
                    char ch = c;
                    
                    // 根据p1处理填充字符
                    if (p1 == 3) {
                        // p1=3：全部用星号填充
                        ch = '*';
                    } else if (islower(c)) {
                        // 字母：p1=1保持小写，p1=2转大写
                        if (p1 == 2) {
                            ch = toupper(c);
                        }
                    }
                    // 数字在p1=1或2时保持不变
                    
                    // 根据p2重复字符
                    for (int k = 0; k < p2; k++) {
                        s1 += ch;
                    }
                }
            } else {
                // 逆序：从右到左
                for (char c = right - 1; c > left; c--) {
                    char ch = c;
                    
                    // 根据p1处理填充字符
                    if (p1 == 3) {
                        ch = '*';
                    } else if (islower(c)) {
                        if (p1 == 2) {
                            ch = toupper(c);
                        }
                    }
                    
                    // 根据p2重复字符
                    for (int k = 0; k < p2; k++) {
                        s1 += ch;
                    }
                }
            }
            
            result += s1;
        } else {
            // 不满足展开条件，保留减号
            result += '-';
        }
    }
    
    cout << result << endl;
    return 0;
}
