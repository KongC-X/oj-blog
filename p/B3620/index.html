B3620 x 进制转 10 进制

洛谷 | 普及- | C++14 | 提交时间: 2026-09-26

算法标签：数学、进制

题目描述

给一个小整数 xxx 和一个 xxx 进制的数 SSS。将 SSS 转为 101010 进制数。对于超过十进制的数码，用 A，B，…\ldots… 表示。

输入格式

第一行一个整数 xxx;

第二行一个字符串 SSS。

输出格式

输出仅包含一个整数，表示答案。

样例

样例输入 #1

16
7B

样例输出 #1

123```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3620 x 进制转 10 进制
     * 题意：给定进制 x 和 x 进制的字符串 S，将其转换为十进制整数。
     *       对于超过 9 的数码，用 A~Z 表示（A=10, B=11, ..., Z=35）。
     *
     * 思路：
     *   1. 读入 x 和字符串 s。
     *   2. 从左到右遍历字符串的每一位字符 c：
     *        - 若 c 是数字 '0'~'9'，则数值 d = c - '0'；
     *        - 若 c 是大写字母 'A'~'Z'，则数值 d = c - 'A' + 10。
     *   3. 用 ans 累加：ans = ans * x + d。
     *   4. 输出 ans。
     *
     * 时间复杂度：O(|S|)，|S| 很小，完全可行。
     * 结果不超过 10^9，用 long long 安全。
     */

    int x;          // x: 进制（2 ≤ x ≤ 36）
    string s;       // s: x 进制的字符串
    cin >> x >> s;

    long long ans = 0;   // ans: 十进制结果

    for (int i = 0; i < s.size(); i++) {
        char c = s[i];
        int d;           // d: 当前字符对应的数值
        if (c >= '0' && c <= '9') {
            d = c - '0';
        } else {
            d = c - 'A' + 10;
        }
        ans = ans * x + d;
    }

    cout << ans << endl;
    return 0;
}
