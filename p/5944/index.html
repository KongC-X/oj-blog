5944 - 黄金格

题目描述

小杨在探险时发现一张矩形地图，地图 HHH 行和 WWW 列，每个格子坐标为( r,cr, cr,c )（ 其中 rrr 表示行号 111 到 HHH ，ccc 表示列号 111 到 WWW ）。

小杨听说地图中隐藏着一些“黄金格”，这些格子满足一个神秘的数学挑战：当格子坐标 ( r,cr, cr,c ) 代入特定的不等式关系
成立时，该格子就是黄金格。具体来说，黄金格的条件是：(r²+c²)≤x+r−c\sqrt{(r^² + c^²)} \le x + r -c(r²+c²)​≤x+r−c。

例如，如果参数 x=5x=5x=5，那么格子 (4,34,34,3) 就是黄金格。因为左边坐标平方和的平方根 (4²+3²)\sqrt{(4^² + 3^²)}(4²+3²)​ 算出来是 555 ，而右边 5+4−35+4-35+4−3 算出来是 666 ，555 小于等于666 ，符合条件。

输入

三行，每行一个正整数，分别表示 H,W,xH,W,xH,W,x 。含义如题面所示。

输出

一行一个整数，代表黄金格数量。

解题思路

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    int a[100][100],b[100][100],i,j,n,m,c=0;
    cin>>n>>m;
    //读入第一幅图像的值 
    for(i=0;i<n;i++){
        for(j=0;j<m;j++){
            cin>>a[i][j];
        }
    }
    //读入第二幅图像的值 
    for(i=0;i<n;i++){
        for(j=0;j<m;j++){
            cin>>b[i][j];
        }
    }
    
    //统计相同点的数量
    for(i=0;i<n;i++){
        for(j=0;j<m;j++){
            if(a[i][j]==b[i][j]){
                c++;
            }
        }
    } 
    
    double r = c*100.0/(n*m);
    cout<<fixed<<setprecision(2)<<r<<endl;
    return 0;
}
