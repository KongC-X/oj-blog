6320 - 新龟兔赛跑

题目描述

自从上次龟兔赛跑，兔子因为轻敌而惨败后，一直心有不甘，因此有了新一届龟兔赛跑。

乌龟和上次一样，将会以恒定的速度往终点爬行，题目将给出乌龟从起点到终点所需时间；

兔子并没有吸取教训，只是打算在终点前少睡一会儿，题目将给出兔子的速度，和兔子打算在终点前睡觉的时间；

起点和终点之间的距离固定为 1000.01000.01000.0，请帮忙计算乌龟和兔子谁会获胜？

输入

输入包含 3 行，每行一个浮点数：

第 1 行的浮点数表示乌龟从起点到终点所需时间；

第 2 行的浮点数表示兔子的速度；

第 3 行的浮点数表示兔子打算在终点前睡觉的时间。

输出

输出包含 2 行：

第 1 行，如果乌龟获胜，输出 turtle；如果兔子获胜，输出 rabbit；如果平局，输出 tie；

第 2 行，输出兔子到达终点所需的总时间（含兔子睡觉的时间），保留两位小数。

AC代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B4573 [GESP202609 一级] 新龟兔赛跑
     * 题意：乌龟时间 t，兔子速度 v，兔子睡觉时间 s，距离 1000.0。
     *       兔子总时间 = 1000.0 / v + s，与乌龟时间 t 比较，判断胜负。
     * 输出：胜者（turtle/rabbit/tie），以及兔子总时间（保留两位小数）。
     */
    double t, v, s;          // t: 乌龟时间, v: 兔子速度, s: 兔子睡觉时间
    cin >> t >> v >> s;

    double r = 1000.0 / v + s;   // r: 兔子总时间

    if (t < r) {
        cout << "turtle" << endl;
    } else if (t > r) {
        cout << "rabbit" << endl;
    } else {
        cout << "tie" << endl;
    }

    cout << fixed << setprecision(2) << r << endl;
    return 0;
}
