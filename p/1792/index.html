1792 - 换钞票

题目描述

将一张一百元的钞票换成 101010 元和 202020 元两种面额的钞票，两种不同的面额都要有，有哪些不同的换法。

请按照 101010 元面额的数量由小到大，202020 元面额的数量由大到小输出所有的结果。

第 111 组满足条件的方案为：222 444 ，也就是 222 张 101010 元，444 张 202020 元。

输入

无

输出

输出满足条件的方案，每行 222 个整数，第 111 个整数代表101010 元面额的数量，第 222 个整数代表 202020 元面额的数量。

输出时按照 101010 元面额数量从小到大，202020 元面额数量从大到小输出。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int main(){
    //使用穷举法猜 可以兑换的张数
    int i,j; 
    //i:10元张数 j:20元张数 
    for(i=1;i<=10;i++) //因为10元最多可以换10张 
    {
        for(j=5;j>=1;j--)//5元最多可以换5张,从大到小猜 
        {
            if( 10*i + 20*j == 100 )
            {
                cout<<i<<" "<<j<<endl;
            }
        }   
    } 
    //注意：每一种面额都要有，都应该从1开始 
    return 0;
}
