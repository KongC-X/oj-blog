P17456 [GESP202609 五级] 饮品调制

洛谷 | 普及+/提高-| C++14 | 提交时间: 2026-09-18

算法标签：贪心、排序、2026、GESP

题目描述

你想调制一份甜度恰到好处的饮品给你的朋友们品尝。

有 $n$ 种原料可供用于调制饮品。第 $i$ 种原料存量有 $v_i$ 升，每升含有 $s_i$ 克糖分。你可以自由选择原料加入饮品，但每种原料的使用量不得超过其剩余存量。也就是说，假设第 $i$ 种原料选用 $k_i$ 升，应当有 $0\le k_i\le v_i$，$k_i$ 可以取 $0$ 到 $v_i$ 之间的任何数字（包括小数）。

一份甜度恰到好处的饮品需要保证甜度恰好为 $t$。最终你调制得到的饮品甜度将为 $\frac{\sum_{i=1}^{n}k_i\cdot s_i}{\sum_{i=1}^{n}k_i}$。为了让更多的朋友喝到饮品，请问最多能调制出多少升甜度恰到好处的饮品？如果无法调制出甜度恰到好处的饮品，则认为答案是 $0$。

输入格式

第一行，两个整数 $n,t$，分别表示原料种类数量，恰到好处的甜度。

接下来 $n$ 行，每行两个整数 $v_i,s_i$，分别表示第 $i$ 种原料的存量体积，每升含有的糖分质量。

输出格式

一行，一个小数，表示能调制出的甜度恰到好处的饮品最大体积，保留三位小数。

样例

样例输入 #1

4 2
6 1
5 2
8 5
1 0```

**样例输出 #1**

14.667```

样例输入 #2

2 5
3 4
5 3```

**样例输出 #2**

0.000```

AC 代码

#include <bits/stdc++.h>
using namespace std;

struct Node {
    int v;   // 体积
    int d;   // 每升偏移量的绝对值
};

// 按 d 从大到小排序
bool cmp(Node a, Node b) {
    return a.d > b.d;
}

int main() {
    /*
     * 题目：P17456 [GESP202609 五级] 饮品调制
     * 题意：n 种原料，每种有体积 v 和甜度 s，可选择使用 k 升（0 ≤ k ≤ v），
     *       使总甜度 = Σ(k·s) / Σk = t，最大化总体积 Σk。
     *       无法恰好达到 t 则输出 0.000。
     *
     * 思路：
     * 1. 原料分三类：s==t（中性）、s>t（正偏移）、s<t（负偏移）。
     *    中性原料全部使用，不影响甜度。
     * 2. 正偏移原料每升贡献 (s-t)，负偏移每升贡献 (t-s) 的抵消量。
     *    分别算出总正偏移 P 和总负偏移 N。
     * 3. P==N：全部原料都能用。
     *    P>N：正偏移过多，按 d=s-t 降序减少正偏移原料（优先削减每升偏移量大的）。
     *    N>P：对称处理负偏移。
     * 4. 输出总体积，保留三位小数。
     *
     * 时间复杂度：O(n log n)，n ≤ 2000。
     */
    int n, t;
    cin >> n >> t;

    int v[2005], s[2005];
    for (int i = 0; i < n; i++) cin >> v[i] >> s[i];

    double tot = 0;        // 中性原料总体积
    double P = 0, N = 0;   // 正偏移总量、负偏移总量
    Node a[2005], b[2005];
    int pc = 0, nc = 0;    // 正偏移、负偏移原料个数

    for (int i = 0; i < n; i++) {
        if (s[i] == t) {
            tot += v[i];
        } else if (s[i] > t) {
            a[pc].v = v[i];
            a[pc].d = s[i] - t;
            P += v[i] * (s[i] - t);
            pc++;
        } else {
            b[nc].v = v[i];
            b[nc].d = t - s[i];
            N += v[i] * (t - s[i]);
            nc++;
        }
    }

    double ans = 0;

    if (P == N) {
        double sp = 0, sn = 0;
        for (int i = 0; i < pc; i++) sp += a[i].v;
        for (int i = 0; i < nc; i++) sn += b[i].v;
        ans = tot + sp + sn;
    } else if (P > N) {
        sort(a, a + pc, cmp);
        double need = P - N;
        double pu = 0;
        for (int i = 0; i < pc; i++) pu += a[i].v;
        for (int i = 0; i < pc; i++) {
            double mr = a[i].v * a[i].d;
            if (need >= mr) {
                need -= mr;
                pu -= a[i].v;
            } else {
                pu -= need / a[i].d;
                need = 0;
                break;
            }
        }
        double sn = 0;
        for (int i = 0; i < nc; i++) sn += b[i].v;
        ans = tot + sn + pu;
    } else {
        sort(b, b + nc, cmp);
        double need = N - P;
        double nu = 0;
        for (int i = 0; i < nc; i++) nu += b[i].v;
        for (int i = 0; i < nc; i++) {
            double mr = b[i].v * b[i].d;
            if (need >= mr) {
                need -= mr;
                nu -= b[i].v;
            } else {
                nu -= need / b[i].d;
                need = 0;
                break;
            }
        }
        double sp = 0;
        for (int i = 0; i < pc; i++) sp += a[i].v;
        ans = tot + sp + nu;
    }

    cout << fixed << setprecision(3) << ans << endl;
    return 0;
}
