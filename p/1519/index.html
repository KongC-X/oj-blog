1519 - 求1~n中每个数的因子有哪些？

题目描述

输出 $1 \sim n$中每个数的因子有哪些，从小到大输出！

比如：$n=10$，那么输出结果如下。

$1:1$

$2:1$ $2$

$3:1$ $3$

$4:1$ $2$ $4$

$5:1$ $5$

$6:1$ $2$ $3$ $6$

$7:1$ $7$

$8:1$ $2$ $4$ $8$

$9:1$ $3$ $9$

$10:1$ $2$ $5$ $10$

其中，每行冒号前的整数代表了 $1 \sim n$ 的每个数，冒号后的的数字代表了这个整数有哪些因子，用空格隔开。

输入

一个整数 $n（n \le 1000$）。

输出

按要求输出 $1 \sim n$ 中每个数的因子有哪些。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;

int main() {
    int n,i,j;
    cin >> n;
    for(i = 1;i <= n;i++) {
        cout << i << ":";
        for(j = 1;j <= i;j++) {
            if (i % j == 0) {
                cout << j << " ";
            }
        }
        cout << endl;
    }
}
