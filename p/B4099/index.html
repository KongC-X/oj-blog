B4099 [CSP-X2022 山东] 摧毁

洛谷 | 普及- | C++14 | 提交时间: 2026-08-11

算法标签：贪心、2022、山东、CSP-X 小学组

题目描述

坐地日行八万里，巡天遥看一千河。

2077 年，人类不仅仅是赛博科技得到了发展，太空技术也已经得到了极大的发展。地球的不同外轨道上已经充斥着各种功能用途的人造卫星。因为一个轨道上的卫星数量是有上限的，且卫星更新换代速度很快，如果想要发射新的卫星，需要把所有旧的卫星摧毁。

人类有两种不同的武器可以摧毁卫星，具体如下（其中 $\rm PW$ 为新的能量单位）：

  1. 使用定点激光武器花费 $1\ \rm{PW}$ 的代价摧毁任意轨道上指定的一个卫星。

  2. 使用脉冲轨道武器花费 $c\ \rm{PW}$ 的代价把某一轨道上的所有卫星摧毁。

现在有 $n$ 个旧卫星分布在不同的外轨道上，你的任务是摧毁这些旧卫星。给出这 $n$ 个卫星的轨道编号，求将这些卫星全部摧毁的最小代价是多少？

输入格式

第一行一个正整数 $T$，表示测试数据组数。

接下来对于每组测试数据（注意：每组测试数据有 $2$ 行数据，以下共 $2T$ 行数据）：

第一行两个正整数 $n$ 和 $c$ 表示需要摧毁的卫星数量和使用脉冲轨道武器的代价。

第二行 是 $x_1,x_2,x_3,\cdots, x_n$，其中 $x_i$ 表示第 $i$ 个卫星的轨道编号。

输出格式

输出 $T$ 行答案，对于每组测试数据，输出一行一个整数表示摧毁所有卫星的代价。

样例

样例输入 #1

4
10 1
2 1 4 5 2 4 5 5 1 2
5 2
3 2 1 2 2
2 2
1 1
2 2
1 2```

**样例输出 #1**

4
4
2
2```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int a[1000005];   // a: 存储所有卫星轨道编号

int main() {
    /*
     * 题目类型：排序 + 贪心
     * 思路：
     * 对于每个轨道，如果有 k 颗卫星，最优花费是 min(k, c)。
     * 因为可以全部用定点激光（花费 k），也可以一次脉冲（花费 c）。
     * 所以只需统计每个轨道的卫星数，累加 min(k, c)。
     * 用排序后遍历统计每个轨道的数量。
     */
    int t;          // t: 测试数据组数
    scanf("%d", &t);
    while (t--) {
        int n, c;   // n: 卫星总数, c: 脉冲武器花费
        scanf("%d%d", &n, &c);
        for (int i = 0; i < n; i++) {
            scanf("%d", &a[i]);
        }
        sort(a, a + n);   // 升序排序，使相同轨道编号连续

        long long ans = 0;   // 总花费
        int i = 0;
        while (i < n) {
            int j = i;
            // 统计当前轨道（a[i]）的卫星个数
            while (j < n && a[j] == a[i]) j++;
            int k = j - i;   // k: 该轨道卫星数
            ans += min(k, c);
            i = j;
        }
        printf("%lld\n", ans);
    }
    return 0;
}
