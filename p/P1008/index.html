P1008 [NOIP 1998 普及组] 三连击

洛谷 | 普及- | C++14 | 提交时间: 2026-06-12

算法标签：模拟、1998、NOIP 普及组、提交答案、枚举

题目背景

本题为提交答案题，您可以写程序或手算在本机上算出答案后，直接提交答案文本，也可提交答案生成程序。

题目描述

将 1,2,…,91, 2, \ldots , 91,2,…,9 共 999 个数分成 333 组，分别组成 333 个三位数，且使这 333 个三位数构成 1:2:31 : 2 : 31:2:3 的比例，试求出所有满足条件的 333 个三位数。

输出格式

若干行，每行 333 个数字。按照每行第 111 个数字升序排列。

样例

样例输入 #1

无```

**样例输出 #1**

192 384 576

...

（剩余部分不予展示）```

AC 代码

#include <iostream>
using namespace std;

int main() {
    // 枚举第一个三位数 a，a 的范围是 123 ~ 329
    for (int a = 123; a <= 329; a++) {
        int b = a * 2;            // 第二个数
        int c = a * 3;            // 第三个数
        
        // 把 a, b, c 的每一位分解出来
        int d[10] = {0};          // 统计数字 1~9 出现的次数
        d[a % 10]++;  d[a / 10 % 10]++;  d[a / 100]++;
        d[b % 10]++;  d[b / 10 % 10]++;  d[b / 100]++;
        d[c % 10]++;  d[c / 10 % 10]++;  d[c / 100]++;
        
        // 检查数字 1~9 是否恰好各出现一次
        bool ok = true;
        for (int i = 1; i <= 9; i++) {
            if (d[i] != 1) {
                ok = false;
                break;
            }
        }
        if (ok) {
            cout << a << " " << b << " " << c << endl;
        }
    }
    return 0;
}
