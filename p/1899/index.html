1899 - 最满意的方案

题目描述

高考结束了，同学们要开始了紧张的填写志愿的过程，大家希望找一个自己最满意的大学填报方案，请你编程帮忙实现。
现有 mmm (m≤100000m≤100000m≤100000) 所学校，每所学校预计分数线是 aia_iai​ (ai≤106a_i≤10^6ai​≤106) 。有 nnn(n≤100000n≤100000n≤100000) 位学生，估分分别为 bib_ibi​ (bi≤106b_i≤10^6bi​≤106)。

根据 nnn 位学生的估分情况，分别给每位学生推荐一所学校，要求学校的预计分数线和学生的估分相差最小（可高可低，毕竟是估分嘛），这个最小值为不满意度。求所有学生不满意度和的最小值。

输入

第一行读入两个整数 m,nm,nm,n，mmm 表示学校数， nnn 表示学生数。

第二行共有 mmm 个数，表示 mmm 个学校的预计录取分数。

第三行有 nnn 个数，表示 nnn 个学生的估分成绩。

输出

一行，为最小的不满意度之和。（数据保证计算结果≤109≤10^9≤109）

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

const int N = 100010;
int a[N];
int n,m,x,s = 0; // 最小差值的和

int main() {
    cin >> m >> n;
    for(int i = 1;i <= m;i++) cin >> a[i];
    sort(a+1,a+m+1); //对学校分数排序，方便二分

    // n个同学
    int left,right,mid;
    for(int i = 1;i <= n;i++) {
        cin >> x; // x: 同学的分数
        // 特殊情况不需要二分的情况
        if(x >= a[m]) s = s + x - a[m];
        else if(x <= a[1]) s = s + a[1] - x;
        else {
            left = 1;
            right = m;
            // 找左边界
            while(left <= right) {
                mid = (left + right) / 2;
                if(x <= a[mid]) right = mid - 1;
                else left = mid + 1;
            }
            // 看left和left-1哪个位置的分数差更小
            // left是第一个大于等于x的位置
            s = s + min(a[left] - x,x - a[left - 1]);
        }
    }
    cout << s << endl;
}
