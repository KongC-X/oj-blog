1746 - 能被2、3、5、7中至少2个数整除的数

题目描述

请输出 1∼n1 \sim n1∼n 中至少能够被 2、3、5、72、3、5、72、3、5、7 中两个及两个以上的数整除的数？

比如：303030，就是能够被 2、3、5、72、3、5、72、3、5、7 中的 333 个数整除，就是符合条件的数。

输入

一个整数 n（n≤200）n（n \le 200）n（n≤200） 。

输出

输出 1∼n1 \sim n1∼n 中满足条件的数，每行 111 个。

AC代码

#include<bits/stdc++.h>
using namespace std;
 
int main() {
    int n;
    cin>>n;
    int i;
    //遍历1到n之间的整数 
    for(i=1;i<=n;i++){
        int x=0;//记录能够被2、3、5、7中几个数整除 
        if(i%2==0){
            x++;
        }
        if(i%3==0){
            x++;
        }
        if(i%5==0){
            x++;
        }
        if(i%7==0){
            x++;
        }
        //输出符合两个及两个以上条件的数 
        if(x>1){
            cout<<i<<endl;
        }
    } 
    return 0;
}
