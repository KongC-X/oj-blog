P9855 [CCC 2008 J2] Do the Shuffle

洛谷 | 入门 | C++14 | 提交时间: 2026-08-08

算法标签：2008、CCC（加拿大）

题目描述

Those tiny music machines that play your digital music are really computers that keep track of and play music files. The CCC music player (C3MP)(C^3MP)(C3MP) is currently in development and will be hitting the stores soon! In this problem, you have to simulate a C3MPC^3MPC3MP.

The C3MPC^3MPC3MP music player will hold 555 songs in memory, whose titles will always be A, B, C, D, E. The C3MPC^3MPC3MP also keeps track of a playlist, which is an ordering of all the songs. The C3MPC^3MPC3MP has 4 buttons that the user will press to rearrange the playlist and play the songs.

Initially, the C3MPC^3MPC3MP playist is A,B,C,D,E. The 444 control buttons do the following:

  • button 111: move the first song of the playlist to the end of the playlist. For example: A,B,C,D,E will change to B,C,D,E,A.

  • button 222: move the last song of the playlist to the start of the playlist. For example, A,B,C,D,E will change to E,A,B,C,D.

  • button 333: swap the first two songs of the playlist. For example, A,B,C,D,E will change to B,A,C,D,E.

  • button 444: stop rearranging songs and output the playlist.

输入格式

You need to write a program to simulate a CCC music player. Your program should repeatedly ask for two positive integers b and n. Here b represents the button number that the user wants to press, 1≤b≤41 \leq b \leq 41≤b≤4, and n represents the number of times that the user wants to press button b. You can assume that n always satisfies 1≤n≤101 \leq n \leq 101≤n≤10.

输出格式

The input will always finish with the pair of inputs (b=4,n=1)(b = 4, n = 1)(b=4,n=1) when this happens, you should print the order of songs in the current playlist and your program should end. You can assume that the user will only ever press button 444 once.

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：模拟
     * 思路：用字符串存储播放列表，按按钮操作改变字符串顺序。
     * 按钮1：首字母移到末尾
     * 按钮2：末字母移到开头
     * 按钮3：交换前两个字母
     * 按钮4：输出并结束
     */
    string s = "ABCDE";
    int b, n;
    while (cin >> b >> n) {
        if (b == 4) {
            // 输出播放列表，每个字母后跟空格（样例输出末尾有空格）
            for (int i = 0; i < 5; i++) {
                cout << s[i];
                if (i < 4) cout << ' ';
            }
            cout << endl;
            break;
        }
        // 重复 n 次操作
        for (int i = 0; i < n; i++) {
            if (b == 1) {
                // 第一首歌移到末尾
                s = s.substr(1) + s[0];
            } else if (b == 2) {
                // 最后一首歌移到开头
                s = s[4] + s.substr(0, 4);
            } else if (b == 3) {
                // 交换前两首歌
                swap(s[0], s[1]);
            }
        }
    }
    return 0;
}
