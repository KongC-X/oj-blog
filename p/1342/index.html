1342 - 怎样种树？

题目描述

公园准备在小山上种桃树、梨树、苹果树，为了美观，总共准备种 nnn 棵树（ n≥6n\ge 6n≥6 且 nnn 一定是 666 的倍数），要求三种树都得有，且每种树的数量都得是偶数，桃树的数量不能比梨树的数量多，梨树的数量不能比苹果树的数量多。

请问有这三种树的数量分别有哪些可能的组合方法，从少到多分别数出桃树、梨树、苹果树可能的数量组合，每行 111 个方案。（ 6.1.996.1.996.1.99 ）

输入

一个整数 nnn 。（ n≥6n \ge 6n≥6 且是 666 的倍数）

输出

若干行的可能的组合方案，每行 333 个数，分别代表桃树、梨树、苹果树的可能的方案。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int i,j,k,n;
    cin >> n;
    for(i = 2;i <= n;i+=2){
        for(j = 2;j <= n;j+=2){
            for(k = 2;k <= n;k+=2) {
                if(i + j + k == n && i <= j && j <= k) {
                    cout << i << " " << j << " " << k << endl;
                }
            }
        }
    }
    return 0;
}
