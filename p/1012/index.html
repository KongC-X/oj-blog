1012 - 我是第几个单词

题目描述

输入一个英文句子，例如：This is a Book.，可以看到句子是以 . 来作为结束符号的，并且单词之间以一个空格来分隔。

接着再输入一个单词 AAA ，请找出首次在句子中出现的与 AAA 相同的单词，是句子中的第几个单词，若不存在，则输出该句子中单词字符的总个数。

例如对上句子而言，若输入单词 is，则应输出：222。 若输入单词 isa，则应输出：111111。

输入

第一行为以 . 结束的一个词组（仅由若干个大小写字母组成的单词构成，单词间由一空格隔开，除单词和最后的 . 以外，不含其它字符，句子总长度不超过 800800800，每个单词长度不超过 909090 个字符）

第二行是一个单词（不含空格，长度不超过 909090）。

输出

一个整数。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;	

int main() {
    char s[810],a[100],b[100];
    int i,k = 0,c = 1,x = 0;
    gets(s);
    cin >> a;
    for(i = 0;s[i] != '.';i++) {
        if(s[i] != ' ') {
            // in which four coins
            b[k] = s[i];
            k++;
            x++;
            if(s[i + 1] == ' ' || s[i + 1] == '.') {
                // 单词结束啦
                b[k] = '\0';
                if(strcmp(a,b) == 0) {
                    cout << c << endl;
                    return 0;
                } else {
                    c++;
                }
                k = 0;
            }
        }
    }
    cout << x << endl;
}
