B4196 [海淀区小学组 2023] 赛车游戏

洛谷 | 普及- | C++14 | 提交时间: 2026-07-22

算法标签：数学、2023、北京、Special Judge、双指针 two-pointer、科创活动

题目背景

2023 年海淀区中小学生信息学竞赛小学组复赛题目，数据为洛谷自造。

题目描述

陶陶和天天喜欢玩赛车游戏，在游戏中有一条直赛道长度为 $ l $，陶陶的赛车在起点为 $0$ 的位置，准备向终点行驶，天天的赛车在终点为 $ l $ 的位置，准备向起点行驶。赛车的初始速度都为 $1$，在赛道上有 $ n $ 个加速带，第 $ i $ 加速带的位置为 $ a_i $，当小车经过一个加速带时，它的速度就增加 $1$，请你帮忙计算出两车相遇时间。

输入格式

第一行仅有一个整数 $ T $ 表示测试数据的组数，每组测试数据的第一行包含两个整数 $ n $ 和 $ l $，第二行包含 $ n $ 个整数 $ a_1, a_2, a_3, \ldots, a_n $。

输出格式

共有 $ T $ 行，每行仅有一个数，依次对应每组测试数据的答案，表示两车相遇的时间。允许绝对误差、相对误差不超过 $ 10^{-6} $。

样例

样例输入 #1

5
2 10
1 9
1 10
1
5 7
1 2 3 4 6
2 1000000000
413470354 982876160
9 478
1 10 25 33 239 445 453 468 477```

**样例输出 #1**

3.000000000000000
3.666666666666667
2.047619047619048
329737645.7500000
53.70000000000000```

AC 代码

#include <cstdio>
#include <algorithm>
using namespace std;

const double INF = 1e18;
const double EPS = 1e-12;
const int MAXN = 100005;
int a[MAXN];

int main() {
    int T;
    scanf("%d", &T);
    while (T--) {
        int n, l;
        scanf("%d %d", &n, &l);
        for (int i = 0; i < n; i++) {
            scanf("%d", &a[i]);
        }

        /*
          思路：
          陶陶从 0 向右，天天从 l 向左，初始速度均为 1。
          遇到加速带速度 +1。
          用双指针模拟：i 指向陶陶下一个加速带，j 指向天天下一个加速带。
          每次计算三者时间的最小值：
            dt1：陶陶到达 a[i] 的时间
            dt2：天天到达 a[j] 的时间
            dt_meet：两人直接相遇的时间
          选择最小的事件执行，更新位置、速度和时间。
        */
        double t = 0.0;                // 已过时间
        double x1 = 0.0, v1 = 1.0;    // 陶陶：位置、速度
        double x2 = l, v2 = 1.0;      // 天天：位置、速度
        int i = 0, j = n - 1;         // 双指针

        while (1) {
            double dt1 = (i < n) ? (a[i] - x1) / v1 : INF;
            double dt2 = (j >= 0) ? (x2 - a[j]) / v2 : INF;
            double dt_meet = (x2 - x1) / (v1 + v2);

            if (dt_meet <= dt1 + EPS && dt_meet <= dt2 + EPS) {
                t += dt_meet;
                break;
            }

            if (dt1 <= dt2) {                // 陶陶先到加速带
                t += dt1;
                x1 = a[i];
                v1 += 1.0;
                x2 -= v2 * dt1;
                i++;
            } else {                         // 天天先到加速带
                t += dt2;
                x2 = a[j];
                v2 += 1.0;
                x1 += v1 * dt2;
                j--;
            }
        }

        printf("%.15f\n", t);
    }
    return 0;
}
