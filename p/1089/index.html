1089 - 找数游戏

题目描述

一个三位数，各位数字互不相同，十位数字比个位、百位数字之和还要大，且十位、百位数字之和不是质数。桐桐想把符合上述条件的三位数找出来，你能帮助她吗？

输入

无

输出

按照从小到大的顺序，输出满足条件的三位数，每行一个。

AC代码

AC代码

#include<iostream>
#include<cmath>
using namespace std;

int main(){
    int n,a,b,c,i,j,k;
    for(i = 100;i < 1000;i++) {
        a = i/100;
        b = i/10%10;
        c = i%10;
        if(a != b && b != c && a != c && b > a + c) {
            n = a + b;
            k = 0;
            for(j = 2;j <= n - 1;j++) {
                if(n % j == 0) {
                    k = 1;
                    break;
                }
            }
            if(k == 1) {
                cout << i << endl;
            }

        }

    }
}
