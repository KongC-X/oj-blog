1925 - 团队数量

题目描述

芝加哥组织了一场激烈的军事竞赛，很多国家的军人慕名而来，他们要么是队友，要么是敌人。

现建立如下规则：

  • 我的队友的队友，是我的队友；

  • 我的敌人的敌人也是我的队友；

两个人只要是队友，就认为他们属于同一团队，现给你若干参赛军人之间的关系，请问：最多有多少个团队？

输入

第一行是一个整数 NNN (2≤N≤10002 \le N \le 10002≤N≤1000)，表示参赛的人数（从 111 编号到 NNN ）。

第二行 MMM (1≤M≤50001 \le M \le 50001≤M≤5000)，表示关于参赛者的关系信息的条数。

以下 MMM 行，每行可能是 FFF ppp qqq 或是 EEE ppp qqq（1≤p,q≤N1 \le p,q \le N1≤p,q≤N），FFF 表示 ppp 和 qqq 是队友，EEE 表示 ppp 和 qqq 是敌人。

输入数据保证不会产生信息的矛盾。

输出

输出文件只有一行，表示最大可能的团队数。

AC代码

#include<bits/stdc++.h>
using namespace std;
//f：存储每个节点的父节点，并查集数组，大小是2n
int n,m,ans,f[2010];
char c;

//压缩路径求解x的根
int find(int x){
    //x的父直接指向x的根 
    return x == f[x]?x:f[x]=find(f[x]);
} 

//将x和y合并到同一个集合 
void merge(int x,int y){
    int fx = find(x);
    int fy = find(y);
    //如果x和y不在一个集合 
    if(fx != fy){
        f[fx] = fy;
    } 
}

int main(){
    cin>>n>>m;
    // 初始化：每个人有两个节点，i 是本人的“朋友域”,i+n 是本人的“敌人域”
    for(int i = 1;i <= 2 * n;i++) f[i] = i;
    int x,y;
    //m个关系
    for(int i = 1;i <= m;i++){
        cin>>c>>x>>y;
        //朋友关系直接合并 
        if(c == 'F') merge(x,y);
        else if(c == 'E'){
            //敌人 
            merge(x+n,y);// x 的敌人域 和 y 的本人域 合并
            merge(y+n,x);// y 的敌人域 和 x 的本人域 合并
        }
    } 
    
    // 统计有多少个独立的团队（只看真身域）
    for(int i = 1;i <= n;i++){
        if(f[i] == i) ans++;
    } 
    
    cout<<ans;
    return 0;
}
