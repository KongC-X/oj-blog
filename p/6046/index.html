6046 - 捡石头

题目描述

小强在河边捡了 222 块漂亮的石头，他想再捡两块石头，让这 444 块石头的质量正好为 303030 斤，并且新捡的两块石头的质量是介于前两块石头的质量之间的数字。（不能和前两块石头其中一块质量相等）

请编程输出第 333 块和第 444 块石头的质量。注：每个石头的重量都是整数，如果找不到合适的石头，则输出 0 0。

输入

输入 222 个数，数与数之间以空格间隔，表示 222 块石头的质量。

其中第 111 个数不大于第 222 个数，且两个数都在 [1,30][1, 30][1,30] 的范围内。

输出

输出表示第 333、444 块石头的质量的所有可能结果，每块石头质量的数字用空格隔开。

多组结果时，按第 333 块石头质量从小到大排序分行输出。

AC代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int a, b;                     // a: 第一块石头质量, b: 第二块石头质量 (a <= b)
    cin >> a >> b;

    int sum = 30 - a - b;         // 第三块和第四块石头的质量之和
    bool found = false;           // 是否找到至少一组解

    // 枚举第三块石头质量 c，范围为 (a+1) 到 (b-1)
    for (int c = a + 1; c <= b - 1; c++) {
        int d = sum - c;          // 第四块石头质量
        // 检查 d 是否合法：介于 a 和 b 之间，且 c <= d（避免重复输出对称解，如 (8,10) 和 (10,8)）
        if (d >= c && d >= a + 1 && d <= b - 1) {
            cout << c << " " << d << "\n";
            found = true;
        }
    }

    if (!found) {
        cout << "0 0\n";
    }

    return 0;
}
