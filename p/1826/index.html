1826 - 水下探测器：deep.cpp

题目描述

原理：

水下探测器可以潜入湖中在任意水深进行科学探索。
湖水的最大深度为 hhh 米,即它在湖底时到水面的距离，0≤h≤1000 \le h \le 1000≤h≤100；

探测器最初的水下深度为 sss 米，0≤s≤1000 \le s \le 1000≤s≤100；

当探测器不在水面（当前深度大于 000）时，每个 uuu 指令可使它上浮 111 米，而当探测器在水面时，uuu 指令是无效的；

当探测器不在湖底（当前深度小于 hhh）时，每个 ddd 指令可使它下沉 111 米，而当探测器在湖底时，ddd 指令是无效的；

在执行到无效指令时，探测器不做任何操作而继续执行下一指令。

编程实现：

根据给定的 h、sh、sh、s 和一个指令序列（由字符 u、du、du、d 组成的字符串，长度不超过 100100100），求出执行完整的指令序列后，探测器的水下深度。

输入

第一行：hhh 和 sss，以空格分开。0≤s≤h≤1000 \le s \le h \le 1000≤s≤h≤100。

第二行：长度不超过 100100100 的指令字符串，串中仅包含字母 uuu 或 ddd。

输出

代表探测器在执行指令后的水下深度的数字。

AC代码

#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int h, s;                     // h: 湖的最大深度，s: 初始深度
    cin >> h >> s;

    string cmd;                   // 指令序列
    cin >> cmd;

    // 当前深度
    int d = s;

    // 逐条执行指令
    for (int i = 0; i < cmd.size(); i++) {
        if (cmd[i] == 'u') {      // 上浮指令
            if (d > 0) d--;       // 不在水面才有效
        } else {                  // 'd' 下沉指令
            if (d < h) d++;       // 不在湖底才有效
        }
    }

    cout << d << '\n';
    return 0;
}
