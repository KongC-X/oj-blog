B2003 输出第二个整数

洛谷 | 入门 | C++14 | 提交时间: 2026-06-13

题目描述

输入三个整数，整数之间由一个空格分隔。把第二个输入的整数输出。

输入格式

只有一行，共三个整数，整数之间由一个空格分隔。

输出格式

只有一行，一个整数，即输入的第二个整数。

样例

样例输入 #1

123 456 789```

**样例输出 #1**

456```

AC 代码

#include<iostream>
using namespace std;
int main()  {
    int a,b,c;//定义3个分别叫a,b,c的变量
    cin>>a>>b>>c;//cin表示输入，本行表示输入a,b,c
    cout<<b<<endl;//表示输出b
    return 0;
}
