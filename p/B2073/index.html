B2073 求小数的某一位

洛谷 | 入门 | C++14 | 提交时间: 2026-07-05

题目描述

分数 ab\dfrac{a}{b}ba​ 化为小数后，小数点后第 nnn 位的数字是多少？

输入格式

三个正整数 aaa，bbb，nnn，相邻两个数之间用单个空格隔开。0<a≤b≤1000<a\le b\le1000<a≤b≤100，1≤n≤100001 \le n \le 100001≤n≤10000。

样例

样例输入 #1

1 2 1```

**样例输出 #1**

5```

AC 代码

#include <iostream>
using namespace std;

int main() {
    int a, b, n;
    cin >> a >> b >> n;

    int r = a % b;               // 当前余数
    int ans = 0;
    for (int i = 1; i <= n; i++) {
        r *= 10;                 // 补零
        ans = r / b;             // 商即为当前小数位
        r = r % b;               // 更新余数
    }

    cout << ans << endl;
    return 0;
}
