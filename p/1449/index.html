1449 - 求满足条件的数的和

题目描述

小明同学想找出这样的数：能同时被 222 、333 、555 、777 中 222 个及 222个以上的数整除的数，比如 666、303030 、210210210 等。

请你编程帮助小明找出 1∼n1 \sim n1∼n 中满足条件的数的总和是多少？

输入

个整数 nnn ；（n≤9999n \le 9999n≤9999）

输出

一个整数，代表 1≤n1 \le n1≤n 中满足条件的整数的总和；

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int main() {
    //r：求和变量，要清零 
    int i,g,s,b,q,n,c,r = 0;
    cin>>n;
    for(i=1; i<=n; i++) {
        //c是一个反复使用的计数器，因此每次都要清零
        //因为对于每个i都要求能被几个数整除 
        c = 0;  
        
        if(i%2 == 0) {
            c++;
        }
        if(i%3 == 0) {
            c++;
        }
        if(i%5 == 0) {
            c++;
        }
        if(i%7 == 0) {
            c++;
        }
        
        //如果能被2个及2个以上的数整除
        if(c >= 2){
            r = r + i;//求和 
        } 
    }
    //最后输出总和 
    cout<<r<<endl;
}
