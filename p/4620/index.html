4620 - 数位和为偶数的数

题目描述

给定一个整数 nnn，请找出 111 到 nnn 之间（包含 111 和 nnn）所有数位和为偶数的整数。

例如：n=15n = 15n=15，111 到 151515 之间的整数为：111、222、333、444、555、666、777、888、999、101010、111111、121212、131313、141414、151515；

数位和依次为：111、222、333、444、555、666、777、888、999、111、222、333、444、555、666；

数位和为偶数的是：222、444、666、888、111111、131313、151515。

输入

输入一个整数 n（2≤n≤1000)n（2 \le n \le 1000)n（2≤n≤1000)。

输出

一行输出若干个整数，表示 111 到 nnn 之间（包含 111 和 nnn）所有数位和为偶数的数，并按照从小到大的顺序依次输出，整数之间以一个空格隔开。

AC代码

#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    for (int i = 1; i <= n; i++) {
        // 计算 i 的数位和
        int sum = 0;
        int temp = i;
        
        while (temp > 0) {
            sum += temp % 10;  // 加上最后一位
            temp /= 10;         // 去掉最后一位
        }
        
        // 判断数位和是否为偶数
        if (sum % 2 == 0) {
            cout << i << endl;
        }
    }
    
    return 0;
}
