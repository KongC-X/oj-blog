B3774 [信息与未来 2022] 样本分类

洛谷 | 普及| C++14 | 提交时间: 2026-04-29

算法标签：2022、江苏、Special Judge、信息与未来

题目描述

在人工智能中，“分类”是一项非常重要的任务。例如，公安系统通过人工智能分类潜在的电信诈骗，并进行及时的预警。现在我们考虑一种最简单的“线性二分类器”，它由 nnn 个整数参数（常数）a1,a2,⋯ ,ana_1,a_2,\cdots,a_na1​,a2​,⋯,an​ 组成。在输入一组整数 x1,x2,⋯ ,xnx_1,x_2,\cdots,x_nx1​,x2​,⋯,xn​ 时，如果

a1⋅x1+a2⋅x2+⋯+an⋅xn≤0a_1\cdot x_1+a_2\cdot x_2+\dots+a_n\cdot x_n\leq 0a1​⋅x1​+a2​⋅x2​+⋯+an​⋅xn​≤0

成立，则分类器输出 true\texttt{true}true，否则分类器输出 false\texttt{false}false。如果分类器的输入（称为“特征”）选择得当，即便是简单的线性分类器也能取得很好的分类效果。

现在，我们得到了两个用于同一分类任务的分类器：

  • 分类器 AAA，当 a1⋅x1+a2⋅x2+⋯+an⋅xn≤0a_1\cdot x_1+a_2\cdot x_2+\dots +a_n\cdot x_n\leq 0a1​⋅x1​+a2​⋅x2​+⋯+an​⋅xn​≤0 时输出 true\texttt{true}true，否则输出 false\texttt{false}false
  • 分类器 BBB，当 b1⋅x1+b2⋅x2+⋯+bn⋅xn≤0b_1\cdot x_1+b_2\cdot x_2+\dots +b_n\cdot x_n\leq 0b1​⋅x1​+b2​⋅x2​+⋯+bn​⋅xn​≤0 时输出 true\texttt{true}true，否则输出 false\texttt{false}false

由于 AAA 和 BBB 是两个不同的分类器，它们可能会在某些输入的 xxx 上产生分歧，给出不同的分类结果——这样的问题值得我们特别关注。因此，你的任务就是求出一组 x1,x2,⋯ ,xnx_1,x_2,\cdots,x_nx1​,x2​,⋯,xn​，使得分类器 AAA 和 BBB 返回不同的结果。

为了帮助大家理解，我们假设 aia_iai​ 和 bib_ibi​ 分别保存在数组 a\text{a}a 和 b\text{b}b 中（数组下标从 111 到 nnn）。你的任务就是求出数组 x\text{x}x 的元素 x[1],x[2],⋯ ,x[n]\texttt{x[1]},\texttt{x[2]},\cdots,\texttt{x[n]}x[1],x[2],⋯,x[n]，使下面的函数 diverge\texttt{diverge}diverge 返回 true\texttt{true}true：

int n; // 参数/输⼊的个数
bool classify(int param[], int x[]) {
 int y = 0;
 for (int i = 1; i <= n; i++) {
 y += param[i] * x[i];
 }
 if (y <= 0) {
 return true;
 } else {
 return false;
 }
}
bool diverge(int x[]) {
 return classify(a, x) != classify(b, x);
}

输入格式

输入的第一行包含一个整数 nnn，代表分类器参数的个数。

输入的第二行包含 nnn 个整数，代表分类器 AAA 的参数 aia_iai​（1≤i≤n1\le i\le n1≤i≤n）。

输入的第三行包含 nnn 个整数，代表分类器 BBB 的参数 bib_ibi​（1≤i≤n1\le i\le n1≤i≤n）。

输入数据保证两个分类器的参数不是完全相同的。

传题人 Update：本题保证两个分类器的参数不对应成比例且同号，即所有 aibi\dfrac{a_i}{b_i}bi​ai​​ 不全为同一正值，可以证明这种情况下一定有解。

输出格式

输出一行 nnn 个整数，分别是 x1,x2,⋯ ,xnx_1,x_2,\cdots,x_nx1​,x2​,⋯,xn​。其中 xix_ixi​（1≤i≤n1\leq i\leq n1≤i≤n）可以是正数、负数或零，但绝对值不能超过 10,00010,00010,000。如果有多组满足要求的解，输出任意一个即可。

AC 代码

#include <iostream>
#include <cmath>
using namespace std;

int n;
int a[1005], b[1005];
int x[1005];

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) cin >> b[i];

    for (int i = 1; i <= n; i++) x[i] = 0;   // 初始化为0

    if (n == 1) {
        // n=1时由题目保证a1和b1必然异号或有一个为0，取x1=1即可
        x[1] = 1;
    } else {
        int p = -1, q = -1;   // 寻找一对(i,j)使行列式不为0
        for (int i = 1; i <= n && p == -1; i++) {
            for (int j = i + 1; j <= n && p == -1; j++) {
                if (a[i] * b[j] - a[j] * b[i] != 0) {
                    p = i;
                    q = j;
                }
            }
        }

        if (p != -1) {
            // 标准构造：x[p] = b[q]+a[q], x[q] = -a[p]-b[p]
            // 此时 a·x = -b·x ≠ 0，符号必然相反
            x[p] = b[q] + a[q];
            x[q] = -a[p] - b[p];
        } else {
            // 所有2×2行列式都为0 → a与b线性相关，且必为负比例关系
            // 令 x = a (若a不全为0)，否则 x = b
            bool allZero = true;
            for (int i = 1; i <= n; i++) {
                if (a[i] != 0) { allZero = false; break; }
            }
            if (!allZero) {
                for (int i = 1; i <= n; i++) x[i] = a[i];
            } else {
                for (int i = 1; i <= n; i++) x[i] = b[i];
            }
        }
    }

    // 输出
    for (int i = 1; i <= n; i++) {
        cout << x[i];
        if (i < n) cout << " ";
    }
    cout << endl;

    return 0;
}
