B4194 [海淀区小学组 2023] 生日

洛谷 | 普及- | C++14 | 提交时间: 2026-07-22

算法标签：2023、北京、Special Judge、排序、科创活动、小学活动

题目背景

2023 年海淀区中小学生信息学竞赛小学组复赛题目，数据为洛谷自造。

本题数据范围较官方赛事有所修改，保证 n≤5×106n\leq 5\times 10^{\color{red}6}n≤5×106，避免不必要的过大的输入输出量。尽管如此，本题最大的单测试点输入输出仍然可达 100MB 左右，请优化你的输入输出速度。

题目描述

陶陶过生日，有 nnn 个小伙伴站成环形为他庆祝，并将他们标号为 1…n1 \ldots n1…n，他们对应的身高为 a1…ana_1 \ldots a_na1​…an​。求如何排序，能让任意相邻的两个小伙伴之间身高差的绝对值最大值最小。

输入格式

第一行仅有一个整数 nnn，表示参加生日聚会的小伙伴人数。

第二行有 nnn 个整数 a1,a2,…,ana_1, a_2, \ldots, a_na1​,a2​,…,an​，aia_iai​ 表示第 iii 位小伙伴的身高。

输出格式

输出 nnn 个整数，表示排序后的小伙伴的身高。如果有多种方案，输出一种即可。

样例

样例输入 #1

5
2 1 1 3 2```

**样例输出 #1**

1 2 3 2 1```

样例输入 #2

3
30 10 20```

**样例输出 #2**

10 20 30```

AC 代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int a[5000010];                        // 存放身高

int main() {
    int n;
    scanf("%d", &n);
    for (int i = 0; i < n; i++) {
        scanf("%d", &a[i]);
    }

    // 从小到大排序
    sort(a, a + n);

    /*
      思路（贪心构造）：
      排序后，先将所有奇数下标的元素（0,2,4,...）按升序输出，
      再将偶数下标的元素（...,5,3,1）按降序输出。
      这样得到的环形序列，相邻元素的最大差值为 max(a[i+2] - a[i])，
      这是理论上的最小可能值，因此满足“最大相邻差最小”的要求。
      注意：环形排列，从任意位置开始读都可以，我们按此顺序输出即是合法方案。
    */

    // 先输出所有奇数位置（0,2,4,...）
    for (int i = 0; i < n; i += 2) {
        printf("%d ", a[i]);
    }
    // 再输出所有偶数位置（最大的那个偶数开始降序）
    // 如果 n 是奇数，最后一个奇数下标是 n-1，偶数从 n-2 开始降序
    // 如果 n 是偶数，最后一个奇数下标是 n-2，偶数从 n-1 开始降序
    int start = (n % 2 == 0) ? (n - 1) : (n - 2);
    for (int i = start; i >= 0; i -= 2) {
        printf("%d ", a[i]);
    }
}
