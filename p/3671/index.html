3671 - 相似字符串

题目描述

对于两个字符串 AAA 和 BBB ，如果 AAA 可以通过删除一个字符，或插入一个字符，或修改一个字符变成 BBB ，那么我们说 AAA 和 BBB 是相似的。

比如 appleappleapple 可以通过插入一个字符变成 appleeappleeapplee ，可以通过删除一个字符变成 appeappeappe ，也可以通过修改一个字符
变成 bpplebpplebpple ，因此 appleappleapple 和 appleeappleeapplee 、 appeappeappe 、 bpplebpplebpple 都是相似的。但 appleeappleeapplee 并不能通过任意一个操作变成 bpplebpplebpple ，因此它们并不相似。

特别地，完全相同的两个字符串也是相似的。

给定 TTT 组 A，BA，BA，B，请你分别判断他们是否相似。

输入

第一行一个正整数 TTT 。

接下来 TTT 行，每行两个用空格隔开的字符串 AAA 和 BBB 。

保证 T≤100T \le 100T≤100 ， A，BA，BA，B 的长度不超过 505050 。保证 AAA 和 BBB 只包含小写字母。

输出

输出 TTT 行，对于每组 A，BA，BA，B，如果它们相似，则输出 similar ，否则输出 not similar 。

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
using namespace std;
int n;
string s1,s2;
int main(){
    cin>>n;
    for(int i=0;i<n;i++){
        cin>>s1>>s2;
        int q=0,w=0,ans=0;
        if(s1.size()<s2.size()){
            swap(s1,s2);
        }
        if(s1.size()-s2.size()>1){
            cout<<"not similar"<<endl;
        }else if(s1.size()-s2.size()==0){
            for(int j=0;j<s1.size();j++){
                if(s1[j]!=s2[j]){
                    ans++;
                }
            }if(ans<=1){
                cout<<"similar"<<endl;
            }else{
                cout<<"not similar"<<endl;
            }
        }else{
            while(q<s1.size()){
                if(s1[q]==s2[w]){
                    q++;
                    w++;
                }else{
                    q++;
                    ans++;
                }
            }if(ans<=1){
                cout<<"similar"<<endl;
            }else{
                cout<<"not similar"<<endl;
            }
        }
    }
}
