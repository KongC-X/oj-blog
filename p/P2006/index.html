P2006 赵神牛的游戏

洛谷 | 入门 | C++14 | 提交时间: 2026-07-24

算法标签：模拟

题目描述

在 DNF 中，赵神牛有一个缔造者，他一共有 kkk 点法力值，一共有 mmm 个技能，每个技能耗费的法力值为 aia_iai​，可以造成的伤害为 bib_ibi​，而 boss 的体力值为 nnn，请你求出它放哪个技能，才可以打死 boss。

当然，赵神牛技术很菜，他一局只放一个技能，不过每个技能都可以放无数次。

输入格式

第一行有三个整数，分别表示 k,m,nk,m,nk,m,n。

后面 mmm 行，每行两个整数，第 (i+1)(i + 1)(i+1) 行的整数表示耗费的法力值 aia_iai​ 和造成的伤害 bib_ibi​。

输出格式

输出仅一行，即可以杀死 boss 的技能序号，如果有多个，按从小到大的顺序输出，中间用一个空格隔开；如果没有技能能杀死 boss，输出 -1。

样例

样例输入 #1

100 3 5000
20 1000
90 1
110 10000

样例输出 #1

1

样例输入 #2

50 4 10
60 100
70 1000
80 1000
90 0

样例输出 #2

-1```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const int MAXM = 30010;          // m 最大 3e4，多开10
int ans[MAXM];                   // 存储可行的技能编号
int cnt = 0;                     // 可行技能的数量

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    // 思路：
    // 对每个技能，计算所需的最少释放次数 cnt = ceil(n / b_i)，
    // 然后判断 cnt * a_i <= k 是否成立。
    // 注意 b_i == 0 时技能无效；a_i == 0 且 b_i > 0 时无需消耗即可释放。
    // 数据范围可能使 cnt*a_i 超出 int，用 long long。

    int k, m, n;
    cin >> k >> m >> n;

    for (int i = 1; i <= m; i++) {
        ll a, b;
        cin >> a >> b;

        if (b == 0) continue;            // 伤害为0，无效

        ll need = (n + b - 1) / b;       // 最少释放次数（向上取整）
        ll cost;
        if (a == 0) {
            cost = 0;                    // 法力无消耗，可以无限放
        } else {
            cost = need * a;             // 总法力消耗
        }

        if (cost <= k) {
            ans[cnt++] = i;              // 记录技能编号
        }
    }

    if (cnt == 0) {
        cout << -1 << endl;
    } else {
        for (int i = 0; i < cnt; i++) {
            if (i > 0) cout << " ";
            cout << ans[i];
        }
        cout << endl;
    }

    return 0;
}
