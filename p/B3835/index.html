B3835 [GESP202303 一级] 每月天数

洛谷 | 入门 | C++14 | 提交时间: 2025-03-28

算法标签：数学、2023、分支结构、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1121

题目描述

小明刚刚学习了每月有多少天，以及如何判断平年和闰年，想到可以使用编程方法求出给定的月份有多少天。你能做到吗？

输入格式

输入一行，包含两个整数 $A, B$，分别表示一个日期的年、月。约定 $2000 \leq A \leq 3000$，$1 \leq B \leq 12$。

输出格式

输出一行，包含一个整数，表示输入月份有多少天。

样例

样例输入 #1

2022 1```

**样例输出 #1**

31```

样例输入 #2

2020 2```

**样例输出 #2**

29```

AC 代码

#include <iostream>
using namespace std;
int main() {
    int y = 0, m = 0;
    cin >> y >> m;
    bool leap = false; // 判断闰年变量，初始值为 false，意思为是平年
    if (y % 400 == 0 || (y % 4 == 0 && y % 100 != 0))
        leap = true;
    if (m == 1 || m == 3 || m == 5 || m == 7 || m == 8 || m == 10 || m == 12)
        cout << 31 << endl; // 大月
    else if (m == 4 || m == 6 || m == 9 || m == 11)
        cout << 30 << endl; // 小月
    else if (leap)
        cout << 29 << endl; // 闰年 2 月
    else
        cout << 28 << endl; // 平年 2 月
    return 0;
}
