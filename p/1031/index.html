1031 温度转换

1031 - 温度转换

题目描述

编一程序，将摄氏温度换为华氏温度。公式为：f=9/5∗c+32f=9/5*c+32f=9/5∗c+32 。其中 fff 为华氏温度, ccc 是摄氏温度。（5.2.12）

输入

输入一行，只有一个整数 ccc 。

输出

输出只有一行，包括 111 个实数。（保留两位小数）

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
#include<iomanip>
using namespace std;

int main() {
    int c;
    double f;
    cin >> c;
    f = 9.0/5 * c + 32;
    cout << fixed << setprecision(2) << f << endl;
}
