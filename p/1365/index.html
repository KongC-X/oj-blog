1365 - 位数问题

题目描述

在所有的 NNN 位数中，有多少个数中有偶数个数字 333 ？由于结果可能很大，你只需要输出这个答案对 123451234512345 取余的值。

比如：在所有的 222 位数字，包含 000 个 333 的数有 727272 个，包含 222 个 333 的数有 111个，共 737373 个。（请注意：111 位数指 1∼91 \sim 91∼9 这 999 个数，不包含数字 000 ）

输入

一个整数 NNN（1≤N≤10001 \le N \le 10001≤N≤1000）。

输出

NNN 位数中含有偶数个数组 333 的个数。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
/*
设a[i]为i位时有偶数个3，b[i]是i位时有奇数个3
当i=1时，注意，dp一般从最高位算起，所以慢慢打表下来是加的低位，a[1]=8（0不包括），b[1]=1，
所以在递推的时候进行分类讨论：
1.若n-1位为奇数个3，则n位就应该加3，这样才有偶数个3
2.若n-1位为偶数个3，则n位应该不为3，有9种情况 ，这样才有偶数个3
*/
int main(){
    int a[10000],b[1000];
    int i,n;
    cin>>n;
    a[1]=1;
    b[1]=8;
    for(i=2;i<=n;i++){
        a[i] = (a[i-1]*9+b[i-1])%12345;
        b[i] = (b[i-1]*9+a[i-1])%12345;
    }
    cout<<b[n];
}
