1600 - 请假时间计算

题目描述

假设小明的妈妈向公司请了 nnn 天的假，那么请问小明的妈妈总共请了多少小时的假，多少分钟的假？（提示： 111 天有 242424 小时，111 小时有 606060 分钟）

输入

一个整数 nnn，代表小明妈妈请假的天数。

输出

两个整数，每行 111 个。

第 111 行的整数代表小明妈妈请假的小时数。

第 222 行的整数代表小明妈妈请假的分钟数。

解题思路

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    cout << n * 24 << endl;
    cout << n * 24 * 60 << endl;
}
