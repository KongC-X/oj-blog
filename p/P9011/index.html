P9011 [USACO23JAN] Air Cownditioning II B

洛谷 | 普及- | C++14 | 提交时间: 2026-08-07

算法标签：USACO、2023、深度优先搜索 DFS、差分

题目描述

With the hottest recorded summer ever at Farmer John's farm, he needs a way to cool down his cows. Thus, he decides to invest in some air conditioners.

Farmer John's NNN cows (1≤N≤20)(1 \le N \le 20)(1≤N≤20) live in a barn that contains a sequence of stalls in a row, numbered 1⋯1001 \cdots 1001⋯100. Cow iii occupies a range of these stalls, starting from stall sis_isi​ and ending with stall tit_iti​. The ranges of stalls occupied by different cows are all disjoint from each-other. Cows have different cooling requirements. Cow iii must be cooled by an amount cic_ici​, meaning every stall occupied by cow iii must have its temperature reduced by at least cic_ici​ units.

The barn contains MMM air conditioners, labeled 1⋯M(1≤M≤10)1 \cdots M (1 \le M \le 10)1⋯M(1≤M≤10). The iii-th air conditioner costs mim_imi​ units of money to operate (1≤mi≤1000)(1 \le m_i \le 1000)(1≤mi​≤1000) and cools the range of stalls starting from stall aia_iai​ and ending with stall bib_ibi​. If running, the iii-th air conditioner reduces the temperature of all the stalls in this range by pi(1≤pi≤106)p_i (1 \le p_i \le 10^6)pi​(1≤pi​≤106). Ranges of stalls covered by air conditioners may potentially overlap.

Running a farm is no easy business, so FJ has a tight budget. Please determine the minimum amount of money he needs to spend to keep all of his cows comfortable. It is guaranteed that if FJ uses all of his conditioners, then all cows will be comfortable.

输入格式

The first line of input contains NNN and MMM.

The next NNN lines describe cows. The ith of these lines contains si,tis_i, t_isi​,ti​, and cic_ici​.

The next MMM lines describe air conditioners. The ith of these lines contains ai,bi,pia_i, b_i, p_iai​,bi​,pi​, and mim_imi​.

For every input other than the sample, you can assume that M=10M=10M=10.

输出格式

Output a single integer telling the minimum amount of money FJ needs to spend to operate enough air conditioners to satisfy all his cows (with the conditions listed above).

样例

样例输入 #1

2 4
1 5 2
7 9 3
2 9 2 3
1 6 2 8
1 2 4 2
6 9 1 5```

**样例输出 #1**

10```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：枚举子集（状态压缩）
     * 思路：
     * 1. 读入 N, M，奶牛信息 (s, t, c)，空调信息 (a, b, p, m)。
     * 2. 枚举所有空调选择方案 mask（0 ~ (1<<M)-1）：
     *    - 清空冷却数组 cool[101] = {0}。
     *    - 若空调 i 被选中（mask & (1<<i)），对区间 [a_i, b_i] 每个位置加上 p_i。
     *    - 累加费用 cost。
     *    - 检查所有奶牛：对于每个奶牛 i，检查其区间 [s_i, t_i] 中每个位置 j，
     *      若 cool[j] < c_i，则该方案无效。
     *    - 若有效，更新最小费用 ans。
     * 3. 输出 ans。
     */

    int n, m;          // n: 奶牛数, m: 空调数
    cin >> n >> m;

    int s[25], t[25], c[25];    // 奶牛区间和需求
    for (int i = 0; i < n; i++) {
        cin >> s[i] >> t[i] >> c[i];
    }

    int a[15], b[15], p[15], cost[15];   // 空调参数
    for (int i = 0; i < m; i++) {
        cin >> a[i] >> b[i] >> p[i] >> cost[i];
    }

    int ans = 1e9;   // 最小费用，初始为较大值

    // 枚举所有方案
    for (int mask = 0; mask < (1 << m); mask++) {
        int cool[105] = {0};    // 每个位置的降温总量，坐标最大100
        int sum = 0;            // 当前方案总费用

        // 应用选中的空调
        for (int i = 0; i < m; i++) {
            if (mask & (1 << i)) {
                sum += cost[i];
                for (int j = a[i]; j <= b[i]; j++) {
                    cool[j] += p[i];
                }
            }
        }

        // 检查是否满足所有奶牛
        bool ok = true;
        for (int i = 0; i < n && ok; i++) {
            for (int j = s[i]; j <= t[i]; j++) {
                if (cool[j] < c[i]) {
                    ok = false;
                    break;
                }
            }
        }

        if (ok) {
            if (sum < ans) ans = sum;
        }
    }

    cout << ans << endl;
    return 0;
}
