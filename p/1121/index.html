1121 - “倒”数

题目描述

输入一个正整数 $N（ 0 \lt N \lt 2147483647 $），将这个数倒着合成一个新数后输出。

比如： $543$ ，倒过来是 $345$ （请注意： $34500$ ，倒过来是 $543$ ，不是 $00543$ ）！

输入

一行，一个正整数 $N$ 。

输出

一行，一个正整数。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;

int main(){
    int n,s = 0;
    cin >> n;
    while(n != 0) {
        s = s * 10 + n % 10;
        n = n / 10;
    }
    cout << s << endl;
}
