2350 - 奇偶判断

题目描述

【具体要求】

在键盘中输入 nnn 个正整数 a1,a2,a3,...ana_1, a_2, a_3, ... a_na1​,a2​,a3​,...an​ （0≤ai≤1000 \le a_i \le 1000≤ai​≤100)，判断每个正整数是奇数还是偶数，如果是奇数则用 111 表示，如果是偶数则用 000 表示，NNN 个正整数判断后从最后一位开始倒置输出结果。

输入

输入共两行，第一行输入一个正整数 nnn （1<n≤1001 \lt n \le 1001<n≤100）

输出

倒置输出每个正整数的奇偶性，奇数用 111 表示，偶数用 000 表示，数字之间用空格隔开。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int n,i;
int a[110],b[110];
int main() {
    cin >> n;
    for(i=0;i<n;i++){
        cin >> a[i];
        if(a[i] % 2 == 0) {
            b[i] = 0;
        } else {
            b[i] = 1;
        }
    }
    for(i= n - 1;i >= 0;i--){
        cout << b[i] << " ";
    }
}
