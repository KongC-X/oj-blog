B3753 [信息与未来 2019] 堆栈计算机

洛谷 | 普及| C++14 | 提交时间: 2026-04-21

算法标签：2019、江苏、Special Judge、进制、栈、构造、信息与未来

题目描述

有一种新型的堆栈计算机，计算机的内存是一个初始为空的数列，计算机支持三种操作：

  • 1\tt 11 - 将整数 111 放入数列的尾部。任意时刻都可执行此操作。
  • dup\tt dupdup - 将数列尾部的数字复制一份，放入数列尾部。只有数列非空时才能执行此操作。
  • add\tt addadd - 取出（并删除）数列尾部的两个数字，相加后放回数列的尾部。只有数列中至少有两个数字时才能执行此操作。

给定一个正整数，你需要输出一个长度不超过 200200200 的程序（操作的序列），它在执行结束后，恰好得到一个长度为 111 的数列，并且数列中的数字恰好为 nnn。下图展示了一个最终得到 888 的程序。

输入格式

输入一行一个正整数 nnn，表示希望输出的数字。

输出格式

输出一个若干行（不超过 200200200 行，否则判为不正确）的满足上述要求的程序。如有多种方案，输出任意一种即可。注意 dup\tt dupdup 和 add\tt addadd 均为小写。

样例

样例输入 #1

1```

**样例输出 #1**

1```

样例输入 #2

8```

**样例输出 #2**

1
1
add
dup
add
dup
add```

AC 代码

#include <iostream>
#include <string>
using namespace std;

// 这道题要求用堆栈计算机指令构造出给定的数字n。
// 因为只有加法和复制，我们可以利用“二进制分解”的方法：
// 先放一个1作为基础，然后对于n的二进制表示中从第二个高位到最低位的每一位，执行“乘2”（dup + add），
// 如果该位是1则再“加1”（1 + add）。这样操作次数远小于200，可以轻松完成。

// 核心思想：用“翻倍”和“加1”来构造任何数
// 堆栈计算机只有三种操作：放1、复制栈顶、将栈顶两个数相加。巧妙的是：
// 复制栈顶再相加（dup + add）的效果就是把当前数翻倍（变成原来的2倍）。
// 放一个1再相加（1 + add）的效果就是把当前数加1。
// 所以，我们可以像搭积木一样，从1开始，通过“翻倍”和“加1”两种操作，逐步构造出任意大的数。
// 我们想构造数字n，可以从1开始，每次决定是“翻倍”还是“翻倍后加1”，直到达到n。具体做法是：看n能不能被2整除。
// 如果n是偶数，说明最后一步是翻倍得到的，我们先想办法构造出n/2，再翻倍。
// 如果n是奇数，说明最后一步是翻倍后加1得到的，我们先想办法构造出(n-1)/2，再翻倍然后加1。
// 这样一直倒推，直到回到1。然后我们把过程正过来输出指令即可。
// 因为n最大10^9，每次除以2大约30次就到1了。每次操作最多4条指令，总指令数不超过30×4=120条，完全满足要求。

int main() {
    int n;
    cin >> n;

    if (n == 1) {
        cout << 1 << endl;
        return 0;
    }

    // 将 n 转为二进制字符串（无前导0）
    string b = "";
    int t = n;
    while (t > 0) {
        b = char('0' + (t % 2)) + b;
        t /= 2;
    }

    // 初始放一个 1
    cout << 1 << endl;

    // 从二进制第二位开始处理（索引1），第一位已经由初始1表示
    for (int i = 1; i < b.size(); i++) {
        // 乘以2：dup + add
        cout << "dup" << endl;
        cout << "add" << endl;

        // 如果该位是1，再加1
        if (b[i] == '1') {
            cout << 1 << endl;
            cout << "add" << endl;
        }   
    }

    return 0;
}
