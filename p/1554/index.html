1554 - 幸运数字

题目描述

小明认为，如果以下条件之一成立，正整数 xxx 就是一个幸运数字:

1.1.1. xxx 是 444 的倍数;

2.2.2. xxx 是 777 的倍数;

3.3.3. xxx 转换为字符串后包含子串“ 444444 ”或“ 777777”。

例如，105105105 ( 777 的倍数), 442442442 (包含“ 444444 ”), 128412841284 ( 444 的倍数)都是幸运数字，474474474 则不是。 编程统计 111 到 nnn 中幸运数字的数量。

输入

整数 nnn。 (1≤n≤1,000,0001 \le n \le 1,000,0001≤n≤1,000,000 )

输出

一个整数: 1,2,…,n1, 2, \dots, n1,2,…,n 中幸运数字的数量。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int n,c = 0;
int main(){
    cin>>n;
    for(int i = 1;i <= n;i++){
        string s = to_string(i);
        //判断幸运数
        if(i%4==0||i%7==0||s.find("44")!=-1||s.find("77")!=-1){
            c++;
        } 
    }
    
    cout<<c;
    return 0;
}
