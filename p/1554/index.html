1554 - 幸运数字

题目描述

小明认为，如果以下条件之一成立，正整数 $x$ 就是一个幸运数字:

$1.$ $x$ 是 $4$ 的倍数;

$2.$ $x$ 是 $7$ 的倍数;

$3.$ $x$ 转换为字符串后包含子串“ $44$ ”或“ $77$”。

例如，$105$ ( $7$ 的倍数), $442$ (包含“ $44$ ”), $1284$ ( $4$ 的倍数)都是幸运数字，$474$ 则不是。 编程统计 $1$ 到 $n$ 中幸运数字的数量。

输入

整数 $n$。 ($1 \le n \le 1,000,000$ )

输出

一个整数: $1, 2, \dots, n$ 中幸运数字的数量。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int n,c = 0;
int main(){
    cin>>n;
    for(int i = 1;i <= n;i++){
        string s = to_string(i);
        //判断幸运数
        if(i%4==0||i%7==0||s.find("44")!=-1||s.find("77")!=-1){
            c++;
        } 
    }
    
    cout<<c;
    return 0;
}
