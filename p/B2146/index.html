B2146 Hermite 多项式

题目描述

求 Hermite 多项式的值。

hn(x)={1，n=02x，n=12xhn−1(x)−2(n−1)hn−2(x)，n>1h_n(x)=\left\{ \begin{aligned} 1&，&n=0\\ 2x&，&n=1\\ 2xh_{n-1}(x)-2(n-1)h_{n-2}(x)&，& n>1 \end{aligned} \right.hn​(x)=⎩⎨⎧​12x2xhn−1​(x)−2(n−1)hn−2​(x)​，，，​n=0n=1n>1​

对给定的 xxx 和正整数 nnn，求多项式的值。

输入格式

输入两个正整数 nnn 和 xxx 。

样例

样例输入 #1

1 2```

**样例输出 #1**

4```

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 递归函数：计算 Hermite 多项式 H_n(x)，返回 long long 防止溢出
long long h(int n, int x) {
    if (n == 0) return 1;                          // H_0(x) = 1
    if (n == 1) return 2LL * x;                    // H_1(x) = 2x
    return 2LL * x * h(n - 1, x) - 2LL * (n - 1) * h(n - 2, x);  // 递推公式
}

int main() {
    int n, x;
    cin >> n >> x;
    cout << h(n, x) << endl;
    return 0;
}
