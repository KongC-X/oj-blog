P1091 [NOIP 2004 提高组] 合唱队形

洛谷 | 普及- | C++14 | 提交时间: 2026-07-20

算法标签：动态规划 DP、2004、NOIP 提高组、线性 DP

题目描述

nnn 位同学站成一排，音乐老师要请其中的 n−kn-kn−k 位同学出列，使得剩下的 kkk 位同学排成合唱队形。

合唱队形是指这样的一种队形：设 kkk 位同学从左到右依次编号为 1,2,1,2,1,2, … ,k,k,k，他们的身高分别为 t1,t2,t_1,t_2,t1​,t2​, … ,tk,t_k,tk​，则他们的身高满足 t1<⋯<ti>ti+1>t_1< \cdots <t_i>t_{i+1}>t1​<⋯<ti​>ti+1​> … >tk(1≤i≤k)>t_k(1\le i\le k)>tk​(1≤i≤k)。

你的任务是，已知所有 nnn 位同学的身高，计算最少需要几位同学出列，可以使得剩下的同学排成合唱队形。

输入格式

共二行。

第一行是一个整数 nnn（2≤n≤1002\le n\le1002≤n≤100），表示同学的总数。

第二行有 nnn 个整数，用空格分隔，第 iii 个整数 tit_iti​（130≤ti≤230130\le t_i\le230130≤ti​≤230）是第 iii 位同学的身高（厘米）。

输出格式

一个整数，最少需要几位同学出列。

样例

样例输入 #1

8
186 186 150 200 160 130 197 220

样例输出 #1

4

AC 代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

/*
求最长不下降子序列长度，动态转移方程：
    dp[i]=1
    dp[i]=max(dp[j]+1,dp[i])
    j是1 . .i-1 之间的数， a[j]<a[i]
*/
//dpa:从左至右求到每个点的最长不下降子序列的长度
//dpb:从右至左求到每个点的最长不下降子序列的长度
int i,n,j,a[110],dpa[110],dpb[110],ans;

int main() {
    cin >> n;
    for (i = 1; i <= n; i++) {
        cin >> a[i];
    }
    // 递推求 dpa 的值
    for (i = 1; i <= n; i++) {
        dpa[i] = 1; // 默认边界
        for (j = 1; j < i; j++) {
            if (a[j] < a[i]) {
                dpa[i] = max(dpa[i], dpa[j] + 1);
            }
        }
    }
        // 反过来求 dpb[i]
        for (i = n; i >= 1; i--) {
            dpb[i] = 1;
            for (j = n; j > i; j--) {
                if (a[j] < a[i]) {
                    dpb[i] = max(dpb[i], dpb[j] + 1);
                }
            }
        }
        // 求解能留下的最多的人数
        for (i = 1; i <= n; i++) {
            ans = max(ans, dpa[i] + dpb[i] - 1);
        }
        // 计算要出队伍的人数
        cout << n - ans;
        return 0;
}
