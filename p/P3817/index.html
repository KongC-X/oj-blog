P3817 小A的糖果

洛谷 | 普及- | C++14 | 提交时间: 2026-02-05

算法标签：模拟、贪心、洛谷月赛

题目描述

小 A 有 nnn 个糖果盒，第 iii 个盒中有 aia_iai​ 颗糖果。

小 A 每次可以从其中一盒糖果中吃掉一颗，他想知道，要让任意两个相邻的盒子中糖的个数之和都不大于 xxx，至少得吃掉几颗糖。

输入格式

输入的第一行是两个用空格隔开的整数，代表糖果盒的个数 nnn 和给定的参数 xxx。

第二行有 nnn 个用空格隔开的整数，第 iii 个整数代表第 iii 盒糖的糖果个数 aia_iai​。

输出格式

输出一行一个整数，代表最少要吃掉的糖果的数量。

样例

样例输入 #1

3 3
2 2 2```

**样例输出 #1**

1


**样例输入 #2**

6 1
1 6 1 2 0 4```

样例输出 #2

11```

**样例输入 #3**

5 9
3 1 4 1 5```

样例输出 #3

0

AC 代码

#include <iostream>
using namespace std;

long long a[100010];

int main() {
    int n;
    long long x;
    cin >> n >> x;
    
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    
    long long eat = 0;
    for (int i = 1; i < n; i++) {
        if (a[i] + a[i+1] > x) {
            long long t = (a[i] + a[i+1]) - x;
            // 尽量从 a[i+1] 吃，如果不够再从 a[i] 吃
            if (a[i+1] >= t) {
                a[i+1] -= t;
                eat += t;
            } else {
                // a[i+1] 不够吃，全吃完，剩下的从 a[i] 吃
                eat += a[i+1];
                t -= a[i+1];
                a[i+1] = 0;
                a[i] -= t;
                eat += t;
            }
        }
    }
    
    cout << eat << endl;
    
    return 0;
}
