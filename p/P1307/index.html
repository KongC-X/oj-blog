P1307 [NOIP 2011 普及组] 数字反转

洛谷 | 入门 | C++14 | 提交时间: 2025-08-01

算法标签：模拟、字符串、2011、NOIP 普及组

题目描述

给定一个整数 $N$，请将该数各个位上数字反转得到一个新数。新数也应满足整数的常见形式，即除非给定的原数为零，否则反转后得到的新数的最高位数字不应为零（参见样例 2）。

输出格式

一个整数，表示反转后的新数。

样例

样例输入 #1

123```

**样例输出 #1**

321```

样例输入 #2

-380```

**样例输出 #2**

-83```

AC 代码

#include <iostream>
using namespace std;
int numa,numb;//全局变量自动赋值为0 
int main()
{
    cin>>numa;  
    while(numa!=0)
    {
        numb=numb*10+numa%10;
        numa/=10; 
    }
    //将numb原来的数进位，将numa最后一位+进numb,再丢掉此数。当numa为0时停止  
    cout<<numb;//输出，反转后0会被自动处理 
    return 0; 
}
