1697 - 请输出n~1之间所有的整数

题目描述

从键盘读入一个整数 nnn ，请输出 n∼1n \sim 1n∼1 之间所有的整数，每行输出 111 个。

比如，假设读入 n=5n=5n=5 ，输出结果如下：

555

444

333

222

111

输入

一个整数 nnn 。

输出

输出 n∼1n \sim 1n∼1 之间所有的数，每行 111 个。

AC代码

#include <iostream>
using namespace std;

int main(){
    //i用来循环，n用来表示最大数 
    int i,n;
    cin>>n;
    
    //n~1的循环 
    //1、初始值 
    i = n; 
    
    //2、循环条件 
    while(i >= 1){
        cout<<i<<endl;
        //3、让循环停止的方式 
        i = i - 1;
    } 
}
