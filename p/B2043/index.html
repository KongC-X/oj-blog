B2043 判断能否被 3，5，7 整除

洛谷 | 入门 | C++14 | 提交时间: 2026-06-27

题目描述

给定一个整数 $x$，判断它能否被 $3$，$5$，$7$ 整除，并输出以下信息：

1、能同时被 $3,5,7$ 整除（直接输出 3 5 7，每个数中间一个空格）；

2、只能被其中两个数整除（按从小到大的顺序输出两个数，例如：3 5 或者 3 7 或者 5 7，中间用空格分隔）；

3、只能被其中一个数整除（输出这个除数）；

4、不能被任何数整除，输出小写字符 n。

输入格式

输入一行，包括一个整数 $x$。

输出格式

输出一行，按照描述要求给出整数被 $3$，$5$，$7$ 整除的情况。

样例

样例输入 #1

105```

**样例输出 #1**

3 5 7```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int x;                         // x: 待判断的整数
    cin >> x;

    // 思路：依次判断 x 能否被 3、5、7 整除，根据整除的个数输出对应结果。
    // 由于输出需要按 3、5、7 的顺序从小到大，所以用三个 if 分别判断，
    // 并用 cnt 统计整除的个数，用数组或直接判断来控制输出格式。
    
    int cnt = 0;                   // 记录能被整除的数的个数
    if (x % 3 == 0) cnt++;
    if (x % 5 == 0) cnt++;
    if (x % 7 == 0) cnt++;

    if (cnt == 0) {                // 不能被任何数整除
        cout << 'n' << '\n';
    } else if (cnt == 1) {        // 只能被其中一个数整除
        if (x % 3 == 0) cout << 3 << '\n';
        else if (x % 5 == 0) cout << 5 << '\n';
        else if (x % 7 == 0) cout << 7 << '\n';
    } else if (cnt == 2) {        // 只能被其中两个数整除
        if (x % 3 == 0 && x % 5 == 0) cout << "3 5" << '\n';
        else if (x % 3 == 0 && x % 7 == 0) cout << "3 7" << '\n';
        else if (x % 5 == 0 && x % 7 == 0) cout << "5 7" << '\n';
    } else {                       // cnt == 3，同时被三个数整除
        cout << "3 5 7" << '\n';
    }

    return 0;
}
