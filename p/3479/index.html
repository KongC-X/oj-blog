3479 - 小杨做题

题目描述

为了准备考试 ，小杨每天都要做题 。第 111 天 ，小杨做了 aaa 道题 ；第 222 天 ，小杨做了 bbb 道题 ；从第 333 天起 ，小杨每天做的题目数量是前两天的总和。

此外 ，小杨还规定 ，当自己某⼀天做了大于或等于 mmm 题时 ，接下来的所有日子里 ，他就再也不做题了。

请问 ，到了第 NNN 天 ，小杨总共做了多少题呢？

输入

总共 444 行 。第一行⼀个整数 aaa ，第二行⼀个整数 bbb ，第三行⼀个整数 mmm ，第四行⼀个整数 NNN。

输出

一行⼀个整数 ，表示小杨 NNN 天里总共做了多少题目 。

AC代码

AC代码

#include <iostream>
using namespace std;

int main(){
    int a,b,m,n,sum=0,i,c;
    cin>>a>>b>>m>>n;
    sum = a + b;
    for(i = 3;i <= n;i++){
        c = a + b;
        a = b;
        b = c;
        sum += c;
        if(c >= m) break;
    }
    cout<<sum<<endl;
    return 0;
}
