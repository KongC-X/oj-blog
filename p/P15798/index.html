P15798 [GESP202603 五级] 有限不循环小数

洛谷 | 普及- | C++14 | 提交时间: 2026-03-18

算法标签：数论、2026、GESP

题目描述

若 1a\frac{1}{a}a1​ 可化为一个有限的，不循环的小数，则称 aaa 为终止数。

请你求出在 LLL 到 RRR 中终止数的数量。

输入格式

输入一行，包含两个整数 L,RL,RL,R。

输出格式

输出一行，包含一个整数，表示 LLL 到 RRR 中终止数的数量。

样例

样例输入 #1

2 11```

**样例输出 #1**

5```

AC 代码

#include <iostream>
using namespace std;

// 一个分数1/a可化为有限小数的充要条件是a的质因子只包含2和5。
// 因此只需判断区间[L,R]内的每个数，将其中的因子2和5全部除去，若剩余为1，则该数为终止数。
int main() {
    int l, r;
    cin >> l >> r;
    int ans = 0;
    for (int i = l; i <= r; ++i) {
        int t = i;
        while (t % 2 == 0) {
            t /= 2;
        }
        while (t % 5 == 0) {
            t /= 5;
        }
        if (t == 1) ans++;
    }
    cout << ans << endl;
    return 0;
}
