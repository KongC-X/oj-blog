B3673 [语言月赛202210] 垃圾分类

洛谷 | 入门 | C++14 | 提交时间: 2026-08-28

算法标签：2022、O2优化、数组、语言月赛

题目描述

2077 年，由于资源几近枯竭，梦之城推行了一套极其严格的垃圾分类制度。具体的，梦之城将垃圾分为 nnn 类，每一类垃圾只能被放入特定的垃圾桶中。由于梦之城掌握了压缩技术，因此在这里垃圾只有数量之分，没有体积大小之分。

你是梦之城的一位居民。在你居住的社区外有 n+1n + 1n+1 个垃圾桶，标号为 1,2,⋯ ,n,n+11, 2, \cdots, n, n + 11,2,⋯,n,n+1。

对前 nnn 个垃圾桶，它们只能接受对应标号的垃圾，并且有一定的容量。具体的，你会得到一个长度为 nnn 的序列 r1,⋯ ,rnr _ 1, \cdots, r _ nr1​,⋯,rn​。第 iii 个垃圾桶只能接受第 iii 类垃圾，且最多只能被放入 rir _ iri​ 个。

对最后一个垃圾桶，它可以接受所有种类的垃圾，容量也是几近无限的。但是，每向这个垃圾桶放入一个垃圾，居委会会向你收取 ccc 的费用。

某一天，你的家中堆放满了垃圾。在将这些垃圾分类好后，你得到了一个长度为 nnn 的序列 a1,⋯ ,ana _ 1, \cdots, a _ na1​,⋯,an​，代表第 iii 类垃圾有 aia _ iai​ 个。

你想要知道，如果想要扔掉所有的这些垃圾，你的最小花费是多少。

输入格式

共三行。

第一行两个整数 n,cn, cn,c，代表垃圾的种类数和向最后一个垃圾桶放入垃圾的费用。

第二行 nnn 个整数 r1,⋯ ,rnr _ 1, \cdots, r _ nr1​,⋯,rn​，代表垃圾桶的容量。

第三行 nnn 个整数 a1,⋯ ,ana _ 1, \cdots, a _ na1​,⋯,an​，代表每一类垃圾的数量。

输出格式

一行一个整数，代表最小花费。

样例

样例输入 #1

2 7
4 3
7 9```

**样例输出 #1**

63```

样例输入 #2

2 10000
100 100
3 7```

**样例输出 #2**

0```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3673 [语言月赛202210] 垃圾分类
     * 题意：第 i 类垃圾有 a[i] 个，专用桶容量 r[i]，
     *       超出的部分只能放入通用桶，每个费用 c，求最小花费。
     * 思路：总花费 = c * Σ max(0, a[i] - r[i])
     */
    long long n, c;
    cin >> n >> c;
    long long r[1000005], a[1000005];
    for (int i = 0; i < n; i++) cin >> r[i];
    for (int i = 0; i < n; i++) cin >> a[i];

    long long total = 0;
    for (int i = 0; i < n; i++) {
        if (a[i] > r[i]) total += a[i] - r[i];
    }
    cout << total * c << endl;
    return 0;
}
