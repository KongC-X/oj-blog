B2014 与圆相关的计算

洛谷 | 入门 | C++14 | 提交时间: 2026-06-23

题目描述

给出圆的半径，求圆的直径、周长和面积。输入圆的半径实数 rrr，输出圆的直径、周长、面积，每个数保留小数点后 444 位。圆周率取值为 3.141593.141593.14159。

输入格式

输入包含一个实数 rrr（0<r≤100000<r \le 100000<r≤10000），表示圆的半径。

输出格式

输出一行，包含三个数，分别表示圆的直径、周长、面积，数与数之间以一个空格分开，每个数保留小数点后 444 位。

样例

样例输入 #1

3.0```

**样例输出 #1**

6.0000 18.8495 28.2743```

AC 代码

#include<bits/stdc++.h>
using namespace std;
int main(){
    double r,d,c,s,pi=3.14159;
    cin>>r;
    d=2*r;
    c=2*r*pi;
    s=pi*r*r;
    printf("%.4f %.4f %.4f",d,c,s);
    return 0;
}
