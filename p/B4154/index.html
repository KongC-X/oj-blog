B4154 [厦门小学生 C++ 2023] 计算器

洛谷 | 入门 | C++14 | 提交时间: 2026-07-16

算法标签：2023、福建、分支结构、科创活动、小学活动

题目背景

本试题为 2023 年厦门市小学生 C++ 语言复赛试题，数据为洛谷自造。

初赛为笔试。

题目描述

项目式学习能够促进学生更早和更深入的面对和解决现实生活中的问题，学生们初学 C++ 编程，老师设计了一个项目，让学生模拟实现一个最简单的计算器，支持 +, -, *, / 四种运算。

仅需考虑输入输出为整数的情况，输入和输出数据保证在 int 范围，且除法运算的时候，除数保证不为零，且肯定能整除。

输入格式

输入只有一行，共有三个整数 $a,b,c$，两两间以空格间隔，其中 $c$ 为 $1,2,3,4$ 四个整数之一（$1$ 代表加法运算，$2$ 代表减法运算，$3$ 代表乘法运算，$4$ 代表除法运算）。

输出格式

输出只有一行，一个整数，为对应的运算结果。

样例

样例输入 #1

4 2 4```

**样例输出 #1**

2```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b, c;                   // a,b: 操作数, c: 运算类型（1+,2-,3*,4/）
    cin >> a >> b >> c;

    if (c == 1) cout << a + b << endl;
    else if (c == 2) cout << a - b << endl;
    else if (c == 3) cout << a * b << endl;
    else if (c == 4) cout << a / b << endl;   // 题目保证整除且除数不为0

    return 0;
}
