B3621 枚举元组

洛谷 | 普及- | C++14 | 提交时间: 2026-10-09

算法标签：深度优先搜索 DFS、进制

题目描述

$n$ 元组是指由 $n$ 个元素组成的序列。例如 $(1,1,2)$ 是一个三元组、$(233,254,277,123)$ 是一个四元组。

给定 $n$ 和 $k$，请按字典序输出全体 $n$ 元组，其中元组内的元素是在 $[1, k]$ 之间的整数。

「字典序」是指：优先按照第一个元素从小到大的顺序，若第一个元素相同，则按第二个元素从小到大……依此类推。详情参考样例数据。

输入格式

仅一行，两个正整数 $n, k$。

输出格式

若干行，每行表示一个元组。元组内的元素用空格隔开。

2 3```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int n, k;          // n: 元组长度, k: 元素取值范围 1~k
int a[10];         // a: 存储当前正在构造的元组

/*
 * 深度优先搜索，按字典序生成所有 n 元组。
 * pos 表示当前正在填充的位置（从 0 开始）。
 * 当 pos == n 时，说明一个完整的元组已经填好，输出它。
 * 否则，从 1 到 k 依次尝试填入 a[pos]，然后递归填充下一个位置。
 * 因为循环是从小到大，所以自然满足字典序。
 */
void dfs(int pos) {
    if (pos == n) {
        // 输出当前元组
        for (int i = 0; i < n; i++) {
            cout << a[i] << ' ';
        }
        cout << endl;
        return;
    }
    // 从 1 到 k 枚举当前位置的数字
    for (int i = 1; i <= k; i++) {
        a[pos] = i;
        dfs(pos + 1);   // 递归填下一个位置
    }
}

int main() {
    cin >> n >> k;
    dfs(0);   // 从第 0 个位置开始填充
    return 0;
}
