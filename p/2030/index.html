2030 - 信息传递 [NOIP2015 提高组]

题目描述

有 nnn 个同学（编号为 111 到 nnn ）正在玩一个信息传递的游戏。在游戏里每人都有一个固定的信息传递对象，其中，编号为 iii 的同学的信息传递对象是编号为 TiT_iTi​ 的同学。

游戏开始时，每人都只知道自己的生日。之后每一轮中，所有人会同时将自己当前所知的生日信息告诉各自的信息传递对象（注意：可能有人可以从若干人那里获取信息， 但是每人只会把信息告诉一个人，即自己的信息传递对象）。当有人从别人口中得知自己的生日时，游戏结束。请问该游戏一共可以进行几轮？

输入

共222行。

第111行包含1个正整数 nnn ，表示 nnn 个人。

第222行包含 nnn 个用空格隔开的正整数 T1,T2,⋯⋯ ,TnT_1,T_2,\cdots\cdots,T_nT1​,T2​,⋯⋯,Tn​ ，其中第 iii 个整数 TiT_iTi​ 表示编号为 iii 的同学的信息传递对象是编号为 TiT_iTi​ 的同学， Ti≤nT_i \leq nTi​≤n 且 Ti≠iT_i \neq iTi​=i 。

数据保证游戏一定会结束。

输出

111 个整数，表示游戏一共可以进行多少轮。

AC代码

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200010;         // n 最大 200000，多开10个
int fa[MAXN];                    // 并查集父节点
int d[MAXN];                     // d[x] 表示 x 到其根节点的距离
int ans = MAXN;                  // 最小环的长度，初始设一个大数

/*
  带权并查集的查找：找到 x 的根，同时更新 d[x] 为到根的距离。
*/
int find(int x) {
    if (fa[x] != x) {
        int root = find(fa[x]);  // 递归找根
        d[x] += d[fa[x]];        // 将父节点到根的距离加上去
        fa[x] = root;            // 路径压缩
    }
    return fa[x];
}

/*
  合并 x 和 y，并指定 x 指向 y（即有一条 x -> y 的边）。
  如果 x 和 y 已经在同一个集合，说明形成了环，更新最小环长。
*/
void merge(int x, int y) {
    int fx = find(x);
    int fy = find(y);
    if (fx != fy) {
        // 将 fx 接到 fy 上，并设置 fx 到 fy 的距离
        // 使得 x 到 y 的距离恰好为 1（因为 x 直接传递信息给 y）
        fa[fx] = fy;
        d[fx] = d[y] - d[x] + 1;
    } else {
        // x 和 y 已经连通，说明找到环
        int len = d[x] + d[y] + 1;   // 环长 = x到根 + 根到y + 新边(x->y)
        if (len < ans) ans = len;
    }
}

int main() {
    int n;                       // n：总人数
    cin >> n;

    // 初始化并查集：每个人是自己的根，距离为 0
    for (int i = 1; i <= n; i++) {
        fa[i] = i;
        d[i] = 0;
    }

    // 读入每个人的信息传递对象，并合并
    for (int i = 1; i <= n; i++) {
        int v;                   // i 把信息传给 v
        cin >> v;
        merge(i, v);             // 合并 i 和 v，边 i -> v
    }

    cout << ans << endl;
    return 0;
}
