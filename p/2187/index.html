2187 - 是否是完全二叉树

题目描述

棵深度为 kkk 的有 nnn 个结点的二叉树，对树中的结点按从上至下、从左到右的顺序进行编号，如果编号为 iii（1≤i≤n1≤i≤n1≤i≤n）的结点与满二叉树中编号为 iii 的结点在二叉树中的位置相同，则这棵二叉树称为完全二叉树。

**完全二叉树的特点：叶子结点只能出现在最下层和次下层，且最下层的叶子结点集中在树的左部。
**

现在根据边的连接情况判断一棵树是否是完全二叉树。

输入

第一行有 222 个整数 nnn ()和 rrr (1≤r≤n1 \le r \le n1≤r≤n), 表示结点数和树根。

接下来 n−1n-1n−1 行每行有 222 个整数 a,ba,ba,b (1≤a,b≤n1 \le a,b \le n1≤a,b≤n)表示 aaa 结点和 bbb 结点有一条边相连，如果 aaa 是 bbb 的根结点，则 bbb 是 aaa 的左子结点，如果 bbb 是 aaa 的根结点，则 aaa 是 bbb 的右子结点（数据保证是一棵树而不是一座森林)

输出

如果是完全二叉树，输出 yes ，否则输出 no。

AC代码

#include <iostream>
using namespace std;

const int N = 1050;   
int l[N], r[N];      
bool vis[N];         
int n, root;   
int ma = -1;    

void dfs(int x, int id) {
    vis[x] = 1;          // 标记当前结点已访问
    if (id > ma) ma = id;   // 更新最大编号

    // 如果有左孩子且没访问过，递归左子树
    if (l[x] != 0 && !vis[l[x]]) {
        dfs(l[x], 2 * id);  
    }

    // 如果有右孩子且没访问过，递归右子树
    if (r[x] != 0 && !vis[r[x]]) {
        dfs(r[x], 2 * id + 1);
    }
}

int main() {
    cin >> n >> root;

    for (int i = 1; i <= n - 1; i++){
        int x, y;
        cin >> x >> y;

        l[x] = y; 
        r[y] = x;  
    }

    dfs(root, 1); 

    if (ma == n) cout << "yes" << endl;
    else cout << "no" << endl;
    return 0;
}
