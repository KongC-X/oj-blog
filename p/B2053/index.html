B2053 求一元二次方程

洛谷 | 入门 | C++14 | 提交时间: 2026-06-27

算法标签：数学、分支结构

题目描述

利用公式 :

$$x_1=\frac{-b+\sqrt{b^2-4ac}}{2a} , x_2=\frac{-b-\sqrt{b^2-4ac}}{2a}$$

求一元二次方程 $ax^2+bx+c=0$ 的根，其中 $a$ 不等于 $0$。结果要求精确到小数点后 $5$ 位。

输入格式

输入一行，包含三个浮点数 $a,b,c$（它们之间以一个空格分开），分别表示方程 $ax^2+bx+c=0$ 的系数。

输出格式

输出一行，表示方程的解。

若两个实根相等，则输出形式为：x1=x2=aaaa；

若两个实根不等，在满足根小者在前的原则，则输出形式为：x1=aaaa;x2=bbbb；

若无实根输出 No answer!。

所有输出部分要求精确到小数点后 $5$ 位，数字、符号之间没有空格。

样例

样例输入 #1

-15.97 19.69 12.02```

**样例输出 #1**

x1=-0.44781;x2=1.68075```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    double a, b, c;               // 方程系数
    cin >> a >> b >> c;

    double d = b * b - 4 * a * c; // 判别式

    if (d < 0) {
        cout << "No answer!" << endl;
    } else if (d == 0) {          // 两个相等实根
        double x = -b / (2 * a);
        cout << "x1=x2=" << fixed << setprecision(5) << x << endl;
    } else {                      // 两个不等实根
        double x1 = (-b + sqrt(d)) / (2 * a);
        double x2 = (-b - sqrt(d)) / (2 * a);
        if (x1 > x2) {            // 保证小根在前
            double t = x1;
            x1 = x2;
            x2 = t;
        }
        cout << "x1=" << fixed << setprecision(5) << x1 << ";x2=" << x2 << endl;
    }

    return 0;
}
