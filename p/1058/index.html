1058 - 求出100至999范围内的所有水仙花数。

题目描述

所谓水仙花数，就是指各位数字立方之和等于该数的数；a3a^3a3 称为 aaa 的立方，即等于 a×a×aa \times a \times aa×a×a 的值。

例如：因为 153=13+53+33153=1^3+5^3+3^3153=13+53+33 ，所以 153153153 是一个水仙花数。

输入

无

输出

若干行，每行一个整数，表示该范围内的所有水仙花数。

按从小到大的顺序输出。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int i = 100,a,b,c;
    while(i < 1000) {
        a = i / 100;
        b = i % 100 / 10;
        c = i % 10;
        if(a * a * a + b * b * b + c * c * c == i) {
            cout << i << endl;
        }
        i++;
    }
}
