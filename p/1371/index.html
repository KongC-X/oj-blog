1371 均分纸牌

1371 - 均分纸牌

题目描述

有 nnn 堆纸牌（2≤n≤2002≤n≤2002≤n≤200），排成一行，编号分别为 1,2,…,n1,2,\dots,n1,2,…,n 。

已知每堆纸牌有一定的张数，且张数之和均为 nnn 的倍数。移动各堆中的任意张纸牌，使每堆的数量达到相同，且移动次数最少。

移动规则：

每次可以移动任意的张数，第 111 堆可以移向第 222 堆，第 222 堆可以移向第 111 堆或第 333 堆，…\dots…， 第 nnn 堆只可以移向第 n−1n-1n−1 堆。

例如，当 n=4n=4n=4 时：

`堆号      1     2     3     4 
张数      3     5     4     8
`

移动的方法有许多种， 其中的一种方案：

① 第 222 堆向第 111 堆移动 222 张，成为：555 333 444 888。

② 第 444 堆向第 333 堆移动 333 张，成为：555 333 777 555。

③ 第 333 堆向第 222 堆移动 222 张，成为：555 555 555 555。

经过三次移动，每堆都成为 555 张。

输入

第一行一个整数 nnn 。

第二行 nnn 个整数，用空格分隔。

输出

一个整数（表示最少移动次数）。

AC代码

AC代码

#include<iostream>
using namespace std;
int n,a[105],sum=0,ave,ans=0;
int main()
{
  cin>>n;
  for(int i=1; i<=n; i++) { cin>>a[i]; sum+=a[i]; } //读入数据，计算总和
  ave=sum/n; //计算平均值
  for(int i=1; i<=n-1; i++)
  {
    if(a[i]==ave) continue; //如果已经等于平均值，就跳过不处理。
    ans++; //否则需要处理，答案+1
    if(a[i]>ave) //大于平均值
    {
      a[i+1]=a[i+1]+(a[i]-ave); //将多余牌放到第i+1堆上
      a[i]=ave; //当前牌堆数变为平均值
    }
    if(a[i]<ave) //小于平均值
    {
      a[i+1]=a[i+1]-(ave-a[i]); //这里不解释了，同上
      a[i]=ave;
    }
  }
  cout<<ans<<endl; //最后输出最少移动次数
  return 0;
} //结束
