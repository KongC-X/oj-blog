B4064 [GESP202412 二级] 寻找数字

洛谷 | 入门 | C++14 | 提交时间: 2024-12-10

算法标签：数学、2024、循环结构、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1166

题目描述

小杨有一个正整数 $a$，小杨想知道是否存在一个正整数 $b$ 满足 $a=b^4$。

输入格式

第一行包含一个正整数 $t$，代表测试数据组数。

对于每组测试数据，第一行包含一个正整数代表 $a$。

输出格式

对于每组测试数据，如果存在满足条件的正整数 $b$，则输出 $b$，否则输出 $-1$。

样例

样例输入 #1

3
16
81
10```

**样例输出 #1**

2
3
-1```

}
