1607 - 两位数运算

题目描述

小丽在编程课上学会了拆位运算，她已经可以拆出一个两位整数的十位和个位了，她想知道这个整数的十位 /// 个位的结果是多少，请编程帮她实现？（请注意，计算结果要保留 111 位小数）

输入

输入一个两位的正整数 nnn，且 nnn 的个位一定不为 000。

输出

输出这个两位正整数十位除以个位的计算结果，结果保留 111 位小数。

解题思路

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
#include<iomanip>
using namespace std;

int main() {
    int n,a,b;
    double c;
    cin>>n;
    a = n / 10;
    b = n % 10;
    cout << fixed << setprecision(1) << a * 1.0 / b;
}
