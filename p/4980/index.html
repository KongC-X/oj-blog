4980 - 奇偶校验

题目描述

数据在传输过程中可能出错，因此接收方收到数据后通常会校验传输的数据是否正确，奇偶校验是经典的校验方式之一。

给定 nnn 个非负整数 c1,c2,…,cnc_1, c_2, \dots, c_nc1​,c2​,…,cn​ 代表所传输的数据，它们的校验码取决于这些整数在二进制下 111 的数量之和的奇偶性。如果这些整数在二进制下共有奇数个 111 ，那么校验码为 111 ；否则校验码为 000。你能求出这些整数的校验码吗？

输入

第一行，一个正整数 nnn ，表示所传输的数据量。

第二行，nnn 个非负整数 c1,c2,…,cnc_1, c_2, \dots, c_nc1​,c2​,…,cn​，表示所传输的数据。

输出

输出一行，两个整数，以一个空格分隔：

第一个整数表示 c1,c2,…,cnc_1, c_2, \dots, c_nc1​,c2​,…,cn​ 在二进制下 111 的总数量；

第二个整数表示校验码（000 或 111）。

AC代码

AC代码

#include <iostream>
using namespace std;

int countOnes(int num) {
    int count = 0;
    while (num > 0) {
        if (num % 2 == 1) {
            count++;
        }
        num /= 2;
    }
    return count;
}

int main() {
    int n;
    cin >> n;
    int total = 0;
    for (int i = 0; i < n; i++) {
        int num;
        cin >> num;
        total += countOnes(num);
    }
    cout << total << " " << (total % 2) << endl;
    return 0;
}
