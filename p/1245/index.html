1245 - 求s=a+aa+aaa+aaaa+aa...a的值

题目描述

求 s=a+aa+aaa+aaaa+aa…as=a+aa+aaa+aaaa+aa \dots as=a+aa+aaa+aaaa+aa…a 的值，其中 aaa 从键盘读入。比如：读入 222 ，则 s=2+22=24s=2+22=24s=2+22=24 。再比如：读入 555 ， s=5+55+555+5555+55555=61725s=5+55+555+5555+55555=61725s=5+55+555+5555+55555=61725

输入

一个整数 aaa （ aaa 在 1∼91 \sim 91∼9 的范围内）

输出

整数 nnn 代表这个算式的结果

解题思路

AC代码

AC代码

#include<iostream>
using namespace std;

int main() {
    int a,s = 0,n;
    cin>>a;
    //因为程序中要修改a的值，因此要先存下来
    //否则循环次数也会被修改掉 
    n = a; 
    //有a个数要求和
    for(int i = 1;i <= n;i++){
        s = s + a;
        a = a * 10 + n;
    } 
    
    cout<<s;
    return 0;
}
