P10722 [GESP202406 六级] 二叉树

洛谷 | 普及| C++14 | 提交时间: 2026-05-14

算法标签：树形数据结构、2024、图遍历、树的遍历、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1154

题目描述

小杨有一棵包含 nnn 个节点的二叉树，且根节点的编号为 111。这棵二叉树任意一个节点要么是白色，要么是黑色。之后小杨会对这棵二叉树进行 qqq 次操作，每次小杨会选择一个节点，将以这个节点为根的子树内所有节点的颜色反转，即黑色变成白色，白色变成黑色。

小杨想知道 qqq 次操作全部完成之后每个节点的颜色。

输入格式

第一行一个正整数 nnn，表示二叉树的节点数量。

第二行 (n−1)(n-1)(n−1) 个正整数，第 iii（1≤i≤n−11\le i\le n-11≤i≤n−1）个数表示编号为 (i+1)(i+1)(i+1) 的节点的父亲节点编号，数据保证是一棵二叉树。

第三行一个长度为 nnn 的 01\texttt{01}01 串，从左到右第 iii（1≤i≤n1\le i\le n1≤i≤n）位如果为 0\texttt{0}0，表示编号为 iii 的节点颜色为白色，否则为黑色。

第四行一个正整数 qqq，表示操作次数。

接下来 qqq 行每行一个正整数 aia_iai​（1≤ai≤n1\le a_i\le n1≤ai​≤n），表示第 iii 次操作选择的节点编号。

输出格式

输出一行一个长度为 nnn 的 01\texttt{01}01 串，表示 qqq 次操作全部完成之后每个节点的颜色。从左到右第 iii（1≤i≤n1\le i\le n1≤i≤n） 位如果为 0\texttt{0}0，表示编号为 iii 的节点颜色为白色，否则为黑色。

样例

样例输入 #1

6
3 1 1 3 4
100101
3
1
3
2```

**样例输出 #1**

010000```

AC 代码

#include <iostream>
#include <string>
using namespace std;

// 给定一棵树，每个节点可以进行翻转操作。翻转操作会影响节点及其所有子节点的状态。
// 题目要求我们根据给定的翻转操作序列，输出每个节点最终的状态。
// 本题的关键在于理解树结构中翻转操作的传递性：一旦父节点翻转，其所有子节点也会随之翻转。
// 我们便可得到公式：每个结点翻的次数=父节点翻的次数+本身翻的次数。
// 这使得问题可以通过递归的方式来解决。

int n, q;
int p[100005];  // p[i] = 节点i的父节点编号，p[1]=0
int a[100005];  // a[i] = 节点i被直接选中的次数（操作次数）
int b[100005];  // b[i] = 节点i总共被翻转的次数
string s;       // 初始颜色字符串

/*
 * 功能：递归计算节点x的总翻转次数
 * 公式：b[x] = a[x] + b[p[x]]
 *       即：自己操作的次数 + 父节点传递下来的次数
 * 记忆化：b[x] > 0 表示已计算过，直接返回
 * 这其实是一个自顶向下 + 记忆化的递归：
 * 从某个节点出发，沿父指针一路向上，直到遇到已计算的节点
 * 回溯时逐层累加 a[i] 的值
 * 记忆化防止重复计算
 * 注意：这里的父指针 p[i] 在输入时已经给出了，所以不需要建树！
 */
int dfs(int x){
    if (b[x] > 0) return b[x];           // 记忆化，避免重复计算
    b[x] = a[x] + dfs(p[x]);             // 核心递推公式
    return b[x];
}

int main(){
    // 1. 读入二叉树结构
    cin >> n;
    for (int i = 2; i <= n; i++)
        cin >> p[i];       // 读入节点i的父亲
    
    // 2. 读入初始颜色
    cin >> s;
    
    // 3. 读入操作次数并统计每个节点被操作的次数
    cin >> q;
    for (int i = 1; i <= q; i++){
        int op;
        cin >> op;
        a[op]++;           // 节点op被选中一次
    }
    
    // 因为根节点没有父节点，递归公式 b[i] = a[i] + b[p[i]] 到根节点时，b[p[1]] 是未定义的。
    // 4. 预处理根节点：加2（偶数）不影响奇偶性，最终判断颜色时 b[i] % 2 的结果不变，
    // 并且保证b[1]>0，递归的 if(b[x] > 0) return b[x]; 能正常终止
    b[1] = a[1] + 2;
    
    // 5. 对每个未计算的节点递归求解
    for (int i = 1; i <= n; i++)
        if (!b[i])         // b[i] == 0 表示还没算
            dfs(i);
    
    // 6. 根据总翻转次数的奇偶性输出最终颜色
    for (int i = 0; i < n; i++){
        int col = s[i] - '0';        // 初始颜色 0或1
        if (b[i + 1] % 2 == 0)       // 偶数次翻转，颜色不变
            cout << col;
        else                         // 奇数次翻转，颜色取反
            cout << !col;
    }
    cout << endl;
    
    return 0;
}
