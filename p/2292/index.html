2292 - 计算乘积

题目描述

给定两个数 a，ba，ba，b，计算它们的乘积。

输入

一行两个整数 a、ba、ba、b，以空格分隔。（ 0<a0 \lt a0<a , b<10b \lt 10b<108）。

输出

输出一个整数，表示 a、ba、ba、b 的乘积

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int main(){
    long long a,b;
    cin>>a>>b;
    cout<<a*b;
    return 0;
}
