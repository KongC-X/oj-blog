P2926 [USACO08DEC] Patting Heads S

洛谷 | 普及| C++14 | 提交时间: 2026-05-22

算法标签：数学、2008、USACO、素数判断

题目描述

It's Bessie's birthday and time for party games! Bessie has instructed the NNN (1≤N≤1051 \le N \le 10^51≤N≤105) cows conveniently numbered 1⋯N1\cdots N1⋯N to sit in a circle (so that cow iii [except at the ends] sits next to cows i−1i-1i−1 and i+1i+1i+1; cow NNN sits next to cow 111). Meanwhile, Farmer John fills a barrel with one billion slips of paper, each containing some integer in the range 1∼1061 \sim 10^61∼106.

Each cow i then draws a number AiA_iAi​ (1≤Ai≤1061 \le A_i \le 10^61≤Ai​≤106) (which is not necessarily unique, of course) from the giant barrel. Taking turns, each cow iii then takes a walk around the circle and pats the heads of all other cows jjj such that her number AiA_iAi​ is exactly divisible by cow jjj's number AjA_jAj​; she then sits again back in her original position.

The cows would like you to help them determine, for each cow, the number of other cows she should pat.

输入格式

  • Line 1: A single integer: NNN

  • Lines 2∼N+12\sim N+12∼N+1: Line i+1i+1i+1 contains a single integer: AiA_iAi​

输出格式

  • Lines 1∼N1\sim N1∼N: On line iii, print a single integer that is the number of other cows patted by cow iii.

样例

样例输入 #1

5 
2 
1 
2 
3 
4

样例输出 #1

2 
0 
2 
1 
3

AC 代码

#include <iostream>
using namespace std;

const int MAXA = 1000000;    // A_i 的最大值
int cnt[MAXA + 5];           // cnt[x] 表示数字 x 出现的次数
int ans[MAXA + 5];           // ans[x] 表示对于拥有数字 x 的奶牛，能整除它的其他奶牛数量（含自身）
int a[100005];               // 记录每头奶牛的 A_i

int main() {
    // ---------- 思路 ----------
    // 问题转化：奶牛 i 的数字为 A_i，她要找所有其他奶牛 j 使得 A_i % A_j == 0。
    // 即找 A_i 的因子在其他奶牛中出现的总次数。
    //
    // 方法：
    // 1. 统计每个数字出现的次数（cnt 数组）。
    // 2. 枚举所有可能的数字 x (1~MAXA)，如果 cnt[x] > 0，
    //    把 x 的贡献 cnt[x] 加到它的所有倍数 y = x, 2x, 3x... 的 ans[y] 上。
    //    这样 ans[y] 就得到了 y 的所有因子数字的出现次数之和。
    // 3. 对于每头奶牛 i，答案就是 ans[A_i] - 1（减去自己）。
    // 时间复杂度 O(MAXA * (1/1+1/2+...+1/MAXA)) ≈ O(MAXA log MAXA)，可行。
    // -------------------------

    int n;
    cin >> n;
    int max_val = 0;          // 记录出现过的最大数字，以缩小枚举范围

    for (int i = 1; i <= n; ++i) {
        cin >> a[i];
        cnt[a[i]]++;
        if (a[i] > max_val) max_val = a[i];
    }

    // 枚举每一个作为因子的数字 x
    for (int x = 1; x <= max_val; ++x) {
        if (cnt[x] == 0) continue;        // 没有这个数字就不用枚举它的倍数
        // 遍历 x 的所有倍数 y
        for (int y = x; y <= max_val; y += x) {
            ans[y] += cnt[x];             // 数字 x 出现的次数对它的倍数 y 做贡献
        }
    }

    // 输出每头奶牛的答案
    for (int i = 1; i <= n; ++i) {
        // ans[a[i]] 包含了奶牛 i 自己，所以要减 1
        cout << ans[a[i]] - 1 << "\n";
    }

    return 0;
}
