B2122 单词翻转

洛谷 | 入门 | C++14 | 提交时间: 2026-07-12

算法标签：字符串（入门）

题目描述

小明同学写单词的时候喜欢反着写，比如 hello 他会写成 olleh。给出小明同学写的一个句子，请你将所有的单词复原。

输入格式

共一行，一个字符串表示句子，单词之间以空格分隔。

样例

样例输入 #1

olleh dlrow```

**样例输出 #1**

hello
world```

AC 代码

#include<bits/stdc++.h>
using namespace std;
int main(){
    string s;
    while(cin >> s){
        reverse(s.begin(), s.end());
        cout << s << endl;
    }
    
    return 0;
}
