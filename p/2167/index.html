2167 - 树的公共祖先（LCA）

题目描述

给定一棵树和两个不同的结点，求出他们最近的公共祖先父结点。

已知该树有 nnn 个结点，标号 1..n1..n1..n 。

输入

第 111 行输入一个整数 nnn，代表结点数量（n≤100n≤100n≤100）；

第 222 行输入两个整数 x,yx,yx,y，表示需要计算的结点；

以下 n−1n-1n−1 行，每行两个整数 aaa 和 bbb，表示 aaa 的父结点是 bbb。

输出

输出 xxx 与 yyy 的最近公共祖先 rootrootroot。

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 解法一：先标记x到根的每个点，在从y向上找到第一个被标记的点

const int N = 110;
int fa[N];//父子关系 
bool vis[N];//标记哪些点访问过  
int n;
 
int main(){
    cin>>n;
    //将每个元素的父先标记为自己，认为这是一个不可能的值 
    for(int i = 1;i <= n;i++) fa[i] = i; 
    
    int x,y,a,b; 
    cin>>x>>y;//求xy的最近公共祖先 
    for(int i = 1;i <= n - 1;i++){
        cin>>a>>b;
        fa[a] = b;//a的父是b 
    }
    
    //从x出发，将x到根的所有点，标记
    vis[x] = true;//标记出发点,因为如果x就是y的祖先，那么y就会直接找到x，所以x也要标记
    while(fa[x] != x){
        x = fa[x];
        vis[x] = true; 
    }
    
    //从y点向上，找到第1个被标记的点，就是最近的公共祖先
    while(!vis[y]) {
        y = fa[y];
    }
    
    cout<<y;  
    return 0;
}
