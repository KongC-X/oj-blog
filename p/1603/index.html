1603 - 冷饮的价格

题目描述

暑假来了，天气特别热，花花到冷饮店来买冷饮；已知雪糕 $2.5$ 元 $/$ 支，碎碎冰 $1.5$ 元 $/$ 支，花花买了 $x$ 支雪糕和 $y$ 支碎碎冰，老板说今天有优惠，可以有 $1$ 支雪糕免费，请问花花应该付给老板多少钱？

注意：花花至少会买一支雪糕

输入

两个整数 $x$ 和 $y$ ，分别代表了雪糕和碎碎冰的购买数量。

输出

一个小数，代表了花花应付给老板的金额（结果保留 $1$ 位小数）。

解题思路

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
#include<iomanip>
using namespace std;

int main() {
    int x,y;
    double s;
    cin >> x >> y;
    s = 2.5 * x + 1.5 * y - 2.5;
    printf("%.1f",s);
}
