1274 - 求各个科目成绩的平均分

题目描述

请从键盘读入一个整数 nnn（n≤100n \le 100n≤100），代表一个班级同学的人数，然后读入 nnn 个人的语文、数学、英语成绩。

请求出这 nnn 个人的语文、数学、英语三科成绩的平均分分别是多少，结果保留 111 位小数。

输入

第 111 行：一个整数 nnn ，代表班级的人数。

第 222 行~第 n+1n+1n+1 行，输入 nnn 个同学的语文、数学、英语成绩，每行输入一个同学的成绩，成绩用空格隔开！

输出

输出语文、数学、英语三科的平均成绩，分别用空格隔开，平均成绩保留 111 位小数！

解题思路

AC代码

AC代码

#include<iostream>
using namespace std;

int main()
{
    int n, i, a[110][3], chinese = 0, math = 0, english = 0;
    cin >> n;
    for(i = 0; i < n; i++){
        cin >> a[i][0] >> a[i][1] >> a[i][2];
        chinese += a[i][0];
        math += a[i][1];
        english += a[i][2];
    }
    printf("%.1lf %.1lf %.1lf", chinese * 1.0 / n, math * 1.0 / n, english * 1.0 / n);
}
