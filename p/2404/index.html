2404 - 分组

题目描述

A班有的体育课上来了 nnn 位男同学和 nnn 位女同学，体育老师安排大家参加一项体育活动。

该活动要求同学们分成 nnn 组，每组一位男同学，一位女同学，分组的要求是，同一组的男同学和女同学的身高差越大越好。

请你编程计算出，同学们分组后，所有小组的同学身高差值的和，最大是多少？

输入

输入的第 111 行为 111 个整数 nnn ，n≤10000n≤10000n≤10000；

第 222 行包含 nnn 个整数，表示 nnn 个男同学的身高；

第 333 行包含 nnn 个整数，表示 nnn 个女同学的身高；

男女同学的身高均是不超过 100010001000 的整数。

输出

按题意输出所有小组的同学身高差值之和的最大值。

解题思路

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    char s[300],a[300],b[300] = {'\0'};
    int i,k = 0;
    gets(s);
    for(i = 0;i < strlen(s);i++) {
        //如果s[i]不是空格，那么就是单词的一部分，存到a中
        if(s[i] != ' ') {
            a[k++] = s[i];
            // 如果当前单词结束了
            if(s[i + 1] == ' ' || s[i + 1] == '\0') {
                a[k] = '\0';
                // cout << a << endl;
                if(strlen(a) > strlen(b)) {
                    strcpy(b,a);// 将a拷贝给b
                }   
                k = 0;// 清空a字符串，存储下一个单词
            }
        }
    }
    cout << b << endl;
}
