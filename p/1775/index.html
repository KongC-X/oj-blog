1775 - 谁的孙子最多

题目描述

给定一棵树，其中 111 号结点是根结点，问哪一个结点的孙子结点最多，有多少个。（孙子结点，就是儿子结点的儿子结点。）

输入

第一行一个整数 NNN（N≤10000N≤10000N≤10000），表示树结点的个数。

此后 NNN 行，第 iii 行包含一个整数 CiC_iCi​，表示 iii 号结点儿子结点的个数，随后共 CiC_iCi​ 个整数，分别表示一个 iii 号结点的儿子结点（结点编号在 1∼N1 \sim N1∼N 之间）。

输出

一行两个整数，表示孙子结点最多的结点，以及其孙子结点的个数，如果有多个，输出编号最小的（本题测试数据确保有解）。

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

vector<int> a[100010]; 
int n,x,t;
//ma最多的孙子数，r最多的孙子结点的编号 
//c每个结点的孙子的数量 
int ma,r,c;

int main(){
    cin>>n;
    for(int i = 1;i <= n;i++){
        cin>>x;//第i个结点的子结点的数量
        for(int j = 1;j <= x;j++){
            cin>>t; // t是第i个结点的子结点
            a[i].push_back(t);
        }	
    }
    
    // 求每个结点的孙子数量，找出孙子数量最多的结点
    for(int i = 1;i <= n;i++){
        c = 0;
        for(int j = 0;j < a[i].size();j++){
            //求孙子的总数量 
            c = c + a[a[i][j]].size();
        } 
        
        if(c > ma){
            ma = c;
            r = i;
        }
    } 
    
    cout<<r<<" "<<ma;
    return 0;
}
