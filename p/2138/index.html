2138 - 乘积的约数个数

题目描述

给定 nnn 个正整数 aia_iai​，请你输出这些数的乘积的约数个数，答案对 109+710^9+7109+7 取余数。

输入

第一行包含整数 nnn。

接下来 nnn 行，每行包含一个整数 aia_iai​。

数据范围：
1≤n≤100,1≤ai≤2×1091≤n≤100, 1≤a_i≤2 \times 10^91≤n≤100,1≤ai​≤2×109

输出

输出一个整数，表示所给正整数的乘积的约数个数。

AC代码

#include<bits/stdc++.h>
using namespace std;

// 因数个数 = （a1+1）*（a2+1）*… （ai+1）
// 1.所有的数相乘，分解质因子，得到质因子及个数
// 和每个数单独分解质因子，得到质因子及个数，答案一致
// 2.两个数相加的结果%10000，和两个数分别%10000相加，再%10000，答案一致，乘法同理

// 本题思路：将每个数分解质因子，得到每个质因子出现的次数，按公式计算因数个数

long long n,x,r = 1;
map<int,int> m;
map<int,int>::iterator it;
const long long mod = 1e9+7;
int main(){
    cin>>n;
    for(int i = 1;i<=n;i++){
        cin>>x;
        for(int j = 2;j<=sqrt(x);j++){
            while(x%j == 0){
                m[j]++;
                x /= j;
            }
        }
        if(x > 1){
            m[x]++;
        }
    }
    for(it = m.begin();it != m.end();it++){
        r = r * (it->second + 1) % mod;
    }
    cout<<r<<endl;
}
