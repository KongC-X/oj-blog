B4249 [语言月赛 202503] 洗牌

洛谷 | 普及- | C++14 | 提交时间: 2026-07-29

算法标签：2025、字符串（入门）、语言月赛

题目描述

Alice 把 $2n$ 张扑克牌牌面朝下叠成一摞，并记住了从上到下每张扑克牌的种类（使用一个字符串表示）。之后，她将这摞牌交给 Bob 进行洗牌。

Bob 接过牌后，采用一种特殊的洗牌方式：

  1. 首先，他从上到下取出前 $n$ 张牌划分为左堆，剩下的 $n$ 张牌划分为右堆；
  2. 之后，他设定一个新的牌堆，并做 $2n$ 次操作。每次操作中，他随机从左堆或右堆的顶部取出一张牌，并放到新的牌堆的顶部。

虽然 Bob 费尽心思洗牌，但 Alice 依然能记住洗好的牌中每张牌是来自左堆还是右堆。她用一个字符串 $ f $（下标从 $1$ 开始）记录了这个信息，其中：

  • $ f_i = \texttt{L} $ 表示第 $ i $ 次操作选择的牌来自左堆；
  • $ f_i = \texttt{R} $ 表示第 $ i $ 次操作选择的牌来自右堆。

接下来，Bob 按顺序发牌：从洗好的牌堆顶部开始，他交替地把每张牌发给 Alice 和自己，第一张给 Alice，第二张给自己，第三张再给 Alice，以此类推。

你的任务是计算出 Alice 最终拿到的所有牌，并按她拿到牌的顺序输出。

输入格式

输入共三行。

第一行一个整数 $n$，代表扑克牌一共有 $2n$ 张。
第二行 $2n$ 个字符串，代表初始时从上到下每张扑克牌的种类。相邻字符串之间使用一个逗号隔开。
第三行一个长度为 $2n$ 的字符串 $f$，由 $\texttt{L,R}$ 组成，代表 Alice 记住的洗牌顺序。

输出格式

输出 $n$ 行，每行一个字符串，代表 Alice 拿到的所有牌。你需要按照 Alice 拿到牌的顺序从前到后输出。

AC 代码

#include <iostream>
#include <string>
using namespace std;

string a[205];        // 存放初始的 2n 张牌，下标从 0 开始
string b[205];        // 存放按照操作顺序取出的牌，b[i] 是第 i+1 次操作取的牌
int n;                // n 的含义：总牌数为 2n
string s;             // 第二行的逗号分隔字符串
string f;             // 第三行的 L/R 序列

int main() {
    // 读入数据
    cin >> n;                     // n（2n 张牌）
    cin >> s;                     // 逗号分隔的牌，没有空格，cin>> 可一次读入整行
    cin >> f;                     // 洗牌操作序列

    // 解析逗号分隔的字符串 s，将每张牌存入 a 数组
    int p = 0;                    // a 数组当前下标
    string t = "";                // 临时存放当前正在读取的一张牌
    for (int i = 0; i < s.size(); i++) {
        if (s[i] == ',') {        // 遇到逗号，表示一张牌结束
            a[p] = t;
            p++;
            t = "";               // 清空，准备读下一张
        } else {
            t += s[i];            // 普通字符加入当前牌名
        }
    }
    a[p] = t;                     // 最后一张牌（逗号后面没有逗号了）
    p++;                          // p 现在是总牌数，应等于 2n

    // 模拟洗牌过程
    int l = 0;                    // 左堆顶部在 a 中的下标，初始为 0
    int r = n;                    // 右堆顶部在 a 中的下标，初始为 n
    for (int i = 0; i < 2 * n; i++) {
        if (f[i] == 'L') {
            b[i] = a[l];
            l++;
        } else {                  // f[i] == 'R'
            b[i] = a[r];
            r++;
        }
    }

    // 最终新牌堆从上到下是 b[2n-1], b[2n-2], ..., b[0]
    // Alice 拿到从顶部开始的第 1、3、5... 张（索引 2n-1, 2n-3, 2n-5...）
    for (int i = 2 * n - 1; i >= 0; i -= 2) {
        cout << b[i] << endl;
    }

    return 0;
}
