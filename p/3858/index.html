3858 - 立方数

题目描述

小杨有一个正整数 $n$ ，他想知道 $n$ 是否是一个立方数。

一个正整数 $n$ 是立方数当且仅当存在一个正整数 $x$ 满足$ x \times x \times x=n$ 。

输入

第一行包含一个正整数 $n$。

输出

如果正整数 $n$ 是一个立方数，输出 $Yes$，否则输出 $No$。

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    bool flag = false;
    for(int i = 1; i <= n; i++) {
        if(i * i * i == n) {
            flag = true;
            break;
        }
    }
    flag ? cout << "Yes" : cout << "No";
}
