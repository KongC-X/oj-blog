3359 - 逛商场

题目描述

小明是个不太有计划的孩子。

这不，刚到手的零花钱，就全部拿着逛商场去了。小明的原则很简单，只要见到想买的物品而且能买得起，就一定会买下来之后才会继续往前走。

一天下来，小明到底买了多少物品呢？

输入

输入共 333 行：

第一行是一个整数 NNN，表示商场中共有 NNN 种小明想买的物品（1≤N≤1001≤N≤1001≤N≤100）；

第二行共有 NNN 个整数，分别表示小明先后见到想买的物品的价格；

第三行是一个整数 XXX，表示开始时小明共有 XXX 元零花钱。

输出

输出 111 行，包含一个整数，表示小明买到的物品数。

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int n,a[110],i,x,s;
int main() {
    cin >> n;
    for (i=1; i<=n; i++) cin >> a[i];
    cin >> x;
    for (i=1; i<=n; i++) {
        if(a[i] <= x) {
            s++;
            x = x - a[i];
        } 
    }
    cout << s << endl;
}
