B4462 [海淀区入门组 2025] 比赛晋级

洛谷 | 入门 | C++14 | 提交时间: 2026-07-20

算法标签：模拟、2025、北京、分支结构、循环结构、小学活动

题目描述

圣诞节的联欢活动，有一个趣味运动比赛，参加比赛的每名同学都能获得一份圣诞大礼包，同时比赛采用了一个特殊的晋级机制，能晋级到下一轮比赛的同学将获得一份额外的惊喜礼包。晋级规则为：参加本轮比赛的 nnn 名同学，编号从 111 到 nnn，第 iii 名同学本轮比赛的得分为 aia_iai​，指定一名编号为 kkk 的同学并以他的得分 aka_kak​ 为基准，满足得分不低于 aka_kak​ 且得分为正的同学将晋级到下一轮。你的任务是确定：有多少名同学能够获得晋级的额外惊喜礼包。

输入格式

第一行包含两个整数 nnn 和 kkk（1≤k≤n≤501 \leq k \leq n \leq 501≤k≤n≤50）。

第二行包含 nnn 个以空格分隔的整数 a1,a2,…,ana_1, a_2, \ldots, a_na1​,a2​,…,an​（0≤ai≤1000 \leq a_i \leq 1000≤ai​≤100），其中 aia_iai​ 是获得第 iii 名同学的得分。给定的序列是非递增的（即，对于从 111 到 n−1n-1n−1 的所有 iii，满足以下条件：ai≥ai+1a_i \geq a_{i+1}ai​≥ai+1​）。

输出格式

输出获得晋级礼包的同学数量。

样例

样例输入 #1

8 5
10 9 8 7 7 7 5 5```

**样例输出 #1**

6```

样例输入 #2

4 2
0 0 0 0```

**样例输出 #2**

0```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, k;                   // n: 参赛人数, k: 基准同学的编号（1‑based）
    cin >> n >> k;
    int a[55];                  // 存放分数，非递增排列，多开几个位置
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    int x = a[k];               // 基准分数
    int ans = 0;                // 晋级人数
    for (int i = 1; i <= n; i++) {
        if (a[i] >= x && a[i] > 0) {
            ans++;
        }
    }

    cout << ans << endl;
    return 0;
}
