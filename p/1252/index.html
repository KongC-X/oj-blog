1252 - 邮票组合

题目描述

某人有 mmm 张 333 分的邮票和 nnn 张 555 分的邮票，用这些邮票中的一张或若干张（也可以是 000 张）可以得到多少种不同的大于 000 的邮资？

请找出可能组合的邮资方案总数，并按照由小到大的顺序输出所有不重复的大于 000 的方案！（5.1.97）

如：111 张 333 分和 111 张 555 分可能的邮资组合如下

000 张 333 分 +++ 111 张 555 分 === 555 分

111 张 333 分 +++ 000 张 555 分 === 333 分

111 张 333 分 +++ 111 张 555 分 === 888 分

因此，可能的方案有 333 种，排序后的结果是：333 555 888 。

输入

两个整数，mmm 和 nnn ，分别代表了 333 分和 555 分的邮票的数量！（1≤m,n≤1001 \le m,n \le 1001≤m,n≤100）

输出

输出有两行，第一行输出这两种邮票能组合的不同的大于 000 的邮资方案，数与数之间用空格隔开。

第二行输出可能的方案总数。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

/*
由于m和n的最大值是100，按最大值算，能组合出的邮资的最大值=100*3+100*5=800
用长度为810的数组来记录不同邮资的出现
*/
int m,n,a[810],c = 0;//c表示不同方案的数量
int main() {
    cin>>m>>n;
    int x;
    //组合所有的可能
    //3分的可能范围
    for(int i = 0; i <= m; i++) {
        //5分的数量范围
        for(int j = 0; j <= n; j++) {
            x = 3 * i + 5 * j;
            if(x != 0) {
                a[x]++;
                if(a[x] == 1) c++;//统计不同方案的数量
            }
        }
    }

    //循环可能的邮资范围 
    for(int i = 1;i <= 800;i++){
        if(a[i] != 0) cout<<i<<" ";	
    }
    cout<<endl;
    cout<<c;
    return 0;
}
