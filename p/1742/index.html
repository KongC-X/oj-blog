1742 - 三位回文数

题目描述

请从小到大输出 m∼nm \sim nm∼n 之间所有的 333 位的回文数，并求出这些数有多少个。

输入

两个整数 mmm 和 nnn 用空格隔开（ ，且 mmm 和 nnn 一定都是 333 位数）。

输出

先输出 m∼nm \sim nm∼n之间所有的 333 位的回文数，每行 111个；

最后 111 行输出 333 位回文数总共有多少个；

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    int m,n,i,x=0;
    cin>>m>>n;
    //遍历所有m到n之间的三位整数 
    for(i=m;i<=n;i++){
        //判断百位和个位是否相等 
        if(i/100==i%10){
            cout<<i<<endl;
            x++;//记录符合条件的数的个数 
        }
    }
    cout<<x;
    return 0;
}
