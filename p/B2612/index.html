题目描述

给同学分苹果，若每人分 333 个就剩下 111111 个；如果每人分 444 个则少一个，请问有多少同学，有多少个苹果？

输出格式

请输出两个整数表示答案，使用空格隔开。

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】盈亏问题
     * 【核心思路】
     * 设人数为 x，苹果数为 y。
     * 根据题意：y = 3x + 11 且 y = 4x - 1
     * 解得 x = 12，y = 47。
     *
     * 【时间复杂度】O(1)
     */

    int x, y;          // x: 同学人数, y: 苹果数
    x = 12;        // 由 3x+11 = 4x-1 得 x = 12
    y = 3 * x + 11;    // 苹果数

    cout << x << " " << y << endl;   // 输出 12 47
    return 0;
}
