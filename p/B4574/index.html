B4574 [GESP202609 一级] 棋盘上的奖赏

洛谷 | 入门 | C++14 | 提交时间: 2026-09-15

算法标签：2026、循环结构、GESP

题目描述

相传古印度舍罕王为了奖赏宰相西萨发明国际象棋，西萨提的任何要求舍罕王都愿意满足。西萨只求在棋盘第 111 格放 111 粒麦子，第 222 格放 222 粒麦子，之后每一格都放前一格两倍的麦子，以此类推直到第 646464 格。国王觉得这奖赏微不足道，立刻命人取粮。

然而麦子的数量飞速增长：到第 202020 格已需上百万粒，到第 404040 格就耗尽了全国库存，而后面仍有 242424 格。最终国王发现，即便倾尽天下粮食也填不满棋盘。

聪明的你知道前 nnn 格总共需要多少粒麦子吗？

输入格式

一行，一个整数 nnn。

输出格式

一行，一个整数，表示前 nnn 格总共需要的麦子粒数。

样例

样例输入 #1

3```

**样例输出 #1**

7```

样例输入 #2

10```

**样例输出 #2**

1023```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B4574 [GESP202609 一级] 棋盘上的奖赏
     * 题意：第1格1粒，第2格2粒，第3格4粒……第n格是前一格的2倍。
     *       求前 n 格总共多少粒麦子。
     * 思路：用循环模拟每一格，依次累加。
     *       cur 表示当前格的麦子数，初始为 1。
     *       每轮把 cur 加到总和 ans 中，然后 cur 变成原来的 2 倍。
     */
    int n;                 // n: 格数
    cin >> n;

    long long ans = 0;     // ans: 总麦子数
    long long cur = 1;     // cur: 当前格的麦子数

    for (int i = 1; i <= n; i++) {
        ans += cur;        // 把当前格麦子加入总数
        cur *= 2;          // 下一格是当前格的两倍
    }

    cout << ans << endl;
    return 0;
}
