B4074 [CSP-X 2018] 统计成绩

洛谷 | 入门 | C++14 | 提交时间: 2026-08-10

算法标签：2018、山东、CSP-X 小学组

题目描述

考试结束之后，每位同学都依据成绩获得相应的等级：

  • 优秀：$90\sim 100$；
  • 良好：$80\sim 89$；
  • 及格：$60\sim79$；
  • 不及格：$60$ 以下。

现在，需要统计一下获得每个等级的人数分别是多少。

输入格式

第一行，一个正整数 $n$，表示总人数。

第二行，$n$ 个由空格隔开的整数，表示每个同学的成绩（$0\sim100$）。

输出格式

共四行，每行一个整数，依次表示获得优秀、良好、及格、不及格等级的人数。

样例

样例输入 #1

10 
93 33 86 81 47 82 84 92 73 94 ```

**样例输出 #1**

3
4
1
2```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：简单统计
     * 思路：读入 n 和每个成绩，根据分数段累加四个等级的人数。
     * 优秀：90~100
     * 良好：80~89
     * 及格：60~79
     * 不及格：0~59
     */
    int n;          // n: 总人数
    cin >> n;

    int a = 0, b = 0, c = 0, d = 0;  // a:优秀, b:良好, c:及格, d:不及格

    for (int i = 0; i < n; i++) {
        int x;      // x: 当前成绩
        cin >> x;
        if (x >= 90) a++;
        else if (x >= 80) b++;
        else if (x >= 60) c++;
        else d++;
    }

    cout << a << endl << b << endl << c << endl << d << endl;
    return 0;
}
