2302 - 与圆相关的计算

题目描述

给出圆的半径，求圆的直径、周长和面积

输入

输入包含一个实数 rrr( 0<r≤100000 \lt r \le 100000<r≤10000 ),表示圆的半径。

输出

输出一行，包含三个数，分别表示圆的直径，周长、面积，数与数之间以一个空格分开，每个数保留小数点后 444位。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    double r;
    cin>>r;
    cout<<fixed<<setprecision(4)<<2*r<<" ";
    cout<<2*3.14159*r<<" ";
    cout<<3.14159*r*r;
    return 0;
}
