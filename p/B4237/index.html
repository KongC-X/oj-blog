B4237 [海淀区小学组 2024] 硬币重量

洛谷 | 入门 | C++14 | 提交时间: 2026-07-17

算法标签：模拟、字符串、2025、北京、科创活动、小学活动

题目背景

2024 年海淀区中小学生信息学竞赛小学组复赛题目，数据为洛谷自造。

题目描述

有三枚硬币，分别用 A, B, C 表示，两两重量互不相同。一种称量工具，每次称量，既能称量出一个物体的重量，也能直观地确定两个物体谁轻谁重。现将它们两两放在这种称量工具上比较它们的大小，并给出三次比较的结果，每个结果都以 > 和 < 的形式呈现。例如，如果硬币 A 比硬币 B 轻，则称重比较的结果表示为 A < B。你的任务是根据给出的三个比较结果，将三枚硬币按它们的重量从小到大的顺序输出。如果给定的大小关系出现排序矛盾，则输出 Impossible。

输入格式

第一行仅有一个正整数 $T$，表示测试数据的组数，对于每组测试数据包含三行，每行给出一个称重比较的结果。

输出格式

依次给出 $T$ 组测试数据的结果，每组测试数据仅有一行，如果给出的三个比较结果，无法比较出三枚硬币重量的大小（结果相互矛盾），则输出 Impossible，否则输出仅有三个特定字符的字符串，字符串中的字母从左到右代表的硬币重量从小到大。

样例

样例输入 #1

2
A>B
C<B
A>C
A<B
B>C
C>A```

**样例输出 #1**

CBA
ACB```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;                     // T: 测试数据组数
    cin >> T;
    while (T--) {
        string a, b, c;        // a,b,c: 三个比较结果的字符串
        cin >> a >> b >> c;

        // 统一比较方向：如果原运算符为 '<'，就交换左右字母，使之变为 '>'
        if (a[1] == '<') swap(a[0], a[2]);
        if (b[1] == '<') swap(b[0], b[2]);
        if (c[1] == '<') swap(c[0], c[2]);

        // 此时 a[0]、b[0]、c[0] 都是对应比较中的较重者
        // 由于只有三枚硬币，在三次两两比较中，必然有一枚硬币作为较重者出现两次。
        // 这枚最重的硬币就是出现两次的那个字母，另外两枚的重量关系则由第三个比较决定。
        
        if (a[0] == b[0]) {                      // a和b的较重者相同，说明 a[0] 和 b[0] 都是最重的硬币
            cout << c[2] << c[0] << a[0] << endl; // 轻(c[2])、中(c[0])、重(a[0])
        }
        else if (b[0] == c[0]) {                 // b和c的较重者相同
            cout << a[2] << a[0] << b[0] << endl; // 轻(a[2])、中(a[0])、重(b[0])
        }
        else if (a[0] == c[0]) {                 // a和c的较重者相同
            cout << b[2] << b[0] << c[0] << endl; // 轻(b[2])、中(b[0])、重(c[0])
        }
        else {                                   // 没有出现两次的较重者，矛盾
            cout << "Impossible" << endl;
        }
    }
    return 0;
}
