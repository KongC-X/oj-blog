1044 - 找出最经济型的包装箱型号

题目描述

已知有 A，B，C，D，EA，B，C，D，EA，B，C，D，E 五种包装箱，为了不浪费材料，小于 101010 公斤的用 AAA 型，大于等于 101010 公斤小于 202020 公斤的用 BBB 型，大于等于 202020 公斤小于 404040 公斤的用 CCC 型，大于等于 404040 公斤的小于 505050 公斤的用 DDD 型，大于等于 505050 公斤小于 808080 公斤的用 EEE 型。

现在输入一货物的重量（小于 808080 公斤），找出最经济型的包装箱型号。

输入

输入只有一行，包括一个整数。

输出

输出只有一行（这意味着末尾有一个回车符号），包括 111个字符。

解题思路

AC代码

AC代码

#include <iostream>
#include <iomanip>
using namespace std;

int main(){
    //定义变量x表示货物重量 
    int x;
    //输入重量x 
    cin>>x;
    //判断x的范围，输出合适的包装箱 
    if(x<10){
        cout<<"A";
    }else if(x<20){
        cout<<"B";
    }else if(x<40){
        cout<<"C";
    }else if(x<50){
        cout<<"D";
    }else{
        cout<<"E";
    }
    return 0;
}
