1109 - 加密四位数

题目描述

某军事单位用 $4$ 位整数来传递信息，传递之前要求先对这个 $4$ 位数进行加密。加密的方式是每一位都先加上 $5$ 然后对 $10$ 取余数，再将得到的新数颠倒过来。

例如：原数是 $1379$ ，那么每位加 $5$ 对 $10$ 取余数的结果为 $6824$ ，然后颠倒该数，得到新数：$4286$。

再比如：原数是 $2570$，那么每位加 $5$ 对 $10$ 取余数的结果为 $7025$ ，然后颠倒该数，得到新数： $5207$ 。

请根据加密要求，写出加密算法！

输入

加密前的 $4$ 位数。

输出

加密后的结果

AC代码

AC代码

#include <iostream>
using namespace std;
 
int main(){
    //定义变量x,y作为加密前和加密后的数
    //定义变量q,b,s,g作为千位,百位,十位,个位 
    int x,y,q,b,s,g;
    cin>>x;
    //对x进行拆位 
    q=x/1000;
    b=x/100%10;
    s=x%100/10;
    g=x%10;
    //对各个位加密并倒序加权 
    y=(g+5)%10*1000+(s+5)%10*100+(b+5)%10*10+(q+5)%10;
    cout<<y;
    return 0; 
}
