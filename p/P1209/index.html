P1209 [USACO1.3] 修理牛棚 Barn Repair

洛谷 | 普及| C++14 | 提交时间: 2026-10-07

算法标签：动态规划 DP、搜索、贪心、USACO、排序

题目描述

It was a dark and stormy night that ripped the roof and gates off the stalls that hold Farmer John's cows. Happily, many of the cows were on vacation, so the barn was not completely full.

The cows spend the night in stalls that are arranged adjacent to each other in a long line. Some stalls have cows in them; some do not. All stalls are the same width.

Farmer John must quickly erect new boards in front of the stalls, since the doors were lost. His new lumber supplier will supply him boards of any length he wishes, but the supplier can only deliver a small number of total boards. Farmer John wishes to minimize the total length of the boards he must purchase.

Given MMM (1≤M≤501 \le M \le 501≤M≤50), the maximum number of boards that can be purchased; SSS (1≤S≤2001 \le S \le 2001≤S≤200), the total number of stalls; CCC (1≤C≤S1 \le C \le S1≤C≤S) the number of cows in the stalls; and the CCC occupied stall numbers (1≤stall_number≤S1 \le \text{stall\_number} \le S1≤stall_number≤S), calculate the minimum number of stalls that must be blocked in order to block all the stalls that have cows in them.

Print your answer as the total number of stalls blocked.

输入格式

  • Line 1: MMM, SSS, and CCC (space separated).
  • Lines 2..C+1C+1C+1: Each line contains one integer, the number of an occupied stall.

输出格式

A single line with one integer that represents the total number of stalls blocked.

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P1209 [USACO1.3] 修理牛棚 Barn Repair
     * 题意：有 s 个牛棚排成一行，其中 c 个牛棚里有牛（给出编号）。
     *       现在最多可以用 m 块木板，木板可以覆盖任意连续的牛棚段，
     *       要求用这些木板覆盖所有有牛的牛棚，求木板总长度的最小值。
     *
     * 贪心思路：
     *   1. 如果 m >= c，每头牛单独用一块木板，总长度就是 c。
     *   2. 否则，先把所有有牛的牛棚编号从小到大排序。
     *      假设只用 1 块木板，从最小编号覆盖到最大编号，
     *      总长度 = a[c-1] - a[0] + 1。
     *   3. 我们可以用多块木板，相当于在牛棚之间“断开”，
     *      每断开一次，就省去一段空隙（两个有牛牛棚之间的空牛棚数）。
     *      空隙长度 = a[i+1] - a[i] - 1。
     *   4. 最多可以断开 m-1 次（因为 m 块木板之间有 m-1 个断点）。
     *      为了让总长度最小，我们应该选择最大的 m-1 个空隙来断开。
     *   5. 所以，先算出所有相邻牛棚的空隙，从大到小排序，
     *      取前 m-1 个最大的空隙，从总长度中减去它们即可。
     *
     * 时间复杂度：O(c log c)，c ≤ 200，非常快。
     */

    int m, s, c;
    cin >> m >> s >> c;

    int a[205];   // a[i]: 第 i 头牛所在的牛棚编号
    for (int i = 0; i < c; i++) {
        cin >> a[i];
    }

    // 如果木板数足够多，每头牛单独一块
    if (m >= c) {
        cout << c << endl;
        return 0;
    }

    // 将牛棚编号从小到大排序
    sort(a, a + c);

    // 初始用一块木板覆盖所有有牛的牛棚
    int ans = a[c - 1] - a[0] + 1;

    // 计算相邻牛棚之间的空隙
    int g[205];   // g[i]: 第 i 个空隙的长度
    for (int i = 0; i < c - 1; i++) {
        g[i] = a[i + 1] - a[i] - 1;
    }

    // 将空隙从大到小排序
    sort(g, g + c - 1, greater<int>());

    // 减去最大的 m-1 个空隙
    for (int i = 0; i < m - 1 && i < c - 1; i++) {
        ans -= g[i];
    }

    cout << ans << endl;
    return 0;
}
