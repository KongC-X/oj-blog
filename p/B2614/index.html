题目描述

兔子有 $4$ 只脚，鸡有 $2$ 只脚。一个笼子里面有若干只兔子和鸡，共有 $35$ 个头，$94$ 只脚，请问兔子和鸡分别有几只？

输出格式

请输出两个整数表示答案，使用空格隔开。

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】鸡兔同笼
     * 【核心思路】
     * 设兔子 r 只，鸡 c 只。
     * r + c = 35
     * 4r + 2c = 94
     * 解得 r = 12，c = 23。
     *
     * 【时间复杂度】O(1)
     */

    int r, c;          // r: 兔子数, c: 鸡数
    r = (94 - 2 * 35) / 2;   // 公式：r = (脚数 - 2*头数) / 2
    c = 35 - r;              // 鸡数

    cout << r << " " << c << endl;   // 输出 12 23
    return 0;
}
