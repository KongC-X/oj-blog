B4182 [中山市赛 2024] 海洋宝宝

洛谷 | 入门 | C++14 | 提交时间: 2026-07-17

算法标签：模拟、2024、科创活动、小学活动

题目描述

无事可做的 Jimmy 正在观察他刚买回来的“海洋宝宝”——一种喝了水就能“生”出小宝宝的东西。他之前数过，买回来的时候一共有 $n$ 颗海洋宝宝。他发现，每隔 $1$ 小时，每颗海洋宝宝都会生出 $k$ 颗新的海洋宝宝。于是他开始好奇：凑够一万颗海洋宝宝需要等多久呢？十万颗呢？$m$ 颗呢？……

输入格式

一行三个整数，分别为 $n, k, m$。

$n, k$ 的含义见题目描述；$m$ 表示 Jimmy 想凑够 $m$ 颗海洋宝宝。

输出格式

一行一个整数，表示为了凑够 $m$ 颗海洋宝宝，Jimmy 需要等待多少个小时。

样例

样例输入 #1

1 1 4```

**样例输出 #1**

2```

样例输入 #2

7 10 7```

**样例输出 #2**

0```

样例输入 #3

31 4 415926```

**样例输出 #3**

6```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n, k, m;               // n: 初始数量, k: 每颗每小时生的数量, m: 目标数量
    cin >> n >> k >> m;

    int t = 0;                       // t: 需要的小时数
    // 初始已经够，不用等
    if (n >= m) {
        cout << 0 << endl;
        return 0;
    }

    long long cur = n;               // cur: 当前数量
    long long factor = k + 1;        // 每小时数量乘的倍数 (每颗变 k+1 颗)
    
    while (cur < m) {
        cur *= factor;
        t++;
    }

    cout << t << endl;
    return 0;
}
