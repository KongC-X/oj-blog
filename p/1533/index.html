1533 - 小 X 与机器人 (betago)

题目描述

小 X 最近对战胜韩国围棋大神李世石的 AlphaGo 很感兴趣，所以小 X 自己写了一个叫 做 BetaGo的人工智能程序(简称 AI) ， 这个 BetaGo 会做什么呢？

小 X 首先想要让 BetaGo 做到自己在棋盘上落子， 这一点 AlphaGo 是由程序员来完成的。小 X 的设想是这样的： 在棋盘的边框上放置一个小机器人， 这个小机器人会沿着棋盘的边框移动到最接近落子点的位置，然后伸出它的机械臂将棋子放到棋盘上。 这里面最关键的一步是如何让小机器人在棋盘的边框上沿着最短的路径移动，小 X 想请你帮他编个程序解决这个问题。

众所周知，围棋棋盘大小为 19×1919 \times 1919×19(如下图所示) , 图中加粗的一圈即为边框。

我们用一对整数 (xxx, yyy) 来表示棋盘上第 xxx 条横线（从下往上数）与第 yyy 条竖线（从左往右数）的交叉点，如上图中边框上的 A 点用（ 666， 111） 表示， B 点用 (101010， 191919) 表示，小机器人初始时放置在 (x1x1x1, y1y1y1) 这个位置上， 它想要移动到 (x2x2x2, y2y2y2) 这个位置上。 (x1x1x1, y1y1y1) 和(x2x2x2, y2y2y2) 一定是棋盘边框上的交叉点每一步小机器人可以从当前位置移动到相邻（上下左右）的某个位置上， 即每次可以从 (xxx, yyy) 移动到 (x−1x - 1x−1, yyy) 、 (x+1x + 1x+1, yyy) 、 (xxx, y−1y - 1y−1) 、 (xxx, y+1y + 1y+1) 四个位置中的一个， 但是它不能走出或走进棋盘，也就是说它只能沿着棋盘的边框移动到相邻位置， 这就意味着任一时刻相邻位置都恰好只有两个。

BetaGo 会告诉小机器人最少需要走多少步， 但小 X 还是很担心 BetaGo 有的时候会失控，从而告诉他一个错误值。

为此小 X 只好求助你， 希望你编一个程序计算从 (x1x1x1, y1y1y1) 沿着棋盘的边框移动到 (x2x2x2, y2y2y2) 最少需要走 多少步 。 上 图 中 从 A 点 （ 666 ， 111 ） 移 动 到 B 点 (101010 ， 191919) 最 少需 要 走 323232 步 ， 移 动 路线 是 ：（ 6 ， 1 ） → （ 5 ， 1 ） → （ 4 ， 1 ） → （ 3 ， 1 ） → （ 2 ， 1 ） → （ 1 ， 1 ） → (1 ， 2 ） → (1 ， 3 ） →……→(1， 19） →(2， 19） →……→(10， 19）

输入

输入数据仅有一行包含四个用空格隔开的正整数表示 x1x1x1, y1y1y1, x2x2x2,y2y2y2。

数据保证 (x1x1x1, y1y1y1) ， (x2x2x2, y2y2y2) 一定是棋盘边框上的交叉点。

输出

输出一行包含一个整数 ansansans， 表示小机器人从 (x1x1x1, y1y1y1) 移动到 (x2x2x2, y2y2y2) 的最少步数。

解题思路

AC代码

AC代码

#include <iostream>
#include <cmath>   // 使用 abs 函数
using namespace std;

// 将边框上的点映射到一维坐标（顺时针方向，从 (1,1) 开始）
// 周长：共有 19*4 - 4 = 72 个不同的点（角点不重复计算）
int pos(int x, int y) {
    // 下边：x == 1，y 从 1 到 19，坐标从 0 到 18
    if (x == 1)
        return y - 1;
    // 右边：y == 19，x 从 2 到 19（因为 (1,19) 已算在下边），坐标从 19 到 36
    else if (y == 19)
        return 18 + (x - 1);   // 18 是下边的终点，加上 x-1
    // 上边：x == 19，y 从 18 下降到 1（因为 (19,19) 已在右边），坐标从 37 到 54
    else if (x == 19)
        return 36 + (19 - y);   // 36 是右边的终点，加上 (19-y)
    // 左边：y == 1，x 从 18 下降到 2（因为 (19,1) 已在上边，(1,1) 已在下边），坐标从 55 到 71
    else
        return 54 + (19 - x);   // 54 是上边的终点，加上 (19-x)
}

int main() {
    int x1, y1, x2, y2;
    cin >> x1 >> y1 >> x2 >> y2;

    // 获取起点和终点在一维坐标上的位置
    int p1 = pos(x1, y1);
    int p2 = pos(x2, y2);

    // 顺时针方向的距离
    int d = abs(p1 - p2);
    // 最短距离 = min(顺时针距离, 逆时针距离)
    // 逆时针距离 = 总周长 - 顺时针距离
    int ans = min(d, 72 - d);
    cout << ans << endl;

    return 0;
}
