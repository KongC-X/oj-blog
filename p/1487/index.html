1487 - 取扑克牌

题目描述

有 NNN（N≤1000N \le 1000N≤1000）张扑克牌放成一堆，每次从上面取一张牌翻开，再从上面取一张牌放到这堆牌的下面。也就是从上面奇数次取到的牌翻开放成一排，偶数次取到的牌放在下面直到取完。

输入 NNN 张扑克牌的排满数字，输出翻开的情况。比如，N=4N=4N=4，牌面从上到下依次是 111 222 333 444 ，那么翻开牌面的情况为 111 333 222 444 。

输入

第一行是一个整数 NNN（N≤1000N \le 1000N≤1000）。

第二行是 NNN 个整数，代表从上到下的牌面数。

输出

按照翻开牌面的顺序，输出翻开的结果，数字之间用一个空格隔开。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main(){
int n,x;
cin>>n;
queue<int> q;
for(int i=1;i<=n;i++){
    cin>>x;
    q.push(x);
}
while(!q.empty()){
    cout<<q.front()<<" ";
    q.pop();
    q.push(q.front());
    q.pop();
}
return 0;
}
