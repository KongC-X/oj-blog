1561 - 买木头

题目描述

有 nnn 个木材供应商，每个供货商有长度相同一定数量的木头。长木头可以锯短，但短木头不能接长。有一个客人要求 mmm 根长度相同的木头。要求计算出，此时供货商提供的木头满足客人要求的最长的长度是多少。

例如 n=2,m=30n=2,m=30n=2,m=30，两个供货商的木头为

12,1012,1012,10 第 111 个供货商的木头长度为 121212 ，共有 101010 根；

5,105,105,10 第 222 个供货商的木头长度为 555 ，共有 101010 根。

计算的结果为 555 ，即长度为 121212 的木头一根可锯出两根长度为 555 的木头，多余的无用，长度为 555 的木头不动，此时可得到 303030 根长度为 555 的木头。

输入

整数 n,m,L1,S1n,m,L_1,S_1n,m,L1​,S1​ （1≤n≤10000,1≤m≤1000000,1≤L1≤10000,1≤S1≤1001≤n≤10000,1≤m≤1000000,1≤L_1≤10000,1≤S_1≤1001≤n≤10000,1≤m≤1000000,1≤L1​≤10000,1≤S1​≤100）

其中 L1L_1L1​ 是第一个供货商木头的长，S1S_1S1​ 是第一个供货商木头数量。其他供货商木头的长度和数量 LiL_iLi​ 和 SiS_iSi​（i≥2i≥2i≥2），由下面的公式给出：

$L_i=((L

i−1i-1i−1

\times 37011+10193) \mod 10000)+1$

$S_i=((S

i−1i-1i−1

\times 73011+24793) \mod 100)+1$

输出

一个整数，即满足要求的 mmm 根长度相同的木头的最大长度。

本题测试数据保证一定有解。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
using namespace std;

const int N = 10010;
int n,m,i,j;
int len[N],cnt[N];

// 检验切割长度为mid，是否能够切除m根以上的木头
bool check(int mid) {
    int c = 0;
    for(int i = 1;i <= n;i++) {
        c += len[i] / mid * cnt[i];
    }
    return c >= m;
}
 
int main() {
    cin >> n >> m >> len[1] >> cnt[1];
    int l = 1,r = len[1],mid;
    // 生成
    for(int i = 2;i <= n;i++) {
        len[i] = (len[i - 1] * 37011 + 10193) % 10000 + 1;
        cnt[i] = (cnt[i - 1] * 73011 + 24793) % 100 + 1;
        r = max(len[i],r);
    }
    while(l <= r) {
        mid = (l + r) >> 1;
        if(check(mid)) {
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }
    cout << r << endl;
}
