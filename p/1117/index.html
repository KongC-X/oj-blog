1117 - 重新排列

题目描述

现在有一个 303030 位以内的自然数，你可以将组成这个数的各位数字重新排列，得到一个数值为最小的新数，但新数的位数保持不变。

请编程打印出重新排列后的新数。（如：231231231 重新排序后位数不变的最小数是 123123123 ，而 231052310523105 重新排序后位数不变的最小数是 102351023510235）

输入

一个整数（位数 ≤30\le 30≤30 位）。

输出

重新排列后最小的新数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>  
using namespace std;

int z,x,c=1,v[999],b,n,m,i,j;
char a[99],q[999],w[999],r,t;
int main(){
    gets(a);
    sort(a,a+strlen(a));
    if(a[0]!='0'){
        cout<<a;
    }else{
        for(i=0;i<strlen(a);i++){
            if(a[i]!='0'){
                b=i;
                break;
            }
        }
        r=a[b];
        a[b]='0';
        a[0]=r;
        cout<<a;
    }
}
