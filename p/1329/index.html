1329 - 求梯形的面积

题目描述

梯形面积的求解公式为 $S = (a + b) \times h / 2$ 。从键盘读入一个梯形的上底 $a$、下底 $b$ 和高 $h$ ，请计算表梯形的面积。（结果保留1位小数）。（5.1.15）

输入

三个整数 $a、b、h$。

输出

梯形的面积

解题思路

AC代码

AC代码

#include <iostream>
#include <iomanip>
using namespace std;
 
int main(){
    //定义三个整数分别代表上底a,下底b,高h 
    int a,b,h;
    //定义小数S作为梯形面积 
    double S;
    cin>>a>>b>>h;
    //计算梯形面积 
    S=(a+b)*h/2.0;
    //输出结果保留1位小数 
    cout<<fixed<<setprecision(1)<<S;
    return 0;
}
