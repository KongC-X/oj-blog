4614 - 奇妙数

题目描述

如果一个整数能够被它的各位上的非零数字整除，则称该数为奇妙数。

例如：整数 102102102，它的各位上的非零数字为 111 和 222，102102102 既能被 111 整除，也能被 222 整除，所以 102102102是奇妙数;

整数 456456456，它的各位上的非零数字为 4、54、54、5 和 666，456456456 能被 444 和 666 整除，但不能被 555 整除，所以 456456456不是奇妙数。

给定两个整数 nnn 和 mmm，请输出 nnn 到 mmm 之间（包含 nnn 和 mmm）所有的奇妙数；若不存在奇妙数，则输出 −1-1−1。

输入

一行输入两个整数 nnn 和 mmm（1≤n≤m≤1000001 \le n \le m \le 1000001≤n≤m≤100000），整数之间以一个空格隔开。

输出

按照从小到大的顺序输出 nnn 到 mmm 之间（包含 nnn 和 mmm）所有的奇妙数，整数之间以一个空格隔开；若不存在奇妙数，则输出 −1-1−1。

AC代码

#include <iostream>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    
    bool found = false;  // 标记是否找到奇妙数
    
    for (int i = n; i <= m; i++) {
        // 取出 i 的每一位非零数字，检查是否能整除
        int temp = i;
        bool isWonderful = true;  // 假设 i 是奇妙数
        
        while (temp > 0) {
            int digit = temp % 10;  // 取出最后一位
            temp /= 10;  // 去掉最后一位
            
            if (digit != 0) {  // 只考虑非零数字
                if (i % digit != 0) {  // 如果不能被整除
                    isWonderful = false;
                    break;  // 跳出 while 循环
                }
            }
        }
        
        if (isWonderful) {
            cout << i << endl;
            found = true;
        }
    }
    
    if (!found) {
        cout << -1 << endl;
    }
    
    return 0;
}
