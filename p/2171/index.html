2171 - 树的高度（2）

题目描述

一棵树有 nnn 个结点，结点编号为 111~nnn，其中 111 号结点为根结点，根结点的深度为 111，请问每个结点的父结点是谁，每个结点的深度是多少。

输入

第一行是整数 nnn，表示结点数。（1≤n≤201≤n≤201≤n≤20）

后面若干行，每行两个整数aaa bbb，读入数据不保证结点a是结点b的父结点。

本题测试数据保证所有结点能构建为一棵树。

输出

输出有 n−1n-1n−1 行（根结点不需要输出），每行输出 333 个整数；

第 iii 行输出：结点编号 i+1i+1i+1，编号为 i+1i+1i+1 的结点的父结点的编号，该结点的深度（三个整数之间用空格隔开）。

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

const int N = 30;
//fa：父结点 a：邻接矩阵 dep：深度 
int fa[N],a[N][N],dep[N];
int n;

//深搜求：每个结点的父结点编号、深度
void dfs(int x,int f){
    fa[x] = f;//标记元素的父
    dep[x] = dep[f] + 1;//求深度
    //讨论x点能去的点
    for(int i = 1;i <= n;i++){
        //有边 && 要去的点不是父结点
        if(a[x][i]==1&&i!=fa[x]){
            //i的父是x，继续深搜
            dfs(i,x);
        } 
    } 
} 

int main(){
    cin>>n;
    int x,y;
    for(int i = 1;i <= n - 1;i++){
        cin>>x>>y;
        //按无向图来建边 
        a[x][y] = 1;
        a[y][x] = 1;
    }
    //根结点为1
    dfs(1,0);
    
    //输出结果
    for(int i = 2;i <= n;i++){
        cout<<i<<" "<<fa[i]<<" "<<dep[i]<<endl;
    } 
    return 0;
}
