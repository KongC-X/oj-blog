B3655 [语言月赛202208] 天天爱跑步

洛谷 | 普及- | C++14 | 提交时间: 2026-09-03

算法标签：模拟、2022、语言月赛

题目背景

洛咕公司开发了一款新的养成类游戏《天天爱跑步》。

题目描述

为了推广《天天爱跑步》，洛咕公司开发了活跃值系统，同其他游戏一样，连续签到天数越多，每次签到获得的活跃值也就越多。但只要一天不签到，连续天数就要清零。

当连续签到天数达到以下天数时，活跃值奖励将发生如下变化。

  • 111 天：由 000 变为 v1v_1v1​
  • 333 天：由 v1v_1v1​ 变为 v3v_3v3​
  • 777 天：由 v3v_3v3​ 变为 v7v_7v7​
  • 303030 天：由 v7v_7v7​ 变为 v30v_{30}v30​
  • 120120120 天：由 v30v_{30}v30​ 变为 v120v_{120}v120​
  • 365365365 天：由 v120v_{120}v120​ 变为 v365v_{365}v365​
  • 366366366 天或更多天数：均为 v365v_{365}v365​

例如，以下为某游戏玩家连续签到情况及活跃值奖励情况，有助于进一步理解题意。

日期 是否签到 连续签到天数 当天获得活跃值奖励
8 月 8 日 是 111 v1v_1v1​
8 月 9 日 是 222 v1v_1v1​
8 月 10 日 是 333 v3v_3v3​
8 月 11 日 是 444 v3v_3v3​
8 月 12 日 否 000 000
8 月 13 日 是 111 v1v_1v1​
8 月 14 日 是 222 v1v_1v1​
8 月 15 日 是 333 v3v_3v3​

即，签到系统按照如下顺序处理奖励：

  1. 累计连续签到天数
  2. 根据规则确定当日奖励的活跃值
  3. 发放活跃值

现在给出 超高校级的游戏玩家 ⌊\lfloor⌊七海千秋⌉\rceil⌉ 连续 nnn 天的签到情况，请你求出这 nnn 天七海千秋获得的活跃值奖励一共为多少。

连续签到天数从 000 开始计算。

输入格式

输入共 n+2n+2n+2 行。

输入的第一行为一个正整数 nnn，代表 ⌊\lfloor⌊七海千秋⌉\rceil⌉ 游戏的天数。

输入的第二行为六个正整数，分别为 v1,v3,v7,v30,v120,v365v_1,v_3,v_7,v_{30},v_{120},v_{365}v1​,v3​,v7​,v30​,v120​,v365​，含义如题。

接下来的 nnn 行，每行一个整数 111 或 000。其中第 iii 行为 111 表示第 iii 天 ⌊\lfloor⌊七海千秋⌉\rceil⌉ 签到了，输入为 000 表示第 iii 天 ⌊\lfloor⌊七海千秋⌉\rceil⌉ 没有签到。

输出格式

输出一行一个整数，代表 ⌊\lfloor⌊七海千秋⌉\rceil⌉ nnn 天签到所获得的活跃值。

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;
    int v1, v3, v7, v30, v120, v365;
    cin >> v1 >> v3 >> v7 >> v30 >> v120 >> v365;

    int day = 0;          // 连续签到天数
    long long ans = 0;    // 总奖励

    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (x == 0) {
            day = 0;
            // 当天奖励为 0，不需要累加
        } else {
            day++;
            // 根据连续天数判断奖励
            if (day >= 365) ans += v365;
            else if (day >= 120) ans += v120;
            else if (day >= 30) ans += v30;
            else if (day >= 7) ans += v7;
            else if (day >= 3) ans += v3;
            else ans += v1;
        }
    }

    cout << ans << '\n';
    return 0;
}
