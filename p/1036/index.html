1036 - 简单判断

题目描述

读入三个整数 a、b、ca、b、ca、b、c （ 0<a0 \lt a0<a ， b，c<10000b，c \lt 10000b，c<10000 ），数据之间用空格隔开，如果前两个数 a、ba、ba、b 的和大于第三个数 ccc，那么就输出yes，否则就输出no。

输入

一行，三个整数 aaa bbb ccc 。

输出

yes ororor no 。

AC代码

AC代码

#include<iostream>
#include<iomanip>
using namespace std;
int main(){
    int a,b,c;
    cin>>a>>b>>c;
    if(a+b>c){
        cout<<"yes"<<endl;
    }
    else{
        cout<<"no"<<endl;
    }
    return 0; 
}
