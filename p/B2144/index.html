阿克曼（Ackermann）函数 A(m,n)A(m,n)A(m,n) 中，m,nm, nm,n 定义域是非负整数（m≤3m \le 3m≤3，n≤10n \le 10n≤10），函数值定义为：

A(m,n)=n+1\mathit{A}(m,n)=n+1A(m,n)=n+1；（m=0m=0m=0 时）。

A(m,n)=A(m−1,1)\mathit{A}(m,n)=\mathit{A}(m-1,1)A(m,n)=A(m−1,1)；（m>0m>0m>0、n=0n=0n=0 时）。

A(m,n)=A(m−1,A(m,n−1))\mathit{A}(m,n)=\mathit{A}(m-1,\mathit{A}(m,n-1))A(m,n)=A(m−1,A(m,n−1))；（m,n>0m,n>0m,n>0 时）。

样例

样例输入 #1

2 3```

**样例输出 #1**

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 阿克曼函数：递归计算 A(m, n)
int ack(int m, int n) {
    if (m == 0) return n + 1;                  // 规则1
    if (n == 0) return ack(m - 1, 1);          // 规则2
    return ack(m - 1, ack(m, n - 1));          // 规则3
}

int main() {
    int m, n;
    cin >> m >> n;
    cout << ack(m, n) << endl;
    return 0;
}
