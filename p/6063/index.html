6063 - 游乐园门票

题目描述

学校组织全年级同学去游乐园春游。游乐园门票分为学生票和成人票，学生票 aaa 元张，成人票 bbb 元一张。共有 xxx 名同学参加春游，用于买票的经费为 yyy 元，请计算为 xxx 名同学买票后，剩下的钱最多能为多少位教师买票。

输入

四个整数 aaa, bbb, xxx, yyy,分别代表学生票价格、成人票价格、同学人数、经费。保证经费足够购买 xxx 张学生票。

输出

一个整数，剩下的钱最多能为多少位教师买票。

AC代码

#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int a, b, x, y;            // a:学生票价, b:成人票价, x:学生人数, y:总经费
    cin >> a >> b >> x >> y;

    int rest = y - a * x;      // 买完学生票后剩余的钱
    int ans = rest / b;        // 最多能买的成人票数量

    cout << ans << '\n';
    return 0;
}
