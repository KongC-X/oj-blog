1847 - 摆动序列

题目描述

如果一个序列满足下面的性质，我们就将它称为摆动序列：

  • 序列中的所有数都是不大于 kkk 的正整数。

  • 序列中至少有两个数。

  • 序列中的数两两不相等。

  • 如果第 i–1i – 1i–1 个数比第 i–2i – 2i–2 个数大，则第 iii 个数比第 i–2i – 2i–2 个数小；如果第 i–1i – 1i–1 个数比第 i–2i – 2i–2 个数小，则第 iii 个数比第 i–2i – 2i–2 个数大。

比如，当 k=3k = 3k=3 时，有下面几个这样的序列：

`1 2
1 3
2 1
2 1 3
2 3
2 3 1
3 1
3 2
`

一共有 888 种，给定 kkk ，请求出满足上面要求的序列的个数。

输入

输入包含了一个整数 kkk 。（k≤20k \le 20k≤20）

输出

输出一个整数，表示满足要求的序列个数。

解题思路

AC代码

AC代码

#include <iostream>
#include <cmath>

// 计算摆动序列的总数
long long countWiggleSequences(int k) {
    if (k < 2) return 0; // 至少需要两个数
    return 2 * ((1LL << k) - k - 1); // 使用位运算计算2^k
}

int main() {
    int k;
    std::cin >> k;

    long long result = countWiggleSequences(k);
    std::cout << result << std::endl;

    return 0;
}
