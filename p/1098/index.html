1098 - 判断是否构成回文

题目描述

输入一串字符，字符个数不超过 100100100 ，且以 . 结束。

判断它们是否构成回文，如果不含 . 能构成回文输出 TRUE，否则输出 FALSE。

输入

输入只有一行，包括一串字符。（测试数据不含空格）

输出

输出只有一行，TRUE 或者 FALSE 。

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    string s;
    int i;
    bool r = true; // 假设是回文
    getline(cin, s);
     // 循环字符串实际长度的一半
     for(i = 0;i < (s.size() - 1)/2;i ++){
        // 如果对称位置有一个元素不等，就不是回文
         if(s[i] != s[s.size()-i-2]) {
            r = false;
            break;
        }
    }
    // 判断是不是回文
     if (r == true) {
        cout << "TRUE" << endl;
    } else {
        cout << "FALSE" << endl;
    }
}
