1581 - 马里奥的银币1

题目描述

马里奥有很多银币，有一天他得到了一张魔法卡，只要使用这张魔法卡，就可以使得他的银币里面的最大的银币金额变得更大。如果他最大的银币是偶数的金额，可以直接翻倍；如果他最大的银币是奇数的金额，可以使得银币金额加 111 。

比如：假设马里奥存有的银币金额分别为 555 777 888 111 444 ，那么最大的银币面值为 888 ，只要使用魔法卡，银币的金额就会变为555 777 161616 111 444 ；

再比如：假设马里奥存有的银币金额分别为 555 777 999 111 444 ，那么最大的银币面值为 999 ，只要使用魔法卡，银币的金额就会变为 555 777 101010 111 444 ；

已知马里奥众多的银币中，面额最大的银币只有 111 个，请你求出，马里奥使用魔法卡之后，他的银币金额分别是多少？

输入

第一行是一个整数 nnn 代表马里奥有 nnn 个银币。（n≤1000n \le 1000n≤1000）

第二行有 nnn 个整数，用空格隔开，代表马里奥每个银币的金额。

输出

一行有 nnn 个整数，代表使用过魔法卡之后，马里奥的银币的金额，分别是多少？

AC代码

AC代码

#include<iostream>
#include<cstdio>
#include<cstdlib>
using namespace std;
int a[1005];
int main()
{
    int n;
    int max=a[0];
    int b;
    scanf("%d",&n);
    for(int i=0;i<n;i++){
        scanf("%d",&a[i]);
    }
    for(int i=0;i<n;i++){
        if(a[i]>max){
            max=a[i];
            b=i;
        }
    }
    for(int i=0;i<n;i++){
        if(b==i){
            if(a[i]%2==0){
                 a[i]=a[i]*2;
                 for(int i=0;i<n;i++){
                 	printf("%d ",a[i]);
                 }
            }
            else{
                if(a[i]%2==1){
                    a[i]++;
                    for(int i=0;i<n;i++){
                        printf("%d ",a[i]);
                    }
                }else{
                    for(int i=0;i<n;i++){
                        printf("%d ",a[i]); 
                    }
                }
            }
        }
    }
    return 0;
}
