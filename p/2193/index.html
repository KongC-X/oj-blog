2193 - 哈夫曼树

题目描述

哈夫曼树的定义是：一棵具有 nnn 个带权叶结点的二叉树，使得所有叶结点的带权路径长度（叶结点 ××× 叶结点到根结点的路径长度）之和最小，这样的二叉树被称为最优二叉树，也称哈夫曼树。

比如：有 444 个结点的权值是555 444 222 999，可以构建出如下三颗不同的二叉树，第 222 棵二叉树的带权路径长度是最小的。

请读入一个整数 nnn ，代表叶结点的数量，再读入 nnn 个整数，代表叶结点的权值，请求出对应哈夫曼树的带权路径长度。

输入

输入的第一行包含一个正整数 nnn（2≤n≤1002≤n≤1002≤n≤100）。

接下来是 nnn 个正整数，表示 nnn 个叶结点的权值，每个数不超过 100010001000 。

输出

输出构造出的哈夫曼树的带权路径长度。

AC代码

#include <bits/stdc++.h>
using namespace std;

//思路：使用优先队列模拟哈夫曼树的构建过程
//小根堆 
priority_queue<int,vector<int>,greater<int> > q; 
int n,x,ans = 0;//ans：代表哈夫曼树的WPL的值 
 
int main(){
    cin>>n;
    //读入n个元素 
    while(n--){
        cin>>x;
        q.push(x);
    }
    
    //当队列中超过1个元素
    //获取队列头部的2个最小的元素
    int a,b; 
    while(q.size() > 1){
        a = q.top();
        q.pop();
        b = q.top();
        q.pop();
        
        ans += a + b;
        q.push(a+b);
    } 
    
    cout<<ans; 
    return 0;
}
