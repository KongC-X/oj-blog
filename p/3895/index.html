3895 - 平衡序列

题目描述

小杨有一个包含 nnn 个正整数的序列 aaa ，他认为一个序列是平衡的当且仅当存在一个正整数 i(1≤i<n)i(1 \le i \lt n )i(1≤i<n) 使得序列第 111 个到第 iii 个数字的总和等于第 i+1i+1i+1 个到第 nnn 个数字的总和。

小杨想请你判断序列 aaa 是否是平衡的。

输入

第一行包含一个正整数 ttt，代表测试用例组数。

接下来是 ttt 组测试用例。对于每组测试用例，一共两行。

第一行包含一个正整数 nnn，代表序列长度。

第二行包含 nnn 个正整数，代表序列 aaa。

输出

对于每组测试用例，如果序列 aaa是否是平衡的，输出 Yes，否则输出 No。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int s,s1[10010],s2[10010],s3,s4;
int i,j,n,m,q,w;
int main(){
    cin>>n;
    for(i=1;i<=n;i++){
        cin>>m;
        for(j=0;j<m;j++){
            cin>>s1[j];
            s+=s1[j];
        }
        for(j=0;j<m;j++){
            q+=s1[j];
            if(q*2==s){
                w=1;
                break;
            }
        }
        if(w){
            cout<<"Yes"<<endl;
        }else{
            cout<<"No"<<endl;
        }w=0;
        s=0;
        q=0;
    }
}
