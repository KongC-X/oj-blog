B4425 [CSP-X2025 山东] 评奖

洛谷 | 入门 | C++14 | 提交时间: 2026-08-10

算法标签：模拟、2025、山东、CSP-X 小学组

题目描述

期末考试结束了，学校要根据语文、数学、英语的三科成绩评出特优学生和优秀学生。评选规则如下：

  1. 三科均为满分 100100100 分的同学评为特优学生；
  2. 三科中有两科均为 959595 分及以上，另一科为 909090 分及以上的同学评为优秀学生；
  3. 已经被评为特优学生的同学不再参与优秀学生的评选。

已知学生的数量 nnn（学生编号为 111 到 nnn）以及 nnn 个学生的语文、数学、英语成绩，请你根据评选规则计算有多少个特优学生和优秀学生。

输入格式

第一行一个整数 nnn，表示学生的个数。

第二行 nnn 个整数，用空格隔开，第 iii 个整数 aia_iai​ 表示 iii 号学生的语文成绩。

第三行 nnn 个整数，用空格隔开，第 iii 个整数 bib_ibi​ 表示 iii 号学生的数学成绩。

第四行 nnn 个整数，用空格隔开，第 iii 个整数 cic_ici​ 表示 iii 号学生的英语成绩。

输出格式

输出一行两个整数，中间用一个空格隔开，依次表示评出的特优学生和优秀学生的数量。

样例

样例输入 #1

5
90 95 89 100 91
96 99 95 100 92
97 98 95 100 93```

**样例输出 #1**

1 2```

样例输入 #2

10
93 95 80 96 91 97 95 88 80 90
96 90 90 100 97 90 95 89 99 90
99 98 100 100 99 92 95 86 90 90```

**样例输出 #2**

0 5```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：简单判断统计
     * 思路：
     * 1. 读入 n，然后读入三组成绩分别存入 a,b,c 数组。
     * 2. 对每个学生 i：
     *    - 如果 a[i]==100 && b[i]==100 && c[i]==100，则特优数+1。
     *    - 否则判断优秀条件：
     *      统计三科中 >=95 的科数 cnt95，以及是否所有科都 >=90。
     *      若 cnt95 >= 2 且 所有科 >=90，则优秀数+1。
     * 3. 输出特优数和优秀数。
     */
    int n;
    cin >> n;
    int a[100005], b[100005], c[100005];

    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = 0; i < n; i++) cin >> b[i];
    for (int i = 0; i < n; i++) cin >> c[i];

    int t = 0, y = 0;   // t: 特优数, y: 优秀数

    for (int i = 0; i < n; i++) {
        // 先判断特优
        if (a[i] == 100 && b[i] == 100 && c[i] == 100) {
            t++;
            continue;
        }
        // 再判断优秀
        int cnt95 = 0;
        if (a[i] >= 95) cnt95++;
        if (b[i] >= 95) cnt95++;
        if (c[i] >= 95) cnt95++;
        if (cnt95 >= 2 && a[i] >= 90 && b[i] >= 90 && c[i] >= 90) {
            y++;
        }
    }

    cout << t << " " << y << endl;
    return 0;
}
