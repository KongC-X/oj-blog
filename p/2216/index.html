2216 - 找数字

题目描述

给定一个 $n$ 个数的数组 $a$，再给定 $m$ 次询问，每次询问一个整数 $x$ 在数组 $a$ 中是否存在，如果存在，输出 Y，不存在输出 N。

输入

第 $1$ 行是一个整数 $n$（$5≤n≤10^5$）；

第 $2$ 行有 $n$ 个整数，数与数之间用空格隔开；

第 $3$ 行有一个整数$m$（$5≤m≤10^5$）；

第 $4$ 行有 $m$ 个整数，数与数之间用空格隔开；

输出

输出 $m$ 次查询每次查询的结果（Y 或者 N），每次查询结果之间用空格隔开。

解题思路

AC代码

AC代码

#include <iostream>
#include <algorithm>
using namespace std;

const int N = 1e5 + 10;
int a[N];
int n, m;

bool binarySearch(int x) {
    int left = 0, right = n - 1;
    while (left <= right) {
        int mid = left + (right - left) / 2;
        if (a[mid] == x) {
            return true;
        } else if (a[mid] < x) {
            left = mid + 1;
        } else {
            right = mid - 1;
        }
    }
    return false;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    cin >> n;
    for (int i = 0; i < n; ++i) {
        cin >> a[i];
    }
    sort(a, a + n);

    cin >> m;
    for (int i = 0; i < m; ++i) {
        int x;
        cin >> x;
        if (binarySearch(x)) {
            cout << "Y ";
        } else {
            cout << "N ";
        }
    }

    return 0;
}
