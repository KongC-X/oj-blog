3346 - 百鸡问题

题目描述

“百鸡问题”是出自我国古代《张丘建算经》的著名数学问题。大意为：“每只公鸡 555 元，每只母鸡 333 元，每 333 只小鸡 111 元；现在有 100100100 元，买了 100100100 只鸡，共有多少种方案？”

小明很喜欢这个故事，他决定对这个问题进行扩展，并使用编程解决：如果每只公鸡 xxx 元，每只母鸡 yyy 元，每 zzz 只小鸡 111 元；现在有 nnn 元，买了 mmm 只鸡，共有多少种方案？

输入

输入一行，包含五个整数，分别为问题描述中的 x、y、z、n、mx、y、z、n、mx、y、z、n、m。约定 1≤x,y,z≤101 ≤ x, y, z ≤ 101≤x,y,z≤10，1≤n,m≤10001 ≤ n, m ≤ 10001≤n,m≤1000。

输出

输出一行，包含一个整数 CCC，表示有 CCC 种方案。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;
int main(){
    int i,j,k,x,y,z,n,m,s = 0;
    cin >> x >> y >> z >> n >> m;
    for (int i = 0; i <= m; i++)
    {
        for (int j = 0; j <= m - i; j++)
         {
              if ( x * i + j * y + (m - i - j) / z == n && (m - i - j) % z == 0) s++;
         }
    }
    cout << s << endl;
}
