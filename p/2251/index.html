2251 - 最大上升子序列和

题目描述

一个数的序列 bib_ibi​，当 b1<b2<⋯<bsb_1 \lt b_2 \lt \dots \lt b_sb1​<b2​<⋯<bs​ 的时候，我们称这个序列是上升的。

对于给定的一个序列 (a1,a2,…,ana_1, a_2, \dots ,a_na1​,a2​,…,an​)，我们可以得到一些上升的子序列 ($a

i1$, $a

i2,,,\dots,,,a
$ikikik)，这里 1≤i1<i2<⋯<ik≤N1 \le i1 \lt i2 \lt \dots \lt ik \le N1≤i1<i2<⋯<ik≤N。

比如，对于序列 (1,7,3,5,9,4,8)(1, 7, 3, 5, 9, 4, 8)(1,7,3,5,9,4,8)，有它的一些上升子序列，如 (1,7)(1, 7)(1,7)， (3,4,8)(3, 4, 8)(3,4,8) 等等。这些子序列中序列和最大为 181818，为子序列(1,3,5,9)(1, 3, 5, 9)(1,3,5,9)的和。

你的任务，就是对于给定的序列，求出最大上升子序列和。注意，最长的上升子序列的和不一定是最大的，比如序列 (100,1,2,3)(100, 1, 2, 3)(100,1,2,3) 的最大上升子序列和为 100100100，而最长上升子序列为 (1,2,3)(1, 2, 3)(1,2,3)。

输入

输入的第一行是序列的长度 NNN (1≤N≤1000)(1 \le N \le 1000)(1≤N≤1000)。

第二行给出序列中的 NNN 个整数，这些整数的取值范围都在 000 到 100001000010000（可能重复）。

输出

最大上升子序列和。

AC代码

#include <iostream>
using namespace std;

/*
dp[i]：以第i个数结尾的最大子序列的和 
*/
int a[1010],n,dp[1010],ans;
int main() {
    cin>>n;
    for(int i = 1;i <= n;i++){
        cin>>a[i];
        dp[i] = a[i];
    } 
    
    for(int i = 1;i <= n;i++){
        for(int j = 1;j < i;j++){
            if(a[i] > a[j]) dp[i] = max(dp[i],dp[j] + a[i]);
        }
        
        ans = max(ans,dp[i]);
    }
    
    cout<<ans;
    return 0;
}
