1700 - 请输出所有的2位数中，含有数字2的整数

题目描述

请输出所有的 222 位数中，含有数字 222 的整数有哪些，每行 111 个，按照由小到大输出。

比如： 12、20、21、22、23…12、20、21、22、23 \dots12、20、21、22、23… 都是含有数字 222 的整数。

输入

无。

输出

按题意要求由小到大输出符合条件的整数，每行 111 个。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int i = 10,a,b;
    while(i < 100) {
        a = i / 10;
        b = i % 10;
        if(a == 2 || b == 2) {
            cout << i << endl;
        }
        i++;
    }
}
