P10109 [GESP202312 六级] 工作沟通

洛谷 | 普及- | C++14 | 提交时间: 2026-06-02

算法标签：图论、2023、深度优先搜索 DFS、图遍历、最近公共祖先 LCA、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1138

题目描述

某公司有 $N$ 名员工，编号从 $0$ 至 $N-1$。其中，除了 $0$ 号员工是老板，其余每名员工都有一个直接领导。我们假设编号为 $i$ 的员工的直接领导是 $f_i$。

该公司有严格的管理制度，每位员工只能受到本人或直接领导或间接领导的管理。具体来说，规定员工 $x$ 可以管理员工 $y$，当且仅当 $x=y$，或 $x=f_y$，或 $x$ 可以管理 $f_y$。特别地，$0$ 号员工老板只能自我管理，无法由其他任何员工管理。

现在，有一些同事要开展合作，他们希望找到一位同事来主持这场合作，这位同事必须能够管理参与合作的所有同事。如果有多名满足这一条件的员工，他们希望找到编号最大的员工。你能帮帮他们吗？

输入格式

第一行一个整数 $N$，表示员工的数量。

第二行 $N - 1$ 个用空格隔开的正整数，依次为 $f_1,f_2,\dots f_{N−1}$。

第三行一个整数 $Q$，表示共有 $Q$ 场合作需要安排。

接下来 $Q$ 行，每行描述一场合作：开头是一个整数 $m$（$2 \le m \le N$），表示参与本次合作的员工数量；接着是 $m$ 个整数，依次表示参与本次合作的员工编号（保证编号合法且不重复）。

保证公司结构合法，即不存在任意一名员工，其本人是自己的直接或间接领导。

输出格式

输出 $Q$ 行，每行一个整数，依次为每场合作的主持人选。

样例

样例输入 #1

5
0 0 2 2
3
2 3 4
3 2 3 4
2 1 4```

**样例输出 #1**

2
2
0```

样例输入 #2

7
0 1 0 2 1 2
5
2 4 6
2 4 5
3 4 5 6
4 2 4 5 6
2 3 4```

**样例输出 #2**

2
1
1
1
0```

AC 代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 求公共祖先问题：给定一个树结构（员工与领导关系），对于多次查询，找出参与员工的公共祖先中编号最大的那个。

int p[310];                            // p[i] 表示员工 i 的直接领导（0 号老板 p[0]=0 占位）
int cnt[310];                          // 用于统计每位员工作为祖先被访问的次数
int n;                                 // 员工数量
int q;                                 // 合作场数
int m;                                 // 本次合作人数
int x;                                 // 参与员工编号

int main() {
    cin >> n;
    p[0] = 0;                           // 0 号老板没有领导，指向自己方便处理
    for (int i = 1; i < n; i++) {
        cin >> p[i];                    // 读入 f_i
    }
    cin >> q;
    while (q--) {
        cin >> m;
        // 清空计数器
        for (int i = 0; i < n; i++) cnt[i] = 0;
        // 处理每位参与员工
        for (int i = 0; i < m; i++) {
            cin >> x;
            // 向上遍历从 x 到根的所有祖先（包括自己）
            while (true) {
                cnt[x]++;
                if (x == 0) break;      // 根节点处理完即可停止
                x = p[x];               // 跳到直接领导
            }
        }

        // 找出现次数等于 m 的最大编号员工（即公共祖先中编号最大者）
        int ans = 0;
        for (int i = n - 1; i >= 0; i--) {
            if (cnt[i] == m) {
                ans = i;
                break;
            }
        }
        cout << ans << endl;
    }

    return 0;
}
