1527 - 小X与队列

题目描述

小X正和同学们做列队的练习。

有 nnn 名同学排成一路纵队，编号为 iii 的同学排在从前往后数第 iii 个位置上，即：初始时的队列为 1,2,3,...,n1, 2, 3, ..., n1,2,3,...,n 。

接下来小X会发出若干条指令，每条指令形如“请编号为 xxx 的同学排到最前面来”。（例如：若当前时刻的队列为 5,4,3,2,15, 4, 3, 2, 15,4,3,2,1 ，发出一条 x=2x=2x=2 的指令后，队列变成了 2,5,4,3,12, 5, 4, 3, 12,5,4,3,1 ）。

小X发出了很多很多指令，同学们晕头转向不知道该怎么排列。于是就请你算一算，执行完这些指令后，队列应该变成什么样？

输入

第一行两个用空格隔开的正整数 nnn 和 mmm ，分别表示人数和指令数。

第二行 mmm 个用空格隔开的正整数 xix_ixi​，按顺序表示每次指令的 xxx 值。

输出

输出仅有一行包含 nnn 个正整数，相邻两个数之间用一个空格隔开，表示执行完所有指令后的队列。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

const int N = 1e5 + 10;
bool f[N];
int a[N];//存储所有的指令
int n,m;

// 分析指令可以发现，当一个指令出现多次的时候，比如：2出现了2次，最终结果2出现的位置是以最后一次出现的2为准的，样例：2 3 2，先让2跑到最前面，再让3跑到最前面，再让2跑到最前面；最终，2在最前面。
// 因此：可以逆序循环指令数组，从后向前输出没有出现过的数，如果输出过了，标记一下，避免重复输出。
// 再从1~n循环一下，看哪些数没有标记过，说明从未出现过在指令中，再输出一遍。  

int main(){
    cin>>n>>m;
    //读入所有的指令
    for(int i = 1;i <= m;i++){
        cin>>a[i];
    }

    //逆序循环所有的指令，将没有标记过的指令（倒过来第一次出现的）输出，并标记
    for(int i = m;i >= 1;i--){
        if(f[a[i]] == false){
            cout<<a[i]<<" ";
            f[a[i]] = true;//标记这个数字被输出过了
        }
    }

    //将1~n中没有出现过的数组输出
    for(int i = 1;i <= n;i++){
        if(f[i]==false) cout<<i<<" ";
    }
    return 0;
}
