4609 - ABB

题目描述

给定一个字符串 SSS，请统计 SSS 中有多少个 ABBABBABB 形式的子串，以及多少种 ABBABBABB 形式的子串。

例如：S = "nnnseebbetoosee"，ABBABBABB形式的子串有 see、ebb、too、see，共 444 个；不同子串有 see、ebb、too，共 333 种。

输入

输入一个长度不超过 100100100 的字符串 SSS。

输出

输出两个整数，分别表示 SSS 中有多少个 ABBABBABB 形式的子串，以及多少种 ABBABBABB 形式的子串，整数之间以一个空格隔开。

AC代码

AC代码

#include <iostream>
#include <string>
#include <set>
using namespace std;

int main() {
    string s;
    cin >> s;
    int total = 0;  // 总数量
    set<string> unique_abb;  // 存储不同的ABB子串

    // 遍历所有长度为3的子串
    for (int i = 0; i + 2 < s.length(); i++) {
        string sub = s.substr(i, 3);
        // 检查是否符合ABB形式
        if (sub[0] != sub[1] && sub[1] == sub[2]) {
            total++;
            unique_abb.insert(sub);
        }
    }

    cout << total << " " << unique_abb.size() << endl;
    return 0;
}
