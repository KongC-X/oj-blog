B4255 [科大国创杯小学组 2023] 绩点

洛谷 | 入门 | C++14 | 提交时间: 2026-07-19

算法标签：2023、安徽、数组、科创活动、小学活动、科大国创杯

题目背景

转眼间，小可可已经上大学了。他现在面临着绩点焦虑。

在小可可这学期选的一门课上，同学们都在为作业分而拼命开卷。

小可可和同学小多总是说对方是卷怪，现在请你算算到底谁的作业分更高。

题目描述

这门课共有 NNN 个作业，第 iii 次作业的满分为 aia_iai​ 分，小可可在第 iii 次作业中获得了该作业满分的 bi%b_i\%bi​%，小多在第 iii 次作业中获得了该作业满分的 ci%c_i\%ci​%。

请你来判断一下，谁才是那个作业分更高的卷王。

输入格式

第一行一个正整数 NNN，代表作业数目。

第二行 NNN 个正整数，a1,a2,⋯ ,aNa_1, a_2, \cdots, a_Na1​,a2​,⋯,aN​，代表每次作业的总分。

第三行 NNN 个整数，b1,b2,⋯ ,bNb_1, b_2, \cdots, b_Nb1​,b2​,⋯,bN​，代表上文中小可可每次作业的得分率。

第四行 NNN 个整数，c1,c2,⋯ ,cNc_1, c_2, \cdots, c_Nc1​,c2​,⋯,cN​，代表上文中小多每次作业的得分率。

输出格式

如果小可可分数更高，则输出 ke；如果小多分数更高，则输出 do；如果两人分数一样，则输出 same。

样例

样例输入 #1

5
10 10 10 10 20
80 80 80 80 80
100 100 100 100 50```

**样例输出 #1**

do```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;                         // n: 作业次数
    cin >> n;
    int a[10010];                  // 每次作业的满分
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    int b[10010];                  // 小可可的得分率
    for (int i = 0; i < n; i++) {
        cin >> b[i];
    }
    int c[10010];                  // 小多的得分率
    for (int i = 0; i < n; i++) {
        cin >> c[i];
    }

    long long ke = 0;              // 小可可的总分
    long long d = 0;               // 小多的总分
    for (int i = 0; i < n; i++) {
        ke += a[i] * 1LL * b[i];
        d += a[i] * 1LL * c[i];
    }

    if (ke > d) {
        cout << "ke" << endl;
    } else if (ke < d) {
        cout << "do" << endl;
    } else {
        cout << "same" << endl;
    }

    return 0;
}
