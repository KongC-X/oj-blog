B4150 [厦门小学生 C++ 2022] 打车收费

洛谷 | 入门 | C++14 | 提交时间: 2026-07-16

算法标签：2022、福建、分支结构、科创活动、小学活动

题目背景

本试题为 2022 年厦门市小学生 C++ 语言复赛试题，数据为洛谷自造。

初赛为笔试。

题目描述

高老师的家离学校非常远，为了在路上不耽误时间，高老师常常打车上下班，高老师所在的城市出租车收费标准如下：333 公里内（包括 333 公里）起步价为 101010 元，333 公里以上 888 公里以内（包括 888 公里）的每公里收 333 元，超出 888 公里的每公里收 555 元。现在高老师请会编程的你来帮他算算：不同里程数需要支付的打车费用，假定所有数据均为整数，现输入里程数，输出应付的车费。

输入格式

一个正整数，表示里程数。

输出格式

输出一行，包括一个整数，表示应付的车费。

样例

样例输入 #1

2```

**样例输出 #1**

10```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：分段计费
    // 3公里内：10元
    // 3~8公里：起步价10元 + 超出3公里的部分每公里3元
    // 超过8公里：起步价10元 + 5公里*3元 + 超出8公里的部分每公里5元
    int d;                           // d: 里程数
    cin >> d;

    int ans;                         // ans: 总费用
    if (d <= 3) {
        ans = 10;
    } else if (d <= 8) {
        ans = 10 + (d - 3) * 3;
    } else {
        ans = 25 + (d - 8) * 5;      // 10 + 5*3 = 25
    }

    cout << ans << endl;
    return 0;
}
