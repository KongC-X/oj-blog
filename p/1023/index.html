1023 - 判断素数

题目描述

任意输入一个整数，判断它是否为素数。是的话输出 T，不是的话输出 F。

质数（primeprimeprime numbernumbernumber）又称素数，质数定义为在大于 111 的自然数中，除了 111 和它本身以外不再有其他因数。

输入

输入只有一行，包括 111 个整数。（ 1≤n≤1091 \le n \le 10^91≤n≤109 ）

输出

输出只有一行。

解题思路

AC代码

AC代码

#include<iostream>
#include<cmath>
using namespace std;

int main(){
    int n,i,k = 0;
    cin >> n;
    // n - 1会超时,需要使用sqrt(n)
    for(i = 2;i <= sqrt(n);i++){
        if(n % i == 0){
            k++; // 如果是因子，计数器加1
        }
    }
    // 需要考虑n = 1的情况
    if(k == 0 && n > 1) {
        cout << "T" << endl;
    } else {
        cout << "F" << endl;
    }
}
