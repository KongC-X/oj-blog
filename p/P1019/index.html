P1019 [NOIP 2000 提高组] 单词接龙（疑似错题）

洛谷 | 普及| C++14 | 提交时间: 2026-04-29

算法标签：字符串、动态规划 DP、搜索、递推、2000、NOIP 提高组、状压 DP

题目背景

注意：本题为上古 NOIP 原题，不保证存在靠谱的做法能通过该数据范围下的所有数据。本题的难度仅代表设计算法可以通过本题原始数据的难度。

本题为搜索题，本题不接受 hack 数据。关于此类题目的详细内容

NOIP2000 提高组 T3

题目描述

单词接龙是一个与我们经常玩的成语接龙相类似的游戏，现在我们已知一组单词，且给定一个开头的字母，要求出以这个字母开头的最长的“龙”（每个单词都最多在“龙”中出现两次），在两个单词相连时，其重合部分合为一部分，例如 beast 和 astonish，如果接成一条龙则变为 beastonish，另外相邻的两部分不能存在包含关系，例如 at 和 atide 间不能相连。

输入格式

输入的第一行为一个单独的整数 nnn 表示单词数，以下 nnn 行每行有一个单词，输入的最后一行为一个单个字符，表示“龙”开头的字母。你可以假定以此字母开头的“龙”一定存在。

输出格式

只需输出以此字母开头的最长的“龙”的长度。

样例

样例输入 #1

5
at
touch
cheat
choose
tact
a

样例输出 #1

23

AC 代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int n;                // 单词总数
int t;                // 当前龙的累计长度
int ans;              // 记录最长龙的长度
int v[50];            // v[i] 表示第 i 个单词已使用的次数（最多2次）
string s[50];         // 存储所有单词（下标从1开始）

// 深度优先搜索：尝试在当前单词 x 的尾部继续接上其他单词
// x 是当前龙中最后一个单词的完整字符串
void dfs(string x) {
    ans = max(ans, t);          // 用当前龙的长度更新最大值
    int g = x.size();           // 当前龙尾单词的长度

    // 枚举所有单词，尝试接在尾部
    for (int i = 1; i <= n; i++) {
        if (v[i] < 2) {         // 每个单词最多用两次
            int len;
            // 寻找重叠长度：x 的末尾与 s[i] 的开头相同的最大长度
            // len 从 1 开始，不能等于或超过两个单词的完整长度（避免包含关系）
            for (len = 1; len < g && len < s[i].size(); len++) {
                if (x.substr(g - len, len) == s[i].substr(0, len)) {
                    break;      // 找到第一个可行重叠长度就停止
                }
            }
            // 如果找到的重叠长度合法（既小于 x 的长度，也小于 s[i] 的长度）则可以拼接
            if (len < g && len < s[i].size()) {
                v[i]++;                    // 使用次数+1
                t += s[i].size() - len;    // 龙的长度增加（s[i]的长度减去重叠部分）
                dfs(s[i]);                 // 以新接的单词为尾部继续搜索
                t -= s[i].size() - len;    // 回溯：恢复长度
                v[i]--;                    // 回溯：恢复使用次数
            }
        }
    }
}

int main() {
    char c;                // 起始字母
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> s[i];       // 输入所有单词
    }
    cin >> c;

    // 尝试所有以起始字母开头的单词作为龙头
    for (int i = 1; i <= n; i++) {
        if (s[i][0] == c) {
            v[i]++;                // 标记该单词使用了一次
            t = s[i].size();       // 初始龙的长度就是第一个单词的长度
            dfs(s[i]);             // 从该单词开始搜索
            v[i]--;                // 回溯（虽然这里只执行一次，但保持对称）
        }
    }

    cout << ans;           // 输出最大长度
    return 0;
}
