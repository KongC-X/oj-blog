2029 - 缺失的数字

题目描述

有 $n$ 个数字，值就是 $1$ ~ $n$ ，现发现丢失了 $2$ 个数字，请你根据剩余的 $n$ - $2$ 个数字，编程计算一下，缺失的是哪两个数字呢？

输入

第 $1$ 行为整数 $N$ ($N \le 100000$)。

第 $2$ 行有 $N-2$ 个整数(均用空格隔开)表示了剩下 $N-2$ 个数字的值。

输出

一行，按数字从小到大顺序输出两缺失的数字。两个数字之间用一个空格隔开。

解题思路

AC代码

AC代码

#include<iostream>
using namespace std;

int a[100010],x;
int main() {
    int n;
    cin>>n;
    for(int i=1; i<=n-2; i++){
        cin>>x;
        a[x]=1;//标记出现过的数
    }
        
    for(int i=1; i<=n; i++) {
        if(a[i]==0)
            cout<<i<<" ";
    }
    return 0;
}
