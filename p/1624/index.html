1624 - 超市的折扣

题目描述

小区新超市开张搞活动，凡购买总金额满 200200200 元及超过 200200200 元的顾客可以打 888 折（打 888 折的意思是总价 ×0.8\times 0.8×0.8） 。

比如，购买了 212212212 元的商品，那么实际付款（=212×0.8=169.6= 212 \times 0.8 = 169.6=212×0.8=169.6 元），购物不满 200200200 元的顾客可以打 999 折。

小芳买了 333 件商品，请根据超市的活动编程计算一下，小芳实际需要付多少钱？

输入

三个小数，代表小芳购买的三件商品的价格。

输出

一个小数，表示小芳按照超市的活动实际应付的价格（结算结果保留 111 位小数）。

解题思路

AC代码

AC代码

# include <iostream>
# include <iomanip>
using namespace std;

int main() {
    double s,a,b,c;
    cin >> a >> b >> c;
    s = a + b + c;
    if(s >= 200) {
        cout << fixed << setprecision(1) << s * 0.8 << endl;
    } else {
        cout << fixed << setprecision(1) << s * 0.9 << endl;
    }
}
