2119 - 任务的最少完成时间

题目描述

小 AAA 同学接到了 nnn 个需要完成的任务，这 nnn 个任务必须按照接到的顺序完成，每个任务的完成时间为 aia_iai​。

由于任务非常艰巨，小 AAA 同学从老师那里领到了一张减负卡，用这张卡，小 AAA 可以从 nnn 个任务中任意的删除 kkk 个连续的任务，只需要完成剩余的任务。

请问，小 AAA 完成所有任务的总时间最少是多少？

输入

第 111 行，有两个整数 nnn 和 kkk（1≤n≤1061≤n≤10^61≤n≤106，0≤k≤1060≤k≤10^60≤k≤106）。

接下来有 nnn 个整数，每个整数 aia_iai​ 表示每个任务的完成时间。（1≤ai≤10121≤a_i≤10^{12}1≤ai​≤1012）

输出

一个整数，表示小 AAA 任务完成的最少时间。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 有n个数，可以删除连续的k个数
// 求剩余任务时间和的最小值相当于求连续删除的k个数的和的最大值
int n,k;
const int N = 1000010;
typedef long long LL;
LL a[N],b[N],ma;
int main() {
    scanf("%d%d",&n,&k);
    for(int i = 1;i <= n;i++) {
        scanf("%d",&a[i]);
        b[i] = b[i - 1] + a[i]; // 求前缀和
    }
    // 求从每个数开始连续k个数的和，在所有的和中求最大值
    for(int i = 1;i <= n - k + 1;i++) {
        // 区间范围：i ~ i + k - 1
        ma = max(ma,b[i + k - 1] - b[i - 1]);
    }
    // 求剩余任务时间和的最小值
    cout << b[n] - ma << endl;
}
