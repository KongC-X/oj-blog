4985 - 排序

题目描述

体育课上有 nnn 名同学排成一队，从前往后数第 iii 位同学的身高为 hih_ihi​ ，体重为 wiw_iwi​。目前排成的队伍看起来参差不齐，老师希望同学们能按照身高从高到低的顺序排队，如果身高相同则按照体重从重到轻排序。在调整队伍时，每次只能交换相邻两位同学的位置。老师想知道，最少需要多少次交换操作，才能将队伍调整成目标顺序。

输入

第一行，一个正整数 nnn ，表示队伍人数。

接下来 nnn 行，每行两个正整数 hih_ihi​ 和 wiw_iwi​，分别表示第 iii 位同学的身高和体重。

输出

输出一行，一个整数，表示最少需要的交换次数。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

struct Student {
    int h;
    int w;
};

int main() {
    int n,i,s = 0;
    Student a[3030];
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> a[i].h >> a[i].w;
    }
    for(i = 0;i < n - 1;i++) {
        for(int j = 0;j < n - i - 1;j++) {
            if(a[j].h < a[j + 1].h || (a[j].h == a[j + 1].h && a[j].w < a[j + 1].w)) {
                swap(a[j], a[j + 1]);
                s++;
            }
        }
    }
    cout << s << endl;
}
