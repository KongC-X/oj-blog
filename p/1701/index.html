1701 - 请输出所有的3位对称数

题目描述

请输出所有的 333 位对称数，对称数指的是一个整数 nnn 正过来和倒过来是一样的，比如：101、121、282…101、121、282 \dots101、121、282…

请从小到大输出符合条件的3位对称数，每行 111 个。

输入

无。

输出

从小到大按题意输出符合条件的数，每行 111 个。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int i = 100,a,b;
    while(i < 1000) {
        a = i / 100;
        b = i % 10;
        if(a == b) {
            cout << i << endl;
        }
        i++;
    }
}
