1277 - 合唱队形求解

题目描述

$N$ 位同学站成一排，音乐老师要请其中的 $(N-K)$ 位同学出列，使得剩下的 $K$ 位同学不交换位置就能排成合唱队形。

合唱队形是指这样的一种队形：设 $K$ 位同学从左到右依次编号为 $1, 2, \dots , K$，他们的身高分别为 $T_1, T_2, \dots , T_K$，则他们的身高满足 $T_1 \lt T_2 \lt \dots \lt T_i \gt T$$i+1$ $ \gt \dots \gt T_K$ ($1 \le i \le K$)。

你的任务是，已知所有 $N$ 位同学的身高，计算最少需要几位同学出列，可以使得剩下的同学排成合唱队形。

输入

输入的第一行是一个整数 $N$（$2 \le N \le 100$），表示同学的总数。

第二行有 $N$ 个整数，用空格分隔，第 $i$ 个整数 $T_i$（$130 \le T_i \le 230$）是第 $i$ 位同学的身高（厘米）。

输出

输出包括一行，这一行只包含一个整数，就是最少需要几位同学出列。

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

/*
求最长不下降子序列长度，动态转移方程：
    dp[i]=1
    dp[i]=max(dp[j]+1,dp[i])
    j是1 . .i-1 之间的数， a[j]<a[i]
*/
//dpa:从左至右求到每个点的最长不下降子序列的长度
//dpb:从右至左求到每个点的最长不下降子序列的长度
int i,n,j,a[110],dpa[110],dpb[110],ans;

int main() {
    cin >> n;
    for (i = 1; i <= n; i++) {
        cin >> a[i];
    }
    // 递推求 dpa 的值
    for (i = 1; i <= n; i++) {
        dpa[i] = 1; // 默认边界
        for (j = 1; j < i; j++) {
            if (a[j] < a[i]) {
                dpa[i] = max(dpa[i], dpa[j] + 1);
            }
        }
    }
        // 反过来求 dpb[i]
        for (i = n; i >= 1; i--) {
            dpb[i] = 1;
            for (j = n; j > i; j--) {
                if (a[j] < a[i]) {
                    dpb[i] = max(dpb[i], dpb[j] + 1);
                }
            }
        }
        // 求解能留下的最多的人数
        for (i = 1; i <= n; i++) {
            ans = max(ans, dpa[i] + dpb[i] - 1);
        }
        // 计算要出队伍的人数
        cout << n - ans;
        return 0;
}
