P1809 过河问题

洛谷 | 普及+/提高-| C++14 | 提交时间: 2026-07-24

算法标签：贪心、NOI 导刊

题目描述

有一个大晴天，Oliver 与同学们一共 NNN 人出游，他们走到一条河的东岸边，想要过河到西岸。而东岸边有一条小船。

船太小了，一次只能乘坐两人。每个人都有一个渡河时间 TTT，船划到对岸的时间等于船上渡河时间较长的人所用时间。

现在已知 NNN 个人的渡河时间 TTT，Oliver 想要你告诉他，他们最少要花费多少时间，才能使所有人都过河。

注意，只有船在东岸（西岸）的人才能坐上船划到对岸。

输入格式

输入文件第一行为人数 NNN，以下有 NNN 行，每行一个数。

第 i+1i+1i+1 行的数为第 iii 个人的渡河时间。

输出格式

输出文件仅包含一个数，表示所有人都渡过河的最少渡河时间。

样例

样例输入 #1

4
6
7
10
15

样例输出 #1

42

AC 代码

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100010;
long long a[MAXN];                     // 存储每个人的渡河时间（已排序）

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    /*
      思路（经典过河问题）：
      每次将最慢的两个人送过河，有两种策略：
      1. 最快者来回接送：最快的两个人先过去，最快者回来，再带一个慢的过去。
         耗时 = a[1] + 2*a[2] + a[i]   (1-based, a[1]最快)
      2. 最快者反复送慢的：最快者带最慢的过去，回来，再带次慢的过去，回来。
         耗时 = 2*a[1] + a[i] + a[i-1]
      每次选择耗时较小的策略，直到剩余人数 ≤ 3。
      
      边界：
      - 剩1人：耗时 = a[1]
      - 剩2人：耗时 = a[2]（两人一起过，取较慢者）
      - 剩3人：耗时 = a[1] + a[2] + a[3]（最快者带最慢者过去，回来，再带次慢者过去）
    */
    
    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    
    sort(a + 1, a + n + 1);            // 按时间升序
    
    long long ans = 0;
    int i = n;
    
    // 每次处理最慢的两个人，直到剩余人数 <= 3
    while (i >= 4) {
        long long plan1 = 2 * a[1] + a[i] + a[i - 1];   // 最快者来回送
        long long plan2 = a[1] + 2 * a[2] + a[i];       // 最快和次快合作送
        if (plan1 < plan2) {
            ans += plan1;
        } else {
            ans += plan2;
        }
        i -= 2;                        // 送走最慢的两人
    }
    
    // 处理剩余的人数
    if (i == 3) {
        ans += a[1] + a[2] + a[3];     // 最快者带两人过河
    } else if (i == 2) {
        ans += a[2];                   // 两人一起过
    } else if (i == 1) {
        ans += a[1];                   // 一人直接过
    }
    
    cout << ans << endl;
    return 0;
}
