B2118 验证子串

洛谷 | 入门 | C++14 | 提交时间: 2026-07-12

算法标签：字符串（入门）

题目描述

输入两个字符串，验证其中一个串是否为另一个串的子串。

输入格式

两行，每行一个字符串。

输出格式

若第一个串 s1s_1s1​ 是第二个串 s2s_2s2​ 的子串，则输出(s1) is substring of (s2)；

否则，若第二个串 s2s_2s2​ 是第一个串 s1s_1s1​ 的子串，输出(s2) is substring of (s1)；

否则，输出 No substring。

样例

样例输入 #1

abc
dddncabca```

**样例输出 #1**

abc is substring of dddncabca```

样例输入 #2

aaa
bbb```

**样例输出 #2**

No substring```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    string s1, s2;
    cin >> s1 >> s2;

    // 检查 s1 是否为 s2 的子串
    if (s2.find(s1) != string::npos) {
        cout << s1 << " is substring of " << s2 << endl;
    }
    // 检查 s2 是否为 s1 的子串
    else if (s1.find(s2) != string::npos) {
        cout << s2 << " is substring of " << s1 << endl;
    }
    // 都不是子串
    else {
        cout << "No substring" << endl;
    }

    return 0;
}
