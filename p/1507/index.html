1507 - 重复的学号

题目描述

SW是课代表，老师判好卷子之后让他录成绩，他念了 nnn 个人的学号(学号是一个绝对值 10910^9109 以内的整数包括 000 ，没有负数)，但是老师总觉得他念重复了。

还好老师用声控软件记录下了他念的每一个学号，现在请你写程序来判断SW有没有念过某个或者某些学号 222 次及以上。

如果有请你输出 111，否则输出 000。

输入

一个正整数 nnn( 1≤n≤1000001 \le n \le 1000001≤n≤100000 )代表SW念了学号的个数；

之后第 222 行到第 n+1n+1n+1 行，每行一个 10910^9109 以内的整数(包括 000 没有负数)，代表某个同学的学号。

输出

输出一个整数，如果有重复的学号输出 111 ，否则输出 000 。

解题思路

AC代码

AC代码

#include<iostream>
#include<set>
#include<map>
#include<vector>

using namespace std;

map<int, int>m;

int main()
{
    int n, a, flag = 0;
    cin>>n;
    while(n--)
    {
        cin>>a;
        if(m[a] == 0)
            m[a] = 1;
        else
            flag = 1;
    }
    cout<<flag<<endl;
    return 0;
}
