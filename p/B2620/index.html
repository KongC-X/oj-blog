题目描述

输入两个整数 aaa 和 bbb（其绝对值不超过 100001000010000），想知道：

  1. aaa 是否大于 bbb？
  2. aaa 是否小于或等于 bbb？
  3. aaa 是否不等于 bbb？

输入格式

输入两个整数 a 和 b。

输出格式

输出 3 个整数，用空格隔开。对于每一个询问，如果成立（条件为真）输出 1，否则输出 0。

样例

样例输入 #1

2 3

样例输出 #1

0 1 1```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    cout << (a > b) << ' ' << (a <= b) << ' ' << (a != b) << endl;
    return 0;
}
