1337 - 求花坛的面积

题目描述

龙湖校区有一个圆形花坛，量得花坛周围的篱笆长是 $x$ 米，请问该花坛的面积是多少平方米？（假设 $π=3.14$）。（5.2.99）

输入

一个小数 $x$。

输出

花坛的面积（结果保留 $2$ 位小数）

解题思路

AC代码

AC代码

#include <iostream>
#include <iomanip>
using namespace std;	

int main() {
    double x = 3.14,a;
    cin >> a;
    double r = a / 2 / x; // 半径
    double s = x * r * r; // 面积
    cout << fixed << setprecision(2) << s << endl;
}
