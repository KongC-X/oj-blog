题目描述

天然气计费采用阶梯计费。

第一档收费标准：年用气量在 0∼310(含)0\sim 310(含)0∼310(含) 立方米，价格为 333 元/立方米；
第二档收费标准：年用气量在 310∼520(含)310\sim 520(含)310∼520(含) 立方米，价格为 3.33.33.3 元/立方米；
第三档收费标准：年用气量在 520520520 立方米以上，价格为 4.24.24.2 元/立方米。

例如，小 Z 家今年用气量为 600600600 立方米，费用为 310×3+(520−310)×3.3+(600−520)×4.2=930+693+336=1959310\times 3 + (520-310)\times 3.3 + (600-520)\times 4.2=930+693+336=1959310×3+(520−310)×3.3+(600−520)×4.2=930+693+336=1959 元。

现在给出小 Z 家 111 至 121212 月的用气量，请输出小 Z 家每个月的天然气费用。

输入格式

共 121212 行，其中第 iii 行包含一个整数，表示 iii 月的用气量，单位为立方米。

输出格式

共 121212 行，第 iii 行包含一个小数，表示这个月的天然气费用，结果保留至小数点后 111 位。

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3988 [语言月赛 202406] 天然气计价
     * 题意：阶梯计费，年用气量累计。每月给出用气量，计算该月费用。
     * 第一档：0~310，3元/立方米
     * 第二档：310~520，3.3元/立方米
     * 第三档：520以上，4.2元/立方米
     *
     * 思路：维护累计年用气量 t。对于每个月用气量 x，
     * 计算这 x 立方米中，分别有多少落入第一、二、三档。
     * 第一档剩余 = max(0, 310 - t)
     * 第二档剩余 = max(0, 520 - max(310, t))
     * 然后按顺序消耗 x，计算费用。
     * 最后更新 t += x，输出费用（保留一位小数）。
     */
    long long t = 0;          // t: 累计年用气量
    for (int i = 0; i < 12; i++) {
        long long x;          // x: 本月用气量
        cin >> x;

        // 计算第一档剩余量
        long long r1 = 0;
        if (t < 310) r1 = 310 - t;

        // 计算第二档剩余量
        long long r2 = 0;
        if (t < 520) {
            long long s = max(310LL, t);
            r2 = 520 - s;
        }

        // 分配本月用气量
        long long u1 = min(x, r1);          // 第一档用量
        long long u2 = min(x - u1, r2);     // 第二档用量
        long long u3 = x - u1 - u2;         // 第三档用量

        double f = u1 * 3.0 + u2 * 3.3 + u3 * 4.2;  // f: 本月费用

        t += x;              // 更新累计用气量

        cout << fixed << setprecision(1) << f << endl;
    }
    return 0;
}
