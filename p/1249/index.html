1249 - 搬砖问题

题目描述

363636 块砖， 363636 人搬。男搬 444 ，女搬 333 ，两个小儿抬一砖。

要求一次全搬完。问需男、女、小儿各若干？

注意：假设男、女、小孩都有，请按照男、女、小孩的顺序输出所有可能的人数分配，每种人数分配方案占 111 行，每个数字空格隔开。

输入

无

输出

所有可能的人数分配方案，按照由小到大输出。

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int i,j,k;
    for(i = 1;i <= 36/4;i++){
        for(j = 1;j <= 36/3;j++){
            for(k = 1;k <= 200;k++) {
                if(i * 4 + j * 3 + k / 2 == 36 && k % 2 == 0 && i + j + k == 36) {
                    cout << i << " " << j << " " << k << endl;
                }
            }
        }
    }
    return 0;
}
