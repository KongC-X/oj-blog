P9459 「EZEC-14」浴眼盯真

洛谷 | 入门 | C++14 | 提交时间: 2026-07-27

算法标签：模拟、洛谷原创、O2优化、洛谷月赛

题目背景

验题人提示：本题数据在 windows 下生成，即换行符为 \r\n。

题目描述

dXqwq 定义一个字符串四元组 (a,b,c,d)(a,b,c,d)(a,b,c,d) 是“浴眼盯真”的，当且仅当：

  • a,ba,ba,b 的首字母均为 y\texttt{y}y。
  • ccc 恰好等于 ding\texttt{ding}ding。
  • ddd 恰好等于 zhen\texttt{zhen}zhen。

给定四个用空格分隔的字符串 a,b,c,da,b,c,da,b,c,d，保证其只包含小写英文字母，你需要判断 (a,b,c,d)(a,b,c,d)(a,b,c,d) 是否是“浴眼盯真”的。

输入格式

本题有多组测试数据。

第一行输入一个整数 TTT，代表测试数据组数。

接下来 TTT 行，每行输入四个用空格分隔的字符串 a,b,c,da,b,c,da,b,c,d。

输出格式

对于每组数据输出一行。

如果 (a,b,c,d)(a,b,c,d)(a,b,c,d) 是“浴眼盯真”的，输出 Yes，否则输出 No。

样例

样例输入 #1

5
yi yan ding zhen
yu yan ding zhen
zheng tai ding zhen
yin yang guai qi
you xiu su zhi

样例输出 #1

Yes
Yes
No
No
No```

## AC 代码

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 思路：
    // 读取测试数据组数 T，对于每组数据读入四个字符串 a,b,c,d，
    // 检查三个条件：
    //   1. a 和 b 的第一个字母都是 'y'
    //   2. c == "ding"
    //   3. d == "zhen"
    // 全部满足输出 Yes，否则输出 No。

    int T;                  // T: 测试数据组数
    cin >> T;

    string a, b, c, d;      // 四个字符串
    while (T--) {
        cin >> a >> b >> c >> d;

        if (a[0] == 'y' && b[0] == 'y' && c == "ding" && d == "zhen") {
            cout << "Yes" << endl;
        } else {
            cout << "No" << endl;
        }
    }

    return 0;
}
