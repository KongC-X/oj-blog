1238 - 统计每个月兔子的总数

题目描述

有一对兔子，从出生后第 333 个月起每个月都生一对兔子，一对小兔子长到第三个月后每个月又生一对兔子，假如兔子都不死。

问第 nnn 个月（ n≤50n \le 50n≤50 ）的兔子总数为多少对？

输入

输入 111 个整数 nnn ，表示第几个月。

输出

第 nnn 个月兔子的总数量有多少对？

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

long long x,y,z;
int main() {
    int n;
    cin >> n;
    x = 1;
    y = 1;
    for (int i = 3; i <= n; i++) {
        z = x + y;
        x = y;
        y = z;
    }
    if(n == 1 || n == 2) {
        cout << 1;
    } else {
        cout << z;
    }
}
