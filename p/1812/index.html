1812 - 排名第二高的成绩

题目描述

帮老师统计一个班级 NNN （10<N<10010 \lt N \lt 10010<N<100）个同学的考试成绩（成绩不可能全一样）中排名第二高的成绩是多少？

输入

第 111 行有一个整数 nnn（5<n<1005 \lt n \lt 1005<n<100）。

第 222 行有 nnn 个整数，用空格隔开。

输出

输出排名第 222 高的成绩。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int n, a[105];
int main(){
    cin >> n;
    for(int i = 1; i <= n; i++) cin >> a[i];
    sort(a+1, a+n+1);
    for(int i = n - 1; i >= 1; i--){
        if(a[i] < a[n]){
            cout << a[i];
            break;
        }
    }
    return 0;
}
