P1017 [NOIP 2000 提高组] 进制转换

洛谷 | 普及- | C++14 | 提交时间: 2026-05-18

算法标签：模拟、数学、2000、NOIP 提高组、进制

题目背景

NOIP 2000 提高组 T1。

题目描述

我们可以用这样的方式来表示一个十进制数：将每个阿拉伯数字乘以一个以该数字所处位置为指数，以 101010 为底数的幂，再将这些项相加。例如，123123123 可表示为 1×102+2×101+3×1001 \times 10^2+2\times 10^1+3\times 10^01×102+2×101+3×100。

与之相似，对二进制数来说，也可表示成每个二进制数码乘以一个以该数字所处位置为指数，以 222 为底数的幂，再将这些项相加。

一般说来，任何一个正整数 RRR 或一个负整数 −R-R−R 都可以被选来作为一个数制系统的基数。如果是以 RRR 或 −R-R−R 为基数，则需要用到的数码为 0,1,…,R−10,1,\dots,R-10,1,…,R−1。

例如，当 R=7R=7R=7 时，所需用到的数码是 0,1,2,3,4,5,60,1,2,3,4,5,60,1,2,3,4,5,6，这与其是 RRR 或 −R-R−R 无关。如果作为基数的数绝对值超过 101010，则为了表示这些数码，通常使用英文字母来表示那些大于 999 的数码。例如，对 161616 进制数来说，用 AAA 表示 101010，用 BBB 表示 111111，用 CCC 表示 121212，以此类推。

在负进制数中是用 −R-R−R 作为基数。例如，−15-15−15（十进制）相当于 (110001)−2(110001)_{-2}(110001)−2​（−2-2−2 进制），并且它可以被表示为 222 的幂级数之和：

(110001)−2=1×(−2)5+1×(−2)4+0×(−2)3+0×(−2)2+0×(−2)1+1×(−2)0(110001)_{-2}=1\times (-2)^5+1\times (-2)^4+0\times (-2)^3+0\times (-2)^2+0\times (-2)^1+1\times (-2)^0(110001)−2​=1×(−2)5+1×(−2)4+0×(−2)3+0×(−2)2+0×(−2)1+1×(−2)0

设计一个程序，读入一个十进制数和一个负进制数的基数，并将此十进制数转换为此负进制下的数。

输入格式

输入共一行，包含两个整数 n,Rn,Rn,R，分别表示十进制数和负进制数的基数。

输出格式

输出转换后的负进制数及其基数。若此基数的绝对值超过 101010，则参照 161616 进制的方式处理。

样例

30000 -2```

AC 代码

#include <iostream>
#include <string>     // 使用 string 类型
using namespace std;

int main() {
    // ---------- 思路 ----------
    // 把十进制整数 n 转换成负基数 R（R 是负数，如 -2, -16）。
    // 核心：除 R 取余，但要求余数 r 必须在 0 ~ |R|-1 范围内（非负）。
    // 如果直接 n % R 在 C++ 中可能会得到负数余数，
    // 这时我们通过"借位"来修正：r += |R|，同时商 +1。
    // 这样每一步的 n = R * q + r 依然成立，且数码合法。
    //
    // 方法：循环
    //   r = n % R;       // 可能有负
    //   n = n / R;       // 向零取整的商
    //   if (r < 0) {
    //       r -= R;      // R 是负数，减 R 相当于加上 |R|
    //       n++;         // 商加 1（补偿）
    //   }
    //   把 r 转成字符追加到 string 尾部。
    // 直到 n == 0 结束。
    // 最后逆序输出 string 中的字符。
    // 特例：初始 n == 0 则直接存 "0"。
    // -------------------------

    int n, R;                 // n: 待转换的十进制数，R: 负进制基数（-20~-2）
    cin >> n >> R;
    int orig = n;             // 保存原始 n 供最后输出

    string res;               // 存放结果的每一位字符（低位在前）

    if (n == 0) {
        res += '0';           // 特殊情况：原数为 0
    } else {
        while (n != 0) {
            int r = n % R;    // 尝试求余，C++ 中可能为负数（向零取整）
            n = n / R;        // 对应的商

            // 如果余数是负数，调整为合法数码（0 ~ |R|-1）
            if (r < 0) {
                r -= R;       // 相当于 r += |R|，因为 R 是负数
                n++;          // 商进一，保证等式 n_原 = R*商 + 余数 成立
            }

            // 将数码 r 转成字符追加到结果字符串尾部
            if (r < 10)
                res += '0' + r;
            else
                res += 'A' + r - 10;   // 超过 9 用大写字母
        }
    }

    // 输出格式：原始十进制数 = 结果 (baseR)
    cout << orig << "=";
    for (int i = res.size() - 1; i >= 0; --i)   // 逆序输出
        cout << res[i];
    cout << "(base" << R << ")" << endl;

    return 0;
}
