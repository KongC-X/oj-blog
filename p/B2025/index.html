B2025 输出字符菱形

洛谷 | 入门 | C++14 | 提交时间: 2025-07-31

算法标签：顺序结构

题目描述

用 * 构造一个对角线长 $5$ 个字符，倾斜放置的菱形。

输出格式

如样例所示。用 * 构成的菱形。

样例

样例输入 #1

样例输出 #1

  *
 ***
*****
 ***
  *

AC 代码

#include<bits/stdc++.h>
using namespace std;
int main(){
    cout<<"  *"<<endl;
    cout<<" ***"<<endl;
    cout<<"*****"<<endl;
    cout<<" ***"<<endl;
    cout<<"  *"<<endl;
    return 0;
}
