B3691 [语言月赛202212] 狠狠地切割(Easy Version)

洛谷 | 普及- | C++14 | 提交时间: 2026-09-04

算法标签：二分、2022、O2优化、排序、双指针 two-pointer、语言月赛

题目描述

现给你一个长度为 nnn 的序列 a1,⋯ ,ana _ 1, \cdots, a _ na1​,⋯,an​ 和 mmm 个互不相同的整数 b1,⋯ ,bmb _ 1, \cdots, b _ mb1​,⋯,bm​。你需要按照这 mmm 个数对序列 aaa 进行狠狠地切割。

具体的，对于一个数字 i∈[1,n]i \in [1, n]i∈[1,n]，如果存在一个整数 j∈[1,m]j \in [1, m]j∈[1,m]，使得 ai=bja _ i = b _ jai​=bj​，则将位置 iii 称为一个切割点。对序列 aaa 中的每一个切割点，我们在这个位置进行一次狠狠地切割。方法是，将该位置的数字去除，然后在这个位置将其左右的序列/片段一分两半。

如果对狠狠地切割的定义有疑问，可以参照「样例 #1」及「样例解释 #1」进行理解。

你需要计算，在进行了所有可能的狠狠地切割后，序列被切割为了多少片段。

特别的，如果在切割后，某一段内没有数组，那这一段不可被叫做片段。同样的，如果 111 或 nnn 为切割点，其与开头和结尾之间也不存在片段。

如果对片段的概念有疑问，可以参照「样例 #2」及「样例解释 #2」进行理解。

输入格式

第一行为两个整数，依次表示序列 aaa 的长度 nnn 和序列 bbb 的长度 mmm。
第二行有 nnn 个整数，第 iii 个整数表示 aia_iai​。
第三行有 mmm 个整数，第 iii 个整数表示 bib_ibi​。

输出格式

输出一个整数，代表狠狠地切割后的片段的个数。

样例

样例输入 #1

6 2
3 4 3 5 2 6
5 4```

**样例输出 #1**

3```

样例输入 #2

6 3
3 4 3 5 2 6
3 5 6```

**样例输出 #2**

2```

AC 代码

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 500005;
const int MAXV = 5000005;
int a[MAXN];
bool flag[MAXV];   // flag[x] 表示 x 是否在 b 中

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, m;
    cin >> n >> m;

    for (int i = 0; i < n; i++) cin >> a[i];

    for (int i = 0; i < m; i++) {
        int x;
        cin >> x;
        flag[x] = true;
    }

    int ans = 0;
    bool inSeg = false;   // 当前是否处于一个非切割片段中

    for (int i = 0; i < n; i++) {
        if (flag[a[i]]) {          // 是切割点
            inSeg = false;
        } else {                   // 非切割点
            if (!inSeg) {
                ans++;             // 开始一个新片段
                inSeg = true;
            }
        }
    }

    cout << ans << '\n';
    return 0;
}
