1256 - 借书方案知多少

题目描述

小明有五本新书，要借给A，B，C三位小朋友，若每人每次只能借一本，则可以有多少种不同的借法？

输入

无

输出

输出一个整数，表示有多少种借法

解题思路

AC代码

AC代码

#include<iostream>
#include<cmath>
using namespace std;
int main(){
    //i,j,k分别代表借给A，B，C的书
    //num用作计数有多少种借法，初始值为0 
    int i,j,k,num=0;
    //先借给A一本书，有5种情况，进行遍历 
    for(i=1;i<=5;i++){
        //然后借给B一本书，还剩4本书，所以有4种情况，进行遍历 
        for(j=2;j<=5;j++){
            //最后借给C一本书，还剩3本书，所以有3种情况，进行遍历 
            for(k=3;k<=5;k++){
                //每循环一次，借法加1 
                num++;
            }
        }
    } 
    //输出总借法 
    cout<<num;
    return 0;
}
