1070 - 字符图形6-星号倒三角

题目描述

输入一个整数打印字符图形。

输入

一个整数（$０ \lt n \lt 10 $ ）。

输出

一个字符图形，如：$n=3$，则输出图形如下：

`×××××
□×××
□□×
`

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin>>n;
    int i,j;
    for(i=1;i<=n;i++){
        //每行输出i-1个空格 
        for(j=1;j<=i-1;j++){
            cout<<" ";
        }
        //每行输出 2*(n-i)+1个* 
        for(j=1;j<=2*(n-i)+1;j++){
            cout<<"*";
        }
        cout<<endl;
    }
    return 0;
}
