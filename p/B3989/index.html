B3989 [语言月赛 202406] 优惠券

洛谷 | 普及- | C++14 | 提交时间: 2026-11-03

算法标签：2024、O2优化、数组、语言月赛

题目描述

某奶茶店推出优惠活动：

  • 如果按照原价购买了一杯奶茶，可获赠一张优惠券；
  • 如果使用优惠券购买了一杯奶茶，这杯奶茶不会再获赠优惠券；
  • 每张优惠券可折抵 111 元；
  • 购买一杯奶茶使用的优惠券数量不限，但不找零。

现在，小 F 计划购买 nnn 杯奶茶，其价格为 a1,a2,⋯ ,ana_1,a_2,\cdots,a_na1​,a2​,⋯,an​。他可以以任意顺序购买这 nnn 杯奶茶。

请问，小 F 最少花费多少钱，才能买下全部 nnn 杯奶茶？

输入格式

输入共两行。

输入的第一行为一个整数 nnn。
输入的第二行为 nnn 个整数 a1,a2,⋯ ,ana_1,a_2,\cdots,a_na1​,a2​,⋯,an​。
保证 a1≤a2≤⋯≤ana_1\le a_2 \le \cdots \le a_na1​≤a2​≤⋯≤an​。

输出格式

输出一行一个整数，表示最少花费的钱数。

样例

样例输入 #1

5
1 2 3 3 4

样例输出 #1

9

AC 代码

#include <iostream>
using namespace std;

int main() {
    /*
      思路：
      - 按原价购买一杯会获得 1 张优惠券；用优惠券购买则不再获得券。
      - 每张券可抵 1 元，使用数量不限但不找零。
      - 可以任意顺序购买，所以可以先按原价买若干杯攒券，再用券抵扣剩余杯子。
      
      假设选 m 杯用券购买（这 m 杯不产生券），
      则另外 n-m 杯按原价购买，共获得 n-m 张券。
      为了抵扣最多，应把这 m 杯选为价格最高的 m 杯（后缀和 t）。
      可抵扣金额 d = min(n-m, t)。
      总花费 = 总价 s - 最大抵扣额 mx。
      
      枚举 m = 0..n 取最优，时间复杂度 O(n)。
    */

    int n;
    cin >> n;
    int a[1005];                // a[i]: 第 i 杯的价格（已升序）
    long long s = 0;            // s: 所有奶茶总价

    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        s += a[i];
    }

    long long mx = 0;           // mx: 最大可抵扣金额
    long long t = 0;            // t: 当前后缀和（用券杯的总价）

    for (int m = 0; m <= n; m++) {
        if (m > 0) {
            t += a[n - m + 1];  // 加入价格第 n-m+1 杯
        }
        int c = n - m;          // c: 按原价买的杯数 = 获得的券数
        long long d = min((long long)c, t);   // d: 本次可抵扣金额
        if (d > mx) mx = d;
    }

    cout << s - mx << endl;
    return 0;
}
