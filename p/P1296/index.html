P1296 奶牛的耳语

洛谷 | 普及- | C++14 | 提交时间: 2026-06-17

算法标签：模拟、二分、排序、队列、双指针 two-pointer

题目描述

在你的养牛场，所有的奶牛都养在一排呈直线的牛栏中。一共有 $n$ 头奶牛，其中第 $i$ 头牛在直线上所处的位置可以用一个整数坐标 $p_i(0\le p_i \le 10^8)$ 来表示。在无聊的日子里，奶牛们常常在自己的牛栏里与其它奶牛交流一些八卦新闻。每头奶牛发出的声音响度是一样的，而由于声波的能量衰减，某头奶牛发出的声音只能被与它距离不超过 $d(0 \le d \le 10^4)$ 的奶牛所听到，这样这对奶牛就称为可以相互交流的。现在给出所有奶牛的位置和声音所能传播的最远距离 $d$ ，请你编个程序来计算你的养牛场里究竟有多少对可以相互交流的奶牛。

输入格式

第一行包含两个整数 $n,d$。

第二行包含 $n$ 个整数，每个整数都是一个坐标 $p_i$，描述一头奶牛在直线上的位置。

输出格式

一个数，表示养牛场中可以相互交流奶牛的对数。

样例

样例输入 #1

5 10
10 12 16 37 40

样例输出 #1

4```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000005;
int a[MAXN];                      // 存储奶牛位置坐标

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, d;                     // n: 奶牛数, d: 最大交流距离
    cin >> n >> d;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    // ---------- 思路 ----------
    // 排序后，对于每头牛 i，用二分查找最右边满足 a[j] - a[i] <= d 的位置 j。
    // 那么牛 i 可以和 i+1 到 j 的所有牛交流，贡献 (j - i) 对。
    // 由于坐标可能重复且区间可能为空，二分边界需处理。
    // 复杂度 O(n log n)，n=1e6 时可行。

    sort(a, a + n);

    long long ans = 0;            // 答案可能很大，用 long long

    for (int i = 0; i < n; i++) {
        // 在 [i+1, n-1] 中找最后一个 <= a[i] + d 的位置
        int left = i + 1, right = n - 1;
        int best = i;             // best 记录最后一个满足条件的下标，初始化为 i 表示没有
        while (left <= right) {
            int mid = (left + right) / 2;
            if (a[mid] - a[i] <= d) {
                best = mid;       // 满足条件，尝试向右扩展
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
        // best 就是最远的可交流牛，贡献 best - i 对
        ans += (best - i);
    }

    cout << ans << '\n';
    return 0;
}
