洛谷 | 入门 | C++14 | 提交时间: 2026-07-26

算法标签：模拟、数学、2009、COCI（克罗地亚）

题目描述

给你两个十进制正整数 a,ba, ba,b，输出将这两个数翻转后的较大数。

「翻转」在本题中的定义详见「说明 / 提示」部分。

输入格式

第一行，两个十进制正整数 a,ba, ba,b。

输出格式

第一行，aaa 和 bbb 翻转后的较大数。

样例

样例输入 #1

734 893

样例输出 #1

437```

**样例输入 #2**

221 231


**样例输出 #2**

132```

样例输入 #3

839 237

样例输出 #3

938```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    // 思路：输入两个三位正整数，分别翻转（个位变百位，百位变个位），
    //      然后输出翻转后的较大值。
    int a, b;
    cin >> a >> b;

    // 翻转 a 和 b
    int ra = (a % 10) * 100 + ((a / 10) % 10) * 10 + (a / 100);
    int rb = (b % 10) * 100 + ((b / 10) % 10) * 10 + (b / 100);

    // 输出较大者
    cout << (ra > rb ? ra : rb) << endl;
    return 0;
}
