1224 - 过河卒

题目描述

AAA 点有一个过河卒，需要走到目标 BBB 点。

卒行走规则：可以向下、或者向右。同时在棋盘上的任一点有一个对方的马（如下图的 CCC 点），该马所在的点和所有跳跃一步可达的点称为对方马的控制点。

例如：下图 CCC 点可以控制 999 个点（图中的 P1,P2…P8P1,P2 \dots P8P1,P2…P8 和 CCC ），卒不能通过对方马的控制点。 棋盘用坐标表示，现给定 AAA 点位置为 (0,0)(0,0)(0,0)， BBB 点位置为 (n,m)(n,m)(n,m) (n,mn,mn,m 为不超过 202020 的整数)，马的位置 CCC 为 (X,Y)(X,Y)(X,Y)（约定: CCC 点与 AAA 点不重叠，与 BBB 点也不重叠）。

要求你计算出卒从 AAA 点能够到达 BBB 点的路径的条数。

输入

BBB 点的坐标 (n,m)(n,m)(n,m) 以及对方马的坐标 (X,Y)(X,Y)(X,Y)；（马的坐标一定在棋盘范围内，但要注意，可能落在边界的轴上）

输出

输出卒从 AAA 点能够到达 BBB 点的路径条数。（本题的路径条数可能会超过 10910^9109，但不会超过 101810^{18}1018，C/C++选手请注意使用long long）

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    int a[30][30];
    int n,m,x,y;
    cin>> n >> m >> x >> y;
    for(int i=0;i<=n;i++){
        for(int j=0;j<=m;j++){
            a[i][j] = 1;
        }
    }
    a[x][y] = 0;
    // 如果控制点在棋盘内，则设置为0
    if(x-1 >= 0 && y-2 >= 0) a[x-1][y-2] = 0;
    if(x-2 >= 0 && y-1 >= 0) a[x-2][y-1] = 0;
    if(x-2 >= 0 && y+1 <= m) a[x-2][y+1] = 0;
    if(x-1 >= 0 && y+2 <= m) a[x-1][y+2] = 0;
    if(x+1 <= n && y-2 >= 0) a[x+1][y-2] = 0;
    if(x+2 <= n && y-1 >= 0) a[x+2][y-1] = 0;
    if(x+2 <= n && y+1 <= m) a[x+2][y+1] = 0;
    if(x+1 <= n && y+2 <= m) a[x+1][y+2] = 0;

    for(int i = 0;i <= n;i++){
        for(int j = 0;j <= m;j++){
            if(i == 0 && j == 0) continue;
            if(a[i][j] == 0) continue;
            if(i == 0) {
                a[i][j] = a[i][j-1];
            } else if(j == 0) {
                a[i][j] = a[i-1][j];
            } else {
                a[i][j] = a[i-1][j] + a[i][j-1];
            }
        }
    }
    cout << a[n][m] << endl;
}
