1055 - 求满足条件的整数个数

题目描述

在 $1 \sim n$ 中，找出能同时满足用 $3$ 除余 $2$ ，用 $5$ 除余 $3$ ，用 $7$ 除余 $2$ 的所有整数的个数,如果没有请输出 $0$ 。

输入

输入一行，只有一个整数 $n(1 \le n \le 2000)$ 。

输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

AC代码

# include <iostream>
using namespace std;

int main() {
    int i = 1,n,s = 0;
    cin >> n;
    while(i <= n) {
        if(i % 3 == 2 && i % 5 == 3 && i % 7 == 2){
            s++;
        }
        i++;
    }
    cout << s << endl;
}
