1866 - 买杯子

题目描述

小明去商店买杯子，他想买价格在 101010 到 202020 元之间的杯子（含 101010 元和 202020 元），他看到货架上有 333 个不同价格的杯子，请问最终他买了几个杯子，总共花了多少钱？

比如：货架上有如下的 333 个价格的杯子 101010 181818 232323 ，那么最终小明买了 222 个杯子（分别价格为 10、1810、1810、18 ），总共花了 282828 元。

输入

输入 333 个整数，代表 333 个杯子的价格。

输出

输出有 222 个数，用空格隔开；

第 111 个数是一个整数，代表小明买了几个杯子；

第 222 个数是一个整数，代表小明总共花了多少钱；

AC代码

#include<bits/stdc++.h>
using namespace std;
int main(){
    //x:买杯子的个数   y:总共花费的钱数 
    int a,b,c,x=0,y=0;
    cin>>a>>b>>c;
    //如果a  10~20 
    if(a>=10 && a<=20) 
    {
        x++;
        y = y + a; 
    }
    if(b>=10 && b<=20) 
    {
        x++; 
        y = y + b;
    }
    if(c>=10 && c<=20) 
    {
        x++; 
        y = y + c;
    }
    cout<<x<<" "<<y;
    return 0;
}
