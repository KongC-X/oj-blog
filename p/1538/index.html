1538 - 小 X 与煎饼达人(flip)

题目描述

玩着玩着小 X 觉得有点饿了， 他想出门买些吃的。 刚刚走出大门，小 X 就看到有位大叔在做煎饼，而且做法十分有趣。 只见此人将 nnn 块煎饼排成一排，手持一把大铲，将煎饼铲得上下翻飞， 煞是好看。 小 X 顿时食指大动， 赶紧走上前去细细打量， 发现此人做煎饼还十分的讲究，在做的过程中，大叔每次会将从第 xxx 块煎饼开始到第 yyy 块煎饼结束的这 y−x+1y-x+1y−x+1 块煎饼全部翻个个儿（正面翻到反面， 反面翻到正面）。而他每次会选择不同的区间（区间是指连续的一段煎饼，如 3,4,5,63, 4, 5, 63,4,5,6 四块煎饼用区间 [3,6][3, 6][3,6] 表示）来翻这些煎饼。每块煎饼都有正反两面， 开始时这些煎饼都是反面朝上。

此人一共翻了 mmm 次煎饼，看得小 X 眼花缭乱。 但是小 X 很想知道这 nnn 块煎饼到最后一共有多少块是正面朝上的， 于是他只好求助于你了。

输入

输入数据第一行包含两个用空格隔开的正整数表示 nnn 和 mmm 。

接下来 mmm 行每行两个用空格隔开的正整数 xxx 和 yyy， 表示每次将区间 [x，y][x， y][x，y] 中的 y−x+1y-x+1y−x+1 块煎饼翻个个儿。

开始时这 nnn 块煎饼都是反面朝上（提示： 可以用 000 表示煎饼的反面，111 表示煎饼的正面）

输出

输出仅有一行包含一个整数 ansansans ， 表示最后有 ansansans 块煎饼是正面朝上的。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
using namespace std;

/*
开始时这些煎饼都是反面朝上（用0表示）
m次操作之后，问：有多少事个煎饼是正面朝上（用1表示）
求：每个位置翻的次数，如果翻了奇数次，则煎饼是正面朝上
*/

const int N = 1000010;
int a[N]; // 差分数组
int n,m,c;

int main() {
    scanf("%d%d",&n,&m);
    // 读入操作
    int x,y;
    for(int i = 1;i <= m;i++){
        scanf("%d%d",&x,&y);
        a[x]++; // b[l] = b[l] + 1
        a[y+1]--; // b[r + 1] = b[r + 1] - 1
    }
    // 求a数组的前缀和,统计奇数出现的次数
    for(int i = 1;i <= n;i++){
        a[i] = a[i-1] + a[i];
        if(a[i] % 2 != 0) c++;
    }
    cout << c << endl;
}
