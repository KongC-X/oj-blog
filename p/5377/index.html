5377 - 金字塔

题目描述

金字塔由 $n$ 层石块垒成。从塔底向上，每层依次需要 $ n \times n，(n-1) \times (n-1)，...，2 \times 2，1 \times 1 $ 块石块。请问搭建金字塔总共需要多少块石块？

输入

一行，一个正整数 $n$，表示金字塔的层数。

输出

一行，一个正整数，表示搭建金字塔所需的石块数量。

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int n, ans;
int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        ans += i * i;
    }
    cout << ans << endl;
}
