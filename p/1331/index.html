1331 - 做彩纸花边

题目描述

李晓芳用一条长为 $n$ 米的彩纸制作花边，每朵花李晓芳用一条长为 $n$ 米的彩纸制作花边，每朵花的宽度为 $x$ 厘米，花与花之间的间隔为 $y$ 厘米。请问 $n$ 米的彩纸最多能做多少朵花的花边。

如，图中的案例花的宽度为 $4.5cm$ ，花之间的间隔为$1.2cm$ ，那么一条长为 $0.62m$ 的彩纸最多可以做 $11$ 朵花的花边（因为一朵花加一个间隔是 $5.7cm$ ， $10$ 朵花以及间隔共 $57cm$，剩余 $5cm$ 还可以再做一朵花，因此最多共可以做 $11$ 朵花）（5.1.81）。

输入

三个小数 $n、x、y$，用空格隔开。

输出

最多能做多少朵花的花边。

解题思路

AC代码

AC代码

#include <iostream>
#include <iomanip>
using namespace std;

int main(){
    //定义变量n代表彩纸的长度，x代表花的宽度，y代表花与花的间隔 
    double n,x,y;
    //输入n,x,y 
    cin>>n>>x>>y;
    //把n的米转换为厘米
    n = n*100; 
    //判断多出的长度是否够做一朵花 
    int l = n / (x+y);
    if(n - l*(x+y)>=x){
        cout<<l+1;
    }else{
        cout<<l;
    } 
    return 0;
}
