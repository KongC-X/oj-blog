P1087 [NOIP 2004 普及组] FBI 树

洛谷 | 普及- | C++14 | 提交时间: 2026-05-14

算法标签：字符串、搜索、树形数据结构、2004、递归、NOIP 普及组

题目描述

我们可以把由 0 和 1 组成的字符串分为三类：全 0 串称为 B 串，全 1 串称为 I 串，既含 0 又含 1 的串则称为 F 串。

FBI 树是一种二叉树，它的结点类型也包括 F 结点，B 结点和 I 结点三种。由一个长度为 2N2^N2N 的 01 串 SSS 可以构造出一棵 FBI 树 TTT，递归的构造方法如下：

  1. TTT 的根结点为 RRR，其类型与串 SSS 的类型相同；
  2. 若串 SSS 的长度大于 111，将串 SSS 从中间分开，分为等长的左右子串 S1S_1S1​ 和 S2S_2S2​；由左子串 S1S_1S1​ 构造 RRR 的左子树 T1T_1T1​，由右子串 S2S_2S2​ 构造 RRR 的右子树 T2T_2T2​。

现在给定一个长度为 2N2^N2N 的 01 串，请用上述构造方法构造出一棵 FBI 树，并输出它的后序遍历序列。

输入格式

第一行是一个整数 N(0≤N≤10)N(0 \le N \le 10)N(0≤N≤10)，

第二行是一个长度为 2N2^N2N 的 01 串。

输出格式

一个字符串，即 FBI 树的后序遍历序列。

样例

样例输入 #1

3
10001011

样例输出 #1

IBFBBBFIBFIIIFF

AC 代码

#include <iostream>
#include <string>
using namespace std;

int n;
string s; // 输入的01串

// 给一个长度为 2^N 的 01 串，比如 N=3 时长度为 8，字符串是 `10001011`
// 构造规则是递归的：
// 1. 看整个串 → 决定根结点类型（B/I/F）
// 2. 从中间劈成两半 → 左半串构造左子树，右半串构造右子树
// 3. 继续递归，直到每个子串长度为 1（叶子结点）

// 核心技巧：我们不需要真的建树！因为后序遍历的顺序就是：
// 1. 递归处理左半串
// 2. 递归处理右半串
// 3. 输出当前串的类型
// 直接递归输出就行！

/*
 * 功能：判断子串 s[l..r] 的类型，并输出后序遍历
 * 参数：l - 左边界下标，r - 右边界下标
 * 递归思想：
 *   1. 如果 l==r，说明长度为1，直接判断是 '0'→B 还是 '1'→I
 *   2. 否则先递归左半边 (l, mid)，再递归右半边 (mid+1, r)
 *   3. 最后判断当前串的类型并输出（后序：左-右-根）
 */
void dfs(int l, int r){
    if (l == r) // 叶子结点：长度为1
    {
        if (s[l] == '0')
            cout << 'B'; // 全0串 → B
        else
            cout << 'I'; // 全1串 → I
        return;
    }
    
    int mid = (l + r) / 2;
    
    // 后序遍历：先左子树，再右子树
    dfs(l, mid);       // 递归左半串
    dfs(mid + 1, r);   // 递归右半串
    
    // 判断当前串 s[l..r] 的类型
    bool a = false, b = false; // a 表示是否有0，b 表示是否有1
    for (int i = l; i <= r; i++){
        if (s[i] == '0') a = true;
        if (s[i] == '1') b = true;
    }
    
    if (a && b)
        cout << 'F'; // 既有0又有1 → F
    else if (a)
        cout << 'B'; // 只有0 → B
    else
        cout << 'I'; // 只有1 → I
}

int main(){
    cin >> n;       // 输入 N
    cin >> s;       // 输入 01 串，长度 = 2^N
    dfs(0, s.length() - 1); // 从整个串开始递归
    cout << endl;
    return 0;
}
