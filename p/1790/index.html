1790 - 回文字符串

题目描述

回文字符串的判断。回文，正读反读都都相同的字符序列成为回文。例如：abcba就是回文。写程序使用栈判断给定的字符串序列是否是回文。

输入

第一行：输入整数n代表字符串字符个数（字符个数不超过1000个）。

第二行：输入n个字符的字符串。

输出

如果字符串是回文字符串，请输出“Yes”，否则输出“No”。

AC代码

AC代码

#include <iostream>
#include <stack>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    stack<char> s;
    string str;
    cin >> str;
    
    // 将前半部分字符入栈
    for (int i = 0; i < n/2; i++) {
        s.push(str[i]);
    }
    
    // 比较后半部分字符
    int start = (n % 2 == 0) ? n/2 : n/2 + 1;
    bool is_palindrome = true;
    
    for (int i = start; i < n; i++) {
        if (s.top() != str[i]) {
            is_palindrome = false;
            break;
        }
        s.pop();
    }
    
    cout << (is_palindrome ? "Yes" : "No") << endl;
    return 0;
}
