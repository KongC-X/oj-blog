1723 - 奇偶数选大王

题目描述

在数字王国中，有值为 $1 \sim n$ 之间的整数，有奇数也有偶数；他们想分别在奇数和偶数中选出各自的大王，也就是选出奇数和偶数的最大数作为奇数大王和偶数大王。

请你编程帮助数字王国选出奇数和偶数的大王，并将所有的数字从小到大输出。

比如，假设输入 $5$ 个数，分别是 $3$ $8$ $9$ $1$ $6$ ，那么奇数大王（最大数）是 $9$ ，偶数大王（最大数）是 $8$ ，因此输出奇数大王和偶数大王以及所有数按照由小到大排序如下：

`9 8
1 3 6 8 9
`

输入

输入有 $2$ 行；

第 $1$ 行有一个整数 $n$（$n$ 是 $10 \sim 1000$ 之间的整数），代表数字王国中数字的总个数；

第 $2$ 行有 $n$ 个整数（这些整数值在 $1 \sim 1000000$ 之间，测试数据保证有奇数，也有偶数），数字之间用空格隔开。

输出

第 $1$ 行输出 $2$ 个整数，分别是奇数大王和偶数大王，两个数之间用空格隔开；

第 $2$ 行将 $n$ 个整数从小到大排序后输出，数与数之间用空格隔开。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
using namespace std;

int main() {
int n,a[1010];
cin>>n;
for(int i=0;i<n;i++)
{
    cin>>a[i];
}
int max=a[0];
int max1=a[0];
for(int i=0;i<n;i++)
{
    if(a[i]%2==0) 
    {
        if(a[i]>max)
        {
            max=a[i];
        }
    }
    else
    {
        if(a[i]>max1)
        {
            max1=a[i];
        }
    }
}
cout<<max1<<" "<<max<<endl;
sort(a,a+n);
for(int i=0;i<n;i++)
{
    cout<<a[i]<<" ";
}
return 0;
}
