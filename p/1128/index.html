1128 - 整数串拆段

题目描述

将一个长度小于 101010 位的数字串拆成 222 段，使其和为最小的素数。

例如数字串“ 133041330413304 ” ，拆的方法有：

`1 + 3304 = 3305 
13 + 304 = 317 
133 + 04 = 137 
1330 + 4 = 1334 
`

从上面可看出，和为素数的有：317317317 与 137137137 ，最小的是137137137。

输入

一个长度小于 101010 的数字串。

输出

最小的和为素数的数，若无素数则输出 −1-1−1。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// string和数值类型转换函数
// stoi(s): 将字符串s转换为int类型
// string to int
// stof(s): 将字符串s转换为float类型
// string to float
// stod(s): 将字符串s转换为double类型
// string to double
// stoll(s): 将字符串s转换为long long类型
// string to long long

// to_string(int i): 将int类型i转换为字符串类型
// int to string
// to_string(double a): 将double类型a转换为字符串类型,保留小数点后6位(最后一位会四舍五入)

// 判断素数
bool isPrime(int n) {
    if (n <= 1) {
        return false;
    }
    for (int i = 2; i * i <= n; i++) {
        if (n % i == 0) {
            return false;
        }
    }
    return true;
}

int main() {
    int x,y,i,min;
    string s,s1,s2;
    bool flag = true;
    min = INT_MAX;
    cin >> s;
    for(i = 0;i < s.size() - 1;i++) {
        s1 = s.substr(0,i + 1);
        s2 = s.substr(i + 1);
        // cout << s1 << " " << s2 << endl;
        x = stoi(s1);
        y = stoi(s2);
        if(isPrime(x + y) && x + y < min) {
            min = x + y;
            flag = false;
        }
    }
    if(flag) {
        cout << -1 << endl;
    } else {
        cout << min << endl;
    }
}
