1080 - 质因子

题目描述

任意输入一正整数 NNN ，求出它的所有质因子。如：10＝2×510＝2 \times 510＝2×5，20＝2×2×520＝2 \times 2 \times 520＝2×2×5。

输入

输入只有一行，包括 111 个整数 nnn (1≤n≤327681 \le n \le 327681≤n≤32768)。

输出

输出若干行，按从小到大的顺序给出这个数的所有质因子，每行一个。
