B2033 A*B 问题

洛谷 | 入门 | C++14 | 提交时间: 2026-04-22

题目描述

输入两个正整数 AAA 和 BBB，求 A×BA \times BA×B 的值。注意乘积的范围和数据类型的选择。

输入格式

一行，包含两个正整数 AAA 和 BBB，中间用单个空格隔开。1≤A,B≤500001 \le A,B \le 500001≤A,B≤50000。

输出格式

一个整数，即 A×BA \times BA×B 的值。

样例

样例输入 #1

3 4```

**样例输出 #1**

12```

样例输入 #2

36 18```

**样例输出 #2**

648```

AC 代码

#include <bits/stdc++.h>

using namespace std;

int main(){
    long long a, b;//定义。
    cin >> a >> b;//输入。
    cout << a * b;//输出a乘b。
    return 0;
}
