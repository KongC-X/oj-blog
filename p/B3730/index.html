B3730 [信息与未来 2017] 密码锁

洛谷 | 普及- | C++14 | 提交时间: 2026-04-13

算法标签：数学、2017、江苏、枚举、信息与未来

题目描述

乌龟给自己的贵重物品上了密码锁。密码锁上有 555 个数字拨盘。每个数字拨盘每次向上拨使数字增加 111 （999 向上拨得到 000），向下拨使数字减少 111 （000 向下拨得到 999）。

拨盘上的数字组成一个 555 位数。只要拨盘上的数字变为素数，密码锁就会被解开。素数 (又称质数) 是只能被 111 和它自身整除的大于 111 的自然数。因为乌龟动作实在太慢，他希望你帮他计算如何开锁，使得拨动的总次数最少。

输入格式

一个 555 位数，表示拨盘的初始数字。

输出格式

一个 555 位素数，表示开启密码锁使用的素数（拨动次数最少）。如有多组解，输出满足条件的最大数。

样例

样例输入 #1

01210```

**样例输出 #1**

01319```

AC 代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 判断一个数是不是质数（素数）
bool isPrime(int x) {
    if (x < 2) return false;          // 小于2的不是质数
    for (int i = 2; i * i <= x; i++) { // 从2检查到根号x
        if (x % i == 0) return false;  // 如果能整除，就不是质数
    }
    return true;                       // 否则是质数
}

int main() {
    // s: 初始密码（字符串读入，保留前导0）
    string s;
    cin >> s;

    // a[0]~a[4]: 把初始密码的每一位数字存到数组里
    int a[5];
    for (int i = 0; i < 5; i++) {
        a[i] = s[i] - '0';  // 字符转成数字
    }

    int best = -1;      // 最终答案的质数（数值）
    int minMove = 9999; // 最少的拨动次数，先设一个很大的值

    // 从2到99999检查每个数
    for (int p = 2; p <= 99999; p++) {
        if (!isPrime(p)) continue;  // 不是质数就跳过

        // 把质数p转成5位字符串，前面补0
        string t = to_string(p);
        while (t.length() < 5) t = "0" + t;

        // 计算拨动总次数
        int move = 0;
        for (int i = 0; i < 5; i++) {
            int b = t[i] - '0';           // 目标数字
            int d = abs(a[i] - b);        // 直接差
            if (d > 5) d = 10 - d;        // 如果超过5，反向转更短
            move += d;
        }

        // 比较是否更优
        if (move < minMove) {
            minMove = move;
            best = p;
        } else if (move == minMove && p > best) {
            best = p;  // 次数相同时取更大的质数
        }
    }

    // 输出答案，要保证5位（前面补0）
    string ans = to_string(best);
    while (ans.length() < 5) ans = "0" + ans;
    cout << ans << endl;

    return 0;
}
