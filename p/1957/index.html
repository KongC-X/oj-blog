1957 - 求三个数的平均数

题目描述

小雅刚刚考完语文、数学、英语的三门期中考试，她想请你编个程序来帮她算算她的平均分。

要求输入三个正整数，分别表示三科考试的分数，输出它们的平均值。

输入

一行，包括三个正整数，两两之间用一个空格分隔。

输出

一个数，表示输入的三个数的平均值。（注意：结果请保留 333 位小数）。

解题思路

AC代码

AC代码

#include <iostream>
#include <iomanip>
using namespace std;
int main(){
    int a,b,c;
    double d;
    cin>>a>>b>>c;
    d=(a+b+c)/3.0;
    cout << fixed << setprecision(3) << d << endl;
    return 0;
}
