4974 - 假期阅读

题目描述

小 AAA 有一本厚厚的书。这本书总共有 nnn 页，小 AAA 一天中最多只能阅读完其中的 kkk 页。小 AAA 的假期总共有 ttt 天，他想知道在假期中最多能阅读完这本书的多少页。

输入

第一行，一个正整数 nnn，表示书的页数。

第二行，一个正整数 kkk ，表示小 AAA 每天最多阅读的页数。

第三行，一个正整数 ttt ，表示小 AAA 假期的天数。

输出

一行，一个整数，表示假期中所能阅读的最多页数。

AC代码

AC代码

#include <iostream>
using namespace std;

int n, k, t;
int ans;

int main() {
    cin >> n >> k >> t;
    ans = k * t;
    if (n < ans)
        ans = n;
    cout << ans << endl;
    return 0;
}
