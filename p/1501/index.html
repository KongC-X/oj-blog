1501 - 数的操作

题目描述

给定一个 NNN 个数的数组， MMM 次操作，每次操作为下列操作之一。求最后的数组。

操作 111 ：在第 XXX 个数之后插入一个数 YYY 。

操作 222 ：删除第 XXX 个数。

输入

第一行两个整数 N,MN,MN,M（N,M≤100000N,M≤100000N,M≤100000），NNN 表示数组中一开始有 NNN 个数，MMM 表示 MMM 次操作。

第二行 NNN 个整数，表示原来的数组。

接下来 MMM 行，每行第一个数 OPTOPTOPT，表示操作类型。

对于操作 111，接下来两个数 XXX ，YYY ，表示在第 XXX 数之后插入一个数 YYY，保证0≤X≤0≤X≤0≤X≤当前数的个数，若 X=0X=0X=0，表示在数组开头插入。

对于操作 222 ，接下来一个数 XXX ，表示要删除第 XXX 个数，保证 1≤X≤1≤X≤1≤X≤当前数的个数。

输出

输出若干个数，表示最后的数组。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    vector<int> a;
    int n,m,x;
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        cin >> x;
        a.push_back(x);
    }
    for (int i = 1; i <= m; i++) {
        int opt, x, y;
        cin >> opt >> x;
        if (opt == 1) {
            cin >> y;
            a.insert(a.begin() + x, y);
        }
        else {
            a.erase(a.begin() + x - 1);
        }
    }
    // 迭代器遍历
    // for (vector<int>::iterator it = a.begin(); it != a.end(); it++) {
    // 	cout << (*it) << " ";
    // }
    for(int i = 0; i < a.size(); i++) {
        cout << a[i] << " ";
    }
}
