1959 - 写评语

题目描述

输入某学生成绩 $score$ ，根据成绩好坏输出相应评语。

如果成绩在大于等于 $90$ ，输出 Excellent ；

如果成绩在大于等于 $80$ 分且小于 $90$ 分，输出 Good ；

如果成绩大于等于 $60$ 分且小于 $80$ 分，输出 Pass；

成绩小于 $60$ 分，输出 Fail 。

输入

输入一个整数 $score$ ，表示学生的成绩。

输出

输出对应的评语。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;
 
int main(){
    //代表整数 score
    int score;
    //输入一个整数score
    cin>>score;
    if(score>=90){
        cout<<"Excellent";
    }else if(score>=80){
        cout<<"Good";
    }else if(score>=60){
        cout<<"Pass";
    }else{
        cout<<"Fail";
    }
    return 0;
}
