1813 - 找出最大的圆

题目描述

给定一批圆的半径（半径值互不相同），找出这些圆中面积最大的圆，输出它的编号和面积。

圆的面积 = 3.14×3.14 \times3.14× 半径 ×\times× 半径 ，面积输出时保留 222 位小数。

输入

第一行一个整数 nnn（n<100n \lt 100n<100)；

第二行 nnn 个以空格相隔的整数，代表这 nnn 个圆的半径（半径值都在 1∼10001 \sim 10001∼1000 之间)。

输出

输出有 222 个数，用一个空格隔开。

第 111 个数代表最大圆的面积（保留 222 位小数）。

第 222 个数代表这个最大圆是这组数的第几个圆。

解题思路

AC代码

AC代码

#include<iostream>
using namespace std;

int a[110],n,s = 0;

int main() {
    cin>>n;
    for(int i = 0;i < n;i++){
        cin>>a[i];
    }
    int max = 0;
    for(int i = 1;i < n;i++){
        if(a[i] > a[max]){
            max = i;
        }
    }
    double s = 3.14 * a[max] * a[max];
    printf("%.2f ",s);
    cout << max + 1;
}
