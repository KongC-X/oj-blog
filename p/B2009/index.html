B2009 计算 (a+b)/c 的值

洛谷 | 入门 | C++14 | 提交时间: 2026-06-19

题目描述

给定 333 个整数 a,b,ca,b,ca,b,c，计算表达式 (a+b)/c(a+b)/c(a+b)/c 的值，/ 是整除运算。

输入格式

输入仅一行，包括三个整数 a,b,ca,b,ca,b,c，数与数之间以一个空格分开。

输出格式

输出一行，即表达式的值。

样例

样例输入 #1

1 1 3

样例输出 #1

0

AC 代码

#include <bits/stdc++.h>
using namespace std;
int main()
{
    int a, b, c;                 // 声明变量
    cin >> a >> b >> c;          // 输入 a, b, c
    cout << (a + b) / c << endl; // 输出 (a+b)/c
    return 0;                    // 程序结束
}
