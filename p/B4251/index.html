B4251 [科大国创杯小学组 2024] 分析

洛谷 | 入门 | C++14 | 提交时间: 2026-07-19

算法标签：数学、2024、安徽、分支结构、科创活动、小学活动

题目描述

小可可最近在学数学运算！他希望考考你，给你两个整数 $A, B$，询问 $A \times B$ 是否是偶数。

输入格式

一行，两个整数 $A, B$。

输出格式

如果 $A \times B$ 是偶数，输出 Yes，否则输出 No。

样例

样例输入 #1

1 3```

**样例输出 #1**

No```

样例输入 #2

1000000000000000000 1000000000000000000```

**样例输出 #2**

Yes```

AC 代码

#include <iostream>
using namespace std;

int main() {
    unsigned long long a, b;        // a 和 b 最大可达 2^64-1，用 unsigned long long
    cin >> a >> b;

    // 思路：两个整数相乘，只要其中一个是偶数，乘积就是偶数。
    // 如果两个数都是奇数，乘积才是奇数。
    if (a % 2 == 1 && b % 2 == 1) {
        cout << "No" << endl;
    } else {
        cout << "Yes" << endl;
    }

    return 0;
}
