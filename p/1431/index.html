1431 - 迷宫的第一条出路

题目描述

已知一 N×NN \times NN×N 的迷宫，允许往上、下、左、右四个方向行走，现请你按照左、上、右、下顺序进行搜索，找出第一条从左上角到右下角的路径。

输入

输入数据有若干行，第一行有一个自然数 NNN（N≤20N≤20N≤20），表示迷宫的大小；

其后有 NNN 行数据，每行有 NNN 个 000 或 111（数字之间没有空格，000 表示可以通过，111 表示不能通过），用以描述迷宫地图。入口在左上角 (1,1)(1,1)(1,1)处，出口在右下角(N,N)(N,N)(N,N) 处。

所有迷宫保证存在从入口到出口的可行路径。

输出

输出数据仅一行，为按照要求的搜索顺序找到的从入口到出口的第一条路径（搜索顺序：左、上、右、下）。

解题思路

AC代码

AC代码

#include<bits/stdc++.h> 
#include<iostream> 
using namespace std;

int n,m;
char a[50][50]; // 初值为\0，存地图
int r[410][3]; // 记录正确的第一条路径

// 本题按照左上右下顺序
int fx[5] = {0,0,-1,0,1};
int fy[5] = {0,-1,0,1,0};

// k是路径数组的下标
void dfs(int x,int y,int k) {
    r[k][1] = x;
    r[k][2] = y;
    a[x][y] = '1'; // 访问过的点标记为1
    // 如果x,y是终点，则输出
    if(x == n && y == n) {
        for(int i = 1; i <= k; i++) {
            cout << "(" <<  r[i][1] << "," << r[i][2] << ")";
            if(i != k) cout << "->";
        }
        return;
    }
    int tx,ty;
    for(int i = 1; i <= 4; i++) {
        tx = x + fx[i];
        ty = y + fy[i];
        if(a[tx][ty] == '0') {
            dfs(tx,ty,k+1);
        }
    }
}

int main() {
    cin >> n;
    for(int i = 1; i <= n; i++) {
        for(int j = 1; j <= n; j++) {
            cin >> a[i][j];
        }
    }
    dfs(1,1,1);
    return 0;
}
