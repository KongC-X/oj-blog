1417 - 买文具

题目描述

文具店的水笔的单价是一个整数，小明从文具店买了 xxx 支水笔花了 yyy 元。请问如果你要从该文具店购买 555 支水笔需要付多少钱？

输入

两个整数 xxx 和 yyy ，用空格隔开，分别代表小明买的水笔的支数和他付给老板的金额。

输出

一个整数，代表如果你买 555 支水笔，应该付给老板的金额。

解题思路

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int main() {
    int x,y;
    cin >> x >> y;
    cout << y / x * 5 << endl;
    return 0;
}
