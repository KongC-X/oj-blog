1278 - 小X与缩写

题目描述

小X注意到，生活中有很多用到首字母缩写的例子。例如 UOJ 就是通用在线评测 (Universal Online Judge)的缩写。

我们定义一个英文词组的首字母缩写为：取出词组中每个单词的第一个字母、全部转化成大写并顺次连接。

于是小X想请你帮忙写一个程序，读入一行英文句子，将用括号括出的词组替换为首字母缩写再输出。

输入

输入一行仅包含英文字母、英文逗号 ,、英文句号 .、左右括号 () 的句子。

保证括号配对、括号内仅包含若干用空格隔开的英文单词、没有多余的空格。

输出

输出一行，将括号内的词组替换成首字母缩写的结果输出，括号不要输出，括号外的字符原样输出。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

/*
思路：
1. 判断当前字符是否在括号中；
准备布尔f，标记是否在括号中 
遇到(，f = true；
遇到)，f = false;

2. 如果不在括号中，直接输出；
如果在括号中，判断是首字母，再输出； 
*/

string s; 
bool f = false;

int main(){
    getline(cin,s);
    
    for(int i = 0;i < s.size();i++){
        if(s[i] == '('){
            f = true;
        }else if(s[i] == ')'){
            f = false;
        }else{
            //如果在括号里
            if(f == true){
                //如果是首字母输出
                if(isalpha(s[i]) && !isalpha(s[i-1])){
                    cout<<(char)toupper(s[i]);
                } 
            }else{
                cout<<s[i];
            } 
        }
    }
    return 0;
}
