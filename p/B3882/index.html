B3882 [信息与未来 2015] 求回文数

洛谷 | 入门 | C++14 | 提交时间: 2026-04-11

算法标签：2015、江苏、枚举、信息与未来

题目描述

一个正整数，正读和反读都相同的数为回文数，例如 22,131,2442,37073,6,⋯22,131,2442,37073,6,\cdots22,131,2442,37073,6,⋯。所有的 111 位数都是回文数。

现给出一个正整数 nnn，求出 [1,n][1,n][1,n] 中的回文数的个数。

输出格式

一个整数，即 1∼n1\sim n1∼n 中全部回文数的个数。

样例

样例输入 #1

24```

**样例输出 #1**

11```

AC 代码

#include <iostream>
using namespace std;

bool fun(int x) {
    int s = 0, a = x;
    while (a) {
        s = s * 10 + a % 10;
        a /= 10;
    }
    return s == x;
}

int n,sum;
int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        if (fun(i)) sum++;
    }
    cout << sum << endl;
    return 0;
}
