B2095 白细胞计数

洛谷 | 入门 | C++14 | 提交时间: 2026-07-08

题目描述

医院采样了某临床病例治疗期间的白细胞数量样本 nnn 份，用于分析某种新抗生素对该病例的治疗效果。为了降低分析误差，要先从这 nnn 份样本中去除一个数值最大的样本和一个数值最小的样本，然后将剩余 n−2n-2n−2 个有效样本的平均值作为分析指标。同时，为了观察该抗生素的疗效是否稳定，还要给出该平均值的误差，即所有有效样本（即不包括已扣除的两个样本）与该平均值之差的绝对值的最大值。

现在请你编写程序，根据提供的 nnn 个样本值，计算出该病例的平均白细胞数量和对应的误差。

输入格式

输入的第一行是一个正整数 nnn（2<n≤3002<n \le 3002<n≤300），表明共有 nnn 个样本。

以下共有 nnn 行，每行为一个浮点数，为对应的白细胞数量，其单位为 109/L10^9/L109/L。数与数之间以一个空格分开。

输出格式

输出为两个浮点数，中间以一个空格分开。分别为平均白细胞数量和对应的误差，单位也是 109/L10^9/L109/L。计算结果需保留到小数点后 222 位。

样例

样例输入 #1

5
12.0
13.0
11.0
9.0
10.0```

**样例输出 #1**

11.00 1.00```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 1. 读入 n 个样本值，存入数组。
    // 2. 对数组进行排序，去掉第一个（最小值）和最后一个（最大值）。
    // 3. 计算剩余 n-2 个数的平均值。
    // 4. 遍历剩余的数，计算每个数与平均值的差的绝对值，找出最大值作为误差。
    // 5. 输出平均值和误差，保留两位小数。
    
    int n;                               // n: 样本数量
    cin >> n;
    
    double a[315];                       // 数组多开10个，最多 300 个样本
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    
    // 从小到大排序
    sort(a, a + n);
    
    // 去掉最小的一个和最大的一个，剩余有效样本数量为 n-2
    double sum = 0.0;                    // sum: 有效样本的总和
    for (int i = 1; i < n - 1; i++) {
        sum += a[i];
    }
    double avg = sum / (n - 2);          // avg: 平均值
    
    // 计算误差：所有有效样本与平均值之差的绝对值的最大值
    double max_err = 0.0;                // max_err: 最大误差
    for (int i = 1; i < n - 1; i++) {
        double diff = fabs(a[i] - avg);  // fabs 用于 double 类型的绝对值
        max_err = max(max_err, diff);    // 直接用 max 函数更新最大值
    }
    
    cout << fixed << setprecision(2) << avg << " " << max_err << endl;
    return 0;
}
