3477 - 小杨的考试

题目描述

今天是星期 $X$ ，小杨还有 $N$ 天就要考试了，你能推算出小杨考试那天是星期几吗？（本题中使用 $7$ 表示星期日）

输入

输入 $2$ 行，第一行一个整数 $X$ ($ 1 \leq X \leq 7 $);

第二行一个整数 $N$ ($ 1 \leq N \leq 364 $)。

输出

输出一个整数，表示小杨考试那天是星期几。

AC代码

AC代码

#include <iostream>
using namespace std;

int main() {
    int x,n;
    cin>>x>>n;
    if((x + n) % 7 == 0) {
        cout << 7;
    } else {
        cout << (x + n) % 7;
    }
}
