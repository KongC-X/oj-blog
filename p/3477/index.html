3477 - 小杨的考试

题目描述

今天是星期 XXX ，小杨还有 NNN 天就要考试了，你能推算出小杨考试那天是星期几吗？（本题中使用 777 表示星期日）

输入

输入 222 行，第一行一个整数 XXX (1≤X≤71 \leq X \leq 71≤X≤7);

第二行一个整数 NNN (1≤N≤3641 \leq N \leq 3641≤N≤364)。

输出

输出一个整数，表示小杨考试那天是星期几。

AC代码

AC代码

#include <iostream>
using namespace std;

int main() {
    int x,n;
    cin>>x>>n;
    if((x + n) % 7 == 0) {
        cout << 7;
    } else {
        cout << (x + n) % 7;
    }
}
