P11375 [GESP202412 六级] 树上游走

洛谷 | 普及- | C++14 | 提交时间: 2026-05-14

算法标签：模拟、高精度、2024、进制、栈、队列、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1170

题目描述

小杨有一棵包含无穷节点的二叉树（即每个节点都有左儿子节点和右儿子节点；除根节点外，每个节点都有父节点），其中根节点的编号为 111，对于节点 iii，其左儿子的编号为 2×i2\times i2×i，右儿子的编号为 2×i+12\times i + 12×i+1。

小杨会从节点 sss 开始在二叉树上移动，每次移动为以下三种移动方式的任意一种：

  • 第 1 种移动方式：如果当前节点存在父亲节点，向上移动到当前节点的父节点，否则不移动；
  • 第 2 种移动方式：移动到当前节点的左儿子；
  • 第 3 种移动方式：移动到当前节点的右儿子。

小杨想知道移动 nnn 次后自己所处的节点编号。数据保证最后所处的节点编号不超过 101210^{12}1012。

输入格式

第一行包含两个正整数 nnn 和 sss，代表移动次数和初始节点编号。

第二行包含一个长度为 nnn 且仅包含大写字母 U\tt{U}U、L\tt{L}L 和 R\tt{R}R 的字符串，代表每次移动的方式，其中 U\tt{U}U 代表第 1 种移动方式，L\tt{L}L 代表第 2 种移动方式，R\tt{R}R 代表第 3 种移动方式。

输出格式

输出一个正整数，代表最后所处的节点编号。

样例

样例输入 #1

3 2
URR```

**样例输出 #1**

7```

AC 代码

#include <iostream>
#include <string>
using namespace std;

int n;
long long s;         // 初始节点编号
string s1;        // 移动序列
string s2;         // 从根到当前节点的路径 (L=左, R=右)

int main(){
    // 1. 读入
    cin >> n >> s;
    cin >> s1;

    // 2. 把初始节点 s 转换成"从根出发的路径"
    //    方法：不断除以2，看是左儿子还是右儿子
    //    先倒着算出来，再反转
    string t = "";
    while (s > 1){
        if (s % 2 == 0)
            t += 'L';   // 左儿子
        else
            t += 'R';   // 右儿子
        s /= 2;
    }
    // 此时 t 里存的路径是反的（从下往上），需要反转
    s2 = "";
    for (int i = t.length() - 1; i >= 0; i--)
        s2 += t[i];

    // 3. 模拟移动
    for (int i = 0; i < n; i++){
        char op = s1[i];
        if (op == 'L'){
            s2 += 'L';     // 字符串末尾加L
        }else if (op == 'R'){
            s2 += 'R';     // 字符串末尾加R
        }else {
            // op == 'U'
            if (s2.size() > 0)  // 不是根节点才能向上
                s2.erase(s2.size() - 1, 1);  // 删掉最后一个字符
        }
    }

    // 4. 把路径转成节点编号
    //    从根1开始，遇到L就×2，遇到R就×2+1
    long long ans = 1;
    for (int i = 0; i < s2.size(); i++){
        if (s2[i] == 'L')
            ans = ans * 2;         // 左儿子
        else // s2[i] == 'R'
            ans = ans * 2 + 1;     // 右儿子
    }

    cout << ans << endl;
    return 0;
}
