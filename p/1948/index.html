1948 - 评选最佳品牌

题目描述

$n$ 个评委投票，在 $m$ 个商品中评选一个最佳品牌。

评选采用多轮淘汰制，即：每轮投票，淘汰掉得票最少的候选品牌（得票并列最少的品牌一起淘汰）。

如此一轮轮淘汰下去，如果最后只剩下一个品牌当选，即告评选成功。

但如果在某轮投票中，当时未被淘汰的所有候选品牌（大于等于两个品牌）都并列得票最少，即告评选失败。

如果评选成功就输出当选品牌号。否则输出最后一轮评选时唯一选票数的相反数。

在评选流程中，每个评委的态度都可用一个序列来表示；例如当 $m=5$ 时，某评委的评选态度序列为：$3$、$5$、$1$、$2$、$4$，则表示该评委：优先投 $3$ 号，当 $3$ 号被淘汰时投 $5$ 号，当 $3$ 和 $5$ 都被淘汰时投 $1$，当 $3$、$5$、$1$ 都被淘汰时投 $2$，仅剩 $4$ 号时才投 $4$ 号品牌的票。

选票的序列中可以表示弃权，用 $0$ 来表示，例如当 $m=5$ 时，某评委的评选态度序列为：$3$、$5$、$0$，则表示该评委：优先投 $3$ 号，当 $3$ 号被淘汰时投 $5$ 号，其它情况下不投任何品牌的票。

编程实现：请你编一个程序，模拟各轮投票的过程，得到评选结果。

输入

第一行：$m$ (，表示参加评选的品牌数)和 $n$ (，表示参加投票的评委数)，之间以空格分隔。

接下来的 $n$ 行：每行都是长度不超 $m$ 的数字字符串，每个字符串表示一个评委的评选态度。

输出

评选结果。

AC代码

#include <bits/stdc++.h>
using namespace std;

/*
1. m个品牌，n个人。
2. 投票进行多轮，每一轮至少淘汰1个品牌，但也可能淘汰多个。
得票并列最少的都淘汰。
3. 如果所有候选品牌，得票都是并列最少（一样多），评选失败。

思路：
1. 需要投最多m-1轮，每轮就算投掉1个品牌，有m-1轮，就可以结束。
while(true) {  }  也可能某轮投掉了多个品牌。

2. 每轮：
(1) 统计每个品牌的得票：如果品牌被投出去了，看评委投的下一个品牌。
(2) 统计：得票最多的品牌得到了ma票，得票最少的品牌得到了mi票。
情况一：ma == mi，投票失败，输出：0-ma。
情况二：将所有得到mi票的品牌，标记出局，判断还剩几个。
        如果还剩1个，输出这个品牌的编号。
*/
int cnt[20];//每个品牌的得票数
string a[1010];//存储n个人的投票
bool f[20];//标记淘汰
int m, n;

int main() {
    cin >> m >> n;//m个品牌，n个人
    for(int i = 1; i <= n; i++) cin >> a[i];

    //进行最多m-1轮投票
    int x, mi, ma;
    int tot = m;//默认有m个品牌
    while(true) {
        memset(cnt, 0, sizeof(cnt));//本轮投票和上一轮无关

        //1. 统计每个品牌的得票数
        for(int i = 1; i <= n; i++) {
            //for(char c : a[i])
            for(int j = 0; j < a[i].size(); j++) {
                x = a[i][j] - '0';//投票对象品牌
                if(x == 0) break;//弃权
                else if(f[x] == false) { //x没有被投掉，投给x，不看下一个
                    cnt[x]++;
                    break;
                }
            }
        }

        //2. 统计：得票最多的品牌、得票最少的品牌分别得到了几票
        ma = 0, mi = INT_MAX;
        for(int i = 1; i <= m; i++) {
            if(f[i] == false) {
                ma = max(ma, cnt[i]);
                mi = min(mi, cnt[i]);
            }
        }

        //3. 判断哪种情况发生
        if(ma == mi) { //没有被投出去的品牌，得票数都一样多
            cout << 0 - ma;
            break;
        } else {
            //将所有的票最少的品牌标记出局
            int win = 0;
            for(int i = 1; i <= m; i++) {
                if(cnt[i] == mi) {
                    f[i] = true;
                    tot--;
                }

                if(cnt[i] == ma) win = i;//记录得票最多的品牌
            }

            //判断如果只剩1个品牌，输出品牌的编号
            if(tot == 1) {
                cout << win;
                break;
            }
        }
    }

    return 0;
}
