3665 - 小杨买书

题目描述

小杨同学积攒了一部分零用钱想要用来购买书籍，已知一本书的单价是 $13$ 元，请根据小杨零用钱的金额，编写程序计算最多可以购买多少本书，还剩多少零用钱。

输入

输入一个正整数 ，表示小杨拥有的零用钱数。

输出

输出包含两行，第一行，购买图书的本书，第二行剩余的零用钱数。

AC代码

AC代码

#include <iostream>
using namespace std;

int main() {
    int m,i;
    cin >> m;
    cout << m / 13 << endl;
    cout << m % 13;
}
