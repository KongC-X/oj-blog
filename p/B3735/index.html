B3735 [信息与未来 2018] 圣诞树

洛谷 | 入门 | C++14 | 提交时间: 2026-04-11

算法标签：数学、2018、江苏、顺序结构、信息与未来

题目描述

圣诞树共有 nnn 层，从上向下数第 111 层有 111 个星星、第 222 层有 222 个星星、以此类推，排列成下图所示的形状。

星星和星星之间用绳子连接。第 1,2,⋯ ,n−11,2,\cdots, n - 11,2,⋯,n−1 层的每个星星都向下一层最近的两个星星连一段绳子，最后一层的相邻星星之间连一段绳子。

你能算出如果要布置一棵很大（nnn 层）的圣诞树，需要买多少段绳子吗？

输入格式

输入一行一个整数 nnn，圣诞树的层数。

输出格式

输出一行一个整数，代表圣诞树中绳子的段数。

样例

样例输入 #1

2```

**样例输出 #1**

3```

样例输入 #2

4```

**样例输出 #2**

15```

AC 代码

#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    // 总绳子数 = n^2 - 1
    cout << n * n - 1 << endl;
    return 0;
}
