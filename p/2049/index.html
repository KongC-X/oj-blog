2049 - 两点之间的最短路径

题目描述

在一个地图上有 nnn 个点，每个点给出其对应的坐标，有些点之间有路径可达（两点之间有线），有些点之间没有。

请编程求解从一个点到另一个点的最短路径长度。

输入

输入文件共 n+m+3n+m+3n+m+3 行，其中:

第一行为整数 nnn（n≤100n≤100n≤100），表示地图上有 nnn 个点。

第 222 行到第 n+1n+1n+1 行（共 nnn 行） ，每行两个整数 xxx 和 yyy ，描述了一个点的坐标（每个点的坐标均在−10000-10000−10000~100001000010000之间）。

第 n+2n+2n+2 行为一个整数 mmm，表示图中连线的个数。（m≤10000m≤10000m≤10000）

此后的 mmm 行，每行描述一条连线，由两个整数 iii 和 jjj 组成，表示第 iii 个点和第 jjj 个点之间有连线。

最后一行：两个整数 sss 和 ttt ，分别表示源点和目标点是我们读入的 nnn 个点中的第几个点。

输出

输出文件仅一行，一个实数（保留两位小数），表示从 sss 到 ttt 的最短路径长度。

解题思路

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;
int n,m,p,f[5100],c,d,a,b;

//找到元素x的根(不含路径压缩) 
int find(int x){
    //如果x的父节点就是自己，那么x就是根，否则找f[x]的根 
    if(f[x]==x){
        return x;   
    } else{
        return find(f[x]);
    }
    //路径压缩版本的写法
    //如果x的父节点就是自己，那么x就是根，否则将x的父节点直接指向x所在集合的根 
    //return f[x]==x?x:f[x]=find(f[x]); 
}

//合并：将x和y合并到同一个集合，前提：x和y必须是不同的集合
void merge(int x,int y){
    int fx = find(x); //找到x的根
    int fy = find(y); //找到y的根
    if(fx != fy){
        //将y的根的父节点，设置为x的根 
        f[fx] = fy;
    }
} 

int main() {
    //n个人，m个亲戚关系，p次查询 
    cin>>n>>m>>p;
    //初始化，每个人的根节点都指向自己 
    for(int i = 1;i <= n;i++){
        f[i] = i;
    }
    
    for(int i = 1;i <= m;i++){
        cin>>c>>d;
        //cd是亲戚关系，将其合并到同一个集合
        merge(c,d); 
    } 
    
    //p次查询
    for(int i = 1;i <= p;i++){
        cin>>a>>b;
        //问：ab是否有亲戚关系，如果ab的根节点相同，那么是亲戚 
        if(find(a)==find(b)){
            cout<<"Yes"<<endl;
        } else{
            cout<<"No"<<endl; 
        } 
    } 
    return 0;
}
