1100 - 词组缩写

题目描述

定义：一个词组中每个单词的首字母的大写组合称为该词组的缩写。

比如，C语言里常用的 EOF 就是 endendend ofofof filefilefile 的缩写。

输入

测试数据占一行，有一个词组（总长度不超过 200200200），每个词组由一个或多个单词组成；每组的单词个数不超过 101010 个，每个单词有一个或多个大写或小写字母组成；

单词长度不超过 101010，由一个或多个空格分隔这些单词。

输出

输出规定的缩写。

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    char s[210],a[210];
    int i,k = 0;
    gets(s);
    a[k] = s[0];
    k++;
    for(i = 1;i < strlen(s);i++) {
        if(s[i - 1] == ' ' && s[i] != ' ') {
            a[k] = s[i];
            k++;
        }
    }
    for(i = 0;i < strlen(a);i++) {
        if(a[i] >= 'a' && a[i] <= 'z') {
            a[i] = a[i] - 32;
        }
        if(a[i] != ' ') {
            cout << a[i];
        }
    }
}
