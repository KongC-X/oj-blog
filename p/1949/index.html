1949 - 最大购物优惠

题目描述

小惠听说超市正在打折促销，要制订一个得到最大优惠的购物计划。

小惠的体力可以提起 www 单位重量的东西，还有一个能装 vvv 个单位体积的购物袋，并详细了解了各打折商品的重量、体积及此商品实际优惠的金额。她想在自己体力的限度和购物袋容积限度内，尽可能多地得到购物优惠。

超市规定这些打折商品每种只能购买一件。

请你编写程序，制定一个购买商品的计划，求出小惠能得到的最大优惠金额和实际应购买的各商品序号。

输入

第一行：依次为 www、vvv 和 nnn（nnn 为商品种类数），所有数值均为不超过 100100100 的正整数。

接下来的 nnn 行：每行有三个整数，依次为某种商品的重量、体积和让利金额，数值间以空格分开，所有数值均为不超过 100100100 的正整数。

输出

第一行：小惠能够得到的最大让利金额。

第二行：依次为从小到大排列的商品序号，序号从 111 开始，序号间用空格分开。若第二行输出的序列不唯一，则输出其最小字典序。

AC代码

#include <bits/stdc++.h>
using namespace std;

/*
二维费用背包：创建一个三维数组r[105][105][105]记录在第n个物品,w重量,v体积时 最优策略
二维费用的背包问题,在01背包问题的基础上增加一个费用维度
状态转移方程:
dp[i][j][k]=max(dp[i-1][j][k],dp[i-1][j-w[i]][k-v[i]]+c[i])
*/
int w, v, n;
// dp记录最大价值
int dp[105][105][105];
int a[105], b[105], c[105];
// r记录每个状态对应的物品编号序列
vector<int> r[105][105][105];

int main() {
    // 读入数据
    cin >> w >> v >> n;
    for(int i = 1; i <= n; i++) {
        cin >> a[i] >> b[i] >> c[i];
    }

    // 循环物品
    for(int i = 1; i <= n; i++) {
        //循环重量
        for(int j = 0; j <= w; j++) {
            //循环体积
            for(int k = 0; k <= v; k++) {
                // 默认不拿第 i 个物品
                dp[i][j][k] = dp[i - 1][j][k];
                r[i][j][k] = r[i - 1][j][k];

                // 如果装得下，尝试拿第 i 个物品
                if(j >= a[i] && k >= b[i]) {
                    int val_pick = dp[i - 1][j - a[i]][k - b[i]] + c[i];

                    if(val_pick > dp[i][j][k]) {
                        // 情况 1：拿了价值更高，必须更新
                        dp[i][j][k] = val_pick;
                        r[i][j][k] = r[i - 1][j - a[i]][k - b[i]];
                        r[i][j][k].push_back(i);
                    } else if(val_pick == dp[i][j][k]) {
                        // 情况 2：价值相等，利用 vector 自带的 < 运算符比较字典序
                        vector<int> tmp = r[i - 1][j - a[i]][k - b[i]];
                        tmp.push_back(i);

                        if(tmp < r[i][j][k]) {
                            r[i][j][k] = tmp;
                        }
                    }
                }
            }
        }
    }

    // 输出最大优惠金额
    cout << dp[n][w][v] << endl;

    // 输出商品序号
    for(int i = 0; i < r[n][w][v].size(); i++) {
        cout << r[n][w][v][i] << " ";
    }

    return 0;
}
