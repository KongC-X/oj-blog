1666 - 表达式求值

题目描述

给定一个只包含加法和乘法的算术表达式，请你编程计算表达式的值。

输入

一行，为需要你计算的表达式，表达式中只包含数字、加法运算符 “+++” 和乘法运算符 “×\times×”，且没有括号，所有参与运算的数字均为 000 到 231−12^{31}-1231−1 之间的整数。

输入数据保证这一行只有 0−90-90−9、+++、×\times× 这 121212种字符。

输出

一个整数，表示这个表达式的值。

注意：当答案长度多于 444 位时，请只输出最后 444 位，前导 000 不输出。

解题思路

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;	

/*
    第⼀步：分解并存储每个运算数（只存最后4位）、分解并存储每个运算符
    第⼆步：遍历每个数字，如果对应的运算符是*，先将乘法计算，将结果存储到下⼀位 本位清零
    注意本题中的数学原理：
    将两个整数求和取最后4位 = 将两个这个数分别取最后4位后求和，再取最后4位
    将两个整数求积取最后4位 = 将两个这个数分别取最后4位后求积，再取最后4位
    之所以要不断的取最后4位，是为了防⽌溢出。
*/

string s,w = "";
const int N = 100010;
int a[N],k1 = 0,k2 = 0,t; // 存储运算数
char f[N]; // 存储运算符
int r = 0; // 存储结果

int main() {
    cin >> s;
    // 1+1*3+4
    // a:1134
    // f:+*+
    for(int i = 0;i < s.size();i++) {
        // 如果是数字
        if(isdigit(s[i])) {
            w = w + s[i];
            // 判断一下连续数字结束
            if(i == s.size() - 1 || !isdigit(s[i + 1])) {
                // t = stoi(w); // 将字符串转换为整数
                t = atoi(w.c_str()); // 将字符串转换为整数
                k1++;
                a[k1] = t % 10000; // 取最后4位
                w = "";
            }
        } else {
            k2++;
            f[k2] = s[i];
        }
    }
    // 1+1*3+4
    // a:1034
    // f:+*+
    // 循环遍历运算符，优先算乘法
    for(int i = 1;i <= k2;i++) {
        if(f[i] == '*') {
            a[i + 1] = (a[i] * a[i + 1]) % 10000;
            a[i] = 0;
        }
    }
    // 求和	
    for(int i = 1;i <= k1;i++) {
        r = (r + a[i]) % 10000;
    }
    cout << r << endl;
}
