3894 - 小杨的N字矩阵

题目描述

小杨想要构造一个 m×mm \times mm×m 的 NNN 字矩阵（ mmm 为奇数），这个矩阵的从左上角到右下角的对角线、第 111 列和第 mmm 列都是半角加号 +++ ，其余都是半角减号 −-− 。

例如，一个 5×55 \times 55×5 的 NNN 字矩阵如下：

`+---+
++--+
+-+-+
+--++
+---+
`

请你帮小杨根据给定的 mmm 行打印出对应的 NNN 字矩阵。

输入

第一行包含一个正整数 mmm。

输出

输出对应的 NNN 字矩阵。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;

int main() {
    int n,i,j;
    cin >> n;
    for(i = 1;i <= n;i++) {
        for(j = 1;j <= n;j++) {
            if(j == 1 || j == n) {
                cout << '+';
            }else if(i == j) {
                cout << '+';
            }else {
                cout << '-';
            }
        }
        cout << endl;
    }
    return 0;
}
