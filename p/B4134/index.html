B4134 [信息与未来 2014] 关灯

洛谷 | 普及- | C++14 | 提交时间: 2026-04-14

算法标签：数学、2014、江苏、信息与未来

题目描述

有 $n$ 盏灯，编号为 $1,2,\cdots,n$，同时有 $n$ 个人，依次对灯进行操作。开始时，所有的灯都是关闭状态：

  • 第 $1$ 个人的操作：将所有灯打开；
  • 第 $2$ 个人的操作：将 $2$ 及 $2$ 的倍数的灯，状态取反（即“开”状态变为“关”状态，“关”状态变为“开”状态）；
  • 第 $3$ 个人的操作：将 $3$ 及 $3$ 倍数的灯状态取反；
  • ……
  • 第 $i(1\le i\le n)$ 个人的操作：将 $i$ 及 $i$ 倍数的灯状态取反。

当所有操作完成之后，计算出所有开状态灯的编号之和。

输入格式

一个整数，表示 $n$。

输出格式

一个整数，即操作后所有开状态的灯的编号之和。

样例

样例输入 #1

6```

**样例输出 #1**

5```

AC 代码

#include <iostream>
#include <cmath>
using namespace std;

int main() {
    /* 
     * 思路推导：
     * 1. 第 i 个人会切换编号为 i 的倍数的灯的状态。
     * 2. 所以，编号为 x 的灯会被它的每一个因数对应的人切换一次。
     * 3. 如果 x 的因数个数是奇数，那么灯最终是亮着的；如果是偶数，则是灭的。
     * 4. 数学上，一个正整数的因数个数是奇数，当且仅当它是完全平方数（比如 1,4,9,16...）。
     *    为什么？因为因数总是成对出现的（a * b = x），只有当 a = b 时才会落单，
     *    也就是说 x 是完全平方数时，平方根对应的因数只算一次，导致总数为奇数。
     * 5. 因此，问题变成：找出 1 到 n 中所有的完全平方数，求它们的和。
     * 6. 设 k = ⌊√n⌋，那么最大的完全平方数是 k²。
     * 7. 我们需要计算 1² + 2² + ... + k²，使用平方和公式：
     *       S = k * (k + 1) * (2k + 1) / 6
     * 8. 因为 n 最大可达 10^9，所以 k 最大约 31622，S 最大约 1.05×10^13，
     *    用 long long 存储足够。
     */

    long long n;
    cin >> n;

    // 计算不超过 n 的最大完全平方数的平方根
    long long k = sqrt(n);   // sqrt 返回浮点数，赋值给整数时会自动截断小数部分（向下取整）

    // 平方和公式
    long long ans = k * (k + 1) * (2 * k + 1) / 6;

    cout << ans << endl;
    return 0;
}
