2073 - 码头的集装箱

题目描述

码头上停泊一艘远洋轮船，轮船可以装下 ccc 吨的货物，码头上有 nnn 个集装箱需要运走，已知第 iii 个集装箱的重量为wiw_iwi​。

请你编程计算，在不超出轮船最大载重量的情况下，该轮船最多可以运走多少吨的集装箱。（注意：单个集装箱不能拆开运送，对于每个集装箱来说，要么整个运到轮船上，要么不运）

输入

第一行有 222 个正整数 nnn 和 ccc 。nnn 是集装箱数，ccc 是轮船的载重量。

第 222 行中有 nnn 个正整数，表示集装箱的重量（)。

输出

计算出的最大装载重量输出。

AC代码

#include <bits/stdc++.h>
using namespace std;

int n,c,w;
int f[40000];

int main(){
    cin>>n>>c;
    for(int i = 1;i <= n;i++){
        cin>>w;
        for(int j = c;j >= w;j--){
            f[j] = max(f[j],f[j-w]+w);
        }
    }
    
    cout<<f[c];
    return 0;
}
