1650 - 前缀最小值

题目描述

求一个数列的所有前缀最小值之和。

即：给出长度为 nnn 的数列 aia_iai​,求出对于所有 1≤i≤n1≤i≤n1≤i≤n，min(a1,a2,...,ai)min(a_1,a_2,...,a_i)min(a1​,a2​,...,ai​) 的和。

比如，有数列：666666666 304304304 692692692 188188188 596596596，前缀最小值为：666666666 304304304 304304304 188188188 188188188，和为 165016501650。

对于每个位置的前缀最小值解释如下：对于第 111 个数 666666666 ，只有一个数，一定最小；对于第 222 个数，求出前两个数的最小数，是 304304304 ；对于第 333 个数，求出前 333 个数的最小数是 304…304 \dots304… 其余位置依次类推，最后求前缀最小值的和。

由于读入较大，数列由随机种子生成。

其中 a[1]=xa[1]=xa[1]=x，a[i]=(379×a[i−1]+131)mod  997a[i]=(379 \times a[i-1]+131) \mod 997a[i]=(379×a[i−1]+131)mod997。（modmodmod 代表求余数）

输入

一行两个正整数 nnn, xxx ，分别表示数列的长度和随机种子。(n≤100000n ≤ 100000n≤100000,)

输出

一行一个正整数表示该数列的前缀最小值之和。

解题思路

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int a[100100],n,i,x;
int dp[100100];
int ma,s;

int main() {
    cin >> n >> x;
    a[1] = x; // 边界条件
    dp[1] = a[1];
    s = dp[1]; // 求和
    for(i = 2;i <= n;i++) {
        a[i] = (379 * a[i - 1] + 131) % 997;
        // 计算出前i个数的最大值
        dp[i] = min(dp[i - 1], a[i]);
        s += dp[i];
    }
    cout << s << endl;
}
