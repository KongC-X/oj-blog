1162 - 数组元素的删除

题目描述

把一个数组的第 $x$ 个位置的元素删除掉。

输入

输出有三行：

第一行有一个整数 $n$ ( $n ≤ 10$ )；

第二行有 $n$ 个整数（每个整数在$1$~$1000$之间）；

第三行有一个整数 $x$（$1≤x≤n$），为要删除的位置。

输出

输出更新后的数组。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int a[11],i,n,x,y;
int main(){
    cin>>n;
    for(i=1;i<=n;i++){
        cin>>a[i]; 
    }
    cin>>x;
    
    for(i=x;i<=n-1;i++){
        a[i]=a[i+1];
    }
    n--;

    for(i=1;i<=n;i++){
        cout<<a[i]<<" ";
    }
}
