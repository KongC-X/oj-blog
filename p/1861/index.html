1861 - 整除问题

题目描述

编写一个程序，输入三个正整数 min、maxmin、maxmin、max 和 factorfactorfactor ，然后对于 minminmin 到 maxmaxmax 之间的每一个整数（包括 minminmin 和 maxmaxmax ），如果它能被 factorfactorfactor 整除，就把它打印出来。

输入

输入只有一行，包括三个整数 min、maxmin、maxmin、max 和 factorfactorfactor 。

输出

输出只有一行，包括若干个整数，数与数之间用空格隔开。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    int i,mn,mx,factor;
    cin>>mn>>mx>>factor;
    for(i=mn;i<=mx;i++){
        if(i%factor==0){
            cout<<i<<" ";
        }
    }
    return 0;
}
