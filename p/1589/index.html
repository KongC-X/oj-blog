1589 - 最大部分和（连续部分和）

题目描述

有 nnn 个整数（1≤n≤1001≤n≤1001≤n≤100），排成一排，例如：

n=7n=7n=7：
−2-2−2 131313 121212 999 141414 −10-10−10 222 （777个整数）。

其中取连续数（至少选 111 个）的最大部分和为 484848 （即 13+12+9+1413+12+9+1413+12+9+14）。

输入

第一行一个整数 nnn。

第二行 nnn个整数 xix_ixi​（−100≤xi≤100-100≤x_i≤100−100≤xi​≤100）。

第二行的数之间有一个空格。

输出

一个整数（即最大的连续的部分和）。

解题思路

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int a[110],n,i,j;
int dp[110]; // dp[i]表示以第i个数结尾的最大连续子序列和
int ma,s; // ma存放连续最大和，s存放从每个数开始连续数和

int main() {
    cin >> n;
    for(i = 1;i <= n;i++) {
        cin >> a[i];
    }

    // 状态转移方程：
    // dp[i] = max(dp[i-1] + a[i], a[i])
    // 边界：dp[1] = a[1]
    dp[1] = a[1];
    ma = a[1];
    for(i = 2;i <= n;i++) {
        dp[i] = max(dp[i-1] + a[i], a[i]);
        ma = max(ma, dp[i]);
    }
    cout << ma << endl;
}
