1823 - 谷仓的安保

题目描述

Farmer John给谷仓安装了一个新的安全系统，并且要给牛群中的每一个奶牛安排一个有效的密码。一个有效的密码由 LLL (3≤L≤153 \le L \le 153≤L≤15)个小写字母(来自传统的拉丁字母集'a'...'z')组成，至少有一个元音('a', 'e', 'i', 'o', 或者 'u')，至少两个辅音(除去元音以外的音节)，并且有按字母表顺序出现的字母(例如，'abc'是有效的，而'bac'不是) 。

给定一个期望长度 LLL 和 CCC 个小写字母，写一个程序，打印出所有的长度为 LLL、能由这些字母组成的有效密码。密码必须按字母表顺序打印出来，一行一个。

输入

第一行: 两个由空格分开的整数，LLL 和 CCC 。（3≤C≤263 \le C \le 263≤C≤26）

第二行: CCC 个空格分开的小写字母，密码是由这个字母集中的字母来构建的。

输出

输出若干行，每一个输出行包括一个长度为 LLL 个字符的密码(没有空格)。输出行必须按照字母顺序排列。

如果计算出超过 250002500025000 个有效密码，你的程序只需输出前250002500025000 个有效密码，即使后面还存在有效密码。

AC代码

#include <bits/stdc++.h>
using namespace std;

char a[30],r[30];
bool f[30];
int len,c,ans = 0;

//输出
void print(){
    //检验是否包含至少1个元音2个辅音 
    int cnt = 0;
    for(int i = 1;i <= len;i++){
        if(r[i]=='a'||r[i]=='e'||r[i]=='i'||r[i]=='o'||r[i]=='u') cnt++;
    }
    
    //有至少1个元音，2个辅音 
    if(cnt>=1&&len-cnt>=2){
        ans++;
        for(int i = 1;i <= len;i++) cout<<r[i];
        cout<<endl;
        
        if(ans == 25000) exit(0);
    }
} 

//从c个字符中搜索出len个满足条件的字符
void dfs(int x,int cnt){
    if(cnt == len){
        print();
        return;	
    } 
    if(x > c) return;
    
    r[cnt+1] = a[x];
    dfs(x+1,cnt+1);
    dfs(x+1,cnt);
} 

int main() {
    cin>>len>>c;
    for(int i = 1;i <= c;i++){
        cin>>a[i];
    }
    
    sort(a+1,a+c+1);//排序
     
    //从第1个位置开始填字符
    dfs(1,0); 
    return 0;
}
