4736 - “1”出现的次数

题目描述

给定两个正整数 mmm、nnn，在纸上写下从 mmm 到 nnn 的所有整数，然后数一下数字 “1” 出现的次数。

例如：当 m=1m=1m=1，n=2n=2n=2 时，写下 111，222。总共出现了 111 个 “1”；

当 m=8m=8m=8，n=12n=12n=12 时，写下 888，999，101010，111111，121212。总共出现了 444 个“1”。

请设计程序来统计从 mmm 到 nnn 之间（含 mmm 和 nnn ）所有整数中数字“1”出现的次数。

输入

输入包含两个正整数 mmm 和 nnn，分别表示区间的起始值和终止值。两个整数之间用空格分隔。（1≤m≤n≤1061 \le m \le n \le 10^61≤m≤n≤106）

输出

输出一个整数，表示从 mmm 到 nnn 的所有整数中数字“1”出现的总次数。

AC代码

#include <iostream>
using namespace std;

int main() {
    int m, n;
    cin >> m >> n;
    
    int count = 0;  // 统计数字 "1" 出现的次数
    
    for (int i = m; i <= n; i++) {
        int temp = i;
        
        // 分解 temp 的每一位数字
        while (temp > 0) {
            if (temp % 10 == 1) {  // 如果最后一位是 1
                count++;
            }
            temp /= 10;  // 去掉最后一位
        }
    }
    
    cout << count << endl;
    
    return 0;
}
