5943 环保能量球

东方博宜 入门
GESP二级25年12月循环

5943 - 环保能量球

题目描述

小杨最近在玩一个环保主题的游戏。在游戏中，小杨每行走 111 公里就可以获得 111 点“环保能量”。

为了激励玩家，游戏设置了“里程奖励”：小杨每行走 xxx 公里，游戏就会额外奖励 111 点能量。

现在已知小杨总共行走了 nnn 公里，请你帮他计算，他一共能获得多少点环保能量？

输入

第一行包含一个正整数 ttt，代表测试数据组数。

对于每组测试数据：

第一行包含一个正整数 nnn，代表行走的公里数。

第二行包含一个正整数 xxx，代表奖励触发的间隔。

输出

对于每组测试数据，输出一个整数，代表小杨获得的环保能量总数。

AC代码

#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        int n, x;
        cin >> n >> x;
        int total = n + n / x;
        cout << total << endl;
    }
    return 0;
}
