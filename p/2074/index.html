2074 - 货币问题

题目描述

某国家有 nnn 种不同面值的货币，第 iii 种货币价值 aia_iai​ 元。

请问：如果每种货币都提供任意多的数量的情况下，如果需要 mmm 元金额的货币，有多少种不同的方案？

输入

第一行两个整数 nnn，mmm（m≤5000，n≤100m \le 5000，n \le 100m≤5000，n≤100)；

以下 nnn 行，每行一个整数，第 i+1i+1i+1 行为第 iii 种货币的面值。

输出

一个整数，为方案数（方案数$ \le 10
$181818）。

AC代码

#include <bits/stdc++.h>
using namespace std;
 
//完全背包 
long long f[5010];
long long n,m,v;
 
int main(){
    cin>>n>>m;
    f[0] = 1;//边界，组成0元有1种方案 
    for(int i = 1;i <= n;i++){
        cin>>v;
        for(int j = v;j <= m;j++){
            f[j] = f[j] + f[j-v];
        }
    }
     
    cout<<f[m];
     
    return 0;
}
