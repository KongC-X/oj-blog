题目描述

给定 A,IA,IA,I，求一个最小的 NNN，使得⌈NA⌉≥I\lceil\frac{N}{A}\rceil\geq I⌈AN​⌉≥I。

输入格式

一行两个整数 A,IA,IA,I。

输出格式

一行一个整数 NNN。

样例

样例输入 #1

38 24```

**样例输出 #1**

875```

样例输入 #2

1 100```

**样例输出 #2**

100```

样例输入 #3

10 10```

**样例输出 #3**

91```

AC 代码

#include <iostream>
using namespace std;

int main() {
    // 思路：
    // 要求最小的 N，使得 ceil(N / A) >= I。
    // ceil(N / A) >= I 等价于 N > A * (I - 1)。
    // 因此最小的整数 N = A * (I - 1) + 1。

    int A, I;
    cin >> A >> I;

    int N = A * (I - 1) + 1;

    cout << N << endl;
    return 0;
}
