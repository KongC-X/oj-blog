1141 - A类多？B类多？

题目描述

一个自然数转换成二进制数后，如果 111 的个数比 000 的个数多，则称为 AAA 类数，否则称为 BBB 类数。输入 nnn （ n≤10000n \le 10000n≤10000 ），输出 111 到 nnn 之间 AAA 类数、 BBB 类数各多少个。

输入

输入一个整数 nnn （ n≤10000n \le 10000n≤10000 ）

输出

两个整数，为 AAA 类数和 BBB 类数的个数（用空格隔开）。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

//定义函数判断一个数是A类数，还是B类数
//是A类数，返回'A'，是B类数返回'B' 
char fun(int n){
    char r;
    
    //短除法求出n中1的个数和0的个数分别有几个
    int c0 = 0,c1 = 0;
    //短除法，除2取余 
    while(n != 0){
        if(n % 2 == 0) c0++;
        else c1++;
        
        n = n / 2;
    } 
    
    //如果1的个数比0的个数多，则称为A类数
    if(c1 > c0){
        r = 'A';
    } else{
        r = 'B';
    }
    
    return r;
} 

int main(){
    //a统计A类数的个数，b统计B类数的个数 
    int a = 0,b = 0;
    int i,n;
    cin>>n;
    //逐个调用函数判断每个数是A类数，还是B类数 
    for(i = 1;i <= n;i++){
        if(fun(i) == 'A'){
            a++;
        }else{
            b++;
        }
    }
    
    cout<<a<<" "<<b<<endl;
    
    return 0;
}
