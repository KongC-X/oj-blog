B2142 求 1+2+3+...+N 的值

洛谷 | 入门 | C++14 | 提交时间: 2026-07-15

算法标签：函数与递归

题目描述

用递归的方法求 1+2+3+1+2+3+1+2+3+ …… +N+N+N 的值。

样例

样例输入 #1

5```

**样例输出 #1**

15```

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 递归函数：返回 1 + 2 + ... + x 的和
long long sum(int x) {
    if (x == 1) return 1;               // 递归边界：1 的和就是 1
    return x + sum(x - 1);              // 当前数加上前面数的和
}

int main() {
    int n;                              // n: 累加到多少
    cin >> n;
    cout << sum(n) << endl;
    return 0;
}
