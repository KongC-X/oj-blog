P2181 对角线

洛谷 | 普及| C++14 | 提交时间: 2025-07-31

算法标签：数学、洛谷原创、组合数学

题目描述

对于一个 nnn 个顶点的凸多边形，它的任何三条对角线都不会交于一点。请求出图形中对角线交点的个数。

例如，666 边形：

输入格式

输入只有一行一个整数 nnn，代表边数。

输出格式

输出一行一个整数代表答案。

样例

样例输入 #1

3```

**样例输出 #1**

0```

样例输入 #2

6```

**样例输出 #2**

15```

AC 代码

#include<bits/stdc++.h>
using namespace std;
unsigned long long n,ans;
int main()
{
    scanf("%lld",&n);
    ans=n * (n-1) / 2 * (n-2) / 3 * (n-3) / 4;
    printf("%lld\n",ans);
    return 0;
}
