1154 - 数组元素的查找

题目描述

给你 mmm 个整数，查找其中有无值为 nnn 的数，有则输出该数第一次出现的位置，没有则输出 −1-1−1 。

输入

第一行一个整数 mmm 代表数的个数 ( 0≤m≤1000 \le m \le 1000≤m≤100 ) 。

第二行 mmm 个整数（空格隔开）( 这些数在0∼10000000 \sim 10000000∼1000000范围内 )。

第三行为要查找的数 nnn。

输出

nnn 的位置或 −1-1−1。

解题思路

AC代码

AC代码

#include<iostream>
using namespace std;

int main(){
    int a[100],m,n,i;
    bool flag = false;
    cin >> m;
    for(i = 0;i < m;i++){
        cin >> a[i];
    }
    cin >> n;
    for(i = 0;i < m;i++){
        if(a[i] == n){
            cout << i + 1 << endl;
            flag = true;
            break;
        }
    }
    if(flag == false){
        cout << -1 << endl;
    }
}
