1300 - 小明暑假的零花钱

题目描述

小明同学的妈妈在期末考试之后决定根据小明的考试成绩奖励小明不同的暑假零花钱，如果考试成绩在 909090 分以上（包括 909090 分），零花钱是成绩的 333 倍，如果考试成绩在 80∼9080 \sim 9080∼90 之间（包括 808080 不包括 909090 ），零花钱是成绩的 222 倍，如果成绩在 70∼8070 \sim 8070∼80 之间（包括 707070 不包括808080 ），零花钱就是成绩的分数值，如果成绩在 707070 以下，那么暑假只有 505050 元的零花钱。

请从键盘读入小明同学的考试成绩（ 0∼1000 \sim 1000∼100 之间的整数），根据考试成绩计算小明暑假应得的零花钱。

输入

键盘读入一个整数 nnn 代表小明同学的考试成绩（ 0∼1000 \sim 1000∼100 之间）。

输出

小明暑假的零花钱的金额。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    //定义变量a表示成绩, l表示零花钱 
    int a,l;
    //输入成绩 
    cin>>a;
    //根据成绩范围判断零花钱数量 
    //a大于等于90:3倍成绩的零花钱
    //a大于等于80小于90:2倍成绩零花钱
    //a大于等于70小于80:成绩等于零花钱
    //a小于70:零花钱为50 
    if(a>=90){
        l=3*a;
    }else if(a>=80){
        l=2*a;
    }else if(a>=70){
        l=a;
    }else if(a<70){
        l=50;
    }
    //输出零花钱 
    cout<<l;
    return 0;
}
