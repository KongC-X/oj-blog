P9644 [SNCPC2019] Turn It Off

洛谷 | 普及- | C++14 | 提交时间: 2026-08-04

算法标签：2019、二分、O2优化、陕西、省赛/邀请赛

题目描述

It's already 21:30 now, and it's time for BaoBao to go to bed. To ensure his sleeping quality, BaoBao decides to turn all the lights in his bedroom off.

There are nnn lights, numbered from 1 to nnn, arranged in a row in BaoBao's bedroom. Each time BaoBao can select an integer iii and turn all the lights numbered from iii to (i+L−1)(i+L-1)(i+L−1) (both inclusive) off, where LLL is a predefined positive integer. Note that each time the value of LLL must be the same.

Given the initial status of all the lights, please help BaoBao determine the smallest possible LLL so that he can turn all the lights off within kkk times.

输入格式

There are multiple test cases. The first line of the input contains an integer TTT, indicating the number of test cases. For each test case:

The first line contains two integers nnn and kkk (1≤k≤n≤2×1051 \le k \le n \le 2 \times 10^51≤k≤n≤2×105).

The second line contains a string sss (∣s∣=n|s| = n∣s∣=n, s∈{‘0’,‘1’}s \in \{\text{`0'}, \text{`1'}\}s∈{‘0’,‘1’}) indicating the initial status of the lights. Let sis_isi​ be the iii-th character in sss, if si=‘1’s_i = \text{`1'}si​=‘1’ then the iii-th light is initially on, otherwise it's initially off. It's guaranteed that there is at least one `1· in sss.

It's guaranteed that the sum of nnn of all test cases will not exceed 2×1062 \times 10^62×106.

输出格式

For each test case output one line containing one integer, indicating the smallest possible LLL.

样例

样例输入 #1

2
10 4
0101011111
3 1
010```

**样例输出 #1**

3
1```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int n, k;
string s;

// 检查长度 L 是否可行，返回需要的区间数
int check(int L) {
    int cnt = 0;         // 已使用操作次数
    int pos = 0;         // 当前扫描位置（0-based）
    while (pos < n) {
        if (s[pos] == '0') {
            pos++;
            continue;
        }
        // 遇到亮灯，必须在这里开始一次操作
        cnt++;
        if (cnt > k) return cnt;   // 已经超过 k 次，提前退出
        // 这次操作覆盖了 [pos, pos+L-1]，直接跳到 pos+L
        pos += L;
    }
    return cnt;
}

int main() {
    /*
     * 【题目类型】二分答案 + 贪心覆盖
     * 【核心思路】
     * 1. 对于给定的 L，采用贪心：从左到右找到第一个亮灯，放置长度为 L 的区间覆盖它，
     *    然后跳到此区间之后继续找下一个亮灯。
     * 2. 如果覆盖所有亮灯需要的区间数 <= k，则 L 可行。
     * 3. 二分最小的可行 L。
     *
     * 【时间复杂度】O(Σ n log n)
     */

    ios::sync_with_stdio(false);
    cin.tie(0);

    int T;
    cin >> T;
    while (T--) {
        cin >> n >> k;
        cin >> s;

        int l = 1, r = n, ans = n;
        while (l <= r) {
            int mid = (l + r) / 2;
            int need = check(mid);
            if (need <= k) {
                ans = mid;
                r = mid - 1;      // 尝试更小的 L
            } else {
                l = mid + 1;      // L 太小，增大
            }
        }
        cout << ans << endl;
    }
    return 0;
}
