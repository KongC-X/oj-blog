2246 - 判断能否被3，5，7整除

题目描述

给定一个整数，判断它能否被 3，5，73，5，73，5，7 整除，并输出以下信息：

111 、能同时被 3，5，73，5，73，5，7整除（直接输出 333 555 777 ，每个数中间一个空格）；

222 、只能被其中两个数整除（输出两个数，小的在前，大的在后。例如： 333 555 或者 333 777 或者 555 777 ,中间用空格分隔）；

333 、只能被其中一个数整除（输出这个除数）；

444 、不能被任何数整除，输出小写字符 n 。

输入

输入一行，包括一个整数。

输出

输出一行，按照描述要求给出整数被 3，5，73，5，73，5，7 整除的情况。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin>>n;
    if(n%3==0&&n%5==0&&n%7==0) {
        cout<<3<<" "<<5<<" "<<7;
    } else if(n%3!=0&&n%5!=0&&n%7!=0) {
        cout<<"n";
    } else {
        if(n%3==0) {
            cout<<3<<" ";
        }
        if(n%5==0) {
            cout<<5<<" ";
        }
        if(n%7==0) {
            cout<<7<<" ";
        }
    }
    return 0;
}
