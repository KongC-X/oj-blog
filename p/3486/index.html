3486 - 烹饪问题

题目描述

有 NNN 种食材，编号从 000 至 N−1N-1N−1，其中第 iii 种食材的美味度为aia_iai​。

不同食材之间的组合可能产生奇妙的化学反应。具体来说，如果两种食材的美味度分别为 xxx 和 yyy，那么它们的契合
度为 xxx andandand yyy。

其中，andandand 运算为按位与运算，需要先将两个运算数转换为二进制，然后在高位补足 000，再逐位进行与运算。例如，
121212 与 666 的二进制表示分别为 110011001100 和 011001100110 ，将它们逐位进行与运算，得到 010001000100 ，转换为十进制得到444 ，因此 121212 andandand 666 === 444。在 C++ 或 Python 中，可以直接使用 & 运算符表示与运算。

现在，请你找到契合度最高的两种食材，并输出它们的契合度.

输入

第一行一个整数 NNN，表示食材的种数。

接下来一行 NNN 个用空格隔开的整数，依次为 a0,...,aN−1a_0,...,a_N-1a0​,...,aN​−1 ，表示各种食材的美味度。

输出

输出一行一个整数，表示最高的契合度。

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

// 由于是两个数与，而这些数字在电脑中都是以二进制存储的
// 所以我们只需要考察最大的几个数字就行了，后面数字太小，高位0太多肯定不行的
// 在与的时候两个不同数字如果相邻，我们要考察的只需要2位即可
// 而2位最多只能组成4个数字，所以只需要考察最大四个数字即可

long long a[1000010];
bool cmp(int a,int b)
{
    return a>b;
}
int main()
{
    int n;
    scanf("%d",&n);
    for(int i=1;i<=n;i++)
    {
        scanf("%lld",&a[i]);
    }
    sort(a+1,a+n+1,cmp);
    n=min(n,4);
    long long mx=0;
    for(int i=1;i<=n;i++)
    {
        for(int j=1;j<=n;j++)
        {
            if(i!=j)
            {
                mx=max(mx,a[i]&a[j]);
            }
        }
    }
    cout<<mx;
    return 0;
}
