B4517 [科大国创杯小学组 2026] 分糖果

洛谷 | 入门 | C++14 | 提交时间: 2026-07-20

算法标签：数学、安徽、2026、顺序结构、分支结构、科创活动

题目背景

Subtask 0 为民间数据，Subtask 1 为官方测试数据。

题目描述

小可可家里来了 mmm 个小朋友。

小可可家里有 nnn 个糖果，每个糖果的美味值都为 xxx，她想给每个小朋友分 kkk 个糖果。因为糖果太多了数不过来，所以她问你，她分完糖果后剩下的糖果美味值之和是多少。

如果小可可的糖果不够分，请你输出 -1。

输入格式

一行 444 个正整数，分别为 n,x,m,kn, x, m, kn,x,m,k。

输出格式

输出一行一个整数，表示答案。

样例

样例输入 #1

9 3 2 3```

**样例输出 #1**

9```

样例输入 #2

10 4 5 2```

**样例输出 #2**

0```

样例输入 #3

9 4 5 2```

**样例输出 #3**

-1```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n, x, m, k;         // n:糖果总数, x:每个糖果的美味值, m:小朋友数, k:每人分得的糖果数
    cin >> n >> x >> m >> k;

    long long need = m * k;       // 需要的糖果总数
    if (need > n) {
        cout << -1 << endl;       // 糖果不够分
    } else {
        long long left = n - need; // 剩下的糖果数
        long long ans = left * x;  // 剩下的糖果美味值总和
        cout << ans << endl;
    }

    return 0;
}
