3403 - 小杨的储蓄

题目描述

小杨共有 NNN 个储蓄罐，编号从 000 到 N−1N-1N−1。

从第 111 天开始，小杨每天都会往存钱罐里存钱。具体来说，第 iii 天他会挑选一个存钱罐 aia_iai​，并存入 iii 元钱。

过了 DDD 天后，他已经忘记每个储蓄罐里都存了多少钱了，你能帮帮他吗？

输入

输入 222 行，第一行两个整数 N,DN,DN,D ；

第二行 DDD 个整数，其中第 iii 个整数为 aia_iai​（保证 0≤ai≤N−10 \leq a_i \leq N-10≤ai​≤N−1 ）。

每行的各个整数之间用单个空格分隔。

保证 1≤N≤1,0001 \leq N \leq 1,0001≤N≤1,000；1≤D≤1,0001 \leq D \leq 1,0001≤D≤1,000。

输出

输出 NNN 个用单个空格隔开的整数，其中第 iii 个整数表示编号为 i−1i-1i−1 的存钱罐中有多少钱（ i=1,...,Ni = 1,...,Ni=1,...,N ）。

解题思路

AC代码

#include<iostream>
using namespace std;

int main() {
    int i,j,n;
    char c;
    cin >> n;
    // 循环控制行数
    for(i = 1;i <= n;i++) {
        // 打印每一行的数字
        for(j = 1;j <= n;j++) {
            c = j + 64;
            cout << c;
        }
        // 打印每一行的换行符
        cout << endl;
    }
}
