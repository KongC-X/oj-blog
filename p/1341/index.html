1341 - 银行存款问题

题目描述

亮亮把 nnn 元按照 mmm 年期整存存入银行，按照目前银行的年利率，请问到期后亮亮可以连本带息总共拿到多少钱？（ 6.1.986.1.986.1.98 ）

存期（整存整取）

年利率

111年

3.25%3.25\%3.25%

222 年

3.75%3.75 \%3.75%

333年∼4\sim 4∼4 年

4.25%4.25\%4.25%

555 年及 555 年以上

4.75%4.75\%4.75%

输入

两个整数 nnn 和 mmm 。

输出

一个小数，代表亮亮 mmm年后一共可以拿到的金额（保留 111 位小数）。

解题思路

AC代码

AC代码

#include <iostream>
#include <iomanip>
using namespace std;

int main(){
    //定义变量n代表存款金额，m代表存几年 
    int n,m; 
    //输入n,m
    cin>>n>>m;
    
    if(m==1){
        cout<<fixed<<setprecision(1)<<1*n*0.0325+n;	
    } else if(m==2){
        cout<<fixed<<setprecision(1)<<2*n*0.0375+n;
    } else if(m==3||m==4){
        cout<<fixed<<setprecision(1)<<m*n*0.0425+n;
    } else{
        cout<<fixed<<setprecision(1)<<m*n*0.0475+n;	
    }
    return 0;
}
