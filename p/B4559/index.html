B4559 [合肥市小学组 2024 T1] 数字加密

洛谷 | 入门 | C++14 | 提交时间: 2026-07-20

算法标签：2024、安徽、循环结构、小学活动

题目描述

在信息科技课堂上，小肥正在思考“数字加密”实验项目。项目需要加密 $n$ 个正整数，对每一个正整数 $x$ 加密的规则是，将 $x$ 的每一位数字都替换为 $x$ 的最大数字。

例如，$x = 2024$，最大数字是 $4$，加密后为 $4444$；$x = 168$，最大数字是 $8$，加密后为 $888$。

小肥需要计算出 $n$ 个正整数加密后的总和。

输入格式

输入的第一行包含一个正整数 $n$，表示需要加密的正整数个数。

接下来 $n$ 行，每行包含一个需要加密的正整数 $x$。

输出格式

输出一行，其中包含一个正整数，为 $n$ 个正整数加密后的总和。

样例

样例输入 #1

5
1
2
3
4
5```

**样例输出 #1**

15```

样例输入 #2

5
10
2
31
14
53```

**样例输出 #2**

145```

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 函数：对正整数 x 进行加密，返回加密后的数
int jia(int x) {
    int mx = 0;                // 记录最大数字
    int t = x;                 // 临时变量，用于提取每一位
    while (t > 0) {
        int d = t % 10;        // 取出个位
        if (d > mx) mx = d;    // 更新最大数字
        t /= 10;               // 去掉个位
    }
    // 构造加密后的数：将每一位都替换成 mx
    int ans = 0;
    t = x;
    int p = 1;                 // 位权（1,10,100,...）
    while (t > 0) {
        ans += mx * p;         // 累加当前位
        p *= 10;               // 位权乘10
        t /= 10;               // 处理下一位
    }
    return ans;
}

int main() {
    // 思路：读入 n 个数，对每个数调用加密函数，累加求和输出。
    int n;                     // n: 需要加密的正整数个数
    cin >> n;

    long long sum = 0;         // sum: 加密后的总和（用 long long 安全）
    for (int i = 0; i < n; i++) {
        int x;                 // x: 当前需要加密的正整数
        cin >> x;
        sum += jia(x);
    }

    cout << sum << endl;
    return 0;
}
