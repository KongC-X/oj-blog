1582 - 马里奥的银币2

题目描述

马里奥有很多银币，有一天他又得到了一张魔法卡，只要使用这张魔法卡，就可以使得他的银币里面的前一半银币的金额翻倍，后一半银币的金额加 111 （马里奥的银币的数量是偶数），马里奥顿时觉得自己要发财了，迫不及待的使用了这张魔法卡，请你求出，马里奥使用了这张魔法卡之后，他的银币的金额分别是多少？

比如：假设马里奥存有的银币金额分别为888 555 777 888 111 444 ，那么使用魔法卡之后，他的银币的金额变为 161616 101010 141414 999 222 555 。

输入

第一行是一个整数 nnn 代表马里奥有 nnn 个银币（ n≤1000n \le 1000n≤1000，且 nnn 是偶数）；

第二行有 nnn 个整数，用空格隔开，代表马里奥每个银币的金额。

输出

一行有 nnn 个整数，代表使用过魔法卡之后，马里奥的银币的金额，分别是多少？

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

/*
假设有n个数
前一半的下标：0~n/2-1
后一半的下标是：n/2~n-1 
*/ 
int n,a[1010];

int main() {
    cin>>n;
    for(int i = 0;i < n;i++){
        cin>>a[i];
        //按题意修改数组元素的值
        if(i < n / 2){
            a[i] = a[i] * 2; 	
        }else{
            a[i] = a[i] + 1;
        } 
    }
    
    //输出
    for(int i = 0;i < n;i++){
        cout<<a[i]<<" ";
    } 
    return 0;
}
