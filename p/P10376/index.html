P10376 [GESP202403 六级] 游戏

洛谷 | 普及- | C++14 | 提交时间: 2026-06-03

算法标签：动态规划 DP、2024、深度优先搜索 DFS、记忆化搜索、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1146

题目描述

你有四个正整数 n,a,b,cn,a,b,cn,a,b,c，并准备用它们玩一个简单的小游戏。

在一轮游戏操作中，你可以选择将 nnn 减去 aaa，或是将 nnn 减去 bbb。游戏将会进行多轮操作，直到当 n≤cn \leq cn≤c 时游戏结束。

你想知道游戏结束时有多少种不同的游戏操作序列。两种游戏操作序列不同，当且仅当游戏操作轮数不同，或是某一轮游戏操作中，一种操作序列选择将 nnn 减去 aaa，而另一种操作序列选择将 nnn 减去 bbb。如果 a=ba=ba=b，也认为将 nnn 减去 aaa 与将 nnn 减去 bbb 是不同的操作。

由于答案可能很大，你只需要求出答案对 109+710^9 + 7109+7 取模的结果。

输入格式

一行四个整数 n,a,b,cn,a,b,cn,a,b,c。

输出格式

输出一行一个整数表示答案。

样例

样例输入 #1

1 1 1 1```

**样例输出 #1**

1```

样例输入 #2

114 51 4 1```

**样例输出 #2**

176```

样例输入 #3

114514 191 9 810```

**样例输出 #3**

384178446```

AC 代码

#include <iostream>
#include <cstring>
using namespace std;

const int MOD = 1000000007;            // 模数 1e9+7
int dp[200010];                        // dp[x] 表示从当前值为 x 开始到游戏结束的方案数

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, a, b, c;
    cin >> n >> a >> b >> c;

    // ---------- 思路 ----------
    // 该问题是一个有向无环图上的路径计数，可以用动态规划解决。
    // 状态定义：dp[x] = 从值为 x 开始，进行若干次操作直到值 ≤ c 的方案总数。
    // 
    // 初始化：若 x ≤ c，游戏已经结束，只有空操作序列一种方案，故 dp[x] = 1。
    // 
    // 状态转移（x > c）：
    //   可以选择减 a 或减 b（即使 a == b 也视为两种不同操作）。
    //   减 a 后新值为 x - a（若 x - a ≤ c 则直接结束，贡献为 1），
    //   同理减 b 后贡献为 1 或 dp[x - b]。
    //   因此 dp[x] = ( (x - a ≤ c ? 1 : dp[x - a]) + (x - b ≤ c ? 1 : dp[x - b]) ) % MOD。
    // 
    // 最终答案即为 dp[n]。
    // 注意：当 x - a ≤ c 时，包括 x - a <= 0 的情况，都视为 1。
    // 时间复杂度 O(n)，空间 O(n)。

    // 初始化所有 ≤ c 的状态为 1
    for (int i = 0; i <= c; i++) {
        dp[i] = 1;
    }

    // 递推计算 > c 的状态
    for (int x = c + 1; x <= n; x++) {
        long long v = 0;                     // 用 long long 避免加法溢出
        // // 选择减 a
        // x - a <= c ? v += 1 : v += dp[x - a];
        // // 选择减 b
        // x - b <= c ? v += 1 : v += dp[x - b];
        // dp[x] = v % MOD;
        dp[x] = ( (x - a <= c ? 1 : dp[x - a]) + (x - b <= c ? 1 : dp[x - b]) ) % MOD;
    }

    cout << dp[n] << endl;
    return 0;
}
