5391 - 最长连续段

题目描述

对于 kkk 个整数构成的数组 [b1,b2,…,bk][b_1, b_2, \ldots, b_k][b1​,b2​,…,bk​]，如果对 都有 bi+1=bi+1b_{i+1} = b_i + 1bi+1​=bi​+1，那么称数组 bbb 是一个连续段。

给定由 nnn 个整数构成的数组 [a1,a2,…,an][a_1, a_2, \ldots, a_n][a1​,a2​,…,an​]，你可以任意重排数组 aaa 中元素顺序。请问在重排顺序之后，aaa 所有是连续段的子数组中，最长的子数组长度是多少？

例如，对于数组 [1,0,2,4][1, 0, 2, 4][1,0,2,4]，可以将其重排为 [4,0,1,2][4, 0, 1, 2][4,0,1,2]，有以下 101010 个子数组：

其中除 [4,0],[4,0,1],[4,0,1,2][4, 0], [4, 0, 1], [4, 0, 1, 2][4,0],[4,0,1],[4,0,1,2] 以外的子数组均是连续段，因此是连续段的子数组中，最长子数组长度为 3。

输入

第一行，一个正整数 nnn，表示数组长度。

第二行， nnn个整数 a1，a2，...ana_1，a_2，...a_na1​，a2​，...an​，表示数组中的整数。

输出

一行，一个整数，表示数组 aaa 重排顺序后，所有是连续段的子数组的最长长度。

解题思路

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

long long a[100010];

int main() {
    int n;
    cin >> n;
    
    // 读取数组
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    
    // 对数组进行排序
    sort(a, a + n);
    
    int maxLen = 1;      // 记录最长连续段的长度，至少为1
    int currentLen = 1;  // 当前连续段的长度
    
    // 遍历排序后的数组，寻找最长连续整数段
    for (int i = 1; i < n; i++) {
        // 如果当前数字与前一个相同，跳过重复数字
        if (a[i] == a[i - 1]) {
            continue;
        }
        // 如果当前数字正好是前一个数字+1，说明连续
        if (a[i] == a[i - 1] + 1) {
            currentLen++;
        } else {
            // 连续中断，更新最大值并重置当前长度
            if (currentLen > maxLen) {
                maxLen = currentLen;
            }
            currentLen = 1;
        }
    }
    
    // 检查最后一段连续序列
    if (currentLen > maxLen) {
        maxLen = currentLen;
    }
    
    // 输出最长连续段的长度
    cout << maxLen << endl;
    
    return 0;
}
