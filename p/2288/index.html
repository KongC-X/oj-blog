2288 - 数字放大

题目描述

给定一个整数序列以及放大倍数 $x$ ，将序列中每个整数放大 $x$ 倍后输出。

输入

包含三行： 第一行为 $N$ ，表示整数序列的长度($N ≤ 100$)；

第二行为 $N$ 个整数（不超过整型范围），整数之间以一个空格分开；

第三行包含一个整数（不超过整型范围），为指定的整数 $x$ 。

输出

$N$ 个整数，为原序列放大之后的序列，整数之间以一个空格分开。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
long long a[110];
int main(){
    int n,k;
    cin>>n;
    for(int i=0; i<n; i++){
        cin>>a[i];
    } 
    cin>>k;
    
    for(int i=0; i<n; i++){
        cout<<a[i]*k<<" ";
    }
    return 0;
}
