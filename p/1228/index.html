1228 - 排队打水问题

题目描述

有 nnn 个人排队到 rrr 个水龙头去打水，他们装满水桶的时间 t1,t2,...,tnt_1,t_2,...,t_nt1​,t2​,...,tn​ 为整数且各不相等，应如何安排他们的打水顺序才能使他们花费的总时间最少？

每个人打水的时间 = 排队的时间 + 实际打水的时间，本题假设一个人打好水，排在他后面的人接着打水的这个切换过程不消耗时间。

比如，有 222 个人 AAA 和 BBB ，他们打水的时间分别是 333 和 222 ，只有 111 个水龙头，这时，如果 AAA 先打水，BBB 后打水，那么 AAA 和 BBB 打水的时间分别为 333 、3+23+23+2（ BBB 排队 333 分钟）。

因此，所有人打水的总时间就是每个人的打水时间及每个人的排队时间的总和。

输入

第 111 行，两个整数 nnn (1≤n≤5001≤n≤5001≤n≤500) 和 rrr (1≤r≤1001≤r≤1001≤r≤100)。

第 222 行，nnn 个正整数 t1,t2,...,tnt_1,t_2,...,t_nt1​,t2​,...,tn​ ，(1≤ti≤10001≤t_i≤10001≤ti​≤1000)表示每个人装满水桶的时间。

输出

111 行，一个正整数，表示他们花费的最少总时间。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() { 
    int a[600];
    int n,r,i,s = 0;
    cin >> n >> r;
    for(i=1;i<=n;i++) cin >> a[i];
    sort(a+1,a+n+1);
    // for(i=1;i<=n;i++) cout << a[i] << " ";
    for(i=1;i<=n;i++) {
        if(i > r) {
            a[i] = a[i] + a[i - r];
        }
        s += a[i];
    }
    cout << s << endl;
}
