2052 - 图的dfs遍历

题目描述

一个有 $n$ 个结点的无向连通图，这些结点以编号：$1,2 \dots n$ 进行编号，现给出结点间的连接关系。

请以结点 $1$ 为起点，按 dfs（深度优先搜索）、优先访问小编号结点的顺序遍历并输出该图。

输入

第一行为两整数，$n$ 和 $e$ ，表示 $n$ 个顶点，$e$ 条边。（ $2 \le n,e \le 10$ ）

以下 $e$ 行每行两个数，表示两个结点是连通的。

输出

只有一行，为按照优先访问小编号结点的dfs的结果。

AC代码

#include<iostream>
#include <bits/stdc++.h>
using namespace std;

/*
思路：
1.邻接矩阵存储
2.从1点开始深搜
(1)走过标记
(2)第i个点要尝试1~n中所有的点，哪个点能走，深搜前进
*/
 
int n,e;
int a[20][20];//邻接矩阵 
bool f[20];//标记数组，节点是否访问 
 
//访问x节点，小编号优先
void dfs(int x){
    //走过标记
    f[x] = true; 
    cout<<x<<" "; //访问x节点
    //尝试访问x相邻的节点
    for(int i = 1;i <= n;i++){
        // 如果x节点有边，且i节点未访问过
        if(a[x][i] == 1 && !f[i]){
            dfs(i); //访问i节点
        }
    } 
}
 
int main(){
    cin>>n>>e;
    int x,y;
    //存储邻接矩阵，读入e条边
    for(int i = 1;i <= e;i++){
        cin>>x>>y;
        // 无向图，x节点到y节点有边，y节点到x节点也有边
        a[x][y] = 1;
        a[y][x] = 1;
    } 
     
    //从节点1开始访问 
    dfs(1); 
}
