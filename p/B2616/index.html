题目描述

小 A 跑步速度 5 m/s5 \text{ m/s}5 m/s，八尾勇跑步速度 8 m/s8 \text{ m/s}8 m/s，八尾勇在小 A 后面 100 m100 \text{ m}100 m，他们同时起跑，请问需要多长时间八尾勇可以追上小 A？输出一个数字表示答案，使用 cout 直接输出。

输出格式

请输出一个数字表示答案，使用 cout 直接输出。

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 八尾勇速度8 m/s，小A速度5 m/s，速度差 = 3 m/s
    // 距离差 = 100 m，追上时间 = 距离差 / 速度差 = 100 / 3
    cout << 100.0 / 3 << endl;
    return 0;
}
