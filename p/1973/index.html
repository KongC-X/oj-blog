1973 - 回文字母

题目描述

请问在 262626 个大写字母中，有哪些字母的ascii码是回文数。

回文数指的是这个数字正过来和反过来读，是一样的，比如：字母 'BBB' 的ascii码是 666666 ，就是一个回文数。

输入

无

输出

按照ascii码从小到大，输出满足条件的字母，每行一个。

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

/*
思路：循环所有的大写字母
大写字母的ascii在65~90之间 
一定是2位数，因此只要判断这个两位数是否是回文 
*/ 

int main(){
    //循环所有的大写字母 
    for(char i = 'A';i <= 'Z';i++){
        //如果这个字母的ascii码是回文 
        if(i/10==i%10){
            cout<<i<<endl;
        }
    }
    return 0;
}
