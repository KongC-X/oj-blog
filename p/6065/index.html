6065 - 水上表演

题目描述

同学们想看游乐园的水上表演。观众席座位分成 $k$ 排，每排有 $m$ 个座位。同学人数为 $n$,为了好安排座位，老师希望将 $n$ 名同学分成不超过 $k$ 组,每组人数相同且不超过 $m$ 人。请写一个程序，帮助老师判断能不能达成满足条件的分组，能则输出 yes，否则输出 no。

本题有多组数据

输入

第一行: 一个正整数 $T$，代表有 $T$组数据。

第 $2 \sim T+1$ 行:每行三个用空格隔开的正整数 $n$、$k$、$m$，表示同学人数、座位排数与每排座位数。

输出

$T$ 行，每行一个字符串 yes 或 no。

AC代码

#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int T;                       // T: 数据组数
    cin >> T;

    while (T--) {
        int n, k, m;             // n: 同学人数, k: 排数, m: 每排座位数
        cin >> n >> k >> m;

        // 思路：需要将 n 分成不超过 k 组，每组人数相同且不超过 m。
        // 设每组人数为 x，则组数为 n / x。
        // 条件：n % x == 0（整除），n / x <= k（组数不超过排数），x <= m（每组人数不超过座位数）。
        // 枚举 x 从 1 到 min(n, m)，检查条件即可。
        // 由于 n,m ≤ 10000，枚举完全可行。

        bool ok = false;
        int lim = n < m ? n : m;   // x 的上限
        for (int x = 1; x <= lim; x++) {
            if (n % x == 0 && n / x <= k) {
                ok = true;
                break;
            }
        }

        if (ok) cout << "yes\n";
        else    cout << "no\n";
    }

    return 0;
}
