1438 - 骑士巡游

题目描述

马在中国象棋以日字形规则移动，给定 n×mn \times mn×m 大小的棋盘，以及马的初始位置 (x,y)(x,y)(x,y) 和目标位置 (s,t)(s,t)(s,t)，要求不能重复经过棋盘上的同一个点，计算马至少走多少步可以到达目标位置，所有棋盘保证从初始位置到结束位置一定有路径可达。

输入

测试数据包含一行，为六个整数，分别为棋盘的大小以及初始位置坐标 n,m,x,y,s,tn,m,x,y,s,tn,m,x,y,s,t 。（ 1≤x,s≤n≤51 \le x,s \le n \le 51≤x,s≤n≤5，1≤y,t≤m≤51 \le y,t \le m \le 51≤y,t≤m≤5）

输出

包含一行，为一个整数，表示马能到达目标位置的最小步数。

解题思路

AC代码

AC代码

#include <iostream>
#include <iomanip>
#include <bits/stdc++.h>
using namespace std;

int n,m;
int s1,s2,e1,e2;
int d[50][50]; // 初值为0

int fx[9] = {0,2,2,1,1,-1,-1,-2,-2};
int fy[9] = {0,1,-1,2,-2,2,-2,1,-1};

// 深度优先搜索
void dfs(int x,int y,int dep) {
    d[x][y] = dep;
    int tx,ty;
    for(int i = 1;i <= 8;i++) {
        tx = x + fx[i];
        ty = y + fy[i];
        if(tx >= 1 && tx <= n && ty >= 1 && ty <= m && dep + 1 < d[tx][ty]) {
            dfs(tx,ty,dep+1);
        }
    }
}

int main(){
    cin >> n >> m >> s1 >> s2 >> e1 >> e2;
    for(int i=1;i<=n;i++){
        for(int j=1;j<=m;j++){
            // 将最小步数初始值设为INT_MAX
            d[i][j] = INT_MAX;
        }
    }
    dfs(s1,s2,0);
    cout << d[e1][e2] << endl;
}
