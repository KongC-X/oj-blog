1178 - COUNT

题目描述

一本书的页数为 $N$ ，页码从 $1$ 开始编起，请你求出全部页码中，用了多少个 $0，1，2 \dots 9$ 。

输入

一个正整数 $N$ （ $N \le 10000$ ），表示总的页码。

输出

共十行：第 $k$ 行为数字 $k-1$ 的个数。

AC代码

AC代码

#include <iostream>
using namespace std;

int main(){
    int n,a[10] = {0},i,x;
    cin >> n;
    for(i = 1;i <= n;i++) {
        x = i;
        while(x != 0) {
            a[x % 10]++;
            x /= 10;
        }
    }
    for(i = 0;i <= 9;i++) cout << a[i] << endl;
}
