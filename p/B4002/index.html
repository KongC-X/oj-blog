B4002 [GESP202406 二级] 平方之和

洛谷 | 入门 | C++14 | 提交时间: 2024-12-06

算法标签：2024、循环结构、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1150

题目描述

小杨有 nnn 个正整数 a1,a2,…,ana_1,a_2,\dots,a_na1​,a2​,…,an​，他想知道对于所有的 i(1≤i≤n)i (1\le i\le n)i(1≤i≤n)，是否存在两个正整数 xxx 和 yyy 满足 x×x+y×y=aix\times x+y \times y=a_ix×x+y×y=ai​。

输入格式

第一行包含一个正整数 nnn，代表正整数数量。
之后 nnn 行，每行包含一个正整数，代表 aia_iai​。

输出格式

对于每个正整数 aia_iai​，如果存在两个正整数 xxx 和 yyy 满足 x×x+y×y=aix\times x+y \times y=a_ix×x+y×y=ai​，输出 Yes，否则输出 No。

样例

样例输入 #1

2
5
4```

**样例输出 #1**

Yes
No```

AC 代码

#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int main() {
    int n,i,j,a,k;
    bool flag = false;
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> a;
        flag = false;
        for(j = 1;j * j < a;j++) {
            for(k = 1;k * k < a;k++) {
                if(j * j + k * k == a) {
                    flag = true;
                }
            }
        }
        if(flag) {
            cout << "Yes" << endl;
        } else {
            cout << "No" << endl;
        }
    }
}
