P1460 [USACO2.1] 健康的荷斯坦奶牛 Healthy Holsteins

洛谷 | 普及- | C++14 | 提交时间: 2026-08-07

算法标签：搜索、USACO、广度优先搜索 BFS、深度优先搜索 DFS

题目描述

Farmer John prides himself on having the healthiest dairy cows in the world. He knows the vitamin content for one scoop of each feed type and the minimum daily vitamin requirement for his cows. Help Farmer John feed the cows so they stay healthy while minimizing the number of scoops that a cow is fed.

Given the daily requirements of each kind of vitamin that a cow needs, identify the smallest combination of scoops of feed a cow can be fed in order to meet at least the minimum vitamin requirements.

Vitamins are measured in integer units. Cows can be fed at most one scoop of any feed type. It is guaranteed that a solution exists for all contest input data.

输入格式

  • Line 1: Integer VVV (1≤V≤251 \le V \le 251≤V≤25), the number of types of vitamins.
  • Line 2: VVV integers (1≤1 \le1≤ each one ≤1000\le 1000≤1000), the minimum requirement for each of the VVV vitamins that a cow requires each day.
  • Line 3: Integer GGG (1≤G≤151 \le G \le 151≤G≤15), the number of types of feeds available.
  • Lines 4..G+3G+3G+3: VVV integers (0≤0 \le0≤ each one ≤1000\le 1000≤1000), the amount of each vitamin that one scoop of this feed contains. The first line of these GGG lines describes feed 111; the second line describes feed 222; and so on.

输出格式

The output is a single line that contains:

  • the minimum number of scoops a cow must eat, followed by
  • a sorted list from smallest to largest of the feed types the cow is given

If more than one set of feed types yields a minimum number of scoops, choose the set with the smallest feed type numbers.

样例

样例输入 #1

4
100 200 300 400
3
50  50  50  50
200 300 200 300
900 150 389 399```

**样例输出 #1**

2 1 3


## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int v, g;                     // v: 维他命种类, g: 饲料种数
int need[25];                 // 每种维他命需求量
int feed[15][25];             // feed[i][j]：第i种饲料含维他命j的量
int bestCnt = 100;            // 最优种数
int best[15], tmp[15];        // best存放最优编号，tmp存放当前方案

// dfs(idx, cnt, sum[]) 当前考虑到第idx种饲料，已选cnt种，当前维他命总量sum[]
void dfs(int idx, int cnt, int sum[]) {
    // 检查当前是否已经满足需求
    bool ok = true;
    for (int i = 0; i < v; i++) {
        if (sum[i] < need[i]) { ok = false; break; }
    }
    if (ok) {
        if (cnt < bestCnt) {           // 种数更少，更新
            bestCnt = cnt;
            for (int i = 0; i < cnt; i++) best[i] = tmp[i];
        }
        // 因为按编号从小到大搜索，同种数下第一个就是字典序最小，所以不用再更新
        return;
    }
    if (idx >= g) return;              // 所有饲料都考虑完了
    if (cnt >= bestCnt) return;        // 种数已经不比最优少，再选只会更多，剪枝

    // 不选第idx种饲料
    dfs(idx + 1, cnt, sum);

    // 选第idx种饲料
    tmp[cnt] = idx + 1;                // 编号从1开始
    int newSum[25];
    for (int i = 0; i < v; i++) newSum[i] = sum[i] + feed[idx][i];
    dfs(idx + 1, cnt + 1, newSum);
}

int main() {
    cin >> v;
    for (int i = 0; i < v; i++) cin >> need[i];
    cin >> g;
    for (int i = 0; i < g; i++)
        for (int j = 0; j < v; j++)
            cin >> feed[i][j];

    int init[25] = {0};        // 初始维他命总量全0
    dfs(0, 0, init);

    // 输出最优方案
    cout << bestCnt;
    for (int i = 0; i < bestCnt; i++) cout << ' ' << best[i];
    cout << endl;
    return 0;
}
