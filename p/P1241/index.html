P1241 括号序列

洛谷 | 普及- | C++14 | 提交时间: 2026-05-15

算法标签：O2优化、栈

题目描述

定义如下规则：

  1. 空串是「平衡括号序列」
  2. 若字符串 $S$ 是「平衡括号序列」，那么 $\texttt{[}S\texttt]$ 和 $\texttt{(}S\texttt)$ 也都是「平衡括号序列」
  3. 若字符串 $A$ 和 $B$ 都是「平衡括号序列」，那么 $AB$（两字符串拼接起来）也是「平衡括号序列」。

例如，下面的字符串都是平衡括号序列：

  • ()，[]，(())，([])，()[]，()[()]

而以下几个则不是：

  • (，[，]，)(，())，([()

现在，给定一个仅由 (，)，[，]构成的字符串 $s$，请你按照如下的方式给字符串中每个字符配对：

  1. 从左到右扫描整个字符串。
  2. 对于当前的字符，如果它是一个右括号，考察它与它左侧离它最近的未匹配的的左括号。如果该括号与之对应（即小括号匹配小括号，中括号匹配中括号），则将二者配对。如果左侧未匹配的左括号不存在或与之不对应，则其配对失败。

配对结束后，对于 $s$ 中全部未配对的括号，请你在其旁边添加一个字符，使得该括号和新加的括号匹配。

输入格式

输入只有一行一个字符串，表示 $s$。

输出格式

输出一行一个字符串表示你的答案。

样例

样例输入 #1

([()

样例输出 #1

()[]()

样例输入 #2

([)```

**样例输出 #2**

()```

AC 代码

#include <bits/stdc++.h>
using namespace std;

/*
【题目思路与解题过程】
题意：给定一个括号串，按规则匹配后，对未匹配的括号进行补全，
      输出补全后的合法括号序列。

匹配规则：
- 从左到右扫描，遇到右括号时，找左边最近的未匹配左括号。
- 若该左括号与右括号类型匹配，则配对；否则配对失败。
- 扫描结束后，剩下的括号都是未匹配的。

补全规则（根据样例反推）：
- 未匹配的左括号：在它右边补上对应的右括号。
- 未匹配的右括号：在它左边补上对应的左括号。
- 已匹配的括号原样输出。

实现步骤：
1. 用栈 stk 存储左括号的下标。
2. 用数组 match[i] 记录每个位置匹配的括号下标（-1 表示未匹配）。
3. 扫描字符串 s：
   - 左括号：下标入栈。
   - 右括号：如果栈非空且栈顶左括号与当前右括号类型相同，则配对成功，
     记录 match 信息并弹栈；否则该右括号未匹配，忽略。
4. 扫描结束后，栈中剩余下标均为未匹配的左括号。
5. 遍历原串，按字符和 match 信息构造答案：
   - 已匹配：直接输出该字符。
   - 未匹配左括号 '(' 输出 "()"，'[' 输出 "[]"。
   - 未匹配右括号 ')' 输出 "()"，']' 输出 "[]"。
*/

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string s;                     // s: 输入的括号序列
    cin >> s;

    int n = s.size();
    stack<int> stk;               // stk: 存左括号的下标
    vector<int> match(n, -1);     // match[i]: i 位置匹配的括号下标，-1 表示未匹配

    for (int i = 0; i < n; ++i) {
        char c = s[i];
        if (c == '(' || c == '[') {
            stk.push(i);          // 左括号入栈
        } else {                  // 右括号 ) 或 ]
            if (!stk.empty()) {
                int j = stk.top(); // j: 左侧最近的未匹配左括号下标
                // 检查类型是否匹配
                if ((s[j] == '(' && c == ')') || (s[j] == '[' && c == ']')) {
                    match[j] = i; // 记录配对
                    match[i] = j;
                    stk.pop();    // 匹配成功，移除该左括号
                }
                // 不匹配则什么也不做，该右括号保持未匹配
            }
            // 栈空则该右括号未匹配，忽略
        }
    }

    string ans;                   // ans: 补全后的结果字符串
    for (int i = 0; i < n; ++i) {
        if (match[i] != -1) {     // 已配对，直接输出原字符
            ans.push_back(s[i]);
        } else {                  // 未配对，补全一对
            if (s[i] == '(') {
                ans += "()";      // 左小括号补右小括号
            } else if (s[i] == '[') {
                ans += "[]";      // 左中括号补右中括号
            } else if (s[i] == ')') {
                ans += "()";      // 右小括号补左小括号（整体为一对）
            } else if (s[i] == ']') {
                ans += "[]";      // 右中括号补左中括号
            }
        }
    }

    cout << ans << '\n';

    return 0;
}
