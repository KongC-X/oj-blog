1120 - 倒置输出字符串

题目描述

随机输入一个长度不超过 255255255 的字符串，将其倒置后输出。

输入

只有一行。（测试数据不含空格）

输出

只有一行，输出倒置后的字符串。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main()
{
    char a[260];
    cin >> a ;
    int k = strlen(a);
    for(int i = k - 1; i >= 0; i--)
    {
        cout << a[i];
    }
    return 0;
}
