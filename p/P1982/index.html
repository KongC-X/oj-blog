P1982 [NOIP 2013 普及组] 小朋友的数字

洛谷 | 普及+/提高-| C++14 | 提交时间: 2026-11-03

算法标签：动态规划 DP、高精度、递推、2013、NOIP 普及组

题目背景

NOIP2013 普及组 T3

题目描述

有 nnn 个小朋友排成一列。每个小朋友手上都有一个数，这个数可正可负。规定每个小朋友的特征值等于排在他前面（包括他本人）的小朋友中连续若干个（最少有一个）小朋友手上的数之和的最大值。

作为这些小朋友的老师，你需要给每个小朋友一个分数，分数是这样规定的：第一个小朋友的分数是他的特征值，其它小朋友的分数为排在他前面的所有小朋友中（不包括他本人），小朋友分数加上其特征值的最大值。

请计算所有小朋友分数的最大值，输出时保持最大值的符号，将其绝对值对 ppp 取模后输出。

输入格式

第一行包含两个正整数 n,pn,pn,p，之间用一个空格隔开。

第二行包含 nnn 个数，每两个整数之间用一个空格隔开，表示每个小朋友手上的数。

输出格式

一个整数，表示最大分数对 ppp 取模的结果。

样例

样例输入 #1

5 997
1 2 3 4 5

样例输出 #1

21

样例输入 #2

5 7
-1 -1 -1 -1 -1

样例输出 #2

-1

AC 代码

#include <bits/stdc++.h>
using namespace std;
typedef long long LL;

const int N = 1000005;           // n 最大 1e6，多开几个
LL n, p;                         // n: 小朋友人数, p: 取模数
LL a[N];                         // a[i]: 第 i 个小朋友手上的数
LL f[N];                         // f[i]: 第 i 个小朋友的特征值（前 i 个数的最大子段和，不取模）

int main() {
    /*
      思路：
      1. 特征值定义：第 i 个小朋友的特征值 = 前 i 个数中连续若干个数之和的最大值，
         也就是前 i 个数的“最大子段和”。用 Kadane 算法 O(n) 求出：
           cur = max(cur + a[i], a[i])   // 以 i 结尾的最大子段和
           mx  = max(mx, cur)            // 前 i 个数的最大子段和
           f[i] = mx
         注意：f[i] 必须保留完整值，不能提前取模，否则大小关系会被破坏。

      2. 分数定义：
           第 1 个小朋友：score[1] = f[1]
           第 i 个小朋友：score[i] = max_{j < i} (score[j] + f[j])
         用变量 best 维护 max_{j <= i-1}(score[j] + f[j])，
         每算完 score[i] 后把 score[i] + f[i] 纳入 best 即可。

      3. 最大分数可能达到约 1e21，超过 long long，需用 __int128 存储。
         输出时保持符号，将绝对值对 p 取模。

      时间复杂度 O(n)，空间复杂度 O(n)。
    */

    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> p;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    // ---------- 第一步：计算每个人的特征值 f[i] ----------
    LL cur = 0;                  // 以当前位置结尾的最大子段和
    LL mx = LLONG_MIN;           // 前 i 个数的最大子段和（特征值）
    for (int i = 1; i <= n; i++) {
        cur = max(cur + a[i], a[i]);     // 要么接上前面，要么从自己重新开始
        mx = max(mx, cur);               // 更新前 i 个数的最大子段和
        f[i] = mx;                       // 特征值，完整保留不取模
    }

    // ---------- 第二步：按定义计算分数 ----------
    // score[1] = f[1]
    // score[i] = max_{j < i} (score[j] + f[j])，i >= 2
    __int128 s = f[1];                       // 当前 score[i]（初始为 score[1]）
    __int128 best = (__int128)f[1] + s;      // j = 1 的候选：score[1] + f[1]
    __int128 ans = s;                        // 记录所有分数中的最大值

    for (int i = 2; i <= n; i++) {
        s = best;                            // score[i]
        if (s > ans) ans = s;                // 更新最大分数
        __int128 t = (__int128)f[i] + s;     // 把 j = i 的候选加入 best
        if (t > best) best = t;
    }

    // ---------- 第三步：保持符号，绝对值对 p 取模后输出 ----------
    if (ans >= 0) {
        cout << (LL)(ans % p) << endl;
    } else {
        cout << -(LL)((-ans) % p) << endl;
    }

    return 0;
}
