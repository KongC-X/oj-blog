B4210 [常州市赛 2022] 最早对决

洛谷 | 普及- | C++14 | 提交时间: 2026-07-22

算法标签：2022、江苏、分支结构、分类讨论、科创活动、小学活动

题目背景

搬运自 http://czoj.com.cn/p/451。数据为民间数据。

题目描述

小 X\text{X}X 和小 Y\text{Y}Y 凭借出色的程序设计能力，顺利入选了“我们爱科学”活动，该活动以科学精神、创新意识、实践能力的培养为目标，激发广大中小学生爱科学、学科学、用科学的兴趣。

报到之后小 X\text{X}X 和小 Y\text{Y}Y 有幸被分进了人工智能（简称 AI）班，经过一周紧张刺激的AI学习， 每位同学都编写了一个 AI 程序“黑白棋”，经过对弈平台的双循环赛，一共选出了 323232 位种 子选手，编号分别为 1∼321 \sim 321∼32，其余选手均为非种子选手，编号为 33∼12833 \sim 12833∼128。 最后的决战拉开帷幕，比赛采用淘汰赛制，共有 128128128 位选手参加这场淘汰赛，两两对决， 胜者进入下一轮，而输的将被直接淘汰出局。通过抽签产生这 128128128 位选手的对阵表，抽签规则如下：

首先将种子选手的编号从小到大排序，111 号种子安排在 111 号位置，222 号种子安排在 128128128号位置。接着将整个赛区分为上半赛区和下半赛区，即上半赛区是 1∼641 \sim 641∼64 号位置，下半赛区是 65∼12865 \sim 12865∼128 号位置，将上半赛区的最后一个位置和下半赛区的第一个位置选出来（646464 号和 656565 号），然后将接下来的 222 位种子选手（333 号和 444 号）通过随机抽签的方式安排在这 222 个位置中，也就是说 333 号种子既可能抽到 646464 号位置，也可能抽到 656565 号位置，333 号种子的位置通过抽签定下来之后，444 号种子就自动被安排到另一个位置；接下去对于每个赛区再继续分上半赛区和下半赛区，这样就形成了1∼32,33∼64,65∼96,97∼1281 \sim 32,33 \sim 64,65 \sim 96,97 \sim 1281∼32,33∼64,65∼96,97∼128 四个赛区，将所有上半赛区的最后一个位置 和下半赛区的第一个位置选出来（323232 号,333333 号,969696 号,979797 号）。然后将接下来的 444 位种子选手（555 号,666 号,777 号,888 号）通过随机抽签的方式安排到这 444 个位置中，然后继续划分赛区，直到所有种子选手被安排完毕，剩下的 969696 个非种子选手通过随机抽签安排到余下空位中。

小 X\text{X}X 和小 Y\text{Y}Y 的 AI 十分强大，两人的 AI 可以打败除了他们以外的所有对手，但是他们发现， 假如小 X\text{X}X 的编号是 111 号，小 Y\text{Y}Y 的编号是 222 号，他们将作为头两号种子坐在 111 号位置和 128128128 号位置， 两人将所向披靡一路击败所有的对手，直到决赛（第 777 轮）才会相遇。

现在给出小 X\text{X}X 和小 Y\text{Y}Y 的编号，他们想知道最早会在哪一轮相遇？

输入格式

输入数据仅有一行包含两个用空格隔开的正整数 SSS 和 TTT，表示小 X\text{X}X 和小 Y\text{Y}Y 的编号。

输出格式

输出数据仅有一行包含一个正整数，表示他们最早相遇的轮数。

  • 第 111 轮：128128128 进 646464；
  • 第 222 轮：646464 进 323232；
  • 第 333 轮：323232 进 161616；
  • 第 444 轮：161616 进 888；
  • 第 555 轮：888 进 444；
  • 第 666 轮：半决赛；
  • 第 777 轮：决赛。

样例

样例输入 #1

1 3```

**样例输出 #1**

6```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 种子选手(编号1~32)按规则分布在淘汰赛表的特定位置，
    // 编号越小的种子越靠两边（1号在1位，2号在128位），
    // 编号越大的种子越向中间集中。
    // 因此，两人中编号较大的那个决定了他们最早可能在哪个阶段相遇：
    //   - 如果较大编号 > 32（非种子），第1轮就可能相遇；
    //   - 如果较大编号 > 16，最早在第3轮（32进16）相遇；
    //   - 如果较大编号 > 8，最早在第4轮（16进8）相遇；
    //   - 如果较大编号 > 4，最早在第5轮（8进4）相遇；
    //   - 如果较大编号 > 2，最早在第6轮（半决赛）相遇；
    //   - 否则，两人是1号和2号种子，最早在决赛（第7轮）相遇。

    int s, t;                     // 两人编号
    cin >> s >> t;

    // 确保 t 是较大的编号
    if (s > t) swap(s, t);

    if (t > 32) {                 // 至少有一人不是种子
        cout << 1 << endl;
    } else if (t > 16) {          // 较大编号在17~32之间
        cout << 3 << endl;
    } else if (t > 8) {           // 9~16
        cout << 4 << endl;
    } else if (t > 4) {           // 5~8
        cout << 5 << endl;
    } else if (t > 2) {           // 3~4
        cout << 6 << endl;
    } else {                      // 1~2
        cout << 7 << endl;
    }

    return 0;
}
