1067 - 字符图形3-平行四边形

题目描述

输入一个整数打印字符图形。

输入

一个整数（0<n<100 \lt n \lt 100<n<10）。

输出

一个字符图形。

AC代码

# include <iostream>
using namespace std;

int main() {
    int i,j,n;
    cin >> n;
    for(i = 0;i < n;i++) {
        for(j = 0;j < i;j++) {
            cout << " ";
        } 
        for(j = 0;j < n; j++) {
            cout << "*";
        }
        cout << endl;
    }
}
