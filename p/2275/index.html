2275 - 最大子矩阵

题目描述

已知矩阵的大小定义为矩阵中所有元素的和。给定一个矩阵，你的任务是找到最大的非空（大小至少是 1×11 \times 11×1 ）子矩阵。

比如，如下 4×44 \times 44×4 子矩阵。

`0 -2 -7 0
9 2 -6 2
-4 1 -4 1
-1 8 0 -2
`

的最大子矩阵是：

`9 2
-4 1
-1 8
`

这个子矩阵的大小是151515。

输入

输入是一个N×NN \times NN×N的矩阵。

输入的第一行给出。

再后面的若干行中，依次（首先从左到右给出第一行的 NNN 个整数，再从左到右给出第二行的 NNN 个整数 …\dots…）

给出矩阵中的 N2N^2N2 个整数，整数之间由空白字符分隔（空格或者空行）。

已知矩阵中整数的范围都在[−127,127][-127, 127][−127,127]。

输出

输出最大子矩阵的大小。

AC代码

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 105;
int a[MAXN][MAXN];               // 存储矩阵，1-based
int b[MAXN];                     // 压缩后的一维数组，b[j] = 第j列在当前上下行之间的和

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            cin >> a[i][j];
        }
    }

    // ---------- 思路 ----------
    // 问题：最大子矩阵和，经典问题，O(N^3)解法。
    // 枚举子矩阵的上下边界 i（起始行）和 k（结束行），
    // 将这之间的每一列求和，压缩成一个一维数组 b[1..n]。
    // 然后对 b 求最大子段和（Kadane算法），即为在当前上下边界下的最大子矩阵和。
    // 所有上下边界组合的结果取最大值即可。

    int ans = -1e9;              // 最大子矩阵和，初始为极小值

    for (int i = 1; i <= n; i++) {          // i: 子矩阵上边界
        memset(b, 0, sizeof(b));            // 重置列和
        for (int k = i; k <= n; k++) {      // k: 子矩阵下边界
            // 将第 k 行累加到 b 中
            for (int j = 1; j <= n; j++) {
                b[j] += a[k][j];
            }

            // Kadane算法求 b 的最大子段和
            int cur = 0;                    // cur: 以当前j结尾的最大子段和
            int maxb = b[1];                // b数组的最大子段和，初始取b[1]
            for (int j = 1; j <= n; j++) {
                if (cur > 0) cur += b[j];
                else         cur = b[j];
                if (cur > maxb) maxb = cur;
            }
            if (maxb > ans) ans = maxb;
        }
    }

    cout << ans << '\n';
    return 0;
}
