1131 - 删除指定字符

题目描述

从键盘输入一个字符串 strstrstr 和一个字符 ccc ，删除 strstrstr 中的所有字符 ccc 并输出删除后的字符串 strstrstr 。

输入

第一行是一个字符串，字符串不含空格，长度 ≤100\le 100≤100 ；

第二行是一个字符。

输出

删除指定字符后的字符串。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int main(){
    char a[1000],c,b[1000];
    cin>>a>>c;
    int k=0;
    for(int i=0;a[i];i++){
        if(a[i]!=c){
            b[k]=a[i];
            k++;
        }
    }
    b[k]='\0';
    cout<<b;
}
