P10098 [ROIR 2023] 地铁建设 (Day 2)

洛谷 | 普及- | C++14 | 提交时间: 2026-08-04

算法标签：数学、二分、2023、Special Judge、枚举、ROIR（俄罗斯）

题目背景

翻译自 ROIR 2023 D2T1。

用于铺设地铁隧道的盾构机有 nnn 个发动机。所有发动机是并联的，所以所有发动机两端的电压都相同。

每个发动机有两种模式，假设所有发动机接收到的电压都为 xxx，则当 x≤zix\le z_ix≤zi​ 时第 iii 个发动机在第一模式下工作，否则它在第二模式下工作。

第 iii 个发动机在第一模式下的单位电流为 aia_iai​，在第二模式下的单位电流为 bib_ibi​。所以，根据 P=UIP=UIP=UI，当发动机处于第一模式时，每增加 111 单位电压，其功率增加 aia_iai​ 单位；当发动机处于第二模式时，每增加 111 单位电压，其功率增加 bib_ibi​ 单位。换句话说，当电压为 xxx 单位电压，如果第 iii 个发动机处于第一模式下，它以 ai×xa_i\times xai​×x 的单位功率运行；如果处于第二模式下，它以 ai×zi+bi×(x−zi)a_i\times z_i + b_i\times(x - z_i)ai​×zi​+bi​×(x−zi​) 的单位功率运行。

题目描述

最少需要提供多大的电压（电压需要是整数），才能使所有发动机的总功率大于或等于 ppp？

输入格式

第一行输入两个整数 nnn 和 ppp。

接下来的 nnn 行，每行包含三个整数 zi,ai,biz_i,a_i,b_izi​,ai​,bi​。

输出格式

输出一个整数表示最小电压。

样例

样例输入 #1

1 6
4 1 2```

**样例输出 #1**

5```

样例输入 #2

3 15
2 3 3
4 2 1
5 2 2```

**样例输出 #2**

3```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int n;              // n: 发动机个数
long long p;        // p: 目标总功率
long long z[105];   // z[i]: 第 i 个发动机的模式切换电压
long long a[105];   // a[i]: 第 i 个发动机第一模式的单位电流
long long b[105];   // b[i]: 第 i 个发动机第二模式的单位电流

// 检查函数：判断电压为 x 时，总功率是否 >= p
bool check(long long x) {
    long long sum = 0;   // sum: 当前总功率
    for (int i = 1; i <= n; i++) {
        if (x <= z[i]) {
            // 第一模式：功率 = a[i] * x
            sum += a[i] * x;
        } else {
            // 第二模式：功率 = a[i] * z[i] + b[i] * (x - z[i])
            sum += a[i] * z[i] + b[i] * (x - z[i]);
        }
        // 剪枝：如果已经达到目标，提前返回 true，防止溢出
        if (sum >= p) return true;
    }
    return sum >= p;
}

int main() {
    /*
     * 【题目类型】二分答案
     * 【核心思路】
     * 1. 总功率 P(x) 随电压 x 单调不递减，因此可以二分答案。
     * 2. 二分范围：左边界 L = 0（电压为0时功率为0），右边界 R = 2e12（足够大）。
     * 3. 每次取 mid = (L + R) / 2，用 check(mid) 判断 mid 是否可行。
     * 4. 如果可行，说明答案 <= mid，缩小右边界；否则答案 > mid，缩小左边界。
     * 5. 最终 L 为最小可行电压。
     *
     * 【时间复杂度】O(n log V)，V ≈ 2e12
     */

    cin >> n >> p;
    for (int i = 1; i <= n; i++) {
        cin >> z[i] >> a[i] >> b[i];
    }

    // 二分查找最小可行电压
    long long L = 0, R = 2000000000000LL;  // R: 上界 2e12
    while (L + 1 < R) {
        long long mid = (L + R) / 2;
        if (check(mid)) {
            R = mid;   // mid 可行，尝试更小
        } else {
            L = mid;   // mid 不可行，需要更大
        }
    }

    cout << R << endl;   // R 即为最小可行电压
    return 0;
}
