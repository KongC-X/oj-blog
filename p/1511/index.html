1511 - 数字之和为13的整数

题目描述

求出 1∼n1 \sim n1∼n 范围内的整数，使其数字之和为 131313，请问这样的数有多少个？

例如：数 858585 ，其数字之和为 8+5=138+5=138+5=13 ；数 373373373，其数字之和为 3+7+3=133+7+3=133+7+3=13 。

输入

一个整数 nnn（n≤10000000n \le 10000000n≤10000000）；

输出

输出一个整数，代表符合条件数的总个数。

AC代码

AC代码

#include <iostream>
using namespace std;

// 求一个数的各位数字之和
int numSum(int num) {
    int sum = 0;
    while(num != 0) {
        sum += num % 10;
        num = num / 10;
    }
    return sum;
}

int main(){
    int i,n,s,a,sum = 0;
    cin >> n;
    for(i = 1;i <= n; i++) {
        s = 0;
        a = i;
        s = numSum(a);
        if(s == 13) {
            sum++;
        }
    }
    cout << sum << endl;
}
