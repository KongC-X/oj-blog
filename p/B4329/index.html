B4329 [语言月赛 202505] 等分差试题序列

洛谷 | 入门 | C++14 | 提交时间: 2026-08-15

算法标签：2025、循环结构、数组、语言月赛

题目描述

2025 年 5 月语言月赛共有 nnn 道题，第 iii 道题的分值为 aia_iai​。

如果试题 lll 至试题 rrr 中，每两道相邻试题的分值差相同，则称试题 lll 至试题 rrr 构成「等分差试题序列」。特别地，如果 l=rl=rl=r 或 l+1=rl+1=rl+1=r，我们也认为它构成「等分差试题序列」。

例如，当 n=6n=6n=6，a=[1,3,4,5,7,9]a=[1,3,4,5,7,9]a=[1,3,4,5,7,9]：

  • 试题 2∼42\sim42∼4 构成「等分差试题序列」，因为相邻两道试题之间的分值差依次为 4−3=5−4=14-3=5-4=14−3=5−4=1。
  • 试题 111 构成「等分差试题序列」。这符合上述定义的特别情况。
  • 试题 3∼53\sim 53∼5 不构成「等分差试题序列」，因为相邻两道试题之间的分差依次为 5−4=15-4=15−4=1，7−5=27-5=27−5=2。

给出试题的数目和分值，请问最长的「等分差试题序列」包含多少道试题。

输入格式

第一行为一个正整数 nnn。

第二行为 nnn 个正整数 a1,a2,⋯ ,ana_1,a_2,\cdots,a_na1​,a2​,⋯,an​，其中 aia_iai​ 表示第 iii 道试题的分值。

输出格式

输出一行一个整数，表示最长的「等分差试题序列」包含的试题数目。

样例

样例输入 #1

6
1 3 4 5 7 9```

**样例输出 #1**

3```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B4329 [语言月赛 202505] 等分差试题序列
     * 题意：给定序列 a[1..n]，求最长的连续子序列，使得相邻元素差值相等。
     * 等价于：求差值数组 d[i] = a[i+1] - a[i] 的最长连续相等段长度 + 1。
     *
     * 核心思路：
     * 1. 若子序列 a[l..r] 是等分差序列，则 d[l], d[l+1], ..., d[r-1] 全部相等。
     * 2. 所以问题转化为在差值数组 d 中找最长连续相同值的个数 cnt，
     *    答案即为 cnt + 1（因为 cnt 个差值对应 cnt+1 个元素）。
     * 3. 特判：n=1 或 n=2 时，直接输出 n（因为单个或两个元素必然构成等分差序列）。
     *
     * 时间复杂度：O(n)
     */
    int n;
    cin >> n;
    long long a[5005];          // 存储原始分值
    for (int i = 0; i < n; i++) cin >> a[i];

    if (n <= 2) {
        cout << n << endl;
        return 0;
    }

    long long d[5005];          // 差值数组，长度 n-1
    for (int i = 0; i < n - 1; i++) {
        d[i] = a[i + 1] - a[i];
    }

    int ans = 1;                // 至少包含一个元素
    int cnt = 1;                // 当前连续相等差值的个数（从第一个差值开始）
    for (int i = 1; i < n - 1; i++) {
        if (d[i] == d[i - 1]) {
            cnt++;
        } else {
            ans = max(ans, cnt + 1);   // 差值个数 cnt 对应元素数 cnt+1
            cnt = 1;                   // 重置
        }
    }
    ans = max(ans, cnt + 1);           // 处理最后一段

    cout << ans << endl;
    return 0;
}
