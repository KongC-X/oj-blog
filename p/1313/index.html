1313 - 第n盆花是什么颜色？

题目描述

学校操场上摆放了 mmm 组花排成了一排，每组花有 333 盆颜色分别是蓝花、黄花、红花。小芳和同学们开始玩一个游戏，从第一盆花开始数数，当数到 nnn 的时候让同学们来计算他面前的是什么颜色的花。如果数到最后一盆了，就倒过来往前数。

例如：有 333 组花，小芳数到了 888 ，就是倒数第二盆黄花（333 组花有 999 盆）；小芳数到了 999 就是最后一盆红花；小芳数到 101010 ，又回到倒数第二盆黄花。（4.1.30）

输入

两个整数 mmm 和 nnn （mmm 和 nnn 都是 1∼10000001 \sim 10000001∼1000000 之间的整数），mmm 代表总共有多少组花，nnn 代表小芳数到的数字。

输出

花的颜色，输出它们颜色的拼音，如：lan、huang、hong。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
 
int main(){
    int i,m,n,t=0,cnt=0;
    cin>>m>>n;
    bool f=true;//1:+  0:-
    m=3*m;
    //cout<<m<<endl; 
    string a[m+100];//注意数组的大小为3*m+100 
    for(i=1;i<=m;i++){
        if(i%3==1){
            a[i]="lan";
        }else if(i%3==2){
            a[i]="huang";
        }else if(i%3==0){
            a[i]="hong";
        }
    //  cout<<i<<" "<<a[i]<<endl;
         
    }
    //模拟一个计数指针，从头到尾递增，从尾到头递减 
    while(t<n){
        t++;        
        if(f) cnt++;
        else cnt--;
        if(cnt==m){
            f=false;            
        }else if(cnt==1){
            f=true;
        }
        //cout<<cnt<<endl;
    }
     
    cout<<a[cnt];
     
    return 0;
}
