B3662 [语言月赛202209] 山峰

洛谷 | 普及- | C++14 | 提交时间: 2026-08-23

算法标签：2022、Special Judge、数组、语言月赛

题目描述

洛咕公司可以被分为 nnn 行 mmm 列的土地，第 iii 行第 jjj 列的土地初始海拔为 ai,ja_{i,j}ai,j​。行号和列号均从 111 开始编号。

在漫长的岁月中，一共发生了 TTT 次地理变迁。每次地理变迁，两块土地的海拔会发生交换。

如果有一块土地，比上下左右直接相邻的土地海拔都高，我们称其为一个山峰。

Berland 王国的首领想要知道，在所有地理变迁完成后，王国一共有多少山峰，它们的坐标分别为多少。

例如：n=m=3n=m=3n=m=3，海拔高度如下所示

1  2  31  4  21  1  21 \ \ 2 \ \ 3 \\ 1 \ \ 4 \ \ 2\\ 1 \ \ 1 \ \ 21  2  31  4  21  1  2

其中，(1,3),(2,2)(1,3),(2,2)(1,3),(2,2) 是山峰。

输入格式

输入的第一行为两个整数 n,mn,mn,m，分别代表行数与列数。

接下来 nnn 行，每行 mmm 个整数，第 iii 行第 jjj 个整数代表 ai,ja_{i,j}ai,j​。

接下来一行一个整数 TTT。

接下来 TTT 行，每行四个整数 x1,y1,x2,y2x_1,y_1,x_2,y_2x1​,y1​,x2​,y2​，代表 x1x_1x1​ 行 y1y_1y1​ 列的土地与 x2x_2x2​ 行 y2y_2y2​ 列的土地发生了地理变迁。

输出格式

输出的第一行为一个整数，代表地理变迁后山峰的数量 kkk。

接下来 kkk 行，每行两个整数 x,yx,yx,y，代表一座山峰在第 xxx 行第 yyy 列。

你可以以任意顺序输出山峰的坐标。

样例

样例输入 #1

3 3
1 2 3
1 4 2
1 1 2
0```

**样例输出 #1**

2
2 2
1 3```

样例输入 #2

3 3
1 2 3
1 2 2
1 1 4
1
2 2 3 3```

**样例输出 #2**

2
1 3
2 2```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int n, m, T;
long long a[1005][1005];

// 判断 (x,y) 是否为山峰
bool ok(int x, int y) {
    long long h = a[x][y];
    if (x > 1 && a[x-1][y] >= h) return false;
    if (x < n && a[x+1][y] >= h) return false;
    if (y > 1 && a[x][y-1] >= h) return false;
    if (y < m && a[x][y+1] >= h) return false;
    return true;
}

int main() {
    scanf("%d%d", &n, &m);
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            scanf("%lld", &a[i][j]);

    scanf("%d", &T);
    while (T--) {
        int x1, y1, x2, y2;
        scanf("%d%d%d%d", &x1, &y1, &x2, &y2);
        swap(a[x1][y1], a[x2][y2]);
    }

    int ans[1000005][2];   // 最多 n*m 个山峰
    int cnt = 0;
    for (int i = 1; i <= n; i++)
        for (int j = 1; j <= m; j++)
            if (ok(i, j)) {
                ans[cnt][0] = i;
                ans[cnt][1] = j;
                cnt++;
            }

    printf("%d\n", cnt);
    for (int i = 0; i < cnt; i++)
        printf("%d %d\n", ans[i][0], ans[i][1]);

    return 0;
}
