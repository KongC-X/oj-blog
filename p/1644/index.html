1644 - 大数的平方

题目描述

判断两个数 a，ba，ba，b （不相等），输出较大数的平方值。

输入

两个整数 a,ba, ba,b（不大于 327673276732767 ）。

输出

较大数的平方。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;
 
int main(){
    int a,b;
    cin>>a>>b;
    if(a>b){
        cout<<a*a;
    }else{
        cout<<b*b;
    }
}
