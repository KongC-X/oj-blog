1766 - 统计数对个数

题目描述

考虑一组 nnn 个不同的正整数 a1,a2,...,ana_1,a_2,...,a_na1​,a2​,...,an​ ，它们的值在 111 到 100000010000001000000 之间。给定一个整数 xxx。

写一个程序计算这样的数对个数 (ai,aj)(a_i,a_j)(ai​,aj​) ， 并且 ai+aj=xa_i+a_j=xai​+aj​=x 。

输入

标准输入的第一行是一个整数 nnn ( 1≤n≤10000001≤n≤10000001≤n≤1000000 )。

第二行有 nnn 个整数表示元素。

第三行是一个整数 xxx ( 1≤x≤20000001≤x≤20000001≤x≤2000000 )。

输出

输出一行包含一个整数表示这样的数对个数。

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
#include<set>
using namespace std;

int n,x,c,sum;
int a[1000010];
int main(){
    set<int> s;
    cin>>n;
    for(int i=0;i<n;i++){
        cin>>c;
        s.insert(c);
    }
    cin>>x;
    set<int>::iterator it;
    //cout<<s.size()<<endl;
    for(it=s.begin();it!=s.end();it++){
        if(s.find(x - *it)!=s.end() && s.find(x - *it) != it){
            sum++;
            s.erase(s.find(x - *it));
        }
    }
    cout<< sum <<endl; 
    return 0;
}
