B3660 [语言月赛202209] 集卡

洛谷 | 入门 | C++14 | 提交时间: 2026-08-22

算法标签：2022、O2优化、循环结构、语言月赛

题目背景

小 A 最近迷上了集卡。

题目描述

小 A 最近买了 TTT 次卡牌，每次买了 nnn 张（注意，不同次买的卡牌数量不一定相同）。每张卡都有一个数字编号，如果编号是 0 则代表抽到了隐藏款。

小 A 想分别知道每次购买的卡牌中，是否抽到了隐藏款。如果抽到了则输出 yes，否则输出 no。

输入格式

第一行，一个整数 TTT，表示小 A 最近买了 TTT 次卡牌。

接下来包含 2T2T2T 行数据，代表了小 A 这 TTT 次购买卡牌的情况。

对于每次购买卡牌的情况，共包含两行输入。

第一行为一个整数 nnn，表示购买了 nnn 张卡牌。
第二行包含 nnn 个整数，表示本次购买的 nnn 张卡牌的数字编号。

提示： 如果无法理解输入格式，可以先阅读下方的输入输出样例，再结合样例来理解输入格式。

输出格式

共 TTT 行，每行一个 yes 或者 no，表示是否抽到了隐藏款。如果抽到了则输出 yes，否则输出 no。

样例

样例输入 #1

1
5
1 2 3 4 0```

**样例输出 #1**

yes```

样例输入 #2

2
3
1 2 3
4
1 2 0 3```

**样例输出 #2**

no
yes```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3660 [语言月赛202209] 集卡
     * 题意：T 次购买，每次给 n 张卡牌编号，判断是否有编号 0（隐藏款）。
     * 有则输出 yes，否则 no。
     */
    int T, n, x;
    cin >> T;
    while (T--) {
        cin >> n;
        bool flag = false;
        for (int i = 0; i < n; i++) {
            cin >> x;
            if (x == 0) flag = true;
        }
        cout << (flag ? "yes" : "no") << endl;
    }
    return 0;
}
