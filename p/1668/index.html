1668 - 运动会成绩统计

题目描述

学校运动会的跳水比赛已经结束，裁判统计出了选手们的成绩，并根据大家的成绩划分好了金牌、银牌和铜牌的获奖分数线。

裁判规定，总分 100100100 分；获得 92.892.892.8 分及 92.892.892.8 分以上的选手获得金牌；在 92.892.892.8 分以下但在 85.685.685.6 分及85.685.685.6 分以上的选手获得银牌；在 85.685.685.6 分以下，但在82.182.182.1 分及 82.182.182.1 分以上的选手获得铜牌；分数在 82.182.182.1 分以下的选手不获奖。

请从键盘读入一名选手的分数，判断他应该获得哪个奖项？

如获得金牌，请输出 jin ，银牌请输出 yin ，铜牌请输出 tong ，没有获得奖项请输出 sorry 。

输入

某位选手的分数。

输出

如获奖请输出该选手获得的奖项，如不获奖，请输出 sorry 。

AC代码

#include <iostream>
using namespace std;
 
int main(){
    //定义变量x代表成绩 
    double x;
    cin>>x;
    //判断x的范围 
    if(x>=92.8){
        cout<<"jin";
    }else if(x>=85.6){
        cout<<"yin";
    }else if(x>=82.1){
        cout<<"tong";
    }else{
        cout<<"sorry";
    }
}
