1225 - 打印空心等腰三角形

题目描述

从键盘读入一个整数 $n$ ，代表等腰三角形的边长，请输出一个边长为 $n$ 的等腰三角形！

为了方便观察，我们在例子中将空格替换成□，将*替换为×，请在程序中正常输出空格和*！

如：$n=3$ 则输出

`□□×
□×□×
×××××
`

$n=5$ 则输出：

`□□□□×
□□□×□×
□□×□□□×
□×□□□□□×
×××××××××
`

输入

整数 $n（n \le 9）$

输出

按题意输出图形。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

/*
1.先打实心
2.将实心中间的*替换为空格
（1）第1行和最后1行都属于边界上的*
（2）其他行，只有第1个和最后一个是边界上的*，其余的都在内部 
*/
int main(){
    int n;
    cin>>n;
    for(int i = 1;i <= n;i++){
        for(int j = 1;j <= n - i;j++){
            cout<<" ";
        }
        
        for(int j = 1;j <= 2 * i - 1;j++){
            //如果是第1行或者最后一行，都直接输出 
            if(i==1 || i == n){
                cout<<"*";	
            }else{
                //如果是本行第1个或者最后一个，输出*，其余的替换为空格
                if(j == 1 || j == 2 * i - 1){
                    cout<<"*";
                } else{
                    cout<<" ";
                }
            }
        }
        cout<<endl;
    }	
    return 0;
}
