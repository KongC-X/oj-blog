B3877 [信息与未来 2015] 分数计数

洛谷 | 普及- | C++14 | 提交时间: 2026-04-13

算法标签：模拟、2015、江苏、信息与未来

题目描述

有 $n$ 个球队，编号为 $1\sim n$，共进行 $n$ 场比赛，每场比赛有一个胜队。计分方法如下：

  • 是连胜中的第一次胜利，则本次胜利得 $1$ 分。
  • 是连胜中的第二次胜利，则本次胜利得 $2$ 分。
  • 是连胜中的第三次胜利，则本次胜利得 $3$ 分。
  • 连胜超过三次以上的胜场，每场得 $3$ 分。

例如 $n=12$，比赛的胜队为 $1,2,1,1,3,2,1,1,1,1,4,2$，计分如下：

  • 队 $1$：$1+1+2+1+2+3+3=13$ 分；
  • 队 $2$：$1+1+1=3$ 分；
  • 队 $3\sim 4$：$1$ 分。
  • 队 $5\sim 12$：$0$ 分。

求得分最多的队伍的分数。

输入格式

两个整数 $n,x_1$，$n$ 为球队数，$x_1$ 为第一次胜队号，第 $i(i\ge2)$ 场比赛胜队的编号由
以下公式确定：

$x_i = ((x_{i-1}\times 3703+1047) \bmod n)+1$。

输出格式

一个整数，即得分最多队的分数。

样例

样例输入 #1

10 5```

**样例输出 #1**

3```

AC 代码

#include <iostream>
using namespace std;
// a：存储每场比赛的胜队
// cnt：存储每个队伍总得分
long long x[1000010], cnt[1000010];
long long n, c ,ma;

int main(){
    cin >> n >> x[1]; // 第一场胜利的队伍
    for (int i = 2; i <= n; i++){
        x[i] = ((x[i - 1] * 3703 + 1047) % n) + 1;
    }

    for (int i = 1; i <= n; i++){
        if (x[i] == x[i - 1]){     // 若该队伍连胜，那么我们就更新 cnt 来确定应该加的分数
            c = c < 3 ? c + 1 : c; // 判断连胜有没有超过三场
            cnt[x[i]] += c;        // x[i]为胜利队伍名称，所以s[x[i]]也就是该队伍所对应的得分情况了
        }
        else { // 这里是连胜中第一次胜利的情况
            c = 1;
            cnt[x[i]] += c;
        }
        ma = max(ma, cnt[x[i]]); // 这里可以在每次循环后直接把当前的最大得分求出来
    }

    cout << ma;

    return 0;
}
