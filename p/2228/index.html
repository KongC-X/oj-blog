2228 - 出栈顺序

题目描述

大家都知道，栈满足先进后出的特性。一个栈，如果按照 $1,2,3...,n$ 的顺序入栈，出栈顺序可以是：$n...3,2,1$。

考虑到栈可以边进边出，就可能产生多种不同的出栈序列，比如：入栈顺序是 $1,2,3,4,5$，出栈顺序可能是： $3,4,2,1,5$，但不可能是：$3,5,1,4,2$。

请问：如果一个栈，按照 $1,2,3...,n$ 的顺序入栈，允许栈边进边出的情况下，判断出栈顺序是否合法。

输入

第 $1$ 行读入一个整数 $m$，代表有多少组出栈的数据等待检测（$m≤30$）。

接下来读入 $m$ 组数据，每组数据的第 $1$ 行，读入一个整数 $n$，代表本组数据的出栈序列中有 $n$ 个整数（$1≤n≤100$）。

每组数据的第 $2$ 行，读入 $n$ 个整数，数字之间用空格隔开。

输出

对于每组输入，请输出该组出栈序列是否合法，如果合法，请输出Yes，不合法请输出No。请注意，每组数据的输出占 $1$ 行。

AC代码

AC代码

// 按照给定的顺序，模拟入栈出栈的过程。
// 比如给定出栈顺序是：3,4,2,1,5，用vector存储。
// 那么，模拟入栈出栈过程如下：
// 入栈1
// 入栈2
// 入栈3，因为第1个出栈是3，说明3此时立刻出栈了，因此3从栈中弹出，也从vector中删除，删除后栈顶元素是2和4匹配不上
// 入栈4，栈顶元素和当前vector第1个数匹配，说明应该出栈，同时从vector中删除，接下来发现2和1也匹配，因此都删除。
// 入栈5，匹配，删除，此时vector和stack都为空。

#include<bits/stdc++.h>
using namespace std;

stack<int> st;
vector<int> v;
int m,n,x;

int main() {
    cin>>m;//数据量 
    while(m--){
        //清空vector和stack
        v.clear();
        while(!st.empty()) st.pop();
        
        //读入
        cin>>n;
        for(int i = 1;i <= n;i++){
            cin>>x;
            v.push_back(x);//出栈顺序 
        } 
        
        //匹配当前出栈顺序
        for(int i = 1;i <= n;i++){
            st.push(i);
            
            //尝试匹配st的栈顶元素和v的第1个元素
            while(!st.empty()&&!v.empty()&&st.top()==v.front()){
                //删除
                st.pop();//栈弹出栈顶元素
                v.erase(v.begin()); 
            } 
        }
        
        //模拟结束后，栈和vector应该都是空的
        if(st.empty() && v.empty()) cout<<"Yes"<<endl;
        else cout<<"No"<<endl; 
    }
    return 0;
}
