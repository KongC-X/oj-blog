2351 - 神奇的二维码

题目描述

【具体要求】
二维码是现在日常生活中最常用到的一种编码，比如名片、传单、产品包装上都会用到二维码。

不知道同学们有没有发现一个有趣的现象，二维码是不规律的，但是我们不管从哪个角度去扫码，都能正确识别。主要是因为二维码有三个定位点，手机通过这三个点位置来确定二维码编码的区域和角度。

如下图所示：

现要求输入一个由 000 和 111 组成的正方形二维码矩阵（且左上角、右上角、左下角三个定位点必须为“ 111 ”），将二维码顺时针旋转 909090 度后输出。

输入

输入共 n+1n+1n+1 行，第一行输入一个正整数 （ 4≤n≤324 \le n \le 324≤n≤32 )，表示该二维码矩阵大小为 n×nn \times nn×n ;

第 2∼n+12 \sim n+12∼n+1 行，每行 nnn 个由 000 或 111 组成，数字之间用空格隔开，代表二维码矩阵（且左上角、右上角、左下角三个定位点必须为“ 111 ”）。

输出

输出 nnn 行，每行 nnn 个正整数，输出矩阵为顺时针旋转 909090 度后的矩阵二维码。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;
int a[42][42]; 
int main(){
    int n;
    cin>>n;
    
    for(int i=1; i<=n; i++){
        for(int j=1; j<=n; j++){
            cin>>a[i][j];
        }
    }
    
    for(int i=1; i<=n; i++){
        for(int j=n; j>=1; j--){
            cout<<a[j][i]<<" ";
            //cout<<j<<","<<i<<" ";
        }
        cout<<endl;
    }
    
    return 0;
}
