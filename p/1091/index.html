1091 - 奇数及偶数和

题目描述

给出一个正整数 n（1≤n≤1000n（1≤n≤1000n（1≤n≤1000 ），求出 1，2，…n1，2，\dots n1，2，…n 中全部奇数和以及全部偶数的和。
例如：n=9n=9n=9 ；

奇数和 1+3+5+7+9=251+3+5+7+9=251+3+5+7+9=25 ；

偶数和 2+4+6+8=202+4+6+8=202+4+6+8=20 。

输入

一个整数 nnn 。

输出

一行，奇数和与偶数和，中间一个" "（空格）。

AC代码

# include <iostream>
using namespace std;

int main(){
    int i,n,s1 = 0,s2 = 0;
    cin >> n;
    for(i = 1;i <= n;i++) {
        if(i % 2 == 0) {
            s1 += i;
        } else {
            s2 += i;
        }
    }
    cout << s2 << " " << s1 << endl;
}
