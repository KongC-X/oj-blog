1355 - 门票的定价

题目描述

某剧院举办文艺演出，经过调研发现，如果票价定为每张 303030 元，那么 120012001200 张门票可以全部售出；如果票价每增加 111 元，那么售出的门票就减少 nnn 张（ n≤100n \le 100n≤100 ）。现要求门票价格在不低于 303030 元的情况下，请问门票价格定为多少钱，可以使得总门票收入最高，最高总门票收入是多少元？（如果在多个价格下，门票总收入一样高，就取价格较低的门票单价）（ 9.19.19.1 ）

输入

一个整数 nnn

输出

两个整数，用空格隔开，代表门票最终的定价以及总门票收入

解题思路

AC代码

AC代码

#include<iostream>
#include<cmath>
using namespace std;

int main() {
    int i,max = 0,x,n,s;
    cin >> n;
    for(i = 0;i <= 1200/n;i++) {
        s = (30 + i) * (1200 - n * i);
        if(s > max) {
            max = s;
            x = 30 + i;
        }
    }
    cout << x << ' ' << max << endl;
}
