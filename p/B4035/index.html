B4035 [GESP202409 一级] 美丽数字

洛谷 | 入门 | C++14 | 提交时间: 2025-03-28

算法标签：数学、2024、分支结构、循环结构、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1157

题目描述

小杨有 nnn 个正整数，他认为一个正整数是美丽数字当且仅当该正整数是 999 的倍数但不是 888 的倍数。

小杨想请你编写一个程序计算 nnn 个正整数中美丽数字的数量。

输入格式

第一行包含一个整数 nnn，代表正整数个数。
第二行有 nnn 个正整数 a1,a2,…ana_1, a_2, \dots a_na1​,a2​,…an​。

输出格式

输出一个整数，表示其中美丽数字的数量。

样例

样例输入 #1

3
1 9 72```

**样例输出 #1**

1```

AC 代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;
int n,i,s,x;
int main() {
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> x;
        if(x % 9 == 0 && x % 8 != 0) {
            s++;
        }
    }
    cout << s << endl;
}
