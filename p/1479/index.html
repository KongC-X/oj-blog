1479 - 超级字符串

题目描述

fish在无数次oi竞赛的狱炼之后，悟出一个真理，往往越容易的题目，陷阱越深。由此，fish创作了这道题目。

fish 首先给出两个短串 A=4567 ( 444 个字符)， B=123( 333 个字符)。反复进行如下的操作得到一个长串 CCC。
（１）C=B+A（１）C=B+A（１）C=B+A(例如：A=4567 ,B=123 C=B+A=C=B+A=C=B+A= 1234567)

（２）A=B,B=C（２）A=B , B=C（２）A=B,B=C (上述例子 A=123 B=1234567)

请你编程找出这个长串的第 nnn 个字符。

输入

第一行包含一个整数 n。(1≤n≤109)n 。(1 \le n \le 10^9)n。(1≤n≤109)

输出

仅一行，包含一个字符，表示这个长串的第 nnn 个字符。

AC代码

AC代码

#include <iostream>
#include <string>
using namespace std;

string s1 = "1234567";
string s2 = "1234567123";
long long f[50]; // 长度数组

// 在 S[k] 中找第 pos 个字符（pos从1开始）
char find(int k, long long pos) {
    if (k == 1) return s1[pos - 1];
    if (k == 2) return s2[pos - 1];
    if (pos <= f[k - 1]) return find(k - 1, pos);
    else return find(k - 2, pos - f[k - 1]);
}

int main() {
    long long n;
    cin >> n;

    // 预处理长度
    f[1] = 7;
    f[2] = 10;
    int k = 2;
    while (f[k] < n) {
        k++;
        f[k] = f[k - 1] + f[k - 2];
    }

    cout << find(k, n) << endl;
    return 0;
}
