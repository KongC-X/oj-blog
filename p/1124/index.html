1124 - 表达式的值II

题目描述

给出一个表达式，其中运算符仅包含 + 和 - 两种运算符，且没有括号。要求求出表达式的最终值。

数据保证要计算的数字的数量不超过 100100100 个，每个整数的数值和计算结果的数值都在 intintint 的范围内。

请注意：数字可能是 111 位数，也可能是多位数，如：1+1−1=11+1-1=11+1−1=1 ，12+23−11=2412+23-11=2412+23−11=24 。

输入

仅一行，即为表达式。

输出

计算结果的数值。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s,s1,s2;
    char c = '+';
    getline(cin,s);
    int i,k = 0;
    for(i = 0;i < s.size();i++) {
        if(isdigit(s[i])) {
            s1 += s[i];
            if(!isdigit(s[i+1])) {
                if(c == '+') {
                    k += stoi(s1);
                } else if(c == '-'){
                    k -= stoi(s1);
                }
                s1 = "";
            }
        } else {
            c = s[i];
        }
    }
    cout << k << endl;
}
