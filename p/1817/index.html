1817 - 输入的这些数是否对称

题目描述

从键盘输入一个整数 NNN（4≤N≤204 \le N \le 204≤N≤20），接下来输入NNN 个数，判断输入的这些数是否对称,是输出YES，否则输出NO？（注意N可以是奇数或者偶数）。对称的意思是这些数正过来读和反过来读都是一样的。

比如有 444 个数： 111 222 222 111 ，就是对称的，再比如有 555 个数： 111 222 333 222 111 ，也是对称的，但有 555 个数： 111 222 333 111 222 ，就不是对称的。

输入

第 111 行有一个整数 nnn。 （4≤n≤204 \le n \le 204≤n≤20）

第 222 行有 nnn 个整数。

输出

如果是对称的请输出：YES，否则输出：NO。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
using namespace std;

int n,h,a[30];
int main() {
cin>>n;
for(int i=0;i<n;i++)
{
    cin>>a[i];
}
for(int i=0;i<n/2;i++) //不需分奇偶 
{
    if(a[i]==a[n-i-1])
    {
        h++;
    }
}
if(h==n/2) cout<<"YES";
else cout<<"NO";
}
