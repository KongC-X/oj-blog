1817 - 输入的这些数是否对称

题目描述

从键盘输入一个整数 $N$（$4 \le N \le 20$），接下来输入$N$ 个数，判断输入的这些数是否对称,是输出YES，否则输出NO？（注意N可以是奇数或者偶数）。对称的意思是这些数正过来读和反过来读都是一样的。

比如有 $4$ 个数： $1$ $2$ $2$ $1$ ，就是对称的，再比如有 $5$ 个数： $1$ $2$ $3$ $2$ $1$ ，也是对称的，但有 $5$ 个数： $1$ $2$ $3$ $1$ $2$ ，就不是对称的。

输入

第 $1$ 行有一个整数 $n$。 （$4 \le n \le 20$）

第 $2$ 行有 $n$ 个整数。

输出

如果是对称的请输出：YES，否则输出：NO。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
using namespace std;

int n,h,a[30];
int main() {
cin>>n;
for(int i=0;i<n;i++)
{
    cin>>a[i];
}
for(int i=0;i<n/2;i++) //不需分奇偶 
{
    if(a[i]==a[n-i-1])
    {
        h++;
    }
}
if(h==n/2) cout<<"YES";
else cout<<"NO";
}
