P1570 KC 喝咖啡

洛谷 | 普及| C++14 | 提交时间: 2026-07-28

算法标签：二分、洛谷原创、分数规划

题目描述

话说 KC 和 SH 在福州的时候常常跑去 85°C 喝咖啡或者其他的一些什么东西。

这天，KC 想要喝一杯咖啡，服务员告诉他，现在有 nnn 种调料，这杯咖啡只可以加入其中的 mmm 种（当然 KC 一定会加入 mmm 种，不会加入少于 mmm 种的调料），根据加入的调料不同，制成这杯咖啡要用的时间也不同，得到的咖啡的美味度也不同。

KC 在得知所有的 nnn 种调料后，作为曾经的化竞之神的他，马上就知道了所有调料消耗的时间 cic _ ici​ 以及调料的美味度 viv _ ivi​。由于 KC 急着回去刷题，所以他想尽快喝到这杯咖啡，但他又想喝到美味的咖啡，所以他想出了一个办法，他要喝到 ∑vi∑ci\dfrac{\sum v _ i}{\sum c _ i}∑ci​∑vi​​ 最大的咖啡，也就是单位时间的美味度最大的咖啡。

现在，KC 把调料信息告诉了 SH，要 SH 帮他算出喝到的咖啡的 ∑vi∑ci\dfrac{\sum v _ i}{\sum c _ i}∑ci​∑vi​​，但 SH 不想帮 KC 算这东西，于是 KC 就只能拜托你来算了。

注释：∑\sum∑ 表示求和，所以 ∑vi∑ci\dfrac{\sum v _ i}{\sum c _ i}∑ci​∑vi​​ 表示美味度的总和除以消耗时间的总和。

输入格式

输入数据共三行。

第一行为一个整数 n,mn, mn,m，表示调料种数和能加入的调料数。

接下来两行，每行为 nnn 个数，第一行第 iii 个整数表示调料 iii 的美味度 viv _ ivi​，第二行第 iii 个整数表示调料 iii 消耗的时间 cic _ ici​。

输出格式

一个实数 TTT，表示 KC 喝的咖啡的最大 ∑vi∑ci\dfrac{\sum v _ i}{\sum c _ i}∑ci​∑vi​​，保留三位小数。

样例

样例输入 #1

3 2
1 2 3
3 2 1

样例输出 #1

1.667

AC 代码

#include <bits/stdc++.h>
using namespace std;

const int MAXN = 205;
int n, m;
double v[MAXN], c[MAXN];   // v[i] 美味度，c[i] 消耗时间
double d[MAXN];            // 权值 v[i] - mid * c[i]

// 检查比值 mid 是否可行：存在 m 种调料使得 ∑v_i / ∑c_i >= mid
bool check(double mid) {
    for (int i = 0; i < n; i++) {
        d[i] = v[i] - mid * c[i];
    }
    // 从大到小排序
    sort(d, d + n, greater<double>());
    double sum = 0;
    for (int i = 0; i < m; i++) {
        sum += d[i];
    }
    return sum >= 0;
}

int main() {
    /*
      思路：0/1 分数规划 + 二分答案
      最大化 (∑v) / (∑c)，经典二分法。
      对于给定的 mid，判断是否存在方案使 ∑(v - mid*c) ≥ 0。
      若最大的 m 个权值之和 ≥ 0，则 mid 可行，尝试更大的 mid；
      否则 mid 不可行，减小 mid。
      二分直到精度足够，输出保留三位小数。
    */
    cin >> n >> m;
    for (int i = 0; i < n; i++) cin >> v[i];
    for (int i = 0; i < n; i++) cin >> c[i];

    double L = 0, R = 100000;     // 比值上限足够大
    // 循环 60 次，精度满足 1e-6
    for (int t = 0; t < 60; t++) {
        double mid = (L + R) / 2;
        if (check(mid))
            L = mid;
        else
            R = mid;
    }

    cout << fixed << setprecision(3) << L << endl;
    return 0;
}
