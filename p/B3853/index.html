B3853 [语言月赛 202309] 等式判断

洛谷 | 入门 | C++14 | 提交时间: 2026-07-28

算法标签：2023、O2优化、分支结构、语言月赛

题目描述

给出三个整数 a,b,ca,b,ca,b,c，保证 b≠0b \neq 0b=0。

  • 如果 a+b=ca + b = ca+b=c，请你输出 plus\texttt{plus}plus。
  • 如果 a−b=ca - b = ca−b=c，请你输出 minus\texttt{minus}minus。
  • 如果以上两条均不满足，请输出 illegal\texttt{illegal}illegal。

输入格式

输入只有一行三个整数，依次表示 a,b,ca,b,ca,b,c。

输出格式

输出一行一个字符串表示答案。

样例

样例输入 #1

1 2 3```

**样例输出 #1**

plus```

样例输入 #2

3 2 1```

**样例输出 #2**

minus```

样例输入 #3

1 1 4```

**样例输出 #3**

illegal```

AC 代码

#include <iostream>
using namespace std;

int main() {
    // 思路：判断 a+b 或 a-b 是否等于 c，输出对应结果。
    long long a, b, c;           // a,b,c：输入的三个整数，用 long long 防溢出
    cin >> a >> b >> c;

    if (a + b == c) {
        cout << "plus" << endl;
    } else if (a - b == c) {
        cout << "minus" << endl;
    } else {
        cout << "illegal" << endl;
    }

    return 0;
}
