1537 - 小 X 玩游戏(game)

题目描述

听完了故事，小 XXX 又想去玩一会儿游戏了。 这是一个很奇特的单机游戏， 游戏规则如下：

游戏中一共有 4×n4 × n4×n 张牌，每张牌上有一个数字， 这些数字恰好是 111～4×n4 × n4×n。一开始电脑会把这 4×n4 × n4×n 张牌随机打乱，然后会发 2×n2 × n2×n 张牌给小 XXX。那些剩下的 2×n2 × n2×n 牌电脑会再打乱一次，然后排成一排展示给小 XXX 看。而小 XXX 需要做的就是将自己的 2×n2 × n2×n 张牌也排成一排，与电脑展示的 2×n2 × n2×n 张牌一一对应。

之后就开始评分了，对于前 nnn 对牌（一对牌是指小 XXX 的一张加上电脑的一张）， 牌上数字小的一方获得一分； 而对于后 nnn 对牌， 牌上数字大的一方获得一分。

例如当 n=3n=3n=3 时， 共有 121212 张牌 ， 牌上的数字是 111 ～ 121212 。 电脑打乱后，小 XXX 拿到 666 张牌 ，假设是111, 333, 444, 555, 777, 888。 此时电脑手中还剩下 222, 666, 999, 101010, 111111, 121212。同样假设电脑会将这 666 张牌按照 999, 111111, 666, 222, 121212, 101010 这样的顺序展示给小 XXX 看。如果小 XXX 是将 666 张牌按 111, 777, 555, 888, 444, 333 这么排的，那么小 XXX 会获得 444 分。

第 111 对： 1–91 – 91–9 ，小 XXX 得 111 分， 电脑得 000 分

第 222 对： 7–117 – 117–11，小 XXX 得 111 分， 电脑得 000 分

第 333 对： 5–65 – 65–6 ，小 XXX 得 111 分， 电脑得 000 分

第 444 对： 8–28 – 28–2 ，小 XXX 得 111 分， 电脑得 000 分

第 555 对： 4–124 – 124–12， 电脑得 111 分，小 XXX 得 000 分

第 666 对： 3–103 – 103–10， 电脑得 111 分，小 XXX 得 000 分

前一半第 111 对～第 333 对牌是比谁小，后一半第 444 对～第 666 对牌是比谁大。前一列数字代表的是小 XXX 的牌，后一列数字代表的是电脑的牌。

小 XXX 现在已经拿到了 2×n2 × n2×n 张牌，同时电脑也已经展示出了它的 2×n2 × n2×n 张牌是怎么排列的，小 XXX 想知道他最多能够获得多少分？

输入

输入数据第一行为一个正整数 nnn。

接下来一行共有 2×n2 × n2×n 个用空格隔开的正整数， 表示小 XXX 手中拥有的 2×n2 × n2×n 张牌。

再下一行同样是 2×n2 × n2×n 个用空格隔开的正整数， 表示电脑展示出的 2×n2 × n2×n 张牌（以读入的顺序展示）。

输出

输出一行只有一个数 ansansans， 表示小 XXX 最多能够获得的分数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

/*
1. 前n张小的得分，后n张大的得分
2. 小X牌随意调，电脑牌不能动
问：小X最多得分 

解题策略：
1. 小X牌从小到大排序
2. 电脑前n张排序，后n张排序
3. 双指针算分 
*/
int a[2010],b[2010];
int n; 

int main(){
    cin>>n;
    for(int i = 1;i <= 2 * n;i++) cin>>a[i];
    for(int i = 1;i <= 2 * n;i++) cin>>b[i];
    
    sort(a+1,a+2*n+1);
    sort(b+1,b+n+1);
    sort(b+n+1,b+2*n+1);
    
    int l = 1,r = 1,ans = 0;
    while(l <= n && r <= n){
        if(a[l] < b[r]){
            l++;
            r++;
            ans++;
        }else{
            r++;//调整电脑的牌 
        }
    }
    
    l = n + 1,r = n + 1;
    while(l <= 2 * n && r <= 2 * n){
        if(a[l] > b[r]){
            l++;
            r++;
            ans++;
        }else{
            l++;//小X不能得分，将小X牌调大 
        }
    }
    
    cout<<ans; 
    
    return 0;
}
