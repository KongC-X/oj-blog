P10415 [蓝桥杯 2023 国 A] 切割

洛谷 | 普及- | C++14 | 提交时间: 2026-10-10

算法标签：数学、2023、数论、蓝桥杯国赛

题目背景

数据提供：https://www.luogu.com.cn/discuss/838792

题目描述

给定一个 W×HW\times HW×H 的长方形，两边长度均为整数。小蓝想把它切割为很多个边长为整数的小正方形。假设切割没有任何损耗，正方形的边长至少为 222，不允许出现余料，要求所有正方形的大小相等，请问最多能切割出多少个?

输入格式

输入一行，包含两个整数 W,HW, HW,H，用一个空格分隔。

输出格式

输出一行包含一个整数表示答案。如果不存在满足要求的方案，输出 000。

样例

样例输入 #1

10 20```

**样例输出 #1**

50```

样例输入 #2

6 9```

**样例输出 #2**

6```

样例输入 #3

8 13```

**样例输出 #3**

0```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P10415 [蓝桥杯 2023 国 A] 切割
     * 题意：给定 W×H 的长方形，要切成若干个边长相等的小正方形，
     *       要求正方形边长至少为 2，不能有剩余，求最多能切出多少个。
     *
     * 思路：
     *   1. 设正方形边长为 d，则必须满足 d 能整除 W 和 d 能整除 H，
     *      即 d 是 W 和 H 的公约数。
     *   2. 为了让切出的正方形数量最多，边长 d 应该尽可能小。
     *      但题目要求 d ≥ 2，所以我们要找到 W 和 H 的最小公约数（≥2）。
     *   3. 其实所有公约数都是最大公约数 g = gcd(W, H) 的约数。
     *      因此如果 g < 2（即 g = 1），说明没有任何公约数 ≥ 2，输出 0。
     *      否则，最小的可行边长就是 g 的最小质因数（≥2）。
     *   4. 但我们可以直接取 d = g（最大公约数）吗？
     *      注意：d 越小，切出的数量 (W/d) * (H/d) 越大。
     *      所以我们应该取 g 的最小约数（≥2）作为边长，而不是 g 本身。
     *   5. 不过，题目要求的是“最多能切割出多少个”，即最大化 (W/d)*(H/d)。
     *      这等价于最小化 d（d ≥ 2 且 d|W, d|H）。
     *      所以我们需要找到 W 和 H 的最小公约数 d ≥ 2。
     *   6. 如何求最小公约数？可以枚举 d 从 2 到 min(W,H)，
     *      但 W,H ≤ 10^9，直接枚举会超时。
     *      更好的方法：d 一定是 g = gcd(W,H) 的约数。
     *      我们只需要找到 g 的最小质因数即可（若 g ≥ 2）。
     *      如果 g 本身是质数，则 d = g；否则 d = g 的最小质因数。
     *   7. 但还有一种更简单的情况：如果 g ≥ 2，那么 d = g 的任意约数都可行。
     *      为了最小化 d，我们可以从 2 开始试除 g，找到 g 的最小约数（≥2），
     *      这个约数就是最小的可行边长 d。
     *   8. 最后答案 = (W/d) * (H/d)。
     *
     * 时间复杂度：求 gcd O(log min(W,H))，找最小约数最多 O(sqrt(g)) ≤ O(sqrt(10^9))。
     */

    long long W, H;
    cin >> W >> H;

    long long g = __gcd(W, H);   // g: W 和 H 的最大公约数

    // 如果最大公约数小于 2，说明不存在边长 ≥ 2 的正方形
    if (g < 2) {
        cout << 0 << endl;
        return 0;
    }

    // 寻找 g 的最小约数（≥2），即最小的可行边长 d
    long long d = g;   // d: 边长，初始为 g
    for (long long i = 2; i * i <= g; i++) {
        if (g % i == 0) {
            d = i;     // 找到最小约数
            break;
        }
    }
    // 如果循环结束没有找到约数，说明 g 是质数，d 保持为 g

    // 计算能切出的正方形数量
    long long ans = (W / d) * (H / d);
    cout << ans << endl;

    return 0;
}
