1848 - 比较字符串

题目描述

编程实现两个字符串 s1s1s1 和 s2s2s2 的字典序比较。（保证每一个字符串不是另一个的前缀，且长度在 100100100 以内）。

若 s1s1s1 和 s2s2s2 相等，输出 000 ；若它们不相等，则指出其第一个不同字符的ASCII码的差值：如果 s1>s2s1>s2s1>s2 ，则差值为正；如果 ，则差值为负。

输入

输入 222 个字符串，每个字符串仅包含小写字母（不含空格），两个字符串之间用空格隔开。

输出

按题意输出差值或 000 。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main()
{
    string s1,s2;
    cin>>s1>>s2;
    if(s1 == s2){
        cout<<0;
    }else{
        for(int i = 0;i < min(s1.size(),s2.size());i++){
            if(s1[i] != s2[i]){
                cout<<(s1[i]-s2[i]);
                break;
            }
        }
    }
    return 0;
}
