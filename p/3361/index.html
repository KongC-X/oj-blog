3361 - 绝对素数

题目描述

如果一个两位数是素数，且它的数字位置经过对换后仍为素数，则称为绝对素数，例如 131313。给定两个正整数 AAA、BBB，请求出大于等于 AAA、小于等于 BBB 的所有绝对素数。

输入

输入 111 行，包含两个正整数 AAA 和 BBB。保证 。

输出

若干行，每行一个绝对素数，从小到大输出。

AC代码

AC代码

#include <iostream>
using namespace std;
bool is(int n){
    for(int i=2;i*i<=n;i++){
        if(n%i==0)return 0;
    }
    return 1;
}
bool is_swap(int m){
    int ge,shi,sum;
    ge=m%10;
    shi=m/10;
    sum=ge*10+shi;
    if(is(sum))return 1;
    return 0;
}
int main(){
    int a,b;
    cin>>a>>b;
    for(int i=a;i<=b;i++){
        if(is(i)&&is_swap(i))cout<<i<<endl;
    }
    return 0;
}
