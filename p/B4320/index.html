B4320 [科大国创杯小学组 2025] 饼干

洛谷 | 入门 | C++14 | 提交时间: 2026-07-19

算法标签：数学、2025、科创活动、小学活动、科大国创杯

题目背景

Subtask 0 为民间数据，Subtask 1 为官方数据。

题目描述

小可可有一个 1×n1 \times n1×n 的长方形盘子，现在他想在里面放一些 1×m1 \times m1×m 的饼干，饼干不能重叠，他想知道他最多能放多少块饼干？

输入格式

一行两个整数 n,mn, mn,m，如题面定义。

输出格式

一行一个整数，表示最多能放的饼干的数量。

样例

样例输入 #1

19 6```

**样例输出 #1**

3```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    long long n, m;                // n: 盘子长度, m: 每块饼干长度
    cin >> n >> m;

    // 最多能放 n / m 块饼干（相当于问 n 里面有几个 m）
    cout << n / m << endl;
    return 0;
}
