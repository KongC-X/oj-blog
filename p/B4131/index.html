B4131 [信息与未来 2014] 奇怪的车牌号

洛谷 | 普及- | C++14 | 提交时间: 2026-04-13

算法标签：2014、江苏、提交答案、枚举、信息与未来

题目描述

汽车的车牌号是一个 888 位数，最高位可以为 000，所以车牌号范围为 000000000000000000000000 到 999999999999999999999999。现在，有一辆汽车出了事故，驾驶员逃逸了。有三位目击者向警方提供了线索：

  • 甲：车牌号的前 444 位是递增且连续的自然数，即 0123,1234,⋯ ,67890123,1234,\cdots,67890123,1234,⋯,6789；
  • 乙：车牌号的后 444 位也是递增且连续的自然数；
  • 丙：车牌号的各位数字和是某个整数的平方。

例如，012312340123123401231234 就是一个满足以上条件的车牌号，因为：0123,12340123,12340123,1234 均为递增的自然数，其各位数字和 161616 为 444 的平方。

当然，满足上面的三个条件的车牌号还有许多，你的任务是求出所有满足条件的车牌号个数。

输出格式

一个整数，即满足条件的车牌号的个数。

AC 代码

#include<bits/stdc++.h>
using namespace std;
/*
1.前4个数递增，如果前4个数的第1个数是i，那么前四个数的和一定是4*i+6
2.后四个数同前四个数的规律
3.因此本题只要循环前4个数的第一个数的范围：0~6，后四个数的第1个数的范围0~6
  然后判断总和是否是平方数就可以了 
*/
int main(){
    int c=0,i,j;
    for(i=0;i<=6;i++){
        for(j=0;j<=6;j++){
            int x = sqrt(4*i+4*j+12); 
            if(x * x == 4 * i + 4 * j + 12){
                c++;
            }
        }
    }
    cout<<c<<endl;
    return 0;
}
