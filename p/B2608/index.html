题目描述

洛谷的评测任务是单位时间内均匀增加的。888 台评测机 303030 分钟可以刚好把评测队列中的程序评测完毕，101010 台评测机 666 分钟可以刚好把评测队列中的程序评测完毕，请问几台评测机可以在 101010 分钟时刚好把评测队列中的程序评测完毕？

输出格式

请输出一个数字表示答案。这个数字是一个整数。

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】牛吃草问题（匀速增长+匀速消耗）
     * 【核心思路】
     * 设初始程序数为 P，每分钟新增 R，每台评测机每分钟评测 1 个。
     * 根据题意：
     *   P + 30*R = 8*30   (1)
     *   P + 6*R  = 10*6   (2)
     * 由 (1)-(2) 得 24R = 240-60 = 180，所以 R = 7.5
     * 代回 (2) 得 P = 60 - 6*7.5 = 15
     * 设需要 x 台，则 P + 10*R = x*10
     * 代入得 15 + 75 = 10x，所以 x = 9
     *
     * 【时间复杂度】O(1)
     */

    // 变量定义（用 double 因为 R 可能是小数）
    double p;   // p: 初始队列中的程序数
    double r;   // r: 每分钟新增的程序数
    double x;   // x: 需要的评测机台数

    // 解方程求 R
    r = (8.0 * 30 - 10.0 * 6) / (30.0 - 6.0);   // 8台30分钟 vs 10台6分钟
    // 求 P
    p = 10.0 * 6 - 6.0 * r;                      // 利用第二个条件
    // 求 x
    x = (p + 10.0 * r) / 10.0;                  // 10分钟清空所需台数

    // 输出结果（因为 x 一定是整数，直接输出整数部分）
    cout << (int)x << endl;   // 9

    return 0;
}
