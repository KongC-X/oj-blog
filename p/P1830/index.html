P1830 轰炸III

洛谷 | 入门 | C++14 | 提交时间: 2026-06-09

算法标签：模拟、洛谷原创

题目背景

一个大小为 $n\times m$ 的城市遭到了 $x$ 次轰炸，每次都炸了一个每条边都与边界平行的矩形。

题目描述

在轰炸后，有 $y$ 个关键点，指挥官想知道，它们有没有受到过轰炸，如果有，被炸了几次，最后一次是第几轮。

输入格式

第一行共四个整数，分别为 $n,m,x,y$。

接下来 $x$ 行，每行四个整数 $x_1,y_1,x_2,y_2$，表示被轰炸的矩形的左上角坐标和右下角坐标（比如 $1,3,7,10$ 就表示被轰炸的地方是从 $(1,3)$ 到 $(7,10)$ 的矩形）。

接下来 $y$ 行，每行两个整数，表示这个关键点的坐标。

输出格式

输出共 $y$ 行，每行第一个字符为 Y 或 N，表示是否被轰炸；若为 Y，在一个空格后为两个整数，表示被炸了几次和最后一次是第几轮。

样例

样例输入 #1

10 10 2 3
1 1 5 5
5 5 10 10
3 2
5 5
7 1

样例输出 #1

Y 1 1
Y 2 2
N

AC 代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

/*
  P1830 轰炸III — 暴力模拟
  用两个二维数组记录每个格子的状态
  cnt[i][j] = 被炸次数
  last[i][j] = 最后一轮的编号
  n,m≤100，直接遍历矩形，复杂度完全够用
*/

int cnt[105][105];   // cnt[i][j]：格子(i,j)被炸了几次
int last[105][105];  // last[i][j]：最后一次被炸是第几轮

int main() {
    int n, m, x, y;
    cin >> n >> m >> x >> y;
    
    // 模拟 x 次轰炸，k 是轮数编号（从1开始）
    for(int k = 1; k <= x; k++) {
        int x1, y1, x2, y2;  // 矩形左上角和右下角
        cin >> x1 >> y1 >> x2 >> y2;
        // 遍历矩形内所有格子
        for(int i = x1; i <= x2; i++) {
            for(int j = y1; j <= y2; j++) {
                cnt[i][j]++;       // 被炸次数+1
                last[i][j] = k;    // 记录最后一轮
            }
        }
    }
    
    // 查询 y 个关键点
    for(int k = 1; k <= y; k++) {
        int a, b;  // 关键点坐标
        cin >> a >> b;
        if(cnt[a][b] > 0) {
            // 被炸过：输出 Y、次数、最后一轮
            cout << "Y " << cnt[a][b] << " " << last[a][b] << endl;
        } else {
            // 没被炸过
            cout << "N" << endl;
        }
    }
    
    return 0;
}
