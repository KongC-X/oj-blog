1654 - 全部排列问题

题目描述

输入 nnn 输出 1…n1 \dots n1…n 个数的全部排列。全部排列中，数字可以重复 。

例如输入 333 ，输出全部排列的结果如下：111、112、113、121、122、123、131、132、133、211、212、213、221、222、223、231111、112、113、121、122、123、131、132、133、211、212、213、221、222、223、231111、112、113、121、122、123、131、132、133、211、212、213、221、222、223、231、232、233、311、312、313、321、322、323、331、332、333232、233、311、312、313、321、322、323、331、332、333232、233、311、312、313、321、322、323、331、332、333。

输入

一个整数 nnn（1<n≤61 \lt n \le 61<n≤6）。

输出

按照由小到大的顺序输出 1…n1 \dots n1…n 这 nnn 个数的全部排列情况。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;

int n;
int arr[10]; // n ≤ 6，分配10个足够

void dfs(int step) {
    if (step > n) {
        for (int i = 1; i <= n; i++) {
            cout << arr[i];
        }
        cout << endl;
        return;
    }
    
    for (int i = 1; i <= n; i++) {
        arr[step] = i;
        dfs(step + 1);
    }
}

int main() {
    cin >> n;
    dfs(1);
    return 0;
}
