1497 - 分数线的划定

题目描述

宇航局准备招收一批科研人员从事月球探索的航空科研工作。这个职位来了很多应聘者，宇航局对众多应聘者进行综合素质考试，最终会选出 xxx 名综合得分排名靠前应聘者。目前考试已经结束了，宇航局需要根据目前考试的成绩计算出，如果要选出 xxx 个分数靠前的人，分数线应该划到多少分？请你写一个程序来帮助宇航局计算分数线。

比如：如果有 101010 名选手参加考试，他们的得分如下
100100100 999999 989898 979797 969696 959595 949494 939393 929292 919191 909090 。

如果要选出 333 名分数靠前的人，那么分数线应该划在 989898 分。

输入

第一行是一个整数 nnn ，代表参加考试的人数。（n≤1000n \le 1000n≤1000）

第二行有 nnn 个整数，用空格隔开，代表 nnn 个人的考试分数。（注意：不存在成绩一样的分数）

第三行有一个整数 xxx （x<nx \lt nx<n），代表宇航局要选出的人数。

输出

一个整数，代表如果要选出 xxx 个人，宇航局应当划出的分数线。

AC代码

AC代码

#include <iostream>
using namespace std;
int main() {
    //数组大小按照题目的要求定义，最好多定义10个
    int a[1010],n,i,j,t,k;
    cin>>n;
    for(i=0; i<n; i++) {
        cin>>a[i];
    }
    cin >> k;
    for(i=1; i<=n-1; i++) {
        for(j=0; j<=n-i-1; j++) {
            //按照从大到小排序
            if(a[j]<a[j+1]) {
                t=a[j];
                a[j]=a[j+1];
                a[j+1]=t;
            }

        }
    }

    //第1大的数，下标是0，第2大的数下标是1，第3大的数下标是2
    //第k大的数，下标是k-1
    cout<<a[k-1];

    return 0;
}
