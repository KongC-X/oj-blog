P1421 小玉买文具

洛谷 | 入门 | C++14 | 提交时间: 2025-07-31

算法标签：模拟

题目描述

班主任给小玉一个任务，到文具店里买尽量多的签字笔。已知一只签字笔的价格是 111 元 999 角，而班主任给小玉的钱是 aaa 元 bbb 角，小玉想知道，她最多能买多少只签字笔呢。

输入格式

输入只有一行两个整数，分别表示 aaa 和 bbb。

输出格式

输出一行一个整数，表示小玉最多能买多少只签字笔。

样例

样例输入 #1

10 3

样例输出 #1

5

AC 代码

#include<cstdio>
int main()
{
    int a,b;//a元b角
    int c;//转换后的班主任给的价钱
    scanf("%d %d",&a,&b);
    c=a*10+b;//把a元b角转换为a*10+b角
    printf("%d",c/19);//19在这里表示19角，原来是1.9元，不过已经被转换掉了
    return 0;
}
