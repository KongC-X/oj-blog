B3827 [NICA #2] 高考组题

洛谷 | 普及- | C++14 | 提交时间: 2026-09-22

算法标签：O2优化、结构体

题目描述

高考是能决定每个考生命运的考试，因此作为组卷人的 Aya 将高考组卷视为重中之重。现在 Aya 有 $n$ 个备选的高考题。

对于每一道可能选入试卷的高考题，其有 $k$ 个指标来评判它各个方面的维度，例如难度、新颖度、与现实生活的结合性等。每个指标均为一个正整数。

Aya 认为，一个题被放入高考卷的必要性，是这些指标的平均值。他认为，必要性前二高的试题必须要被放进高考试卷。若有多个必要性前二大的试题则选择较早出现的那个。请告诉 Aya 哪个题目是必须要放进高考试卷的。

输入格式

第一行输入两个正整数 $n,k$，含义如题所述；

第二行开始，往下 $n$ 行，每行输入 $k$ 个正整数，以空格隔开，第 $i$ 行表示第 $i-1$ 道题的各个指标是多少。

输出格式

输出两行，表示必要性前两大的试题是哪两个题。优先输出必要性最高的；若有多个题目必要性相同，则优先输出较早出现的。

样例

样例输入 #1

3 2
10 20
15 25
20 30```

**样例输出 #1**

3
2```

样例输入 #2

3 2
10 20
5 25
1 2```

**样例输出 #2**

1
2```

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 结构体：存储每道题的信息
struct Node {
    int id;    // id: 题目编号（从1开始）
    int sum;   // sum: 该题所有指标的总和（必要性 = sum / k，k相同所以比较sum即可）
};

// 比较函数：按总和从大到小排序，若总和相同则按编号从小到大排序
bool cmp(Node a, Node b) {
    if (a.sum != b.sum) return a.sum > b.sum;  // 总和大的排前面
    return a.id < b.id;                        // 总和相同，编号小的排前面
}

int main() {
    /*
     * 题目：B3827 [NICA #2] 高考组题
     * 题意：n 道题，每道题有 k 个指标，必要性 = 指标平均值。
     *       找出必要性前两大的题目编号，若必要性相同则优先输出编号小的（即出现早的）。
     * 思路：
     *   1. 读入 n, k。
     *   2. 对每道题，累加 k 个指标得到总和 sum，记录编号 id。
     *   3. 按 sum 降序、id 升序排序。
     *   4. 输出排序后前两个题目的编号。
     *
     * 时间复杂度：O(n log n)，n ≤ 100，非常快。
     */

    int n, k;
    cin >> n >> k;

    Node a[105];   // 最多 100 道题

    for (int i = 0; i < n; i++) {
        a[i].id = i + 1;      // 题目编号从 1 开始
        a[i].sum = 0;
        for (int j = 0; j < k; j++) {
            int x;
            cin >> x;
            a[i].sum += x;    // 累加指标
        }
    }

    // 排序
    sort(a, a + n, cmp);

    // 输出前两名
    cout << a[0].id << endl;
    cout << a[1].id << endl;

    return 0;
}
