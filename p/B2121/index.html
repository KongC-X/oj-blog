B2121 最长最短单词

洛谷 | 入门 | C++14 | 提交时间: 2026-07-12

算法标签：字符串（入门）

题目描述

输入 111 行句子（不多于 200200200 个单词，每个单词长度不超过 100)100)100)，只包含字母、空格、逗号和句号。单词由至少一个连续的字母构成，空格、逗号和句号都是单词间的间隔。

输出第 111 个最长的单词和第 111 个最短单词。

输出格式

输出数据：

第 111 行，第一个最长的单词。

第 222 行，第一个最短的单词。

样例

样例输入 #1

I am a student,i am studying Programming language C in Peking University.```

**样例输出 #1**

Programming
I```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 1. 读入一行句子（包含空格、逗号、句号等）。
    // 2. 逐个字符遍历，字母则累加到当前单词 cur 中。
    // 3. 遇到非字母（分隔符或结束符）时，如果 cur 非空，则一个单词结束。
    //    获取该单词长度，更新最长/最短单词（都是取第一个出现的）。
    // 4. 循环结束后输出最长和最短单词（各占一行）。
    // 注意：需要将单词长度转为 int 再与 max_len/min_len 比较，避免无符号数与负数比较的问题。

    string s;
    getline(cin, s);

    int max_len = -1;              // 最长单词长度，初始 -1 保证第一次必定更新
    int min_len = 1000;            // 最短单词长度，初始设一个大于最大可能长度的值（单词长度 <= 100）
    string max_word, min_word;     // 对应的单词
    string cur = "";               // 当前正在构建的单词

    for (int i = 0; i <= s.size(); i++) {
        char c = s[i];             // 当 i == s.size() 时 c 为 '\0'，作为结束标志
        if ((c >= 'a' && c <= 'z') || (c >= 'A' && c <= 'Z')) {
            cur += c;              // 字母则追加
        } else {
            // 非字母（分隔符或结束符）且 cur 非空，说明一个单词刚结束
            if (!cur.empty()) {
                int len = cur.size();   // 将 size_t 转为 int，单词长度 <= 100，安全
                if (len > max_len) {    // 更新最长单词（第一次找到或更长）
                    max_len = len;
                    max_word = cur;
                }
                if (len < min_len) {    // 更新最短单词（第一次找到或更短）
                    min_len = len;
                    min_word = cur;
                }
                cur = "";              // 清空，准备下一个单词
            }
        }
    }

    cout << max_word << endl;
    cout << min_word << endl;

    return 0;
}
