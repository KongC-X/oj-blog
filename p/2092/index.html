2092 - 当总统

题目描述

小明想当丑国的总统，丑国大选是按各州的投票结果来确定最终的结果的，如果得到超过一半的州的支持就可以当选，而每个州的投票结果又是由该州选民投票产生的，如果某个州超过一半的选民支持小明，则他将赢得该州的支持。现在给出每个州的选民人数，请问小明至少需要赢得多少选民的支持才能当选？

输入

输入一个整数 nnn，代表有 nnn（）组数据；

每组数据的第一行是一个整数 mmm（1≤m≤1011 \le m \le 1011≤m≤101）,表示丑国的州数。

接下来包括 mmm 个正整数，分别表示每个州的选民数，每个州的选民数不超过 100100100 。

输出

对于每组数据输出一行，表示小明至少需要赢得支持的选民数。

AC代码

AC代码

#include<bits/stdc++.h>
#include<iostream>
using namespace std;

/*
策略：要优先赢得人数较少的洲的支持
1. 如果有m个洲，要赢得m/2+1个洲的支持 
2. 如果第j个洲有a[j]个人，要赢得a[j]/2+1个人的支持 
*/ 
int n,m,a[110],c;
int main() {
    cin>>n;
    //读入n组数据
    for(int i = 1;i <= n;i++){
        //读入m个洲的信息
        cin>>m;
        for(int j = 1;j <= m;j++){
            cin>>a[j];
        } 
        
        //对本洲人数排序
        sort(a+1,a+m+1); 
        
        //计算最少要赢得多少个人的支持
        c = 0;
        for(int j = 1;j <= m / 2 + 1;j++){
            c = c + (a[j] / 2 + 1);
        }
        
        cout<<c<<endl;
    } 
}
