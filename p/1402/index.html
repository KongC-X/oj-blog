1402 - 字符串加密？

题目描述

在情报传递过程中，为了防止情报被截获，往往需要对情报用一定的方式加密，简单的加密算法虽然不足以完全避免情报被破译，但仍然能防止情报被轻易的识别。

我们给出一种最简的的加密方法，对给定的一个字符串，把其中从 $a-y$ ，$A-Y$ 的字母用其后继字母替代，把 $z$ 和 $Z$ 用 $a$ 和 $A$ 替代，其他非字母字符不变，则可得到一个简单的加密字符串。

输入

输入一行，包含一个字符串，长度不超过 $80$ 个字符。

输出

输出每行字符串的加密字符串。

解题思路

AC代码

AC代码

#include <iostream>
#include <cstring>
using namespace std;

int main(){
    char a[1000];
    //cin >> a;
    gets(a);
    int i;
    for(i = 0;i < strlen(a);i++) {
        if(a[i] >= 'a' && a[i] <= 'y' || a[i] >= 'A' && a[i] <= 'Y') {
            a[i] = a[i] + 1;
        } else if(a[i] == 'z' || a[i] == 'Z') {
            a[i] = a[i] - 25;
        }
        cout << a[i];
    }
}
