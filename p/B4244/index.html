B4244 [语言月赛 202503] 水流

洛谷 | 入门 | C++14 | 提交时间: 2026-07-29

算法标签：2025、分支结构、语言月赛

题目描述

有一片池塘，池塘中间的一道非常高的闸门将池塘分隔分为左右两侧。左侧水面高为 $a$ 米，右侧水面高为 $b$ 米。

现在将闸门的高度降低到 $c$ 米，请问此时水是从左向右流动，还是从右向左流动，还是不流动？

输入格式

输入共一行三个整数 $a, b, c$，代表初始时左侧水面高度、右侧水面高度、闸门降低后的高度。

输出格式

输出一个字符串：

  • 如果水会从左向右流动，则输出 LeftToRight；
  • 如果水会从右向左流动，则输出 RightToLeft；
  • 如果水不流动，则输出 None。

样例

样例输入 #1

7 3 4

样例输出 #1

LeftToRight

样例输入 #2

7 7 6

样例输出 #2

None

样例输入 #3

7 6 7

样例输出 #3

None

AC 代码

#include <iostream>
using namespace std;

int main() {
    int a, b, c;              // a:左水位, b:右水位, c:闸门高度
    cin >> a >> b >> c;

    if (a == b) {             // 两边水位相等，水不流动
        cout << "None" << endl;
    } else if (a > b && a > c) { // 左边高且左边水位超过闸门，水从左向右流
        cout << "LeftToRight" << endl;
    } else if (b > a && b > c) { // 右边高且右边水位超过闸门，水从右向左流
        cout << "RightToLeft" << endl;
    } else {                  // 其他情况：没有水能越过闸门，不流动
        cout << "None" << endl;
    }

    return 0;
}
