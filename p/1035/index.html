1035 - 判断成绩等级

题目描述

输入某学生成绩，如果 868686 分以上(包括 868686 分）则输出 VERY GOOD ，如果在 606060 到 858585 之间的则输出 GOOD (包括 606060 和 858585 )，小于 606060 的则输出 BAD。

输入

输入只有一行，包括 111 个整数。

输出

输出只有一行（这意味着末尾有一个回车符号）。

解题思路

AC代码

AC代码

#include <iostream>
using namespace std;

int main(){
    //定义变量x作为学生成绩 
    int x;
    //输入学生成绩 
    cin>>x;
    //判断学生成绩范围，输出对应的单词 
    if(x>=86){
        cout<<"VERY GOOD"<<endl;
    }else if(x>=60){
        cout<<"GOOD"<<endl;
    }else{
        cout<<"BAD";
    }
    return 0;
}
