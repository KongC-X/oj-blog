1744 - 纯粹的四位奇数

题目描述

纯粹奇数指的是一个数的各个位都是奇数的数，比如：$1357$ ；请编程求出 $1000$ ~ $n$ 中，所有的四位的纯粹奇数的和是多少？

输入

一个整数 $n$（ $n$ 为 $1000$~$9999$ 之间的整数）；

输出

一个整数，代表 $1000$~$n$ 中所有四位纯粹奇数的和。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    int n,i,q,b,s,g,sum=0;
    cin>>n;
    //遍历1000到n之间的所有4位数 
    for(i=1000;i<=n;i++){
        //对i进行拆位 
        q=i/1000;
        b=i/100%10;
        s=i%100/10;
        g=i%10;
        //判断i的各个位是奇数 
        if(q%2==1&&b%2==1&&s%2==1&&g%2==1){
            sum=sum+i;//对符合条件的数累加 
        }
    }
    cout<<sum;
    return 0;
}
