1299 - 请问一个整数n能够被2、3、5、7中哪些数整除

题目描述

从键盘读入一个整数 $n$ ，请问 $n$ 能够被 $2、3、5、7$ 中哪些数整除，从小到大依次输出 $n$ 能够整除的数，每行一个。

如：
输入： $20$

输出：

$2$

$5$

输入

一个整数 $n$（ $n \le 10000$ ）。

输出

$n$ 能够整除的数。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    //定义整数变量n 
    int n;
    //输入n 
    cin>>n;
    //可能满足多个条件所以用多if判断 
    if(n%2==0){
        cout<<2<<endl;
    }
    if(n%3==0){
        cout<<3<<endl;
    }
    if(n%5==0){
        cout<<5<<endl;
    }
    if(n%7==0){
        cout<<7<<endl;
    }
    return 0;
}
