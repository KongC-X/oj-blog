1396 - 开学大采购？

题目描述

新学期开始了，学校计划采购一批新的篮球和排球用来上体育课。

学校共有 nnn 元经费，咨询体育用品店得知篮球 xxx 元 /// 个，排球 yyy 元 /// 个，现要求篮球和排球都至少采购 111 个， nnn 元经费全部用完，且篮球和排球的总数要超过 505050 个。

请问有哪些采购方案？（按照篮球从少到多，排球从多到少输出所有可行的方案）

输入

三个整数，n、x、yn、x、yn、x、y 用空格隔开分别代表总经费、篮球单价、排球单价。

输出

所有可行的采购方案，每个组方案有 222 个整数用空格隔开，第 111 个整数代表篮球的采购个数，第 222 个整数代表排球的采购个数。

AC代码

AC代码

#include <iostream>
using namespace std;
int main() {
    int n, x, y, t;
    cin>>n>>x>>y;
    //枚举篮球的购买范围
    for(int i = 1;i <= (n - y) / x;i++){
        //计算剩余的钱 
        t = n - i * x;
        if(t % y == 0 && i + t / y > 50){
            cout<<i<<" "<<t / y<<endl;
        } 
    } 
}
