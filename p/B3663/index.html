B3663 [语言月赛202209] Luogu Academic

洛谷 | 入门 | C++14 | 提交时间: 2026-08-25

算法标签：2022、字符串（入门）、语言月赛

题目描述

七海在 LA 群中游走，获得了一个由英文小写字符组成的字符串 $S$。

七海想要知道，子串 luogu 在其中出现了多少次。

提示： 一个字符串中，任意连续的字符构成的子字符串称为子串。

例如，字符串 abc 一共包含 7 个子串，分别为：空串（不包含任何字符)，a，ab，abc，b，bc，c。注意，字符串 ac 不是 abc 的子串。

输入格式

输入一行一个字符串 $S$。

输出格式

输出一行一个整数，代表子串 luogu 在字符串 $S$ 中出现的次数。

样例

样例输入 #1

luoluoguluogu```

**样例输出 #1**

2```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3663 [语言月赛202209] Luogu Academic
     * 题意：统计字符串中连续子串 "luogu" 的出现次数。
     * 思路：遍历每个位置，用 substr 截取长度为 5 的子串，与 "luogu" 比较。
     */
    string s;
    cin >> s;
    int n = s.size();
    int ans = 0;
    for (int i = 0; i + 4 < n; i++) {
        if (s.substr(i, 5) == "luogu") ans++;
    }
    cout << ans << endl;
    return 0;
}
