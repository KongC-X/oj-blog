P2822 [NOIP 2016 提高组] 组合数问题

洛谷 | 普及| C++14 | 提交时间: 2026-05-22

算法标签：数学、2016、NOIP 提高组、组合数学、前缀和

题目背景

NOIP2016 提高组 D2T1

题目描述

组合数 $\binom{n}{m}$ 表示的是从 $n$ 个物品中选出 $m$ 个物品的方案数。举个例子，从 $(1,2,3)$ 三个物品中选择两个物品可以有 $(1,2),(1,3),(2,3)$ 这三种选择方法。根据组合数的定义，我们可以给出计算组合数 $\binom{n}{m}$ 的一般公式：

$$\binom{n}{m}=\frac{n!}{m!(n-m)!}$$

其中 $n!=1\times2\times\cdots\times n$；特别地，定义 $0!=1$。

小葱想知道如果给定 $n,m$ 和 $k$，对于所有的 $0\leq i\leq n,0\leq j\leq \min \left ( i, m \right )$ 有多少对 $(i,j)$ 满足 $k\mid\binom{i}{j}$。

输入格式

第一行有两个整数 $t,k$，其中 $t$ 代表该测试点总共有多少组测试数据，$k$ 的意义见问题描述。

接下来 $t$ 行每行两个整数 $n,m$，其中 $n,m$ 的意义见问题描述。

输出格式

共 $t$ 行，每行一个整数代表所有的 $0\leq i\leq n,0\leq j\leq \min \left ( i, m \right )$ 中有多少对 $(i,j)$ 满足 $k\mid\binom{i}{j}$。

样例

样例输入 #1

1 2
3 3```

**样例输出 #1**

1```

样例输入 #2

2 5
4 5
6 7```

**样例输出 #2**

0
7


## AC 代码

```cpp
#include <iostream>
using namespace std;

const int N = 2000;               // 最大 n,m 范围
int c[N + 5][N + 5];              // c[i][j]: 组合数 C(i,j) 模 k 的结果
int s[N + 5][N + 5];              // s[i][j]: 满足条件的对数前缀和

int main() {
    // ---------- 思路 ----------
    // 1. 利用递推公式预处理所有 C(i,j) 模 k 的值：
    //    C(i,j) = C(i-1,j-1) + C(i-1,j)  (模 k 意义下)
    //    初始 C(i,0) = C(i,i) = 1 % k
    // 2. 若 C(i,j) % k == 0，则标记 b[i][j] = 1，否则 0
    // 3. 对标记数组做二维前缀和 s[i][j]，
    //    表示 0<=x<=i, 0<=y<=j 且 y<=x 的范围内满足条件的个数
    //    注意 j 不能超过 i，因此对于 j>i 的部分，s[i][j] 保持为 s[i][i]
    //    实际询问时，若 m > n 则取 m = n，直接使用 s[n][m]
    // 4. 每组询问 O(1) 输出 s[n][min(n,m)]
    // -------------------------

    int t, k;
    cin >> t >> k;

    // 预处理组合数模 k
    for (int i = 0; i <= N; ++i) {
        c[i][0] = c[i][i] = 1 % k;          // 边界赋值
        for (int j = 1; j < i; ++j) {
            c[i][j] = (c[i - 1][j - 1] + c[i - 1][j]) % k;
        }
    }

    // 构建前缀和 s[i][j]
    // s[i][j] 表示所有 x<=i, y<=j 且 y<=x 的范围内 (C(x,y) % k == 0) 的个数
    for (int i = 0; i <= N; ++i) {
        for (int j = 0; j <= i; ++j) {
            // 当前点是否满足条件
            int val = (c[i][j] == 0) ? 1 : 0;
            // 二维前缀和递推
            if (i == 0 && j == 0)
                s[i][j] = val;
            else if (i == 0)
                s[i][j] = s[i][j - 1] + val;
            else if (j == 0)
                s[i][j] = s[i - 1][j] + val;
            else
                s[i][j] = s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1] + val;
        }
        // 对于 j > i 的部分，用 s[i][i] 填充，方便询问时直接取 min(n,m)
        for (int j = i + 1; j <= N; ++j) {
            s[i][j] = s[i][i];
        }
    }

    // 处理询问
    while (t--) {
        int n, m;
        cin >> n >> m;
        if (m > n) m = n;           // j 最大不超过 i
        cout << s[n][m] << "\n";
    }

    return 0;
}
