P5412 [YNOI2019] 排队

洛谷 | 普及- | C++14 | 提交时间: 2026-08-05

算法标签：模拟、2019、各省省选、排序、云南

题目描述

小明所在的班级要举办一场课外活动，在活动开始之前老师告诉小明：“需要把男女生分成两队，并且每一队都要按照身高从矮到高进行排序”。但是由于小明的马虎，没有把老师的安排转达给同学，导致全班同学已经排成了一列。活动马上要开始了，小明的老师对此很困扰，你能帮帮她吗？

输入格式

每个输入文件包含多组数据。

输入文件的第一行，包含一个正整数 $T$，代表该输入文件中所含的数据组数。

接下来是 $T$ 组数据，每组数据的格式如下：

每组数据包含 $3$ 行；

第一行包含一个整数 $n$，代表班级的总人数，其中 $(0 < n \leq 2\times 10^{3})$；

第二行包含 $n$ 个整数，它们之间用一个空格隔开，代表已经排成的一列中每一位同学的性别。每一位整数只取 $0$ 或 $1$（$0$ 表示女生，$1$ 表示男生）；

第三行包含 $n$ 个浮点数，它们之间用一个空格隔开，与第二行中的数据一一对应，代表已经排成的一列中每一位同学的身高 $h(100 \leq h \leq 200)$。

输出格式

输出文件包含 $2T$ 行，分别对应 $T$ 组数据的答案，每组答案的格式如下：

每组答案包含 $2$ 行；

第一行按照从小到大的顺序输出所有女生的身高；

第二行按照从小到大的顺序输出所有男生的身高。

注意在输出身高时，请按照原来的身高保留对应的小数点位数。

样例

样例输入 #1

1
5
1 0 1 0 1
120.2 130.3 140.4 150.5 160.6

样例输出 #1

130.3 150.5
120.2 140.4 160.6

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 比较函数：升序
bool cmp(double a, double b) {
    return a < b;
}

int main() {
    /*
     * 【题目类型】排序 + 分类
     * 【核心思路】
     * 1. 读入性别数组 s[] 和身高数组 h[]。
     * 2. 将女生身高存入 g[]，男生身高存入 b[]。
     * 3. 分别排序后输出。
     * 4. 用 double 存储身高，输出时保留原有小数位数。
     */

    int t;          // t: 数据组数
    cin >> t;
    while (t--) {
        int n;      // n: 人数
        cin >> n;

        int s[2005];           // s[i]: 第 i 个同学的性别
        double h[2005];        // h[i]: 第 i 个同学的身高

        for (int i = 0; i < n; i++) cin >> s[i];
        for (int i = 0; i < n; i++) cin >> h[i];

        double g[2005], b[2005]; // g: 女生身高, b: 男生身高
        int gc = 0, bc = 0;      // gc: 女生人数, bc: 男生人数

        for (int i = 0; i < n; i++) {
            if (s[i] == 0) g[gc++] = h[i];
            else b[bc++] = h[i];
        }

        sort(g, g + gc, cmp);
        sort(b, b + bc, cmp);

        // 输出女生
        for (int i = 0; i < gc; i++) {
            if (i) cout << ' ';
            cout << g[i];
        }
        cout << endl;
        // 输出男生
        for (int i = 0; i < bc; i++) {
            if (i) cout << ' ';
            cout << b[i];
        }
        cout << endl;
    }
    return 0;
}
