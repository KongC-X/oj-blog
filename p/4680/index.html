4680 - 词频统计

题目描述

在文本处理中，统计单词出现的频率是一个常见的任务。现在，给定 $n$ 个单词，你需要找出其中出现次数最多的单词。在本题中，忽略单词中字母的大小写（即 Apple 、 apple 、APPLE、aPPle 等均视为同一个单词）。

请你编写一个程序，输入 $n$ 个单词，输出其中出现次数最多的单词。

输入

第一行，一个整数 $n$ ，表示单词的个数；

接下来 $n$ 行，每行包含一个单词，单词由大小写英文字母组成。

输入保证，出现次数最多的单词只会有一个。

输出

输出一行，包含出现次数最多的单词（输出单词为小写形式）。

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int n,i,j,sum,ma;
string s;
string a[110];

int main() {
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> a[i];
    }
    for(i = 0;i < n;i++) {
        for(j = 0;j < a[i].size();j++) {
            if(a[i][j] >= 'A' && a[i][j] <= 'Z') {
                a[i][j] = a[i][j] + 32;
            }
        }
    }
    for(i = 0;i < n;i++) {
        sum = 0;
        for(j = i + 1;j < n;j++) {
            if(a[i] == a[j]) {
                sum++;
            }
        }
        if(sum > ma) {
            ma = sum;
            s = a[i];
        }
    }
    cout << s << endl;
}
