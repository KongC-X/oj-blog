B4502 [GESP202603 四级] 礼盒排序

洛谷 | 普及- | C++14 | 提交时间: 2026-03-18

算法标签：排序、2026、结构体、GESP

题目描述

商店推出了许多礼盒，每个礼盒中包含 kkk 件商品，每件商品都有一个价格。

现在需要对这些礼盒进行排序，排序规则如下：

  1. 先按礼盒总价格从小到大排序；
  2. 如果总价格相同，按礼盒中最贵商品的价格从小到大排序；
  3. 如果仍然相同，按礼盒中最便宜商品的价格从小到大排序；
  4. 如果仍然相同，按礼盒编号从小到大排序。

请输出排序后的礼盒编号。

输入格式

第一行包含两个整数 nnn 和 kkk，分别表示礼盒数量和每个礼盒中商品的数量。

接下来 nnn 行，每行包含 kkk 个整数，第 iii 行表示第 iii 个礼盒中各商品的价格。

输出格式

输出一行，包含排序后的礼盒编号（编号从 111 开始），用空格分隔。

样例

样例输入 #1

4 3
3 5 2
4 1 5
2 2 4
3 4 3```

**样例输出 #1**

3 4 2 1```

AC 代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

struct Box {
    int id;
    int sum;
    int max;
    int min;
};

bool cmp(Box a, Box b) {
    // 按总价、最贵、最便宜、编号依次升序比较
    if (a.sum < b.sum ||
        (a.sum == b.sum && a.max < b.max) ||
        (a.sum == b.sum && a.max == b.max && a.min < b.min) ||
        (a.sum == b.sum && a.max == b.max && a.min == b.min && a.id < b.id))
        return true;
    else
        return false;
}

int main() {
    int n, k;
    cin >> n >> k;
    Box a[1010];
    for (int i = 0; i < n; ++i) {
        a[i].id = i + 1;
        int sum = 0, mx = 0, mn = 10001;
        for (int j = 0; j < k; ++j) {
            int p;
            cin >> p;
            sum += p;
            if (p > mx) mx = p;
            if (p < mn) mn = p;
        }
        a[i].sum = sum;
        a[i].max = mx;
        a[i].min = mn;
    }
    sort(a, a + n, cmp);
    for (int i = 0; i < n; ++i) {
        if (i > 0) cout << ' ';
        cout << a[i].id;
    }
    cout << endl;
    return 0;
}
