B4223 [常州市赛 2024] 早起的鸟儿有虫吃

洛谷 | 普及- | C++14 | 提交时间: 2026-07-25

算法标签：2024、江苏、分支结构、科创活动、小学活动

题目背景

搬运自 http://czoj.com.cn/p/949。数据为民间数据。

感谢 @kradcigam 提供的数据。

题目描述

清晨，丛林里的鸟儿开始了一天的忙碌，吃早餐。

丛林可以看成是一个无限大的网格，每个格子在 000 时刻都有且仅有一只虫子。丛林里有 nnn 只鸟，第 iii 只鸟在 000 时刻在第 xix_ixi​ 行，第 yiy_iyi​ 列。其中，对于所有数据保证 xi=1x_i=1xi​=1 或 yi=1y_i=1yi​=1，即第 iii 只鸟初始时一定在第 111 行或第 111 列。

为了简化问题，我们假设鸟都只会向下或向右直线飞行，而虫子是不动的。当鸟儿在任何时刻（包括时刻 000）飞过一个格子时，就会吃掉该格子内的虫子。相应的，该时刻之后，该格子就不再有虫子了。

同时保证：如果一只鸟往下飞，则它的起始位置一定在第一行；如果一只鸟往右飞，则它的起始位置一定在第一列。为了保证鸟的飞行方向唯一，鸟的初始位置不会是 (1,1)(1,1)(1,1)。

因为所有鸟都喜欢享受连续的免费早餐，所以如果在飞行时到达了一个已经没有虫子的格子，它就会非常不爽，直接停止在这个格子中。测试数据保证所有的鸟在任意时刻的位置互不相同。

需要注意的是，吃早餐的时间是有限的，只有 WWW 个单位的时间。因此，如果一只鸟在时刻 WWW 开始时还没有停止，那它会在这个时刻开始前被强制停止。

现在，想请聪明的你求出，对于每个 i(1≤i≤n)i(1\le i\le n)i(1≤i≤n)，第 iii 只鸟吃了多少只虫子？

输入格式

第一行，两个正整数 n,Wn, Wn,W，分别表示鸟的数量和吃早餐的总时刻数。

接下来 nnn 行，每行两个正整数 xi,yix_i,y_ixi​,yi​。

输出格式

共 nnn 行，第 iii 行一个正整数，表示第 iii 只鸟吃的虫子数。

样例

样例输入 #1

1 5
2 1```

**样例输出 #1**

5```

样例输入 #2

2 20
2 1
1 5```

**样例输出 #2**

4
20```

AC 代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 一只鸟如果可以连续一直吃，最多可以吃到 W 只虫子，所以最大值为 W。
// 如果两只鸟在不同方向飞行，则它们在无时限中必定会相交，
// 把两只鸟的横纵坐标交叉比较，较大的就会到没虫子的格子。
// 我们只需要用 i,j 去枚举所有鸟可以吃到的虫子数即可。

long long x[10], y[10];        // 存储每只鸟的初始坐标
bool d[10];                    // d[i]: 方向，0表示向右，1表示向下

int main() {
    int n;
    long long w;
    cin >> n >> w;

    // 读入鸟的信息
    for (int i = 1; i <= n; i++) {
        cin >> x[i] >> y[i];
        if (x[i] == 1) {       // 起始位置在第一行，所以是向下飞
            d[i] = 1;          // 1: 向下
        } else {               // 起始位置在第一列，所以是向右飞
            d[i] = 0;          // 0: 向右
        }
    }

    // 对每只鸟单独计算答案
    for (int i = 1; i <= n; i++) {
        long long ans = w;     // 初始假设能飞满时间 w

        for (int j = 1; j <= n; j++) {
            if (i == j) continue; // 同一只鸟跳过

            if (d[i] == 1) {   // 当前鸟 i 向下飞
                if (d[j] != d[i]) { // 另一只鸟 j 是向右飞
                    // 相遇点在 (x[j], y[i])
                    // 鸟 i 到达时间：x[j]-1，鸟 j 到达时间：y[i]-1
                    // 如果 y[i] < x[j]，鸟 j 先到（更快），鸟 i 被阻挡
                    if (y[i] < x[j]) {
                        // 鸟 i 最多飞到 x[j]-1 行，共 x[j]-1 只虫子
                        ans = min(ans, x[j] - 1);
                    }
                }
            } else {           // 当前鸟 i 向右飞
                if (d[j] != d[i]) { // 另一只鸟 j 是向下飞
                    // 相遇点在 (x[j], y[i])
                    // 鸟 i 到达时间：y[i]-1，鸟 j 到达时间：x[j]-1
                    // 如果 x[i] < y[j]，鸟 j 先到，鸟 i 被阻挡
                    if (x[i] < y[j]) {
                        // 鸟 i 最多飞到 y[j]-1 列，共 y[j]-1 只虫子
                        ans = min(ans, y[j] - 1);
                    }
                }
            }
        }
        cout << ans << endl;
    }
    return 0;
}
