B2139 区间内的真素数

洛谷 | 普及- | C++14 | 提交时间: 2026-07-15

算法标签：函数与递归

题目描述

找出正整数 $M$ 和 $N$ 之间（$M\le N$）的所有真素数。

真素数的定义：如果一个正整数 $P$ 为素数，且其反序也为素数，那么 $P$ 就为真素数。

例如，$11$，$13$ 均为真素数。因为 $11$ 的反序还是 $11$，而 $11$ 是素数；$13$ 的反序是 $31$，而 $13$ 和 $31$ 均为素数。

输入格式

输入两个数 $M$ 和 $N$，空格间隔。

输出格式

按从小到大输出 $M$ 和 $N$ 之间（包括 $M$ 和 $N$）的真素数，逗号间隔。如果之间没有真素数，则输出 No。

样例

样例输入 #1

10 35```

**样例输出 #1**

11,13,17,31```

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 判断一个数是否为素数
bool isPrime(int x) {
    if (x < 2) return false;
    for (int i = 2; i * i <= x; i++) {
        if (x % i == 0) return false;
    }
    return true;
}

// 返回整数 x 的反序数（例如 13 -> 31）
int revNum(int x) {
    int r = 0;
    while (x > 0) {
        r = r * 10 + x % 10;
        x /= 10;
    }
    return r;
}

int main() {
    int M, N;
    cin >> M >> N;

    bool first = true;               // 控制是否输出逗号
    bool found = false;              // 是否找到至少一个真素数
    for (int i = M; i <= N; i++) {
        if (isPrime(i) && isPrime(revNum(i))) {
            if (!first) cout << ',';
            cout << i;
            first = false;
            found = true;
        }
    }

    if (!found) cout << "No";
    cout << endl;

    return 0;
}
