B2139 区间内的真素数

洛谷 | 普及- | C++14 | 提交时间: 2026-07-15

算法标签：函数与递归

题目描述

找出正整数 MMM 和 NNN 之间（M≤NM\le NM≤N）的所有真素数。

真素数的定义：如果一个正整数 PPP 为素数，且其反序也为素数，那么 PPP 就为真素数。

例如，111111，131313 均为真素数。因为 111111 的反序还是 111111，而 111111 是素数；131313 的反序是 313131，而 131313 和 313131 均为素数。

输入格式

输入两个数 MMM 和 NNN，空格间隔。

输出格式

按从小到大输出 MMM 和 NNN 之间（包括 MMM 和 NNN）的真素数，逗号间隔。如果之间没有真素数，则输出 No。

样例

样例输入 #1

10 35```

**样例输出 #1**

11,13,17,31```

AC 代码

#include <bits/stdc++.h>
using namespace std;

// 判断一个数是否为素数
bool isPrime(int x) {
    if (x < 2) return false;
    for (int i = 2; i * i <= x; i++) {
        if (x % i == 0) return false;
    }
    return true;
}

// 返回整数 x 的反序数（例如 13 -> 31）
int revNum(int x) {
    int r = 0;
    while (x > 0) {
        r = r * 10 + x % 10;
        x /= 10;
    }
    return r;
}

int main() {
    int M, N;
    cin >> M >> N;

    bool first = true;               // 控制是否输出逗号
    bool found = false;              // 是否找到至少一个真素数
    for (int i = M; i <= N; i++) {
        if (isPrime(i) && isPrime(revNum(i))) {
            if (!first) cout << ',';
            cout << i;
            first = false;
            found = true;
        }
    }

    if (!found) cout << "No";
    cout << endl;

    return 0;
}
