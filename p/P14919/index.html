P14919 [GESP202512 六级] 路径覆盖

洛谷 | 普及| C++14 | 提交时间: 2026-06-16

算法标签：搜索、贪心、2025、深度优先搜索 DFS、树形 DP、GESP

题目背景

对应的选择、判断题：https://ti.luogu.com.cn/problemset/1202

题目描述

给定一棵有 $n$ 结点的有根树 $T$，结点依次以 $1,2,\ldots,n$ 编号，根结点编号为 $1$。方便起见，编号为 $i$ 的结点称为结点 $i$。

初始时 $T$ 中的结点均为白色。你需要将 $T$ 中的若干个结点染为黑色，使得所有叶子到根的路径上至少有一个黑色结点。将结点 $i$ 染为黑色需要代价 $c_i$，你需要在满足以上条件的情况下，最小化染色代价之和。

叶子是指 $T$ 中没有子结点的结点。

输入格式

第一行，一个正整数 $n$，表示结点数量。

第二行，$n-1$ 个正整数 $f_2,f_3,\ldots,f_n$，其中 $f_i$ 表示结点 $i$ 的父结点的编号，保证 $f_i<i$。

第三行，$n$ 个正整数 $c_1,c_2,\ldots,c_n$，其中 $c_i$ 表示将结点 $i$ 染为黑色所需的代价。

输出格式

一行，一个整数，表示在满足所有叶子到根的路径上至少有一个黑色结点的前提下，染色代价之和的最小值。

样例

样例输入 #1

4
1 2 3
5 6 2 3```

**样例输出 #1**

2```

样例输入 #2

7
1 1 2 2 3 3
64 16 15 4 3 2 1```

**样例输出 #2**

10```

AC 代码

#include <iostream>
using namespace std;

const int MAXN = 100005;
long long c[MAXN];                // c[i]：染黑结点i的代价
long long sum[MAXN];              // sum[i]：结点i的所有子结点的dp值之和
long long dp[MAXN];               // dp[i]：以i为根的子树，在祖先无黑点的前提下，满足叶子到i路径至少一个黑点的最小代价
int f[MAXN];                      // f[i]：结点i的父结点
bool leaf[MAXN];                  // leaf[i]：i是否为叶子

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;                        // n：结点数
    cin >> n;

    // 初始化所有结点为叶子，后面更新
    for (int i = 1; i <= n; i++) leaf[i] = true;

    // 读入父结点信息，并标记父结点不是叶子
    for (int i = 2; i <= n; i++) {
        cin >> f[i];
        leaf[f[i]] = false;       // f[i] 有了孩子，不再是叶子
    }
    // 注意：根1如果没有任何孩子，那么leaf[1]仍为true，后面会特殊处理

    // 读入染色代价
    for (int i = 1; i <= n; i++) {
        cin >> c[i];
    }

    // 自底向上DP：从n倒序遍历到2
    for (int i = n; i >= 2; i--) {
        if (leaf[i]) {
            // 叶子：祖先无黑点时，必须自己染黑
            dp[i] = c[i];
        } else {
            // 非叶子：可以在自己染黑 或 让所有孩子的子树内部满足 中取较小者
            dp[i] = min(c[i], sum[i]);
        }
        // 将当前结点的dp值贡献给父结点
        sum[f[i]] += dp[i];
    }

    // 处理根结点1
    if (leaf[1]) {                // 如果根是叶子（树只有1个结点的情况，但n>=2一般不会）
        dp[1] = c[1];
    } else {
        dp[1] = min(c[1], sum[1]);
    }

    cout << dp[1] << '\n';
    return 0;
}
