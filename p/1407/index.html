1407 - 图像相似度

题目描述

给出两幅相同大小的黑白图像（用 0−10-10−1 矩阵表示，000 代表白色，111 代表黑色）表示，求它们的相似度。

说明：若两幅图像在相同位置上的像素点颜色的值相同，则称它们在该位置具有相同的像素点。两幅图像的相似度定义为相同像素点数占总像素点数的百分比。

比如：输入

`2 2
1 0
0 1
1 1
1 1
`

数据解释：第一行的 222 222 表示图像的尺寸是 222 行，每行 222 个整数；接下来的两行数据 111 000 和 000 111 表示第一幅图片的数值，再接下来两行数据 111 111 和 111 111 表示第二幅图片的数值；

从数据上可以看出，两幅图片有 222 个数是相等的，因此两幅图片的相似度为 50%50\%50%，实际输出不需要输出百分号，结果保留 222 位小数，因此实际输出 50.0050.0050.00 。

输入

第一行包含两个整数 nnn 和 mmm ，表示图像的行数和列数，中间用单个空格隔开。（1≤n,m≤1001 \le n,m \le 1001≤n,m≤100）

之后 nnn 行，每行 mmm 个整数 000 或 111 ，表示第一幅黑白图像上各像素点的颜色。相邻两个数之间用单个空格隔开。

之后 nnn 行，每行 mmm 个整数 000 或 111 ，表示第二幅黑白图像上各像素点的颜色。相邻两个数之间用单个空格隔开。

输出

一个小数，表示相似度（以百分比的形式给出，但百分号不需要显示），精确到小数点后两位。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    int a[100][100],b[100][100],i,j,n,m,c=0;
    cin>>n>>m;
    //读入第一幅图像的值 
    for(i=0;i<n;i++){
        for(j=0;j<m;j++){
            cin>>a[i][j];
        }
    }
    //读入第二幅图像的值 
    for(i=0;i<n;i++){
        for(j=0;j<m;j++){
            cin>>b[i][j];
        }
    }
    
    //统计相同点的数量
    for(i=0;i<n;i++){
        for(j=0;j<m;j++){
            if(a[i][j]==b[i][j]){
                c++;
            }
        }
    } 
    
    double r = c*100.0/(n*m);
    cout<<fixed<<setprecision(2)<<r<<endl;
    return 0;
}
