1853 - 黑色星期五

题目描述

有些西方人比较迷信，如果某个月的 131313 号正好是星期五，他们就会觉得不太吉利，用古人的说法，就是“诸事不宜”。请你编写一个程序，统计出在某个特定的年份中，出现了多少次既是 131313 号又是星期五的情形，以帮助你的迷信朋友解决难题。

说明：

  • 一年有 365365365 天，闰年有 366366366 天，所谓闰年，即能被 444 整除且不能被 100100100 整除的年份，或是既能被 100100100 整除也能被 400400400 整除的年份；

  • 已知 199819981998 年 111 月 111 日是星期四，用户输入的年份肯定大于或等于 199819981998 年。

输入

输入只有一行，即某个特定的四位数的年份（大于或等于 199819981998 年）。

输出

输出只有一行，即在这一年中，出现了多少次既是 131313 号又是星期五的情形。

AC代码

AC代码

#include <iostream>
using namespace std;

bool isLeapYear(int year) {
    if (year % 4 != 0) {
        return false;
    } else if (year % 100 != 0) {
        return true;
    } else {
        return (year % 400 == 0);
    }
}

int daysInMonth(int month, int year) {
    if (month == 2) {
        return isLeapYear(year) ? 29 : 28;
    } else if (month == 4 || month == 6 || month == 9 || month == 11) {
        return 30;
    } else {
        return 31;
    }
}

int main() {
    int year;
    cin >> year;

    int totalDays = 0;
    for (int y = 1998; y < year; ++y) {
        totalDays += isLeapYear(y) ? 366 : 365;
    }

    int dayOfWeek = (4 + totalDays) % 7; // 1998年1月1日是星期四（4）

    int count = 0;
    for (int month = 1; month <= 12; ++month) {
        if ((dayOfWeek + 12) % 7 == 5) { // 13号是星期五（5）
            count++;
        }
        dayOfWeek = (dayOfWeek + daysInMonth(month, year)) % 7;
    }

    cout << count << endl;

    return 0;
}
