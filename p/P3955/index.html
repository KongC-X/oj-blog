P3955 [NOIP 2017 普及组] 图书管理员

洛谷 | 普及- | C++14 | 提交时间: 2026-08-07

算法标签：字符串、2017、NOIP 普及组、排序

题目背景

NOIP2017 普及组 T2

题目描述

图书馆中每本书都有一个图书编码，可以用于快速检索图书，这个图书编码是一个正整数。每位借书的读者手中有一个需求码，这个需求码也是一个正整数。如果一本书的图书编码恰好以读者的需求码结尾，那么这本书就是这位读者所需要的。小 D 刚刚当上图书馆的管理员，她知道图书馆里所有书的图书编码，她请你帮她写一个程序，对于每一位读者，求出他所需要的书中图书编码最小的那本书，如果没有他需要的书，请输出 -1。

输入格式

第一行，包含两个正整数 n,qn,qn,q，以一个空格分开，分别代表图书馆里书的数量和读者的数量。

接下来的 nnn 行，每行包含一个正整数，代表图书馆里某本书的图书编码。

接下来的 qqq 行，每行包含两个正整数，以一个空格分开，第一个正整数代表图书馆里读者的需求码的长度，第二个正整数代表读者的需求码。

输出格式

qqq 行，每行包含一个整数，如果存在第 iii 个读者所需要的书，则在第 iii 行输出第 iii 个读者所需要的书中图书编码最小的那本书的图书编码，否则输出 −1-1−1。

样例

样例输入 #1

5 5 
2123 
1123 
23 
24 
24 
2 23 
3 123 
3 124 
2 12 
2 12```

**样例输出 #1**

23
1123
-1
-1
-1 ```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】模拟 + 字符串后缀匹配
     * 【核心思路】
     * 1. 将所有图书编码读入整型数组，排序（为了找到最小编码）。
     * 2. 对于每个读者：
     *    - 读入需求码长度 len 和需求码 x（整数）。
     *    - 将需求码转为字符串 sx。
     *    - 遍历排序后的图书编码，将每个编码转为字符串，检查是否以 sx 结尾。
     *    - 若是，输出该编码，跳出；否则输出 -1。
     * 
     * 优点：不用计算模数，直接比较字符串末尾，直观不易错。
     * 缺点：每次都需要转字符串，但 n,q≤1000，完全没问题。
     *
     * 【时间复杂度】O(n log n + q * n * L)，L为字符串长度，最坏约8，仍很快。
     */

    int n, q;
    cin >> n >> q;

    int a[1005];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    sort(a, a + n);   // 升序，保证第一个匹配的是最小编码

    while (q--) {
        int len, x;
        cin >> len >> x;
        string sx = to_string(x);  // 需求码的字符串形式

        int ans = -1;
        for (int i = 0; i < n; i++) {
            string sa = to_string(a[i]);
            // 检查 sa 是否以 sx 结尾
            if (sa.size() >= sx.size() && sa.substr(sa.size() - sx.size()) == sx) {
                ans = a[i];
                break;
            }
        }
        cout << ans << endl;
    }

    return 0;
}
