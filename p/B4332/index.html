B4332 [语言月赛 202505] 简易 JSON 解析

洛谷 | 普及- | C++14 | 提交时间: 2025-06-03

算法标签：2025、字符串（入门）、语言月赛

题目描述

JSON 是常用的结构化文本，在本题中，我们将实现一个简易的 JSON 解析器。

JSON 格式可以理解为一个键值对结构，通过访问 key1，可以获取 val1，不同的键值对之间由英文半角逗号隔开。

{
  key1: val1,
  key2: val2,
  key3: val3
}

通常，键（key）是字符串。与 C/C++ 语言相同，JSON 文本中的字符串常量由 "" 标识。在本题中，我们实现一个较为简单的 JSON 文本解析，假定值（val）仅由整数和 JSON 文本构成。

下面是一个符合本题假设的 JSON 文本例子。

{
  "k1": 10,
  "k2": {
    "k21": 15,
    "k22": 20
  },
  "k3": 30
}

给出压缩为一行的 JSON 文本（简单的去掉空白符）与每一级访问的键，给出访问的结果。保证这个结果是一个整数。

输入格式

输入的第一行为一个字符串，表示压缩为一行的 JSON 文本，不含空格。

输入的第二行为一个整数 $p$，表示依次访问的键的级数。

接下来 $p$ 行，每行一个字符串，表示本级访问的键。

输出格式

一行一个整数，表示访问结果。

样例

样例输入 #1

{"k1":10,"k2":{"k21":15,"k22":20},"k3":30}
1
k1```

**样例输出 #1**

10```

样例输入 #2

{"k1":10,"k2":{"k21":15,"k22":20},"k3":30}
2
k2
k22```

**样例输出 #2**

20```

AC 代码

#include <iostream>
#include <string>
using namespace std;

int main() {
    string json;  // 存储输入的JSON字符串
    int p;        // 存储访问键的级数
    cin >> json >> p;  // 读取JSON字符串和级数
    
    string current = json;  // 当前正在处理的JSON字符串，初始为完整的JSON
    
    // 循环处理每一级的键访问
    for (int i = 0; i < p; i++) {
        string key;    // 存储当前级要访问的键
        cin >> key;    // 读取键名
        
        // 构造要查找的目标字符串格式："键名":
        string target = "\"" + key + "\":";
        // 在当前JSON中找到目标字符串的位置，然后移动到值的开始位置
        int pos = current.find(target) + target.length();
        
        // 判断值的类型
        if (current[pos] == '{') {
            // 如果值是嵌套的JSON对象（以{开始）
            int count = 1;      // 用于匹配大括号，初始为1（已遇到一个{）
            int start = pos++;  // 记录嵌套对象的开始位置，并将pos移到下一个字符
            // 循环找到匹配的右大括号
            while (count > 0) {
                if (current[pos] == '{') count++;  // 遇到左大括号，计数加1
                if (current[pos] == '}') count--;  // 遇到右大括号，计数减1
                pos++;  // 移动到下一个字符
            }
            // 提取嵌套的JSON对象作为新的当前JSON
            current = current.substr(start, pos - start);
        } else {
            // 如果值是整数
            int result = 0;  // 存储解析出的整数结果
            // 循环读取连续的数字字符
            while (isdigit(current[pos])) {
                // 将字符转换为数字并累加到结果中
                result = result * 10 + (current[pos] - '0');
                pos++;  // 移动到下一个字符
            }
            cout << result << endl;  // 输出最终结果
            return 0;  // 找到整数值后结束程序
        }
    }
    
    return 0;  // 程序正常结束
}
