1597 - 买文具

题目描述

花花去文具店买了 $1$ 支笔和 $1$ 块橡皮，已知笔 $x$ 元 $/$ 支，橡皮 $y$元 $/$ 块，花花付给了老板 $n$ 元，请问老板应该找给花花多少钱？

输入

三个整数 $x、y、n$ ，分别代表了笔的单价、橡皮的单价和花花付给老板的钱（已知花花付给老板的钱 $n \ge x+y$ ）。

输出

一个整数，代表老板应该找给花花的钱。

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int main() {
    int x,y,n;
    cin >> x >> y >> n;
    cout << n - (x + y) << endl;
    return 0;
}
