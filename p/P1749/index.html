P1749 [入门赛 #19] 分饼干 II

洛谷 | 入门 | C++14 | 提交时间: 2026-06-08

算法标签：2024、O2优化、语言月赛

题目描述

老师有 NNN 块饼干，要分给 kkk 名小朋友。

每名小朋友至少拿到一块饼干，老师想让每名小朋友拿到的饼干数量都不一样多，请问老师能否实现这个目标。

输入格式

本题单个测试点内有多组测试数据。

输入共 T+1T + 1T+1 行。

输入第一行为一个整数 TTT，代表测试数据组数。
接下来 TTT 行，每行两个整数，分别为 N,kN,kN,k。

输出格式

输出共 TTT 行，依次对应 TTT 组测试数据。如果该组测试数据

  • 可以实现，输出 Yes。
  • 无法实现，输出 No。

样例

样例输入 #1

1
1 1

样例输出 #1

Yes

样例输入 #2

1
5 3

样例输出 #2

No

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int T;                     // T: 测试组数
    cin >> T;
    while (T--) {
        long long n, k;        // n: 饼干总数, k: 小朋友数
        cin >> n >> k;

        // 最少需要的饼干数：1+2+...+k = k*(k+1)/2
        long long mi = k * (k + 1) / 2;
        if (n >= mi) {
            cout << "Yes\n";
        } else {
            cout << "No\n";
        }
    }
    return 0;
}
