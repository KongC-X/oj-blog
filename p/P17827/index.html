P17827 [CSP-J 2026] 旅游 / travel（民间数据）

洛谷 | 入门 | C++14 | 提交时间: 2026-10-31

算法标签：模拟、字符串、O2优化、2026、CSP-J 入门级、分类讨论

题目描述

小 R 和小 X 准备坐高铁出门旅游。他们买了两张二等座车票，车票上写着各自的车厢号和座位号。两人希望座位相邻，这样旅途中可以坐在一起。

他们乘坐的列车由 171717 节车厢组成，车厢编号是 01 到 17。其中，01 和 16 号车厢是一等座车厢，其余车厢是二等座车厢。两人买的都是二等座车票，座位都在二等座车厢中。每节二等座车厢共有 181818 排，每排有 555 个座位。座位号由两位排号和一位大写字母组成，例如 03C 表示第 333 排 C 座。每一排的座位按照从左到右的顺序排列，座位字母依次是 A、B、C、D、F，其中 C 座与 D 座之间是过道，即每排过道左侧的座位序列是 A、B、C，右侧是 D、F。以下是一节二等座车厢的座位示意图：

:::align{center}

:::

两个座位相邻，当且仅当在同一节车厢的同一排，位于过道的同一侧，且在该侧的座位序列中相邻。

你需要帮助小 R 依次判断：

  • 两张车票对应的座位是否在同一节车厢；
  • 两张车票对应的座位是否在同一节车厢的同一排；
  • 两张车票对应的座位是否在同一节车厢的同一排，且位于过道的同一侧；
  • 两张车票对应的座位是否相邻。

输入格式

从文件 travel.in 中读入数据。

输入的第一行包含四个字符串 c1,s1,c2,s2c_1,s_1,c_2,s_2c1​,s1​,c2​,s2​，分别表示小 R 的车票上的车厢号、座位号，以及小 X 的车票上的车厢号、座位号。

输出格式

输出到文件 travel.out 中。

输出一行一个长度为 444 的 01 字符串，分别表示四个问题的答案，其中 1 代表是，0 代表否。

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    string c1, s1, c2, s2;   // c1,c2: 车厢号(两位)   s1,s2: 座位号(两位排号 + 一位字母)
    cin >> c1 >> s1 >> c2 >> s2;

    int p1, p2;              // 座位在一排中的位置：A=0 B=1 C=2 | 过道 | D=3 F=4
    if (s1[2] == 'A') p1 = 0;
    else if (s1[2] == 'B') p1 = 1;
    else if (s1[2] == 'C') p1 = 2;
    else if (s1[2] == 'D') p1 = 3;
    else p1 = 4;

    if (s2[2] == 'A') p2 = 0;
    else if (s2[2] == 'B') p2 = 1;
    else if (s2[2] == 'C') p2 = 2;
    else if (s2[2] == 'D') p2 = 3;
    else p2 = 4;

    bool q1 = (c1 == c2);                                 // 1. 同一节车厢
    bool q2 = q1 && s1[0] == s2[0] && s1[1] == s2[1];     // 2. 同一排
    bool q3 = q2 && (p1 < 3) == (p2 < 3);                 // 3. 过道同一侧
    bool q4 = q3 && abs(p1 - p2) == 1;                    // 4. 该侧序列中相邻

    cout << q1 << q2 << q3 << q4 << endl;                 // 连在一起输出四个 0/1
    return 0;
}
