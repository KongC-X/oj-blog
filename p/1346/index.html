1346 - 等比例缩放照片

题目描述

如图所示的一张照片（图①），可以把它的宽度或者高度减小从而减少照片的尺寸（如图②、③、④）。但只有等比例缩放的情况下照片才是最好看的，如图④；图②照片被压扁，图③照片被拉长。

给定图片的原始尺寸以及n组要压缩的尺寸，请问哪组压缩后的数据的宽高比最接近原始数据？如果有多组压缩尺寸的宽高比都是一样的且都是最接近原始数据的，那么输出压缩后面积最小的那组数据。

输入

第 111 行， 222 个整数 xxx 和 yyy ，代表图片的原始尺寸的宽和高

第 222 行，一个整数 nnn ，代表接下来有 nnn 组压缩后的尺寸（ n≤100n \le 100n≤100 ）

接下来 nnn 行，每行 222 个数，代表 nnn 组压缩后的宽和高（确保输入的宽 ≥\ge≥ 高）（本题所有照片的宽高均在 1∼100001 \sim 100001∼10000 之间）

输出

宽高比和原始图片最接近的宽高数据，如果有多组这样的数，输出面积最小的那组（不存在多组宽高比和原始数据一样接近且面积又一样的数据）

解题思路

AC代码

AC代码

#include <iostream>
#include <iomanip>
#include <bits/stdc++.h>
using namespace std;

struct Pic {
    int width; // 宽
    int height; // 高
    double diff; // 差值
    int area; // 面积
}a[110];

bool cmp(Pic a, Pic b) {
    if(a.diff > b.diff || (a.diff == b.diff && a.area > b.area)) {
        return false;
    } else {
        return true;
    }
}

int main() {
    int x,y,i,n;
    double z,k,mi = INT_MAX;
    cin >> x >> y;
    z = 1.0 * x / y; // 原始宽高比
    cin >> n;
    for(i=0;i<n;i++) {
        cin>>a[i].width>>a[i].height;
        k = 1.0 * a[i].width / a[i].height; // 当前宽高比
        a[i].diff = abs(z - k); // 差值
        a[i].area = a[i].width * a[i].height; // 面积
    }
    // 按照差值从小到大排序,差值一样按照面积从小到大
    sort(a, a + n, cmp);
    cout << a[0].width << " " << a[0].height << endl;
}
