1451 - n个一位数能够组成的最大数

题目描述

请问 nnn 个一位数能够组成的最大的整数是多少。

比如，nnn =333 ，333 个整数为 1、3、91、3、91、3、9 ，那么组成的最大整数是 931931931 。

比如， nnn = 444 ， 444 个整数为 2、8、0、62、8、0、62、8、0、6 ，那么组成的最大整数是 862086208620 。

输入

第一行为一个整数 nnn （n<10n \lt 10n<10）。

第二行为 nnn 个一位数。

输出

一行，包含一个组成的最大整数。

解题思路

AC代码

AC代码

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

bool cmp(int a,int b) {
    return a > b ? true : false;
}

int main() {
    int n,i;
    cin >> n;
    string s,s1;
    for(i = 0;i < n;i++) {
        cin >> s1;
        s += s1;
    }
    sort(s.begin(),s.end(),cmp);
    cout << s;
}
