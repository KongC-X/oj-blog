B3699 [语言月赛202301] 就要 62

洛谷 | 入门 | C++14 | 提交时间: 2026-09-13

算法标签：2023、O2优化、循环结构、语言月赛

题目描述

给你一个整数 $x$，你需要判断，这个整数中是否出现过数字 $62$ 或者能够被 $62$ 整除。如果是，输出 Yes，否则输出 No 即可。

输入格式

输入共一行，为一个整数 $x$。

输出格式

输出共一行。

如果 $x$ 中出现过数字 $62$ 或者能够被 $62$ 整除，输出一行 Yes，否则输出一行 No。

样例

样例输入 #1

11624```

**样例输出 #1**

Yes```

样例输入 #2

12214```

**样例输出 #2**

Yes```

样例输入 #3

16124```

**样例输出 #3**

No```

样例输入 #4

62```

**样例输出 #4**

Yes```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3699 [语言月赛202301] 就要 62
     * 题意：判断整数 x 中是否出现过子串 "62"，或者 x 能否被 62 整除。
     * 思路：
     * 1. 用字符串读入 x（最大 10^18，用 long long 也可，但字符串方便查子串）。
     * 2. 将字符串转为 long long 判断能否被 62 整除。
     * 3. 用 s.find("62") 判断是否包含连续子串 "62"。
     * 4. 满足任一条件输出 Yes，否则输出 No。
     */
    string s;
    cin >> s;

    long long x = stoll(s);   // 转为整数，x ≤ 10^18，long long 安全

    if (x % 62 == 0 || s.find("62") != string::npos) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }

    return 0;
}
