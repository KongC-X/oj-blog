1856 - 输出米字形

题目描述

根据输入的正整数n (1 米字形由一个(2n-1)*(2n-1)的矩阵组成，矩阵包含从大写A开始的n个字母

例如:n=3时，包含A,B,C；n=4时，包含A,B,C,D。

矩阵的正中间为n个字母中字典序最大的那个，从这个字母开始，沿着西北、正北、东北、正西、正东、西南、正南、东南八个方向各有一条由大写字母组成的直线。并且直线上的字母按字典序依次减小，直到大写字母A。

矩阵的其它位置用英文句号．填充。

输入

输入一个整数n（n<=30）

输出

按题意输出图形

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
char a[60][60];
int n; 
int main(){
    cin>>n;
    int i,j,m = 2*n-1;
    //左上角 
    for(i=1;i<=n;i++){
        for(j=1;j<=n;j++){
            if(i==j) a[i][j] = char(i-1+'A');
            else if(i==n) a[i][j] = char(j-1+'A');
            else if(j==n) a[i][j] = char(i-1+'A');
            else a[i][j] = '.';
        }
    }
    //右上角 
    for(i=1;i<=n;i++){
        for(j=n+1;j<=m;j++){
            a[i][j] = a[i][m-j+1];      
        }
    }
    //左下角 
    for(i=n+1;i<=m;i++){
        for(j=1;j<=n;j++){
            a[i][j] = a[m-i+1][j];      
        }
    }
    //右下角 
    for(i=n+1;i<=m;i++){
        for(j=n+1;j<=m;j++){
            a[i][j] = a[i][m-j+1];      
        }
    }
    //输出 
    for(i=1;i<=m;i++){
        for(j=1;j<=m;j++){
            cout<<a[i][j];    
        }   
        cout<<endl;
    }
    return 0;
}
