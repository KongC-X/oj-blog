2005 - 选班委

题目描述

小 TTT 和他的小伙伴们到 CZCZCZ 中学的创新实验班报到后的第一件事就是选班委，班主任 RRR 老师走上讲台宣布了选举办法，首先让全班 404040 位同学依次上讲台做自我介绍，然后按照 职位一个一个依次进行选举，先选班长，再选学习委员……，选举办法是每人投一票，谁 的票数最高就选谁担任这个职位，最后围棋高手小 WWW 颇具大将风范被选为班长，学神小 ZZZ 当选为学习委员那是众望所归，小 SSS 则有天生一副好嗓子，不但歌唱得好，并且能将多种 动物的叫声模仿得惟妙惟肖，因此当选为文体委员。小 TTT 同学在本次选举中负责计票，他 觉得手工计票太慢了，且容易出错，因此想请你编一个程序实现机器计票功能。

这个程序 要能实现以下功能：全班共有 nnn 个同学，依次用 111 到 nnn 编号，共有 mmm 个人（包括班主任和 任课老师等）参与了投票，每张选票上写有一个同学的编号，得票最多的同学当选。

输入

输入数据第一行包含两个用空格隔开的正整数 nnn 和 mmm，其中 n≤200n \le 200n≤200，m≤2000m \le 2000m≤2000。

第二行有 mmm 个用空格隔开的不超过 nnn 的正整数，表示这 mmm 张选票上所写的编号。

输出

输出得票最多的那个同学的编号。如果同时有两名以上同学得票最多，输出编号最小的那个同学的编号。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int a[210],n,x,ma,m;
int main(){ 
    //n人参加竞选，m张投票
    cin>>n>>m; 
    int i;
    for(i=1;i<=m;i++){
        cin>>x;
        a[x]++;//数组计数法 
    }
    ma=0;
    for(i=1;i<=n;i++){
        if(a[i]>a[ma]){
            ma=i;
        }  
    }
    cout<<ma;
}
