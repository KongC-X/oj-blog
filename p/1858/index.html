1858 - 数组查找及替换

题目描述

给定某整数数组和某一整数 bbb 。

要求删除数组中可以被 bbb 整除的所有元素，同时将该数组各元素按从小到大排序。如果数组元素数值在 'AAA' 到 'ZZZ' 的 ASCII 之间，替换为对应字母。

元素个数不超过 100100100，bbb 在 111 至 100100100 之间。

输入

第一行为表示数组元素个数 NNN 和整数 bbb。(1≤N≤1001 \le N \le 1001≤N≤100)

第二行为数组各个元素。

输出

按照要求输出。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
using namespace std;

int a[110];
int c[110];
int main(){
    int n,b,m=0;
    cin>>n>>b;

    for(int i=0;i<n;i++){
        cin>>a[i];
    }
    //从a数组中寻找b的倍数,如果不是b的倍数存入c数组
    for(int i=0;i<n;i++){
        if(a[i]%b!=0){
            c[m] = a[i];
            m++; 
        } 
    }
    //默认从小到大排序
    sort(c,c+m);
    
    for(int i=0;i<m;i++){
        if(c[i]>=65&&c[i]<=90){
            cout<<char(c[i])<<" ";	
        }else{
            cout<<c[i]<<" ";
        }
        
    }
    
    return 0;
}
