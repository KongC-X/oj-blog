1122 - 计算表达式

题目描述

表达式的形式如：3+5∗6−43+5*6-43+5∗6−4 其中, 运算数为一位整数,运算符为 +、−、∗+、-、*+、−、∗三种，且运算符没有优先级的区分，一律自左向右计算。
如上例的计算过程为：3+5∗6−4=8∗6−4=48−4=443+5*6-4=8*6-4=48-4=443+5∗6−4=8∗6−4=48−4=44

输入

一行，即表达式字符串。（长度小于 100100100）

输出

一个整数，即表达式的计算结果（结果在−20000-20000−20000至200002000020000之间）

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s,s1,s2;
    getline(cin,s);
    int i,a,b;
    s1 = s[0];
    for(i = 1;i < s.size();i+=2) {
        if(s[i] == '+') {
            a = stoi(s1);
            s2 = s[i+1];
            b = stoi(s2);
            s1 = to_string(a+b);
        } else if(s[i] == '-') {
            a = stoi(s1);
            s2 = s[i+1];
            b = stoi(s2);
            s1 = to_string(a-b);
        } else if(s[i] == '*') {
            a = stoi(s1);
            s2 = s[i+1];
            b = stoi(s2);
            s1 = to_string(a*b);
        }
    }
    cout << s1 << endl;
}
