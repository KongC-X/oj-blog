1220 - 买糕点

题目描述

妈妈给了小明 nnn 元，给小明同学去面包店买糕点吃，小明非常喜欢吃切片面包和蛋挞，今天切片面包 xxx 元一件（一包），蛋挞 yyy 元一件（一盒）；小明想花光 nnn 元买这两样糕点，而且每样都至少买一件，请问，小明可以采购的方案中，能够买最多面包的方案是什么？

比如，100100100 元，面包 151515 元/件，蛋挞 101010 元/件，那么可行的购买方案有：

222 件面包 777 件蛋挞

444 件面包 444 件蛋挞

666 件面包 111 件蛋挞

而上述方案中，面包最多的购买方案是： 666 件面包 111 件蛋挞，因此输出：666 111

输入

三个变量：nnn xxx yyy，分别代表总金额，面包的单价和蛋挞的单价！

输出

两个数，分别代表采购方案中能够买到最多面包的件数和蛋挞的件数！

解题思路

AC代码

AC代码

# include <iostream>
using namespace std;

int main() {
    int n,x,y,i,j;
    cin >> n >> x >> y;
    for(i = n/x;i >= 1;i--){
        for(j = 1;j <= n/y;j++){
            if(i*x+j*y==n){
                cout << i << " " << j << endl;
                return 0;
            }
        }
    }
}
