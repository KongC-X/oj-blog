1612 - 零花钱问题

题目描述

甲乙丙三位同学出去购买文具，甲带了 $n$ 元，乙比甲多带了 $8$ 元，丙比乙少带了 $2$ 元。

请输出甲乙丙各带了多少钱，以及平均每人带了多少钱？

输入

输入一个整数 $n$ 代表甲带的金额。

输出

输出有 $4$ 行：

第 $1$ 行输出甲带的金额。

第 $2$ 行输出乙带的金额。

第 $3$ 行输出丙带的金额。

第 $4$ 行输出平均每人带了多少钱，平均值保留 $1$ 位小数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    //定义变量n代表甲带的金额 
    int n; 
    //输入n 
    cin>>n;
    cout<<n<<endl;
    cout<<n+8<<endl;
    cout<<n+8-2<<endl;
    cout<<fixed<<setprecision(1)<<(n+n+8+n+8-2)/3.0;
    return 0;
}
