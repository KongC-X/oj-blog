1859 - 完数判断

题目描述

一个数如果恰好等于它的因子之和，这个数就称 为“完数”。

例如，666 的因子为 1、2、31、2、31、2、3 ，而 6＝1＋2＋36＝1＋2＋36＝1＋2＋3 ，因此 666 就是“完数”。又如，282828 的因子为 1、2、4、7、141、2、4、7、141、2、4、7、14 ，而 28＝1＋2＋4＋7＋1428＝1＋2＋4＋7＋1428＝1＋2＋4＋7＋14 ，因此 282828 也是“完数”。

编写一个程序，判断用户输入的一个数是否为“完数”

输入

输入只有一行，即一个整数。

输出

输出只有一行，如果该数为完数，输出 yes，否则输出no。

解题思路

AC代码

AC代码

#include <iostream>
#include <cmath>
using namespace std;

// 求一个数的因子和
 int sumOfFactors(int n) {
    int sum = 0;
    for (int i = 1; i <= sqrt(n); i++) {
        if (n % i == 0) {
            if(i != n / i) {
                sum = sum + i + n / i;
            } else {
                sum = sum + i;
            }
        }
    }
    sum = sum - n; // 减去 n 本身
     return sum;
}

int main() {
    int n;
    cin >> n;
    if(sumOfFactors(n) == n) {
        cout << "yes" << endl;
    } else {
        cout << "no" << endl;
    }
}
