B2079 求出 e 的值

洛谷 | 入门 | C++14 | 提交时间: 2026-07-04

题目描述

利用公式 $e=1+1/1!+1/2!+1/3!+ \cdots +1/n!$，求 $e$ 的值，要求保留小数点后 $10$ 位。

输入格式

输入只有一行，该行包含一个整数 $n$，表示计算 $e$ 时累加到 $1/n!$。

输出格式

输出只有一行，该行包含计算出来的 $e$ 的值，要求打印小数点后 $10$ 位。

样例

样例输入 #1

10```

**样例输出 #1**

2.7182818011```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin >> n;

    double e = 1.0;            // 第一项 1
    long long fact = 1;        // 阶乘值，初始为 1!
    for (int i = 1; i <= n; i++) {
        fact *= i;             // 计算 i!
        e += 1.0 / fact;       // 累加 1/i!
    }

    cout << fixed << setprecision(10) << e << endl;
    return 0;
}
