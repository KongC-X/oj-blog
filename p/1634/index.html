1634 - 游戏任务

题目描述

小明接受了一个游戏任务，在 202020 分钟内从 AAA 地到 BBB 地！途中会出现 333 个难题，要求小明用最快的时间解答出来？

请编程求小明能不能完成任务，能的输出 “ YES ” 不能的输出 “ NO ” 。

输入

同一行输入 c,s,a1,a2,a3c,s,a1,a2,a3c,s,a1,a2,a3 五个数。

（ ccc 代表 AAA 、BBB 两地的距离， sss 代表小明的速度， a1,a2,a3a1,a2,a3a1,a2,a3 代表解答问题的时间！）

输出

一行，能的输出 能的输出 “ YES ” 不能的输出 “ NO ” 。

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    int c,s,a1,a2,a3;
    cin>>c>>s>>a1>>a2>>a3;
    //判断总用时是否大于20分钟 
    if((c*1.0/s+a1+a2+a3)>20) {
        cout<<"NO";
    }else{
        cout<<"YES";
    }
    return 0;
}
