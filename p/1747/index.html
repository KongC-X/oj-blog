1747 - 连续递增或递减数

题目描述

请问 100∼n100 \sim n100∼n 中连续递增或者连续递减的 333 位数有总和是多少，有多少个？

连续递递增或递减指的是三位数相邻的两位之间都是递增的或者是递减的。

比如：139139139 ，三位数就是连续递增的，因为 1<31 \lt 31<3 ， 3<93 \lt 93<9；

再比如：931931931，三位数就是连续递减的，因为 9>39 \gt 39>3 ， 3>13 \gt 13>1；

输入

一个三位的整数 nnn 。

输出

第 111 行输出满足条件的数的总和是多少。

第 222 行输出满足条件的数有多少个。

AC代码

#include <bits/stdc++.h>
using namespace std;

int main(){
    int n,i,sum=0,y=0,b,s,g;
    cin>>n;
    //遍历100到n的所有三位数 
    for(i=100;i<=n;i++){
        b=i/100;
        s=i/10%10;
        g=i%10;
        //连续递增或者连续递减
        if((b<s&&s<g)||(b>s&&s>g)){
            sum=sum+i;
            y++;
        }
    }
    cout<<sum<<endl<<y;
    return 0;
}
