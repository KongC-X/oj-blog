B4388 [语言月赛 202508] 共享航班

洛谷 | 普及| C++14 | 提交时间: 2026-08-08

算法标签：并查集、2025、字符串（入门）、语言月赛

题目背景

一趟航班的机票可能由多个航空公司（简称航司）销售。每一个航司在销售该航班机票时，都会给该航班一个专属于该航司的代码。例如，某趟航班由 CA 和 ZH 两家公司售票，其航班号分别为 CA1234 和 ZH4321，但是这两个航班号对应的其实指的是同一趟航班，只是不同航司对该航班的编号不同。这样的航班被称为代码共享航班。

请注意本题设定的代码共享条件、航班代码格式与生活实际略有不同，请以题目要求为准。

题目描述

扶苏获取了 nnn 条航线数据，每条数据都是一个字符串，包括一趟航班的代码、出发地、目的地、起飞时间。一条数据的格式是：

CODE-DEP-DES-HH:MM

其中：

  • CODE 是该航班的代码，该代码是一个长度为 666 的字符串，前两位是字母，表示所属航司，后四位是数字，是航司给该航班的代号。同一航司的代码前两位相同，不同航司的代码前两位不同，因此可以用航班号前两位来区分和表示航司。例如 CA1234，SC9876。
  • DEP 是一个长度为 333 的字符串，表示飞机的出发机场代码。不同机场的代码不同，例如 PEK 表示北京首都国际机场。
  • DES 是一个长度为 333 的字符串，表示飞机的到达机场代码。不同机场的代码不同，例如 PVG 表示上海浦东国际机场。
  • HH:MM 是一个长度为 555 的字符串，H 和 M 均是 0∼90 \sim 90∼9 的数字，表示起飞的小时和分钟，不足两位时补 0。例如：09:21 表示 999 点 212121 分。

下面是一个例子：

CA1501-PEK-PVG-08:30
SC5306-PEK-PVG-08:30
ZH2468-PEK-PVG-08:30
CZ1357-PEK-PVG-08:30
MU9197-SHA-TFU-08:00

依次表示：

  • CA 公司售卖的代号为 CA1501 的航班，从 PEK 飞往 PVG，起飞时间 08:30。
  • SC 公司售卖的代号为 SC5306 的航班，从 PEK 飞往 PVG，起飞时间 08:30。
  • ZH 公司售卖的代号为 ZH2468 的航班，从 PEK 飞往 PVG，起飞时间 08:30。
  • CZ 公司售卖的代号为 CZ1357 的航班，从 PEK 飞往 PVG，起飞时间 08:30。
  • MU 公司售卖的代号为 MU9197 的航班，从 SHA 飞往 TFU，起飞时间 08:00。

同时，扶苏还知道有些航司之间有联盟关系，每个航司最多属于一个联盟。两条数据是共享航班当且仅当：

  • 它们的公司属于同一个联盟。
  • 它们起飞、降落机场分别相同。
  • 它们起飞时间相同。

可能有多个航班两两之间均构成代码共享关系，此时它们对应同一趟实际航班。

例如，扶苏知道 CA 和 SC 和 ZH 同属于一个联盟，而 CZ 不属于该联盟，所以上面例子里前三条是共享航班，对应同一趟实际的航班，但前三条和第四条不是共享航班。而第五条和前四条信息的起降地、时间均不同，因此也不和前四条构成代码共享关系。上面例子中共有三趟实际的航班。

已知共有 mmm 个联盟，属于第 iii 个联盟的航司有 cic_ici​ 个，其代码（航班号前缀）分别是 si,1,si,2,…sm,cis_{i,1}, s_{i,2}, \dots s_{m, c_i}si,1​,si,2​,…sm,ci​​。同时给定 nnn 条航班信息，你要求出这 nnn 条信息对应了多少实际的航班。

注意：

  1. 可能有航司不属于任何联盟。
  2. 同一航司在同一时间、同一起降地可能有多条航线数据，此时它们对应同一趟实际航班。

输入格式

第一行是两个整数，表示信息数 nnn 和联盟数 mmm。

接下来 mmm 行，表示一个联盟的信息，按如下格式输入：

  • 首先是一个整数，表示该联盟的航司数 cic_ici​。
  • 接下来有 cic_ici​ 个长度为 222 的字符串，表示该联盟每个航司的代码（航班号前缀）。

接下来 nnn 行，每行一个字符串，表示一条航班信息，其具体格式见【题目描述】部分。

输出格式

输出一行一个整数，表示共有多少个实际航班。

样例

样例输入 #1

7 2
3 CA ZH SC
2 CZ MF
CA1501-PEK-PVG-08:30
CZ1357-PEK-PVG-08:30
SC5306-PEK-PVG-08:30
ZH2468-PEK-PVG-08:30
MF1357-PEK-PVG-08:30
MU9197-SHA-TFU-08:00
CA9197-SHA-TFU-08:00```

**样例输出 #1**

4```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int n, m;
int b[676];          // 航司代码（2字母）→ 联盟编号，-1表示无联盟
string p[105], q[105], r[105]; // 出发地、目的地、时间
int g[105];          // 每条航班的联盟编号
int fa[105];         // 并查集父节点

int fd(int x) {
    return fa[x] == x ? x : fa[x] = fd(fa[x]);
}

void mg(int x, int y) {
    int rx = fd(x), ry = fd(y);
    if (rx != ry) fa[rx] = ry;
}

int main() {
    /*
     * 题目类型：并查集 + 字符串分割
     * 思路：
     * 1. 用 b[676] 将航司代码（如 CA）映射到联盟编号（0~m-1），无联盟为 -1。
     * 2. 对每条航班，按 '-' 分割出 CODE、DEP、DES、时间，记录联盟编号、出发地、目的地、时间。
     * 3. 两两判断：若同属一个联盟（且不是 -1），且出发地、目的地、时间都相同，则合并。
     * 4. 统计并查集中根节点个数，即为实际航班数。
     */

    cin >> n >> m;
    memset(b, -1, sizeof(b));

    // 读联盟
    for (int i = 0; i < m; i++) {
        int c;
        cin >> c;
        for (int j = 0; j < c; j++) {
            string s;
            cin >> s;
            int idx = (s[0] - 'A') * 26 + (s[1] - 'A');
            b[idx] = i;
        }
    }

    // 读航班
    for (int i = 0; i < n; i++) {
        string s;
        cin >> s;

        // 分割字符串（格式固定：CODE-DEP-DES-HH:MM）
        int pos1 = s.find('-');
        int pos2 = s.find('-', pos1 + 1);
        int pos3 = s.find('-', pos2 + 1);

        string code = s.substr(0, pos1);               // 航班代码
        p[i] = s.substr(pos1 + 1, pos2 - pos1 - 1);    // 出发地
        q[i] = s.substr(pos2 + 1, pos3 - pos2 - 1);    // 目的地
        r[i] = s.substr(pos3 + 1);                     // 时间

        // 取出航司代码（前两位）
        int idx = (code[0] - 'A') * 26 + (code[1] - 'A');
        g[i] = b[idx];          // 联盟编号（可能 -1）

        fa[i] = i;              // 并查集初始化
    }

    // 合并共享航班
    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            if (g[i] == -1 || g[j] == -1) continue;
            if (g[i] != g[j]) continue;
            if (p[i] == p[j] && q[i] == q[j] && r[i] == r[j]) {
                mg(i, j);
            }
        }
    }

    // 统计实际航班数
    int ans = 0;
    for (int i = 0; i < n; i++) {
        if (fd(i) == i) ans++;
    }

    cout << ans << endl;
    return 0;
}
