1398 - 奇偶统计

题目描述

在一个 nnn 行 mmm 列的二维数组中，有若干奇数和偶数，请编程统计出这个二维数组中，奇数和偶数分别有多少个？

输入

第一行是两个整数 nnn 和 mmm （ nnn 和 mmm 都是 2∼1002 \sim 1002∼100 之间的整数），代表接下来的二维数组有 nnn 行 mmm 列。

接下来 nnn 行，每行有 mmm 个整数。（这些整数都是 0∼99990 \sim 99990∼9999 之间的整数）

输出

两个整数用空格隔开，分别代表二维数组中奇数、偶数的个数。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    //s1表示奇数的个数,s2表示偶数的个数 
    int n,m,a[101][101],i,j,s1=0,s2=0;
    cin>>n>>m; 
    //读入二维数组
    for(i=0;i<n;i++){
        for(j=0;j<m;j++){
            cin>>a[i][j];
        }
    }
    //遍历二维数组
    for(i=0;i<n;i++){
        for(j=0;j<m;j++){
            //判断是偶数还是奇数 
            if(a[i][j] % 2 == 0){
                s2++;
            }else{
                s1++;
            }
        }
    }
    cout<<s1<<" "<<s2;
}
