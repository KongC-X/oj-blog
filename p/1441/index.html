1441 - 骑士牛

题目描述

John用他的一头母牛和Don先生交换了一头“骑士牛”。这头牛有一个独特的能力——在牧场中能像中国象棋中的马一样跑跳（会中国象棋吗？不会？注意：本题不考虑马被“蹩脚”的情况）。

当然，这头牛不能跳到岩石或树上，不过能跳到有牧草的地方。这儿有一个宽为 XXX，高为 YYY 的矩形牧场(1≤X≤150;1≤Y≤1501 ≤ X ≤ 150; 1 ≤ Y ≤ 1501≤X≤150;1≤Y≤150)。 “骑士牛”和其它牛一样喜欢干草。给你一张包含“骑士牛”出发地和树、岩石、灌木或其它障碍物及大包干草等位置信息的地图，确定“骑士牛”得到干草最少要跳几“跳”。

地图中“骑士牛”出发地用 K表示；障碍物用 * 表示，牧草用 . 表示，干草所在地用 H 表示。这儿有一个示例地图：

骑士牛得到干草的最少步骤在下图中用 ABC…… 表示，最少要跳 555 “跳”（其它的路径可能超过 555 “跳”）：

输入

第 111 行: 两个空格隔开的整数: XXX 和 YYY。

第 2..Y+12..Y+12..Y+1 行: 第 Y−i+2Y-i+2Y−i+2 行包含 XXX 个没有空格的字符（就像上面的地图一样）：表示第 iii 行的地图。

输出

一个单独的整数表示最少的得到干草的“跳”数。所有的数据都能得到干草。

解题思路

AC代码

#include<iostream>
#include<bits/stdc++.h>
using namespace std;

// a存储矩阵，q存储队列（遍历过的点）
char a[200][200]; // 迷宫
int q[40000][4]; // 队列
int n,m,i,j,tx,ty;
int s1,s2,e1,e2; // 起始点
int head = 1,tail = 1; // head：头指针，tail：尾指针
// 八个方向
int fx[9] = {0,-1,-2,-2,-1,1,2,2,1};
int fy[9] = {0,-2,-1,1,2,2,1,-1,-2};

int main() {
    // n行m列
    cin >> m >> n;
    for(i = 1;i <= n;i++) {
        for(j = 1;j <= m;j++) {
            cin >> a[i][j];
            // 找到出发点和终点
            if(a[i][j] == 'K') {
                s1 = i;
                s2 = j;
            } else if(a[i][j] == 'H') {
                e1 = i;
                e2 = j;
            }
        }
    }

    // 1,1点存入队列，以1，1为head访问四个方向
    q[1][1] = s1;
    q[1][2] = s2;
    q[1][3] = 0; // 记录步数
    // 当head <= tail时，说明队列还有点没有尝试标记过四个方向
    while(head <= tail) {
        // 尝试访问head的八个方向
        for(i = 1;i <= 8;i++) {
            // 从head对应的点加上四个方向的变化量得到新的点
            tx = q[head][1] + fx[i];
            ty = q[head][2] + fy[i];
            // 如果新的点在矩阵范围内，且没有被标记过，则标记
            if(a[tx][ty] == '.' || a[tx][ty] == 'H') {
                a[tx][ty] = '*'; // 标记代表走过了
                // 新的点存入队列，以新点为head访问四个方向
                tail++;
                q[tail][1] = tx;
                q[tail][2] = ty;
                q[tail][3] = q[head][3] + 1; // 步数加1

                if(tx == e1 && ty == e2) { // 如果到达终点，输出步数
                    cout << q[tail][3] << endl;
                }
            }
        }
        head++; // head指向队列头的下一个点
    }
}
