1393 - 与7无关的数？

题目描述

一个整数，如果这个数能够被 777 整除，或者其中有一位是 777，我们称为这个数是与 777 有关的数。比如： 141414 能被 777 整除，171717 有一位为 777 ，这两个数都是与 777 有关的数。

请你编程求出 1∼n（n≤999）1 \sim n（n \le 999）1∼n（n≤999） 中，与 777 无关的数的总和是多少？

比如 1∼101 \sim 101∼10 中与 777 无关的数的和为：1+2+3+4+5+6+8+9+10=481+2+3+4+5+6+8+9+10=481+2+3+4+5+6+8+9+10=48 。

输入

一个整数 n（n≤999）n（n \le 999）n（n≤999） 。

输出

1∼n1 \sim n1∼n 中与 777 无关的数的总和。

AC代码

AC代码

# include <iostream>
using namespace std;

int main(){
    int i,n,a,b,c,s = 0;
    cin >> n;
    for(i = 1;i <= n;i++) {
        a = i / 100;
        b = i % 100 / 10;
        c = i % 10;
        if(i % 7 != 0 && a != 7 && b != 7 && c != 7) {
            s+=i;
        }
    }
    cout << s;
}
