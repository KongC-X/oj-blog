1838 - 分解质因数

题目描述

求出区间 $[a,b]$ 中所有整数的质因数分解。
提示

先筛出所有素数，然后再分解。
数据规模和约定
$ 2 \leq a \leq b \leq 10000 $

输入

输入两个整数 $a，b$。

输出

每行输出一个数的分解，形如 $k=a1a2a3...$ $(a1 \leq a2 \leq a3...，k $也是从小到大的)(具体可看样例)

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    int a,b,t;
    cin>>a>>b;
    //遍历从a到b的整数 
    for(int i=a;i<=b;i++){
        cout<<i<<"=";
        t=i;//把i赋值给t,t用作查找质因子,方便处理 
        int j=2;//从2开始查找质因子
        //查找质因子直到t变成1 
        while(t != 1){ 
            if(t%j==0){
                cout<<j;
                t=t/j;
                if(t!=1){
                    cout<<"*";
                }
            }else{
                j++;//如果不能整除质因子+1 
            }
        }
        cout<<endl;
    } 
    return 0;
}
