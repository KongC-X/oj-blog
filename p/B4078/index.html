B4078 [CSP-X2019 山东] 统计成绩

洛谷 | 入门 | C++14 | 提交时间: 2026-08-10

算法标签：2019、山东、CSP-X 小学组

题目描述

$n$ 位同学参加了期中考试，考试共有 $m$ 门课程。

考试结束之后，老师想知道：每位同学有几门课程达到或超过了课程的班级平均分？

现在，请你帮忙统计一下。

输入格式

第一行，两个正整数 $n,m$，$n$ 表示学生总人数，$m$ 表示课程数量。

接下来 $n$ 行，每行 $m$ 个整数，表示一位同学的成绩。

输出格式

共 $n$ 行，每行一个整数，表示该同学达到或超过平均分的课程数量。

样例

样例输入 #1

5 3 
81 80 86  
55 74 79  
92 47 99  
50 65 41  
42 61 74```

**样例输出 #1**

3
2
2
0
0```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：简单统计
     * 思路：
     * 1. 读入 n, m 以及成绩矩阵 a[n][m]。
     * 2. 计算每门课程的平均分 avg[j]（浮点数）。
     * 3. 对每位同学，统计该同学成绩 >= avg[j] 的课程数。
     */
    int n, m;          // n: 人数, m: 课程数
    cin >> n >> m;

    int a[105][25];    // 成绩矩阵
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> a[i][j];
        }
    }

    double avg[25] = {0};   // 每门课平均分
    for (int j = 0; j < m; j++) {
        int sum = 0;
        for (int i = 0; i < n; i++) {
            sum += a[i][j];
        }
        avg[j] = 1.0 * sum / n;
    }

    for (int i = 0; i < n; i++) {
        int cnt = 0;
        for (int j = 0; j < m; j++) {
            if (a[i][j] >= avg[j]) cnt++;
        }
        cout << cnt << endl;
    }

    return 0;
}
