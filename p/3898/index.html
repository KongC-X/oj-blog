3898 - 区间排序

题目描述

小杨有一个包含 nnn个正整数的序列 aaa 。

小杨计划对序列进行多次升序排序，每次升序排序小杨会选择一个区间 $[l,r]
$(l≤r)(l \le r)(l≤r) 并对区间内所有数字，即 al,al+1,…,ara_l,a_{l+1},\dots,a_ral​,al+1​,…,ar​进行升序排序。每次升序排序会在上一次升序排序的结果上进行。

小杨想请你计算出多次升序排序后的序列。

输入

第一行包含一个正整数 nnn，含义如题面所示。

第二行包含 nnn 个正整数 a1,a2,…,ana_1,a_2,\dots,a_na1​,a2​,…,an​ ，代表序列。

第三行包含一个正整数 qqq，代表排序次数。

之后 qqq行，每行包含两个正整数 lil_ili​，rir_iri​ ，代表将区间 [li,ri][l_i,r_i][li​,ri​] 内所有数字进行升序排序。

输出

输出一行包含 nnn 个正整数，代表多次升序排序后的序列。

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;
int a[101];
int main()
{
    int n;
    cin>>n; //输入
    for(int i=1;i<=n;i++)cin>>a[i];
    int q;
    cin>>q;
    for(int i=1;i<=q;i++)
    {
        int l,r;
        cin>>l>>r;
        sort(a+l,a+r+1); //排序
    }
    for(int i=1;i<=n;i++)cout<<a[i]<<" "; //输出
}
