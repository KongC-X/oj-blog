1721 - 输出个位为5或者个位为8数

题目描述

请从小到大输出 1∼n1 \sim n1∼n 中所有个位为 555 或者个位为888 的所有的整数，每行 111 个。

比如，假设 n=20n=20n=20，那么满足条件的数输出如下：

555

888

151515

181818

输入

一个整数 nnn 。

输出

1∼n1 \sim n1∼n 中所有满足条件的整数。

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin>>n;
    int i;
    //遍历1到n的所有整数 
    for(i=1;i<=n;i++){
        //判断个位为5或者个位为8,则输出 
        if(i%10==5||i%10==8){
            cout<<i<<endl;
        }
    }
    return 0;
}
