1547 - 小X转进制

题目描述

小X喜欢研究进制转换。

在了解了进制转换的一般流程后，小 X 突然想起了以前学过的回文数（正着读倒着读都一样的数），于是开始思考一个奇怪的问题：111 到 NNN 中有多少个整数的平方在 MMM 进制下是回文数呢？

小X随手列了几个：

  • 222 的平方 444 ，101010 进制表示为 444，是回文数；

  • 333 的平方 999，222 进制表示为 100110011001，是回文数；

  • 904690469046 的平方 818301168183011681830116，161616 进制表示为 4E0A0E44E0A0E44E0A0E4，是回文数。

小X觉得要全列出来太难了，希望你帮帮他。

输入

第一行包含用一个空格隔开的两个整数 NNN，MMM。

输出

第一行包含一个整数，表示满足要求的整数个数。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 判断一个数字是否回文，第一个参数是这个数字，第二个参数是进制
bool huiwen(int n,int x){
    int a[1000] = {0},i = 0;
    while(n){
        a[i++] = n % x;
        n /= x;
    }
    for(int j = 0;j < i / 2;j++){
        if(a[j] != a[i - j - 1]) return false;
    }
    return true;
}

int main(){
    int n,i,m,s = 0;
    cin >> n >> m;
    for(i = 1;i <= n;i++){
        if(huiwen(i * i,m)){
            s++;
        }
    }
    cout << s << endl;
}
