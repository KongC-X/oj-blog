1964 - 标准零件

题目描述

工厂生产了 nnn 个圆形零件，每个零件有一个半径，判断零件是否合格的方法是，给定一个标准零件的半径值，如果生产出来零件的半径和标准零件半径值的差 ≤5\le 5≤5，那么该零件就是合格的！

比如：工厂生产了 555 个零件，半径分别是797979 979797 115115115 969696 959595 ，标准零件的半径值是 959595 ，按照判断标准，有 333 个零件是合格的，半径分别是：979797 969696 959595。

请你编程计算一下，工厂生产的 nnn 个零件中，有多少个零件是合格的。

输入

第一行：一个整数 nnn 代表有 nnn 个数。（10≤n≤10010 \le n \le 10010≤n≤100）

第二行：nnn 个整数，代表零件的半径。（10≤10 \le10≤ 半径的值 ≤1000\le 1000≤1000）

第三行：一个整数xxx，代表标准零件的半径。（10≤10 \le10≤ 标准零件的半径值 ≤1000\le 1000≤1000）

输出

一个整数，代表合格零件的个数。

AC代码

AC代码

#include <iostream>
#include <cmath> // 用于abs函数
using namespace std;

int main() {
    int n;
    cin >> n;
    
    int parts[n];
    for (int i = 0; i < n; i++) {
        cin >> parts[i];
    }
    
    int x;
    cin >> x;
    
    int count = 0;
    for (int i = 0; i < n; i++) {
        if (abs(parts[i] - x) <= 5) {
            count++;
        }
    }
    
    cout << count << endl;
    return 0;
}
