B4406 [语言月赛 202509] 蓝玫瑰

洛谷 | 入门 | C++14 | 提交时间: 2026-08-08

算法标签：2025、循环结构、语言月赛

题目背景

有人给小 S 送了 666666 朵玫瑰花，小 S 很开心。^^

题目描述

小 S 收到了一束玫瑰花，里面有 aaa 朵红色的，bbb 朵粉色的，ccc 朵白色的。保证 a,b,ca,b,ca,b,c 为偶数。

他可以从中选出不超过 a2\frac{a}{2}2a​ 朵红色玫瑰花，不超过 bbb 朵粉色玫瑰花，至少 c2\frac{c}{2}2c​ 朵白色玫瑰花组成一束新的玫瑰花。

如果这束新的玫瑰花满足以下条件，他认为这束新的玫瑰花是浪漫的：

  • 至少包含一支玫瑰花。空的玫瑰花束显然并不浪漫。
  • 假设选出了 a′a'a′ 朵红色玫瑰花，b′b'b′ 朵粉色玫瑰花，c′c'c′ 朵白色玫瑰花，那么：
    • a′≤b′a'\le b'a′≤b′，且 c′≤b′c'\le b'c′≤b′。因为小 S 喜欢粉色。
    • c′=0c'=0c′=0 或 b′=0b'=0b′=0，否则要求 a′c′≤c′b′\frac{a'}{c'}\le \frac{c'}{b'}c′a′​≤b′c′​。因为小 S 希望颜色不要太艳丽。
    • a′≤10a'\le 10a′≤10。因为小 S 不太喜欢红色。

请你告诉小 S，有多少种不同的新玫瑰花束是浪漫的。两束玫瑰花不同，当且仅当其中存在一种玫瑰花的数量不同。

输入格式

一行三个整数，a,b,ca,b,ca,b,c，描述小 S 收到的玫瑰花。

输出格式

一行一个整数，表示答案。

样例

样例输入 #1

0 4 2```

**样例输出 #1**

7```

样例输入 #2

8 10 4```

**样例输出 #2**

53```

AC 代码

#include <bits/stdc++.h>
using namespace std;

int a, b, c;   // a:红色总数, b:粉色总数, c:白色总数

int main() {
    /*
     * 题目类型：枚举计数
     * 思路：枚举所有可能的 (红,粉,白) 数量组合，检查是否满足浪漫条件。
     * 红色最多 min(a/2, 10)，粉色最多 b，白色至少 c/2 且最多 c。
     * 三重循环枚举，复杂度 O(10 * b * (c/2))，由于 a,b,c≤5000，最坏 10*5000*2500=1.25e8
     */
    cin >> a >> b >> c;

    int ans = 0;
    // i: 红色数量，范围 0 ~ min(a/2, 10)
    for (int i = 0; i <= min(a / 2, 10); i++) {
        // j: 粉色数量，范围 0 ~ b
        for (int j = 0; j <= b; j++) {
            // k: 白色数量，范围 c/2 ~ c（至少取一半）
            for (int k = c / 2; k <= c; k++) {
                // 条件1：非空（不能一朵都不选）
                if (i + j + k == 0) continue;

                // 条件2：红色≤粉色 且 白色≤粉色
                if (i <= j && k <= j) {
                    // 条件3：c'=0 或 b'=0，否则要求 a'/c' ≤ c'/b'
                    // 即：j==0 或 k==0 时自动满足；
                    // 否则比较 (double)i/k <= (double)k/j
                    // 注意：浮点数比较可能有精度问题，但本题数据范围小，可以接受。
                    if (j == 0 || k == 0 || ((double)i / k <= (double)k / j)) {
                        ans++;
                    }
                }
            }
        }
    }

    cout << ans << endl;
    return 0;
}
