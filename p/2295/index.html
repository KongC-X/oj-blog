2295 - (a/b)*c的值

题目描述

给定整数 a、b、ca、b、ca、b、c，计算(a/b)×c(a / b) \times c(a/b)×c的值，这里的除法为实数除法。

输入

一行，三个整数 a、b、ca、b、ca、b、c ，整数间以空格分隔。（ 1≤a,b,c≤10001 \le a,b,c \le 10001≤a,b,c≤1000）

输出

将计算结果保留 666 位小数输出。

AC代码

AC代码

#include <iostream>
#include <iomanip>
using namespace std;
int main(){
    int a,b,c;
    cin>>a>>b>>c;
    cout<<fixed<<setprecision(6)<<(a*1.0/b)*c;
    return 0;
}
