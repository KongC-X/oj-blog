B4079 [CSP-X2019 山东] 金币

洛谷 | 普及- | C++14 | 提交时间: 2026-08-10

算法标签：2019、二分、山东、CSP-X 小学组

题目描述

乔治在梦中来到了一个神奇部落，这个部落的神树具有奇特的功能：对于每一位新朋友，都会获赠金币，而且金币的数量会随时间的延续而增加：

  • 第 111 周，每天 111 枚金币；
  • 第 222 周，每天 222 枚金币；
  • 第 333 周，每天 333 枚金币；
  • ……

请问：至少多少天，乔治的金币数量达到 nnn 枚？

输入格式

一行，只有一个正整数 nnn。

输出格式

一行，一个整数，表示金币达到 nnn 枚所需的最少天数。

样例

样例输入 #1

30```

**样例输出 #1**

17```

AC 代码

#include <bits/stdc++.h>
using namespace std;

long long n;   // n: 目标金币数（至少需要达到的金币数量）

/*
 * 检查函数：判断在 mid 天内能否获得至少 n 枚金币
 * 金币获取规律：
 *   第 1 周（第 1~7 天）：每天 1 枚，共 7 枚
 *   第 2 周（第 8~14 天）：每天 2 枚，共 14 枚
 *   第 3 周：每天 3 枚，...
 *   第 x 周：每天 x 枚，共 7*x 枚
 *
 * 参数 mid：给出的天数（非负整数）
 * 返回值：若能获得 >= n 枚金币，返回 true；否则 false
 */
bool check(long long mid) {
    long long x = mid / 7;              // x: 完整的周数（mid 天中有 x 个整周）
    // 前 x 周获得的金币数：
    // 每周金币数 = 7 * 周编号，所以总和 = 7 * (1 + 2 + ... + x) = 7 * x * (x + 1) / 2
    long long cnt = 7 * (1 + x) * x / 2;
    // 剩余天数（不足一周的部分）：mid % 7
    // 这些天属于第 (x+1) 周，每天获得 (x+1) 枚金币
    cnt += (x + 1) * (mid % 7);
    // 判断是否达到目标
    return cnt >= n;
}

int main() {
    cin >> n;

    // 二分查找最小的天数 ans，使得 check(ans) 为 true
    // 下界 l = 1（至少需要 1 天，因为 n >= 1）
    // 上界 r = 4000000000（4e9）足够覆盖最大数据（n=10^18 时约需 3.75e9 天）
    // 同时 mid 最大约 4e9，x≈5.7e8，7*x*x≈2.3e18 < 9e18，不会溢出 long long
    long long l = 1, r = 4000000000LL;
    long long ans = 0;

    while (l <= r) {
        long long mid = (l + r) / 2;    // 中间天数
        if (check(mid)) {               // 如果 mid 天可行
            ans = mid;                  // 记录答案
            r = mid - 1;                // 尝试更小的天数
        } else {
            l = mid + 1;                // mid 天不够，需要更多天数
        }
    }

    cout << ans << endl;   // 输出最少天数
    return 0;
}
