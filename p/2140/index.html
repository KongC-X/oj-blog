给定一个整数 NNN，找出它的所有质因子，并按如下格式输出：

$N=p1

a1a1a1
  • p2$a2a2a2∗⋯∗pk* \dots * pk∗⋯∗pkakakak。

注意: 如果 N=1N=1N=1 则输出 1=11=11=1。

在程序的实际输出时，$p1

a1$写作：$p1 \text{\textasciicircum} a1$。 其中 $pk$ 是质因子，应按照递增顺序排列，$ak$ 是 $pk$ 的指数，如果 $ak$ 为 $1$，则不必输出。 比如：如果 $N=100$，那么输出：$100=2 \text{\textasciicircum} 2*5 \text{\textasciicircum} 2$。 再比如：如果 $N=20$，那么输出：$20=2 \text{\textasciicircum} 2*5$。 ## 输入 一个整数 $N$。（$N≤2

解题思路

AC代码

#include <bits/stdc++.h>
using namespace std;

/*
a[i]==b[j],方程：dp[i-1][j-1]+1
a[i]!=b[j],方程：max(dp[i][j-1],dp[i-1][j])
*/
const int N = 1010;//常量，表示数组大小 
int a[N],b[N],dp[N][N];
int n,i,j; 

int main() {
    cin>>n;
    for(i = 1;i <= n;i++) cin>>a[i];
    for(i = 1;i <= n;i++) cin>>b[i];
    
    //递推
    for(i = 1;i <= n;i++){
        for(j = 1;j <= n;j++){
            if(a[i] == b[j]) dp[i][j] = dp[i-1][j-1] + 1;
            else dp[i][j] = max(dp[i-1][j],dp[i][j-1]);
        }
    } 
    
    cout<<dp[n][n];
    return 0;
}
