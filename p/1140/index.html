1140 - 亲密数对

题目描述

键盘输入 NNN ，NNN 在 222 至 200020002000 之间，求 222 至 NNN 中的亲密数对，就是 AAA 的因子和等于 BBB ，BBB 的因子和等于 AAA ，且 A≠BA \neq BA=B 。

如 484848 和 757575 是亲密数对。484848 的因子和为 2+3+4+6+8+12+16+24=752+3+4+6+8+12+16+24=752+3+4+6+8+12+16+24=75 ，而 757575 的因子和为 3+5+15+25=483+5+15+25=483+5+15+25=48 。

输入

只有一行，为一个整数 NNN （ 2≤N≤20002 \le N \le 20002≤N≤2000 ）

输出

输出若干行，每行两个整数（用一个空格隔开）。

解题思路

AC代码

AC代码

#include <iostream>
#include <cmath>
using namespace std;

// 求一个数的因子和
int sumOfFactors(int n) {
    int sum = 0;
    for (int i = 2; i < n; i++) {
        if (n % i == 0) {
            sum += i;
        }
    }
    return sum;
}


int main() {
    // cout << sumOfFactors(48) << endl; // 75
    int n,i,j;
    cin >> n;
    for(i = 2;i <= n;i++){
        for(j = 2;j <= n;j++) {
            if(sumOfFactors(i) == j && sumOfFactors(j) == i) {
                cout << i << " " << j << endl;
            }
        }
    }
}
