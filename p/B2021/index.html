B2021 输出保留 3 位小数的浮点数

洛谷 | 入门 | C++14 | 提交时间: 2026-06-25

题目描述

读入一个单精度浮点数，保留 333 位小数输出这个浮点数。

提示：无需考虑浮点误差。

输入格式

只有一行，一个单精度浮点数。

输出格式

也只有一行，读入的单精度浮点数。

样例

样例输入 #1

12.34521```

**样例输出 #1**

12.345```

AC 代码

#include<bits/stdc++.h>
using namespace std;
int main(){
    double a;
    cin >> a;
    cout << fixed << setprecision(3) << a;
}
