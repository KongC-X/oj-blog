6064 - 过山车

题目描述

过山车非常刺激，乐乐同学却因为晕车体质无法和同学们一起玩。为了打发等待的时间，他在纸上大致记录了过山车轨道的图形，并估算了 $n$ 个关键点的高度。

如果一个点高于所有相邻的点，则称这个点为"峰"。乐乐觉得，坐过山车最刺激的时刻就是经过"峰"的时候。请写一个程序，计算过山车“峰"的个数。

输入

第一行:一个正整数 $n$;

第二行: $n$ 个正整数 $a_1,a_2,a_3 \dots a_n,a_i$表示第 $i$个点的高度。

输出

一个整数，表示“峰"的个数。

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

/*
  过山车"峰"计数
  
  峰 = 高于所有相邻的点
  首尾各只有一个邻居，中间有两个邻居
  直接 O(N) 扫描一遍即可
*/

const int MAXN = 100010;  // n≤100000，多开一点
int a[MAXN];              // 高度数组

int main() {
    int n;
    cin >> n;
    for(int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    
    int ans = 0;  // 峰的个数
    
    // 第一个点：只和右边比
    if(n >= 1 && a[1] > a[2]) {
        ans++;
    }
    
    // 中间的点：和左右两个比
    for(int i = 2; i < n; i++) {
        if(a[i] > a[i-1] && a[i] > a[i+1]) {
            ans++;
        }
    }
    
    // 最后一个点：只和左边比
    if(n >= 2 && a[n] > a[n-1]) {
        ans++;
    }
    
    cout << ans << endl;
    
    return 0;
}
