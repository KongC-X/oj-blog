1630 - 打电话

题目描述

超市有一门公共电话，收费标准是，如果通话时间在 101010 分钟内，那么按照 1.5元/1.5元/1.5元/ 分钟收费，如果通话时间超过 101010 分钟（含 101010 分钟）按照 1.2元/1.2元/1.2元/ 分钟收费。

比如，如果通话 999 分钟，那么应付金额 =9×1.5=13.5= 9 \times 1.5 = 13.5=9×1.5=13.5 元；

如果通话 101010 分钟，那么只需要按照 1.21.21.2 元收费，应付金额 =10×1.2=12.0=10 \times 1.2 = 12.0=10×1.2=12.0 元；

请编程从键盘读入一个整数 nnn ，代表通话时间，按照要求计算出应付金额是多少？（计算结果保留 111 位小数）。

输入

一个整数 nnn，代表通话时间。

输出

应付金额，计算结果保留 111 位小数。

解题思路

AC代码

AC代码

#include <iostream>
#include <iomanip>
using namespace std;
 
int main(){
    int n;
    cin>>n;
    double p;
    if(n<10){
        p=1.5*n;
    }else{
        p=1.2*n;
    }
    cout<<fixed<<setprecision(1)<<p;
}
