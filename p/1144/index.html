1144 - 等差素数组

题目描述

如果两个素数之和的一半仍然是一个素数，则这三个素数可以组成一个等差素数组，如 (3+7)/2=5(3+7)/2=5(3+7)/2=5，则 (3，5，7)(3，5，7)(3，5，7) 为一个等差素数组，编程求 100100100 以内的所有等差素数组。

这里列出的 333 555 777 是符合题目要求的第一个等差素数组（注意：本题不考虑 333 个数相等的情况）。

输入

无；

输出

若干行，每行 333 个数。空格隔开！（每行的三个数从小到大排列，先按第一个数从小到大输出等差素数组，如果第一个数相同，再按第二个数从小到大输出）

解题思路

AC代码

AC代码

#include<bits/stdc++.h>
using namespace std;

//判断素数
bool sushu(int n) {
    bool f = true;//假设是素数
    //循环n的因子范围
    for(int i = 2; i <= sqrt(n); i++) {
        //如果找到n的因子，n就不是素数
        if(n % i == 0) {
            f = false;
            break;
        }
    }

    //判断特殊情况
    if(n <= 1) f = false;
    return f;
}

int main() {
    int i,j;
    //找素数对
    for(i = 3; i <= 100; i++) {
        //如果i是素数，再找第2个数
        if(sushu(i) == true) {
            //找第2个数
            for(j = i + 1; j <= 100; j++) {
                //除2以外，两个素数相加，结果必然是偶数 
                if(sushu(j)==true && sushu((i+j)/2)==true){
                    cout<<i<<" "<<(i+j)/2<<" "<<j<<endl; 
                }
            }
        }
    }
    return 0;
}
