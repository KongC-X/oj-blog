1409 - 棋盘里的麦子

题目描述

传说西塔发明了国际象棋而使国王十分高兴，他决定要重赏西塔，西塔说：“我不要你的重赏 ，陛下，只要你在我的棋盘上赏一些麦子就行了。

在棋盘的第 111 个格子里放 111 粒，在第 222 个格子里放222 粒，在第 333 个格子里放 444 粒，在第 444 个格子里放 888 粒，依此类推，以后每一个格子里放的麦粒数都是前一个格子里放的麦粒数的 222 倍，直到放满第 646464 个格子就行了”。

“区区小数，几粒麦子，这有何难，来人”，国王令人如数付给西塔。

计数麦粒的工作开始了，第一格内放 111 粒，第二格内放 222 粒第三格内放 444粒，…\dots… 还没有到第二十格，一袋麦子已经空了。

一袋又一袋的麦子被扛到国王面前来。但是，麦粒数一格接一格飞快增长着，国王很快就看出，即便拿出全国的粮食，也兑现不了他对西塔的诺言。

请你编程帮助国王计算出，第 nnn 个棋盘格子中需要放多少粒麦子？

输入

一个整数 nnn 代表第 nnn 格棋盘（n≤100n \le 100n≤100 ）

输出

一个整数，代表第 nnn 格棋盘中麦子的总数。

解题思路

AC代码

AC代码

#include<iostream>
using namespace std;

int a[100] = {1};
int n,k = 1,i,j;
int main() {
    cin >> n;
    for(i = 1; i < n; i++) {
        for(j = 0; j < k; j++) {
            a[j] = a[j] * 2;
        }
        for(j = 0;j < k;j++) {
            if(a[j] >= 10) {
                a[j+1] += a[j] / 10;
                a[j] = a[j] % 10;
            }
        }
        if(a[k] != 0) {
            k++;
        }
    }
    for(i = k - 1;i >= 0;i--) {
        cout << a[i];
    }
}
