1029 - 倒序输出一个四位整数

题目描述

任意读入一个四位整数，颠倒后输出。

输入

输入一行，只有一个整数 $x(1000 \le x \le 9999)$ 。

输出

输出只有一行，包括 $1$ 个整数。

AC代码

AC代码

#include<iostream>
#include<bits/stdc++.h>
#include<iomanip>
using namespace std;

int main() {
    int x,a,b,c,d,n;
    cin>>x;
    a = x/1000;
    b = (x%1000)/100;
    c = ((x%1000)%100)/10;
    d = ((x%1000)%100)%10;
    n = d * 1000 + c * 100 + b * 10 + a;
    cout<<n;
}
