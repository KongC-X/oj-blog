P1115 最大子段和

洛谷 | 普及- | C++14 | 提交时间: 2026-07-08

算法标签：动态规划 DP、贪心、递推、分治、前缀和、线性 DP

题目描述

给出一个长度为 nnn 的序列 aaa，选出其中连续且非空的一段使得这段和最大。

输入格式

第一行是一个整数，表示序列的长度 nnn。

第二行有 nnn 个整数，第 iii 个整数表示序列的第 iii 个数字 aia_iai​。

输出格式

输出一行一个整数表示答案。

样例

样例输入 #1

7
2 -4 3 -1 2 -4 3

样例输出 #1

4```

## AC 代码

```cpp
#include<bits/stdc++.h> 
using namespace std; 
const long long maxn = 2 * 1e5;
long long maxi = -1e4, s = 0;
long long a[maxn];
int main(){
    int n;
    cin >> n;
    for(int i = 1; i <= n; i++){
        if(s < 0){
            s = 0;
        }
        cin >> a[i];
        s += a[i];
        maxi = max(maxi, s);
    }
    cout << maxi;
    return 0; 
}
