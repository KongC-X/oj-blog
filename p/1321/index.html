1321 - 时钟旋转（2）

题目描述

时钟从时间： xx:xxxx:xxxx:xx （ xxxxxx 时 xxxxxx 分），走到时间：xx:xxxx:xxxx:xx （ xxxxxx 时 xxxxxx 分），时针共旋转了多少度？（假设第一个时间 ≤\le≤ 第二个时间，222 个时间都是 121212 小时制，且两个时间的时间差不超过 121212 小时，也就是说时针旋转的度数在 360360360 度之内，也就是 1≤1 \le1≤ 时间 1≤1 \le1≤ 时间 2≤122 \le 122≤12 （4.2.4）

输入

222行，第一行为起始时间（如：01:0001:0001:00），第二行为结束时间。（如：01:0501:0501:05）

输出

时针旋转的度数。（结果保留 111 位小数）

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 求出总分钟数
int minute(string s) {
    // xx:xx
    int h = (s[0] - '0') * 10 + s[1] - '0';
    int m = (s[3] - '0') * 10 + s[4] - '0';
    return h * 60 + m;
}

int main() {
    string s1,s2;
    int n;
    double s;
    cin >> s1 >> s2;
    n = minute(s2) - minute(s1);
    s = n * 1.0 / 60 * 30;
    printf("%.1f", s);
}
