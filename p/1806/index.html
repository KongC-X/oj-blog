1806 - 是什么数列？

题目描述

小明学习了等差数列和等比数列的知识。

等差数列是指从第二项起，每一项与它的前一项的差都是相等的。比如数列：111 333 555 777 999和数列：999 777 555 333 111 都是等差数列。

等比数列是指从第二项起，每一项与它的前一项的比值都是相等的。比如数列：111 222 444 888 161616 和数列：161616 888 444 222 111 都是等比数列。

现从键盘读入 nnn 个整数，判断是等差数列还是等比数列，如果是等差数列，请输出dengcha，如果是等比数列，请输出dengbi，如果两种数列都不是，请输出no。

本题中等差数列的差值和等比数列的比值，一定是整数。

输入

第一行有 111 个整数 nnn 。（5≤n≤1005 \le n \le 1005≤n≤100）

第二行有 nnn 个不相同的整数，用空格隔开。（这 nnn 个数都是1∼10001 \sim 10001∼1000之间的整数）

输出

如果是等差数列，请输出dengcha，如果是等比数列请输出dengbi，如果都不符合，请输出no。

解题思路

AC代码

AC代码

#include <bits/stdc++.h>
    using namespace std;
    int main()
    {
      int n,fdc=0,fdb=0;
      double dc,db;
      cin>>n;
      double a[n+10];
      for(int i=1; i<=n; i++)
      {
        cin>>a[i];
      }
      dc=a[1]-a[2];//等差的值
      db=a[1]/a[2];//等比的值
      for(int i=2; i<n; i++)
      {
        if(a[i]-a[i+1]!=dc)
        {
          fdc=1;   //不是等差就标记
        }
        if(a[i]/a[i+1]!=db)
        {
          fdb=1;  //不是等比就标记
        }
      }
      if(fdc==0)
      {
        cout<<"dengcha";
      }
      else if(fdb==0)
      {
        cout<<"dengbi";
      }
      else
      {
        cout<<"no";
      }
      return 0;
    }
