# 1491 - 数字三角

## 题目描述

输入一个整数 $n$，打印 $n$ 行的数字三角！

## 输入

一个整数 $n（n \lt 10$ ）

## 输出

$n$ 行的数字三角。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
    int n;
    cin>>n;
    int i,j;
    //循环n行 
    for(i=1;i<=n;i++){
    	//先循环输出每行前面的空格 
        for(j=1;j<=i-1;j++){
            cout<<" ";
        }
        //再循环输出每行的数字 
        for(j=1;j<=n-i+1;j++){
            cout<<j;
        }
        cout<<endl;
    }
}
```
