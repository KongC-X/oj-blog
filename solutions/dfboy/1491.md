# 1491 - 数字三角

## 题目描述

输入一个整数 $n$，打印 $n$ 行的数字三角！

## 输入

一个整数 $n（n \lt 10$ ）

## 输出

$n$ 行的数字三角。

## 解题思路

## AC代码

```cpp
// 提示：用结构体存储每张图片的宽、高、面积以区其距离原始数据的宽高比的差值。
#include <iostream>
#include <iomanip>
#include <bits/stdc++.h>
using namespace std;

struct Pic {
    int width; // 宽
    int height; // 高
    double diff; // 差值
    int area; // 面积
}a[110];

bool cmp(Pic a, Pic b) {
    if(a.diff > b.diff || (a.diff == b.diff && a.area > b.area)) {
        return false;
    } else {
        return true;
    }
}

int main() {
    int x,y,i,n;
    double z,k;
    cin >> x >> y;
    z = 1.0 * x / y; // 原始宽高比
    cin >> n;
    for(i=0;i<n;i++) {
        cin>>a[i].width>>a[i].height;
        k = 1.0 * a[i].width / a[i].height; // 当前宽高比
        a[i].diff = abs(z - k); // 差值
        a[i].area = a[i].width * a[i].height; // 面积
    }
    // 按照差值从小到大排序,差值一样按照面积从小到大
    sort(a, a + n, cmp);
    cout << a[0].width << " " << a[0].height << endl;
}
```
