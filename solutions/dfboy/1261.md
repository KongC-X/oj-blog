# 1261 - 韩信点兵

## 题目描述

韩信有一队士兵，他想知道有多少人，他就让士兵报数，如果按照 $1$ 到 $5$ 报数，最末一个士兵报的数为 $1$ 。

按照 $1$ 到 $6$  报数，最末一个士兵报的数为 $5$ 。

按照 $1$ 到 $7$ 报数，最末一个士兵报的数为 $4$ 。

最后再按 $1$ 到$11$ 报数，最末一个士兵报的数为 $10$ 。

请问韩信这队士兵最少有多少人？

## 输入

无。

## 输出

输出这队士兵最少有多少人？
