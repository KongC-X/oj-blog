# 1028 - 输入一个三位数，把个位和百位对调后输出

## 题目描述

输入一个三位自然数，然后把这个数的百位数与个位数对调，输出对调后的数。

## 输入

输入一行，只有一个整数 $x(100 \le x \le 999)$ 。

## 输出

输出只有一行，包括 $1$ 个整数。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
#include<iomanip>
using namespace std;

int main() {
    int x,n;
    int a,b,c;
    cin >> x;
    a = x / 100;
    b = (x % 100) / 10;
    c = (x % 100) % 10;
    n = c * 100 + b * 10 + a;
    cout << n << endl;
}
```
