# 1028 - 输入一个三位数，把个位和百位对调后输出

## 题目描述

输入一个三位自然数，然后把这个数的百位数与个位数对调，输出对调后的数。

## 输入

输入一行，只有一个整数 $x(100 \le x \le 999)$ 。

## 输出

输出只有一行，包括 $1$ 个整数。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin>>n;
    int i,j;
    for(i=1;i<=n;i++){
    	//每行输出i-1个空格 
        for(j=1;j<=i-1;j++){
            cout<<" ";
        }
        //每行输出 2*(n-i)+1个* 
        for(j=1;j<=2*(n-i)+1;j++){
            cout<<"*";
        }
        cout<<endl;
    }
	return 0;
}
```
