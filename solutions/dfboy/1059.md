# 1059 - 求数

## 题目描述

输出 $1 \sim 999$ 中有因数 $3$ ，且至少有一位数字是 $5$ 的数。

## 输入

无。

## 输出

若干个数 每行一个。
## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	//定义整数变量i用作循环 
	int i;
	//从1到999做循环 
    for(i=1;i<=999;i++){
    	//判断i是否有因数3 
        if(i%3==0){
        	//判断i中至少有一位数字是5 
            if(i%10==5||i/10%10==5||i/100==5){
                cout<<i<<endl;
            }
        }
    }
	return 0;
}
```
