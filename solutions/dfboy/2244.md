# 2244 - 打印字符

## 题目描述

输入一个 $ASCII$ 码，输出对应的字符。

## 输入

一个整数，即字符的 $ASCII$ 码，保证存在对应的可见字符。

## 输出

一行，包含相应的字符。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
	int x;
	cin>>x;
	char c=x;
	cout<<c;
	return 0;
}
```
