# 2244 - 打印字符

## 题目描述

输入一个 $ASCII$ 码，输出对应的字符。

## 输入

一个整数，即字符的 $ASCII$ 码，保证存在对应的可见字符。

## 输出

一行，包含相应的字符。

## 解题思路

## AC代码

```cpp
#include<iostream>
using namespace std;
int a[1010];
int main() {
    int n,i,m,k = 0;
    cin >> n;
    for(i = 0; i < n; i++) {
        cin >> m;
        bool flag = false; // 标记元素是否出现过
        for(int j = 0; j < k; j++) {
            if(a[j] == m) {
                flag = true;
                break;
            }    
        }
        if(flag == false) {
            a[k] = m;
            k++;
        }
    }
    cout << k << endl;
    // 排序
    for(i = 0;i < k - 1; i++) {
        for(int j = 0; j < k - i - 1; j++) {
            if(a[j] > a[j + 1]) {
                int temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        }
    }
    for(i = 0;i < k; i++) {
        cout << a[i] << endl;
    }
}
```
