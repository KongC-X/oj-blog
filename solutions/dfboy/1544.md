# 1544 - 吃西瓜（ watermelon ）

## 题目描述

炎热的夏天来的可真快，小花猫和编程兔决定去买一个又大又甜的西瓜。可是小花和编程兔是两只非常奇怪的动物，都是偶数的爱好者，它们希望把西瓜切成两半后，每一部分的重量都是
$2$ 的倍数公斤（大于 $0$）。当然有编程兔在，它们很快就决定了买哪个瓜。小朋友你知道要不要买这个瓜吗？

## 输入

第一行只有一个正整数，表示西瓜的重量 $w$（单位是公斤）。

## 输出

如果能达到要求，就输出 `YES`，否则就输出 `NO`。(注意区分大小写)。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    // s是输入的字符串，a是要查找的字符串，b是s中每个单词
    char s[810],a[100],b[100];
    // k是b的索引，c是a在s中出现的第几个单词，x是s中字符的个数
    int i,k = 0,c = 1,x = 0;
    gets(s);
    gets(a);
    for(i = 0;s[i] != '.';i++) {
        if(s[i] != ' ') {
            b[k++] = s[i];
            x++; // x是s中字符的个数，每次统计一下
            if(s[i + 1] == ' ' || s[i + 1] == '.') {
                b[k] = '\0';
                // 比较a和b是否相等，相等输入当前是第几个单词
                // 不相等c++，k归零
                if(strcmp(a,b) == 0) {
                    cout << c << endl;
                    return 0; // 找到就结束程序
                } else {
                    c++;
                }
                k = 0;
            }
        }
    }
    cout << x << endl; // 如果没有找到，输入字符总数
}
```
