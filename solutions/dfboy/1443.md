# 1443 - 泉水

## 题目描述

Leyni是一个地质调查员，有一天在他调查的地方突然出现个泉眼。由于当地的地势不均匀，有高有低，他觉得如果这个泉眼不断的向外溶出水来，这意味着这里在不久的将来将会一个小湖。水往低处流，凡是比泉眼地势低或者等于的地方都会被水淹没，地势高的地方水不会越过。而且又因为泉水比较弱，当所有地势低的地方被淹没后，水位将不会上涨，一直定在跟泉眼一样的水位上。

由于Leyni已经调查过当地很久了，所以他手中有这里地势的详细数据。所有的地图都是一个矩形，并按照坐标系分成了一个个小方格，Leyni知道每个方格的具体高度。我们假定当水流到地图边界时，不会流出地图外，现在他想通过这些数据分析出，将来这里将会出现一个多大面积的湖。

## 输入

第一行有四个整数 $n,m,p_1,p_2$ ($n,m \le 1000$)，$n$ 和 $m$ 表示当前地图的长和宽，$p_1$ 和 $p_2$ 表示当前地图的泉眼位置，即第 $p_1$ 行第 $p_2$ 列。

随后的 $n$ 行中，每行有 $m$ 个数据。表示这每一个对应坐标的高度。

## 输出

输出对应地图中会有多少个格子被水充满。

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int a[1010][1010],q[1000010][3];
bool f[1010][1010]; // f数组用于标记是否走过
int n,m,i,j,tx,ty,p1,p2;

int head = 1,tail = 1; // 队列头尾指针

// 右下左上
int fx[5] = {0,0,1,0,-1};
int fy[5] = {0,1,0,-1,0};

int main() {
    cin >> n >> m >> p1 >> p2;
    for(i = 1;i <= n;i++) {
        for(j = 1;j <= m;j++) {
            cin >> a[i][j];
        }
    }
    // 把起点存到队列中
    q[head][1] = p1;
    q[tail][2] = p2;
    f[p1][p2] = true; // 标记起点为走过
    while(head <= tail) {
        for(int i = 1;i <= 4;i++) {
            tx = q[head][1] + fx[i];
            ty = q[head][2] + fy[i];
            if(tx >= 1 && tx <= n && ty >= 1 && ty <= m && f[tx][ty] == false && a[tx][ty] <= a[p1][p2]) {
                tail++;
                q[tail][1] = tx;
                q[tail][2] = ty;
                f[tx][ty] = true; // 标记为走过
            }
        }
        head++; // 队列头指针后移
    }
    cout << tail << endl;
}
```
