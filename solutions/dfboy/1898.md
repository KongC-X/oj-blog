# 1898 - 同时出现的数

## 题目描述

$Medusa$ 同学拿到了 $2$ 组数字，老师请你编程帮他找出，第 $2$ 组数中的哪些数，在第 $1$ 组数中出现了，从小到大输出所有满足条件的数。

比如：

第 $1$ 组数有：$8$  $7$  $9$  $8$  $2$  $6$  $3$

第 $2$ 组数有：$9$  $6$  $8$  $3$  $3$  $2$  $10$

那么应该输出：$2$  $3$  $3$  $6$  $8$  $9$

## 输入

第一行两个整数 $n$ 和 $m$ ，分别代表 $2$ 组数的数量。

第二行 $n$ 个整数。

第三行 $m$ 个整数。

对于 $60\%$ 的数据 $1 \le n$,$m \le 1000$，每个数$ \le 2\times 10^9$。

对于 $100\%$ 的数据 $1 \le n$, $m \le 100000$ ，每个数 $ \le 2\times 10^9$。

## 输出

按照要求输出满足条件的数，数与数之间用空格隔开。

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;
/*
第2组数中的哪些数，在第1组数中出现了
从⼩到⼤输出所有满⾜条件的数
思路：采⽤⼆分查找第2个数组中哪些数在第1个数组中出现了
1.对a 数组排序：⽅便⼆分查找
2.对b 数组排序：⽅便结果从⼩到⼤输出
3.循环b 数组的每个数，在a 数组中⼆分查找是否存在
*/

int a[100010],b[100010];
int main() {
	int n,m,x,i,j;
	cin >> n  >> m;
	for(i = 0;i < n;i++) {
		cin >> a[i];
	}
	for(i = 0;i < m;i++) {
		cin >> b[i];
	}
	sort(a,a+n);
	sort(b,b+m);
	for(i = 0;i < m;i++) {
		int left = 0,right = n-1;
		while(left <= right) {
			int mid = (left + right) / 2;
			if(a[mid] == b[i]) {
				cout << b[i] << " ";
				break;
			} else if(a[mid] < b[i]) {
				left = mid + 1;
			} else {
				right = mid - 1;
			}
		}
	}
}
```
