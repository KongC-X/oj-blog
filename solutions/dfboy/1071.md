# 1071 - 字符图形7-星号菱形

## 题目描述

输入一个整数 $n$ ，请打印出 $n*2+1$ 行的字符图形。

## 输入

一个整数（$0 \lt n \lt 10$）。

## 输出

一个字符图形，如输入 $2$ ，则产生 $5$ 行的菱形（为方便找规律，这里将空格用 $□$ 替代，实际输出，请输出空格）。

```
`□□×
□×××
×××××
□×××
□□×
`
```
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	int n;
    cin>>n;
    int i,j;
    //循环n+1行 
    for(i=1;i<=n+1;i++){
    	//每行输出 n-i+1个空格 
        for(j=1;j<=n-i+1;j++){
            cout<<" ";
        }
        //每行输出 2*i-1个* 
        for(j=1;j<=2*i-1;j++){
            cout<<"*";
        }
        cout<<endl;
    }
    //循环n行 
    for(i=1;i<=n;i++){
    	//每行输出i个空格 
        for(j=1;j<=i;j++){
            cout<<" ";
        }
        //每行输出 2*(n-i)+1个* 
        for(j=1;j<=2*(n-i)+1;j++){
            cout<<"*";
        }
        cout<<endl;
    }
	return 0;
}
```
