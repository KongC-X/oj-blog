# 1148 - 数数小木块

## 题目描述

在墙角堆放着一堆完全相同的正方体小木块，如下图所示：

因为木块堆得实在是太有规律了，你只要知道它的层数就可以计算所有木块的数量了。

## 输入

只有一个整数  $n$ ，表示这堆小木块的层数，已知 $1 \le n \le 100$  。

## 输出

只有一个整数，表示这堆小木块的总数量。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;

int pk[55];

int main() {
	int n;
	cin >> n;
	for(int i = 1; i <= n; i++) {
		char t, c;
		cin >> t >> c;
		int m;
		if(t == 'S') m = 0;
		else if(t == 'H') m = 13;
		else if(t == 'C') m = 26;
		else m = 39;
		if(c == 'A') m += 1;
		else if(c == 'T') m += 10;
		else if(c == 'J') m += 11;
		else if(c == 'Q') m += 12;
		else if(c == 'K') m += 13;
		else m += (int)(c - '0');
		pk[m] = 1;
	}
	int cnt = 0;
	for(int i = 1; i <= 52; i++) {
		if(pk[i] == 0)
			cnt++;
	}
	cout << cnt << endl;
	return 0;
}
```
