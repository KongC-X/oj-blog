# 1148 - 数数小木块

## 题目描述

在墙角堆放着一堆完全相同的正方体小木块，如下图所示：

因为木块堆得实在是太有规律了，你只要知道它的层数就可以计算所有木块的数量了。

## 输入

只有一个整数  $n$ ，表示这堆小木块的层数，已知 $1 \le n \le 100$  。

## 输出

只有一个整数，表示这堆小木块的总数量。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    int s = 1,n,x = 1;
    cin >> n;
    for(int i = 2;i <= n;i++) {
        x = x + i;
        s += x;
    }
    cout << s << endl;
}
```
