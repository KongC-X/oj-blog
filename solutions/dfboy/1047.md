# 1047 - 能否构成直角三角形

## 题目描述

判定三条线段 $a，b，c$ 能否构成一个直角三角形。如果能构成，请计算出面积（保留一位小数），不然输出 `No` 。

## 输入

一行，三个整数。

## 输出

面积（保留 $1$ 位小数） 或 `No` 。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int a,b,c,t;
	cin>>a>>b>>c;
	if(a>b)t=a,a=b,b=t;
	if(b>c)t=b,b=c,c=t;
	if(a>b)t=a,a=b,b=t;
	if(a+b>c&&a*a+b*b==c*c)cout<<fixed<<setprecision(1)<<(a*b)/2.0;
	else cout<<"No";
	return 0;
}
```
