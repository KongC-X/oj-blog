# 1047 - 能否构成直角三角形

## 题目描述

判定三条线段 $a，b，c$ 能否构成一个直角三角形。如果能构成，请计算出面积（保留一位小数），不然输出 `No` 。

## 输入

一行，三个整数。

## 输出

面积（保留 $1$ 位小数） 或 `No` 。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int a,b;
    cin >> a >> b;
    cout << (a + b) * 2 << endl;
    cout << a * b << endl;
}
```
