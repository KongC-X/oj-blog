# 1120 - 倒置输出字符串

## 题目描述

随机输入一个长度不超过 $255$ 的字符串，将其倒置后输出。

## 输入

只有一行。（测试数据不含空格）

## 输出

只有一行，输出倒置后的字符串。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h> // 万能头文件
#include <iostream>
using namespace std;

/*
    01背包问题
    二维数组：dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - w[i]] + v[i])
    一维数组滚动优化：从背包容量开始倒序遍历到当前物品的重量wi
    一维数组：dp[j] = max(dp[j], dp[j - w[i]] + v[i])

    完全背包问题：每种物品可以取无限次
    二维数组：dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - k * w[i]] + k* v[i])
    经过变换之后和01二维只有一个i和i - 1的区别：
    dp[i][j] = max(dp[i - 1][j], dp[i][j - w[i]] + v[i])
    一维数组滚动优化：从当前物品的重量wi开始正序遍历到背包容量c
    一维数组：dp[j] = max(dp[j], dp[j - w[i]] + v[i])

*/


// 我们先用二维数组求解完全背包，会发现超时了
int n,maxw;
int dp[10010][10010],i,j;
int w[10010],v[10010];

int main() {
    cin >> maxw >> n;
    for(i = 1; i <= n; i++) {
        cin >> w[i] >> v[i];
    }
    for(i = 1; i <= n; i++) {
        for(j = 1;j <= maxw; j++) {
            if(j >= w[i]) {
                dp[i][j] = max(dp[i - 1][j], dp[i][j - w[i]] + v[i]);
            } else {
                dp[i][j] = dp[i - 1][j];
            }
        }
    }
    cout << dp[n][maxw] << endl;
}
```
