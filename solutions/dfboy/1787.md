# 1787 - 字符图形-数字正三角（2）

## 题目描述

输入一个整数打印数字图形。

## 输入

一个整数。（ $ 0 \lt n \lt 10$ ）

## 输出

一个数字图形。
## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
    int n;
    cin>>n;
    int i,j;
    //输出n行 
    for(i=1;i<=n;i++){
    	//每行先输出 n-i个空格 
        for(j=1;j<=n-i;j++){
            cout<<" ";
        }
        //每行再输出 2*i-1个数 
        for(j=1;j<=2*i-1;j++){
            cout<<j;
        }
        cout<<endl;
    }
	return 0;
}
```
