# 1596 - 火柴棒三角形问题

## 题目描述

如下图所示，摆 $1$ 个火柴棒三角形需要 $3$ 根火柴，那么摆 $2$ 个火柴棒三角形就需要 $6$ 根火柴，请问摆 $n$ 个火柴棒三角形需要多少根火柴？

## 输入

一个整数 $n$ ，代表想要摆放的火柴棒三角形的数量。

## 输出

一个整数，代表了需要多少根火柴的数量。

## 解题思路

## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

// a存储矩阵，q存储队列（遍历过的点）
char a[200][200]; // 迷宫
int q[40000][4]; // 队列
int n,m,i,j,tx,ty;
int s1,s2,e1,e2; // 起始点
int head = 1,tail = 1; // head：头指针，tail：尾指针
// 八个方向
int fx[9] = {0,-1,-2,-2,-1,1,2,2,1};
int fy[9] = {0,-2,-1,1,2,2,1,-1,-2};

int main() {
    // n行m列
    cin >> m >> n;
    for(i = 1;i <= n;i++) {
        for(j = 1;j <= m;j++) {
            cin >> a[i][j];
            // 找到出发点和终点
            if(a[i][j] == 'K') {
                s1 = i;
                s2 = j;
            } else if(a[i][j] == 'H') {
                e1 = i;
                e2 = j;
            }
        }
    }

    // 1,1点存入队列，以1，1为head访问四个方向
    q[1][1] = s1;
    q[1][2] = s2;
    q[1][3] = 0; // 记录步数
    // 当head <= tail时，说明队列还有点没有尝试标记过四个方向
    while(head <= tail) {
        // 尝试访问head的八个方向
        for(i = 1;i <= 8;i++) {
            // 从head对应的点加上四个方向的变化量得到新的点
            tx = q[head][1] + fx[i];
            ty = q[head][2] + fy[i];
            // 如果新的点在矩阵范围内，且没有被标记过，则标记
            if(a[tx][ty] == '.' || a[tx][ty] == 'H') {
                a[tx][ty] = '*'; // 标记代表走过了
                // 新的点存入队列，以新点为head访问四个方向
                tail++;
                q[tail][1] = tx;
                q[tail][2] = ty;
                q[tail][3] = q[head][3] + 1; // 步数加1

                if(tx == e1 && ty == e2) { // 如果到达终点，输出步数
                    cout << q[tail][3] << endl;
                }
            }
        }
        head++; // head指向队列头的下一个点
    }
}
```
