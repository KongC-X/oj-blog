# 1359 - 八进制转换二进制

## 题目描述

请将一个 $100$ 位以内的 $8$ 进制整数转换为 $2$ 进制整数！

## 输入

$100$ 位以内的 $8$ 进制整数。

## 输出

该数对应的 $2$ 进制整数。

## 解题思路

## AC代码

```cpp
// 我下面这个解法有哪些问题？
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    char s[210],a[210];
    int i,k = 0;
    gets(s);
    a[k] = s[0];
    k++;
    for(i = 1;i < strlen(s);i++){
        if(s[i] == ' ') {
            a[k] = s[i + 1];
            k++;
        }
    }
    for(i = 0;i < strlen(a);i++){
        if(a[i] >= 'a' && a[i] <= 'z'){
            a[i] = a[i] - 32;
        }
        cout << a[i];
    }
}

// 问题1: 单词之间没说只有一个空格

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    char s[210],a[210];
    int i,k = 0;
    gets(s);
    a[k] = s[0];
    k++;
    for(i = 1;i < strlen(s);i++){
        if(s[i - 1] == ' ' && s[i] != ' ') {
            a[k] = s[i];
            k++;
        }
    }
    for(i = 0;i < strlen(a);i++){
        if(a[i] >= 'a' && a[i] <= 'z'){
            a[i] = a[i] - 32;
        }
        if(a[i] != ' ') {
            cout << a[i];
        }
    }
}
```
