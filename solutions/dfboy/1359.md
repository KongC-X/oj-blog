# 1359 - 八进制转换二进制

## 题目描述

请将一个 $100$ 位以内的 $8$ 进制整数转换为 $2$ 进制整数！

## 输入

$100$ 位以内的 $8$ 进制整数。

## 输出

该数对应的 $2$ 进制整数。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

string t[8] = {"000","001","010","011","100","101","110","111"};
int main(){
    string s,r;
    cin >> s;
    // s[i]转换为0-7的整数，然后再求对应的3位二进制数
    int x,i;
    for(i = 0;i < s.size();i++){
        x = s[i] - '0';
        r += t[x];
    }
    // cout << r;
    // 这样转换完前面会有多余的0，接下来删除0
    while(r[0] == '0') r.erase(0,1);

    if(r == "") {
        cout << 0;
    } else {
        cout << r;
    }
}
```
