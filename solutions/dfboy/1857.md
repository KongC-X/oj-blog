# 1857 - 数的划分

## 题目描述

将整数 $n$ 分成 $k$ 份，且每份不能为空，任意两个划分方案不能相同(不考虑顺序)。

例如：$n=7$，$k=3$，下面三种分法被认为是相同的。

```
`1，1，5;
1，5，1;
5，1，1;
`
```

问有多少种不同的分法。

$n=7$，$k=3$ 有 $4$ 种不同的分法，分别是：

```
`1，1，5;
1，2，4;
1，3，3;
2，2，3;
`
```

## 输入

两个整数 $n$，$k$ 用空格隔开。（$6 \lt n \le 200$，$2 \le k \le 6$）

## 输出

一个整数，即不同的分法。
## AC代码

```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, k;                       // n: 被划分的数，k: 份数
    cin >> n >> k;

    // ========== DP 思路 ==========
    // 问题：将 n 分成 k 个正整数之和，且不考虑顺序（即组合）。
    // 要求所有份非空，即每份至少为 1。
    // 为了保证不计顺序，我们强制划分出的 k 个数为非递减排列。
    //
    // 状态定义：
    //   dp[i][j] 表示将整数 i 划分为 j 份（每份 >= 1）的不同方案数。
    //
    // 状态转移：
    //   考虑划分中的最小值是否为 1：
    //   - 若至少有一份是 1，则去掉这一份，剩下的 i-1 要分成 j-1 份，
    //     方案数 = dp[i-1][j-1]。
    //   - 若所有份都至少为 2，那么我们将每一份都减去 1，则 i-j 分成 j 份，
    //     方案数 = dp[i-j][j]（需满足 i >= j）。
    //   因此 dp[i][j] = dp[i-1][j-1] + (i >= j ? dp[i-j][j] : 0)
    //
    // 边界条件：
    //   dp[0][0] = 1   (0 分成 0 份有一种方案)
    //   dp[0][j] = 0   (j > 0 时 0 不能分成 j 份)
    //   dp[i][0] = 0   (i > 0 时无法分成 0 份)
    //
    // 答案：dp[n][k]
    // 复杂度 O(n*k)，n≤200, k≤6，完全可行。

    int dp[205][10] = {0};         // 多开一点空间
    dp[0][0] = 1;                  // 初始状态

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= k; j++) {
            dp[i][j] = dp[i-1][j-1];          // 至少有一份为 1
            if (i >= j) {
                dp[i][j] += dp[i-j][j];       // 所有份都 >= 2
            }
        }
    }

    cout << dp[n][k] << '\n';
    return 0;
}
```
