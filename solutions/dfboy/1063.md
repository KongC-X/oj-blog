# 1063 - 素数的个数

## 题目描述

编程求正整数 $M$ 与 $N$ 之间的所有素数的个数。（ $1 \le M \le N \le 30000$ ）

## 输入

输入只有一行，包括 $2$ 个整数 $M,N$ ，之间用一个空格分开。

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

## 解题思路

## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int i,j,k,n,m;
    cin >> n >> m;
    for(i = 0;i <= n/5;i++){
        for(j = 0;j <= n/3;j++){
            for(k = 0;k <= n * 3;k++) {
                if(i * 5 + j * 3 + k / 3 == n && k % 3 == 0 && i + j + k == m) {
                    cout << i << " " << j << " " << k << endl;
                }
            }
        }
    }
    return 0;
}


// 上面的方法会超时，采用双循环的方法
int main() {
	int n,m; 
	cin>>n>>m;
	for(int g=0;g<=n/5;g++){
		for(int h=0;h<=(n-5*g)/3;h++){
			int x = (n-5*g-3*h)*3;
			if(g+h+x==m){
				cout<<g<<" "<<h<<" "<<x<<endl;
			}
		}
	} 
	return 0;
}
```
