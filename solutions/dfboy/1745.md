# 1745 - 纯粹的五位偶数

## 题目描述

纯粹偶数指的是一个数的各个位都是偶数的数，比如：$24686$ ；请编程求出 $10000 \sim n$ 中，所有的五位的纯粹偶数有多少个？

## 输入

一个整数 $n（n$ 为一个 $5$位的整数）。

## 输出

一个整数，代表 $10000 \sim n$ 之间的纯粹偶数有多少个。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
    int n;
    cin>>n;
    int i,x1,x2,x3,x4,x5,y=0;
    //遍历10000到n之间所有的五位整数 
    for(i=10000;i<=n;i++){
    	//对i进行拆位 
        x1=i/10000;
        x2=i/1000%10;
        x3=i/100%10;
        x4=i%100/10;
        x5=i%10;
		//判断各个位是否都是偶数
        if(x1%2==0&&x2%2==0&&x3%2==0&&x4%2==0&&x5%2==0){
            y++;//计数符合条件的数的个数 
        } 
    }
    cout<<y;
	return 0;
}
```
