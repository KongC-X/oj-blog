# 1521 - 计算分数加减表达式的值

## 题目描述

编写程序，输入 $n$ 的值，求 $1/1 - 1/2 + 1/3 - 1/4 + 1/5 - 1/6 + 1/7 - 1/8 + \dots $ 前 $n$ 项的和。

## 输入

输入一个正整数 $n$ 。( $1 \le n \le 1000$ ) 。

## 输出

输出一个实数，为表达式的值，保留到小数点后四位。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int a[110];
int n,x,s,i,k;
int main() {
    cin >> n >> x;
    // 输出西瓜重量
    for(i = 1;i <= n;i++) {
        cin >> a[i];
    }
    // 从小到大排序
    sort(a + 1, a + n + 1);
    // 依次求和比较，这里不能直接用i来输出，需要设置一个k，因为可能会出现刚好全部满足的情况
    for(i = 1;i <= n;i++) {
        s += a[i];
        if(s > x) {
            break;
        } else {
            k++;
        }
    }
    cout << k << endl;
}
```
