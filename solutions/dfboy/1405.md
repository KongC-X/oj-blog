# 1405 - 小丽找潜在的素数

## 题目描述

小丽同学在编程中学到了二进制数的概念，她发现，有些二进制数，如果转为 $10$ 进制，就是素数，小丽把这些数称为潜在的素数；比如 $2$ 进制 $1101011$，转为 $10$ 进制后为 $107$ ，就是素数。

请编程帮小丽找出，哪些二进制数转为 $10$ 进制后，是素数，计算出这样的数有多少个？

## 输入

第一行是一个整数 $n$（$10 \le n \le 100$）。

接下来 $n$ 行，每行是一个 $30$ 位以内的 $2$ 进制数。

## 输出

一个整数代表所有转为 $10$ 进制后是素数的 $2$ 进制数的个数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int a, b;                        // a,b: 查询区间 [a, b]
bool f[100000010];               // f[i]: true 表示 i 是合数（或 0、1），false 表示素数

int main() {
    /*
      思路：
      1. 先看一个关键性质：
         除了 11 以外，所有偶数位的回文数都能被 11 整除，所以一定不是素数。
         结论：偶数位回文数中，只有 11 是素数，其余全是合数。
         因此 1e8 以内不存在 8 位回文质数，最大只需要考虑 7 位回文数（≤ 9999999）。
         所以可以把上界 b 截断到 1e7，大幅减少筛法的工作量。

      2. 用埃氏筛筛出 [0, b] 内的所有素数：
         f[i] = false 表示 i 是素数，f[i] = true 表示 i 是合数。
         0 和 1 特殊标记为 true（非素数）。

      3. 从 a 到 b 逐个枚举：
         如果 i 是素数，就把 i 反转得到 r，判断 r 是否等于 i。
         相等说明 i 是回文数，输出即可。

      时间复杂度：筛法 O(b log log b)，枚举判回文 O((b-a) * 位数)，
      在 b ≤ 1e7 时完全可行。
    */

    cin >> a >> b;

    // 偶数位回文数（8 位及以上）不可能是素数，截断上界
    if (b >= 10000000) b = 10000000;

    // 0 和 1 不是素数
    f[0] = true;
    f[1] = true;

    // ---------- 埃氏筛 ----------
    for (int i = 2; i * i <= b; i++) {
        if (!f[i]) {                         // i 是素数
            for (int j = i + i; j <= b; j += i) {
                f[j] = true;                 // 标记 i 的倍数为合数
            }
        }
    }

    // ---------- 枚举区间内每个数，判断素数 + 回文 ----------
    for (int i = a; i <= b; i++) {
        if (!f[i]) {                         // i 是素数
            // 反转 i
            int t = i;                       // t: 临时变量，用于逐位取出
            int r = 0;                       // r: i 反转后的数
            while (t != 0) {
                r = r * 10 + t % 10;
                t /= 10;
            }
            // 反转后与原数相等，说明是回文数
            if (r == i) {
                cout << i << endl;
            }
        }
    }

    return 0;
}




#include<bits/stdc++.h>
using namespace std;
int main(){
	ios::sync_with_stdio(0),cin.tie(0),cout.tie(0);
	long long a,b;
	cin>>a>>b;
	for(int i=a;i<=b;i++){
		if(i%2==0){//特判偶数
			continue;
		}
		int w=i,s=0;
		while(w!=0){//判断是否为回文数
			s=s*10+w%10;
			w/=10;
		}
		if(s!=i){
			continue;
		}
		int f=0;//判断是否为质数
		for(int j=2;j*j<=i;j++){
			if(i%j==0){
				f=1;
				break;
			}
		}
		if(f==0){
			cout<<i<<endl;
		}
	}
	
}
```
