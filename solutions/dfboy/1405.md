# 1405 - 小丽找潜在的素数

## 题目描述

小丽同学在编程中学到了二进制数的概念，她发现，有些二进制数，如果转为 $10$ 进制，就是素数，小丽把这些数称为潜在的素数；比如 $2$ 进制 $1101011$，转为 $10$ 进制后为 $107$ ，就是素数。

请编程帮小丽找出，哪些二进制数转为 $10$ 进制后，是素数，计算出这样的数有多少个？

## 输入

第一行是一个整数 $n$（$10 \le n \le 100$）。

接下来 $n$ 行，每行是一个 $30$ 位以内的 $2$ 进制数。

## 输出

一个整数代表所有转为 $10$ 进制后是素数的 $2$ 进制数的个数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 判断一个数字是否是素数
bool isPrime(int num) {
    if (num <= 1) {
        return false;
    }
    for (int i = 2; i <= sqrt(num); i++) {
        if (num % i == 0) {
            return false;
        }
    }
    return true;
}

int main(){
    string s;
    int n,i,j,x,k,t = 0;
    cin >> n;
    for(i = 0;i < n;i++){
        cin >> s;
        k = 0;
        for(j = s.size() - 1;j >= 0;j--) {
            x = (s[j] - '0') * pow(2, s.size() - j - 1);
            k += x;
        }
        if(isPrime(k)) {
            t++;
        }
    }
    cout << t << endl;
}
```
