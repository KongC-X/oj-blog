# 1701 - 请输出所有的3位对称数

## 题目描述

请输出所有的 $3$ 位对称数，对称数指的是一个整数 $n$ 正过来和倒过来是一样的，比如：$101、121、282 \dots $

请从小到大输出符合条件的3位对称数，每行 $1$ 个。

## 输入

无。

## 输出

从小到大按题意输出符合条件的数，每行 $1$ 个。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

bool cmp(int a,int b) {
    return a > b ? true : false;
}

int main() {
    int n,i;
    cin >> n;
    string s,s1;
    for(i = 0;i < n;i++) {
        cin >> s1;
        s += s1;
    }
    sort(s.begin(),s.end(),cmp);
    cout << s;
}
```
