# 1812 - 排名第二高的成绩

## 题目描述

帮老师统计一个班级 $N$ （$10 \lt N \lt 100$）个同学的考试成绩（成绩不可能全一样）中排名第二高的成绩是多少？

## 输入

第 $1$ 行有一个整数 $n$（$5 \lt n \lt 100$）。

第 $2$ 行有 $n$ 个整数，用空格隔开。

## 输出

输出排名第 $2$ 高的成绩。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

const int N = 100100;
int a[N];
int n,q; // n个数，q次查询

int fun(int x) {
    int l = 1,r = n,mid;
    while(l <= r) {
        mid = (l + r) >> 1; // 右移运算符，相当于/2
        if(x < a[mid]) r = mid - 1;
        else if(x > a[mid]) l = mid + 1;
        else if(x == a[mid]) l = mid + 1; // 相等右移
    }
    // l就是数组中第一个大于x的数的位置
    if(a[l - 1] == x) return l - 1;
    else return -1;
}

int main() {
    scanf("%d", &n);
    for(int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }
    scanf("%d", &q);
    int x;
    for(int i = 1; i <= q; i++) {
        scanf("%d", &x);
        // 求x在数组中首次出现的位置
        // cout << fun(x) << " ";
        printf("%d ", fun(x));
    }
}
```
