# 2348 - 最大公约数问题

## 题目描述

【具体要求】 
如果在已知两个正整数 x 和 y 的情况下，我们可以通过计算得到 x 和 y 唯一的最大公约数 a 和唯一的最小公倍数 b，但是反之，如果我们已知最大公约数 a 和最小公倍数 b，我们可能会得到多组正整数 x、y。  

现在要求编写一个程序，输入 a 和 b，直接输出有多少组数是以 a 为最大公约数和以 b 为最小公倍数。  

例如：以 3 为最大公约数，60 为最小公倍数，能得到（3，60）、（12，15）、（15，12）、（60，3）共四组 x、y。

## 输入

输入两个正整数 a 和 b（1 < a,b < 100），中间用空格隔开，分别表示最大公约数和最小公倍数。

## 输出

输出一个正整数，表示有多少组符合要求的 x、y。

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 函数：计算最大公约数
int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;
}

// 函数：计算以 a 为最大公约数和 b 为最小公倍数的正整数对的数量
int countPairs(int a, int b) {
    if (b % a != 0) {
        return 0; // b 必须是 a 的倍数
    }

    int k = b / a;
    int count = 0;

    // 寻找 k 的所有因子
    for (int m = 1; m * m <= k; ++m) {
        if (k % m == 0) {
            int n = k / m;

            // 检查 m 和 n 是否互质
            if (gcd(m, n) == 1) {
                count++; // (m, n) 是互质的
                if (m != n) {
                    count++; // (n, m) 也是互质的
                }
            }
        }
    }
    return count;
}

int main() {
    int a, b;
    cin >> a >> b;
    int result = countPairs(a, b);
    cout << result << endl;
    return 0;
}
