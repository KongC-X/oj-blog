# 1554 - 幸运数字

## 题目描述

小明认为，如果以下条件之一成立，正整数 $x$ 就是一个幸运数字:

$1.$ $x$ 是 $4$ 的倍数;

$2.$ $x$ 是 $7$ 的倍数;

$3.$  $x$ 转换为字符串后包含子串“ $44$ ”或“ $77$”。

例如，$105$ ( $7$ 的倍数), $442$ (包含“ $44$ ”), $1284$ ( $4$ 的倍数)都是幸运数字，$474$ 则不是。 编程统计 $1$ 到 $n$ 中幸运数字的数量。

## 输入

整数 $n$。 ($1 \le n \le 1,000,000$ )

## 输出

一个整数: $1, 2, \dots, n$ 中幸运数字的数量。

## 解题思路

## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

// a存储矩阵，q存储队列（遍历过的点）
char a[110][110];
int q[11000][4];
int n,m,i,j,tx,ty;
// head：头指针，tail：尾指针
int head = 1,tail = 1;
// 四个方向,右下左上
int fx[5] = {0,0,1,0,-1};
int fy[5] = {0,1,0,-1,0};
int s1,s2,e1,e2; // 起点和终点的行列坐标

int main() {
    cin >> n >> m;
    for(i = 1;i <= n;i++) {
        for(j = 1;j <= m;j++) {
            cin >> a[i][j];
            if(a[i][j] == '@') {
                s1 = i; // 起点行
                s2 = j; // 起点列
                a[i][j] = '.'; // 将终点标记为可访问
            } else if(a[i][j] == '*') {
                e1 = i; // 终点行
                e2 = j; // 终点列
                a[i][j] = '.'; // 将终点标记为可访问
            }
        }
    }
    // 1,1点存入队列，以1，1为head访问四个方向
    q[1][1] = s1;
    q[1][2] = s2;
    q[1][3] = 0; // 步数
    a[s1][s2] = '#'; // 标记起点为已访问
    // 当head <= tail时，说明队列还有点没有尝试标记过四个方向
    while(head <= tail) {
        // 尝试访问head的四个方向
        for(i = 1;i <= 4;i++) {
            // 从head对应的点加上四个方向的变化量得到新的点
            tx = q[head][1] + fx[i];
            ty = q[head][2] + fy[i];
            // 如果新的点在矩阵范围内，且没有被标记过，则标记
            if(a[tx][ty] == '.') {
                a[tx][ty] = '#'; // 标记代表走过了
                // 新的点存入队列，以新点为head访问四个方向
                tail++;
                q[tail][1] = tx;
                q[tail][2] = ty;
                q[tail][3] = q[head][3] + 1; // 步数加一

                if(tx == e1 && ty == e2) { // 如果到达终点，输出步数
                    cout << q[tail][3] << endl;
                    return 0;
                }
            }
        }
        head++; // head指向队列头的下一个点
    }
    cout << -1 << endl; // 如果没有到达终点，输出-1
}
```
