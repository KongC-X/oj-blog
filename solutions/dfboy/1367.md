# 1367 - 骨牌铺方格

## 题目描述

有 $1 \times n$（$n \le 50$）的一个长方形，用 $1 \times 1$、$1 \times 2$ 和 $1 \times 3$ 的骨牌铺满方格，请问有多少种铺法？

例如当 $n=3$ 时为 $1 \times 3$ 的方格。此时用 $1 \times 1$ 、$1 \times 2$ 和 $1 \times 3$ 的骨牌铺满方格，共有四种铺法。如下图：

## 输入

一个整数 $n$（$n \le 50$）

## 输出

骨牌的铺法。

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    int n,i,a,b,c,d;
    cin >> n;
    a = 1;
    b = 2;
    c = 4;
    for(i = 4;i <= n;i++) {
        d = a + b + c;
        a = b;
        b = c;
        c = d;
    }
    if(n == 1) {
        cout << 1 << endl;
    } else if(n == 2) {
        cout << 2 << endl;
    } else if(n == 3) {
        cout << 4 << endl;
    } else {
        cout << d << endl;
    }
}
```
