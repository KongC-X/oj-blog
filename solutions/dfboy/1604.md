# 1604 - 高精度除单精度

## 题目描述

请从键盘读入一个高精度整数 $a$（不超过 $100$ 位），再读入另一个单精度整数 $b$（$b$ 不超过 $8$ 位），请求出 $a$ 除以 $b$ 得到的商，是多少？

## 输入

输入有 $2$ 行，第一行有一个整数 $a$（不超过 $100$ 位），第二行有一个整数 $b$。

## 输出

请输出 `a/b` 得到的商。

## 解题思路

## AC代码

```cpp
# include <iostream>
# include <iomanip>
using namespace std;

int main() {
    double s,a,b,c;
    cin >> a >> b >> c;
    s = a + b + c;
    if(s >= 200) {
        cout << fixed << setprecision(1) << s * 0.8 << endl;
    } else {
        cout << fixed << setprecision(1) << s * 0.9 << endl;
    }
}
```
