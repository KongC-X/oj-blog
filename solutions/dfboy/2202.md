# 2202 - 二叉树是否对称

## 题目描述

假设一棵二叉树中**每个结点的两棵子树都是空，或者都不为空**，我们称该二叉树是对称二叉树。

给定一棵二叉树的字符串表示的结果，请编程判断，该二叉树是否是对称二叉树。

例如：下图所示的两棵二叉树中，$T_1$ 是对称二叉树，$T_2$ 不是对称二叉树。

二叉树用顺序结构给出，若读到 `#` 则该结点为空，二叉树 `T1=ABCDE`，`T2=ABCD#E`，如果二叉树是对称的，输出`Yes`,反之输出`No`。

## 输入

一行字符串，字符串仅包含**大写字母、小写字母、字符 `#` **这三种类型的字符，表示二叉树的顺序存储序列，用字符 `#` 代表空结点，长度不大于 $1000$ 。

## 输出

如果二叉树是对称的，输出 `Yes`，反之输出`No`。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 本题是按照完全二叉树的形式读入的二叉树，对于对称的判断方法是，只要每个结点的两个子树同时为空，或者同时不为空即可。
// 而两个相邻的子树结点在给定的字符串中一定是相邻的，因此可以判断，除了第1个结点（根）以外，其余相邻的结点都为 # 或者都为非 #，那么就是对称的。

string s;
int main() {
    cin >> s;
    if(s.size() % 2 == 0) {
        cout << "No";
        return 0;
    }
    for(int i = 1; i < s.size(); i = i + 2) {
        if(s[i] == '#' && s[i + 1] != '#' || s[i] != '#' && s[i + 1] == '#') {
            cout << "No";
            return 0;
        }
    }
    cout << "Yes";
    return 0;
}
```
