# 1505 - 整数的拼接

## 题目描述

设有 $n$ 个整数（$3 \le n \le 100$），将这些整数拼接起来，可以形成一个最大的整数。

例如：$n=3$，三个整数分别为 $21$ $7$ $34$， 拼接后最大的整数为：$73421$。

再比如：$n=3$，三个整数分别是 $1$ $10$ $110$，拼接后最大的整数是：$111010$。

## 输入

第一行一个整数 $n$ ，表示有 $n$ 个整数。

第二行 $n$ 个整数，数与数之间用一个空格分隔。

## 输出

输出一个拼接后的最大的整数。

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
	思路：
		s1="1",s2="10"
		s1+s2>s2+s1
		"110">"101"
		位数相同的两个数，字典码大的一定大
		1 10 110 排序后的结果：1 110 10 
*/

string s[110];
int n;

bool cmp(string s1,string s2){
	if(s1+s2>s2+s1){
		return true;
	}else{
		return false;
	}
}

int main(){
	cin>>n;
	for(int i=0; i<n; i++){
		cin>>s[i];
	}
	
	sort(s,s+n,cmp);
	
	for(int i=0; i<n; i++){
		cout<<s[i];
	}

	return 0;
}
```
