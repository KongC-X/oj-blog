# 1332 - 需要举办多少场足球赛？

## 题目描述

某市组织足球比赛，比赛方式为，$n$ 个球队要求必须都两两比$1$ 次，最后得胜最多的队伍获得总冠军（假设不存在两个队胜场一样多的情况）。

请问如果按照上述赛制，$n$ 个球队（$n \le 10$ ）要举行多少场比赛。（ $5.1.96$ ）

## 输入

一个整数 $n$ ，代表球队总数。

## 输出

一个整数代表共需举办多少场比赛。
## AC代码
## AC代码

```cpp
#include<iostream>
#include<cmath>
using namespace std;

int main() {
    int n,i,s = 0;
    cin >> n;
    for(i = n;i >= 1;i--) {
        s += n - i;
    }
    cout << s << endl;
}
```
