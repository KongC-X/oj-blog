# 2352 - 阶乘累加和

## 题目描述

【具体要求】  

数学课上，老师给同学们布置了一道家庭作业：计算从 1 到正整数 n（1 < n <= 20）之间每个正整数的阶乘累加和。当 n = 4 时，最终结果 s = 1! + 2! + 3! + 4! = 33。当数字逐渐增大时计算难度也在增大。  

小蓝通过编写程序来完成作业。

## 输入

输入一个正整数 n（1 < n <= 20）。

## 输出

输出最终的计算结果 s 。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

long long factorial(int n) {
    long long s = 1;
    for (int i = 1; i <= n; i++) {
        s *= i;
    }
    return s;
}

int main() {
    int n,i;
    cin >> n;
    long long s = 0;
    for (i = 1; i <= n; i++) {
        s += factorial(i);
    }
    cout << s << endl;
}
```
