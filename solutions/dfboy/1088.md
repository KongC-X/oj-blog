# 1088 - 求两个数M和N的最大公约数

## 题目描述

求两个正整整数 $M$ 和 $N$ 的最大公约数($M$，$N$都在长整型范围内）  

（5.1.42）

## 输入

输入一行，包括两个正整数。

## 输出

输出只有一行，包括 $1$ 个正整数。
## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;

long long fun(long long a,long long b) {
    if(a % b != 0) {
        return fun(b, a % b);
    } else {
        return b;
    }
}

int main() {
    long long a,b;
    cin>>a>>b;
    cout<<fun(a,b)<<endl;
}
```
