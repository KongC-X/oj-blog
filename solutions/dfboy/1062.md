# 1062 - 求落地次数

## 题目描述

小球从 $100$ 米高处自由落下，着地后又弹回高度的一半再落下。

经过多少次落地后，小球弹起的高度才会低于 $0.5$ 米？

## 输入

无。

## 输出

一行，一个整数。
## AC代码
## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int s = 0;
    double h = 100;
    while(h >= 0.5) {
        h /= 2.0;
        s++;
    }
    cout << s << endl;
}
```
