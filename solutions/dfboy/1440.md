# 1440 - 卫星照片

## 题目描述

农夫约翰总是想要一个农场的地图，所以他拍摄了一张 $N$ 行 $M$ 列的卫星照片。一部分的照片看起来像这样：

```
`..................
..#####.......##..
..#####......##...
..................
#.......###.....#.
#.....#####.......
`
```

他认为每个联通块都是一个谷仓或一头奶牛。联通块由若干个彼此水平或垂直相邻的 '＃' 符号组成。以下的照片被认为是两个联通块：

```
`....
.#..
..#.
....
`
```

农夫约翰认为一个联通块是谷仓，当且仅当它是一个完整的矩形，否则该联通块是一头奶牛。在第一张照片上面，有三个谷仓（大小分别为 $2 \times 1$ , $2 \times 5$ 和 $1 \times 1$ ）和两头奶牛。
计算他的卫星照片中谷仓和奶牛的数量。

## 输入

行 $1$：两个空格分隔的整数： $N$ 和 $M$ ( $N,M \le 80$)。

行 $2..N + 1$：行 $i + 1$ 表示照片的行 $i$ 包含 $M$ 个字符（且不含空格）。

## 输出

行1：照片中的谷仓数量。

行2：照片中的奶牛数量。

```cpp
#include <iostream>
#include <cstring>
using namespace std;

int N, M;
char a[85][85];
bool vis[85][85];          // 是否访问过
int q[6405][2];            // BFS 队列
int dx[4] = {0,1,0,-1};
int dy[4] = {1,0,-1,0};

int main() {
    cin >> N >> M;
    for (int i = 0; i < N; i++) {
        cin >> a[i];
    }

    int barn = 0, cow = 0;
    memset(vis, 0, sizeof(vis));

    for (int i = 0; i < N; i++) {
        for (int j = 0; j < M; j++) {
            if (a[i][j] == '#' && !vis[i][j]) {
                // BFS 找连通块
                int head = 0, tail = 0;
                q[tail][0] = i; q[tail][1] = j; tail++;
                vis[i][j] = true;

                int minR = i, maxR = i, minC = j, maxC = j;
                int cnt = 0;   // 连通块格子数

                while (head < tail) {
                    int r = q[head][0], c = q[head][1]; head++;
                    cnt++;
                    if (r < minR) minR = r;
                    if (r > maxR) maxR = r;
                    if (c < minC) minC = c;
                    if (c > maxC) maxC = c;

                    for (int d = 0; d < 4; d++) {
                        int nr = r + dx[d], nc = c + dy[d];
                        if (nr >= 0 && nr < N && nc >= 0 && nc < M && a[nr][nc] == '#' && !vis[nr][nc]) {
                            vis[nr][nc] = true;
                            q[tail][0] = nr; q[tail][1] = nc; tail++;
                        }
                    }
                }

                // 检查是否构成完整矩形
                int area = (maxR - minR + 1) * (maxC - minC + 1);
                if (cnt == area) barn++;
                else cow++;
            }
        }
    }

    cout << barn << "\n" << cow << endl;
    return 0;
}
```
