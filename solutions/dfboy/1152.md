# 1152 - 求n个数的最大值和最小值

## 题目描述

任意输入 $n$ 个整数，把它们的最大值，最小值求出来。

## 输入

输入只有一行，包括一个整数 $n$ ($1 \le n \le 20$),后面跟着 $n$ 个数， 每个数的范围在$0 \sim 32767$之间。

## 输出

输出只有一行,包括 $2$ 个整数。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;

int main(){
    int a[30],n,i,max,min;
    cin >> n;
    for(i = 0;i < n;i++){
        cin >> a[i];
    }
    max = 0; // 下标
    min = 0; // 下标
    for(i = 0;i < n;i++){
        if(a[i] > a[max]){
            max = i;
        }
        if(a[i] < a[min]){
            min = i;
        }
    }
    cout << a[max] << " " << a[min] << endl;
}
```
