# 1152 - 求n个数的最大值和最小值

## 题目描述

任意输入 $n$ 个整数，把它们的最大值，最小值求出来。

## 输入

输入只有一行，包括一个整数 $n$ ($1 \le n \le 20$),后面跟着 $n$ 个数， 每个数的范围在$0 \sim 32767$之间。

## 输出

输出只有一行,包括 $2$ 个整数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() { 
    int a[600];
    int n,r,i,s = 0;
    cin >> n >> r;
    for(i=1;i<=n;i++) cin >> a[i];
    sort(a+1,a+n+1);
    // for(i=1;i<=n;i++) cout << a[i] << " ";
    for(i=1;i<=n;i++) {
        if(i > r) {
            a[i] = a[i] + a[i - r];
        }
        s += a[i];
    }
    cout << s << endl;
}
```
