# 1779 - 装箱问题

## 题目描述

有一个箱子容量为 $V$（正整数，$0 \le V \le 200000$ ），同时有 $n$ 个物品（ $0 \lt n \le 30$ )，每个物品有一个体积（正整数）。

要求 $n$ 个物品中，任取若干个装入箱内，使箱子的剩余空间为最小。

## 输入

$1$ 个整数，表示箱子容量；

$1$ 个整数，表示有 $n$ 个物品；

接下来 $n$ 行，分别表示这 $n$ 个物品的各自体积；

## 输出

$1$ 个整数，表示箱子剩余空间。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int dp[35][200010]; // dp[i][j]表示前i个物品，容量为j时的最大装入体积
int v, n, a[35];

int main() {
    cin >> v >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    // 动态规划填充
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= v; j++) {
            if (j < a[i]) {
                dp[i][j] = dp[i-1][j]; // 放不下当前物品
            } else {
                dp[i][j] = max(dp[i-1][j], dp[i-1][j-a[i]] + a[i]); // 比较放与不放的情况
            }
        }
    }
    
    // 输出剩余空间
    cout << v - dp[n][v] << endl;
    return 0;
}
```
