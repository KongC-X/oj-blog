# 1041 - 判断三个整数是否相邻

## 题目描述

判断三个整数是否相邻，是输出 `TRUE`，否则输出`FALSE`。

## 输入

输入只有一行，包括3个整数。

## 输出

输出只有一行。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 定义vector类型的数组，数组中的每个元素都是一个vector
vector<int> a[1100];
int i,j,n,c,x;
int main() {
	cin >> n;
	for(i = 0;i < n;i++) {
		cin >> c;// 每个数组的大小
		for(j = 0;j < c;j++) {
			cin >> x;// 每个数组中的元素
			a[i].push_back(x);// 将元素添加到数组中
		}
		// 每一行的vector读入结束，直接排序
		sort(a[i].begin(),a[i].end());
	}
	sort(a,a + n); // 将数组按照字典从小到大的顺序排序
	// 输出
	for(i = 0;i < n;i++) {
	    for(j = 0;j < a[i].size();j++) {
	    	cout << a[i][j] << " ";
	    }
	    cout << endl;
	}
}
```
