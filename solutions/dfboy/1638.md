# 1638 - 判断正负数或零

## 题目描述

输入一个整数，判断它是正数、负数或零。  

输入输出要求：

输入的数是正数时，输出该数 $ \gt 0$ 。

输入的数是负数时，输出该数 $ \lt 0$ 。

输入的数是 $0$ 时，输出 $0=0$ 。

## 输入

一个整数 $n$。

## 输出

按题目要求输出判断结果。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	int n;
	cin>>n;
	
	//判断n与0的关系 
	if(n>0){
		cout<<n<<">0";
	}else if(n<0){
		cout<<n<<"<0";
	}else{
		cout<<"0=0";
	} 
	return 0;
}
```
