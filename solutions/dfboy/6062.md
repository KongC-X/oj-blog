# 6062 - 小球

## 题目描述

有 $n$ 个小球摆成一排，第 $i$ 个小球的颜色为 $c$，在这一排小球中，你可以选择其中连续的 $K$ 个小球并且获得他们。

你喜欢五彩缤纷的颜色，所以你获得的小球不同颜色越多，就越高兴，输出你能获得的最多的小球颜色数。

## 输入

第一行，两个数字 $n$ 和 $k$，表示一共有多少个小球，以及你可以选择获得其中连续的 $K$ 个小球。

第二行，$n$ 个数字，表示每个小球的颜色 $c_i$。

## 输出

一行，一个整数，表示你能获得的最多小球的颜色数量。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 300005;
int a[MAXN];                      // 小球颜色序列

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, k;                     // n: 小球总数，k: 连续选取的长度
    cin >> n >> k;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    // ---------- 思路 ----------
    // 问题：求长度为 K 的连续子数组中不同颜色数的最大值。
    // 采用滑动窗口：维护一个长度为 K 的窗口，用 map 记录窗口内每种颜色的出现次数。
    // 滑动时更新不同颜色计数，并维护最大值。
    // 时间复杂度 O(n log n)（若使用 unordered_map 可期望 O(n)），空间 O(n)。

    unordered_map<int, int> cnt;  // 记录窗口内每种颜色的出现次数
    int distinct = 0;             // 当前窗口内不同颜色的数量

    // 初始化第一个长度为 K 的窗口
    for (int i = 0; i < k; i++) {
        if (cnt[a[i]] == 0) distinct++;
        cnt[a[i]]++;
    }
    int ans = distinct;

    // 滑动窗口：每次移除左端点颜色，添加右端点颜色
    for (int i = k; i < n; i++) {
        // 移除左端点（下标 i-k）
        cnt[a[i - k]]--;
        if (cnt[a[i - k]] == 0) distinct--;

        // 添加右端点（下标 i）
        if (cnt[a[i]] == 0) distinct++;
        cnt[a[i]]++;

        if (distinct > ans) ans = distinct;
    }

    cout << ans << '\n';
    return 0;
}
```
