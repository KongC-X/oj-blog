# 1317 - 正多边形每个内角的度数？

## 题目描述

根据多边形内角和定理，正多边形内角和等于：（ $n － 2$ ） $\times$ $180^\circ$ ( $n$ 大于等于 $3$ 且 $n$ 为整数）（如下图所示是三角形、四边形、五边形、六边形的形状）。

请根据正多边形的边数，计算该正多边形每个内角的度数。（结果保留$1$位小数）。（4.1.83）

## 输入

正多边形的边数 $n$ （ $n \ge 3$  且 $n  \le 10$ ）。

## 输出

该正 $n$ 边形每个内角的度数。

## 解题思路

## AC代码
## AC代码

```cpp
#include <iostream>
#include <iomanip>
using namespace std;
 
int main (){
	// 定义变量 n 作为正多边形的边数 
    int n;
    cin>>n;
    // 定义一个小数变量 d 作为每个内角的度数 
	// 按照公式计算每个内角的度数 
    double d=(n-2)*180.0/n;
    // 输出结果并保留 1 位小数 
    cout<<fixed<<setprecision(1)<<d;
}
```
