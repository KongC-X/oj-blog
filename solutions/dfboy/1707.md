# 1707 - 淘淘的零花钱

## 题目描述

小明和淘淘一起玩，小明问淘淘：“淘淘，你爸爸给你多少零花钱？”淘淘没有直接回答，反问了一句：“你有多少？”小明就把自己零花钱的数目告诉了淘淘，淘淘说：“真巧，我的刚好相反。” 

  你能根据小明的零花钱数目算出淘淘的零花钱数目吗？

## 输入

一个两位整数，表示小明的零花钱数目。

## 输出

一个整数，表示淘淘的零花钱数目。

## 解题思路
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	//定义变量p代表零花钱数 
	int p;
	//输入p 
	cin>>p;
	
	cout<<p/10+p%10*10; 
	return 0;
}
```
