# 1118 - 既生瑜，何生亮！

## 题目描述

某数的平方是 $7$ 位数，且这 $7$ 个数字不相同，如$1267^2$ = $1605289$。 编写程序，输入 $x$ ，$y$ （ $1000 \le x \le y \le 9999$ ）在 $x \sim y$ 的范围内找出所有符合条件的数并打印出来。

## 输入

一行，两个整数。

## 输出

若干行，每行一个符合条件的数。

```cpp
#include <bits/stdc++.h>
using namespace std;

//判断某个数是否是7位数，且各个位不相等
bool fun(int n){
	if(n < 1000000 || n > 9999999) return false;
	
	//判断n各个位互不相等
	//数组计数法，统计n的各个位出现的次数 
	int a[20] = {0};
	while(n != 0){
		a[n % 10]++;
		n = n / 10;
	} 
	
	//判断是否有某个数出现了不止1次 
	for(int i = 0;i <= 9;i++){
		if(a[i] > 1) return false;
	}
	
	return true; 
} 

int main(){
	int x,y;
	cin>>x>>y;
	for(int i = x;i <= y;i++){
		if(fun(i*i)) cout<<i<<endl; 
	}
    return 0;
}
```
