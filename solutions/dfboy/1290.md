# 1290 - 二进制转换十进制

## 题目描述

请将一个 $25$ 位以内的 $2$ 进制正整数转换为 $10$ 进制！

## 输入

一个 $25$ 位以内的二进制正整数。

## 输出

该数对应的十进制。
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s;
    int t = 1,x = 0,i;
    cin >> s;
    // 11001
    for(i = s.size() - 1;i >= 0;i--) {
        x = x + (s[i] - '0') * t;
        t = t * 2;
    }
    cout << x << endl;
}
```
