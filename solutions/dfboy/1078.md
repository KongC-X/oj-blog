# 1078 - 求恰好使s=1+1/2+1/3+…+1/n的值大于X时n的值。

## 题目描述

求恰好使 $s=1+1/2+1/3+ \dots +1/n $ 的值大于 $X$ 时 $n$ 的值。( $2 \le x \le 10$ )

## 输入

输入只有一行，包括 $1$ 个整数 $X$ 。

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。
## AC代码
## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int i = 1,x;
    double s = 0;
    cin >> x;
    while(s <= x) {
        s += 1.0 / i;
        i++;
    }
    cout << i - 1 << endl;
}
```
