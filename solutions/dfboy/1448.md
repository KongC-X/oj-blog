# 1448 - 随机体能测试

## 题目描述

学校想随机抽取一部分同学参加体能测试，看看同学们的体能怎么样。

张老师想了一个办法，找出学号中含有 $1$ 的同学，让他们参加体能测试；如果某同学的学号含有 $1$ 个 $1$ ，那么要测试 $1$ 次，如果含有 $2$ 个 $1$ ，就要参加 $2$ 次测试。

比如：小明同学的学号为 $1211$ ，那么他就要参加 $3$ 次测试。

请问，学号 $1 \sim n$ 中的同学们，总共要参加多少次测试？

## 输入

一个整数 $n（n \le 9999）$ 。

## 输出

一个整数，代表 $1 \sim n$ 号同学总共要参加测试的次数。
## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	int n,s=0;//s用作记录总共参加测试的次数 
	cin>>n;
	//遍历 1-n号同学 
	for(int i=1;i<=n;i++){
		int num=0,t=i;//num用作记录i号同学要参加测试的次数 
		//循环记录出i中有几个1 
		while(t>0){
			if(t%10==1){
				num++;
			}
			t=t/10;
		}
		//添加到总次数中 
		s+=num;
	}

	cout<<s; 
	return 0;
}
```
