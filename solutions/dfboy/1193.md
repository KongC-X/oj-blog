# 1193 - 斜角II

## 题目描述

输入整数 $N$ ，输出相应方阵。

## 输入

一个整数 $N$ 。（ $0 \lt N \le 10$ )

## 输出

一个方阵，每个数字的场宽为 $3$ 。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int total = 0;
    string a[100]; // 最多100个子串
    int c = 0;
    for(int i = 0; i < s.size() - 2; i++) {
        if(s[i] != s[i+1] && s[i+1] == s[i+2]) {
            string t = s.substr(i, 3);
            total++;
            // 检查是否已经记录过该子串
            bool flag = false;
            for (int j = 0; j < c; ++j) {
                if (a[j] == t) {
                    flag = true;
                    break;
                }
            }
            if (!flag) {
                a[c] = t;
                c++;
            }
        }
    }

    cout << total << " " << c << endl;

    return 0;
}
```
