# 1073 - 沙漏

## 题目描述

赵老师最近在编一个操作系统，正好编到鼠标的繁忙状态，需要一个沙漏符号，正好大家都在学 $C++$ ，你的任务就是帮赵老师编一个程序打印一个沙漏符号。

## 输入

一个整数 $n$ ，符号的行数（保证 $n$ 是大于 $1$ 的奇数）。

## 输出

沙漏符号，使用 `*` 打印。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
n行的沙漏：由n/2+1行倒三角 + n/2+1行正三角组成
中间有一个*是公用的
*/
int main() {
	int n;
	cin>>n;
	n = n / 2 + 1;//得到一半的三角的行数

	for(int i = n; i >= 1; i--) {
		for(int j = 1; j <= n - i; j++) {
			cout<<" ";
		}

		for(int j = 1; j <= 2 * i - 1; j ++) {
			cout<<"*";
		}
		cout<<endl;
	}

	//正三角
	/*
	  n = 3
	  i=1 2个空格 1个星
	  i=2 1个空格 3个星
	  i=3 0个空格 5个星
	  第i行 n-i个空格 2 * i - 1个星
	*/
	for(int i = 2; i <= n; i++) {
		for(int j = 1; j <= n - i; j++) {
			cout<<" ";
		}

		for(int j = 1; j <= 2 * i - 1; j ++) {
			cout<<"*";
		}
		cout<<endl;
	}
	return 0;
}
```
