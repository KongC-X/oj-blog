# 1090 - 同因查找

## 题目描述

求出 $10$ 至 $1000$ 之内能同时被 $2、3、7$ 整除的数，并输出。

每行一个。

## 输入

无

## 输出

按要求输出满足条件的数，每行 $1$ 个。
## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
 
int main() {
    int i;
	//遍历范围为10到1000 
    for(i=10;i<=1000;i++){
    	//能同时被2、3、7整除的i输出 
        if(i%2==0&&i%3==0&&i%7==0){
            cout<<i<<endl;
        }
    }
    return 0;
}
```
