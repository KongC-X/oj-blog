# 1887 - 连胜王

## 题目描述

在篮球比赛中，连胜是一件让球迷非常兴奋的事情。现给出 $n$ 场比赛的获胜队伍编号，请求出哪个队伍连胜的场次最多？

本题的输入确保获得连胜场次最多的球队，只有 $1$ 个。

比如，输入 $6$ 场比赛获胜队伍数据如下：$1$ $2$ $2$ $2$ $6$ $6$；

那么，$1$ 号队没有获得过连胜，$2$ 号队连胜 $3$ 场，$6$ 号队连胜 $2$ 场，获得连胜场次最多的球队是 $2$ 号队。

## 输入

第 $1$ 行有一个整数 $n$ ，代表比赛的场数。（$5≤n≤100$）

第 $2$ 行有 $n$ 个整数，分别代表了每场比赛获得胜利的球队的编号。

## 输出

输出连胜场次最多球队的编号。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
思路：
1.统计每个数连续出现了几次；
2.打擂台求出连续出现次数最多的数； 
*/
/*
 ma：代表连续相同的数最多出现的次数
 r：代表连续出现最多次的数，是哪个数 
*/
int n,a[110],c = 0,ma = 0,r;

int main() {
	cin>>n;
	for(int i = 0;i < n;i++){
		cin>>a[i];
	}
	
	//统计连续相等的数出现的次数
	for(int i = 0;i < n;i++){
		c++;
		//判断连续相等的数是否结束
		if(i==n-1||a[i]!=a[i+1]){
			//cout<<a[i]<<" "<<c<<endl;
			if(c > ma){
				ma = c;//替换次数 
				r = a[i];//替换结果 
			}
			
			c = 0;
		} 
	} 
	
	cout<<r; 
	return 0;
}
```
