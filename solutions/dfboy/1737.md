# 1737 - 奇怪的数？

## 题目描述

小明最近刚刚学习数学，回家后老师布置了一道题目：要求小明找出满足条件的奇怪整数：

$A$ 、该数为四位数

$B$ 、该数的千位和十位对调，百位和个位对调后，仍然等于本身

$C$ 、该数为奇数。

你能帮助小明找到满足以上条件的奇怪整数吗？

## 输入

输入一个整数 $n(n \ge 1000)$ 。

## 输出

$n$ 以内的奇怪整数，每行一个。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;

int pk[55];

int main() {
	int n;
	cin >> n;
	for(int i = 1; i <= n; i++) {
		char t, c;
		cin >> t >> c;
		int m;
		if(t == 'S') m = 0;
		else if(t == 'H') m = 13;
		else if(t == 'C') m = 26;
		else m = 39;
		if(c == 'A') m += 1;
		else if(c == 'T') m += 10;
		else if(c == 'J') m += 11;
		else if(c == 'Q') m += 12;
		else if(c == 'K') m += 13;
		else m += (int)(c - '0');
		pk[m] = 1;
	}
	int cnt = 0;
	for(int i = 1; i <= 52; i++) {
		if(pk[i] == 0)
			cnt++;
	}
	cout << cnt << endl;
	return 0;
}
```
