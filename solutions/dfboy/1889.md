# 1889 - 多重背包（2）

## 题目描述

有 $N$ 种物品和一个容量是 $V$ 的背包。

第 $i$ 种物品最多有 $s_i$ 件，每件体积是 $v_i$，价值是 $w_i$ 。

求解将哪些物品装入背包，可使物品体积总和不超过背包容量，且价值总和最大。

输出最大价值。

## 输入

第一行两个整数，$N$，$V$，用空格隔开，分别表示物品种数和背包容积。

接下来有 $N$ 行，每行三个整数 $v_i,w_i,s_i$，用空格隔开，分别表示第 $i$ 种物品的体积、价值和数量。

## 输出

输出一个整数，表示最大价值。

数据范围：

$0 \lt N \le 1000$, $0 \lt V \le 2000$, $0 \lt v_i,w_i,s_i \le 2000$。

## AC代码

```cpp
// 核心思想： 不要将第 i 种物品简单地拆分成 s[i] 个单独的物品。而是利用二进制的思想，将其拆分成 O(log s[i]) 个新的“组合物品”。这些组合物品经过精心设计，使得用它们进行 0-1 背包选择时，能够等价地表示出选取 0 到 s[i] 件原物品 i 的所有可能情况。
// 任何整数都可以用 2 的幂次方的和唯一表示（二进制表示）。例如 7 = 1 + 2 + 4，10 = 2 + 8（或者 1 + 2 + 4 + 3，但需注意拆分方法）。

#include <bits/stdc++.h> // 万能头文件
#include <iostream>
using namespace std;

const int N = 20010;
int v[N],w[N],dp[2010];
int n,m; // n为物品数量，m为背包容量
int vi,wi,si;
int k = 0;

int main() {
    cin >> n >> m;
    for(int i = 1; i <= n; i++){
        cin >> vi >> wi >> si;
        // 对si二进制化，比如：
        // 有10件一样的物品，转换为有4件不同的物品：1 2 4 3
        // 这4种物品的体积分别为：1*vi 2*vi 4*vi 3*vi
        int t = 1; // 权重，表示2的次方
        while(t <= si) {
            k++; // 物品数量+1
            v[k] = t * vi;
            w[k] = t * wi;
            si = si - t;
            t = t * 2;
        }
        // 如果si不为0，说明有剩余，则直接加上
        if(si > 0) {
            k++;
            v[k] = si * vi;
            w[k] = si * wi;
        }
    }
    // 01背包
    for(int i = 1; i <= k; i++){
        for(int j = m; j >= v[i]; j--){
            dp[j] = max(dp[j],dp[j-v[i]]+w[i]);
        }
    }
    cout << dp[m] << endl;
}
```
