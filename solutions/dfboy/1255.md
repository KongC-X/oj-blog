# 1255 - 分数之和

## 题目描述

求这样的四个自然数 $p,q,r,s$($p \le q \le r \le s$)，使得以下等式成立：$1/p+1/q+1/r+1/s=1$，请输出所有满足条件的不重复的解。

按照字典序从小到大，前 $4$ 组满足条件的解为：

```
`2 3 7 42
2 3 8 24
2 3 9 18
2 3 10 15
...
`
```

## 输入

无

## 输出

输入若干行，每行分别输出 $p$ $q$ $r$ $s$，之间用一个空格符分开。

按照字典序升序的顺序输出结果。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
	for(int p = 2;p <= 4;p++){
		for(int q = p;q <= 6;q++){
			for(int r = q;r <= 12;r++){
				//分母不能为0 
				if(p*q*r-q*r-p*r-p*q == 0) continue;
				//前三项确定，计算出第4项
				int s = p*q*r/(p*q*r-q*r-p*r-p*q);
				if(p*q*r%(p*q*r-q*r-p*r-p*q)==0&&s>=r){
					cout<<p<<" "<<q<<" "<<r<<" "<<s<<endl;
				}
			}
		}
	}
	return 0;
}
```
