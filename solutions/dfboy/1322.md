# 1322 - 求数的量级？

## 题目描述

有一个很大的整数 $n$（ $n \ge 10000$ 且 $n \le 9999999999$ ），请问该数的最高位是什么量级的，输出该量级的拼音？

可选单位：万（ `wan` ）、十万（ `shi  wan` ）、百万（ `bai wan` ）、千万（ `qian wan` ）、亿（ `yi` ）、十亿（ `shi yi` ）。

如：$n=123456789$ ，则输出： `yi`。

$（4.2.15）$。

## 输入

一个很大的整数 $n$ （ $n \ge 10000$ 且 $n \le 9999999999$ ）。

## 输出

$n$ 量级的拼音。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
#include<iostream>
using namespace std;

/*
策略：要优先赢得人数较少的洲的支持
1. 如果有m个洲，要赢得m/2+1个洲的支持 
2. 如果第j个洲有a[j]个人，要赢得a[j]/2+1个人的支持 
*/ 
int n,m,a[110],c;
int main() {
    cin>>n;
    //读入n组数据
	for(int i = 1;i <= n;i++){
		//读入m个洲的信息
		cin>>m;
		for(int j = 1;j <= m;j++){
			cin>>a[j];
		} 
		
		//对本洲人数排序
		sort(a+1,a+m+1); 
		
		//计算最少要赢得多少个人的支持
		c = 0;
		for(int j = 1;j <= m / 2 + 1;j++){
			c = c + (a[j] / 2 + 1);
		}
		
		cout<<c<<endl;
	} 
}
```
