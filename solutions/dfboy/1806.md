# 1806 - 是什么数列？

## 题目描述

小明学习了等差数列和等比数列的知识。

等差数列是指从第二项起，每一项与它的前一项的差都是相等的。比如数列：$1$ $3$ $5$ $7$ $9$和数列：$9$  $7$   $5$  $3$  $1$ 都是等差数列。

等比数列是指从第二项起，每一项与它的前一项的比值都是相等的。比如数列：$1$  $2$  $4$  $8$  $16$ 和数列：$16$  $8$  $4$  $2$  $1$ 都是等比数列。

现从键盘读入 $n$ 个整数，判断是等差数列还是等比数列，如果是等差数列，请输出`dengcha`，如果是等比数列，请输出`dengbi`，如果两种数列都不是，请输出`no`。

本题中等差数列的差值和等比数列的比值，一定是整数。

## 输入

第一行有 $1$ 个整数 $n$ 。（$5 \le n \le 100$）

第二行有 $n$ 个不相同的整数，用空格隔开。（这 $n$ 个数都是$1 \sim 1000$之间的整数）

## 输出

如果是等差数列，请输出`dengcha`，如果是等比数列请输出`dengbi`，如果都不符合，请输出`no`。

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;
// (a+b)*c
string s,s1,s2,s3;
int x,y,z;
int main(){
	cin>>s;
	int p = s.find("+");
    int q = s.find("*");
	s1 = s.substr(1,p - 1);
	s2 = s.substr(p + 1,q - p - 2);
    s3 = s.substr(q + 1);
	// cout<<s1 << " " << s2 << " " << s3;
	
	//转换整数
	x = stoi(s1);
	y = stoi(s2);
	z = stoi(s3);
	cout << (x + y) * z << endl; 
	return 0;
}
```
