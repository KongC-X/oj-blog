# 1404 - 有趣的斜角？

## 题目描述

输入一个整数 $n（n \lt 10$），输出 $n$ 行 $n$ 列的如下图所示的数字图形。

## 输入

一个整数 $n$ 。（ $1 \lt n \lt 10$ )

## 输出

一个方阵，每个数字的场宽为 $5$ 。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int a[20][20];

int main() {
    int n, id = 1;
    cin >> n;
    for(int i = 0; i < n; i++) {
        for(int j = 1; j <= n; j++) {
            for(int k = 1; k <= n; k++) {
                if(k - j == i) {
                    a[j][k] = id;
                    if(j != k)
                        a[k][j] = id;
                    id++;
                }
            }
        }
    }
    for(int i = 1; i <= n; i++) {
        for(int j = 1; j <= n; j++) {
            cout << setw(5) << a[i][j];
        }
        cout << endl;
    }
    return 0;
}
```
