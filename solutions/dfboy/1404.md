# 1404 - 有趣的斜角？

## 题目描述

输入一个整数 $n（n \lt 10$），输出 $n$ 行 $n$ 列的如下图所示的数字图形。

## 输入

一个整数 $n$ 。（ $1 \lt n \lt 10$ )

## 输出

一个方阵，每个数字的场宽为 $5$ 。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n,a[110];//记录每个父有几个子
 
int main(){
	cin>>n;
	int x,y;
	for(int i = 1;i < n;i++){
		cin>>x>>y;
		a[x]++;
	} 
	
	//输出结果
	for(int i = 1;i <= n;i++){
		cout<<a[i]<<" ";
	} 
    return 0;
}
```
