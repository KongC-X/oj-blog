# 2185 - 子树的大小

## 题目描述

有如上图所示的完全二叉树，该二叉树有 $n$ 个结点，编号从上向下、从左向右以此为 $1 \sim n$。请问，编号为 $m$ 的结点所在的子树，包含了多少个结点？

比如，$n = 12$，$m = 3$，则上图中的结点 $13$，$14$，$15$ 以及后面的结点都是不存在的，结点 $m=3$ 所在子树中包括的结点有 $3$，$6$，$7$，$12$，因此结点 $m$ 的所在子树中共有 $4$ 个结点。

## 输入

输入两个整数 $m$，$n$。 ($1 \le m \le n \le 10^9$)

## 输出

输出结点 $m$ 所在子树中包含的结点的数目。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
1.从结点m开始求该结点的右孩子的编号，如果该编号存在，每层满的二叉树的深度+1
从而可以求出除了最后一层以外的每层满的部分的二叉树有多少个结点
2.计算最后一层第1个结点的编号，判断最后一层（不满）是否存在
如果存在，加上最后一层的结点数量 
*/
int n,m;
int cnt = 0;//每层都满的二叉树的层数
int ans = 0;//结点的总数量 

int main(){
	cin>>m>>n;
	for(int i = m;i <= n;i = i * 2 + 1){
		cnt++;
	}
	
	ans = (1<<cnt) - 1;//2^cnt - 1
	//求出最后一层不满的（假设存在）第1个结点的编号
	int s = m * (1<<cnt);
	if(s <= n) ans += n - s + 1;
	
	cout<<ans;
	return 0;
}
```
