# 1168 - 歌唱比赛评分

## 题目描述

四（$1$） 班要举行一次歌唱比赛，以选拔更好的苗子参加校的歌唱比赛。评分办法如下：设 $N$ 个评委，打 $N$ 个分数（ $0 \le $ 每个分数 $ \le  10$ ），去掉一个最高分，去掉一个最低分，剩下的评委的平均分即为该选手的最后得分。

但是选手太多了，靠人工计算每个选手的得分太慢太麻烦。你能不能帮帮他们，设计一个程序让计算机来算出选手的最后得分呢？（ $4.1.53$ ）

## 输入

第一行为一个整数 $N$ （$ 5 \le N \le  10 $）；

第二行为 $N$ 个整数 $Ai$ （$ 0 \le  Ai \le  10$ ）。

## 输出

选手的最后得分（保留两位小数）。
