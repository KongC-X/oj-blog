# 1168 - 歌唱比赛评分

## 题目描述

四（$1$） 班要举行一次歌唱比赛，以选拔更好的苗子参加校的歌唱比赛。评分办法如下：设 $N$ 个评委，打 $N$ 个分数（ $0 \le $ 每个分数 $ \le  10$ ），去掉一个最高分，去掉一个最低分，剩下的评委的平均分即为该选手的最后得分。

但是选手太多了，靠人工计算每个选手的得分太慢太麻烦。你能不能帮帮他们，设计一个程序让计算机来算出选手的最后得分呢？（ $4.1.53$ ）

## 输入

第一行为一个整数 $N$ （$ 5 \le N \le  10 $）；

第二行为 $N$ 个整数 $Ai$ （$ 0 \le  Ai \le  10$ ）。

## 输出

选手的最后得分（保留两位小数）。
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int a[20],n;
//将最大数设置为整数的最小值
//最小数，设置为整数的最大值 
int ma=INT_MIN,mi=INT_MAX; 
double s;
int main() {
	int i;
	cin>>n;
	for(i=0; i<n; i++) {
		cin>>a[i];
		//打擂台求最大、最小 
		if(a[i] > ma) ma = a[i];
		if(a[i] < mi) mi = a[i];
		
		s = s + a[i];//求和 
	}

	cout<<fixed<<setprecision(2)<<(s - ma - mi)/(n-2);
}
```
