# 1102 - 字符串中的空格移位

## 题目描述

输入一个字符串，将其中的所有空格都移到最前面，然后输出。

## 输入

一个字符串。如：a□b□c（为了能看清空格，□代表一个空格，但实际测试数据中不用□表示空格）

## 输出

空格全部移到了串前的字符串。如：□□abc

## 解题思路

## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int a[20],i,n;
    cin >> n;
    for(i = 0; i < n; i++) {
        cin >> a[i];    
    }
    // 从小到大冒泡排序
    for(i = 0; i < n - 1; i++) {
        for(int j = 0; j < n - i - 1; j++) {
            if(a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }
    for(i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
}
```
