# 1170 - 最大数

## 题目描述

$n$ 个数中最大的那个数在哪里？输出其位置，若有多个最大数则都要输出。

## 输入

第一行： $n$ （ $3 \le  n \le  10$） ；

第二行：空格隔开的 $n$ 个数。

## 输出

输出若干个数，表示最大数的位置，每行一个。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
/*
1.求最大数
2.求哪些位置的数是最大数 
*/ 
int main()
{
    int n,i,a[20],max=INT_MIN;//求最大数 ;
    cin>>n;
    for(i=0;i<n;i++)
    {
        cin>>a[i];
        if(a[i]>max)
        {
            max=a[i];
        }
    }
    //求哪些位置的数是最大的 
    for(i=0;i<n;i++)
    {
        if(a[i]==max)
        {
            cout<<i+1<<endl;
        }
    }
    return 0;
}
```
