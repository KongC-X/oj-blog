# 1502 - 数字翻转

## 题目描述

给定一个 $N$ 个数的数组， $M$ 次操作。每次操作将数组的一段翻转，求最后的数组。（提示：可以尝试 $reverse$ 函数）

## 输入

第一行两个整数 $N$，$M$（$N,M \le 1000$）含义见试题描述。

第二行 $N$ 个整数，表示原来的数组。

接下来 $M$ 行，每行两个整数 $X,Y$（$1 \le X \le Y \le N$），表示翻转区间 $[X,Y]$ 。

## 输出

一行 $N$ 个整数，表示操作后的数组。

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

vector<int> a;
int n,m,x,y,i,j;
int main() {
	cin >> n >> m;
	for(i = 0;i < n;i++) {
		cin >> x;
		a.push_back(x);
	}
	while(m--) {
		cin >> x >> y;
		reverse(a.begin() + x - 1,a.begin() + y);
	}
	for(i = 0;i < n;i++) {
		cout << a[i] << " ";
	}
}
```
