# 1502 - 数字翻转

## 题目描述

给定一个 $N$ 个数的数组， $M$ 次操作。每次操作将数组的一段翻转，求最后的数组。（提示：可以尝试 $reverse$ 函数）

## 输入

第一行两个整数 $N$，$M$（$N,M \le 1000$）含义见试题描述。

第二行 $N$ 个整数，表示原来的数组。

接下来 $M$ 行，每行两个整数 $X,Y$（$1 \le X \le Y \le N$），表示翻转区间 $[X,Y]$ 。

## 输出

一行 $N$ 个整数，表示操作后的数组。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main()
{
	int i,j,x,n,sum=0,a[10010];
	cin>>n>>x;
	for(i=1;i<=n;i++)       
   cin>>a[i];
   for(i=1;i<=n-1;i++)
   for(j=1;j<=n-i;j++)
       if(a[j]>a[j+1]) swap(a[j],a[j+1]);
	for(i=x+1;i<=n-x;i++)
    	sum=sum+a[i];
	cout<<fixed<<setprecision(1)<<(sum*1.0)/(n-x*2)<<endl;
return 0;
}
```
