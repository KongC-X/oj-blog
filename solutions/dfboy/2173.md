# 2173 - 连续的最长偶数序列

## 题目描述

从键盘读入 $n$ 个整数，请问这 $n$ 个整数中，连续的偶数最多有多少个？

## 输入

第 $1$ 行输入一个整数 $n$ （$n≤100$）；

第 $2$ 行读入 $n$ 个整数，数字之间用空格隔开；

## 输出

输出一个整数，代表连续偶数的最长序列有多长。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <iomanip>
#include <bits/stdc++.h>
using namespace std;

int n;
char a[50][50]; // 初值为\0
int r[410][3]; // 记录正确的第一条路径

// 本题要求按照左上右下的顺序，所以这里要修改顺序
int fx[5] = {0,0,-1,0,1};
int fy[5] = {0,-1,0,1,0};

// 深度优先搜索，k是路径数组的下标
void dfs(int x,int y,int k) {
    // 记录探索到的点的坐标
    r[k][1] = x;
    r[k][2] = y;
    a[x][y] = '1'; // 将走过的点设为1防止死循环
    // 如果xy是终点了，就打印路径
    if(x == n && y == n) {
        for(int i = 1;i <= k;i++) {
            cout << "(" << r[i][1] << "," << r[i][2] << ")";
            // 如果i不是最后一个点，就打印箭头
            if(i != k) cout << "->";
        }
        exit(0); // 退出程序
    }
    int tx,ty;
    for(int i = 1;i <= 4;i++) {
        tx = x + fx[i];
        ty = y + fy[i];
        if(a[tx][ty] == '0') {
            dfs(tx,ty,k+1);
        }
    }
}

int main(){
    cin >> n;
    for(int i=1;i<=n;i++){
        for(int j=1;j<=n;j++){
            cin >> a[i][j];
        }
    }
    dfs(1,1,1);
}
```
