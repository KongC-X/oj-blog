# 1815 - 最后一次出现该数的位置

## 题目描述

从键盘输入一个整数 $N$ ，输入 $N$ ($5 \le N \le 100$)个元素，输入一个整数，判断这个数组中最后一次出现该数的位置，如果没有请输出$-1$。

## 输入

第 $1$ 行读入一个整数 $N$。（$5 \le N \le 100$）

第 $2$ 行读入 $n$ 个整数用空格隔开。

第 $3$ 行读入 $1$ 个整数，代表要找的数。

## 输出

输出 $1$ 个整数，代表最后一次出现整数的位置，如果数组中不存在这样的数，请输出 $-1$。

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 定义函数，判断一个字符数组是否回文
bool huiwen(char s[]) {
    int len = strlen(s);
    for (int i = 0; i < len / 2; i++) {
        if (s[i] != s[len - i - 1]) {
            return false;
        }
    }
    return true;
}

int main() {
    char s[1000];
    cin >> s;
    // 当s是可能接触过镜面的字符串就循环
    // 回文并且长度必须得是偶数，因为aba不满足
    while(huiwen(s) && strlen(s) % 2 == 0) {
        s[strlen(s) / 2] = '\0';
        // 将字符串中间的字符置为\0，即可实现字符串长度减半
    }
    cout << strlen(s) << endl;
}
```
