# 1863 - 特殊的数字四十

## 题目描述

$1234$ 是一个非常特殊的四位数，因为它的各位数之和为 $10$ ，编程求所有这样的四位整数。

## 输入

无。

## 输出

按从小到大的顺序输出满足条件的四位数。每个数字占用一行。
## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
 
int main() {
    int i,q,b,s,g,sum;
    //遍历所有的四位数 
    for(i=1000;i<=9999;i++){
        q=i/1000;
        b=i/100%10;
        s=i%100/10;
        g=i%10;
        //求各位数字和 
        sum=q+b+s+g;
        //如果各位数字和等于10就输出这个数 
        if(sum==10){
            cout<<i<<endl;
        }
    }
    return 0;
}
```
