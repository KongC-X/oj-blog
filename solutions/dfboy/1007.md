# 1007 - 统计大写英文字母的个数

## 题目描述

算算以 '`.`' 结束的一串字符中含有多少个大写的英文字母。

## 输入

输入一串字符（长度不超过 $80$ ），以 '`.`' 结束。

## 输出

输出一行，即这串字符中大写字母的个数。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

string s;
int c = 0;
int main() {
	getline(cin,s);//读取一行字符串，可以含空格 
	
	for(int i = 0;i < s.size();i++){
		if(s[i] >= 'A' && s[i] <= 'Z'){
			c++;
		}
	}
	
	cout<<c;
	return 0;
}
```
