# 1007 - 统计大写英文字母的个数

## 题目描述

算算以 '`.`' 结束的一串字符中含有多少个大写的英文字母。

## 输入

输入一串字符（长度不超过 $80$ ），以 '`.`' 结束。

## 输出

输出一行，即这串字符中大写字母的个数。

## 解题思路

## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int main(){
	string s,x;
	char order,c;
	getline(cin,s); 
	cin>>order>>c;
	int p=s.find(c);
	if(p==-1){
		cout<<"Not exist"; 
	}
	else if(order=='D'){
		s.erase(p,1);
		cout<<s;
	}
	else if(order=='I'){
		cin>>x; 
		int k;
		while(p!=-1){//如果p等-1说明全部找完c了 
			//如果p不是-1  记录当前c的位置 
			k=p;
			p=s.find(c,p+1);//p点是c  看p后面有没有c 
		}
		s.insert(k,x);//最后一次出现c的位置是k  在k前面插入 
		cout<<s; 
	}
	else if(order=='R'){
		cin>>x; 
		while(p!=-1){
			s.replace(p,1,x);
			p=s.find(c,p+1); 
		}
		cout<<s; 
	}
	return 0;
}
```
