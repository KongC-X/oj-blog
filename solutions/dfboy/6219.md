# 6219 - 满二叉树

## 题目描述

给定一棵以 1 号结点为根的二叉树，共有 $n$ 个结点，结点编号为 $1$ 到 $n$。第 $i$ 个结点的左孩子为 $l_i$，右孩子为 $r_i$，若没有对应孩子则为 0。

对于每个结点，都可以看作一棵以该结点为根的子树。若一棵二叉树所有叶子结点深度相同，且每个非叶子结点都有两个孩子，则称它为满二叉树。请统计这 $n$ 棵子树中有多少棵是满二叉树。

## 输入

第一行一个整数 $n$。

接下来 $n$ 行，第 $i$ 行两个整数 $l_i,r_i$。

## 输出

输出一个整数，表示满二叉树子树的数量。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 100010;
int l[N], r[N];                // l[i], r[i]：结点 i 的左、右儿子，0 表示空
int n, ans;                    // n：结点总数，ans：满二叉树个数

// 返回以 u 为根的子树的高度，如果该子树不是满二叉树则返回 -1
int dfs(int u) {
    if (u == 0) return 0;                          // 空树高度为 0（满二叉树定义中的辅助边界）
    int hl = dfs(l[u]);                            // 左子树高度
    int hr = dfs(r[u]);                            // 右子树高度
    if (hl != -1 && hr != -1 && hl == hr) {        // 左右均为满二叉树且高度相等
        ans++;                                     // 当前子树是满二叉树，计数加 1
        return hl + 1;                             // 返回当前子树高度
    }
    return -1;                                     // 不是满二叉树，返回 -1
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> l[i] >> r[i];
    }

    dfs(1);
    cout << ans << endl;
    return 0;
}
```
