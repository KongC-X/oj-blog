# 1633 - 判断3的倍数

## 题目描述

判断一个数是不是 $3$ 的倍数，如果是打印 `yes` ，否则打印 `no`。

## 输入

一行，一个整数。

## 输出

一行，`yes` 或者 `no` 。
## AC代码
## AC代码

```cpp
#include <iostream>
using namespace std;
 
int main(){
    int n;
    cin>>n;
    if(n%3==0){
        cout<<"yes";
    }else{
        cout<<"no";
    }
}
```
