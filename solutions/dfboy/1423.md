# 1423 - 考试成绩的简单统计

## 题目描述

期末考试结束，王老师想知道这次考试中成绩优秀的同学有多少人（考试成绩大于或等于 $90$ 表示成绩优秀），请你编程帮助王老师来计算出成绩优秀的人数。

## 输入

第一行，一个整数 $n$ 代表有 $n$ 个人的成绩（ $n \le 100$）；

第二行，$n$个人的成绩，用空格隔开。

## 输出

成绩优秀的同学的总人数。
## AC代码
## AC代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int n,x,s = 0;
    int a[110];
    cin >> n;
    // 循环输入多少次
    for(int i = 0;i < n;i++) {
        cin >> a[i];
    }
    // 循环数组
    for(int i = 0;i < n;i++) {
        if(a[i] >= 90) {
            s++;
        }
    }
    cout << s << endl;
}
```
