# 1670 - 象棋大赛

## 题目描述

市里要组织象棋大赛，年龄在 $8 \sim 30$ 周岁之间的选手可以报名参赛。为了公平起见，大赛组委会将选手们分了青年组、少年组和儿童组，大赛组委会规定：

$15 \sim 30$ 周岁之间的选手为青年组选手、$11 \sim 14$ 周岁之间的选手为少年组选手、$8 \sim 10$ 周岁的选手为儿童组选手。

请从键盘读入一名选手的年龄，输出他应该分到哪一组。

青年组请输出 `qingnianzu` 、少年组请输出 `shaonianzu` 、儿童组请输出 `ertongzu` 。

## 输入

输入一个整数 $n$ 代表某位选手的年龄（$n$ 是 $8 \sim 30$ 之间的整数）。

## 输出

输出该选手的分组。

#include <iostream>
using namespace std;
int main(){
	//定义整数n代表某位选手的年龄
    int n;
    //输入n 
    cin>>n;
    if(n>=15){
        cout<<"qingnianzu";
    }else if(n>=11){
        cout<<"shaonianzu";
    }else if(n>=8){
        cout<<"ertongzu";
    }
}
