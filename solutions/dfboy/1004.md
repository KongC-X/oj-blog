# 1004 - 编程求1*2*3*...*n

## 题目描述

编程求 $1 \times 2  \times 3 \times  \dots \times n$ 。

## 输入

输入一行，只有一个整数 $n$($1 \le n \le 10$)；

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。
## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int i = 1,n,s = 1;
    cin >> n;
    while(i <= n) {
        s *= i;
        i++;
    }
    cout << s << endl;
}
```
