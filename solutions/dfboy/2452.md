# 2452 - 最长子区间

## 题目描述

给定 $n$ 个整数，在这 $n$ 个整数中任意的取连续区间中的数字求和，请问：满足区间和是 $7$ 的倍数的最长的区间长度是多少？

## 输入

第$1$行输入一个整数 $N$（$1≤N≤50,000$）  

第$2$行输入$n$个整数（整数范围在$0…1,000,000$之间）

## 输出

输出满足题意的最长子区间的长度，如果找不到符合题意的子区间，请输出 `0`。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int s,s1[10010],s2[10010],s3,s4;
int i,j,n,m,q,w;
int main(){
	cin>>n;
	for(i=1;i<=n;i++){
		cin>>m;
		for(j=0;j<m;j++){
			cin>>s1[j];
			s+=s1[j];
		}
		for(j=0;j<m;j++){
			q+=s1[j];
			if(q*2==s){
				w=1;
				break;
			}
		}
		if(w){
			cout<<"Yes"<<endl;
		}else{
			cout<<"No"<<endl;
		}w=0;
		s=0;
		q=0;
	}
}
```
