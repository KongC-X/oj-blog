# 2452 - 最长子区间

## 题目描述

给定 $n$ 个整数，在这 $n$ 个整数中任意的取连续区间中的数字求和，请问：满足区间和是 $7$ 的倍数的最长的区间长度是多少？

## 输入

第$1$行输入一个整数 $N$（$1≤N≤50,000$）  

第$2$行输入$n$个整数（整数范围在$0…1,000,000$之间）

## 输出

输出满足题意的最长子区间的长度，如果找不到符合题意的子区间，请输出 `0`。

## 解题思路

## AC代码

```cpp
// 同余定理：
// 如果两个前缀和对7取模的余数相同，那么这两个位置之间的子区间和一定是7的倍数
// 数学表达：如果 sum[i] % 7 == sum[j] % 7，那么 (sum[i] - sum[j]) % 7 == 0，即区间 [j+1, i] 的和是7的倍数

#include <iostream>
using namespace std;

int main() {
    int n, num, first[7] = {0}, max_len = 0;
    long long sum = 0;
    
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> num;
        sum += num;
        int r = sum % 7;
        // 当余数为0时，说明从头到当前位置的和是7的倍数，长度就是当前位置 i
		// 当余数不为0时，如果余数已记录，则计算当前位置与首次出现位置的差值，否则记录该余数的首次出现位置
        if (r == 0) {
            // 情况1：当前前缀和本身就是7的倍数
    		// 这意味着从数组开头到当前位置的和是7的倍数
            max_len = max(max_len, i);  // 从头到当前的和是7的倍数
        }
        // 使用 first[r] 的值判断是否已记录（0表示未记录）
        else if (first[r]) {
            // 情况2：之前出现过相同的余数
    		// 这意味着两个位置之间的区间和是7的倍数
            max_len = max(max_len, i - first[r]);  // 区间[first[r]+1, i]满足条件
        } else {
            // 情况3：首次出现这个余数
    		// 记录这个余数第一次出现的位置
            first[r] = i;  // 首次出现该余数
        }
    }
    
    cout << max_len;
    return 0;
}
```
