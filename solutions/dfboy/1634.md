# 1634 - 游戏任务

## 题目描述

小明接受了一个游戏任务，在 $20$ 分钟内从 $A$ 地到 $B$ 地！途中会出现 $3$ 个难题，要求小明用最快的时间解答出来？

请编程求小明能不能完成任务，能的输出 “ `YES` ” 不能的输出 “ `NO` ” 。

## 输入

同一行输入 $c,s,a1,a2,a3$ 五个数。  

（ $c$ 代表 $A$ 、$B$ 两地的距离， $s$ 代表小明的速度， $a1,a2,a3$ 代表解答问题的时间！）

## 输出

一行，能的输出 能的输出 “ `YES` ” 不能的输出 “ `NO` ” 。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	int c,s,a1,a2,a3;
	cin>>c>>s>>a1>>a2>>a3;
	//判断总用时是否大于20分钟 
	if((c*1.0/s+a1+a2+a3)>20) {
		cout<<"NO";
	}else{
		cout<<"YES";
	}
	return 0;
}
```
