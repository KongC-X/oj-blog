# 1145 - 数列求和

## 题目描述

有一数列如下：  $1$   $2$   $4$   $7$   $11$   $16$   $22$  $\dots$  试求该数列前 $N$ 项之和。

## 输入

一个整数 $N$ （ $0 \lt  N \lt 1000$ ）。

## 输出

一个整数。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;

int num(int n) {
    if (n == 1) {
        return 1;
    } else {
        return num(n - 1) + n - 1;
    }
}

int main(){
    int i,n,s = 0;
    cin >> n;
    for(i = 1; i <= n; i++){
        s += num(i);
    }
    cout << s << endl;
}
```
