# 1145 - 数列求和

## 题目描述

有一数列如下：  $1$   $2$   $4$   $7$   $11$   $16$   $22$  $\dots$  试求该数列前 $N$ 项之和。

## 输入

一个整数 $N$ （ $0 \lt  N \lt 1000$ ）。

## 输出

一个整数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    int a[30][30]; // 存放棋盘的值，默认初值为0
    int n,m,i,j,x,y,k;
    cin >> n >> m >> x >> y;

    // 将棋盘所有值设为1
    for(i = 0; i <= n; i++) {
        for(j = 0; j <= m; j++) {
            a[i][j] = 1;
        }
    }

    // 设置马及马的控制点为0
    a[x][y] = 0;
    // 如果控制点在棋盘内，则设置为0
    if(x-1 >= 0 && y-2 >= 0) a[x-1][y-2] = 0;
    if(x-2 >= 0 && y-1 >= 0) a[x-2][y-1] = 0;
    if(x-2 >= 0 && y+1 <= m) a[x-2][y+1] = 0;
    if(x-1 >= 0 && y+2 <= m) a[x-1][y+2] = 0;
    if(x+1 <= n && y-2 >= 0) a[x+1][y-2] = 0;
    if(x+2 <= n && y-1 >= 0) a[x+2][y-1] = 0;
    if(x+2 <= n && y+1 <= m) a[x+2][y+1] = 0;
    if(x+1 <= n && y+2 <= m) a[x+1][y+2] = 0;

    // 输出棋盘检验
    // for(i = 0; i <= n; i++) {
    //     for(j = 0; j <= m; j++) {
    //         cout << a[i][j] << " ";
    //     }
    //     cout << endl;
    // }

    // 递推计算
    for(i = 0;i <= n;i++) {
        for(j = 0;j <= m;j++) {
            // 初始位置不用算
            if(i == 0 && j == 0) continue;
            // 马的控制点不用算
            if(a[i][j] == 0) continue;

            if(i == 0) { // 如果是第一行，取左边的值
                a[i][j] = a[i][j-1];
            } else if(j == 0) { // 如果是第一列，取上方的值
                a[i][j] = a[i-1][j];
            } else { // 否则就是正常的其余点
                a[i][j] = a[i-1][j] + a[i][j-1];
            }
        }
    }
    cout << a[n][m];
}
```
