# 1784 - 数字直角（2）

## 题目描述

请打印 $n$ 行的数字直角三角形。

## 输入

一个整数 $n$（$ n \lt 10$）。

## 输出

输出如下方图所示 $n$ 行的数字直角三角形。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	int n;
    cin>>n;
    int i,j;
    //输出n行 
    for(i=1;i<=n;i++){
    	//每行输出i列 
        for(j=1;j<=i;j++){
            cout<<j;
        }
        cout<<endl;
    }
	return 0;
}
```
