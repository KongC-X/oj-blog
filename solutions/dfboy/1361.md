# 1361 - n个数取出r个数排列

## 题目描述

从 $1 \sim n$ 任意挑出 $r$ 个数进行排列，请从小到大输出所有可能的排列结果。

如：$n=5$，$r=2$，则输出结果如下

```
`1 2
1 3
1 4
1 5
2 1
2 3
2 4
2 5
3 1
3 2
3 4
3 5
4 1
4 2
4 3
4 5
5 1
5 2
5 3
5 4
`
```

## 输入

两个整数 $n$ 和 $r$ （ $n$ 和 $r$ 都是 $2 \sim 6$ 之间的整数）

## 输出

从 $1 \sim n$ 中取出 $r$ 个数的排列结果！
## AC代码

```cpp
#include <iostream>
using namespace std;

int n,r;
int a[100]; // 存放全排列的结果
bool f[100]; // 标记是否使用过数字

// 打印输出函数
void print(){
    for(int i = 1;i <= r;i++) {
        cout << a[i];
        if(i != r) {
            cout << " ";
        } else {
            cout << endl;
        }
    }
}

// 递归函数为a数组每个元素赋值
void dfs(int k) {
    for(int i = 1;i <= n;i++) {
        // 如果i这个数没有被用过，则填写到下标为k的位置
        if(f[i] == false && k <= r) {
            a[k] = i;
            f[i] = true;// 标记被选中了
            // 如果a中存储了r个元素，输出结果，否则递归为k+1的下标赋值
            if(k == r) {
                print();
            } else {
                dfs(k + 1);
            }
            f[i] = false; // 回溯到前一个状态
        }
    }
}

int main(){
    cin >> n >> r;
    dfs(1);
}
```
