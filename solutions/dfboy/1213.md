# 1213 - 删除数组的最小数

## 题目描述

在一个不重复的数组中，请将这个数组的最小数删除后输出。

## 输入

第一行有一个整数 $n$  ( $5 \le n  \le 100$ )；

第二行有 $n$ 个不重复的整数。

## 输出

删除最小数后的数组。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
	int a[110],n,mi,i;
	cin>>n;
	for(i = 0; i < n; i++) {
		cin>>a[i];
	}

	//查找最小数
	mi = a[0];
	for(i = 1; i < n; i++) {
		if(a[i] < mi) {
			mi = a[i];
		}
	}

	//输出除了最小数以外的数
	for(i = 0; i < n; i++) {
		if(a[i] != mi) {
			cout<<a[i]<<" ";
		}
	}
	return 0;
}
```
