# 1213 - 删除数组的最小数

## 题目描述

在一个不重复的数组中，请将这个数组的最小数删除后输出。

## 输入

第一行有一个整数 $n$  ( $5 \le n  \le 100$ )；

第二行有 $n$ 个不重复的整数。

## 输出

删除最小数后的数组。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
#include<iostream>
using namespace std;

/*
策略：要优先赢得人数较少的洲的支持
1. 如果有m个洲，要赢得m/2+1个洲的支持 
2. 如果第j个洲有a[j]个人，要赢得a[j]/2+1个人的支持 
*/ 
int n,m,a[110],c;
int main() {
    cin>>n;
    //读入n组数据
	for(int i = 1;i <= n;i++){
		//读入m个洲的信息
		cin>>m;
		for(int j = 1;j <= m;j++){
			cin>>a[j];
		} 
		
		//对本洲人数排序
		sort(a+1,a+m+1); 
		
		//计算最少要赢得多少个人的支持
		c = 0;
		for(int j = 1;j <= m / 2 + 1;j++){
			c = c + (a[j] / 2 + 1);
		}
		
		cout<<c<<endl;
	} 
}
```
