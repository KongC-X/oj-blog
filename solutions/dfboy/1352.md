# 1352 - 费马定理

## 题目描述

公元 $1640$ 年，法国著名数学家费马发现：

而 $3、5、17、257、65537$ 都是质数，于是费马猜想：对于一切自然数 $n$ ，$2$2n $+1$ 都是质数，可是到了 $1732$ 年，数学家欧拉发现一个数 $n$ 并不满足费马的这个猜想，请问欧拉发现的这个数 $n$ 最小是多少？（在 $long$ $long$ 的范围内）（ $7.2$ ）

## 输入

无

## 输出

满足条件的数 $n$ 。

## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

bool f[5000010];
long long s,e,c,i,j;

int main() {
	cin >> s >> e;
	// 埃拉托斯特筛法
	for(i = 2;i * i <= e;i++) {
		if(!f[i]) {
			for(j = i * i;j <= e;j += i) {
				f[j] = true;
			}
		}
	}
	// 两两素数配对，找到s~e之间的半素数
	for(i = 2;i * i <= e;i++) {
		if(!f[i]) {
			for(j = i;j * i <= e;j++) {
				if(!f[j] && j * i >= s) {
					c++;
				}
			}
		}
	}
	cout << c << endl;
}
```
