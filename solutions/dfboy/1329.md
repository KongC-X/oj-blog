# 1329 - 求梯形的面积

## 题目描述

梯形面积的求解公式为 $S = (a + b) \times h / 2$ 。从键盘读入一个梯形的上底 $a$、下底 $b$ 和高 $h$ ，请计算表梯形的面积。（结果保留1位小数）。（5.1.15）

## 输入

三个整数 $a、b、h$。

## 输出

梯形的面积

## 解题思路

## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int n,i,s,a[100010];
int main() {
    cin >> n;
    for(i = 0;i < n;i++) {
        scanf("%d",&a[i]);
        s += a[i];
    }
    int left = 0; // 左半部分的和
    int min_diff = INT_MAX; // 最小的差值
    // 遍历数组，并在每个位置计算左半部分和右半部分的差值
    for(i = 0;i < n - 1;i++) {
        left += a[i];
        int right = s - left; // 右半部分的和
        int diff = abs(left - right); // 左右部分的差值
        min_diff = min(min_diff, diff); // 更新最小的差值
    }
    cout << min_diff << endl;
}
```
