# 3857 - 休息时间

## 题目描述

小杨计划在某个时刻开始学习，并决定在学习 $k$ 秒后开始休息。

小杨想知道自己开始休息的时刻是多少。

## 输入

前三行每行包含一个整数，分别表示小杨开始学习时刻的时 $h$ 、分 $m$ 、秒 $s$ （ $h，m ，s$ 的值符合 $1 \le h \le  12,0 \le m \le  59,0 \le s \le  59$）。

第四行包含一个整数 $k$，表示小杨学习的总秒数（注： $k$ 的值符合 $1 \le k \le  3600$ ）。

## 输出

输出一行，包含三个整数，分别表示小杨开始休息时刻的时、分、秒。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int a[1000] = {1};
// k代表a数组中元素的个数，代表2的n次方高精度的整数位数
int n,i,j,k = 1;
int main() {
    cin >> n;
    // 第一层循环是这个数要乘多少次2
    for(i = 1; i <= n; i++) {
        // 第二层是每次有几位要乘2
        for(j = 0;j < k;j++) {
            a[j] = a[j] * 2;
        }
        // 处理进位
        for(j = 0;j < k;j++) {
            if(a[j] >= 10) {
                a[j + 1] += a[j] / 10;
                a[j] = a[j] % 10;
            }
        }
        // 判断a数组是否多出一位
        if(a[k] != 0) {
            k++;
        }
    }
    // 逆序输出
    for(i = k - 1;i >= 0;i--) {
        cout << a[i];
    }
}
```
