# 2349 - 打印 STEM86

## 题目描述

【具体要求】  

设计一个程序，输出如下样例中“STEM86”图形。

## 输入

无

## 输出

直接在终端输出“STEM86”图形，每个大字符之间有空格隔开。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int m,n,w,s;
    cin >> m >> n >> s;
    w = s / n;
    cout << m * w << endl;
}
```
