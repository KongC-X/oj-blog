# 1711 - 输出满足条件的整数1

## 题目描述

有这样的两位数，其十位上的数字比个位上的数字要大，且十位和个位上的数字之和为偶数，请找出所有的满足条件的 $2$ 位数。

## 输入

无。

## 输出

输出满足条件的 $2$ 位数，每行一个。
## AC代码
## AC代码

```cpp
#include <iostream>
using namespace std;
 
int main(){
    int i,s,g,sum;
    //遍历所有的2位数 
    for(i=10;i<=99;i++){
    	//拆位求出十位和个位 
        s=i/10;
        g=i%10;
        //求十位和个位的和 
        sum=s+g;
        //如果十位大于个位,且和是偶数,就输出这个数 
        if(s>g&&sum%2==0){
            cout<<i<<endl;
        }
    }
    return 0; 
}
```
