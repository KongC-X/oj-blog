# 1334 - 扑克牌组合

## 题目描述

小明从一副扑克牌中（没有大小王， $J$ 认为是数字 $11$ ，  $Q$ 是 $12$ ， $K$ 是 $13$ ， $A$ 是 $1$ ）抽出 $2$ 张牌求和，请问能够组合出多少个不相等的数，按照由小到大输出这些数。（5.1.98）

## 输入

第一行是一个整数 $n$ 代表（ $n \le 52$ ）扑克牌的总数量；

第二行的 $n$ 个整数分别代表扑克牌的数值。

## 输出

第一行是一个整数 $m$ 代表组合出不相等的数字个数；

第二行 $m$ 个数用空格隔开代表这 $m$ 个由小到大排序的不相等的数。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

const int N = 100010;
int a[N];
int n,m,x,s = 0; // 最小差值的和

int main() {
    cin >> m >> n;
    for(int i = 1;i <= m;i++) cin >> a[i];
    sort(a+1,a+m+1); //对学校分数排序，方便二分

    // n个同学
    int left,right,mid;
    for(int i = 1;i <= n;i++) {
        cin >> x; // x: 同学的分数
        // 特殊情况不需要二分的情况
        if(x >= a[m]) s = s + x - a[m];
        else if(x <= a[1]) s = s + a[1] - x;
        else {
            left = 1;
            right = m;
            // 找左边界
            while(left <= right) {
                mid = (left + right) / 2;
                if(x <= a[mid]) right = mid - 1;
                else left = mid + 1;
            }
            // 看left和left-1哪个位置的分数差更小
            // left是第一个大于等于x的位置
            s = s + min(a[left] - x,x - a[left - 1]);
        }
    }
    cout << s << endl;
}
```
