# 1189 - 数字走向VI

## 题目描述

输入整数 $N$ ，输出相应方阵。

## 输入

一个整数 $N$ 。（ $0 \lt N \le 10$ )

## 输出

一个方阵，每个数字的场宽为 $3$ 。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[10][10];
int main(){
    int n;
    cin >> n;
    int k = 1;
    for(int i = 0; i < n; i++)
    {
        for(int j = n - 1; j >= 0; j--)
        {
            a[i][j] = k++;
        }

    }
    for(int i = 0; i < n; i++)
    {
        for(int j = 0; j < n; j++)
        {
            cout << setw(3) << a[i][j];
        }
        cout << endl;
    }

	return 0;
}
```
