# 1613 - 跳远成绩

## 题目描述

张晓峰在体育课上考核跳远项目，体育老师要求每位同学跳 $3$ 次，取 $3$ 次成绩的平均值为该同学的成绩。

已知张晓峰第一次跳 $x$ 米，第二次只跳到了第一次的 $80\%$ 的距离（ $80\%$ 指的是 $x \times 0.8$ ），第三次跳到了第一次的 $90\%$ 的距离（ $90\%$ 指的是$ x \times 0.9$）。

请问张晓峰的平均成绩是多少？

## 输入

一个整数 $x$ ，代表张晓峰第一次跳远的距离。

## 输出

一个小数，代表张晓峰的平均成绩，输出保留 $1$ 位小数。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	//定义整数变量x代表第一次跳远的距离 
	int x;
	//输入x 
	cin>>x;
	cout<<fixed<<setprecision(1)<<(x+x*0.8+x*0.9)/3.0; 
	return 0;
}
```
