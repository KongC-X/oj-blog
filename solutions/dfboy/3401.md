# 3401 - 小杨的X字矩阵

## 题目描述

小杨想要构造一个 $N \times N$ 的 $X$ 字矩阵（$N$ 为奇数），这个矩阵的两条对角线都是半角加号 `+` ，其余都是半角减号 `-` 。例如，一个 $ 5 \times 5 $的 $X$ 字矩阵如下：

```
+---+
-+-+-
--+--
-+-+-
+---+

```

请你帮小杨根据给定的 $N$ 打印出对应的“ $X$ 字矩阵”。

## 输入

一行一个整数 $N$ （$ 5 \leq N \leq 49$，保证 $N$ 为奇数）。

## 输出

输出对应的“$X$ 字矩阵”。

请严格按格式要求输出，不要擅自添加任何空格、标点、空行等任何符号。你应该恰好输出 $N$ 行，每行除了换行符外恰好包含 $N$ 个字符，这些字符要么是 `+` ，要么是 `-` 。

在常规程序中，输入、输出时提供提示是好习惯。但在本场考试中，由于系统限定，请不要在输入、输出中附带任何提示信息。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <iomanip>
#include <bits/stdc++.h>
using namespace std;

// 梯形
struct Trapezoid {
    int top; // 上底
    int bottom; // 下底
    int height; // 高
}a[110];

int main() {
    int i,n;
    double s,ma = 0;
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> a[i].top >> a[i].bottom >> a[i].height;
        s = (a[i].top + a[i].bottom) * a[i].height / 2.0;
        ma = max(ma,s);
    }
    cout << fixed << setprecision(1) << ma << endl;
}

// 还可以用结构体存储每个梯形的上底、下底、高和面积。
```
