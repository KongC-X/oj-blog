# 1163 - 相加之和最大，并给出它们的起始位置

## 题目描述

有一组数，其排列形式如下： $11$，$19$，$9$，$12$，$5$，$20$，$1$，$18$，$4$，$16$，$6$，$10$，$15$，$2$，$17$，$3$，$14$，$7$，$13$，$8$， 且尾部 $8$ 和头部 $11$ 首尾相连，构成环形的一组数；

编程找出相邻的 $4$ 个数，其相加之和最大，并给出它们的起始位置。

## 输入

第一行有一个整数 $n$ ( $5 ≤ n ≤ 20$ )；

第二行有 $n$ 个数（对于第 $i$ 个整数的值 $a_i$ 满足 $1≤a_i≤1000$）。

## 输出

第一行有一个数，即最大的和；

第二行有一个数，即起始数的位置。

注意：数据保证最大值唯一的区间唯一。

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
思路：
1.从每个数开始求连续4个数的和
2.注意：从倒数第3个数开始没有连续的4个数，要加上前面的数

可以采用环形数组的处理方法：下标%数组长度
连续的四个数的下标：a[i],a[(i+1)%n],a[(i+2)%n],a[(i+3)%n]
比如：
n=8
下标：
0 1 2 3 4 5 6 7 8%8=0 9%8=1... 
*/ 
//ma代表最大的和，r代表最大和的起始位置 
int a[30],n,s,ma = INT_MIN,r; 

int main() {
	cin>>n;
	for(int i = 0;i < n;i++){
		cin>>a[i];
	}
	
	//从每个数的位置开始求连续4个数的和
	for(int i = 0;i < n;i++){
		s = a[i]+a[(i+1)%n]+a[(i+2)%n]+a[(i+3)%n]; 
		//cout<<s<<endl;
		if(s > ma){
			ma = s;
			r = i + 1;
		}
	}
	
	cout<<ma<<endl<<r; 
}
```
