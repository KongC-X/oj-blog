# 1163 - 相加之和最大，并给出它们的起始位置

## 题目描述

有一组数，其排列形式如下： $11$，$19$，$9$，$12$，$5$，$20$，$1$，$18$，$4$，$16$，$6$，$10$，$15$，$2$，$17$，$3$，$14$，$7$，$13$，$8$， 且尾部 $8$ 和头部 $11$ 首尾相连，构成环形的一组数；

编程找出相邻的 $4$ 个数，其相加之和最大，并给出它们的起始位置。

## 输入

第一行有一个整数 $n$ ( $5 ≤ n ≤ 20$ )；

第二行有 $n$ 个数（对于第 $i$ 个整数的值 $a_i$ 满足 $1≤a_i≤1000$）。

## 输出

第一行有一个数，即最大的和；

第二行有一个数，即起始数的位置。

注意：数据保证最大值唯一的区间唯一。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

/*
思路：最大值和最小值尝试分一组
1. 如果最大值 + 最小值 <= w，则分到一组
2. 否则，最大值单独分一组 
*/

int a[30010],w,n,c = 0;

int main() {
	cin>>w>>n;

	for(int i = 1;i <= n;i++){
		cin>>a[i];
	}
	
	sort(a+1,a+n+1);

	int h = 1,t = n;//表示头尾在哪里
	while(h <= t){
		//头尾分一组 
		if(a[h] + a[t] <= w){
			c++;
			h++;
			t--;
		}else{
			//尾单独分一组
			c++;
			t--; 
		}
	} 
	cout<<c;
	return 0;
}
```
