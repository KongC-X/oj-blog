# 1476 - 字符串编辑

## 题目描述

从键盘输入一个字符串（长度 $ \le 40$ 个字符），并以字符 `.` 结束。

例如：`This is a book.` 现对该字符串进行编辑，编辑功能有：

**操作一：删除字符。**

`D`：删除一个字符，命令的格式为：`D a`。其中 `a`为被删除的字符。

例如：`D s`  表示删除字符 `s` ，若字符串中有多个 `s`，则删除第一次出现的。

如上例中删除的结果为： `Thi is a book.`

**操作二：插入字符。**

`I`：插入一个字符，命令的格式为：`I a1 a2`。其中 `a1` 表示插入到指定字符前面，`a2` 表示将要插入的字符。

例如：`I s d` 表示在指定字符 `s` 的前面插入字符 `d` ，若原串中有多个 `s` ，则插入在最后一个字符的前面。

如上例中，原串：`This is a book.`，插入后：`This ids a book.`。

**操作三：替换字符。**

`R`：替换一个字符，命令格式为：`R a1 a2`。其中 `a1` 为被替换的字符，`a2` 为替换的字符，若在原串中有多个 `a1` 则应全部替换。

例如，原串： `This is a book.`，输入命令：`R o e`，替换后的字符串为：`This is a beek.`。

**特殊情况：**

在编辑过程中，若出现被改的字符不存在时，则给出提示信息 `Not exist`。

## 输入

每个测试文件只包含一组测试数据，每组输入数据包含两行：

第一行，输入一个字符串，表示原串；

第二行，输入一个字符串，表示命令，数据保证命令不会出错，也就是命令一定严格按照题目要求输入。

## 输出

对于每组输入数据，输出编辑后的字符串，如果被改的字符不存在，则输出 `Not exist` （引号不输出）。
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s,x;
    char order,c;
    getline(cin ,s);
    cin >> order >> c;
    int p = s.find(c);
    if(p == -1) {
        cout << "Not exist";
    } else if(order == 'D') {
        s.erase(p,1);
        cout << s;
    } else if(order == 'I') {
        cin >> x;
        int k;
        // 循环找到最后一个c的位置
        while(p != -1) {
            k = p;
            p = s.find(c,p+1);
        } 
        s.insert(k,x); // 插入
        cout << s;
    } else if(order == 'R') {
        cin >> x;
        while(p != -1) {
            s.replace(p,1,x);
            p = s.find(c,p+1);
        }
        cout << s;
    }
}
```
