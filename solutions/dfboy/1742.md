# 1742 - 三位回文数

## 题目描述

请从小到大输出 $m \sim n$ 之间所有的 $3$ 位的回文数，并求出这些数有多少个。

## 输入

两个整数 $m$ 和 $n$ 用空格隔开（  ，且 $m$ 和 $n$ 一定都是 $3$ 位数）。

## 输出

先输出 $m \sim n$之间所有的 $3$ 位的回文数，每行 $1$个；

最后 $1$ 行输出 $3$ 位回文数总共有多少个；

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
#include <map>
using namespace std;

pair<int,int> a[10100];
int n,i,x,y;
int main() {
	cin >> n;
	for(i = 1;i <= n;i++) {
		cin >> x >> y;
		a[i] = make_pair(x, y);
	}
	sort(a + 1, a + n + 1);
	for(i = 1;i <= n;i++) {
		cout << a[i].first << " " << a[i].second << endl;
	}
}
```
