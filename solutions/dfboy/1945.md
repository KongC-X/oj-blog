# 1945 - 高精度减法2

## 题目描述

高精度减法，求a-b a,b都不超过240位

## 输入

两个非负整数 
每行一个

## 输出

一个数

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    stack<int> s;
    int n;
    cin>>n;
    int c=1;
    for(int i=1;i<=n;i++){         // 1 2 3 4
        int x;
        cin>>x;              // 3 2 4 1
        if(x>=c){          //假设输入的是3，就先将前三个数压入 结束后 开始弹出 
            while(x>=c){
                s.push(c);  //把c推进去栈 
                c++;       //计数器同步更新 
                cout<<"A"; 
            }
        }
        else{
            s.pop();
        } 
        cout<<"B";   //每一轮都得往外弹出元素 
    }
    return 0; 
}
```
