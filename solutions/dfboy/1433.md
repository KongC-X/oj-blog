# 1433 - 走出迷宫的最少步数2

## 题目描述

当你站在一个迷宫里的时候，往往会被错综复杂的道路弄得失去方向感，如果你能得到迷宫地图，事情就会变得非常简单。

假设你已经得到了一个 $n \times m$ 的迷宫的图纸，请你找出从起点到出口的最短路。

## 输入

第一行是两个整数 $n$ 和 $m$ ($1 \le n,m \le 100$)，表示迷宫的行数和列数。

接下来 $n$ 行，每行一个长为 $m$ 的字符串，表示整个迷宫的布局。

字符 `.` 表示空地，`#` 表示墙，`S` 表示起点 `T` 表示出口。

本题数据保证，从起点到出口存在至少一条合法的路径。

## 输出

输出从起点到出口最少需要走的步数。

```cpp
#include<iostream>
#include<iomanip>
#include<bits/stdc++.h>
using namespace std;

int n,m;
char a[110][110]; // 二维数组存储迷宫
int d[110][110]; // 二维数组存储路径长度

// 右下左上
int fx[5] = {0,0,1,0,-1};
int fy[5] = {0,1,0,-1,0};
void dfs(int x,int y,int k) {
    d[x][y] = k; // 记录路径长度
    int tx,ty; // 临时变量
    for(int i = 1;i <= 4;i++) {
        tx = x + fx[i];
        ty = y + fy[i];
        if(a[tx][ty] == '.' && k + 1 < d[tx][ty]) {
            dfs(tx,ty,k + 1);
        }
    }
}

int main() {
    int s1,s2,e1,e2;
    cin >> n >> m;
    for(int i = 1;i <= n;i++) {
        for(int j = 1;j <= m;j++) {
            cin >> a[i][j];
            if(a[i][j] == 'S') {
                s1 = i;
                s2 = j;
            }
            if(a[i][j] == 'T') {
                e1 = i;
                e2 = j;
                a[i][j] = '.'; // 将终点设为可走
            }
            d[i][j] = INT_MAX; // 初始化路径长度为最大值
        }
    }
    dfs(s1,s2,0);
    cout << d[e1][e2] << endl; // 输出路径长度
}
```
