# 2242 - 计算(a+b)/c的值

## 题目描述

给定 $3$ 个整数 $a、b、c$，计算表达式 $(a+b)/c$ 的值，$/$ 是整除运算。

## 输入

输入仅一行，包括三个整数 $a、b、c$ , 数与数之间以一个空格分开。( $－10,000 \lt a,b,c \lt 10,000 $,  $c$ 不等于 $0$ )。

## 输出

输出一行，即表达式的值。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
        LIN X  命令代表左边进队操作；
        RIN X  表示右边进队操作；
        ROUT  表示右边出队操作；
        LOUT  表示从左边出队操作。
	*/
    string s;
    vector<int > v; // 记录错误的时间
    deque<int > d; // 双端队列

    int n,x;
    cin >> n;
    for(int i = 1;i <= n;i++) {
        cin >> s;
        if(s == "LIN") {
            cin >> x;
            d.push_front(x);
        }
        if(s == "RIN") {
            cin >> x;
            d.push_back(x);
        }
        if(s == "LOUT") {
            if(d.size() == 0) {
                v.push_back(i);
            } else {
                d.pop_front();
            }
        }
        if(s == "ROUT") {
            if(d.size() == 0) {
                v.push_back(i);
            } else {
                d.pop_back();
            }
        }
    }
    for(int i = 0;i < d.size();i++) {
        cout << d[i] << " ";
    }
    cout << endl;
    for(int i = 0;i < v.size();i++) {
        cout << v[i] << " ERROR" << endl;
    }
}
```
