# 2242 - 计算(a+b)/c的值

## 题目描述

给定 $3$ 个整数 $a、b、c$，计算表达式 $(a+b)/c$ 的值，$/$ 是整除运算。

## 输入

输入仅一行，包括三个整数 $a、b、c$ , 数与数之间以一个空格分开。( $－10,000 \lt a,b,c \lt 10,000 $,  $c$ 不等于 $0$ )。

## 输出

输出一行，即表达式的值。

## AC代码

#include <bits/stdc++.h>
using namespace std;

int main() {
	int a,b,c;
	cin>>a>>b>>c;
	cout<<(a+b)/c;
	return 0;
}
