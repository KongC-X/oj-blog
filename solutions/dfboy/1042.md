# 1042 - 求任意三位数打乱次序后的最大值

## 题目描述

任意输入一个三位整数，再把它的次序打乱重新组合一个新的三位整数，使其值最大。

## 输入

输入只有一行，包括 $1$ 个整数。

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

## 解题思路

## AC代码

```cpp
/* 思路：定义结构体数组，存储每个活动的起止时间，按照结束时间升序排序
第一个活动必选，遍历后续的所有活动，找到每个开始时间>=上一个选中活动结束时间的活动 */

#include <iostream>
#include <iomanip>
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int begin;
    int end;
}a[110];

bool cmp(Node a,Node b) {
    if(a.end < b.end) { 
        return true;
    } else {
        return false;
    }
}

int main() {
    int i,j,n,c = 0,e;
    cin >> n;
    for(i = 0; i < n; i++) {
        cin >> a[i].begin >> a[i].end;
    }
    sort(a,a + n,cmp);
    // 第一个活动必选
    c = 1; 
    e = a[0].end;
    for(i = 1; i < n; i++) {
        if(a[i].begin >= e) {
            c++;
            e = a[i].end;
        }
    }
    cout << c << endl;
}
```
