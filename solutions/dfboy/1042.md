# 1042 - 求任意三位数打乱次序后的最大值

## 题目描述

任意输入一个三位整数，再把它的次序打乱重新组合一个新的三位整数，使其值最大。

## 输入

输入只有一行，包括 $1$ 个整数。

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
#include<iomanip>
#include<algorithm>
#include<string>
using namespace std;
bool cmp(char a, char b){
	return a>b;
}
int main(){
	string s;
	cin>>s;
	sort(s.begin(),s.end(),cmp);
	cout<<s<<endl;
	return 0; 
}
```
