# 1101 - 时间的差

## 题目描述

看到两个标准格式的时间，有小时，有分钟，有秒，格式如：$h:m:s$，即 时 : 分 : 秒。

你想知道，这两个时间之间相差多少吗？

## 输入

输入包括两行，两行均为一个“时 : 分 : 秒”格式的时间。

且本题保证第一个时间一定大于第二个时间！

## 输出

输出就是输入的两个时间之间的秒数差。

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

// 求总秒数
int secends(string s) {
    // xx:xx:xx
    // 注意这是字符，不是真正的数字
    int h = (s[0] - '0') * 10 + (s[1] - '0');
    int m = (s[3] - '0') * 10 + (s[4] - '0');
    int se = (s[6] - '0') * 10 + (s[7] - '0');
    return h * 3600 + m * 60 + se;
}

int main(){
    string s1,s2;
    cin>>s1>>s2;
    cout<<secends(s1) - secends(s2)<<endl;
}
```
