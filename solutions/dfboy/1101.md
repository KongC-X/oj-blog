# 1101 - 时间的差

## 题目描述

看到两个标准格式的时间，有小时，有分钟，有秒，格式如：$h:m:s$，即 时 : 分 : 秒。

你想知道，这两个时间之间相差多少吗？

## 输入

输入包括两行，两行均为一个“时 : 分 : 秒”格式的时间。

且本题保证第一个时间一定大于第二个时间！

## 输出

输出就是输入的两个时间之间的秒数差。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	//定义变量X作为三位整数,S作为各个数位之和 
	int X,S,b,s,g;
    cin>>X;
    //拆位求解百位,十位,个位 
    b=X/100;
    g=X%10;
    s=X/10%10;
    //求和 
    S=b+s+g;
    cout<<S<<endl;
	return 0;
}
```
