# 1328 - 柱状图

## 题目描述

柱状图是非常直观的用来表示数值的一种图形描述方式，如图所示是 $2011$ 年我国几种常用家电的产量。

请用编程来模拟一下柱状图，从键盘读入 $n$ 种物品的数量（ $n \le  100$ ，每种物品数量在 $1 \sim 10 $之间），用一颗星来代表物品数量为 $1$ ，输出每种物品的编号及其数量。（4.2.106）

如：假设有 $3$ 种物品，数量分别为 $3$   $7$   $6$ ，则输出如下图所示的柱状图

```
`1:***
2:*******
3:******
`
```

## 输入

第一行是一个整数 $n$ ，代表物品种类；

第二行输入每种物品的数量。

## 输出

如图所示的柱状图。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    int a[110][110];
    int r[110][3]; // 用于记录每层路径的下标
    int n,i,j,x,y,k = 1;
    cin >> n;
    // 输入数组
    for(i = 1; i <= n; i++) {
        for(j = 1; j <= i; j++) {
            cin >> a[i][j];
        }
    }
    // 从倒数第2层开始逆推，每个点累加下方的值和右下方的值中的较大值
    for(i = n - 1; i >= 1; i--) {
        for(j = 1; j <= i; j++) {
            a[i][j] = a[i][j] + max(a[i + 1][j], a[i + 1][j + 1]);
        }
    }
    // 记录第一个点的坐标
    r[1][1] = 1;
    r[1][2] = 1;
    
    // 表示当前正在计算的点的坐标
    x = 1;
    y = 1;

    // 推导第2行到第n行的路径
    while(x < n) {
        k++;
        if(a[x + 1][y] > a[x + 1][y + 1]) {
            r[k][1] = x + 1;
            r[k][2] = y;
            x = x + 1;
        } else {
            r[k][1] = x + 1;
            r[k][2] = y + 1;
            x = x + 1;
            y = y + 1;
        }
    }

    // 逆序输出从底到顶的路径
    for(int i = n;i >= 1;i--) {
        cout << r[i][1] << "," << r[i][2];
        if(i != 1) {
            cout << "->";
        } else {
            cout << endl;
        }
    }
    cout << a[1][1];
}
```
