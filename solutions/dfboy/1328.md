# 1328 - 柱状图

## 题目描述

柱状图是非常直观的用来表示数值的一种图形描述方式，如图所示是 $2011$ 年我国几种常用家电的产量。

请用编程来模拟一下柱状图，从键盘读入 $n$ 种物品的数量（ $n \le  100$ ，每种物品数量在 $1 \sim 10 $之间），用一颗星来代表物品数量为 $1$ ，输出每种物品的编号及其数量。（4.2.106）

如：假设有 $3$ 种物品，数量分别为 $3$   $7$   $6$ ，则输出如下图所示的柱状图

```
`1:***
2:*******
3:******
`
```

## 输入

第一行是一个整数 $n$ ，代表物品种类；

第二行输入每种物品的数量。

## 输出

如图所示的柱状图。

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main()
{
    int n;
    int a[1023];
    cin >> n;
    for(int i=1;i<=n;i++)
    {
        cin >> a[i];
    }
    for(int i=1;i<=n;i++)
    {
        cout << i << ":";
        for(int j=1;j<=a[i];j++)
        {
            cout << "*";
        }
        cout << endl;
    }
}
```
