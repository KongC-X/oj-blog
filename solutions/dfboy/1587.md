# 1587 - 连续非素数的最大长度

## 题目描述

给出一个正整数 $n$ （ $2 \le n \le 1000000$ ），例如 $n=30$ ，在 $1，2，3，\dots 30$ 中，连续的非素数有:

$4$    长度为 $1$

$6$    长度为 $1$

$8$  $9$  $10$   长度为 $3$ 

$12$    长度为 $1$

$14$   $15$   $16$  长度为 $3$ 

$18$  长度为 $1$

$20$  $21$  $22$    长度为 $3$

$24$  $25$  $26$  $27$  $28$ 长度为$5$

$30$    长度为 $1$ 

其中，最大长度为 $5$ ，即有连续的 $5$ 个非素数。

## 输入

一个整数 $n$ 。

## 输出

一个整数，即连续非素数最大长度。
## AC代码

```cpp
#include <iostream>
#include <cmath>
using namespace std;

const int MAXN = 5000005;  // 最大数据范围
bool isPrime[MAXN];        // true 表示是素数，false 表示不是素数
int n;

int main() {
    cin >> n;

    // 1. 埃氏筛法：标记素数
    // 初始化：假设所有数都是素数
    for (int i = 2; i <= n; i++) {
        isPrime[i] = true;
    }
    // 筛掉非素数
    for (int i = 2; i * i <= n; i++) {
        if (isPrime[i]) {
            for (int j = i * i; j <= n; j += i) {
                isPrime[j] = false;
            }
        }
    }

    // 2. 统计最长连续非素数长度
    int maxLen = 0;  // 记录最大长度
    int curLen = 0;  // 当前连续非素数长度

    for (int i = 2; i <= n; i++) {
        if (!isPrime[i]) {       // 如果是非素数
            curLen++;
            if (curLen > maxLen) {
                maxLen = curLen;
            }
        } else {                 // 如果是素数，中断连续
            curLen = 0;
        }
    }

    cout << maxLen << endl;

    return 0;
}
```
