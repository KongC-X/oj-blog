# 6051 - 定制架子问题

## 题目描述

李莳花要做一个架子，把她喜欢的摆件叠放起来，她的每个摆件的位置顺序是固定的。这个架子的宽度是 $W$，每层排放的摆件不能超过这个宽度，每层架子的高度不能低于最高的摆件的高度。

假设，给出排列好的每个摆件的宽度 $W_i$ ，和高度 $H_i$ ，请计算需要最少多高的架子。

## 输入

输入的第一行有 $2$ 个数字，一个是摆件的个数 $n$，和架子的宽度 $W$。 

以下摆件个数 $n$ 行，每行的第一个数是摆件的宽度 $W_i$ 和高度 $H_i$。

## 输出

输出放置摆件架子的最低高度。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, W;                    // n: 摆件个数, W: 架子宽度
    cin >> n >> W;

    int w[1005], h[1005];        // w[i]: 第i个摆件宽度, h[i]: 高度 (1‑based)
    for (int i = 1; i <= n; i++) {
        cin >> w[i] >> h[i];
    }

    // ---------- DP 思路 ----------
    // 问题类型：线性划分DP（类似于分段使各段最大值之和最小）
    // 状态定义：dp[i] 表示前 i 个摆件所需的最小架子总高度。
    // 初始化：dp[0] = 0，dp[1..n] 初值设为大数。
    // 转移：枚举最后一层的起始位置 j+1 (j < i)，
    //       要求第 j+1 到 i 的摆件总宽度 <= W，
    //       该层高度为 max(h[j+1]..h[i])，
    //       则 dp[i] = min(dp[j] + 该层最大高度)。
    // 复杂度 O(n^2)，n ≤ 1000 可行。

    long long dp[1005];          // 用 long long 防止溢出，总高可达 1e7
    for (int i = 0; i <= n; i++) dp[i] = 1e18;
    dp[0] = 0;

    for (int i = 1; i <= n; i++) {
        long long sumW = 0;      // 当前层从 j+1 到 i 的宽度累计
        int mxH = 0;             // 当前层的最大高度
        // 从 i 向前枚举 j，代表最后一层的左端点前一个位置
        for (int j = i; j >= 1; j--) {
            sumW += w[j];
            if (sumW > W) break; // 宽度超标，不能再向左扩展
            if (h[j] > mxH) mxH = h[j];
            // 此时最后一层为 j..i，前 j-1 个的最优解为 dp[j-1]
            if (dp[j - 1] + mxH < dp[i]) {
                dp[i] = dp[j - 1] + mxH;
            }
        }
    }

    cout << dp[n] << '\n';
    return 0;
}
```
