# 1233 - 求中位数

## 题目描述

中位数指的是一组数，如果按照大小排序排好后最中间的那个数的值，如果有偶数个元素，那么就是最中间两个数的平均数！

比如：$2$   $5$   $8$   $1$   $6$ ，排序后的结果为 $1$   $2$   $5$   $6$   $8$ ，那么这组数的中位数就是  $5$ ！

再比如： $8$   $9$   $1$   $2$   $3$   $0$ ，排序后的结果为 $0$   $1$   $2$   $3$   $8$   $9$ ，那么这组数的中位数就是 $(2+3)/2=2.5$ 。

## 输入

第一行：一个整数 $n$ 代表有 $n$ 个数（ $n \le 100$） 。

第二行： $n$ 个数的值。

## 输出

中位数（结果保留1位小数）。

## 解题思路

## AC代码

```cpp
int main() {
    // 从键盘读入字符数组
    char s[100];
    cin >> s;
    // cin之后，字符数组默认补充\0，以‘ ’作为结束
    gets(s);
    // gets(): 以回车作为结束
    cout << s << endl;

    // 遍历字符数组 strlen(),循环有效字符的下标（\0之前的字符）
    // 还有一种方法：s[i] != '\0'
    for (int i = 0;i < strlen(s);i++) {
        cout << s[i] << endl;
    }
}
```
