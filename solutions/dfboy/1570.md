# 1570 - 字符替换

## 题目描述

把一个字符串中特定的字符全部用给定的字符替换，得到一个新的字符串。

## 输入

只有一行，由一个字符串和两个字符组成，中间用单个空格隔开。

字符串是待替换的字符串，字符串长度小于等于 $100$ 个字符，且不含空格等空白符；

接下来一个字符为需要被替换的特定字符；

接下来一个字符为用于替换的给定字符。

## 输出

一行，即替换后的字符串。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream> 
#include<bits/stdc++.h> 
using namespace std;

int main(){
    string s,s1,s2;
    int p;
    cin >> s >> s1 >> s2;
    p = s.find(s1);
    while(p != -1) {
        s.replace(p, 1, s2);
        p = s.find(s1,p + 1);
    }
    cout << s << endl;
}
```
