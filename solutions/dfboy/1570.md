# 1570 - 字符替换

## 题目描述

把一个字符串中特定的字符全部用给定的字符替换，得到一个新的字符串。

## 输入

只有一行，由一个字符串和两个字符组成，中间用单个空格隔开。

字符串是待替换的字符串，字符串长度小于等于 $100$ 个字符，且不含空格等空白符；

接下来一个字符为需要被替换的特定字符；

接下来一个字符为用于替换的给定字符。

## 输出

一行，即替换后的字符串。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// x代表每个导弹的高度
// p代表找到的能拦截导弹的系统下标
// k代表在a中已经有的能拦截导弹的系统数量
int a[1010],i,j,n,x,k,p;
int main() { 
    cin >> n;
    for(i = 1;i <= n;i++) {
        cin >> x;
        p = -1;
        // 循环a数组，找到第一个能够拦截的系统
        for(j = 1;j <= k;j++) {
            if(a[j] >= x) {
                p = j;
                break;
            }
        }
        // 如果没找到系统拦截
        if(p == -1) {
            k++;
            a[k] = x; // 设定系统能拦截的最高高度
        } else {
            a[p] = x; // 用第p个系统能拦截的最高高度更新为当前导弹的高度
        }
    }
    cout << k;
}
```
