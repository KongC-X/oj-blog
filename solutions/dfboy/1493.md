# 1493 - 放大的Z

## 题目描述

打印 $n$ 行放大的 $Z$ 。
比如：
$n=3$ ，打印图形如下

```
`***
 *
***
`
```

$n=4$ ，打印图形如下

```
`****
  *
 *
****
`
```

$n=5$，打印图形如下

```
`*****
   *
  *
 *
*****
`
```

## 输入

一个整数 $n（n \lt 10$ ）

## 输出

n行放大的Z。
