# 1215 - Fish学数学

## 题目描述

花了一个多月的时间，Fish 终于学会了比较两个数的大小。他想检测下自己是否已经真的学会了，找来了 Bug 考考他。  Bug 马上写出了 $n$ 个数，要 Fish 数出每个数后面比他小的数的总个数， Fish 马上开始数了起来。 Bug 自己也在旁边算，可他发现自己也还不太清楚，但又不想在 Fish 面前丢脸，所以来求助你，希望你能够在 Fish 面前算出标准答案。

## 输入

第一行为数 $n$ ( $n \le 200$ )；

接下来 $n$ 行每行一个数 $a_i$ （ $ a_i \le 1000000$ )。

## 输出

一个数，每个数后面比他小的总个数。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[210],i,j,n,c;
int main(){
	cin>>n;
	for(i=1;i<=n;i++){
		cin>>a[i];
	}
	for(i=n;i>=1;i--){
		j=i;
		while(j<=n){
			if(a[i]>a[j]){
				c++;
			}
			j++;
		}
	}
	cout<<c<<endl;
}
```
