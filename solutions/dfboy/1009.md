# 1009 - 数组逆序

## 题目描述

给你 $n$ 个整数，将其逆序输出。

## 输入

第一行一个整数 $n$ （$3 \le n \le 100 $)代表数的个数。

第二行 $n$ 个整数（空格隔开）（这些数在 $0 \sim 10^6$ 之间)。

## 输出

$n$ 个整数（空格隔开）。
## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int a[110],n,i,t;
    cin >> n;
    for (i=0;i<n;i++) cin >> a[i];

    // 解法一：不真正逆序，而是直接倒序输出
    // for (i=n-1;i>=0;i--) cout << a[i] << " ";

    // 解法二：实现真正的逆序，循环数组长度的一半，对称交换位置
    for(i = 0;i < n /2;i++) {
        t = a[i];
        a[i] = a[n-i-1];
        a[n-i-1] = t;
    }
    for(i = 0;i < n;i++) cout << a[i] << " ";
}
```
