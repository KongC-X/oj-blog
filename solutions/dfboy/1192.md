# 1192 - 斜角I

## 题目描述

输入整数 $N$ ，输出相应方阵。

## 输入

一个整数 $N$ 。（ $0 \lt N \le 10$ )

## 输出

一个方阵，每个数字的场宽为 $3$ 。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

/*
思路：最大值和最小值尝试分一组
1. 如果最大值 + 最小值 <= w，则分到一组
2. 否则，最大值单独分一组 
*/

int a[30010],w,n,c = 0;

int main() {
	cin>>w>>n;

	for(int i = 1;i <= n;i++){
		cin>>a[i];
	}
	
	sort(a+1,a+n+1);

	int h = 1,t = n;//表示头尾在哪里
	while(h <= t){
		//头尾分一组 
		if(a[h] + a[t] <= w){
			c++;
			h++;
			t--;
		}else{
			//尾单独分一组
			c++;
			t--; 
		}
	} 
	cout<<c;
	return 0;
}
```
