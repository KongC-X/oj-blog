# 1748 - 山形数

## 题目描述

山形数指的是一个三位数，中间的十位比两边的个位和百位都大，类似山的形状。

请编程输出所有的山形数。

## 输入

无。

## 输出

从小到大输出所有的山形数，每行 $1$ 个。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
    int i,b,s,g;
    //遍历100到999的所有三位整数 
    for(i=100;i<=999;i++){
    	//对i进行拆位 
        b=i/100;
        s=i/10%10;
        g=i%10;
        //判断十位比两边的个位和百位都大
        if(s>b&&s>g){
            cout<<i<<endl;
        }
    }
    return 0;
}
```
