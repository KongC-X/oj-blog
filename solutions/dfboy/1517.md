# 1517 - 将n拆成2个数的乘积

## 题目描述

将 $n$ 拆成 $a \times b$ 的形式，比如：$10=2 \times 5$ ，请注意，此处 $10=5 \times 2$ 和 $10=2 \times 5$，认为是同一个方案。

## 输入

一行，一个整数 $n$ 。（ $n \le 1000$）

## 输出

若干行算式，每行 $1$ 个。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;
 
int main(){
	//定义变量x,y作为加密前和加密后的数
	//定义变量q,b,s,g作为千位,百位,十位,个位 
    int x,y,q,b,s,g;
    cin>>x;
    //对x进行拆位 
    q=x/1000;
    b=x/100%10;
    s=x%100/10;
    g=x%10;
    //对各个位加密并倒序加权 
    y=(g+5)%10*1000+(s+5)%10*100+(b+5)%10*10+(q+5)%10;
    cout<<y;
    return 0; 
}
```
