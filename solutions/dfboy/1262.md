# 1262 - 该存多少钱

## 题目描述

假设银行一年整存零取的月息为 $0.63 \%$。现在某人手中有一笔钱，他打算在今后的五年中的年底取出 $1000$ 元，到第五年时刚好取完，请算出他存钱时应存入多少。

## 输入

无

## 输出

第一年年初要存入多少钱，结果保留 $2$ 位小数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

//降序排列辅助函数
bool cmp(int a,int b){
    return a > b ? true : false; 
}

int main() { 
    int a[110];
    int n,m,i,s = 0;
    cin >> m >> n;
    for(i=0;i<n;i++) cin >> a[i];
    sort(a,a+n,cmp); // 从大到小排序
    // for(i=0;i<n;i++) cout << a[i] << " ";
    for(i=0;i<n;i++){
        s += a[i];
        if(s >= m){
            cout << i+1 << endl;
            break;
        }
    }
    if(s < m) {
        cout << "NO" << endl;
    }
}
```
