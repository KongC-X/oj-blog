# 1395 - 小丽找数？

## 题目描述

小丽同学想在 $1 \sim n$ 中找出这样的数，这个数的各个位的和不能被 $2$ 整除也不能被 $5$ 整除，比如 $3、12、25、30、100$ 。这些数都满足各个位的和不能被 $2$ 和 $5$ 整除。

请你编程找出 $1 \sim n$ 中这些数有多少个？

## 输入

一个整数 $n（n \le 9999$）。

## 输出

$1 \sim n$ 中满足条件的数的个数。
## AC代码
## AC代码

```cpp
# include <iostream>
using namespace std;

int main(){
    int i,n,a,s = 0,sum = 0;
    cin >> n;
    for(i = 1;i <= n;i++) {
        a = i; // 不要直接使用i，否则会出现错误
        s = 0; // 每次清空s
        while(a != 0) {
            s += a % 10;
            a = a / 10;
        }
        if(s % 2 != 0 && s % 5 != 0) {
            sum++;
        }
    }
    cout << sum;
}
```
