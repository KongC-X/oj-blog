# 1515 - 将n拆成2个数的和

## 题目描述

将 $n$ 拆成 $a+b$ 的形式，比如： $10=2+8$ ，请注意$10=8+2$ 此处认为和 $10=2+8$ 是同一个方案。

## 输入

一行一个数, $n（n \le 100）$ 。

## 输出

若干行算式，每行 $1$ 个。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	int n;
	cin>>n;
	//遍历a值范围从小到大 
	for(int i=0;i<=n/2;i++){
		//输出式子 
		cout<<n<<"="<<i<<"+"<<n-i<<endl;
	} 
	return 0;
}
```
