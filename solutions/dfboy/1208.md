# 1208 - 螺旋方阵

## 题目描述

输出如样例所示的 $n \times n$ 的螺旋方阵。

## 输入

一个整数 $n$ ( $0 \lt n \lt 10$ )。

## 输出

一个 $n$ 行方阵，每行 $n$ 个数，每个数场宽为 $3$。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main()
{
  int a[101],n,min,cnt=0;
  double sum=0;
  cin>>n;
  for(int i=1;i<=n;i++)
      cin>>a[i];
   min=a[1];
  for(int i=2;i<=n;i++)
      if(min>a[i])  min=a[i];
  for(int i=1;i<=n;i++)	
      if(min==a[i])  cnt++;	
  for(int i=1;i<=n;i++)
      if(a[i]!=min)  
	      sum=sum+a[i];
cout<<fixed<<setprecision(1)<<sum*1.0/(n-cnt);
  return  0;
}
```
