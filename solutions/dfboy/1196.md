# 1196 - 拐角I

## 题目描述

输入整数 $N$ ，输出相应方阵。

## 输入

一个整数 $N$ 。（ $0 \lt N \le 10$ )

## 输出

一个方阵，每个数字的场宽为 $3$ 。
## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int a[20][20];
int n;

// 递归为二维数组的第i行和第i列赋值
void fun(int i) {
    // 递归出口（条件）
    if(i <= n) {
        // 第i行从下标为i的那一列开始赋值
        for(int j = i; j <= n; j++) {
            // 为第i行赋值
            a[i][j] = i;
            // 为第i列赋值
            a[j][i] = i;
        }
        // 递归为下一行赋值
        fun(i + 1);
    }
}

int main() {
    cin >> n;
    fun(1);
    for(int i = 1; i <= n; i++) {
        for(int j = 1; j <= n; j++) {
            cout << setw(3) << a[i][j];
        }
        cout << endl;
    }
}
```
