# 1714 - 输出满足条件的整数4

## 题目描述

输出 $1 \sim n$ 中含有数字 $3$ 或者含有数字 $5$ ，且因数有 $2$ （即能被 $2$ 整除）的所有整数。（ $n \lt 1000$）

## 输入

从键盘输入一个整数 $n$ 。

## 输出

输出满足条件的整数，每行一个。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream> 
using namespace std;

int main() {
	int n,x,i = 1,c;
	cin >> n;
	while(i <= n) {
		x = i;
		while(x != 0) {
			c = x % 10;
			x = x / 10;
			if((c == 3 || c == 5) && i % 2 == 0) {
				cout << i << endl;
				break;
			}
		}
		i++;
	}
}
```
