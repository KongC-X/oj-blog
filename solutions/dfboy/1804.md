# 1804 - 统计直角、锐角、钝角的个数？

## 题目描述

输入 $n$ 个整数，代表角的度数，请编程计算出这些角中直角（$90$ 度的角）、锐角（$ \lt 90$ 度的角）、钝角（$ \gt 90$度的角）分别有多少个？

## 输入

第 $1$ 行有一个整数 $n$，代表有 $n$ 个角的度数。（$n \le 100$）

第 $2$ 行有 $n$ 个整数，代表角的度数（角的度数是$ \ge 1$且$ \lt 180$的整数）。

## 输出

输出 $3$ 个整数，用空格隔开，分别代表直角的个数、锐角的个数、钝角的个数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

string s,s1,s2;
long long x,y;
int main(){
	cin>>s;
	//123*45=
	int p = s.find("*");
	s1 = s.substr(0,p);
	s2 = s.substr(p+1,s.size()-1-p-1);
//	cout<<s1<<endl<<s2;
	
	//转换整数
	x = atoll(s1.c_str());
	y = atoll(s2.c_str());
	cout<<x*y; 
	return 0;
}
```
