# 1167 - 字典排序

## 题目描述

输入 $N$（$N \le 10$）个不超过 $4$ 位的整数，并要求按字典顺序（字典顺序的方法：先比较第一个数字，小者在先，若相同再比较第 $2$ 位数字，以此类推），由小到大排序输出。

## 输入

第一行为一个整数 $N$。

第 $2 \sim N+1$ 行为 $N$ 个不超过 $4$ 位的整数。

## 输出

一行，按字典顺序由小到大排序输出这 $N$ 个整数。
## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
//sort字符串排序就是用字典序
string a[20];
int n,i;
int main(){
	cin>>n;
	for(i=1;i<=n;i++){
		cin>>a[i];
	}
	sort(a+1,a+n+1);
	for(i=1;i<=n;i++){
		cout<<a[i]<<" ";
	}
	return 0;
}
```
