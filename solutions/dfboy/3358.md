# 3358 - 勾股数

## 题目描述

勾股数是很有趣的数学概念。如果三个正整数 $a$、$b$、$c$，满足 $a^2 + b^2 = c^2$，而且 $1 ≤ a ≤ b ≤ c$，我们就将 $a、b、c$ 组成的三元组 ($a, b, c$) 称为勾股数。

你能通过编程，数数有多少组勾股数，能够满足 $c ≤ n$ 吗？

## 输入

输入一行，包含一个正整数 $n$。约定 $1 ≤ n ≤ 1000$。

## 输出

输出一行，包含一个整数 $C$，表示有 $C$ 组满足条件的勾股数。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <cmath>

int main() {
	int n, ans = 0; std::cin >> n;
	for (int a = 1; a <= n; ++a)
		for (int b = a; b <= n; ++b) {
			int c = sqrt(a * a + b * b);
			if (c > n || c * c != a * a + b * b) continue;
			++ans;
		}
	std::cout << ans;
	return 0;
}
```
