# 1418 - 求一个5位数的各个位之和

## 题目描述

从键盘读入一个 $5$ 位的正整数，请求出这个 $5$ 位数的各个位之和。

## 输入

一个 $5$ 位的正整数 $n$ 。

## 输出

这个 $5$ 位数的各个位之和。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
#include<iomanip>
using namespace std;

int main() {
    int x,a,b,c,d,e;
    cin>>x;
    a = x / 10000;
    b = (x % 10000) / 1000;
    c = ((x % 10000) % 1000) / 100;
    d = (((x % 10000) % 1000) % 100) / 10;
    e = ((((x % 10000) % 1000) % 100) % 10);
    cout<<a + b + c + d + e<<endl;
}
```
