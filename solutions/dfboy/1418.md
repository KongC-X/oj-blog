# 1418 - 求一个5位数的各个位之和

## 题目描述

从键盘读入一个 $5$ 位的正整数，请求出这个 $5$ 位数的各个位之和。

## 输入

一个 $5$ 位的正整数 $n$ 。

## 输出

这个 $5$ 位数的各个位之和。

## 解题思路

## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int a[110],n,i,x,t;
    cin >> x;
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> a[i];
    }
    for(i = 0;i < n;i++) {
        if(a[i] > x) {  // 找到第一个大于x的位置并标记
            t = i;
            break;
        }
    }
    for(i = n - 1;i >= t;i--) {  // 从标记处开始移动元素
        a[i + 1] = a[i];
    }
    a[t] = x;
    for (i=0;i<n+1;i++) cout << a[i] << " ";
}
```
