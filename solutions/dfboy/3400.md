# 3400 - 小明的幸运数

## 题目描述

所有个位数为 $k$ 的正整数，以及所有 $k$ 的倍数，都被小明称为“ 幸运数”。小明想知道正整数 $L$ 和 $R$ 之间（包括 $L$ 和 $R$ ）所有 $k$ 幸运数的和，你能帮帮他吗？

## 输入

输入 $3$ 行。第一行包含一个正整数 $k$ ，第二行包含一个正整数 $L$，第三行包含一个正整数 $R$。约定 $2 \leq k \leq 9$, $1 \leq L \leq R \leq 1000 $。

## 输出

输出 $1$ 行，符合题意的幸运数之和。

## 解题思路

## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int i,j,n;
    char c;
    cin >> n;
    // 循环控制行数
    for(i = 1;i <= n;i++) {
        // 打印每一行的数字
        for(j = 1;j <= n;j++) {
            c = j + 64;
            cout << c;
        }
        // 打印每一行的换行符
        cout << endl;
    }
}
```
