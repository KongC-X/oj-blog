# 1629 - 六位数是否对称

## 题目描述

请从键盘读入一个六位整数，判断这个六位整数是否是对称数（对称数指的是，这个数正过来和倒过来是同一个数。

比如： $123321、685586、862268$ 等数都是对称数），如果是对称数，则输出 “`Y`” ，否则输出 “`N`” 。（请注意字母的大小写）。

## 输入

读入一个六位的整数。

## 输出

如果这个六位数是对称数，输出 “`Y`” ，如果不是，输出 “`N`” 。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int n,a[110][110],ma;

// 深搜：从(1,1)开始，每次向下或向右走，求出所有路径和的最大值
void dfs(int x,int y,int sum) {
    ma = max(sum,ma);
    // 递归出口：当x > n时，说明已经遍历完所有点
    if(x <= n) {
        // cout << x << " " << y << " " << sum << endl;
        // 递归走：x+1,y 和 x+1,y+1
        dfs(x+1,y,sum+a[x+1][y]);
        dfs(x+1,y+1,sum+a[x+1][y+1]);
    }
}

int main() {
    cin >> n;
    int i,j;
    for(i = 1;i <= n;i++) {
        for(j = 1;j <= i;j++) {
            cin >> a[i][j];
        }
    }
    dfs(1,1,a[1][1]);
    cout << ma << endl;
}

// 当层级过深时，深搜递归会有大量数据重复计算导致运行超时
```
