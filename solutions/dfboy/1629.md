# 1629 - 六位数是否对称

## 题目描述

请从键盘读入一个六位整数，判断这个六位整数是否是对称数（对称数指的是，这个数正过来和倒过来是同一个数。

比如： $123321、685586、862268$ 等数都是对称数），如果是对称数，则输出 “`Y`” ，否则输出 “`N`” 。（请注意字母的大小写）。

## 输入

读入一个六位的整数。

## 输出

如果这个六位数是对称数，输出 “`Y`” ，如果不是，输出 “`N`” 。

## 解题思路

## AC代码
## AC代码

```cpp
#include <iostream>
using namespace std;
 
int main(){
    int x,sw,w,q,b,s,g;
    cin>>x;
    sw=x/100000;
    w=x/10000%10;
    q=x/1000%10;
    b=x%1000/100;
    s=x%100/10;
    g=x%10;
    if(sw==g && w==s && q==b){
        cout<<"Y";
    }else{
        cout<<"N";
    }
}
```
