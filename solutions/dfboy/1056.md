# 1056 - 所有不超过1000的数中含有数字3的自然数

## 题目描述

编程求出所有不超过 $1000$ 的数中，含有数字 $3$ 的自然数，并统计总数。

## 输入

无。

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main()
{
    char a[260];
    cin >> a ;
    int k = strlen(a);
    for(int i = k - 1; i >= 0; i--)
    {
        cout << a[i];
    }
    return 0;
}
```
