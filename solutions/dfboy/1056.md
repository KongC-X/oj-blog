# 1056 - 所有不超过1000的数中含有数字3的自然数

## 题目描述

编程求出所有不超过 $1000$ 的数中，含有数字 $3$ 的自然数，并统计总数。

## 输入

无。

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

## 解题思路

## AC代码
## AC代码

```cpp
# include <iostream>
using namespace std;

int main(){
    int i,a,b,c,s = 1;
    for(i = 1;i < 1000;i++) {
        if(i >= 10 && i <= 100) {
            a = i / 10;
            b = i % 10;
            if(a == 3 || b == 3) {
                s++;
            }
        }
        else if(i > 100 && i < 1000) {
            a = i / 100;
            b = (i % 100) / 10;
            c = i % 10;
            if(a == 3 || b == 3 || c == 3) {
                s++;
            }
        }
    }
    cout << s;
}
```
