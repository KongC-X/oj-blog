# 1805 - 珠子计算

## 题目描述

杰克把 $N$ ($3 ≤ N ≤ 80$)粒蓝色和橙色的珠子连成了一串，问有多少对珠子（相邻的）是不同颜色的。

比如：输入$1$ $0$ $1$ $0$ $1$ $0$，那么有 $6$ 对相邻的珠子是不同颜色的。

## 输入

第一行，一个整数 $N$；

第二行，$N$ 个数字（$0$ 或 $1$），其中 $0$ 表示橙色，$1$ 表示蓝色。

## 输出

输出相邻两粒珠是不同颜色的对数。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 判断a数组中是否含有字母a
bool isHaveA(char a[]) {
    for(int i = 0;i < strlen(a);i++) {
        if(a[i] == 'a') {
            return true;
        }
    }
    return false;
}

int main() {
    char s[300],a[300],b[300] = {'\0'};
    int i,k = 0;
    bool flag = false;
    gets(s);
    for(i = 0;i < strlen(s);i++) {
        //如果s[i]不是空格，那么就是单词的一部分，存到a中
        if(s[i] != ' ') {
            a[k++] = s[i];
            // 如果当前单词结束了
            if(s[i + 1] == ' ' || s[i + 1] == '.') {
                a[k] = '\0';
                // 判断a数组中是否含有字母a
                if(isHaveA(a)) {
                    flag = true;
                    if(strlen(a) > strlen(b)) {
                        strcpy(b,a);// 将a拷贝给b
                    }  
                }
                k = 0;// 清空a字符串，存储下一个单词
            }
        }
    }
    if(flag) {
        cout << b << endl;
    }else {
        cout << "NO" << endl;
    }
}
```
