# 1654 - 全部排列问题

## 题目描述

输入 $n$ 输出 $1 \dots n$ 个数的全部排列。全部排列中，数字可以重复 。

例如输入 $3$ ，输出全部排列的结果如下：$111、112、113、121、122、123、131、132、133、211、212、213、221、222、223、231$、$232、233、311、312、313、321、322、323、331、332、333$。

## 输入

一个整数 $n$（$1 \lt n \le 6$）。

## 输出

按照由小到大的顺序输出 $1 \dots n$ 这 $n$ 个数的全部排列情况。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    int n,i,x = 2;
    cin >> n;
    for(i = 0; i < n; i++){
        x = x + 2 * i;
    }
    cout << x << endl;
}
```
