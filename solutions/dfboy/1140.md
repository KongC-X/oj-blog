# 1140 - 亲密数对

## 题目描述

键盘输入 $N$ ，$N$ 在 $2$ 至 $2000$ 之间，求 $2$ 至 $N$ 中的亲密数对，就是 $A$ 的因子和等于 $B$ ，$B$ 的因子和等于 $A$ ，且 $A \neq B$ 。 

如 $48$ 和 $75$ 是亲密数对。$48$ 的因子和为 $2+3+4+6+8+12+16+24=75$ ，而 $75$ 的因子和为 $3+5+15+25=48$ 。

## 输入

只有一行，为一个整数 $N$ （ $2 \le N \le 2000$ ）

## 输出

输出若干行，每行两个整数（用一个空格隔开）。

```cpp
#include <iostream>
#include <cmath>
using namespace std;

// 求一个数的因子和
int sumOfFactors(int n) {
    int sum = 0;
    for (int i = 2; i < n; i++) {
        if (n % i == 0) {
            sum += i;
        }
    }
    return sum;
}


int main() {
    // cout << sumOfFactors(48) << endl; // 75
    int n,i,j;
    cin >> n;
    for(i = 2;i <= n;i++){
        for(j = 2;j <= n;j++) {
            if(sumOfFactors(i) == j && sumOfFactors(j) == i) {
                cout << i << " " << j << endl;
            }
        }
    }
}
```
