# 1696 - 请输出1~n之间所有的整数

## 题目描述

从键盘读入一个整数 $n$ ，请循环输出 $1 \sim n$ 之间所有的整数，每行输出 $1$ 个。

比如，假设 $n=5$ ，那么输出结果如下：

$1$

$2$

$3$

$4$

$5$

## 输入

一个整数 $n$ 。

## 输出

输出 $1 \sim n$ 之间所有的整数。
## AC代码

```cpp
#include <iostream>
using namespace std;

int main(){
	//i用来循环，n用来表示最大数 
	int i,n;
	cin>>n;
	
	//1~n的循环
	//1、初始值 
	i = 1; 
	
	//2、循环条件
	while(i <= n){
		cout<<i<<endl;
		//3、让循环停止的方式 
		i = i + 1;
	} 
}
```
