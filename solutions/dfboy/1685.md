# 1685 - n个数的全排列

## 题目描述

从键盘读入 $n$ 个整数（每个数都是 $1 \sim 9$ 之间的数），输出这 $n$ 个整数的全排列（数字不能重复）。

## 输入

第 $1$ 行输入一个整数 $n$。（$1 \le n \le 8$）

第 $2$ 行输入 $n$ 个不相等的整数。（每个数在 $[1,9]$ 的范围内）

## 输出

输出若干行，每行包括 $n$ 个数据，表示一种排列方案，所**有的排列按字典码从小到大排序输出**。
## AC代码
## AC代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 10;
int n;
int nums[MAXN];
int current[MAXN];
bool visited[MAXN];

void dfs(int depth) {
    if (depth == n) {
        for (int i = 0; i < n; i++) {
            cout << current[i] << (i == n - 1 ? "\n" : " ");
        }
        return;
    }
    
    for (int i = 0; i < n; i++) {
        if (!visited[i]) {
            visited[i] = true;
            current[depth] = nums[i];
            dfs(depth + 1);
            visited[i] = false;
        }
    }
}

int main() {
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> nums[i];
    }
    
    // 排序，确保字典序
    sort(nums, nums + n);
    
    dfs(0);
    
    return 0;
}
```
