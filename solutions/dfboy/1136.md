# 1136 - 输出m和n范围内的完全数(完美数)

## 题目描述

任何一个自然数的约数中都有1和它本身，我们把小于它本身的因数叫做这个自然数的真约数。 如6的所有真约数是 $1$、$2$、$3$，而且 $6=1＋2＋3$ 。

像这样，一个数所有真约数的和正好等于这个数，通常把这个数叫做完美数。 古希腊人非常重视完美数。毕达哥拉斯发现它之后，人们就开始了对完美数的研究。 

现在要求输出所有在 $m$ 和 $n$ 范围内的完美数。

## 输入

输入只有一行，是两个整数 $m,n$，中间用空格隔开。（$2 \le m \le n \le 32767$)

## 输出

输出范围内的所有完全数，数与数之间用空格隔开。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

//求约数和
int fun(int n)
{
    int s = 0;

    //循环n的约数范围
    for(int i = 1; i <= sqrt(n); i++)
    {
        //如果i是n的因子
        if(n % i == 0)
        {
            //因子相等加1个，不等加2个
            if(i != n / i) s = s + i + n / i;
            else s = s + i;
        }
    }

    s = s - n;//不包括自己
    return s;
}

int m,n;
int main()
{
    cin>>m>>n;
    for(int i = m; i <= n; i++)
    {
        if(fun(i) == i)
        {
            cout<<i<<" ";
        }
    }
    return 0;
}
```
