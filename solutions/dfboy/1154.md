# 1154 - 数组元素的查找

## 题目描述

给你 $m$ 个整数，查找其中有无值为 $n$ 的数，有则输出该数第一次出现的位置，没有则输出 $-1$ 。

## 输入

第一行一个整数 $m$ 代表数的个数 ( $0 \le m \le 100$ ) 。

第二行 $m$ 个整数（空格隔开）( 这些数在$0 \sim 1000000$范围内 )。

第三行为要查找的数 $n$。

## 输出

$n$ 的位置或 $-1$。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
	int a[110],n,mi,i;
	cin>>n;
	for(i = 0; i < n; i++) {
		cin>>a[i];
	}

	//查找最小数
	mi = a[0];
	for(i = 1; i < n; i++) {
		if(a[i] < mi) {
			mi = a[i];
		}
	}

	//输出除了最小数以外的数
	for(i = 0; i < n; i++) {
		if(a[i] != mi) {
			cout<<a[i]<<" ";
		}
	}
	return 0;
}
```
