# 1287 - 高精度乘

## 题目描述

高精度乘，求两个很大的非负整数相乘的结果。

## 输入

$2$ 个非负整数，每个一行，每个整数不超过 $240$ 位。

## 输出

一个整数，表示相乘的结果。
## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
#include<iostream>
using namespace std;
string s1,s2;
int p,x;
int a[250],b[250],c[500];
int main(){
	cin>>s1>>s2;
	for(int i=s1.size()-1;i>=0;i--){
		a[i]=s1[s1.size()-1-i]-'0';
	}
	for(int i=s2.size()-1;i>=0;i--){
		b[i]=s2[s2.size()-1-i]-'0';
	}
	// 循环a数组的每⼀位，⽤a[i]去乘b数组的每⼀位b[j]
	// 结果错位加到c数组的c[i+j]这⼀位上
	for(int i = 0;i < s1.size();i++) {
		for(int j = 0;j < s2.size();j++) {
			c[i + j] = c[i + j] + a[i] * b[j];
			// 进位
			if(c[i + j] >= 10) {
				c[i + j + 1] = c[i + j + 1] + c[i + j] / 10;
				c[i + j] = c[i + j] % 10;
			}
		}
	}
	// 去除前导0
	for(int i = s1.size() + s2.size() - 1;i>=0;i--){
		if(c[i]!=0){
			p=i;
			break;
		}
	}
	for(int i=p;i>=0;i--){
		cout<<c[i];
	}
}
```
