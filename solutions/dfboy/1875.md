# 1875 - 数字和

## 题目描述

桐桐把合数 $483$ 的各位数字相加 $(4+8+3)=15$ ，再将 $483$ 分解成质因数相乘：$483=3 \times 7 \times 23$，把这些质因数各位数字相加 $(3+7+2+3)$，其和也为 $15$。

即：某合数的各位数字之和等于它所有质因数的各数字之和。你帮助桐桐把 $n$ 以内(包括 $n$ )具有上述特点的所有合数找出来好吗？

## 输入

一个整数 $n$ ($10 \le n \le 30000$)。

## 输出

若干行，每行输出 $5$ 个满足题目条件的数。

```cpp
#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

// 拆位求和
int num(int n) {
    int sum = 0;
    while(n) {
        sum += n % 10;
        n /= 10;
    }
    return sum;
}

// 判断一个数是质数
bool isPrime(int n) {
    if(n < 2) {
        return false;
    }
    for(int i = 2;i <= sqrt(n);i++) {
        if(n % i == 0) {
            return true;
        }
    }
    return false;
}

int main() {
    int n,j,k,i,t = 0,s1,s2;
    cin >> n;
    for(j = 4;j <= n;j++) {
        if(!isPrime(j)) {
            continue;
        }
        s1 = 0; // 数字和
        s2 = 0; // 因子数字和
        i = 2; // 从2开始找j的因⼦
        k = j; // 保存j的值
        s1 = num(k);
        // cout << "s1:" << s1 << endl;
        while(k != 1) {
            // 如果i是j的因⼦
            if(k % i == 0) {
                s2 += num(i);
                k = k / i;
            } else {
                i++; // 看下⼀个数
            }
        }
        // cout << "s2:" << s2 << endl;
        if(s1 == s2) {
            cout << j << " ";
            t++; // 计数
            if(t % 5 == 0) {
                cout << endl;
            }
        }
    }
}
```
