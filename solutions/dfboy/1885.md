# 1885 - 钱币兑换

## 题目描述

在一个国家仅有 $1$ 分，$2$ 分，$3$ 分硬币，将钱 $N$ 分 () 兑换成硬币有很多种兑法。

请你编程序计算出共有多少种兑法。

## 输入

输入一个正整数 $N$，$N$ 小于 $32768$。

## 输出

输出兑换的方法数。（本题数据的计算结果在int范围内）
## AC代码

```cpp
// 解法一：找出状态转移方程，二维数组求解
// 要凑n分：令dp[i][j]==x 表示用前i种硬币构造j 美分共有x种方法。
// 初始化:  dp为全0且dp[0][0]==1。
// 状态转移: dp[i][j] = sum(dp[i-1][j] , dp[i][j-val[i]])
// sum是求和, val[i]是第i种硬币的面值。
// 上述方程 前者是指第i值硬币一个都不选, 后者是指至少选1个第i种硬币。

#include <bits/stdc++.h>
using namespace std;

int n,i,j,dp[4][40000];
 
int main() {
	int n;
	cin>>n;
	
	for(int i = 1;i <= 3;i++){
		dp[i][0] = 1;//初始化 
		//j从i开始循环，防止背包容量不够 
		for(int j = 1;j <= n;j++){
			if(j < i){
				dp[i][j] = dp[i - 1][j];
			} else{
				dp[i][j] = dp[i - 1][j] + dp[i][j - i]; 	
			}
		}
	}
	
	cout<<dp[3][n];
	return 0;
}
```
