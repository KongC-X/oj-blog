# 2056 - 铲雪车snow

## 题目描述

随着白天越来越短夜晚越来越长，我们不得不考虑铲雪问题了。

整个城市所有的道路都是双车道，因为城市预算的削减，整个城市只有 $1$ 辆铲雪车。铲雪车只能把它开过的地方（车道）的雪铲干净，无论哪儿有雪，铲雪车都得从停放的地方出发，游历整个城市的街道。

现在的问题是：最少要花多少时间去铲掉所有道路上的雪呢？

## 输入

输入数据的第 $1$ 行表示铲雪车的停放坐标（$x,y$），$x$，$y$ 为整数，单位为米。

下面最多有 $100$ 行，每行给出了一条街道的起点坐标和终点坐标，所有街道都是笔直的，且都是双向一个车道。铲雪车可以在任意交叉口、或任何街道的末尾任意转向，包括转U型弯。铲雪车铲雪时前进速度为 $20$ km/h，不铲雪时前进速度为 $50$ km/h。

保证：铲雪车从起点一定可以到达任何街道。

## 输出

铲掉所有街道上的雪并且返回出发点的最短时间，精确到分钟。（请输出 $2$ 位的分钟数，如：$3$ 小时 $1$ 分钟，请输出 `3:01`）
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 定义变量：
    // x1,y1,x2,y2：每条街道的起点和终点坐标
    // s,e：铲雪车停放的起始坐标（虽然读取了，但本题总路程固定，与起点位置无关，因此未使用）
    long long x1, y1, x2, y2, s, e;
    long long h, m;   // h: 最终小时数, m: 最终分钟数
    double r = 0;     // r 先累加街道总长度（单位：米），最后转换为总时间（单位：小时）

    // 读取铲雪车的停放坐标（仅消耗输入流，后续计算中无需使用）
    cin >> s >> e;

    // 循环读取所有街道的起点和终点坐标，直到文件结束
    while (cin >> x1 >> y1 >> x2 >> y2) {
        // 计算当前这条街道的长度（欧几里得距离），单位：米
        // 注意：坐标差值是 long long 类型，但 sqrt 需要 double 类型，C++ 会隐式转换
        r = r + sqrt((x2 - x1) * (x2 - x1) + (y2 - y1) * (y2 - y1));
    }

    // 核心计算：
    // 1. 乘以 2：因为题目说所有道路都是双车道（双向），铲雪车必须把两个方向都铲干净
    // 2. 除以 1000：将米转换为千米
    // 3. 除以 20：铲雪时的速度为 20 km/h，得到总耗时（单位：小时）
    r = r * 2 / 1000 / 20;

    // 提取整数部分作为小时数
    h = (long long)(r);

    // 提取小数部分转换为分钟：
    // (r - h) * 60 得到剩余分钟数（浮点数）
    // 加 0.5 是为了四舍五入到最近的整数分钟
    m = (long long)((r - h) * 60 + 0.5);

    // 输出格式：小时:两位分钟数（例如 3:05）
    // %02lld 表示分钟不足两位时用前导零补齐
    printf("%lld:%02lld\n", h, m);

    return 0;
}
```
