# 1642 - 成绩

## 题目描述

根据用户输入的成绩，判断是否通过了考试。

## 输入

一个整数，表示考试成绩。

## 输出

成绩 $ \ge 60$，输出 “`pass!`”；否则输出 “ `sorry!` ” 。
## AC代码

```cpp
#include <iostream>
using namespace std;
int main(){
    int s;
    cin>>s;
    if(s>=60){
        cout<<"pass!";
    }else{
        cout<<"sorry!";
    }
}
```
