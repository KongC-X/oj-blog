# 1161 - 元素插入有序数组

## 题目描述

给你一个整数 $n$ 和一个数列(数列个数不超过 $1000$ )，这个数列保证从小到大排列，现要求将这个整数 $n$ 插入到数列中，使新的数列仍然从小到大排列。

## 输入

第一行一个整数 $n$ 表示等待插入的数 ；

第二行一个整数 $m$ 表示数列中数的个数；

第三行 $m$ 个整数（空格隔开）。

## 输出

一行整数：新的数列（空格隔开）。

#include<bits/stdc++.h>
using namespace std;
int a[11],i,n,x,y;
int main(){
	cin>>x;
	cin>>n;
	for(i=1;i<=n;i++){
		cin>>a[i]; 
	}
	n++;
	a[n]=x;
	sort(a+1,a+n+1);
	for(i=1;i<=n;i++){
		cout<<a[i]<<" ";
	}
}
