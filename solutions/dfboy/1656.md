# 1656 - 是两位的偶数吗

## 题目描述

输入一个整数 $n$ ，请帮忙判断一下这个整数 $n$ 是否是两位的偶数，如果是输出 `Yes` ，如果不是，请输出 `No` 。（请注意大小写）。

比如：$28$ 就是一个两位偶数，而 $128$ 就不是两位偶数。

## 输入

一个整数 $n$ 。

## 输出

如果n是两位偶数输出 `Yes` ，否则输出 `No` 。

## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int a;
    cin >> a;
    if(a >= 10 && a <= 99 && a % 2 == 0) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }
}
```
