# 1451 - n个一位数能够组成的最大数

## 题目描述

请问 $n$ 个一位数能够组成的最大的整数是多少。

比如，$n$ =$3$ ，$3$ 个整数为 $1、3、9$ ，那么组成的最大整数是 $931$ 。

比如， $n$ = $4$ ， $4$ 个整数为 $2、8、0、6$ ，那么组成的最大整数是 $8620$ 。

## 输入

第一行为一个整数 $n$ （$n \lt 10$）。

第二行为 $n$ 个一位数。

## 输出

一行，包含一个组成的最大整数。

## 解题思路

## AC代码

```cpp
// 解法一：使用公共变量s,递归循环加到s上
#include<iostream>
using namespace std;
int n,s;
void fun(int i) {
    if(i <= n) {
        s += i;
        fun(i + 1); // 递归调用
    }
}
int main() {
    cin >> n;
    fun(1);
    cout << s;
}


// 解法二：通过层层累加，然后将和层层返回
#include<iostream>
using namespace std;
int n;
int fun(int i) {
    if(i <= n) {
        return i + fun(i + 1); // 递归调用
    } else {
        return 0; // 递归终止条件
    }
}
int main() {
    cin >> n;
    cout << fun(1); // 调用递归函数
}


// 解法三：将1-n中每个数都加到第二个参数s上，传递到下一层
// 一直到i>n，递归结束，求和也结束了，返回s的值
#include<iostream>
using namespace std;
int n;
int fun(int i, int s) {
    if(i <= n) {
        return fun(i + 1, s + i); // 递归调用，传递下一个数和累加和
    } else {
        return s; // 返回累加和
    }
}
int main() {
    cin >> n;
    cout << fun(1, 0); // 调用递归函数
}
```
