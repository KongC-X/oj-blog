# 1780 - 采灵芝

## 题目描述

仙岛上种了无数的不同种类的灵芝，小芳跟着爷爷来到仙岛采摘灵芝。由于他们带的食物和饮用水有限，必须在时间 $t$ 内完成采摘。

假设岛上有 $m$ 种不同种类的灵芝，每种灵芝都有无限多个，已知每种灵芝采摘需要的时间，以及这种灵芝的价值；

请你编程帮助小芳计算，在有限的时间 $t$ 内，能够采摘到的灵芝的最大价值是多少？

## 输入

输入第一行有两个整数 $T$（$1 \le T \le 100000$）和 $M$（$1 \le M \le 2000$），用一个空格隔开，$T$代表总共能够用来采灵芝的时间，$M$ 代表岛上灵芝的种类数。

接下来的 $M$ 行每行包括两个在 $1$ 到 $10000$ 之间（包括 $1$ 和 $10000$ ）的整数，分别表示采摘某种灵芝的时间和这种灵芝的价值。

## 输出

输出一行，这一行只包含一个整数，表示在规定的时间内，可以采到的灵芝的最大总价值。
## AC代码

```cpp
#include <bits/stdc++.h> // 万能头文件
#include <iostream>
using namespace std;

/*
    01背包问题
    二维数组：dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - w[i]] + v[i])
    一维数组滚动优化：从背包容量开始倒序遍历到当前物品的重量wi
    一维数组：dp[j] = max(dp[j], dp[j - w[i]] + v[i])

    完全背包问题：每种物品可以取无限次
    二维数组：dp[i][j] = max(dp[i - 1][j], dp[i - 1][j - k * w[i]] + k* v[i])
    经过变换之后和01二维只有一个i和i - 1的区别：
    dp[i][j] = max(dp[i - 1][j], dp[i][j - w[i]] + v[i])
    一维数组滚动优化：从当前物品的重量wi开始正序遍历到背包容量c
    一维数组：dp[j] = max(dp[j], dp[j - w[i]] + v[i])

*/

int c; // 背包容量
int dp[100010];
int n,wi,vi;

int main() {
    cin >> c >> n;
    // 遍历每个物品
    for(int i = 1;i <= n;i++) {
        cin >> wi >> vi;
        // 从当前物品的重量wi开始正序遍历
        for(int j = wi;j <= c;j++) {
            dp[j] = max(dp[j], dp[j - wi] + vi);
        }
    }
    cout << dp[c] << endl;
}
```
