# 1184 - 数字走向I

## 题目描述

输入整数 $N$ ，输出相应方阵。

## 输入

一个整数 $N$ 。（ $0 \lt N \le 10$ )

## 输出

一个方阵，每个数字的场宽为 $3$ 。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int a[20][20],n,x = 1,i,j;
int main() {
    cin >> n;
    for(i = 0;i < n;i++) {
        for(j = 0;j < n;j++) {
            a[i][j] = x;
            x++;
        }
    }
    for(i = 0;i < n;i++) {
        for(j = 0;j < n;j++) {
            cout << setw(3) << a[i][j];
        }
        cout << endl;
    }
}
```
