# 3674 - B -smooth 数

## 题目描述

小杨同学想寻找一种名为 $B-smooth$ 数的正整数。

如果一个正整数的最大质因子不超过 $B$，则该正整数为 $B-smooth$ 数。

小杨同学想知道，对于给定的 $n$ 和 $B$，有多少个不超过 $n$ 的 $B-smooth$ 数。

## 输入

第一行包含两个正整数 $n，B$，含义如题面所示。

## 输出

输出一个非负整数，表示不超过 $n$ 的 $B-smooth$ 数的数量。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[1000010];
int ans;
int main() {
	int n, b;
	cin >> n >> b;
	a[1] = 1;
	for (int i = 2; i <= n; i++) {
		if (!a[i]) {
			for (int j = i; j <= n; j += i)
				a[j] = i;
		}
	}
	for (int i = 1; i <= n; i++) { 
		if (a[i] <= b)
			ans++;
	}
	cout << ans;
	return 0;
}
```
