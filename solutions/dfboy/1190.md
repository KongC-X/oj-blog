# 1190 - 对角线I

## 题目描述

输入整数 $N$ ，输出相应方阵。

## 输入

一个整数 $N$ 。（ $0 \lt N \le 10$ )

## 输出

一个方阵，每个数字的场宽为 $3$ 。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;

int main(){
    int a[20],s=0,i,h;
    for(i = 0;i < 10;i++) {
        cin>>a[i];
    }
    cin >> h;
    for(i = 0;i < 10;i++) {
        if(a[i] <= h + 30) {
            s++;
        }
    }
    cout << s << endl;
}
```
