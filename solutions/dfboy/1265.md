# 1265 - 爱因斯坦的数学题

## 题目描述

爱因斯坦出了一道这样的数学题：有一条长阶梯，若每步跨 $2$ 阶，则最最后剩一阶，若每步跨 $3$ 阶，则最后剩 $2$ 阶，若每步跨 $5$ 阶，则最后剩 $4$ 阶，若每步跨 $6$ 阶则最后剩 $5$ 阶。

只有每次跨 $7$ 阶，最后才正好一阶不剩。

请问这条阶梯最少共有多少阶？

## 输入

无。

## 输出

这条阶梯最少的阶数。

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
 
int main(){
    int i=1;
    //从一开始穷举，直到找到复合条件的数，跳出循环 
    while(1){
        if(i%2==1&&i%3==2&&i%5==4&&i%6==5&&i%7==0){
            cout<<i<<endl;
            break;
        }
        i++;
    }
    return 0;
}
```
