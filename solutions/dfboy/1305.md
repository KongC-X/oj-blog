# 1305 - 求四个数的最大数

## 题目描述

已知有四个不等的数，将其中的最大数找出来。

## 输入

输入只有一行，包括 $4$ 个整数。之间用一个空格分开。

## 输出

输出只有一行，包括 $1$ 个整数。

## 解题思路

## AC代码
## AC代码

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main(){
	//定义整数变量a,b,c,d代表输入的4个整数
	//m代表最大数 
    int a,b,c,d,m;
    //输入4个整数 
    cin>>a>>b>>c>>d;
    //用"打擂台"对数字做比较找出最大的值 
	m=a;
    if(b>m){
        m=b;
    }
    if(c>m){
        m=c;
    }
    if(d>m){
        m=d;
    }
    //输出最大值m 
    cout<<m;    
	return 0;
}
```
