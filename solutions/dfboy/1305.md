# 1305 - 求四个数的最大数

## 题目描述

已知有四个不等的数，将其中的最大数找出来。

## 输入

输入只有一行，包括 $4$ 个整数。之间用一个空格分开。

## 输出

输出只有一行，包括 $1$ 个整数。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

struct Shop{
    int price; // 单价
    int num; // 数量
}a[1100];

bool cmp(Shop a,Shop b) {
    if(a.price > b.price) {
        return false;
    } else {
        return true;
    }
}

int main() {
    int i,m,n,k = 0,s = 0;
    cin >> m >> n;
    for(i = 0;i < n;i++) {
        cin >> a[i].price >> a[i].num;
    }
    // 按照单价从低到高排序
    sort(a,a+n,cmp);
    // 输出验证
    // for(i = 0;i < n;i++) {
    //     cout << a[i].price << " " << a[i].num << endl;
    // }
    for(i = 0;i < n;i++) {
        k += a[i].num;
        s += a[i].price * a[i].num;
        if(k >= m) {
            s = s - a[i].price * (k - m);
            break;
        }
    }
    cout << s << endl;
}
```
