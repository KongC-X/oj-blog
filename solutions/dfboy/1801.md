# 1801 - 传球游戏

## 题目描述

上体育课的时候，小蛮的老师经常带着同学们一起做游戏。这次，老师带着同学们一起做传球游戏。

游戏规则是这样的：$n$个同学站成一个圆圈，其中的一个同学手里拿着一个球，当老师吹哨子时开始传球，每个同学可以把球传给自己左右的两个同学中的一个（左右任意），当老师再次吹哨子时，传球停止，此时，拿着球没有传出去的那个同学就是败者，要给大家表演一个节目。

聪明的小蛮提出一个有趣的问题：有多少种不同的传球方法可以使得从小蛮手里开始传的球，传了 $m$次 以后，又回到小蛮手里。两种传球方法被视作不同的方法，当且仅当这两种方法中，接到球的同学按接球顺序组成的序列是不同的。比如有三个同学 $1$ 号、 $2$ 号、 $3$ 号，并假设小蛮为 $1$ 号，球传了 $3$ 次回到小蛮手里的方式有 $1$->$2$->$3$->$1$ 和 $1$->$3$->$2$->$1$ ，共 $2$ 种。

## 输入

一行，有两个用空格隔开的整数$n,m(3 \le n \le 30,1 \le m \le 30)$。

## 输出

$1$个整数，表示符合题意的方法数。

```cpp
#include <iostream>
using namespace std;

// 这个程序解决的问题是：在n个同学围成一圈的传球游戏中，从指定同学（小蛮，编号为0）开始传球，传m次后球又回到小蛮手中的不同传球方法数
int main() {
    int n, m;
    cin >> n >> m;
    // dp数组用于存储中间结果，dp[i][j]表示传了i次球后，球在编号为j的同学手里的方法数
    int dp[m + 1][n]; 

    // 初始化边界条件：传球0次时，球只能在小蛮（编号为0）手里，所以dp[0][0] = 1，其他位置为0
    for (int i = 0; i < n; i++) {
        dp[0][i] = 0;
    }
    dp[0][0] = 1;

    // 开始状态转移过程
    // 外层循环i表示传球的次数，从第1次传到第m次
    for (int i = 1; i <= m; i++) {
        // 内层循环j表示同学的编号，从0到n - 1
        for (int j = 0; j < n; j++) {
            // 第i次球传到编号为j的同学手里的方法数，等于第i - 1次球在编号为(j - 1 + n) % n（左边同学）手里的方法数
            // 加上第i - 1次球在编号为(j + 1) % n（右边同学）手里的方法数
            // 这里使用取模运算(n + j - 1) % n 来处理同学编号循环的情况，确保左边同学编号在合法范围内
            dp[i][j] = dp[i - 1][(j - 1 + n) % n]+dp[i - 1][(j + 1) % n];
        }
    }
    // 输出传m次球后，球回到小蛮（编号为0）手里的方法数
    cout << dp[m][0] << endl; 
    return 0;
}
```
