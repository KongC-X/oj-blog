# 4141 - 数字替换

## 题目描述

小杨有一个包含 $n$ 个数字的序列 $A$，即 $A = { a_1,a_2, \dots , a_n } $，他想将其中大于 $k$ 的数字都替换为序列的最大值，将其中小于 $k$ 的数字都替换为序列的最小值，请你帮他计算出替换后的序列。

## 输入

第一行包含两个正整数 $n,k$，含义如题⾯所示。

第二行包含 $n$ 个数字，代表序列 $A$。

## 输出

输出 $n$ 个整数，代表替换后的结果。

```cpp
#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int n,k,i,mi,ma;
int a[100010];

int main() {
    cin>>n>>k;
    for(i = 0;i < n;i++) {
        cin>>a[i];
    }
    ma = a[0];
    mi = a[0];
    for(i = 0;i < n;i++) {
        if(a[i] < mi) mi = a[i];
        if(a[i] > ma) ma = a[i];
    }
    // cout << ma << " " << mi;
    for(i = 0;i < n;i++) {
        if(a[i] > k) a[i] = ma;
        if(a[i] < k) a[i] = mi;
    }
    for(i = 0;i < n;i++) {
        cout << a[i] << " ";
    }
}
```
