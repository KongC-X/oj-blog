# 4141 - 数字替换

## 题目描述

小杨有一个包含 $n$ 个数字的序列 $A$，即 $A = { a_1,a_2, \dots , a_n } $，他想将其中大于 $k$ 的数字都替换为序列的最大值，将其中小于 $k$ 的数字都替换为序列的最小值，请你帮他计算出替换后的序列。

## 输入

第一行包含两个正整数 $n,k$，含义如题⾯所示。

第二行包含 $n$ 个数字，代表序列 $A$。

## 输出

输出 $n$ 个整数，代表替换后的结果。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <cmath>
using namespace std;

// 求数位的和
int digitSum(int n) {
    int sum = 0;
    while (n > 0) {
        sum += n % 10;
        n /= 10;
    }
    return sum;
}

int main() {
    int n;
    cin >> n;
    while(n >= 10) {
        n = digitSum(n);
    }
    cout << n << endl;
}
```
