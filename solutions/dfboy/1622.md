# 1622 - 十位大还是个位大

## 题目描述

请从键盘读入一个两位数（个位和十位不相等），计算一下，这个两位数的十位和个位，哪一位更大， 输出更大的那一位。

比如，输入 $18$ ，由于十位为 $1$ ，个位为 $8$ ，个位更大，因此输出 $8$ 。

## 输入

输入一个两位整数。

## 输出

输出这个两位数的十位和个位的较大数。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int a[100],n,i,x;
int dp[100];
int ma,s;

int main() {
    cin >> n;
    for(i = 1;i <= n;i++) {
        cin >> a[i];
    }
    // 交代边界的值
    dp[1] = a[1];
    dp[2] = max(a[1],a[2]);
    // 递推
    for(i = 3;i <= n;i++) {
        dp[i] = max(dp[i - 1],dp[i - 2] + a[i]);
    }
    cout << dp[n];
}
```
