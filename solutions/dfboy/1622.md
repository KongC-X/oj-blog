# 1622 - 十位大还是个位大

## 题目描述

请从键盘读入一个两位数（个位和十位不相等），计算一下，这个两位数的十位和个位，哪一位更大， 输出更大的那一位。

比如，输入 $18$ ，由于十位为 $1$ ，个位为 $8$ ，个位更大，因此输出 $8$ 。

## 输入

输入一个两位整数。

## 输出

输出这个两位数的十位和个位的较大数。

## AC代码

# include <iostream>
# include <iomanip>
using namespace std;

int main() {
    int n,a,b;
    cin >> n;
    a = n / 10;
    b = n % 10;
    if (a > b) {
        cout << a << endl;
    } else {
        cout << b << endl;
    }

}
