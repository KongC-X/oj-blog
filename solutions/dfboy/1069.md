# 1069 - 字符图形5-星号梯形

## 题目描述

输入一个整数打印字符图形 $n=3$ 输出：

```
`□□***
□*****
*******
`
```

$n=5$，输出：

```
`□□□□***
□□□*****
□□*******
□*********
***********
`
```

输出中的 `□` 代表空格。

## 输入

一个整数（ $ 0 \lt n \lt 10 $）。

## 输出

一个字符图形。
