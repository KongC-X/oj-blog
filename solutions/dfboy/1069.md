# 1069 - 字符图形5-星号梯形

## 题目描述

输入一个整数打印字符图形 $n=3$ 输出：

```
`□□***
□*****
*******
`
```

$n=5$，输出：

```
`□□□□***
□□□*****
□□*******
□*********
***********
`
```

输出中的 `□` 代表空格。

## 输入

一个整数（ $ 0 \lt n \lt 10 $）。

## 输出

一个字符图形。
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n;
    cin>>n;
    int i,j;
    for(i=1;i<=n;i++){
    	//每行输出n-i个空格 
        for(j=1;j<=n-i;j++){
            cout<<" ";
        }
        //每行输出 2*i+1个* 
        for(j=1;j<=2*i+1;j++){
            cout<<"*";
        }
        cout<<endl;
    }
    return 0;
}
```
