# 1645 - 正负数

## 题目描述

从键盘读入一个非 $0$ 整数，判断它的正负。是正数，则输出“ `+` ”，是负数，则输出 “ `-` ” 。

## 输入

一个非 $0$ 整数 $n$ ( $n$ 在 $-32768 \sim 32767$ 之间)。

## 输出

是正数，则输出 “ `+` ”，是负数，则输出 “`-`” 。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	int n;
	cin>>n;
	
	if(n>0){
		cout<<"+";
	}else{
		cout<<"-";
	} 
	return 0;
}
```
