# 1700 - 请输出所有的2位数中，含有数字2的整数

## 题目描述

请输出所有的 $2$ 位数中，含有数字 $2$ 的整数有哪些，每行 $1$ 个，按照由小到大输出。

比如： $12、20、21、22、23 \dots $ 都是含有数字 $2$ 的整数。

## 输入

无。

## 输出

按题意要求由小到大输出符合条件的整数，每行 $1$ 个。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s;
    long long n,x;
    char c;
    cin >> n;
    // 短除法
    while(n != 0) {
        x = n % 8;
        c = x + '0'; // 这里要先把数字转成字符才能存入字符串
        s = c + s;
        n = n / 8; // 记得把n除8
    }
    if(s == "") {
        cout << 0 << endl; // 考虑n==0的情况
    } else {
        cout << s << endl;
    }
}
```
