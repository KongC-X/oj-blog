# 4676 - 四舍五入

## 题目描述

四舍五入是一种常见的近似计算方法。现在，给定 $n$ 个整数，你需要将每个整数四舍五入到最接近的整十数。例
如， $43$ 四舍五入后为 $40$ ， $58$  四舍五入后为  $60$ 。

## 输入

共 $n+1$ 行，第一行，一个整数 $n$ ，表示接下来输入的整数个数。

接下来 $n$ 行，每行一个整数 $a_1，...，a_n$ ，表示需要四舍五入的整数。

## 输出

$n$ 行，每行一个整数，表示每个整数四舍五入后的结果。
## AC代码
## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int main() {
    int n,i,x,t,k;
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> x;
        t = x % 10;
        if(t > 4) {
            k = 10 - t;
            x += k;
        } else {
            x -= t;
        }
        cout << x << endl;
    }
}
```
