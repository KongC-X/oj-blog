# 4965 - 无序数对

## 题目描述

从键盘读入整数 $N$，请输出 $[1, N]$ 范围内**每个数和它后面的数**，构成的无序数对。

输出时，按照第 $1$ 个数从小到大，第 $1$ 个数相同，第 $2$ 个数从小到大的顺序输出。

比如 $N=4$，则 $[1, 4]$ 范围内的有序数对有：

```
`1 2
1 3
1 4
2 3
2 4
3 4
`
```

## 输入

输入一个整数 $N$。($1 \le N \le 100$)。

## 输出

按照从小到大的顺序，输出所有的无序数对。
## AC代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int N;
    cin >> N;
    
    for (int i = 1; i <= N; i++) {
        for (int j = i + 1; j <= N; j++) {
            cout << i << " " << j << endl;
        }
    }
    
    return 0;
}
```
