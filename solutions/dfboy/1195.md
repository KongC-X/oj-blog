# 1195 - 斜角IV

## 题目描述

输入整数 $N$ ，输出相应方阵。

## 输入

一个整数 $N$ 。（ $0 \lt N \le 10$ )

## 输出

一个方阵，每个数字的场宽为 $3$ 。

## 解题思路

## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int i,s = 1;
    for(i = 9;i >= 1;i--) {
        s = (s + 1) * 2;
    }
    cout << s << endl;
}
```
