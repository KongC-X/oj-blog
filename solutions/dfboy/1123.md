# 1123 - 表达式的值

## 题目描述

给出一个表达式，其中运算符仅包含 `+` ,要求求出表达式的最终值。

如：$1+1$，则结果为 $2$，$1+2+3$ 则结果为 $6$， $12+23$ 则结果 $35$ 。

## 输入

仅一行，即为含有正整数和 `+` 号的表达式。

## 输出

仅一行，既为表达式算出的结果（所有数据保证，读入的表达式长度不超过30位，计算结果 $\le 10^9$ ）。

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s,s1,s2;
    int i,x,k = 0;
    cin >> s;
    s = s + "+";
    for(i = 0;i < s.size();i++) {
        if(s[i] != '+') {
            s1 += s[i];
            if(s[i + 1] == '+') {
                // cout << s1 << " ";
                x = stoi(s1);
                k += x;
                s1 = "";
            }
        }
    }
    cout << k << endl;
}
```
