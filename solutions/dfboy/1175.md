# 1175 - 语文成绩

## 题目描述

给出 $N$ ( $5 \le N \le 150$ )个人的语文成绩，求 $N$ 个人的语文总分和平均分，并按成绩高低排序后输出。

## 输入

第 $1$ 行：一个整数 $N$ ；

第 $2$ 行：空格隔开的 $N$ 个整数，表示 $N$ 个人的语文成绩。

## 输出

第 $1$ 行：一个整数，为 $N$ 个人的总分；

第 $2$ 行： $N$ 个人的语文平均分，保留两位小数； 

第 $3$ 行： $N$ 个空格隔开的整数，为从高到低输出的 $N$ 个人的成绩。

```cpp
# include <iostream>
using namespace std;

int main() {
    int a[200],i,n,s = 0;
    double v;
    cin >> n;
    for(i = 0; i < n; i++) {
        cin >> a[i];
        s += a[i];
    }
    cout << s << endl; // 总分
    v = s * 1.0 / n;
    printf("%.2f\n",v); // 平均分
    // 从大到小冒泡排序
    for(i = 0; i < n - 1; i++) {
        for(int j = 0; j < n - i - 1; j++) {
            if(a[j] < a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }
    for(i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
}
```
