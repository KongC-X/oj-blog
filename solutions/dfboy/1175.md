# 1175 - 语文成绩

## 题目描述

给出 $N$ ( $5 \le N \le 150$ )个人的语文成绩，求 $N$ 个人的语文总分和平均分，并按成绩高低排序后输出。

## 输入

第 $1$ 行：一个整数 $N$ ；

第 $2$ 行：空格隔开的 $N$ 个整数，表示 $N$ 个人的语文成绩。

## 输出

第 $1$ 行：一个整数，为 $N$ 个人的总分；

第 $2$ 行： $N$ 个人的语文平均分，保留两位小数； 

第 $3$ 行： $N$ 个空格隔开的整数，为从高到低输出的 $N$ 个人的成绩。

## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int a[110],n,i,t;
    cin >> n;
    for (i=0;i<n;i++) cin >> a[i];

    // 解法一：不真正逆序，而是直接倒序输出
    // for (i=n-1;i>=0;i--) cout << a[i] << " ";

    // 解法二：实现真正的逆序，循环数组长度的一半，对称交换位置
    for(i = 0;i < n /2;i++) {
        t = a[i];
        a[i] = a[n-i-1];
        a[n-i-1] = t;
    }
    for(i = 0;i < n;i++) cout << a[i] << " ";
}
```
