# 1188 - 数字走向V

## 题目描述

输入整数 $N$ ，输出相应方阵。

## 输入

一个整数 $N$ 。（ $0 \lt N \le 10$ )

## 输出

一个方阵，每个数字的场宽为 $3$ 。
## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[10][10];
int main(){
    int n;
    cin >> n;
    int k = n * n;
    for(int i = 0; i < n; i++)
    {
        for(int j = 0; j < n; j++)
        {
            a[i][j] = k--;
        }

    }
    for(int i = 0; i < n; i++)
    {
        for(int j = 0; j < n; j++)
        {
            cout << setw(3) << a[i][j];
        }
        cout << endl;
    }

	return 0;
}
```
