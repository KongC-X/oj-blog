# 1033 - 判断奇偶数

## 题目描述

输入一个整数，判断是否为偶数。是输出 `y e s` ，否则输出`n o`。

## 输入

输入只有一行，包括 $1$ 个整数（该整数在 $1 \sim 10000$ 的范围内）。

## 输出

输出只有一行。（**注意输出格式**，具体请看下方提示）。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	int n;
    cin>>n;
    int i,j;
    //循环n+1行 
    for(i=1;i<=n+1;i++){
    	//每行输出 n-i+1个空格 
        for(j=1;j<=n-i+1;j++){
            cout<<" ";
        }
        //每行输出 2*i-1个* 
        for(j=1;j<=2*i-1;j++){
            cout<<"*";
        }
        cout<<endl;
    }
    //循环n行 
    for(i=1;i<=n;i++){
    	//每行输出i个空格 
        for(j=1;j<=i;j++){
            cout<<" ";
        }
        //每行输出 2*(n-i)+1个* 
        for(j=1;j<=2*(n-i)+1;j++){
            cout<<"*";
        }
        cout<<endl;
    }
	return 0;
}
```
