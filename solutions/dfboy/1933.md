# 1933 - 比赛组队

## 题目描述

有一场数学团体赛，学校要从 $n$ 个人中选出 $m$个人组队参赛，这 $m$ 个人中有 $k$ 对人本身在校内就是一个团队的，因此在一个团队的同学要么都选，要么都不选。

请你编程选出尽可能和 $m$ 接近的人数。

## 输入

第一行，三个正整数 $n,m,k$。

第 $2$ 至第 $k$ 行,每行 $2$个数，表示在校内就在一个团队的 $2$ 个人的编号（编号为 $1,2, \dots ,n$）。

数据范围：

$1≤n,m≤2 \times 10^4$。

## 输出

一行，与原来的 $m$ 尽可能接近的选出的人数。

如果有两种方案与 $m$ 的差的绝对值相等，选较小的一种。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
  思路：
  1. 用并查集将同一个团队的人合并，同时统计每个团队的人数 p[i]。
  2. 问题转化为：从这些团队中选若干个，使得总人数尽量接近 m。
     这是一个 0/1 背包问题，每个团队看作一个物品，其“重量”和“价值”都是团队人数。
  3. 背包容量设为 2*m，这样可以覆盖所有可能接近 m 的人数（包括超过 m 的情况）。
  4. 最后在 0 ~ 2*m 中找与 m 差值最小的 dp[i]，差值相同时选较小的那个。
*/

int n, m, k;
int fa[20010];           // 并查集父节点
int p[20010];            // p[i]：以 i 为根的团队人数，非根节点为 0
int dp[40010];           // dp[j]：容量为 j 时能获得的最大人数（0/1背包）

int find(int x) {
    if (x == fa[x]) return x;
    return fa[x] = find(fa[x]);
}

int main() {
    cin >> n >> m >> k;

    // 初始化并查集，每个人最初都是自己的根，团队人数为 1
    for (int i = 1; i <= n; i++) {
        fa[i] = i;
        p[i] = 1;
    }

    int x, y;
    // 读入 k 对关系，合并团队
    for (int i = 1; i <= k; i++) {
        cin >> x >> y;
        int fx = find(x);
        int fy = find(y);
        if (fx != fy) {
            fa[fx] = fy;          // 将 fx 的根指向 fy
            p[fy] += p[fx];       // 人数累加到新根
            p[fx] = 0;            // 旧根的人数清零
        }
    }

    // 0/1 背包：每个团队要么全选，要么不选
    // 背包容量设为 2*m，确保能容纳所有可能的人数
    for (int i = 1; i <= n; i++) {
        if (p[i] == 0) continue;     // 跳过非根节点
        int sz = p[i];               // 当前团队的人数
        for (int j = 2 * m; j >= sz; j--) {
            // 选或不选该团队，取人数较大者
            dp[j] = max(dp[j], dp[j - sz] + sz);
        }
    }

    // 寻找最接近 m 的结果
    int mi = INT_MAX;   // 记录当前最小差值
    int ans = 0;        // 记录最终答案（人数）
    for (int i = 0; i <= 2 * m; i++) {
        int diff = abs(dp[i] - m);
        // 差值更小，直接更新
        if (diff < mi) {
            mi = diff;
            ans = dp[i];
        }
        // 差值相等时，选择人数较小的方案
        else if (diff == mi && dp[i] < ans) {
            ans = dp[i];
        }
    }

    cout << ans << endl;
    return 0;
}
```
