# 4615 - 字符矩阵

## 题目描述

给定一个仅包含小写字母的字符串 S，用这些字符恰好排成一个 $n$ 行 $m$ 列的矩阵（$m \le n$），请找出所有符合要求的矩阵中最接近于正方形的那个矩阵。然后从第一列开始，逐列按照从上到下的顺序输出矩阵中的字符。

例如：`S = "abcdefgh"`。按要求 $m \le n$ 有如下两种矩阵：

最接近正方形的矩阵是第一种。从第一列开始，逐列按照从上到下的顺序输出矩阵中的字符，结果为：`aebfcgdh`。

## 输入

输入一个字符串，仅包含小写字母且长度不超过 $200$。

## 输出

请找出符合题目要求的最接近正方形的字符矩阵，从第一列开始，逐列按照从上到下的顺序输出矩阵中的字符。

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    string s;
    int n,m,l;
    cin >> s;
    l = s.size();
    n = 1;
    m = l;
    int min_diff = m - n;
    // 尝试所有可能的行数，找到最接近正方形的行数
    for(int i = 1;i <= sqrt(l);i++) {
        if(l % i == 0) {
            int j = l / i;
            int diff = abs(i - j);
            if(diff < min_diff) {
                n = i;
                m = j;
                min_diff = diff;
            }
        }
    }
    // 创建字符矩阵并填入字符串的字符
    char a[n][m];
    int k = 0;
    for(int i = 0;i < n;i++) {
        for(int j = 0;j < m;j++) {
            a[i][j] = s[k];
            k++;
        }
    }
    // 从上到下输出字符矩阵
    for(int j = 0;j < m;j++) {
        for(int i = 0;i < n;i++) {
            cout << a[i][j];
        }
    }
}
```
