# 1356 - 小兔子的最大活动面积

## 题目描述

用长 $n$ 米( $n \le 100$ 且 $n$ 是一个偶数)的篱笆围城长方形的生物园饲养小兔，要求生物园的长宽都是整数,请问怎样围才能使得小兔子的活动范围最大，输出最大面积？（9.2）

## 输入

一个整数$n$。

## 输出

最大面积。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
#include<cmath>
using namespace std;

int main() {
    int i,max = 0,n,s;
    cin >> n;
    for(i = 1;i <= n / 4;i++) {
        s = (n / 2 - i) * i;
        if(s > max) {
            max = s;
        }
    }
    cout << max << endl;
}
```
