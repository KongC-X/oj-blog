# 1356 - 小兔子的最大活动面积

## 题目描述

用长 $n$ 米( $n \le 100$ 且 $n$ 是一个偶数)的篱笆围城长方形的生物园饲养小兔，要求生物园的长宽都是整数,请问怎样围才能使得小兔子的活动范围最大，输出最大面积？（9.2）

## 输入

一个整数$n$。

## 输出

最大面积。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
	 //从2开始找n的因⼦
	 int n,i = 2;
	 cin>>n;
	 while(n != 1){
		//如果i是n的因⼦
      	if(n % i == 0){
			 cout<<i<<endl;
 		     n = n / i;
		}else{
			 i++; //看下⼀个数
 		}
 	}
}
```
