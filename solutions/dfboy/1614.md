# 1614 - 小华的零花钱

## 题目描述

小明和小华去购买课外书，小明带了 $x$ 元（ $x$ 是一个三位整数），小明问小华带了多少钱，小华说自己带的钱只有小明带的金额的个位和百位的和那么多，请你编程帮助小华计算一下，他带了多少零花钱？

比如，假设小明带了 $689$ 元，那么小华带的金额就是 $ 6 + 9 = 15$ 元。

## 输入

一个整数 $x$ 代表小明的零花钱的金额，$x$ 是一个三位的整数。

## 输出

小华的零花钱的金额。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	//定义变量x代表小明的零花钱金额 
	//g,b分别代表个位和百位 
	int x,g,b; 
	//输入x
	cin>>x;
	//对x拆位求解个位和百位
	g = x % 10;
	b = x/100;
	//对个位和百位求和并输出结果 
	cout<<g+b; 
	 
	return 0;
}
```
