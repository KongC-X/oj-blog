# 1363 - 数字矩形(2)

## 题目描述

从键盘读入一个整数 $n$，输出如下图形

如：$n=3$，输出

```
`123
123
123
`
```

如：$n = 5$，输出

```
`12345
12345
12345
12345
12345
`
```

## 输入

一个整数 $n（n \lt 10$）

## 输出

输出 $n$ 行的图形。
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
 
int main() {
    int n;
    cin>>n;
    int i,j;
    //循环n行 
    for(i=1;i<=n;i++){
    	//每行循环n次 
        for(j=1;j<=n;j++){
            cout<<j;
        }
        cout<<endl;
    }
    return 0;
}
```
