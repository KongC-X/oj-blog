# 1341 - 银行存款问题

## 题目描述

亮亮把 $n$ 元按照 $m$ 年期整存存入银行，按照目前银行的年利率，请问到期后亮亮可以连本带息总共拿到多少钱？（ $6.1.98$ ） 

存期（整存整取） 

年利率 

$1$年 

$3.25\%$ 

 $2$ 年 

 $3.75 \%$  

$3$年$ \sim 4$ 年 

$4.25\%$ 

 $5$ 年及 $5$ 年以上 

 $4.75\%$

## 输入

两个整数 $n$ 和 $m$ 。

## 输出

一个小数，代表亮亮 $m$年后一共可以拿到的金额（保留 $1$ 位小数）。

## 解题思路

## AC代码

```cpp
#include<iostream>
#include<iomanip>
using namespace std;
int m,n;
double sum;
int a[30]; 
int main()
{
	cin>>m>>n;
	for(int i=1;i<=n;i++){
		cin>>a[i];
		sum+=a[i];
	}
	sum=sum*1.0/n*m;
	cout<<fixed<<setprecision(1)<<sum;
}
```
