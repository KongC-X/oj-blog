# 1844 - 判定字符位置

## 题目描述

返回给定字符串 $s$ 中元音字母的首次出现位置。英语元音字母只有 `a`、`e`、`i`、`o`、`u` 五个。

若字符串中没有元音字母，则输出 $0$ 。

只考虑小写的情况。

## 输入

输入一个仅含小写字母的字符串，长度不超过 $20$ 位。

## 输出

按题意输出位置或输出 $0$ 。
## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
string s;
int main() {
	cin>>s;
	bool f = false;//假设没有
	for(int i=0; i<s.size(); i++) {
		if(s[i]=='a'||s[i]=='e'||s[i]=='i'||s[i]=='o'||s[i]=='u') {
			cout<<i+1;
			f = true;
			break;
		}
	}

	if(f==false) cout<<0;

	return 0;
}
```
