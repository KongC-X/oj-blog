# 1014 - 编程求1+1/2+1/3+...+1/n

## 题目描述

编程求 $1+1/2+1/3+ \dots +1/n$ 。

## 输入

输入一行，只有一个整数 $n(1 \le n \le 200)$ 。

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个实数。(保留 $3$ 位小数) 。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

const int N = 2e5 + 10;
int a[N];
int n, t;
long long ans;

// 左边界
int findLower(int target) {
    int left = 1, right = n + 1;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (a[mid] >= target) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }
    return left;
}

// 右边界
int findUpper(int target) {
    int left = 1, right = n + 1;
    while (left < right) {
        int mid = left + (right - left) / 2;
        if (a[mid] > target) {
            right = mid;
        } else {
            left = mid + 1;
        }
    }
    return left;
}

int main() {
    scanf("%d%d", &n, &t);
    
    for (int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }
    
    sort(a + 1, a + n + 1);
    
    for (int i = 1; i <= n; i++) {
        int target = t + a[i]; // 找 a[i] + T 在数组里出现了多少次
        int s = findLower(target); // 找到第一个等于 a[i]+T 的位置 L
        int e = findUpper(target); // 找到第一个大于 a[i]+T 的位置 R
        ans += e - s; //  a[i]+T 出现的次数就是 R - L
    } 
    
    cout << ans;
    return 0;
}
```
