# 1793 - 采购水果

## 题目描述

食堂采购员用 $n$ 元去水果市场采购苹果和梨，已知苹果 $x$ 元/斤，梨 $y$ 元/斤，要求每种水果都至少购买到 $10$ 斤或 $10$ 斤以上，且要把 $n$ 元花完，请问有多少种不同的买法？

## 输入

三个整数 $n$、$x$、$y$ ，分别代表总金额、苹果的单价和梨的单价。

## 输出

一个整数，代表购买方案的总数。

## 解题思路

## AC代码
## AC代码

```cpp
# include <iostream>
using namespace std;

int main(){
    int i,j,n,x,y,s = 0;
    cin >> n >> x >> y;
    for(i = 10;i <= n/x;i++) {
        for(j = 10;j <= n/y;j++) {
            if(i* x + j * y == n) {
                s++;
            }
        }
    }
    cout << s << endl;
}
```
