# 1793 - 采购水果

## 题目描述

食堂采购员用 $n$ 元去水果市场采购苹果和梨，已知苹果 $x$ 元/斤，梨 $y$ 元/斤，要求每种水果都至少购买到 $10$ 斤或 $10$ 斤以上，且要把 $n$ 元花完，请问有多少种不同的买法？

## 输入

三个整数 $n$、$x$、$y$ ，分别代表总金额、苹果的单价和梨的单价。

## 输出

一个整数，代表购买方案的总数。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

/*
思路：
准备一个栈(在栈底存储一个*,防止栈空),存储左括号，遇到左括号，入栈
遇到右括号：判断栈顶元素是否是配对的左括号
如果是，弹出栈顶元素
如果不是，结束判断，得到结论，括号不匹配
循环结束，栈的大小应该是1
*/

stack<char> s;
string t;
int i;
int main() {
	cin >> t;
	s.push('*'); // 栈底放一个*，防止栈空
	for (i = 0; i < t.size(); i++) {
		if (t[i] == '(' || t[i] == '['){
			// 如果是左括号，入栈
			s.push(t[i]);
		} else {
			// 说明遇到右括号
			if(t[i] == ')' && s.top() == '(' || t[i] == ']' && s.top() == '[') {
				// 如果栈顶元素是配对的左括号，弹出栈顶元素
				s.pop();
			} else {
				// 否则，括号不匹配
				cout << "no" << endl;
				return 0;
			}
		}
	}
	// 如果栈大小是1，说明括号匹配
	if (s.size() == 1) {
		cout << "yes" << endl;
	} else {
		// 否则，括号不匹配
		cout << "no" << endl;	
	}
}
```
