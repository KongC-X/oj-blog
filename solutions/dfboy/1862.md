# 1862 - 友好数

## 题目描述

有两个整数，如果每个整数的约数和（除了它本身以外）等于对方，我们就称这对数是友好的。例如：

$9$ 的约数和有：$1+3=4$

$4$ 的约数和有：$1+2=3$

所以 $9$ 和 $4$ 不是友好的。

$220$的约数和有：$1 、2、 4、 5 、10 、11、 20、 22、 44 、55、 110=284$

$284$ 的约数和有：$1、 2 、4 、71、 142=220$
所以 $220$ 和 $284$ 是友好的。
编写程序，判断两个数是否是友好数。

## 输入

一行，两个整数，由空格分隔（两个整数都小于 $10000$ ）

## 输出

如果是友好数，输出"`yes`"，否则输出"`no`"，注意不包含引号。

## 解题思路

## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int a[110],n,i,x,t;
    cin >> x;
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> a[i];
    }
    for(i = 0;i < n;i++) {
        if(a[i] > x) {  // 找到第一个大于x的位置并标记
            t = i;
            break;
        }
    }
    for(i = n - 1;i >= t;i--) {  // 从标记处开始移动元素
        a[i + 1] = a[i];
    }
    a[t] = x;
    for (i=0;i<n+1;i++) cout << a[i] << " ";
}
```
