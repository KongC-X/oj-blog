# 1125 - 删除字符串中间的*

## 题目描述

输入一个字符串，将串前和串后的`*`保留，而将中间的`*`删除。

## 输入

一个含`*`的字符串。

## 输出

删除了串中的`*`的字符串。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int a[1010];
int n,c;
int main() {
	cin>>n;
	for(int i = 1;i <= n;i++) cin>>a[i];
	cin>>c;
	
	sort(a+1,a+n+1); // 从小到大排序
	
    // 设置两个指针，一个指向开头，一个指向结尾
	int l = 1, r = n, ans = 0;
	while(l <= r){
		if(a[l] + a[r] <= c){
			l++;
			r--;
		}else{
			r--;
		}
        ans++;
	}
	cout<<ans;
	return 0;
}
```
