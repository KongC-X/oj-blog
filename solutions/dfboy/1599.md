# 1599 - 米老鼠偷糖果

## 题目描述

米老鼠发现了厨房放了 $n$ 颗糖果，它一次可以背走 $a$ 颗，请问米老鼠背了 $x$ 次之后还剩多少颗？（假设 $x$ 次之后一定有糖果剩下）。

## 输入

三个整数 $n、a、x$ 分别代表总共有 $n$ 颗糖果，米老鼠一次背走 $a$ 颗糖果，总共背了 $x$ 次。

## 输出

一个整数，代表剩余的糖果数量。

## 解题思路

## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int a[100][100], b[100][100],c[100][100];
    int n, m, i, j;
    cin >> n >> m; // 读取矩阵的行数n和列数m

    // 读取矩阵 A
    for (i = 0; i < n; i++) {
        for (j = 0; j < m; j++) {
            cin >> a[i][j];
        }
    }
    // 读取矩阵 B
    for (i = 0; i < n; i++) {
        for (j = 0; j < m; j++) {
            cin >> b[i][j];
        }
    }
    // 计算矩阵 A 和 B 的和
    for (i = 0; i < n; i++) {
        for (j = 0; j < m; j++) {
            c[i][j] = a[i][j] + b[i][j];
            cout << c[i][j] << " ";
        }
        cout << endl;
    }
}
```
