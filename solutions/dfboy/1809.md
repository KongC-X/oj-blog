# 1809 - 最贵商品和最便宜商品之差

## 题目描述

小明去超市买商品，买了 $N$ 件，每件商品的价格都是整数，小明想知道这 $N$ 件商品中，最贵商品和最便宜商品之间相差多少元？

请你编写程序帮忙小明计算。

## 输入

第 $1$ 行输入一个整数 $n$（$n \le 1000$）。

第 $2$ 行有 $n$ 个整数。

## 输出

输出一个整数，代表差值。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

/*
求数组的最大数和最小数的差 
*/ 
//ma 代表最大数，mi 代表最小数 
int a[1100],n,ma,mi; 

int main() {
	cin>>n;
	for(int i = 0;i < n;i++){
		cin>>a[i];
	}
	
	ma = a[0];// 假设第 1 个数最大
	mi = a[ 0];
	
	// 循环剩余的元素，打擂台找最大、最小数 
	for(int i = 1;i < n;i++){
		if(a[i] > ma){
			ma = a[i];
		} 
		
		if(a[i] < mi){
			mi = a[i];
		}
	} 
	
	cout<<ma - mi;
	return 0;
}
```
