# 1809 - 最贵商品和最便宜商品之差

## 题目描述

小明去超市买商品，买了 $N$ 件，每件商品的价格都是整数，小明想知道这 $N$ 件商品中，最贵商品和最便宜商品之间相差多少元？

请你编写程序帮忙小明计算。

## 输入

第 $1$ 行输入一个整数 $n$（$n \le 1000$）。

第 $2$ 行有 $n$ 个整数。

## 输出

输出一个整数，代表差值。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
#include<iostream>
using namespace std;

// 解法一：利用原数组求差分数组
const int N = 100010;
int a[N], b[N]; // a是原数组，b是差分数组
int n,k,l,r,p;

int main() {
    cin >> n >> k;
    for(int i = 1; i <= n; i++) {
        cin >> a[i];
        b[i] = a[i] - a[i-1]; // 求差分数组
    }
    // k次操作
    for(int i = 1; i <= k; i++) {
        cin >> l >> r >> p;
        b[l] = b[l] + p;
        b[r+1] = b[r+1] - p;
    }
    // 求b数组的前缀和，就是a数组做了k次操作后的结果
    for(int i = 1; i <= n; i++) {
        a[i] = b[i] + a[i-1];
        // b[i] = b[i - 1] + b[i]; // 也可直接在b数组上求前缀和
        cout << a[i] << " ";
    }
}


// 解法二：读入时直接求差分数组
const int N = 100010;
int a[N], b[N]; // a是原数组，b是差分数组
int n,k,l,r,p;

int main() {
    cin >> n >> k;
    for(int i = 1; i <= n; i++) {
        cin >> p; // 读入时直接求差分数组
        // 求差分数组
        b[i] = b[i] + p;
        b[i+1] = b[i+1] - p;
    }
    // k次操作
    for(int i = 1; i <= k; i++) {
        cin >> l >> r >> p;
        b[l] = b[l] + p;
        b[r+1] = b[r+1] - p;
    }
    // 求b数组的前缀和，就是a数组做了k次操作后的结果
    for(int i = 1; i <= n; i++) {
        b[i] = b[i - 1] + b[i];
        cout << b[i] << " ";
    }
}
```
