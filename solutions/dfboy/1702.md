# 1702 - 四位数的差

## 题目描述

输入一个四位数，将这个数各位数字倒序合成一个新数，输出原数和新数的差。

## 输入

一行，一个整数。

## 输出

一行，一个整数。

## 解题思路
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	//定义变量x作为输入的四位整数 
	//q,b,s,g分别作为千位,百位,十位,个位 
	int x,q,b,s,g;
	//输入x
	cin>>x;
	//对x进行拆位
	q = x / 1000;
	b = x / 100 % 10;
	s = x % 100 / 10;
	g = x % 10; 
	//计算原数-新数 
	cout<<x - (q + b*10 + s*100 + g*1000); 
	return 0;
}
```
