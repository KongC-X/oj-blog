# 1211 - 数组元素的插入

## 题目描述

在一个数组的第 $x$ 个位置插入一个新的数 $y$。

## 输入

输入有四行。

第一行有一个整数 $n$ ($5 ≤ n ≤ 10$）。

第二行有 $n$ 个整数，用空格隔开。

第三行有一个整数 $x$，为要插入的位置。

第四行有一个整数 $y$，为要插入的整数。

## 输出

更新后的数组。

## 解题思路

## AC代码

```cpp
#include<iostream>
using namespace std;
int a[1010];
int main() {
    int n,i,m,k = 0;
    cin >> n;
    for(i = 0; i < n; i++) {
        cin >> m;
        bool flag = false; // 标记元素是否出现过
        for(int j = 0; j < k; j++) {
            if(a[j] == m) {
                flag = true;
                break;
            }    
        }
        if(flag == false) {
            a[k] = m;
            k++;
        }
    }
    cout << k << endl;
    // 排序
    for(i = 0;i < k - 1; i++) {
        for(int j = 0; j < k - i - 1; j++) {
            if(a[j] > a[j + 1]) {
                int temp = a[j];
                a[j] = a[j + 1];
                a[j + 1] = temp;
            }
        }
    }
    for(i = 0;i < k; i++) {
        cout << a[i] << endl;
    }
}
```
