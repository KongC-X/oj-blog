# 1723 - 奇偶数选大王

## 题目描述

在数字王国中，有值为 $1 \sim n$ 之间的整数，有奇数也有偶数；他们想分别在奇数和偶数中选出各自的大王，也就是选出奇数和偶数的最大数作为奇数大王和偶数大王。

请你编程帮助数字王国选出奇数和偶数的大王，并将所有的数字从小到大输出。

比如，假设输入 $5$ 个数，分别是 $3$ $8$ $9$ $1$ $6$ ，那么奇数大王（最大数）是 $9$ ，偶数大王（最大数）是 $8$ ，因此输出奇数大王和偶数大王以及所有数按照由小到大排序如下：

```
`9 8
1 3 6 8 9
`
```

## 输入

输入有 $2$ 行；

第 $1$ 行有一个整数 $n$（$n$ 是 $10 \sim 1000$ 之间的整数），代表数字王国中数字的总个数；

第 $2$ 行有 $n$ 个整数（这些整数值在 $1 \sim 1000000$ 之间，测试数据保证有奇数，也有偶数），数字之间用空格隔开。

## 输出

第 $1$ 行输出 $2$ 个整数，分别是奇数大王和偶数大王，两个数之间用空格隔开；

第 $2$ 行将 $n$ 个整数从小到大排序后输出，数与数之间用空格隔开。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
dp[i][j]：代表有i个物品，背包容量为j时，能够存储的最大价值
对于第i个物品：
情况一：背包容量j<物品重量w[j]，放不下，能够存放的价值dp[i-1][j]
情况二：背包容量j>=物品重量w[j]，放得下
能够得到的最大价值 = max(dp[i-1][j],v[i]+dp[i-1][j-w[i]])
*/ 
int dp[110][20010];
int n,w[110],v[110],maxw,i,j;

int main(){
	cin>>maxw>>n;
	//读入每个物品的重量和价值
	for(i = 1;i <= n;i++){
		cin>>w[i]>>v[i];
	} 
	// 递推求dp数组
	for(i = 1;i <= n;i++){
		//循环背包容量从1~maxw
		for(j = 1;j <= maxw;j++){
			//如果放不下:背包容量<物品重量 
			if(j < w[i]){
				dp[i][j] = dp[i-1][j]; 
			}else{
				//放得下，就看放进来价值高，还是不放价值高
				dp[i][j] = max(dp[i-1][j],v[i]+dp[i-1][j-w[i]]);
			} 
		} 
	} 	
	//输出n个物品，背包容量为maxw的情况下最大价值 
	cout<<dp[n][maxw];
}
```
