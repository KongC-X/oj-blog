# 1214 - 在最大数后面插入一个数

## 题目描述

在一个不重复数组的最大数的后面插入一个新的数 $y$。

## 输入

三行： 

第一行有一个整数 $n$  ( $5 \le  n  \le  100$ ）；

第二行有 $n$ 个整数；

第三行有一个整数 $y$，为要插入的数。

## 输出

更新后的数组。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

string sig, hrd;

int main(){
	cin >> sig >> hrd;
	int l = hrd.size(), ll = 0, cnt = 0;
	while (ll != l) {
		++cnt;
		for (int i = 0; i < sig.size(); ++i)
			if (sig[i] == hrd[ll])
				ll++;//听到当前字母就跳到下一个
	}
	cout << cnt << endl;
	return 0;
}
```
