# 1607 - 两位数运算

## 题目描述

小丽在编程课上学会了拆位运算，她已经可以拆出一个两位整数的十位和个位了，她想知道这个整数的十位 $/$ 个位的结果是多少，请编程帮她实现？（请注意，计算结果要保留 $1$ 位小数）

## 输入

输入一个两位的正整数 $n$，且 $n$ 的个位一定不为 $0$。

## 输出

输出这个两位正整数十位除以个位的计算结果，结果保留 $1$ 位小数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

string s1,s2;
int a[250],b[250],c[250];
int i,p,len,x;
int main() {
    cin >> s1 >> x;
    // 逆序存储
    for(i = s1.size() - 1;i >= 0;i--) {
        a[i] = s1[s1.size() - 1 - i] - '0';
    }

    // 逐位相乘
    for(i = 0;i < s1.size();i++) {
        c[i] = a[i] * x;
    }
    
    // 处理进位,这里注意：该题中的乘法最多多出四位，所以c数组长度为s1.size() + 4
    for(i = 0;i < s1.size() + 4;i++) {
        if(c[i] >= 10) {
            c[i + 1] += c[i] / 10;
            c[i] %= 10;
        }
    }
    // 去除前导0
    for(i = s1.size() + 4 - 1;i >= 0;i--) {
        if(c[i] != 0) {
            p = i;
            break;
        }
    }
    // 逆序输出结果
    for(i = p;i >= 0;i--){
        cout << c[i];
    }
}
```
