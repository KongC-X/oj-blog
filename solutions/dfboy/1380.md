# 1380 - 小X学游泳

## 题目描述

小 X 想要学游泳。

这天，小 X 来到了游泳池，发现游泳池可以用 $N$ 行 $M$ 列的格子来表示，每个格子的面积都是 $1$ ，且格子内水深相同。

由于小 X 刚刚入门，他只能在水深相同的地方游泳。为此，他把整个游泳池看成若干片区域，如果两个格子相邻（上下左右四个方向）且水深相同，他就认为它们属于同一片区域。

小X想知道最大的一片区域面积是多少，希望你帮帮他。

## 输入

第一行包含用一个空格隔开的两个整数 $N,M$。（$1≤N,M≤100$）。

接下来 $N$ 行，每行包含 $M$ 个 $1$ 到 $9$ 的数字，表示每个格子的水深。

## 输出

第一行包含一个整数，表示最大的一片区域面积。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n,m;
int q[10010][3];
int h,t;
int fx[5] = {0,0,1,0,-1};
int fy[5] = {0,1,0,-1,0};
char a[110][110];
bool f[110][110];
int cnt,sum,ma;

//从x,y开始将相邻的能走到相同的值标记掉
void bfs(int x,int y){
	h = 1;
	t = 1;
	q[1][1] = x;
	q[1][2] = y;
	//走过标记
	f[x][y] = true;
	int tx,ty;
	while(h <= t){
		for(int i = 1;i <= 4;i++){
			tx = q[h][1] + fx[i];
			ty = q[h][2] + fy[i];
			//没有出边界，没走过，值相同
			if(a[tx][ty]!='\0' && a[tx][ty]==a[x][y] && !f[tx][ty]){
				t++;
				q[t][1] = tx;
				q[t][2] = ty;
				//走过标记
				f[tx][ty] = true;
			}
		}

		h++;
	}

	ma = max(ma,t);//连通块面积求最大
}

int main() {
	cin>>n>>m;
	for(int i = 1;i <= n;i++){
		for(int j = 1;j <= m;j++){
			cin>>a[i][j];
		}
	}

	//从每个*开始bfs
	for(int i = 1;i <= n;i++){
		for(int j = 1;j <= m;j++){
            bfs(i,j);
		}
	}

	cout<<ma;
	return 0;
}
```
