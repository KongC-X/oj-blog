# 1495 - 求因子数量

## 题目描述

从键盘读入一个整数 $n$（ $n \le 100$ ），请求出 $1 \sim n$ 的每个数的因子个数（求因子个数时，不含 $1$ 和自己，比如 $10$ 只有 $2$ 个因子），每行一个打印出来。

## 输入

一个整数 $n$；

## 输出

$n$ 行，每行一个整数，代表了每个整数的因子个数。
## AC代码
## AC代码

```cpp
#include <iostream>
using namespace std;

int main() {
	int n,i,j,s = 0;
	cin >> n;
	for(i = 1;i <= n;i++) {
		for(j = 2;j < i;j++) {
			if (i % j == 0) {
				s++;
			}
		}
		cout << s << endl;
		s = 0;
	}
}
```
