# 2292 - 计算乘积

## 题目描述

给定两个数 $a，b$，计算它们的乘积。

## 输入

一行两个整数 $a、b$，以空格分隔。（ $0 \lt a$ , $b \lt 10 $8）。

## 输出

输出一个整数，表示 $a、b$ 的乘积
## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main(){
	long long a,b;
	cin>>a>>b;
	cout<<a*b;
	return 0;
}
```
