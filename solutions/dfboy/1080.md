# 1080 - 质因子

## 题目描述

任意输入一正整数 $N$ ，求出它的所有质因子。如：$10＝2 \times 5$，$20＝2 \times 2 \times 5$。

## 输入

输入只有一行，包括 $1$ 个整数 $n$ ($1 \le n \le 32768$)。

## 输出

输出若干行，按从小到大的顺序给出这个数的所有质因子，每行一个。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
 //从2开始找n的因⼦
 int n,i = 2;
 cin>>n;
 while(n != 1){
 //如果i是n的因⼦
      if(n % i == 0){
 cout<<i<<endl;
 n = n / i;
 }else{
i++; //看下⼀个数
 }
 }
 return 0;
}
```
