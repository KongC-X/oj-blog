# 1738 - 胜负对决

## 题目描述

有一组数本来都是队友，但是一天它们在一个问题上出现分歧，于是他们分成了 $2$ 派各自为政，第奇数个数分一队叫`KING`，该队的气势值为该队所有数的和。第偶数个数分另一队`WIN`，该队的气势值为该队所有数的和。

请分别求出`KING`队和`WIN`队的气势值，并输出哪一队的气势值更高（如果两队气势值相同，也输出`KING`）？

比如：有一组数为 $2$ $8$ $1$ $3$ $6$ ，那么`KING`队气势值 =  $2 + 1 + 6 = 9$ ，而`WIN`队气势值 =  $8 + 3 = 11$ ，因此输出结果如下：

`KING`  $9$ 

`WIN`  $11$ 

`WIN`

## 输入

第一行输入 $n$ （ $n$ 是 $1 \sim 1000$ 之间的整数）。

第二行输入 $n$ 个数（每个数都是 $1 \sim 100$ 之间的数）。

## 输出

第一行先输出队名`KING`，再空一格输出`KING`队的气势值。

第二行先输出队名`WIN`，再空一格输出`WIN`队的气势值。

第三行输出气势值更高的队名，如果两队气势值一样高，也输出`KING`。

```cpp
#include<bits/stdc++.h>
#include<iostream>
using namespace std;

int a[1010],n,i,s1,s2;
int main() {
    cin >> n;
    for(i=1;i<=n;i++){
        cin >> a[i];
        if(i % 2 == 1) {
            s1 += a[i];
        } else {
            s2 += a[i];
        }
    }
    cout << "KING " << s1 << endl;
    cout << "WIN " << s2 << endl;
    if(s1 >= s2) {
        cout << "KING";
    } else {
        cout << "WIN";
    }
}
```
