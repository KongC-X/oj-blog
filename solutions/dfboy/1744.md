# 1744 - 纯粹的四位奇数

## 题目描述

纯粹奇数指的是一个数的各个位都是奇数的数，比如：$1357$ ；请编程求出 $1000$ ~ $n$ 中，所有的四位的纯粹奇数的和是多少？

## 输入

一个整数 $n$（ $n$ 为 $1000$~$9999$ 之间的整数）；

## 输出

一个整数，代表 $1000$~$n$ 中所有四位纯粹奇数的和。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    char s[110];
    int i,k = 0;
    gets(s);
    for(i = 0;i < strlen(s);i++) {
        if(s[i] != ' ' && (s[i+1] == ' ' || s[i + 1] == '\0')) {
            k++;
        }
    }
    cout << k << endl;
}
```
