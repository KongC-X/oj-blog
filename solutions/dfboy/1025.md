# 1025 - 兑换硬币

## 题目描述

用一张一元票换 $1$ 分、$2$ 分和 $5$ 分的硬币，每种至少一枚， 
问有几种换法？

## 输入

无

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。
## AC代码
## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int i,j,k,s = 0;
    for(i = 1;i <= 100/1;i++){
        for(j = 1;j <= 100/2;j++){
            for(k = 1;k <= 100/5;k++) {
                if(i * 1 + j * 2 + k * 5 == 100) {
                    s++;
                }
            }
        }
    }
    cout << s << endl;
    return 0;
}
```
