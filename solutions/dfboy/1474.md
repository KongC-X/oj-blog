# 1474 - FJ的字符串

## 题目描述

问题描述： 

FJ在沙盘上写了这样一些字符串： 

```
`A1  =  “A” 
A2  =  “ABA” 
A3  =  “ABACABA” 
A4  =  “ABACABADABACABA”
`
```

$\dots$  

$\dots$

你能找出其中的规律并写所有的数列 $AN$ 吗？ 

输入格式

仅有一个数：$N  \le  26$。 

输出格式

请输出相应的字符串 $AN$，以一个换行符结束。输出中不得含有多余的空格或换行、回车符。

## 输入

$3$ 。

## 输出

$ ABACABA $。
## AC代码

```cpp
#include <iostream>
using namespace std;

// 递归输出 A_k，其中第 k 个字母为 c（c = 'A' + k - 1）
void print(int k, char c) {
    if (k == 1) {
        cout << 'A';
        return;
    }
    char prev = c - 1;          // 第 k-1 个字母
    print(k - 1, prev);         // 输出 A_{k-1}
    cout << c;                  // 输出中间字母
    print(k - 1, prev);         // 再次输出 A_{k-1}
}

int main() {
    int n;
    cin >> n;
    print(n, 'A' + n - 1);
    cout << endl;
    return 0;
}
```
