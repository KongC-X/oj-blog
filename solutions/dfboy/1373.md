# 1373 - 删数问题

## 题目描述

键盘输入一个高精度的正整数 $n$（ $n \le 1000$ 位），去掉其中任意 $s$ 个数字后剩下的数字按原左右顺序将组成一个新的正整数。编程对给定的 $n$ 和 $s$ （$s \lt n$ 的位数，且**数据保证 $n$ 删除 $s$ 个数之后不为 $0$ **，还是一个非 $0$ 的整数），寻找一种方案，使得剩下的数字组成的数最小。

例如：$153748$ 要删除 $2$ 个数，使得剩下的数字最小，应当删除 $5$ 和 $7$，得到 $1348$ 。（注意：$1087$ 如果要删除 $1$ 个数，删除 $1$ 结果是最小的，得到结果 $87$ ）。

## 输入

第一行是一个高精度整数 $n$；

第二行是需要删除的位数 $s$；

## 输出

最后剩下的最小数。

```cpp
#include <iostream>
using namespace std;

string s;
int n,a[1010],k;
int main() {
    cin >> s >> n;
    int l = s.size();
    // 把字符串转为数组
    for(int i =0;i < l;i++) {
        a[i] = s[i] - '0';
    }
    // 第一层循环为删几次
    for(int i = 1;i <= n;i++) {
        // 第二层循环为删哪个数,优先删大的数
        for(int j = 0;j < l;j++) {
            if(a[j] > a[j + 1]) {
                // 如果比后面的数大，则删掉
                for(int k = j;k < l;k++) {
                    a[k] = a[k + 1];
                }
                l--;
                break;
            }
        }
    }
    // 去除前导0
    int i = 0;
    while(a[i] == 0) {
        i++;
        k++;
    }
    // 输出结果
    for(int i = k;i < l;i++) {
        cout << a[i];
    }
}
```
