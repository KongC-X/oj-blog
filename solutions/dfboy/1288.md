# 1288 - 正整数n转换为8进制

## 题目描述

请将一个整数 $n$（$n \le 10^{12}$）的整数转换为 $8$ 进制！

## 输入

整数 $n$ 。

## 输出

$n$ 的 $8$ 进制对应的数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int n,i,a[100];
int main() {
    cin >> n;
    for(i = 1;i <= n;i++){
        cin >> a[i];
    }
    sort(a+1,a+n+1);
    for(i = 1;i <= n;i+=2){
        cout << a[i] << " ";
    }
    for(i = n-1;i >= 1;i-=2){
        cout << a[i] << " ";
    }
}
```
