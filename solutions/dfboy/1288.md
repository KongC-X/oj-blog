# 1288 - 正整数n转换为8进制

## 题目描述

请将一个整数 $n$（$n \le 10^{12}$）的整数转换为 $8$ 进制！

## 输入

整数 $n$ 。

## 输出

$n$ 的 $8$ 进制对应的数。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s;
    long long n,x;
    char c;
    cin >> n;
    // 短除法
    while(n != 0) {
        x = n % 8;
        c = x + '0'; // 这里要先把数字转成字符才能存入字符串
        s = c + s;
        n = n / 8; // 记得把n除8
    }
    if(s == "") {
        cout << 0 << endl; // 考虑n==0的情况
    } else {
        cout << s << endl;
    }
}
```
