# 1360 - 卒的遍历

## 题目描述

在一张 $n \times m$ 的棋盘上（如 $6$ 行 $7$ 列）的最左上角 $(1,1)$ 的位置有一个卒。该卒**只能向下或者向右走**，且卒采取的策略是**先向下**，**下边走到头就向右**，请问从 $(1,1)$ 点走到 $(n,m)$ 点可以怎样走，输出这些走法。

## 输入

两个整数 $n，m$ 代表棋盘大小（$3≤n≤8,3≤m≤8$）

## 输出

卒的行走路线。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

//判断字符是字母
bool zimu(char c) {
    if(c >= 'a' && c <= 'z' || c >= 'A' && c <= 'Z') return true;
    else return false;
}

//判断字符是数字
bool shuzi(char c) {
    if(c >= '0' && c <= '9') return true;
    else return false;
}

int main() {
    char s[30];
    gets(s); //注意，本题可能有空格，不能cin读入
    bool f = true;//假设合法
    //1、变量名含有除了字母数字下划线以外的字符
    for(int i = 0; i < strlen(s); i++) {
        if((zimu(s[i]) || shuzi(s[i]) || s[i] == '_') == false) {
            f = false;
            break;
        }
    }
    //2、以数字开头
    if(shuzi(s[0])) {
        f = false;
    }
    //3、有4个关键词
    if(strcmp(s, "int") == 0 || strcmp(s, "double") == 0 || strcmp(s, "cin") == 0 || strcmp(s, "cout") == 0) {
        f = false;
    }
    f ? cout << "yes" : cout << "no";
}
```
