# 1360 - 卒的遍历

## 题目描述

在一张 $n \times m$ 的棋盘上（如 $6$ 行 $7$ 列）的最左上角 $(1,1)$ 的位置有一个卒。该卒**只能向下或者向右走**，且卒采取的策略是**先向下**，**下边走到头就向右**，请问从 $(1,1)$ 点走到 $(n,m)$ 点可以怎样走，输出这些走法。

## 输入

两个整数 $n，m$ 代表棋盘大小（$3≤n≤8,3≤m≤8$）

## 输出

卒的行走路线。

```cpp
#include <iostream>
#include <iomanip>
#include <bits/stdc++.h>
using namespace std;
int n,m,c; 
int r[20][3]; // 记录路径
// 本题要求按照下右的顺序
int fx[3] = {0,1,0};
int fy[3] = {0,0,1};
// 打印函数，k是路径数组的下标
void print(int k) {
    c++;
    cout << c << ":";
    for(int i = 1;i < k;i++) {
        cout << r[i][1] << "," << r[i][2] << "->";
    }
    // 最后到n，m点，单独打印输出
    cout << n << "," << m << endl;
}
// 深度优先搜索，k是路径数组的下标
void dfs(int x,int y,int k) {
    // 记录探索到的点的坐标
    r[k][1] = x;
    r[k][2] = y;
    // 如果xy是终点了，就打印路径
    if(x == n && y == m) {
        print(k);
        // 停止递归函数，到了终点打印，就不需要递归了
        return;
    }
    int tx,ty;
    for(int i = 1;i <= 2;i++) {
        tx = x + fx[i];
        ty = y + fy[i];
        if(tx >= 1 && tx <= n && ty >= 1 && ty <= m) {
            dfs(tx,ty,k+1);
        }
    }
}
int main(){
    cin >> n >> m;
    dfs(1,1,1);
}
```
