# 1449 - 求满足条件的数的和

## 题目描述

小明同学想找出这样的数：能同时被 $2$ 、$3$ 、$5$ 、$7$ 中 $2$ 个及 $2$个以上的数整除的数，比如 $6$、$30$ 、$210$ 等。

请你编程帮助小明找出 $1 \sim n$ 中满足条件的数的总和是多少？

## 输入

个整数 $n$ ；（$n \le 9999$）

## 输出

一个整数，代表 $1 \le n$ 中满足条件的整数的总和；

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int q[250010][4];//队列
int n,m,c,h,t;
char a[510][510];
int fx[5] = {0,0,1,0,-1};
int fy[5] = {0,1,0,-1,0};
int s1,s2,e1,e2;

int main() {
	cin>>m>>n>>c;
	for(int i = 1; i <= n; i++) {
		for(int j = 1; j <= m; j++) {
			cin>>a[i][j];
			if(a[i][j] == 'S') {
				s1 = i;
				s2 = j;
				a[i][j] = '.';
			} else if(a[i][j] == 'E') {
				e1 = i;
				e2 = j;
				a[i][j] = '.';
			}

		}
	}

	//bfs：初始化 
	h = 1;
	t = 1;
	q[1][1] = s1;
	q[1][2] = s2;
	q[1][3] = 0;
	a[s1][s2] = '#';//走过标记
	 
	int tx,ty;
	while(h <= t) {
		for(int i = 1; i <= 4; i++) {
			tx = q[h][1] + fx[i];
			ty = q[h][2] + fy[i];
			//该点可行 
			if(a[tx][ty]=='.') {
				//入队 
				t++;
				q[t][1] = tx;
				q[t][2] = ty;
				q[t][3] = q[h][3] + 1;
				a[tx][ty] = '#';//标记
				//判终点 
				if(tx==e1&&ty==e2) {
					cout<<q[t][3] * c;
					return 0;
				}
			}
		}

		h++;
	}

	cout<<-1;
	return 0;
}
```
