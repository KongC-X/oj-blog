# 3894 - 小杨的N字矩阵

## 题目描述

小杨想要构造一个 $m \times m$ 的 $N$ 字矩阵（ $m$ 为奇数），这个矩阵的从左上角到右下角的对角线、第 $1$  列和第 $m$ 列都是半角加号 $+$ ，其余都是半角减号  $-$ 。

例如，一个  $5 \times 5$ 的 $N$ 字矩阵如下：

```
`+---+
++--+
+-+-+
+--++
+---+
`
```

请你帮小杨根据给定的 $m$ 行打印出对应的 $N$ 字矩阵。

## 输入

第一行包含一个正整数 $m$。

## 输出

输出对应的 $N$ 字矩阵。

## 解题思路

## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int m,n;
    cin >> m >> n;
    if(m > n) {
        cout << m * (m - n) << endl;
    } else {
        cout << n * (n - m) << endl;
    }
}
```
