# 1158 - 输出奇数和偶数

## 题目描述

输入 $n$ 个整数，将其中的奇数和偶数分别显示出来（$1 \lt  n \lt 30$）。

## 输入

第一行：一个整数 $n$ ；

第二行： $n$ 个空格隔开的整数。

## 输出

第一行：若干个奇数；

第二行：若干个偶数。（每个数前面都有一个空格）
## AC代码

```cpp
#include<iostream>
using namespace std;
int main() {
	int a[40],n;
	cin>>n;
	for(int i=0; i<n; i++) {
		cin>>a[i];
	}
	//输出奇数 
	for(int i=0; i<n; i++) {
		if(a[i]%2==1)cout<<a[i]<<" ";
	}
	cout<<endl;
	//输出偶数 
	for(int i=0; i<n; i++) {
		if(a[i]%2==0)cout<<a[i]<<" ";
	}
}
```
