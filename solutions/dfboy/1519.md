# 1519 - 求1~n中每个数的因子有哪些？

## 题目描述

输出 $1 \sim n$中每个数的因子有哪些，从小到大输出！

比如：$n=10$，那么输出结果如下。

$1:1$

$2:1$ $2$

$3:1$ $3$

$4:1$ $2$ $4$

$5:1$ $5$

$6:1$ $2$ $3$ $6$

$7:1$ $7$

$8:1$ $2$ $4$ $8$

$9:1$ $3$ $9$

$10:1$ $2$ $5$ $10$

其中，每行冒号前的整数代表了 $1 \sim n$ 的每个数，冒号后的的数字代表了这个整数有哪些因子，用空格隔开。

## 输入

一个整数 $n（n \le 1000$）。

## 输出

按要求输出 $1 \sim n$ 中每个数的因子有哪些。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
    int n,i,q,b,s,g,sum=0;
    cin>>n;
    //遍历1000到n之间的所有4位数 
    for(i=1000;i<=n;i++){
    	//对i进行拆位 
        q=i/1000;
        b=i/100%10;
        s=i%100/10;
        g=i%10;
        //判断i的各个位是奇数 
        if(q%2==1&&b%2==1&&s%2==1&&g%2==1){
            sum=sum+i;//对符合条件的数累加 
        }
    }
    cout<<sum;
	return 0;
}
```
