# 1204 - 有趣的数字图形I

## 题目描述

读入一个整数 $n$ ,输出一个 $n \times n$ 的方阵。 对角线是 $1$ ，对角线向右上逐渐递增，左下为空格，每个数场宽为 $5$ 。

## 输入

一个整数 $n$ 。（ $n \lt 100$ ）

## 输出

$n \times n$ 的方阵。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
int n;
cin>>n;
int a[n][n];
for(int i=0;i<n;i++)
{
	for(int j=i;j<n;j++)
	{
		a[i][j]=j-i+1;
	}
}
	for(int i=0;i<n;i++)
{
	for(int j=0;j<i;j++)
	{
		cout<<setw(5)<<" ";
	}
	for(int j=i;j<n;j++)
	{
		cout<<setw(5)<<a[i][j];
	}
	cout<<endl;
}
return 0; 	

}
```
