# 1204 - 有趣的数字图形I

## 题目描述

读入一个整数 $n$ ,输出一个 $n \times n$ 的方阵。 对角线是 $1$ ，对角线向右上逐渐递增，左下为空格，每个数场宽为 $5$ 。

## 输入

一个整数 $n$ 。（ $n \lt 100$ ）

## 输出

$n \times n$ 的方阵。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <cmath>
using namespace std;

// 判断是否是素数
bool isPrime(int n) {
    if (n <= 1) {
        return false;
    }
    for (int i = 2; i <= sqrt(n); i++) {
        if (n % i == 0) {
            return false;
        }
    }
    return true;
}

int main() {
    int i,n;
    for(i = 1000;i < 3000;i++) { // 1234
        n = i; // 不能修改i的值
        if(isPrime(n)) {
            n = n % 1000; // 234
            if(isPrime(n)) {
                n = n % 100; // 34
                if(isPrime(n)) {
                    n = n % 10; // 4
                    if(isPrime(n)) {
                        cout << i << endl;
                    }
                }
            }
        }
    }
}
```
