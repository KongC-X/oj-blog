# 1453 - 橘子排队

## 题目描述

秋天到了，同学们去橘子园摘橘子。

张老师要求同学们把摘好的橘子去掉一个最大的，再去掉一个最小的的橘子，求出剩余的橘子的平均重量，并将剩余的橘子按照由轻到重排序。

## 输入

第一行是橘子的数量 $n$。（$3≤n≤200$）

第二行是 $n$ 个正整数，表示这些橘子的重量。

## 输出

第一行输出剩余橘子的平均重量，结果保留 $1$ 位小数。

第二行输出剩余橘子按照由轻到重排序后的结果。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int a[20][20],n,x = 1,i,j;
int main() {
    cin >> n;
    for(i = n-1;i >= 0;i--) {
        for(j = 0;j < n;j++) {
            a[i][j] = x;
            x++;
        }
    }
    // for(i = 0;i < n;i++) {
    //     for(j = 0;j < n;j++) {
    //         a[n-1-i][j] = x;
    //         x++;
    //     }
    // }
    for(i = 0;i < n;i++) {
        for(j = 0;j < n;j++) {
            cout << setw(3) << a[i][j];
        }
        cout << endl;
    }
}
```
