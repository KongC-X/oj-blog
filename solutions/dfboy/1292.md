# 1292 - 十六进制转十进制

## 题目描述

请将一个**不超过 $10$ 位**的十六进制正整数转换为十进制整数。

## 输入

$10$ 位以内的十六进制正整数，如果该十六进制中有字母，字母用大写英文字母表示。

## 输出

该数对应的十进制整数。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s;
    long long n,x = 0,i;
    cin >> s;
    // 1AF
    for(i = s.size() - 1;i >= 0;i--) {
        if(isdigit(s[i])) {
            n = (s[i] - '0') * pow(16,s.size() - i - 1); 
        } else {
            n = (s[i] - 'A' + 10) * pow(16,s.size() - i - 1);
        }
        x += n;
    }
    cout << x << endl;
}
```
