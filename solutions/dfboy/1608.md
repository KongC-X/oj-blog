# 1608 - 三位数运算

## 题目描述

小丽在编程课上学会了拆位运算，她已经可以拆出一个三位整数的百位、十位和个位了，她想知道这个整数的（百位 $+$ 十位） $/$ （十位 $+$ 个位）的结果是多少，请编程帮她实现？（请注意，计算结果要保留 $2$ 位小数）。

比如：整数 $135$ 的（百位 $+$ 十位）$/$ （十位 $+$ 个位）的计算结果 $= （1+3）/（3+5） = 4 / 8 = 0.50$ 。

## 输入

读入一个三位的正整数 $n$（$n$ 的各个位中都不含数字 $0$）。

## 输出

输出这个三位正整数（百位 $+$ 十位）除以（十位 $+$ 个位）的计算结果，保留 $2$ 位小数。

## 解题思路

## AC代码

```cpp
#include<iostream>
#include<iomanip>
using namespace std;

int a[20][20];
int n;

void fun(int start,int len,int x) {
    if(len > 0) {
        int i,j;
        // 向右
        for(j = start;j <= start + len - 1;j++) {
            a[start][j] = x;
            x++;
        }
        // 向下
        for(i = start + 1;i <= start + len - 1;i++) {
            a[i][start + len - 1] = x;
            x++;
        }
        // 向左
        for(j = start + len - 2;j >= start;j--) {
            a[start + len - 1][j] = x;
            x++;
        }
        // 向上
        for(i = start + len - 2;i >= start + 1;i--) {
            a[i][start] = x;
            x++;
        }
        fun(start + 1,len - 2,x);
    }
}

int main() {
    cin >> n;
    fun(1, n, 1);
    for(int i = 1;i <= n;i++) {
        for(int j = 1;j <= n;j++) {
            cout << setw(3) << a[i][j];
        }
        cout << endl;
    }
}
```
