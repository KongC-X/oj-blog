# 1651 - 跳格子

## 题目描述

地面上有一排长度为 $n$ 的格子 $1 \sim n$，每个格子上都有一个数 $x_i$，开始时你在位置 $0$ ，每次你可以向前跳 $1 \sim 2$ 格，然后取走格子上的数，直到跳到位置 $n+1$。

取走的数的和就是你的得分，现在你想知道你可能的最大得分是多少。

## 输入

一行四个整数 $n,A,B,C$ ($n≤100000$，$0≤A,B,C≤10000$)，其中 $n$ 表示格子的数量。

$x[i]$ 由如下方式生成：

## 输出

一行一个整数 $ans$ 表示可能的最大得分。

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s;
    long long n,x = 0,i;
    cin >> s;
    // 1AF
    for(i = s.size() - 1;i >= 0;i--) {
        if(isdigit(s[i])) {
            n = (s[i] - '0') * pow(16,s.size() - i - 1); 
        } else {
            n = (s[i] - 'A' + 10) * pow(16,s.size() - i - 1);
        }
        x += n;
    }
    cout << x << endl;
}
```
