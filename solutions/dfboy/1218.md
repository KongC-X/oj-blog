# 1218 - 摘苹果

## 题目描述

小红来到苹果园，帮园长摘苹果，园长请小红把摘完的苹果的最小的那个去掉（如果有多个最小的苹果，那么都要去掉），剩余的苹果算一下平均一个苹果有多重？（平均重量请保留 $1$ 位小数）

## 输入

输入有 $2$ 行：

第一行：一个整数 $n$ 代表小红摘的 $n$ 个苹果（ $3 \le n \le 100$ ）；

第二行： $n$ 个苹果的重量（分别用 $n$ 个整数表示，本题不存在 $n$ 个苹果一样重的情况）。

## 输出

去掉最小的苹果后，摘到的苹果的平均重量！

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <cmath>
using namespace std;

// 求一个数的因子和
int sumOfFactors(int n) {
    int sum = 0;
    for (int i = 2; i < n; i++) {
        if (n % i == 0) {
            sum += i;
        }
    }
    return sum;
}

int main() {
    int n,i,j;
    cin >> n;
    for(i = 2;i <= n;i++){
        for(j = 2;j <= n;j++) {
            if(sumOfFactors(i) == j && sumOfFactors(j) == i) {
                cout << i << " " << j << endl;
            }
        }
    }
}
```
