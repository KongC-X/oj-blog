# 1218 - 摘苹果

## 题目描述

小红来到苹果园，帮园长摘苹果，园长请小红把摘完的苹果的最小的那个去掉（如果有多个最小的苹果，那么都要去掉），剩余的苹果算一下平均一个苹果有多重？（平均重量请保留 $1$ 位小数）

## 输入

输入有 $2$ 行：

第一行：一个整数 $n$ 代表小红摘的 $n$ 个苹果（ $3 \le n \le 100$ ）；

第二行： $n$ 个苹果的重量（分别用 $n$ 个整数表示，本题不存在 $n$ 个苹果一样重的情况）。

## 输出

去掉最小的苹果后，摘到的苹果的平均重量！

```cpp
#include<bits/stdc++.h>
using namespace std;
int main()
{
  int a[101],n,min,cnt=0;
  double sum=0;
  cin>>n;
  for(int i=1;i<=n;i++)
      cin>>a[i];
   min=a[1];
  for(int i=2;i<=n;i++)
      if(min>a[i])  min=a[i];
  for(int i=1;i<=n;i++)	
      if(min==a[i])  cnt++;	
  for(int i=1;i<=n;i++)
      if(a[i]!=min)  
	      sum=sum+a[i];
cout<<fixed<<setprecision(1)<<sum*1.0/(n-cnt);
  return  0;
}
```
