# 1301 - 小明有没有考到90分

## 题目描述

小明同学有一个习惯，如果考试考到 $90$ 分及以上，他就会说 `yes` ，如果没有考到，他就不说话。

请从键盘读入一个整数 $n$ 代表小明同学 的考试成绩，判断是否要输出 `yes` 。

## 输入

一个整数 $n$ 代表小明同学的考试成绩。

## 输出

如果考到 $90$ 分及以上，输出 `yes`，否则不输出。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	//定义变量n表示成绩 
	int n;
	//输入成绩
	cin>>n;
	
	if(n>=90){
		cout<<"yes";
	} 
	return 0;
}
```
