# 1231 - 考试成绩的分布情况

## 题目描述

期末考试结束，小明的语文老师想知道，这次考试的成绩分布情况，主要计算如下几个数据：平均分、$ \ge $ 平均分的总人数、 $ \lt $ 平均分的总人数，请你写程序帮助小明的语文老师来计算一下！

## 输入

第一行，一个整数 $n$ 代表有 $n$ 个人的成绩（ $n \le 100$ ）；

第二行， $n$ 个人的语文成绩。

## 输出

$3$ 个值，分别代表平均分、$ \ge $ 平均分的总人数、$ \lt $ 平均分的总人数，请注意，平均分保留 $1$ 位小数！
## AC代码
## AC代码

```cpp
#include<iostream>
#include<iomanip>
using namespace std;
int a[110],c1,c2,sum;
double ans;
int main()
{
	int n;
	cin>>n;
	for(int i=1;i<=n;i++){
		cin>>a[i];
		sum+=a[i];
	}
	ans=sum*1.0/n;
	for(int i=1;i<=n;i++)
	{
		if(a[i]>=ans){
			c1++;
		}
		else{
			c2++;
		}
	}
	cout<<fixed<<setprecision(1)<<ans<<" "<<c1<<" "<<c2;
	return 0;
}
```
