# 1243 - 请求出一个3位数打乱次序后能组成的最小的3位数是多少？

## 题目描述

请问一个三位数打乱次序后能组成的位数不变的（任然是 $3$ 位数）的三位数是多少？

比如： $n=321$ ，能组成的最小 $3$ 位数是 $123$ ；如果$n=230$ ，能组成的最小 $3$ 位数是 $203$！

## 输入

输入一个三位的正整数 $n$ 。

## 输出

这个三位的正整数 $n$ 打乱次序后能组成的最小的三位数。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	//定义变量n代表一个三位正整数
	//b,s,g代表百位,十位,个位 
	int n,b,s,g;
	//输入n
	cin>>n;
	b = n / 100;
	s = n / 10 % 10;
	g = n % 10;
	//对b,s,g进行由小到大排序 
	int t;
	if(s>g){
		t = s;
		s = g;
		g = t;
	} 
	if(b>s){
		t = b;
		b = s;
		s = t;
	}
	if(s>g){
		t = s;
		s = g;
		g = t;
	} 
	//如果b为0,先调换b和s的值 
	if(b==0){
		t = b;
		b = s;
		s = t;		
	}
	//如果b还是为0,调换b和g的值 
	if(b==0){
		t = g;
		g = b;
		b = t;
	}
	cout<<b*100+s*10+g;
	return 0;
}
```
