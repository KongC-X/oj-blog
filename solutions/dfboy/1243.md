# 1243 - 请求出一个3位数打乱次序后能组成的最小的3位数是多少？

## 题目描述

请问一个三位数打乱次序后能组成的位数不变的（任然是 $3$ 位数）的三位数是多少？

比如： $n=321$ ，能组成的最小 $3$ 位数是 $123$ ；如果$n=230$ ，能组成的最小 $3$ 位数是 $203$！

## 输入

输入一个三位的正整数 $n$ 。

## 输出

这个三位的正整数 $n$ 打乱次序后能组成的最小的三位数。

## 解题思路

## AC代码

```cpp
// 核心思想： 不要将第 i 种物品简单地拆分成 s[i] 个单独的物品。而是利用二进制的思想，将其拆分成 O(log s[i]) 个新的“组合物品”。这些组合物品经过精心设计，使得用它们进行 0-1 背包选择时，能够等价地表示出选取 0 到 s[i] 件原物品 i 的所有可能情况。
// 任何整数都可以用 2 的幂次方的和唯一表示（二进制表示）。例如 7 = 1 + 2 + 4，10 = 2 + 8（或者 1 + 2 + 4 + 3，但需注意拆分方法）。

#include <bits/stdc++.h> // 万能头文件
#include <iostream>
using namespace std;

const int N = 20010;
int v[N],w[N],dp[2010];
int n,m; // n为物品数量，m为背包容量
int vi,wi,si;
int k = 0;

int main() {
    cin >> n >> m;
    for(int i = 1; i <= n; i++){
        cin >> vi >> wi >> si;
        // 对si二进制化，比如：
        // 有10件一样的物品，转换为有4件不同的物品：1 2 4 3
        // 这4种物品的体积分别为：1*vi 2*vi 4*vi 3*vi
        int t = 1; // 权重，表示2的次方
        while(t <= si) {
            k++; // 物品数量+1
            v[k] = t * vi;
            w[k] = t * wi;
            si = si - t;
            t = t * 2;
        }
        // 如果si不为0，说明有剩余，则直接加上
        if(si > 0) {
            k++;
            v[k] = si * vi;
            w[k] = si * wi;
        }
    }
    // 01背包
    for(int i = 1; i <= k; i++){
        for(int j = m; j >= v[i]; j--){
            dp[j] = max(dp[j],dp[j-v[i]]+w[i]);
        }
    }
    cout << dp[m] << endl;
}
```
