# 1245 - 求s=a+aa+aaa+aaaa+aa...a的值

## 题目描述

求 $s=a+aa+aaa+aaaa+aa \dots a$ 的值，其中 $a$ 从键盘读入。比如：读入 $2$ ，则 $s=2+22=24$ 。再比如：读入 $5$ ， $s=5+55+555+5555+55555=61725$

## 输入

一个整数 $a$ （ $a$ 在 $1 \sim 9$ 的范围内）

## 输出

整数 $n$ 代表这个算式的结果

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

const int N = 100100;
int a[N];
int n,q; // n个数，q次查询

int fun(int x) {
    int l = 1,r = n,mid;
    while(l <= r) {
        mid = (l + r) >> 1; // 右移运算符，相当于/2
        if(x < a[mid]) r = mid - 1;
        else if(x > a[mid]) l = mid + 1;
        else if(x == a[mid]) l = mid + 1; // 相等右移
    }
    // l就是数组中第一个大于x的数的位置
    if(a[l - 1] == x) return l - 1;
    else return -1;
}

int main() {
    scanf("%d", &n);
    for(int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }
    scanf("%d", &q);
    int x;
    for(int i = 1; i <= q; i++) {
        scanf("%d", &x);
        // 求x在数组中首次出现的位置
        // cout << fun(x) << " ";
        printf("%d ", fun(x));
    }
}
```
