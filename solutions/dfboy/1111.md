# 1111 - 找最长单词

## 题目描述

编写程序，根据给出的一个结束于 `.` 的字符字串，找出其中最长的含有字母 `a` 的单词。

## 输入

一行，为一个字符字串，结束于句点 `.`。(读入的字符串的总长度不超过 $300$ 个字符)

字串中的单词由一个或几个空格隔开。

## 输出

一行。显示找出的最长的含有字母 `a` 的子串。

如果有多个这样的子串，只显示其中的第一个；若没有含字母 `a` 的子串，则显示 `NO` 。

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s,s1,max;
    int p = 0,i;
    bool flag = false;
    getline(cin,s);
    for(i = 0;i < s.size();i++) {
        if(s[i] != ' ') {
            s1 += s[i];
            if(s[i + 1] == ' ' || s[i + 1] == '.') {
                // cout << s1 << endl;
                p = s1.find('a');
                if(p != -1) {
                    flag = true;
                    if(s1.size() > max.size()) {
                        max = s1;
                    }
                }
                s1 = "";
            }
        }
    }
    if(!flag) {
        cout << "NO";
    } else {
        cout << max;
    }

}
```
