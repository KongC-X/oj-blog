# 1111 - 找最长单词

## 题目描述

编写程序，根据给出的一个结束于 `.` 的字符字串，找出其中最长的含有字母 `a` 的单词。

## 输入

一行，为一个字符字串，结束于句点 `.`。(读入的字符串的总长度不超过 $300$ 个字符)

字串中的单词由一个或几个空格隔开。

## 输出

一行。显示找出的最长的含有字母 `a` 的子串。

如果有多个这样的子串，只显示其中的第一个；若没有含字母 `a` 的子串，则显示 `NO` 。

## 解题思路

## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int a[110],n,i,x,t;
    cin >> x;
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> a[i];
    }
    for(i = 0;i < n;i++) {
        if(a[i] > x) {  // 找到第一个大于x的位置并标记
            t = i;
            break;
        }
    }
    for(i = n - 1;i >= t;i--) {  // 从标记处开始移动元素
        a[i + 1] = a[i];
    }
    a[t] = x;
    for (i=0;i<n+1;i++) cout << a[i] << " ";
}
```
