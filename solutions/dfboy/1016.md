# 1016 - 买小猫小狗

## 题目描述

某动物饲养中心用 $X$ 元专款购买小狗(每只 $A$ 元)和小猫(每只$B$ 元)两种小动物。

要求专款专用，(至少猫狗各一)，正好用完。

请求出方案的总数。如没有请输出 $0$ 。

## 输入

输入一行，只有三个整数，分别为 $X,A,B$。( $100 \lt X \lt 32768，  1 \le A \le 100，1 \le  B \le 100 $ )

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

```cpp
// 某动物饲养中心用 X 元专款购买小狗 (每只 A 元) 和小猫 (每只 B 元) 两种小动物。
// 要求专款专用，(至少猫狗各一)，正好用完。
// 请求出方案的总数。如没有请输出0
# include <iostream>
using namespace std;

int main() {
    int x,a,b,i,j,s=0;
    cin >> x >> a >> b;
    for(i = 1;i <= x/a;i++){
        for(j = 1;j <= x/b;j++){
            if(i*a+j*b==x){
                s++;
            }
        }
    }
    cout << s << endl;
    return 0;
}
```
