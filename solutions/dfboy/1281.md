# 1281 - 求2+2*2+2*2*2+…+2*2*2*….*2

## 题目描述

求 $2+2*2+2*2*2+…+2*2*2*…*2$ 的和是多少？最后一项有多少 $2$ 相乘由键盘读入的 $n$ 决定（$1 \le n \le 100$）。

比如：$n=3$，那么$s=2+2*2+2*2*2=14$。

## 输入

从键盘读入一个整数 $n$（$1 \le n \le 100$）。

## 输出

输出求出的和。
## AC代码
## AC代码

```cpp
#include<iostream> 
#include<bits/stdc++.h> 
using namespace std;

int a[1000] = {1};
int r[1000]; 
int n,i,j,k = 1,k2 = 1,len;// k代表数组当前长度
int main() {
	cin >> n;
	// 第一层循环是用来控制循环的次数
	for(i = 1;i <= n;i++) {
		// 第二层循环是有几位要乘2
		for(j = 0;j < k;j++) {
			a[j] = a[j] * 2;
		}
		// 处理进位
		for(j = 0;j < k;j++) {
		    if(a[j] >= 10) {
				a[j + 1]++;
				a[j] = a[j] - 10;
			}
		}
		// 如果有进位，增加数组长度
		if(a[k] != 0) {
			k++;
		}
		len = max(k2, k);
		for(j = 0;j < len;j++) {
			r[j] += a[j];
		}
		for(j = 0;j < len;j++) {
			if(r[j] >= 10) {
				r[j + 1]++;
				r[j] = r[j] - 10;
			}
		}
		// 如果最后一位有进位，增加数组长度
		if(r[len] != 0) {
			len++;
		}
	}
	// 输出结果
	for(i = len - 1;i >= 0;i--) {
		cout << r[i];
	}
}
```
