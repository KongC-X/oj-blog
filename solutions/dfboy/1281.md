# 1281 - 求2+2*2+2*2*2+…+2*2*2*….*2

## 题目描述

求 $2+2*2+2*2*2+…+2*2*2*…*2$ 的和是多少？最后一项有多少 $2$ 相乘由键盘读入的 $n$ 决定（$1 \le n \le 100$）。

比如：$n=3$，那么$s=2+2*2+2*2*2=14$。

## 输入

从键盘读入一个整数 $n$（$1 \le n \le 100$）。

## 输出

输出求出的和。
