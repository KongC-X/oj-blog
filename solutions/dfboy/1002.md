# 1002 - 编程求解1+2+3+...+n

## 题目描述

编程求解下列式子的值： $S=1+2+3+ \dots +n $。

## 输入

输入一行，只有一个整数 $n(1 \le n \le 1000)$ 。

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
#include<iostream>
using namespace std;

// 解法1: 使用公共变量s，递归循环加到s上
int n,s;

void fun(int i) {
    if(i <= n) {
        s += i; // 递归循环加到s上
        fun(i + 1);
    }
}

int main() {
    cin >> n; // 5
    fun(1);
    cout << s;
}
```
