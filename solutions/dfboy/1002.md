# 1002 - 编程求解1+2+3+...+n

## 题目描述

编程求解下列式子的值： $S=1+2+3+ \dots +n $。

## 输入

输入一行，只有一个整数 $n(1 \le n \le 1000)$ 。

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int x,y,n;
    cin >> x >> y;
    n = y/x * 5;
    cout << n << endl;
}
```
