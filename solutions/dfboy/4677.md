# 4677 - 等差矩阵

## 题目描述

小 $A$ 想构造一个 $n$ 行 $m$ 列的矩阵，使得矩阵的每一行与每一列均是等差数列。小 $A$ 发现，在矩阵的第 $i$ 行第 $j$ 列填入整数 $i \times j$ ，得到的矩阵能满足要求。你能帮小 $A$ 输出这个矩阵吗？

## 输入

一行，两个正整数 $n，m$ 。

## 输出

共 $n$ 行，每行 $m$ 个由空格分割的整数，表示小 $A$ 需要构造的矩阵。
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    int n,m,i,j;
    cin >> n >> m;
    for(i=1;i<=n;i++){
        for(j=0;j<m;j++){
            cout << i + i * j << " ";
        }
        cout << endl;
    }
}
```
