# 1628 - 三位数是否对称

## 题目描述

请从键盘读入一个三位整数，判断这个三位整数是否是对称数（对称数指的是，这个数正过来和倒过来是同一个数，比如：$121、686、808$ 等数都是对称数），如果是对称数，则输出“`Y`” ，否则输出“`N`” 。（请注意字母的大小写）。

## 输入

读入一个三位的整数。

## 输出

如果这个三位数是对称数，输出 “`Y`” ，如果不是，输出“`N`” 。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 写一个函数，用来将字符数组转成整数输出
int charToInt(char s[]) {
    int i = 0;
    int sum = 0;
    while(s[i] != '\0') {
        // 这里要注意s[i] - '0'
        sum = sum * 10 + (s[i] - '0');
        i++;
    }
    return sum;
}

int main() {
    char s[30],a[30],b[30];
    int i,p,k = 0;
    cin >> s;
    // 找到+的位置，用来分割两个数
    for(i = 0;i < strlen(s);i++) {
        if(s[i] == '+') {
            p = i;
            break;
        }
    }
    // 第一个数
    for(i = 0;i < p;i++) {
        a[i] = s[i];
    }
    a[p] = '\0';
    // 第二个数,从p+1开始，strlen(s) - 1结束,因为不能算=
    for(i = p + 1;i < strlen(s) - 1;i++) {
        b[k] = s[i];
        k++;
    }
    b[k] = '\0';
    // cout << a << " " << b << endl;
    cout << charToInt(a) + charToInt(b) << endl;
}
```
