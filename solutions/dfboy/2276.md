# 2276 - 求逆序对问题

## 题目描述

给定 $N$ 个数的序列 $a_1,a_2, \dots ,a_N$ ，定义一个数对 $(a_i, a_j)$ 为 “重要逆序对” 的充要条件为   且 $a_i > 2 \times a_j$。

求给定序列中“重要逆序对”的个数。

## 输入

本题有多个测试点，每个测试点分为两行：

第一行为序列中数字的个数 $N$（$1 ≤ N ≤ 200000$）；

第二行为序列 $a_1, a_2, \dots , a_N$ ($0 ≤a_i≤ 10000000$ )，由空格分开。

$N=0$ 表示输入结束。

## 输出

每个测试点一行，输出一个整数，为给序列中“重要逆序对”的个数。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200005;
int a[MAXN];                    // 原始序列
int tmp[MAXN];                  // 归并临时数组
long long ans;                  // 重要逆序对总数

// 合并两个有序子数组 [l, mid] 和 [mid+1, r]，并统计重要逆序对
void merge(int l, int mid, int r) {
    // 统计重要逆序对：左区间元素 a[i]，右区间元素 a[j]，满足 a[i] > 2 * a[j]
    int ptr = mid + 1;                       // 指向右区间第一个元素
    for (int i = l; i <= mid; i++) {
        // 由于左右区间均升序，随着 i 增大，a[i] 增大，条件 a[i] > 2 * a[ptr] 会持续满足，
        // 所以 ptr 可以单调向右移动，直到条件不满足或越界
        while (ptr <= r && a[i] > 2LL * a[ptr]) {
            ptr++;
        }
        // ptr 之前（mid+1 到 ptr-1）的所有元素都与 a[i] 构成重要逆序对
        ans += (ptr - (mid + 1));
    }

    // 普通归并合并（按升序）
    int i = l, j = mid + 1, k = l;
    while (i <= mid && j <= r) {
        if (a[i] <= a[j]) tmp[k++] = a[i++];
        else              tmp[k++] = a[j++];
    }
    while (i <= mid) tmp[k++] = a[i++];
    while (j <= r)   tmp[k++] = a[j++];
    for (int p = l; p <= r; p++) a[p] = tmp[p];
}

// 归并排序递归函数
void mergeSort(int l, int r) {
    if (l >= r) return;
    int mid = (l + r) / 2;
    mergeSort(l, mid);
    mergeSort(mid + 1, r);
    merge(l, mid, r);
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;                     // 序列长度
    while (cin >> n && n != 0) {
        for (int i = 1; i <= n; i++) cin >> a[i];

        ans = 0;
        mergeSort(1, n);
        cout << ans << '\n';
    }
    return 0;
}
```
