# 1115 - 数字和

## 题目描述

输入一个很大的数，求各位上的数字和。

## 输入

一个很大的整数（不超过 $200$ 位）。

## 输出

一个整数。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int n; // 全局变量，初始值默认是0
int main(){
    string s;
    // int n = 0; // 局部变量，初识值随机
    cin >> s;
    for(int i = 0; i < s.size(); i++){
        n += s[i] - '0';
    }
    cout << n;
}
```
