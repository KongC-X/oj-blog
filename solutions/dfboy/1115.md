# 1115 - 数字和

## 题目描述

输入一个很大的数，求各位上的数字和。

## 输入

一个很大的整数（不超过 $200$ 位）。

## 输出

一个整数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() { 
    int a[600];
    int n,r,i,s = 0;
    cin >> n >> r;
    for(i=1;i<=n;i++) cin >> a[i];
    sort(a+1,a+n+1);
    // for(i=1;i<=n;i++) cout << a[i] << " ";
    for(i=1;i<=n;i++) {
        if(i > r) {
            a[i] = a[i] + a[i - r];
        }
        s += a[i];
    }
    cout << s << endl;
}
```
