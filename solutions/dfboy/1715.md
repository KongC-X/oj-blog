# 1715 - 输出满足条件的整数5

## 题目描述

有这样一个四位数,其千位和百位之和为偶数，十位和个位之和为奇数，且前两位之和大于后两位之和，且含有因数 $8$ ，请输出满足上述条件的整数。

## 输入

无。

## 输出

输出满足条件的整数，每行一个。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	int q,b,s,g,sum1,sum2,i;
	//遍历所有的4位数 
    for(i=1000;i<=9999;i++){
    	//拆位求出千位,百位,十位,个位 
        q=i/1000;
        b=i/100%10;
        s=i%100/10;
        g=i%10;
        sum1=q+b;//千位和百位的和 
        sum2=s+g;//十位和个位的和 
        //千位和百位之和为偶数
		//十位和个位之和为奇数
		//且前两位之和大于后两位之和
		//且含有因数8 
        if(sum1%2==0&&sum2%2==1&&sum1>sum2&&i%8==0){
            cout<<i<<endl;
        }
    }
	return 0;
}
```
