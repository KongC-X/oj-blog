# 1273 - 哥德巴赫猜想的所有解

## 题目描述

求出哥德巴赫猜想的所有解（将一个大于 $9$ 的奇数拆分成三个素数之和），并按从小到大的顺序写出。

## 输入

一行，一个大于 $9$ 的奇数。

## 输出

第一行，一个整数 $N$（ $N \le 1200$ ），表示解的总数。

第 $2-N+1$ 行，每行一个解。

## 解题思路

## AC代码

```cpp
// 思路：记录走到每个点需要的步数，由于BFS 首次访问到的点一定就是最短路径，因此，只要走到终点就打印步数即可。
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

// a存储矩阵，q存储队列（遍历过的点）
char a[50][50];
int q[2500][4];
bool f[1010][1010]; // 标记是否访问过
int n,m,i,j,tx,ty;
// head：头指针，tail：尾指针
int head = 1,tail = 1;
// 四个方向,右下左上
int fx[5] = {0,0,1,0,-1};
int fy[5] = {0,1,0,-1,0};

int main() {
    cin >> n >> m;
    for(i = 1;i <= n;i++) {
        for(j = 1;j <= m;j++) {
            cin >> a[i][j];
        }
    }
    // 1,1点存入队列，以1，1为head访问四个方向
    q[1][1] = 1;
    q[1][2] = 1;
    q[1][3] = 1; // 步数
    // 当head <= tail时，说明队列还有点没有尝试标记过四个方向
    while(head <= tail) {
        // 尝试访问head的四个方向
        for(i = 1;i <= 4;i++) {
            // 从head对应的点加上四个方向的变化量得到新的点
            tx = q[head][1] + fx[i];
            ty = q[head][2] + fy[i];
            // 如果新的点在矩阵范围内，且没有被标记过，则标记
            if(a[tx][ty] == '.') {
                a[tx][ty] = '#'; // 标记代表走过了
                // 新的点存入队列，以新点为head访问四个方向
                tail++;
                q[tail][1] = tx;
                q[tail][2] = ty;
                q[tail][3] = q[head][3] + 1; // 步数加一

                if(tx == n && ty == m) { // 如果到达终点，输出步数
                    cout << q[tail][3] << endl;
                    return 0;
                }
     // 注意：本题不能最后以 q[tail][3] 作为走到右下角的最少步数，因为右下角不一定是最后一个进入队列的点。
            }
        }
        head++; // head指向队列头的下一个点
    }
}
```
