# 1149 - 回文数个数

## 题目描述

一个正整数，正读和反读都相同的数为回文数。

例如 $22$， $131$， $2442$， $37073$， $6$，$\dots$ 所有 $1$ 位数都是回文数。

给出一个正整数 $n$ （ $1 \le n \le 10000$ ），求出 $1,2, \dots ,n$ 之中（包括 $1$ 和 $n$ ）的回文数的个数。

## 输入

任意给定一个正整数 $n$ （ $0 \lt n \le 10000$ ）

## 输出

一个正整数，表示 $[1,n]$ 之间的回文数的个数。
## AC代码
## AC代码

```cpp
#include <iostream>
using namespace std;

// 倒数
int reverse(int n) {
    int s = 0;
    while(n != 0) {
        s = s * 10 + n % 10;
        n = n / 10;
    }
    return s;
}

int main(){
    int i,a,n,s,sum = 0;
    cin >> n;
    for(i = 1;i <= n;i++) {
        a = i;
        s = reverse(a);
        // 如果是回文数则相等
         if(s == i) {
            sum++;
        }
    }
    cout << sum << endl;
}
```
