# 1419 - 请将2个数按照由小到大的顺序排列后输出

## 题目描述

从键盘读入两个整数 $a$ 和 $b$ ，将这两个数按照由小到大的顺序输出。

## 输入

输入任意的两个整数，用空格隔开。

## 输出

输出只有一行，按照由小到大的顺序输出 $2$ 个整数，用空格隔开。

## 解题思路

## AC代码
## AC代码

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main(){
	//定义两个整数变量a,b 
	int a,b;
	//输入a，b 
	cin>>a>>b;
	//如果a>b，先输出b，否则先输出a 
	if(a>b){
		cout<<b<<" "<<a;
	}else{
		cout<<a<<" "<<b;
	}
	return 0;
}
```
