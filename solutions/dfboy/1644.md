# 1644 - 大数的平方

## 题目描述

判断两个数 $a，b$ （不相等），输出较大数的平方值。

## 输入

两个整数 $a, b$（不大于 $32767$ ）。

## 输出

较大数的平方。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h> 
using namespace std;

int fun(int n) {
	int r=0;
	for(int i=2;i<=sqrt(n);i++) {
		if(n%i == 0) {
			if(i == sqrt(n)) {
				r+=i;
			} else {
				r=r+i+(n/i);
			}
		} 
	}
	return r; 
}
int main() {
	int n;
	cin>>n;
	cout<<fun(n);
	return 0; 
}
```
