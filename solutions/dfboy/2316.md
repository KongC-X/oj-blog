# 2316 - 勾股数（gougu）

## 题目描述

勾股定理指直角三角形的两条直角边的平方和等于斜边的平方。中国古代称直角三角形为勾股形，并且直角边中较小者为勾，另一长直角边为股，斜边为弦，所以称这个定理为勾股定理。

勾股弦的长度分别为 $a,b,c$，有：$a^2$ $+$ $b ^2$  $=$ $c^2$ 。
当 $a,b,c$ 均为正整数时，我们称( $a,b,c$ )为勾股数。
如：

$3,4,5$

$5,12,13$

$7,24,25$

$9,40,41$

$ \dots $

均为勾股数。

当然，这只是一部分勾股数，现在的问题是：**按这样的方法**列下去，第 $n$ 组勾股数是什么？

## 输入

一个单独的整数 $n$。

## 输出

三个空格隔开的整数，表示第 $n$ 组勾股数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h> // 万能头文件
#include <iostream>
using namespace std;

const int N = 20010;
int v[N],w[N],s[N];
int dp[1010];
int n,m; 
int vi,wi,si;
int k = 0;

int main() {
    cin >> n >> m;
    for(int i = 1; i <= n; i++){
        cin >> vi >> wi >> si;
        // 如果是多重背包，做二进制拆分
        if(si > 0) {
            int t = 1;
            while(t <= si) {
                k++;
                v[k] = vi * t;
                w[k] = wi * t;
                s[k] = -1;
                si -= t;
                t *= 2;
            }
            if(si > 0) {
                k++;
                v[k] = vi * si;
                w[k] = wi * si;
                s[k] = -1;
            }
        } else {
            k++;
            v[k] = vi;
            w[k] = wi;
            s[k] = si;
        }
    }
    for(int i = 1; i <= k; i++){
        // 判断是01背包还是完全背包
        if(s[i] == -1) {
            for(int j = m; j >= v[i]; j--) {
                dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
            }
        } else {
            for(int j = v[i]; j <= m; j++) {
                dp[j] = max(dp[j], dp[j - v[i]] + w[i]);
            }
        }
    }
    cout << dp[m] << endl;
}
```
