# 1641 - 整数判断

## 题目描述

读入一个数，若这个数大于 $1$ 并且小于 $100$，则输出  `yes` 。

## 输入

一个整数 $a(-32768≤a≤32767)$ 。

## 输出

输入的整数大于 $1$ 并且小于 $100$ ，则输出  `yes`；否则什么也不输出。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	int a;
	cin>>a;
	
	//判断a是否大于1并且小于100 
	if(a>1&&a<100){
		cout<<"yes";
	}
	return 0;
}
```
