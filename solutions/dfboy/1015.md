# 1015 - 鸡兔同笼问题

## 题目描述

鸡兔同笼问题：一个笼子里面有鸡若干只，兔若干只。共有头 $50$ 个，共有腿 $160$ 条。求鸡兔各多少只？

（ $6.2.32$ ）

## 输入

无

## 输出

两个整数，在一行。 

鸡的只数 兔的只数。 

中间空格隔开！

## 解题思路

## AC代码
## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int x,y; // x 是鸡的数量，y 是兔的数量
    for (x = 0; x <= 50; x++) {
        y = 50 - x;
        if (2*x + 4*y == 160) {
            cout << x << endl;
            cout << y << endl;
            break;
        }
    }
    return 0;
}
```
