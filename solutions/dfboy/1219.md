# 1219 - 放大的箭头

## 题目描述

请打印 $n$ 行的放大的箭头（ $n$ 一定是一个奇数）

如：输出 $5$ 行的箭头，输出结果如下，为方便理解，我们用$□$ 代表空格，实际输出的时候，请输出空格！  

每行有 $n$ 颗星！  

```
`*****
□*****
□□*****
□*****
*****
`
```

## 输入

$n$ ，代表有 $n$ 行的图形（ $n$ 一定是一个奇数 $1 \le n \le 99$）。

## 输出

$n$ 行的图形！

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
 
int main() {
    int n;
    cin>>n;
    int i,j;
    //循环n行 
    for(i=1;i<=n;i++){
    	//循环上半部的n/2+1行 
        if(i<=n/2+1){
        	//先输出空格，每行i-1个 
            for(j=1;j<=i-1;j++){
                cout<<" ";
            }
            //输出*每行n个 
            for(j=1;j<=n;j++){
                cout<<"*";
            }
        //循环下半部分 
        }else{
        	//先输出空格，每行n-i个
            for(j=1;j<=n-i;j++){
                cout<<" ";
            }
            //输出*每行n个
            for(j=1;j<=n;j++){
                cout<<"*";
            }
        }
        cout<<endl;
    } 
    return 0;
}
```
