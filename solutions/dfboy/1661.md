# 1661 - 宇航员选拔

## 题目描述

宇航局来到某部队，想从该部队挑选身体好的战士进行航空航天的培训和考核，挑选未来的宇航员。宇航局在身体素质方面定了 $3$ 个基本的标准：身高在 $165$ 厘米$ \sim 185$  厘米之间，体重在 $50$ 公斤$ \sim 80$公斤之间，年龄在$16 \sim 19$周岁（所有数据都包含边界值，也就是身高包含$165$ 厘米和 $185$ 厘米，体重和年龄以此类推）。

现从键盘读入一位战士的年龄、身高、体重数据（都是整数），请问该战士是否符合宇航局定的基本标准，如果符合，请输出 `Y` ，如果不符合，请输出 `N` 。

## 输入

读入三个整数，分别代表一位战士的年龄、体重、身高数据。

## 输出

根据判断结果输出 `Y` 或者 `N` 。
## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
 
 
int main(){
    int a,h,w;
    cin>>a>>w>>h;
    if(a>=16&&a<=19&&w>=50&&w<=80&&h>=165&&h<=185){
        cout<<"Y";
    }else{
        cout<<"N";
    }
}
```
