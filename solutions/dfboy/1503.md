# 1503 - 排序

## 题目描述

给定 $N$ 个数组，要求先对这 $N$ 个数组分别进行排序，然后再根据 $N$ 的数组的字典序对这 $N$ 个数组进行排序。

输出排序的结果。

## 输入

第一行一个整数 $N$，表示数组数。

接下来 $N$（$N≤1000$）行，每一行先包含一个整数 $C$（$C≤1000$），表示数组的大小，接下来 $C$ 个整数，表示数组中的一个元素。

## 输出

共 $N$ 行，每行表示一个数组。

## 解题思路

## AC代码

```cpp
#include<iostream>
#include<iomanip>
using namespace std;
int a[110],c1,c2,sum;
double ans;
int main()
{
	int n;
	cin>>n;
	for(int i=1;i<=n;i++){
		cin>>a[i];
		sum+=a[i];
	}
	ans=sum*1.0/n;
	for(int i=1;i<=n;i++)
	{
		if(a[i]>=ans){
			c1++;
		}
		else{
			c2++;
		}
	}
	cout<<fixed<<setprecision(1)<<ans<<" "<<c1<<" "<<c2;
	return 0;
}
```
