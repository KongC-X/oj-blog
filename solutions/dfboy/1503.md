# 1503 - 排序

## 题目描述

给定 $N$ 个数组，要求先对这 $N$ 个数组分别进行排序，然后再根据 $N$ 的数组的字典序对这 $N$ 个数组进行排序。

输出排序的结果。

## 输入

第一行一个整数 $N$，表示数组数。

接下来 $N$（$N≤1000$）行，每一行先包含一个整数 $C$（$C≤1000$），表示数组的大小，接下来 $C$ 个整数，表示数组中的一个元素。

## 输出

共 $N$ 行，每行表示一个数组。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 定义vector类型的数组，数组中的每个元素都是一个vector
vector<int> a[1100];
int i,j,n,c,x;
int main() {
	cin >> n;
	for(i = 0;i < n;i++) {
		cin >> c;// 每个数组的大小
		for(j = 0;j < c;j++) {
			cin >> x;// 每个数组中的元素
			a[i].push_back(x);// 将元素添加到数组中
		}
		// 每一行的vector读入结束，直接排序
		sort(a[i].begin(),a[i].end());
	}
	sort(a,a + n); // 将数组按照字典从小到大的顺序排序
	// 输出
	for(i = 0;i < n;i++) {
	    for(j = 0;j < a[i].size();j++) {
	    	cout << a[i][j] << " ";
	    }
	    cout << endl;
	}
}
```
