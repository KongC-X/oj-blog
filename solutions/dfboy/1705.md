# 1705 - 四个人从高到低排队

## 题目描述

输入四个人的身高，输出从大到小的四个数。

## 输入

输入一行，只有四个人的身高。

## 输出

输出只从大到小的四个数。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	//定义变量a,b,c,d代表四个人身高 
	int a,b,c,d;
	//输入a,b,c,d 
	cin>>a>>b>>c>>d;
	
	//用排队法对其从大到小排序
	int t;
	if(a<b){
		t = a;
		a = b;
		b = t;
	}
	if(b<c){
		t = b;
		b = c;
		c = t;
	}
	if(c<d){
		t = c;
		c = d;
		d = t;
	}
	if(a<b){
		t = a;
		a = b;
		b = t;
	}
	if(b<c){
		t = b;
		b = c;
		c = t;
	}
	if(a<b){
		t = a;
		a = b;
		b = t;
	}
	cout<<a<<" "<<b<<" "<<c<<" "<<d;
	return 0;
}
```
