# 1097 - 统计字符的个数

## 题目描述

从键盘中任意输入一串字符，直至输入 `#` 字符代表结束。

请编程统计输入的字符中的大写字母，小写字母和数字字符的个数分别是多少？

## 输入

输入只有一行，包括一串字符。(长度小于 $20$，且没有空格)

## 输出

输出只有一行，包括 $3$ 个整数。分别代表大写字符，小写字符和数字字符的个数。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;
int a[110];
int main() {
	int n,i,j,t,k,m;
	cin >> n;
	for(i=0; i<n; i++) {
		cin>>a[i];
	}
	for(i = 0; i < n - 1; i++) {
		for(j = 0; j < n - i - 1; j++) {
			if(a[j] < a[j+1]) {
				t=a[j];
				a[j]=a[j+1];
				a[j+1]=t;
			}
		}
	}
    cin >> k;
    for(i=0; i<n; i++) {
        if(a[i]==k) {
            cout << i+1 << endl;
            break;
        }
    }
}
```
