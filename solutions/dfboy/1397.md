# 1397 - 完美的偶数？

## 题目描述

完美偶数指的是，如果一个数本身是偶数，且这个数是偶数位的数，且这个数的各个位也是偶数，那么这个数就可以称为完美偶数；比如： $28$ 就是完美偶数，而 $246$ 就不是，因为 $246$ 是一个 $3$ 位数。

请你编程求出，从键盘读入的 $n$ 个数中，哪些数是完美的偶数，输出他们。

## 输入

第一行是一个整数 $n$（ $n \le 100$ ）；

第二行是 $n$ 个整数（这些整数都是 $1 \sim 9999$ 范围内的整数）。

## 输出

按顺序输出这 $n$ 个数中的完美偶数，每个数一行。
## AC代码

```cpp
#include <iostream>
using namespace std;
int a[101];
int main() {
	int n;
	cin>>n;
	for(int i=0;i<n;i++){
		cin>>a[i];
	}
	for(int i=0;i<n;i++){
		int g=a[i]%10; // 个位
		int s=a[i]/10%10; // 十位
		int b=a[i]/100%10; // 百位
		int q=a[i]/1000; // 千位
		if(a[i]>=10&&a[i]<=99){
			if(g%2==0&&s%2==0){
				cout<<a[i]<<endl;
			}
		}else if(a[i]>=1000&&a[i]<=9999){
			if(g%2==0&&s%2==0&&b%2==0&&q%2==0){
				cout<<a[i]<<endl;
			}
		}
	}
}
```
