# 1271 - 高精度整数除法

## 题目描述

求 $a/b$ 的结果。

已知 $a$，$b$ 为 $10^8$ 范围内的非负整数，求 $a/b$ 保留前 $n$ 位小数商的结果。

## 输入

读入三个整数 $a$ $b$ $n$。

## 输出

输出一行数字。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
	int a[110],n,mi,i;
	cin>>n;
	for(i = 0; i < n; i++) {
		cin>>a[i];
	}

	//查找最小数
	mi = a[0];
	for(i = 1; i < n; i++) {
		if(a[i] < mi) {
			mi = a[i];
		}
	}

	//输出除了最小数以外的数
	for(i = 0; i < n; i++) {
		if(a[i] != mi) {
			cout<<a[i]<<" ";
		}
	}
	return 0;
}
```
