# 1162 - 数组元素的删除

## 题目描述

把一个数组的第 $x$ 个位置的元素删除掉。

## 输入

输出有三行：

第一行有一个整数 $n$ ( $n ≤ 10$ )；

第二行有 $n$ 个整数（每个整数在$1$~$1000$之间）；

第三行有一个整数 $x$（$1≤x≤n$），为要删除的位置。

## 输出

输出更新后的数组。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    int n,i,a,b,c,d;
    cin >> n;
    a = 1;
    b = 2;
    c = 4;
    for(i = 4;i <= n;i++) {
        d = a + b + c;
        a = b;
        b = c;
        c = d;
    }
    if(n == 1) {
        cout << 1 << endl;
    } else if(n == 2) {
        cout << 2 << endl;
    } else if(n == 3) {
        cout << 4 << endl;
    } else {
        cout << d << endl;
    }
}
```
