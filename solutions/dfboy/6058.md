# 6058 - 种树

## 题目描述

学校组织植树活动，每个班级都需要种植固定数量的树苗。

已知共有若干个班级参与，请问总共需要准备多少棵树苗？

## 输入

一行，两个正整数 $m$ 和 $n$，分别表示每个班级分到的树苗数量和班级数量。（$1 \le m \le 100,1 \le n \le 100$）

## 输出

一行，一个正整数，表示需要准备的树苗数量。
## AC代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int m,n;
    cin >> m >> n;
    cout << m * n << endl;

}
```
