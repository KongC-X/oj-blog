# 2237 - Pell数列

## 题目描述

Pell数列 $a_1, a_2, a_3, \dots ,a_n$ 的定义是这样的，$a_1 = 1, a_2 = 2, ... , a_n = 2 \times a$$n − 1$$+a$$n - 2$ $(n > 2)$ 。

给出一个正整数 $k$ ，要求Pell数列的第 $k$ 项模上 $32767$ 是多少。

## 输入

第 $1$ 行是测试数据的组数 $n$ ，后面跟着 $n$ 行输入。

每组测试数据占 $1$ 行，包括一个正整数 $k$ ( )。

## 输出

$n$ 行，每行输出对应一个输入。输出应是一个非负整数。

## 解题思路

## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

/*
第1行是入口，第n行是出口
伤害值:经过所有点的伤害值的最大
求:最小的伤害代价(求最大值的小的问题)

二分答案:
1.答案具备单调性 -- 可以二分
2.思考二分的范围:答案在什么范围内
3.思考左边界、右边界
*/

int a[1010][1010];
int n,m,i,j;
int l = INT_MAX,r = INT_MIN,mid;

// check(mid):判断伤害值为id的情况下，能否通过迷阵
//检验方法:采用广搜，从1,1出发，走a[i][j]<=mid的点，看能否走到第n行
// 广搜变量准备
int q[1000100][3];
int fx[5] = {0,0,1,0,-1};
int fy[5] = {0,1,0,-1,0};
bool f[1010][1010]; // 记录是否访问过
bool check(int v) {
    // 重设标记数组的值，因为要广搜多次
    memset(f, false, sizeof(f));
    int h = 1,t = 1; // 队列头尾指针
    q[1][1] = 1; // 起点行
    q[1][2] = 1; // 起点列
    f[1][1] = true; // 标记起点已访问
    int tx,ty;
    while(h <= t) {
        // 尝试四个方向
        for(int i = 1;i <= 4;i++) {
            tx = q[h][1] + fx[i];
            ty = q[h][2] + fy[i];
            // 如果该点在迷阵内，且未访问过，且伤害值小于等于v
            if(tx >= 1 && tx <= n && ty >= 1 && ty <= m && !f[tx][ty] && a[tx][ty] <= v) {
                t++; // 队列尾指针后移
                q[t][1] = tx; // 将该点加入队列
                q[t][2] = ty;
                f[tx][ty] = true; // 标记该点已访问

                // 如果到达终点，返回true
                if(tx == n) {
                    return true;
                }
            }
        }
        h++; // 队列头指针后移
    }
    return false; // 如果遍历完都没到达终点，返回false
}


int main() {
    cin >> n >> m;
    for(i=1; i<=n; i++) {
        for(j=1; j<=m; j++) {
            cin >> a[i][j];
            // 如果不是第一行和最后一行，才是伤害值
            if(i != 1 && i != n) {
                l = min(l, a[i][j]);
                r = max(r, a[i][j]);
            }
        }
    }
    // 二分
    while(l <= r) {
        mid = (l + r) >> 1;
        // 如果伤害值为mid能通过，减少伤害值再尝试
        if(check(mid)) {
            r = mid - 1; // 尝试更小的伤害值
        } else {
            l = mid + 1; // 尝试更大的伤害值
        }
    }
    cout << l << endl; // 输出最小的伤害代价
    return 0;
}
```
