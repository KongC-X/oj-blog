# 1081 - 时间转换

## 题目描述

给定一个从 $0$ 秒开始计时的秒数，请将其转换为 $x:x:x$ 的格式。

## 输入

输入一个秒数 $n$。（）

## 输出

输出这个秒数对应的时:分:秒，请注意，这里的时、分、秒要求输出 $2$ 位数，不足 $2$ 位，请补 $0$。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <cstdio>
using namespace std;

int main() {
    int a,b;
    double c;
    cin >> a >> b;
    c = b * 1.0 / a * 100;
    printf("%.3f%%\n",c);
    return 0;
}
```
