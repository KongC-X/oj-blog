# 1081 - 时间转换

## 题目描述

给定一个从 $0$ 秒开始计时的秒数，请将其转换为 $x:x:x$ 的格式。

## 输入

输入一个秒数 $n$。（）

## 输出

输出这个秒数对应的时:分:秒，请注意，这里的时、分、秒要求输出 $2$ 位数，不足 $2$ 位，请补 $0$。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
	int t,h,m,s;
    cin>>t;
    //小时部分 
    h = t/3600;
    //分钟部分 
    m = (t%3600)/60;
    //秒部分 
    s = t%60;
    //如果小时部分小于10,前面需要加个0 
    if(h<10) cout<<"0"<<h<<":";
    else cout<<h<<":";
    //如果分钟部分小于10,前面需要加个0 
    if(m<10) cout<<"0"<<m<<":";
    else cout<<m<<":";
    //如果秒部分小于10,前面需要加个0 
    if(s<10) cout<<"0"<<s;
    else cout<<s; 
	return 0;
}
```
