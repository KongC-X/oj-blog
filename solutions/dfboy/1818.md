# 1818 - 温度统计？

## 题目描述

气象台发布了未来 $n$ 天的温度预报。请你编程帮助老师计算一下，未来 $n$ 天最高温度和最低温度的差值是多少？哪天温度最低？

## 输入

第 $1$ 行有一个整数 $n$。 （$n \le 100$）

第 $2$ 行有 $n$ 个整数，代表未来 $n$ 天的天气。

## 输出

第 $1$ 行有 $1$ 个整数，代表最高问题和最低温度的差值。

第 $2$ 行输出第几天温度最低，如果有多天温度都是最低的，那么都要输出（多个数用空格隔开）。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;

int a[110],n; 

int main() {
    int max,min;
	cin>>n;
	for(int i = 0;i < n;i++){
		cin>>a[i];
	}
	max = 0;
	min = 0;
	// 循环剩余的元素，打擂台找最大、最小数 
	for(int i = 1;i < n;i++){
		if(a[i] > a[max]){
			max = i;
		} 
		if(a[i] < a[min]){
			min = i;
		}
	}
    cout << a[max] - a[min] << endl;
    for(int i = 0;i < n;i++) {
        if(a[i] == a[min]) {
            cout << i + 1 << " ";
        }
    }

}
```
