# 1185 - 数字走向II

## 题目描述

输入整数 $N$ ，输出相应方阵。

## 输入

一个整数 $N$ 。（ $0 \lt N \le 10$ )

## 输出

一个方阵，每个数字的场宽为 $3$ 。

## 解题思路

## AC代码

```cpp
#include<iostream>
using namespace std; 

const int N = 5e5 + 10;
int n,a,b,w[N];
int l = 1,r = 0,mid;

//检验，如果给定mid秒，能否弄干所有的衣服
//思路：先晒，晒不干的烘
bool check(int mid){
	int sum = 0;//烘干湿度比较大的衣服的总时间
	int t;
	for(int i = 1;i <= n;i++){
		if(w[i] > mid * a){
			t = w[i] - mid * a;//剩余湿度
			if(t % b == 0) sum += t / b;
			else sum += t / b + 1;	
		}
	} 
	
	return sum <= mid;
} 
 
int main() {
	scanf("%d%d%d",&n,&a,&b);
	for(int i = 1;i <= n;i++){
		scanf("%d",&w[i]);
		r = max(r,w[i]);
	}
	
	r = r / a + 1;//最湿的衣服，晒干的时间
	
	while(l <= r){
		mid = l + r >> 1;
		//如果mid秒能弄干，减少时间尝试 
		if(check(mid)) r = mid - 1;
		else l = mid + 1; 
	} 
	printf("%d",l);
	return 0;
}
```
