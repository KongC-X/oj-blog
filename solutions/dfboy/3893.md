# 3893 - 数位之和

## 题目描述

小杨有 $n$个正整数，他认为一个正整数是美丽数字当且仅当该正整数每一位数字的总和是 $7$ 的倍数。

小杨想请你编写一个程序判断 $n$ 个正整数哪些是美丽数字。

## 输入

第一行包含一个正整数 $n$ ，代表正整数个数。

之后 $n$ 行，每行包含一个正整数。

## 输出

对于每个正整数，如果是美丽数字则输出 `Yes`，否则输出 `No`。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <iomanip>
#include <bits/stdc++.h>
using namespace std;

// s1,s2表示起始点，e1,e2表示终点
int n,s1,s2,e1,e2;
int a[110][110];
bool flag = false; // 假设走不到终点

// 定义数组，存储x和y的变化，第一个为0不用，后面四个分别代表右下左上
int fx[5] = {0,0,1,0,-1};
int fy[5] = {0,1,0,-1,0};
// 深度优先搜索
void dfs(int x,int y) {
    a[x][y] = 1; // 没走为0，走了就设为1
    int tx,ty;
    // 通过循环方向值变化的数组，将x和y的变化逐个相加到x和y上
    for(int i = 1;i <= 4;i++) {
        tx = x + fx[i];
        ty = y + fy[i];
        if(tx >= 1 && tx <= n && ty >= 1 && ty <= n && a[tx][ty] == 0) {
            // 如果走到了终点就把flag设为true
            if(tx == e1 && ty == e2) {
                flag = true;
            } else {
                dfs(tx,ty);
            }
        }
    }
}

int main(){
    cin >> n;
    for(int i=1;i<=n;i++){
        for(int j=1;j<=n;j++){
            cin >> a[i][j];
        }
    }
    cin >> s1 >> s2 >> e1 >> e2;
    // 如果起始点和终点有走不到的情况直接输出no,否则就正常dfs
    if(a[s1][s2] == 1 || a[e1][e2] == 1){
        cout << "NO" << endl;
    } else {
        dfs(s1,s2);
        flag ? cout << "YES" << endl : cout << "NO" << endl;
    }
}

// 优化：
// 请问上述写法如果到了终点，递归会不会立刻停止?
// 不会，通过递归之后输出二维数组可以发现这点!
// 解决方法：在递归之前的判断中，添加flag==false,要求必须没有找到终点，才能递归，从而减少一些无用的递归。
void dfs(int x,int y) {
    a[x][y] = 1;
    int tx,ty;
    // 通过循环方向值变化的数组，将x和y的变化逐个相加到x和y上
    for(int i = 1;i <= 4;i++) {
        tx = x + fx[i];
        ty = y + fy[i];
        if(tx >= 1 && tx <= n && ty >= 1 && ty <= n && a[tx][ty] == 0 && flag == false) {
            if(tx == e1 && ty == e2) {
                flag = true;
            } else {
                dfs(tx,ty);
            }
        }
    }
}
```
