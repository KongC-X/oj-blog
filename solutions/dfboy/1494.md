# 1494 - 奇特的三角

## 题目描述

请根据下列规律输出奇特的图形，是一个被*包围了的@三角形   

比如，$n=3$，输出：

```
`**@**
*@@@*
@@@@@
`
```

## 输入

输入一个整数（ $n \lt 10$ ）

## 输出

输出 $n$ 行的图形。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main(){
    int n;
    cin>>n;
    int i,j;
    //循环n行 
    for(i=1;i<=n;i++){
    	//每行输出n-i个* 
        for(j=1;j<=n-i;j++){
            cout<<"*";
        }
        //每行输出2*i-1个@ 
        for(j=1;j<=2*i-1;j++){
            cout<<"@";
        }
        //每行输出n-i个* 
        for(j=1;j<=n-i;j++){
            cout<<"*";
        }
        //输出换行 
        cout<<endl;
    }
    return 0; 
}
```
