# 1807 - 排好队了吗？

## 题目描述

体育课上，体育老师要求同学们按照从矮到高或者从高到矮排好队，现在从键盘读入 $n$ 个人的身高，请问，这 $n$ 个人按照老师的要求排好队了吗？如果排好队了，请输出`Good`，如果没有排好，请输出`No`。

## 输入

第一行有 $1$ 个整数 $n$ （$5 \le n \le 10$），代表有 $n$ 个人。

第二行有 $n$ 个整数，用空格隔开表示 $n$ 个人的身高。（这 $n$ 个数都是 $120 \sim 180$ 之间的整数，可能存在身高一样的同学）

## 输出

如果排好队了，请输出`Good`，如果没有排好，请输出`No`。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
dp[i][j]：代表有i个物品，背包容量为j时，能够存储的最大价值
对于第i个物品：
情况一：背包容量j<物品重量w[j]，放不下，能够存放的价值dp[i-1][j]
情况二：背包容量j>=物品重量w[j]，放得下
能够得到的最大价值 = max(dp[i-1][j],v[i]+dp[i-1][j-w[i]])
*/ 
int dp[110][20010];
int n,w[110],v[110],maxw,i,j;

int main(){
	cin>>maxw>>n;
	//读入每个物品的重量和价值
	for(i = 1;i <= n;i++){
		cin>>w[i]>>v[i];
	} 
	// 递推求dp数组
	for(i = 1;i <= n;i++){
		//循环背包容量从1~maxw
		for(j = 1;j <= maxw;j++){
			//如果放不下:背包容量<物品重量 
			if(j < w[i]){
				dp[i][j] = dp[i-1][j]; 
			}else{
				//放得下，就看放进来价值高，还是不放价值高
				dp[i][j] = max(dp[i-1][j],v[i]+dp[i-1][j-w[i]]);
			} 
		} 
	} 	
	//输出n个物品，背包容量为maxw的情况下最大价值 
	cout<<dp[n][maxw];
}
```
