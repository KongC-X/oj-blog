# 3896 - 回文拼接

## 题目描述

一个字符串是回文串，当且仅当该字符串从前往后读和从后往前读是一样的，例如， `aabaa` 和 `ccddcc` 都是回文串，
但 `abcd` 不是。

小杨有 $n$ 个仅包含小写字母的字符串，他想请你编写程序判断每个字符串是否由两个长度至少为 $2$ 的回文串前后拼接而成。

## 输入

第一行包含一个正整数 $n$，代表字符串数量。

之后 $n$ 行每行一个仅包含小写字母的字符串。

## 输出

对于每个字符串输出一行，如果该字符串由两个长度至少为 $2$ 的回文串前后拼接而成则输出 `Yes`，否则输出 `No`。
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int n;
char s[110];

int main() {
    cin >> n;
    while (n--) {
        cin >> s;
        int len = strlen(s);
        bool flag = false; //假设不是拼接回文
        for(int i = 2; i <= len - 2; i++) { //枚举第一段字符长度
            bool f1 = 1, f2 = 1; //假设前后两段都是回文串
            // 前半段
            for(int j = 0; j < i; j++) {
                if (s[j] != s[i - 1 - j]) { //不相等就不是回文串
                    f1 = 0; //标记为非回文串
                    break;
                }
            }
            //后半段
            for(int j = i; j < len; j++) {
                if (s[j] != s[len - 1 - j + i]) {//不相等就不是回文串
                    f2 = 0;//标记为非回文串
                    break;
                }
            }
            if (f1 == 1 && f2 == 1) {//如果都是回文串
                flag = true;//标记为回文拼接
                break;
            }
        }
        if(flag) {
            cout << "Yes" << endl;
        } else {
            cout << "No" << endl;
        }
    }
    return 0;
}
```
