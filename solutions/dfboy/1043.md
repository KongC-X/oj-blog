# 1043 - 行李托运价格

## 题目描述

某车站行李托运收费标准是： $10$  公斤或 $10$ 公斤以下，收费 $2.5$ 元，超过 $10$ 公斤的行李，按每超过 $1$ 公斤增加 $1.5$ 元进行收费。 

试编一程序，输入行李的重量，算出托运费。

## 输入

输入只有一行，包括 $1$ 个整数。

## 输出

输出只有一行，包括 $1$ 个数。 （保留两位小数）。
## AC代码
## AC代码

```cpp
#include <iostream>
#include <iomanip>
using namespace std;

int main(){
	//定义变量n代表货物重量 
    int n;
    //输入货物重量 
    cin>>n;
    //定义小数变量m表示金额 
    double m;
    //判断重量n是否小于10 
    if(n<=10){
        m=2.5;
    }else{
        m=2.5+1.5*(n-10);
    }
    cout<<fixed<<setprecision(2)<<m;
	return 0;
}
```
