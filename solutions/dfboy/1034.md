# 1034 - 两数比大小

## 题目描述

有 $A$，$B$ 两个不相等的数，请将其中较大数打印出来。

## 输入

输入只有一行，包括 $2$ 个整数。之间用一个空格分开。

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。
## AC代码

```cpp
#include<iostream>
#include<iomanip>
using namespace std;
int main(){
	int a,b;
	cin>>a>>b;
	if(a>b){
		cout<<a<<endl;
	}
	else{
		cout<<b<<endl;
	}
	return 0; 
}
```
