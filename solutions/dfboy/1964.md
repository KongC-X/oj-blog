# 1964 - 标准零件

## 题目描述

工厂生产了 $n$ 个圆形零件，每个零件有一个半径，判断零件是否合格的方法是，给定一个标准零件的半径值，如果生产出来零件的半径和标准零件半径值的差 $ \le 5$，那么该零件就是合格的！

比如：工厂生产了 $5$ 个零件，半径分别是$79$  $97$   $115$  $96$  $95$ ，标准零件的半径值是 $95$ ，按照判断标准，有 $3$ 个零件是合格的，半径分别是：$97$  $96$  $95$。

请你编程计算一下，工厂生产的 $n$ 个零件中，有多少个零件是合格的。

## 输入

第一行：一个整数 $n$ 代表有 $n$ 个数。（$10 \le n  \le 100$）

第二行：$n$ 个整数，代表零件的半径。（$10 \le$ 半径的值 $\le 1000$）

第三行：一个整数$x$，代表标准零件的半径。（$10 \le$ 标准零件的半径值 $\le 1000$）

## 输出

一个整数，代表合格零件的个数。
