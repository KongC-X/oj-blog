# 4139 - 寻找数字

## 题目描述

小杨有一个正整数 $a$，小杨想知道是否存在一个正整数 $b$ 满足 $a=b^4$ 。

## 输入

第一行包含一个正整数 $t$，代表测试数据组数。

对于每组测试数据，第一行包含一个正整数代表 $a$。

## 输出

对于每组测试数据，如果存在满足条件的正整数 $b$，则输出 $b$ ，否则输出 $-1$。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

// 求两个高精度的整数之和
string add(string s1,string s2) {
    string r; // 存放总和
    int a[1000] = {0}, b[1000] = {0}, c[1000] = {0};
    int i;
    for(i = 0; i < s1.size(); i++) {
        a[i] = s1[s1.size() - i - 1] - '0';
    }
    for(i = 0; i < s2.size(); i++) {
        b[i] = s2[s2.size() - i - 1] - '0';
    }
    int len = max(s1.size(), s2.size());
    for(i = 0; i < len; i++) {
        c[i] += a[i] + b[i];
        if(c[i] >= 10) {
            c[i + 1] += c[i] / 10;
            c[i] %= 10;
        }
    }
    if(c[len] != 0) {
        len++;
    }
    for(i = len - 1; i >= 0; i--) {
        r += char(c[i] + '0');
    }
    return r;
}

int main() {
    int M, N;
    cin >> M >> N;
    
    int d = N - M;
    
    if (d == 0) {
        cout << "1";
        return 0;
    }
    
    string a = "1", b = "1";
    
    // 计算从f(0)=1, f(1)=1开始的斐波那契数列
    for (int i = 2; i <= d; i++) {
        string c = add(a, b);
        a = b;
        b = c;
    }
    
    cout << b;
    return 0;
}
```
