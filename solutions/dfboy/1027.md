# 1027 - 求任意三位数各个数位上数字的和

## 题目描述

对于一个任意的三位自然数 $x$ ，编程计算其各个数位上的数字之和 $S$ 。

## 输入

输入一行，只有一个整数 $x(100 \le x  \le 999)$ 。

## 输出

输出只有一行，包括 $1$ 个整数。

## 解题思路

## AC代码

```cpp
#include<iostream>
#include<cmath>
using namespace std;

int main(){
    int i = 1;
    while(sqrt(i+100) != int(sqrt(i+100)) || sqrt(i+100+168) != int(sqrt(i+100+168))) {
        i++;
    }
    cout << i << endl;
}
```
