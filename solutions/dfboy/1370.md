# 1370 - 平面分割（II）

## 题目描述

同一平面内有 $n$（$n≤500$）条直线，已知其中 $p$（$p≥2$）条直线相交于同一点，则这 $n$ 条直线最多能将平面分割成多少个不同的区域？

## 输入

两个整数 $n$（$n≤500$）和 $p$（$2≤p≤n$）。

## 输出

一个正整数，代表最多分割成的区域数目。
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	//至少2*p个 
	int n,p,i;
	cin>>n>>p;
	int total = 2*p;
	//每增加一条线 
	for(i=p+1;i<=n;i++){
		total += i; 
	} 
	cout<<total;
	return 0;
}
```
