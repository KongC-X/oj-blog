# 2354 - 注册账号

## 题目描述

【具体要求】  

我们在注册网站时需要自己输入一个账号，某网站的注册要求比较严格，注册账号有如下要求：   

要求一：注册账号只能由大小写字母，数字和下划线组成；  

要求二：注册账号区分大小写，其中必须要包含大写字母，小写字母可有可无；   

要求三：注册账号必须包含数字和下划线二者其一，但二者不能同时出现；  

要求四：如果包含数字，数字不能放开头。  

现在需要你编写一个程序判断一个输入的注册账号是否符合要求。  

例如：  

输入一个账号 Jack44324_  

其符合要求 1，不包含字母，数字和下划线以外的字符；  

其含大写字母，符合要求 2；  

包含数字和下划线，但是二者同时出现，不符合要求 3；  

包含数字且数字不在开头，符合要求 4；  

所以这个账号因不符合要求 3 为不合法。

## 输入

输入一个字符串，长度不超过 20，输入数据只能包含数字、大小写字母和下划线。

## 输出

如果注册账号符合要求则输出“Pass!”，不符合要求则输出“Illegal!”。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

string s; 
bool f1;//判断是否有大写字母 
bool f2;//判断是否有数字
bool f3;//判断是否有下划线 
int main() {
	cin>>s;
	
	//判断是否只有字母数字下划线
	for(int i = 0;i < s.size();i++){
		if(!(isalpha(s[i])||isdigit(s[i])||s[i]=='_')){
			cout<<"Illegal!";
			return 0;
		} 
		
		if(isupper(s[i])) f1 = true; 
		else if(isdigit(s[i])) f2 = true;
		else if(s[i]=='_') f3 = true;
	} 
	
	//如果没有大写字母
	if(f1==false){
		cout<<"Illegal!";
		return 0;
	} 
	
	//如果没有数字下划线，或者同时包含数字下划线，或者以数字开头 
	if((f2&&f3) || !(f2||f3) || isdigit(s[0])){
		cout<<"Illegal!";
		return 0;
	} 
	
	cout<<"Pass!";
	return 0;
}
```
