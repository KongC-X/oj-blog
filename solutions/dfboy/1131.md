# 1131 - 删除指定字符

## 题目描述

从键盘输入一个字符串 $str$ 和一个字符 $c$ ，删除 $str$ 中的所有字符 $c$ 并输出删除后的字符串 $str$ 。

## 输入

第一行是一个字符串，字符串不含空格，长度 $ \le 100$ ；

第二行是一个字符。

## 输出

删除指定字符后的字符串。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	char a[1000],c,b[1000];
	cin>>a>>c;
	int k=0;
	for(int i=0;a[i];i++){
		if(a[i]!=c){
			b[k]=a[i];
			k++;
		}
	}
	b[k]='\0';
	cout<<b;
}
```
