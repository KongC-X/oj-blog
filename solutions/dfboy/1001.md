# 1001 两数之和

## 题目描述

给定一个整数数组 `nums` 和一个目标值 `target`，找出数组中和为目标值的两个数的下标。

**输入**
```
nums = [2, 7, 11, 15], target = 9
```

**输出**
```
[0, 1]
```

## 思路

使用哈希表一次遍历：

1. 遍历数组，对于每个元素 `nums[i]`
2. 检查 `target - nums[i]` 是否在哈希表中
3. 如果存在，返回两个下标
4. 否则将当前元素及其下标加入哈希表

时间复杂度 $O(n)$，空间复杂度 $O(n)$。

## 代码

```cpp
#include <iostream>
#include <vector>
#include <unordered_map>
using namespace std;

int main() {
    int n, target;
    cin >> n >> target;
    
    vector<int> nums(n);
    for (int i = 0; i < n; i++) {
        cin >> nums[i];
    }
    
    unordered_map<int, int> mp;
    for (int i = 0; i < n; i++) {
        int need = target - nums[i];
        if (mp.count(need)) {
            cout << mp[need] << " " << i << endl;
            return 0;
        }
        mp[nums[i]] = i;
    }
    
    cout << "No solution" << endl;
    return 0;
}
```
