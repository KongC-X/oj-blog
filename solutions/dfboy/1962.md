# 1962 - 数值计算

## 题目描述

给出一个不多于 $5$ 位的非负整数 （非 $0$ 结尾），要求:

$1、$ 求出它是几位数

$2、$ 分别输出每一位数字

$3、$ 按逆序输出各位数字，例如原数为 $321$ ,应输出 $123$ 。

## 输入

一个不大于 $5$ 位的正整数。

## 输出

三行  

第 $1$ 行 $5$ 位数。  

第 $2$ 行 用空格分开的每个数字。  

第 $3$ 行 按逆序输出这个数。
## AC代码

```cpp
#include <iostream>
using namespace std;

int main(){
    int n,s = 0,sum = 0,a;
    cin >> n;
    while(n != 0) {
        s = s * 10 + n % 10;
        n = n / 10;
        sum++;
    }
    cout << sum << endl;
    a = s;
    while(a != 0) {
        cout << a % 10 << " ";
        a = a / 10;
    }
    cout << endl;
    cout << s << endl;
}
```
