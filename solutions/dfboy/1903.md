# 1903 - 自然数的拆分方案总数

## 题目描述

给定一个自然数 $N$ ，要求把 $N$ 拆分成若干个正整数相加的形式，参与加法运算的数可以重复。

**注意:**

- 拆分方案不考虑顺序，也就是 $3=1+2$ 和 $3=2+1$ 算作相同的方案；

- 至少拆分成 $2$ 个数的和。

- 求拆分的方案数 $\mod 2147483648$ 的结果。

## 输入

一个自然数 $N$。（$1≤N≤4000$）

## 输出

输入一个整数，表示结果。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
背包容量是：N
相当于：
1.有N-1个物品，他们的体积是1~N-1
2.选出若干物品，体积的和为N
3.每个物品的使用次数没有限制
完全背包的问题！
f(i,j) = f(i-1,j) + f(i-1,j-i)
第i种数不用，用i-1种数凑出j；第i种数用，用i-1种数凑出j-i
*/
int n;
int f[4010];

int main(){
	cin>>n;
	f[0] = 1;//边界
	for(int i = 1;i < n;i++){
		//完全背包
		for(int j = i;j <= n;j++){
			//u代表unsigned，否则大整数输出在非C99的环境会有警告
			f[j] = (f[j] + f[j-i]) % 2147483648u;
		} 
	} 
	cout<<f[n];
	
}
```
