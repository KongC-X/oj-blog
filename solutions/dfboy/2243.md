# 2243 - 反向输出一个三位数

## 题目描述

将一个三位数反向输出。

## 输入

一个三位数 $n$ 。

## 输出

反向输出 $n$ 。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
	int n,i,g,s,b;
	cin>>n;
	b=n/100;
	s=n/10%10;
	g=n%10;
	cout<<g<<s<<b;
	return 0;
}
```
