# 2243 - 反向输出一个三位数

## 题目描述

将一个三位数反向输出。

## 输入

一个三位数 $n$ 。

## 输出

反向输出 $n$ 。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
#include<iostream>
using namespace std;

// 倒序
bool cmp(int a, int b){
    return a > b ? true : false;
}

int a[10010],b[10010];
int n,sum;

int main(){
	cin >> n;
	for(int i=1; i<=n; i++){
		cin >> a[i];
	}
	for(int i=1; i<=n; i++){
		cin >> b[i];
	}
	
	sort(a+1, a+1+n);
	sort(b+1, b+1+n, cmp);

	for(int i=1; i<=n; i++){
		sum += abs(a[i] - b[i]);
	}	
	cout << sum;
}
```
