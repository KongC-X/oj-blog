# 1698 - 请输出带有特殊尾数的数

## 题目描述

请输出 $1 \sim n$ 中所有个位为 $1、3、5、7$ 中任意一个数的整数，每行 $1$ 个。( $n \lt 1000$ )

比如，假设从键盘读入 $20$，输出结果如下：

$1$

$3$

$5$

$7$

$11$

$13$

$15$

$17$

## 输入

一个整数 $n$ 。

## 输出

输出满足条件的数，每行 $1$ 个。

## 解题思路

## AC代码
## AC代码

```cpp
#include <iostream>
using namespace std;

/*
  题目要求打印1~n中满足条件的数
  第一步：打印1~n的每一个数
  第二步：判断每个数是否满足条件，如果满足条件就打印 
*/ 
int main(){
	int i,n,g;
	cin>>n;
	i = 1;
	
	while(i <= n){
		//拆出每个数的个位 
		g = i % 10;
		//不是每个数都要输出
		//必须是个位是1 3 5 7中任意一个数的数，才能输出 
		if(g==1||g==3||g==5||g==7){
			cout<<i<<endl;
		}
		
		i = i + 1;
	}
}
```
