# 4610 - 分割数列

## 题目描述

给定一个由 $n$ 个整数组成的数列，请将其分割成左右两部分，要求左半部分子数列的和与右半部分子数列的和最接近，请输出这两部分子数列和的差值（取非负值）。

例如：$n = 5$，数列中的 $5$ 个整数分别是 $2$、$1$、$3$、$4$、$3$，将其分割成左右两部分，左半部分是 $2$、$1$、$3$，右半部分是 $4$、$3$；此时两部分子数列的和最接近，差值为 $1$。

## 输入

第一行输入一个整数 $n（2 \le n \le 100000）$。

第二行输入 $n$ 个整数（$1 \le $整数 $ \le 1000$），整数之间以一个空格隔开。

## 输出

输出一个整数，表示这两部分子数列和的差值（取非负值）。
## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int n,i,s,a[100010];
int main() {
    cin >> n;
    for(i = 0;i < n;i++) {
        scanf("%d",&a[i]);
        s += a[i];
    }
    int left = 0; // 左半部分的和
    int min_diff = INT_MAX; // 最小的差值
    // 遍历数组，并在每个位置计算左半部分和右半部分的差值
    for(i = 0;i < n - 1;i++) {
        left += a[i];
        int right = s - left; // 右半部分的和
        int diff = abs(left - right); // 左右部分的差值
        min_diff = min(min_diff, diff); // 更新最小的差值
    }
    cout << min_diff << endl;
}
```
