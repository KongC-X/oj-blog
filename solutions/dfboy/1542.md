# 1542 - 小X算排名

## 题目描述

小 $X$ 很关心自己在学校的表现。 

班主任手上有一本“个人得分记录本”，如果一位同学表现好就会加分，表现差则会扣分。学期结束，每位同学都得知了自己的个人得分。小 $X$ 想知道其他同学情况如何，但由于排名不公布，他只好一个个去问班里的其他同学。 

 现在，小 $X$ 手上有班里共 $N$ 位同学的个人得分，他想知道每位同学的排名 （得分相同则排名相同，见样例），可并不知道该如何计算，希望你帮帮他。

## 输入

第一行包含一个整数 $N$ 。 

接下来 $N$ 行，第 $i$ 行包含一个整数 $A_i$，表示第 $i$ 位同学的得分。

## 输出

$N$ 行，第 $i$ 行包含一个整数，表示第 $i$ 位同学的排名。

```cpp
// 思路：用 map 统计出每个分数出现的次数，按照分数降序排序，再将分数出现的次数修正

#include <bits/stdc++.h>
#include <iostream>
#include <map>
using namespace std;
 
//存放分数（key）以及分数出现的次数（value） 
map<int,int,greater<int> > m;
int n,i,c = 0,a[100100],t;
 
int main(){
    scanf("%d", &n);
    for(i = 0;i < n;i++){
        scanf("%d", &a[i]);
        //判断该分数在map中是否存在
        if(m.count(a[i]) == 0){
            //将分数存入map，记录值为1（分数出现的次数） 
            m[a[i]] = 1;
        }else{
            m[a[i]]++; 
        } 
    }
     
    //修正map的value为排名 
    map<int,int>::iterator it;
    for(it = m.begin();it != m.end();it++){
        t = it->second;
        m[it->first] = c + 1;//修正排名 
        c = c + t;//统计每个分数之前有几个人 
    }
     
    //输出每个分数的排名
    for(i = 0;i < n;i++){
        printf("%d\n", m[a[i]]);
    } 
    return 0;
}
```
