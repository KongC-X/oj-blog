# 1256 - 借书方案知多少

## 题目描述

小明有五本新书，要借给A，B，C三位小朋友，若每人每次只能借一本，则可以有多少种不同的借法？

## 输入

无

## 输出

输出一个整数，表示有多少种借法

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s,s1,max;
    int p = 0,i;
    bool flag = false;
    getline(cin,s);
    for(i = 0;i < s.size();i++) {
        if(isdigit(s[i])) {
            s1 += s[i];
            if(!isdigit(s[i+1])) {
                // cout << s1 << endl;
                if(s1.size() > max.size()) {
                    max = s1;
                    p = i + 1 - max.size();
                }
                s1 = "";
            }
        }
    }
    cout << p + 1 << endl;
}
```
