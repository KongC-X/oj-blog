# 1819 - 奇怪的电梯

## 题目描述

有一天我做了一个梦，梦见了一种很奇怪的电梯。

大楼的每一层楼都可以停电梯，而且第 $i$ 层楼 ($1≤i≤N$) 上有一个数字 $K_i$($0≤K_i≤N$) 。电梯只有四个按钮：开，关，上，下。上下的层数等于当前楼层上的那个数字。当然，如果不能满足要求，相应的按钮就会失灵。

例如： $3,3,1,2,5$ 代表了 $K_i$($K_1=3,K_2=3,…$) ，从 $1$ 楼开始。在 $1$ 楼，按“上”可以到 $4$ 楼，按“下”是不起作用的，因为没有 $−2$ 楼。那么，从 $A$ 楼到 $B$ 楼至少要按几次按钮呢？

## 输入

共二行。

第一行为 $3$ 个用空格隔开的正整数，表示 $N,A,B$($1≤N≤200$, $1≤A,B≤N$)。

第二行为 $N$ 个用空格隔开的非负整数，表示 $K_i$ 。

## 输出

一行，即最少按键次数,若无法到达，则输出 $-1$ 。

## 解题思路

## AC代码

```cpp
// 思路：用 map 统计出每个分数出现的次数，按照分数降序排序，再将分数出现的次数修正

#include <bits/stdc++.h>
#include <iostream>
#include <map>
using namespace std;
 
//存放分数（key）以及分数出现的次数（value） 
map<int,int,greater<int> > m;
int n,i,c = 0,a[100100],t;
 
int main(){
    scanf("%d", &n);
    for(i = 0;i < n;i++){
        scanf("%d", &a[i]);
        //判断该分数在map中是否存在
        if(m.count(a[i]) == 0){
            //将分数存入map，记录值为1（分数出现的次数） 
            m[a[i]] = 1;
        }else{
            m[a[i]]++; 
        } 
    }
     
    //修正map的value为排名 
    map<int,int>::iterator it;
    for(it = m.begin();it != m.end();it++){
        t = it->second;
        m[it->first] = c + 1;//修正排名 
        c = c + t;//统计每个分数之前有几个人 
    }
     
    //输出每个分数的排名
    for(i = 0;i < n;i++){
        printf("%d\n", m[a[i]]);
    } 
    return 0;
}
```
