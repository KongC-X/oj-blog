# 1954 - 最大纯色正方形

## 题目描述

铺砖的工人来到一个操场，将整个操场按正方形铺砖（整个操场可视为 $R$ 行 $C$ 列的矩阵，矩阵的每个元素为一块正方形砖块），正方形砖块有两种，一种为蓝色，另一种为红色。请你写一个程序求出为最大纯色正方形的面积。

## 输入

第一行两个正整数 $R$ 和 $C$ 。

接下来 $R$ 行 $C$ 列描述整个操场，红色砖块用 $1$ 来表示，蓝色砖块用 $0$ 来表示。

数据范围
$40\%$ 的数据 $R,C \le 10$ 。

$70\%$ 的数据 $R,C \le 50$ 。

$100\%$ 的数据 $R,C \le 200$ 。

## 输出

一个数，表示最大纯色正方形的面积。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
    int n,i,q,b,s,g,sum=0;
    cin>>n;
    //遍历1000到n之间的所有4位数 
    for(i=1000;i<=n;i++){
    	//对i进行拆位 
        q=i/1000;
        b=i/100%10;
        s=i%100/10;
        g=i%10;
        //判断i的各个位是奇数 
        if(q%2==1&&b%2==1&&s%2==1&&g%2==1){
            sum=sum+i;//对符合条件的数累加 
        }
    }
    cout<<sum;
	return 0;
}
```
