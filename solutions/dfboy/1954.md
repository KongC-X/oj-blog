# 1954 - 最大纯色正方形

## 题目描述

铺砖的工人来到一个操场，将整个操场按正方形铺砖（整个操场可视为 $R$ 行 $C$ 列的矩阵，矩阵的每个元素为一块正方形砖块），正方形砖块有两种，一种为蓝色，另一种为红色。请你写一个程序求出为最大纯色正方形的面积。

## 输入

第一行两个正整数 $R$ 和 $C$ 。

接下来 $R$ 行 $C$ 列描述整个操场，红色砖块用 $1$ 来表示，蓝色砖块用 $0$ 来表示。

数据范围
$40\%$ 的数据 $R,C \le 10$ 。

$70\%$ 的数据 $R,C \le 50$ 。

$100\%$ 的数据 $R,C \le 200$ 。

## 输出

一个数，表示最大纯色正方形的面积。

```cpp
#include <bits/stdc++.h>
using namespace std;

const int N = 210;
int s[N][N], x; //前缀和
int n, m;

int main() {
    cin >> n >> m;
    for(int i = 1; i <= n; i++) {
        for(int j = 1; j <= m; j++) {
            cin >> x;
            //求二维数组的前缀和
            s[i][j] = s[i - 1][j] + s[i][j - 1] - s[i - 1][j - 1] + x;
        }
    }

    //枚举正方形的边长
    for(int len = min(n, m); len >= 1; len--) {
        //枚举每个起点，最多枚举到倒数len行，倒数len列
        for(int i = 1; i <= n - len + 1; i++) {
            for(int j = 1; j <= m - len + 1; j++) {
                int x1 = i, y1 = j, x2 = i + len - 1, y2 = j + len - 1;
                x = s[x2][y2] - s[x1 - 1][y2] - s[x2][y1 - 1] + s[x1 - 1][y1 - 1];
                if(x == 0 || x == len * len) {
                    cout << len * len;
                    return 0;
                }
            }
        }
    }
    return 0;
}
```
