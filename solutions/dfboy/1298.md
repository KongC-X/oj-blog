# 1298 - 摘花生问题

## 题目描述

Hello Kitty 想摘点花生送给她喜欢的米老鼠。她来到一片有网格状道路的矩形花生地(如下图)，从西北角进去，东南角出来。地里每个道路的交叉点上都有种着一株花生苗，上面有若干颗花生，经过一株花生苗就能摘走该它上面所有的花生。Hello Kitty只能向东或向南走，不能向西或向北走。问Hello Kitty 最多能够摘到多少颗花生。  

如输入：  

```
`2 2  
1 1  
3 4  
`
```

代表有 $2$ 行，每行有 $2$ 株花生，那么摘能摘到的最多的花生就是：$1$->$3$->$4$ ，总和为 $8$ 颗花生。

## 输入

第一行是两个整数 $n$ 和 $m$ （ $1 \le n,m \le 100$ ），代表了花生地里有 $n$ 行，每行有 $m$ 列的花生！

后面 $n$ 行，每行有 $m$ 个整数代表了每行中，每株花生的数量！( 每株花生数量$ \le 10000$ )

## 输出

输出是一个整数，代表了最多能摘到的花生的总数；

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main() {
    int a[110][110];
    int n,m,i,j,x,y;
    cin >> n >> m;
    // 输入数组
    for(i = 1; i <= n; i++) {
        for(j = 1; j <= m; j++) {
            cin >> a[i][j];
        }
    }
    for(i = 1; i <= n; i++) {
        for(j = 1; j <= m; j++) {
            a[i][j] = a[i][j] + max(a[i - 1][j], a[i][j - 1]);
        }
    }
    cout << a[n][m] << endl;
}
```
