# 1240 - 念数字

## 题目描述

编一个“念数字”的程序。当你输入一个 $0 \sim 99$ 之间的数后，计算机就会用汉语拼音输出这个数的“念”法。

比如：$35$，念出来应该是：`san shi wu`，$16$ 念出来应该是`shi liu`，$0$ 念出来应该是 `ling`。

## 输入

一行，一个整数 $n$。($0 \le n \le 99$)

## 输出

输出这个整数的念法。
## AC代码

```cpp
#include <iostream>
using namespace std;

//函数：读出数字0~9
//由于函数的作用是直接“读出”也就是cout，因此函数不需要返回值
//返回值类型写void 
void fun(int n){
    switch(n) {
        case 0: cout<<"ling"; break;
        case 1: cout<<"yi"; break;
        case 2: cout<<"er"; break;
        case 3: cout<<"san"; break;
        case 4: cout<<"si"; break;
        case 5: cout<<"wu"; break;
        case 6: cout<<"liu"; break;
        case 7: cout<<"qi"; break;
        case 8: cout<<"ba"; break;
        case 9: cout<<"jiu"; break;
    }
}
 
int main(){
	int n;
	cin>>n;
	//一位数，直接读 
	if(n < 10) fun(n);
	else{
		//两位数，判断个位和十位
		int s = n / 10;
		int g = n % 10;
		//十位不为1，要读出来 
		if(s != 1){
			fun(s);
			cout<<" ";	
		}
		//shi必读 
		cout<<"shi";
		//个位不为0，要读出来
		if(g != 0){
			cout<<" ";
			fun(g);
		} 
	} 
	
	return 0;
}
```
