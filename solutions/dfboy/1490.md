# 1490 - 坐标排序

## 题目描述

输入 $n$ 个不同的坐标，按 $x$ 轴的值从小到大排序，如果 $x$ 相同，则按照 $y$ 排序。

## 输入

第 $1$ 行是一个整数 $n$（ $n≤10000$ ）。

接下来有 $n$ 行，每行有 $2$ 个整数，代表了 $1$ 个点的坐标。

## 输出

输出 $n$ 行，每行有 $2$ 个整数，输出排序后的 $n$ 个坐标。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    string s,s1,max;
    int p = 0,i;
    bool flag = false;
    getline(cin,s);
    s = s + " ";
    for(i = 0;i < s.size();i++) {
        if(s[i] != ' ') {
            s1 += s[i];
            if(s[i + 1] == ' ') {
                // cout << s1 << endl;
                if(s1.size() > max.size()) {
                    max = s1;
                }
                s1 = "";
            }
        }
    }
    cout << max << endl;
}
```
