# 1490 - 坐标排序

## 题目描述

输入 $n$ 个不同的坐标，按 $x$ 轴的值从小到大排序，如果 $x$ 相同，则按照 $y$ 排序。

## 输入

第 $1$ 行是一个整数 $n$（ $n≤10000$ ）。

接下来有 $n$ 行，每行有 $2$ 个整数，代表了 $1$ 个点的坐标。

## 输出

输出 $n$ 行，每行有 $2$ 个整数，输出排序后的 $n$ 个坐标。

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
#include <map>
using namespace std;

pair<int,int> a[10100];
int n,i,x,y;
int main() {
	cin >> n;
	for(i = 1;i <= n;i++) {
		cin >> x >> y;
		a[i] = make_pair(x, y);
	}
	sort(a + 1, a + n + 1);
	for(i = 1;i <= n;i++) {
		cout << a[i].first << " " << a[i].second << endl;
	}
}
```
