# 1971 - 大小写转换

## 题目描述

从键盘读入一个字母，可能是大写字母也可能是小写字母。

请判断一下如果是大写字母，输出其对应的小写字母，如果是小写字母，输出其对应的大写字母。

比如：'$a$' 对应的大写字母是 '$A$'，'$M$' 对应的小写字母是 '$m$' 。

## 输入

输出一个字母。

## 输出

如果输入是大写字母，输出对应的小写字母；如果输入是小写字母，输出对应的大写字母。
## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;

int main(){
    int x;
    char c;
    cin >> c;
    // 由于字符的本质是编码（整数），所以可以直接比较大小和计算
    if(c >= 'A' && c <= 'Z'){
        c = c + 32;
    } else if(c >= 'a' && c <= 'z'){
        c = c - 32;
    }
    cout<< c << endl;
}
```
