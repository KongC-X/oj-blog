# 1902 - 最少的修改次数

## 题目描述

现有整数 $A_1,A_2,...A_n$，修改最少的数字为实数（整数或者小数），使得数列严格单调递增。

## 输入

第一行，一个整数 $n$ 。（$n≤10^5$）

第二行，$n$ 个整数 $A_i$ 。（$A_i≤10^9$）

## 输出

$1$ 个整数，表示最少修改的数字的数量。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <map>
using namespace std;

int main() {
    int n;
    cin >> n;
    
    map<int, int> count_map;
    
    // 读取并统计数字出现次数
    for (int i = 0; i < n; i++) {
        int num;
        cin >> num;
        count_map[num]++;
    }
    
	map<int, int>::iterator it;
    // 输出结果（map已自动按key排序）
    for (it = count_map.begin(); it != count_map.end(); ++it) {
        cout << it->first << " " << it->second << endl;
    }
    
    return 0;
}
```
