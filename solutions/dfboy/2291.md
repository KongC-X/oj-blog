# 2291 - 交换输出

## 题目描述

输入两个整数 $a$ 、$b$ ，将他们交换输出。

## 输入

一行两个整数 $a$、$b$，以空格分隔。，$16$。

## 输出

一行两个整数 $b$、$a$ ，以空格分隔。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main(){
	int a;
	long long b;
	cin>>a>>b;
	cout<<b<<" "<<a;
	return 0;
}
```
