# 2291 - 交换输出

## 题目描述

输入两个整数 $a$ 、$b$ ，将他们交换输出。

## 输入

一行两个整数 $a$、$b$，以空格分隔。，$16$。

## 输出

一行两个整数 $b$、$a$ ，以空格分隔。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
#include<iostream>
using namespace std;

string st;
int n,a[251],l,k;

int main(){
  cin>> st >> n;
  l=st.size();
  
  // 转为整数
  for(int i=0;i<l;i++){
    a[i]=st[i]-'0';
  }

  // 第一层循环为删几次
  for(int i=1;i<=n;i++){
    // 第二层循环为删哪个数，优先删大的数
    for(int j=0;j<l;j++){
        if(a[j] > a[j+1]) {
          // 如果比后面的数大，则删掉
          for(int k=j;k<l;k++){
            a[k]=a[k+1];
          }
          l--;
          break;
      }
    }
  }
  int i=0;
  // 跳过前导0
  while(a[i] == 0 && k < l - 1){
    k++;
    i++;
  }
  // 从k（第一个非0数）开始输出
  for(int i = k;i<l;i++){
    cout<<a[i];
  }
  return 0;
}
```
