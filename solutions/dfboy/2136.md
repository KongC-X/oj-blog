# 2136 - 筛素数

## 题目描述

输入一个整数 $n$，请问 $1 \sim n$ 范围内有多少个素数？

## 输入

一个整数 $n$（$1 \le n \le 10^6$）

## 输出

输出 $n$ 范围内素数的个数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
a[i]==b[j],方程：dp[i-1][j-1]+1
a[i]!=b[j],方程：max(dp[i][j-1],dp[i-1][j])
*/
const int N = 1010;//常量，表示数组大小 
int a[N],b[N],dp[N][N];
int n,i,j; 

int main() {
	cin>>n;
	for(i = 1;i <= n;i++) cin>>a[i];
	for(i = 1;i <= n;i++) cin>>b[i];
	
	//递推
	for(i = 1;i <= n;i++){
		for(j = 1;j <= n;j++){
			if(a[i] == b[j]) dp[i][j] = dp[i-1][j-1] + 1;
			else dp[i][j] = max(dp[i-1][j],dp[i][j-1]);
		}
	} 
	
	cout<<dp[n][n];
	return 0;
}
```
