# 2136 - 筛素数

## 题目描述

输入一个整数 $n$，请问 $1 \sim n$ 范围内有多少个素数？

## 输入

一个整数 $n$（$1 \le n \le 10^6$）

## 输出

输出 $n$ 范围内素数的个数。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;
bool f[1000010]; // 标记素数，false表示素数，true表示合数
int k,n;
int main() {
    cin >> n;
    // 特判特殊的数
    f[0] = true;
    f[1] = true;
    k = n - 1; // 初始素数个数为n-1，因为1不是素数
    // 循环所有的数，逐个判断是否为素数
    for(int i = 2; i * i <= n; i++) {
        // 如果当前数是素数，则将其所有的倍数标记为合数
        if(!f[i]) {
            // 将i的倍数标记为合数
            for(int j = i * i; j <= n;j += i) {
                // 如果没有标记过
                if(!f[j]) {
                    f[j] = true;
                    k--; // 素数个数减⼀
                }
            }
        }
    }
    cout << k << endl;
}
```
