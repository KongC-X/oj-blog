# 1970 - 判断是什么字符

## 题目描述

从键盘读入一个字符，有可能是大写字母、小写字母、数字中的一种，请编程判断，该字符具体是什么字符，如果是大写字母请输出 `$upper$`，如果是小写字母请输出 `$lower$`，如果是数字请输出 `$digit$`。

## 输入

一个字符。

## 输出

按题意输出是哪种字符。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;

int main(){
    int x;
    char c;
    cin >> c;
    // 由于字符的本质是编码（整数），所以可以直接比较大小和计算
    if(c >= 'A' && c <= 'Z'){
        cout << "upper";
    } else if(c >= 'a' && c <= 'z'){
        cout << "lower";
    } else if(c >= '0' && c <= '9'){
        cout << "digit";
    }
}
```
