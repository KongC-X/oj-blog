# 1248 - 求数列的第n项的值是多少？

## 题目描述

请问如下数列 $1，2，2，3，3，3，4，4，4，4 \dots $ 请问这个数列的第 $n$ 项是多少？

## 输入

从键盘读入一个整数 $n$ ，代表要求的项数。

## 输出

一个整数 $n$ 代表该项的值是多少？

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;
int main() {
    int i = 1,y;
    double r,m;
    cin >> r >> m >> y;
    while(i <= y) {
        m *= (1 + r/100);
        i++;
    }
 	cout<<int(m)<<endl;
	return 0;
}
```
