# 1006 - 打印星号三角形

## 题目描述

打印星号三角形。

## 输入

输入只有一行，包括 $1$ 个整数 $n$ ， $n$ 代表行数。

## 输出

输出 $n$ 行。

## 解题思路

## AC代码

```cpp
#include<iostream>
using namespace std;

int main(){
	int m,a[105];
	cin>>m;
	for(int i=0; i <= m - 1; i++){
		cin>>a[i];
	} 
	for(int i=1; i <= m - 2; i++){
		if(a[i]>a[i-1]&&a[i]>a[i+1]){
			cout<<a[i]<<endl;
		}
	}
	return 0; 
}
```
