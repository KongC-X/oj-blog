# 1975 - 字母矩形2

## 题目描述

输入一个整数 $n$ ，打印 $n$ 行 $n$ 列的字母矩形。

比如，假设 $n=3$，那么打印 $3$ 行 $3$ 列的字母矩形如下：

```
`ABC
ABC
ABC
`
```

## 输入

一个整数（ $0 \lt n \lt 10$）

## 输出

$n$ 行 $n$ 列的字母矩形。
## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int i,j,n;
    char c;
    cin >> n;
    // 循环控制行数
    for(i = 1;i <= n;i++) {
        // 打印每一行的数字
        for(j = 1;j <= n;j++) {
            c = j + 64;
            cout << c;
        }
        // 打印每一行的换行符
        cout << endl;
    }
}
```
