# 2029 - 缺失的数字

## 题目描述

有 $n$ 个数字，值就是 $1$ ~ $n$ ，现发现丢失了 $2$ 个数字，请你根据剩余的 $n$ - $2$ 个数字，编程计算一下，缺失的是哪两个数字呢？

## 输入

第 $1$ 行为整数 $N$ ($N \le 100000$)。

第 $2$ 行有 $N-2$ 个整数(均用空格隔开)表示了剩下 $N-2$ 个数字的值。

## 输出

一行，按数字从小到大顺序输出两缺失的数字。两个数字之间用一个空格隔开。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
    int n,i,sum=0,y=0,b,s,g;
    cin>>n;
    //遍历100到n的所有三位数 
    for(i=100;i<=n;i++){
        b=i/100;
        s=i/10%10;
        g=i%10;
        //连续递增或者连续递减
        if((b<s&&s<g)||(b>s&&s>g)){
            sum=sum+i;
            y++;
        }
    }
    cout<<sum<<endl<<y;
	return 0;
}
```
