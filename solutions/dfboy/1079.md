# 1079 - 三角形的个数

## 题目描述

从键盘输入整数 $L$，统计出边长为整数，周长为 $L$ 的不是等边三角形的个数。

## 输入

整数 $L$ ( $3 \le L \le 32767$ )。

## 输出

三角形个数。
## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
	int l,a,b,c,s=0;//s作为三角形的个数 
    cin>>l;
    //a最长为L/3 //b>=a 
    for(a = 1;a <= l / 3;a++){
        for(b=a;b <= (l - a) / 2;b++){
        	//第三条边的长度 
            c = l - a - b;
            // 如果两边之和大于第三边,且不是等边三角形,个数加1 
            if(a+b>c&&(a!=b||b!=c||a!=c)){
                s++;
            }
        }
    } 
    cout<<s;
	return 0;
}
```
