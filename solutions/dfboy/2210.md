# 2210 - 选数

## 题目描述

已知n（1<=n<=20）个整数x1,x2,…,xn（1<=xi<=5000000），以及一个整数k（k<n）。从n个整数中任选k个整数相加，可分别得到一系列的和。现在，要求你计算出和为素数共有多少种。

例如当 n=4，k=3，4 个整数分别为 3,7,12,19 时，可得全部的组合与它们的和为：

3+7+12=22

3+7+19=29

7+12+19=38

3+12+19=34

现在，要求你计算出和为素数共有多少种。

例如上例，只有一种的和为素数：3+7+19=29。

## 输入

第一行两个空格隔开的整数 n,k（1≤n≤20，k<n）。 

第二行 n 个整数，分别为x1,x2...xn（1≤xi≤5*106）

## 输出

输出一个整数，表示种类数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 定义二维的vector
// vector<vector<int> > a(100100);
// 定义vector类型的数组，数组中的每个元素都是一个vector
vector<int> a[100100];
int n,m,i,j,x,y;
int main() {
	cin >> n >> m;
	// 读入m组指令
	for(i = 0;i < m;i++) {
		cin >> x >> y; // 向第x个数组中，存入元素y
		a[x-1].push_back(y);
	}
	// 输出每个数组中的元素
	for(i = 0;i < n;i++) {
	    cout << a[i].size() << " ";
		sort(a[i].begin(), a[i].end()); // 对每个数组进行排序
		for(j = 0;j < a[i].size();j++) {
			cout << a[i][j] << " "; // 输出每个数组中的元素
		}
		cout << endl;
	}
}
```
