# 1666 - 表达式求值

## 题目描述

给定一个只包含加法和乘法的算术表达式，请你编程计算表达式的值。

## 输入

一行，为需要你计算的表达式，表达式中只包含数字、加法运算符 “$+$” 和乘法运算符 “$ \times $”，且没有括号，所有参与运算的数字均为 $0$ 到   $2^{31}-1$ 之间的整数。  

输入数据保证这一行只有 $ 0-9$、$+$、$ \times $ 这 $12 $种字符。

## 输出

一个整数，表示这个表达式的值。  

注意：当答案长度多于 $4$ 位时，请只输出最后 $4$ 位，前导 $0$ 不输出。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 写一个函数，用来将字符数组转成整数输出
long long charToLongLong(char s[]) {
    int i = 0;
    long long sum = 0;
    while(s[i] != '\0') {
        // 这里要注意s[i] - '0'
        sum = sum * 10 + (s[i] - '0');
        i++;
    }
    return sum;
}

int main() {
    char s[30],a[30],b[30];
    int i,p,k = 0;
    long long ans;
    cin >> s;
    // 找到*的位置，用来分割两个数
    for(i = 0;i < strlen(s);i++) {
        if(s[i] == '*') {
            p = i;
            break;
        }
    }
    // 第一个数
    for(i = 0;i < p;i++) {
        a[i] = s[i];
    }
    a[p] = '\0';
    // 第二个数,从p+1开始，strlen(s) - 1结束,因为不能算=
    for(i = p + 1;i < strlen(s) - 1;i++) {
        b[k] = s[i];
        k++;
    }
    b[k] = '\0';
    // cout << a << " " << b << endl;
    ans = charToLongLong(a) * charToLongLong(b);
    cout << ans << endl;
}
```
