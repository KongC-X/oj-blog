# 1762 - 数字查询

## 题目描述

有 $n$ 个同学，每个同学的名字用一个英文小写字母的字符串表示，**所有同学名字互不相同**，并为每个同学分配一个数字。

给出 $q$ 次询问，每次询问给出一个同学的名字，请求出该同学分配到的数字是多少？

## 输入

第 $1$ 行 $n$ ，$q$ 。

接下来 $n$ 行，每行有一个英文字母构成的字符串，以及一个数字，中间用空格隔开；

接下来 $q$ 行，每行一次询问，代表一个同学的名字。

## 输出

输出 $q$ 行，每行输出询问同学名字对应的数字。
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int n,p;
double h;
map<string,int> a;
string b;
int main()
{
	cin>>n>>p;
	for(int i=1;i<=n;i++)
	{
		cin>>b>>h;
		a[b]=h;
	}
	for(int i=1;i<=p;i++)
	{
		cin>>b;
		cout<<a[b]<<endl;
	}
	return 0;
}
```
