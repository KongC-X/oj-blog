# 1225 - 打印空心等腰三角形

## 题目描述

从键盘读入一个整数 $n$ ，代表等腰三角形的边长，请输出一个边长为 $n$ 的等腰三角形！

为了方便观察，我们在例子中将空格替换成□，将`*`替换为`×`，请在程序中正常输出空格和`*`！

如：$n=3$ 则输出

```
`□□×
□×□×
×××××
`
```

$n=5$ 则输出：

```
`□□□□×
□□□×□×
□□×□□□×
□×□□□□□×
×××××××××
`
```

## 输入

整数 $n（n \le 9）$

## 输出

按题意输出图形。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

// 拆位求和
int num(int n) {
    int sum = 0;
    while(n) {
        sum += n % 10;
        n /= 10;
    }
    return sum;
}

// 判断一个数是质数
bool isPrime(int n) {
    if(n < 2) {
        return false;
    }
    for(int i = 2;i <= sqrt(n);i++) {
        if(n % i == 0) {
            return true;
        }
    }
    return false;
}

int main() {
    int n,j,k,i,t = 0,s1,s2;
    cin >> n;
    for(j = 4;j <= n;j++) {
        if(!isPrime(j)) {
            continue;
        }
        s1 = 0; // 数字和
        s2 = 0; // 因子数字和
        i = 2; // 从2开始找j的因⼦
        k = j; // 保存j的值
        s1 = num(k);
        // cout << "s1:" << s1 << endl;
        while(k != 1) {
            // 如果i是j的因⼦
            if(k % i == 0) {
                s2 += num(i);
                k = k / i;
            } else {
                i++; // 看下⼀个数
            }
        }
        // cout << "s2:" << s2 << endl;
        if(s1 == s2) {
            cout << j << " ";
            t++; // 计数
            if(t % 5 == 0) {
                cout << endl;
            }
        }
    }
}
```
