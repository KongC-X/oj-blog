# 1788 - 字符图形-数字正三角（3）

## 题目描述

输入一个整数打印数字图形。

## 输入

一个整数（）。

## 输出

一个数字图形。
## AC代码
## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int i,j,n;
    cin >> n;
    for(i = 1;i <= n;i++) {
        // 每行输出i-1个空格
        for(j = 1;j <= i - 1;j++) {
            cout << " ";
        }
        // 每行输出2*(n-i)+1个数
        for(j = 1;j <= 2 * (n - i) + 1;j++) {
            cout << n - i + 1;
        }
        cout << endl;
    }
}
```
