# 1155 - 找找谁的身高超过全家的平均身高

## 题目描述

找找谁的身高超过全家的平均身高。

全家 $n$ 口人，输入输出数据如下： (平均身高保留一位小数)。

## 输入

第一行有一个整数 $n$ (  )；

第二行是 $n$ 个整数，用空格隔开。

## 输出

第一行为全家的平均身高（保留一位小数）；

第二行有若干个数，为超过平均身高的人的身高厘米数。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

//定义数组长度要比题目需要的多定义10个 
//将变量定义到main的外面
//初始值不是随机，整数初始值都是0 
int a[20];
int n,i,s = 0; 
double v;//存放平均值 

int main() {
	cin>>n;
	for(i = 0;i < n;i++){
		cin>>a[i];
		//求和
		s = s + a[i]; 
	} 
	//平均 
	v = s * 1.0 / n; 
	
	cout<<"AVE="<<fixed<<setprecision(1)<<v<<endl; 
	
	//求哪些人的身高超过平均身高
	for(i = 0;i < n;i++){
		if(a[i] > v){
			cout<<i+1<<":"<<a[i]<<" ";
		}
	} 
	return 0;
}
```
