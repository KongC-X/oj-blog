# 1625 - 谁的年龄大

## 题目描述

甲乙两个人在公园相遇，甲说我今年 $n$ 岁了（ $n$ 是一个两位的整数，个位和十位不相等），乙说，太巧了，你的年龄倒过来，就是我的年龄，请问两个人谁的年龄更大， 请输出那个更大的年龄？

比如，假设甲今年 $12$ 岁，那么乙就是 $21$ 岁，乙的年龄更大，应当输出乙的年龄 $21$ 岁。

## 输入

输入一个整数 $n$ ，代表甲的年龄。

## 输出

输出两个人年龄的较大值。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int n,a[110][110],ma;

// 深搜：从(1,1)开始，每次向下或向右走，求出所有路径和的最大值
void dfs(int x,int y,int sum) {
    ma = max(sum,ma);
    // 递归出口：当x > n时，说明已经遍历完所有点
    if(x <= n) {
        // cout << x << " " << y << " " << sum << endl;
        // 递归走：x+1,y 和 x+1,y+1
        dfs(x+1,y,sum+a[x+1][y]);
        dfs(x+1,y+1,sum+a[x+1][y+1]);
    }
}

int main() {
    cin >> n;
    int i,j;
    for(i = 1;i <= n;i++) {
        for(j = 1;j <= i;j++) {
            cin >> a[i][j];
        }
    }
    dfs(1,1,a[1][1]);
    cout << ma << endl;
}

// 当层级过深时，深搜递归会有大量数据重复计算导致运行超时
```
