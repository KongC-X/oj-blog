# 1830 - 算面积2

## 题目描述

$gsh$给了你 $N$ 个正方形，请你算出这 $N$ 个正方形的面积和。

## 输入

第一行一个 $N$ 。 （$N \le 100$）

下面 $N$ 行，每行一个整数表示一个正方形的边长。

## 输出

一个整数，表示面积和。

## 解题思路

## AC代码

```cpp
# include<bits/stdc++.h>
using namespace std;

/*
思路：
1.小T的年龄是a[t1][t2]
2.统计出第x行有多少个值是a[t1][t2]
  第y列有多少个值是a[t1][t2]
  答案 = 统计出来的总数 - 2（包括了2次自己） 
*/ 

int main() {
	int a[210][210];
	int i,j,n,m,t1,t2,sum = 0; 
	cin>>n>>m;
	for(i = 1;i <= n;i++){
		for(j = 1;j <= m;j++){
			cin>>a[i][j];
		}
	}
	//读入小t的位置 
	cin>>t1>>t2;
	//循环第t1行（本质上是循环m列的每个数） 
	//为了好理解，我们用j来循环列 
	for(j = 1;j <= m;j++){
		if(a[t1][j] == a[t1][t2]){
			sum++;
		}
	}
	//循环第t2列（本质上是循环n行的每个数）
	for(i = 1;i <= n;i++){
		if(a[i][t2] == a[t1][t2]){
			sum++;
		}
	} 
	cout<<sum - 2 << endl;
}
```
