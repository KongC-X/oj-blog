# 1830 - 算面积2

## 题目描述

$gsh$给了你 $N$ 个正方形，请你算出这 $N$ 个正方形的面积和。

## 输入

第一行一个 $N$ 。 （$N \le 100$）

下面 $N$ 行，每行一个整数表示一个正方形的边长。

## 输出

一个整数，表示面积和。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[101];
int main()
{
    int n,sum = 0;
    cin >> n;
    for(int i = 1;i <= n;i++)
    {
        cin >> a[i];
        sum += a[i] * a[i];
    }
    cout << sum << endl;
    return 0;
}
```
