# 2350 - 奇偶判断

## 题目描述

【具体要求】

在键盘中输入 $n$ 个正整数 $a_1, a_2, a_3, ... a_n$ （$0 \le a_i \le 100$)，判断每个正整数是奇数还是偶数，如果是奇数则用 $1$ 表示，如果是偶数则用 $0$ 表示，$N$ 个正整数判断后从最后一位开始倒置输出结果。

## 输入

输入共两行，第一行输入一个正整数 $n$ （$1 \lt n \le 100$）

## 输出

倒置输出每个正整数的奇偶性，奇数用 $1$ 表示，偶数用 $0$ 表示，数字之间用空格隔开。

## 解题思路

## AC代码

```cpp
#include<iostream>
#include<cmath>
using namespace std;
int a[1010];
bool sushu(int n){  //判断素数函数 
	bool f = true;
	for(int i = 2;i <= sqrt(n);i++){
		if(n % i == 0){
			f = false;
			break;
		}
	} 
	//判断特殊情况
	if(n <= 1) f = false; 
	return f;
} 

int main() {
	int k=0;
	for(int i=10;i<=1000;i++){
		if(sushu(i)==true){
			a[k]=i;
			k++;
		}
	}
	for(int i=0;i<k;i++){
		if(a[i]>=10&&a[i]<=99){
			if(a[i]/10==a[i]%10){
				cout<<a[i]<<endl;
			}
		}else{
			if(a[i]/100==a[i]%10){
				cout<<a[i]<<endl;
			}	
		}
	}
	
}
```
