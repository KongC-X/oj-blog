# 2076 - 环游世界之背包问题

## 题目描述

张老师准备环游世界，出发之前要做的最重要的事情，当然是整理自己的背包啦。张老师有一个容积为m的背包 ，有n个物品作为放入背包的待选物品 ，每样东西都有自己的价值Wi，和体积Vi ，第i个物品有Ni个 （Ni=0时表示有无限多个），请你编程帮助张老师计算，他的背包能够存入的最大价值是多少？

$30\%$数据满足  1 <= m,n <=1000

$100\%$数据满足  1 <=m,n <= 10000

## 输入

第$1$行有$2$个整数$N,M$，表示物品的种类和背包的容积；

第$2-N+1$行，每行有$3$个整数$Vi$，$Wi$，$Pi$，分别表示每个物品的体积，价值，个数。（体积<=5000,价值<=5000,个数<=1000）

## 输出

一个整数，表示能够存入背包的最大价值。

```cpp
#include <iostream>
#include <vector>
#include <algorithm>
using namespace std;

int main() {
    int n, m;
    cin >> n >> m;
    
    // dp[i]表示容积为i时的最大价值
    vector<int> dp(m + 1, 0);
    
    for (int i = 0; i < n; i++) {
        int v, w, p;
        cin >> v >> w >> p;
        
        if (p == 0) {  // 完全背包：无限个物品
            // 正序遍历，可以重复使用同一物品
            for (int j = v; j <= m; j++) {
                dp[j] = max(dp[j], dp[j - v] + w);
            }
        }
        else if (p == 1) {  // 01背包：只有1个物品
            // 逆序遍历，确保每个物品只用一次
            for (int j = m; j >= v; j--) {
                dp[j] = max(dp[j], dp[j - v] + w);
            }
        }
        else {  // 多重背包：有p个物品
            // 使用二进制优化的多重背包
            int k = 1;
            while (k <= p) {
                // 将k个物品看作一个整体
                int vol = k * v;
                int val = k * w;
                
                // 如果超出背包容量，跳出
                if (vol > m) {
                    break;
                }
                
                // 01背包方式处理这个"物品包"
                for (int j = m; j >= vol; j--) {
                    dp[j] = max(dp[j], dp[j - vol] + val);
                }
                
                p -= k;
                k *= 2;
            }
            
            // 处理剩余的物品
            if (p > 0) {
                int vol = p * v;
                int val = p * w;
                if (vol <= m) {
                    for (int j = m; j >= vol; j--) {
                        dp[j] = max(dp[j], dp[j - vol] + val);
                    }
                }
            }
        }
    }
    
    cout << dp[m] << endl;
    
    return 0;
}
```
