# 1643 - 行李托运费

## 题目描述

乘坐飞机时，当乘客行李小于等于 $20 $公斤时，按每公斤 $1.68$ 元收费，大于 $20$ 公斤时，按每公斤 $1.98 $元收费，编程计算收费(保留 $2$ 位小数)。

## 输入

一个数，表示行李重量（单位：公斤）。

## 输出

行李托运费，保留 $2$ 位小数。

## 解题思路

## AC代码

```cpp
有的时候用cin可能刚好会超时，这个时候使用scanf会提高算法的效率
cin 和 scanf 在性能上有一定差异。在 C++ 中，cin 是类型安全的输入流，使用起来方便，但在处理大量输入时，它的性能可能会受到影响，尤其是在需要频繁读取输入的情况下。相比之下，scanf 是 C 语言的输入函数，通常在处理大量数据时效率更高，因为它直接读取输入而不进行类型检查和格式化。
如果你在比赛或需要优化输入输出性能的场景下，可以考虑使用 scanf。
此外，还可以通过以下方法进一步提高 cin 的性能：
	取消同步：使用 ios::sync_with_stdio(false); 可以使 cin 和 printf 不再同步，从而提高性能。
	使用 cin.tie(0)：解除 cin 和 cout 的绑定，避免不必要的刷新。
```
