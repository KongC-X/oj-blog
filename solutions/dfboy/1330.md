# 1330 - 求最大梯形的面积

## 题目描述

从键盘读入 $n$ ( $3 \le n \le 100$ )个梯形的上底、下底和高，请问这 $n$ 个梯形中，最大面积的梯形的面积是多少？（梯形面积的求解公式为 $S = (a + b) \times  h / 2$ ，也就是 (上底 $+$ 下底) $\times $ 高 $/ 2$ ）

（ $5.1.18$ ）

## 输入

第 $1$ 行为 $1$ 个整数 $n$ ，接下来 $n$ 行每行 $3$ 个整数分别代表梯形的上底、下底和高。

## 输出

最大面积梯形的面积（结果保留 $1$ 位小数）
