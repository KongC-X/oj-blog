# 1191 - 对角线II

## 题目描述

输入整数 $N$ ，输出相应方阵。

## 输入

一个整数 $N$ 。（ $0 \lt N \le 10$ )

## 输出

一个方阵，每个数字的场宽为 $3$ 。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

/*
 遍历每个字符，判断如果是字符'1'则计数 
*/
int main() {
	string s;
	cin>>s;
	int c = 0;
	for(int i = 0;i < s.size();i++){
		if(s[i] == '1') c++;
	}
	cout<<c;
	return 0;
}
```
