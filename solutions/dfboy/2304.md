# 2304 - Minecraft

## 题目描述

Minecraft是一个几乎无所不能的沙盒世界，玩家可以利用游戏内的各种资源进行创造，搭建自己的世界。

在Minecraft中，基本的建筑元素是边长为1个单位的立方体，小明想用N个这种小立方体搭建一个长方体，并用他珍藏已久的贴纸对其进行装饰。如果一张贴纸可以贴满小立方体的一个面。那么，他需要用掉多少张贴纸呢？

## 输入

一个整数N，表示小明所拥有的小立方体的个数。N不会超过1000。

## 输出

一个整数。即小明最少用掉的贴纸有多少张

## 解题思路

## AC代码
## AC代码

```cpp
#include <iostream>
#include <climits>
using namespace std;

int main() {
    int N;
    cin >> N;
    int min_stickers = INT_MAX;

    for (int a = 1; a <= N; ++a) {
        if (N % a != 0) continue;
        for (int b = 1; b <= N / a; ++b) {
            if ((N / a) % b != 0) continue;
            int c = N / a / b;
            int stickers = 2 * (a * b + a * c + b * c);
            if (stickers < min_stickers) {
                min_stickers = stickers;
            }
        }
    }

    cout << min_stickers << endl;
    return 0;
}
```
