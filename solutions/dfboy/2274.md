# 2274 - 小球放盒子

## 题目描述

有 $N$ 个相同的球，$M$ 个不同的盒子，每个盒子最多放 $K$ 个球。

请计算将这 $N$ 个球全部放入盒子中的方案数模 $1000007$ 后的结果。

## 输入

三个正整数，依次为 $N$，$M$，$K$。

## 输出

输出方案数模 $1000007$ 后的结果。
## AC代码

```cpp
#include<bits/stdc++.h>

using namespace std;

const int MAXN=5e3+10;
const int MOD=1000007;
int N,M,K;
int ways[MAXN][MAXN];
///前m个盒子放入n个球的放法
int main()
{
	scanf("%d %d %d",&N,&M,&K);
	ways[0][0]=1;
	for(int i=1;i<=M;i++){
		ways[i][0]=1;
		ways[0][i]=0;
	}
	for(int m=1;m<=M;m++){
		int sum=m;
		for(int n=1;n<=N;n++){
			ways[m][n]=sum;
			sum=(sum+ways[m-1][n+1])%MOD;
			if(n-K>=0)sum=(sum-ways[m-1][n-K]+MOD)%MOD;
		}
	}
	printf("%d\n",ways[M][N]);
	return 0;
}
```
