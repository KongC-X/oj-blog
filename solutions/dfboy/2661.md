# 2661 - 差为给定的数

## 题目描述

给定一组整数，再另外给定一个整数 $T$，请编程计算出，这组整数中，两数之差为 $T$ 的数对，有多少组？

请注意：不同位置的数字一样的数对算不同的数对。

## 输入

输入共两行。

第一行，两个整数 $N, T$。

第二行，$N$ 个整数，用空格隔开。

## 输出

一个整数，表示数组中包含的满足 $A - B = T$ 的数对的个数。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;

int max(int a, int b) {
    return a > b ? a : b;
}

int main() {
    int m,n,max_num;
    cin >> m >> n;
    max_num = max(m,n);
    cout << max_num << endl;
}
```
