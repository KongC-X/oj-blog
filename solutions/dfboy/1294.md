# 1294 - 二进制转十六进制

## 题目描述

请将一个**不超过 $100$ 位**的二进制数转换为十六进制数！

## 输入

一个不超过 $100$ 位的二进制整数。

## 输出

该数对应的十六进制数。
## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 将四位的二进制转换为1位的十六进制
char num(string s) {
    // 1101，从最低位开始展开，先转换为10进制
    // 再转换为16进制
    int n,x = 0;
    for(int i = s.size() - 1; i >= 0; i--) {
        n = (s[i] - '0') * pow(2, s.size() - 1 - i);
        x += n;
    }
    char c;
    if(x >= 10) {
        c = x - 10 + 'A';
    } else {
        c = x + '0';
    }
    return c;
}

int main(){
    string s;
    cin >> s;
    // 补0
    if(s.size() % 4 == 1) {
        s = "000" + s;
    } else if(s.size() % 4 == 2) {
        s = "00" + s;
    } else if(s.size() % 4 == 3) {
        s = "0" + s;
    }
    // 四位截取输出对应的十六进制
    for(int i = 0;i < s.size();i += 4) {
        cout << num(s.substr(i, 4));
    }
}
```
