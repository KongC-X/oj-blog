# 1722 - 输出两位的巧数

## 题目描述

巧数指的是这样一种特殊的数，该数的各个位数字之和加上各个位数字之积等于本身的自然数。

比如整数 $19$ ，就是一个巧数，因为 $(1+9)+(1 \times 9) = 10 + 9 =19$。

请编程输出所有 $2$ 位的巧数。

## 输入

无。

## 输出

由小到大输出所有的 $2$ 位巧数，每行 $1$ 个。

## 解题思路

## AC代码
## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int i = 10,a,b;
    while(i < 100) {
        a = i / 10;
        b = i % 10;
        if(a + b + (a * b) == i) {
            cout << i << endl;
        }
        i++;
    }
}
```
