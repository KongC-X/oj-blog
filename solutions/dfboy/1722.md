# 1722 - 输出两位的巧数

## 题目描述

巧数指的是这样一种特殊的数，该数的各个位数字之和加上各个位数字之积等于本身的自然数。

比如整数 $19$ ，就是一个巧数，因为 $(1+9)+(1 \times 9) = 10 + 9 =19$。

请编程输出所有 $2$ 位的巧数。

## 输入

无。

## 输出

由小到大输出所有的 $2$ 位巧数，每行 $1$ 个。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
a[i]==b[j],方程：dp[i-1][j-1]+1
a[i]!=b[j],方程：max(dp[i][j-1],dp[i-1][j])
*/
const int N = 1010;//常量，表示数组大小 
int a[N],b[N],dp[N][N];
int n,i,j; 

int main() {
	cin>>n;
	for(i = 1;i <= n;i++) cin>>a[i];
	for(i = 1;i <= n;i++) cin>>b[i];
	
	//递推
	for(i = 1;i <= n;i++){
		for(j = 1;j <= n;j++){
			if(a[i] == b[j]) dp[i][j] = dp[i-1][j-1] + 1;
			else dp[i][j] = max(dp[i-1][j],dp[i][j-1]);
		}
	} 
	
	cout<<dp[n][n];
	return 0;
}
```
