# 2172 - 树的直径

## 题目描述

树的直径指的是，树中两点之间的最长路径。现给定一棵树的数据，请问该树的直径的是多少？

比如，如图所示的树，直径应该是 $3-2-5-6$，路径长度为 $3$。

## 输入

第 $1$ 行有一个整数 $n$，代表结点的数量，结点的编号为 $1 \sim n$。（$n≤100$） 

接下来有 $n-1$ 行，每行有 $2$ 个整数 $x,y$，表示结点 $x$ 和 $y$ 之间有一条边。（不保证 $x$ 是 $y$ 的父）

## 输出

输出一个整数 $n$ 代表树的直径。
## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// dfs 求树的直径:
// 利用了树的直径的性质: 树的直径等于树的两个节点之间的最大距离。
// 对树上的任意一个点，与之距离最远的点一定是树的直径的一个端点。
// 根据这个性质，我们可以通过两次 DFS 来求出树的直径。
// 1. 先求出离根节点 1 最远的节点 x
// 2. 以x为根节点，求出离节点 x 最远的节点 y
// 3. 输出节点 x 和 y 之间的距离，即树的直径

int a[110][110]; // 邻接矩阵
int fa[110]; // fa[i] 表示节点 i 的父节点
int dep[110]; // dep[i] 表示节点 i 的深度
int n,x,y;

// 深度优先搜索
void dfs(int x,int f) {
    fa[x] = f; // 记录父节点
    dep[x] = dep[f] + 1; // 计算当前节点的深度
    // 遍历所有节点，寻找与当前节点 x 相邻且不是父节点 f 的节点
    for(int i=1;i<=n;i++){
        if(a[x][i] && i!=f){
            dfs(i,x); // 递归访问相邻节点
        }
    }
}

int main() {
    cin >> n;
    // 读入 n-1 条边，构建邻接矩阵
    for(int i=1;i<n;i++){
        cin >> x >> y;
        a[x][y] = 1;
        a[y][x] = 1;
    }
    dfs(1,0); // 从节点 1 开始 DFS，父节点为 0
    // 求出离根节点 1 最远的节点 x
    x = 1;
    for(int i = 2;i <= n; i++) {
        if(dep[i] > dep[x]) {
            x = i;
        }
    }
    // 以x为根节点，求出离节点 x 最远的节点 y
    dfs(x,0); // 从节点 x 开始 DFS，父节点为 0
    y = 1;
    for(int i = 2;i <= n; i++) {
        if(dep[i] > dep[y]) {
            y = i;
        }
    }
    // cout << x << " " << y << endl; // 输出节点 x 和 y
    cout << dep[y] - 1 << endl; // 输出节点 x 和 y 之间的距离，即树的直径，减去 1 是因为树的直径是节点之间的距离，而不是边数
}
```
