# 1632 - 需要几辆车

## 题目描述

学校有 $n$ 位同学要外出旅游，一辆大巴车可以坐 $30$ 人，请问需要几辆大巴车？

## 输入

一个整数 $n$，代表同学的总人数。

## 输出

一个整数，代表需要大巴车的数量。

## 解题思路

## AC代码

```cpp
#include<iostream>
#include<iomanip>
using namespace std;
int a[110],n;
double s=0;

int main() {
	cin>>n;
	for(int i=0; i<n; i++) {
		cin>>a[i];
	}
    int max = a[0];
    for(int i=0; i<n; i++) {
		if(a[i]>max) {
            max = a[i];
        }
        s += a[i];
	}
	//(总和-最贵的书价+最贵的书价*0.9)*0.9
    s = (s-max+max*0.9) * 0.9;
	cout<< fixed << setprecision(1) << s << endl;

}
```
