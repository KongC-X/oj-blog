# 1632 - 需要几辆车

## 题目描述

学校有 $n$ 位同学要外出旅游，一辆大巴车可以坐 $30$ 人，请问需要几辆大巴车？

## 输入

一个整数 $n$，代表同学的总人数。

## 输出

一个整数，代表需要大巴车的数量。

## 解题思路

## AC代码
## AC代码

```cpp
#include <iostream>
using namespace std;
 
int main(){
    int n,m;
    cin>>n;
    if (n % 30==0){
        m=n/30;
    }else{
        m=n/30+1;
    }
    cout<<m;
}
```
