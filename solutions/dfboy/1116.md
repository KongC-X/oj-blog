# 1116 - 调换位置

## 题目描述

将用逗号隔开的两个英语单词交换位置输出。

## 输入

一行以逗号隔开的两个英文单词。（字符串长度不超过 $100$）

## 输出

将两个单词交换后输出的结果。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	char a[2000],b[2000];
	int i,n,z;
	cin>>a;
	z=0;
	n=0;
	for(i=0;i<strlen(a);i++){
		if(a[i]==','){
			z=i;
			break;
		}
	}
	for(i=z+1;i<strlen(a);i++){
		b[n]=a[i];
		n++;
	}
	b[n]=',';
	n++;
	for(i=0;i<z;i++){
		b[n]=a[i];
		n++;
	}
	b[n]='\0';
	cout<<b;
	return 0;
}
```
