# 1212 - 移动数组元素

## 题目描述

在一个不重复的数组中，请将这个数组的最小数和数组第一个数交换，最大数和数组最后一个数交换。

## 输入

第一行有一个整数 $n$ ( $5  \le  n  \le  100$ ）；

 第二行有 $n$ 个不重复的整数。

## 输出

移动位置后的数组。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
#include<iostream>
using namespace std;

// 倒序
bool cmp(int a, int b){
    return a > b ? true : false;
}

int a[10010],b[10010];
int n,sum;

int main(){
	cin >> n;
	for(int i=1; i<=n; i++){
		cin >> a[i];
	}
	for(int i=1; i<=n; i++){
		cin >> b[i];
	}
	
	sort(a+1, a+1+n);
	sort(b+1, b+1+n, cmp);

	for(int i=1; i<=n; i++){
		sum += abs(a[i] - b[i]);
	}	
	cout << sum;
}
```
