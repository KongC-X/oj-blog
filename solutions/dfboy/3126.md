# 3126 - 由中根序列和先根序列重建二叉树

## 题目描述

给定一棵二叉树的中序遍历和先序遍历，重建该二叉树并输出后序遍历。

## 输入

第一行输入一个整数 $n$ ，表示二叉树的节点数。

第二行输入 $n$ 个整数，表示二叉树的先序遍历序列。

第三行输入 $n$ 个整数，表示二叉树的中序遍历序列。

## 输出

输出一行 $n$ 个整数，表示重建二叉树后的后序遍历序列。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 有n个数，可以删除连续的k个数
// 求剩余任务时间和的最小值相当于求连续删除的k个数的和的最大值
int n,k;
const int N = 1000010;
typedef long long LL;
LL a[N],b[N],ma;
int main() {
    scanf("%d%d",&n,&k);
    for(int i = 1;i <= n;i++) {
        scanf("%d",&a[i]);
        b[i] = b[i - 1] + a[i]; // 求前缀和
    }
    // 求从每个数开始连续k个数的和，在所有的和中求最大值
    for(int i = 1;i <= n - k + 1;i++) {
        // 区间范围：i ~ i + k - 1
        ma = max(ma,b[i + k - 1] - b[i - 1]);
    }
    // 求剩余任务时间和的最小值
    cout << b[n] - ma << endl;
}
```
