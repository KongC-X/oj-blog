# 1108 - 正整数N转换成一个二进制数

## 题目描述

输入一个不大于 $32767$ 的整数 $n$ ，将它转换成一个二进制数。

## 输入

输入只有一行，包括一个整数 $n$ ($0 \le n \le 32767$)。

## 输出

输出只有一行。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	string s;
	int n,x;
	char c;
	cin>>n;
	if(n==0){
		cout<<'0';
	}
	else{
	
	while(n!=0){
		x=n%2;
		c=x+'0';
		s=c+s;
		n=n/2;
	 }
	 cout<<s;
	}
}
```
