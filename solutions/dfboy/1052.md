# 1052 - 行李托运费

## 题目描述

车站行李托运费标准是： $10$ 千克或 $10$ 千克以下，每千克收费 $1.5$ 元，超过 $10$ 千克的行李，按每超过 $1$ 千克 $2.5$ 元进行收费。

试编一程序，输入行李的托运费，算出行李的重量。

## 输入

读入一个小数，表示行李的托运费。

## 输出

一个小数，即行李的重量，保留两位小数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 将四位的二进制转换为1位的十六进制
char num(string s) {
    // 1101，从最低位开始展开，先转换为10进制
    // 再转换为16进制
    int n,x = 0;
    for(int i = s.size() - 1; i >= 0; i--) {
        n = (s[i] - '0') * pow(2, s.size() - 1 - i);
        x += n;
    }
    char c;
    if(x >= 10) {
        c = x - 10 + 'A';
    } else {
        c = x + '0';
    }
    return c;
}

int main(){
    string s;
    cin >> s;
    // 补0
    if(s.size() % 4 == 1) {
        s = "000" + s;
    } else if(s.size() % 4 == 2) {
        s = "00" + s;
    } else if(s.size() % 4 == 3) {
        s = "0" + s;
    }
    // 四位截取输出对应的十六进制
    for(int i = 0;i < s.size();i += 4) {
        cout << num(s.substr(i, 4));
    }
}
```
