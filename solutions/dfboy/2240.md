# 2240 - 和为给定数

## 题目描述

给出若干个整数，询问其中是否有一对不同位置上数的和等于给定的数。

## 输入

共三行： 第一行是整数 $n$ ($0 \lt n \le 100,000$)，表示有 $n$个整数。

第二行是 $n$ 个整数。整数的范围是在 $0$ 到 $10$$8$ 之间。

第三行是一个整数 $m$（$0 \le m \le 2^{30}$)，表示需要得到的和。

## 输出

若存在和为 $m$ 的数对，输出两个整数，小的在前，大的在后，中间用单个空格隔开。

若有多个数对满足条件，选择数对中较小的数更小的。若找不到符合要求的数对，输出一行 `No`。

```cpp
#include <bits/stdc++.h>
using namespace std;

int a[100010],n,m;

int main(){
  cin>>n;
  for(int i = 1;i <= n;i++){
    cin>>a[i];
  }
  cin>>m;
  
  sort(a+1,a+n+1);
  
  int l = 1,r = n;//l从前向后找，r从后向前找
  while(l < r){
    if(a[l] + a[r] > m) r--;
    else if(a[l] + a[r] < m) l++;
    else{
      cout<<a[l]<<" "<<a[r];
      return 0;
    }
  }
  
  cout<<"No";
	return 0;
}
```
