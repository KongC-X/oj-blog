# 2240 - 和为给定数

## 题目描述

给出若干个整数，询问其中是否有一对不同位置上数的和等于给定的数。

## 输入

共三行： 第一行是整数 $n$ ($0 \lt n \le 100,000$)，表示有 $n$个整数。

第二行是 $n$ 个整数。整数的范围是在 $0$ 到 $10$$8$ 之间。

第三行是一个整数 $m$（$0 \le m \le 2^{30}$)，表示需要得到的和。

## 输出

若存在和为 $m$ 的数对，输出两个整数，小的在前，大的在后，中间用单个空格隔开。

若有多个数对满足条件，选择数对中较小的数更小的。若找不到符合要求的数对，输出一行 `No`。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
const int N = 1e5 + 10;
int a[N],l,r,mid,n,c;

//测试距离为mid，可以放几头牛
bool check(int mid) {
	int tot = 1;//默认能放1头 
	//last:表示上1个牛栏
	int last = 1;//第1个牛栏肯定有牛
	for(int i = 2; i <= n; i++) {
		if(a[i] - a[last] >= mid) {
			tot++;//牛栏数自增
			last = i;
		}
	}

	if(tot >= c) return true;
	else return false;
}

int main() {
	//n个牛栏，c头要分隔的奶牛
	cin>>n>>c;
	for(int i = 1; i <= n; i++) {
		cin>>a[i];
	}
	//排序
	sort(a+1,a+1+n);
	//在[l,r]之间查找最大的最近距离
	l=1,r=a[n]-a[1];
	//找右边界
	while(l <= r) {
		mid = (l + r) >> 1;
		if(check(mid)) l = mid + 1;
		else r = mid - 1;
	}

	cout<<l-1;
	return 0;
}
```
