# 1121 - “倒”数

## 题目描述

输入一个正整数 $N（ 0 \lt N \lt 2147483647 $），将这个数倒着合成一个新数后输出。

比如： $543$ ，倒过来是 $345$ （请注意： $34500$ ，倒过来是 $543$ ，不是 $00543$ ）！

## 输入

一行，一个正整数 $N$ 。

## 输出

一行，一个正整数。

## 解题思路

## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int a[200],i,n,s = 0;
    double v;
    cin >> n;
    for(i = 0; i < n; i++) {
        cin >> a[i];
        s += a[i];
    }
    cout << s << endl; // 总分
    v = s * 1.0 / n;
    printf("%.2f\n",v); // 平均分
    // 从大到小冒泡排序
    for(i = 0; i < n - 1; i++) {
        for(int j = 0; j < n - i - 1; j++) {
            if(a[j] < a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }
    for(i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
}
```
