# 1518 - 多项式求和

## 题目描述

输入一个正整数 $n$，求 $1!-2!+3!-4!+ \dots +N!$ 的结果。

比如：$n=3$，则结果 $= 1-(1*2)+(1*2*3) = 5$。

$n! = 1 * 2 * 3 * 4 * ... * n$，也就是 $1 \sim n$ 之间所有数的积，比如：$5!=1*2*3*4*5=120$。

## 输入

一个正整数 $n（n \le 10$ ）

## 输出

一个整数，代表运算结果。

## 解题思路

## AC代码

```cpp
# include <iostream>
using namespace std;

int s;
void fun(int n) {
    if(n % 2 == 0) {
        s++;
        fun(n / 2);
    }
}

int main() {
    int n;
    cin >> n;
    fun(n);
    cout << s << endl;
}
```
