# 1264 - 4位反序数

## 题目描述

设 $N$ 是一个四位数，它的 $9$ 倍恰好是其反序数，求 $N$ 。

反序数就是将整数的数字倒过来形成的整数。例如： $1234$ 的反序数是 $4321$ 。

## 输入

无。

## 输出

输出 $N$ 这个四位数。
## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int i = 1000,a,b,c,d,n;
    while(i < 10000) {
        a = i / 1000;
        b = i % 1000 / 100;
        c = i % 100 / 10;
        d = i % 10;
        n = d * 1000 + c * 100 + b * 10 + a;
        if(i * 9 == n) {
            cout << i << endl;
        }
        i++;
    }
}
```
