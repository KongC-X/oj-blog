# 1942 - 回文质数 Prime Palindromes

## 题目描述

因为 $151$ 既是一个质数又是一个回文数（从左到右和从右到左是看一样的），所以 $151$ 是回文质数。

写一个程序来找出范围 $[a,b]$($5 \le a \lt b \le 100,000,000$)(一亿)间的所有回文质数。

## 输入

第 $1$ 行: 二个整数 $a$ 和 $b$。

## 输出

输出一个回文质数的列表，一行一个。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

/*
思路：
准备一个栈(在栈底存储一个*,防止栈空),存储左括号，遇到左括号，入栈
遇到右括号：判断栈顶元素是否是配对的左括号
如果是，弹出栈顶元素
如果不是，结束判断，得到结论，括号不匹配
循环结束，栈的大小应该是1
*/

stack<char> s;
string t;
int i;
int main() {
	cin >> t;
	s.push('*'); // 栈底放一个*，防止栈空
	for (i = 0; i < t.size(); i++) {
		if (t[i] == '(' || t[i] == '['){
			// 如果是左括号，入栈
			s.push(t[i]);
		} else {
			// 说明遇到右括号
			if(t[i] == ')' && s.top() == '(' || t[i] == ']' && s.top() == '[') {
				// 如果栈顶元素是配对的左括号，弹出栈顶元素
				s.pop();
			} else {
				// 否则，括号不匹配
				cout << "no" << endl;
				return 0;
			}
		}
	}
	// 如果栈大小是1，说明括号匹配
	if (s.size() == 1) {
		cout << "yes" << endl;
	} else {
		// 否则，括号不匹配
		cout << "no" << endl;	
	}
}
```
