# 2453 - 编辑子矩阵

## 题目描述

有一个 $n \times n$ 大小的方阵，矩阵中的初始值为 $0$ ，有 $k$ 次操作，每次会将矩阵中以 $x$$1$ , $y$$1$ 和 $x$$2$ , $y$$2$ 为左上角和右下角的子矩阵中的每个数加 $1$ 。

请输出经过 $k$ 次加数操作后，方阵中每个元素的值。

## 输入

第1行有两个整数 $n$ 和 $k$。（$n,k ≤ 1000$）

接下来 $k$ 行，每行有 $4$ 个整数 $x$$1$ , $y$$1$ 和 $x$$2$ , $y$$2$，两点坐标均在方阵范围内，且左上角的坐标 ≤ 右下角的坐标。

## 输出

输出经过 $k$ 次操作后，方阵中每个元素的值。
## AC代码

```cpp
#include <iostream>
using namespace std;

const int MAXN = 1010;            // n 最大 1000，多开几个
int d[MAXN][MAXN];                // 二维差分数组，最后还原成答案

int main() {
    /*
      思路：二维差分

      每次把子矩阵 (x1,y1) 到 (x2,y2) 全部加 1，
      如果直接双重循环修改，最坏 k*n*n = 1e9，会超时。

      用二维差分可以 O(1) 完成一次矩形修改：
      对子矩形 (x1,y1) 到 (x2,y2) 加 1，只需要修改 d 的四个位置：
		d[x1][y1]         += 1;    // ① 起点开始影响
		d[x1][y2+1]       -= 1;    // ② 右边一列开始取消影响
		d[x2+1][y1]       -= 1;    // ③ 下边一行开始取消影响
		d[x2+1][y2+1]     += 1;    // ④ 右下角补回来（被减了两次）

      所有修改完成后，对差分数组求二维前缀和，就能还原每个格子的值：
        d[i][j] += d[i-1][j] + d[i][j-1] - d[i-1][j-1]

      总复杂度 O(k + n^2)，n,k ≤ 1000，完全可行。
    */

    int n, k;                     // n: 方阵大小, k: 操作次数
    cin >> n >> k;

    for (int i = 1; i <= k; i++) {
        int x1, y1, x2, y2;       // 子矩阵左上角和右下角
        cin >> x1 >> y1 >> x2 >> y2;

        // 二维差分：矩形加 1 的四个关键位置
        d[x1][y1]++;
        d[x1][y2 + 1]--;
        d[x2 + 1][y1]--;
        d[x2 + 1][y2 + 1]++;
    }

    // 对差分数组求二维前缀和，还原每个格子的值
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            d[i][j] += d[i - 1][j] + d[i][j - 1] - d[i - 1][j - 1];
        }
    }

    // 输出结果方阵
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= n; j++) {
            cout << d[i][j];
            if (j < n) cout << " ";   // 数字之间空格，行末不加多余空格
        }
        cout << endl;
    }

    return 0;
}
```
