# 1291 - 八进制转十进制

## 题目描述

请将一个 $20$ 位以内的八进制数转换为十进制整数。

## 输入

$20$ 位以内的八进制数。

## 输出

该数对应的十进制数。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    long long n,x = 0,i;
    cin >> s;
    // 11001
    for(i = s.size() - 1;i >= 0;i--) {
        n = (s[i] - '0') * pow(8,s.size() - 1 - i);
        x += n;
    }
    cout << x;
}
```
