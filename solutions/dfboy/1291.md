# 1291 - 八进制转十进制

## 题目描述

请将一个 $20$ 位以内的八进制数转换为十进制整数。

## 输入

$20$ 位以内的八进制数。

## 输出

该数对应的十进制数。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
 
int main() {
    int n;
    cin>>n;
    int i;
    //遍历1到n之间的整数 
    for(i=1;i<=n;i++){
        int x=0;//记录能够被2、3、5、7中几个数整除 
        if(i%2==0){
            x++;
        }
        if(i%3==0){
            x++;
        }
        if(i%5==0){
            x++;
        }
        if(i%7==0){
            x++;
        }
        //输出符合两个及两个以上条件的数 
        if(x>1){
            cout<<i<<endl;
        }
    } 
    return 0;
}
```
