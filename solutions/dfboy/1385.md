# 1385 - 有趣的数字图形

## 题目描述

输入一个整数n（ $n \lt 10$），输出 $n$ 行 $n$ 列的如下图所示的数字图形。

## 输入

一个整数 $n$ 。（  $1 \lt  n \lt 10$  )

## 输出

一个方阵，每个数字的场宽为 $5$ 。
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[20][20];

int main(){
    int i = 0, j = 0, k = 0, n;
    cin >> n;

    for(int i = 0; i < n; i++)
    {
        a[i][i] = ++k;
    }
    k = 1;
    while(k < n)
    {
        i = 0;
        j = i + k;
        while(i < n && j < n)
        {
            a[i][j] = a[i][j-1] + a[i+1][j];
            a[j][i] = a[i][j];
            i++;
            j++;
        }
        k++;
    }

    for(int i = 0; i < n; i++)
    {
        for(int j = 0; j < n; j++)
        {
            cout << setw(5) << a[i][j];
        }
        cout << endl;
    }
	return 0;
}
```
