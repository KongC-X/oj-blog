# 1242 - 第K大与第K小数

## 题目描述

给定一个长度为 $N$ ( $0 \lt n \le 10000$ )的序列，保证每一个序列中的数字 $a[i]$ 是正整数且唯一  ，编程要求求出整个序列中第 $k$ 大的数字减去第 $k$ 小的数字的值 $m$ ，并判断 $m$ 是否为质数。($0 \lt k \le n$)

## 输入

输入格式：

第一行为 $2$ 个数 $n，k$（含义如上题）；

第二行为 $n$ 个数，表示这个序列。

## 输出

输出格式：

如果 $m$ 为质数,则第一行为`YES`,第二行为这个数 $m$;

否则 ，第一行为`NO` ，第二行为这个数 $m$。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 辗转相除法求最大公约数
int gys(int a,int b) {
    int t;
    while(a % b != 0) {
        t = a % b;
        a = b;
        b = t;
    }
    return b;
}

int main(){
    string s,s1,s2,fz1,fm1,fz2,fm2;
    int p,x1,x2,y1,y2,r1,r2,t;
    cin >> s;
    p = s.find('+');
    if(p == -1) {
        p = s.find('-');
    }
    s1 = s.substr(0,p);
    s2 = s.substr(p+1);
    // cout << s1 << " " << s2 << endl;

    fz1 = s1.substr(0,s1.find('/'));
    fm1 = s1.substr(s1.find('/')+1);
    fz2 = s2.substr(0,s2.find('/'));
    fm2 = s2.substr(s2.find('/')+1);
    // cout << fz1 << " " << fm1 << " " << fz2 << " " << fm2 << endl;

    x1 = stoi(fz1);
    y1 = stoi(fm1);
    x2 = stoi(fz2);
    y2 = stoi(fm2);

    r2 = y1 * y2; // 计算结果的分母
    if(s.find('+') != -1) {
        r1 = x1 * y2 + x2 * y1; // 计算结果的分子
    } else {
        r1 = x1 * y2 - x2 * y1; // 计算结果的分子
        if(r1 < 0) {
            cout << "-"; // 如果分子是负的先输出负号，然后改成正数运算
            r1 = r1 * -1;
        }
    }
    // cout << r1 << "/" << r2 << endl;
    t = gys(r1,r2);  // 求分子分母最大公约数

    // 如果分子是分母的倍数则直接除掉
    if(r1 % r2 == 0) {
        cout << r1 / r2 << endl;
    } else {
        cout << r1 / t << "/" << r2 / t << endl;
    }
}
```
