# 1729 - 同构数

## 题目描述

同构数是这样一种数：它出现在它的平方数的右端。例如：$5$ 的平方是 $25$ ， $5$ 就是同构数，$25$ 的平方是 $625，25$ 也是同构数。

再比如：$100$ 以内的同构数有 $1$ $5$ $6$ $25$ $76$ 这$5$ 个整数。

请编程计算出 $1 \sim N$ 之间（包括 $N$ ）的全部同构数有多少个？

## 输入

一个正整数 $N$。（ $N \le 10000$） 。

## 输出

一个整数，代表 $1 \sim N$ 之间的全部同构数的个数。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int a[100100],n,i,x;
int dp[100100];
int ma,s;

int main() {
    cin >> n >> x;
    a[1] = x; // 边界条件
    dp[1] = a[1];
    s = dp[1]; // 求和
    for(i = 2;i <= n;i++) {
        a[i] = (379 * a[i - 1] + 131) % 997;
        // 计算出前i个数的最小值
        dp[i] = min(dp[i - 1], a[i]);
        s += dp[i];
    }
    cout << s << endl;
}
```
