# 1729 - 同构数

## 题目描述

同构数是这样一种数：它出现在它的平方数的右端。例如：$5$ 的平方是 $25$ ， $5$ 就是同构数，$25$ 的平方是 $625，25$ 也是同构数。

再比如：$100$ 以内的同构数有 $1$ $5$ $6$ $25$ $76$ 这$5$ 个整数。

请编程计算出 $1 \sim N$ 之间（包括 $N$ ）的全部同构数有多少个？

## 输入

一个正整数 $N$。（ $N \le 10000$） 。

## 输出

一个整数，代表 $1 \sim N$ 之间的全部同构数的个数。

## 解题思路

## AC代码
## AC代码

```cpp
#include <iostream>
using namespace std;
int main (){
 int n,cnt=0;
 cin>>n;
 for(int i=1;i<=n;i++){
 int x=i*i;//求平⽅数
 int t=i,f=0;//f⽤来标记i是否出现在其平⽅数的右端
 while(t){//t的位数较少，所以把t!=0作为判断条件
 if(t%10!=x%10){//判断两者的个位是否相同
 f=1;//不同则打标记
 break;
 }
 t/=10,x/=10;
 }
 if(f==0) cnt++;//符合条件计数
 }
 cout<<cnt; 
 return 0;
}
```
