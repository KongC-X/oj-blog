# 1401 - 浪尖数？

## 题目描述

小丽在上班编程课时，发现有一些数很有趣，这些数正好比该数左右相邻的数都大，就像大海里的浪花的浪尖一样美丽；小丽就给这些数起了一个名字叫做“浪尖数”，比如： $2$  $3$   $1$ 中的 $3$ ，就像一朵波浪的浪尖一样，正好比左右两个数都大。

请你编程帮助小丽计算一下，一个数组中有多少个“浪尖数”。

## 输入

第一行，是一个整数 $n$ 代表数组找那个有 $n$ 个数（ $n \le 100$）；

第二行有 $n$ 个整数，用空格隔开。

## 输出

输出一个整数，代表满足条件的浪尖数的数量。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;
int main() {
	//数组大小按照题目的要求定义，最好多定义10个
	int a[110],n,i,j,t,s = 0;
    double v;
	cin>>n;
	for(i=0; i<n; i++) {
		cin>>a[i];
	}
	for(i = 0; i < n - 1; i++) {
		for(j = 0; j < n - i - 1; j++) {
			//按照从大到小排序
			if(a[j]<a[j+1]) {
				t=a[j];
				a[j]=a[j+1];
				a[j+1]=t;
			}
		}
	}
	for(i=0; i<5; i++) {
        s += a[i];
    }
    v = s / 5.0;
    printf("%.1f",v);
}
```
