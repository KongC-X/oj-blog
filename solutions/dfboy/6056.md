# 6056 - 删除 k 位数字，得到最小的数

## 题目描述

输入一个数字串 $N$，长度不超过 $250$ 位，去掉其中任意 $k$ 个数字后剩下的数字按原左右次序将组成一个新的整数，要求组成新的整数最小。

## 输入

输入两行正整数。
第一行输入一个高精度的正整数 $n$。
第二行输入一个正整数 $k$，表示需要删除的数字个数。

## 输出

输出一个整数，最后剩下的最小数。
## AC代码

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string a;                     // a: 输入的数字串
    int k;                        // k: 需要删除的数字个数
    cin >> a >> k;
    int n = a.size();             // n: 原始长度

    // ---------- 思路 ----------
    // 贪心 + 栈（数组模拟）
    // 目标：删除 k 个数字后，剩下的数字按原顺序组成的数最小。
    // 策略：从左到右遍历，当前数字比栈顶小且还能删时，删掉栈顶（相当于放弃较大的高位），
    //       然后压入当前数字。这样高位尽可能小。
    // 遍历完后如果还没删够 k 个，从末尾继续删（因为此时序列已经非递减，删末尾损失小）。
    // 最后记得去除前导零，若结果为空则输出 0。

    char stk[255];                // 模拟栈，存储最终保留的数字
    int top = 0;                  // 栈顶指针（栈中元素个数）

    for (int i = 0; i < n; i++) {
        // 当栈不空、还有删除配额、且栈顶数字大于当前数字时，弹出栈顶（删除）
        while (top > 0 && k > 0 && stk[top - 1] > a[i]) {
            top--;
            k--;
        }
        stk[top++] = a[i];        // 当前数字入栈
    }

    // 如果还没删够 k 个，从末尾删除（栈顶弹出）
    top -= k;                     // 直接减少栈大小

    // 去除前导零，找到第一个非零位置
    int start = 0;
    while (start < top && stk[start] == '0') {
        start++;
    }

    // 输出结果
    if (start == top) {           // 全是零，输出 0
        cout << 0 << '\n';
    } else {
        for (int i = start; i < top; i++) {
            cout << stk[i];
        }
        cout << '\n';
    }

    return 0;
}
```
