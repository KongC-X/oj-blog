# 1703 - 小明买水果

## 题目描述

小明去超市买了若干斤水果，你能根据水果的单价，小明买的水果数量，编一个程序计算出总金额，并打印出清单。

## 输入

输入两个值，

第一个为商品的单价，是一个小数。

第二个为商品的数量，是一个整数。

用空格隔开。

## 输出

一行，商品的单价，数量，及金额，中间用空格隔开。

单价保留两位小数，总金额去掉小数，数量为整数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

char s[200]; 
int a[200];
int main(){
    cin>>s;
    for(int i = 0;i < strlen(s);i++){
        a[s[i]]++;
    }
    char ma = 'a';//出现次数最多的小写字母 
    for(char i = 'a';i <= 'z';i++){
    	//如果有多个最多，求编码最大的 
        if(a[i] >= a[ma]){
            ma = i;
        }
    }
    cout<<ma;
}
```
