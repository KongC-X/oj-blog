# 1039 - 求三个数的最大数

## 题目描述

已知有三个不等的数，将其中的最大数找出来。

## 输入

输入只有一行，包括 $3$ 个整数。之间用一个空格分开。

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

## 解题思路

## AC代码
## AC代码

```cpp
#include <iostream>
using namespace std;

int main() {
	// 求三个数的最大值
	int a ,b ,c;
	cin >> a >> b >> c;
	if(a > b) {
		if(a > c) {
			cout << a << endl;
		} else {
			cout << c << endl;
		}
	} else {
		if( b > c) {
			cout << b << endl;
		} else {
			cout << c << endl;
		}
	}
}
```
