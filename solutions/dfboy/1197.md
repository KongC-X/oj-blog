# 1197 - 拐角II

## 题目描述

输入整数 $N$ ，输出相应方阵。

## 输入

一个整数 $N$ 。（ $0 \lt N \le 10$ )

## 输出

一个方阵，每个数字的场宽为 $3$ 。
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int a[20][20],n,x = 1,i,j;
int main() {
    cin >> n;
    for(i = 0;i < n;i++) {
        for(j = 0;j < n - i;j++) {
            a[n - i - 1][j] = i + 1; // 横向
            // 因为是对称的，所以另一半坐标直接反过来就行了
            a[j][n - i - 1] = i + 1; // 纵向
        }
    }
    for(i = 0;i < n;i++) {
        for(j = 0;j < n;j++) {
            cout << setw(3) << a[i][j];
        }
        cout << endl;
    }
}
```
