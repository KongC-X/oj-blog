# 1105 - 字符串连接

## 题目描述

给出两个字符串，将它们进行拼接，拼接过程中每个字符只允许出现一次。

如：两个字符串 $s1="adeab"，s2="fcadex"$ ，那么连接时$s1$ 留下 $adeb$ （第 $2$ 个 $a$ 出现过了，就不要了），再将 $s2$ 连接上来形成 $adebfcx$，两个字符串中重复的都过滤掉，但剩余的顺序不要调整。

## 输入

两行，每行一个只包含小写英文字母的字符串。

## 输出

一行，连接后的字符串。

## AC代码

```cpp
#include<iostream> 
#include<bits/stdc++.h> 
using namespace std;
int main(){
    string s,s1,s2,s3;
    getline(cin,s1);
    getline(cin,s2);
    s = s1 + s2;
    for(int i = 0;i < s.size();i++) {
        if(s3.find(s[i]) == -1){
            s3 += s[i];
        }
    }
    cout << s3 << endl;
}
```
