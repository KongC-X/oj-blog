# 1717 - 饮料的价格？

## 题目描述

小区商店的老板新进了一批橙汁，由于进货进多了，老板担心卖不完，于是想了一个促销方案，希望大家可以多买一些回家。

如果只买 $1$瓶，卖 $5$ 元 $/$ 瓶；

如果买 $2$ 瓶 $ \sim $ 5瓶，卖 $4.5$ 元 $/$ 瓶；

如果买 $6$ 瓶 $ \sim $ 10瓶，卖 $4$ 元 $/$ 瓶；

如果买 $10$ 瓶以上，卖 $3.5$ 元 $/$ 瓶；

请从键盘读入顾客购买的数量，计算一下，顾客应付的总金额（总金额保留 $1$ 位小数）。

比如，某位顾客购买了 $6$ 瓶橙汁，那么单价就是 $4$ 元 $/$ 瓶，该顾客应付总价 $= 6 * 4.0 = 24.0$ 元。

## 输入

一个整数 $n$，代表顾客购买橙汁的瓶数。

## 输出

一个小数，代表顾客应付价格，计算结果保留 $1$ 位小数。

```cpp
#include <iostream>
#include <iomanip>
using namespace std;
 
int main(){
    int n;
    cin>>n;
    double p;
    if(n>10){
        p=3.5*n;
    }else if(n>=6){
        p=4*n;
    }else if(n>=2){
        p=4.5*n;
    }else{
        p=5*n;
    }
    cout<<fixed<<setprecision(1)<<p;  
}
```
