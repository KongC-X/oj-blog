# 1717 - 饮料的价格？

## 题目描述

小区商店的老板新进了一批橙汁，由于进货进多了，老板担心卖不完，于是想了一个促销方案，希望大家可以多买一些回家。

如果只买 $1$瓶，卖 $5$ 元 $/$ 瓶；

如果买 $2$ 瓶 $ \sim $ 5瓶，卖 $4.5$ 元 $/$ 瓶；

如果买 $6$ 瓶 $ \sim $ 10瓶，卖 $4$ 元 $/$ 瓶；

如果买 $10$ 瓶以上，卖 $3.5$ 元 $/$ 瓶；

请从键盘读入顾客购买的数量，计算一下，顾客应付的总金额（总金额保留 $1$ 位小数）。

比如，某位顾客购买了 $6$ 瓶橙汁，那么单价就是 $4$ 元 $/$ 瓶，该顾客应付总价 $= 6 * 4.0 = 24.0$ 元。

## 输入

一个整数 $n$，代表顾客购买橙汁的瓶数。

## 输出

一个小数，代表顾客应付价格，计算结果保留 $1$ 位小数。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int n, m, l[10010], s[10010];
int ma, sum;

int main()
{
    cin >> n >> m >> l[1] >> s[1];
    for (int i = 2; i <= n; i++)
    {
        l[i] = ((l[i - 1] * 37011 + 10193) % 10000) + 1;
        ma = max(ma, l[i]);
        s[i] = ((s[i - 1] * 73011 + 24793) % 100) + 1;
    }
    ma = max(ma, l[1]); // ma存储最大长度值
    for (int i = ma; i >= 1; i--)
    { // 贪心，从可取的最大长度开始计算
        for (int j = 1; j <= n; j++)
        {
            sum = sum + l[j] / i * s[j]; // sum记录在i长度下，可以锯出的数量
        }
        if (sum >= m) // 满足条件
        {
            cout << i;
            return 0;
        }
        sum = 0;
    }
    return 0;
}
```
