# 2537 - 文章处理（article）

## 题目描述

侦探小 $A$ 发现了一篇奇怪的文章，这篇文章中有他正在侦办的案件的线索。  

但是这篇文章实在是太长了，分析非常需要时间，于是他找到了会编程的你，请你帮忙完成如下任务。  

将这篇只包含英文单词和空格组成的文章中的所有的单词，去除重复的单词后，按字典码从小到大排序后输出。

## 输入

一行仅包含英文单词和空格的字符串。（单词数$≤100$，单词长度$≤50$，单词之间包含** $1$ 个或多个**空格）。

## 输出

按题意要求输出处理后的结果，输出有若干行，每行有一个单词。

## 解题思路

## AC代码
## AC代码

```cpp
#include <iostream>
#include <set>
#include <string>
using namespace std;

int main() {
    set<string> word_set;  // 自动去重和排序的集合
    string word;
    
    // 读取单词直到输入结束
    while (cin >> word) {
        word_set.insert(word);  // 自动处理去重和排序
    }
    
    // 输出结果
	set<string>::iterator it;
	for (it = word_set.begin(); it != word_set.end(); ++it) {
		cout << *it << endl;
	}
    return 0;
}
```
