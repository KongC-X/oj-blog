# 2537 - 文章处理（article）

## 题目描述

侦探小 $A$ 发现了一篇奇怪的文章，这篇文章中有他正在侦办的案件的线索。  

但是这篇文章实在是太长了，分析非常需要时间，于是他找到了会编程的你，请你帮忙完成如下任务。  

将这篇只包含英文单词和空格组成的文章中的所有的单词，去除重复的单词后，按字典码从小到大排序后输出。

## 输入

一行仅包含英文单词和空格的字符串。（单词数$≤100$，单词长度$≤50$，单词之间包含** $1$ 个或多个**空格）。

## 输出

按题意要求输出处理后的结果，输出有若干行，每行有一个单词。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;
int a[10010];
int main() {
	int n,i,j,t,k,m;
	cin >> n >> k;
	for(i=0; i<n; i++) {
		cin>>a[i];
	}
	for(i = 0; i < n - 1; i++) {
		for(j = 0; j < n - i - 1; j++) {
			if(a[j] > a[j+1]) {
				t=a[j];
				a[j]=a[j+1];
				a[j+1]=t;
			}
		}
	}
    m = a[n-k] - a[k-1];
    // 判断m是否是质数
    bool flag = true;
    for(int i = 2; i <= m / 2; i++) {
        if(m % i == 0) {
            flag = false;
            break;
        }
    }
    if(m <= 1) {
        flag = false;  // 有可能m是负数
    }
    if(flag) {
        cout << "YES" << endl;
    } else {
        cout << "NO" << endl;
    }
    cout << m << endl;
}
```
