# 1023 - 判断素数

## 题目描述

任意输入一个整数，判断它是否为素数。是的话输出 `T`，不是的话输出 `F`。

质数（$prime$ $number$）又称素数，质数定义为在大于 $1$ 的自然数中，除了 $1$ 和它本身以外不再有其他因数。

## 输入

输入只有一行，包括 $1$ 个整数。（ $1 \le n \le 10^9$ ）

## 输出

输出只有一行。
