# 4142 - 打印数字

## 题目描述

小杨为数字 $ 0, 1, 2 $ 和  $3$ 设计了一款表示形式，每个数字占用了  $5 \times 5$ 的网格。数字 $ 0, 1, 2 $ 和  $3$ 的表示形式如下：

```
`..... ****. ..... .....
.***. ****. ****. ****.
.***. ****. ..... .....
.***. ****. .**** ****.
..... ****. ..... .....
`
```

小杨想请你将给定的数字 $n$ 转换为对应的表示形式。

## 输入

第一行包含一个正整数代表 $n$。

## 输出

输出对应的表示形式。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int n,m,x;
struct Num
{
    int num,loc;//num是当前数字,loc是该数字的位置
} a[100010];
bool cmp(Num a,Num b)//sort判断函数
{
    if(a.num<b.num)return true;
    else return false;
}
int find(int x)//二分找数函数
{
    int l=1,r=n,mid;
    while(l<=r)
    {
        mid=l+r>>1;
        if(a[mid].num<x)//通过分治来缩小二分左右边界
        {
            l=mid+1;
        }
        else if(a[mid].num>x)
        {
            r=mid-1;
        }
        else
        {
            return a[mid].loc;//找到了直接返回它的位置
        }
    }
    return 0;//否则返回0
}
int main()
{
    scanf("%d",&n);//scanf运行效率较高,cin可能会超时
    for(int i = 1; i <= n; i++)
    {
        scanf("%d",&a[i].num);
        a[i].loc=i;
    }
    sort(a+1,a+n+1,cmp);//自定义排序
    scanf("%d",&m);
    for(int i = 1; i <= m; i++)
    {
        scanf("%d",&x);
        printf("%d\n",find(x));
    }
    return 0;
}
```
