# 4142 - 打印数字

## 题目描述

小杨为数字 $ 0, 1, 2 $ 和  $3$ 设计了一款表示形式，每个数字占用了  $5 \times 5$ 的网格。数字 $ 0, 1, 2 $ 和  $3$ 的表示形式如下：

```
`..... ****. ..... .....
.***. ****. ****. ****.
.***. ****. ..... .....
.***. ****. .**** ****.
..... ****. ..... .....
`
```

小杨想请你将给定的数字 $n$ 转换为对应的表示形式。

## 输入

第一行包含一个正整数代表 $n$。

## 输出

输出对应的表示形式。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

string s;
int i,j,k;
char num[10][30] = {
    "..... ****. ..... .....",
    ".***. ****. ****. ****.",
    ".***. ****. ..... .....",
    ".***. ****. .**** ****.",
    "..... ****. ..... ....."
};

int main() {
    cin >> s;
    for(i = 0;i < 5;i++) {
        for(k = 0;k < s.size();k++){
        // cout << s[k] << " ";
            if(s[k] == '0') {
                for(j = 0;j < 5;j++){
                    cout << num[i][j];
                }
            } else if(s[k] == '1') {
                for(j = 6;j < 11;j++){
                    cout << num[i][j];
                }
            } else if(s[k] == '2') {
                for(j = 12;j < 17;j++){
                    cout << num[i][j];
                }
            } else if(s[k] == '3') {
                for(j = 18;j < 23;j++){
                    cout << num[i][j];
                }
            }
        }
        cout << endl;
    }
}
```
