# 1110 - 编程求解1+3+5+...+n

## 题目描述

编程求解下列式子的值： $S=1+3+5+...+n$ 。

## 输入

输入一行，只有一个整数 $n(1 \le n \le 1000)$ 。

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

## 解题思路

## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int a[110],n,i,t;
    cin >> n;
    for (i=0;i<n;i++) cin >> a[i];

    // 解法一：不真正逆序，而是直接倒序输出
    // for (i=n-1;i>=0;i--) cout << a[i] << " ";

    // 解法二：实现真正的逆序，循环数组长度的一半，对称交换位置
    for(i = 0;i < n /2;i++) {
        t = a[i];
        a[i] = a[n-i-1];
        a[n-i-1] = t;
    }
    for(i = 0;i < n;i++) cout << a[i] << " ";
}
```
