# 1110 - 编程求解1+3+5+...+n

## 题目描述

编程求解下列式子的值： $S=1+3+5+...+n$ 。

## 输入

输入一行，只有一个整数 $n(1 \le n \le 1000)$ 。

## 输出

输出只有一行（这意味着末尾有一个回车符号），包括 $1$ 个整数。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	int n,s=0;//s表示和，初始值为0 
	cin>>n;
	//遍历1-n的奇数 
	for(int i=1;i<=n;i+=2){
		s+=i; 
	}
	cout<<s; 
	return 0;
}
```
