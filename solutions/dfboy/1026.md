# 1026 - 求商数和余数

## 题目描述

输入 $a,b$ 两个整数，编程求出 $a$ 除以 $b$ 得到的商和余数。

## 输入

输入一行，只有两个整数(中间有空格)。

## 输出

输出只有一行，两个整数(中间有空格)。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;

int main(){
	/*
		n行
		第几行	几列空格	几列星 
		第1行	2个			1个星 
		第2行	1个			3个星 
		第3行	0个			5个星 
		第i行	n-i个 		2*i-1 
	*/
	int n,i,j;
	cin>>n;
	for(i=1;i<=n;i++){
		for(j=1;j<=n-i;j++){
			cout<<" ";
		}
		for(j=1;j<=2*i-1;j++){
			cout<<"*";
		}
		cout<<endl; 
	}
	return 0;
}
```
