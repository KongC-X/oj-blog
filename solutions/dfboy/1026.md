# 1026 - 求商数和余数

## 题目描述

输入 $a,b$ 两个整数，编程求出 $a$ 除以 $b$ 得到的商和余数。

## 输入

输入一行，只有两个整数(中间有空格)。

## 输出

输出只有一行，两个整数(中间有空格)。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;
int main(){
	int a,b;
	cin>>a>>b;
	cout<<a/b<<" "<<a%b;
	return 0; 
}
```
