# 1223 - 汉诺塔的移动次数

## 题目描述

汉诺塔的问题大家都已经很熟悉了，有三个柱子，每个柱子上有一些大小不一的金片，要把金片从 $A$ 柱移动到 $C$ 柱，可以借助 $B$ 柱，请问 $n$ 个金片的情况下，需要最少移动多少次？

## 输入

输入一个整数 $n$ 代表金片的数量（$n \le 20$）。

## 输出

一个整数，代表 $n$ 个金片的移动次数。

## 解题思路

```cpp
#include<iostream>
using namespace std;

/*
汉诺塔移动问题
1、先将n-1个（除了最下面那个）盘子从A借助C移动到B，需要n-1次fun(n-1)次
2、将最下面那个盘子从A移动到C，需要1次fun(1)次
3、将n-1个（除了最下面那个）盘子从B借助A移动到C，需要n-1次fun(n-1)次
因此得到结论：fun(n) = fun(n-1) + 1 + fun(n-1) = 2*fun(n-1) + 1
* */

int fun(int n) {
    if(n == 1) {
        return 1;
    } else {
        return 2 * fun(n - 1) + 1;
    }
}

int main() {
    int n;
    cin >> n;
    cout << fun(n) << endl;
    return 0;
}
```
