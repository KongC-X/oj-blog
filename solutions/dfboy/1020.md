# 1020 - 算算和是多少

## 题目描述

输入一个三位正整数，然后与它倒过来的数相加，输出和。

如：输入 $167$ ，则和为$167+761=928$。

## 输入

只有一行，一个三位正整数。

## 输出

一个正整数

## 解题思路

## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int a[20],i,n;
    cin >> n;
    for(i = 0; i < n; i++) {
        cin >> a[i];    
    }
    // 从小到大冒泡排序
    for(i = 0; i < n - 1; i++) {
        for(int j = 0; j < n - i - 1; j++) {
            if(a[j] > a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }
    for(i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
}
```
