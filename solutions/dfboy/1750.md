# 1750 - 有0的数

## 题目描述

请求出 $1 \sim n$ 中含有数字 $0$ 的数，有多少个？

## 输入

一个整数 $n（n \le 999）$ 。

## 输出

一个整数，代表 $1 \sim n$ 中含有数字 $0$ 的数的个数。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;

bool isLeapYear(int year) {
    if (year % 4 != 0) {
        return false;
    } else if (year % 100 != 0) {
        return true;
    } else {
        return (year % 400 == 0);
    }
}

int daysInMonth(int month, int year) {
    if (month == 2) {
        return isLeapYear(year) ? 29 : 28;
    } else if (month == 4 || month == 6 || month == 9 || month == 11) {
        return 30;
    } else {
        return 31;
    }
}

int main() {
    int year;
    cin >> year;

    int totalDays = 0;
    for (int y = 1998; y < year; ++y) {
        totalDays += isLeapYear(y) ? 366 : 365;
    }

    int dayOfWeek = (4 + totalDays) % 7; // 1998年1月1日是星期四（4）

    int count = 0;
    for (int month = 1; month <= 12; ++month) {
        if ((dayOfWeek + 12) % 7 == 5) { // 13号是星期五（5）
            count++;
        }
        dayOfWeek = (dayOfWeek + daysInMonth(month, year)) % 7;
    }

    cout << count << endl;

    return 0;
}

/*
代码解释
函数isLeapYear：
判断给定年份是否为闰年。规则是：能被4整除但不能被100整除，或者能被400整除的年份是闰年。

函数daysInMonth：
返回给定月份在该年份的天数。二月份的天数根据是否为闰年确定。

主函数main：
读取输入的年份。
计算从1998年1月1日到目标年份1月1日的总天数totalDays。
根据总天数计算目标年份1月1日的星期几dayOfWeek（1998年1月1日是星期四，对应数字4）。
遍历每个月份，检查该月的13号是否是星期五（即(dayOfWeek + 12) % 7 == 5），如果是则增加计数。
更新dayOfWeek为下个月1日的星期几。
输出统计结果。
这种方法确保了我们能够准确计算出给定年份中所有13号是星期五的次数，适用于大范围的年份输入。
*/
```
