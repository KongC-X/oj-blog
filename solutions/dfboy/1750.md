# 1750 - 有0的数

## 题目描述

请求出 $1 \sim n$ 中含有数字 $0$ 的数，有多少个？

## 输入

一个整数 $n（n \le 999）$ 。

## 输出

一个整数，代表 $1 \sim n$ 中含有数字 $0$ 的数的个数。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int main(){
    int n,i,a,s = 0,x;
    cin >> n;
    for(i = 1;i <= n;i++) {
        x = i;
        while(x != 0) {
            a = x % 10;
            if(a == 0) {
                s++;
                break;
            }
            x = x / 10;
        }
    }
    cout << s << endl;
}
```
