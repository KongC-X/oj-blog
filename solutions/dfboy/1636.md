# 1636 - 超市卖电池

## 题目描述

某超市卖电池，每节电池 $2$ 元钱。若数量超过 $10$ 节，则可打 $9$ 折。请输入购买电池节数，打印相应价钱（得到保留一位小数）。

## 输入

一行，一个整数。

## 输出

一行，相应的价钱。

## 解题思路

## AC代码
## AC代码

```cpp
#include <iostream>
#include <iomanip>
using namespace std;
 
int main(){
    int n;
    cin>>n;
    double m;
    if(n>10){
        m=2*n*0.9;
    }else{
        m=2*n;
    }
    cout<<fixed<<setprecision(1)<<m;
}
```
