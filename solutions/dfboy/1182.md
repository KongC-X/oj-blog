# 1182 - 大小写转换

## 题目描述

把一个字符串里所有的大写字母换成小写字母，小写字母换成大写字母。其他字符保持不变。

## 输入

输入为一行字符串，其中不含空格。长度不超过 $80$ 个字符。

## 输出

输出转换好的字符串。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;
    int total = 0;
    string a[100]; // 最多100个子串
    int c = 0;
    for(int i = 0; i < s.size() - 2; i++) {
        if(s[i] != s[i+1] && s[i+1] == s[i+2]) {
            string t = s.substr(i, 3);
            total++;
            // 检查是否已经记录过该子串
            bool flag = false;
            for (int j = 0; j < c; ++j) {
                if (a[j] == t) {
                    flag = true;
                    break;
                }
            }
            if (!flag) {
                a[c] = t;
                c++;
            }
        }
    }

    cout << total << " " << c << endl;

    return 0;
}
```
