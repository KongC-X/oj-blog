# 1138 - 求无暇素数

## 题目描述

一个两位整数 $A$ 本身是素数，若将其个位数字与十位数字交换，得到一个新的两位数 $B$ ，而 $B$ 也是素数，我们则称 $A$ 为无暇素数。 例如： $31$ 是素数，个位数字与十位数字交换后得到 $13$ ，也是素数。所以 $31$ 是无暇素数。

问题： 给出一个数字字符串（即字串中的字符全部由数字组成），求出其所有长度为 $2$ 的子串组成的无暇素数。

## 输入

一个数字字符串（长度  ），以"$\%$"结束。

## 输出

全部的无暇素数，之间用一个逗号隔开。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <iomanip>
#include <bits/stdc++.h>
using namespace std;

// s1,s2表示起始点，e1,e2表示终点
int n,s1,s2,e1,e2;
int a[110][110];
bool flag = false; // 假设走不到终点

// 定义数组，存储x和y的变化，第一个为0不用，后面四个分别代表右下左上
int fx[5] = {0,0,1,0,-1};
int fy[5] = {0,1,0,-1,0};
// 深度优先搜索
void dfs(int x,int y) {
    a[x][y] = 1; // 没走为0，走了就设为1
    int tx,ty;
    // 通过循环方向值变化的数组，将x和y的变化逐个相加到x和y上
    for(int i = 1;i <= 4;i++) {
        tx = x + fx[i];
        ty = y + fy[i];
        if(tx >= 1 && tx <= n && ty >= 1 && ty <= n && a[tx][ty] == 0) {
            // 如果走到了终点就把flag设为true
            if(tx == e1 && ty == e2) {
                flag = true;
            } else {
                dfs(tx,ty);
            }
        }
    }
}

int main(){
    cin >> n;
    for(int i=1;i<=n;i++){
        for(int j=1;j<=n;j++){
            cin >> a[i][j];
        }
    }
    cin >> s1 >> s2 >> e1 >> e2;
    // 如果起始点和终点有走不到的情况直接输出no,否则就正常dfs
    if(a[s1][s2] == 1 || a[e1][e2] == 1){
        cout << "NO" << endl;
    } else {
        dfs(s1,s2);
        flag ? cout << "YES" << endl : cout << "NO" << endl;
    }
}

// 优化：
// 请问上述写法如果到了终点，递归会不会立刻停止?
// 不会，通过递归之后输出二维数组可以发现这点!
// 解决方法：在递归之前的判断中，添加flag==false,要求必须没有找到终点，才能递归，从而减少一些无用的递归。
void dfs(int x,int y) {
    a[x][y] = 1;
    int tx,ty;
    // 通过循环方向值变化的数组，将x和y的变化逐个相加到x和y上
    for(int i = 1;i <= 4;i++) {
        tx = x + fx[i];
        ty = y + fy[i];
        if(tx >= 1 && tx <= n && ty >= 1 && ty <= n && a[tx][ty] == 0 && flag == false) {
            if(tx == e1 && ty == e2) {
                flag = true;
            } else {
                dfs(tx,ty);
            }
        }
    }
}
```
