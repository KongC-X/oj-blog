# 1138 - 求无暇素数

## 题目描述

一个两位整数 $A$ 本身是素数，若将其个位数字与十位数字交换，得到一个新的两位数 $B$ ，而 $B$ 也是素数，我们则称 $A$ 为无暇素数。 例如： $31$ 是素数，个位数字与十位数字交换后得到 $13$ ，也是素数。所以 $31$ 是无暇素数。

问题： 给出一个数字字符串（即字串中的字符全部由数字组成），求出其所有长度为 $2$ 的子串组成的无暇素数。

## 输入

一个数字字符串（长度  ），以"$\%$"结束。

## 输出

全部的无暇素数，之间用一个逗号隔开。

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
思路：
第一步：定义函数判断素数
第二步：从第1个字符开始，每次取2位字符，判断2位字符组成的数字是否是无暇素数 
第三步：将所有的无暇素数加上逗号，拼为字符串，最后删除字符串末尾多余的逗号输出 
*/ 

//判断素数
bool sushu(int n){
	//假设是素数，找到因子就不是素数 
	bool f = true;
	//循环n的因子范围
	//利用成对求解因子的思想，只需要循环到sqrt(n)即可 
	for(int i = 2;i <= sqrt(n);i++){
		if(n % i == 0){
			f = false;
			break;//有因子就是素数，不需要继续判断 
		}
	} 
	//判断特殊情况
	if(n <= 1) f = false; 
	return f;
} 

int main() {
	//r用来存放计算结果 
	string s,r;
	int i,x,y;
	cin>>s;
	//循环所有字符，从每个字符开始截取2个字符作为整数来计算
	//由于最后一个字符是%，只要循环到倒数第3个字符（下标：s.size()-3） 
	for(i = 0;i <= s.size() - 3;i++){
		//s[i]十位，s[i+1]个位
		x = (s[i]-'0')*10+(s[i+1]-'0');
		//y是x倒过来的数
		y = (s[i+1]-'0')*10+(s[i]-'0'); 
		if(sushu(x)==true&&sushu(y)==true){
			//cout<<x<<",";//测试
			r = r + s[i] + s[i+1] + ","; 
		} 
	}
	
	//最后一定会多一个逗号，删除
	if(r!="") r.erase(r.size()-1,1); 
	cout<<r;
}
```
