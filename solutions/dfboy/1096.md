# 1096 - 打印字母塔

## 题目描述

输入行数 $n$,打印图形。

## 输入

输入只有一行，包括 $1$ 个整数。( $n \le 15 $)

## 输出

输出有 $n$ 行。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

const int N = 100010;
int a[N];
int n,m,x,s = 0; // 最小差值的和

int main() {
    cin >> m >> n;
    for(int i = 1;i <= m;i++) cin >> a[i];
    sort(a+1,a+m+1); //对学校分数排序，方便二分

    // n个同学
    int left,right,mid;
    for(int i = 1;i <= n;i++) {
        cin >> x; // x: 同学的分数
        // 特殊情况不需要二分的情况
        if(x >= a[m]) s = s + x - a[m];
        else if(x <= a[1]) s = s + a[1] - x;
        else {
            left = 1;
            right = m;
            // 找左边界
            while(left <= right) {
                mid = (left + right) / 2;
                if(x <= a[mid]) right = mid - 1;
                else left = mid + 1;
            }
            // 看left和left-1哪个位置的分数差更小
            // left是第一个大于等于x的位置
            s = s + min(a[left] - x,x - a[left - 1]);
        }
    }
    cout << s << endl;
}
```
