# 1096 - 打印字母塔

## 题目描述

输入行数 $n$,打印图形。

## 输入

输入只有一行，包括 $1$ 个整数。( $n \le 15 $)

## 输出

输出有 $n$ 行。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int i,j,n;
    char c;
    cin >> n;
    // 我们先得到
    //   1
    //  212
    // 32123
    // 循环控制行数
    for(i = 1;i <= n;i++) {
        // 打印每一行的空格数
        for(j = 1;j <= n - i;j++) {
            cout << " ";
        }
        // 打印每一行的数字
        for(j = 1;j <= i;j++) {
            c = i - j + 1 + 64;
            cout << c;
            // cout << i - j + 1;
        }
        for(j = 1;j <= i - 1;j++) {
            c = j + 1 + 64;
            cout << c;
            // cout << j + 1;
        }
        // 打印每一行的换行符
        cout << endl;
    }
}
```
