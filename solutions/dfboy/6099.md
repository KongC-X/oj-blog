# 6099 - 找数

## 题目描述

给定一个包含 $n$ 个互不相同的正整数的数组 $A$ 与一个包含 $m$ 个互不相同的正整数的数组 $B$，请你帮忙计算有多少个数在数组 $A$ 与数组 $B$ 中均出现。

## 输入

第一行包含两个整数 $n,m$。

第二行包含 $n$ 个正整数 $a_1,a_2,\cdots,a_n$ 表示数组 $A$。

第三行包含 $m$ 个正整数 $b_1,b_2,\cdots,b_m$ 表示数组 $B$。

## 输出

输出一个整数，表示在数组 $A$ 与数组 $B$ 中均出现的数的个数。
## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int a[100010];
int n,m,s,b;
int main() {
    cin >> n >> m;
    for(int i = 0;i < n;i++){
        cin >> a[i];
    }
    sort(a,a+n);
    for(int i = 0;i < m;i++) {
        cin >> b;
        int l = 0,r = n - 1;
        bool flag = false;
        while(l <= r) {
            int mid = (l + r) / 2;
            if(a[mid] == b) {
                flag = true;
                break;
            } else if(a[mid] < b) {
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }
        if(flag) {
            s++;
        }
    }
    cout << s << endl;
}
```
