# 1743 - 五位回文偶数

## 题目描述

请求出 $m \sim n$ 之间所有的 $5$ 位回文偶数，有多少个，总和是多少？

回文偶数指的是既是回文数又是偶数的数，比如：$23432、66866$ 等。

## 输入

两个整数 $m$ 和 $n$ 用空格隔开（$m \le n$，且 $m$ 和 $n$ 一定都是 $5$ 位数）。

## 输出

第 $1$ 行输出一个整数，代表 $m \sim n$之间的回文偶数有多少个。

第 $2$ 行输出一个整数，代表 $m \sim n$ 之间的回文偶数总和是多少

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

const int N = 100100;
int a[N];
int n,q; // n个数，q次查询

int fun(int x) {
    int l = 1,r = n,mid;
    while(l <= r) {
        mid = (l + r) >> 1; // 右移运算符，相当于/2
        if(x < a[mid]) r = mid - 1;
        else if(x > a[mid]) l = mid + 1;
        else if(x == a[mid]) r = mid - 1;
    }
    if(a[l] == x) return l;
    else return -1;
}

int main() {
    scanf("%d", &n);
    for(int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }
    scanf("%d", &q);
    int x;
    for(int i = 1; i <= q; i++) {
        scanf("%d", &x);
        // 求x在数组中首次出现的位置
        // cout << fun(x) << " ";
        printf("%d ", fun(x));
    }
}
```
