# 1325 - 表达式的值(III)

## 题目描述

从键盘读入一个格式为 `(a+b)*c`的运算式，请计算该运算式的结果。

如：输入 $(12+13)\times 20$，输出： $500$。

（$4.2.62$）

## 输入

一个如 `(a+b)*c`的运算式。（本题测试数据中 $a、b、c$ 都是int范围的数，计算结果也在int范围）

## 输出

一个整数代表运算结果。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;

int main() {
	int n,i,j,s = 0,c,a = 1;
	cin >> n;
	
	// 单循环
	// for(i = 1;i <= n;i++) {
	// 	a = a * i;
	// 	s += a;
	// }
	// cout << s;

	// 双循环
	for(i = 1;i <= n;i++) {
		c = 1;
		for(j = 1;j <= i;j++) {
			c = c * j;
		}
		s += c;
	}
	cout << s;
}
```
