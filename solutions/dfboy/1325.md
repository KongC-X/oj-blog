# 1325 - 表达式的值(III)

## 题目描述

从键盘读入一个格式为 `(a+b)*c`的运算式，请计算该运算式的结果。

如：输入 $(12+13)\times 20$，输出： $500$。

（$4.2.62$）

## 输入

一个如 `(a+b)*c`的运算式。（本题测试数据中 $a、b、c$ 都是int范围的数，计算结果也在int范围）

## 输出

一个整数代表运算结果。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;
// (a+b)*c
string s,s1,s2,s3;
int x,y,z;
int main(){
	cin>>s;
	int p = s.find("+");
    int q = s.find("*");
	s1 = s.substr(1,p - 1);
	s2 = s.substr(p + 1,q - p - 2);
    s3 = s.substr(q + 1);
	// cout<<s1 << " " << s2 << " " << s3;
	
	//转换整数
	x = stoi(s1);
	y = stoi(s2);
	z = stoi(s3);
	cout << (x + y) * z << endl; 
	return 0;
}
```
