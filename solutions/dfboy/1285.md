# 1285 - 计算N的阶乘

## 题目描述

请计算 $n$ 的阶乘（$1 \le n \le 100$）  

$n$ 的阶乘计算公式为：$n!=n \times (n-1) \times (n-2) \times \dots  \times 1$，如：$5!=5 \times 4 \times 3 \times 2 \times 1=120$。

## 输入

一个整数 $n$($1 \le n \le 100$)。

## 输出

$n$ 的阶乘。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;

int n, m;
bool alive[101];
int main() {
    cin >> n >> m;
    // 初始都在圈中，alive[i] = true表示还在
    for (int i = 1; i <= n; ++i) {
        alive[i] = true;
    }
    int count = 0; // 当前报数的数字
    int remain = n; // 剩余的人数
    int index = 1;  // 当前报数的人

    while (remain > 0) {
        if (alive[index]) {
            count++;
            // 当count等于m时，输出当前人的编号，标记为出圈，重置count，减少剩余人数remain
            if (count == m) {
                cout << index << " ";
                alive[index] = false;
                count = 0;
                remain--;
            }
        }
        index++;
        if (index > n) {
            index = 1; // 循环到第一个人
        }
    }
}
```
