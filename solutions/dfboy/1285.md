# 1285 - 计算N的阶乘

## 题目描述

请计算 $n$ 的阶乘（$1 \le n \le 100$）  

$n$ 的阶乘计算公式为：$n!=n \times (n-1) \times (n-2) \times \dots  \times 1$，如：$5!=5 \times 4 \times 3 \times 2 \times 1=120$。

## 输入

一个整数 $n$($1 \le n \le 100$)。

## 输出

$n$ 的阶乘。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream> 
#include<bits/stdc++.h> 
using namespace std;

int a[1000] = {1};
int n,i,j,k = 1;// k代表数组当前长度
int main() {
	cin >> n;
	// 第一层循环是用来控制循环的次数
	for(i = 1;i <= n;i++) {
		// 第二层循环是有几位要乘i
		for(j = 0;j < k;j++) {
			a[j] = a[j] * i;
		}
		// 处理进位,由于i可能是两位数，所以要加2
		for(j = 0;j < k + 2;j++) {
		    if(a[j] >= 10) {
				a[j + 1] = a[j + 1] + a[j] / 10; // 进位
				a[j] = a[j] % 10;
			}
		}
		// 如果有进位，增加数组长度
		if(a[k + 1] != 0) {
			k += 2;
		} else if(a[k] != 0) {
			k++;
		}
	}
	// 输出结果
	for(i = k - 1;i >= 0;i--) {
		cout << a[i];
	}
}
```
