# 1173 - 求子序列的个数

## 题目描述

给定一串整数数列，求出所有的递增和递减子序列的数目。

如数列 $7，2，6，9，8，3，5，2，1$ 可分为 $（7，2），（2，6，9），（9，8，3）$， $（3，5），（5，2，1）$  $5$ 个子序列，答案就是 $5$ ， 我们称 $2，9，3，5$ 为转折元素。

## 输入

第一行，一个整数 $N$ ( $2 \le N \le 10$ )；

第二行，$N$ 个整数，任意两个相邻的数都不相等。

## 输出

一个整数。

## 解题思路

## AC代码

```cpp
#include <iostream>
using namespace std;
int main() {
	//数组大小按照题目的要求定义，最好多定义10个
	int a[1010],n,i,j,t,k;
	cin>>n>>k;
	for(i=0; i<n; i++) {
		cin>>a[i];
	}

	for(i=1; i<=n-1; i++) {
		for(j=0; j<=n-i-1; j++) {
			//按照从大到小排序
			if(a[j]<a[j+1]) {
				t=a[j];
				a[j]=a[j+1];
				a[j+1]=t;
			}

		}
	}

	//第1大的数，下标是0，第2大的数下标是1，第3大的数下标是2
	//第k大的数，下标是k-1
	cout<<a[k-1];

	return 0;
}
```
