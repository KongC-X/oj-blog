# 1275 - 输出杨辉三角的前N行

## 题目描述

输出杨辉三角的前 $N$ 行( $N \lt 10$ )。

## 输入

输入只有一行，包括 $1$ 个整数 $N$ 。

## 输出

输出只有 $N$ 行。
## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
	int n,i,j;
    int a[11][11] = {0};
	cin>>n;
	for(i = 0;i < n; i++) {
        for(j = 0;j <= i;j++) {
            if(j == 0) {
                a[i][j] = 1;
            } else {
                // 每个数是上一行的两数之和
            	a[i][j] = a[i-1][j-1] + a[i-1][j];
            }
        }
    }
    // 输出杨辉三角形
	for(i = 0;i < n;i++){
		for(j = 0;j <= i;j++){
			cout<<a[i][j]<<" ";
		}
		cout<<endl;
	}
}
```
