# 3478 - 小杨报数

## 题目描述

小杨需要从 $1$ 到 $N$ 报数。在报数过程中，小杨希望跳过 $M$ 的倍数。例如，如果 $N = 5$，$M = 2$ ，那么小杨就需要依次报出 $1$、$3$ 、$5$ 。

现在，请你依次输出小杨报的数。

## 输入

输入 $2$ 行，第一行一个整数 $N$；

第二行一个整数 $M$。

## 输出

输出若干行，依次表示小杨报的数。
## AC代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int n,m,i;
    cin>>n>>m;
    for(i = 1;i <= n;i++) {
        if(i % m != 0) {
            cout<<i<<endl;
        }
    }
}
```
