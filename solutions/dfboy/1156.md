# 1156 - 排除异形基因

## 题目描述

神舟号飞船在完成宇宙探险任务回到地球后，宇航员张三感觉身体不太舒服，去了医院检查，医生诊断结果：张三体内基因已被改变，原有人体基因序列中已经被渗入外星球不明异形生物基因，但可喜的是，这些异形基因都有一个共同的特征，就是该基因序号的平方除以 $7$ 的余数都是 $1$，要赶快清除掉，否则会危害整个人类。赶快行动吧。

## 输入

第一行是一个整数 $n$ （基因个数 $3 \le n \le 200$）；

第二行是 $n$ 个整数（张三的基因序列）。

## 输出

去除异形基因后的正常序列，空格隔开。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;
int main(){
    int a[200],n,i;
    cin>>n;
    for(i=0;i<n;i++){
        cin>>a[i];
        if(a[i]*a[i]%7!=1){
        	cout<<a[i]<<" ";
        }
    }
    return 0;
}
```
