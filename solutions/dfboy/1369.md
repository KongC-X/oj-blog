# 1369 - Pell数列

## 题目描述

有一种数列，它的前 $10$ 项的值分别为：$1$ $2$ $5$ $12$ $29$ $70$ $169$ $408$ $985$ $2378$，这个数列被称为 Pell 数列，请问该数列的第 $n$ 项的值是多少？（$n \le 1000$）

## 输入

一个整数 $n$ 。

## 输出

第 $n$ 项的值。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int a[20][20],n,x = 1,i,j;
int main() {
    cin >> n;
    for(i = 0;i < n;i++) {
        for(j = 0;j <= n - i;j++) {
            a[i][j + i] = i + 1; // 横向
            a[i + j][i] = i + 1; // 纵向
        }
    }
    for(i = 0;i < n;i++) {
        for(j = 0;j < n;j++) {
            cout << setw(3) << a[i][j];
        }
        cout << endl;
    }
}
```
