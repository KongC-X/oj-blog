# 1932 - 舞伴

## 题目描述

小明在A公司工作，小红在B公司工作。这两个公司的员工有一个特点：一个公司的员工都是同性。A公司有 $N$ 名员工，编号为 $1 \sim N$ ，其中有 $P$ 对朋友关系。B公司有 $M$ 名员工，编号为 $-1 \sim -M$，其中有 $Q$ 对朋友关系。

朋友的朋友一定还是朋友。每对朋友关系用两个整数 $(X_i,Y_i)$ 组成，表示朋友的编号分别为 $X_i$,$Y_i$。男人的编号是正数，女人的编号是负数。小明的编号是 $1$ ，小红的编号是 $-1$ 。

大家都知道，小明和小红是朋友。现举办一场舞会，每个人要找一个异性作为自己的舞伴，那么，请你写一个程序求出两公司之间，通过小明和小红认识的人最多一共能组成多少对舞伴。（包括他们自己）

## 输入

第 $1$ 行，$4$ 个空格隔开的正整数 $N,M,P,Q$ 。

之后 $P$ 行，每行两个正整数 $X_i$,$Y_i$ 。

之后 $Q$ 行，每行两个负整数 $X_i$,$Y_i$ 。

$N,M \le 10000$, $P,Q \le 20000$ 。

## 输出

一行，一个正整数，表示通过小明和小红认识的人最多一共能组成多少对舞伴。（包括他们自己）
## AC代码

```cpp
// 也可以用种类并查集的思想解决

#include <bits/stdc++.h>
using namespace std;

int f[20010];                     // 并查集数组，大小要能容纳 A公司(n) + B公司(m)，多开10个

// 并查集查找：找到 x 所属集合的根，同时进行路径压缩
int find(int x){
    return f[x] == x ? x : f[x] = find(f[x]);
}

// 并查集合并：将 x 和 y 所在的两个集合合并
void merge(int x, int y){
    int fx = find(x);
    int fy = find(y);
    if(fx != fy){
        f[fx] = fy;              // 将一个根指向另一个根
    }
}

int main(){
    int n, m, p, q;              // n:A公司男员工数, m:B公司女员工数, p:A公司朋友关系数, q:B公司朋友关系数
    cin >> n >> m >> p >> q;

    // ---------- 解题思路 ----------
    // A公司（男）编号 1~n，B公司（女）原编号 -1~-m。
    // 为了用一个并查集处理两个公司，我们将 B 公司的编号取绝对值后加上 n，
    // 映射到 n+1 ~ n+m 区间。这样，小明是 1，小红是 n+1。
    //
    // 小明和小红是朋友，相当于桥梁。小明能接触到的男性都在 find(1) 集合中，
    // 小红能接触到的女性都在 find(n+1) 集合中。
    // 因为小明和小红相识，这两个集合中的任意一对男女都可以通过他们成为舞伴。
    // 因此，最多能组成的舞伴对数 = min(小明所在集合的男性数, 小红所在集合的女性数)。

    int ra = 0, rb = 0;          // ra: 小明所在集合的男性人数, rb: 小红所在集合的女性人数

    // 初始化并查集，共 n+m 个人
    for(int i = 1; i <= n + m; i++) f[i] = i;

    // 读入 A 公司的 p 对朋友关系（编号均为正整数）
    int x, y;
    for(int i = 1; i <= p; i++){
        cin >> x >> y;
        merge(x, y);             // 直接将两个男性连入同一集合
    }

    // 读入 B 公司的 q 对朋友关系（编号均为负整数）
    for(int i = 1; i <= q; i++){
        cin >> x >> y;
        x = x * -1;              // 取绝对值，变成正数
        y = y * -1;
        merge(x + n, y + n);     // 加上偏移量 n，映射到 n+1~n+m 范围后再合并
    }

    // 统计与小明（编号 1）同属一个集合的男性人数
    for(int i = 1; i <= n; i++){
        if(find(i) == find(1)) ra++;
    }

    // 统计与小红（编号 n+1）同属一个集合的女性人数
    for(int i = n + 1; i <= n + m; i++){
        if(find(i) == find(n + 1)) rb++;
    }

    // 舞伴对数由较少的一方决定
    cout << min(ra, rb) << endl;
    return 0;
}
```
