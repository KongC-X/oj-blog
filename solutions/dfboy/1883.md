# 1883 - 求n个数中出现次数最多的数

## 题目描述

从键盘读入 $n$ 个整数（ $n \le 100$ ），这 $n$ 个数都是 $1 \sim 10$ 之间的数，请求出出现次数最多的数是哪个数？

比如：假设读入 $5$ 个数，分别为 $1$ $2$ $3$ $3$ $5$ ，出现次数最多的数就是 $3$ 。（本题的数据确保出现次数最多的数只有 $1$ 个，不存在多个数出现的次数都最多的情况）

## 输入

第 $1$ 行输入一个整数 $n$ 。

第 $2$ 行输入 $n$ 个整数，用空格隔开。

## 输出

输出出现次数最多的数。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;
int a[20]; // 统计数组
int main() {
    int n,i,m;
    cin >> n;
    for(i = 0; i < n; i++) {
        cin >> m;
        a[m]++;
    }
    int max = 1;
    for(i = 1;i <= 10; i++) {
        if(a[i] > a[max]) {
            max = i;
        }
    }
    cout << max << endl;
}
```
