# 1883 - 求n个数中出现次数最多的数

## 题目描述

从键盘读入 $n$ 个整数（ $n \le 100$ ），这 $n$ 个数都是 $1 \sim 10$ 之间的数，请求出出现次数最多的数是哪个数？

比如：假设读入 $5$ 个数，分别为 $1$ $2$ $3$ $3$ $5$ ，出现次数最多的数就是 $3$ 。（本题的数据确保出现次数最多的数只有 $1$ 个，不存在多个数出现的次数都最多的情况）

## 输入

第 $1$ 行输入一个整数 $n$ 。

第 $2$ 行输入 $n$ 个整数，用空格隔开。

## 输出

输出出现次数最多的数。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

const int N = 100100;
int a[N];
int n,q; // n个数，q次查询

int fun(int x) {
    int l = 1,r = n,mid;
    while(l <= r) {
        mid = (l + r) >> 1; // 右移运算符，相当于/2
        if(x < a[mid]) r = mid - 1;
        else if(x > a[mid]) l = mid + 1;
        else if(x == a[mid]) r = mid - 1;
    }
    if(a[l] == x) return l;
    else return -1;
}

int main() {
    scanf("%d", &n);
    for(int i = 1; i <= n; i++) {
        scanf("%d", &a[i]);
    }
    scanf("%d", &q);
    int x;
    for(int i = 1; i <= q; i++) {
        scanf("%d", &x);
        // 求x在数组中首次出现的位置
        // cout << fun(x) << " ";
        printf("%d ", fun(x));
    }
}
```
