# 1159 - 数组元素的移动

## 题目描述

数组元素的移动，把数组的第 $x$ 个位置的元素先保存起来，然后把 $x+1$ 到 $n$ 的元素，依次往前移一位，最后原来的第 $x$ 个位置的元素放在最后。

## 输入

有 $3$ 行

第一行有一个整数 $n$ ($ n \le 10$ )；

第二行有 $n$ 个整数；

第三行有一个整数 $x$ 。

## 输出

移动后的数组。
## AC代码
## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int a[20],n,i,x;
int main() {
    cin >> n;
    for(i = 1; i <= n;i++) {
        cin >> a[i];
    }
    cin >> x;
    int t = a[x]; // 保存一下
    for(i = x;i <= n;i++) {
        a[i] = a[i+1];
    }
    a[n] = t;
    for(i = 1;i <= n;i++) {
        cout << a[i] << " ";
    }
}
```
