# 1934 - 数字游戏（number）

## 题目描述

小 K 同学向小 P 同学发送了一个长度为 $8$ 的 **01 字符串**来玩数字游戏，小 P 同学想要知道字符串中究竟有多少个 1。

注意：$01$ 字符串为每一个字符是 $0$ 或者 $1$ 的字符串，如 “$101$” （不含双引号）为一个长度为 $3$ 的 $01$ 字符串。

## 输入

输入文件只有一行，一个长度为 $8$ 的 $01$ 字符串 $s$。

## 输出

输出文件只有一行，包含一个整数，即 $01$ 字符串中**字符 1** 的个数。

## 解题思路

## AC代码

```cpp
// 思路：用 map 统计出每个分数出现的次数，按照分数降序排序，再将分数出现的次数修正

#include <bits/stdc++.h>
#include <iostream>
#include <map>
using namespace std;
 
//存放分数（key）以及分数出现的次数（value） 
map<int,int,greater<int> > m;
int n,i,c = 0,a[100100],t;
 
int main(){
    scanf("%d", &n);
    for(i = 0;i < n;i++){
        scanf("%d", &a[i]);
        //判断该分数在map中是否存在
        if(m.count(a[i]) == 0){
            //将分数存入map，记录值为1（分数出现的次数） 
            m[a[i]] = 1;
        }else{
            m[a[i]]++; 
        } 
    }
     
    //修正map的value为排名 
    map<int,int>::iterator it;
    for(it = m.begin();it != m.end();it++){
        t = it->second;
        m[it->first] = c + 1;//修正排名 
        c = c + t;//统计每个分数之前有几个人 
    }
     
    //输出每个分数的排名
    for(i = 0;i < n;i++){
        printf("%d\n", m[a[i]]);
    } 
    return 0;
}
```
