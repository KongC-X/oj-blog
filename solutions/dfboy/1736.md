# 1736 - 班长问题？

## 题目描述

小明暑期开学后，老师们委托小明为某班级选取一个班长，选取要求：要求选取的班长为班级中年龄最大的那位，已知该班级中有 $5$ 位同学，每位同学的年龄都不相同。

## 输入

$5$ 个整数（小于 $100$ ），分别表示该班级中 $5$ 位同学的年龄。

## 输出

一个整数，表示班长的年龄。

## 解题思路

## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	//分别表示该班级中5位同学的年龄
    int a,b,c,d,e;
    //输入成绩 
    cin>>a>>b>>c>>d>>e;
    //用于存放较大的年龄 
    int x;
    //找出最大的年龄 
    x=a;
    if(x<b){
        x=b;
    }
    if(x<c){
        x=c;
    }
    if(x<d){
        x=d;
    }
    if(x<e){
        x=e;
    }
    //输出最大的年龄 
    cout<<x;
	return 0;
}
```
