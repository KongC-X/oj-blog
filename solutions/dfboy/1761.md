# 1761 - 最大子集

## 题目描述

有 $N$ 个**互不相同**的整数，另外给定一个正整数 $T$，定义两个整数 $x,y$（$x≤y$） 不冲突的条件为，$y \neq T \times x$。

请求出该集合的最大子集，要求子集中的元素互不冲突。

## 输入

第一行给定两个数 $N$ 和 $T$ （$1≤N≤10^5$, $1≤T≤10^9$）。

接下来一行包含 $N$ 个不同正整数 $a_i$（ $1≤a_i≤10^9$）。

## 输出

输出最大互不冲突子集的数量。

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

vector<int> v;
int n,m,op;
int x,y,z;

int main() {
	cin>>n>>m;
	for(int i = 1; i <= n; i++) {
		scanf("%d",&x);
		v.push_back(x);
	}

	while(m--) {
		cin>>op;
		if(op == 1) {
			cin>>x>>y;
			if(x == 0) v.insert(v.begin(),y);
			else v.insert(v.begin()+x,y);
		} else if(op == 2) {
			cin>>x;
			v.erase(v.begin()+x-1);
		} else if(op == 3) {
			cin>>x>>y;
			sort(v.begin()+x-1,v.begin()+y);
		} else if(op == 4) {
			cin>>x>>y;
			reverse(v.begin()+x-1,v.begin()+y);
		} else if(op == 5) {
			cin>>x>>y>>z;
			int c = 0;//讨论数字的个数
			int i = x - 1;
			while(i <= y - 1 && c < (y-x+1)) {
				if(v[i] == z) {
					v.erase(v.begin()+i);
				} else{
					i++;
				}
				c++;
			}
		}
	}
	for(int i = 0; i < v.size(); i++) {
		printf("%d ",v[i]);
	}
	return 0;
}
```
