# 1393 - 与7无关的数？

## 题目描述

一个整数，如果这个数能够被 $7$ 整除，或者其中有一位是 $7$，我们称为这个数是与 $7$ 有关的数。比如： $14$ 能被 $7$ 整除，$17$ 有一位为 $7$ ，这两个数都是与 $7$ 有关的数。

请你编程求出 $1 \sim n（n \le 999）$ 中，与 $7$ 无关的数的总和是多少？

比如 $1 \sim 10$ 中与 $7$ 无关的数的和为：$1+2+3+4+5+6+8+9+10=48$ 。

## 输入

一个整数 $n（n \le 999）$ 。

## 输出

$1 \sim n$ 中与 $7$ 无关的数的总和。
## AC代码

```cpp
# include <iostream>
using namespace std;

int main(){
    int i,n,a,b,c,s = 0;
    cin >> n;
    for(i = 1;i <= n;i++) {
        a = i / 100;
        b = i % 100 / 10;
        c = i % 10;
        if(i % 7 != 0 && a != 7 && b != 7 && c != 7) {
            s+=i;
        }
    }
    cout << s;
}
```
