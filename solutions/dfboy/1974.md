# 1974 - 字母矩形1

## 题目描述

输入一个整数 $n$，打印 $n$ 行 $n$ 列的字母矩形。

比如，假设 $n=3$，那么打印 $3$ 行 $3$ 列的字母矩形如下：

```
`AAA
BBB
CCC
`
```

## 输入

一个整数。（$0\lt n \lt 10$）

## 输出

$n$ 行 $n$ 列的字母矩形。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
#include<iostream>
#include<set>
using namespace std;

int n,ans,m;
multiset<int> s;
int x;

int main() {
	cin>>n>>m;
	for(int i=1; i<=n; i++) {
		cin>>x;
		s.insert(x);
	}
	multiset<int>::iterator it;
	for(it = s.begin();it != s.end();it++){
        ans += s.count(m+*it); // 这里必须使用s.count()，count函数作用是统计元素出现的次数
		// 如果使用s.find(m+*it)，则只能找到第一个匹配的元素，无法统计重复元素
		// if(s.find(m+*it) != s.end()) {
		// 	ans++;
		// }
	}
	cout<<ans<<endl;
	return 0;
}
```
