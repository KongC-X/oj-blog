# 1749 - 有哪些闰年

## 题目描述

闰年的判断有两个条件，只需满足一个即可

$1、$ 能够被 $4$ 整除但不能被 $100$ 整除的为闰年；

$2、$ 能够被 $400$ 整除的为闰年；

比如： $1996$ 年就是闰年。

请编程计算出，从 $1900$ 年 $ \sim n$ 年之间有多少个闰年？

## 输入

一个整数 $n（n$ 是一个 $ \ge 1900$ 的四位整数）。

## 输出

一个整数，代表 $1900$ 年 $ \sim n$ 年之间闰年的有多少个。

## 解题思路

## AC代码

```cpp
// 按照给定的顺序，模拟入栈出栈的过程。
// 比如给定出栈顺序是：3,4,2,1,5，用vector存储。
// 那么，模拟入栈出栈过程如下：
// 入栈1
// 入栈2
// 入栈3，因为第1个出栈是3，说明3此时立刻出栈了，因此3从栈中弹出，也从vector中删除，删除后栈顶元素是2和4匹配不上
// 入栈4，栈顶元素和当前vector第1个数匹配，说明应该出栈，同时从vector中删除，接下来发现2和1也匹配，因此都删除。
// 入栈5，匹配，删除，此时vector和stack都为空。

#include<bits/stdc++.h>
using namespace std;

stack<int> st;
vector<int> v;
int m,n,x;

int main() {
	cin>>m;//数据量 
	while(m--){
		//清空vector和stack
		v.clear();
		while(!st.empty()) st.pop();
		
		//读入
		cin>>n;
		for(int i = 1;i <= n;i++){
			cin>>x;
			v.push_back(x);//出栈顺序 
		} 
		
		//匹配当前出栈顺序
		for(int i = 1;i <= n;i++){
			st.push(i);
			
			//尝试匹配st的栈顶元素和v的第1个元素
			while(!st.empty()&&!v.empty()&&st.top()==v.front()){
				//删除
				st.pop();//栈弹出栈顶元素
				v.erase(v.begin()); 
			} 
		}
		
		//模拟结束后，栈和vector应该都是空的
		if(st.empty() && v.empty()) cout<<"Yes"<<endl;
		else cout<<"No"<<endl; 
	}
	return 0;
}
```
