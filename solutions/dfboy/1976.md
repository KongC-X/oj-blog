# 1976 - 字母直角1

## 题目描述

输入一个整数 $n$，打印 $n$ 行的字母直角。

比如，假设 $n=3$ ，那么打印 $3$ 行的字母直角如下：

```
`A
AB
ABC
`
```

## 输入

一个整数（$0 \lt n \lt 10$）

## 输出

$n$ 行的字符直角。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int i,j,n;
    char c;
    cin >> n;
    // 循环控制行数
    for(i = 1;i <= n;i++) {
        // 打印每一行的数字
        for(j = 1;j <= i;j++) {
            c = j + 64;
            cout << c;
        }
        // 打印每一行的换行符
        cout << endl;
    }
}
```
