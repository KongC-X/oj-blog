# 1976 - 字母直角1

## 题目描述

输入一个整数 $n$，打印 $n$ 行的字母直角。

比如，假设 $n=3$ ，那么打印 $3$ 行的字母直角如下：

```
`A
AB
ABC
`
```

## 输入

一个整数（$0 \lt n \lt 10$）

## 输出

$n$ 行的字符直角。

## 解题思路

## AC代码

```cpp
/*
第一步：用string读入高精度整数
第二步：将两个高精度整数逆序存入ab两个整数数组
第三步：从左向右，逐位求和，结果存入c数组从左向右，逐位进位
第四步：逆序输出结果
*/

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

string s1,s2;
int a[250],b[250],c[250];
int i,p,len;
int main() {
    cin >> s1 >> s2;
    // 逆序存入整数数组中
    for(i = s1.size() - 1;i >= 0;i--) {
        a[i] = s1[s1.size() - 1 - i] - '0';
    }
    for(i = s2.size() - 1;i >= 0;i--) {
        b[i] = s2[s2.size() - 1 - i] - '0';
    }
    // 加法的次数取决于较长的那个字符串
    len = s1.size() > s2.size() ? s1.size() : s2.size();
    // 验证
    // for(i = 0;i < len;i++) {
    //     cout << a[i] << " ";
    // }
    // 逐位相加
    for(i = 0;i < len;i++) {
        c[i] = a[i] + b[i];
    }
    // 进位
    for(i = 0;i < len;i++) {
        if(c[i] >= 10) {
            c[i + 1] = c[i + 1] + c[i] / 10;
            c[i] = c[i] % 10;
        }
    }
    // 两个不超过len位的整数做加法，结果可能是len+1位
    if(c[len] != 0) {
        len++;
    }
    // 逆序输出结果
    for(i = len - 1;i >= 0;i--){
        cout << c[i];
    }
}
```
