# 1040 - 求三个数的大小顺序

## 题目描述

输入三个数，按由大到小顺序打印出来。

## 输入

输入只有一行，包括 $3$ 个整数，之间用一个空格分开。

## 输出

输出只有一行，包括 $3$ 个整数，之间用一个空格分开。
## AC代码
## AC代码

```cpp
#include <iostream>
using namespace std;

int main(){
	//定义变量a,b,c,t
	int a,b,c,t;
	//输入a,b,c
	cin>>a>>b>>c;
	
	//排队法从大到小排序 
	//第一轮比较
	//如果a<b,交换a和b的位置
	if(a<b){
		t = a;
		a = b;
		b = t;
	}
	//如果b<c,交换b和c的位置
	if(b<c){
		t = b;
		b = c;
		c = t;
	}
	//此时c一定存储了最小的数
	//第二轮比较
	//比较a和b的大小,如果b>a,交换a和b的位置 
	if(b>a){
		t = a;
		a = b;
		b = t;
	} 
	
	cout<<a<<" "<<b<<" "<<c; 
	return 0;
}
```
