# 1249 - 搬砖问题

## 题目描述

$36$ 块砖， $36$ 人搬。男搬 $4$ ，女搬 $3$ ，两个小儿抬一砖。

要求一次全搬完。问需男、女、小儿各若干？

注意：假设男、女、小孩都有，请按照男、女、小孩的顺序输出所有可能的人数分配，每种人数分配方案占 $1$ 行，每个数字空格隔开。

## 输入

无

## 输出

所有可能的人数分配方案，按照由小到大输出。

## 解题思路

## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int a[200],i,n,s = 0;
    double v;
    cin >> n;
    for(i = 0; i < n; i++) {
        cin >> a[i];
        s += a[i];
    }
    cout << s << endl; // 总分
    v = s * 1.0 / n;
    printf("%.2f\n",v); // 平均分
    // 从大到小冒泡排序
    for(i = 0; i < n - 1; i++) {
        for(int j = 0; j < n - i - 1; j++) {
            if(a[j] < a[j + 1]) {
                int t = a[j];
                a[j] = a[j + 1];
                a[j + 1] = t;
            }
        }
    }
    for(i = 0; i < n; i++) {
        cout << a[i] << " ";
    }
}
```
