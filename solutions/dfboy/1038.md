# 1038 - 编程求解数学中的分段函数

## 题目描述

编程求解数学中的分段函数。

$ \dots \dots \dots \dots x+1$ (当 $x \gt 0$ )。

$y=f(x)= \dots 0$ (当 $x=0$ )。

$ \dots \dots \dots \dots x-1$ (当 $x \lt 0$ )。

上面描述的意思是：当 $x \gt 0$ 时 $y=x+1$ ; 当 $x=0$ 时 $y=0$ ; 当 $x \lt 0$ 时 $y=x-1$ 。

## 输入

输入一行，只有一个整数 $x(-30000 \le x \le 30000$ )。

## 输出

输出只有一行，包括 $1$ 个整数(即 $y$ )。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
#include<iomanip>
using namespace std;
int main(){
	int x,y;
	cin>>x;
	if(x>0){
		y=x+1;
	}
	else if(x<0){
		y=x-1;
	}
	else{
		y=0;
	}
	cout<<y;
	return 0; 
}
```
