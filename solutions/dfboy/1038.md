# 1038 - 编程求解数学中的分段函数

## 题目描述

编程求解数学中的分段函数。

$ \dots \dots \dots \dots x+1$ (当 $x \gt 0$ )。

$y=f(x)= \dots 0$ (当 $x=0$ )。

$ \dots \dots \dots \dots x-1$ (当 $x \lt 0$ )。

上面描述的意思是：当 $x \gt 0$ 时 $y=x+1$ ; 当 $x=0$ 时 $y=0$ ; 当 $x \lt 0$ 时 $y=x-1$ 。

## 输入

输入一行，只有一个整数 $x(-30000 \le x \le 30000$ )。

## 输出

输出只有一行，包括 $1$ 个整数(即 $y$ )。

## 解题思路

## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int a[110],n,i,x;
    cin >> n;
    for (i=0;i<n;i++) cin >> a[i];
    cin >> x;
    // 第一种方法：假装删除，遇到下标为x不输出
    x--;
    for(i = 0;i < n;i++) {
        if(i != x) cout << a[i] << " ";
    }
    // 第二种方法：真的删除，把后面的元素往前移
    for(i = x-1;i < n-1;i++) {
        a[i] = a[i+1];
    }
    for (i=0;i<n-1;i++) cout << a[i] << " "; // n-1
}
```
