# 1169 - 编程输入10个正整数，然后自动按从大到小的顺序输出

## 题目描述

编程输入 $10$ 个正整数，然后自动按从大到小的顺序输出。

## 输入

输入只有一行，包括 $10$ 整数。

## 输出

输出只有一行,包括 $10$ 个整数。
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int a[20],i;
int main(){
	for(i=1;i<=10;i++){
		cin>>a[i];
	}
	sort(a+1,a+10+1);
	for(i=10;i>=1;i--) cout<<a[i]<<" ";
	return 0;
}
```
