# 1331 - 做彩纸花边

## 题目描述

李晓芳用一条长为 $n$ 米的彩纸制作花边，每朵花李晓芳用一条长为 $n$ 米的彩纸制作花边，每朵花的宽度为 $x$ 厘米，花与花之间的间隔为 $y$ 厘米。请问 $n$ 米的彩纸最多能做多少朵花的花边。

如，图中的案例花的宽度为 $4.5cm$ ，花之间的间隔为$1.2cm$ ，那么一条长为 $0.62m$ 的彩纸最多可以做 $11$ 朵花的花边（因为一朵花加一个间隔是 $5.7cm$ ， $10$ 朵花以及间隔共 $57cm$，剩余 $5cm$ 还可以再做一朵花，因此最多共可以做 $11$ 朵花）（5.1.81）。

## 输入

三个小数 $n、x、y$，用空格隔开。

## 输出

最多能做多少朵花的花边。

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	char s[110];
	char c;
	cin>>s>>c;
	//假删除：遍历每个字符，除了要删除的字符c以外，剩余的输出 
	int i;
	for(i = 0;i < strlen(s);i++){
		if(s[i] != c){
			cout<<s[i];
		}
	} 
}


// 真删除：新建一个数组，不等于c的都存进去
#include<bits/stdc++.h>
using namespace std;

int main()
{
    char a[1000], c, b[1000];
    cin >> a >> c;
    int k = 0;
    for(int i = 0; a[i]; i++)
    {
        if(a[i] != c) b[k++] = a[i];
    }
    b[k] = '\0';
    cout << b;
    return 0;
}
```
