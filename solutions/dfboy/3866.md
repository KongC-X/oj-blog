# 3866 - 小杨的幸运数字

## 题目描述

小杨认为他的幸运数字应该恰好有两种不同的质因子，例如 $12=2 \times 2 \times 3$ 的质因子有 $2，3$，恰好为两种不同的质因子，因此 $12$ 是幸运数字，而$30=2 \times 3 \times 5$ 的质因子有 $2，3，5$，不符合要求，不为幸运数字。

小杨现在有 $n$ 个正整数，他想知道每个正整数是否是他的幸运数字。

## 输入

第一行包含一个正整数 $n$，代表正整数个数。

之后 $n$ 行，每行一个正整数。

## 输出

输出 $n$ 行，对于每个正整数，如果是幸运数字，输出 $1$，否则输出 $0$。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int i,j,n,a[50][50],x,y;
int main() {
    cin >> n;
    // 设置初始坐标为第一行正中央
    x = 0;
    y = n / 2;
    a[x][y] = 1; // 设定第一行正中央为1
    for(i = 2;i <= n * n;i++) { //重复第二步和第三步操作，总共需要n*n次
        int tx = (x - 1 + n) % n; //上次填数位置x坐标变化
        int ty = (y + 1) % n; //上次填数位置y坐标变化
        if(a[tx][ty] == 0) { //如果新位置为空，则填入数字
            a[tx][ty] = i; //填数
        } else { //第二步没成功做第三步操作
            tx = (x + 1) % n; //上次填数位置x坐标变化
			ty = y; //y坐标不变
			a[tx][y]=i; // 填数
        }
        x = tx; //更新x坐标
        y = ty; //更新y坐标
    }
    for(i = 0;i < n;i++) { //输出结果
        for(j = 0;j < n;j++) {
            cout << a[i][j] << " ";
        }
        cout << endl;
    }
}
```
