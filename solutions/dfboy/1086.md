# 1086 - 姐妹数对

## 题目描述

给定两个不同的正整数 $x,y$，若 $x+y$ 能被 $3$ 除尽或能被 $7$ 除尽，则称 $x,y$ 为姐妹数对。

例如：

 $2,4$、$2,5$，为姐妹数对。

 $3,14$，不是姐妹数对。

那么，对给出的一个整数 $n(1 \le n \le 100)$ ，$ 1,2,\dots,n$ 之间有多少个姐妹数。

## 输入

一个整数 $n$ 。

## 输出

一个整数，即 $1 \sim n$ 之间姐妹数对的个数。

## 解题思路

## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main(){
    int n,x;
    cin>>n;
    queue<int> q;
    for(int i=1;i<=n;i++){
        cin>>x;
        q.push(x);
    }
    while(!q.empty()){
        cout<<q.front()<<" ";
        q.pop();
        q.push(q.front());
        q.pop();
    }
    return 0;
}
```
