# 1086 - 姐妹数对

## 题目描述

给定两个不同的正整数 $x,y$，若 $x+y$ 能被 $3$ 除尽或能被 $7$ 除尽，则称 $x,y$ 为姐妹数对。

例如：

 $2,4$、$2,5$，为姐妹数对。

 $3,14$，不是姐妹数对。

那么，对给出的一个整数 $n(1 \le n \le 100)$ ，$ 1,2,\dots,n$ 之间有多少个姐妹数。

## 输入

一个整数 $n$ 。

## 输出

一个整数，即 $1 \sim n$ 之间姐妹数对的个数。

## 解题思路

## AC代码
## AC代码

```cpp
#include <iostream>
using namespace std;

int main() {
	int n,i,j,sum,num = 0;
	cin >> n;
	for(i = 1;i < n;i++) {
		for(j = i + 1;j <= n;j++) {
			sum = i + j;
			if (sum % 3 == 0 || sum % 7 == 0) {
				num++;
			}
		}
	}
	cout << num;
}
```
