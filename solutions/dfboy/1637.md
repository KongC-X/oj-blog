# 1637 - 水果批发

## 题目描述

水果商店批发桔子， $100$ 千克或 $100$ 千克以下，每千克 $2$ 元。超过 $100$ 千克，超过部分每千克 $1$ 元。输入批发重量求批发价格。

## 输入

一行，一个整数，代表水果重量。

## 输出

一行，一个整数，代表水果价钱。
## AC代码
## AC代码

```cpp
#include <iostream>
#include <iomanip>
using namespace std;
 
int main(){
    int w,p;
    cin>>w;
    if(w<=100){
        p=2*w;
    }else{
        p=2*100+w-100;
    }
    cout<<p;
}
```
