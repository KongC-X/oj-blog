# 1605 - 求一个两位数的个位和十位的和

## 题目描述

从键盘读入一个两位的整数 $n$ ，请求出这个两位整数个位和十位的和是多少？

## 输入

一个两位的整数 $n$ 。

## 输出

一个整数，代表 $n$ 个位和十位的和。

## 解题思路

## AC代码

```cpp
# include <iostream>
# include <iomanip>
using namespace std;

int main() {
    int n,a,b,m;
    cin >> n;
    a = n / 10;
    b = n % 10;
    m = b * 10 + a;
    if (m > n) {
        cout << m << endl;
    } else {
        cout << n << endl;
    }
}
```
