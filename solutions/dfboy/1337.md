# 1337 - 求花坛的面积

## 题目描述

龙湖校区有一个圆形花坛，量得花坛周围的篱笆长是 $x$ 米，请问该花坛的面积是多少平方米？（假设 $π=3.14$）。（5.2.99）

## 输入

一个小数 $x$。

## 输出

花坛的面积（结果保留 $2$ 位小数）

## 解题思路

## AC代码

```cpp
#include<iostream>
using namespace std;

int main() {
    int i,j,n;
    char c;
    cin >> n;
    // 循环控制行数
    for(i = 1;i <= n;i++) {
        // 打印每一行的数字
        for(j = 1;j <= n;j++) {
            c = i + 64;
            cout << c;
        }
        // 打印每一行的换行符
        cout << endl;
    }
}
```
