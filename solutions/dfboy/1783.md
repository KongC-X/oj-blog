# 1783 - 数字直角（1）

## 题目描述

请打印 $n$ 行的数字直角三角形。

## 输入

一个整数 $n$（$n \lt 10$）。

## 输出

输出如下方图所示 $n$ 行的数字直角三角形。
## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int i,j,n;
    cin >> n;
    for(i = 1;i <= n;i++) {
        for(j = 1;j <= i;j++) {
            cout << i;
        } 
        cout << endl;
    }
}
```
