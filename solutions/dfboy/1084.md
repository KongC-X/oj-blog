# 1084 - 因子求和

## 题目描述

已知一个正整数 $N$（ $20 \le N \le 800000000$ ），请你编写程序求出该数的全部因子（不包括 $1$ 和 $n$ ）的和。

## 输入

一个正整数 $n$ 。

## 输出

一个整数代表 $n$ 的因子和。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h> 
using namespace std;

int fun(int n) {
	int r=0;
	for(int i=2;i<=sqrt(n);i++) {
		if(n%i == 0) {
			if(i == sqrt(n)) {
				r+=i;
			} else {
				r=r+i+(n/i);
			}
		} 
	}
	return r; 
}
int main() {
	int n;
	cin>>n;
	cout<<fun(n);
	return 0; 
}
```
