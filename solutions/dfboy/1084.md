# 1084 - 因子求和

## 题目描述

已知一个正整数 $N$（ $20 \le N \le 800000000$ ），请你编写程序求出该数的全部因子（不包括 $1$ 和 $n$ ）的和。

## 输入

一个正整数 $n$ 。

## 输出

一个整数代表 $n$ 的因子和。

## 解题思路

## AC代码

```cpp
#include<iostream>
#include<cmath>
using namespace std;

int main() {
    int i,max = 0,x,n,s;
    cin >> n;
    for(i = 0;i <= 1200/n;i++) {
        s = (30 + i) * (1200 - n * i);
        if(s > max) {
            max = s;
            x = 30 + i;
        }
    }
    cout << x << ' ' << max << endl;
}
```
