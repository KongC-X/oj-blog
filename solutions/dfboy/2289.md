# 2289 - 数字判断

## 题目描述

输入一个字符，如果输入的字符是数字，输出yes，否则输出no

## 输入

一个字符

## 输出

如果输入的字符是数字，输出yes，否则输出no
## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
char c;
cin>>c;
if(c>='0'&&c<='9'){
	cout<<"yes";
}else{
	cout<<"no";
}



}
```
