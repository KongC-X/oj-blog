# 1343 - 种蔬菜

## 题目描述

王阿姨在一块蔬菜地种了 $4$ 种不同的蔬菜，分别是：番茄、黄瓜、韭菜、萝卜，四种蔬菜共占地 $80$ 平方米；其中已知番茄、黄瓜、韭菜的分别占总土地的 $a\%、b\%、c\%$（$a、b、c$一定是整数），请计算出番茄、黄瓜、韭菜、萝卜分别占地多少平方米。（$6.2.7$）

## 输入

$3$ 个百分数，分别代表番茄、黄瓜、韭菜的占地百分比。(每个百分数之间用空格隔开)

## 输出

番茄、黄瓜、韭菜、萝卜的占地面积，数与数之间用空格隔开，保留 $1$位小数。

```cpp
#include <iostream>
#include <cstdio>
using namespace std;

int main() {
    string s1, s2, s3;
    cin >> s1 >> s2 >> s3;

    // 去掉百分号并转整数
    int a = stoi(s1.substr(0, s1.length() - 1));
    int b = stoi(s2.substr(0, s2.length() - 1));
    int c = stoi(s3.substr(0, s3.length() - 1));
    int d = 100 - a - b - c;

    double total = 80.0;
    double v1 = total * a / 100.0;
    double v2 = total * b / 100.0;
    double v3 = total * c / 100.0;
    double v4 = total * d / 100.0;

    printf("%.1f %.1f %.1f %.1f\n", v1, v2, v3, v4);
    return 0;
}
```
