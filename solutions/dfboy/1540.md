# 1540 - 小X数字母

## 题目描述

小 X 喜欢研究字符串。

这天，小 X 随手在草稿纸上写下了一个大写字母字符串。此时，班长把成绩报告单发到了每位同学的手中。小 X 看到自己每门都是 `A` （优秀），非常高兴，灵光一闪想到一个问题：
在刚刚写下的字符串中，字母 `A` 最多连续出现了多少次呢？

小 X 立刻数了起来，但这个字符串实在是太长了，希望你帮帮他。

## 输入

第一行包含一个整数 $N$ ，表示字符串长度。

第二行包含一个字符串。

## 输出

第一行包含一个整数，表示该字符串中字母 `A` 最多连续出现的次数。
