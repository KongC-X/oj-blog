# 1003 - 编程求1+3+5+...+n

## 题目描述

编程求 $1+3+5+ \dots +n$ 。

## 输入

输入一行，只有一个整数 $n (1 \le n \lt 10000)$ 这里 $n$ 为奇数。

## 输出

输出只有一行。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
	//i,j,k分别代表红，白，黑球
	//s用作计数器 
	int i,j,k,s=0;
	//遍历取出的8个球中，红色球可能的个数 
	for(i=0;i<=3;i++){
		//遍历取出的8个球中，白色球可能的个数 
		for(j=0;j<=3;j++){
			//遍历取出的8个球中，黑色球可能的个数 
			for(k=0;k<=6;k++){
				//三种颜色的球个数总和要等于8 
				if(i+j+k==8){
					s++;
				}
			}
		}
	}
	cout<<s;
	return 0;
}
```
