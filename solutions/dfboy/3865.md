# 3865 - 黑白格

## 题目描述

小杨有一个 $n$ 行 $m$ 列的网格图，其中每个格子要么是白色，要么是黑色。

小杨想知道至少包含 $k$ 个黑色格子的最小子矩形包含了多少个格子。

## 输入

第一行包含三个正整数 $n，m，k$ ，含义如题目所示。

之后 $n$ 行，每行一个长度为 $m$ 的 $01$ 串，代表网格图第 $i$ 行格子的颜色，如果为 $0$，则对应格子为白色，否则为黑色。

## 输出

输出一个整数，代表至少包含 $k$ 个黑色格子的最小子矩形包含格子的数量，如果不存在则输出 $0$。
## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

bool a[110][110];
int b[110][110];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    int n,m,k;
    cin >> n >> m >> k;
    for(int i = 1;i <= n;i++) {
        for(int j = 1;j <= m;j++) {
            char c;
            cin >> c;
            a[i][j] = c - '0';
            b[i][j] = b[i-1][j] + b[i][j-1] - b[i-1][j-1] + a[i][j];
        }
    }
    int t = INT_MAX;
    for(int x1 = 0;x1 < n;x1++) {
        for(int y1 = 0;y1 < m;y1++) {
            for(int x2 = x1;x2 <= n;x2++) {
                for(int y2 = y1;y2 <= m;y2++) {
                    int tmp = b[x2][y2] - b[x2][y1]-b[x1][y2] + b[x1][y1];
                    if(tmp >= k) {
                        t = min(t,(x2 - x1)*(y2 - y1));
                    }
                }
            }
        }
    }
    // 无解
    cout << (t == INT_MAX ? 0 : t) << endl;
}
```
