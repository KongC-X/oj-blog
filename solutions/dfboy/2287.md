# 2287 - 整数排序

## 题目描述

给定10个整数的序列，要求对其重新排序。排序要求:  

1.奇数在前，偶数在后；  

2.奇数按从大到小排序；  

3.偶数按输入顺序逆序排序。

## 输入

输入一行，包含10个整数，彼此以一个空格分开，每个整数的范围是大于等于0，小于等于100。

## 输出

按照要求排序后输出一行，包含排序后的10个整数，数与数之间以一个空格分开。

```cpp
#include <bits/stdc++.h>
using namespace std;

bool cmp(int a,int b){
	if(a>b){
		return true;
	}else{
		return false;
	}
}

int a[10],b[10],c[10];
int main(){
	int i,k=0,j=0;
	for(i=1; i<=10; i++){
		cin>>a[i];
	}
	
	for(i=1; i<=10; i++){
		if(a[i]%2!=0){
			j++;
			b[j] = a[i];
		}
	}
	sort(b+1,b+j+1,cmp);
	
	for(i=1; i<=10; i++){
		if(a[i]%2==0){
			k++;
			c[k] = a[i];
		}
	}
	reverse(c+1,c+k+1);
	
	for(i=1; i<=j; i++){
		cout<<b[i]<<" ";
	}
	for(i=1; i<=k; i++){
		cout<<c[i]<<" ";
	}
	return 0;
}
```
