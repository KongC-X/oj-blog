# 1447 - 统计4位的回文数

## 题目描述

回文数指的是正过来读和反过来读都是一样的数，比如 $1661$ 、 $2772$ 都是回文数，请你编程找出所有的 $4$ 位的回文数。

## 输入

无

## 输出

由小到大输出所有的 $4$ 位回文数，每行 $1$ 个。

## 解题思路

## AC代码
## AC代码

```cpp
#include<bits/stdc++.h>
using namespace std;
 
int main() {
	//定义千位，百位，十位，个位 
    int i,q,b,s,g;
    //遍历所有4位数 
    for(i=1000;i<=9999;i++){
        q=i/1000;
        b=i/100%10;
        s=i%100/10;
        g=i%10;
        //如果千位=个位，百位=十位说明是回文数 
        if(q==g&&b==s){
            cout<<i<<endl;
        }
    }
    return 0;
}
```
