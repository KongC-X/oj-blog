# 1000 - 熟悉一下Online Judge的环境

## 题目描述

请不要笑。用来适应环境的题目，自然比较简单些。 

计算 $2$ 个整数的和,这两个整数都在 $1$ 到 $100$ 之间。

## 输入

输入只有一行，包括 $2$ 个整数 $a$ , $b$ ，之间用一个空格分开。

## 输出

输出只有一行，包括 $1$ 个整数。
## AC代码

```cpp
#include<iostream>  // 头文件
using namespace std; // 命名空间
int main(){ // 主函数 
    int a,b;
    cin >> a >> b;
    cout << a + b << endl;
}
```
