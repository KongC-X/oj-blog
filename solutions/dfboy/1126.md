# 1126 - 英文翻译

## 题目描述

请将一个数字，翻译成对应的英文。

## 输入

一个自然数 $n$。（$0\le n \le 2^{31}-1$）

## 输出

输出这个数的英文，最后不要有多余的空格。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

//降序排列辅助函数
bool cmp(int a,int b){
    return a > b ? true : false; 
}

int main() { 
    int a[110];
    int n,m,i,s = 0;
    cin >> m >> n;
    for(i=0;i<n;i++) cin >> a[i];
    sort(a,a+n,cmp); // 从大到小排序
    // for(i=0;i<n;i++) cout << a[i] << " ";
    for(i=0;i<n;i++){
        s += a[i];
        if(s >= m){
            cout << i+1 << endl;
            break;
        }
    }
    if(s < m) {
        cout << "NO" << endl;
    }
}
```
