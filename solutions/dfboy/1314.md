# 1314 - 仰卧起坐成绩统计

## 题目描述

四年级二班女同学在体育课上进行了一轮仰卧起坐测试。成绩计算表如下。

```
`一分钟内做仰卧起坐的个数  成绩
   =60个                  A
`
```

请从键盘读入 $n$ 位同学的在一分钟内做仰卧起坐的数量，计算出每个成绩区间的人数，按照人数降序排序，如果有多个成绩区间人数一样多，那么先输出成绩较好的区间。（ $4.1.44$ ）

## 输入

第一行是一个整数 $n$ 代表同学的人数（ $n \le 100$ ）;

第二行是 $n$ 个同学一分钟完成仰卧起坐的数量。

## 输出

输出  $6$ 行为 $6$ 个成绩区间的人数，每行按照“成绩:人数”的格式输出，按照人数降序输出。

## AC代码

```cpp
// 解法二：动态规划
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int a[110],n,i,j;
int dp[110]; // dp[i]表示以第i个数结尾的最大连续子序列和
int ma,s; // ma存放连续最大和，s存放从每个数开始连续数和

int main() {
    cin >> n;
    for(i = 1;i <= n;i++) {
        cin >> a[i];
    }

    // 状态转移方程：
    // dp[i] = max(dp[i-1] + a[i], a[i])
    // 边界：dp[1] = a[1]
    dp[1] = a[1];
    ma = a[1];
    for(i = 2;i <= n;i++) {
        dp[i] = max(dp[i-1] + a[i], a[i]);
        ma = max(ma, dp[i]);
    }
    cout << ma << endl;
}
```
