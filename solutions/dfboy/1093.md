# 1093 - 打印小写字母表

## 题目描述

把英文字母表的小写字母按顺序和倒序打印出来。(每行 $13$ 个)

## 输入

无

## 输出

输出四行。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    char s[300],a[300],b[300] = {'\0'};
    int i,k = 0;
    gets(s);
    for(i = 0;i < strlen(s);i++) {
        //如果s[i]不是空格，那么就是单词的一部分，存到a中
        if(s[i] != ' ') {
            a[k++] = s[i];
            // 如果当前单词结束了
            if(s[i + 1] == ' ' || s[i + 1] == '\0') {
                a[k] = '\0';
                // cout << a << endl;
                if(strlen(a) > strlen(b)) {
                    strcpy(b,a);// 将a拷贝给b
                }   
                k = 0;// 清空a字符串，存储下一个单词
            }
        }
    }
    cout << b << endl;
}
```
