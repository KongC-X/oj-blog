# 1093 - 打印小写字母表

## 题目描述

把英文字母表的小写字母按顺序和倒序打印出来。(每行 $13$ 个)

## 输入

无

## 输出

输出四行。

## 解题思路

## AC代码
## AC代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

int main(){
    string s;
    char c;
    for(c = 'a'; c <= 'z'; c++) {
        s += c;
        if(c == 'm' || c == 'z') {
            s += '\n';
        }
    }
    for(c = 'z'; c >= 'a'; c--) {
        s += c;
        if(c == 'n') {
            s += '\n';
        }
    }
    cout << s << endl;
}
```
