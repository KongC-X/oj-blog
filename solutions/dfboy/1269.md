# 1269 - 高精度减法

## 题目描述

高精度减法，求 $a-b$。$a,b$ 都是不超过 $240$ 位的非负整数。

## 输入

两个非负整数，每行一个。

## 输出

一个整数，代表两个整数相减之后的结果。
## AC代码
## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;
/*
⾼精度减法；
第⼀步：判断正负，如果s1⽐s2对应的整数⼩，结果为负，交换s1 s2
第⼆步：将两个字符串，逆序存⼊2个整数输出测试
第三步：从左⾄右，逐位相减，不够借位
第四步：从右向左，逆序输出
*/
string s1,s2; //⾼精度整数
int a[250],b[250],c[250]; //存储⾼精度整数的数组
int p;
int main() {
	cin >> s1 >> s2; //读⼊⾼精度整数
	//判断正负 s1 = 123 s2 = 1234   s1 = 123 s2 = 234
	if(s1.size() < s2.size() || (s1.size() == s2.size() && s1 < s2)){
		swap(s1,s2); //交换s1 s2
		cout << "-"; //输出负号
	}
	// 逆序存放到数组中
	for(int i = s1.size() - 1;i >= 0;i--) {
		a[i] = s1[s1.size() - 1 - i] - '0';
	}
	for(int i = s2.size() - 1;i >= 0;i--) {
		b[i] = s2[s2.size() - 1 - i] - '0';
	}
	// 诸位相减
	for(int i = 0;i < s1.size();i++) {
		c[i] = a[i] - b[i];
	}
	// 判断是否需要借位
	for(int i = 0;i < s1.size();i++) {
		if(c[i] < 0) {
			c[i + 1]--; //借位
			c[i] = c[i] + 10; //当前位
		}
	}
	// 去除前导0
	for(int i = s1.size() - 1;i >= 0;i--) {
		if(c[i] != 0) {
			p = i;
			break;
		}
	}
	// 逆序输出结果
	for(int i = p;i >= 0;i--) {
	    cout << c[i];
	}
	return 0;
}
```
