# 2233 - 爬楼梯

## 题目描述

树老师爬楼梯，他可以每次走 $1$ 级或者 $2$ 级，输入楼梯的级数，求不同的走法数。

例如：楼梯一共有 $3$ 级，他可以每次都走一级，或者第一次走一级，第二次走两级 也可以第一次走两级，第二次走一级，一共 $3$ 种方法。

## 输入

输入包含若干行，每行包含一个正整数 $N$，代表楼梯级数，$1 \le N \le 30$。

## 输出

不同的走法数，每一行输入对应一行输出。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int a[100],n,i,x;
int dp[100];
int ma,s;

int main() {
    cin >> n;
    for(i = 1;i <= n;i++) {
        cin >> a[i];
    }
    // 交代边界的值
    dp[1] = a[1];
    dp[2] = max(a[1],a[2]);
    // 递推
    for(i = 3;i <= n;i++) {
        dp[i] = max(dp[i - 1],dp[i - 2] + a[i]);
    }
    cout << dp[n];
}
```
