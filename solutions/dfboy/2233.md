# 2233 - 爬楼梯

## 题目描述

树老师爬楼梯，他可以每次走 $1$ 级或者 $2$ 级，输入楼梯的级数，求不同的走法数。

例如：楼梯一共有 $3$ 级，他可以每次都走一级，或者第一次走一级，第二次走两级 也可以第一次走两级，第二次走一级，一共 $3$ 种方法。

## 输入

输入包含若干行，每行包含一个正整数 $N$，代表楼梯级数，$1 \le N \le 30$。

## 输出

不同的走法数，每一行输入对应一行输出。

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int a[40];
int n;
int main()
{
	while (cin >> n)
	{
		//交代起始项
		a[1] = 1;
		a[2] = 2;
		//从第3项开始推导
		for (int i = 3; i <= n; i++)
		{
			a[i] = a[i - 1] + a[i - 2];
		}

		cout << a[n] << endl;
	}
	return 0;
}
```
