# 1712 - 输出满足条件的整数2

## 题目描述

有这样的三位数，其百位、十位、个位的数字之和为偶数，且百位大于十位，十位大于个位，请输出满所有满足条件的整数。

## 输入

无

## 输出

输出满足条件的整数，每行一个。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main(){
    int m,n;
    cin>>m>>n;
    int i,sum=0,x=0;
    //遍历m~n之间所有的5位数 
    for(i=m;i<=n;i++){
    	//万位等于个位，千位等于十位，且是个偶数 
        if(i%2==0&&i/10000==i%10&&i/1000%10==i%100/10){
            x++;//统计符合条件的数的个数 
            sum=sum+i;//对符合条件的数求和 
        }
    }
    cout<<x<<endl<<sum;
	return 0;
}
```
