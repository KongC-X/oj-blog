# 1712 - 输出满足条件的整数2

## 题目描述

有这样的三位数，其百位、十位、个位的数字之和为偶数，且百位大于十位，十位大于个位，请输出满所有满足条件的整数。

## 输入

无

## 输出

输出满足条件的整数，每行一个。

## 解题思路

## AC代码
## AC代码

```cpp
# include <iostream>
using namespace std;

int main() {
    int i = 100,a,b,c;
    while(i < 1000) {
        a = i / 100;
        b = i % 100 / 10;
        c = i % 10;
        if((a + b + c) % 2 == 0 && a > b && b > c) {
            cout << i << endl;
        }
        i++;
    }
}
```
