# 2067 - 走出迷宫的方法数

## 题目描述

有一个 $n \times m$ 的矩阵迷宫，每个点都可以走，如果从 $1,1$ 点出发，只能向下或者向右行走，请问走到 $n,m$ 点有多少种不同的方法。

## 输入

输入 $1$ 行有 $2$ 个整数 $n$ 和 $m$ ，用空格隔开（ $2 \le n,m \le 30$ ）

## 输出

输出 $1$ 个整数，表示总方法数。
## AC代码
## AC代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
走到每个点的路径数量 = 走到其左侧的路径数量 + 走到其上方的路径数量
a[i][j] = a[i][j-1] + a[i-1][j]
边界条件：a[i][1] = 1,a[1][j] = 1
*/
long long a[40][40];
int n,m;
int main() {
    cin>>n>>m;
    for(int i = 1;i <= n;i++){
        for(int j = 1;j <= m;j++){
            if(i == 1) a[i][j] = 1;
            else if(j == 1) a[i][j] = 1;
            else a[i][j] = a[i][j-1] + a[i-1][j];
        }
    }

    cout<<a[n][m];
	return 0;
}
```
