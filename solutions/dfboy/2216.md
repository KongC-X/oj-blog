# 2216 - 找数字

## 题目描述

给定一个 $n$ 个数的数组 $a$，再给定 $m$ 次询问，每次询问一个整数 $x$ 在数组 $a$ 中是否存在，如果存在，输出 `Y`，不存在输出 `N`。

## 输入

第 $1$ 行是一个整数 $n$（$5≤n≤10^5$）；

第 $2$ 行有 $n$ 个整数，数与数之间用空格隔开；

第 $3$ 行有一个整数$m$（$5≤m≤10^5$）；

第 $4$ 行有 $m$ 个整数，数与数之间用空格隔开；

## 输出

输出 $m$ 次查询每次查询的结果（`Y` 或者 `N`），每次查询结果之间用空格隔开。

## 解题思路

## AC代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

// 定义vector类型的数组，数组中的每个元素都是一个vector
vector<int> a[1100];
int i,j,n,c,x;
int main() {
	cin >> n;
	for(i = 0;i < n;i++) {
		cin >> c;// 每个数组的大小
		for(j = 0;j < c;j++) {
			cin >> x;// 每个数组中的元素
			a[i].push_back(x);// 将元素添加到数组中
		}
		// 每一行的vector读入结束，直接排序
		sort(a[i].begin(),a[i].end());
	}
	sort(a,a + n); // 将数组按照字典从小到大的顺序排序
	// 输出
	for(i = 0;i < n;i++) {
	    for(j = 0;j < a[i].size();j++) {
	    	cout << a[i][j] << " ";
	    }
	    cout << endl;
	}
}
```
