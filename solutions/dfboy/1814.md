# 1814 - 卖苹果的最大利润

## 题目描述

阿凡提批发了 $m$ 斤苹果准备出售，批发价是 $x$ 元/斤。假设他能知道未来 $n$ 天每天苹果的市场单价，请问他在第几天出售利润最高（如果有多天都能使得他的利润最高，那么他会尽早卖出），最高利润是多少钱？

比如：假设阿凡提批发了 $100$ 斤苹果，批发价是 $5$ 元/斤；未来 $8$ 天市场上每天苹果的单价是 $4$  $6$  $5$  $3$  $1$  $5$  $6$  $5$ ，那么第 $2$ 天和第 $7$ 天都是能让他利润最高的时间，他会选择第 $2$ 天出售，能够获得$100$ 元的利润（利润 = 出售总价 - 批发总价）。

## 输入

第 $1$ 行读入 $3$ 个整数 $m$ 、$x$ 、$n$ ；（$m$ 、$ x$ 都是 $1 \sim 1000$ 之间的整数，$n$ 是 $5 \sim 100$ 之间的整数）

第 $2$ 行有 $n$ 个整数，用空格隔开，代表未来 $n$ 天苹果的单价。（数据保证 $n$ 天中一定会出现苹果的销售价>阿凡提的批发价的情况）

## 输出

输出 $2$ 个整数，用空格隔开；

第 $1$ 个整数代表阿凡提在第几天出售苹果，第 $2$ 个整数代表阿凡提获得的总利润。

```cpp
#include<bits/stdc++.h>
using namespace std;
int a[110],j,m,x,n;
int ma=1;//假设下标为1的数是最大数 
int main() {
	cin>>m>>x>>n;
	//由于本题问位置，因此我们下标从1开始，比较方便求位置 
	for(int i=1; i<=n; i++) {
		cin>>a[i];
		//打擂台找最大数下标
		if(a[i]>a[ma]) ma=i;
	}
	
	//输出结果 
	cout<<ma<<" "<<(a[ma]-x)*m;
}
```
