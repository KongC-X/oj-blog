# 1649 - 前缀最大值

## 题目描述

求一个数列的所有前缀最大值之和。

即：给出长度为 $n$ 的数列 $a_i$，求出对于所有 $1≤i≤n$，$max(a_1,a_2,...,a_i)$ 的和。

比如，有数列：$666$ $304$ $692$ $188$ $596$，前缀最大值为：$666$ $666$ $692$ $692$ $692$，和为 $3408$。

对于每个位置的前缀最大值解释如下：对于第 $1$ 个数 $666$ ，只有一个数，一定最大；对于第 $2$ 个数，求出前两个数的最大数，还是 $666$ ；对于第 $3$ 个数，求出前 $3$ 个数的最大数是 $692 \dots$ 其余位置依次类推，最后求前缀最大值得和。

由于读入较大，数列由随机种子生成。

其中 $a[1]=x$，$a[i]=(379 \times a[i-1]+131) \mod 997$。（$mod$ 代表求余数）

## 输入

一行两个正整数 $n$, $x$ ，分别表示数列的长度和随机种子。($n ≤ 100000$，)

## 输出

一行一个正整数表示该数列的前缀最大值之和。

## 解题思路

## AC代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int n,a[110][110],ma;
int d[110][110]; 

// d(x,y): 表示x,y点到底层经过的数字和的最大值
// d(x,y) = a[x][y] + max(d(x+1,y),d(x+1,y+1))

// 动态规划：递推求解
void fun1() {
    int i,j;
    // 最后一层d[x][y] = a[x][y], 是问题的边界
    for(j = 1;j <= n;j++) {
        d[n][j] = a[n][j]; // 赋值最后一层
    }
    // 从倒数第二层开始递推
    for(i = n - 1;i >= 1;i--) {
        for(j = 1;j <= i;j++) {
            d[i][j] = a[i][j] + max(d[i+1][j],d[i+1][j+1]);
        }
    }
}

int main() {
    cin >> n;
    int i,j;
    for(i = 1;i <= n;i++) {
        for(j = 1;j <= i;j++) {
            cin >> a[i][j];
        }
    }
    // 方法二：动态规划(递推)
    fun1();
    cout << d[1][1] << endl;
}
// 时间复杂度 O(n^2)
```
