# 1649 - 前缀最大值

## 题目描述

求一个数列的所有前缀最大值之和。

即：给出长度为 $n$ 的数列 $a_i$，求出对于所有 $1≤i≤n$，$max(a_1,a_2,...,a_i)$ 的和。

比如，有数列：$666$ $304$ $692$ $188$ $596$，前缀最大值为：$666$ $666$ $692$ $692$ $692$，和为 $3408$。

对于每个位置的前缀最大值解释如下：对于第 $1$ 个数 $666$ ，只有一个数，一定最大；对于第 $2$ 个数，求出前两个数的最大数，还是 $666$ ；对于第 $3$ 个数，求出前 $3$ 个数的最大数是 $692 \dots$ 其余位置依次类推，最后求前缀最大值得和。

由于读入较大，数列由随机种子生成。

其中 $a[1]=x$，$a[i]=(379 \times a[i-1]+131) \mod 997$。（$mod$ 代表求余数）

## 输入

一行两个正整数 $n$, $x$ ，分别表示数列的长度和随机种子。($n ≤ 100000$，)

## 输出

一行一个正整数表示该数列的前缀最大值之和。

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

/*
解题步骤：
1、 划分阶段；
2、 确定状态和状态变量；
3、 确定决策和状态转移方程；
4、 寻找边界条件：
归纳得知，动态转移方程如下：
dp[i]=max(dp[i-1],a[i]) dp[1]=a[1] (边界)
前 i个 数 的 最 大 数 =max ( 前 i-1个数的最大数，a[i])
*/

int a[100100],n,i,x;
int dp[100100];
int ma,s;

int main() {
    cin >> n >> x;
    a[1] = x; // 边界条件
    dp[1] = a[1];
    s = dp[1]; // 求和
    for(i = 2;i <= n;i++) {
        a[i] = (379 * a[i - 1] + 131) % 997;
        // 计算出前i个数的最大值
        dp[i] = max(dp[i - 1], a[i]);
        s += dp[i];
    }
    cout << s << endl;
}
```
