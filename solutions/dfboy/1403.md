# 1403 - 找回文数？

## 题目描述

James同学发现了在二维数组中有一些回文数，请编程找出这些回文数，并按照输入的顺序输出。 

（回文数指的是这个数正过来读和反过来读是同一个数的数，比如 $1、8、99、252、1221$ 等）。

## 输入

第一行是两个整数 $n$ 和 $m$ （$n$ 和 $m$ 都是 $4 \sim 100$ 之间的整数），代表接下来的二维数组有 $n$ 行 $m$ 列。

接下来 $n$ 行，每行有 $m$ 个整数，这些整数都是 $1 \sim 9999$ 之间的整数。

## 输出

按照输入的顺序输出满足条件的回文数，每行 $1$ 个。

## 解题思路

## AC代码

```cpp
// 贪心策略：优先选择结束时间尽可能早的活动，因为结束时间越早，剩余的时间就越多，那么剩余的时间可以排更多的活动
// 解法：按照结束时间升序排序，然后逐个统计哪个活动的开始时间 >= 上一个被选中活动的结束时间  

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int n; //活动数量
int s[110],e[110]; //活动起止时间
int i,j,c,etime; 
int main() {
	cin>>n;
	for(i = 0;i < n;i++){
		cin>>s[i]>>e[i];
	}
	//按照结束时间升序
	for(i = 1;i <= n - 1;i++){
		for(j = 0;j <= n - i - 1;j++){
			if(e[j] > e[j+1]){
				swap(e[j],e[j+1]);
				swap(s[j],s[j+1]);
			}
		}
	} 
	
	//第1个活动必选
	etime = e[0];//存储第1个活动的结束时间
	c = 1;//已经有1个选中的活动了

	//在剩余活动中继续选 
	for(i = 1;i < n;i++){
		//如果有一个活动的开始时间>=上一个选中活动的结束时间 
		if(s[i] >= etime){
			c++;
			etime = e[i];
		}
	} 
	cout<<c;
	return 0;
}



#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

struct Node {
    int begin;
    int end;
}a[110];

bool cmp(Node a, Node b) {
    if(a.end < b.end) {
        return true;
    } else {
        return false;
    }
}

int main() {
    int i,j,n,c = 0,e;
    cin >> n;
    for (i = 0; i < n; i++) {
        cin >> a[i].begin >> a[i].end;
    }
    sort(a,a + n,cmp);
    c = 1; // 第一个活动必须选
    e = a[0].end;
    for(i = 1;i < n;i++) {
        if(a[i].begin >= e) {
            c++;
            e = a[i].end;
        }
    }
    cout << c << endl;
}
```
