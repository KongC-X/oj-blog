# B4231 [四川青少年 C++ 算法设计大赛 2024] 4-5 年级组第 2 题

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-18

**算法标签**：`四川`、`2024`、`分支结构`、`科创活动`、`小学活动`

## 题目背景

第二届四川省青少年 C++ 算法设计大赛小学 4-5 年级组全省总决赛试题。数据为洛谷自造。

## 题目描述

小 X 的闹钟设定在了 $h_1:m_1:s_1$ 这个时刻（24 小时制），在设定完闹钟之后，小 X 就去睡觉去了。因为小 X 最近非常劳累，所以直到闹钟响之前，小 X 是绝对不会醒来的。现在，已知小 X 睡觉时间是 $h_2:m_2:s_2$ 这个时刻，小 X 想知道在闹钟把他闹醒的时候，他一共睡了多久。（闹钟每天都会响，到了第二天，时间会重置回 $00:00:00$）

## 输入格式

- 第一行三个整数 $h_1,m_1,s_1$，表示闹钟响的时刻。
- 第二行三个整数 $h_2,m_2,s_2$，表示小 X 睡觉的时刻。

## 输出格式

一行用空格隔开的三个整数 $h,m,s$，表示小 X 一共睡了 $h$ 小时 $m$ 分钟 $s$ 秒。

## 样例

**样例输入 #1**
```
19 0 0
8 30 0```

**样例输出 #1**
```
10 30 0```

**样例输入 #2**
```
8 30 0
19 0 0```

**样例输出 #2**
```
13 30 0```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int h1, m1, s1;  // 闹钟响的时刻
    int h2, m2, s2;  // 睡觉的时刻

    cin >> h1 >> m1 >> s1;
    cin >> h2 >> m2 >> s2;

    // 将时间转换为秒数（从 00:00:00 开始）
    int t1 = h1 * 3600 + m1 * 60 + s1;  // 闹钟秒数
    int t2 = h2 * 3600 + m2 * 60 + s2;  // 睡觉秒数

    // 如果闹钟时刻小于睡觉时刻，说明跨天了，闹钟时刻应加上一天的总秒数
    if (t1 <= t2) {
        t1 += 24 * 3600;
    }

    // 计算睡眠时长（单位：秒）
    int diff = t1 - t2;

    // 转换回时分秒
    int h = diff / 3600;
    int m = (diff % 3600) / 60;
    int s = diff % 60;

    cout << h << " " << m << " " << s << endl;
    return 0;
}
```
