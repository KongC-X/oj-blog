# B3650 [语言月赛 202208] 求和

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-20

**算法标签**：`2022`、`循环结构`、`语言月赛`

## 题目描述

输入一个整数 $n(1\le n \le 10^7)$，每行输出一个数，表示数字 $1$ 到 $i$ 的和。

比如，当 $n=5$ 时，

第 1 行输出一个数字 1；

第 2 行输出数字 3，因为 `1 + 2 = 3`；

第 3 行输出数字 6，因为 `1 + 2 + 3 = 6`；

第 4 行输出数字 10，因为 `1 + 2 + 3 + 4 = 10`；

第 5 行输出数字 15，因为 `1 + 2 + 3 + 4 + 5 = 15`。

## 输入格式

输入一个数 $n(1\le n \le 10^7)$。

## 输出格式

输出共 $n(1\le n \le 10^7)$ 行，每行一个整数。

第 $i$ 行输出的数，表示数字 1 到 i 的和。

## 样例

**样例输入 #1**
```
2```

**样例输出 #1**
```
1
3```

**样例输入 #2**
```
5```

**样例输出 #2**
```
1
3
6
10
15```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3650 [语言月赛202208] 求和
     * 题意：输入 n，输出 1 到 i 的和，i 从 1 到 n，每行一个。
     * 注意：n 最大 1e7，sum 用 long long，换行用 '\n' 避免 endl 频繁刷新。
     */
    long long n;
    cin >> n;
    long long sum = 0;
    for (long long i = 1; i <= n; i++) {
        sum += i;
        printf("%lld\n", sum);   // 或 cout << sum << '\n';
    }
    return 0;
}
```
