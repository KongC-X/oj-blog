# B2042 判断一个数能否同时被 3 和 5 整除

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-27

## 题目描述

判断一个数 $n$ 能否同时被 $3$ 和 $5$ 整除。

## 输入格式

输入一行，包含一个整数 $n$。

## 输出格式

输出一行，如果能同时被 $3$ 和 $5$ 整除输出 `YES`，否则输出 `NO`。

## 样例

**样例输入 #1**
```
15```

**样例输出 #1**
```
YES```

## AC 代码

```cpp
#include<iostream>
using namespace std;
int main() {
    int n;
    cin>>n;
    cout<<(n % 15 == 0 ? "YES" : "NO");
}

```
