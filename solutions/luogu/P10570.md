## 题目描述

你有两个啮合在一起的齿轮，你希望齿轮 A 每转 $a$ 圈齿轮 B 都能转恰好 $b$ 圈。

由于精细度要求，每个齿轮都必须有**不少于** $c$ 个齿，求齿轮 A 和齿轮 B 的总齿数和的最小值。

## 输入格式

**本题有多组数据。**

第一行一个整数 $T$ 描述数据组数。对于每组数据：

- 仅一行，三个整数 $a, b, c$。

## 输出格式

对于每组数据，一行一个整数表示答案。

## 样例

**样例输入 #1**
```
3
2 3 4
4 8 5
5 2 8
```

**样例输出 #1**
```
10
15
28
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int T;
    cin >> T;
    while (T--) {
        long long a, b, c;
        cin >> a >> b >> c;

        // 思路：
        // 啮合齿轮满足 a * x = b * y，其中 x 是 A 齿数，y 是 B 齿数。
        // 设 g = gcd(a, b)，a' = a / g，b' = b / g，
        // 则 x = b' * k，y = a' * k（k 为正整数）。
        // 要求 x, y >= c，即 b' * k >= c 且 a' * k >= c。
        // 只需 k >= ceil(c / min(a', b'))。
        // 总齿数和 = (a' + b') * k，取最小 k 即可。

        long long g = __gcd(a, b);
        long long A = a / g;          // a'
        long long B = b / g;          // b'

        long long m = min(A, B);
        // 向上取整：c / m
        long long k = (c + m - 1) / m;

        long long ans = (A + B) * k;
        cout << ans << "\n";
    }
    return 0;
}
```
