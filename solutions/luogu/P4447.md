# P4447 [AHOI2018初中组] 分组

> **洛谷** | 普及+/提高 | C++14 | 提交时间: 2026-02-08

**算法标签**：`二分`、`博弈论`、`后缀数组`、`整体二分`

## 题目描述

小可可的学校信息组总共有 $n$ 个队员，每个人都有一个实力值 $a_i$。现在，一年一度的编程大赛就要到了，小可可的学校获得了若干个参赛名额，教练决定把学校信息组的 $n$ 个队员分成若干个小组去参加这场比赛。

但是每个队员都不会愿意与实力跟自己过于悬殊的队员组队，于是要求分成的每个小组的队员实力值连续，同时，一个队不需要两个实力相同的选手。举个例子：$[1, 2, 3, 4, 5]$ 是合法的分组方案，因为实力值连续；$[1, 2, 3, 5]$ 不是合法的分组方案，因为实力值不连续；$[0, 1, 1, 2]$ 同样不是合法的分组方案，因为出现了两个实力值为 $1$ 的选手。

如果有小组内人数太少，就会因为时间不够而无法获得高分，于是小可可想让你给出一个合法的分组方案，满足所有人都恰好分到一个小组，使得人数最少的组人数最多，输出人数最少的组人数的最大值。

注意：实力值可能是负数，分组的数量没有限制。

## 输入格式

输入有两行：

第一行一个正整数 $n$，表示队员数量。  

第二行有 $n$ 个整数，第 $i$ 个整数 $a_i$ 表示第 $i$ 个队员的实力。

## 输出格式

输出一行，包括一个正整数，表示人数最少的组的人数最大值。

## 样例

**样例输入 #1**
```
7
4 5 2 3 -4 -3 -5```

**样例输出 #1**
```
3
```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
#include <map>
#include <queue>
#include <vector>
using namespace std;

int a[100010];

int main() {
    int n;
    cin >> n;
    
    // 读入实力值
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    
    // 按实力值升序排序
    sort(a, a + n);
    
    // mp[x]存储以x结尾的所有组的长度（小顶堆，堆顶是最小长度）
    map<int, priority_queue<int, vector<int>, greater<int>>> mp;
    
    // 遍历每个队员
    for (int i = 0; i < n; i++) {
        int x = a[i];
        
        // 查找以x-1结尾的组
        map<int, priority_queue<int, vector<int>, greater<int>>>::iterator it;
        it = mp.find(x - 1);
        
        if (it != mp.end() && !it->second.empty()) {
            // 找到可以接上的组，取长度最小的
            int len = it->second.top();
            it->second.pop();
            
            // 如果这个堆空了，删除这个key
            if (it->second.empty()) {
                mp.erase(it);
            }
            
            // 长度+1，结尾更新为x
            mp[x].push(len + 1);
        } else {
            // 没有可以接上的组，新建组
            mp[x].push(1);
        }
    }
    
    // 找出所有组中的最小长度
    int ans = n + 1;  // 初始化为最大值
    
    // 遍历map
    map<int, priority_queue<int, vector<int>, greater<int>>>::iterator it;
    for (it = mp.begin(); it != mp.end(); it++) {
        // it->first是结尾实力值
        // it->second是存储长度的优先队列
        if (!it->second.empty()) {
            int len = it->second.top();  // 取最小长度
            if (len < ans) {
                ans = len;
            }
        }
    }
    
    cout << ans << endl;
    
    return 0;
}
```
