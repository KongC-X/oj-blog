# P1143 进制转换

> **洛谷** | 普及- | C++14 | 提交时间: 2026-05-18

**算法标签**：`递归`

## 题目描述

请你编一程序实现两种不同进制之间的数据转换。

## 输入格式

共三行，第一行是一个正整数，表示需要转换的数的进制 $n\ (2\le n\le 16)$，第二行是一个 $n$ 进制数，若 $n>10$ 则用大写字母 $\verb!A!\sim \verb!F!$ 表示数码 $10\sim 15$，并且该 $n$ 进制数对应的十进制的值不超过 $10^9$，第三行也是一个正整数，表示转换之后的数的进制 $m\ (2\le m\le 16)$。

## 输出格式

一个正整数，表示转换之后的 $m$ 进制数。

## 样例

**样例输入 #1**
```
16
FF
2
```

**样例输出 #1**
```
11111111```

## AC 代码

```cpp
#include <iostream>
#include <cstring>   // strlen
using namespace std;

int main() {
    // ---------- 思路 ----------
    // 1. 先把 n 进制数（字符串）转换成十进制整数
    // 2. 再把十进制整数转换成 m 进制数
    // 任意进制转换都可以用“十进制”作为中间桥梁。
    // -------------------------

    int n, m;               // n: 原进制   m: 目标进制
    char s[100];            // 存放输入的 n 进制数（题目保证不超过 10^9，长度很安全）

    cin >> n >> s >> m;

    // ---------- 第 1 步：n 进制 → 十进制 ----------
    long long x = 0;        // x: 转换得到的十进制数值（long long 比 int 更安全）
    int len = strlen(s);    // 字符串长度

    for (int i = 0; i < len; ++i) {
        int d;              // d: 当前这一位表示的实际数值（0~15）
        if (s[i] >= '0' && s[i] <= '9')
            d = s[i] - '0';          // 数字字符 → 数字
        else
            d = s[i] - 'A' + 10;     // 大写字母 A~F → 10~15

        x = x * n + d;               // 按权展开（霍纳法则），等价于 x = x * n + d
        // 例如 16 进制 "FF":
        // x=0 -> x=0*16+15=15 -> x=15*16+15=255
    }

    // 特殊情况：如果十进制值是 0，直接输出 0
    if (x == 0) {
        cout << 0 << endl;
        return 0;
    }

    // ---------- 第 2 步：十进制 → m 进制 ----------
    char res[100];          // 存放 m 进制结果的每一位字符（逆序存储）
    int p = 0;              // p: 当前已经存到 res 的第几个位置（索引）

    while (x > 0) {
        int r = x % m;      // 余数 r (0 ~ m-1)
        if (r < 10)
            res[p++] = '0' + r;        // 0~9 → 字符 '0'~'9'
        else
            res[p++] = 'A' + r - 10;   // 10~15 → 字符 'A'~'F'
        x /= m;                         // 去掉最后一位，继续处理高位
    }

    // 逆序输出（因为我们是从低位开始存的）
    for (int i = p - 1; i >= 0; --i)
        cout << res[i];
    cout << endl;

    return 0;
}
```
