# B3690 [语言月赛202212] 盒武器

> **洛谷** | 普及- | C++14 | 提交时间: 2026-09-04

**算法标签**：`2022`、`Special Judge`、`O2优化`、`分支结构`、`循环结构`、`字符串（入门）`

## 题目描述

Aya 在网校共有两名助教，她们的网名分别为某 E 和 L 队。

Aya 热衷于开盒。他对两名助教使用了盒武器，得知某 E 的真实姓名为一个字符串 $s$，L 队的真实姓名为一个字符串 $t$。两个人的名字均只包含英文小写字母。

Aya 确信实力和姓名的字典序有关，姓名字典序越靠前，实力越强。

但是事实上，L 队的实力严格强于某 E。所以，你需要重新确定 $26$ 个英文小写字母的大小顺序，以保证 Aya 得到的结果与事实相符。

也就是说，请你重新定义 $26$ 个字母之间的大小关系，使得按照你新定义的大小关系比较 $s,t$ 两字符串的字典序时，满足 $t < s$。

字符串 $t$ 的字典序小于 $s$ 的字典序当且仅当满足如下两个条件之一：
1. $t$ 是 $s$ 的一个前缀；
2. 存在一个位置 $j \leq \min(|s|, |t|)$，使得对 $1 \leq i < j$ 都有 $s_i = t_i$ 且 $t_j < s_j$。其中两字符相比较的小于号是你重新定义的小于关系。

## 输入格式

输入的第一行为一个字符串 $s$。  
输入的第二行为一个字符串 $t$。

## 输出格式

输出一行一个字符串，长度为 $26$，$\texttt{a} \sim \texttt {z}$ 这些字符在你的输出中均应恰好出现一次，以表示字母之间新定义的大小关系。

在输出中靠前位置的字母小于在输出中靠后位置的字母。

答案可能有多种，你只需要给出任意一组。

## 样例

**样例输入 #1**
```
b
a
```

**样例输出 #1**
```
abcdefghijklmnopqrstuvwxyz```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s, t;
    cin >> s >> t;

    // 如果 t 是 s 的前缀，则 t < s 自动成立，直接输出原字母顺序
    if (t.size() <= s.size() && s.substr(0, t.size()) == t) {
        cout << "abcdefghijklmnopqrstuvwxyz\n";
        return 0;
    }

    // 找到第一个不同的位置
    int p = 0;
    while (s[p] == t[p]) p++;

    char c1 = s[p], c2 = t[p];   // 我们需要 c2 < c1

    // 构造新顺序：c2 放在最前面，c1 放在第二位，其余字母按原顺序
    string ans;
    ans += c2;
    ans += c1;
    for (char ch = 'a'; ch <= 'z'; ch++) {
        if (ch != c1 && ch != c2) ans += ch;
    }

    cout << ans << '\n';
    return 0;
}
```
