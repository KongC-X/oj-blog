# B4295 [蓝桥杯青少年组国赛 2022] 报数游戏

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-17

**算法标签**：`模拟`、`2022`、`队列`、`蓝桥杯青少年组`

## 题目描述

某班级男生人数为 $X$ 人，女生人数为 $Y$ 人，现全班同学围成一个圆圈，并按照顺时针方向为每名同学编号（从 $1$ 到 $X+Y$）。现给出一个正整数 $K$（$2<K<(X+Y)$），从编号为 $1$ 的同学开始顺时针方向报数，报到 $K$ 的同学退出圆圈，下一名同学继续从 $1$ 报数，再次报到 $K$ 的同学退出圆圈。如此循环，直到剩余人数为 $X$ 时游戏结束。

请你计算出游戏开始时 $X$ 名男生分别应该排在什么位置，才能保证每次离开的都是女生，游戏结束时剩余 $X$ 人都是男生。并将游戏开始时每名男生的位置编号按照从小到大顺序输出。

例如：$X=5$，$Y=3$，$K=3$，$8$ 名同学按照如下图的顺序排列（蓝色为男生位置，红色为女生位置），可以使 $3$ 轮报数过后最后剩余的 $5$ 名同学都为男生。故 $5$ 名男同学的编号分别为 $2$、$4$、$5$、$7$、$8$。

## 输入格式

输入三个正整数 $X$、$Y$、$K$（$3 \leq X \leq 100$，$3 \leq Y \leq 100$，$2 < K < (X+Y)$），$X$ 表示男生人数，$Y$ 表示女生人数，$K$ 表示报数的关键数字，三个正整数之间以一个空格隔开。

## 输出格式

输出 $X$ 个整数，表示每名男生位置编号按照从小到大的顺序排列，编号之间以一个空格隔开。

## 样例

**样例输入 #1**
```
5 3 3```

**样例输出 #1**
```
2 4 5 7 8```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int x, y, k;   // x: 男生人数, y: 女生人数, k: 报数关键数字
vector<int> a; // a: 当前剩余人员的位置编号（1-based）

int main() {
    /*
     * ======================================================================
     * 题目：B4295 [蓝桥杯青少年组国赛 2022] 报数游戏
     * 题意：有 X 个男生和 Y 个女生围成一圈，从1号开始报数，报到 K 的人出列，
     *       直到剩余 X 人时停止。要求最后剩余的都是男生。
     *       输出这 X 个男生应占的位置编号。
     *
     * 核心思路（约瑟夫环逆用）：
     *   1. 将所有人（X+Y）按1~N编号，放入vector。
     *   2. 从编号1开始报数，每报到K就删除该位置的人（相当于“淘汰”）。
     *      因为我们要保证淘汰的都是女生，所以最终剩下的人就是男生。
     *   3. 循环删除直到人数 = X，此时vector中剩下的就是男生的位置。
     *   4. 这些位置排序后输出。
     *
     * 为什么这样是正确的？
     *   因为约瑟夫环淘汰顺序是确定的，当我们把最后剩下的位置设为男生时，
     *   所有被淘汰的位置都自动成为女生，且每次出局的人一定按顺序是女生。
     *   因此不需要额外判断，直接模拟淘汰即可。
     *
     * 时间复杂度：O(N^2)，N ≤ 200，完全可行。
     * ======================================================================
     */

    cin >> x >> y >> k;
    int n = x + y;   // 总人数

    // 初始化位置编号 1~n
    for (int i = 1; i <= n; i++) {
        a.push_back(i);
    }

    int p = 0; // p: 当前报数起始位置的下标（0-based）

    // 当人数 > x 时，继续淘汰
    while (a.size() > x) {
        // 找到本轮要淘汰的人的下标：
        // 从 p 开始数 k 个人（包括p），所以下标向前移动 (k-1) 步
        p = (p + k - 1) % a.size();
        a.erase(a.begin() + p); // 删除该位置（淘汰）
        // 注意：删除后，下一轮从该位置开始报数（因为下一个人顶替了被删位置）
        // 我们的 p 正好指向被删位置，下一轮自然从正确位置开始，无需额外调整
    }

    // 剩余的人就是男生应该站的位置
    sort(a.begin(), a.end()); // 按从小到大排序输出

    for (int i = 0; i < a.size(); i++) {
        cout << a[i] << " ";
    }
}
```
