# B4533 [信息与未来 2026] 旅行计划

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-05-26

**算法标签**：`动态规划`、`哈希`、`2-SAT`、`CDQ分治`

## 题目描述

Dr. X 想从城市 $0$ 出发前往城市 $n$。对于所有满足 $0 \le i \le n - 1$ 的整数 $i$，城市 $i$ 与城市 $i + 1$ 之间都有高铁和飞机两种出行方式：

- 坐高铁从城市 $i$ 到城市 $i + 1$ 花费的时间为 $g_i$；
- 坐飞机从城市 $i$ 到城市 $i + 1$ 花费的时间为 $f_i$。

然而，Dr. X 很害怕坐飞机，因此他希望整个行程中乘坐飞机的次数不得超过 $k$ 次。

为了减少坐飞机的次数，Dr. X 可以选择从城市 $i$ 直接飞到城市 $i + j$ ($j \ge 1$)，总飞行时间等于途经各段航线的飞行时间之和 $$\begin{aligned} f_i + f_{i+1} + \cdots + f_{i+j-1}, \end{aligned}$$ 但这样一次连续飞行 **只算乘坐一次飞机**。请计算 Dr. X 从城市 $0$ 出发到达城市 $n$ 所需的最少时间。

## 输入格式

输入第一行包含两个整数 $n$ 和 $k$，分别表示路线的数量和最多允许的坐飞机次数。

第二行包含 $n$ 个空格分隔的整数 $g_0, g_1, \ldots, g_{n-1}$，其中 $g_i$ 表示从城市 $i$ 坐高铁到城市 $i + 1$ 所花费的时间。

第三行包含 $n$ 个空格分隔的整数 $f_0, f_1, \ldots, f_{n-1}$，其中 $f_i$ 表示从城市 $i$ 坐飞机到城市 $i + 1$ 所花费的时间。

## 输出格式

输出一个整数，表示 Dr. X 从城市 $0$ 到达城市 $n$ 所需的最少时间。

## 样例

**样例输入 #1**
```
3 1
4 6 8
1 11 4```

**样例输出 #1**
```
14```

**样例输入 #2**

## AC 代码

```cpp
#include <cstdio>
#include <algorithm>
using namespace std;

const int MAXN = 100005;
const long long INF = 1e18;         // 极大值，表示不可行

int n, k;
int g[MAXN], f[MAXN];               // g[i]: 高铁时间, f[i]: 飞机时间
long long S_g[MAXN], S_f[MAXN];     // 前缀和
long long dp0[MAXN], dp1[MAXN];     // dp0: ≤j次飞行, dp1: 正在计算的新一轮

int main() {
    scanf("%d%d", &n, &k);
    for (int i = 0; i < n; i++) scanf("%d", &g[i]);
    for (int i = 0; i < n; i++) scanf("%d", &f[i]);

    // ---------- 前缀和 ----------
    // S_g[i] = 从城市0坐高铁到城市i的总时间（i段全选高铁）
    // S_f[i] = 从城市0坐飞机到城市i的总时间（i段全选飞机）
    S_g[0] = 0; S_f[0] = 0;
    for (int i = 0; i < n; i++) {
        S_g[i+1] = S_g[i] + g[i];
        S_f[i+1] = S_f[i] + f[i];
    }

    // ---------- 阶段0：允许0次飞行，只能全坐高铁 ----------
    for (int i = 0; i <= n; i++) {
        dp0[i] = S_g[i];            // 一路高铁到底
    }

    // ---------- 逐步增加允许的飞行次数 ----------
    // 外层循环：当前允许飞行 j 次
    for (int j = 1; j <= k; j++) {

        dp1[0] = INF;               // 城市0还没走任何路，不可能"已经飞过j次"，设为不可行

        long long min_val = INF;    // 维护 min{ dp0[t] - S_f[t] }，其中 t < i
        // 这个式子的含义见下方"飞行转移"处的解释

        // 内层循环：计算到达城市 i 的最短时间
        for (int i = 1; i <= n; i++) {

            // ---- 维护 min_val ----
            // 把城市 i-1 作为"飞行起点"加入候选
            // dp0[t] 表示用 ≤j-1 次飞行到达 t 的最短时间
            long long val = dp0[i-1] - S_f[i-1];
            if (val < min_val) min_val = val;

            // ---- 飞行转移 ----
            // 从某个城市 t (< i) 连续飞到 i，消耗 1 次飞行机会
            // 前提是用 ≤j-1 次飞行到达 t 是可行的
            // 飞行时间 = S_f[i] - S_f[t]
            // 总时间 = dp0[t] + (S_f[i] - S_f[t])
            //        = S_f[i] + (dp0[t] - S_f[t])
            // 对 t 求最小值，就是 S_f[i] + min{ dp0[t] - S_f[t] }
            long long plane = INF;
            if (min_val != INF)
                plane = S_f[i] + min_val;

            // ---- 高铁转移 ----
            // 从城市 i-1 坐高铁到 i，不消耗飞行次数
            // dp1[i-1] 已经在本次循环中算好了（允许飞行 j 次）

            dp1[i] = min(dp1[i-1] + g[i-1], plane);   // 取两种方式中更优的
        }

        // ---- 合并：dp0 是本轮之前允许 ≤j-1 次的最优值 ----
        // dp1 是本轮算出的"恰好使用本次机会"的结果
        // 取 min 得到允许 ≤j 次的最优值
        for (int i = 0; i <= n; i++) {
            if (dp0[i] < dp1[i]) dp1[i] = dp0[i];
        }

        // 交换：dp0 现在存储 ≤j 次飞行的结果，供下一轮使用
        swap(dp0, dp1);
    }

    printf("%lld\n", dp0[n]);       // 答案：允许 ≤k 次飞行到达城市 n 的最短时间
    return 0;
}
```
