# P1403 [AHOI2005] 约数研究

> **洛谷** | 普及- | C++14 | 提交时间: 2026-05-24

**算法标签**：`递归`、`双指针`、`状压DP`、`笛卡尔树`、`整体二分`、`排序算法`

## 题目描述

科学家们在 Samuel 星球上的探险得到了丰富的能源储备，这使得空间站中大型计算机 Samuel II 的长时间运算成为了可能。由于在去年一年的辛苦工作取得了不错的成绩，小联被允许用 Samuel II 进行数学研究。

小联最近在研究和约数有关的问题，他统计每个正数 $N$ 的约数的个数，并以 $f(N)$ 来表示。例如 $12$ 的约数有 $1,2,3,4,6,12$，因此 $f(12)=6$。下表给出了一些 $f(N)$ 的取值：

| $N$    | $1$  | $2$  | $3$  | $4$  | $5$  | $6$  |
| ------ | ---- | ---- | ---- | ---- | ---- | ---- |
| $f(N)$ | $1$  | $2$  | $2$  | $3$  | $2$  | $4$  |

现在请你求出：

$$
\sum_{i=1}^n f(i)
$$

## 输入格式

输入一个整数 $n$。

## 样例

**样例输入 #1**
```
3
```

**样例输出 #1**
```
5
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000005;   // n 最大 1e6，多开一点防止越界
int a[MAXN];                // a[i] 表示 i 的约数个数

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;
    cin >> n;

    // ---------- 思路：调和级数法（倍数法） ----------
    // 我们要求 ∑_{i=1}^n f(i)，f(i) 是 i 的约数个数。
    // 传统做法是对每个 i 去枚举它的约数，但这会很慢。
    // 换个角度：数字 d 是哪些数的约数？
    // 答案：d 是 d, 2d, 3d, 4d, ... 的约数。
    //
    // 因此我们可以这样做：
    //   初始化数组 a[1..n] 全为 0。
    //   对于每个 d = 1..n：
    //       对于每个 j = d, 2d, 3d, ... ≤ n：
    //           a[j]++         （d 是 j 的一个约数）
    //
    // 循环次数分析：
    //   d=1 时内层循环 n 次，
    //   d=2 时内层循环 n/2 次，
    //   d=3 时内层循环 n/3 次，
    //   ...
    //   总次数 ≈ n * (1 + 1/2 + 1/3 + ... + 1/n)
    //   这个 1+1/2+1/3+...+1/n 叫做调和级数，大小约为 ln n。
    //   所以总复杂度 O(n log n)，当 n=1e6 时大概 1.4e7 次，很安全。
    //
    // 最后 a[1] + a[2] + ... + a[n] 就是 ∑ f(i)，输出即可。
    // ---------------------------------------------

    // 调和级数法统计每个数的约数个数
    for (int d = 1; d <= n; ++d) {          // d 是作为约数的数字
        for (int j = d; j <= n; j += d) {   // j 是 d 的所有倍数
            a[j]++;                          // d 是 j 的一个约数，计数加 1
        }
    }

    // 累加所有 f(i)
    long long s = 0;                         // 答案可能较大，用 long long
    for (int i = 1; i <= n; ++i) {
        s += a[i];
    }

    cout << s << '\n';
    return 0;
}
```
