# B2015 计算并联电阻的阻值

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-23

## 题目描述

对于阻值为 $r_1$ 和 $r_2$ 的电阻，其并联电阻阻值公式计算如下：
$$R=\dfrac{1}{\dfrac{1}{r_1}+\dfrac{1}{r_2}}$$

输入实数 $r_1,r_2$。输出并联之后的阻抗大小，结果保留小数点后 $2$ 位。

## 输入格式

两个实数 $r_1,r_2$，以一个空格分开。

## 输出格式

并联之后的阻抗大小，保留小数点后 $2$ 位。

## 样例

**样例输入 #1**
```
1 2```

**样例输出 #1**
```
0.67```

## AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
    double r1,r2;
    cin>>r1>>r2;
    printf("%.2f",1/(1/r1+1/r2));
}

```
