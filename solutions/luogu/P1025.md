# P1025 [NOIP 2001 提高组] 数的划分

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-05-26

**算法标签**：`动态规划`、`图论`、`暴力枚举`、`单调队列`、`构造`、`A*搜索`

## 题目描述

将整数 $n$ 分成 $k$ 份，且每份不能为空，任意两个方案不相同（不考虑顺序）。

例如：$n=7$，$k=3$，下面三种分法被认为是相同的。

$1,1,5$；   
$1,5,1$；   
$5,1,1$。

问有多少种不同的分法。

## 输入格式

$n,k$（$6<n \le 200,2  \le k  \le  6$）。

## 输出格式

$1$ 个整数，即不同的分法。

## 样例

**样例输入 #1**
```
7 3
```

**样例输出 #1**
```
4
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, k;                     // n: 被划分的数, k: 份数
int ans;                      // 答案：不同分法的数量

/*
 * DFS 思路：
 * 要避免重复（比如 1,1,5 和 1,5,1 视为同一种），
 * 我们可以强制让每一份的值从小到大（非递减）。
 * 这样就能保证同样的组合只会被生成一次。
 *
 * 参数说明：
 *   x  : 当前还剩多少需要分
 *   y  : 还剩几份需要填
 *   st : 这一份最小可以取多少（保证非递减）
 *
 * 剪枝：
 *   当前份的值 i 最大只能取到 x / y（平均分），
 *   因为后面 y 份都不能比 i 小，如果 i 太大，后面不够分。
 */
void dfs(int x, int y, int st) {
    if (y == 1) {                    // 只剩最后一份
        if (x >= st) ans++;          // 剩下的数不小于前一份，合法
        return;
    }
    // 枚举当前这一份的值 i，从 st 到 x / y
    for (int i = st; i <= x / y; i++) {
        dfs(x - i, y - 1, i);        // 下一份至少为 i
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> k;
    ans = 0;
    dfs(n, k, 1);                    // 初始：剩余 n，k 份，最小可以取 1
    cout << ans << '\n';

    return 0;
}
```
