# B2157 短信计费

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-13

**算法标签**：`循环结构`

## 题目描述

用手机发短信，一条短信资费为 $0.1$ 元，但限定一条短信的内容在 $70$ 个字以内（包括 $70$ 个字）。如果你一次所发送的短信超过了 $70$ 个字，则会按照每 $70$ 个字一条短信的限制把它分割成多条短信发送。假设已经知道你当月所发送的短信的字数，试统计一下你当月短信的总资费。

## 输入格式

第一行是整数 $n$（$1 \le n \le 10000$），表示当月发送短信的总次数，接着 $n$ 行每行一个整数，表示每次短信的字数。

## 输出格式

输出一行，当月短信总资费，单位为元，精确到小数点后 $1$ 位。

## 样例

**样例输入 #1**
```
10
39
49
42
61
44
147
42
72
35
46```

**样例输出 #1**
```
1.3```

## AC 代码

```cpp
#include <iostream>
#include <iomanip>   // 用于 fixed 和 setprecision
using namespace std;

// 函数：根据短信字数返回需要拆分的条数（70字/条，向上取整）
int cnt(int x) {
    if (x % 70 == 0) return x / 70;       // 整除情况
    return x / 70 + 1;                    // 有余数则多一条
}

int main() {
    // 思路：用函数 cnt 计算每次短信的条数，乘以 0.1 元累加，最后保留一位小数输出。
    int n;                               // n：短信总次数
    cin >> n;

    double sum = 0.0;                    // sum：总资费，初始化为 0
    for (int i = 0; i < n; i++) {
        int x;                           // x：本次短信字数
        cin >> x;
        sum += cnt(x) * 0.1;             // 调用函数计算条数，累加费用
    }

    cout << fixed << setprecision(1) << sum << endl;
    return 0;
}
```
