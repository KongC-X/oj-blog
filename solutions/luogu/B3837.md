# B3837 [GESP202303 二级] 画三角形

> **洛谷** | 普及- | C++14 | 提交时间: 2025-03-28

**算法标签**：`最小割`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1122>

## 题目描述

输入一个正整数 $n$，请使用大写字母拼成一个这样的三角形图案（参考样例输入输出）：三角形图案的第 $1$ 行有 $1$ 个字母，第 $2$ 行有 $2$ 个字母，以此类推；在三角形图案中，由上至下、由左至右依次由大写字母 $\texttt{A}-\texttt{Z}$ 填充，每次使用大写字母 $\texttt Z$ 填充后，将从头使用大写字母 $\texttt A$ 填充。

## 输入格式

输入一行，包含一个正整数 $n$。约定 $2 \le n \le 40$。

## 输出格式

输出符合要求的三角形图案。注意每行三角形图案的右侧不要有多余的空格。

## 样例

**样例输入 #1**
```
3```

**样例输出 #1**
```
A
BC
DEF```

**样例输入 #2**
```
7```

**样例输出 #2**
```
A
BC
DEF
GHIJ
KLMNO
PQRSTU
VWXYZAB```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main(){
    int n,i,j;
    char c = 'A'; // 初始设为A
    cin >> n;
    for(i = 1;i <= n;i++) {
        for(j = 1;j <= i;j++) {
            cout << c;
            c++; // 每次输出ascii码就增加1
            // 如果+1超过Z了就重新设为A
            if(c > 'Z') {
                c = 'A';
            }
        }
        cout << endl;
    }
}
```
