# P11376 [GESP202412 六级] 运送物资

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-06-17

**算法标签**：`二分`、`费用流`、`队列`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1170>

## 题目描述

小杨管理着 $m$ 辆货车，每辆货车每天需要向 A 市和 B 市运送若干次物资。小杨同时拥有 $n$ 个运输站点，这些站点位于 A 市和 B 市之间。

每次运送物资时，货车从初始运输站点出发，前往 A 市或 B 市，之后返回初始运输站点。A 市、B 市和运输站点的位置可以视作数轴上的三个点，其中 A 市的坐标为 $0$，B 市的坐标为 $x$，运输站点的坐标为 $p$ 且有 $0 \lt p \lt x$。货车每次去 A 市运送物资的总行驶路程为 $2p$，去 B 市运送物资的总行驶路程为 $2(x - p)$。

对于第 $i$ 个运输站点，其位置为 $p_i$ 且至多作为 $c_i$ 辆车的初始运输站点。小杨想知道，在最优分配每辆货车的初始运输站点的情况下，所有货车每天的最短总行驶路程是多少。

## 输入格式

第一行包含三个正整数 $n,m,x$，代表运输站点数量、货车数量和两市距离。

之后 $n$ 行，每行包含两个正整数 $p_i$ 和 $c_i$，代表第 $i$ 个运输站点的位置和最多容纳车辆数。

之后 $m$ 行，每行包含两个正整数 $a_i$ 和 $b_i$，代表第 $i$ 辆货车每天需要向 A 市运送 $a_i$ 次物资，向 B 市运送 $b_i$ 次物资。

## 输出格式

输出一个正整数，代表所有货车每天的最短总行驶路程。

## 样例

**样例输入 #1**
```
3 4 10
1 1
2 1
8 3
5 3
7 2
9 0
1 10000```

**样例输出 #1**
```
40186```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

const int MAXN = 100005;

// 结构体复用：站点和车辆都用此结构体
// 站点：p 为位置，c 为容量
// 车辆：p 为去 A 市的次数 a_i，c 为去 B 市的次数 b_i
struct Node {
    ll p;
    int c;
} a[MAXN], b[MAXN];               // a[] 站点，b[] 货车

// 排序比较函数1：站点按位置 p 从小到大排序
bool cmp1(Node u, Node v) {
    return u.p < v.p;
}

// 排序比较函数2：车辆按 |a_i - b_i| 从大到小排序
// 绝对值越大，说明对站点位置的敏感度越高，应优先分配极值站点
bool cmp2(Node u, Node v) {
    ll du = abs(u.p - u.c);       // |a_i - b_i|，u.p 为 a_i，u.c 为 b_i
    ll dv = abs(v.p - v.c);
    return du > dv;               // 降序排列
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n, m;
    ll x;                         // A、B两市距离
    cin >> n >> m >> x;

    // 读入 n 个运输站点
    for (int i = 1; i <= n; i++) {
        cin >> a[i].p >> a[i].c;  // 位置、容量
    }

    // 读入 m 辆车的运输需求
    for (int i = 1; i <= m; i++) {
        cin >> b[i].p >> b[i].c;  // a_i, b_i
    }

    // ==================== 解题思路 ====================
    // 设第 i 辆车分配给位置为 p 的站点，去 A 市 a_i 次，去 B 市 b_i 次。
    // 总路程 = Σ [2*a_i*p + 2*b_i*(x-p)] = 2 * [ Σ (a_i - b_i)*p + x*Σ b_i ]。
    // 常数项 x*Σ b_i 不变，因此只需最小化 S = Σ w_i * p_i，其中 w_i = a_i - b_i。
    //
    // 贪心策略：
    // 1. 站点按位置 p 升序排列。
    // 2. 车辆按 |w_i| 从大到小排序（即对路程影响越大的车越优先挑选站点）。
    // 3. 对于 w_i > 0（去 A 次数多），应分配最小的 p，使 w_i*p 尽量小（正权配小值）。
    //    对于 w_i < 0（去 B 次数多），应分配最大的 p，因为 w_i 为负，配大 p 会使乘积更负，从而 S 更小。
    //    对于 w_i = 0，p 无所谓，总路程贡献恒为 2*x*b_i。
    //
    // 具体实现：
    // - 用双指针 l=1（最左，最小 p）和 r=n（最右，最大 p）。
    // - 遍历排序后的车辆，若 w_i > 0 则从左指针取站点（跳过容量已满的站点）；
    //   若 w_i < 0 则从右指针取站点；若 w_i = 0 则不需要站点位置（直接加常数项）。
    // - 每次取站点时，容量减 1，并累加该车产生的路程（此处先累加一半，最后再乘 2）。
    // ================================================

    sort(a + 1, a + n + 1, cmp1);        // 站点按位置升序
    sort(b + 1, b + m + 1, cmp2);        // 车辆按 |a-b| 降序

    int l = 1, r = n;                    // 左右指针
    ll ans = 0;                          // 累加未乘2的总路程

    for (int i = 1; i <= m; i++) {
        ll ai = b[i].p;                  // 去A次数
        ll bi = b[i].c;                  // 去B次数

        if (ai == bi) {                  // 权重为0，位置无影响
            // 贡献为 2 * bi * x，先加 bi * x，最后统一乘2
            ans += bi * x;
        } else if (ai > bi) {            // w_i > 0，需配最小 p
            // 跳过容量已用完的左侧站点
            while (l <= r && a[l].c == 0) l++;
            a[l].c--;                    // 占用一个容量
            // 总路程（一半）= bi*x + (ai-bi)*p
            ans += bi * x + (ai - bi) * a[l].p;
        } else {                         // ai < bi，w_i < 0，需配最大 p
            // 跳过容量已用完的右侧站点
            while (l <= r && a[r].c == 0) r--;
            a[r].c--;
            // 这里 (ai-bi) 为负，加负数即相当于减去
            ans += bi * x + (ai - bi) * a[r].p;
        }
    }

    // 之前计算的是实际路程的一半，输出时乘2
    cout << ans * 2 << '\n';
    return 0;
}
