# P1255 数楼梯

> **洛谷** | 普及- | C++14 | 提交时间: 2026-01-08

**算法标签**：`数学`、`暴力枚举`

## 题目描述

楼梯有 $N$ 阶，上楼可以一步上一阶，也可以一步上二阶。

编一个程序，计算共有多少种不同的走法。

## 样例

**样例输入 #1**
```
4```

**样例输出 #1**
```
5```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 高精度加法函数
string add(string s1,string s2) {
    int a[5010] = {0}, b[5010] = {0}, c[5010] = {0};
    
    // 将字符串逆序存入数组，方便从个位开始计算
    for (int i = s1.size() - 1; i >= 0; i--) {
        a[s1.size() - 1 - i] = s1[i] - '0';
    }

    for (int i = s2.size() - 1; i >= 0; i--) {
        b[s2.size() - 1 - i] = s2[i] - '0';
    }
    
    // 找到两个数中较长的长度
    int len = max(s1.size(), s2.size());
    
    // 逐位相加
    for (int i = 0; i < len; i++) {
        c[i] += a[i] + b[i];
        // 处理进位
        if (c[i] >= 10) {
            c[i + 1]++;  // 进位
            c[i] -= 10;  // 当前位减10
        }
    }
    
    // 判断最高位是否有进位
    if (c[len] != 0) {
        len++;
    }
    
    // 将结果数组转换为字符串（注意要逆序）
    string result = "";
    for (int i = len - 1; i >= 0; i--) {
        result += (c[i] + '0');
    }
    
    return result;
}

int main() {
    int n;
    cin >> n;
    
    string s1,s2,s;
    // 初始化斐波那契数列的前两项
    s1 = "1";  // f(0) = 1
    s2 = "1";  // f(1) = 1
    
    if (n == 0 || n == 1) {
        cout << "1" << endl;
        return 0;
    }
    
    // 递推计算斐波那契数列的第n项
    for (int i = 2; i <= n; i++) {
        s = add(s1, s2); // f(i) = f(i-1) + f(i-2)
        s1 = s2;   // f(i-2) = f(i-1)
        s2 = s;   // f(i-1) = f(i)
    }

    cout << s << endl;
    return 0;
}
```
