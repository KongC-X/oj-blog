# B3997 [洛谷 202406GESP 模拟 三级] 小洛的字符串分割

> **洛谷** | 入门 | C++14 | 提交时间: 2026-09-23

## 题目描述

对于一个字符串 $S$，小洛定义它为 **回文** 的，当且仅当字符串 $S$ 从左往右读和从右往左读一样，例如 $\tt abcba$ 是回文的，而 $\tt abcca$ 不是。

小洛现在有一个字符串 $S$，他想将这个字符串分为若干段，段长度分别为 $1,2,3,\dots$。具体而言，他会先将第一个字符拿出来作为字符串 $S_1$，再将第 $2,3$ 个字符拿出来作为 $S_2$，再将第 $4,5,6$ 个字符拿出来作为 $S_3$，以此类推……最后若还有多余的字符，则单独作为一段。

例如说，对于字符串 $\tt aaababcaacd$，会被分为如下的五个字符串：

- $S_1=\tt a$；
- $S_2=\tt aa$；
- $S_3=\tt bab$；
- $S_4=\tt caac$；
- $S_5=\tt d$；

字符串 $\tt aaababcaacd$ 分割出的 $5$ 个字符串都是回文的。

小洛想要知道，对于读入的字符串 $S$，这些被分割出来的字符串，有**多少个**是回文的呢？

## 输入格式

输入一行，一个字符串 $S$。

## 输出格式

输出一个整数，表示答案。

## 样例

**样例输入 #1**
```
aaababcaacd```

**样例输出 #1**
```
5```

**样例输入 #2**
```
abacdcaaba```

**样例输出 #2**
```
2```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;
    cin >> s;

    int n = s.size();
    int i = 0;          // i: 当前段的起始下标
    int len = 1;        // len: 期望的段长度，从 1 开始递增
    int ans = 0;        // ans: 回文段的数量

    while (i < n) {
        // 实际段长度：如果剩余字符不足 len，则取剩余全部
        int t = min(len, n - i);

        // 判断 s[i ... i+t-1] 是否回文
        bool flag = true;
        for (int j = 0; j < t / 2; j++) {
            if (s[i + j] != s[i + t - 1 - j]) {
                flag = false;
                break;
            }
        }
        if (flag) ans++;

        i += t;    // 移动到下一段的起始位置
        len++;          // 下一段期望长度增加 1
    }

    cout << ans << endl;
    return 0;
}
```
