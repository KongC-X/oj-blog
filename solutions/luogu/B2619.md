## 题目描述

根据咕咕网校的预测，当课程定价为 $110$ 元时，会有 $10$ 人报名。如果课程价格每降低 $1$ 元，就会多 $1$ 名报名者（反之亦然）。如果希望总共能收到 $3500$ 元学费的话，那么应该定价多少呢？已知本题有两个答案符合要求，则取较小的那一个。如果这个答案不是整数，则需四舍五入精确到整数。

## 输出格式

请输出一个整数表示答案。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 设定价比110元降低了d元，则报名人数为10+d人，学费为(110-d)*(10+d)
     * 令(110-d)*(10+d)=3500，展开得 -d^2+100d-2400=0，即 d^2-100d+2400=0
     * 解得 d=40 或 d=60，对应定价 70 或 50，取较小者 50。
     */
    cout << 50 << endl;
    return 0;
}
```
