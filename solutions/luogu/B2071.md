# B2071 余数相同问题

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-05

## 题目描述

已知三个正整数 $a$，$b$，$c$。现有一个大于 $1$ 的整数 $x$，将其作为除数分别除 $a$，$b$，$c$，得到的余数相同。

请问满足上述条件的 $x$ 的最小值是多少？数据保证 $x$ 有解。

## 输入格式

一行，三个不大于 $1000000$ 的正整数 $a$，$b$，$c$，两个整数之间用一个空格隔开。

## 输出格式

一个整数，即满足条件的 $x$ 的最小值。

## 样例

**样例输入 #1**
```
300 262 205```

**样例输出 #1**
```
19```

## AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main() {
    int a, b, c;
    cin >> a >> b >> c;
    
    for(int i = 2; i <= a && i <= b && i <= c; i++) 
        if(a % i == b % i && b % i == c % i) {
            cout << i;
            return 0;
        }
}

```
