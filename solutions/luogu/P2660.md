# P2660 zzc 种田

> **洛谷** | 普及- | C++14 | 提交时间: 2026-05-23

**算法标签**：`递归`、`二分`、`最小环`、`随机化`

## 题目背景

可能以后 zzc 就去种田了。

## 题目描述

田地是一个巨大的矩形，然而 zzc 每次只能种一个正方形,而每种一个正方形时 zzc 所花的体力值是正方形的周长，种过的田不可以再种，zzc 很懒还要节约体力去泡妹子，想花最少的体力值去种完这块田地，问最小体力值。

## 输入格式

两个正整数 $x,y$，表示田地的长和宽。

## 样例

**样例输入 #1**
```
1 10```

**样例输出 #1**
```
40```

**样例输入 #2**
```
2 2 ```

**样例输出 #2**
```
8```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long a, b;          // 田地的长和宽
    cin >> a >> b;

    long long sum = 0;       // 所有正方形边长之和

    // 辗转相切：每次从矩形中切出尽可能大的正方形
    while (a && b) {
        if (a < b) swap(a, b);        // 保证 a 为长边
        long long k = a / b;          // 能切出 k 个边长为 b 的正方形
        sum += k * b;                 // 累加边长
        a %= b;                       // 剩余部分的长
    }

    // 体力 = 边长之和 × 4
    cout << sum * 4 << '\n';

    return 0;
}
```
