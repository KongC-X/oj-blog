# P13491 【MX-X14-T1】拼凑基因

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-06

**算法标签**：`O2优化`、`梦熊比赛`

## 题目描述

小 A 给了你两个长度为 $n$ 的字符串 $S,T$，他想问你是否可以将 $S$ 划分为若干子串\*后以任意顺序拼接在一起使其等于 $T$。

\*子串的定义为原字符串中**连续**的一段字符组成的字符串。

## 输入格式

第一行，一个整数 $n$。

第二行，一个长度为 $n$ 的字符串 $S$。

第三行，一个长度为 $n$ 的字符串 $T$。

保证 $S,T$ 中只包含小写英文字母。

## 输出格式

仅一行，一个字符串 `Yes` 或者 `No`，表示 $S$ 是否可以通过划分为若干子串然后以任意顺序拼接这些子串变成 $T$。

## 样例

**样例输入 #1**
```
5
xyzab
abxyz```

**样例输出 #1**
```
Yes```

**样例输入 #2**
```
6
aabbcc
bccaab```

**样例输出 #2**
```
Yes```

**样例输入 #3**
```
3
abc
bda```

**样例输出 #3**
```
No```

## AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
string a,b;
int n;
int main(){
    cin>>n>>a>>b;
    sort(a.begin(),a.end());
    sort(b.begin(),b.end());
    cout<<((a==b)?"Yes":"No");
}

```
