# P2758 编辑距离

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-07-28

**算法标签**：`字符串`、`动态规划 DP`、`数学`

## 题目描述

设 $A$ 和 $B$ 是两个字符串。我们要用最少的字符操作次数，将字符串 $A$ 转换为字符串 $B$。这里所说的字符操作共有三种：

1. 删除一个字符；
2. 插入一个字符；
3. 将一个字符改为另一个字符。

$A, B$ 均只包含小写字母。

## 输入格式

第一行为字符串 $A$；第二行为字符串 $B$；字符串 $A, B$ 的长度均小于 $2000$。

## 输出格式

只有一个正整数，为最少字符操作次数。

## 样例

**样例输入 #1**
```
sfdqxbw
gfdgw
```

**样例输出 #1**
```
4
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string A, B;
    cin >> A >> B;
    int n = A.size(), m = B.size();

    /*
      DP 思路：
      状态定义：dp[i][j] 表示将 A 的前 i 个字符（下标0..i-1）转换成 B 的前 j 个字符
                所需的最少操作次数。
      初始化：
        - dp[i][0] = i   (把A的前i个字符全部删除，变成空串)
        - dp[0][j] = j   (把空串插入j次变成B的前j个字符)
      状态转移（i>0, j>0）：
        若 A[i-1] == B[j-1]，则这一位不需要操作，dp[i][j] = dp[i-1][j-1]。
        否则，考虑三种操作，取最小值：
          1. 删除 A 的第 i 个字符：dp[i][j] = dp[i-1][j] + 1
          2. 插入 B 的第 j 个字符：dp[i][j] = dp[i][j-1] + 1
          3. 替换 A 的第 i 个字符为 B 的第 j 个字符：dp[i][j] = dp[i-1][j-1] + 1
      最终答案：dp[n][m]
    */
    int dp[2005][2005];
    // 初始化边界
    for (int i = 0; i <= n; i++) dp[i][0] = i; // 删除 i 次
    for (int j = 0; j <= m; j++) dp[0][j] = j; // 插入 j 次

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (A[i - 1] == B[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1];      // 字符相同，无需操作
            } else {
                // 三种操作：删除、插入、替换，取最小值
                int t = min(dp[i - 1][j], dp[i][j - 1]);
                dp[i][j] = min(t, dp[i - 1][j - 1]) + 1;
            }
        }
    }
    cout << dp[n][m] << endl;
    return 0;
}
```
