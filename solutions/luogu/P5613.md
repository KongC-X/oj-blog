# P5613 [MtOI2019] 黑蚊子多

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-24

**算法标签**：`模拟`、`2019`、`洛谷原创`、`O2优化`、`洛谷月赛`

## 题目描述

Hikari 的面前有 $n(1\leq n\leq 1000)$ 级台阶，每 $1s$ 她可以向上跳 $m(1\leq m\leq n)$ 级台阶。（不在中间的台阶上停留）

台阶上有 $k(k\leq 10)$ 个特殊的平台 $a_i$，Hikari 在该平台 **停留** 时会使得 $m$ 增加 $1$。

请问 Hikari 到达台阶顶部花费的时间。

## 输入格式

共 $2$ 行。

第 $1$ 行输入 $3$ 个非负整数 $n,m,k$。

第 $2$ 行输入 $k$ 个正整数，第 $i$ 个正整数表示 $a_i$，保证输入的 $a_i$ 单调递增。

## 输出格式

共 $1$ 行，输出 $1$ 个正整数表示花费的时间。

## 样例

**样例输入 #1**
```
10 5 0```

**样例输出 #1**
```
2```

**样例输入 #2**
```
31 4 2
8 13```

**样例输出 #2**
```
6```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】模拟
     * 【核心思路】
     * 1. 用 bool 数组 arr[1005] 记录哪些台阶是特殊平台。
     * 2. pos 表示当前所在台阶（初始为 0），m 表示当前步长，ans 记录时间。
     * 3. 循环模拟每一秒：
     *    a. ans++
     *    b. pos += m   (跳一次)
     *    c. 如果 pos >= n，说明到达顶部，输出 ans 结束。
     *    d. 如果 pos 是特殊平台，则 m++（停留使步长增加）。
     * 4. 由于 n 很小，直接模拟即可。
     *
     * 【时间复杂度】O(n)
     */

    // 变量定义
    int n, m, k;          // n: 台阶总数, m: 初始步长, k: 特殊平台个数
    cin >> n >> m >> k;

    bool arr[1005] = {false};  // arr[i]: 第 i 级台阶是否为特殊平台

    // 读入 k 个特殊平台并标记
    for (int i = 0; i < k; i++) {
        int a;   // 临时变量 a: 特殊平台的编号
        cin >> a;
        arr[a] = true;
    }

    int pos = 0;   // pos: 当前位置（初始在 0 级，即地面）
    int ans = 0;   // ans: 花费的时间（秒数）

    // 模拟跳跃过程
    while (pos < n) {
        ans++;          // 每 1 秒
        pos += m;       // 向上跳 m 级

        if (pos >= n) {
            break;      // 已经到达或超过顶部，结束
        }

        // 如果落在特殊平台上，步长增加 1
        if (arr[pos]) {
            m++;
        }
    }

    // 输出结果
    cout << ans << endl;

    return 0;
}
```
