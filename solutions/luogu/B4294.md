# B4294 [蓝桥杯青少年组国赛 2022] 电线上的小鸟

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-14

**算法标签**：`模拟`、`字符串`、`2022`、`字符串（入门）`、`蓝桥杯青少年组`

## 题目描述

在一根电线上落有 $N$ 只小鸟，每只小鸟的朝向要么向左（用 `q` 表示），要么向右（用 `p` 表示）。每只小鸟只能看到它视线方向上的相邻小鸟。给定 $N$ 只小鸟的朝向序列，请计算：
- 有多少只小鸟没有被任何小鸟看到（被 $0$ 只小鸟看到）；
- 有多少只小鸟被 $1$ 只小鸟看到；
- 有多少只小鸟被 $2$ 只小鸟看到。

例如：当 $N=6$，朝向序列为 `p q p p q q` 时：
- 有 $2$ 只小鸟被 $0$ 只小鸟看到（第 $3$ 只和第 $6$ 只）；
- 有 $2$ 只小鸟被 $1$ 只小鸟看到（第 $1$ 只和第 $2$ 只）；
- 有 $2$ 只小鸟被 $2$ 只小鸟看到（第 $4$ 只和第 $5$ 只）。

## 输入格式

输入共两行：
- 第一行：一个正整数 $N$（$3 \leq N \leq 1000$），表示小鸟的数量；
- 第二行：$N$ 个字符（每个字符为 `q` 或 `p`），表示小鸟的朝向序列，字符之间用一个空格隔开。

## 输出格式

输出三个整数，分别表示：
1. 被 $0$ 只小鸟看到的小鸟数量；
2. 被 $1$ 只小鸟看到的小鸟数量；
3. 被 $2$ 只小鸟看到的小鸟数量。

三个整数之间用一个空格隔开。

## 样例

**样例输入 #1**
```
6
p q p p q q```

**样例输出 #1**
```
2 2 2```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B4294 [蓝桥杯青少年组国赛 2022] 电线上的小鸟
     * 题意：每只小鸟朝左（q）或朝右（p），每只小鸟只能看到它朝向方向相邻的那只小鸟。
     *       统计每只小鸟被多少只小鸟看到（0、1、2），输出个数。
     *
     * 核心思路：
     * 1. 用数组 a[1..N] 存储每只小鸟的朝向，'p' 表示朝右，'q' 表示朝左。
     * 2. 对于第 i 只小鸟，它可能被以下小鸟看到：
     *    - 左邻居 i-1，如果 i-1 存在且 a[i-1] == 'p'（朝右，能看到右边的小鸟）。
     *    - 右邻居 i+1，如果 i+1 存在且 a[i+1] == 'q'（朝左，能看到左边的小鸟）。
     * 3. 因此，每只小鸟的被看到次数 = (i>1 && a[i-1]=='p') + (i<N && a[i+1]=='q')。
     * 4. 统计每个次数的数量，输出。
     *
     * 时间复杂度：O(N)
     */

    int N;
    cin >> N;

    char a[1005];          // 存储每只小鸟的朝向（1-based）
    for (int i = 1; i <= N; i++) {
        cin >> a[i];       // 读入字符，空格会被 cin 自动跳过
    }

    int cnt0 = 0, cnt1 = 0, cnt2 = 0;   // 分别记录被看到 0,1,2 次的数量

    for (int i = 1; i <= N; i++) {
        int vis = 0;       // 第 i 只小鸟被看到的次数

        // 左邻居能否看到 i？
        if (i > 1 && a[i-1] == 'p') vis++;

        // 右邻居能否看到 i？
        if (i < N && a[i+1] == 'q') vis++;

        // 根据次数累加
        if (vis == 0) cnt0++;
        else if (vis == 1) cnt1++;
        else if (vis == 2) cnt2++;
    }

    cout << cnt0 << " " << cnt1 << " " << cnt2 << endl;

    return 0;
}
```
