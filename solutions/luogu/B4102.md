# B4102 [CSP-X2023 山东] 克隆机

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-11

**算法标签**：`2023`、`山东`、`CSP-X 小学组`

## 题目描述

有一台神奇的克隆机，可以克隆任何东西。将样品放进克隆机，可以克隆出一份一样的“复制品”。

小明得到了 $k$ 种珍贵的植物种子，依次用 $\text{A,B,C,D,\dots,Z}$ 表示（$1\le k\le 26$）。一开始，每种植物种子只有 $1$ 粒。

小明想利用克隆机克隆出更多种子。将一粒种子作为样品放进克隆机，就可以得到一粒克隆出来的相同的种子，这样一粒种子就变成了两粒种子。小明将 $k$ 粒不同的种子按字母先后顺序排队，从 A 开始依次放入克隆机，每次把得到的两粒相同的种子（放入的 $1$ 粒和克隆出来的 $1$ 粒）放到队尾，这样不断的进行克隆。

例如，一共有 $7$ 种不同的种子，依次用 $\text{A,B,C,D,E,F,G}$ 表示。

- 第 $1$ 粒种子 $\text{A}$ 放进克隆机之前，队列是：$\text{A,B,C,D,E,F,G}$。
- 第 $1$ 粒种子 $\text{A}$ 放进克隆机之后，队列是：$\text{B,C,D,E,F,G,A,A}$。
- 第 $3$ 粒种子 $\text{C}$ 放进克隆机之前，队列是：$\text{C,D,E,F,G,A,A,B,B}$。
- 第 $3$ 粒种子 $\text{C}$ 放进克隆机之后，队列是：$\text{D,E,F,G,A,A,B,B,C,C}$。

请问第 $n$ 粒放进克隆机的是什么种子？用 $\text{A,B,C,D,\dots,Z}$ 表示。

## 输入格式

输入 $1$ 行 $2$ 个数字，$k$ 和 $n$，用空格隔开。

## 输出格式

输出 $1$ 个字符，代表第 $n$ 粒放进克隆机的种子。

## 样例

**样例输入 #1**
```
7 10```

**样例输出 #1**
```
B```

**样例输入 #2**
```
26 80```

**样例输出 #2**
```
A```

**样例输入 #3**
```
15 689```

**样例输出 #3**
```
G```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

long long k, n;   // k: 种子种类数，n: 第 n 粒放入的种子（1-based）

int main() {
    cin >> k >> n;

    /*
     * 核心思想：将整个过程看作一棵完全二叉树（或叫“无限”树）。
     * 前 k 个节点是根节点，对应 A~第 k 个字母。
     * 每个节点被取出时，会产生两个子节点（自身和克隆），它们被放到队尾。
     * 于是所有节点按广度优先顺序（放入顺序）编号。
     * 对于编号 i（从 0 开始），如果 i >= k，则它的父节点编号为 (i - k) / 2。
     * 因为前 k 个节点没有父节点（它们是根）。
     * 所以，我们可以从目标节点 n（转为 0-based）不断向上找父节点，
     * 直到找到一个根节点（编号 < k），它的字母就是答案。
     */

    // 如果 n 在第一批（前 k 个）中，直接输出第 n 个字母（1-based）
    if (n <= k) {
        cout << char('A' + n - 1) << endl;   // 注意 n 是 1-based，减 1 转为 0-based
        return 0;
    }

    // 将 n 转为 0-based 索引：第 n 个对应编号 n-1
    n--;

    // 不断向上追溯父节点，直到编号落在根节点范围 [0, k-1]
    while (n >= k) {
        n = (n - k) / 2;   // 父节点编号公式（整数除法）
    }

    // 此时 n 就是根节点的编号（0~k-1），转换为对应字母
    cout << char('A' + n) << endl;

    return 0;
}
```
