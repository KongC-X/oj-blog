## 题目描述

小 A 有两块球形橡皮泥，一个半径是 $4$，一个半径是 $10$。他想把这两块橡皮泥揉在一起，然后塑造成一个正方体，请问这个正方体的棱长是多少？如果结果不是整数，则舍去小数点之后的数字。取 $\pi = 3.141593$。

## 输出格式

请输出一个整数表示答案。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 两个球半径4和10，总体积 = (4/3)*pi*(4^3 + 10^3) = (4/3)*pi*(64+1000)
    // 开立方后向下取整，棱长约为16
    cout << 16 << endl;
    return 0;
}
```
