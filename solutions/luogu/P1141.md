# P1141 01迷宫

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-07-30

**算法标签**：`搜索`、`并查集`、`广度优先搜索 BFS`、`深度优先搜索 DFS`、`队列`

## 题目描述

有一个仅由数字 $0$ 与 $1$ 组成的 $n \times n$ 格迷宫。若你位于一格 $0$ 上，那么你可以移动到相邻 $4$ 格中的某一格 $1$ 上，同样若你位于一格 $1$ 上，那么你可以移动到相邻 $4$ 格中的某一格 $0$ 上。

你的任务是：对于给定的迷宫，询问从某一格开始能移动到多少个格子（包含自身）。

## 输入格式

第一行为两个正整数 $n,m$。

下面 $n$ 行，每行 $n$ 个字符，字符只可能是 $0$ 或者 $1$，字符之间没有空格。

接下来 $m$ 行，每行两个用空格分隔的正整数 $i,j$，对应了迷宫中第 $i$ 行第 $j$ 列的一个格子，询问从这一格开始能移动到多少格。

## 输出格式

$m$ 行，对于每个询问输出相应答案。

## 样例

**样例输入 #1**
```
2 2
01
10
1 1
2 2
```

**样例输出 #1**
```
4
4
```

## AC 代码

```cpp
#include <cstdio>
#include <cstring>
using namespace std;

const int MAXN = 1005;
const int MAXQ = 1000005;          // 最大格子数 1000*1000+5
int n, m;                          // n:迷宫边长，m:询问次数
char g[MAXN][MAXN];                // 地图，下标从1开始，0/1 字符
int v[MAXN][MAXN];                 // v[x][y] 表示(x,y)所属连通块编号，0表示未访问
int s[MAXQ];                       // s[id] 表示编号为 id 的连通块大小
int q[MAXQ][3];                    // 队列，q[?][1]存行，q[?][2]存列
int fx[5] = {0,0,1,0,-1};         // 方向数组，1~4：右、下、左、上
int fy[5] = {0,1,0,-1,0};

int main() {
    scanf("%d %d", &n, &m);
    for (int i = 1; i <= n; ++i) {
        scanf("%s", g[i] + 1);     // 读入一行字符，从下标1开始存放
    }

    int cnt = 0;                   // 连通块编号计数器
    // 遍历所有格子，对未访问的格子开始BFS，划分连通块
    for (int i = 1; i <= n; ++i) {
        for (int j = 1; j <= n; ++j) {
            if (v[i][j] == 0) {
                cnt++;                         // 新连通块编号
                int head = 1, tail = 1;        // 队列头尾指针
                q[1][1] = i;                   // 起点入队
                q[1][2] = j;
                v[i][j] = cnt;                 // 标记为当前连通块
                int sum = 1;                   // 连通块大小
                while (head <= tail) {
                    int x = q[head][1];
                    int y = q[head][2];
                    // 尝试四个方向
                    for (int d = 1; d <= 4; ++d) {
                        int tx = x + fx[d];
                        int ty = y + fy[d];
                        // 坐标合法、未访问、且数字与当前格子不同（0/1交替）
                        if (tx >= 1 && tx <= n && ty >= 1 && ty <= n && v[tx][ty] == 0 && g[tx][ty] != g[x][y]) {
                            tail++;
                            q[tail][1] = tx;
                            q[tail][2] = ty;
                            v[tx][ty] = cnt;   // 标记
                            sum++;             // 连通块大小加1
                        }
                    }
                    head++;
                }
                s[cnt] = sum;                  // 记录该连通块大小
            }
        }
    }

    // 处理询问
    while (m--) {
        int x, y;
        scanf("%d %d", &x, &y);
        printf("%d\n", s[v[x][y]]);            // 直接输出所属连通块的大小
    }
    return 0;
}
```
