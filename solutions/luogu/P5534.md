# P5534 【XR-3】等差数列

> **洛谷** | 入门 | C++14 | 提交时间: 2026-05-26

**算法标签**：`模拟`、`递归`、`入门模拟`

## 题目描述

小 X 给了你一个等差数列的前两项以及项数，请你求出这个等差数列各项之和。

等差数列：对于一个 $n$ 项数列 $a$，如果满足对于任意 $i \in [1,n)$，有 $a_{i+1} - a_i = d$，其中 $d$ 为定值，则称这个数列为一个等差数列。

## 输入格式

一行 $3$ 个整数 $a_1, a_2, n$，表示等差数列的第 $1,2$ 项以及项数。

**数据范围：**

- $|a_1|,|a_2| \le 10^6$。
- $3 \le n \le 10^6$。

## 输出格式

一行一个整数，表示答案。

## 样例

**样例输入 #1**
```
1 2 3
```

**样例输出 #1**
```
6
```

**样例输入 #2**
```
-5 -10 5
```

**样例输出 #2**
```
-75
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    // a: 第1项, b: 第2项, n: 项数
    long long a, b, n;        // 用 long long 防止中间乘法溢出
    cin >> a >> b >> n;

    // 思路：等差数列求和 = (首项 + 末项) * 项数 / 2
    // 公差 d = b - a
    // 末项 c = a + (n - 1) * d
    // 总和 s = (a + c) * n / 2

    long long d = b - a;                     // 公差
    long long c = a + (n - 1) * d;           // 末项
    long long s = (a + c) * n / 2;           // 总和

    cout << s << '\n';
    return 0;
}
```
