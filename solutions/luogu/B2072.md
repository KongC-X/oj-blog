# B2072 分苹果

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-05

## 题目描述

把一堆苹果分给 $n$ 个小朋友，要使每个人都能拿到苹果，而且每个人拿到的苹果数都不同的话，这堆苹果至少应该有多少个？

## 输入格式

一个不大于 $1000$ 的正整数 $n$，代表小朋友人数。

## 输出格式

一个整数，表示满足条件的最少苹果个数。

## 样例

**样例输入 #1**
```
8
```

**样例输出 #1**
```
36
```

## AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int n,ans=0;
	cin>>n;
	for(int i=1;i<=n;i++)
	ans+=i;//累加
	
	cout<<ans;//输出
	
	return 0;
}

```
