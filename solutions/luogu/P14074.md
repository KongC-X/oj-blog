# P14074 [GESP202509 五级] 有趣的数字和

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1193>

## 题目描述

如果一个正整数的二进制表示包含奇数个 $1$，那么小 A 就会认为这个正整数是有趣的。

例如，$7$ 的二进制表示为 $(111)_2$，包含 $1$ 的个数为 $3$ 个，所以 $7$ 是有趣的。但是 $9=(1001)_2$ 包含 $2$ 个 $1$，所以 $9$ 不是有趣的。

给定正整数 $l,r$，请你统计满足 $l\le n\le r$ 的有趣的整数 $n$ 之和。

## 输入格式

一行，两个正整数 $l,r$，表示给定的正整数。

## 输出格式

一行，一个正整数，表示 $l,r$ 之间有趣的整数之和。

## 样例

**样例输入 #1**
```
3 8```

**样例输出 #1**
```
19```

**样例输入 #2**
```
65 36248```

**样例输出 #2**
```
328505490```

## AC 代码

```cpp
#include<iostream>
using namespace std;

// b[n] 表示从 1 到 n 的有趣数的和（n 取值 0~15），是预先计算好的小范围查询表
// b[0] = 0：1 到 0 没有数，和为 0
// b[1] = 1：1 到 1 的有趣数只有 {1}，和=1
// b[2] = 3：1 到 2 的有趣数 {1,2}，和=3
// b[3] = 3：1 到 3 的有趣数 {1,2}（3 的二进制 11 有两个 1，不有趣），和=3
// b[7] = 14：1 到 7 的有趣数 {1,2,4,7}，和=14
// b[15] = 60：1 到 15 的有趣数 {1,2,4,7,8,11,13,14}，和=60

int b[16] = {0, 1, 3, 3, 7, 7, 7, 14, 22, 22, 22, 33, 33, 46, 60, 60};

// 计算整数 n 的二进制表示中 1 的个数
int count(int n){
    if(n == 1)return 1;
    int cnt = 0;
    // 循环 0 到 30 位（覆盖 0~2^31-1 的范围）
    for(int i = 0;i <= 30;i++){ 
        // 检查第 i 位是否为 1
        if((n >> i) & 1){
            cnt++; 
        }
    }
    return cnt;
}

// 在二进制中，每 4 个连续数字的“有趣数”分布有规律：
// 观察 0~3, 4~7, 8~11, 12~15... 每个长度为 4 的块：
// 块 [4k, 4k+3] 中恰好有 2 个有趣数
// 这些有趣数的和大约是 8k+... 的形式
// 通过数学归纳可以证明:sum(4c−1)=4c^2−c

//  1 到 n 的有趣数的和
long long sum(long long n){ 
    if(n < 16)return b[n];  // 小范围直接查表
    // 找到最近的 4 的倍数起点
    long long c = ((n - 4) >> 2);  // 等价于 c = (n-4)/4（向下取整）
    // sum(4c - 1) 的值
    long long s = ((c * c) << 2) - c ;  // a = 4 * c * c - c
    // 现在 s 等于 1 到 (4c-1) 的有趣数之和,我们还需要加上从 4c 到 n 的有趣数
    // 循环从 4*c 到 n，检查每个数是否为有趣数，如果是则累加
    for(long long i = (c << 2);i <= n;i++){  // i 从 4*c 到 n
        if(count(i) % 2 == 1){  // 如果 i 的二进制 1 的个数为奇数
            s += i;     // 累加到总和
        }
    }
    return s;
}

int main(){
    long long l, r;
    cin >> l >> r;
    // 计算区间 [l, r] 的有趣数和
    cout << sum(r) - sum(l - 1) << endl; // 标准的前缀和技巧：[l, r] 的和 = [1, r] 的和 - [1, l-1] 的和
}
