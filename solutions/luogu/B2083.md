# B2083 画矩形

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-04

## 题目描述

根据输入的四个参数：$a,b,c,f$ 参数，画出对应的矩形。

前两个参数 $a,b$ 为整数，依次代表矩形的高和宽；

第三个参数 $c$ 是一个字符，表示用来填充的矩形符号；

第四个参数 $f$ 为整数，$0$ 代表空心，否则代表实心。

具体例子请见样例。

## 输入格式

第一行：$a,b,c,f$。

## 样例

**样例输入 #1**
```
7 7 @ 0
```

**样例输出 #1**
```
@@@@@@@
@     @
@     @
@     @
@     @
@     @
@@@@@@@```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;                // a: 矩形的高, b: 矩形的宽
    char c;                  // c: 填充字符
    int f;                   // f: 0表示空心，非0表示实心
    cin >> a >> b >> c >> f;

    // 思路：逐行打印。若实心或行为第一行/最后一行，打印全c；否则打印 c + 空格*(b-2) + c。
    for (int i = 1; i <= a; i++) {
        if (f != 0 || i == 1 || i == a) {   // 实心或首尾行
            for (int j = 1; j <= b; j++) {
                cout << c;
            }
        } else {                             // 空心中间行
            cout << c;
            for (int j = 2; j < b; j++) {   // 中间 b-2 个空格
                cout << ' ';
            }
            cout << c;
        }
        cout << endl;
    }
    return 0;
}
```
