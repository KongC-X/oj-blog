# P2197 【模板】Nim 游戏

> **洛谷** | 普及+/提高-| C++14 | 提交时间: 2026-07-24

**算法标签**：`博弈论`、`SG 函数`、`模板题`

## 题目描述

甲，乙两个人玩 Nim 取石子游戏。

Nim 游戏的规则是这样的：地上有 $n$ 堆石子，每人每次可从任意一堆石子里取出任意多枚石子扔掉，可以取完，不能不取。每次只能从一堆里取。最后没石子可取的人就输了。假如甲是先手，且告诉你这 $n$ 堆石子的数量，他想知道是否存在先手必胜的策略。

## 输入格式

**本题有多组测试数据。**

第一行一个整数 $T$，表示有 $T$ 组数据。

接下来每两行是一组数据：
- 第一行一个整数 $n$，表示有 $n$ 堆石子；
- 第二行有 $n$ 个非负整数，表示每一堆石子的数量。

## 输出格式

共 $T$ 行，每行表示如果对于这组数据存在先手必胜策略则输出 `Yes`，否则输出 `No`。

## 样例

**样例输入 #1**
```
2
2
1 1
2
1 0```

**样例输出 #1**
```
No
Yes```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
      思路：Nim 游戏模板题
      结论：所有堆石子数量的异或和不为 0 时，先手必胜；否则先手必败。
      因为只有将所有石子数异或起来不等于0，先手才能通过一次操作将其变为0，
      从而使自己处于必胜态。
    */
    int T;
    cin >> T;
    while (T--) {
        int n;
        cin >> n;
        int x = 0;               // 异或和
        for (int i = 1; i <= n; i++) {
            int a;
            cin >> a;
            x ^= a;
        }
        if (x != 0) {
            cout << "Yes" << endl;
        } else {
            cout << "No" << endl;
        }
    }
    return 0;
}
```
