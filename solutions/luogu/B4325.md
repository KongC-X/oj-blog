# B4325 [语言月赛 202505] 翻书

> **洛谷** | 入门 | C++14 | 提交时间: 2025-06-03

**算法标签**：`匈牙利算法`

## 题目描述

双面打印是常见的节约纸张的方式。小 A 双面打印了某份文件，第 $1,2$ 页在第一张纸上，第 $3,4$ 页在第二张纸上……

页数更小的一面称为正面，另一面称为反面。翻开 $k$ 张纸，可以看到第 $k$ 张纸的反面和第 $k+1$ 张纸的正面。

请问，小 A 想要阅读第 $p$ 页的内容，应该翻开多少张纸。

## 输入格式

输入一行一个整数 $p$。

## 输出格式

输出一行一个整数，表示需要翻开的纸张页数。

## 样例

**样例输入 #1**
```
1```

**样例输出 #1**
```
0```

**样例输入 #2**
```
4```

**样例输出 #2**
```
2```

## AC 代码

```cpp
#include<iostream>
using namespace std;

long long n;
int main() {
    cin >> n;
    cout << n / 2 << endl;
}
```
