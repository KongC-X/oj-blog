# B3683 [语言月赛202211] String Problem

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-08-30

**算法标签**：`字符串`、`2022`、`O2优化`、`语言月赛`

## 题目背景

扶苏很喜欢研究制糊串问题。

## 题目描述

扶苏给你了两个长度为 $n$ 的字符串 $s$ 和 $t$，请你判定这两个字符串是否相同。

扶苏觉得这个问题太简单了，所以她还给出了 $q$ 次操作，每次操作是修改其中一个字符串的某个位置的字符。每次操作过后，都请你回答一次 $s$ 和 $t$ 是否相同。

字符串下标从 1 开始编号。例如，若字符串 $s$ 为 $\texttt {abc}$，要将它的第二个位置修改为 $d$，则修改后的字符串为 $\texttt{adc}$。

## 输入格式

**本题单测试点内有多组测试数据**。

输入的第一行是一个整数 $T$，表示数据组数。接下来按顺序给出每组数据的输入：

对每组数据，第一行是两个整数，依次表示字符串长度 $n$ 和操作的次数 $q$。  
第二行是一个长度为 $n$ 的字符串，表示 $s$。  
第三行是一个长度为 $n$ 的字符串，表示 $t$。  
接下来 $q$ 行，每行两个整数 $o, p$ 和一个字符 $c$，其中 $o$ 是 $0$ 或 $1$。
- 若 $o = 0$，则表示将字符串 $s$ 的第 $p$ 个字符修改成 $c$。
- 若 $o = 1$，则表示将字符串 $t$ 的第 $p$ 个字符修改成 $c$。

## 输出格式

对每组数据，依次输出答案。

每组数据共需要输出 $q + 1$ 行。  
首先对初始给定的字符串 $s$ 和 $t$，若他们相同，则输出一行 `Yes`，否则输出一行 `No`。  
接下来，对每次操作，若操作后两字符串相同，输出一行 `Yes`，否则输出一行 `No`。

## 样例

**样例输入 #1**
```
2
3 2
abc
abc
1 2 d
0 2 d
5 0
abdce
acdce
```

**样例输出 #1**
```
Yes
No
Yes
No```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3683 [语言月赛202211] String Problem
     * 题意：给定两个字符串 s 和 t，支持单点修改，每次修改后回答两字符串是否相等。
     *
     * 核心思路：
     * 1. 维护一个变量 d，表示 s 和 t 在相同位置上有多少个字符不同。
     * 2. 初始时，遍历所有位置，统计不同的字符个数。
     * 3. 每次修改时，只更新被修改位置对 d 的影响：
     *    - 修改前，若该位置 s[p] != t[p]，则它贡献了 1 个不同；
     *    - 修改后，若该位置 s[p] != t[p]，则它贡献了 1 个不同。
     *    根据修改前后的变化，调整 d。
     * 4. 若 d == 0，则两字符串相同，输出 Yes；否则输出 No。
     * 5. 所有操作 O(1) 完成，总复杂度 O(n + q)。
     *
     * 注意：n, q 最大 1e6，需使用快速 IO（ios::sync_with_stdio(false)）。
     */
    ios::sync_with_stdio(false);
    cin.tie(0);

    int T;
    cin >> T;

    while (T--) {
        int n, q;
        cin >> n >> q;
        string s, t;
        cin >> s >> t;

        int d = 0;   // d: 当前 s 和 t 中不同字符的位置数
        for (int i = 0; i < n; i++) {
            if (s[i] != t[i]) d++;
        }

        // 初始状态
        cout << (d == 0 ? "Yes\n" : "No\n");

        while (q--) {
            int o, p;
            char c;
            cin >> o >> p >> c;
            p--;   // 转为 0-based 下标

            if (o == 0) {   // 修改字符串 s 的第 p 个字符为 c
                // 修改前，该位置若不同，则 d 中包含了这一处不同
                if (s[p] != t[p]) {
                    // 修改后若变成相同，则 d 减 1
                    if (c == t[p]) d--;
                } else {
                    // 修改前相同，修改后不同，则 d 加 1
                    if (c != t[p]) d++;
                }
                s[p] = c;   // 执行修改
            } else {        // 修改字符串 t 的第 p 个字符为 c
                if (s[p] != t[p]) {
                    if (c == s[p]) d--;
                } else {
                    if (c != s[p]) d++;
                }
                t[p] = c;
            }

            cout << (d == 0 ? "Yes\n" : "No\n");
        }
    }

    return 0;
}
```
