# P10457 占卜DIY

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-04

**算法标签**：`模拟`、`队列`

## 题目描述

lyd 学会了使用扑克 DIY 占卜。方法如下：一副去掉大小王的扑克共 $52$ 张，打乱后均分为 $13$ 堆，编号 $1\sim 13$，每堆 $4$ 张，其中第 $13$ 堆称作“生命牌”，也就是说你有 $4$ 条命。这里边，$4$ 张 $K$ 被称作死神。

初始状态下，所有的牌背面朝上扣下。

流程如下：

- 抽取生命牌中的最上面一张（第一张）。
- 把这张牌翻开，正面朝上，放到牌上的数字所对应编号的堆的最上边。（例如抽到 $2$，正面朝上放到第 $2$ 堆牌最上面，又比如抽到 $J$，放到第 $11$ 堆牌最上边，注意是正面朝上放）
- 从刚放了牌的那一堆最底下（最后一张）抽取一张牌，重复第 $2$ 步。（例如你上次抽了 $2$，放到了第二堆顶部，现在抽第二堆最后一张发现是 $8$，又放到第 $8$ 堆顶部……）
- 在抽牌过程中如果抽到 $K$，则称死了一条命，就扔掉 $K$ 再从第 $1$ 步开始。
- 当发现四条命都死了以后，统计现在每堆牌上边正面朝上的牌的数目，只要同一数字的牌出现 $4$ 张正面朝上的牌（比如 $4$ 个 $A$），则称“开了一对”，当然 $4$ 个 $K$ 是不算的。
- 统计一共开了多少对，开了 $0$ 对称作“极凶”，$1\sim 2$ 对为“大凶”，$3$ 对为“凶”，$4\sim 5$ 对为“小凶”，$6$ 对为“中庸”，$7\sim 8$ 对“小吉”，$9$ 对为“吉”，$10\sim11$ 对为“大吉”，$12$ 对为“满堂开花，极吉”。

如果还不明白，请参考样例。

## 输入格式

一共 $13$ 行，为每堆牌的具体牌是什么（不区分花色只区分数字），每堆输入的顺序为从上到下。

为了便于读入，用 $0$ 代表 $10$。

## 样例

**样例输入 #1**
```
8 5 A A
K 5 3 2
9 6 0 6
3 4 3 4
3 4 4 5
5 6 7 6
8 7 7 7
9 9 8 8
9 0 0 0
K J J J
Q A Q K
J Q 2 2
A K Q 2```

**样例输出 #1**
```
9```

## AC 代码

```cpp
#include<bits/stdc++.h>        // 万能头文件，包含所有常用库
#define int long long          // 把 int 全部替换为 long long（防止数据溢出）
using namespace std;           // 使用标准命名空间

deque<int> a[20];              // 13堆牌（下标1~13），每堆用双端队列存储牌面值
int b[20];                     // b[i] 表示第 i 堆已经正面朝上的牌的数量
int sum;                       // sum 记录已经“开对”的数量（即正面牌达到4张的堆数）
char x;                        // 临时变量，用于读入字符

signed main(){                 // 因为用了 #define int，这里用 signed 表示真正的 int 主函数
    // ========== 读入 13 堆牌，每堆4张 ==========
    for(int i=1; i<=13; i++) {          // 遍历13堆
        for(int j=1; j<=4; j++) {       // 每堆4张
            cin >> x;                   // 读入一个字符（牌面，如 'A','2','K'）
            // 将字符转换为对应的数字
            if(x <= '9' && x >= '1') a[i].push_back(x - '0');  // '1'~'9' 转 1~9
            else if(x == '0') a[i].push_back(10);              // '0' 代表 10
            else if(x == 'J') a[i].push_back(11);
            else if(x == 'Q') a[i].push_back(12);
            else if(x == 'K') a[i].push_back(13);
            else if(x == 'A') a[i].push_back(1);
        }
    }

    // ========== 开始模拟占卜流程 ==========
    // 注意：这个循环会一直执行，直到生命牌堆（第13堆）被抽空
    // 每次循环对应“抽一条命”的过程（从生命牌堆顶部开始）
    while(!a[13].empty()) {
        int t = a[13].front();    // 从生命牌堆顶部取一张牌（数字 t）
        a[13].pop_front();        // 移除这张牌（它被抽走了）

        // 这是核心循环：只要没抽到 K（t != 13），就一直执行
        while(t != 13) {
            // ====== 把刚抽到的牌（数字 t）放到第 t 堆顶部，并翻成正面 ======
            b[t]++;               // 第 t 堆正面朝上的牌数量 +1
            if(b[t] >= 4) sum++;  // 如果这一堆正面牌达到4张，就算“开了一对”
                                  // 注意用 >= 是因为之后还可能翻到这一堆，防止重复计数

            // ====== 从第 t 堆的底部取一张牌（作为下一次要翻的牌） ======
            int p = a[t].back();  // p: 第 t 堆最底下的牌面值
            a[t].pop_back();      // 移除这张底牌

            // ====== 下一次循环将翻开的牌就是 p ======
            t = p;                // 更新 t 为刚取的底牌，继续循环
        }
        // 当 t == 13 时跳出内层循环，代表抽到了 K，死了一条命
        // 然后外层 while 会继续从生命牌堆取下一张牌，开始下一条命
    }

    // ========== 输出最终结果 ==========
    cout << sum;    // sum 就是总共开了多少对
    return 0;
}
```
