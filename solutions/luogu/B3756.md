# B3756 [信息与未来 2021] 幸运数字

> **洛谷** | 普及- | C++14 | 提交时间: 2026-04-14

**算法标签**：`快速傅里叶变换`、`CDQ分治`、`排序算法`

## 题目描述

如果一个正整数 $n$ 在五进制、七进制、九进制的表示下都没有数字 $0$，我们就称 $n$ 是幸运数字。例如：

- $(987)_{10}=(12422)_5=(2610)_7=(1316)_9$，因此 $n=987$ 不是幸运数字。

- $(988)_{10}=(12423)_5=(2611)_7=(1317)_9$，因此 $n=988$ 是幸运数字。

写程序求出 $a,a+1,a+2,\cdots,b$ 之间一共有多少个幸运数字。

## 输入格式

输入一行两个正整数 $a$ 和 $b$。

## 输出格式

输出一行，表示 $a,a+1,a+2,\cdots,b$ 中幸运数字的个数。

## 样例

**样例输入 #1**
```
100 1000```

**样例输出 #1**
```
203```

**样例输入 #2**
```
900 4096```

**样例输出 #2**
```
389```

## AC 代码

```cpp
#include <iostream>
#include <string>
using namespace std;

// 将十进制数 n 转换为 base 进制的字符串
string toBase(int n, int base) {
    if (n == 0) return "0";
    string res = "";
    while (n > 0) {
        int digit = n % base;              // 取当前最低位
        res = char(digit + '0') + res;     // 拼接到前面
        n /= base;
    }
    return res;
}

// 判断字符串中是否含有字符 '0'
bool hasZero(string s) {
    for (int i = 0; i < s.length(); i++) {
        if (s[i] == '0') return true;
    }
    return false;
}

// 判断 n 是否为幸运数字
bool isLucky(int n) {
    // 分别转换五、七、九进制，检查是否都不含 0
    if (hasZero(toBase(n, 5))) return false;
    if (hasZero(toBase(n, 7))) return false;
    if (hasZero(toBase(n, 9))) return false;
    return true;
}

int main() {
    int a, b;
    cin >> a >> b;

    int cnt = 0;
    for (int i = a; i <= b; i++) {
        if (isLucky(i)) cnt++;
    }

    cout << cnt << endl;
    return 0;
}
```
