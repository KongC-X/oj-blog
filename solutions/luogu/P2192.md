# P2192 HXY玩卡片

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-13

**算法标签**：`模拟`

## 题目描述

HXY 得到了一些卡片，这些卡片上标有数字 $0$ 或 $5$。

现在她可以选择其中一些卡片排成一列，使得排出的一列数字组成的数最大，且满足被 $90$ 整除这个条件。

同时，这个数必须为合法的某个非负整数，即不能含有前导 $0$，即 $0$ 不能作为这串数的首位。

但是特殊地，整数 $0$ 满足条件。

如果不能排出这样的数，输出 $-1$。

## 输入格式

第一行，卡片的个数 $n$。

第二行，分别给出了这 $n$ 个数（只能为数字 $5$ 或 $0$）。

## 输出格式

仅一行，如果可以排出，则输出这个数。否则输出 $-1$。

## 样例

**样例输入 #1**
```
4
5 0 5 0```

**样例输出 #1**
```
0
```

**样例输入 #2**
```
11
5 5 5 5 5 5 5 5 0 5 5```

**样例输出 #2**
```
5555555550```

**样例输入 #3**
```
2
5 5```

**样例输出 #3**
```
-1
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P2192 HXY玩卡片
     * 题意：用若干张0和5的卡片，选择其中一些排成一个数，要求无前导0（0本身除外），
     *       且能被90整除，求最大的这样的数，不存在则输出-1。
     * 
     * 思路：
     * 1. 能被90整除 ⇔ 能被10整除（个位为0）且能被9整除（各位数字之和是9的倍数）。
     * 2. 数字只由0和5组成，所以各位数字之和 = 5 * (5的个数)。因此5的个数必须是9的倍数。
     * 3. 为了使数最大，应尽量多的使用5，并且5放在前面，0放在后面（末尾必须为0）。
     * 4. 如果没有0，无法满足个位为0，输出-1。
     * 5. 如果5的个数少于9，则无法组成正数，但可以用一张0得到数字0（合法），所以输出0。
     * 6. 否则，取最大的9的倍数个5（即 cnt5 - cnt5%9 ），后面跟上所有0，即为答案。
     */
    int n;
    cin >> n;
    int cnt5 = 0, cnt0 = 0;
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (x == 5) cnt5++;
        else cnt0++;
    }

    // 没有0，无法被10整除
    if (cnt0 == 0) {
        cout << -1 << endl;
        return 0;
    }

    // 5的个数不足9个，只能排出0
    if (cnt5 < 9) {
        cout << 0 << endl;
        return 0;
    }

    // 使用最大的9的倍数个5
    int use5 = cnt5 - cnt5 % 9;
    // 如果use5为0，说明没有5可用，只能输出0（但此时cnt5<9已处理，所以这里不会执行）
    string ans;
    for (int i = 0; i < use5; i++) ans.push_back('5');
    for (int i = 0; i < cnt0; i++) ans.push_back('0');
    cout << ans << endl;

    return 0;
}
```
