# B2086 不定方程求解

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-04

## 题目描述

给定正整数 $a$，$b$，$c$。求不定方程 $ax+by=c$ 关于未知数 $x$ 和 $y$ 的所有非负整数解组数。

## 输入格式

一行，包含三个正整数 $a$，$b$，$c$，两个整数之间用单个空格隔开。每个数均不大于 $1000$。

## 输出格式

一个整数，即不定方程的非负整数解组数。

## 样例

**样例输入 #1**
```
2 3 18```

**样例输出 #1**
```
4```

## AC 代码

```cpp
#include <iostream>
using namespace std;
int a, b, c, ans;
int main(){
    cin >> a >> b >> c;
    for(int x = 0;a * x <= c;x++)
        for(int y = 0;b * y <= c;y++)
            if(a * x + b * y == c) ans++;
    cout << ans;
    return 0;
}

```
