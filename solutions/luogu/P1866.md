# P1866 编号

> **洛谷** | 普及- | C++14 | 提交时间: 2026-05-18

**算法标签**：`递归`、`暴力枚举`、`容斥原理`、`队列`

## 题目描述

太郎有 $N$ 只兔子，现在为了方便识别它们，太郎要给他们编号。兔子们向太郎表达了它们对号码的喜好，每个兔子 $i$ 想要一个整数，介于 $1$ 和 $M_i$ 之间（可以为 $1$ 或 $M_i$）。当然，每个兔子的编号是不同的。现在太郎想知道一共有多少种编号的方法。

你只用输出答案对 $10^9+7$ 取余的结果即可。如果这是不可能的，就输出 $0$。

## 输入格式

第一行是一个整数 $N$。

第二行 $N$ 个整数 $M_i$。

## 输出格式

一个整数，表示方案总数。

## 样例

**样例输入 #1**
```
2
5 8
```

**样例输出 #1**
```
35```

## AC 代码

```cpp
#include <iostream>
#include <algorithm>  // sort
using namespace std;

const int MOD = 1000000007;   // 模数 1e9+7

int main() {
    // ---------- 思路 ----------
    // 每只兔子 i 的编号范围是 1 ~ M_i，且所有兔子编号两两不同。
    // 将兔子按 M_i 从小到大排序。
    // 排序后，对于第 i 只兔子（i 从 0 开始）：
    //   它的上限是 M_i，但前面已经分配了 i 个编号，
    //   并且这些编号一定都在 1 ~ M_i 内（因为 M_i 是递增的），
    //   所以它可选的编号个数为 M_i - i。
    // 如果某一步的可选个数 <= 0，说明无解，答案为 0。
    // 否则将所有可选个数相乘，就是总方案数。
    // 注意每次乘完都要取模。
    // -------------------------

    int n;                       // n: 兔子的数量
    cin >> n;

    int a[55];                   // a: 存放每只兔子的上限 M_i，最多 50
    for (int i = 0; i < n; ++i)
        cin >> a[i];

    // 从小到大排序
    sort(a, a + n);

    long long ans = 1;           // ans: 最终答案（用 long long 防溢出）

    for (int i = 0; i < n; ++i) {
        int t = a[i] - i;        // t: 当前兔子可选的编号个数
        if (t <= 0) {            // 不够选了
            ans = 0;
            break;
        }
        ans = (ans * t) % MOD;   // 乘法取模
    }

    cout << ans << endl;

    return 0;
}
```
