# B3873 [GESP202309 六级] 小杨买饮料

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-06-02

**算法标签**：`动态规划`、`最小割`、`最近公共祖先`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1132>

## 题目描述

小杨来到了一家商店，打算购买一些饮料。这家商店总共出售 $N$ 种饮料，编号从 $0$ 至 $N-1$，其中编号为 $i$ 的饮料售价 $c_i$ 元，容量 $l_i$ 毫升。

小杨的需求有如下几点：

1. 小杨想要尽可能尝试不同种类的饮料，因此他希望每种饮料至多购买 $1$ 瓶；

2. 小杨很渴，所以他想要购买总容量不低于 $L$ 的饮料；

3. 小杨勤俭节约，所以在 $1$ 和 $2$ 的前提下，他希望使用尽可能少的费用。

方便起见，你只需要输出最少花费的费用即可。特别地，如果不能满足小杨的要求，则输出 `no solution`。

## 输入格式

第一行两个整数 $N,L$。

接下来 $N$行，依次描述第 $i=0,1,\cdots,N-1$ 种饮料：每行两个整数 $c_i,l_i$。

## 输出格式

输出一行一个整数，表示最少需要花费多少钱，才能满足小杨的要求。特别地，如果不能满足要求，则输出 `no solution`。

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;
 
/*
 *
 * 解题思路：
 *   这是一个 0-1 背包的变种问题。
 *   每种饮料只有"选"(1瓶)或"不选"(0瓶)两种可能，
 *   目标不是"容量不超过L"，而是"容量至少达到L"，花费最小。
 *
 *   用 dp[j] 表示凑出容量 j 所需的最小花费（j = 0 ~ L）。
 *   对于每种饮料 (c, l)，从大到小更新：
 *     新的容量 = min(当前容量 + l, L)   ← 超过 L 的按 L 算
 *     lᵢ 可能远大于 L，所以 k = min(j + l, L) 是必须的。
 *     不截断会导致数组越界，或者 dp 数组开太大浪费空间。
 *     dp[新容量] = min(dp[新容量], dp[当前容量] + c)
 *     dp[k] = min(dp[k], dp[j] + c)
 *
 *   最后看 dp[L]：如果是 INF 说明凑不够，输出 "no solution"，
 *   否则输出 dp[L]。
 *
 * 时间复杂度：O(N·L) = 500 × 2000 = 1e6，完全可行
 * 空间复杂度：O(L)
 */

const long long INF = 1e18; // 一个很大的数，表示"不可达",
int c[510], l[510];      // c[i]：第 i 种饮料的价格，l[i]：第 i 种饮料的容量
long long dp[2010];     // dp[j]：凑出容量 j 的最小花费

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    // ---------- 输入 ----------
    int n;  // 饮料种类数
    int L;  // 小杨需要的最低容量
    cin >> n >> L;
    for (int i = 1; i <= n; i++) {  // 下标从 1 开始
        cin >> c[i] >> l[i];
    }

    // ---------- DP 初始化 ----------
    // 把所有容量都设为"不可达"
    for (int j = 0; j <= L; j++) {
        dp[j] = INF;
    }
    dp[0] = 0;  // 容量 0 不需要花钱

    // ---------- 核心 DP ----------
    // 遍历每种饮料
    for (int i = 1; i <= n; i++) {
        int cost = c[i];   // 当前饮料的价格
        int vol  = l[i];   // 当前饮料的容量

        // 倒序遍历容量，保证每种饮料只用一次
        for (int j = L; j >= 0; j--) {
            if (dp[j] == INF) continue;  // 当前容量不可达，跳过

            // 买了这瓶后，新的容量（超过 L 就算 L）
            int k = min(j + vol, L);

            // 更新 dp：看看买这瓶会不会更便宜
            dp[k] = min(dp[k], dp[j] + cost);
        }
    }

    // ---------- 输出 ----------
    if (dp[L] == INF) {
        cout << "no solution" << endl;
    } else {
        cout << dp[L] << endl;
    }

    return 0;
}
```
