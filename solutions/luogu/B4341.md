# B4341 [语言月赛 202506] 票价计算

> **洛谷** | 入门 | C++14 | 提交时间: 2025-06-21

**算法标签**：`匈牙利算法`

## 题目描述

某公司有三班同一时刻发车的通勤车，第 $i$ 班车的票价为 $a_i$ 元，运行时间为 $b_i$ 分钟。

小明的公司上班时间是 9:00，最慢的那班车恰好能在 9:00 到达公司。现在公司推出新政策：每在 9:00 前提前一分钟到达公司，可以获得 $c$ 元奖金。

请帮助小明选择一班车，使得实际花费（票价减去奖金）最少。

## 输入格式

输入共一行七个整数 $a_1, b_1, a_2, b_2, a_3, b_3, c$，分别表示三班车的票价、运行时间以及每分钟的奖金金额。

## 输出格式

输出共一行两个整数，表示应该选择的车次编号（$1$，$2$ 或 $3$）和最终的花费。如果有多个选择花费相同，输出编号最小的。

## 样例

**样例输入 #1**
```
3 5 10 6 7 2 1
```

**样例输出 #1**
```
1 2
```

**样例输入 #2**
```
5 10 8 8 15 5 2
```

**样例输出 #2**
```
2 4
```

**样例输入 #3**
```
20 30 15 40 25 35 3
```

**样例输出 #3**
```
1 -10
```

## AC 代码

```cpp
#include<bits/stdc++.h>
#include<iostream>
using namespace std;

int main() {
	int a1,b1,a2,b2,a3,b3,c;
	cin>>a1>>b1>>a2>>b2>>a3>>b3>>c;
	int t = max(max(b1,b2),b3);
	int s1 = a1 - c * (t - b1);
	int s2 = a2 - c * (t - b2);
	int s3 = a3 - c * (t - b3);
	// 选出最小值所对应的车,如果有多个车花费相同，取编号最小的即可。
	if(s1 <= s2 && s1 <= s3) {
		cout<<1<<' '<<s1<<endl;
	} else if(s2 <= s1 && s2 <= s3) {
		cout<<2<<' '<<s2<<endl;
	} else {
		cout<<3<<' '<<s3<<endl;
	}
}
```
