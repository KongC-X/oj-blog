# B4248 [语言月赛 202503] 数字棋盘

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-01

**算法标签**：`2025`、`数组`、`语言月赛`

## 题目描述

有一张 $n$ 行 $m$ 列的方格棋盘，其中第 $i$ 行第 $j$ 列的格子上有一个正整数 $a_{i,j}$。

我们称一个方格在另一个方格的**旁边**，当且仅当这两个方格有公共的边。例如，如果我们用 $(i, j)$ 代指第 $i$ 行第 $j$ 列的格子，那么 $(7, 2)$ 在 $(7, 3)$ 的**旁边**，但$(7, 2)$ 不在 $(8, 3)$ 的**旁边**。

现在给定两个整数 $x, y$，请你求出，在整张棋盘上有多少格子，满足它其中的整数是 $x$，且至少有一个其中整数是 $y$ 的格子在它的旁边。

## 输入格式

输入共 $n + 2$ 行。

第一行两个整数 $n, m$，代表棋盘的行数和列数。

## 输出格式

输出共一行一个整数，代表满足题目要求条件的格子的数量。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】二维数组遍历
     * 【核心思路】
     * 1. 读入 n, m 和棋盘 a[0..n-1][0..m-1]。
     * 2. 读入 x, y。
     * 3. 遍历每个格子 (i, j)：
     *    - 如果 a[i][j] != x，跳过。
     *    - 否则检查四个方向 (dx, dy)：
     *      上 (-1,0), 下 (1,0), 左 (0,-1), 右 (0,1)
     *    - 如果邻居在界内且 a[i+dx][j+dy] == y，则计数+1 并跳出。
     * 4. 输出计数。
     *
     * 【时间复杂度】O(4*n*m)
     */

    int n, m;          // n: 行数, m: 列数
    cin >> n >> m;

    static int a[1005][1005];   // 棋盘，最大 1000，多开一点防越界
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            cin >> a[i][j];
        }
    }

    int x, y;          // x: 目标值, y: 邻居目标值
    cin >> x >> y;

    int ans = 0;       // 答案计数

    // 四个方向：上、下、左、右
    int dx[4] = {-1, 1, 0, 0};
    int dy[4] = {0, 0, -1, 1};

    for (int i = 0; i < n; i++) {
        for (int j = 0; j < m; j++) {
            if (a[i][j] != x) continue;   // 不是 x，跳过

            bool flag = false;
            for (int k = 0; k < 4; k++) {
                int ni = i + dx[k];
                int nj = j + dy[k];
                // 判断邻居是否在棋盘内
                if (ni >= 0 && ni < n && nj >= 0 && nj < m) {
                    if (a[ni][nj] == y) {
                        flag = true;
                        break;
                    }
                }
            }
            if (flag) ans++;
        }
    }

    cout << ans << endl;
    return 0;
}
```
