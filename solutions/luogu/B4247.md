# B4247 [语言月赛 202503] 半个哥德巴赫猜想

> **洛谷** | 普及- | C++14 | 提交时间: 2026-07-29

**算法标签**：`2025`、`循环结构`、`语言月赛`

## 题目描述

对于正整数 $n$，如果存在正整数 $m$（$m\ge 2$）使得 $n$ 是 $m^2$ 的倍数，则称 $n$ 是一个**缪零数**。

对于正整数 $n$，如果它不是 $2 \sim n - 1$ 中任意一个整数的倍数，则称 $n$ 是一个**质数**。特别的，$1$ 不是质数。

给出正整数 $n$，请问 $n$ 有多少种方法写成一个**缪零数**与一个**质数**的和？在所有方案中，缪零数和质数的差（大数减小数）最小是多少？

## 输入格式

输入一行一个整数 $n$。

## 输出格式

输出两行。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】枚举 + 数论
     * 【核心思路】
     * 1. 读入 n。
     * 2. 用埃氏筛标记 2~n 哪些是质数，存入 isPrime 数组。
     * 3. 定义函数 isMiao(x)：判断 x 是否为缪零数。
     *    枚举 m 从 2 到 sqrt(x)，若 m*m 能整除 x，返回 true。
     * 4. 枚举 a 从 2 到 n-2（因为质数至少为 2）：
     *    - 如果 a 是缪零数 且 (n-a) 是质数，则方案数 +1。
     *    - 计算差值 abs(a - (n-a))，更新最小值。
     * 5. 输出方案数和最小差值。
     *
     * 【时间复杂度】埃氏筛 O(n log log n)，枚举判断缪零数 O(n√n) ≈ 1e6
     */

    int n;          // n: 待拆分的数
    cin >> n;

    // ---------- 筛法求质数 ----------
    bool isPrime[10005] = {false};
    // 先全部标记为 true，再筛掉合数
    for (int i = 2; i <= n; i++) isPrime[i] = true;
    for (int i = 2; i * i <= n; i++) {
        if (isPrime[i]) {
            for (int j = i * i; j <= n; j += i) {
                isPrime[j] = false;
            }
        }
    }

    // ---------- 枚举拆分 ----------
    int ansCnt = 0;      // ansCnt: 方案总数
    int minDiff = 1e9;   // minDiff: 最小差值，初始设很大

    for (int a = 2; a <= n - 2; a++) {
        // 检查 a 是否为缪零数
        bool miao = false;
        for (int m = 2; m * m <= a; m++) {
            if (a % (m * m) == 0) {
                miao = true;
                break;
            }
        }
        if (!miao) continue;   // a 不是缪零数，跳过

        int b = n - a;         // b 是另一个数
        if (b >= 2 && isPrime[b]) {   // b 必须是质数
            ansCnt++;
            int diff = a > b ? a - b : b - a;   // 绝对值
            if (diff < minDiff) minDiff = diff;
        }
    }

    // 输出结果
    cout << ansCnt << endl;
    cout << minDiff << endl;

    return 0;
}
```
