# B4230 [四川青少年 C++ 算法设计大赛 2024] 4-5 年级组第 1 题

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-18

**算法标签**：`四川`、`2024`、`顺序结构`、`科创活动`、`小学活动`

## 题目背景

第二届四川省青少年 C++ 算法设计大赛小学 4-5 年级组全省总决赛试题。数据为洛谷自造。

## 题目描述

最近，学校门口的小卖部推出了一个活动：每 $a$ 个瓶盖可以兑换 $5$ 元的现金券。现在，小 X 手里有 $n$ 个瓶盖，他打算把这些瓶盖全部都拿去兑换现金券，小 X 想知道他最多能兑换得到多少元的现金券，以及此刻他手里还剩的瓶盖的数量。

## 输入格式

一行两个整数 $n,a$，如题目中所描述的含义。

## 输出格式

一行用空格隔开的两个整数 $x,y$，表示小 X 最多兑换得到了 $x$ 元的现金券并还剩 $y$ 个瓶盖。

## 样例

**样例输入 #1**
```
10 3```

**样例输出 #1**
```
15 1```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：简单的整除和取余问题。
    // 每 a 个瓶盖换 5 元，一共 n 个瓶盖。
    // 能换的张数：n / a
    // 换得的金额：(n / a) * 5
    // 剩余的瓶盖：n % a
    int n, a;                     // n: 瓶盖总数, a: 兑换所需瓶盖数
    cin >> n >> a;

    int x = (n / a) * 5;          // x: 换得的金额
    int y = n % a;                // y: 剩余的瓶盖数

    cout << x << " " << y << endl;
    return 0;
}
```
