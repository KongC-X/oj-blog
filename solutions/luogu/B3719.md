# B3719 [语言月赛202303] Factorial B

> **洛谷** | 入门 | C++14 | 提交时间: 2026-09-12

**算法标签**：`2023`、`O2优化`、`分支结构`、`语言月赛`

## 题目描述

Farmer John 的孩子做数学题时遇到了一个难题，想要请你解答一下。

这道数学题是，$n!$ 是否是 $12$ 的倍数。

$n!$ 是 $n$ 的阶乘。一般来讲，对于一个正整数 $n$，$n! = 1 \times 2 \times 3 \times \cdots \times n$。特别的，$0 ! = 1$。

Farmer John 也觉得这个问题太难了，因此他想要把这道题交给你来完成，请你帮助他完成这个问题。

## 输入格式

输入共一行一个整数 $n$。

## 输出格式

输出共一行一个字符串。

对第一行，如果 $n!$ 是 $12$ 的倍数，输出 `Yes`，否则输出 `No`。

## 样例

**样例输入 #1**
```
3```

**样例输出 #1**
```
No```

**样例输入 #2**
```
7```

**样例输出 #2**
```
Yes```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3719 [语言月赛202303] Factorial B
     * 题意：判断 n! 是否是 12 的倍数。
     * 思路：12 = 3 × 4，n >= 4 时 n! 一定同时含有因子 3 和 4，所以是 12 的倍数。
     *       n < 4 时，n! 分别为 1,1,2,6，都不是 12 的倍数。
     */
    long long n;   // n: 输入的整数，最大可达 10^18
    cin >> n;

    if (n >= 4) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }

    return 0;
}
```
