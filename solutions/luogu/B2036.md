# B2036 输出绝对值

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-26

## 题目描述

输入一个浮点数 $n$，输出这个浮点数的绝对值。

## 输入格式

输入一个浮点数 $n$，其绝对值不超过 $10000$。

## 输出格式

输出 $n$ 的绝对值，保留到小数点后两位。

## 样例

**样例输入 #1**
```
-3.14```

**样例输出 #1**
```
3.14```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main(){
    double f;
    cin >> f;
    cout << fixed << setprecision(2) << abs(f); // 保留两位小数
}

```
