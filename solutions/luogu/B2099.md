# B2099 矩阵交换行

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-09

## 题目描述

给定一个 $5 \times 5$ 的矩阵(数学上，一个 $r \times c$ 的矩阵是一个由 $r$ 行 $c$ 列元素排列成的矩形阵列)，将第 $n$ 行和第 $m$ 行交换，输出交换后的结果。

## 输入格式

输入共 $6$ 行，前 $5$ 行为矩阵的每一行元素,元素与元素之间以一个空格分开。

第 $6$ 行包含两个整数 $m$、$n$，以一个空格分开（$1 \le m,n \le 5$）。

## 输出格式

输出交换之后的矩阵，矩阵的每一行元素占一行，元素之间以一个空格分开。

## 样例

**样例输入 #1**
```
1 2 2 1 2
5 6 7 8 3
9 3 0 5 3
7 2 1 4 6
3 0 8 2 4
1 5```

**样例输出 #1**
```
3 0 8 2 4
5 6 7 8 3
9 3 0 5 3
7 2 1 4 6
1 2 2 1 2```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 题目要求交换5x5矩阵的第m行和第n行，然后输出。
    // 1. 读入5x5矩阵到二维数组 g。
    // 2. 读入要交换的行号 m 和 n。
    // 3. 通过循环逐列交换第 m 行和第 n 行的元素。
    // 4. 按行输出交换后的矩阵，每行元素用空格隔开。

    int g[15][15];                 // 矩阵，行数5，多开10行和列确保安全
    // 读入5行，每行5列
    for (int i = 1; i <= 5; i++) {
        for (int j = 1; j <= 5; j++) {
            cin >> g[i][j];
        }
    }

    int m, n;                      // m, n: 要交换的两行（行号从1开始）
    cin >> m >> n;

    // 逐列交换第 m 行和第 n 行的元素
    for (int j = 1; j <= 5; j++) {
        int tmp = g[m][j];         // 临时变量保存
        g[m][j] = g[n][j];
        g[n][j] = tmp;
    }

    // 输出交换后的矩阵
    for (int i = 1; i <= 5; i++) {
        for (int j = 1; j <= 5; j++) {
            cout << g[i][j];
            if (j < 5) cout << ' '; // 每行元素间空格
        }
        cout << endl;
    }

    return 0;
}
```
