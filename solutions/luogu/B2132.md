# B2132 素数对

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-14

**算法标签**：`函数与递归`

## 题目描述

定义两个相差为 $2$ 的素数称为素数对，如 $5$ 和 $7,17$ 和 $19$ 等，要求找出所有两个数均不大于 $n$ 的素数对。

## 输入格式

一个正整数 $n$。$1 \le n \le 10000$。

## 输出格式

所有小于等于 $n$ 的素数对。每对素数对输出一行，中间用单个空格隔开。若没有找到任何素数对，输出 `empty`。

## 样例

**样例输入 #1**
```
10```

**样例输出 #1**
```
3 5
5 7```

**样例输入 #2**
```
100```

**样例输出 #2**
```
3 5
5 7
11 13
17 19
29 31
41 43
59 61
71 73```

**样例输入 #3**
```
3```

**样例输出 #3**
```
empty```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 函数：判断一个数是否为素数
bool isPrime(int x) {
    if (x < 2) return false;            // 小于2不是素数
    for (int i = 2; i * i <= x; i++) {  // 试除到sqrt(x)
        if (x % i == 0) return false;   // 有因数，不是素数
    }
    return true;                        // 无因数，是素数
}

int main() {
    // 思路：
    // 1. 读入 n。
    // 2. 遍历 i 从 2 到 n-2，检查 i 和 i+2 是否都是素数（调用 isPrime 函数）。
    // 3. 如果是，输出这一对，并标记找到了至少一对。
    // 4. 若遍历完没找到，输出 empty。
    int n;                              // n: 范围上限
    cin >> n;

    bool found = false;                 // found: 是否找到素数对
    for (int i = 2; i + 2 <= n; i++) {
        if (isPrime(i) && isPrime(i + 2)) {
            cout << i << " " << i + 2 << endl;
            found = true;
        }
    }

    if (!found) {                       // 没找到任何素数对
        cout << "empty" << endl;
    }

    return 0;
}
```
