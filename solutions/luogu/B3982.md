# B3982 [信息与未来 2024] 数据排序

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-04-21

**算法标签**：`模拟`、`费用流`、`CDQ分治`、`队列`

## 题目描述

在计算机世界中，“表格”是一种简单、基础而且十分通用的数据结构，在数据库、人工智能等领域中都有广泛的应用。表格由若干行、若干列的单元格组成：

| Name     | p1   | p2   | p3   | Score |
| :------- | :--- | ---- | ---- | ----- |
| ZhangSan | 40   | 30   | 28   | 98    |
| LiSi     | 40   | 28   | 30   | 98    |
| WangWu   | 40   | 25   | 20   | 85    |

CSV (Comma-Separated Values) 是一种常用的表格格式。Dr. X 需要你编程处理简化的 CSV 文
件，格式规定如下：

- CSV 文件包含 $n$ 行数据，其中第一行是标题行。
- CSV 文件每行一个字符串，对应了表格的一行。行中的单元格由**半角逗号**分隔。
- 每个单元格至少包含一个字符。单元格有两种类型：
  - **数值单元格**：由至少一个数字字符 $(0\sim 9)$ 组成。
  - **字符串单元格**：由数字字符 $(0\sim 9)$ 和大小写字母 $(\tt{a\sim z},\tt{A\sim Z})$ 组成,且至少包含一个字母。

- 标题行的所有单元格都是字符串单元格，且互不相同。标题行中包含了列的名称。

以下是一个 CSV 文件的示例：

```
Name,p1,p2,p3,Score
ZhangSan,40,30,28,98
LiSi,40,28,30,98
WangWu,40,25,20,85
```

你的任务是**根据指定的列为表格中的行排序**。例如根据 `Score- , Name+ , p3-` 排序意味着：

- 优先按 Score 列从大到小排序。Score 列都是数值单元格，因此按数值排序。

- 如果 Score 列相同，按 Name 列从小到大排序。Name 列都是字符串单元格，因此按照字典排序。

- 如果 Score 和 Name 列都相同，按 p3 列从大到小排序。p3 列都是数值单元格，因此按数
  值排序。

我们保证 CSV 文件每一行的单元格数量相同，且除标题行外，**每一列要么全是数值单元格，要么全是字符串单元格**。

## 输入格式

输入数据分为两部分。第一部分描述了 CSV 表格：
- 第一行一个整数 $n$，表示 CSV 文件的行数（**包含标题行**）。
- 接下来 $n$ 行,每行一个字符串，描述 CSV 表格中的行。

第二部分描述了排序要求:

- 第一行一个整数 $m$，表示排序依据列的数量。

- 接下来 $m$ 行，每行一个字符串，按顺序给出了排序依据的列名及排序方式（加号或减号）。加号代表升序排列、减号代表降序排列。

## 输出格式

输出 $n$ 行，为排序后的 CSV 表格（**包含标题行**）。对于所有排序依据列的值都相同的行，保持它们在输入文件中的相对顺序。

## 样例

**样例输入 #1**
```
4
Name,p1,p2,p3,Score
ZhangSan,40,30,28,98
LiSi,40,28,30,98
WangWu,40,25,20,85
3
Score-
Name+
p3-```

**样例输出 #1**
```
Name,p1,p2,p3,Score
LiSi,40,28,30,98
ZhangSan,40,30,28,98
WangWu,40,25,20,85```

## AC 代码

```cpp
#include <iostream>
#include <string>
#include <algorithm>
#include <cctype>
using namespace std;

int n, m;
string data[105][15];      // 存储整个表格，行号0~n-1，列号0~c-1
int colCnt;                // 列数
int colType[15];           // 列类型：0表示字符串，1表示数值
string colName[15];        // 列名（标题行的值）
int keyIdx[15];            // 排序关键字的列索引（按优先级顺序）
int keyDir[15];            // 排序方向：1表示升序(+)，-1表示降序(-)

// 判断一个字符串是否全为数字（数值单元格）
bool isNum(const string &s) {
    for (char ch : s) if (!isdigit(ch)) return false;
    return true;
}

// 比较两个数据行（行号r1和r2）
bool cmp(int r1, int r2) {
    for (int i = 0; i < m; i++) {
        int col = keyIdx[i];
        int dir = keyDir[i];
        if (colType[col] == 1) { // 数值列
            int v1 = stoi(data[r1][col]);
            int v2 = stoi(data[r2][col]);
            if (v1 != v2) {
                return dir == 1 ? v1 < v2 : v1 > v2;
            }
        } else { // 字符串列
            if (data[r1][col] != data[r2][col]) {
                return dir == 1 ? data[r1][col] < data[r2][col] : data[r1][col] > data[r2][col];
            }
        }
    }
    return false; // 完全相同，保持原顺序（稳定排序不需要额外处理）
}

int main() {
    // 读入表格
    cin >> n;
    cin.ignore();
    for (int i = 0; i < n; i++) {
        string line;
        getline(cin, line);
        int c = 0, pos = 0;
        while (true) {
            int nxt = line.find(',', pos);
            if (nxt == string::npos) {
                data[i][c++] = line.substr(pos);
                break;
            } else {
                data[i][c++] = line.substr(pos, nxt - pos);
                pos = nxt + 1;
            }
        }
        if (i == 0) colCnt = c;
    }

    // 解析列名和列类型
    for (int j = 0; j < colCnt; j++) {
        colName[j] = data[0][j];
        // 通过第一行数据判断该列是否为数值列
        colType[j] = isNum(data[1][j]) ? 1 : 0;
    }

    // 读入排序要求
    cin >> m;
    cin.ignore();
    for (int i = 0; i < m; i++) {
        string s;
        getline(cin, s);
        char dirChar = s.back(); // 最后一个字符是 '+' 或 '-'
        string name = s.substr(0, s.length() - 1); // 去掉符号即为列名
        // 找到对应的列索引
        for (int j = 0; j < colCnt; j++) {
            if (colName[j] == name) {
                keyIdx[i] = j;
                break;
            }
        }
        keyDir[i] = (dirChar == '+') ? 1 : -1;
    }

    // 准备排序索引（数据行号从1到n-1）
    int order[105];
    for (int i = 1; i < n; i++) order[i-1] = i;
    stable_sort(order, order + (n-1), cmp);

    // 输出标题行
    for (int j = 0; j < colCnt; j++) {
        if (j > 0) cout << ',';
        cout << data[0][j];
    }
    cout << endl;
    // 输出排序后的数据行
    for (int i = 0; i < n-1; i++) {
        int r = order[i];
        for (int j = 0; j < colCnt; j++) {
            if (j > 0) cout << ',';
            cout << data[r][j];
        }
        cout << endl;
    }

    return 0;
}
```
