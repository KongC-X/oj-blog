# B3887 [语言月赛 202311] 风球

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-30

**算法标签**：`2023`、`O2优化`、`分支结构`、`语言月赛`

## 题目背景

与中国大陆不同，当台风即将来袭时，香港天文台将会根据情况发布 $1,3,8,9,10$ 五个等级的热带气旋警告信号。数字越大，代表台风影响越严重。当发布 $8$ 号烈风信号时，香港就会停课停工。下图为香港天文台的 $10$ 号飓风信号：

## 题目描述

香港天文台选定了 $8$ 个气象站。在台风影响期间，香港天文台会根据这些气象站的风速观测数据决定发布哪一个等级的预警。

- 因为已经受到台风影响，因此必然会发布 $1$ 号戒备信号；
- 若有 $4$ 个气象站的持续风力达到或超过 $41$ 千米/小时，则发布 $3$ 号强风信号；
- 若有 $4$ 个气象站的持续风力达到或超过 $63$ 千米/小时，则发布 $8$ 号烈风信号；
- 若有 $1$ 个气象站的持续风力达到或超过 $118$ 千米/小时，则发布 $10$ 号飓风信号；
- 多个条件同时满足，则发布其中最高等级的信号。

现在给定这些气象站的风力数据，请计算出香港天文台应当发布什么警告信号。

## 输入格式

输入共一行，用空格隔开的 $8$ 个正整数，表示这 $8$ 个气象站的风速观测数据。

## 输出格式

输出一行一个正整数，表示应当发布哪一个等级的警告信号。

## 样例

**样例输入 #1**
```
126 75 94 57 53 81 50 48```

**样例输出 #1**
```
10```

**样例输入 #2**
```
76 40 49 36 26 42 27 26```

**样例输出 #2**
```
1```

**样例输入 #3**
```
99 83 96 54 63 59 45 55```

**样例输出 #3**
```
8```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】模拟判断
     * 【核心思路】
     * 1. 读入 8 个气象站的风速数据。
     * 2. 从最高等级到最低等级依次判断：
     *    - 先检查是否有风速 >= 118 的站，有则输出 10。
     *    - 再检查风速 >= 63 的站数是否 >= 4，是则输出 8。
     *    - 再检查风速 >= 41 的站数是否 >= 4，是则输出 3。
     *    - 若都不满足，输出 1（必定发布 1 号）。
     * 3. 注意必须从高到低判断，因为高等级条件满足时直接输出。
     *
     * 【时间复杂度】O(8)
     */

    int a[8];          // a[0]~a[7]: 8 个气象站的风速数据
    for (int i = 0; i < 8; i++) {
        cin >> a[i];
    }

    // 统计各风速阈值达标的气象站数量
    int c1 = 0;        // c1: 风速 >= 118 的站数
    int c2 = 0;        // c2: 风速 >= 63 的站数
    int c3 = 0;        // c3: 风速 >= 41 的站数

    for (int i = 0; i < 8; i++) {
        if (a[i] >= 118) c1++;
        if (a[i] >= 63)  c2++;
        if (a[i] >= 41)  c3++;
    }

    // 从高到低判断
    if (c1 >= 1) {
        cout << 10 << endl;   // 有 1 个站达到 118，发布 10 号
    } else if (c2 >= 4) {
        cout << 8 << endl;    // 有 4 个站达到 63，发布 8 号
    } else if (c3 >= 4) {
        cout << 3 << endl;    // 有 4 个站达到 41，发布 3 号
    } else {
        cout << 1 << endl;    // 都不满足，发布 1 号
    }

    return 0;
}
```
