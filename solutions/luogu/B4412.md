# B4412 [GESP202509 二级] 菱形

> **洛谷** | 普及- | C++14 | 提交时间: 2025-10-10

**算法标签**：`匈牙利算法`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1190>

## 题目描述

小 A 想绘制一个菱形。具体来说，需要绘制的菱形是一个 $n$ 行 $n$ 列的字符画，$n$ 是一个大于 $1$ 的奇数。菱形的四个顶点依次位于第 $1$ 行、第 $1$ 列、第 $n$ 行、第 $n$ 列的正中间，使用 `#` 绘制。相邻顶点之间也用 `#` 连接。其余位置都是 `.`。

例如，一个 $5$ 行 $5$ 列的菱形字符画是这样的：

```
..#..
.#.#.
#...#
.#.#.
..#..
```

给定 $n$，请你帮小 A 绘制对应的菱形。

## 输入格式

一行，一个正整数 $n$。

## 输出格式

输出共 $n$ 行，表示对应的菱形。

## 样例

**样例输入 #1**
```
3```

**样例输出 #1**
```
.#.
#.#
.#.```

**样例输入 #2**
```
9```

**样例输出 #2**
```
....#....
...#.#...
..#...#..
.#.....#.
#.......#
.#.....#.
..#...#..
...#.#...
....#....```

## AC 代码

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int n;
    cin >> n;
    int mid = n / 2;
    
    for (int i = 0; i < n; i++) {
        for (int j = 0; j < n; j++) {
            if (abs(i - mid) + abs(j - mid) == mid) {
                cout << "#";
            } else {
                cout << ".";
            }
        }
        cout << endl;
    }
    
    return 0;
}
```
