# P15800 [GESP202603 六级] 选数

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-06-16

**算法标签**：`动态规划`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1210>

## 题目描述

给定两个包含 $n$ 个整数的数组 $a=[a_1,\dots,a_n]$ 与 $b=[b_1,\dots,b_n]$。你需要指定若干下标 $p_1\lt \cdots\lt p_k$（$1\leq k\leq n$）使得以下条件成立：

- $1\leq p_i\leq n$（$1\leq i\leq k$）；
- $p_{i+1}\geq p_i+b_{p_i}$（$1\leq i< k$）。

你需要在满足以上条件的前提下最大化 $\sum_{i=1}^k a_{p_i}$，也即最大化数组 $a$ 对应下标的整数之和。

## 输入格式

第一行，一个正整数 $n$，表示数组长度。

第二行，$n$ 个正整数 $a_1,a_2,\dots,a_n$，表示数组 $a$。

第三行，$n$ 个正整数 $b_1,b_2,\dots,b_n$，表示数组 $b$。

## 输出格式

一行，一个整数，表示在满足下标条件的前提下，数组 $a$ 对应下标的整数之和的最大值。

## 样例

**样例输入 #1**
```
4
1 2 3 4
3 3 1 1```

**样例输出 #1**
```
7```

**样例输入 #2**
```
6
1 1 4 5 1 4
1 2 3 2 1 0```

**样例输出 #2**
```
11```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 有 n 个数的数组 a 和 b，从下标为 1 到 n 的数中选数，当选了下标为 i 的数时，可以加上 a i的价值，
// 但只能在下标 ≥i+b i的数中选下一个数，也可以不再选择其他数。求最大价值。

const int MAXN = 100005;
int n;
long long a[MAXN], b[MAXN];         // a: 价值, b: 跳跃距离限制
long long dp[MAXN];                 // dp[i]: 从 i 开始选取（包含 i）的最大总和
long long suf[MAXN];                // suf[i]: max{ dp[j] } (j >= i)

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    // ---------- 思路 ----------
    // 倒序 DP + 后缀最大值优化。
    // 定义 dp[i] 表示从 i 开始选（必须选 i）的最大总和。
    // 转移：选 i 后，下一次选的下标 j 必须满足 j >= max(i+1, i+b[i])，
    //       因为既要严格递增（j > i），又要满足题目条件（j >= i+b[i]）。
    // 设 nxt = max(i+1, i+b[i])，则：
    //   dp[i] = a[i] + (nxt <= n ? suf[nxt] : 0)
    // 其中 suf[nxt] 表示从 nxt 开始可选的最大 dp 值。
    // 计算完后更新 suf[i] = max(suf[i+1], dp[i])。
    // 答案 = max(dp[1..n])。
    // 时间复杂度 O(n)，空间 O(n)。

    cin >> n;
    for (int i = 1; i <= n; i++) cin >> a[i];
    for (int i = 1; i <= n; i++) cin >> b[i];

    suf[n + 1] = 0;
    long long ans = 0;

    for (int i = n; i >= 1; i--) {
        int nxt = i + b[i];               // 根据条件 p_{i+1} >= i + b[i]
        if (nxt < i + 1) nxt = i + 1;     // 结合严格递增，至少是 i+1
        if (nxt > n) {
            dp[i] = a[i];                 // 后面不能再选
        } else {
            dp[i] = a[i] + suf[nxt];      // 加上后面能选的最大和
        }
        suf[i] = max(suf[i + 1], dp[i]);  // 更新后缀最大值
        if (dp[i] > ans) ans = dp[i];
    }

    cout << ans << '\n';
    return 0;
}
```
