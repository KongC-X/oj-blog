# B4529 [信息与未来 2026] 幸运数字

> **洛谷** | 普及- | C++14 | 提交时间: 2026-05-26

**算法标签**：`CDQ分治`、`排序算法`

## 题目描述

如果一个正整数的十进制表示中，每种数字都恰好出现了偶数次，Dr. X 就认为它是幸运数字。例如：

- $11$ 是幸运数字，数字 $1$ 出现了 $2$ 次 (偶数次)。
- $131131$ 是幸运数字，数字 $1$ 出现了 $4$ 次，数字 $3$ 出现了 $2$ 次，都是偶数次。
- $23333$ 不是幸运数字，因为数字 $2$ 出现了 $1$ 次 (奇数次)。
- $123$ 不是幸运数字，因为数字 $1$、$2$、$3$ 各出现了 $1$ 次 (奇数次)。

给定两个正整数 $a$ 和 $b$，请你计算 $a, a+1, a+2, \ldots, b$ 中幸运数字的数量。

## 输入格式

输入两个空格分隔的正整数 $a$ 和 $b$。

## 输出格式

输出一个整数，表示 $a, a+1, a+2, \ldots, b$ 中幸运数字的数量。

## 样例

**样例输入 #1**
```
1 100```

**样例输出 #1**
```
9```

**样例输入 #2**
```
1 10000```

**样例输出 #2**
```
261```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int a, b;                    // 区间 [a, b]
    cin >> a >> b;

    int ans = 0;                 // 幸运数字个数

    // 思路：
    // 数据范围最大 1e6，可以直接遍历 [a,b] 逐个判断。
    // 对于每个数，统计其十进制每位数字的出现次数（0~9）。
    // 若所有出现过的数字次数都是偶数，则是幸运数字。

    for (int i = a; i <= b; i++) {
        int cnt[10] = {0};       // cnt[d] 表示数字 d 出现的次数，初始全 0
        int x = i;               // 临时变量，用于取各位
        while (x > 0) {
            int d = x % 10;      // 当前最低位数字
            cnt[d]++;
            x /= 10;
        }
        // 检查是否所有出现过的数字次数都是偶数
        bool ok = true;
        for (int d = 0; d <= 9; d++) {
            if (cnt[d] % 2 != 0) {  // 出现了奇数次
                ok = false;
                break;
            }
        }
        if (ok) ans++;
    }

    cout << ans << '\n';
    return 0;
}
```
