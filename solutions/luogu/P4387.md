# P4387 【深基15.习9】验证栈序列

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-05-15

**算法标签**：`模拟`

## 题目描述

给出两个序列 pushed 和 poped 两个序列，其取值从 $1$ 到 $n(n \le 100000)$。已知入栈序列是 pushed，如果出栈序列有可能是 poped，则输出 `Yes`，否则输出 `No`。请注意，给定的序列一定是一个**排列**（即没有重复数字）。

为了防止骗分，每个测试点有多组数据，不超过 $5$ 组。

## 输入格式

第一行一个整数 $q$，询问次数。

接下来 $q$ 个询问，对于每个询问：

第一行一个整数 $n$ 表示序列长度；

第二行 $n$ 个整数表示入栈序列；

第三行 $n$ 个整数表示出栈序列；

## 输出格式

对于每个询问输出答案。

## 样例

**样例输入 #1**
```
2
5
1 2 3 4 5
5 4 3 2 1
4
1 2 3 4
2 4 1 3```

**样例输出 #1**
```
Yes
No```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
【题目思路与解题过程】
题意：已知入栈序列 pushed 和出栈序列 poped（都是 1~n 的排列），
      判断 poped 是否是 pushed 的一个合法出栈序列。

解题思路：模拟法
1. 用一个栈 stk 来模拟整个入栈出栈过程。
2. 遍历入栈序列，将每个元素压入栈中。
3. 每次压栈后，检查栈顶元素是否等于当前应该出栈的元素（poped[p]）：
   - 如果相等，说明这个元素可以立即出栈，将其弹出，并将出栈指针 p 后移；
   - 重复这个判断，直到栈空或栈顶不等于 poped[p]。
4. 入栈序列全部处理完后，如果栈为空，说明所有元素都成功按 poped 的顺序出栈，
   则输出 Yes；否则输出 No。

时间复杂度 O(n)，每组数据每个元素最多入栈一次、出栈一次。
*/

const int MAXN = 100005;  // 最大序列长度

int a[MAXN];              // a: 入栈序列 pushed
int b[MAXN];              // b: 出栈序列 poped

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int q;                 // q: 询问组数
    cin >> q;
    
    while (q--) {
        int n;             // n: 序列长度
        cin >> n;
        
        for (int i = 0; i < n; ++i) cin >> a[i];  // 读入入栈序列
        for (int i = 0; i < n; ++i) cin >> b[i];  // 读入出栈序列
        
        stack<int> stk;    // stk: 模拟栈
        int p = 0;         // p: 当前出栈序列的指针，指向下一个期望出栈的元素
        
        for (int i = 0; i < n; ++i) {
            stk.push(a[i]);              // 模拟入栈
            // 只要栈顶等于当前要出栈的元素，就连续出栈
            while (!stk.empty() && stk.top() == b[p]) {
                stk.pop();
                ++p;                     // 指针后移
            }
        }
        
        // 若栈为空，说明全部匹配成功
        if (stk.empty()) {
            cout << "Yes\n";
        } else {
            cout << "No\n";
        }
    }
    
    return 0;
}
```
