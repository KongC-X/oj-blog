# B2145 digit 函数

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-15

**算法标签**：`函数与递归`

## 题目描述

在程序中定义一函数 $digit(n,k)$，它能分离出整数 $n$ 从右边数第 $k$ 个数字。

## 输入格式

正整数 $n$ 和 $k$。

## 样例

**样例输入 #1**
```
31859 3```

**样例输出 #1**
```
8```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 递归函数：返回整数 n 从右边数第 k 个数字
int digit(int n, int k) {
    if (k == 1) return n % 10;          // 递归边界：第1个就是最右边的个位
    return digit(n / 10, k - 1);        // 去掉最右边一位，找第 k-1 个
}

int main() {
    int n, k;                           // n: 正整数，k: 第几个数字（从右数）
    cin >> n >> k;
    cout << digit(n, k) << endl;
    return 0;
}
```
