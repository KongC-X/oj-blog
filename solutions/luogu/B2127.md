# B2127 求正整数 2 和 n 之间的完全数

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-13

**算法标签**：`函数与递归`

## 题目描述

求正整数 $2$ 和 $n$ 之间的完全数（一行一个数）。

完全数：对于一个自然数，所有比它小的所有因数之和，等于它本身，它就是个完全数。如 $6=1+2+3$。

## 输入格式

输入 $n(n \le 10000)$。

## 输出格式

一行一个数，按由小到大的顺序。

## 样例

**样例输入 #1**
```
10
```

**样例输出 #1**
```
6
```

**样例输入 #2**
```
100
```

**样例输出 #2**
```
6
28
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 判断 x 是否为完全数（真因数之和等于自身）
bool isPerfect(int x) {
    int sum = 0;                  // sum: 真因数的和
    for (int i = 1; i < x; i++) { // 枚举所有比 x 小的数
        if (x % i == 0) {         // i 是 x 的因数
            sum += i;
        }
    }
    return sum == x;              // 相等则是完全数
}

int main() {
    int n;                        // n: 范围上限
    cin >> n;

    // 遍历 2 到 n，输出所有完全数
    for (int i = 2; i <= n; i++) {
        if (isPerfect(i)) {
            cout << i << endl;
        }
    }

    return 0;
}
```
