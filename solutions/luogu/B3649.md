# B3649 [语言月赛202208] 大小比较

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-20

**算法标签**：`2022`、`分支结构`、`语言月赛`

## 题目描述

给出整数 $a,b$，若 $a \le b$，输出 `YE5`，否则输出 `N0`（第二个字符为阿拉伯数字）。

## 输入格式

输入一行两个整数 $a,b$。

## 输出格式

输出一行，为你的答案。

## 样例

**样例输入 #1**
```
3 5```

**样例输出 #1**
```
YE5```

**样例输入 #2**
```
5 3```

**样例输出 #2**
```
N0```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    if (a <= b) cout << "YE5" << endl;
    else cout << "N0" << endl;
    return 0;
}
```
