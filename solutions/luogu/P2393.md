# P2393 yyy loves Maths II

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-13

## 题目背景

上次蒟蒻 redbag 可把 yyy 气坏了，yyy 说他只是小学生，蒟蒻 redbag 这次不坑他了。

## 题目描述

redbag 给了 yyy 很多个数，要 yyy 计算这些数的和。

必须要快，redbag 只给了 yyy $1$ 秒的时间！！！

## 输出格式

一行，一个实数（四舍五入精确到 $5$ 位小数），表示这些数的和。

## 样例

**样例输入 #1**
```
1
```

**样例输出 #1**
```
1.00000
```

## AC 代码

```cpp
#include <iomanip>   // cout 保留小数需使用此库
#include <iostream>
using namespace std;

int main() {
    /*
     * 题目：P2393 yyy loves Maths II
     * 题意：输入很多个数（≤5e4个），每个数≤2.33e8，小数点后最多6位，
     *       求总和，四舍五入精确到5位小数。
     *
     * 核心思路：
     * 1. 为了避免浮点数累加误差，先将每个数乘以 1e6（因为最多 6 位小数），
     *    得到整数后累加。
     * 2. 使用 long double 存储累加结果，确保乘法结果不溢出且足够精确。
     * 3. 最后将累加结果除以 1e6，用 cout 输出保留 5 位小数。
     *
     * 时间复杂度：O(输入个数)
     */
    long double ans = 0;   // 以 1e-6 为单位的累加和（用 long double）
    long double tmp;
    while (cin >> tmp) {   // 读到文件结束为止
        ans += tmp * 1000000;
    }
    cout << fixed << setprecision(5) << ans / 1000000 << endl;
    return 0;
}
```
