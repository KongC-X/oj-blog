# P10262 [GESP样题 六级] 亲朋数

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-06-02

**算法标签**：`动态规划`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1106>

## 题目描述

给定一串长度为 $L$、由数字 $0\sim 9$ 组成的数字串 $S$。容易知道，它的连续子串共有 $\frac{L(L + 1)}2$ 个。如果某个子串对应的数（允许有前导零）是 $p$ 的倍数，则称该子串为数字串 $S$ 对于 $p$ 的亲朋数。

例如，数字串 $S$ 为“ $12342$ ”、$p$ 为 $2$，则在 $15$ 个连续子串中，亲朋数有“ $12$ ”、“ $1234$ ”、“ $12342$ ”、“ $2$ ”、“ $234$ ”、“ $2342$ ”、“ $34$ ”、“ $342$ ”、“ $4$ ”、“ $42$ ”、“ $2$ ”共 $11$ 个。注意其中“ $2$ ”出现了 $2$ 次，但由于其在 $S$ 中的位置不同，记为不同的亲朋数。

现在，告诉你数字串 $S$ 和正整数 $p$ ，你能计算出有多少个亲朋数吗？

## 输入格式

输入的第一行，包含一个正整数 $p$。约定 $2 \leq p \leq 128$。  
输入的第二行，包含一个长为 $L$ 的数字串 $S$。约定 $1 \leq L \leq 10^6$。

## 输出格式

输出一行一个整数表示答案。

## 样例

**样例输入 #1**
```
2
102```

**样例输出 #1**
```
5
```

**样例输入 #2**
```
2
12342```

**样例输出 #2**
```
11```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 解题思路：
// 从左到右扫描数字串，维护一个计数数组 dp[j]，
// 表示"以当前位置为结尾的所有子串中，数值模 p = j 的个数"。    
// 扫描到新数字 d 时：
//   1. 所有以 i-1 结尾的子串，扩展一位得到以 i 结尾的子串
//      新余数 = (旧余数 * 10 + d) % p，对应计数累加到临时数组
//   2. 当前数字 d 自己也是一个长度为 1 的子串
//   3. 累加 dp[0] 到答案（这些就是以 i 结尾且是 p 的倍数的子串）

// 举个例子，S = "123", p = 2：
// 处理 '1'：以位置0结尾的子串有 "1"
//         余数分布：1%2=1 → dp[1]=1

// 处理 '2'：以位置1结尾的子串有 "12", "2"
//         "1" 扩展为 "12"：旧余数1 → (1×10+2)%2 = 0
//         "2" 新增：2%2=0
//         所以 dp[0]=2

// 处理 '3'：以位置2结尾的子串有 "123", "23", "3"
//         "12" 扩展为 "123"：0 → (0×10+3)%2 = 1
//         "2" 扩展为 "23"：0 → (0×10+3)%2 = 1
//         "3" 新增：3%2=1
//         所以 dp[1]=3
// 答案 ans = dp[0] 的总和 = 2（"12", "2"）

// 为什么对？因为每个子串有唯一的右端点，枚举右端点就不会漏。
// 为什么快？p 最大才 128，数组大小固定，每次 O(p) 转移即可。
//
// 时间复杂度：O(L * p)，其中 L ≤ 10^6，p ≤ 128
// 空间复杂度：O(p)

int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int p;       // 模数，2 ≤ p ≤ 128
    string s;    // 数字串 S，长度 1 ≤ L ≤ 1e6
    cin >> p >> s;

    // dp[j]：以当前处理位置为右端点的子串中，数值 mod p = j 的子串个数
    long long dp[130] = {0};
    long long ans = 0; // 总答案，最多约 5×10^11，用 long long

    // 逐位扫描数字串
    for (int i = 0; i < s.size(); i++) {
        int d = s[i] - '0';            // 当前位的数字

        long long ndp[130] = {0};       // 更新后的 dp，先全部清 0
        for (int j = 0; j < p; j++) {
            // 所有以"前一位"为右端点的子串，后面拼上 d，余数跟着变化
            int t = (j * 10 + d) % p;  // 新余数
            ndp[t] += dp[j];
        }
        ndp[d % p]++;                   // d 自己单独构成一个长度为 1 的子串

        // 把 ndp 复制回 dp，准备处理下一位
        for (int j = 0; j < p; j++) {
            dp[j] = ndp[j];
        }

        ans += dp[0];                   // dp[0] 就是当前位为右端点的亲朋数个数
    }

    cout << ans << endl;
    return 0;
}

```
