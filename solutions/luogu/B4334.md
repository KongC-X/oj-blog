# B4334 [中山市赛 2023] 未命名

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-19

**算法标签**：`模拟`、`2023`、`科创活动`、`小学活动`

## 题目描述

这是一个独一无二的世界，所以有 $N$ 张写有互不相同的自然数的卡片，第 $i$ 张卡片写着 $A_i$，现在你得到了一个未命名的空白卡片，想在上面写上一个自然数 $x$ 满足以下条件：

1. $x$ 不等于任意一张卡片上的数字。 
2. $x$ 可以表示为两张互不相同卡片的数字之和。 

现在，你想知道有哪些自然数 $x$ 可以写在空白卡片上。

## 输入格式

第一行一个正整数 $N$，表示已写有自然数的卡片数量。 

第二行有 $N$ 个用空格隔开的互不相同的自然数，表示卡片上的自然数。

## 输出格式

第一行一个正整数 $M$，表示可以写在空白卡片上的数字的个数。 

第二行有 $M$ 个用空格隔开的自然数，表示可以写在空白卡片上的数字，需要从小到大输出。

## 样例

**样例输入 #1**
```
4
4 9 3 5 ```

**样例输出 #1**
```
5
7 8 12 13 14 ```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题意：给定 N 个互不相同的自然数，求所有不在卡片中且可表示为两数之和的数。
     * 思路：枚举所有 i<j，计算和 s，若 s 未出现在卡片中，则加入 ans。
     *       最后排序去重输出。
     */
    int n;          // n: 卡片数量
    cin >> n;

    int a[2005];    // 存储卡片数字
    bool vis[200005] = {false}; // 标记哪些数字在卡片中

    for (int i = 0; i < n; i++) {
        cin >> a[i];
        vis[a[i]] = true;
    }

    int ans[4000005]; // 最多有 n*(n-1)/2 个和，约 2e6，开大点
    int p = 0;        // 当前答案个数

    for (int i = 0; i < n; i++) {
        for (int j = i + 1; j < n; j++) {
            int s = a[i] + a[j];
            if (!vis[s]) ans[p++] = s;
        }
    }

    sort(ans, ans + p);
    // 使用 unique 去重
    int q = unique(ans, ans + p) - ans;

    cout << q << endl;
    for (int i = 0; i < q; i++) {
        cout << ans[i] << ' ';
    }
}
```
