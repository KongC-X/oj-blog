# P1928 外星密码

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-02-12

**算法标签**：`模拟`、`贪心`、`最小环`、`栈`

## 题目描述

有了防护伞，并不能完全避免 2012 的灾难。地球防卫小队决定去求助外星种族的帮助。经过很长时间的努力，小队终于收到了外星生命的回信。但是外星人发过来的却是一串密码。只有解开密码，才能知道外星人给的准确回复。解开密码的第一道工序就是解压缩密码，外星人对于连续的若干个相同的子串 $\texttt{X}$ 会压缩为 $\texttt{[DX]}$ 的形式（$D$ 是一个整数且 $1\leq D\leq99$），比如说字符串 $\texttt{CBCBCBCB}$ 就压缩为 $\texttt{[4CB]}$ 或者$\texttt{[2[2CB]]}$，类似于后面这种压缩之后再压缩的称为二重压缩。如果是 $\texttt{[2[2[2CB]]]}$ 则是三重的。现在我们给你外星人发送的密码，请你对其进行解压缩。

## 输入格式

输入一行，一个字符串，表示外星人发送的密码。

## 输出格式

输出一行，一个字符串，表示解压缩后的结果。

## 样例

**样例输入 #1**
```
AC[3FUN]```

**样例输出 #1**
```
ACFUNFUNFUN```

## AC 代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

/**
 * 递归解压函数
 * @return 解压后的字符串
 * 
 * 核心思路：
 * 1. 每次调用处理一个"[]"包裹的压缩块，或者处理普通字符
 * 2. 遇到'['就读取数字，然后递归处理内部的压缩块
 * 3. 遇到']'就结束当前层的处理，返回结果
 * 4. 利用cin的顺序读取特性，天然处理了嵌套结构
 */
string f() {
    string s1 = "", s2;  // s1: 当前层的结果，s2: 递归返回的子串
    char ch;
    
    // 不断读取字符，直到遇到换行符（输入结束）或']'（当前层结束）
    while (cin >> ch) {
        // 输入结束（样例是单行输入，实际测试可能是文件输入）
        if (ch == '\n') break;
        
        if (ch == '[') {
            // 遇到'['：开始一个压缩块
            int t;
            scanf("%d", &t);        // 读取重复次数
            s2 = f();              // 递归解压内部的字符串
            while (t--) s1 += s2;  // 重复t次并拼接到结果
        }
        else if (ch == ']') {
            // 遇到']'：当前压缩块结束，返回结果给上一层
            return s1;
        }
        else {
            // 普通字符：直接拼接到结果
            s1 += ch;
        }
    }
    
    return s1;  // 整个字符串处理完毕
}

int main() {
    cout << f();
    return 0;
}
```
