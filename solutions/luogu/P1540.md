# P1540 [NOIP 2010 提高组] 机器翻译

> **洛谷** | 普及- | C++14 | 提交时间: 2026-05-15

**算法标签**：`模拟`、`记忆化搜索`、`构造`

## 题目背景

NOIP2010 提高组 T1

## 题目描述

小晨的电脑上安装了一个机器翻译软件，他经常用这个软件来翻译英语文章。

这个翻译软件的原理很简单，它只是从头到尾，依次将每个英文单词用对应的中文含义来替换。对于每个英文单词，软件会先在内存中查找这个单词的中文含义，如果内存中有，软件就会用它进行翻译；如果内存中没有，软件就会在外存中的词典内查找，查出单词的中文含义然后翻译，并将这个单词和译义放入内存，以备后续的查找和翻译。

假设内存中有 $M$ 个单元，每单元能存放一个单词和译义。每当软件将一个新单词存入内存前，如果当前内存中已存入的单词数不超过 $M-1$，软件会将新单词存入一个未使用的内存单元；若内存中已存入 $M$ 个单词，软件会清空最早进入内存的那个单词，腾出单元来，存放新单词。

假设一篇英语文章的长度为 $N$ 个单词。给定这篇待译文章，翻译软件需要去外存查找多少次词典？假设在翻译开始前，内存中没有任何单词。

## 输入格式

共 $2$ 行。每行中两个数之间用一个空格隔开。

第一行为两个正整数 $M,N$，代表内存容量和文章的长度。

第二行为 $N$ 个非负整数，按照文章的顺序，每个数（大小不超过 $1000$）代表一个英文单词。文章中两个单词是同一个单词，当且仅当它们对应的非负整数相同。

## 输出格式

一个整数，为软件需要查词典的次数。

## 样例

**样例输入 #1**
```
3 7
1 2 1 5 4 4 1
```

**样例输出 #1**
```
5
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
【题目思路与解题过程】
题意：有一个容量为 M 的内存，能存放最近使用过的单词。
      当要翻译一个单词时，先在内存中查找：
      - 如果存在（命中），直接翻译，不需要查词典；
      - 如果不存在（缺失），需要查词典，并将该单词加入内存。
      内存满时，淘汰最早进入内存的单词（即先进先出）。
      要求统计整个翻译过程中查词典的总次数。

解题思路：
1. 使用队列 q 按顺序存储当前内存中的单词，队首是最早进入的。
2. 用一个布尔数组 in[1005] 标记某个单词是否在内存中。
3. 遍历每个单词 x：
   - 如果 in[x] == true，命中，什么也不做。
   - 如果 in[x] == false，缺失，查词典次数 cnt++。
       然后判断内存是否已满：
       if (q.size() == M)：
           弹出队首 out，并设置 in[out] = false。
       将新单词 x 入队，并设置 in[x] = true。
4. 最后输出 cnt。
*/

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int m, n;                // m: 内存容量, n: 文章长度
    cin >> m >> n;
    
    queue<int> q;            // q: 记录内存中单词的进入顺序
    bool in[1005] = {false}; // in[x]: 单词 x 当前是否在内存中 (单词值≤1000)
    int cnt = 0;             // cnt: 查词典的次数
    
    for (int i = 0; i < n; ++i) {
        int x;               // x: 当前文章中的单词
        cin >> x;
        
        if (!in[x]) {        // 内存中没有，需要查词典
            ++cnt;           // 查词典次数 +1
            
            if (q.size() == m) {          // 内存已满，需要淘汰最早进入的单词
                int out = q.front();       // 队首即最早进入的单词
                q.pop();
                in[out] = false;           // 标记该单词已离开内存
            }
            
            q.push(x);        // 新单词加入队列
            in[x] = true;     // 标记已在内存中
        }
        // else 命中，无需操作
    }
    
    cout << cnt << '\n';
    
    return 0;
}
```
