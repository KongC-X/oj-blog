# B2096 直方图

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-08

## 题目描述

给定一个非负整数数组，统计里面每一个数的出现次数。我们只统计到数组里最大的数。

假设 $F_{\max}$（$F_{\max} \le 10^5$）是数组里最大的数，那么我们只统计 $\{0,1,2, \ldots ,F_{\max} \}$ 里每个数出现的次数。

## 输入格式

第一行，一个整数 $n$ 表示数组的大小（$1 \le n \le 10^5$）。

紧接着一行是数组的 $n$ 个元素。

## 输出格式

按顺序输出每个数的出现次数，一行一个数。如果没有出现过，则输出 $0$。

对于例子中的数组，最大的数是 $3$，因此我们只统计 $\{0,1,2,3\}$ 的出现频数。

## 样例

**样例输入 #1**
```
5
1 1 2 3 1```

**样例输出 #1**
```
0
3
1 
1```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 1. 读入 n 和数组元素，同时找出数组的最大值 mx。
    // 2. 创建一个大小为 mx+1 的计数数组 cnt，初始化为 0。
    // 3. 遍历数组，对每个元素进行计数。
    // 4. 从 0 到 mx，依次输出 cnt[i]（每个数占一行）。
    // 时间复杂度 O(n + mx)，空间 O(mx)，满足题目数据范围。

    int n;                          // n: 数组大小
    cin >> n;

    int a[100010];                  // 存储数组元素，最多 1e5
    int mx = -1;                    // mx: 数组中的最大值，初始为 -1
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        if (a[i] > mx) mx = a[i];   // 更新最大值
    }

    int cnt[100010] = {0};          // 计数数组，大小至少为 mx+1，这里多开 10 个
    for (int i = 0; i < n; i++) {
        cnt[a[i]]++;                // 统计每个数出现的次数
    }

    // 输出从 0 到 mx 每个数的出现次数
    for (int i = 0; i <= mx; i++) {
        cout << cnt[i] << endl;
    }

    return 0;
}
```
