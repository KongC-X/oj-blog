# P1048 [NOIP 2005 普及组] 采药

> **洛谷** | 普及- | C++14 | 提交时间: 2026-06-02

**算法标签**：`动态规划`、`双指针`、`字符串模拟`、`最近公共祖先`

## 题目描述

辰辰是个天资聪颖的孩子，他的梦想是成为世界上最伟大的医师。为此，他想拜附近最有威望的医师为师。医师为了判断他的资质，给他出了一个难题。医师把他带到一个到处都是草药的山洞里对他说：“孩子，这个山洞里有一些不同的草药，采每一株都需要一些时间，每一株也有它自身的价值。我会给你一段时间，在这段时间里，你可以采到一些草药。如果你是一个聪明的孩子，你应该可以让采到的草药的总价值最大。”

如果你是辰辰，你能完成这个任务吗？

## 输入格式

第一行有 $2$ 个整数 $T$（$1 \le T \le 1000$）和 $M$（$1 \le  M \le 100$），用一个空格隔开，$T$ 代表总共能够用来采药的时间，$M$ 代表山洞里的草药的数目。

接下来的 $M$ 行每行包括两个在 $1$ 到 $100$ 之间（包括 $1$ 和 $100$）的整数，分别表示采摘某株草药的时间和这株草药的价值。

## 输出格式

输出在规定的时间内可以采到的草药的最大总价值。

## 样例

**样例输入 #1**
```
70 3
71 100
69 1
1 2
```

**样例输出 #1**
```
3```

## AC 代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

/*
dp[i][j]：代表有i个物品，背包容量为j时，能够存储的最大价值
对于第i个物品：
情况一：背包容量j<物品重量w[j]，放不下，能够存放的价值dp[i-1][j]
情况二：背包容量j>=物品重量w[j]，放得下
能够得到的最大价值 = max(dp[i-1][j],v[i]+dp[i-1][j-w[i]])
*/ 
int dp[110][20010];
int n,w[110],v[110],maxw,i,j;

int main(){
	cin>>maxw>>n;
	//读入每个物品的重量和价值
	for(i = 1;i <= n;i++){
		cin>>w[i]>>v[i];
	} 
	// 递推求dp数组
	for(i = 1;i <= n;i++){
		//循环背包容量从1~maxw
		for(j = 1;j <= maxw;j++){
			//如果放不下:背包容量<物品重量 
			if(j < w[i]){
				dp[i][j] = dp[i-1][j]; 
			}else{
				//放得下，就看放进来价值高，还是不放价值高
				dp[i][j] = max(dp[i-1][j],v[i]+dp[i-1][j-w[i]]);
			} 
		} 
	} 	
	//输出n个物品，背包容量为maxw的情况下最大价值 
	cout<<dp[n][maxw];
}
```
