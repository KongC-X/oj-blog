# P11247 [GESP202409 六级] 算法学习

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-06-17

**算法标签**：`递归`、`二分`、`费用流`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1162>

## 题目描述

小杨计划学习 $m$ 种算法，为此他找了 $n$ 道题目来帮助自己学习，每道题目最多学习一次。

小杨对于 $m$ 种算法的初始掌握程度均为 $0$。第 $i$ 道题目有对应的知识点 $a_i$，即学习第 $i$ 道题目可以令小杨对第 $a_i$ 种算法的掌握程度提高 $b_i$。小杨的学习目标是对于 $m$ 种算法的掌握程度均至少为 $k$。

小杨认为连续学习两道相同知识点的题目是不好的，小杨想请你编写程序帮他计算出他最少需要学习多少道题目才能使得他在完成学习目标的同时避免连续学习两道相同知识点的题目。

## 输入格式

第一行三个正整数 $m, n, k$，代表算法种类数，题目数和目标掌握程度。  
第二行 $n$ 个正整数 $a_1, a_2, ..., a_n$，代表每道题目的知识点。  
第三行 $n$ 个正整数 $b_1, b_2, ..., b_n$，代表每道题目提升的掌握程度。

## 输出格式

输出一个整数，代表小杨最少需要学习题目的数量，如果不存在满足条件的方案，输出 -1。

## 样例

**样例输入 #1**
```
3 5 10
1 1 2 3 3
9 1 10 10 1```

**样例输出 #1**
```
4```

**样例输入 #2**
```
2 4 10
1 1 1 2
1 2 7 10```

**样例输出 #2**
```
-1```

## AC 代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

const int MAXN = 100010;

/*
 * 解题思路：
 * 问题可以转化为：从 n 道题目中选出最少的题目，使得：
 *   1. 每种算法的经验值之和 ≥ k；
 *   2. 选出的题目序列可以排列成没有相邻两个题目属于同一知识点的序列。
 *
 * 贪心选法：每种算法优先选择提升值最大的题目，直到该算法的总经验 ≥ k。
 * 这样可以在满足条件1的前提下，使得每种算法选择的题目数尽可能少。
 *
 * 接下来需要判断是否存在一种排列方式，使得相同知识点的题目不相邻。
 * 这是一个经典的排列问题：如果某一知识点的题目数最多为 ma，则最少需要的总题目数
 * 至少为 2*ma - 1（例如：A B A B A，需要 ma-1 个间隔）。而且该知识点的总题目数为 mk，
 * 其余知识点的题目总数为 n - mk，要间隔开需要 n - mk ≥ ma - 1，即 ma ≤ n - mk + 1。
 *
 * 答案取满足间隔条件的最小总题数 max(2*ma - 1, s)，其中 s 为贪心选出的总题数。
 * 若所有知识点均已达标，且间隔条件可满足，则输出答案；否则输出 -1。
 */

struct Node {
    int x, y;          // x: 提升值, y: 知识点编号
} a[MAXN];

// 按提升值从大到小排序
bool cmp(Node a, Node b) {
    return a.x > b.x;
}

int m, n, k;                     // m:算法种数, n:题目数, k:目标掌握程度
int cnt[MAXN];                   // cnt[i] 知识点 i 的题目总数
int sum[MAXN];                   // sum[i] 知识点 i 已获得的经验
int num[MAXN];                   // num[i] 知识点 i 已选的题目数
int c;                           // 已达到 k 经验的知识点数量
int s;                           // 已选题目总数
int ma;                          // 出现最多次的知识点的已选题目数
int mk = INT_MAX;                // 对应知识点的总题数（多个时取最小）

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> m >> n >> k;
    // 读入知识点，统计每个知识点的题目总数
    for (int i = 1; i <= n; i++) {
        cin >> a[i].y;           // 知识点
        cnt[a[i].y]++;
    }
    // 读入提升值
    for (int i = 1; i <= n; i++) {
        cin >> a[i].x;           // 提升值
    }

    // 按提升值从大到小排序（贪心基础）
    sort(a + 1, a + n + 1, cmp);

    // 贪心选择：每个知识点优先选价值最高的题，直到经验 ≥ k
    for (int i = 1; i <= n; i++) {
        int v = a[i].x;          // 当前题目的提升值
        int t = a[i].y;          // 当前题目的知识点

        if (sum[t] < k) {        // 该知识点还需要更多经验
            sum[t] += v;         // 累加经验
            num[t]++;            // 该知识点选中的题目数 +1
            s++;                 // 总选中题目数 +1

            // 选完这道题后，若该知识点首次达标，则达标数 +1
            if (sum[t] >= k) c++;

            // 维护出现次数最多的知识点信息
            if (num[t] > ma) {
                ma = num[t];     // 更新最大已选题目数
                mk = cnt[t];     // 记录该知识点的总题数
            } else if (num[t] == ma && cnt[t] < mk) {
                // 如果有多个知识点的已选题目数都等于 ma，则保留总题数较小的
                // （因为总题数越小，能用来间隔的其他题目越少，对间隔条件更严格）
                mk = cnt[t];
            }
        }
    }

    // 判断是否有解：
    // 1. 不是所有知识点都达标
    // 2. 最大已选题目数 ma 需要满足 2*ma - 1 ≤ n （间隔理论最小长度不能超过总题数）
    // 3. 其他题目的总数要足够将该知识点的题目隔开：n - mk ≥ ma - 1
    // 解释：
    // 1.所有 m 个知识点都必须达标。
    // 2.相同知识点的题目不能相邻，需要至少 ma - 1 个其他题目把它们隔开。
    // 最少需要的总题数 = ma + (ma - 1) = 2*ma - 1，若总题目数 n 小于这个值，就一定无法摆开所有题目。
    // 3.mk 是那个出现次数最多的知识点所拥有的所有题目总数，那么其他知识点的题目总数就是 n - mk，
    // 为了把 ma 个同知识点题目隔开，需要 ma - 1 个“间隔题目”，这些间隔题目必须来自其他知识点，因此：
    // n - mk >= ma - 1 → ma <= n - mk + 1
    if (c != m || ma * 2 - 1 > n || ma > n - mk + 1) {
        cout << -1 << endl;
        return 0;
    }

    // 最少需要学习的题目数：贪心选出的 s 和间隔理论需要的最小值取最大
    cout << max(ma * 2 - 1, s) << endl;
    return 0;
}
