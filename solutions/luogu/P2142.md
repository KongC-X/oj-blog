# P2142 高精度减法

> **洛谷** | 普及- | C++14 | 提交时间: 2026-07-06

**算法标签**：`模拟`、`高精度`、`洛谷原创`

## 题目描述

给定两个正整数 $a,b$，求 $a-b$ 的值。

## 输入格式

输入共两行，每行一个正整数，分别为 $a,b$。

## 输出格式

输出一行一个整数，表示 $a-b$ 的值。

如果 $a-b<0$，**请输出负号**。

## 样例

**样例输入 #1**
```
2
1```

**样例输出 #1**
```
1```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;
/*
⾼精度减法；
第⼀步：判断正负，如果s1⽐s2对应的整数⼩，结果为负，交换s1 s2
第⼆步：将两个字符串，逆序存⼊2个整数输出测试
第三步：从左⾄右，逐位相减，不够借位
第四步：从右向左，逆序输出
*/
string s1,s2; //⾼精度整数
int a[10250],b[10250],c[10250]; //存储⾼精度整数的数组
int p;
int main() {
    cin >> s1 >> s2; //读⼊⾼精度整数
    //判断正负 s1 = 123 s2 = 1234   s1 = 123 s2 = 234
    if(s1.size() < s2.size() || (s1.size() == s2.size() && s1 < s2)){
        swap(s1,s2); //交换s1 s2
        cout << "-"; //输出负号
    }
    // 逆序存放到数组中
    for(int i = s1.size() - 1;i >= 0;i--) {
        a[i] = s1[s1.size() - 1 - i] - '0';
    }
    for(int i = s2.size() - 1;i >= 0;i--) {
        b[i] = s2[s2.size() - 1 - i] - '0';
    }
    // 诸位相减
    for(int i = 0;i < s1.size();i++) {
        c[i] = a[i] - b[i];
    }
    // 判断是否需要借位
    for(int i = 0;i < s1.size();i++) {
        if(c[i] < 0) {
            c[i + 1]--; //借位
            c[i] = c[i] + 10; //当前位
        }
    }
    // 去除前导0
    for(int i = s1.size() - 1;i >= 0;i--) {
        if(c[i] != 0) {
            p = i;
            break;
        }
    }
    // 逆序输出结果
    for(int i = p;i >= 0;i--) {
        cout << c[i];
    }
    return 0;
}

```
