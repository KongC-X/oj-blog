# P8448 [LSOT-1] 暴龙的土豆

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-31

**算法标签**：`数学`、`洛谷原创`

## 题目描述

给定一个正整数 $n$。

每次操作可以选两个素数 $y,z$，其中要求 $z$ 是奇素数。

令 $x=y^z$，如果 $x$ 能除尽 $n$ 则计为一次有效操作，$n$ 变为 $\dfrac nx$。

现在需要你回答，对于 $n$ 最多能够进行多少次有效操作。

## 输入格式

**本题有多组数据。**

第一行一个正整数 $T$。

接下来 $T$ 行，每行一个正整数 $n$。

## 输出格式

对于每组数据，输出答案。

## 样例

**样例输入 #1**
```
2
16
9```

**样例输出 #1**
```
1
0```

**样例输入 #2**
```
2
1327104
3623878656000```

**样例输出 #2**
```
5
12```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P8448 [LSOT-1] 暴龙的土豆
     * 题意：给定 n，每次操作选一个素数 y 和奇素数 z，令 x = y^z，
     *       若 x 能整除 n，则 n /= x，问最多能操作多少次。
     *
     * ======================================================================
     * 核心思路：
     *
     * 1. 每次操作相当于从 n 中移除一个质数的奇数次幂（指数≥3）。
     *    （因为 y 是质数，z 是奇素数，所以 y^z 是指数 ≥3 的质数幂）
     *
     * 2. 对于 n 的每个质因子 p，设其在 n 中的指数为 e。
     *    每次操作最多可消耗指数 3（一次 y^3），且只能消耗奇数次幂（3,5,7,...）。
     *    但最优策略是每次都消耗 3，因为消耗越多对后续操作越有利。
     *    因此，质因子 p 最多能贡献 e / 3 次操作（向下取整）。
     *
     * 3. 我们不需要先分解质因数，而是从 k=2 开始枚举所有可能的底数 k，
     *    检查 k^3 是否能整除当前 n。
     *    - 如果 k 是质数，则 k^3 合法，执行一次操作：ans++，n /= k^3。
     *    - 如果 k 是合数，它的质因子都小于 k，且这些质因子已经被之前的
     *      循环处理掉了，所以合数 k 的 k^3 不会再整除 n。
     *    因此，合数只是浪费一次 k++，不会产生错误计数。
     *
     * 4. 循环终止条件：当 k^3 > n 时，任何更大的 k 都不可能再整除 n，
     *    因为 k^3 已经大于 n，无法作为因子。
     *
     * 5. 对于每个质因子，每次操作消耗指数 3，总操作数为 Σ floor(e_p / 3)。
     *
     * 时间复杂度：枚举 k 从 2 到 n^(1/3)，约 1e6，T≤100，可过。
     * ======================================================================
     */

    int T;
    cin >> T;

    while (T--) {
        long long n;
        cin >> n;

        long long ans = 0;    // 操作次数
        long long k = 2;      // 从 2 开始枚举底数

        // 当 k^3 > n 时，不可能再有 k^3 能整除 n
        while (k * k * k <= n) {
            // 只要 k^3 能整除当前 n，就执行一次操作
            while (n % (k * k * k) == 0) {
                ans++;
                n /= (k * k * k);   // 去掉一个 k^3
            }
            k++;   // 尝试下一个底数
        }

        cout << ans << '\n';
    }

    return 0;
}
```
