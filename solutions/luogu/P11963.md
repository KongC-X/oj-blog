# P11963 [GESP202503 六级] 环线

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-06-17

**算法标签**：`动态规划`、`2-SAT`、`匈牙利算法`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1178>

## 题目描述

小 A 喜欢坐地铁。地铁环线有 $n$ 个车站，依次以 $1,2,\cdots,n$ 标号。车站 $i\ (1\leq i<n)$ 的下一个车站是车站 $i+1$。特殊地，车站 $n$ 的下一个车站是车站 $1$。

小 A 会从某个车站出发，乘坐地铁环线到某个车站结束行程，这意味着小 A 至少会经过一个车站。小 A 不会经过一个车站多次。当小 A 乘坐地铁环线经过车站 $i$ 时，小 A 会获得 $a_i$ 点快乐值。请你安排小 A 的行程，选择出发车站与结束车站，使得获得的快乐值总和最大。

## 输入格式

第一行，一个正整数 $n$，表示车站的数量。

第二行，$n$ 个整数 $a_i$，分别表示经过每个车站时获得的快乐值。

## 输出格式

一行，一个整数，表示小 A 能获得的最大快乐值。

## 样例

**样例输入 #1**
```
4
-1 2 3 0```

**样例输出 #1**
```
5```

**样例输入 #2**
```
5
-3 4 -5 1 3```

**样例输出 #2**
```
5```

## AC 代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
using namespace std;

int n;                        // n: 车站数量
long long a[200010];          // a[i]: 经过车站 i 获得的快乐值
long long sum = 0;            // 所有快乐值的总和

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        sum += a[i];
    }

    // ---------- 思路 ----------
    // 问题：求环形数组的最大子段和（至少包含一个元素）。
    // 
    // 经典做法：
    //   情况1：答案不跨越环的首尾，等价于普通数组的最大子段和。
    //   情况2：答案跨越首尾，等价于总和减去普通数组的最小子段和。
    //   在此解释一下情况2: 假设我们把数组画在一个圆上，如果答案跨越了首尾，答案 = 整个圆的总和 — 中间没选的那一段，
    //   中间没选的那一段一定是一段连续的子数组，而且因为我们想要答案最大，所以没选的那段应该尽可能小。
    //   因此：跨越首尾的最大和 = 总和 - 最小子段和
    //   特殊情况：如果所有数都是负数，那么情况2会得到空段（和为0），
    //   此时应直接取情况1的结果（即最大的那个负数）。
    // 最终答案 = max(普通最大子段和, sum - 普通最小子段和)，
    // 但要特判全负数的情况。

    // 1. 计算普通最大子段和 ma
    long long ma = a[1];
    long long t = a[1]; // 当前子段和
    for (int i = 2; i <= n; i++) {
        if (t > 0) t += a[i];   // 继续扩展
        else       t = a[i];    // 另起一段
        ma = max(ma, t);
    }

    // 2. 计算普通最小子段和 mi
    long long mi = a[1];
    t = a[1]; // 当前子段和
    for (int i = 2; i <= n; i++) {
        if (t < 0) t += a[i];   // 继续扩展
        else       t = a[i];    // 另起一段
        mi = min(mi, t);
    }

    // 3. 环形最大子段和
    long long s = 0;
    if (ma < 0) {           // 全为负数，此时 mi 也是负数，sum - mi 可能为0或更大
        s = ma;           // 直接取最大负数
    } else {
        s = max(ma, sum - mi);
    }

    cout << s << endl;
    return 0;
}
```
