# B3789 [信息与未来 2023] 程序分析

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-04-29

**算法标签**：`模拟`、`最小环`、`最小割`、`CDQ分治`

## 题目描述

程序分析技术是一种用于理解和改进计算机程序的方法。它可以帮助我们找出程序中的错误、提高程序的性能、优化代码结构等。其中，静态分析技术在不运行程序的情况下对程序代码进行分析。它可以检查代码的语法、风格、潜在错误等。例如，静态分析可以帮助我们找出程序中未使用的变量、可能的数组越界等问题。

小小设计了一个自己的编程语言，并命名为 X 语言。你能为它设计一个静态分析器吗？

X 语言程序中只有两个整型变量 $x$ 和 $y$，且无需定义，可以直接使用。变量 $x$ 的值从程序外输入（输入值可以是任何 C++ int 范围内的值），$y$ 的初始值是 $0$。一个 X 语言程序由若干行组成，每行恰好包含一条命令，是以下三种命令之一：
1. 条件分支：`if (条件) {`；
2. 对 $y$ 赋值：`y = 数字;`；
3. 条件结束：`}`。

其中，“条件”要么是 `x > 数字`，要么是 `x < 数字`。赋值语句和条件中的“数字”都是 $1$ 到 $10^9$ 之间的常数。`if` 和赋值的含义同 C++ 语言中的条件和赋值语句。

请你编写一个静态分析器，分析一个 X 语言程序执行结束时，所有可能的 $y$ 的值。

## 输入格式

输入数据第一行为整数 $n$，代表程序的行数。

接下来 $n$ 行，每行一个命令，描述了一个合法的 X 语言程序：输入的程序保证括号配对，且符合问题描述中的约定。为了便于大家解析 (例如用 `cin` 或 `scanf` 读入)，输入程序中的 `if` 后、`{` 前、`=`、`<`、`>` 左右都恰好有一个空格，行首可能有若干空格缩进。除此之外，输入不含多余的空格或空白字符。

## 输出格式

输出一行，从小到大不重复地输出程序结束时，变量 $y$ 所有可能的值。数字之间由一个空格隔开。

## AC 代码

```cpp
#include <iostream>
#include <string>
#include <cstdio>
#include <algorithm>
using namespace std;

const int MAXN = 1005;
int n;                         // 程序行数
int tp[MAXN], vl[MAXN];        // tp[i]: 指令类型, vl[i]: 数值（若为 } 则忽略）
int pc;                        // 程序指令计数 (program counter)

int nums[MAXN], numLen;        // 所有常数（if 中的数字和赋值右值）
int tests[MAXN * 5], testLen;  // 测试的 x 值列表
int res[MAXN * 5], resLen;     // 最终收集的 y 值

// 给定 x 值，模拟执行，返回最终的 y
int run(int x) {
    int y = 0, i = 0;
    while (i < pc) {
        if (tp[i] == 0) {           // if (x > num)
            if (x > vl[i]) i++;     // 条件真，进入
            else {                  // 条件假，跳过整个块
                int d = 1; i++;
                while (d > 0 && i < pc) {
                    if (tp[i] == 0 || tp[i] == 1) d++;
                    else if (tp[i] == 3) d--;
                    i++;
                }
            }
        } else if (tp[i] == 1) {    // if (x < num)
            if (x < vl[i]) i++;
            else {
                int d = 1; i++;
                while (d > 0 && i < pc) {
                    if (tp[i] == 0 || tp[i] == 1) d++;
                    else if (tp[i] == 3) d--;
                    i++;
                }
            }
        } else if (tp[i] == 2) {    // y = num;
            y = vl[i];
            i++;
        } else if (tp[i] == 3) {    // '}'
            i++;
        }
    }
    return y;
}

int main() {
    cin >> n; cin.ignore();

    pc = 0;
    numLen = 0;
    for (int i = 0; i < n; i++) {
        string line;
        getline(cin, line);
        int p = line.find_first_not_of(" \t");
        if (p == string::npos) continue;
        line = line.substr(p);

        if (line[0] == 'i') {
            char op; int num;
            sscanf(line.c_str(), "if (x %c %d) {", &op, &num);
            tp[pc] = (op == '>') ? 0 : 1;
            vl[pc] = num;
            pc++;
            nums[numLen++] = num;
        } else if (line[0] == 'y') {
            int num;
            sscanf(line.c_str(), "y = %d;", &num);
            tp[pc] = 2;
            vl[pc] = num;
            pc++;
            nums[numLen++] = num;
        } else if (line[0] == '}') {
            tp[pc] = 3;
            vl[pc] = 0;
            pc++;
        }
    }

    // 常数去重排序
    sort(nums, nums + numLen);
    numLen = unique(nums, nums + numLen) - nums;

    testLen = 0;
    if (numLen > 0) {
        tests[testLen++] = nums[0] - 1;
        tests[testLen++] = nums[numLen - 1] + 1;
    } else {
        tests[testLen++] = 0;
    }

    for (int i = 0; i < numLen; i++) {
        int c = nums[i];
        tests[testLen++] = c;
        tests[testLen++] = c - 1;
        tests[testLen++] = c + 1;
    }
    for (int i = 0; i < numLen - 1; i++) {
        int mid = (nums[i] + nums[i + 1]) / 2;
        tests[testLen++] = mid;
    }

    // 测试点去重
    sort(tests, tests + testLen);
    testLen = unique(tests, tests + testLen) - tests;

    resLen = 0;
    for (int i = 0; i < testLen; i++) {
        int yval = run(tests[i]);
        bool found = false;
        for (int j = 0; j < resLen; j++) {
            if (res[j] == yval) { found = true; break; }
        }
        if (!found) res[resLen++] = yval;
    }

    sort(res, res + resLen);
    for (int i = 0; i < resLen; i++) {
        cout << res[i];
        if (i < resLen - 1) cout << " ";
    }
    cout << endl;
    return 0;
}
```
