# B3921 [GESP202312 一级] 小杨的考试

> **洛谷** | 入门 | C++14 | 提交时间: 2025-03-28

**算法标签**：`递归`、`最小割`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1133>

## 题目描述

今天是星期 $X$，小杨还有 $N$ 天就要考试了，你能推算出小杨考试那天是星期几吗？（本题中使用 $7$ 表示星期日）

## 输入格式

输入 $2$ 行，第一行一个整数 $X(1\le X \le 7)$；第二行一个整数 $N(1≤N≤364)$。

## 输出格式

输出一个整数，表示小杨考试那天是星期几。

## 样例

**样例输入 #1**
```
1
6```

**样例输出 #1**
```
7```

**样例输入 #2**
```
5
3```

**样例输出 #2**
```
1```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int x,n;
    cin>>x>>n;
    if((x + n) % 7 == 0) {
        cout << 7;
    } else {
        cout << (x + n) % 7;
    }
}
```
