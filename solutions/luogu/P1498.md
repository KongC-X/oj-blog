# P1498 南蛮图腾

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-02-12

**算法标签**：`贪心`、`最小环`、`莫队`、`栈`、`迭代加深`

## 题目背景

自从到了南蛮之地，孔明不仅把孟获收拾的服服帖帖，而且还发现了不少少数民族的智慧，他发现少数民族的图腾往往有着一种分形的效果，在得到了酋长的传授后，孔明掌握了不少绘图技术，但唯独不会画他们的图腾，于是他找上了你的爷爷的爷爷的爷爷的爷爷……帮忙，作为一个好孙子的孙子的孙子的孙子……你能做到吗？

## 题目描述

给定一个正整数 $n$，参考输出样例，输出图形。

## 输入格式

每个数据输入一个正整数 $n$，表示图腾的大小（此大小非彼大小）。

## 样例

**样例输入 #1**
```
2```

**样例输出 #1**
```
   /\
  /__\
 /\  /\
/__\/__\
```

**样例输入 #2**
```
3```

**样例输出 #2**
```
       /\
      /__\
     /\  /\
    /__\/__\
   /\      /\
  /__\    /__\
 /\  /\  /\  /\
/__\/__\/__\/__\```

## AC 代码

```cpp
#include <iostream>
#include <cmath>
#include <cstring>
using namespace std;

const int MAXH = 1050;   // 2^10 = 1024，足够
const int MAXW = 2050;   // 2^11 = 2048

char a[MAXH][MAXW]; // 全局画布，初始化为空格
int H, W;                // 实际高度、宽度

// n=1 的基础矩形，高2宽4
const char base[2][4] = {
    {' ', '/', '\\', ' '},
    {'/', '_', '_', '\\'}
};

/**
 * 递归绘制图腾
 * @param n 当前层级
 * @param x 左上角行坐标
 * @param y 左上角列坐标
 * 图形尺寸：高度 = 1<<n，宽度 = 1<<(n+1)
 */
void draw(int n, int x, int y) {
    if (n == 1) {
        // 复制基础矩形到画布
        for (int i = 0; i < 2; i++) {
            for (int j = 0; j < 4; j++) {
                a[x + i][y + j] = base[i][j];
            }
        }
        return;
    }

    int h2 = 1 << (n - 1);   // 子图形高度
    int w2 = 1 << n;         // 子图形宽度

    // 三个子图形的位置
    draw(n - 1, x, y + w2 / 2); // 上方居中
    draw(n - 1, x + h2, y);           // 左下
    draw(n - 1, x + h2, y + w2);      // 右下
}

int main() {
    int n;
    cin >> n;

    H = 1 << n;        // 2^n
    W = 1 << (n + 1);  // 2^(n+1)

    // 画布初始化为空格
    for (int i = 0; i < H; i++) {
        for (int j = 0; j < W; j++) {
            a[i][j] = ' ';
        }
    }

    // 从左上角(0,0)开始绘制
    draw(n, 0, 0);

    // 输出，去掉每行末尾的空格
    for (int i = 0; i < H; i++) {
        // 找到该行最后一个非空格字符
        int last = W - 1;
        while (last >= 0 && a[i][last] == ' ') {
            last--;
        }
        // 输出从0到last的字符
        for (int j = 0; j <= last; j++) {
            cout << a[i][j];
        }
        cout << endl;
    }

    return 0;
}
```
