# B4202 [常州市赛 2021] 书页

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-17

**算法标签**：`模拟`、`2021`、`江苏`、`科创活动`、`小学活动`

## 题目背景

搬运自 <http://czoj.com.cn/p/438>。数据为民间数据。

## 题目描述

[](VFhwSmVVNXFTWGM9)
小 X 把一本书摊开在桌上。这本书的页码是连续的，从 $1$ 到 $n$。  

![](https://cdn.luogu.com.cn/upload/image_hosting/78pc5h3o.png)

现在他告诉你现在桌面上书本左右两页的页码是什么，请你回答他当他翻到第 $A$ 页时，第 $A$ 页会在左边还是右边。

## 输入格式

第一行 $1$ 个正整数 $n$，表示这本书的页码从 $1$ 标号到 $n$。   
第二行 $2$ 个正整数，表示现在书本左右两页的页码 $P_1$ 和 $P_2$。   
第三行 $1$ 个正整数，表示小 X 想问你第 $A$ 页在左边还是右边。

## 输出格式

如果第 $A$ 页在左边，输出 `L`；如果第 $A$ 页在右边，输出 `R`。

## 样例

**样例输入 #1**
```
5
2 3
1```

**样例输出 #1**
```
R```

**样例输入 #2**
```
5
2 3
4```

**样例输出 #2**
```
L```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 书本摊开时，左边页码与右边页码的奇偶性不会因为翻页而改变。
    // 即：左边页码的奇偶性和当前给出的 P1 相同，右边页码的奇偶性和 P2 相同。
    // 因此，只需判断目标页码 A 的奇偶性是否与 P1 一致：
    //   若 A % 2 == P1 % 2，则 A 在左边，输出 L；
    //   否则在右边，输出 R。
    int n, P1, P2, A;
    cin >> n;
    cin >> P1 >> P2;
    cin >> A;

    if (A % 2 == P1 % 2) {
        cout << "L" << endl;
    } else {
        cout << "R" << endl;
    }

    return 0;
}
```
