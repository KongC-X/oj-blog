# P5715 【深基3.例8】三位数排序

> **洛谷** | 入门 | C++14 | 提交时间: 2025-08-01

## 题目描述

给出三个整数 $a,b,c(0\le a,b,c \le 100)$，要求把这三位整数从小到大排序。

## 输入格式

输入三个整数 $a,b,c$，以空格隔开。

## 输出格式

输出一行，三个整数，表示从小到大排序后的结果。

## 样例

**样例输入 #1**
```
1 14 5```

**样例输出 #1**
```
1 5 14```

**样例输入 #2**
```
2 2 2```

**样例输出 #2**
```
2 2 2```

## AC 代码

```cpp
#include <iostream>
#include <algorithm>

using namespace std;

int a[4];

int main()
{
    cin>>a[1]>>a[2]>>a[3];
    sort(a+1,a+4);
    cout<<a[1]<<' '<<a[2]<<' '<<a[3];
    return 0;
}
  

```
