# B4193 [海淀区小学组 2023] 排座位

> **洛谷** | 普及- | C++14 | 提交时间: 2026-07-22

**算法标签**：`贪心`、`2023`、`北京`、`科创活动`、`小学活动`

## 题目描述

信息学省队选手由 $a$ 名男生和 $b$ 名女生组成，他们准备乘火车去外地参加比赛。火车由若干节车厢组成，第一节车厢有 $n$ 个连续的座位，每个座位要么空着，要么已经有乘客。为了让男女选手之间增加交流，你需要按以下要求排座位：相邻的同学不能同时是男生或者是女生。

请从 $a + b$ 名学生中选出最多的学生安排在第一节车厢的空座位上以满足题目要求。

## 输入格式

第一行包括三个整数 $n, a$ 和 $b$，分别表示第一节车厢座位数量，男生数量和女生数量。

第二行包含长度为 $n$ 的字符串，由字符 `·` 和 `*` 组成，其中 `·` 代表座位是空的，`*` 代表有乘客的座位。

## 输出格式

输出一行一个整数，表示第一节车厢最多可以安排的学生。

## 样例

**样例输入 #1**
```
5 1 1
*...*```

**样例输出 #1**
```
2```

**样例输入 #2**
```
6 2 3
*...*.```

**样例输出 #2**
```
4```

**样例输入 #3**
```
3 2 3
***```

**样例输出 #3**
```
0```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
        思路（贪心）：
        从左到右逐个处理每个座位。
        t 记录上一个人安排的是男生(1)还是女生(2)，初始为0表示还没有安排人。
        遇到空位 '.' 时：
          1. 如果上一个是障碍物或还没有安排人（t == 0）：
             因为还没有"与上一个人性别不同"的限制，优先选择剩余人数多的一方，
             这样可以让人数多的一方尽量用掉，同时也能留出另一方去填别的空位。
             如果人数多的没有了，再选人数少的；如果都没有了，就不能安排。
          2. 如果上一个人已经安排了（t != 0）：
             必须安排性别不同的人，如果有人就安排，没有人则无法安排，该段后续空位也都不能安排。
             将 t 设为0，表示这一段结束了。
        遇到障碍物 '*' 时：
          直接让 t = 0，表示一段结束，后面可以重新选择性别。
    */
    int n, a, b;                    // n:座位数, a:男生数, b:女生数
    string s;
    cin >> n >> a >> b >> s;

    int t = 0;                    // 上一个安排的人：0-无, 1-男, 2-女
    int ans = 0;                    // 已安排的总人数

    // 从左到右逐个处理每个座位
    for (int i = 0; i < n; i++) {
        char c = s[i];
        if (c == '*') {
            // 障碍物：重置状态，后续可以自由选择性别
            t = 0;
        } else if (t == 0) {
            // 没有前一个人限制：优先安排剩余人数多的性别
            if (a >= b && a > 0) {           // 男生不少于女生且还有男生
                a--;
                t = 1;
                ans++;
            } else if (b > 0) {              // 还有女生
                b--;
                t = 2;
                ans++;
            } else {
                t = 0;                     // 没人可安排
            }
        } else {
            // 有前一个人限制：必须安排不同性别
            if (t == 1 && b > 0) {         // 上一个是男，且还有女生
                b--;
                t = 2;
                ans++;
            } else if (t == 2 && a > 0) {  // 上一个是女，且还有男生
                a--;
                t = 1;
                ans++;
            } else {
                // 需要的人没有了，这一段不能再放人
                t = 0;
            }
        }
    }

    cout << ans << endl;
    return 0;
}
```
