# B3664 [语言月赛202209] 零食售卖点

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-25

**算法标签**：`2022`、`O2优化`、`排序`、`语言月赛`

## 题目描述

洛咕公司有一条无限长的大道，可以被视为一个数轴。在这条大道上，一共有 $k$ 个零食售卖点，第 $i$ 个零食售卖点的坐标为 $a_i$。

Aya 非常热爱零食，他想知道，**相邻**两个零食售卖点之间的距离最大为多少。第 $i$ 个零食售卖点和第 $j$ 个零食售卖点之间的距离为 $|a_i-a_j|$。

$|x|$ 代表 $x$ 的绝对值。即，当 $x\ge0$，$|x|=x$；当 $x<0$，$|x|=-x$。例如，$|4|=4,|0|=0,|-1|=1$。

## 输入格式

输入的第一行为一个整数 $k$。

输入的第二行为 $k$ 个整数，第 $i$ 个为 $a_i$。

**请注意，$a_i$ 不保证按照升序给出。**

## 输出格式

输出一行一个整数，代表**相邻**两个零食售卖点之间的距离最大为多少。

## 样例

**样例输入 #1**
```
4
3 5 1 20```

**样例输出 #1**
```
15```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3664 [语言月赛202209] 零食售卖点
     * 题意：给定 k 个坐标，求排序后相邻两个点的最大距离。
     * 思路：排序，依次计算相邻差，取最大值。
     */
    int k;
    scanf("%d", &k);
    int a[5005];
    for (int i = 0; i < k; i++) scanf("%d", &a[i]);
    sort(a, a + k);
    int ans = 0;
    for (int i = 1; i < k; i++) {
        ans = max(ans, a[i] - a[i - 1]);
    }
    printf("%d\n", ans);
    return 0;
}
```
