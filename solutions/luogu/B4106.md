# B4106 [CSP-X2024 山东] 翻硬币

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-12

**算法标签**：`2024`、`山东`、`差分`、`CSP-X 小学组`

## 题目描述

$n$ 枚硬币从左到右依次排成一排，编号依次为 $1$ 到 $n$。硬币的正面朝上用 $0$ 表示，背面朝上用 $1$ 表示，一开始所有的硬币都是正面朝上。

现进行 $m$ 次操作，每次操作是把一个区间内的所有硬币翻过来：原来正面朝上的变为反面朝上，原来反面朝上的变为正面朝上。

第 $i$ 次操作的区间 $[l_i,r_i]$：表示把从第 $l_i$ 到第 $r_i$ 枚之间的所有硬币都翻过来。

求 $m$ 次操作后所有硬币从左到右依次组成的 $01$ 数字序列。

## 输入格式

第一行整数 $n$ 和整数 $m$，表示一共有 $n$ 枚硬币和 $m$ 次操作。

以下 $m$ 行，每行两个正数数 $l_i,r_i$，依次表示每次操作区间。

## 输出格式

$m$ 次操作结束后 $n$ 枚硬币从左到右依次组成的 $01$ 数字序列。

## 样例

**样例输入 #1**
```
5 3
2 4
1 3
3 5```

**样例输出 #1**
```
10101```

**样例输入 #2**
```
10 5
1 6
8 10
3 7
4 6
2 5```

**样例输出 #2**
```
1010011111```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int n, m;               // n: 硬币数量, m: 操作次数
int a[1000010];         // a[]: 差分数组，记录每个位置翻转次数的变化

int main() {
    /*
     * 核心思路：
     * 1. 初始所有硬币都是正面（0）。
     * 2. 每次区间翻转，等价于将该区间内每个位置被翻转的次数 +1。
     * 3. 用差分数组 a[] 来记录区间加减操作：
     *    - 对区间 [l, r] 翻转，执行 a[l] += 1，a[r+1] -= 1。
     *    - 因为 a[l] 表示从 l 开始的翻转次数变化，a[r+1] 表示在 r+1 处减少。
     *    - 这样，前缀和 sum 就能表示当前位置总共被翻转了多少次。
     * 4. 最后从左到右计算前缀和 sum，sum%2 就是最终状态：
     *    - sum%2 == 0 → 正面（0）
     *    - sum%2 == 1 → 反面（1）
     *
     * 为什么不用异或？
     * 用加减法同样有效，而且更符合差分数组的标准定义，容易理解。
     * 因为每次翻转相当于“取反”，即奇数次翻转变反面，偶数次翻转变正面。
     * 所以只需要统计每个位置被翻转的总次数，看奇偶性即可。
     *
     * 时间复杂度：O(n + m)，空间 O(n)。
     * ======================================================================
     */

    cin >> n >> m;

    for (int i = 0; i < m; i++) {
        int l, r;
        cin >> l >> r;

        // 区间 [l, r] 整体翻转：从 l 开始多翻 1 次，从 r+1 开始少翻 1 次
        a[l]++;
        if (r + 1 <= n) {   // 防止越界（因为 r 最大为 n，r+1 可能为 n+1）
            a[r + 1]--;
        }
    }

    int sum = 0;          // 当前位置累积的翻转次数
    for (int i = 1; i <= n; i++) {
        sum += a[i];      // 前缀和，得到第 i 个硬币被翻转的总次数
        cout << (sum % 2); // 奇数次为 1（反面），偶数次为 0（正面）
    }

    cout << endl;
    return 0;
}
```
