# B2039 整数大小比较

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-26

## 题目描述

输入两个整数，比较它们的大小。若 $x>y$ ，输出 `>` ；若 $x=y$ ，输出 `=` ；若 $x<y$，输出 `<` 。

## 输入格式

一行，包含两个整数 $x$ 和 $y$ ，中间用单个空格隔开。 $0 \le x<2^{32}, -2^{31} \le y<2^{31}$ 。

## 输出格式

一个字符。若 $x>y$，输出 `>` ；若 $x=y$ ，输出 `=` ；若 $x<y$ ，输出 `<` ；

## 样例

**样例输入 #1**
```
1000 100```

**样例输出 #1**
```
>```

## AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
long long x,y;
int main(){
	cin>>x>>y;
	if(x>y) cout<<">";
	else if(x==y) cout<<"=";
	else cout<<"<";
	return 0;
}

```
