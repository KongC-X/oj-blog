# P1658 购物

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-07-24

**算法标签**：`贪心`

## 题目描述

你就要去购物了，现在你手上有 $N$ 种不同面值的硬币，每种硬币有无限多个。为了方便购物，你希望带尽量少的硬币，但要能组合出 $1$ 到 $X$ 之间的任意值。

## 输入格式

第一行两个数 $X, N$，以下 $N$ 个数，表示每种硬币的面值。

## 输出格式

最少需要携带的硬币个数，如果无解输出 `-1`。

## 样例

**样例输入 #1**
```
20 4
1 2 5 10
```

**样例输出 #1**
```
5
```

## AC 代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int a[15]; // 存储硬币面值，N<=10

int main() {
    int X, N;
    cin >> X >> N;
    for (int i = 0; i < N; i++) {
        cin >> a[i];
    }
    sort(a, a + N); // 从小到大排序

    // 如果没有面值1，无法组成1，无解
    if (a[0] != 1) {
        cout << -1 << endl;
        return 0;
    }

    int S = 1;       // 当前已经可以覆盖 [1, S]
    int ans = 1;     // 至少需要一枚1分硬币
    int pos = 0;     // 当前使用的最大面值在数组中的下标，初始为0（即1分）

    // 循环直到覆盖范围达到X
    while (S < X) {
        // 在已排序的硬币中，选择面值 <= S+1 的最大面值
        // 由于数组有序，pos可以后移
        while (pos + 1 < N && a[pos + 1] <= S + 1) {
            pos++;
        }
        // 现在 a[pos] 是当前可用的最大面值
        S += a[pos];
        ans++;
    }

    cout << ans << endl;
    return 0;
}
```
