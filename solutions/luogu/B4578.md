# B4578 [GESP202609 三级] 分割字符串

> **洛谷** | 普及- | C++14 | 提交时间: 2026-09-16

**算法标签**：`字符串`、`2026`、`GESP`

## 题目描述

小明拿到了一段字符串文本，小明希望用下面的规则分割这个字符串：

1. 小明从左到右扫描字符串，遇到第一个空格后停止，并将字符串分割为左右两个部分（舍弃用于分割的这个空格）；
2. 对于上次分割后右侧的字符串，小明继续扫描，第一次遇到连续两个空格后停止，并将字符串分割为左右两个部分（舍弃用于分割的这两个空格）；
3. 对于上次分割后右侧的字符串，小明继续扫描，第一次遇到连续三个空格后停止，并将字符串分割为左右两个部分（舍弃用于分割的这三个空格）；
4. 以此类推，小明每分割一次，下一次分割就需要更长的连续空格；直到字符串无法再次分割。

最后输出每次分割的左侧的字符串，以及最后一次分割的右侧字符串。

如果字符串完全无法进行任何一次分割，直接输出其本身。

## 输入格式

输入一行，一个字符串。

## 输出格式

输出若干行。每行为分割后的一个字符串，注意依次输出：

第一次分割左侧的字符串，第二次分割左侧的字符串，……，最后一次分割左侧的字符串，最后一次分割右侧的字符串。

## 样例

**样例输入 #1**
```
sdfd 55 55   99312```

**样例输出 #1**
```
sdfd
55 55
 99312```

**样例输入 #2**
```
AbCd   999```

**样例输出 #2**
```
AbCd

999```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B4578 [GESP202609 三级] 分割字符串
     * 题意：按照连续空格个数依次递增（1个、2个、3个...）分割字符串。
     *       每次找到第一个连续 k 个空格，将字符串分成左右两部分（去掉这 k 个空格），
     *       输出左侧部分，然后对右侧部分继续用 k+1 个空格分割。
     *       直到找不到连续 k 个空格，最后输出剩余的右侧部分。
     *       如果一开始就无法分割，直接输出原字符串。
     *
     * 思路：
     *   1. 读入整行字符串 s。
     *   2. 令 k = 1，表示本次需要寻找连续 k 个空格。
     *   3. 循环：
     *        a. 在 s 中寻找连续 k 个空格的起始位置 pos。
     *        b. 如果找不到，跳出循环。
     *        c. 输出 s 从开头到 pos 之前的部分（左侧字符串）。
     *        d. 将 s 更新为 pos + k 之后的部分（右侧字符串，跳过分隔用的 k 个空格）。
     *        e. k++，下次寻找更长的连续空格。
     *   4. 循环结束后，输出当前剩余的 s（最后一次分割的右侧字符串，或原字符串）。
     *
     * 注意：字符串长度不超过 1000，直接暴力搜索连续空格即可。
     */

    string s;                 // s: 当前待分割的字符串
    getline(cin, s);          // 读入整行（可能包含空格）

    int k = 1;                // k: 本次需要寻找的连续空格个数

    while (true) {
        int pos = -1;         // pos: 连续 k 个空格的起始位置，-1 表示未找到
        int n = s.size();

        // 暴力搜索连续 k 个空格
        for (int i = 0; i + k <= n; i++) {
            bool ok = true;   // ok: 从 i 开始是否连续 k 个都是空格
            for (int j = 0; j < k; j++) {
                if (s[i + j] != ' ') {
                    ok = false;
                    break;
                }
            }
            if (ok) {
                pos = i;
                break;
            }
        }

        if (pos == -1) break; // 找不到连续 k 个空格，结束分割

        // 输出左侧部分
        cout << s.substr(0, pos) << endl;

        // 更新 s 为右侧部分（跳过这 k 个空格）
        s = s.substr(pos + k);

        k++;                  // 下次需要更长的连续空格
    }

    // 输出最后一次分割的右侧字符串（如果从未分割，则输出原字符串）
    cout << s << endl;

    return 0;
}
```
