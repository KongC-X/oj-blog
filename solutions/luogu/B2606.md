# B2606 【深基1.例9】圆的计算

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-03

## 题目描述

当半径为 $r=5$，请输出圆的周长、面积和球体积。取 $\pi=3.141593$。请直接使用 `cout` 输出答案，每行一个数字。

## 输出格式

请直接使用 `cout` 输出答案，每行一个数字。一共三个数字。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】公式计算
     * 【核心思路】
     * 1. 设半径 r = 5，圆周率 pi = 3.141593。
     * 2. 周长 = 2 * pi * r
     * 3. 面积 = pi * r * r
     * 4. 球体积 = 4.0 / 3.0 * pi * r * r * r
     * 5. 每行输出一个数。
     *
     * 【时间复杂度】O(1)
     */

    double r = 5;           // r: 半径
    double pi = 3.141593;   // pi: 圆周率

    double c = 2 * pi * r;              // c: 圆周长
    double s = pi * r * r;              // s: 圆面积
    double v = 4.0 / 3.0 * pi * r * r * r;  // v: 球体积

    cout << c << endl;
    cout << s << endl;
    cout << v << endl;

    return 0;
}
```
