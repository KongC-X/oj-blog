# B2048 计算邮资

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-27

## 题目描述

请根据邮件的重量和用户选择是否加急计算邮费。计算规则：

- 重量在 $1000$ 以内（包括），基本费 $8$ 元；

- 超过 $1000$ 克的部分，每 $500$ 克加收超重费 $4$ 元，不足 $500$ 克部分按 $500$ 克计算；

- 如果用户选择加急，多收 $5$ 元。

## 输入格式

一行，包含一个正整数 $x$ 和一个字符 $c$（`y` 或 `n`），之间用一个空格隔开，分别表示重量和是否加急。

如果字符是 `y`，说明选择加急；如果字符是 `n`，说明不加急。

## 输出格式

输出一行一个正整数，表示邮费。

## 样例

**样例输入 #1**
```
1200 y```

**样例输出 #1**
```
17```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int x;                         // x: 邮件重量（克）
    char c;                        // c: 是否加急（y/n）
    cin >> x >> c;

    int ans = 8;                   // 基本费 8 元

    if (x > 1000) {                // 超过 1000 克需要加收超重费
        int extra = x - 1000;      // 超出的重量
        // 每 500 克加收 4 元，不足 500 克按 500 克计算
        int n = (extra + 499) / 500;  // 等价于 ceil(extra / 500)
        ans += n * 4;
    }

    if (c == 'y') {                // 如果选择加急，额外加 5 元
        ans += 5;
    }

    cout << ans << '\n';
    return 0;
}
```
