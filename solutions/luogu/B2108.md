# B2108 图像模糊处理

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-09

## 题目描述

给定 $n$ 行 $m$ 列的图像各像素点的灰度值，要求用如下方法对其进行模糊化处理：

$1.$ 四周最外侧的像素点灰度值不变；

$2.$ 中间各像素点新灰度值为该像素点及其上下左右相邻四个像素点原灰度值的平均（舍入到最接近的整数）。

## 输入格式

第一行包含两个整数 $n$ 和 $m$，表示图像包含像素点的行数和列数。$1 \le n \le 100$，$1 \le m \le 100$。

接下来 $n$ 行，每行 $m$ 个整数，表示图像的每个像素点灰度。相邻两个整数之间用单个空格隔开，每个元素均在 $0$ ∼ $255$ 之间。

## 输出格式

$n$ 行，每行 $m$ 个整数，为模糊处理后的图像。相邻两个整数之间用单个空格隔开。

## 样例

**样例输入 #1**
```
4 5
100 0 100 0 50
50 100 200 0 0
50 50 100 100 200
100 100 50 50 100```

**样例输出 #1**
```
100 0 100 0 50
50 80 100 60 0
50 80 100 90 200
100 100 50 50 100```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 对图像进行模糊处理：
    // - 四周边界的像素灰度值保持不变；
    // - 内部像素的新灰度值为其本身及上下左右相邻共5个像素原灰度值的平均值，结果四舍五入取整。
    // 可用整数运算实现四舍五入：(总和 + 2) / 5 即可。
    // 边读边处理：读入原始矩阵到二维数组，然后按规则输出。
    
    int n, m;                          // n: 行数, m: 列数
    cin >> n >> m;

    int a[110][110];                   // 存储原始灰度值，多开10个

    // 读入原始图像
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            cin >> a[i][j];
        }
    }

    // 输出模糊处理后的图像
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            // 判断是否为边界
            if (i == 1 || i == n || j == 1 || j == m) {
                cout << a[i][j];       // 边界不变
            } else {
                // 计算自身和上下左右五个像素的总和
                int sum = a[i][j] + a[i-1][j] + a[i+1][j] + a[i][j-1] + a[i][j+1];
                // 四舍五入到最接近的整数，等价于 (sum + 2) / 5
                cout << (sum + 2) / 5;
            }
            // 控制空格的输出：不是每行最后一个数就输出空格
            if (j < m) cout << ' ';
        }
        cout << endl;
    }

    return 0;
}
```
