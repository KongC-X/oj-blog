# P2841 A*B Problem

> **洛谷** | 提高+/省选- | C++14 | 提交时间: 2026-07-27

**算法标签**：`数学`、`高精度`、`递推`、`进制`

## 题目描述

给出一个数 $A$ ，你需要给出一个最小的数 $B$ ，使得 $A\times B$ 的结果只含有 $0$ 和 $1$ 。

## 输出格式

正整数 $B$ 和 $A\times B$ 的结果，两数之间用一个空格隔开。

## 样例

**样例输入 #1**
```
6```

**样例输出 #1**
```
185 1110
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXA = 10005;                 // A 的最大值 10000

int pre[MAXA];                          // pre[r]：记录状态 r 的前驱信息。低 1 位表示最后添加的数字（0 或 1），高位表示前驱余数
bool vis[MAXA];                         // 标记余数是否已访问过

int main() {
    /*
      思路：
      要找最小的 B，使得 A * B = C，且 C 只由数字 0 和 1 组成。
      即找最小的只含 0/1 的正整数 C，且 C 是 A 的倍数。
      然后输出 B = C / A 和 C。

      方法：BFS 构造 C。
      从数字 1 开始（因为 C 不能有前导零，第一位必须是 1）。
      维护当前 C 除以 A 的余数。每次在 C 的末尾添加 '0' 或 '1'，
      相当于余数变为 (原余数 * 10 + 0/1) % A。
      用 BFS 遍历不同余数，第一次到达余数 0 时所构造的 C 就是最小的 C。
      
      回溯路径得到 C，再做一次高精度除以低精度得到 B。
    */

    int A;                              // 输入的正整数 A
    cin >> A;

    if (A == 1) {                       // 特判：A=1，最小的 C=1，B=1
        cout << "1 1\n";
        return 0;
    }

    queue<int> q;                       // BFS 队列，存储余数
    int start = 1 % A;                  // C 的第一位是 1，余数为 1 % A
    vis[start] = true;
    pre[start] = -1;                    // 特殊标记，表示这是起点，数字是 1
    q.push(start);

    // BFS
    while (!q.empty()) {
        int u = q.front(); q.pop();
        if (u == 0) break;              // 找到了余数为 0 的状态，即 C % A == 0

        // 在末尾添加 0 和 1
        for (int d = 0; d <= 1; d++) {
            int v = (u * 10 + d) % A;
            if (!vis[v]) {
                vis[v] = true;
                pre[v] = (u << 1) | d;   // 把前驱 u 和新数字 d 打包存储
                q.push(v);
            }
        }
    }

    // 回溯构造只含 0/1 的字符串 C
    string C;
    int cur = 0;                         // 从终点（余数 0）开始
    while (cur != -1) {
        if (cur == start) {              // 到达起点，数字是 1
            C.push_back('1');
            break;
        }
        int d = pre[cur] & 1;            // 取出最后添加的数字
        C.push_back('0' + d);
        cur = pre[cur] >> 1;             // 取出前驱余数
    }
    reverse(C.begin(), C.end());         // 翻转得到正序的 C

    // 高精度除法：计算 B = C / A
    string B;
    long long r = 0;                     // 当前余数
    for (int i = 0; i < C.size(); i++) {
        r = r * 10 + (C[i] - '0');
        B.push_back(r / A + '0');
        r %= A;
    }
    // 去掉 B 的前导零
    int pos = 0;
    while (pos + 1 < B.size() && B[pos] == '0') pos++;
    B = B.substr(pos);

    cout << B << " " << C << endl;
    return 0;
}
```
