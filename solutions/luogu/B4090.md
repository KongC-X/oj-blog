# B4090 [CSP-X2020 山东] 侠盗阿飞

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-11

**算法标签**：`贪心`、`2020`、`山东`、`枚举`、`排序`、`CSP-X 小学组`

## 题目描述

侠盗阿飞获得了一笔意外之财 $w$ 元钱，他想用这笔钱去帮助需要帮助的人。现在知道有 $n$ 个需要帮助的人以及他们每个人需要的钱数 $x_i$ 元（$i=0,1,2,3,\dots,n-1$），阿飞应该如何支配这笔钱使得能得到帮助的人数最多？

## 输入格式

第一行：两个数，阿飞的钱数 $w$，需要帮助的人数 $n$。

第二行：$n$ 个数，分别表示第 $i$ 个人需要的钱数 $x_i$。

## 输出格式

只有一个整数，表示阿飞最多能帮到的人数（最多的人数）。

## 样例

**样例输入 #1**
```
10 5
1 2 3 4 5```

**样例输出 #1**
```
4```

**样例输入 #2**
```
1000 10
20 20 150 110 180 50 200 140 120 200```

**样例输出 #2**
```
9```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：贪心
     * 思路：
     * 为了帮助尽可能多的人，应该优先帮助需要钱最少的人。
     * 1. 读入 w（总钱数）和 n（人数）。
     * 2. 读入 n 个需要钱数存入数组 a[]。
     * 3. 将 a 按升序排序。
     * 4. 从小到大累加，直到累加和 > w，则之前的人数就是答案。
     * 5. 输出答案。
     */
    long long w;        // w: 阿飞的钱数
    int n;              // n: 人数
    cin >> w >> n;

    long long a[505];   // 存储每个人需要的钱数
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    sort(a, a + n);     // 从小到大排序

    long long sum = 0;  // 当前累加的钱数
    int ans = 0;        // 能帮助的人数

    for (int i = 0; i < n; i++) {
        if (sum + a[i] <= w) {
            sum += a[i];
            ans++;
        } else {
            break;      // 再加就会超过，后面的人需求更大，无需继续
        }
    }

    cout << ans << endl;
    return 0;
}
```
