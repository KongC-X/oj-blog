# B4073 [CSP-X 2018] 快递费用

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-10

**算法标签**：`2018`、`山东`、`CSP-X 小学组`

## 题目描述

某快递公司按邮寄物品的重量收费，收费标准如下：

重量在 $500$ 克以内的，一律 $20$ 元；

超过 $500$ 克的，超重的部分按每 $500$ 克加收费用。超出的重量不足 $500$ 克的，按 $500$ 克计算。例如：$1020$ 克，超重 $520$ 克，需加收两份费用。

根据目的地的不同，加收的费用是不一样的。快递公司划分了五个目的地区域：

- 区域 $1$：每超重 $500$ 克加收 $4$ 元；

- 区域 $2$：每超重 $500$ 克加收 $6$ 元；

- 区域 $3$：每超重 $500$ 克加收 $9$ 元；

- 区域 $4$：每超重 $500$ 克加收 $10$ 元；

- 区域 $5$：每超重 $500$ 克加收 $17$ 元。

给出物品的重量 $w$ 和目的地区域编号 $n$，请你计算快递费用。

## 输入格式

一行，两个正整数 $w, n$。

## 输出格式

一行，一个整数，表示快递费用。

## 样例

**样例输入 #1**
```
1020 3```

**样例输出 #1**
```
38```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：简单分段计费
     * 思路：
     * 1. 重量 <= 500 克：收费 20 元。
     * 2. 重量 > 500 克：基础 20 元，超重部分每 500 克（不足按 500 算）加收对应区域费用。
     * 3. 区域单价：1~5 号区域分别对应 4,6,9,10,17 元。
     */
    long long w, n;        // w: 重量, n: 区域编号
    cin >> w >> n;

    int price[6] = {0, 4, 6, 9, 10, 17};  // 下标1~5对应区域单价

    long long ans = 20;    // 基础费用
    if (w > 500) {
        long long extra = w - 500;               // 超重部分
        long long cnt = (extra + 499) / 500;     // 需要加收的份数（向上取整）
        ans += cnt * price[n];
    }

    cout << ans << endl;
    return 0;
}
```
