# P6421 [COCI 2008/2009 #2] RESETO

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-26

**算法标签**：`模拟`、`数学`、`2008`、`COCI（克罗地亚）`

## 题目描述

埃拉托色尼筛法是一种著名的素数筛法，可以查找所有直至 $n$ 的素数。该算法的步骤是：
1. 写下 $2$ 到 $n$ 之间的所有整数（包括 $2$ 和 $n$）。
2. 找到尚未划掉的最小数，并将其命名为 $p$； 则 $p$ 是素数。
3. 划掉 $p$ 及其所有尚未划掉的倍数。
4. 如果尚有数未被划掉，请转到步骤 $2$。

编写一个程序，给定 $n$ 和 $k$，找出第 $k$ 个被划掉的整数。

## 输入格式

一行两个整数 $n$ 和 $k$，其具体含义请见题目描述。

## 输出格式

一行一个整数，表示第 $k$ 个被划掉的整数。

## 样例

**样例输入 #1**
```
7 3```

**样例输出 #1**
```
6```

**样例输入 #2**
```
15 12```

**样例输出 #2**
```
7```

**样例输入 #3**
```
10 7```

**样例输出 #3**
```
9```

## AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

bool f[1000010]; // 标记是否被划掉，false 表示未被划掉，true 表示已被划掉
int n, k;

int main() {
    cin >> n >> k; // n: 范围上限, k: 要找的第 k 个被划掉的数

    // 特判 0 和 1（虽然题目从 2 开始，但保留此习惯）
    f[0] = true;
    f[1] = true;

    int cnt = 0; // 记录已经划掉的数的个数

    // 循环所有的数，模拟埃拉托色尼筛法
    for (int i = 2; i <= n; i++) {
        // 如果当前数未被划掉，则它是素数，需要划掉它及其倍数
        if (!f[i]) {
            // 划掉素数 i 本身
            f[i] = true;
            cnt++;
            if (cnt == k) {
                cout << i << endl;
                return 0;
            }

            // 将 i 的所有倍数（从 2*i 开始）都划掉
            for (int j = 2 * i; j <= n; j += i) {
                // 如果没有被划掉过，则划掉它
                if (!f[j]) {
                    f[j] = true;
                    cnt++;
                    if (cnt == k) {
                        cout << j << endl;
                        return 0;
                    }
                }
            }
        }
    }

    return 0;
}
```
