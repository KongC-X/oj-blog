# P5724 【深基4.习5】求极差 / 最大跨度值 / 最大值和最小值的差

> **洛谷** | 入门 | C++14 | 提交时间: 2025-08-01

## 题目描述

给出 $n$ 和 $n$ 个整数 $a_i$，求这 $n$ 个整数中的极差是什么。极差的意思是一组数中的最大值减去最小值的差。

## 输入格式

第一行输入一个正整数 $n$，表示整数个数。

第二行输入 $n$ 个整数 $a_1,a_2 \dots a_n$，以空格隔开。

## 输出格式

输出一个整数，表示这 $n$ 个整数的极差。

## 样例

**样例输入 #1**
```
6
4 1 5 1 4 1```

**样例输出 #1**
```
4```

## AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int a[100001];
int main()
{
	int n;
	cin>>n;
    for(int i=1;i<=n;i++)
    {
    	scanf("%d",&a[i]);
	}
	sort(a+1,a+n+1);
	cout<<a[n]-a[1];
    return 0;
}

```
