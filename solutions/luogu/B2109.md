# B2109 统计数字字符个数

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-07

## 题目描述

输入一行字符，统计出其中数字字符的个数。

## 输入格式

一行字符串，总长度不超过 $255$。

## 输出格式

输出为 $1$ 行，输出字符串里面数字字符的个数。

## 样例

**样例输入 #1**
```
Today is 2021-03-27```

**样例输出 #1**
```
8```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main(){
    string s;
    getline(cin, s);//要用 getline
    int cnt = 0;
    for (int i = 0; i < s.size(); i++){
        if (s[i] <= '9' && s[i] >= '0')
            cnt++;
    }
    cout << cnt << endl;
    return 0;
}

```
