# B3907 [语言月赛 202312] NK

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-30

**算法标签**：`2023`、`O2优化`、`循环结构`、`语言月赛`

## 题目描述

给定两个正整数 $N, K$，请你统计符合以下条件的正整数 $x$ 的数量：

- $1 \leq x \leq N ^ N$。
- $(x \bmod K)$ 是 $N$ 的倍数。
- $x$ 的个位是 $N$。

$x \bmod K$ 代表 $x$ 除以 $K$ 的余数，例如 $7 \bmod 3 = 1$。

## 输入格式

输入一行两个整数 $N, K$。

## 输出格式

输出一行一个整数，代表符合题干中所有条件的 $x$ 的数量。

## 样例

**样例输入 #1**
```
4 6```

**样例输出 #1**
```
17```

**样例输入 #2**
```
7 6```

**样例输出 #2**
```
0```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】数学 + 周期模拟
     * 【核心思路】
     * 1. x 的个位是 N，所以 x = N + 10*t (t >= 0)。
     * 2. x 的范围：1 <= x <= N^N，所以 t 最大为 (N^N - N) / 10。
     * 3. 条件 (x mod K) % N == 0 只和 x mod K 有关。
     * 4. x 每次加 10，余数序列 x mod K 的周期为 T = K / gcd(K, 10)。
     * 5. 先模拟一个周期的余数，统计符合条件的个数 p。
     * 6. 总项数 c = (N^N - N) / 10 + 1。
     * 7. 完整周期数 f = c / T，剩余 r = c % T。
     * 8. 再模拟前 r 个余数，统计符合条件的个数 q。
     * 9. 答案 = f * p + q。
     *
     * 【时间复杂度】O(K / gcd(K, 10)) ≤ 10^6
     */

    int n, k;            // n: 个位数（1~9）, k: 模数
    cin >> n >> k;

    // 计算 n^n（n 很小，直接循环乘）
    long long a = 1;     // a: n^n，即 x 的上限
    for (int i = 1; i <= n; i++) {
        a *= n;
    }

    // 如果 a < n，说明没有符合个位是 n 的数（但实际 n>=1 时不会发生，保留判断）
    if (a < n) {
        cout << 0 << endl;
        return 0;
    }

    // 等差数列 x = n, n+10, n+20, ... 的总项数
    long long c = (a - n) / 10 + 1;   // c: 满足个位是 n 且 <= n^n 的数字个数

    // 计算余数序列的周期 T
    int d = __gcd(k, 10);    // d: k 和 10 的最大公约数
    int t = k / d;           // t: 余数序列周期长度

    // 模拟一个周期内的余数，统计满足条件的个数
    int p = 0;               // p: 一个周期内符合 (余数 % n == 0) 的个数
    int x = n % k;           // x: 当前余数（从第一项 n%k 开始）
    for (int i = 0; i < t; i++) {
        if (x % n == 0) {    // 检查 (x mod k) 是否是 n 的倍数
            p++;
        }
        x = (x + 10) % k;    // 下一个余数（公差为 10）
    }

    // 计算完整周期数和剩余个数
    long long f = c / t;     // f: 完整周期数
    long long r = c % t;     // r: 剩余项数

    // 模拟前 r 个余数，统计满足条件的个数
    int q = 0;               // q: 剩余部分中符合条件的个数
    x = n % k;               // 重新从第一项开始
    for (int i = 0; i < r; i++) {
        if (x % n == 0) {
            q++;
        }
        x = (x + 10) % k;
    }

    // 最终答案
    long long ans = f * p + q;
    cout << ans << endl;

    return 0;
}
```
