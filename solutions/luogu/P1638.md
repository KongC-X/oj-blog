# P1638 逛画展

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-07-24

**算法标签**：`二分`、`USACO`、`单调队列`、`队列`、`双指针 two-pointer`

## 题目描述

博览馆正在展出由世上最佳的 $m$ 位画家所画的图画。

游客在购买门票时必须说明两个数字，$x$ 和 $y$，代表他要看展览中的第 $x$ 幅至第 $y$ 幅画（包含 $x,y$）之间的所有图画，而门票的价钱就是一张图画一元。

Sept 希望入场后可以看到所有名师的图画。当然，他想最小化购买门票的价格。

请求出他购买门票时应选择的 $x,y$，数据保证一定有解。

若存在多组解，**输出 $x$ 最小的那组**。

## 输入格式

第一行两个整数 $n,m$，分别表示博览馆内的图画总数及这些图画是由多少位名师所绘画的。

第二行包含 $n$ 个整数 $a_i$，代表画第 $i$ 幅画的名师的编号。

## 输出格式

一行两个整数 $x,y$。

## 样例

**样例输入 #1**
```
12 5
2 5 3 1 3 2 4 1 1 5 4 3
```

**样例输出 #1**
```
2 7```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 1000010;          // n 最大 1e6，多开10
const int MAXM = 2010;             // m 最大 2000，多开10

int a[MAXN];                       // 存储每幅画对应的画家编号
int cnt[MAXM];                     // 当前窗口内每种画出现的次数
int n, m;                          // n:画的总数, m:画家的总数

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    /*
      思路：滑动窗口（双指针）
      维护一个窗口 [l, r]，保证窗口内包含所有 m 位画家的画作。
      r 不断右移扩展窗口，当窗口内包含所有画家时，尝试右移 l 缩小窗口。
      在缩小过程中记录最短的窗口长度，若长度相同，由于 l 从小到大遍历，
      第一次找到的最短窗口即为 x 最小的解。
      时间复杂度 O(n)，n=1e6 可行。
    */
    
    cin >> n >> m;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    
    int l = 1;                     // 窗口左边界
    int kind = 0;                  // 当前窗口内不同画家的数量
    int min_len = n + 1;           // 最短窗口长度，初始极大值
    int best_l = 1, best_r = n;    // 记录最优窗口的左右端点
    
    for (int r = 1; r <= n; r++) {
        // 将 a[r] 加入窗口
        if (cnt[a[r]] == 0) {      // 这种画之前没出现过
            kind++;
        }
        cnt[a[r]]++;
        
        // 如果窗口内包含了所有画家，尝试缩小左边界
        while (kind == m) {
            int len = r - l + 1;
            if (len < min_len) {   // 找到了更短的窗口
                min_len = len;
                best_l = l;
                best_r = r;
            }
            
            // 将 a[l] 移出窗口
            cnt[a[l]]--;
            if (cnt[a[l]] == 0) {  // 这种画在窗口中不再出现
                kind--;
            }
            l++;
        }
    }
    
    cout << best_l << " " << best_r << endl;
    return 0;
}
```
