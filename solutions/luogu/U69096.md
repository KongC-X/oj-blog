# U69096 前缀和的逆

> **洛谷** | 暂无评定 | C++14 | 提交时间: 2026-07-22

**算法标签**：`广东`、`前缀和`

## 题目背景

明明是个可爱的蓝孩子，最近~~她~~他学习了前缀和。

什么，你竟然不会前缀和？[让明明来教你！](https://oi-wiki.org/basic/prefix-sum/)

## 题目描述

于是按照套路，明明刷前缀和的题目刷累了，他瞅了瞅这道题，觉得很简单，就想请让你来帮忙做这一题：

有 $N$ 个正整数放到数组 $B$ 里，它是数组 $A$ 的前缀和数组，求 $A$ 数组。

## 输入格式

第一行 $1$ 个正整数 $N$。
第二行 $N$ 个正整数。

## 样例

**样例输入 #1**
```
6
2 10 20 25 30 43```

**样例输出 #1**
```
2 8 10 5 5 13```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：前缀和的逆运算（差分）
    // 已知前缀和数组 b，求原数组 a。
    // 公式：a[1] = b[1]，对于 i >= 2：a[i] = b[i] - b[i-1]。
    // 时间复杂度 O(N)。

    int n;                         // n: 数组长度
    cin >> n;

    int b[110];                    // 前缀和数组，多开10个
    for (int i = 1; i <= n; i++) {
        cin >> b[i];
    }

    // 输出原数组的第一个数
    cout << b[1];

    // 从第二个数开始，每个数 = 当前前缀和 - 前一个前缀和
    for (int i = 2; i <= n; i++) {
        cout << " " << b[i] - b[i - 1];
    }
    cout << endl;

    return 0;
}
```
