# B4451 [GESP202512 四级] 建造

> **洛谷** | 普及- | C++14 | 提交时间: 2026-01-03

**算法标签**：`匈牙利算法`、`排序算法`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1200>

## 题目描述

小 A 有一张 $M$ 行 $N$ 列的地形图，其中第 $i$ 行第 $j$ 列的数字 $a_{ij}$ 代表坐标 $(i, j)$ 的海拔高度。

停机坪为一个 $3 \times 3$ 的区域，且内部所有 $9$ 个点的最大高度和最小高度之差不超过 $H$。

小 A 想请你计算出，在所有适合建造停机坪的区域中，区域内部 $9$ 个点海拔之和最大是多少。

## 输入格式

第一行三个正整数 $M, N, H$，含义如题面所示。

之后 $M$ 行，第 $i$ 行包含 $N$ 个整数 $a_{i1}, a_{i2}, \dots, a_{iN}$，代表坐标 $(i, j)$ 的高度。

数据保证总存在一个适合建造停机坪的区域。

## 输出格式

输出一行，代表最大的海拔之和。

## 样例

**样例输入 #1**
```
5 5 3
5 5 5 5 5
5 1 5 1 5
5 5 5 5 5
5 2 5 2 5
3 5 5 5 2```

**样例输出 #1**
```
40```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int a[1010][1010];

int main() {
    int M, N, H;
    cin >> M >> N >> H;
    for (int i = 1; i <= M; ++i) {
        for (int j = 1; j <= N; ++j) {
            scanf("%d", &a[i][j]);
        }
    }
    int ans = 0;
    for (int i = 1; i <= M - 2; ++i) {
        for (int j = 1; j <= N - 2; ++j) {
            int min = 100010;
            int max = 0;
            int sum = 0;
            for (int dx = 0; dx < 3; ++dx) {
                for (int dy = 0; dy < 3; ++dy) {
                    int val = a[i + dx][j + dy];
                    sum += val;
                    if (val < min) min = val;
                    if (val > max) max = val;
                }
            }
            if (max - min <= H && sum > ans) {
                ans = sum;
            }
        }
    }
    cout << ans << endl;
    return 0;
}
```
