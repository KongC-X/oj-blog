# B4179 [厦门小学生 C++ 2024] 战线巡逻

> **洛谷** | 普及- | C++14 | 提交时间: 2026-07-16

**算法标签**：`贪心`、`2024`、`福建`、`排序`、`差分`、`科创活动`

## 题目背景

本试题为 2024 年厦门市小学生 C++ 语言**复赛**试题，数据为洛谷自造。

**初赛**为笔试。

## 题目描述

在一条战线中，有 $n$ 个需要巡逻的点，为了完成巡逻任务，指挥部计划指派 $k$ 个哨兵，每个哨兵可以自由选择起始位置 $i$，不消耗体力。但哨兵每移动一个单位距离（从 $i$ 到 $i+1$ 或 $i-1$），则消耗 $1$ 点体力。

指挥部的目标是将 $k$ 个哨兵合理部署到战线上，使得：
- 所有需要巡逻的点都由至少一名哨兵巡逻过。
- 哨兵总体力消耗的最小。

请你设计一个合理的方案，计算最小的体力消耗，并输出结果。

## 输入格式

- 第一行，两个整数，分别是 $k$ 和 $n$；
- 第二行，$n$ 个整数，战线中必须巡逻的坐标 $a_i$。

## 样例

**样例输入 #1**
```
3 4
-10 -1 1 14```

**样例输出 #1**
```
2```

**样例输入 #2**
```
4 9
-11 -3 0 9 -100 2 17 20 1```

**样例输出 #2**
```
15```

**样例输入 #3**
```
5 3
-1000 100 200```

**样例输出 #3**
```
0```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int a[100010];                       // 坐标数组
int d[100010];                       // 相邻坐标差值数组

// 从大到小排序
bool cmp(int x, int y) {
    return x > y;
}

int main() {
    /*
        思路：
        1. 问题本质：k个哨兵覆盖n个点，每个哨兵覆盖一段连续的区间，
           总消耗 = 所有区间长度之和。
           因为哨兵初始位置可以任意选，所以最优策略是：
           - 将n个点从小到大排序。
           - 把整段（最小点到最大点）切分成k段，每段由一名哨兵负责。
           - 切分的位置就是相邻两点之间最大的k-1个间隙。
           
        2. 算法步骤：
           - 如果 k >= n，一个哨兵守一个点，消耗为0。
           - 否则：
             a) 将坐标排序。
             b) 计算相邻坐标之间的间隙 d[i] = a[i+1] - a[i]。
             c) 将间隙从大到小排序。
             d) 总消耗 = 总跨度(末坐标 - 首坐标) - 前k-1个最大间隙之和。
           
        3. 时间复杂度：O(n log n)，主要花在排序上。
    */

    int k, n;                      // k:哨兵数, n:点数
    cin >> k >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    // 如果哨兵数不少于点数，消耗为0
    if (k >= n) {
        cout << 0 << endl;
        return 0;
    }

    // 坐标从小到大排序
    sort(a, a + n);

    // 计算相邻间隙
    for (int i = 0; i < n - 1; i++) {
        d[i] = a[i + 1] - a[i];
    }

    // 间隙从大到小排序
    sort(d, d + n - 1, cmp);

    // 总跨度
    long long t = a[n - 1] - a[0];   // 首尾距离

    // 去掉前 k-1 个最大的间隙（在这些位置分段，省去走这些间隙的体力）
    long long s = 0;
    for (int i = 0; i < k - 1; i++) {
        s += d[i];
    }

    cout << t - s << endl;
    return 0;
}
```
