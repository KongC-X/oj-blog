## 题目描述

首先所有的灯都是关的（注意是关！），编号为 $1$ 的人走过来，把是 $1$ 的倍数的灯全部打开，编号为 $2$ 的人把是 $2$ 的倍数的灯全部关上，编号为 $3$ 的人又把是 $3$ 的倍数的灯开的关上，关的开起来……直到第 $N$ 个人为止。

给定 $N$，求 $N$ 轮之后，还有哪几盏是开着的。

## 输入格式

一个数 $N$，表示灯的个数和操作的轮数。

## 输出格式

若干数，表示开着的电灯编号。

## 样例

**样例输入 #1**
```
5```

**样例输出 #1**
```
1 4```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long n;                     // n: 灯的个数
    cin >> n;

    // ---- 思路 ----
    // 第 i 盏灯被操作的次数等于 i 的因子个数。
    // 最终开着的灯其因子个数为奇数，即 i 是完全平方数。
    // 输出 1..n 中的所有完全平方数。

    for (long long i = 1; i * i <= n; i++) {
        cout << i * i;
        if ((i + 1) * (i + 1) <= n) cout << ' ';
    }
    cout << '\n';

    return 0;
}
```
