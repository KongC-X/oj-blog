# P8814 [CSP-J 2022] 解密

> **洛谷** | 普及- | C++14 | 提交时间: 2025-09-15

**算法标签**：`递归`、`后缀数组`、`回文串`、`入门模拟`

## 题目描述

给定一个正整数 $k$，有 $k$ 次询问，每次给定三个正整数 $n_i, e_i, d_i$，求两个正整数 $p_i, q_i$，使 $n_i = p_i \times q_i$、$e_i \times d_i = (p_i - 1)(q_i - 1) + 1$。

## 输入格式

第一行一个正整数 $k$，表示有 $k$ 次询问。

接下来 $k$ 行，第 $i$ 行三个正整数 $n_i, d_i, e_i$。

## 输出格式

输出 $k$ 行，每行两个正整数 $p_i, q_i$ 表示答案。

为使输出统一，你应当保证 $p_i \leq q_i$。

如果无解，请输出 `NO`。

## 样例

**样例输入 #1**
```
10
770 77 5
633 1 211
545 1 499
683 3 227
858 3 257
723 37 13
572 26 11
867 17 17
829 3 263
528 4 109
```

**样例输出 #1**
```
2 385
NO
NO
NO
11 78
3 241
2 286
NO
NO
6 88
```

## AC 代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

long long n,d,e,t;//int 会爆掉
int main(){
	scanf("%d",&t);
	while(t--){//多组数据
		scanf("%lld %lld %lld",&n,&d,&e);
        // q + p = n − ed + 2
		long long delta=(n - e * d + 2) * (n - e * d + 2) - 4 * n;
		if(delta < 0){//特判解为虚数的情况
			printf("NO\n");
			continue;
		}
		long long p=1.0 * ((n - e * d + 2) - sqrt(delta)) / 2;
        long long q=1.0 * ((n - e * d + 2) + sqrt(delta)) / 2;
		if(p > 0 && q > 0 && p * q == n && e * d == (p - 1) * (q - 1) + 1){
            printf("%lld %lld\n",p,q); //由于精度原因，需要再次判断题目条件
        } else {
            printf("NO\n");
        }
	}
	return 0;
}

```
