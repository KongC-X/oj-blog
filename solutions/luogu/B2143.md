# B2143 进制转换

> **洛谷** | 普及- | C++14 | 提交时间: 2026-07-15

**算法标签**：`函数与递归`

## 题目描述

用递归算法将一个十进制整数 $X$（$1 \le X \le 10^9$）转换成任意进制数 $M$（$2\le M\le16$，$M$ 为整数）。

## 输入格式

一行两个数，第一个十进制整数 $X$，第二个为进制 $M$。

## 样例

**样例输入 #1**
```
31 16 ```

**样例输出 #1**
```
1F```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 递归函数：将 x 转换为 m 进制并输出
void convert(int x, int m) {
    if (x == 0) return;              // 递归边界：x为0时结束
    convert(x / m, m);               // 先处理高位
    int r = x % m;                   // 当前位的值
    if (r < 10) cout << r;           // 0~9 直接输出数字
    else        cout << char('A' + r - 10); // 10~15 转为字母 A~F
}

int main() {
    int X, M;                        // X: 十进制数, M: 目标进制
    cin >> X >> M;
    convert(X, M);
    cout << endl;
    return 0;
}
```
