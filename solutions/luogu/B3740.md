# B3740 [信息与未来 2018] 棋盘游戏

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-04-17

**算法标签**：`图论`、`二分`、`博弈论`、`CDQ分治`

## 题目描述

给定一个十进制数 $x$，将它转换为二进制字符串并在高位填 $0$ 以补足 $16$ 位，就得到了
一个长度为 $16$ 的 $01$ 字符串，我们用这个字符串表示 $4 × 4$ 的棋盘，按从左到右、从上到下的顺序将 $0$（白子）、$1$（黑子）放入棋盘。

例如，$(447)_{10} = (0000 0001 1011 1111)_2$，按顺序填入棋盘（$0$ 白子、$1$ 黑子），得到如下棋盘（左边棋盘）：

![](https://cdn.luogu.com.cn/upload/image_hosting/vyma7pie.png)

我们现在可以交换棋盘中**相邻**（共享一条边的两个格子相邻，因此一个格子至多有 $4$ 个相邻的格子）的黑色和白色棋子。从左图的棋盘变为全部白子在上、全部黑子在下（右边棋盘所示）的棋盘，至少需要 $3$ 步。

对于给定的棋盘（保证棋盘中恰好有 $8$ 个白子和 $8$ 个黑子），求把棋盘变为全部白子在上、全部黑子在下最少的交换步数。

## 输入格式

输入一行一个整数 $x$，为十进制表示下的棋盘。

## 输出格式

输出一行一个整数，最少需要交换的步数。

## 样例

**样例输入 #1**
```
447```

**样例输出 #1**
```
3```

**样例输入 #2**
```
42405```

**样例输出 #2**
```
8```

#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 这道题可以转化为：将初始棋盘中的8个白子（0）移动到目标位置（第1、2行，即索引0~7）的最少总步数。
// 由于棋子相同，我们只需把初始白子所在位置的索引排序，与目标位置索引0~7一一对应，
// 计算每个白子移动到对应目标位置的曼哈顿距离（行差+列差），再求和即可。

// 数学上有一个结论：如果两个序列都是从小到大排序的，那么对应项之差的绝对值之和是最小的（一维情况下）。
// 对于二维网格，曼哈顿距离可以分解为行和列独立的一维问题，所以同样适用。
// 我们的 pos 数组是按扫描顺序（从左到右、从上到下）自然从小到大排序的（因为索引 0~15 本身就是从小到大）。
// 目标位置 0~7 也是从小到大。因此直接按顺序一一对应（第 i 个白子去第 i 个目标位置），就能得到最小的总移动步数。

// 举个简单例子
// 假设棋盘 2x2，有 2 个白子要移到上半（前两个格子）。初始白子在索引 2 和 3（下半行）。目标位置是 0 和 1。
// 白子位置：[2, 3]（已排序）
// 目标位置：[0, 1]（已排序）
// 按顺序对应：2→0（距离2），3→1（距离2），总步数=4。
// 如果交换对应：2→1（距离1），3→0（距离3），总步数=4，一样大。实际上任意匹配总和相同，但一维情况下顺序对应是最优的，且总距离与匹配方式无关当曼哈顿距离可分解时）。这里总步数固定为 4。

// int main() {
//     int x;
//     cin >> x;

//     int pos[8];   // 存白子（0）的位置索引 0~15
//     int cnt = 0;  // 已找到的白子数量

//     // 从高位到低位检查16位二进制，索引0对应最高位（左上角）
//     for (int i = 0; i < 16; i++) {
//         // 位权：第 i 位对应 2^(15-i)
//         int bit = (x >> (15 - i)) & 1;
//         if (bit == 0) {            // 白子
//             pos[cnt] = i;
//             cnt++;
//         }
//     }

//     // 目标位置：0~7（上半棋盘）
//     int ans = 0;
//     for (int i = 0; i < 8; i++) {
//         int r1 = pos[i] / 4;       // 当前白子行
//         int c1 = pos[i] % 4;       // 当前白子列
//         int r2 = i / 4;            // 目标行（因为目标索引就是 i）
//         int c2 = i % 4;            // 目标列
//         // 曼哈顿距离 = 行差 + 列差
//         ans += abs(r1 - r2) + abs(c1 - c2); // 累加即得所有白子移到目标位置的最少总步数。
//     }

//     // 这样，我们就不需要模拟交换过程，直接用数学方法算出了最少步数。
//     // 这也是这类“移动棋子到目标区域”问题的经典解法。
//     cout << ans << endl;

// 上面的方法不能拿满分，不能简单按顺序对应，需要找到白子位置与目标位置之间的最小总曼哈顿距离匹配。
// 因为数据规模小，我们可以枚举目标位置的全排列，计算每种匹配的总距离，取最小值。

int pos[8];       // 白子所在位置索引 (0~15)
int target[8] = {0, 1, 2, 3, 4, 5, 6, 7}; // 目标位置
int used[8];      // 标记目标位置是否已被分配
int minSum;       // 最小总距离

// 计算曼哈顿距离
int dist(int p, int t) {
    int r1 = p / 4, c1 = p % 4;
    int r2 = t / 4, c2 = t % 4;
    return abs(r1 - r2) + abs(c1 - c2);
}

// 递归枚举全排列，idx为当前要分配的白子下标，sum为当前累加距离
void dfs(int idx, int sum) {
    if (idx == 8) {
        if (sum < minSum) minSum = sum;
        return;
    }
    for (int i = 0; i < 8; i++) {
        if (!used[i]) {
            used[i] = 1;
            dfs(idx + 1, sum + dist(pos[idx], target[i]));
            used[i] = 0;
        }
    }
}

int main() {
    int x;
    cin >> x;

    // 提取白子位置（bit为0）
    int cnt = 0;
    for (int i = 0; i < 16; i++) {
        if (((x >> (15 - i)) & 1) == 0) { // 白子
            pos[cnt++] = i;
        }
    }

    minSum = 1e9;
    dfs(0, 0);
    cout << minSum << endl;

    return 0;
}
