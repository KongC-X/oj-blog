# B3685 [语言月赛 202212] 计算

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-28

**算法标签**：`2022`、`O2优化`、`顺序结构`、`语言月赛`

## 题目描述

给定一个 $3$ 位整数 $n$，计算：
1. $n$ 的各位数字之和；
2. $n$ 的各位数字之和的平方；
3. $n$ 的各位数字之和的立方；

例如，当这个三位数是 $123$ 时：

1. 各位数字之和为：$1+2+3=6$；
2. 各位数字之和的平方为：$(1+2+3)^2=(1+2+3)\times (1+2+3)=36$；
3. 各位数字之和的立方为：$(1+2+3)^3=(1+2+3)\times (1+2+3)\times (1+2+3)=216$。

## 输入格式

输入只有一行一个三位整数 $n$。

## 输出格式

输出共**三行**，第一行为各位数字之和，第二行为各位数字之和的平方，第三行为各位数字之和的立方。

## 样例

**样例输入 #1**
```
817```

**样例输出 #1**
```
16
256
4096
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3685 [语言月赛202212] 计算
     * 题意：给定三位整数 n，求各位数字之和 s，输出 s, s^2, s^3。
     */
    int n;
    cin >> n;
    int a = n / 100;          // 百位
    int b = (n / 10) % 10;    // 十位
    int c = n % 10;           // 个位
    int s = a + b + c;
    cout << s << endl;
    cout << s * s << endl;
    cout << s * s * s << endl;
    return 0;
}
```
