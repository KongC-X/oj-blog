# P9586 「MXOI Round 2」游戏

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-31

**算法标签**：`模拟`、`数学`、`贪心`、`洛谷原创`、`O2优化`、`洛谷月赛`

## 题目描述

小 C 和小 D 正在玩一款蒸蒸日上的游戏。

这款游戏共有 $3$ 种手牌：杀、闪、斩。他们的用途分别如下：

- 杀：对对方使用，对方需要使用一张**闪**，否则对方输掉游戏；**或**回应对方的**斩**；
- 闪：回应对方的**杀**；
- 斩：对对方使用，对方需要使用一张**杀**，否则对方输掉游戏。

玩家在每使用一张牌后，都需要弃掉该使用的牌。

从小 C 开始，每个回合依次属于小 C 和小 D。在玩家的回合内，该玩家可以出**任意**张**杀**和**斩**，对方需要做出对应的回应。当然，玩家也可以不出牌，直接进入对方的回合。

现在，小 C 共有 $c_1$ 张杀、$c_2$ 张闪、$c_3$ 张斩，小 D 共有 $d_1$ 张杀、$d_2$ 张闪、$d_3$ 张斩，**双方都知道对方的手牌**。你需要求出，双方在都进行最优策略的情况下，游戏的结果会如何。

## 输入格式

**本题有多组测试数据。**

第一行输入一个整数 $T$，表示测试数据组数。

接下来依次输入每组测试数据，对于每组测试数据，输入一行六个整数 $c_1,c_2,c_3,d_1,d_2,d_3$。

## 输出格式

对于每组测试数据，输出一行：

- 若双方在都进行最优策略的情况下，小 C 可以获胜，则输出 `C`；
- 若双方在都进行最优策略的情况下，小 D 可以获胜，则输出 `D`；
- 若双方在都进行最优策略的情况下，游戏会平局，即谁也无法获胜，则输出 `E`。

## 样例

**样例输入 #1**
```
3
3 1 4 1 5 9
1 1 4 5 1 4
5 2 1 2 6 3```

**样例输出 #1**
```
C
D
E```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    /*
     * 题目：P9586 「MXOI Round 2」游戏
     * 题意：小C先手，双方手牌为杀、闪、斩。杀需闪回应，斩需杀回应。
     *       每回合可出任意张杀和斩，对方必须回应，否则攻击方胜。
     *       求最优策略下胜负结果（C/D/E）。
     *
     * 核心思路（博弈分析）：
     * 1. 小C先手，若他有某种攻击牌数量严格大于对方对应防御牌数量，
     *    则他可以直接出该种牌全部，立即获胜。
     *    即：c1 > d2（杀>闪） 或 c3 > d1（斩>杀） → C胜。
     *
     * 2. 若小C不能直接赢，则他必须考虑能否阻止小D获胜。
     *    小D获胜方式只有两种：
     *       a) 用斩赢：若 d3 > c1，则小D斩数 > 小C杀数，小C无法防御，
     *          小D可以在自己回合直接出斩获胜 → D胜。
     *       b) 用杀赢：若 d1 > c2，则小D杀数 > 小C闪数。
     *          但小C可以通过出斩来消耗小D的杀，从而削弱小D的杀攻击。
     *          小C最多能消耗的杀数为 c3（因为出斩需要消耗自己的斩）。
     *          如果 c3 >= d1 - c2，则小C能够将小D的杀数消耗至 ≤ c2，
     *          从而小D无法用杀获胜，此时双方都无法直接赢，平局 E。
     *          否则，小D杀数仍大于小C闪数，小D胜。
     *
     * 3. 其他情况（小D既不能斩赢也不能杀赢，或小C能阻止杀赢），平局 E。
     *
     * 时间复杂度：O(T)，T ≤ 1e5
     */

    int T;
    cin >> T;
    while (T--) {
        long long c1, c2, c3, d1, d2, d3;
        cin >> c1 >> c2 >> c3 >> d1 >> d2 >> d3;

        // 小C直接获胜
        if (c1 > d2 || c3 > d1) {
            cout << "C\n";
            continue;
        }

        // 小D用斩获胜（无法阻止）
        if (d3 > c1) {
            cout << "D\n";
            continue;
        }

        // 小D用杀获胜，小C尝试用斩消耗
        if (d1 > c2) {
            if (c3 >= d1 - c2) {
                cout << "E\n";   // 小C消耗足够，平局
            } else {
                cout << "D\n";   // 小C消耗不足，小D胜
            }
            continue;
        }

        // 小D也无法获胜，平局
        cout << "E\n";
    }

    return 0;
}
```
