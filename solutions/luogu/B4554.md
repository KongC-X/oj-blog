# B4554 [GESP202606 二级] 菱形

> **洛谷** | 普及- | C++14 | 提交时间: 2026-06-30

## 题目描述

给定正整数 $n$，在 $(2n - 1) \times (2n - 1)$ 个网格的画布中，使用字符画一个边长为 $n$ 个网格的菱形。其中，空白网格使用 $\cdot$ 表示，菱形边所在的网格用 $+$ 表示。

例如当 $n = 3$ 时，图形如下：

```
..+..
.+.+.
+...+
.+.+.
..+..
```

## 输入格式

输入一个正整数 $n$；

## 输出格式

输出 $2n - 1$ 行，表示按要求画的菱形。

## 样例

**样例输入 #1**
```
4```

**样例输出 #1**
```
...+...
..+.+..
.+...+.
+.....+
.+...+.
..+.+..
...+...```

## AC 代码

```cpp
#include <iostream>
#include <cmath>
using namespace std;

int main() {
    int n;                            // n: 菱形边长
    cin >> n;

    int sz = 2 * n - 1;               // 画布大小（行数和列数）
    int c = n - 1;                    // 中心点的行/列索引（从0开始）

    // 逐行输出
    for (int i = 0; i < sz; i++) {
        for (int j = 0; j < sz; j++) {
            // 判断当前点是否在菱形的四条边上
            // 菱形边上的点满足：曼哈顿距离 |i - c| + |j - c| == c (即 n-1)
            if (abs(i - c) + abs(j - c) == c) {
                cout << "+";
            } else {
                cout << ".";
            }
        }
        cout << endl;
    }

    return 0;
}
```
