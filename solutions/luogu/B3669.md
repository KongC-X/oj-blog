# B3669 [语言月赛 202210] 购物节

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-26

**算法标签**：`2022`、`O2优化`、`分支结构`、`语言月赛`

## 题目描述

一个商店有两种包装的本子，第一种是单本装，一本 $x$ 元，第二种是十本优惠装，一套 $y$ 元。

现在商店推出“双十一”活动，每种包装的本子都优惠 1 元，优惠后价格为单本装 $x - 1$ 元，十本装为 $y - 1$ 元。

小明想要买**恰好** $n$ 个本子，请问**至少**需要花多少钱？

注：这里的“恰好”的意义为，不能买少于 $n$ 个本子，也不能买超过 $n$ 个本子。

## 输入格式

共一行，包括三个整数 $x,y,n$，分别表示单本装的价格，十本优惠装的价格，小明需要的本子的数量。

## 输出格式

共一个数，表示小明购买 $n$ 个本子至少需要花费的钱的数目。

## 样例

**样例输入 #1**
```
10 80 10```

**样例输出 #1**
```
79```

**样例输入 #2**
```
10 80 11```

**样例输出 #2**
```
88```

**样例输入 #3**
```
10 80 1```

**样例输出 #3**
```
9```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3669 [语言月赛 202210] 购物节
     * 题意：单本装优惠后 a 元，十本装优惠后 b 元，买恰好 n 本，求最小花费。
     * 思路：设买 t 套十本装（0≤t≤n/10），则花费 f(t) = t*b + (n-10t)*a = n*a + t*(b-10a)。
     *       这是 t 的线性函数，极值在端点取得，因此只需比较 t=0 和 t=n/10（向下取整）两种情况。
     *       答案 = min(n*a, (n/10)*b + (n%10)*a)。
     *       注意用 long long 防止溢出。
     */
    long long x, y, n;
    cin >> x >> y >> n;
    long long a = x - 1;       // 优惠后单本价
    long long b = y - 1;       // 优惠后十本价

    long long ans1 = a * n;                           // 全部买单价
    long long ans2 = (n / 10) * b + (n % 10) * a;    // 尽量买十本装，剩余买单本

    cout << min(ans1, ans2) << endl;
    return 0;
}
```
