# B2141 确定进制

> **洛谷** | 普及- | C++14 | 提交时间: 2026-07-15

**算法标签**：`函数与递归`

## 题目描述

$6 \times 9=42$ 对于十进制来说是错误的，但是对于 $13$ 进制来说是正确的。即 $6_{(13)} \times 9_{(13)}=42_{(13)}$，而 $42_{(13)}=4 \times 13^1+2 \times 13^0=54_{(10)}$。

你的任务是写一段程序读入三个整数 $p,q$ 和 $r$，然后确定一个进制 $B(2 \le B \le 16)$ 使得 $p\times q=r$。如果 $B$ 有很多选择，则输出最小的一个。

例如：$p=11,q=11,r=121$，则有 $11_{(3)} \times 11_{(3)}=121_{(3)}$，因为 $11_{(3)}=1 \times 3^1+1 \times 3^0=4_{(10)}$ 和 $121_{(3)}=1 \times 3^2+2 \times 3^1+1 \times 3^0=16_{(10)}$。对于进制 $10,$ 有 $11_{(10)} \times 11_{(10)}=121_{(10)}$。这种情况下，应该输出 $3$。如果没有合适的进制，则输出 $0$。

## 输入格式

一行，包含三个整数 $p,q,r$，相邻两个整数之间用单个空格隔开。

## 输出格式

一个整数：即使得 $p \times q=r$ 成立的最小的 $B$。如果没有合适的 $B$，则输出 $0$。

## 样例

**样例输入 #1**
```
6 9 42```

**样例输出 #1**
```
13```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 函数：将字符串 s 按进制 B 转换为十进制整数（long long）。若出现非法数字（>= B）则返回 -1。
long long toDec(const string &s, int B) {
    long long res = 0;
    for (int i = 0; i < s.size(); i++) {
        int d = s[i] - '0';
        if (d >= B) return -1;
        res = res * B + d;
    }
    return res;
}

int main() {
    string p, q, r;
    cin >> p >> q >> r;

    // 枚举进制 B（2~16），找最小的合法进制
    for (int B = 2; B <= 16; B++) {
        long long x = toDec(p, B);
        long long y = toDec(q, B);
        long long z = toDec(r, B);
        if (x != -1 && y != -1 && z != -1 && x * y == z) {
            cout << B << endl;
            return 0;
        }
    }

    // 没有合适的进制，输出 0
    cout << 0 << endl;
    return 0;
}
```
