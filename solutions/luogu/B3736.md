# B3736 [信息与未来 2018] 最大公约数

> **洛谷** | 入门 | C++14 | 提交时间: 2026-04-11

**算法标签**：`递归`、`博弈论`、`CDQ分治`

## 题目描述

输入三个正整数 $x,y,z$，求它们的最大公约数（Greatest Common Divisor）$g$：最大的正整数 $g ≥1$，满足 $x,y,z$ 都是 $g$ 的倍数，即 $(x \bmod g) = (y \bmod g) = (z \bmod g) = 0$。

## 输入格式

输入一行三个正整数 $x,y,z$。

## 输出格式

输出一行一个整数 $g$，表示 $x,y,z$ 的最大公约数。

## 样例

**样例输入 #1**
```
12 34 56```

**样例输出 #1**
```
2```

**样例输入 #2**
```
28 70 28```

**样例输出 #2**
```
14```

## AC 代码

```cpp
#include <iostream>
#include <algorithm>   // 使用 __gcd 或自己实现 gcd
using namespace std;

// 欧几里得算法求最大公约数
int gcd(int a, int b) {
    while (b != 0) {
        int r = a % b;
        a = b;
        b = r;
    }
    return a;
}

int main() {
    int x, y, z;
    cin >> x >> y >> z;
    // 先求 x 和 y 的 gcd，再与 z 求 gcd
    int g = gcd(gcd(x, y), z);
    cout << g << endl;
    return 0;
}
```
