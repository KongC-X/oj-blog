# P1923 【深基9.例4】求第 k 小的数

> **洛谷** | 普及- | C++14 | 提交时间: 2025-08-26

**算法标签**：`栈`

## 题目描述

输入 $n$ 个数字 $a_i$，输出这些数字中第 $k$ 小的数。最小的数是第 $0$ 小。

请尽量不要使用 `nth_element` 来写本题，因为本题的重点在于练习分治算法。

## 输入格式

第一行有两个整数，分别表示 $n$ 和 $k$。

第二行有 $n$ 个整数，第 $i$ 个数表示 $a_i$。

## 输出格式

一个整数，表示第 $k$ 小的数。

## 样例

**样例输入 #1**
```
5 1
4 3 2 1 5
```

**样例输出 #1**
```
2
```

## AC 代码

```cpp
#include<bits/stdc++.h> 
#include<iostream> 
using namespace std;

int a[5000010];

int main() {
	int n,k;
	cin >> n >> k;
	for(int i = 0;i < n;i++) {
		scanf("%d", &a[i]);
	}
	sort(a,a+n);
	cout << a[k] << endl;
}
```
