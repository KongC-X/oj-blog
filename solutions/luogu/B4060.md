# B4060 位运算 1

> **洛谷** | 入门 | C++14 | 提交时间: 2026-09-27

## 题目描述

基本的位运算共 $6$ 种，分别为按位与、按位或、按位异或、按位取反、左移和右移。

现要求：输入三个正整数 $a,b,k$，请你输出 $6$ 行整数，每行整数分别为：
- $a$ 按位与 $b$；
- $a$ 按位或 $b$；
- $a$ 按位异或 $b$；
- $a$ 按位取反；
- $a$ 左移 $k$ 位；
- $a$ 右移 $k$ 位；

的值。

## 输入格式

输入 $3$ 个正整数 $a,b,k$。

## 输出格式

输出 $6$ 行整数，含义如题目所示。

## 样例

**样例输入 #1**
```
15 12 2```

**样例输出 #1**
```
12
15
3
-16
60
3```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    /*
     * 题目：B4060 位运算 1
     * 题意：输入 a, b, k，输出六种位运算的结果：
     *       1. a & b  （按位与）
     *       2. a | b  （按位或）
     *       3. a ^ b  （按位异或）
     *       4. ~a     （按位取反）
     *       5. a << k （左移 k 位）
     *       6. a >> k （右移 k 位）
     *
     * 数据范围：1 ≤ a, b ≤ 2^15，1 ≤ k ≤ 15，使用 int 即可。
     */
    int a, b, k;
    cin >> a >> b >> k;

    cout << (a & b) << endl;    // 按位与
    cout << (a | b) << endl;    // 按位或
    cout << (a ^ b) << endl;    // 按位异或
    cout << (~a) << endl;       // 按位取反
    cout << (a << k) << endl;   // 左移
    cout << (a >> k) << endl;   // 右移

    return 0;
}
```
