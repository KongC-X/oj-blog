# B4461 [海淀区入门组 2025] 制作饮品

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-20

**算法标签**：`数学`、`2025`、`北京`、`小学活动`

## 题目描述

圣诞节快到了，有 $n$ 名同学参加一项联欢活动，为了丰富活动内容，组织者增加了一个自制饮品的环节。在这个环节中，活动策划者准备了一些原料，要求每名同学恰好制作 $x$ 杯指定规格的饮品。你的任务是根据给定的原料数量，确定 $x$ 的最大值。

活动策划者准备的原料有：$k$ 瓶饮料，每瓶饮料 $l$ 毫升；$c$ 个柠檬，每个柠檬切成了 $d$ 片；$p$ 克食盐。

饮品的指定规格为：每杯饮品包含 $v_1$ 毫升饮料，$1$ 片柠檬和 $p_1$ 克食盐。

## 输入格式

在一行中给出 $8$ 个正整数 $n$、$k$、$l$、$c$、$d$、$p$、$v_1$、$p_1$，这些数均为不小于 $1$ 且不超过 $1000$ 的正整数，两两之间用一个空格分隔。

## 输出格式

输出仅有一个整数，表示每个人可以制作的饮品数量的最大值。

## 样例

**样例输入 #1**
```
3 4 5 10 8 100 3 1```

**样例输出 #1**
```
2```

**样例输入 #2**
```
5 100 10 1 19 90 4 3```

**样例输出 #2**
```
3```

**样例输入 #3**
```
10 100 1000 25 23 1 50 1```

**样例输出 #3**
```
0```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n, k, l, c, d, p, v1, p1;
    cin >> n >> k >> l >> c >> d >> p >> v1 >> p1;

    // 计算每种原料能做的总杯数，取最小值，再除以人数
    int ans = min({k * l / v1, c * d, p / p1}) / n;
    cout << ans << endl;

    return 0;
}
```
