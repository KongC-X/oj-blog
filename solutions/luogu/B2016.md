# B2016 浮点数向零舍入

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-24

## 题目描述

输入一个双精度浮点数，将其向零舍入到整数。说明：向零舍入的含义是，正数向下舍入，负数向上舍入。

## 输入格式

一个双精度浮点数 $x$。

## 输出格式

一个整数，即向零舍入到整数的结果。

## 样例

**样例输入 #1**
```
2.3```

**样例输出 #1**
```
2```

## AC 代码

```cpp
#include<iostream>
using namespace std;
int main(){
	long long x;
	cin>>x;
	cout<<x<<endl;
	return 0;
}

```
