# B2129 最大数 max(x,y,z)

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-13

**算法标签**：`函数与递归`

## 题目描述

已知：

$m=\dfrac{\max(a,b,c)}{\max(a+b,b,c) \times \max(a,b,b+c)}$

输入三个整数 $a$，$b$，$c$，求 $m$。

把求三个数的最大数 $\max(x,y,z)$ 分别定义成函数和过程来做。

## 输入格式

输入只有一个行三个整数，分别为 $a, b, c$。

## 输出格式

输出一行一个小数，为答案，保留三位小数。

## 样例

**样例输入 #1**
```
1 2 3```

**样例输出 #1**
```
0.200```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 函数：返回三个整数中的最大值
int max3(int x, int y, int z) {
    int m = x;                    // m 记录当前最大值
    if (y > m) m = y;
    if (z > m) m = z;
    return m;
}

int main() {
    int a, b, c;                  // a,b,c: 输入的三个整数
    cin >> a >> b >> c;

    // 计算分子：max(a,b,c)
    int fz = max3(a, b, c);

    // 计算分母的两个因子
    int fm1 = max3(a + b, b, c);   // max(a+b, b, c)
    int fm2 = max3(a, b, b + c);   // max(a, b, b+c)

    // 计算 m，注意转为浮点数
    double ans = (double)fz / (fm1 * fm2);

    // 输出保留三位小数
    cout << fixed << setprecision(3) << ans << endl;

    return 0;
}
```
