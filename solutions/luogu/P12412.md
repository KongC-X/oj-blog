## 题目描述

OI 集训了，但是同学们还想上文化课。

一共有 $k$ 节文化课，小 Y 有 $n$ 个好朋友，他的第 $i$ 个好朋友计划选择 $m_i$ 节课。由于小 Y 觉得他太强了，所以没有选择任何一节。

小 Y 好朋友们知道，当他们全都在上同一节课时，机房就只剩下小 Y 一人，此时小 Y 会感到孤独。因此好朋友们希望调整他们的选课方案，使得小 Y 的孤独时间尽可能短。请计算在最优安排下，小 Y 会感到孤独的课程数量的最小值。

## 输入格式

第一行两个正整数 $n,k$。

第二行 $n$ 个正整数 $m_i$。

## 输出格式

一个整数，表示在最优安排下，小 Y 会感到孤独的课程数量的最小值。

## 样例

## AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;

int main() {
    /*
     * ======================================================================
     * 题目：P12412 「YLLOI-R1-T1」等你下课
     * 题意：n 个好朋友，每人选 m_i 节课（共 k 节），求所有人都选的课数最小值。
     *
     * 核心思路（补集法）：
     * 1. 定义“孤独”的课 = 所有人都选的课。
     *    反过来想，如果一节课至少有一个人没选，那它就不是孤独课。
     *
     * 2. 统计所有人“没选”的课的总数 sum：
     *    第 i 个人没选的课数 = k - m_i
     *    所有人没选的总数 sum = Σ(k - m_i)
     *
     * 3. 如果 sum >= k：
     *    说明所有 k 节课都至少被某个人“没选”过，
     *    那么每节课都不是所有人都选，答案 = 0。
     *
     * 4. 如果 sum < k：
     *    说明有 k - sum 节课没有被任何人“没选”过，
     *    也就是这些课被所有人选了，答案 = k - sum。
     *
     * 5. 等价于 ans = max(0, k - sum)
     *    但代码中用了 if 判断，更直观。
     *
     * 时间复杂度：O(n)
     * 空间复杂度：O(1)
     * ======================================================================
     */

    long long n, k;       // n: 朋友数, k: 课总数
    long long m;          // m: 第 i 个朋友选的课数
    long long sum = 0;    // sum: 所有人没选的课的总数

    cin >> n >> k;

    while (n--) {
        cin >> m;
        sum += k - m;     // 累加每个人没选的课数
    }

    // 如果 sum >= k，说明所有课都有人没选，答案 0
    // 否则答案 = k - sum（这些课没人没选，即所有人都选）
    if (k - sum > 0) cout << k - sum << endl;
    else cout << 0 << endl;

    return 0;
}
```
