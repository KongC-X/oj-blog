# B2028 反向输出一个三位数

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-25

## 题目描述

将一个三位数反向输出，例如输入 $358$，反向输出 $853$。

## 样例

**样例输入 #1**
```
100```

**样例输出 #1**
```
001```

**样例输入 #2**
```
001```

**样例输出 #2**
```
100```

**样例输入 #3**
```
678```

**样例输出 #3**
```
876```

## AC 代码

```cpp
#include<iostream>
using namespace std;
int main() {
    int x;
    int a, b, c;
    cin>>x;
    a=x/100;//百位
    b=x/10%10;//十位
    c=x%10;//个位
    cout<<c<<b<<a;//反向输出
    return 0;
}

```
