# P14075 [GESP202509 六级] 划分字符串

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-06-17

**算法标签**：`动态规划`、`匈牙利算法`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1194>

## 题目描述

小 A 有一个由 $n$ 个小写字母组成的字符串 $s$。他希望将 $s$ 划分为若干个子串，使得子串中每个字母至多出现一次。例如，对于字符串 `street` 来说，`str + e + e + t` 是满足条件的划分；而 `s + tree + t` 不是，因为子串 `tree` 中 `e` 出现了两次。

额外地，小 A 还给出了价值 $a_1,a_2,\ldots,a_n$，表示划分后长度为 $i$ 的子串价值为 $a_i$。小 A 希望最大化划分后得到的子串价值之和。你能帮他求出划分后子串价值之和的最大值吗？

## 输入格式

第一行，一个正整数 $n$，表示字符串的长度。

第二行，一个包含 $n$ 个小写字母的字符串 $s$。

第三行，$n$ 个正整数 $a_1,a_2,\ldots,a_n$，表示不同长度的子串价值。

## 输出格式

一行，一个整数，表示划分后子串价值之和的最大值。

## 样例

**样例输入 #1**
```
6
street
2 1 7 4 3 3```

**样例输出 #1**
```
13```

**样例输入 #2**
```
8
blossoms
1 1 2 3 5 8 13 21```

**样例输出 #2**
```
8```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

long long dp[100010];              // dp[i]：前 i 个字符能获得的最大价值

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int n;                       // 字符串长度
    string s;                    // 原始字符串
    cin >> n >> s;
    s = " " + s;                 // 前面补一个占位符，使下标从 1 开始更方便

    long long a[100010];           // a[i]：长度为 i 的子串价值
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    // ---------- DP 思路 ----------
    // 定义 dp[i] 表示将前 i 个字符按要求划分后，能获得的最大价值。
    // 初始 dp[0] = 0。
    // 转移时，考虑最后一段子串 [j, i]（其中 1 <= j <= i），
    // 该子串内每个字母至多出现一次。
    // 因为小写字母只有 26 种，所以最后一段子串长度最多为 26。
    // 枚举最后一段的长度 len（从 1 到 min(i, 26)），
    // 向左检查 s[i-len+1 .. i] 是否无重复字母，
    // 一旦出现重复就停止（因为更短的子串也必然包含重复）。
    // 若合法，则 dp[i] = max(dp[i], dp[i-len] + a[len])。
    // 最终答案即为 dp[n]。

    dp[0] = 0;
    for (int i = 1; i <= n; i++) {
        // 至少可以单独分出一个长度为 1 的子串，先假设最后一段就是长度 1 的子串，只包含当前字符
        // 这永远是一个合法的划分，因为单个字母肯定不重复。
        // 因此 dp[i] 至少可以取 dp[i - 1] + a[1]（前 i-1 个字符的最优划分，加上这个单字母子串的价值）。
        dp[i] = dp[i - 1] + a[1]; 

        bool vis[26] = {false};     // 标记当前子串中字母是否出现过
        for (int len = 1; len <= 26 && i - len + 1 >= 1; len++) {
            int t = s[i - len + 1] - 'a';   // 当前子串最左侧字符
            if (vis[t]) break;                 // 有重复，不能再继续扩展长度
            vis[t] = true;
            dp[i] = max(dp[i], dp[i - len] + a[len]); // 更新答案
        } 
    }

    cout << dp[n] << endl;
    return 0;
}
```
