# B2147 求 f(x,n)

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-15

**算法标签**：`函数与递归`

## 题目描述

已知 $f(x,n)=\sqrt{n+\sqrt{(n-1)+\sqrt{(n-2)+\sqrt{...+2+\sqrt{1+x}}}}}$。

计算 $f(x,n)$ 的值。

## 输入格式

输入实数 $x$ 和正整数 $n$。

## 输出格式

函数值，保留两位小数。

## 样例

**样例输入 #1**
```
4.2 10```

**样例输出 #1**
```
3.68```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

double x;                            // 全局变量，方便递归函数使用

// 递归函数：计算从最内层到第 k 层的值
double f(int k) {
    if (k == 1) return sqrt(1 + x);          // 最内层：sqrt(1 + x)
    return sqrt(k + f(k - 1));                // 外层：sqrt(k + 内层结果)
}

int main() {
    int n;                                   // n: 层数
    cin >> x >> n;
    cout << fixed << setprecision(2) << f(n) << endl;
    return 0;
}
```
