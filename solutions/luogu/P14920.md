# P14920 [GESP202512 六级] 道具商店

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-06-16

**算法标签**：`动态规划`、`匈牙利算法`、`最近公共祖先`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1202>

## 题目描述

道具商店里有 $n$ 件道具可供挑选。第 $i$ 件道具可为玩家提升 $a_i$ 点攻击力，需要 $c_i$ 枚金币才能购买，每件道具只能购买一次。现在你有 $k$ 枚金币，请问你最多可以提升多少点攻击力？

## 输入格式

第一行，两个正整数 $n,k$，表示道具数量以及你所拥有的金币数量。

接下来 $n$ 行，每行两个正整数 $a_i,c_i$，表示道具所提升的攻击力点数，以及购买所需的金币数量。

## 输出格式

输出一行，一个整数，表示最多可以提升的攻击力点数。

## 样例

**样例输入 #1**
```
3 5
99 1
33 2
11 3```

**样例输出 #1**
```
132```

**样例输入 #2**
```
4 100
10 1
20 11
40 33
100 99```

**样例输出 #2**
```
110```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

const int MAXV = 250010;         // 最大总攻击力 = 500 * 500 = 250000，多开一点
const long long INF = 1e18;

int n;                          // n: 道具数量
long long k;                           // k: 拥有的金币数
long long dp[MAXV];                    // dp[j]: 获得 j 点攻击力所需的最少金币数

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n >> k;

    // ---------- 思路 ----------
    // 问题：0/1 背包，但金币上限 k 和物品费用 c_i 都很大（可达 1e9），
    // 而攻击力 a_i 很小（<=500），n <= 500，因此总攻击力最多 250000。
    // 若用传统的 dp[i][w] 表示前 i 件花费 w 金币的最大攻击力，
    // 则 w 可达 1e9，数组开不下。
    // 这里采用“价值背包”转换：
    // dp[j] 表示获得 j 点攻击力所需的最小金币数。
    // 对每件物品（攻击力 a，费用 c），做 0/1 背包更新：
    //   dp[j + a] = min(dp[j + a], dp[j] + c)
    // 最后从大到小找满足 dp[j] <= k 的最大 j 即为答案。
    // 时间复杂度 O(n * 总攻击力) ≈ 500 * 250000 = 1.25e8，可接受。
    // 空间 O(总攻击力) ≈ 250010。

    // 初始化 dp
    for (int j = 0; j < MAXV; j++) dp[j] = INF;
    dp[0] = 0;                   // 0 攻击力不需要金币

    int max_sum = 0;              // 记录当前能达到的最大攻击力，用于优化循环上限

    for (int i = 1; i <= n; i++) {
        int a, c;                 // a: 攻击力提升值, c: 金币花费
        cin >> a >> c;

        // 0/1 背包，倒序更新
        for (int j = max_sum; j >= 0; j--) {
            if (dp[j] == INF) continue; // 跳过无效状态
            dp[j + a] = min(dp[j + a], dp[j] + c); 
        }
        max_sum += a;             // 更新总攻击力上限
        if (max_sum > 250000) max_sum = 250000; // 防止超过数组大小
    }

    // 从大到小寻找第一个花费不超过 k 的攻击力
    int ans = 0;
    for (int j = max_sum; j >= 0; j--) {
        if (dp[j] <= k) {
            ans = j;
            break;
        }
    }

    cout << ans << endl;
    return 0;
}
```
