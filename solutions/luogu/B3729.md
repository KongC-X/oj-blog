# B3729 [信息与未来 2017] 龟兔赛跑

> **洛谷** | 入门 | C++14 | 提交时间: 2026-04-11

**算法标签**：`递归`、`欧拉回路`、`CDQ分治`

## 题目描述

兔子又来找乌龟赛跑啦！同样的错误兔子不会犯两次，所以兔子提出赛跑的时候，乌龟就觉得这场比赛很 不公平。于是兔子进一步放宽了条件，表示他可以在比赛开始以后先睡 $t$ 分钟再开始追乌龟。

乌龟这下没办法确定比赛到底公平不公平了，所以请你来帮忙。假设乌龟每分钟可以跑 $x$ 米，兔子每分钟跑 $y$ 米 $(x\lt y)$。他希望你计算最大的整数赛跑距离 (米)，满足乌龟能在兔子先睡 $t$ 分钟的前提下，比兔子更早或同时到达终点。

## 输入格式

三个整数 $x,y,t$。

## 输出格式

一个整数，表示要求的最长赛跑距离。

## 样例

**样例输入 #1**
```
11 21 7```

**样例输出 #1**
```
161```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int x, y, t;
    cin >> x >> y >> t;

    // 题目要求：乌龟每分钟跑 x 米，兔子每分钟跑 y 米（x < y）
    // 兔子先睡 t 分钟，然后开始追。
    // 设赛跑距离为 L 米，乌龟跑完全程用时 L / x 分钟，
    // 兔子跑完全程用时 L / y 分钟，但兔子先睡了 t 分钟，所以兔子总用时 = t + L / y。
    // 乌龟要更早或同时到达，即：L / x <= t + L / y
    // 两边乘以 xy（正数）：L * y <= t * x * y + L * x
    // 移项：L * y - L * x <= t * x * y  ->  L * (y - x) <= t * x * y
    // 所以：L <= (t * x * y) / (y - x)
    // 因为 L 是整数，所以最大整数 L = floor( t * x * y / (y - x) )

    int ans = t * x * y / (y - x);
    cout << ans << endl;

    return 0;
}
```
