# P1577 切绳子

> **洛谷** | 普及| C++14 | 提交时间: 2026-07-24

**算法标签**：`二分`、`Special Judge`

## 题目描述

有 $N$ 条绳子，它们的长度分别为 $L_i$。如果从它们中切割出 $K$ 条长度相同的绳子，这 $K$ 条绳子每条最长能有多长？答案保留到小数点后 $2$ 位(直接舍掉 $2$ 位后的小数)。

## 输入格式

第一行两个整数 $N$ 和 $K$，接下来 $N$ 行，描述了每条绳子的长度 $L_i$ 。

## 输出格式

切割后每条绳子的最大长度。答案与标准答案误差不超过 $0.01$ 或者相对误差不超过 $1\%$ 即可通过。

## 样例

**样例输入 #1**
```
4 11
8.02
7.43
4.57
5.39```

**样例输出 #1**
```
2.00```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 10010;            // 绳子数量上限 10000，多开10个
int a[MAXN];                       // 存储每条绳子的长度（单位：0.01米）
int n, k;                          // n:绳子数量, k:需要切出的段数

// 判断当每段长度为 len（单位0.01米）时，能否切出至少 k 段
bool check(int len) {
    long long cnt = 0;             // 总段数，可能很大，用long long
    for (int i = 0; i < n; i++) {
        cnt += a[i] / len;
        if (cnt >= k) return true; // 已经够k段，提前返回
    }
    return cnt >= k;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    /*
      思路：二分答案（整数二分）
      将每条绳子的长度乘以100转化为整数（单位厘米），这样避免了浮点误差。
      对目标长度进行二分，范围 [1, 10000000]（即0.01米 ~ 100000.00米）。
      每次判断当前长度mid能否切出至少k段。
      最后将找到的最大长度除以100.0，保留两位小数输出即可。
      时间复杂度 O(n log(max_len))
    */
    
    cin >> n >> k;
    int max_len = 0;               // 记录最长绳子的整数长度（上界）
    for (int i = 0; i < n; i++) {
        double x;
        cin >> x;
        a[i] = (int)(x * 100 + 0.5);  // 四舍五入取整，避免浮点截断误差
        if (a[i] > max_len) max_len = a[i];
    }
    
    int l = 1, r = max_len;        // 二分左右边界
    int ans = 0;                   // 记录答案（单位厘米）
    
    while (l <= r) {
        int mid = l + (r - l) / 2;
        if (check(mid)) {
            ans = mid;             // 可行，记录答案，尝试更大的长度
            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }
    
    // 输出结果，保留两位小数（直接截断就是向下取整，而我们的ans是整数，除以100.0即可）
    printf("%.2f\n", ans / 100.0);
    return 0;
}
```
