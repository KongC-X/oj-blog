# P5731 【深基5.习6】蛇形方阵

> **洛谷** | 入门 | C++14 | 提交时间: 2025-08-02

## 题目描述

给出一个不大于 $9$ 的正整数 $n$，输出 $n\times n$ 
的蛇形方阵。

从左上角填上 $1$ 开始，顺时针方向依次填入数字，如同样例所示。注意每个数字有都会占用 $3$ 个字符，前面使用空格补齐。

## 输入格式

输入一个正整数 $n$，含义如题所述。

## 输出格式

输出符合题目要求的蛇形矩阵。

## 样例

**样例输入 #1**
```
4```

**样例输出 #1**
```
  1  2  3  4
 12 13 14  5
 11 16 15  6
 10  9  8  7```

## AC 代码

```cpp
#include<iostream>
#include<iomanip>
using namespace std;

int a[20][20];
int n;

void fun(int start,int len,int x) {
    if(len > 0) {
        int i,j;
        // 向右
        for(j = start;j <= start + len - 1;j++) {
            a[start][j] = x;
            x++;
        }
        // 向下
        for(i = start + 1;i <= start + len - 1;i++) {
            a[i][start + len - 1] = x;
            x++;
        }
        // 向左
        for(j = start + len - 2;j >= start;j--) {
            a[start + len - 1][j] = x;
            x++;
        }
        // 向上
        for(i = start + len - 2;i >= start + 1;i--) {
            a[i][start] = x;
            x++;
        }
        fun(start + 1,len - 2,x);
    }
}

int main() {
    cin >> n;
    fun(1, n, 1);
    for(int i = 1;i <= n;i++) {
        for(int j = 1;j <= n;j++) {
            cout << setw(3) << a[i][j];
        }
        cout << endl;
    }
}
```
