# B4128 [信息与未来 2014] 夏令营旗手

> **洛谷** | 入门 | C++14 | 提交时间: 2026-04-11

**算法标签**：`强连通分量`、`CDQ分治`

## 题目描述

2014 年江苏省“信息与未来”小学夏令营在金陵中学河西分校进行，组委会决定从河西分校的学生中，推选一位小旗手，并输出其编号。

河西分校的每一位同学都有一个汉语拼音的名字，名字中的字符全部为大写的英文字母，且无空格，例如：

- 名字：王小明
- 拼音：$\tt WANGXIAOMING$

每个大写字母都有一个对应的 ASCII 码，如下表：
| 字符 | 编码（十进制） |
| :----------: | :----------: |
| $\tt A$ | $65$ |
| $\tt B$ | $66$ |
| $\cdots$ | $\cdots$ |
| $\tt Z$ | $90$ |

名字中各字符的 ASCII 码的和即为该学生的编号。

你的任务是根据给出的学生的名字，输出对应的编号。

## 输入格式

一个大写字母组成的字符串 $s$。

## 样例

**样例输入 #1**
```
ABCD```

**样例输出 #1**
```
266```

## AC 代码

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s;
    cin >> s;
    int sum = 0;
    for (int i = 0; i < s.length(); i++) {
        sum += int(s[i]);
    }
    cout << sum << endl;
    return 0;
}
```
