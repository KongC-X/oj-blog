# P14076 [GESP202509 六级] 货物运输

> **洛谷** | 普及- | C++14 | 提交时间: 2026-06-03

**算法标签**：`搜索`、`二分`、`匈牙利算法`、`搜索剪枝`、`迭代加深`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1194>

## 题目描述

A 国有 $n$ 座城市，依次以 $1,2,\ldots,n$ 编号，其中 $1$ 号城市为首都。这 $n$ 座城市由 $n-1$ 条双向道路连接，第 $i$ 条道路（$1 \le i < n$）连接编号为 $u_i,v_i$ 的两座城市，道路长度为 $l_i$。任意两座城市间均可通过双向道路到达。

现在 A 国需要从首都向各个城市运送货物。具体来说，满载货物的车队会从首都开出，经过一座城市时将对应的货物送出，因此车队需要经过所有城市。A 国希望你设计一条路线，在从首都出发经过所有城市的前提下，最小化经过的道路长度总和。注意一座城市可以经过多次，车队最后可以不返回首都。

## 输入格式

第一行，一个正整数 $n$，表示 A 国的城市数量。

接下来 $n-1$ 行，每行三个正整数 $u_i,v_i,l_i$，表示一条双向道路连接编号为 $u_i,v_i$ 的两座城市，道路长度为 $l_i$。

## 输出格式

一行，一个整数，表示你设计的路线所经过的道路长度总和。

## 样例

**样例输入 #1**
```
4
1 2 6
1 3 1
3 4 5```

**样例输出 #1**
```
18```

**样例输入 #2**
```
7
1 2 1
2 3 1
3 4 1
7 6 1
6 5 1
5 1 1```

**样例输出 #2**
```
9```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
#include <vector>
using namespace std;

// ---------- 解题思路 ----------
// 题目要求：从首都(1)出发，经过所有城市至少一次，可以重复经过，最后不必返回首都。
// 这是一棵 n 个节点的树，边有长度。
// 模型分析：
// 如果要求最终返回首都，那么每条边至少需要走两次（去和回），总路程恰好是 2*total。
// 因为可以不返回，我们可以省去从“最后访问的城市”回到首都的那段路。
// 为了让总路程最短，我们应当选择离首都最远的城市作为终点，这样省去的路程最长。
// 因此，答案 = 2 * total - max_dist，其中 max_dist 是从首都(1)到任意节点的最长距离。
// 算法步骤：
// 1. 读入数据，建立树的邻接表，同时计算 total。
// 2. 用 DFS（或 BFS）从节点 1 出发，计算 dist[1..n]。
// 3. 找到 max_dist = max(dist[i])。
// 4. 输出 2*total - max_dist。
// 复杂度：O(n)，对于 n <= 1e5 完全可行。

typedef long long ll;
int n;
vector<pair<int, ll> > g[100010];          // 邻接表：g[u] 存储 (邻居v, 边权w)
ll dist[100010];                          // dist[i] 表示从首都(1)到城市 i 的距离

// 深度优先搜索，计算每个节点到根的距离
// u: 当前节点, fa: 父节点（避免往回走）
void dfs(int u, int fa) {
    for (int i = 0; i < g[u].size(); i++) {
        int v = g[u][i].first;          // 邻居城市编号
        ll w = g[u][i].second;          // 道路长度
        if (v == fa) continue;          // 避免回到父节点
        dist[v] = dist[u] + w;          // 计算距离
        dfs(v, u);                      // 递归访问子树
    }
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    cin >> n;
    ll total = 0;                       // 所有道路长度之和
    for (int i = 0; i < n - 1; i++) {
        int u, v;
        ll w;
        cin >> u >> v >> w;
        // 无向图，双方都要记录
        // make_pair() 用于创建 pair 对象
        g[u].push_back(make_pair(v, w)); // 从 u 到 v 的边，长度为 w
        g[v].push_back(make_pair(u, w)); // 从 v 到 u 的边，长度为 w
        total += w;                     // 累加总权值
    }
    
    dist[1] = 0;
    dfs(1, 0);                           // 从根开始遍历
    
    // 寻找最远距离
    ll ma = 0;
    for (int i = 1; i <= n; i++) {
        ma = max(ma, dist[i]);
    }
    
    ll ans = 2 * total - ma;           // 计算答案
    cout << ans << endl;
    
    return 0;
}
```
