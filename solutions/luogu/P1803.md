# P1803 凌乱的yyy / 线段覆盖

> **洛谷** | 普及- | C++14 | 提交时间: 2026-02-05

**算法标签**：`二分`、`队列`

## 题目背景

**Python 用户可以尝试使用 pypy3 提交试题。**

快 noip 了，yyy 很紧张！

## 题目描述

现在各大 oj 上有 $n$ 个比赛，每个比赛的开始、结束的时间点是知道的。

yyy 认为，参加越多的比赛，noip 就能考的越好（假的）。

所以，他想知道他最多能参加几个比赛。

由于 yyy 是蒟蒻，如果要参加一个比赛必须善始善终，而且不能同时参加 $2$ 个及以上的比赛。

## 输入格式

第一行是一个整数 $n$，接下来 $n$ 行每行是 $2$ 个整数 $a_{i},b_{i}\ (a_{i}<b_{i})$，表示比赛开始、结束的时间。

## 输出格式

一个整数最多参加的比赛数目。

## 样例

**样例输入 #1**
```
3
0 2
2 4
1 3
```

**样例输出 #1**
```
2
```

## AC 代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

const int MAXN = 1e6 + 5;

struct Contest {
    int start, end;
};

bool cmp(Contest a, Contest b) {
    return a.end < b.end;  // 按结束时间升序
}

Contest contests[MAXN];

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int n;
    cin >> n;
    
    for (int i = 0; i < n; i++) {
        cin >> contests[i].start >> contests[i].end;
    }
    
    // 按结束时间升序排序
    sort(contests, contests + n, cmp);
    
    int count = 0;
    int last_end = -1;  // 上一个选择的活动的结束时间
    
    for (int i = 0; i < n; i++) {
        if (contests[i].start >= last_end) {
            count++;
            last_end = contests[i].end;
        }
    }
    
    cout << count << endl;
    
    return 0;
}
```
