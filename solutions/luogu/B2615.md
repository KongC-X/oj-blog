# B2615 【深基1.习7】定期存款

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-03

## 题目描述

银行定期存款年利率是一年定存 $3.5\%$，五年定存 $4\%$。小 A 和 UIM 手上各有 $10000$ 元。小A 决定每次存一年期，到期后将连本带利再存一年，直到存满 $5$ 年。UIM 直接存五年定期。请问 $5$ 年后小 A 和 UIM 分别有多少钱？

## 输出格式

请输出两个浮点数表示答案。直接使用 cout 输出答案即可，中间用空格隔开。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】复利与单利计算
     * 【核心思路】
     * 小A：复利，年利率3.5%，5年：A = 10000 * pow(1.035, 5)
     * UIM：单利，年利率4%，5年：B = 10000 * (1 + 0.04*5)
     *
     * 【时间复杂度】O(1)
     */

    double a, b;   // a: 小A的钱, b: UIM的钱
    a = 10000 * pow(1.035, 5);
    b = 10000 * (1 + 0.04 * 5);

    cout << a << " " << b << endl;
    return 0;
}
```
