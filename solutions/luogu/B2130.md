# B2130 简单算术表达式求值

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-13

**算法标签**：`模拟`、`分支结构`、`函数与递归`

## 题目描述

两位正整数的简单算术运算（只考虑整数运算），算术运算为：

`+`，加法运算；

`-`，减法运算；

`*`，乘法运算；

`/`，整除运算；

`%`，取余运算。

算术表达式的格式为（运算符前后可能有空格）：

运算数运算符运算数。

请输出相应的结果。

## 输出格式

整型算数运算的结果（结果值不一定为 $2$ 位数，可能多于 $2$ 位或少于 $2$ 位）。

## 样例

**样例输入 #1**
```
32+64```

**样例输出 #1**
```
96```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 函数：根据运算符 op 计算 a 和 b 的结果
int calc(int a, char op, int b) {
    if (op == '+') return a + b;
    if (op == '-') return a - b;
    if (op == '*') return a * b;
    if (op == '/') return a / b;   // 整除
    if (op == '%') return a % b;
    return 0;                      // 不会执行到这里
}

int main() {
    string s;                      // s: 输入的表达式
    getline(cin, s);               // 读入整行，可能包含空格

    // 去除所有空格
    string t = "";
    for (int i = 0; i < s.size(); i++) {
        if (s[i] != ' ') t += s[i];
    }

    // 解析：找到运算符位置
    int pos = 0;                   // 运算符在 t 中的下标
    for (int i = 0; i < t.size(); i++) {
        if (t[i] == '+' || t[i] == '-' || t[i] == '*' || t[i] == '/' || t[i] == '%') {
            pos = i;
            break;
        }
    }

    // 提取操作数 a 和 b
    int a = stoi(t.substr(0, pos));        // 左操作数
    int b = stoi(t.substr(pos + 1));       // 右操作数
    char op = t[pos];                      // 运算符

    // 调用函数计算并输出
    cout << calc(a, op, b) << endl;
    return 0;
}
```
