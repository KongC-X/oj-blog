# B3758 [信息与未来 2021] 括号序列

> **洛谷** | 普及- | C++14 | 提交时间: 2026-04-14

**算法标签**：`贪心`、`二分`、`快速傅里叶变换`、`CDQ分治`、`SG函数`

## 题目描述

你得到了一个仅包含左圆括号 `(` 和右圆括号 `)` 的字符串，但其中的括号并不配对。为了使这个字符串变得更好看，你希望在字符串中插入尽可能少的圆括号（可以在任意位置插入任意数量的括号，但已有的括号不能改变），使修改后的字符串括号配对。

## 输入格式

输入一行一个字符串，为括号未全部配对的圆括号序列。

## 输出格式

输出一行，为插入圆括号后配对的字符串。如有多种长度最短的方案，输出任意一个即可。

## 样例

**样例输入 #1**
```
(())()(```

**样例输出 #1**
```
(())()()```

**样例输入 #2**
```
))((```

**样例输出 #2**
```
(())()()```

## AC 代码

```cpp
#include <iostream>
#include <string>
using namespace std;

// 先扫描原字符串，用一个计数器 left 记录当前还有多少左括号没有匹配。
// 如果遇到右括号 )：
// 如果 left > 0，说明前面有左括号可以和它配对，left--。
// 否则，这个右括号是多余的，我们需要在它前面补一个左括号，用一个变量 addLeft 记录补左括号的数量。
// 如果遇到左括号 (，直接 left++。
// 扫描完后，left 就是末尾缺少的右括号数量，我们需要在末尾补上 left 个右括号。
// 最终的字符串就是：先输出 addLeft 个 '('，再输出原字符串，最后输出 left 个 ')'。

int main() {
    string s;
    cin >> s;

    int left = 0;      // 当前未匹配的左括号数量
    int addLeft = 0;   // 需要在最前面补充的左括号数量（针对多余的右括号）

    // 遍历原字符串
    for (int i = 0; i < s.length(); i++) {
        if (s[i] == '(') {
            left++;                 // 遇到左括号，计数加1
        } else { // s[i] == ')'
            if (left > 0) {
                left--;             // 有左括号可以匹配，匹配掉一个
            } else {
                addLeft++;          // 没有左括号可匹配，需要在前面补一个左括号
            }
        }
    }

    // 构造结果：补 addLeft 个 '(' + 原字符串 + 补 left 个 ')'
    string ans;
    // 先补充左括号
    for (int i = 0; i < addLeft; i++) {
        ans += '(';
    }
    // 拼接原字符串
    ans += s;
    // 最后补充右括号
    for (int i = 0; i < left; i++) {
        ans += ')';
    }

    cout << ans << endl;
    return 0;
}
```
