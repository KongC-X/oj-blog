# B2008 计算 (a+b)×c 的值

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-19

## 题目描述

给定 $3$ 个整数 $a,b,c$，计算表达式 $(a+b) \times c$ 的值。

## 输入格式

输入仅一行，包括三个整数 $a,b,c$，数与数之间以一个空格分开。

## 输出格式

输出一行，即表达式的值。

## 样例

**样例输入 #1**
```
2 3 5```

**样例输出 #1**
```
25```

## AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int a,b,c;
	cin>>a>>b>>c;
	cout<<(a+b)*c;
	return 0;
}

```
