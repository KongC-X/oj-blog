# B3700 [语言月赛202301] 九九乘方表

> **洛谷** | 入门 | C++14 | 提交时间: 2026-09-10

**算法标签**：`2023`、`O2优化`、`循环结构`、`语言月赛`

## 题目描述

九九乘法表是数学学习中必须记忆的内容之一。

九九乘法表的前三行为：

`1 * 1 = 1`  
`2 * 1 = 2 2 * 2 = 4`  
`3 * 1 = 3 3 * 2 = 6 3 * 3 = 9`

类似的，我们可以定义出九九乘方表，其前三行为：

`1 ^ 1 = 1`  
`2 ^ 1 = 2 2 ^ 2 = 4`  
`3 ^ 1 = 3 3 ^ 2 = 9 3 ^ 3 = 27`

`a ^ b` 的含义为 $a^b$，也就是 $b$ 个 $a$ 相乘。

例如：$3^4=3\times3\times 3\times 3 = 81$

请你输出九九乘方表的前 $n$ 行，每两项之间由**一个**空格隔开。

## 输入格式

输入一行一个整数 $n$。

## 输出格式

输出 $n$ 行，为九九乘方表的前 $n$ 行。

请注意：符号 ^ 和 = 前后均由一个空格分隔，每两项之间由**一个**空格隔开。

## 样例

**样例输入 #1**
```
3```

**样例输出 #1**
```
1 ^ 1 = 1
2 ^ 1 = 2 2 ^ 2 = 4
3 ^ 1 = 3 3 ^ 2 = 9 3 ^ 3 = 27```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3700 [语言月赛202301] 九九乘方表
     * 题意：输出九九乘方表的前 n 行。第 i 行有 i 项，第 j 项格式为 "i ^ j = i^j"。
     *       项与项之间用一个空格隔开，每行末尾换行。
     * 思路：双重循环，外层 i 从 1 到 n，内层 j 从 1 到 i。
     *       计算 i^j 可以用累乘，注意结果可能较大，用 long long。
     */
    int n;
    cin >> n;

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            if (j > 1) cout << ' ';   // 项之间用空格分隔

            long long p = 1;          // p: i 的 j 次方
            for (int k = 1; k <= j; k++) {
                p *= i;
            }

            cout << i << " ^ " << j << " = " << p;
        }
        cout << endl;   // 每行结束换行
    }

    return 0;
}
```
