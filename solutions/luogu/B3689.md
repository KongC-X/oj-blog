# B3689 [语言月赛 202212] 宇宙密码

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-30

**算法标签**：`2022`、`O2优化`、`循环结构`、`语言月赛`

## 题目描述

经历十九年的探索，人们终于找到了宇宙中的那份瑰宝。

这份瑰宝被装在一个密码箱里，按照情报，密码应为一串长度为 $n$ 的数字 $a$。

人们满怀希望地输入了密码，但是密码箱没有任何反应。

这时人们意识到，在十九年中，由于宇宙射线的侵蚀，密码箱的密码发生了改变。

现在人们知道，能够打开密码箱的新密码是由原密码 $a$ 变化而来。具体的，新密码相比原密码变化了 $t$ 位数字，其中 $t$ 满足 $0 \leq t \leq k$，且对于变化的数字位，变化后的数字是在该位置原数字的基础上增加或减小 $1$ 得到的数字。特别的，如果原数字是 $0$，在原数字基础上减少 $1$ 得到的数字是 $9$；如果原数字是 $9$，在原数字基础上增加 $1$ 得到的数字是 $0$。

现在人们知道了 $n, a, k$，想知道经过宇宙射线侵蚀后，所有可能打开密码箱的密码。

人类将重任交到了你身上，请你帮助人类解决这个问题。你需要由小到大输出所有可能的密码，每个一行。

特别的，有一些密码可能存在前导 $0$。为了方便操作，这时你**不必也不应**将这些前导 $0$ 一并输出。

人类感谢你。

## 输入格式

输入只有一行三个整数，依次代表原密码位数 $n$，去掉前导零后的原密码 $a$，和变化位数的最大值 $k$。

## 输出格式

输出若干行，每一行包含一个整数，代表由小到大的所有可能的密码。

## 样例

**样例输入 #1**
```
3 14 1```

**样例输出 #1**
```
4
13
14
15
24
114
914```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int n, k;       // n: 密码位数, k: 最多允许变化的位数
string a;       // 原密码（已补足前导0，长度为 n）

/*
 * 思路：暴力枚举所有可能的密码（从 0 到 10^n - 1），逐个检查是否合法。
 * 合法条件：
 *   1. 与原密码 a 相比，每一位要么相同，要么在模 10 意义下相差 ±1。
 *      （即 diff == 0 或 diff == 1 或 diff == 9）
 *   2. 满足条件1的位数不超过 k。
 */

// 检查整数 x 是否是一个合法的密码
bool ok(int x) {
    string b = to_string(x);
    while (b.size() < n) b = "0" + b;   // 补前导0，使长度达到 n 位

    int cnt = 0;    // 记录变化的位数
    for (int i = 0; i < n; i++) {
        int bi = b[i] - '0';
        int ai = a[i] - '0';
        int diff = (bi - ai + 10) % 10;   // 模 10 下的差值（0~9）

        if (diff == 0) continue;          // 相同，无需变化
        if (diff != 1 && diff != 9) return false; // 不是 +1 或 -1，非法
        cnt++;
        if (cnt > k) return false;        // 变化位数超过限制
    }
    return true;
}

int main() {
    cin >> n >> a >> k;   // 输入顺序：位数、原密码（可能无前导0）、最大变化位数

    // 原密码补足前导0到 n 位
    while (a.size() < n) a = "0" + a;

    int limit = 1;
    for (int i = 0; i < n; i++) limit *= 10;   // 枚举上限 = 10^n

    // 枚举所有可能的密码（0 到 10^n - 1），输出合法且无前导0的
    for (int x = 0; x < limit; x++) {
        if (ok(x)) cout << x << endl;
    }
    return 0;
}
```
