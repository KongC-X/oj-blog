# B2160 病人排队

> **洛谷** | 普及- | C++14 | 提交时间: 2026-06-28

## 题目描述

编写一个程序，将登记的病人按照以下原则排出看病的先后顺序：
1. 老年人（年龄 $\geq 60$ 岁）比非老年人优先看病。
2. 老年人按年龄从大到小的顺序看病，年龄相同的按登记的先后顺序排序。
3. 非老年人按登记的先后顺序看病。

## 输入格式

第 $1$ 行，输入一个小于 $100$ 的正整数，表示病人的个数；

后面按照病人登记的先后顺序，每行输入一个病人的信息，包括：一个长度小于 $10$ 的字符串表示病人的 ID（每个病人的 ID 各不相同且只含数字和字母），一个整数表示病人的年龄，中间用单个空格隔开。

## 输出格式

按排好的看病顺序输出病人的 ID，每行一个。

## 样例

**样例输入 #1**
```
5
021075 40
004003 15
010158 67
021033 75
102012 30```

**样例输出 #1**
```
021033
010158
021075
004003
102012```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Patient {
    string id;          // 病人ID
    int age;            // 年龄
    int idx;            // 登记的先后顺序（输入顺序，从0开始）
};

// 排序比较函数
bool cmp(Patient a, Patient b) {
    // 判断是否为老年人
    bool old_a = (a.age >= 60);
    bool old_b = (b.age >= 60);
    
    // 如果一个是老年人一个不是，老年人优先
    if (old_a != old_b) return old_a > old_b;
    
    // 都是老年人：年龄大的优先，年龄相同按登记顺序
    if (old_a && old_b) {
        if (a.age != b.age) return a.age > b.age;
        return a.idx < b.idx;
    }
    
    // 都不是老年人：按登记顺序
    return a.idx < b.idx;
}

int main() {
    int n;                     // n: 病人数量
    cin >> n;
    
    Patient p[105];            // 最多100人，开105安全
    for (int i = 0; i < n; i++) {
        cin >> p[i].id >> p[i].age;
        p[i].idx = i;          // 记录原始顺序
    }
    
    sort(p, p + n, cmp);
    
    for (int i = 0; i < n; i++) {
        cout << p[i].id << endl;
    }
    
    return 0;
}
```
