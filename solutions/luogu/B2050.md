# B2050 三角形判断

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-27

## 题目描述

给定三个正整数，分别表示三条线段的长度，判断这三条线段能否构成一个三角形。

## 输入格式

输入共一行，包含三个正整数，分别表示三条线段的长度，数与数之间以一个空格分开。（三条边的长度均不超过 $10000$）

## 输出格式

如果能构成三角形，则输出 `1` ，否则输出 `0`。

## 样例

**样例输入 #1**
```
1 1 1```

**样例输出 #1**
```
1```

**样例输入 #2**
```
1 1 3```

**样例输出 #2**
```
0```

## AC 代码

```cpp
#include <iostream>
using namespace std;
int main() {
	int a, b, c;
	cin >> a >> b >> c;
	if (a + b > c && a + c > b && b + c > a) {
		cout << 1;
	}
	else {
		cout <<0;
	}
}

```
