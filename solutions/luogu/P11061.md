# P11061 【MX-X4-T1】「Jason-1」IO++

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-15

**算法标签**：`O2优化`、`梦熊比赛`

## 题目背景

原题链接：<https://oier.team/problems/X4B>。

## 题目描述

有一类只有输入语句与输出语句的程序，我们用一个非负整数序列 $[a_1, a_2, \ldots]$ 描述它。

该程序将从前往后依次执行，对于第 $i$ 个元素 $a_i$：

- 若 $a_i = 0$，表示一条输入语句：
	- 程序将从输入中读取一个整数。
- 否则，表示一条输出语句：
	- 程序将输出第 $a_i$ 次输入读取到的整数。
	- 对于给出的程序，保证执行本语句前，程序至少进行了 $a_i$ 次输入。对于你编写的程序，你同样需要保证这一点。

特别地，一个长度为 $0$ 的空程序也是合法的。

给定一个长度为 $n$ 的程序 $[b_1, \ldots, b_n]$，你需要求出能够实现相同的功能的程序所需的最短长度。

两个程序能实现相同功能，当且仅当对于任意的长度为 $10^{10^{10}}$、值为 $[1, 10^{10^{10}}]$ 之内整数的输入，两个程序执行的输出语句次数相同，且每一次输出的结果均一致。

## 输入格式

第一行，一个正整数 $n$，表示程序的长度。

第二行，$n$ 个非负整数 $b_1, \ldots, b_n$，描述了一个程序。

## 输出格式

仅一行一个整数，表示要实现相同功能的程序所需要的最小长度。

## 样例

**样例输入 #1**
```
5
0 0 0 1 2
```

**样例输出 #1**
```
4
```

**样例输入 #2**
```
7
0 0 1 0 3 1 3
```

**样例输出 #2**
```
7
```

**样例输入 #3**
```
7
0 1 0 0 2 1 0
```

**样例输出 #3**
```
5
```

**样例输入 #4**
```
4
0 0 0 0
```

**样例输出 #4**
```
0
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * ======================================================================
     * 题目：P11061 【MX-X4-T1】「Jason-1」IO++
     * 题意：程序由输入语句(0)和输出语句(x>0)组成。输出语句 x 表示输出第 x 次输入的值。
     *       给定一个程序 b，求能实现同样功能的最短程序长度。
     *
     * ======================================================================
     * 核心原理（结合样例1说明）：
     *
     * 样例1输入：
     *   5
     *   0 0 0 1 2
     * 
     * 原程序执行：
     *   ① 0 → 读入第1个数（假设输入为 [2,3,4,...]，读入 2）
     *   ② 0 → 读入第2个数（读入 3）
     *   ③ 0 → 读入第3个数（读入 4）
     *   ④ 1 → 输出第1次输入的数（输出 2）
     *   ⑤ 2 → 输出第2次输入的数（输出 3）
     * 
     * 输出为 [2,3]。注意到第3次输入的值（4）从未被任何输出语句引用，是多余的。
     * 因为最大的输出参数是 2，所以只需保证程序在输出第2个数之前至少执行了2次输入。
     * 
     * 优化后最短程序可以是 [0, 0, 1, 2]：
     *   ① 0 → 读入2
     *   ② 0 → 读入3
     *   ③ 1 → 输出第1次输入（2）
     *   ④ 2 → 输出第2次输入（3）
     * 输出仍然为 [2,3]，功能完全一样。长度从5减到4。
     *
     * ======================================================================
     * 通用结论：
     * 1. 每条输出语句（x>0）都必须保留，因为它们各自产生一次输出。
     *    输出次数不能少，否则功能不同。
     * 2. 所有输入语句中，只有那些被输出语句引用的输入值是必要的。
     *    最大输出参数 maxX 表示程序至少需要读取到第 maxX 个输入值。
     *    因此最少需要的输入语句数量 = maxX。
     * 3. 最短程序长度 = 输出语句数量 + maxX。
     *    （构造方式：先放 maxX 个输入语句，再按原顺序放所有输出语句）
     *
     * ======================================================================
     * 复杂度：O(n)，n ≤ 1e5。
     */
    int n;
    cin >> n;
    int outCnt = 0;   // 输出语句的个数
    int maxX = 0;     // 输出语句中参数的最大值
    for (int i = 0; i < n; i++) {
        int x;
        cin >> x;
        if (x > 0) {          // 是输出语句
            outCnt++;
            if (x > maxX) maxX = x;
        }
        // x == 0 是输入语句，我们不需要统计输入语句个数，只需记录 maxX
    }
    cout << outCnt + maxX << endl;
    return 0;
}
```
