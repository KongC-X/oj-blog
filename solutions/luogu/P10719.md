# P10719 [GESP202406 五级] 黑白格

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2025-06-17

**算法标签**：`递归`、`后缀数组`、`费用流`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1153>

## 题目描述

小杨有一个 $n$ 行 $m$ 列的网格图，其中每个格子要么是白色，要么是黑色。

小杨想知道至少包含 $k$ 个黑色格子的最小子矩形包含了多少个格子。

## 输入格式

第一行包含三个正整数 $n,m,k$，含义如题面所示。

之后 $n$ 行，每行⼀个长度为 $m$ 的 $\texttt{01}$ 串，代表网格图第 $i$ 行格子的颜色，如果为 $\texttt{0}$，则对应格子为白色，否则为黑色。

## 输出格式

输出一个整数，代表至少包含 $k$ 个黑色格子的最小子矩形包含格子的数量，如果不存在则输出 $0$。

## 样例

**样例输入 #1**
```
4 5 5
00000
01111
00011
00011```

**样例输出 #1**
```
6```

## AC 代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;
bool a[110][110];// 存储输入
int b[110][110];// 存储二维前缀和
int main(){
	ios::sync_with_stdio(0);cin.tie(0);
	int n,m,k;
    cin>>n>>m>>k;
	for(int i=1;i<=n;i++){
		for(int j=1;j<=m;j++){
			char c;
            cin>>c;
			a[i][j]=c-'0';
			b[i][j]=b[i-1][j]+b[i][j-1]-b[i-1][j-1]+a[i][j]; // 计算二维前缀和
		}
	}
	int mn=INT_MAX;
	for(int x1 = 0;x1 < n;x1++){// 注意这里的范围 
		for(int y1 = 0;y1 < m;y1++){// 注意这里的范围 
			for(int x2 = x1;x2 <= n;x2++){
				for(int y2 = y1;y2 <= m;y2++){
					int tmp=b[x2][y2]-b[x2][y1]-b[x1][y2]+b[x1][y1];// 左上端点为 (x1+1,y1+1)，右上端点为 (x2+1,y2+1) 的矩形中 1 的数量
					if(tmp >= k){
                        mn=min(mn,(x2-x1)*(y2-y1));
                    }
				}
			}
		}
	}
	cout<<((mn==INT_MAX)?0:mn);// 注意判断无解
	return 0;
}

```
