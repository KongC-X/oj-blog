# B3648 [语言月赛202208] 你几岁了

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-20

**算法标签**：`2022`、`顺序结构`、`语言月赛`

## 题目描述

小 A 今年 $x$ 岁。他刚学了英语，想告诉其他人：`I am x years old.`

## 输入格式

输入一个数 $x(2\le x \le 100)$，代表小 A 的年龄。

## 样例

**样例输入 #1**
```
2```

**样例输出 #1**
```
I am 2 years old.```

**样例输入 #2**
```
5```

**样例输出 #2**
```
I am 5 years old.```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3648 [语言月赛202208] 你几岁了
     * 题意：输入年龄 x，输出 "I am x years old."。
     */
    int x;          // x: 年龄
    cin >> x;
    cout << "I am " << x << " years old." << endl;
    return 0;
}
```
