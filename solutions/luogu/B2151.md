# B2151 正常血压

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-03

## 题目描述

监护室每小时测量一次病人的血压，若收缩压在 $90\sim 140$ 之间并且舒张压在 $60\sim 90$ 之间(包含端点值)则称之为正常，现给出某病人若干次测量的血压值，计算病人保持正常血压的最长小时数。

## 输入格式

第一行为一个正整数 $n(n<100)$，其后有 $n$ 行，每行 $2$ 个正整数，分别为一次测量的收缩压和舒张压。

## 输出格式

输出仅一行，血压连续正常的最长小时数。

## 样例

**样例输入 #1**
```
4
100 80
90 50
120 60
140 90```

**样例输出 #1**
```
2```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;                      // n: 测量次数
    cin >> n;
    int cnt = 0;                // cnt: 当前连续正常小时数
    int ans = 0;                // ans: 最长连续正常小时数

    for (int i = 0; i < n; i++) {
        int x, y;               // x: 收缩压, y: 舒张压
        cin >> x >> y;

        // 判断血压是否正常（含边界）
        if (x >= 90 && x <= 140 && y >= 60 && y <= 90) {
            cnt++;              // 正常，累加连续时长
            if (cnt > ans) ans = cnt; // 更新最大值
        } else {
            cnt = 0;            // 不正常，连续中断
        }
    }

    cout << ans << endl;
    return 0;
}
```
