# P5716 【深基3.例9】月份天数

> **洛谷** | 入门 | C++14 | 提交时间: 2025-08-01

## 题目描述

输入年份和月份，输出这一年的这一月有多少天。需要考虑闰年。

## 输入格式

输入两个正整数，分别表示年份 $y$ 和月数 $m$，以空格隔开。

## 输出格式

输出一行一个正整数，表示这个月有多少天。

## 样例

**样例输入 #1**
```
1926 8```

**样例输出 #1**
```
31```

**样例输入 #2**
```
2000 2```

**样例输出 #2**
```
29```

## AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int rn(int y)//闰年函数
{
	return y%400==0||y%4==0&&y%100!=0;
 } 
int m[13]={0,31,28,31,30,31,30,31,31,30,31,30,31};//每个月的天数
int main(){
	int n,y;
	cin>>n>>y;
	if(rn(n))//如果是闰年，则二月有29天
		m[2]=29;
	cout<<m[y];//输出第y月，这里不需要特判，因为如果是闰年前面已经修改过天数了。
	
	return 0;
}


```
