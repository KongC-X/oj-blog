# B2022 输出保留 12 位小数的浮点数

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-25

## 题目描述

读入一个双精度浮点数，保留 $12$ 位小数，输出这个浮点数。

**提示：无需考虑浮点误差。**

## 输入格式

只有一行，一个双精度浮点数。

## 输出格式

也只有一行，保留 $12$ 位小数的浮点数。

## 样例

**样例输入 #1**
```
3.1415926535798932
```

**样例输出 #1**
```
3.141592653580```

## AC 代码

```cpp
#include<iostream>
using namespace std;

long double n;

int main(){
    cin>>n;
    printf("%.12Lf",n);
    return 0;
}

```
