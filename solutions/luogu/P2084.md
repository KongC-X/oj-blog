# P2084 进制转换

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-24

**算法标签**：`模拟`、`字符串`、`线性数据结构`、`洛谷原创`

## 题目描述

今天小明学会了进制转换，比如 $(10101)_2$，那么它的十进制表示的式子就是 :

$$1\times 2^4+0\times 2^3+1\times 2^2+0\times 2^1+1\times 2^0$$

那么请你编程实现，将一个 $M$ 进制的数 $N$ 转换成十进制表示的式子。

注意：当系数为 $0$ 时，该单项式要省略。

## 输入格式

两个整数，$M$ 和 $N$，中间用空格隔开。

## 输出格式

共一行，一个十进制表示的式子。

## 样例

**样例输入 #1**
```
2 10101```

**样例输出 #1**
```
1*2^4+1*2^2+1*2^0```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】进制转换 + 字符串模拟
     * 【核心思路】
     * 1. 输入 M（进制，2~9）和 N（M进制的数，可能长达1000位，必须用字符串存储）。
     * 2. 从最高位到最低位逐位处理。
     *    第 i 位（0-based）的指数 = 总长度 - 1 - i。
     *    例如 N="10101" (长度5)，i=0 时指数=4，i=1时指数=3，...
     * 3. 如果当前位是字符 '0'，系数为0，题目要求省略该项，直接跳过。
     * 4. 如果当前位非零，转为数字 digit，输出 "digit*M^指数"。
     * 5. 多个项之间用 '+' 连接，用一个 bool 变量 first 标记是否为第一项。
     * 6. 最后输出 endl 换行。
     *
     * 【时间复杂度】遍历一次字符串，O(|N|)，满足 N 位数 ≤ 1000 的要求。
     */

    // 变量定义
    int m;          // m: 进制（2~9）
    string n;       // n: 输入的 M 进制数（字符串形式）
    cin >> m >> n;  // 读取输入

    int len = n.size();          // len: 数字的位数
    bool first = true;           // first: 标记当前是不是第一个输出的项

    // 从高位到低位遍历每一位
    for (int i = 0; i < len; i++) {
        char c = n[i];           // 当前位的字符
        if (c == '0') {
            continue;            // 系数为 0，省略该项，直接看下一位
        }
        int digit = c - '0';     // 当前位的数值（1~9）
        int exp = len - 1 - i;   // 当前位对应的指数（最高位指数最大）

        // 如果不是第一项，先输出 '+' 连接
        if (!first) {
            cout << '+';
        }
        // 输出单项式：数字*M^指数
        cout << digit << '*' << m << '^' << exp;
        first = false;           // 标记已经输出过一项，后续项要加 '+'
    }

    cout << endl;   // 换行（按题目要求用 endl）
    return 0;
}
```
