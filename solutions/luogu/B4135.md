# B4135 [信息与未来 2014] 取数

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-04-21

**算法标签**：`动态规划`、`强连通分量`、`CDQ分治`

## 题目描述

有 $n$ 个数排成一排，从 $n$ 个数中任取若干个数，取数规则为每次取相邻的 $2$ 个数，不能取 $1$ 个，也不能取多于 $2$ 个连续的数，找一种取法，使取到数的和为最大。

## 输入格式

第一行一个整数，表示 $n$；
第二行有 $n$ 个整数，表示 $x_1,x_2,\cdots,x_n$。

## 输出格式

一个整数，即合理取法中最大的和。

## 样例

**样例输入 #1**
```
6
13 2 17 14 8 16```

**样例输出 #1**
```
43```

## AC 代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

int n;
long long a[100010], dp[100010]; // dp[i] 表示前 i 个数中能获得的最大和

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    dp[0] = 0;
    if (n >= 1) dp[1] = 0;
    if (n >= 2) dp[2] = a[1] + a[2];
    for (int i = 3; i <= n; i++) {
        // 若不取第 i-1 和第 i 个数，则 dp[i] = dp[i-1]。
        // 若取这两个数，则第 i-2 个数不能取（否则会形成连续取数长度 ≥ 3），
        // 因此只能从 dp[i-3] 转移，加上 a[i-1] + a[i]
        dp[i] = max(dp[i-1], dp[i-3] + a[i-1] + a[i]);
    }

    cout << dp[n] << endl;
    return 0;
}
```
