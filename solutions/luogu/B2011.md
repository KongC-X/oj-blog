# B2011 计算分数的浮点数值

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-20

## 题目描述

两个整数 $a$ 和 $b$ 分别作为分子和分母，即分数 $\dfrac{a}{b}$，求它的浮点数值（双精度浮点数，保留小数点后 $9$ 位）。

## 输入格式

输入仅一行，包括两个整数 $a$ 和 $b$。

## 输出格式

输出也仅一行，分数 $\dfrac{a}{b}$ 的浮点数值（双精度浮点数，保留小数点后 $9$ 位）。

## 样例

**样例输入 #1**
```
5 7```

**样例输出 #1**
```
0.714285714```

## AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
double a,b;
int main(){
    cin>>a>>b;
    cout<<fixed<<setprecision(9)<<a*1.0/b;
	return 0;
}

```
