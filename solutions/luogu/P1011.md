# P1011 [NOIP 1998 提高组] 车站

> **洛谷** | 普及- | C++14 | 提交时间: 2026-06-13

**算法标签**：`递归`、`树`、`构造`

## 题目描述

火车从始发站（称为第 $1$ 站）开出，在始发站上车的人数为 $a$，然后到达第 $2$ 站，在第 $2$ 站有人上、下车，但上、下车的人数相同，因此在第 $2$ 站开出时（即在到达第 $3$ 站之前）车上的人数保持为 $a$ 人。从第 $3$ 站起（包括第 $3$ 站）上、下车的人数有一定规律：上车的人数都是前两站上车人数之和，而下车人数等于上一站上车人数，一直到终点站的前一站（第 $n-1$ 站），都满足此规律。现给出的条件是：共有 $n$ 个车站，始发站上车的人数为 $a$，最后一站下车的人数是 $m$（全部下车）。试问 $x$ 站开出时车上的人数是多少？

## 输入格式

输入只有一行四个整数，分别表示始发站上车人数 $a$，车站数 $n$，终点站下车人数 $m$ 和所求的站点编号 $x$。

## 输出格式

输出一行一个整数表示答案：从 $x$ 站开出时车上的人数。

## 样例

**样例输入 #1**
```
5 7 32 4
```

**样例输出 #1**
```
13
```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int a, n, m, x;                // a:始发站上车, n:车站数, m:终点下车, x:查询站
    cin >> a >> n >> m >> x;

    if (n == 2) {                  // 只有两站
        if (m == a) {
            if (x == 1) cout << a << endl;
            else        cout << 0 << endl;
        }
        return 0;
    }

    // 枚举第2站上车人数 b，范围 0 ~ m（显然 b 不会超过 m）
    for (int b = 0; b <= m; b++) {
        int u[25], p[25];          // u[i]:上车人数, p[i]:开出时车上人数
        u[1] = a;  p[1] = a;
        u[2] = b;  p[2] = a;       // 第2站上下车相同，开出仍为a

        for (int i = 3; i <= n; i++) {
            u[i] = u[i-1] + u[i-2];          // 上车 = 前两站上车之和
            p[i] = p[i-1] + u[i-2];          // 下车 = 上一站上车人数，所以净增 u[i-2]
        }

        // 第 n-1 站开出时的人数应为 m（终点站全部下车）
        if (p[n-1] == m) {
            // 找到合法的 b，输出第 x 站开出时人数
            if (x >= 1 && x <= n) cout << p[x] << endl;
            else                  cout << 0 << endl;
            return 0;
        }
    }

    return 0;
}
```
