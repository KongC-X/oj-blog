# B4104 [CSP-X2024 山东] 购物

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-12

**算法标签**：`2024`、`山东`、`CSP-X 小学组`

## 题目描述

双十一，很多人在疯狂地购物。

商家推出了各种各样的优惠活动，吸引顾客购买更多的商品。

某商家推出如下的优惠活动：

该商家共有 $n$ 件商品，单独购买第 $i$ 件商品的费用为 $a_i$。顾客也可以花费 $w$ 购买 一张优惠券，一张优惠券最多可兑换 $m$ 件商品（无需额外付费）。顾客可以购买任意张优惠券；

如果最后商品不足 $m$ 件，优惠券也可以使用。

求顾客购买完所有 $n$ 件商品的最小费用。

## 输入格式

第一行有 $3$ 个整数 $n, m, w$。

第二行有 $n$ 个整数，第 $i$ 个为 $a_i$，表示第 $i$ 件商品的费用。

## 输出格式

购买所有商品的最小费用。

## 样例

**样例输入 #1**
```
5 2 8
2 7 1 8 4```

**样例输出 #1**
```
15```

**样例输入 #2**
```
5 3 8
6 7 4 8 9```

**样例输出 #2**
```
16```

## AC 代码

```cpp
#include <cstdio>
#include <algorithm>
using namespace std;

// 数据范围较大，要开 long long 
long long num, cnt, ans;   // num: 当前组商品价格之和, cnt: 当前组商品数, ans: 最终答案
long long n, m, w, a[200005];

int main() {
    /*
     * 题目类型：贪心 + 排序
     * 核心思路：
     * 1. 购买一张优惠券花费 w，最多可兑换 m 件商品（免去这些商品的价格）。
     * 2. 为了最小化总花费，应当让优惠券覆盖尽可能贵的商品（因为节省更多）。
     * 3. 将商品价格从高到低排序（这里用升序然后倒序访问）。
     * 4. 每次取最贵的 m 件商品作为一组，如果这一组商品的总价 >= w，
     *    则购买一张优惠券覆盖它们（花费 w），否则直接购买这一组商品（花费总价）。
     * 5. 对每一组都做上述选择，累加费用即可。
     * 6. 如果最后剩余商品不足 m 件，也作为一组按同样方式处理。
     *
     * 为什么贪心正确？
     * 因为优惠券是“最多 m 件”，且可以随意组合。我们希望被优惠券覆盖的商品尽量贵，
     * 而没有被覆盖的商品尽量便宜。所以按价格从高到低分组，每组用券或直接买，
     * 这样能保证在最贵的商品上使用优惠券的决策是最优的（局部最优构成全局最优）。
     */

    scanf("%lld%lld%lld", &n, &m, &w);
    for (int i = 1; i <= n; i++) scanf("%lld", &a[i]);

    // 升序排序，便于从后向前遍历（即从大到小）
    sort(a + 1, a + 1 + n);

    // 倒序遍历，每次取 m 件为一组
    for (int i = n; i >= 1; i--) {
        num += a[i];   // 累加当前组商品价格
        cnt++;         // 当前组商品数量加 1

        // 当凑够 m 件时，处理这一组
        if (cnt == m) {
            // 这一组商品要么用券（花费 w），要么直接买（花费 num），取较优
            ans += (num < w ? num : w);
            // 重置当前组
            num = cnt = 0;
        }
    }

    // 处理最后剩余不足 m 件的组（如果有）
    ans += (num < w ? num : w);

    printf("%lld\n", ans);
    return 0;
}
```
