# B4037 [GESP202409 二级] 小杨的 N 字矩阵

> **洛谷** | 入门 | C++14 | 提交时间: 2025-03-28

**算法标签**：`模拟`、`费用流`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1158>

## 题目描述

小杨想要构造一个 $m \times m$ 的 $N$ 字矩阵（$m$ 为奇数），这个矩阵的从左上角到右下角的对角线、第 $1$ 列和第 $m$ 列都是半角加号 `+` ，其余都是半角减号 `-` 。例如，一个 $5 \times 5$ 的 N 字矩阵如下：

```plain
+---+
++--+
+-+-+
+--++
+---+
```

请你帮小杨根据给定的 $m$ 打印出对应的 N 字矩阵。

## 输入格式

输入只有一行包含一个正整数 $m$。

## 输出格式

输出对应的 $N$ 字矩阵。

## 样例

**样例输入 #1**
```
5```

**样例输出 #1**
```
+---+
++--+
+-+-+
+--++
+---+```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
	int n,i,j;
	cin >> n;
	for(i = 1;i <= n;i++) {
		for(j = 1;j <= n;j++) {
			if(j == 1 || j == n) {
				cout << '+';
			}else if(i == j) {
				cout << '+';
			}else {
				cout << '-';
			}
		}
		cout << endl;
	}
	return 0;
}
```
