# B4121 [语言月赛 202501] 会场座位

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-28

**算法标签**：`2025`、`分支结构`、`语言月赛`

## 题目描述

一个会场有 $100$ 个座位，座位的编号从左到右依次是 $99,97,\ldots,7,5,3,1,0,2,4,6,\ldots,96,98$。

给出两个**不同的**座位 $a,b$，请判断座位 $a,b$ 之间间隔了多少个座位。

## 输入格式

输入一行两个**不同的**自然数 $a,b$，表示两个座位。

## 输出格式

输出一行一个自然数，表示间隔的座位数量。

## 样例

**样例输入 #1**
```
2 5
```

**样例输出 #1**
```
3
```

**样例输入 #2**
```
2 6
```

**样例输出 #2**
```
1
```

**样例输入 #3**
```
85 83
```

**样例输出 #3**
```
0
```

## AC 代码

```cpp
#include <iostream>
#include <cmath>    // abs 函数
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;

    // 思路：
    // 座位排列：奇数降序（99,97,...,1）、0、偶数升序（2,4,...,98）。
    // 定义“中缝”为 0 和 1 之间的位置。
    // 座位 x 到中缝的座位个数恰好为 ⌊x/2⌋（即 x/2 向下取整）。
    // 分两种情况：
    //   1. a,b 奇偶性不同 → 分别位于中缝两侧 → 间隔数 = ⌊a/2⌋ + ⌊b/2⌋
    //   2. a,b 奇偶性相同 → 在中缝同一侧 → 间隔数 = |⌊a/2⌋ - ⌊b/2⌋| - 1

    int ha = a / 2;    // ⌊a/2⌋
    int hb = b / 2;    // ⌊b/2⌋

    int ans;
    if ((a % 2) == (b % 2)) {
        // 同侧：间隔 = 两位置到中缝的座位数之差 - 1
        ans = abs(ha - hb) - 1;
    } else {
        // 异侧：间隔 = 两位置到中缝的座位数之和
        ans = ha + hb;
    }

    cout << ans << endl;
    return 0;
}
```
