# B2085 第 n 小的质数

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-04

## 题目描述

输入一个正整数 $n$，求正整数范围中第 $n$ 小的质数。

## 输入格式

一个不超过 $30000$ 的正整数 $n$。

## 输出格式

第 $n$ 小的质数。

## 样例

**样例输入 #1**
```
10
```

**样例输出 #1**
```
29```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAX = 400000;           // 筛法上界，确保能找到第 30000 个质数

int main() {
    int n;                        // n：要找第 n 小的质数
    cin >> n;

    // ---------- 思路 ----------
    // 用埃拉托色尼筛法预处理出所有不超过 MAX 的质数，
    // 然后依次输出第 n 个质数即可。
    // 第 30000 个质数约为 350377，因此 MAX=400000 足够安全。
    // -------------------------

    bool isP[MAX + 5];            // 标记是否为质数，true 表示是质数
    memset(isP, 1, sizeof(isP));  // 初始假设全是质数
    isP[0] = isP[1] = false;      // 0 和 1 不是质数

    for (int i = 2; i * i <= MAX; i++) {
        if (isP[i]) {
            for (int j = i * i; j <= MAX; j += i) {
                isP[j] = false;   // 标记 i 的倍数为合数
            }
        }
    }

    int cnt = 0, ans = 0;         // cnt：已找到的质数个数，ans：第 n 个质数
    for (int i = 2; i <= MAX; i++) {
        if (isP[i]) {
            cnt++;
            if (cnt == n) {
                ans = i;
                break;
            }
        }
    }

    cout << ans << endl;
    return 0;
}
```
