# B4198 [常州市赛 2020] 比赛

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-17

**算法标签**：`2020`、`江苏`、`分支结构`、`循环结构`、`科创活动`、`小学活动`

## 题目背景

搬运自 <http://czoj.com.cn/p/446>。数据为民间数据。

## 题目描述

小 $\text X$ 参加了一场作文比赛的初赛。算上小 $\text X$ ，他的学校一共有 $n$ 个人参加了这场比赛。一个礼拜后，小 $\text X$ 兴奋地打开比赛官网，发现一等奖、二等奖、三等奖的分数线和所有人的得分都已经公布了，但没有提到获得什么奖项才能进入复赛。小 $\text X$ 想问问你，如果要获得了 $A$ 等奖才能进入复赛的话，他的学校有多少人能进入复赛呢？  

假设 $A$ 等奖的分数线是 $x$，一个人的分数是 $y$，那么如果 $y$ 大于等于 $x$，这个人就获得了 $A$ 等奖。

## 输入格式

输入数据共有四行。  

第一行一个正整数 $n$，表示小 $\text X$ 的学校一共有 $n$ 个人参加了比赛。  
第二行 $n$ 个正整数，表示小 $\text X$ 的学校中所有人的得分。  
第三行三个正整数 $L_3,L_2,L_1$，分别表示三等奖、二等奖、一等奖的分数线。  
第四行一个正整数 $A$，表示要获得了 $A$ 等奖才能进入复赛。

## 输出格式

输出一行包含一个整数，表示有多少人进入复赛。

## 样例

**样例输入 #1**
```
4
99 101 200 300
100 200 300
2```

**样例输出 #1**
```
2```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 1. 读入参赛人数 n。
    // 2. 读入 n 个人的得分，存入数组 a。
    // 3. 读入三等奖、二等奖、一等奖的分数线 L3, L2, L1。
    // 4. 读入需要达到的奖项等级 A。
    // 5. 根据 A 确定分数线：一等奖对应 L1，二等奖对应 L2，三等奖对应 L3。
    // 6. 遍历所有得分，统计大于等于该分数线的人数。
    // 7. 输出人数。

    int n;                          // n: 参赛人数
    cin >> n;

    int a[10010];                   // 存储每个人的得分，n 最大 10000，多开10个
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int L3, L2, L1;                 // 三等奖、二等奖、一等奖分数线
    cin >> L3 >> L2 >> L1;

    int A;                          // 需要达到的奖项等级
    cin >> A;

    int line;                       // line: 对应的分数线
    if (A == 1) line = L1;
    else if (A == 2) line = L2;
    else line = L3;                 // A == 3

    int cnt = 0;                    // cnt: 进入复赛的人数
    for (int i = 0; i < n; i++) {
        if (a[i] >= line) {
            cnt++;
        }
    }

    cout << cnt << endl;
    return 0;
}
```
