# B3654 [语言月赛202208] 影子字符串

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-21

**算法标签**：`2022`、`字符串（入门）`、`语言月赛`

## 题目背景

众所周知，影子并不是实际物体。

## 题目描述

给出多个字符串（数目未知），**每行**一个。

其中有可能会有重复的字符串，而我们认为在这些字符串中，较靠后出现的都是靠前出现的字符串的“**影子**”。

例如，

```plain
abc
def
abc
abc
abc
```

我们在第 $1,3,4,5$ 行都出现了字符串 `abc`，那么 $3,4,5$ 行的字符串会被称为“影子字符串”。

现在要求把所有的**非影子字符串**都按照**行号从小到大**依次拼接为一个长串并输出。

## 输入格式

多个字符串，每行一个，含义见题目描述。

**注意：输入结尾以字符串 `0` 结束（即一行里仅有一个 `0`）。**

## 输出格式

共一行，表示所有非影子字符串按照行号从小到大依次拼接成的一个长串。

## 样例

**样例输入 #1**
```
cc
b
a
cc
0```

**样例输出 #1**
```
ccba```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3654 [语言月赛202208] 影子字符串
     * 题意：输入多行字符串，以单独 "0" 结束。重复出现的字符串（第一次之后）都是影子，
     *       只保留第一次出现（非影子）按原顺序拼接输出。
     *
     * 思路：用数组 seen 记录已经出现过的非影子字符串，每次读入新字符串时，
     *       在 seen 中查找是否已存在。若不存在，则加入并拼接到答案。
     *       最多 500 个不同字符串，直接线性查找即可。
     */
    string s, ans;
    string seen[505];   // seen: 存储已出现过的非影子字符串
    int cnt = 0;        // cnt: 已出现的非影子字符串个数

    while (cin >> s && s != "0") {
        bool found = false;
        // 检查是否已经出现过
        for (int i = 0; i < cnt; i++) {
            if (seen[i] == s) {
                found = true;
                break;
            }
        }
        if (!found) {
            ans += s;           // 拼接
            seen[cnt++] = s;    // 加入记录
        }
    }

    cout << ans << endl;
    return 0;
}
```
