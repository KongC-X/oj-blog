# P1226 【模板】快速幂

> **洛谷** | 普及- | C++14 | 提交时间: 2026-04-21

**算法标签**：`递归`、`暴力枚举`、`最小环`

## 题目描述

给你三个整数 $a,b,p$，求 $a^b \bmod p$。

## 输入格式

输入只有一行三个整数，分别代表 $a,b,p$。

## 输出格式

输出一行一个字符串 `a^b mod p=s`，其中 $a,b,p$ 分别为题目给定的值， $s$ 为运算结果。

## 样例

**样例输入 #1**
```
2 10 9
```

**样例输出 #1**
```
2^10 mod 9=7
```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    // 使用 long long 防止乘法溢出（int 最大约 2e9，两数相乘可能达 1e18）
    long long a, b, p;
    cin >> a >> b >> p;

    // n 存放最终结果，初始为 a^0 = 1，注意当 p=1 时任何数模 1 都是 0，所以写成 1 % p
    long long n = 1 % p;
    // m 存放 a^(2^k) mod p，初始为 a^1 mod p
    long long m = a % p;
    // e 存放剩余的指数，每次循环右移一位（除以2）
    long long e = b;

    // 快速幂核心：把指数 b 拆成二进制，例如 10 = 8+2 = 2^3 + 2^1
    // 对应 a^10 = a^8 × a^2
    // 我们只需要在二进制位为 1 时乘上对应的 base（a 的 2 的幂次方）
    while (e > 0) {
        // 判断当前二进制最低位是否为 1（等价于 e % 2 == 1）
        // 如果是 1，说明需要乘上当前的 m
        if (e % 2 == 1) {
            n = (n * m) % p;   // 乘上 m 并取模，防止溢出
        }
        // m 平方，相当于指数翻倍：a^(2^k) -> a^(2^(k+1))
        m = (m * m) % p;
        // 指数右移一位，相当于去掉已经处理过的最低位
        e /= 2;
    }

    // 按题目要求的格式输出
    cout << a << "^" << b << " mod " << p << "=" << n << endl;

    return 0;
}
```
