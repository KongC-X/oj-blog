# P1478 陶陶摘苹果（升级版）

> **洛谷** | 普及- | C++14 | 提交时间: 2026-02-05

**算法标签**：`二分`、`随机化`、`队列`、`最近公共祖先`

## 题目描述

又是一年秋季时，陶陶家的苹果树结了 $n$ 个果子。陶陶又跑去摘苹果，这次他有一个 $a$ 公分的椅子。当他手够不着时，他会站到椅子上再试试。

这次与 NOIp2005 普及组第一题不同的是：陶陶之前搬凳子，力气只剩下 $s$ 了。当然，每次摘苹果时都要用一定的力气。陶陶想知道在 $s<0$ 之前最多能摘到多少个苹果。

现在已知 $n$ 个苹果到达地上的高度 $x_i$，椅子的高度 $a$，陶陶手伸直的最大长度 $b$，陶陶所剩的力气 $s$，陶陶摘一个苹果需要的力气 $y_i$，求陶陶最多能摘到多少个苹果。

## 输入格式

第 $1$ 行：两个数 苹果数 $n$，力气 $s$。

第 $2$ 行：两个数 椅子的高度 $a$，陶陶手伸直的最大长度 $b$。

第 $3$ 行~第 $3+n-1$ 行：每行两个数 苹果高度 $x_i$，摘这个苹果需要的力气 $y_i$。

## 输出格式

只有一个整数，表示陶陶最多能摘到的苹果数。

## 样例

**样例输入 #1**
```
8 15
20 130
120 3
150 2
110 7
180 1
50 8
200 0
140 3
120 2```

**样例输出 #1**
```
4```

## AC 代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

// 苹果结构体
struct Apple {
    int h;  // 高度
    int c;  // 花费力气
};

// 比较函数：按花费力气升序
bool cmp(const Apple &a, const Apple &b) {
    return a.c < b.c;
}

Apple all[5005];    // 所有苹果
Apple ok[5005];     // 可摘的苹果
int cnt = 0;        // 可摘苹果数量

int main() {
    int n, s;       // 苹果数，剩余力气
    int a, b;       // 椅子高度，手臂长度
    
    cin >> n >> s;
    cin >> a >> b;
    
    int max_h = a + b;  // 能够到的最大高度
    
    // 读入所有苹果
    for (int i = 0; i < n; i++) {
        cin >> all[i].h >> all[i].c;
    }
    
    // 筛选可摘的苹果
    for (int i = 0; i < n; i++) {
        if (all[i].h <= max_h) {
            ok[cnt].h = all[i].h;
            ok[cnt].c = all[i].c;
            cnt++;
        }
    }
    
    // 按花费力气排序（贪心：先摘花费力气小的）
    sort(ok, ok + cnt, cmp);
    
    int ans = 0;        // 摘到的苹果数
    int left = s;       // 剩余力气
    
    // 贪心摘苹果
    for (int i = 0; i < cnt; i++) {
        if (left >= ok[i].c) {  // 力气足够
            ans++;               // 摘到苹果
            left -= ok[i].c;     // 消耗力气
        } else {
            break;               // 力气不够，结束
        }
    }
    
    cout << ans << endl;
    
    return 0;
}
```
