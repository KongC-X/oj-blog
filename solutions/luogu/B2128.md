# B2128 素数个数

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-13

**算法标签**：`函数与递归`

## 题目描述

编程求 $2\sim n$（$n$ 为大于等于 $2$ 的正整数）中有多少个素数。

## 输入格式

输入 $n(2 \le n \le 50000)$。

## 输出格式

输出一行，表示 $2\sim n$ 中的素数个数。

## 样例

**样例输入 #1**
```
10
```

**样例输出 #1**
```
4
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 判断 x 是否为素数
bool isPrime(int x) {
    if (x < 2) return false;          // 小于2不是素数
    for (int i = 2; i * i <= x; i++) { // 只需检查到 sqrt(x)
        if (x % i == 0) return false; // 能被整除则不是素数
    }
    return true;                      // 没找到因数，是素数
}

int main() {
    int n;                            // n: 范围上限
    cin >> n;

    int cnt = 0;                      // cnt: 素数个数
    for (int i = 2; i <= n; i++) {    // 遍历 2~n
        if (isPrime(i)) {             // 调用函数判断
            cnt++;
        }
    }

    cout << cnt << endl;
    return 0;
}
```
