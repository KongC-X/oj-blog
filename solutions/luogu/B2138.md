# B2138 最大质因子序列

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-14

**算法标签**：`函数与递归`

## 题目描述

任意输入两个正整数 $m,n$（$2\le m\le n\le5000$），依次输出 $m$ 到 $n$ 之间每个数的最大质因子（包括 $m$ 和 $n$；如果某个数本身是质数，则输出这个数自身）。

## 输入格式

一行，包含两个正整数 $m$ 和 $n$，其间以单个空格间隔。

## 输出格式

一行，每个整数的最大质因子，以逗号间隔。

## 样例

**样例输入 #1**
```
5 10```

**样例输出 #1**
```
5,3,7,2,3,5```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 函数：返回正整数 x 的最大质因子
int maxPrimeFactor(int x) {
    int maxp = 1;                       // 记录当前找到的最大质因子
    for (int i = 2; i * i <= x; i++) {  // 试除到 sqrt(x)
        while (x % i == 0) {            // 只要还能被 i 整除
            maxp = i;                   // 更新最大质因子
            x /= i;                     // 除去这个质因子
        }
    }
    if (x > 1) maxp = x;                // 最后剩下的就是最大的质因子
    return maxp;
}

int main() {
    // 思路：遍历 m 到 n，用 maxPrimeFactor 函数求每个数的最大质因子，
    // 按格式输出，用逗号隔开。
    int m, n;                           // m,n: 范围端点
    cin >> m >> n;

    for (int i = m; i <= n; i++) {
        if (i > m) cout << ',';         // 第一个数前不加逗号
        cout << maxPrimeFactor(i);
    }
    cout << endl;
    return 0;
}
```
