# B4151 [厦门小学生 C++ 2022] 成绩分化

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-16

**算法标签**：`2022`、`福建`、`循环结构`、`科创活动`、`小学活动`

## 题目背景

本试题为 2022 年厦门市小学生 C++ 语言**复赛**试题，数据为洛谷自造。

**初赛**为笔试。

## 题目描述

期中考结束，高老师想知道班级学生成绩两极分化的情况，以便采取有效的措施来解决此问题。已知高老师班上共有 $n$ 个学生，每个学生有一个 $0\sim 100$ 分的整数成绩，现在高老师请会编程的你帮忙计算班里学生成绩最高分与最低分的差值。

## 输入格式

第一行，一个整数，表示班级的学生人数。 

接下来 $n$ 行，每行一个整数，表示一个学生的期中考成绩。

## 输出格式

输出一行，包括一个整数，表示最高分与最低分的差值。

## 样例

**样例输入 #1**
```
5
68
57
76
85
80```

**样例输出 #1**
```
28```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;                           // n: 学生人数
    cin >> n;

    int mx = -1, mn = 101;           // mx: 最高分，初始比0小；mn: 最低分，初始比100大
    for (int i = 0; i < n; i++) {
        int x;                       // x: 当前学生的成绩
        cin >> x;
        if (x > mx) mx = x;          // 更新最高分
        if (x < mn) mn = x;          // 更新最低分
    }

    cout << mx - mn << endl;         // 输出差值
    return 0;
}
```
