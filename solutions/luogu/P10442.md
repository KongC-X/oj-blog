# P10442 「MYOI-R3」字符串

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-27

**算法标签**：`模拟`、`字符串`、`洛谷原创`、`O2优化`、`洛谷月赛`

## 题目描述

给定字符串 $s,t$。

现在你要在 $s,t$ 中删除一些字符并将它们重新排列使 $s=t$。

问操作后的 $|s|$（即字符串 $s$ 的长度）最大是多少？

## 输入格式

第一行一个字符串 $s$。

第二行一个字符串 $t$。

## 输出格式

一行一个整数，表示操作后的 $|s|$ 的最大值。

## 样例

**样例输入 #1**
```
abc
bc```

**样例输出 #1**
```
2```

**样例输入 #2**
```
aaaaa
bbbbb```

**样例输出 #2**
```
0```

## AC 代码

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    // 思路：
    // 问题等价于从 s 和 t 中选出相同的字符集，使得字符总数最大。
    // 由于可以任意删除和重新排列，顺序不重要，只需每种字母在 s 和 t 中都能凑出。
    // 因此对于每个小写字母 c，取 min(cnt_s[c], cnt_t[c])，求和即为答案。
    string s, t;
    cin >> s >> t;

    int cnt1[26] = {0};  // s 中各字母出现次数
    int cnt2[26] = {0};  // t 中各字母出现次数

    for (int i = 0; i < s.size(); i++) {
        cnt1[s[i] - 'a']++;
    }
    for (int i = 0; i < t.size(); i++) {
        cnt2[t[i] - 'a']++;
    }

    int ans = 0;
    for (int i = 0; i < 26; i++) {
        ans += min(cnt1[i], cnt2[i]);
    }

    cout << ans << endl;
    return 0;
}
```
