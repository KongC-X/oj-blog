# B4228 [常州市赛 2024] 盒子

> **洛谷** | 普及- | C++14 | 提交时间: 2026-07-28

**算法标签**：`贪心`、`2024`、`江苏`、`排序`、`双指针 two-pointer`、`科创活动`

## 题目背景

搬运自 <http://czoj.com.cn/p/954>。数据为民间数据。

## 题目描述

小 Y 有 $n$ 个盒子，第 $i$ 个盒子的大小是 $a_i$，小 Y 保证 $a_i$ 一定是 $2$ 的若干次方，比如 $1,2,4,8,16,32,64,128,256,512,1024\cdots$，一个大小为 $a_i$ 的盒子的容量是 $\dfrac{a_i}2$，就是说它可以装下总大小不超过 $\dfrac{a_i}2$ 的其他盒子，特别地，大小为 $1$ 的盒子不能装下其他盒子。并且，装在盒子里的盒子也可以装其他盒子，比如，大小为 $8$ 的盒子可以装下一个大小为 $4$ 的盒子且大小为 $4$ 的盒子事先已经装了一个大小为 $2$ 的盒子。

现在小 Y 想知道，最少能有多少个不被其他盒子装下的盒子？

## 输入格式

第一行 $1$ 个正整数 $n$，表示盒子的数量。

第二行 $n$ 个正整数 $a_i$，表示每个盒子的大小，保证 $a_i$ 一定是 $2$ 的若干次方。

## 输出格式

一行一个正整数表示最少能有多少个不被其他盒子装下的盒子。

## 样例

**样例输入 #1**
```
5
1 2 1 1 8```

**样例输出 #1**
```
1```

**样例输入 #2**
```

1 1 1```

**样例输出 #2**

3```

**样例输入 #3**

3```

1```

## AC 代码

```cpp
#include <bits/stdc++.h> 
#define int long long              // 数据可能较大，全部改用 long long 存储
using namespace std;

const int maxn = 100005;
int n, a[maxn], c[maxn], ans;

signed main() {
    cin >> n;
    ans = n;                        // 初始时假设每个盒子都独立，没有被其他盒子装

    for (int i = 1; i <= n; i++) 
        cin >> a[i];

    // 贪心前必须把盒子从小到大排序
    sort(a + 1, a + n + 1);

    // 计算每个盒子的剩余容量：容量 = 自身大小 / 2
    for (int i = 1; i <= n; i++) 
        c[i] = a[i] / 2;

    /*
      双指针贪心过程：
        i 指向当前要尝试被装进其他盒子的小盒子（从小到大）
        j 指向当前考虑的大盒子（容量较大，可能装下小盒子）
        每次检查第 j 个盒子能否装下第 i 个盒子：
          - 若能装下，更新第 j 个盒子的剩余容量，小盒子被装走（i++），
            成功装入一次就意味着最终顶层盒子数 ans 减少 1。
          - 若装不下，说明当前大盒子不够大，需要换更大的盒子（j++）。
        每个小盒子最多被装一次，每个大盒子的容量也只被用来装更小的盒子。
    */
    for (int i = 1, j = 2; j <= n; ) {
        if (c[j] >= a[i]) {        // 大盒子 j 能装下小盒子 i
            c[j] -= a[i];          // 占用大盒子对应容量
            i++;                   // 小盒子被处理，指针后移
            ans--;                 // 顶层盒子总数减少 1
        } else {
            j++;                   // 当前大盒子装不下，试下一个更大的盒子
        }
    }

    cout << ans;                   // 输出最少顶层盒子数
    return 0;
}
```
