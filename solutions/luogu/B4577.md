# B4577 [GESP202609 三级] 公共二进制位

> **洛谷** | 普及- | C++14 | 提交时间: 2026-09-16

**算法标签**：`进制`、`位运算`、`2026`、`GESP`

## 题目描述

小红有 $n$ 个非负整数 $a_1,a_2,\ldots,a_n$。她将每个整数转换为二进制后，想知道有多少个二进制位在所有整数中均为 $1$。

二进制位从右向左编号为 $0,1,2,\ldots$。若某个整数的二进制表示中没有第 $k$ 位，则认为它的第 $k$ 位为 $0$。

请你求出满足条件的二进制位数量。

## 输入格式

- 第一行一个整数 $n$，表示整数的个数。
- 第二行 $n$ 个非负整数 $a_1,a_2,\ldots,a_n$。

## 输出格式

输出一个整数，表示所有整数的二进制表示中均为 $1$ 的二进制位数量。

## 样例

**样例输入 #1**
```
3
13 7 15```

**样例输出 #1**
```
2```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B4577 [GESP202609 三级] 公共二进制位
     * 题意：给出 n 个非负整数，统计有多少个二进制位在所有整数中均为 1。
     *       位从右向左编号 0,1,2,...，不存在的位视为 0。
     *
     * 思路：
     *   枚举每一个二进制位 b（0 到 30，因为 10^9 < 2^30，31 位足够）。
     *   对于每个位 b，检查所有数的第 b 位是否都是 1。
     *   如果全部都是 1，则答案加 1。
     *
     * 时间复杂度：O(n * 31)，n ≤ 20000，非常快。
     */
    int n;                 // n: 整数个数
    cin >> n;

    int a[20005];          // a[i]: 第 i 个整数
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int ans = 0;           // ans: 公共为 1 的二进制位数量

    // 枚举二进制位，0 到 30（覆盖 10^9 的范围）
    for (int b = 0; b <= 30; b++) {
        bool ok = true;    // ok: 当前位是否所有数都为 1
        for (int i = 0; i < n; i++) {
            // 取出 a[i] 的第 b 位
            if (((a[i] >> b) & 1) == 0) {
                ok = false;
                break;
            }
        }
        if (ok) ans++;
    }

    cout << ans << endl;
    return 0;
}
```
