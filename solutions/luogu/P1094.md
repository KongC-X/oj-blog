# P1094 [NOIP 2007 普及组] 纪念品分组

> **洛谷** | 普及- | C++14 | 提交时间: 2026-02-08

**算法标签**：`二分`、`背包`、`字符串模拟`、`队列`

## 题目背景

NOIP2007 普及组 T2

## 题目描述

元旦快到了，校学生会让乐乐负责新年晚会的纪念品发放工作。为使得参加晚会的同学所获得的纪念品价值相对均衡，他要把购来的纪念品根据价格进行分组，但每组最多只能包括两件纪念品，并且每组纪念品的价格之和不能超过一个给定的整数。为了保证在尽量短的时间内发完所有纪念品，乐乐希望分组的数目最少。

你的任务是写一个程序，找出所有分组方案中分组数最少的一种，输出最少的分组数目。

## 输入格式

共 $n+2$ 行：

第一行包括一个整数 $w$，为每组纪念品价格之和的上限。

第二行为一个整数 $n$，表示购来的纪念品的总件数 $G$。

第 $3\sim n+2$ 行每行包含一个正整数 $P_i$ 表示所对应纪念品的价格。

## 输出格式

一个整数，即最少的分组数目。

## 样例

**样例输入 #1**
```
100 
9 
90 
20 
20 
30 
50 
60 
70 
80 
90
```

**样例输出 #1**
```
6
```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int p[30005];  // 纪念品价格，最多30000个

int main() {
    int w, n;  // w: 每组上限, n: 纪念品数量
    cin >> w >> n;
    
    // 读入所有纪念品价格
    for (int i = 0; i < n; i++) {
        cin >> p[i];
    }
    
    // 按价格升序排序（方便双指针贪心）
    sort(p, p + n);
    
    int ans = 0;      // 分组数
    int l = 0;        // 左指针（最便宜的）
    int r = n - 1;    // 右指针（最贵的）
    
    // 双指针贪心
    while (l <= r) {
        if (p[l] + p[r] <= w) {
            // 最便宜的和最贵的可以配对
            l++;      // 最便宜的用了
            r--;      // 最贵的用了
        } else {
            // 最贵的不能和任何人配对，单独一组
            r--;      // 只用了最贵的
        }
        ans++;        // 无论配对还是单独，都增加一组
    }
    
    cout << ans << endl;
    
    return 0;
}
```
