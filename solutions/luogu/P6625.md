# P6625 [省选联考 2020 B 卷] 卡牌游戏

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-04

**算法标签**：`贪心`、`2020`、`各省省选`、`前缀和`

## 题目描述

轩轩某天想到了一个卡牌游戏，游戏规则如下：

1. 初始时轩轩的手中有自左向右排成一排的 $n$ 张卡牌，每张卡牌上有一个整数分值。
2. 接下来，轩轩每次可以选取卡牌序列最左边的连续若干张卡牌（至少 $2$ 张），将它们替换为一张新卡牌。新卡牌将插入到序列的最左端，它的分值为本次操作中被替换掉的卡牌的分值之和。
3. 初始时轩轩总分为 $0$，每执行一次卡牌替换操作，新卡牌的分值将加到总分中。当序列长度为 $1$ 时游戏结束，轩轩也可以在任意时刻结束游戏。

现在给出序列中各个卡牌的分值，请你来帮助轩轩计算他能够获得的最高总分是多少？

## 输入格式

第一行一个正整数 $n$，代表卡牌的数目。

接下来一行 $n$ 个以空格分隔的整数，第 $i$ 个数字 $a_i$ 代表自左向右第 $i$ 张卡牌的分值。

## 输出格式

仅一行一个整数表示答案。

## 样例

**样例输入 #1**
```
3
2 -1 2```

**样例输出 #1**
```
4```

**样例输入 #2**
```
7
-4 3 0 7 -3 -5 -3```

**样例输出 #2**
```
9```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】前缀和 + DP
     * 【核心思路】
     * 1. 读取 n 和数组 a[1..n]。
     * 2. 计算前缀和 S[i] = a[1] + ... + a[i]。
     * 3. 从左到右扫描 i = 2..n：
     *    - 维护 mx 表示所有 dp[j] (j < i) 以及 0 的最大值。
     *    - 当前选择 i 作为最后一次操作，获得分数 cur = S[i] + mx。
     *    - 更新 mx = max(mx, cur)。
     * 4. 输出 mx。
     *
     * 为什么这样正确？因为每次操作对应一个前缀和，选择一系列递增下标，
     * 总分等于这些前缀和之和。dp 求最大子序列和变种。
     *
     * 【时间复杂度】O(n)
     */

    int n;          // n: 卡牌数量
    cin >> n;

    long long S = 0;        // S: 当前前缀和
    long long mx = 0;       // mx: 之前所有 dp 以及 0 的最大值

    // 第一个元素单独处理，用于初始化前缀和
    long long first;
    cin >> first;
    S = first;

    // 从第 2 个元素开始处理
    for (int i = 2; i <= n; i++) {
        long long x;        // x: 当前卡牌分值
        cin >> x;
        S += x;             // 更新前缀和 S[i]

        // 如果选择 i 作为最后一次操作，得分 = S[i] + mx
        long long cur = S + mx;
        if (cur > mx) mx = cur;
    }

    cout << mx << endl;
    return 0;
}
```
