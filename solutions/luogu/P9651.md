# P9651 [SNCPC2019] Digit Product

> **洛谷** | 入门 | C++14 | 提交时间: 2026-10-10

**算法标签**：`快速幂`、`入门模拟`、`缩点`

## 题目描述

Define the ''digit product'' $f(x)$ of a positive integer $x$ as the product of all its digits. For example, $f(1234) = 1 \times 2 \times 3 \times 4 = 24$, and $f(100) = 1 \times 0 \times 0 = 0$.

Given two integers $l$ and $r$, please calculate the following value:
$$(\prod_{i=l}^r f(i)) \mod (10^9+7)$$ 
In case that you don't know what $\prod$ represents, the above expression is the same as 
$$(f(l) \times f(l+1) \times \dots \times f(r)) \mod (10^9+7)$$

## 输入格式

There are multiple test cases. The first line of the input contains an integer $T$ (about $10^5$), indicating the number of test cases. For each test case:

The first and only line contains two integers $l$ and $r$ ($1 \le l \le r \le 10^9$), indicating the given two integers. The integers are given without leading zeros.

## 输出格式

For each test case output one line containing one integer indicating the answer.

## 样例

**样例输入 #1**
```
2
1 9
97 99
```

**样例输出 #1**
```
362880
367416
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MOD = 1000000007;   // 模数 10^9+7

// 计算数字 x 的“数字乘积”f(x)
int f(int x) {
    int res = 1;              // res: 乘积结果
    while (x > 0) {
        int d = x % 10;       // 取出当前最低位
        res *= d;             // 乘入结果
        if (res == 0) return 0; // 只要出现 0，乘积必为 0，直接返回
        x /= 10;              // 去掉最低位
    }
    return res;
}

int main() {
    /*
     * 题目：P9651 [SNCPC2019] Digit Product
     * 题意：给定 l, r，计算 ∏_{i=l}^r f(i) mod (10^9+7)，
     *       其中 f(i) 是 i 的所有数字的乘积。
     *       有 T 组测试数据，T 大约 10^5，l, r ≤ 10^9。
     *
     * 关键观察：
     *   1. 如果区间 [l, r] 中包含任何一个含有数字 0 的数，
     *      那么 f(这个数) = 0，整个乘积就是 0。
     *   2. 任意 10 个连续整数中，必有一个数的个位是 0（即含有数字 0）。
     *      因此，如果区间长度 r - l + 1 > 9，则区间内必然含有 0，
     *      答案直接为 0。
     *   3. 如果区间长度 ≤ 9，我们可以直接暴力计算每个 f(i) 并累乘。
     *      最多 9 个数，每个数最多 10 位，计算量极小。
     *
     * 时间复杂度：每组数据 O(1) 判断 + O(9*10) 暴力计算，总 O(T)，T ≤ 1e5。
     */

    int T;
    scanf("%d", &T);
    while (T--) {
        int l, r;
        scanf("%d%d", &l, &r);

        // 如果区间长度 > 9，必然包含数字 0，答案直接为 0
        if (r - l + 1 > 9) {
            printf("0\n");
            continue;
        }

        long long ans = 1;   // ans: 乘积结果
        bool zero = false;   // zero: 是否遇到 f(i) = 0
        for (int i = l; i <= r; i++) {
            int fi = f(i);
            if (fi == 0) {
                zero = true;
                break;
            }
            ans = (ans * fi) % MOD;
        }

        if (zero) {
            printf("0\n");
        } else {
            printf("%lld\n", ans);
        }
    }

    return 0;
}
```
