# P5535 【XR-3】小道消息

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-05-29

**算法标签**：`递归`、`入门模拟`

## 题目描述

小 X 想探究小道消息传播的速度有多快，于是他做了一个社会实验。

有 $n$ 个人，其中第 $i$ 个人的衣服上有一个数 $i+1$。小 X 发现了一个规律：当一个衣服上的数为 $i$ 的人在某一天知道了一条信息，他会在第二天把这条信息告诉衣服上的数为 $j$ 的人，其中 $\gcd(i,j)=1$（即 $i,j$ 的最大公约数为 $1$）。在第 $0$ 天，小 X 把一条小道消息告诉了第 $k$ 个人，小 X 想知道第几天时所有人都会知道这条小道消息。

可以证明，一定存在所有人都知道了这条小道消息的那一天。

提示：你可能需要用到的定理——[伯特兰-切比雪夫定理](https://baike.baidu.com/item/%E4%BC%AF%E7%89%B9%E5%85%B0-%E5%88%87%E6%AF%94%E9%9B%AA%E5%A4%AB%E5%AE%9A%E7%90%86/2053704)。

## 输入格式

一行 $2$ 个正整数 $n,k$。

**数据范围：**

- $2 \le n \le 10^{14}$。
- $1 \le k \le n$。

## 输出格式

一行一个正整数，表示答案。

## 样例

**样例输入 #1**
```
3 1
```

**样例输出 #1**
```
2
```

**样例输入 #2**
```
6 4
```

**样例输出 #2**
```
1
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 判断一个数是否为素数（试除法）
// 因为只有一组数据，sqrt(1e14)=1e7，运算量可以接受
bool isp(long long x) {
    if (x < 2) return false;
    for (long long i = 2; i * i <= x; i++) {
        if (x % i == 0) return false;
    }
    return true;
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    long long n, k;
    cin >> n >> k;

    long long x = k + 1;          // 第 k 个人衣服上的数

    // 根据伯特兰-切比雪夫定理：
    // - 若 x 是质数且 x > (n+1)/2，则 x 与所有其他人的数都互质（因为不会出现 x 的倍数）。
    //   这种情况下，第一天 x 就可以直接把消息传给所有人，答案为 1。
    // - 否则，区间 ((n+1)/2, n+1] 内必定存在一个质数 p。
    //   x 不可能等于 p（否则会落入上一种情况），且 p 不整除 x（因为 p > (n+1)/2 ≥ x/2），
    //   所以 gcd(x, p) = 1。因此：
    //     第 1 天：x 传给 p
    //     第 2 天：p 传给其他所有人（p 与所有数都互质）
    //   总天数为 2。
    if (isp(x) && 2 * x > n + 1) {
        cout << 1 << '\n';
    } else {
        cout << 2 << '\n';
    }

    return 0;
}
```
