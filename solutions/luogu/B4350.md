# B4350 [信息与未来 2025] 美味水果

> **洛谷** | 普及- | C++14 | 提交时间: 2026-04-14

**算法标签**：`二分`、`匈牙利算法`、`CDQ分治`、`队列`

## 题目描述

Dr. X 收到了一份礼物：$n$ 个水果，其中第 $i$ 个水果的好吃程度为 $x_i$。新鲜的水果会随时间变得不如最初好吃：
- 每天，Dr. X 可以选择吃掉一个水果，并记录下该天吃掉的水果的好吃程度。
- 没有被吃掉的每个水果，好吃程度将在第二天变为 $y = \lfloor\sqrt x\rfloor$，即 “开根号取整”：$y$ 是满足 $y^2 ≤ x$ 的最大整数。

请计算，在所有可能的吃水果顺序中，Dr. X 最多能获得多少好吃程度的总和。

## 输入格式

输入包含两行：第一行，一个整数 $n$，表示水果数量；第二行，$n$ 个用空格分隔的整数 $x_1 , x_2 , \cdots, x_n$，表示每个水果的初始好吃程度。

## 输出格式

输出一个整数，表示能够获得的好吃程度总和的最大值。

## 样例

**样例输入 #1**
```
2
100 10```

**样例输出 #1**
```
103```

**样例输入 #2**
```
6
1 3 7 10 15 21```

**样例输出 #2**
```
28```

## AC 代码

```cpp
#include <iostream>
#include <algorithm>
#include <cmath>
using namespace std;

int a[100010];
int n;

// 自定义比较函数：降序排序（大的在前）
bool cmp(int x, int y) {
    return x > y;
}

// 对 x 进行一次衰减：x = floor(sqrt(x))
int fun(int x) {
    return (int)sqrt(x);  // sqrt 返回 double，转 int 自动向下取整
}

int main() {
    /*
     * 思路：
     * 1. 每天吃一个水果，其余水果的好吃程度变为 floor(sqrt(x))。
     * 2. 为了让总和最大，应该优先吃初始值大的水果，避免它们因衰减而大幅变小。
     * 3. 将水果按初始值降序排列。
     * 4. 第 i 个被吃的水果（i 从 0 开始）已经经历了 i 次衰减（前 i 天它都在衰减）。
     *    因此，它的贡献 = 对初始值连续应用 i 次衰减函数后的值。
     * 5. 由于衰减很快（最多约5次就到1），对每个水果直接模拟 i 次衰减即可。
     */

    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    // 降序排序，使用自定义 cmp 函数
    sort(a, a + n, cmp);

    long long sum = 0;
    for (int i = 0; i < n; i++) {
        int v = a[i];
        // 进行 i 次衰减，但最多衰减到 1 即可停止
        int t = i;
        while (t > 0 && v > 1) {
            v = fun(v);
            t--;
        }
        sum += v;
    }

    cout << sum << endl;
    return 0;
}
```
