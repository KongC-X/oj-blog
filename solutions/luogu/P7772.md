# P7772 [COCI 2009/2010 #2] FAKTOR

## 题目背景

本题为[$\texttt{COCI 2009-2010}\ 2^\texttt{nd}\ \texttt{round}\ \text{T1 FAKTOR}$](https://hsin.hr/coci/archive/2009_2010/contest2_tasks.pdf)。

## 题目描述

给定 $A,I$，求一个最小的 $N$，使得$\lceil\frac{N}{A}\rceil\geq I$。

## 输入格式

一行两个整数 $A,I$。

## 输出格式

一行一个整数 $N$。

## 样例

**样例输入 #1**
```
38 24```

**样例输出 #1**
```
875```

**样例输入 #2**
```
1 100```

**样例输出 #2**
```
100```

**样例输入 #3**
```
10 10```

**样例输出 #3**
```
91```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    // 思路：
    // 要求最小的 N，使得 ceil(N / A) >= I。
    // ceil(N / A) >= I 等价于 N > A * (I - 1)。
    // 因此最小的整数 N = A * (I - 1) + 1。

    int A, I;
    cin >> A >> I;

    int N = A * (I - 1) + 1;

    cout << N << endl;
    return 0;
}
```
