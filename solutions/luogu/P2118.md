# P2118 [NOIP 2014 普及组] 比例简化

> **洛谷** | 普及- | C++14 | 提交时间: 2026-05-29

**算法标签**：`递归`、`强连通分量`、`字符串模拟`、`排序算法`

## 题目背景

NOIP2014 普及组 T2

## 题目描述

在社交媒体上，经常会看到针对某一个观点同意与否的民意调查以及结果。例如，对某一观点表示支持的有 $1498$ 人，反对的有 $902$ 人，那么赞同与反对的比例可以简单的记为 $1498:902$。

不过，如果把调查结果就以这种方式呈现出来，大多数人肯定不会满意。因为这个比例的数值太大，难以一眼看出它们的关系。对于上面这个例子，如果把比例记为 $5:3$，虽然与真实结果有一定的误差，但依然能够较为准确地反映调查结果，同时也显得比较直观。

现给出支持人数 $A$，反对人数 $B$，以及一个上限 $L$，请你将 $A$ 比 $B$ 化简为 $A'$ 比 $B'$，要求在 $A'$ 和 $B'$ 均不大于 $L$ 且 $A'$ 和 $B'$ 互质（两个整数的最大公约数是 $1$）的前提下，$\dfrac{A'}{B'} \ge  \dfrac{A}{B}$ 且 $\dfrac{A'}{B'} - \dfrac{A}{B}$ 的值尽可能小。

## 输入格式

共一行，包含三个整数 $A,B,L$，每两个整数之间用一个空格隔开，分别表示支持人数、反对人数以及上限。

## 输出格式

共一行，包含两个整数 $A',B'$，中间用一个空格隔开，表示化简后的比例。

## 样例

**样例输入 #1**
```
1498 902 10```

**样例输出 #1**
```
5 3```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// ==================== 思路 ====================
// 给定 A, B, L，要找一对正整数 A', B'，满足：
// 1. A' <= L, B' <= L
// 2. gcd(A', B') = 1
// 3. A'/B' >= A/B
// 4. 在满足上述条件的前提下，A'/B' - A/B 尽可能小
//
// 数据范围 L ≤ 100，可以直接枚举所有可能的分子 i 和分母 j（1..L）。
// 对于每一对 (i,j)，检查三个条件：
//   - 互质：__gcd(i,j) == 1
//   - 比值不小于 A/B：i*B >= A*j （避免浮点误差，用交叉相乘）
//   - 差值更小：记录历史上差值最小的那一对作为答案
//
// 用两个变量 p, q 存储当前最优分子分母，初始 p = 0 表示未找到。
// 枚举完毕后，p, q 即为答案。
// ===============================================

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);
    
    int A, B, L;
    cin >> A >> B >> L;
    
    int p = 0, q = 1;                // p/q 为当前最优答案，初始 p=0 表示暂未找到
    for (int i = 1; i <= L; i++) {   // 枚举分子 i
        for (int j = 1; j <= L; j++) { // 枚举分母 j
            if (__gcd(i, j) != 1) continue;          // 必须互质
            if (i * B < A * j) continue;             // 保证 i/j >= A/B
            
            if (p == 0) {            // 第一次找到可行解，直接记录
                p = i;
                q = j;
                continue;
            }
            
            // 比较当前解 (i,j) 与最优解 (p,q) 的误差
            // 误差 = i/j - A/B，通分后比较分子即可
            long long d1 = 1LL * i * B - 1LL * A * j;   // (i*B - A*j) / (j*B)
            long long d2 = 1LL * p * B - 1LL * A * q;   // (p*B - A*q) / (q*B)
            if (d1 * q < d2 * j) {   // d1/(j*B) < d2/(q*B) 等价于 d1*q < d2*j
                p = i;
                q = j;
            }
        }
    }
    
    cout << p << ' ' << q << '\n';
    return 0;
}
```
