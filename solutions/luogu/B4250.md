# B4250 [语言月赛 202503] 蛋挞制作工坊

> **洛谷** | 普及- | C++14 | 提交时间: 2026-07-29

**算法标签**：`模拟`、`2025`、`语言月赛`

## 题目描述

Alice 和 Bob 正在教小朋友们制作蛋挞。制作一个蛋挞需要 $m$ 种材料，编号 $1 \sim m$。一个蛋挞当中，材料 $i$ 需要 $g_i$ 克。

有 $n$ 个小朋友（编号为 $1 \sim n$）想要制作蛋挞，其中第 $i$ 个小朋友准备了 $c_{i,j}$ 克的材料 $j$。所有小朋友都用自己准备的材料制作了**尽可能多**的蛋挞。

现在蛋挞已经被食堂叔叔阿姨送进烤箱，小朋友们要排队领取自己的蛋挞，但是领取顺序成了一个难题。

Alice 提倡勤俭节约，所以她会**指定一种材料**，并让所有小朋友按照这种材料的剩余量从少到多排队，这种材料剩余量少的小朋友排在前面。

Bob 鼓励劳动，所以**在 Alice 指定的材料剩余一样多时**，Bob 会让制作出的蛋挞更多的小朋友排在前面；如果制作出的蛋挞也一样多，那么编号小的小朋友排前面。

你现在并不知道 Alice 指定的材料是材料 $1,2,\ldots,m$ 中的哪个，所以你想知道每一种情况下小朋友们的排队结果。

## 输入格式

输入共 $n + 2$ 行。

第一行两个整数 $n, m$，代表小朋友的数量和材料的种类数。

## 输出格式

输出共 $m$ 行，每行 $n$ 个整数。

第 $i$ 行的 $n$ 个整数，代表 Alice 指定的材料编号为 $i$ 时，小朋友排队后由前到后的编号。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 结构体：存储每个小朋友的信息
struct Node {
    int id;               // 编号 (1~n)
    long long cnt;        // 制作的蛋挞数量
    long long left[55];   // 每种材料剩余量（最多50种）
};

int key;     // 全局变量，表示当前排序依据的材料编号（1~m）

// 比较函数，用于 sort
bool cmp(const Node &a, const Node &b) {
    // 1. 按材料 key 的剩余量从小到大
    if (a.left[key] != b.left[key])
        return a.left[key] < b.left[key];
    // 2. 若剩余量相同，按蛋挞数量从大到小
    if (a.cnt != b.cnt)
        return a.cnt > b.cnt;
    // 3. 若蛋挞数量也相同，按编号从小到大
    return a.id < b.id;
}

int main() {
    /*
     * 【题目类型】结构体排序（使用 sort + cmp）
     * 【核心思路】
     * 1. 读入 n, m 和材料需求 g[]。
     * 2. 读入每个小朋友的原料 c[][]。
     * 3. 计算每个小朋友的蛋挞数量 cnt = min(c[i][j] / g[j])。
     * 4. 计算剩余量 left[i][j] = c[i][j] - cnt * g[j]。
     * 5. 对于每种材料 k (1~m)：
     *    - 设置全局 key = k。
     *    - 用 sort 对 stu 数组（下标1~n）排序，排序规则由 cmp 决定。
     *    - 输出排序后的 id。
     *
     * 【时间复杂度】O(m * n log n)，n,m ≤ 50
     */

    int n, m;                 // n: 小朋友数, m: 材料种类
    cin >> n >> m;

    long long g[55];          // g[i]: 制作一个蛋挞需要材料 i 的克数
    for (int i = 1; i <= m; i++) {
        cin >> g[i];
    }

    long long c[55][55];      // c[i][j]: 第 i 个小朋友拥有的材料 j 克数
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            cin >> c[i][j];
        }
    }

    Node stu[55];             // stu[i]: 第 i 个小朋友的信息
    for (int i = 1; i <= n; i++) {
        stu[i].id = i;
        // 计算最大能做多少个蛋挞（取最小值）
        long long cnt = 1e18; // 先设很大的数
        for (int j = 1; j <= m; j++) {
            long long can = c[i][j] / g[j];
            if (can < cnt) cnt = can;
        }
        stu[i].cnt = cnt;
        // 计算剩余每种材料的量
        for (int j = 1; j <= m; j++) {
            stu[i].left[j] = c[i][j] - cnt * g[j];
        }
    }

    // 对每种材料作为排序关键字
    for (int k = 1; k <= m; k++) {
        key = k;   // 设定全局排序依据
        // 对下标 1~n 的元素排序（注意要包含 stu[1] 到 stu[n]）
        sort(stu + 1, stu + n + 1, cmp);

        // 输出排序后的编号
        for (int i = 1; i <= n; i++) {
            cout << stu[i].id;
            if (i < n) cout << ' ';
        }
        cout << endl;
    }

    return 0;
}
```
