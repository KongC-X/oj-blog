# B4007 [GESP202406 二级] 计数

> **洛谷** | 入门 | C++14 | 提交时间: 2025-03-28

**算法标签**：`费用流`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1150>

## 题目描述

小杨认为自己的幸运数是正整数 $k$（注：保证 $1 \le k\le 9$）。小杨想知道，对于从 $1$ 到 $n$ 的所有正整数中， $k$ 出现了多少次。

## 输入格式

第一行包含一个正整数 $n$。

第二行包含一个正整数 $k$。

## 输出格式

输出从 $1$ 到 $n$ 的所有正整数中， $k$ 出现的次数。

## 样例

**样例输入 #1**
```
25
2```

**样例输出 #1**
```
9```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int n,i,a,b,k,s = 0;
    cin >> n >> k;
    for(i = 1; i <= n; i++) {
        a = i; // 不能在循环里修改i的值，把i保存下来
        // 经典的while循环短除法问题
        while(a != 0) {
            b = a % 10;
            if(b == k) {
                s++;
            }
            a = a / 10;
        }
    }
    cout << s;
}
```
