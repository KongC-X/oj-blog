# P7226 [COCI 2015/2016 #3] POT

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-26

**算法标签**：`模拟`、`数学`、`2015`、`COCI（克罗地亚）`

## 题目描述

老师给同学们发了一封电子邮件，任务如下。

> 写一个程序，给你 $n$ 个数，输出 $X$。      
> $$X = num_1^{p_1} + num_2^{p_2} + \cdots + num_n^{p_n}$$         
> $num_1$，$num_2$，$\cdots$，$num_n$ 都是整数，$p_1$，$p_2$，$\cdots$，$p_n$ 都是一位数。    

但是出现了一些玄学错误，使得 $X$ 变成了：
$$X = q_1 + q_2 +... + q_n$$

注：$q_i = num_i \times 10 + p_i$。

例如，原来的 $X$ 为 $21^2+125^3$，但现在变成了 $212+1253$。请帮助老师编写一个程序，输出原来 $X$ 的值。

## 输入格式

第一行，一个正整数 $n$。

接下来 $n$ 行，每行一个整数 $q_i$。

## 输出格式

仅一行一个整数，$X$ 的值。

## 样例

**样例输入 #1**
```
2
212
1253
```

**样例输出 #1**
```
1953566```

**样例输入 #2**
```
5
23
17
43
52
22
```

**样例输出 #2**
```
102```

**样例输入 #3**
```
3
213
102
45
```

**样例输出 #3**
```
10385```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 每个输入 q_i = num_i * 10 + p_i，其中 p_i 是 0~9 的个位数。
    // 所以 num_i = q_i / 10，p_i = q_i % 10。
    // 计算 num_i ^ p_i 并累加即可。
    // 注意 p_i 可能为 0，此时 num_i^0 = 1（题目保证 num_i >= 1）。

    int n;                   // n: 数的个数
    cin >> n;

    long long sum = 0;       // sum: 最终累加结果，用 long long 防溢出
    for (int i = 0; i < n; i++) {
        int q;               // q: 输入的 q_i
        cin >> q;

        int p = q % 10;      // p_i: 个位数（指数）
        int num = q / 10;    // num_i: 去掉个位后的底数

        // 计算 num 的 p 次幂（简单循环，p ≤ 9 很小）
        long long val = 1;
        for (int j = 0; j < p; j++) {
            val *= num;
        }

        sum += val;
    }

    cout << sum << endl;
    return 0;
}
```
