# P2708 硬币翻转

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-07

**算法标签**：`模拟`、`字符串`、`搜索`

## 题目描述

有很多个硬币摆在一行，有正面朝上的，也有背面朝上的。正面朝上的用 $1$ 表示，背面朝上的用 $0$ 表示。

现在要求从这行的第一个硬币开始，将**从第一个硬币开始的前若干个硬币**同时翻面，求如果要将所有硬币翻到正面朝上，最少要进行这样的操作多少次？

## 输入格式

一个字符串，由 $0$ 和 $1$ 组成，表示硬币的初始状态。

## 输出格式

一个整数，表示要翻转的最少次数。

## 样例

**样例输入 #1**
```
10```

**样例输出 #1**
```
2```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】贪心 / 思维
     * 【核心思路】
     * 操作规则：每次可以选择从第一个硬币开始的前若干个硬币（一个前缀）同时翻面。
     * 
     * 关键观察：
     * 1. 翻面操作只会改变前缀区间的状态，不会改变未选中的部分。
     * 2. 最终目标是所有硬币变为 '1'。
     * 3. 从左到右扫描，每当遇到当前字符和前一个字符不同时，意味着这两个位置之间
     *    必须有一次翻转操作，才能让它们变成相同（因为翻转前缀会影响所有位置，
     *    但只有分界点需要额外处理）。
     *    例如 "10"：第一个是1，第二个是0，不同，需要一次翻转（翻转第1个变0，得到"00"）；
     *    再从0到1的不同再需要一次翻转（翻转前两个变1，得到"11"）。所以相邻不同就计数。
     * 4. 另外，如果最后一个字符是 '0'，因为最终要求全部为 '1'，而翻转操作只能翻转前缀，
     *    最后一个字符若为0，则必须通过一次翻转整个字符串（前缀长度为n）来把它变成1，
     *    所以需要额外加1次。
     * 
     * 综上所述：
     *   答案 = (相邻字符不同的次数) + (最后一个字符是否为 '0' ? 1 : 0)
     * 
     * 【时间复杂度】O(n)，n为字符串长度，最坏1e6，完全可行。
     */

    string s;          // s: 输入的硬币状态字符串
    cin >> s;

    int n = s.size();  // n: 字符串长度
    int ans = 0;       // ans: 最少翻转次数

    // 统计相邻不同的次数
    for (int i = 1; i < n; i++) {
        if (s[i] != s[i-1]) {
            ans++;
        }
    }

    // 如果最后一位是 '0'，需要额外一次翻转整个字符串
    if (s[n-1] == '0') {
        ans++;
    }

    cout << ans << endl;
    return 0;
}
```
