# B3760 [信息与未来 2021] 掷骰子

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-04-21

**算法标签**：`快速傅里叶变换`、`CDQ分治`

## 题目背景

骰子是一个正六面体（立方体），每一面上有圆点表示的数字（圆点的数量表示数字的大小）。一个普通的骰子的六个面上分别有 $1\sim 6$ 这 $6$ 个不同的数字：

![](https://cdn.luogu.com.cn/upload/image_hosting/unawcttj.png)

## 题目描述

但是今天你得到了一个特殊的骰子，虽然每个面上的数字依然是 $1\sim 6$ 之间的一个，但不同面上的数字却可能重复。为了还原骰子上的数字，你使用摄像头从不同角度拍摄了多张骰子的照片（骰子可能在空间中任意翻转）。但限于摄像头的角度，你拍摄的每张照片都只能拍到骰子的三个面。

你需要根据摄像头拍摄到的多张照片，推断出骰子每个面上可能的数字。

## 输入格式

输入数据的第一行为一个整数 $n$，代表摄像头拍摄的次数。

接下来 $n$ 行，每行三个整数 $x,y,z(1\leq x,y,z\leq 6)$，代表一次摄像机拍摄到骰子三个面上的数字，如下图所示：

![](https://cdn.luogu.com.cn/upload/image_hosting/i18m9lvu.png)

输入数据保证所有的 $x,y,z$ 都是从同一个骰子拍摄得到的。

## 输出格式

输出一行两个整数（中间用一个空格隔开），分别表示满足摄像头拍摄到结果的骰子上数字和的最小值和最大值。

## 样例

**样例输入 #1**
```
2
1 1 1
2 2 1```

**样例输出 #1**
```
8 13```

**样例输入 #2**
```
2
1 2 3
4 5 6```

**样例输出 #2**
```
21 21```

## AC 代码

```cpp
#include<iostream>
#include<bits/stdc++.h>
using namespace std;

// 暴力枚举 6 个面上的数字（每个面 1 到 6 ），因为只有 6 的 6 次方，所以不会超时。 
// 接着判断是否与题中给出的数据相符，如果相符就求最大和最小值。

int n,x[25],y[25],z[25];
int maxx=0,minn=INT_MAX;

bool check(int a,int b,int c,int d,int e,int f){
	for(int i=1;i<=n;i++){
		int xx=x[i],yy=y[i],zz=z[i];
		if(xx==a && yy==b && zz==c) continue;
		if(xx==a && yy==b && zz==e) continue;
		if(xx==b && yy==d && zz==e) continue;
		if(xx==b && yy==d && zz==c) continue;
		if(xx==a && yy==f && zz==c) continue;
		if(xx==a && yy==f && zz==e) continue;
		if(xx==d && yy==f && zz==e) continue;
		if(xx==c && yy==f && zz==d) continue;
		xx=y[i],yy=z[i],zz=x[i];
		if(xx==a && yy==b && zz==c) continue;
		if(xx==a && yy==b && zz==e) continue;
		if(xx==b && yy==d && zz==e) continue;
		if(xx==b && yy==d && zz==c) continue;
		if(xx==a && yy==f && zz==c) continue;
		if(xx==a && yy==f && zz==e) continue;
		if(xx==d && yy==f && zz==e) continue;
		if(xx==c && yy==f && zz==d) continue;
		xx=z[i],yy=x[i],zz=y[i];
		if(xx==a &&yy==b &&zz==c) continue;
		if(xx==a &&yy==b &&zz==e) continue;
		if(xx==b &&yy==d &&zz==e) continue;
		if(xx==b &&yy==d &&zz==c) continue;
		if(xx==a &&yy==f &&zz==c) continue;
		if(xx==a &&yy==f &&zz==e) continue;
		if(xx==d &&yy==f &&zz==e) continue;
		if(xx==c &&yy==f &&zz==d) continue;
		return false;
	}
	return true;
}

int main(){
	cin>>n;
	for(int i=1;i<=n;i++)
		cin>>x[i]>>y[i]>>z[i];
	for(int a=1;a<=6;a++)
		for(int b=1;b<=6;b++)
			for(int c=1;c<=6;c++)
				for(int d=1;d<=6;d++)
					for(int e=1;e<=6;e++)
						for(int f=1;f<=6;f++)
							if(check(a,b,c,d,e,f))
								maxx=max(maxx,a+b+c+d+e+f),minn=min(minn,a+b+c+d+e+f);						
	cout<<minn<<' '<<maxx;
	return 0;
}

```
