# P4710 「物理」平抛运动

> **洛谷** | 普及- | C++14 | 提交时间: 2026-10-10

**算法标签**：`数学`、`Special Judge`、`O2优化`、`洛谷月赛`

## 题目描述

> 小 F 回到班上，面对自己 28 / 110 的物理，感觉非常凉凉。他准备从最基础的力学学起。

如图，一个可以视为质点的小球在点 $A(x_0, y_0)$ 沿 $x$ 轴负方向以某速度抛出，无视除重力外的所有阻力，最后恰好以速度 $v$ 砸到 $B(0, 0)$ 点。

![A1](https://cdn.luogu.com.cn/upload/pic/17884.png)

给定 $v$ 的大小与方向，你的任务是求出 $(x_0,y_0)$。

给定的速度单位为 $m \cdot s ^ {-1}$，重力加速度 $g = 10 \ (m \cdot s ^ {-2})$，请输出以 $m$ 为单位的答案。

如果你没有学过相关内容也没有关系，你可以从样例和提示里理解该题所求内容。

## 输入格式

输入一行，为两个最多 $6$ 位的小数 $v, \theta(1 \leq v \leq 100, 15 ^ \circ \leq \theta \leq 75 ^ \circ )$，即速度与图中所标角在弧度制下的大小。

## 输出格式

输出一行，两个最多 $15$ 位的小数 $x_0, y_0$，为你的答案。

你的答案与参考答案的相对误差或者绝对误差小于 $10 ^ {-3}$ 即视为正确。

## 样例

**样例输入 #1**
```
14.142136 0.785398```

**样例输出 #1**
```
10 5```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P4710 「物理」平抛运动
     * 题意：小球从 A(x0, y0) 沿 x 轴负方向抛出，最终以速度 v 砸到 B(0,0)。
     *       给定 v 的大小和方向 a（弧度制），重力加速度 g = 10，求 x0, y0。
     *
     * 物理分析：
     *   将落地速度 v 分解：
     *     水平分速度 vx = v * sin(a)
     *     竖直分速度 vy = v * cos(a)
     *   落地时间 t = vy / g = v * cos(a) / g
     *   水平位移 x0 = vx * t = v^2 * sin(a) * cos(a) / g
     *   竖直位移 y0 = 1/2 * g * t^2 = v^2 * cos^2(a) / (2g)
     *
     * 时间复杂度：O(1)
     */
    double v, a;   // v: 落地速度大小, a: 速度与竖直方向的夹角（弧度）
    cin >> v >> a;

    double g = 10.0;
    double x = v * v * sin(a) * cos(a) / g;
    double y = v * v * cos(a) * cos(a) / (2 * g);

    cout << fixed << setprecision(10) << x << " " << y << endl;
    return 0;
}
```
