# B4129 [信息与未来 2014] 奇数及偶数和

> **洛谷** | 入门 | C++14 | 提交时间: 2026-04-11

**算法标签**：`递归`、`强连通分量`、`CDQ分治`

## 题目描述

给出一个正整数 $n$，求出 $1,2,3,\cdots,n$ 中全部的奇数和、偶数和。

## 输入格式

一个整数，表示 $n$。

## 输出格式

一行两个整数，表示奇数和及偶数和。

## 样例

**样例输入 #1**
```
6```

**样例输出 #1**
```
9 12```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;
    long long odd_sum = 0, even_sum = 0;
    for (int i = 1; i <= n; i++) {
        if (i % 2 == 1) {
            odd_sum += i;
        } else {
            even_sum += i;
        }
    }
    cout << odd_sum << " " << even_sum << endl;
    return 0;
}
```
