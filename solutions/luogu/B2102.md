# B2102 计算鞍点

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-09

## 题目描述

给定一个 $5 \times 5$ 的矩阵，每行只有一个最大值，每列只有一个最小值，寻找这个矩阵的鞍点。鞍点指的是矩阵中的一个元素，它是所在行的最大值，并且是所在列的最小值。

例如：在下面的例子中，第 $4$ 行第 $1$ 列的元素就是鞍点，值为 $8$。

```
11 3 5 6 9
12 4 7 8 10
10 5 6 9 11
8  6 4 7 2
15 10 11 20 25
```

## 输入格式

输入包含一个 $5$ 行 $5$ 列的矩阵。

## 输出格式

如果存在鞍点，输出鞍点所在的行、列及其值，如果不存在，输出 `not found`。

## 样例

**样例输入 #1**
```
11 3 5 6 9
12 4 7 8 10
10 5 6 9 11
8  6 4 7 2
15 10 11 20 25```

**样例输出 #1**
```
4 1 8```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 鞍点：该元素是所在行的最大值，同时是所在列的最小值。
    // 矩阵固定为5×5，每行只有一个最大值，每列只有一个最小值。
    // 1. 读入矩阵。
    // 2. 对于每一行，找到该行的最大值及其列号。
    // 3. 检查该最大值是否也是它所在列的最小值：遍历该列的所有行，如果发现比它小的数，则不是鞍点。
    // 4. 如果找到鞍点，输出行号、列号和值；否则输出 "not found"。
    // 因为矩阵很小，直接暴力扫描即可，复杂度 O(n^2)。

    int a[15][15];                     // 存储矩阵，行数5，多开10

    // 读入 5x5 矩阵
    for (int i = 1; i <= 5; i++) {
        for (int j = 1; j <= 5; j++) {
            cin >> a[i][j];
        }
    }

    bool found = false;                // 是否找到鞍点

    // 遍历每一行
    for (int i = 1; i <= 5; i++) {
        // 找第 i 行的最大值及其列号
        int mx = a[i][1];              // 假设第一个元素最大
        int col = 1;                   // 最大值所在的列号
        for (int j = 2; j <= 5; j++) {
            if (a[i][j] > mx) {
                mx = a[i][j];
                col = j;
            }
        }

        // 检查 mx 是否是第 col 列的最小值
        bool isMin = true;
        for (int k = 1; k <= 5; k++) {
            if (a[k][col] < mx) {      // 该列中有比 mx 更小的数
                isMin = false;
                break;
            }
        }

        // 如果既是行最大又是列最小，则找到鞍点
        if (isMin) {
            cout << i << " " << col << " " << mx << endl;
            found = true;
            break;                      // 题目暗示只有一个鞍点？找到后退出即可
        }
    }

    if (!found) {
        cout << "not found" << endl;
    }

    return 0;
}
```
