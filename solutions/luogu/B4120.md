# B4120 [语言月赛 202501] 数字谜

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-28

**算法标签**：`2025`、`顺序结构`、`语言月赛`

## 题目描述

给出一个两位数 $a$，问至少要把 $a$ 加上几（可以 $+0$），才能让 $a$ 的个位变成 $b$。

## 输入格式

输入有一行两个自然数 $a,b$，含义同题目描述。

## 输出格式

输出一行一个自然数表示答案。

## 样例

**样例输入 #1**
```
47 9
```

**样例输出 #1**
```
2
```

**样例输入 #2**
```
89 3
```

**样例输出 #2**
```
4
```

**样例输入 #3**
```
30 0
```

**样例输出 #3**
```
0
```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, b;
    cin >> a >> b;
    int cur = a % 10;          // 当前的个位
    int ans = (b - cur + 10) % 10; // 需要加上的最小非负整数
    cout << ans << endl;
    return 0;
}
```
