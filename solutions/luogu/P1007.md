# P1007 独木桥

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-06-28

**算法标签**：`模拟`、`二分`

## 题目背景

战争已经进入到紧要时间。你是运输小队长，正在率领运输部队向前线运送物资。运输任务像做题一样的无聊。你希望找些刺激，于是命令你的士兵们到前方的一座独木桥上欣赏风景，而你留在桥下欣赏士兵们。士兵们十分愤怒，因为这座独木桥十分狭窄，只能容纳 $1$ 个人通过。假如有 $2$ 个人相向而行在桥上相遇，那么他们 $2$ 个人将无法绕过对方，只能有 $1$ 个人回头下桥，让另一个人先通过。但是，可以有多个人同时呆在同一个位置。

## 题目描述

突然，你收到从指挥部发来的信息，敌军的轰炸机正朝着你所在的独木桥飞来！为了安全，你的部队必须撤下独木桥。独木桥的长度为 $L$，士兵们只能呆在坐标为整数的地方。所有士兵的速度都为 $1$，但一个士兵某一时刻来到了坐标为 $0$ 或 $L+1$ 的位置，他就离开了独木桥。

每个士兵都有一个初始面对的方向，他们会以匀速朝着这个方向行走，中途不会自己改变方向。但是，如果两个士兵面对面相遇，他们无法彼此通过对方，于是就分别转身，继续行走。转身不需要任何的时间。

由于先前的愤怒，你已不能控制你的士兵。甚至，你连每个士兵初始面对的方向都不知道。因此，你想要知道你的部队最少需要多少时间就可能全部撤离独木桥。另外，总部也在安排阻拦敌人的进攻，因此你还需要知道你的部队最多需要多少时间才能全部撤离独木桥。

## 输入格式

第一行共一个整数 $L$，表示独木桥的长度。桥上的坐标为 $1, 2, \cdots, L$。

第二行共一个整数 $N$，表示初始时留在桥上的士兵数目。

第三行共有 $N$ 个整数，分别表示每个士兵的初始坐标。

## 输出格式

共一行，输出 $2$ 个整数，分别表示部队撤离独木桥的最小时间和最大时间。$2$ 个整数由一个空格符分开。

## 样例

**样例输入 #1**
```
4
2
1 3
```

**样例输出 #1**
```
2 4```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：每个士兵独立选择方向，彼此相遇等价于互相穿过（因为转向不耗时），
    // 所以每个士兵离开桥的最短时间是走到较近一端的时间，最长时间是走到较远一端的时间。
    // 整体最小撤离时间 = max(每个士兵的最短离开时间)
    // 整体最大撤离时间 = max(每个士兵的最长离开时间)

    int L, n;                     // L: 桥长, n: 士兵数
    cin >> L >> n;

    int mn = 0, mx = 0;           // mn: 最小撤离时间, mx: 最大撤离时间

    for (int i = 0; i < n; i++) {
        int p;                    // p: 当前士兵位置
        cin >> p;

        int l = p;                // 向左走的时间
        int r = L + 1 - p;        // 向右走的时间

        // 更新最小时间：每个士兵选近端，整体取最大值（最后一人撤离时间）
        int a = min(l, r);
        if (a > mn) mn = a;

        // 更新最大时间：每个士兵选远端，整体取最大值
        int b = max(l, r);
        if (b > mx) mx = b;
    }

    cout << mn << ' ' << mx << endl;
    return 0;
}
```
