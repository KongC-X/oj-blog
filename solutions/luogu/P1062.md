# P1062 [NOIP 2006 普及组] 数列

> **洛谷** | 普及- | C++14 | 提交时间: 2026-06-14

**算法标签**：`递归`、`单调栈`、`字符串模拟`

## 题目描述

给定一个正整数 $k$（$3\leq k\leq 15$），把所有 $k$ 的方幂及所有有限个互不相等的 $k$ 的方幂之和构成一个递增的序列，例如，当 $k = 3$ 时，这个序列是：

$1, 3, 4, 9, 10, 12, 13, \ldots$

（该序列实际上就是：$3^0,3^1,3^0+3^1,3^2,3^0+3^2,3^1+3^2,3^0+3^1+3^2,…$）

请你求出这个序列的第 $N$ 项的值，用 $10$ 进制数表示。

例如，对于 $k = 3$，$N = 100$，正确答案应该是 $981$。

## 输入格式

两个由空格隔开的正整数 $k, N$（$3\leq k\leq 15$，$10\leq N\leq 1000$）。

## 输出格式

一个正整数。整数前不要有空格和其他符号。

## 样例

**样例输入 #1**
```
3 100```

**样例输出 #1**
```
981```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int k, N;                        // k: 底数 (3~15), N: 所求项数 (10~1000)
    cin >> k >> N;

    // ---------- 思路 ----------
    // 观察序列：所有项都是 k 的不同方幂之和，且每一项的指数集合没有重复。
    // 例如 k=3 时，序列为：
    //   第1项:  1 = 3^0              (二进制 001)
    //   第2项:  3 = 3^1              (二进制 010)
    //   第3项:  4 = 3^0 + 3^1        (二进制 011)
    //   第4项:  9 = 3^2              (二进制 100)
    //   第5项: 10 = 3^0 + 3^2        (二进制 101)
    //   第6项: 12 = 3^1 + 3^2        (二进制 110)
    //   第7项: 13 = 3^0 + 3^1 + 3^2  (二进制 111)
    // 可以发现，序列的第 N 项恰好对应 N 的二进制表示中，哪几位为 1，就包含哪些 k 的幂。
    // 这是因为我们枚举幂集的方式恰好与二进制计数一致。
    // 因此，只需将 N 按二进制展开，若第 i 位（从0开始）为 1，则累加 k^i。
    // 举例：k=3, N=100 (二进制 1100100 -> 第2,5,6位为1)
    //       第100项 = 3^2 + 3^5 + 3^6 = 9 + 243 + 729 = 981。
    // 时间复杂度 O(log N)，完全可行。
    // -------------------------

    long long ans = 0;               // 存储第 N 项的值，可能较大（k=15,N=1000 时远超 int）
    long long p = 1;                 // p = k^i，初值为 k^0 = 1

    // 不断取出 N 的最低位二进制位
    while (N > 0) {
        if (N & 1) {                 // 如果当前最低位是 1，则这一项包含 k^i
            ans += p;
        }
        p *= k;                      // 更新 p 为 k^(i+1)，供下一位使用
        N >>= 1;                     // 右移一位，处理更高位
    }

    cout << ans << '\n';
    return 0;
}
```
