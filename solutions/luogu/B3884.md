# B3884 [信息与未来 2015] 加数

> **洛谷** | 普及- | C++14 | 提交时间: 2026-04-13

**算法标签**：`模拟`、`二分图`、`CDQ分治`

## 题目描述

给出一个正整数 $n$，在 $n$ 的右边加入 $\left\lfloor\dfrac n2\right\rfloor$，然后在新数的右边
再加入 $\left\lfloor\dfrac{\left\lfloor\dfrac n2\right\rfloor}2\right\rfloor$，一直这样进行下去，直到加入的数为 $0$ 为止（注意，$0$ 不应当被加入）。

求加数结束后新数的长度。

## 输入格式

一行一个整数 $n$。

## 输出格式

一行一个整数，为加数结束后新数的长度。

## 样例

**样例输入 #1**
```
37```

**样例输出 #1**
```
8```

## AC 代码

```cpp
#include <iostream>
using namespace std;

// 计算数字 x 的位数
int cnt(int x) {
    int res = 0;
    while (x) {
        x /= 10;
        res++;
    }
    return res;
}

int main() {
    int n;
    cin >> n;

    int ans = cnt(n);  // 先加上初始数字 n 的位数

    // 不断除以2，直到为0
    while (n / 2 > 0) {
        n /= 2;
        ans += cnt(n);
    }

    cout << ans << endl;
    return 0;
}
```
