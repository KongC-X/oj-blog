# B2094 不与最大数相同的数字之和

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-07

## 题目描述

输出一个整数数列中不与最大数相同的数字之和。

## 输入格式

输入分为两行：

第一行为 $N$($N$ 为接下来数的个数，$N \le 100$)；

第二行为 $N$ 个整数，数与数之间以一个空格分开，每个整数的范围是 $-1000,000$ 到 $1000,000$。

## 输出格式

输出为 $N$ 个数中除去最大数其余数字之和。

## 样例

**样例输入 #1**
```
3
1 2 3 ```

**样例输出 #1**
```
3
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 1. 读入N个数，找出其中的最大值。
    // 2. 遍历所有数，如果某个数不等于最大值，就把它累加到答案里。
    // 3. 输出答案。
    // 因为有多个最大值时，所有最大值都不参与求和，所以这个方法是正确的。
    
    int n;                           // n: 数字的个数
    cin >> n;
    
    int a[105];                      // 存储所有数字，题目保证 n <= 100
    int mx = -1000001;               // mx: 当前找到的最大值，初始化为一个很小的数
    
    // 读入所有数字，并找出最大值
    for (int i = 0; i < n; i++) {
        cin >> a[i];
        if (a[i] > mx) {
            mx = a[i];               // 更新最大值
        }
    }
    
    int ans = 0;                     // ans: 不与最大值相同的数字之和
    // 遍历数组，累加不等于最大值的数
    for (int i = 0; i < n; i++) {
        if (a[i] != mx) {
            ans += a[i];
        }
    }
    
    cout << ans << endl;
    return 0;
}
```
