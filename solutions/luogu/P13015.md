# P13015 [GESP202506 六级] 学习小组

> **洛谷** | 普及- | C++14 | 提交时间: 2026-06-03

**算法标签**：`动态规划`、`匈牙利算法`、`最近公共祖先`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1186>

## 题目描述

班主任计划将班级里的 $ n $ 名同学划分为若干个学习小组，每名同学都需要分入某一个学习小组中。观察发现，如果一个学习小组中恰好包含 $ k $ 名同学，则该学习小组的讨论积极度为 $ a_k $。

给定讨论积极度 $ a_1, a_2, \ldots, a_n $，请你计算将这 $ n $ 名同学划分为学习小组的所有可能方案中，讨论积极度之和的最大值。

## 输入格式

第一行，一个正整数 $ n $，表示班级人数。

第二行，$ n $ 个非负整数 $ a_1, a_2, \ldots, a_n $，表示不同人数学习小组的讨论积极度。

## 输出格式

输出共一行，一个整数，表示所有划分方案中，学习小组讨论积极度之和的最大值。

## 样例

**样例输入 #1**
```
4
1 5 6 3```

**样例输出 #1**
```
10```

**样例输入 #2**
```
8
0 2 5 6 4 3 3 4```

**样例输出 #2**
```
12```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// ---------- 思路 ----------
// 这是经典的完全背包DP（类似整数拆分，但不同点在于顺序无关且每个组独立贡献）。
// 问题：将n划分为若干正整数之和，每种划分方式对应把同学分成若干小组，
//       每组大小对应一个加数，获得对应大小的积极度，求最大总积极度。
//
// 状态定义：dp[i] 表示 i 名同学划分成若干小组后的最大讨论积极度之和。
// 初始条件：dp[0] = 0（0人总积极度为0）。
// 状态转移：对于每个 i（1..n），考虑最后一个小组的人数 j（1..i），
//           划分的总积极度为 dp[i-j] + a[j]，
//           取所有 j 中的最大值。
// 递推公式：dp[i] = max(dp[i], dp[i-j] + a[j])
//
// 时间复杂度 O(n^2)，空间 O(n)，完美适合 n <= 1000。

int n;        // n: 总人数
int a[1005];  // a[k]: 大小为k的小组积极度
int dp[1005]; // dp[i]：i 名同学的最大积极度和

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }
    dp[0] = 0; // 初始条件：0人总积极度为0
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= i; j++) {
            dp[i] = max(dp[i], dp[i - j] + a[j]);
        }
    }
    cout << dp[n] << endl;
    return 0;
}
```
