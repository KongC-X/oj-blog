# B3804 [语言月赛 202307] 数字判断

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-16

**算法标签**：`2023`、`O2优化`、`顺序结构`、`分支结构`、`语言月赛`

## 题目背景

请注意，本题只有通过全部测试点才能获得分数。

## 题目描述

给定三个整数 $a, b, c$，请你判断它们是否满足如下**所有**条件：

1. $a + b + c \leq 100$。
2. $b$ 是 $5$ 的倍数。
3. $c$ 是 $7$ 的倍数。
3. $a - b > b - c$。

如果上述条件均满足，请输出 $\texttt{Yes}$，否则输出 $\texttt{No}$。

## 输入格式

输入只有一行三个整数，依次表示 $a,b,c$。

## 输出格式

输出一行一个字符串表示答案。

## 样例

**样例输入 #1**
```
50 10 7```

**样例输出 #1**
```
Yes```

**样例输入 #2**
```
100 100 100```

**样例输出 #2**
```
No```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3804 [语言月赛 202307] 数字判断
     * 题意：判断三个整数 a,b,c 是否同时满足：
     *       1. a+b+c ≤ 100
     *       2. b 是 5 的倍数
     *       3. c 是 7 的倍数
     *       4. a-b > b-c
     *       全部满足输出 Yes，否则 No。
     */
    long long a, b, c;
    cin >> a >> b >> c;

    if (a + b + c <= 100 && b % 5 == 0 && c % 7 == 0 && a - b > b - c) {
        cout << "Yes" << endl;
    } else {
        cout << "No" << endl;
    }

    return 0;
}
```
