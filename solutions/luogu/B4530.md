# B4530 [信息与未来 2026] 快递无人机

> **洛谷** | 普及- | C++14 | 提交时间: 2026-05-26

**算法标签**：`图论`、`CDQ分治`

## 题目描述

Dr. X 制作了一台快递无人机，正在测试投送包裹。

:::align{center}
![](https://cdn.luogu.com.cn/upload/image_hosting/usj6f3rm.png)
:::

投送的目标区域是一个圆形空地，它的边界在地图上用星号 `*` 标出。地图上的空白区域用半角点号 `.` 表示，每个包裹的落点用小写字母 `o` 标记。下图是一个例子：

```
........o
...***...
..*****..
..*...*..
..*.o.*..
..*...*..
..*****..
...***...
.........
```

上图中，`*` 围成的区域代表圆形空地。包裹 `o` 如果落在边界围成的区域**内部**，就是一次正确投送。Dr. X 想请你统计正确投送的包裹数量。包裹要么在圆内，要么在圆外，保证不会在圆形的边界上。

## 输入格式

输入第一行包含两个空格分隔的整数 $n$ 和 $m$，表示地图的行数和列数。接下来 $n$ 行，每行 $m$ 个字符，描述整张地图。字符只包含 `*`（边界）、 `.`（空白） 和 `o`（包裹）。保证 `*` 恰好围成一个闭合的环形边界，且地图中至少有一个 `o`。

## 输出格式

输出一个整数，表示落在圆形区域内的包裹数量。

## 样例

**样例输入 #1**
```
9 9
........o
...***...
..*****..
..*...*..
..*.o.*..
..*...*..
..*****..
...***...
.........```

**样例输出 #1**
```
1```

**样例输入 #2**
```
12 13
.............
.....***.....
...*******...
...*.....*...
..*...o...*..
..*.......*..
..*..o.o..*..
..*.......*..
...*.....*...
...*******...
.....***.....
o............```

**样例输出 #2**
```
3```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 题目保证 * 构成一个闭合的环形边界，且不接触地图边缘。
// 因此，如果一个 o 在环内，那么从它向上、下、左、右四个方向走，最终都会撞到 *；
// 如果它在环外，至少有一个方向会走到地图边缘而碰不到 *。
// 利用这一性质，对每个 o 检查四个方向是否都能遇到 *，是则计数。
// 这种方法简单高效，在本题的简单环形条件下完全正确。

char c[100][100];            // 存放地图字符，使用 1‑based 下标
int a, b, d, e, i, j, n, m, f, g;

int main() {
    cin >> n >> m;
    // 读入地图
    for (i = 1; i <= n; i++) {
        for (j = 1; j <= m; j++) {
            cin >> c[i][j];
        }
    }

    // 遍历整个地图，对每个包裹 'o' 判断是否在环内
    for (i = 1; i <= n; i++) {
        for (j = 1; j <= m; j++) {
            if (c[i][j] == 'o') {
                g = 0;  // 记录上下左右四个方向中，碰到边界 '*' 的次数
                
                // 向上扫描，找第一颗 '*'
                for (a = i; a >= 1; a--) {
                    if (c[a][j] == '*') {
                        g++;
                        break;
                    }
                }
                // 向下扫描
                for (a = i; a <= n; a++) {
                    if (c[a][j] == '*') {
                        g++;
                        break;
                    }
                }
                // 向左扫描
                for (a = j; a >= 1; a--) {
                    if (c[i][a] == '*') {
                        g++;
                        break;
                    }
                }
                // 向右扫描
                for (a = j; a <= m; a++) {
                    if (c[i][a] == '*') {
                        g++;
                        break;
                    }
                }

                // 四个方向都能碰到 '*'，说明该 'o' 被环形边界完全包围，即在内部
                if (g == 4) {
                    d++;   // 内部包裹计数器加一
                }
            }
        }
    }

    cout << d << '\n';
    return 0;
}
```
