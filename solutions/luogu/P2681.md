# P2681 众数

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-05

**算法标签**：`模拟`、`2016`、`洛谷原创`、`洛谷月赛`

## 题目背景

Alice 和 Bob 玩游戏。

## 题目描述

Alice 现在有一个序列 $a_1,a_2,...a_n$。

现在她需要 Bob 支持询问一个区间内的众数,还要支持修改一个位置的 $a_i$。

## 输入格式

第一行两个整数 $n,m$。

第二行 $n$ 个整数，表示 $a_1,...,a_n$。

接下来 $m$ 行，每行三个整数 $flag,x,y$。

如果 $flag=0$，表示询问 $\big[x,y\big]$ 区间内的众数，如果有多个输出较小的。

如果 $flag=1$，表示将 $a_x$ 改为 $y$。

## 输出格式

对于每个 $flag=0$ 的询问，每行输出一个整数表示答案。

## 样例

**样例输入 #1**
```
5 3
1 1 2 2 1
0 1 4
1 2 3
0 1 4```

**样例输出 #1**
```
1
2```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】暴力 + 数组统计
     * 【核心思路】
     * 1. a[] 存序列，n 为长度，m 为操作次数。
     * 2. 查询区间 [x, y] 时：
     *    - 用 b[] 存区间内不同的值，c[] 存对应出现次数，t 为不同值个数。
     *    - 遍历区间每个元素，若已存在 b[] 中则对应 c++，否则新增。
     *    - 最后在 b[] 和 c[] 中找到出现次数最大且值最小的，输出。
     * 3. 修改操作直接 a[x] = y。
     *
     * 【时间复杂度】每次查询 O(L * D)，L 为区间长度，D 为不同值个数，
     *              n,m≤1000，完全可行。
     */

    int n, m;          // n: 长度, m: 操作数
    cin >> n >> m;

    long long a[1005]; // a[i]: 第 i 个元素
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
    }

    while (m--) {
        int f, x, y;   // f: 操作类型, x,y: 参数
        cin >> f >> x >> y;

        if (f == 0) {
            // 查询区间 [x, y] 的众数
            long long b[1005];   // b: 区间内不同值
            int c[1005];         // c: 对应出现次数
            int t = 0;           // t: 不同值个数

            for (int i = x; i <= y; i++) {
                bool ok = false;
                for (int j = 0; j < t; j++) {
                    if (b[j] == a[i]) {
                        c[j]++;
                        ok = true;
                        break;
                    }
                }
                if (!ok) {
                    b[t] = a[i];
                    c[t] = 1;
                    t++;
                }
            }

            // 找众数（出现次数最大，值最小）
            long long ans = b[0];
            int mx = c[0];
            for (int i = 1; i < t; i++) {
                if (c[i] > mx) {
                    mx = c[i];
                    ans = b[i];
                } else if (c[i] == mx && b[i] < ans) {
                    ans = b[i];
                }
            }
            cout << ans << endl;
        } else {
            // 修改
            a[x] = y;
        }
    }

    return 0;
}
```
