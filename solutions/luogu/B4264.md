# B4264 [GESP202503 四级] 二阶矩阵

> **洛谷** | 入门 | C++14 | 提交时间: 2025-03-28

**算法标签**：`匈牙利算法`、`排序算法`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1176>

## 题目描述

小 A 有一个 $n$ 行 $m$ 列的矩阵 $A$。

小 A 认为一个 $2 \times 2$ 的矩阵 $D$ 是好的，当且仅当 $D_{1,1} \times D_{2,2} = D_{1,2} \times D_{2,1}$。其中 $D_{i,j}$ 表示矩阵 $D$ 的第 $i$ 行第 $j$ 列的元素。

小 A 想知道 $A$ 中有多少个好的子矩阵。

## 输入格式

第一行，两个正整数 $n, m$。

接下来 $n$ 行，每行 $m$ 个整数 $A_{i,1}, A_{i,2}, \ldots, A_{i,m}$。

## 输出格式

一行，一个整数，表示 $A$ 中好的子矩阵的数量。

## 样例

**样例输入 #1**
```
3 4
1 2 1 0
2 4 2 1
0 3 3 0```

**样例输出 #1**
```
2```

## AC 代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int i,j,n,m,s;
int a[510][510];
int main() {
    cin >> n >> m;
    for(i=1;i<=n;i++) {
        for(j=1;j<=m;j++) {
            cin >> a[i][j];
        } 
    }
    for(i = 1;i <= n - 1;i++) {
        for(j = 1;j <= m - 1;j++) {
            if(a[i][j] * a[i + 1][j + 1] == a[i + 1][j] * a[i][j + 1]) {
                s++;
            }
        }
    }
    cout << s << endl;
}
```
