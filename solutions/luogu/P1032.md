# P1032 [NOIP 2002 提高组] 字串变换（疑似错题）

> **洛谷** | 普及+/提高 | C++14 | 提交时间: 2026-04-29

**算法标签**：`贪心`、`图论`、`高精度`、`构造`、`搜索剪枝`、`A*搜索`

## 题目背景

本题不保证存在靠谱的多项式复杂度的做法。测试数据非常的水，各种做法都可以通过，不代表算法正确。因此本题题目和数据仅供参考。

本题为搜索题，本题不接受 hack 数据。[关于此类题目的详细内容](https://www.luogu.com.cn/paste/pf94n89x)

## 题目描述

已知有两个字串 $A,B$ 及一组字串变换的规则（至多 $6$ 个规则），形如：

- $A_1\to B_1$。
- $A_2\to B_2$。

规则的含义为：在 $A$ 中的子串 $A_1$ 可以变换为 $ B_1$，$A_2$ 可以变换为 $B_2\cdots$。

例如：$A=\texttt{abcd}$，$B＝\texttt{xyz}$，

变换规则为：

- $\texttt{abc}\rightarrow\texttt{xu}$，$\texttt{ud}\rightarrow\texttt{y}$，$\texttt{y}\rightarrow\texttt{yz}$。

则此时，$A$ 可以经过一系列的变换变为 $B$，其变换的过程为：

- $\texttt{abcd}\rightarrow\texttt{xud}\rightarrow\texttt{xy}\rightarrow\texttt{xyz}$。

共进行了 $3$ 次变换，使得 $A$ 变换为 $B$。

## 输入格式

第一行有两个字符串 $A,B$。

接下来若干行，每行有两个字符串 $A_i,B_i$，表示一条变换规则。

## 输出格式

若在 $10$ 步（包含 $10$ 步）以内能将 $A$ 变换为 $B$，则输出最少的变换步数；否则输出 `NO ANSWER!`。

## 样例

**样例输入 #1**
```
abcd xyz
abc xu
ud y
y yz
```

**样例输出 #1**
```
3
```

## AC 代码

```cpp
#include <iostream>
#include <string>
#include <cstring>
using namespace std;

string A, B;                   // 初始串和目标串
string ru[10], rv[10];         // 规则：ru[i] -> rv[i]
int rt;                        // 规则数量 (rule total)

string q[1000005];             // BFS 队列：存储字符串（数组模拟）
int ste[1000005];              // 对应的步数
string vis[1000005];           // 访问过的字符串（去重用）
int vcnt;                      // 已访问数量

bool isVis(const string &s) {
    for (int i = 0; i < vcnt; i++) {
        if (vis[i] == s) return true;
    }
    return false;
}

int bfs() {
    int head = 0, tail = 0;
    q[tail] = A;
    ste[tail] = 0;
    tail++;
    vis[vcnt++] = A;

    while (head < tail) {
        string cur = q[head];
        int step = ste[head];
        head++;

        if (step > 10) return -1;           // 超过10步，不再扩展
        if (cur == B) return step;          // 找到目标

        // 枚举所有规则
        for (int i = 0; i < rt; i++) {
            // 在当前字符串中查找所有匹配 ru[i] 的位置
            int pos = 0;
            while ((pos = cur.find(ru[i], pos)) != string::npos) {
                string nxt = cur.substr(0, pos) + rv[i] + cur.substr(pos + ru[i].length());
                if (!isVis(nxt) && nxt.length() <= 100) { // 限制长度防止无限膨胀
                    vis[vcnt++] = nxt;
                    q[tail] = nxt;
                    ste[tail] = step + 1;
                    tail++;
                }
                pos++; // 继续查找下一个匹配位置
            }
        }
    }
    return -1;
}

int main() {
    // 读入 A 和 B
    cin >> A >> B;
    rt = 0;
    // 读入规则，直到 EOF
    while (cin >> ru[rt] >> rv[rt]) {
        rt++;
        if (rt >= 10) break;      // 安全上限
    }

    int ans = bfs();
    if (ans == -1 || ans > 10) {
        cout << "NO ANSWER!" << endl;
    } else {
        cout << ans << endl;
    }
    return 0;
}
```
