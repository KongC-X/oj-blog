# B2110 找第一个只出现一次的字符

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-07

## 题目描述

给定一个只包含小写字母的字符串，请你找到第一个仅出现一次的字符。如果没有，输出 `no`。

## 输入格式

一个字符串，长度小于 $1100$。

## 输出格式

输出第一个仅出现一次的字符，若没有则输出 `no`。

## 样例

**样例输入 #1**
```
abcabd```

**样例输出 #1**
```
c```

**样例输入 #2**
```
aabbcc```

**样例输出 #2**
```
no```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    string s;                          // s: 输入的字符串
    cin >> s;

    int cnt[26] = {0};                 // cnt[i]: 字母 i+'a' 的出现次数

    // 第一次遍历：统计每个字母出现的次数
    for (int i = 0; i < s.size(); i++) {
        cnt[s[i] - 'a']++;
    }

    // 第二次遍历：按原字符串顺序，找到第一个出现次数为 1 的字母
    for (int i = 0; i < s.size(); i++) {
        if (cnt[s[i] - 'a'] == 1) {
            cout << s[i] << endl;
            return 0;
        }
    }

    // 如果没找到，输出 no
    cout << "no" << endl;
    return 0;
}
```
