# B3619 10 进制转 x 进制

> **洛谷** | 普及- | C++14 | 提交时间: 2026-10-10

## 题目描述

给定一个十进制整数 $n$ 和一个小整数 $x$。将整数 $n$ 转为 $x$ 进制。对于超过十进制的数码，用 `A`，`B` ... 表示。

## 输入格式

第一行一个整数 $n$；

第二行一个整数 $x$。

## 输出格式

输出仅包含一个整数，表示答案。

## 样例

**样例输入 #1**
```
1000
2
```

**样例输出 #1**
```
1111101000
```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int main() {
	long long n;
	int x;
	cin >> n >> x;
	if(n ==0) {
		cout << 0 << endl;
		return 0;
	}
	string s = "";
	while(n) {
		int r = n % x;
		if(r < 10) {
			s = char('0' + r) + s;
		} else {
			s = char('A' + (r - 10)) + s;
		}
		n /= x;
	}
	cout << s << endl;
}
```
