# P1149 [NOIP 2008 提高组] 火柴棒等式

> **洛谷** | 普及- | C++14 | 提交时间: 2025-08-30

**算法标签**：`图论`、`BFS`、`构造`、`排序算法`

## 题目描述

给你 $n$ 根火柴棍，你可以拼出多少个形如 $A+B=C$ 的等式？等式中的 $A$、$B$、$C$ 是用火柴棍拼出的整数（若该数非零，则最高位不能是 $0$）。用火柴棍拼数字 $0\sim9$ 的拼法如图所示：

![](https://cdn.luogu.com.cn/upload/image_hosting/p5hsawt2.png)

注意：

1. 加号与等号各自需要两根火柴棍；
2. 如果 $A\neq B$，则 $A+B=C$ 与 $B+A=C$ 视为不同的等式（$A,B,C\geq0$）；
3. $n$ 根火柴棍必须全部用上。

## 输入格式

一个整数 $n(1 \leq n\leq 24)$。

## 输出格式

一个整数，能拼成的不同等式的数目。

## 样例

**样例输入 #1**
```
14```

**样例输出 #1**
```
2```

**样例输入 #2**
```
18```

**样例输出 #2**
```
9```

## AC 代码

```cpp
#include<bits/stdc++.h>
#include<iostream>
using namespace std;

int s[10] = {6, 2, 5, 5, 4, 5, 6, 3, 7, 6};
int n, ans;

int fun(int x){
	int sum = 0;
	if(x < 10){
		sum = s[x];
	} else{
		int t = x;
		while(t != 0){
			sum += s[t % 10];
			t /= 10;
		}
	}
	return sum;
}

int main(){
	cin >> n;
	for(int i = 0;i <= 1000;i++){
    	for(int j = 0;j <= 1000;j++){
    		if(fun(i) + fun(j) + fun(i + j) == n - 4){
                //若满足此条件，则等式成立
    			ans++;
			}
		}
	}
	cout << ans << endl;
	return 0;
}

```
