# B4209 [常州市赛 2022] 阶梯电价

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-17

**算法标签**：`2022`、`江苏`、`分支结构`、`科创活动`、`小学活动`

## 题目背景

搬运自 <http://czoj.com.cn/p/450>。数据为民间数据。

## 题目描述

碳中和是指国家、企业、产品、活动或个人在一定时间内直接或间接产生的二氧化碳或温室气体排放总量，通过植树造林、节能减排等形式，以抵消自身产生的二氧化碳或温室气体排放量，实现正负抵消，达到相对“零排放”。

龙城电力公司为了配合碳中和推出了阶梯电价的标准。以下为阶梯电价的计费说明：阶梯电价的实施周期为一年，在本年度中用电量在 $2760$ 度以内的，算作第一阶梯，这是基本保障的用电量，每度电按 $0.52$ 元计价；从 $2761$ 度至 $4800$ 度算作第二阶梯，每度电按 $0.57$ 元计价，电价与发电平均成本持平；第三阶梯从 $4801$ 度开始计费，每度电按 $0.82$ 元计价，以促进节约用电。每过一年电表读数归零，每个月的电费视用电情况收取，每度电的价格取决于这度电属于哪个阶梯。

小 $\text{X}$ 有个每月底查看自家电表的习惯，并记录下每个月电表的读数（这里需要注意，每年年初电表的读数都会从 0 开始计算。）。现在小 $\text{X}$ 知道了 上个月底的电表读数 $u$ 和当前这个月底的电表读数 $v$（其中 $u≤v$，且 $u$ 和 $v$ 都是大于等于 $0$ 的整数即非负整数），小 $\text{X}$ 想知道按照阶梯电价的标准，当前这个月的电费是多少，你能写一个程序帮他计算一下吗？

## 输入格式

一行用空格隔开的两个整数 $u$ 和 $v$，分别表示上个月底的电表读数和当前这个月底的电表读数。

## 输出格式

一行一个实数，表示当前这个月的电费，要求输出时保留 $2$ 位小数。

## 样例

**样例输入 #1**
```
2700 5000```

**样例输出 #1**
```
1358.00```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 函数：计算从 0 到 x 度的累计电费
double cost(int x) {
    // 第一阶梯：0 ~ 2760 度，每度 0.52 元
    if (x <= 2760) {
        return x * 0.52;
    }
    // 第二阶梯：2761 ~ 4800 度，每度 0.57 元
    if (x <= 4800) {
        return 2760 * 0.52 + (x - 2760) * 0.57;
    }
    // 第三阶梯：4801 度以上，每度 0.82 元
    return 2760 * 0.52 + (4800 - 2760) * 0.57 + (x - 4800) * 0.82;
}

int main() {
    int u, v;                     // u: 上月底电表读数，v: 本月底电表读数
    cin >> u >> v;

    // 本月电费 = 截止本月底的累计电费 - 截止上月底的累计电费
    double ans = cost(v) - cost(u);

    // 输出保留两位小数
    cout << fixed << setprecision(2) << ans << endl;
    return 0;
}
```
