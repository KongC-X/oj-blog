## 题目描述

$3$ 名同学 $3$ 小时可以扫干净 $3$ 间教室，那么 $9$ 名同学 $9$ 小时可以扫干净几间教室？

## 输出格式

请输出一个数字表示答案。这个数字是一个整数。

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】归一问题（工作效率）
     * 【核心思路】
     * 1. 3人3小时扫3间教室，总人时 = 3*3 = 9 人时。
     * 2. 每人每小时效率 = 3间 / 9人时 = 1/3 间/(人·时)。
     * 3. 9人9小时总人时 = 9*9 = 81 人时。
     * 4. 总教室数 = 81 * (1/3) = 27 间。
     *
     * 【时间复杂度】O(1)
     */

    double eff;        // eff: 每人每小时能扫的教室数
    double total;      // total: 总教室数

    eff = 3.0 / (3.0 * 3.0);          // 3间 ÷ 9人时 = 1/3
    total = eff * (9.0 * 9.0);        // 效率 × 总人时

    cout << (int)total << endl;       // 输出整数 27
    return 0;
}
```
