# P1100 高低位交换

> **洛谷** | 普及- | C++14 | 提交时间: 2026-05-18

**算法标签**：`贪心`、`递归`

## 题目描述

给出一个小于 $2^{32}$ 的非负整数。这个数可以用一个 $32$ 位的二进制数表示（不足 $32$ 位用 $0$ 补足）。我们称这个二进制数的前 $16$ 位为“高位”，后 $16$ 位为“低位”。将它的高低位交换，我们可以得到一个新的数。试问这个新的数是多少（用十进制表示）。

例如，数 $1314520$ 用二进制表示为 $0000\,0000\,0001\,0100\,0000\,1110\,1101\,1000$（添加了 $11$ 个前导 $0$ 补足为 $32$ 位），其中前 $16$ 位为高位，即 $0000\,0000\,0001\,0100$；后 $16$ 位为低位，即 $0000\,1110\,1101\,1000$。将它的高低位进行交换，我们得到了一个新的二进制数 $0000\,1110\,1101\,1000\,0000\,0000\,0001\,0100$。它即是十进制的 $249036820$。

## 输入格式

一个小于 $2^{32}$ 的非负整数。

## 样例

**样例输入 #1**
```
1314520
```

**样例输出 #1**
```
249036820
```

## AC 代码

```cpp
#include <cstdio>   // scanf, printf

int main() {
    // ---------- 思路 ----------
    // 题目要求将 32 位二进制数的前 16 位（高位）与后 16 位（低位）交换。
    // 这可以用位运算一步完成，相当于“循环左移 16 位”。
    //
    // 假设原数 x，我们想要的操作为：
    //   1. 把低 16 位移到高位：x << 16
    //   2. 把高 16 位移到低位：x >> 16
    //   3. 合并两部分： (x << 16) | (x >> 16)
    //
    // 因为 x 是无符号 32 位整数，右移时高位自动补 0；
    // 左移时低 16 位正确移到高位，低位自动补 0；
    // 最后按位或（|）将两部分拼成完整的新数。
    // -------------------------

    unsigned int x;           // x: 输入的原数（< 2^32，无符号 32 位）
    scanf("%u", &x);

    // 高低位交换
    unsigned int ans = (x << 16) | (x >> 16);
    // 注释：
    // (x << 16)  低 16 位变成高 16 位，低 16 位补 0
    // (x >> 16)  高 16 位变成低 16 位，高 16 位补 0
    // 两者按位或合并，得到交换后的完整 32 位数

    printf("%u\n", ans);      // 输出十进制结果

    return 0;
}
```
