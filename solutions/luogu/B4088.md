# B4088 [CSP-X2020 山东] 最大回文数

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-10

**算法标签**：`模拟`、`2020`、`山东`、`循环结构`、`字符串（入门）`、`CSP-X 小学组`

## 题目描述

回文数指的是一个数字，从左到右读和从右到左读都一样。例如，$1221$ 和 $1234321$ 是回文数，$1234$ 不是回文数。现有 $n$ 个正整数 $a_i(i=0,1,2,3,\dots,n-1)$，请找出其中最大的回文数。

## 输入格式

输入文件的第一行只有一个正整数 $n$，代表正整数 $a_i$ 的个数。

接下来的 $n$ 行，每行包含一个正整数 $a_i$。输入保证一定有回文数。

## 输出格式

输出文件一行，一个正整数，即最大的回文数。

## 样例

**样例输入 #1**
```
3
4718
1221
121```

**样例输出 #1**
```
1221```

**样例输入 #2**
```
5
3944
953
8
75739
46```

**样例输出 #2**
```
8```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：字符串处理 + 比较
     * 思路：
     * 1. 回文数最大可达 10^32，远超 long long，因此用字符串读入和比较。
     * 2. 判断回文：字符串 s 与反转后的字符串是否相等。
     * 3. 比较两个数字字符串的大小：先比较长度，长度大的更大；长度相同则字典序更大。
     * 4. 遍历所有输入，若当前数字是回文且比当前最大值大，则更新。
     */
    int n;
    cin >> n;

    string ans = "";   // 当前最大的回文数（空表示未找到）

    for (int i = 0; i < n; i++) {
        string s;
        cin >> s;

        // 判断是否为回文
        string rev = s;
        reverse(rev.begin(), rev.end());
        if (s != rev) continue;

        // 与当前最大值比较
        if (ans == "" ||
            s.size() > ans.size() ||
            (s.size() == ans.size() && s > ans)) {
            ans = s;
        }
    }

    cout << ans << endl;
    return 0;
}
```
