# B2035 判断数正负

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-26

## 题目描述

给定一个整数 $N$，判断其正负。如果 $N>0$, 输出 `positive` ; 如果 $N=0$, 输出 `zero` ; 如果 $N<0,$ 输出 `negative`。

## 输入格式

一个整数 $N(-10^9 \le N \le 10^9)$。

## 输出格式

如果 $N>0$， 输出 `positive`; 

如果 $N=0$, 输出 `zero`； 

如果 $N<0$， 输出 `negative`。

## 样例

**样例输入 #1**
```
95```

**样例输出 #1**
```
positive```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
	int n;
	cin>>n;
	if(n>0) {
		cout<<"positive";
	} else if(n==0) {
		cout<<"zero";
	} else {
		cout<<"negative";
	}
	return 0;
}

```
