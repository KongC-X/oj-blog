# P10721 [GESP202406 六级] 计算得分

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-06-03

**算法标签**：`贪心`、`动态规划`、`费用流`、`最近公共祖先`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1154>

## 题目描述

小杨想要计算由 $m$ 个小写字母组成的字符串的得分。

小杨设置了一个包含 $n$ 个正整数的计分序列 $A=[a_1,a_2,\ldots,a_n]$，如果字符串的一个子串由 $k(1\leq k \leq n)$ 个 $\texttt{abc}$ 首尾相接组成，那么能够得到分数 $a_k$，并且字符串包含的字符不能够重复计算得分，整个字符串的得分是计分子串的总和。

例如，假设 ，字符串 $\texttt{dabcabcabcabzabc}$ 的所有可能计分方式如下：
- $\texttt{d+abc+abcabc+abz+abc}$ 或者 $\texttt{d+abcabc+abc+abz+abc}$，其中 $\texttt{d}$ 和 $\texttt{abz}$ 不计算得分，总得分为 $a_1+a_2+a_1$。
- $\texttt{d+abc+abc+abc+abz+abc}$，总得分为 $a_1+a_1+a_1+a_1$。
- $\texttt{d+abcabcabc+abz+abc}$，总得分为 $a_3+a_1$。

小杨想知道对于给定的字符串，最大总得分是多少。

## 输入格式

- 第一行包含一个正整数 $n$，代表计分序列 $A$ 的长度。

- 第二行包含 $n$ 个正整数，代表计分序列 $A$。

- 第三行包含一个正整数 $m$，代表字符串的长度。

- 第四行包含一个由 $m$ 个小写字母组成的字符串。

## 输出格式

输出一个整数，代表给定字符串的最大总得分。

## 样例

**样例输入 #1**
```
3
3 1 2
13
dabcabcabcabz
```

**样例输出 #1**
```
9```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// ---------- 思路 ----------
// 问题：将字符串划分为若干不重叠的子串，每个子串要么是 k 个连续 "abc" 组成（1<=k<=n），得分 a[k]，
//       要么是其他字符（不得分）。求最大总分。
// 解法：
// 1. 扫描字符串，找出所有由连续 "abc" 组成的极长段（段内只含完整的 "abc" 重复，没有其它字符）。
//    因为只有当 "abc" 连续排列时，才能从中截取 k 个 "abc" 作为计分子串。
// 2. 对于每一个长度为 cnt（cnt 个 "abc"）的段，问题转化为：
//       有一个长度为 cnt 的线性序列，每个单位是一个 "abc"。
//       可以选取若干不相交的区间，每个区间长度 k (1<=k<=min(n,cnt))，得分 a[k]。
//       求最大得分。
//    用动态规划：设 dp[i] 表示前 i 个 "abc" 的最大得分。
//       初始 dp[0]=0。
//       转移：dp[i] = max(dp[i-1], max_{1<=k<=min(n,i)} dp[i-k] + a[k])
//       解释：第 i 个 "abc" 可以不被任何区间包含（得分为 dp[i-1]），
//             或者作为某个区间的末尾，该区间包含最后 k 个 "abc"。
// 3. 将所有段的 dp[cnt] 累加，即得最终答案。
// 时间复杂度 O(m * n)，空间 O(m)，完全可行。

int n, m;
int a[30];                             // 计分序列 a[1..n]
string s;
long long ans;                           // 总得分可能较大，用 long long
long long dp[100010];           // dp[j] 前 j 个 "abc" 的最大得分

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++){
        cin >> a[i];
    }
    cin >> m >> s;
    int i = 0;
    while (i < m) {
        // 检查当前位置开始是否为 "abc"
        if (i + 2 < m && s[i] == 'a' && s[i+1] == 'b' && s[i+2] == 'c') {
            // 统计连续 "abc" 的个数
            int cnt = 0;
            while (i + 2 < m && s[i] == 'a' && s[i+1] == 'b' && s[i+2] == 'c') {
                cnt++;
                i += 3;
            }
            // DP 求这一段的最大得分 
            dp[0] = 0;
            for (int j = 1; j <= cnt; j++) {
                dp[j] = dp[j-1];          // 不取第 j 个 "abc" 作为区间结尾
                for (int k = 1; k <= n && k <= j; k++) {
                    dp[j] = max(dp[j], dp[j-k] + a[k]);
                }
            }
            ans += dp[cnt];
        } else {
            i++;                          // 非 "abc" 字符，跳过
        }
    }

    cout << ans << endl;
    return 0;
}
```
