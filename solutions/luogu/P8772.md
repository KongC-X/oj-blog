# P8772 [蓝桥杯 2022 省 A] 求和

> **洛谷** | 普及- | C++14 | 提交时间: 2026-07-23

**算法标签**：`2022`、`前缀和`、`差分`、`蓝桥杯省赛`

## 题目描述

给定 $n$ 个整数 $a_{1}, a_{2}, \cdots, a_{n}$, 求它们两两相乘再相加的和，即

$$
S=a_{1} \cdot a_{2}+a_{1} \cdot a_{3}+\cdots+a_{1} \cdot a_{n}+a_{2} \cdot a_{3}+\cdots+a_{n-2} \cdot a_{n-1}+a_{n-2} \cdot a_{n}+a_{n-1} \cdot a_{n}
$$

## 输入格式

输入的第一行包含一个整数 $n$ 。

第二行包含 $n$ 个整数 $a_{1}, a_{2}, \cdots a_{n}$ 。

## 输出格式

输出一个整数 $S$，表示所求的和。请使用合适的数据类型进行运算。

## 样例

**样例输入 #1**
```
4
1 3 6 9```

**样例输出 #1**
```
117```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200010;          // n 最大 2e5，多开 10 个
long long a[MAXN];                // 原数组
long long s[MAXN];                // 前缀和数组

int main() {
    // 思路：利用前缀和优化
    // S = a1*(a2+...+an) + a2*(a3+...+an) + ... + a_{n-1}*an
    // 对于每个 i，需要乘以 a[i] 后面的所有数之和 = 总和 - 前缀和[i]
    // 即 S = Σ a[i] * (s[n] - s[i])，其中 s[i] = a[1]+...+a[i]
    // 时间复杂度 O(n)

    int n;                         // n: 数字个数
    cin >> n;

    s[0] = 0;
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        s[i] = s[i - 1] + a[i];    // 计算前缀和
    }

    long long ans = 0;             // 最终结果
    for (int i = 1; i < n; i++) {  // i 最大到 n-1
        ans += a[i] * (s[n] - s[i]);
    }

    cout << ans << endl;
    return 0;
}
```
