# P1572 计算分数

> **洛谷** | 普及- | C++14 | 提交时间: 2026-05-23

**算法标签**：`模拟`、`贪心`、`随机化`

## 题目描述

Csh 被老妈关在家里做分数计算题，但显然他不愿意做这么多复杂的计算。况且在家门口还有 Xxq 在等着他去一起看电影。为了尽快地能去陪 Xxq 看电影，他把剩下的计算题交给了你，你能帮他解决问题吗？

## 输入格式

输入一行，为一个分数计算式。

计算式中只包含数字、`+`、`-`、`/`。其中 `/` 为分数线，分数线左边为分子，右边为分母。输入数据保证不会出现繁分数。如果输入计算式的第一项为正，不会有前缀 `+` 号；若为负，会有前缀 `-` 号。

所有整数均以分数形式出现。

## 输出格式

输出一行，为最后的计算结果（如果为整数则用整数表示，否则用最简分数表示）。

保证答案内出现的所有数（如果答案是分数即为分子和分母）均在 $32$ 位带符号整数的表示范围之内。

## 样例

**样例输入 #1**
```
2/1+1/3-1/4```

**样例输出 #1**
```
25/12```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string s;
    cin >> s;

    long long ansx = 0, ansy = 1;   // 结果分子、分母，初始 0/1
    int p = 0, len = s.size();

    while (p < len) {
        char op = '+';             // 默认为加
        if (s[p] == '+' || s[p] == '-') {
            op = s[p];
            p++;
        }

        // 读分子
        long long x = 0;
        while (p < len && isdigit(s[p])) {
            x = x * 10 + (s[p] - '0');
            p++;
        }
        p++;  // 跳过 '/'

        // 读分母
        long long y = 0;
        while (p < len && isdigit(s[p])) {
            y = y * 10 + (s[p] - '0');
            p++;
        }

        // 通分并加减
        if (op == '+')
            ansx = ansx * y + x * ansy;
        else
            ansx = ansx * y - x * ansy;
        ansy = ansy * y;

        // 约分（保持分母正）
        long long g = __gcd(abs(ansx), ansy);
        ansx /= g;
        ansy /= g;
    }

    // 输出最简结果
    if (ansy == 1)
        cout << ansx << '\n';
    else
        cout << ansx << '/' << ansy << '\n';

    return 0;
}
```
