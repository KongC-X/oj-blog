# B2068 统计满足条件的 4 位数

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-03

## 题目描述

给定若干个四位数，求出其中满足以下条件的数的个数：个位数上的数字减去千位数上的数字，再减去百位数上的数字，再减去十位数上的数字的结果大于零。

## 输入格式

输入为两行，第一行为四位数的个数 $n$，第二行为 $n$ 个的四位数。$(n \le 100)$。

## 输出格式

输出为一行，包含一个整数，表示满足条件的四位数的个数。

## 样例

**样例输入 #1**
```
5
1234 1349 6119 2123 5017```

**样例输出 #1**
```
3
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int n;                         // n: 四位数的个数
    cin >> n;
    int ans = 0;                   // ans: 满足条件的个数

    for (int i = 0; i < n; i++) {
        int x;                     // x: 当前四位数
        cin >> x;

        // 分解各位数字
        int a = x / 1000;          // 千位
        int b = x / 100 % 10;      // 百位
        int c = x / 10 % 10;       // 十位
        int d = x % 10;            // 个位

        // 判断个位 - 千位 - 百位 - 十位是否大于 0
        if (d - a - b - c > 0) {
            ans++;
        }
    }

    cout << ans << endl;
    return 0;
}
```
