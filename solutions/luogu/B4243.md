# B4243 [语言月赛 202503] 长方形

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-29

**算法标签**：`2025`、`顺序结构`、`语言月赛`

## 题目背景

对于一个长为 $a$，宽为 $b$ 的长方形，它的面积是 $S = a \times b$，它的周长是 $L = 2 \times (a + b)$。

## 题目描述

假设一个长方形的长和宽均为整数，给定它的长 $a$ 和面积 $S$，请你求出这个长方形的周长 $L$。

## 输入格式

输入共一行两个整数 $a, S$，分别代表给定长方形的长和面积。

## 输出格式

输出一行一个整数，代表输入长方形的周长。

## 样例

**样例输入 #1**
```
4 24
```

**样例输出 #1**
```
20
```

**样例输入 #2**
```
8 72
```

**样例输出 #2**
```
34
```

**样例输入 #3**
```
1 100
```

**样例输出 #3**
```
202
```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int a, S;                       // a: 长, S: 面积
    cin >> a >> S;

    int b = S / a;                  // b: 宽 = 面积 / 长
    int ans = 2 * (a + b);          // ans: 周长 = 2 * (长 + 宽)

    cout << ans << endl;
    return 0;
}
```
