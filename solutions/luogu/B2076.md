# B2076 球弹跳高度的计算

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-05

**算法标签**：`Special Judge`、`循环结构`

## 题目描述

一球从某一高度落下（整数，单位米），每次落地后反跳回原来高度的一半，再落下。

编程计算气球在第 $10$ 次落地时，共经过多少米？第 $10$ 次反弹多高？

## 输入格式

输入一个整数 $h$，表示球的初始高度。

## 输出格式

输出包含两行：

第 $1$ 行：到球第 $10$ 次落地时，一共经过的米数。

第 $2$ 行：第 $10$ 次弹跳的高度。

注意：结果可能是实数，结果用 double 类型保存。

提示：输出时不需要对精度特殊控制，用 `cout<<ANSWER`，或者 `printf("%g",ANSWER)` 即可。

## 样例

**样例输入 #1**
```
20```

**样例输出 #1**
```
59.9219
0.0195313```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    double h;                // 初始高度
    cin >> h;

    double sum = h;          // 总路程，第一次落地经过 h
    double b = h / 2.0;      // 当前反弹高度，第一次落地后反弹 h/2

    // 计算第2次到第10次落地
    for (int i = 2; i <= 10; i++) {
        sum += 2 * b;        // 一次弹起再落下的路程
        b /= 2.0;            // 下一次反弹高度减半
    }

    // 输出总路程和第10次反弹高度
    cout << sum << "\n" << b << endl;
    return 0;
}
```
