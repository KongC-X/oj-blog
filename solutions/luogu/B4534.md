# B4534 [信息与未来 2026] 桌面游戏

> **洛谷** | 普及+/提高 | C++14 | 提交时间: 2026-05-26

**算法标签**：`图论`、`递推`、`CDQ分治`

## 题目描述

Dr. X 设计了一个双人桌面游戏，在一个 $3 \times 3$ 的方格中轮流填入数字 $1, 2, \ldots, 9$。现在，方格中已经填好了一部分数字，Dr. X 和 Dr. Y 按如下规则交替填入数字 (Dr. X 先填)：

1. 每一轮，从当前剩余未使用的数字中，找到最小的一个数字。
2. 选择方格中的任意一个空位，将该数字填入。
3. 换另一个人重复这一过程，当方格被填满时，游戏结束。

游戏结束后，双方计算分数的规则：

- Dr. X 的分数 $x$ 等于三行数字乘积之和。
- Dr. Y 的分数 $y$ 等于三列数字乘积之和。

Dr. X 和 Dr. Y 都希望拉开和对方分数的差距：Dr. X 希望最大化 $x - y$，而 Dr. Y 希望最小化 $x - y$。他们都互相知道对方都是绝顶聪明的人，一定会采取对自己最有利的策略。请你写程序预判游戏的最终结果：

- 若 Dr. X 的分数更高，输出 $\texttt{first}$；
- 若 Dr. Y 的分数更高，输出 $\texttt{second}$；
- 若两人分数相同，输出 $\texttt{tie}$。

## 输入格式

第一行输入一个整数 $T$，表示数据组数。

接下来包含 $T$ 组数据。每组数据包含 $3$ 行，每行 $3$ 个整数，表示当前的 $3 \times 3$ 方格，其中 $0$ 表示该位置为空。输入数据保证初始方格中所有非零数字互不相同，且都在 $1$ 到 $9$ 之间。

## 输出格式

对于每组数据，输出一行字符串，表示最终结果。

## 样例

**样例输入 #1**
```
3
1 2 3
4 5 6
7 8 0
1 4 7
2 5 8

**样例输出 #1**

## AC 代码

```cpp
#include <iostream>
#include <algorithm>
using namespace std;

// ---------- 全局变量 ----------
int a[3][3];               // 当前棋盘，0 表示空位
int rest[9];               // 剩余未使用的数字（从小到大排序）
int m;                     // 空位数量 = 剩余数字的个数
int empty_r[9], empty_c[9];// 空位的行列坐标

// ---------- 计算 x - y ----------
// x = 三行乘积之和, y = 三列乘积之和
int calc() {
    int x = 0, y = 0;
    for (int i = 0; i < 3; i++) {
        x += a[i][0] * a[i][1] * a[i][2];  // 第 i 行乘积
        y += a[0][i] * a[1][i] * a[2][i];  // 第 i 列乘积
    }
    return x - y;  // Dr.X 希望这个值越大越好
}

// ---------- Minimax + Alpha-Beta 剪枝 ----------
// step : 当前是第几步（0-based），即将填入 rest[step]
// alpha: 当前玩家（Max节点）已知能保证的最差值（下界）
// beta : 对手（Min节点）已知能保证的最差值（上界）
// 返回值: 在当前局面下，双方都按最优策略博弈后的最终 x-y 值
int dfs(int step, int alpha, int beta) {
    // 终止条件：所有空位都已填满
    if (step == m) return calc();

    // ---- Dr.X 的回合（step 为偶数）：最大化 ----
    if (step % 2 == 0) {
        int best = -1000000;  // 初始化为极小值
        for (int i = 0; i < m; i++) {
            int r = empty_r[i], c = empty_c[i];
            if (a[r][c] != 0) continue;     // 这个位置已经被填了

            a[r][c] = rest[step];            // 填入当前数字
            int v = dfs(step + 1, alpha, beta);
            if (v > best) best = v;          // 取最大值
            if (best > alpha) alpha = best;  // 更新 alpha
            a[r][c] = 0;                     // 回溯

            if (alpha >= beta) break;        // Beta 剪枝：对手不会让这个分支发生
        }
        return best;

    // ---- Dr.Y 的回合（step 为奇数）：最小化 ----
    } else {
        int best = 1000000;   // 初始化为极大值
        for (int i = 0; i < m; i++) {
            int r = empty_r[i], c = empty_c[i];
            if (a[r][c] != 0) continue;

            a[r][c] = rest[step];
            int v = dfs(step + 1, alpha, beta);
            if (v < best) best = v;          // 取最小值
            if (best < beta) beta = best;    // 更新 beta
            a[r][c] = 0;

            if (alpha >= beta) break;        // Alpha 剪枝：自己不会让这个分支发生
        }
        return best;
    }
}

// ---------- 主函数 ----------
int main() {
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    int T;
    cin >> T;
    while (T--) {
        // 1. 读入棋盘，记录哪些数字已被使用
        bool used[10] = {false};  // used[d] = true 表示数字 d 已在棋盘上
        m = 0;                    // 空位计数
        for (int i = 0; i < 3; i++) {
            for (int j = 0; j < 3; j++) {
                cin >> a[i][j];
                if (a[i][j] == 0) {
                    empty_r[m] = i;      // 记录空位坐标
                    empty_c[m] = j;
                    m++;
                } else {
                    used[a[i][j]] = true;  // 标记已使用
                }
            }
        }

        // 2. 收集剩余数字（1~9 中未使用的），自动从小到大
        int cnt = 0;
        for (int d = 1; d <= 9; d++) {
            if (!used[d]) {
                rest[cnt++] = d;  // 因为 d 是从小到大遍历的，rest 自然有序
            }
        }
        // cnt 应该等于 m

        // 3. 如果棋盘已满，直接计算
        if (m == 0) {
            int diff = calc();
            if (diff > 0) cout << "first\n";
            else if (diff < 0) cout << "second\n";
            else cout << "tie\n";
            continue;
        }

        // 4. Minimax 搜索（alpha-beta 剪枝）
        int diff = dfs(0, -1000000, 1000000);

        // 5. 输出结果
        if (diff > 0) cout << "first\n";
        else if (diff < 0) cout << "second\n";
        else cout << "tie\n";
    }
    return 0;
}
