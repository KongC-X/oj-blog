# P1601 高精度加法

> **洛谷** | 普及- | C++14 | 提交时间: 2025-08-11

**算法标签**：`模拟`、`贪心`、`数学`

## 题目背景

本题是高精度加法的模板题。

## 题目描述

给定两个非负整数 $a,b$，求它们的和。**不用考虑负数**。

## 输入格式

输入共两行，每行一个非负整数，分别为 $a,b$。

## 输出格式

输出一行一个非负整数，表示 $a+b$ 的值。

## 样例

**样例输入 #1**
```
1
1```

**样例输出 #1**
```
2```

**样例输入 #2**
```
1001
9099```

**样例输出 #2**
```
10100```

## AC 代码

```cpp
/*
第一步：用string读入高精度整数
第二步：将两个高精度整数逆序存入ab两个整数数组
第三步：从左向右，逐位求和，结果存入c数组从左向右，逐位进位
第四步：逆序输出结果
*/

#include <bits/stdc++.h>
#include <iostream>
using namespace std;

string s1,s2;
int a[250],b[250],c[250];
int i,p,len;
int main() {
    cin >> s1 >> s2;
    // 逆序存入整数数组中
    for(i = s1.size() - 1;i >= 0;i--) {
        a[i] = s1[s1.size() - 1 - i] - '0';
    }
    for(i = s2.size() - 1;i >= 0;i--) {
        b[i] = s2[s2.size() - 1 - i] - '0';
    }
    // 加法的次数取决于较长的那个字符串
    len = s1.size() > s2.size() ? s1.size() : s2.size();
    // 验证
    // for(i = 0;i < len;i++) {
    //     cout << a[i] << " ";
    // }
    // 逐位相加
    for(i = 0;i < len;i++) {
        c[i] = a[i] + b[i];
    }
    // 进位
    for(i = 0;i < len;i++) {
        if(c[i] >= 10) {
            c[i + 1] = c[i + 1] + c[i] / 10;
            c[i] = c[i] % 10;
        }
    }
    // 两个不超过len位的整数做加法，结果可能是len+1位
    if(c[len] != 0) {
        len++;
    }
    // 逆序输出结果
    for(i = len - 1;i >= 0;i--){
        cout << c[i];
    }
}
```
