# B2152 分离整数的各个数

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-05

## 题目描述

给定一个整数 $n$，要求从个位开始分离出它的每一位数字。从个位开始按照从低位到高位的顺序依次输出每一位数字。

## 输入格式

输入一个整数 $n$ （$1 \le n \le 100\,000\,000$）。

## 输出格式

从个位开始按照从低位到高位的顺序依次输出每一位数字。数字之间以一个空格分开。

## 样例

**样例输入 #1**
```
123```

**样例输出 #1**
```
3 2 1```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int n;
    cin >> n;

    // 思路：每次取出 n 的个位输出，然后去掉个位，直到 n 为 0。
    // 但由于是从低位到高位输出，直接循环即可。注意控制空格。
    bool first = true;
    while (n > 0) {
        if (!first) cout << ' ';
        cout << n % 10;
        n /= 10;
        first = false;
    }
    // 如果 n 初始为 0（题目保证 n>=1，所以不会），但若为0，上面循环不执行，会没有输出。
    // 根据题目范围 n>=1，没问题。
    cout << endl;
    return 0;
}
```
