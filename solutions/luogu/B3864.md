# B3864 [GESP202309 一级] 小明的幸运数

> **洛谷** | 入门 | C++14 | 提交时间: 2025-03-28

**算法标签**：`递归`、`最小割`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1127>

## 题目描述

所有个位数为 $k$ 的正整数，以及所有 $k$ 的倍数，都被小明称为“ $k$ 幸运数”。小明想知道正整数 $L$ 和 $R$ 之间（包括 $L$ 和 $R$）所有 $k$ 幸运数的和，你能帮帮他吗？

## 输入格式

输入 $3$ 行。第一行包含一个正整数 $k$，第二行包含一个正整数 $L$，第三行包含一个正整数 $R$。约定 $2 \le k \le 9$，$1 \le L \le R \le 1000$。

## 输出格式

输出 $1$ 行，符合题意的幸运数之和。

## 样例

**样例输入 #1**
```
7
1
10```

**样例输出 #1**
```
7```

**样例输入 #2**
```
7
10
20```

**样例输出 #2**
```
31```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int l,r,k,i,s = 0;
    cin >> k >> l >> r;
    for(i = l;i <= r;i++) {
        if(i % 10 == k || i % k == 0) {
            s += i;
        }
    }
    cout << s << endl;
}
```
