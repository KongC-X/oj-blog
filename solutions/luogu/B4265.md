# B4265 [朝阳区小学组 2019] rectangle

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-19

**算法标签**：`2019`、`北京`、`顺序结构`、`科创活动`、`小学活动`

## 题目描述

给出一个长方形的长和宽，求长方形的周长和面积。

## 输入格式

两个整数 $a,b$（$1\leq a,b\leq 10\,000$），分别表示长方形的长和宽，以空格隔开。

## 输出格式

两个整数，分别表示长方形的周长和面积，以 $1$ 个空格隔开。

## 样例

**样例输入 #1**
```
5 3```

**样例输出 #1**
```
16 15```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int a, b;                     // a: 长, b: 宽
    cin >> a >> b;
    int c = 2 * (a + b);          // c: 周长
    int s = a * b;                // s: 面积
    cout << c << ' ' << s << endl;
    return 0;
}
```
