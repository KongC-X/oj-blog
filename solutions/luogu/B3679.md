# B3679 [语言月赛202211] Zone Selection

> **洛谷** | 入门 | C++14 | 提交时间: 2026-09-02

**算法标签**：`2022`、`结构体`、`语言月赛`

## 题目描述

在第五人格巅峰七阶及以上的排位赛中，需要进行区域选择。我们将在本题中形式化、推广化的解决区域选择问题。

在地图中，共有 $n$ 台密码机，第 $i$ 台密码机的坐标为 $(x_i,y_i)$。在推广化的游戏中，有 $k$ 名求生者。每名求生者可以选择一台密码机作为其出生点，我们称被选择的密码机为 **出生密码机**。

监管者共有 $T$ 个出生点可供选择。第 $i$ 个可能的出生点坐标为 $(x_i,y_i)$。此时，由于“封禁”天赋的存在，离监管者最远的密码机将不能被破译。

**如果多台密码机与监管者的距离相同且最远，“封禁”天赋将会封禁这几台密码机中标号最小的那一台。**

请问在该 $T$ 个出生点中，有多少出生点，可以使某一台 **出生密码机** 被封禁。

请注意：坐标点 $(x_1,y_1)$ 与坐标点 $(x_2,y_2)$ 之间的距离为 $\sqrt{(x_1-x_2)^2+(y_1-y_2)^2}$。

## 输入格式

输入共 $n+T+k+1$ 行。

输入的第一行为三个整数 $n,k,T$。

接下来 $n$ 行，每行两个整数 $x_i,y_i$，表示一台密码机的坐标。

接下来 $k$ 行，每行两个整数 $x_i,y_i$，表示一名求生者选择出生密码机的坐标，保证该坐标在上面出现过。

接下来 $T$ 行，每行两个整数 $x_i,y_i$，表示监管者的一个出生点。

## 输出格式

输出一行一个整数，为答案。

## 样例

**样例输入 #1**
```
4 2 2
-1 0
0 -1
2 0
0 2
-1 0
0 2
3 0
0 0```

**样例输出 #1**
```
1```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

struct Node {
    int x, y;   // 坐标
    bool b;     // 是否为出生密码机
} p[1005];

int main() {
    /*
     * 题目：B3679 [语言月赛202211] Zone Selection
     * 题意：n台密码机，k台出生密码机，T个监管者出生点。
     *       对每个监管者位置，找离他最远的密码机（距离相同取编号小），
     *       若该密码机是出生密码机，则计数+1。
     * 数据范围：n,k,T ≤ 1000，暴力 O(T*n) 可行。
     */
    int n, k, T;
    cin >> n >> k >> T;

    for (int i = 0; i < n; i++) {
        cin >> p[i].x >> p[i].y;
        p[i].b = false;
    }

    for (int i = 0; i < k; i++) {
        int x, y;
        cin >> x >> y;
        // 找到对应密码机，标记为出生密码机
        for (int j = 0; j < n; j++) {
            if (p[j].x == x && p[j].y == y) {
                p[j].b = true;
                break;
            }
        }
    }

    int ans = 0;
    for (int i = 0; i < T; i++) {
        int sx, sy;
        cin >> sx >> sy;
        long long mx = -1;
        int id = -1;
        for (int j = 0; j < n; j++) {
            long long dx = p[j].x - sx;
            long long dy = p[j].y - sy;
            long long d = dx * dx + dy * dy;
            if (d > mx) {
                mx = d;
                id = j;
            }
            // 距离相同时不更新，因为 j 从小到大，编号小的自然保留
        }
        if (p[id].b) ans++;
    }

    cout << ans << '\n';
    return 0;
}
```
