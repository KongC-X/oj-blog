# P2651 添加括号III

> **洛谷** | 普及- | C++14 | 提交时间: 2026-05-23

**算法标签**：`递归`、`数学`、`二分图`、`随机化`

## 题目描述

现在给出一个表达式，形如 $a_{1}/a_{2}/a_{3}/.../a_{n}$。

如果直接计算，就是一个个除过去，比如 $1/2/1/4 = 1/8$。

然而小$\text{A}$看到一个分数感觉很不舒服，希望通过添加一些括号使其变成一个整数。一种可行的办法是 $(1/2)/(1/4)=2$ 。

现在给出这个表达式，求问是否可以通过添加一些括号改变运算顺序使其成为一个整数。

## 输入格式

一个测试点中会有多个表达式。

第一行 $t$ ，表示表达式数量。

对于每个表达式，第一行是 $n$，第二行 $n$ 个数，第 $i$ 个数表示 $a_{i}$。

## 输出格式

输出 $t$ 行。

对于每个表达式，如果可以通过添加括号改变顺序使其变成整数，那么输出 `Yes`，否则输出 `No`。

## 样例

**样例输入 #1**
```
2
4
1 2 1 4
5
6 5 7 9 12```

**样例输出 #1**
```
Yes
No```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 10005;
int a[MAXN];                     // 存放序列 a1..an

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int t;                       // 测试数据组数
    cin >> t;
    while (t--) {
        int n;
        cin >> n;
        for (int i = 1; i <= n; ++i) cin >> a[i];

        // ---------- 详细思路 ----------
        // 原始表达式为 a1 / a2 / a3 / ... / an，默认是左结合（从左向右算）。
        // 通过添加括号可以改变运算顺序，例如：
        //   a1 / (a2 / a3 / a4)  相当于 a1 * (a3 * a4) / a2
        // 一般地，无论怎样加括号，a2 一定留在最外层分母的位置，
        // 而 a1、a3、a4、...、an 都可以通过括号翻到分子上。
        //
        // 因此，该表达式能变成整数当且仅当：
        //   a2 能整除 (a1 * a3 * a4 * ... * an)
        //
        // 直接相乘会溢出（乘积极大），我们采用“约分”的方法：
        //   用 a2 分别与每个分子上的数求最大公约数并除掉，
        //   如果最后 a2 变为 1，说明 a2 的所有因子都在分子中找到了，
        //   此时结果为整数；否则无法整除。
        // ---------------------------------------------------------

        int d = a[2];                     // d 表示分母剩余的因子，初始为 a2

        d /= __gcd(d, a[1]);              // 用 a1 去约掉 d 的部分因子
        for (int i = 3; i <= n && d > 1; ++i) {
            d /= __gcd(d, a[i]);          // 依次用 a3...an 约分
        }

        if (d == 1)                       // 分母被完全约掉 → 结果是整数
            cout << "Yes\n";
        else
            cout << "No\n";
    }
    return 0;
}
```
