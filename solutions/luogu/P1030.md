# P1030 [NOIP 2001 普及组] 求先序排列

> **洛谷** | 普及- | C++14 | 提交时间: 2026-06-14

**算法标签**：`贪心`、`字符串`、`单调队列`、`最小环`、`字符串模拟`、`迭代加深`

## 题目描述

给出一棵二叉树的中序与后序排列。求出它的先序排列。（约定树结点用不同的大写字母表示，且二叉树的节点个数 $ \le 8$）。

## 输入格式

共两行，均为大写字母组成的字符串，表示一棵二叉树的中序与后序排列。

## 输出格式

共一行一个字符串，表示一棵二叉树的先序。

## 样例

**样例输入 #1**
```
BADC
BDCA
```

**样例输出 #1**
```
ABCD
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

/*
  根据二叉树的中序遍历 in 和后序遍历 post，输出先序遍历
  递归思路：
  1. 后序遍历的最后一个字符是当前子树的根节点
  2. 在中序遍历中找到根节点的位置 pos
  3. 中序的左边部分（in[0..pos-1]）是左子树的中序
     右边部分（in[pos+1..]）是右子树的中序
  4. 后序中对应长度的前半部分是左子树的后序，中间部分是右子树的后序
     后序总长度去掉最后一个根节点，分配：
       左子树后序长度 = pos
       右子树后序长度 = 总长度-1 - pos
  5. 先序：先输出根，再递归左子树，再递归右子树
*/
void solve(string in, string post) {
    if (in.empty()) return;                    // 空子树直接返回

    char root = post.back();                   // 后序遍历的最后一个字符是根
    cout << root;                              // 先序：先输出根

    // 在中序中找到根的位置
    int pos = in.find(root);

    // 左子树的中序和后序
    string inL = in.substr(0, pos);
    string postL = post.substr(0, pos);

    // 右子树的中序和后序
    string inR = in.substr(pos + 1);
    string postR = post.substr(pos, post.size() - 1 - pos);

    solve(inL, postL);                         // 递归左子树
    solve(inR, postR);                         // 递归右子树
}

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string in;    // 中序遍历
    string post;  // 后序遍历
    cin >> in >> post;

    solve(in, post);
    cout << '\n';

    return 0;
}
```
