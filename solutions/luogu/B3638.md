# B3638 T1 三角形面积

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-09

**算法标签**：`数学`、`顺序结构`

## 题目背景

**请尽量在 20min 之内写完题目。这是指「写代码」的时间；「读题」时间不计算在内。**

## 题目描述

给定平面直角坐标系上的三个整点 $A, B, C$ 的坐标，求其围成的三角形面积。

**数据保证答案一定是整数。所以如果你采用了浮点数来计算，请四舍五入到整数**。

---

**两点之间的距离公式：** $(x_1, y_1), (x_2, y_2)$ 之间的距离是 $\sqrt{(x_1 - x_2)^2 + (y_1 - y_2)^2}$   

**海伦公式：** 若三角形的边长为 $a, b, c$，则三角形的面积是 $\sqrt{s(s-a)(s-b)(s-c)}$，其中 $s=\frac12(a+b+c)$.

## 输入格式

共三行，每行表示一个三角形上的点。  
每行包含两个正整数，表示点的坐标，形式为 `x y`。

## 输出格式

共一行，一个整数，表示三角形面积。

## 样例

**样例输入 #1**
```
10 20
30 40
50 50```

**样例输出 #1**
```
100```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：计算几何（海伦公式）
     * 思路：
     * 1. 读入三个顶点坐标 (x1,y1), (x2,y2), (x3,y3)
     * 2. 用两点距离公式计算三条边长 a, b, c
     * 3. 海伦公式：s = (a+b+c)/2，面积 = sqrt(s*(s-a)*(s-b)*(s-c))
     * 4. 因为答案保证为整数，将浮点数四舍五入后输出
     */
    double x1, y1, x2, y2, x3, y3;
    cin >> x1 >> y1;
    cin >> x2 >> y2;
    cin >> x3 >> y3;

    // 计算三边长度
    double a = sqrt((x2 - x1) * (x2 - x1) + (y2 - y1) * (y2 - y1));
    double b = sqrt((x3 - x2) * (x3 - x2) + (y3 - y2) * (y3 - y2));
    double c = sqrt((x1 - x3) * (x1 - x3) + (y1 - y3) * (y1 - y3));

    // 海伦公式
    double s = (a + b + c) / 2.0;
    double area = sqrt(s * (s - a) * (s - b) * (s - c));

    // 四舍五入到整数（+0.5后取整）
    int ans = (int)(area + 0.5);
    cout << ans << endl;

    return 0;
}
```
