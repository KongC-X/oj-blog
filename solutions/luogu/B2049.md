# B2049 最大数输出

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-27

## 题目描述

输入三个整数，输出最大的数。

## 输入格式

输入为一行，包含三个整数，数与数之间以一个空格分开。

## 输出格式

输出一行，包含一个整数，即最大的整数。

## 样例

**样例输入 #1**
```
10 20 56```

**样例输出 #1**
```
56```

## AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
int main(){
	int a,b,c;
	cin >> a >> b >> c;
	cout << max(a,max(b,c));
}

```
