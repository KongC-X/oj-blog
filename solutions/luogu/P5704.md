# P5704 【深基2.例6】字母转换

> **洛谷** | 入门 | C++14 | 提交时间: 2025-07-31

## 题目描述

输入一个小写字母，输出其对应的大写字母。例如输入 q[回车] 时，会输出 Q。

## 样例

**样例输入 #1**
```
q```

**样例输出 #1**
```
Q```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int main(){
    char c;
    cin>>c;
    cout<<char(c-32);
}

```
