# P1562 还是 N 皇后

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-07-28

**算法标签**：`搜索`、`进制`、`位运算`

## 题目背景

正如题目所说，这题是著名的 $N$ 皇后问题。

## 题目描述

一个 $ N×N $ 的跳棋棋盘，有 $ N $ 个皇后棋子被放置在棋盘上，使得每行、每列有且只有一个皇后棋子，每条对角线（包括两条主对角线的所有平行线）上至多有一个皇后棋子。棋盘上一部分格子可以放置棋子，而另一部分则不可以。

求放置棋子的方案总数。

## 输入格式

第一行有一个 $N$。接下来有 $N$ 行 $N$ 列描述一个棋盘，`*` 表示可放，`.` 表示不可放。

## 样例

**样例输入 #1**
```
4
**.*
****
****
****```

**样例输出 #1**
```
1```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int n;
char g[20][20];                     // 棋盘，1‑based，'*' 可放，'.' 不可放
long long ans;                      // 方案数可能较大

/*
  位运算版 DFS（深度优先搜索）
  参数：
    r    : 当前要放的行 (1‑based)
    col  : 列占用标记，二进制从低位到高位对应列 1~n
    ld   : 左对角线占用标记（左上到右下），同一对角线的 (r+j) 相同
    rd   : 右对角线占用标记（右上到左下），同一对角线的 (r-j+n) 相同
*/
void dfs(int r, int col, int ld, int rd) {
    if (r > n) {                    // 所有行都已成功放置
        ans++;
        return;
    }
    // 当前行能放的位置：
    // 1) 列、两个对角线都没有占用；
    // 2) 该格子是 '*'（可放）。
    int mask = 0;
    for (int j = 1; j <= n; j++) {
        if (g[r][j] == '*')
            mask |= (1 << (j - 1));        // 第 j 列可用则对应位置 1
    }
    // 排除被占用的列、被占用的对角线
    int can = mask & ~(col | ld | rd);
    // 遍历所有可放位置（利用 lowbit）
    while (can) {
        int pos = can & -can;              // 取出最低位的 1
        can ^= pos;                        // 去掉这个位置，继续尝试其他
        // 计算 pos 对应的列号（1‑based）
        int j = __builtin_ctz(pos) + 1;    // GCC 内置函数，计算末尾 0 的个数
        dfs(r + 1,
            col | pos,
            (ld | pos) << 1,               // 左对角线：下一行会右移一位
            (rd | pos) >> 1);              // 右对角线：下一行会左移一位
    }
}

int main() {
    cin >> n;
    for (int i = 1; i <= n; i++)
        cin >> (g[i] + 1);        // 读入整行，从 g[i][1] 开始

    dfs(1, 0, 0, 0);
    cout << ans << endl;
    return 0;
}
```
