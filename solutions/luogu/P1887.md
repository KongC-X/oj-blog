# P1887 乘积最大3

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-12

**算法标签**：`递归`、`随机化`

## 题目描述

请你找出 $M$ 个和为 $N$ 的正整数，他们的乘积要尽可能的大。

输出字典序最小的一种方案。

## 输入格式

一行，两个正整数 $N,M$

## 输出格式

$M$ 个和为 $N$ 的，乘积尽可能的大的正整数。

## 样例

**样例输入 #1**
```
6 3```

**样例输出 #1**
```
2 2 2```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    int N, M;                        // N: 总和, M: 个数
    cin >> N >> M;

    // ---------- 思路 ----------
    // 和固定时，数字越接近乘积越大。因此把 N 均分给 M 个数最优。
    // q = N / M 为基础值，r = N % M 为余数，有 r 个数需要比 q 多 1。
    // 为保证字典序最小，先输出较小的数 (M-r 个 q)，再输出较大的数 (r 个 q+1)。
    // 下面的循环用一个条件判断即可简洁实现。

    int q = N / M;
    int r = N % M;

    for (int i = 0; i < M; i++) {
        if (i > 0) cout << ' ';            // 数字间空格，行末无多余空格
        // 前 M-r 个输出 q，后 r 个输出 q+1
        cout << (i < M - r ? q : q + 1);
    }
    cout << '\n';

    return 0;
}
```
