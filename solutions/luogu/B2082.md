# B2082 数字统计

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-04

## 题目描述

请统计某个给定范围 $[L,R]$ 的所有整数中，数字 $2$ 出现的次数。

比如给定范围 $[2,22]$，数字 $2$ 在数 $2$ 中出现了 $1$ 次，在数 $12$ 中出现 $1$ 次，在数 $20$ 中出现 $1$ 次，在数 $21$ 中出现 $1$ 次，在数 $22$ 中出现 $2$ 次，所以数字 $2$ 在该范围内一共出现了 $6$ 次。

## 输入格式

输入共 $1$ 行，为两个正整数 $L$ 和 $R$，之间用一个空格隔开。

## 输出格式

输出共 $1$ 行，表示数字 $2$ 出现的次数。

## 样例

**样例输入 #1**
```
2 22```

**样例输出 #1**
```
6```

**样例输入 #2**
```
2 100```

**样例输出 #2**
```
20```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    int L, R;                     // L: 区间左端点, R: 区间右端点
    cin >> L >> R;

    int ans = 0;                  // ans: 数字 2 出现的总次数

    // 遍历 [L, R] 之间的每一个整数
    for (int i = L; i <= R; i++) {
        int x = i;                // 临时变量，用于逐位分解
        // 分解当前数的每一位
        while (x > 0) {
            if (x % 10 == 2) {    // 当前个位是 2
                ans++;
            }
            x /= 10;              // 去掉个位，继续判断更高位
        }
    }

    cout << ans << endl;
    return 0;
}
```
