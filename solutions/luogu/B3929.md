# B3929 [GESP202312 五级] 小杨的幸运数

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2025-06-24

**算法标签**：`后缀数组`、`最小割`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1137>

## 题目描述

小杨认为，所有大于等于 $a$ 的完全平方数都是他的超级幸运数。

小杨还认为，所有超级幸运数的倍数都是他的幸运数。自然地，小杨的所有超级幸运数也都是幸运数。

对于一个非幸运数，小杨规定，可以将它一直 $+1$，直到它变成一个幸运数。我们把这个过程叫做幸运化。例如，如果 $a=4$，那么 $4$ 是最小的幸运数，而 $1$ 不是，但我们可以连续对 $1$ 做 $3$ 次 $+1$ 操作，使其变为 $4$，所以我们可以说， $1$ 幸运化后的结果是 $4$。

现在，小杨给出 $N$ 个数，请你首先判断它们是不是幸运数；接着，对于非幸运数，请你将它们幸运化。

## 输入格式

第一行 $2$ 个正整数 $a, N$。

接下来 $N$ 行，每行一个正整数 $x$ ，表示需要判断（幸运化）的数。

## 输出格式

输出 $N$ 行，对于每个给定的 $x$ ，如果它是幸运数，请输出 `lucky`，否则请输出将其幸运化后的结果。

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

const int max_bound = 2000001; // 定义最大边界
bool lucky[max_bound + 1]; // 初始化所有数为非幸运数
int main() {
    int a, N;
    cin >> a >> N;
    // 预处理标记幸运数
	// 使用布尔数组lucky标记所有幸运数。
	// 从大于等于a的最小平方数开始，标记其所有倍数（包括自身）为幸运数。
    int start_i = ceil(sqrt(a)); // 计算起始平方根
    for (int i = start_i; ; i++) {
        long long sq = (long long)i * i;// 计算平方数
        if (sq > max_bound) break;// 超过边界则停止
        for (long long j = sq; j <= max_bound; j += sq) {
            lucky[j] = true; // 标记超级幸运数及其倍数
        }
    }
    
    // 预处理幸运化结果
    int res[max_bound + 1] = {0}; // 存储每个数的幸运化结果
    int min_lucky = 0; // 记录当前最小幸运数
	// 从后向前遍历，维护当前遇到的最小幸运数min_lucky。
	// 当我们从后向前遍历时，遇到的第一个幸运数一定是该位置之后的最小幸运数。
	// 当我们遇到幸运数时，它一定是当前剩余数字中最小的幸运数
	// 对于前面的非幸运数，它们只需要使用当前记录的最小幸运数
    for (int i = max_bound; i >= 1; i--) {
        if (lucky[i]) {
            min_lucky = i; // 更新最小幸运数
            res[i] = i; // 幸运数的幸运化结果为其自身
        } else {
            res[i] = min_lucky; // 非幸运数的幸运化结果为下一个幸运数
        }
    }
    
    // 处理查询
    for (int i = 0; i < N; i++) {
        int x;
        cin >> x;
        if (lucky[x]) {
            cout << "lucky" << endl;
        } else {
            cout << res[x] << endl;
        }
    }
    return 0;
}
```
