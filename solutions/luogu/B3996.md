# B3996 [洛谷 202406GESP 模拟 三级] 小洛的数字游戏

> **洛谷** | 入门 | C++14 | 提交时间: 2026-10-08

**算法标签**：`模拟`、`循环结构`、`数组`

## 题目描述

小洛有一个正整数 $n$，他会进行若干次下列操作：

- 取出正整数 $n$ 的末位，记作 $x$；
- 将 $x$ 平方之后，保留个位，放于 $n$ 的首位之前（如果是 $0$，则数字不保留前导 $0$）；

上述两步合计为一次操作。例如有一个正整数 $142$，它可以进行如下操作：

- 取出末尾的 $2$，原正整数变为 $14$；
- $2^2=4$，放于 $14$ 首位之前成为 $414$，第一次操作完成；
- 取出末尾的 $4$，原正整数变为 $41$；
- $4^2=16$，保留个位的 $6$，放于 $41$ 的首位成为 $641$，第二次操作完成；
- 以此类推……

现在小洛想知道，对于一个正整数 $n$，能否进行**不超过 $q$ 次**操作让其变为正整数 $m$。请你帮帮他。

## 输入格式

输入三个正整数 $n,m,q$。

## 输出格式

如果能进行不超过 $q$ 次操作让正整数 $n$ 变为正整数 $m$，则输出若干行，第 $i$ 行输出一个正整数表示进行第 $i$ 次操作后的正整数 $n$ 的值。否则输出一行一个整数 $-1$。

## 样例

**样例输入 #1**
```
123 611 10```

**样例输出 #1**
```
912
491
149
114
611```

**样例输入 #2**
```
123 231 12345```

**样例输出 #2**
```
-1```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：B3996 [洛谷 202406GESP 模拟 三级] 小洛的数字游戏
     * 题意：给定 n, m, q。每次操作：
     *       1. 取出 n 的末位 x，n 去掉末位。
     *       2. 计算 x^2 的个位 y。
     *       3. 如果 y != 0，将 y 放到 n 的前面形成新数；如果 y == 0，则新数就是 n。
     *       问能否在不超过 q 次操作内将 n 变为 m。
     *       如果能，按顺序输出每次操作后的 n；否则输出 -1。
     *
     * 思路：直接模拟，最多模拟 q 次。因为 q ≤ 10^6，每次操作 O(1)，
     *       总时间完全可以接受。用数组记录每一步的结果，如果中途得到 m
     *       就输出记录的所有结果；如果模拟完 q 次还没得到 m，输出 -1。
     *
     * 注意：n 和 m 最大 10^9，用 long long。
     *       预计算 10 的幂，避免使用 pow 的浮点误差。
     */

    long long n, m, q;
    cin >> n >> m >> q;

    // 如果一开始就相等，0 次操作即可，不输出任何内容
    if (n == m) {
        return 0;
    }

    // 预计算 10 的幂，最大需要 10^12 左右
    long long p10[15];
    p10[0] = 1;
    for (int i = 1; i <= 12; i++) {
        p10[i] = p10[i - 1] * 10;
    }

    long long steps[1000005];   // 记录每次操作后的 n
    int cnt = 0;                // 操作次数
    bool found = false;         // 是否找到 m

    for (int i = 0; i < q; i++) {
        // 取出末位 x
        int x = n % 10;
        n /= 10;                // 去掉末位

        // 计算 y = x^2 的个位
        int y = (x * x) % 10;

        // 计算当前 n 的位数
        int len = 0;
        long long temp = n;
        if (temp == 0) {
            len = 0;
        } else {
            while (temp > 0) {
                temp /= 10;
                len++;
            }
        }

        // 构造新数
        if (y != 0) {
            n = y * p10[len] + n;
        }
        // 如果 y == 0，n 保持不变

        // 记录并检查
        steps[cnt++] = n;
        if (n == m) {
            found = true;
            break;
        }
    }

    if (found) {
        // 输出所有操作后的结果
        for (int i = 0; i < cnt; i++) {
            cout << steps[i] << endl;
        }
    } else {
        cout << -1 << endl;
    }

    return 0;
}
```
