# B2093 查找特定的值

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-02

**算法标签**：`数组`

## 题目描述

在一个序列（下标从 $0$ 开始）中查找一个给定的值，输出第一次出现的位置。

## 输入格式

第一行包含一个正整数 $n$，表示序列中元素个数。$1 \le n \le 10000$。

第二行包含 $n$ 个整数，依次给出序列的每个元素，相邻两个整数之间用单个空格隔开。元素的绝对值不超过 $10000$。

第三行包含一个整数 $x$，为需要查找的特定值。$x$ 的绝对值不超过 $10000$。

## 输出格式

若序列中存在 $x$，输出 $x$ 第一次出现的下标；  否则输出 `-1`。

## 样例

**样例输入 #1**
```
5
2 3 6 7 3
3```

**样例输出 #1**
```
1```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】顺序查找
     * 【核心思路】
     * 1. 读入 n。
     * 2. 读入 n 个整数到数组 a[0..n-1]。
     * 3. 读入待查找的值 x。
     * 4. 从 i=0 到 n-1 遍历：
     *    - 如果 a[i] == x，输出 i，程序结束。
     * 5. 如果遍历完都没找到，输出 -1。
     *
     * 【时间复杂度】O(n)
     */

    int n;          // n: 元素个数
    cin >> n;

    int a[10005];   // a: 存储序列
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int x;          // x: 要查找的值
    cin >> x;

    for (int i = 0; i < n; i++) {
        if (a[i] == x) {
            cout << i << endl;
            return 0;   // 找到后立即退出程序
        }
    }

    // 没找到
    cout << -1 << endl;
    return 0;
}
```
