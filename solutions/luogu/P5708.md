# P5708 【深基2.习2】三角形面积

> **洛谷** | 入门 | C++14 | 提交时间: 2025-07-31

**算法标签**：`SG函数`

## 题目描述

一个三角形的三边长分别是 $a$、$b$、$c$，那么它的面积为 $\sqrt{p(p-a)(p-b)(p-c)}$，其中 $p=\frac{1}{2}(a+b+c)$。输入这三个数字，计算三角形的面积，四舍五入精确到 $1$ 位小数。

## 输入格式

第一行输入三个实数 $a,b,c$，以空格隔开。

## 输出格式

输出一个实数，表示三角形面积。精确到小数点后 $1$ 位。

## 样例

**样例输入 #1**
```
3 4 5```

**样例输出 #1**
```
6.0```

## AC 代码

```cpp
#include<bits/stdc++.h>
using namespace std;
double a,b,c,p,ans;
int main()
{
	cin>>a>>b>>c;
	p=(a+b+c)/2;
	ans=sqrt(p*(p-a)*(p-b)*(p-c));
	printf("%.1lf",ans);
	return 0;
}

```
