# P15799 [GESP202603 五级] 找数

> **洛谷** | 普及- | C++14 | 提交时间: 2026-03-18

**算法标签**：`后缀数组`、`三分`

## 题目描述

给定一个包含 $n$ 个互不相同的正整数的数组 $A$ 与一个包含 $m$ 个互不相同的正整数的数组 $B$，请你帮忙计算有多少个数在数组 $A$ 与数组 $B$ 中均出现。

## 输入格式

第一行包含两个整数 $n,m$。

第二行包含 $n$ 个正整数 $a_1,a_2,\cdots,a_n$ 表示数组 $A$。

第三行包含 $m$ 个正整数 $b_1,b_2,\cdots,b_m$ 表示数组 $B$。

## 输出格式

输出一个整数，表示在数组 $A$ 与数组 $B$ 中均出现的数的个数。

## 样例

**样例输入 #1**
```
3 5
4 2 3
3 1 5 4 6```

**样例输出 #1**
```
2```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int a[100010];

int main() {
    int n, m;
    cin >> n >> m;
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }
    sort(a, a + n);

    int ans = 0;
    for (int i = 0; i < m; ++i) {
        int b;
        cin >> b;
        // 二分查找
        int l = 0, r = n - 1;
        bool flag = false;
        while (l <= r) {
            int mid = (l + r) / 2;
            if (a[mid] == b) {
                flag = true;
                break;
            } else if (a[mid] < b) {
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }
        if (flag) ans++;
    }
    cout << ans << endl;
    return 0;
}
```
