# B2144 阿克曼（Ackermann）函数

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-15

**算法标签**：`分支结构`、`函数与递归`

## 题目描述

阿克曼（Ackermann）函数 $A(m,n)$ 中，$m, n$ 定义域是非负整数（$m \le 3$，$n \le 10$），函数值定义为：

$\mathit{A}(m,n)=n+1$；（$m=0$ 时）。

$\mathit{A}(m,n)=\mathit{A}(m-1,1)$；（$m>0$、$n=0$ 时）。

$\mathit{A}(m,n)=\mathit{A}(m-1,\mathit{A}(m,n-1))$；（$m,n>0$ 时）。

## 样例

**样例输入 #1**
```
2 3```

**样例输出 #1**
```
9```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

// 阿克曼函数：递归计算 A(m, n)
int ack(int m, int n) {
    if (m == 0) return n + 1;                  // 规则1
    if (n == 0) return ack(m - 1, 1);          // 规则2
    return ack(m - 1, ack(m, n - 1));          // 规则3
}

int main() {
    int m, n;
    cin >> m >> n;
    cout << ack(m, n) << endl;
    return 0;
}
```
