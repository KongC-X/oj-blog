# P2637 [USACO08NOV] 第一次，第二次，成交！Going Once, Going Twice, Gone! B

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-09

**算法标签**：`模拟`、`2008`、`USACO`、`枚举`

## 题目描述

因为奶牛们的节食运动给 FJ 余下了一大批干草无法处理，所以他准备要开一个拍卖会去出售他的干草。

他有 $n$ 批干草。他的客户有 $m$ 个，都是和他一样的农夫。第 $i$ 名农夫会告诉 FJ 他会为 FJ 的每批干草付 $p_i$ 的钱。每个农夫都想买（也只想买）FJ 的一批草料。

为了确保农夫们不会互相嫉妒，所以 FJ 决定要以一个固定的价格出售他的草料。每一个出价大于等于 FJ 的要价的农夫将会买到草料。

请你帮助 FJ 找出能让他卖出最多的钱的最低的单批草料的售价。

## 输入格式

第一行：两个被空格隔开的整数 $n$ 和 $m$。

第二行到第 $m+1$ 行：第 $i+1$ 行只包含一个整数 $p_i$。

## 输出格式

共一行，包含由空格隔开的两个整数：FJ 能出的每批草料的最低价格，以及他能赚到的最多的钱。

## 样例

**样例输入 #1**
```
5 4
2
8
10
7```

**样例输出 #1**
```
7 21```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：枚举 / 排序
     * 核心思路：
     * 1. 售价只能取农夫出价中的某个值，否则可以调整到下一个出价来提高收益或保持不变。
     * 2. 将出价升序排序，枚举每个出价作为售价 p。
     *    则出价 >= p 的农夫数量 = m - i（从 i 到末尾）。
     * 3. 收益 = 人数 * p，但不能超过干草批数 n（因为最多卖 n 批）。
     * 4. 记录最大收益，如果收益相同则取较小的售价。
     */
    int n, m;          // n: 干草批数, m: 农夫数
    cin >> n >> m;

    int a[1005];       // a[]: 存储每个农夫的出价
    for (int i = 0; i < m; i++) {
        cin >> a[i];   // 读入出价
    }

    sort(a, a + m);    // 升序排序，便于统计人数

    int bp = 0, bm = 0;  // bp: 最优售价, bm: 最大收益（初始0）

    for (int i = 0; i < m; i++) {
        int p = a[i];      // 当前枚举的售价（第 i 个出价）
        int c = m - i;     // 出价 >= p 的农夫数（因为排序后从 i 到末尾都 >= p）
        int mo = c * p;    // 按当前售价和人数计算的收益

        if (c > n) {       // 如果愿意买的农夫数超过干草批数，最多只能卖 n 批
            c = n;
            mo = c * p;    // 重新计算收益
        }

        // 如果当前收益更大，或收益相等但价格更低，则更新最优解
        if (mo > bm || (mo == bm && p < bp)) {
            bm = mo;
            bp = p;
        }
    }

    // 输出最优售价和最大收益
    cout << bp << " " << bm << endl;
    return 0;
}
```
