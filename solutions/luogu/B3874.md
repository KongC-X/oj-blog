# B3874 [GESP202309 六级] 小杨的握手问题

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-06-02

**算法标签**：`LCA`、`最小环`、`最小割`、`队列`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1132>

## 题目描述

小杨的班级里共有 $N$ 名同学，学号从 $0$ 至 $N-1$。

某节课上，老师安排全班同学进行一次握手游戏，具体规则如下：老师安排了一个顺序，让全班 $N$ 名同学依次进入教室。每位同学进入教室时，需要和 **已经在教室内** 且 **学号小于自己** 的同学握手。

现在，小杨想知道，整个班级总共会进行多少次握手。

**提示：可以考虑使用归并排序进行降序排序，并在此过程中求解。**

## 输入格式

输入包含 $2$ 行。第一行一个整数 $N$ ，表示同学的个数；第二行 $N$ 个用单个空格隔开的整数，依次描述同学们进入教室的顺序，每个整数在 $0 \sim N-1$ 之间，表示该同学的学号。

保证每位同学会且只会进入教室一次。

## 输出格式

输出一行一个整数，表示全班握手的总次数。

## 样例

**样例输入 #1**
```
4
2 1 3 0```

**样例输出 #1**
```
2```

**样例输入 #2**
```
6
0 1 2 3 4 5```

**样例输出 #2**
```
15```

## AC 代码

```cpp
#include <bits/stdc++.h> 
#include <iostream> 
using namespace std;

int a[300010];  // 存储学生进入教室的顺序（学号）
long long ans = 0;  // 总握手次数（即顺序对的数量）

// ---------- 题目思路 ----------
// 问题本质：给定一个 0..N-1 的排列（进入顺序），每进入一个学生，
// 他需要和当前已经在教室中且学号小于自己的所有人握手。
// 因此，握手总次数 = 对于每一个位置 i，统计在它之前出现的、学号比 a[i] 小的元素个数，
// 并对所有 i 求和。这等价于求整个序列的「正序对」总数。
//
// 我们可以利用归并排序在合并过程中高效地统计顺序对：
// 当合并左右两个已排序的子数组时，若左半部分的当前元素 a[i] 小于右半部分的当前元素 a[j]，
// 因为右半部分已经升序，所以 a[i] 一定也小于 a[j] 及其之后的所有元素（共 right - j + 1 个）。
// 这些元素在原序列中均位于 a[i] 之后，且学号更大，因此它们都能和 a[i] 形成握手。
// 累加这些数量，即可得到总的握手次数。
//
// 归并排序的时间复杂度为 O(n log n)，空间复杂度 O(n)，满足题目 3e5 的数据范围。
// --------------------------

// 合并函数：将 arr[left..mid] 和 arr[mid+1..right] 两个已排序的子数组合并，
//           并在此过程中统计顺序对（握手次数）。
void merge(int arr[], int left, int mid, int right) {
    int i = left;                        // 左子数组的起始索引
    int j = mid + 1;                     // 右子数组的起始索引
    int k = 0;                           // 临时数组 temp 的索引
    int temp[right - left + 1];          // 临时数组用于存储合并后的结果
    // 区间内的元素数量 = 右边界 - 左边界 + 1

    // 当左右子数组都还有元素时，比较它们的当前元素
    while (i <= mid && j <= right) {
        if (arr[i] < arr[j]) {           // 左元素 < 右元素
            // 此时 arr[i] 小于 arr[j]，且右半部分已经升序，
            // 所以 arr[i] 也小于 arr[j] 及其之后的所有元素（共 right - j + 1 个）。
            // 这些元素在原序列中都位于 arr[i] 之后，即构成握手。
            ans += (right - j + 1);      // 统计顺序对
            temp[k++] = arr[i++];
        } else {
            temp[k++] = arr[j++];
            // 逆序对：左元素大于右元素，统计握手次数
            // ans += (mid - i + 1);
        }
    }

    // 将左子数组剩余的元素直接放入 temp
    while (i <= mid) {
        temp[k++] = arr[i++];
    }

    // 将右子数组剩余的元素直接放入 temp
    while (j <= right) {
        temp[k++] = arr[j++];
    }

    // 将临时数组 temp 中的元素复制回原数组 arr
    for (i = left, k = 0; i <= right; i++, k++) {
        arr[i] = temp[k];
    }
}

// 归并排序函数：递归地将数组分成两半，然后调用 merge 进行合并
void mergeSort(int arr[], int left, int right) {
    if (left < right) {
        int mid = (left + right) / 2;               // 中间索引
        // 另一种防止溢出的写法：int mid = left + (right - left) / 2;
        mergeSort(arr, left, mid);                  // 对左半部分排序
        mergeSort(arr, mid + 1, right);             // 对右半部分排序
        merge(arr, left, mid, right);               // 合并并统计握手次数
    }
}

int main() {
    ios::sync_with_stdio(false);                  // 加速输入输出
    cin.tie(0);

    int n;                                        // 学生总人数
    cin >> n;
    for (int i = 0; i < n; i++) {
        cin >> a[i];                              // 读入学生进入教室的顺序（学号）
    }

    mergeSort(a, 0, n - 1);                       // 对数组进行归并排序，内部完成握手次数统计

    cout << ans << endl;                          // 输出总握手次数
    return 0;
}
