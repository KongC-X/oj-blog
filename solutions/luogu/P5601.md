# P5601 小 D 与笔试

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-24

**算法标签**：`枚举`、`洛谷月赛`

## 题目背景

小 D 是一位即将参加 ION 的 IO 选手，然而笔试题库中数量繁多的奇怪题目让他大伤脑筋，快来帮帮他！

## 题目描述

笔试题库可以抽象为 $n$ 道题目，每道题目由题面和答案组成，都是一个字符串，保证所有题目题面互不相同。

为了检验小 D 背笔试的效果，教练进行了一次模拟考试，考试包含 $q$ 道题目，每道题目都有 $4$ 个选项，小 D 需要从 $4$ 个选项中选出与答案相符的选项。

现在你需要帮助小 D 完成这场考试。

## 输入格式

第一行两个正整数 $n, q$。

接下来 $n$ 行，每行 $2$ 个用空格分隔的字符串，表示这道题目的题面和答案。

接下来 $q$ 行，每行 $5$ 个用空格分隔的字符串，第一个字符串表示模拟考试中这道题目的题面，其余 $4$ 个字符串按顺序分别为这道题目的选项 A 到选项 D，保证选项各不相同。

## 输出格式

对于模拟考试中的每道题目，输出一个字符表示这道题目答案对应的选项，保证所有题目均有解。

## 样例

**样例输入 #1**
```
3 4
decoak yes
duliuchutiren nonono
csps noiptg
decoak yes no qwq qaq
csps noiptg noippj noi cspj
decoak qwq qaq yesyes yes
duliuchutiren yes no nono nonono```

**样例输出 #1**
```
A
A
D
D
```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    // 思路：
    // 1. 读入题库的 n 道题，存储题面和对应答案。
    // 2. 对于模拟考试中的每道题，根据题面在题库中找到正确答案。
    // 3. 将正确答案与四个选项比对，输出匹配的选项字母（A~D）。
    // 数据范围很小，直接暴力查找即可。

    int n, q;                        // n:题库题数，q:考试题数
    cin >> n >> q;

    string p[105];                   // p[i] 存储第 i 道题的题面
    string a[105];                   // a[i] 存储第 i 道题的答案
    for (int i = 0; i < n; i++) {
        cin >> p[i] >> a[i];
    }

    while (q--) {
        string t;                    // 考试题的题面
        string o[4];                 // 四个选项（A~D）
        cin >> t >> o[0] >> o[1] >> o[2] >> o[3];

        // 在题库中找到该题面的正确答案
        string right;
        for (int i = 0; i < n; i++) {
            if (p[i] == t) {
                right = a[i];
                break;
            }
        }

        // 匹配选项
        if (o[0] == right) cout << "A" << endl;
        else if (o[1] == right) cout << "B" << endl;
        else if (o[2] == right) cout << "C" << endl;
        else cout << "D" << endl;
    }

    return 0;
}
```
