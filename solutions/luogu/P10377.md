# P10377 [GESP202403 六级] 好斗的牛

> **洛谷** | 普及- | C++14 | 提交时间: 2026-06-03

**算法标签**：`模拟`、`图论`、`费用流`、`排序算法`、`迭代加深`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1146>

## 题目描述

你有 $10^9$ 个牛棚，从左到右一字排开。你希望把 $n$ 头牛安置到牛棚里。麻烦的是，你的牛很好斗，如果他们附近有其他的牛，他们就会不安分地去挑事。其中，第 $i$ 头牛的攻击范围是 $(a_i, b_i)$，这意味着，如果他的左边 $a_i$ 个牛棚或者右边 $b_i$ 个牛棚有其他牛，它就会去挑事。

你想留下一段连续的牛棚，并把其他牛棚都卖掉。请问您最少需要留下多少牛棚，才能保证至少存在一种方案能够把所有的 $n$ 头牛都安置进剩余的牛棚里，且没有牛会挑事？

## 输入格式

第一行一个正整数 $n$。  
第二行 $n$ 个正整数 $a_1, a_2, \dots a_n$。  
第三行 $n$ 个正整数 $b_1, b_2, \dots b_n$。

## 输出格式

输出一行一个整数表示答案。

## 样例

**样例输入 #1**
```
2
1 2
1 2
```

**样例输出 #1**
```
4```

**样例输入 #2**
```
3
1 2 3
3 2 1
```

**样例输出 #2**
```
7```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

int n;
int a[10], b[10];          // 每头牛的左右攻击范围
int p[10];                 // 排列数组，p[i] 表示第 i 个位置的牛的编号

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    cin >> n;
    for (int i = 0; i < n; i++) cin >> a[i];
    for (int i = 0; i < n; i++) cin >> b[i];

    // ---------- 思路 ----------
    // 将 n 头牛安置在一段连续的牛棚中，互不攻击。
    // 两头牛 i 和 j，若 i 在左，j 在右，则必须满足：
    //   距离 > b[i]（i 右边不能有牛）且 > a[j]（j 左边不能有牛）
    // 所以相邻牛之间最小间隔为 max(b[i], a[j]) + 1。
    // 
    // 当所有牛按某个顺序排成一排时，总长度 = 1 (第一头牛) + Σ(间隔)
    // = n + Σ_{相邻} max(b[左], a[右])。
    //
    // 由于 n ≤ 9，我们可以枚举所有排列，计算该排列下所需的最小总长度，
    // 取最小值即为答案。
    // n == 9 时，排列数为 9! = 362880，完全可行。
    // 注意：当 n=1 时，公式仍成立（总和为 0，长度 = 1）。
    
    // 初始化排列为 0,1,2,...,n-1
    for (int i = 0; i < n; i++) p[i] = i;

    long long ans = 1e18;    // 最小总长度（用 long long 防溢出，实际上不大）
    // 用do-while循环枚举所有排列,因为我们需要先计算当前排列的长度再生成下一个排列
    do {
        long long sum = 0; // 计算当前排列的总长度
        // 计算相邻间隔之和
        for (int i = 0; i < n - 1; i++) {
            int left = p[i];      // 左边牛的编号
            int right = p[i + 1]; // 右边牛的编号
            sum += max(b[left], a[right]);
        }
        long long len = n + sum;  // 总长度 = 所有牛占据的牛棚数 + 所有间隔的空位数
        ans = min(len, ans); // 取当前排列的总长度与 ans 中的较小值
    } while (next_permutation(p, p + n)); // 枚举所有排列
    // next_permutation 函数将排列 p 改为下一个字典序排列，若已经是最后一个排列，则返回 false
    // 第一个参数为排列数组的起始地址，第二个参数为排列数组的结束地址
    // next_permutation 函数返回值为 bool 类型，若返回 true，则表示成功生成下一个排列，若返回 false，则表示已经是最后一个排列
    // 每次调用平均 O(N) 时间，N 为序列长度。全排列总数 N!，所以枚举所有排列的复杂度为 O(N! * N)。
    cout << ans << endl;
    return 0;
}
```
