# B2062 乘方计算

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-02

## 题目描述

给出一个整数 $a$ 和一个正整数 $n$，求乘方 $a^n$。

## 输入格式

一行，包含两个整数 $a$ 和 $n$。$-1000000 \le a \le 1000000$，$1 \le n \le 10000$。

## 输出格式

一个整数，即乘方结果。题目保证最终结果的绝对值不超过 $1000000$。

## 样例

**样例输入 #1**
```
2 3```

**样例输出 #1**
```
8```

```cpp
#include<bits/stdc++.h>
using namespace std;
long long a,b;
int main(){
    cin>>a>>b;
	cout<<pow(a,b);
}
