# B4447 [GESP202512 二级] 环保能量球

> **洛谷** | 入门 | C++14 | 提交时间: 2026-01-03

**算法标签**：`匈牙利算法`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1198>

## 题目描述

小杨最近在玩一个环保主题的游戏。在游戏中，小杨每行走 1 公里就可以获得 1 点“环保能量”。

为了激励玩家，游戏设置了“里程奖励”：小杨每行走 $x$ 公里，游戏就会额外奖励 1 点能量。

现在已知小杨总共行走了 $n$ 公里，请你帮他计算，他一共能获得多少点环保能量？

## 输入格式

第一行包含一个正整数 $t$，代表测试数据组数。

对于每组测试数据：

- 第一行包含一个正整数 $n$，代表行走的公里数。
- 第二行包含一个正整数 $x$，代表奖励触发的间隔。

## 输出格式

对于每组测试数据，输出一个整数，代表小杨获得的环保能量总数。

## 样例

**样例输入 #1**
```
3
5
2
10
3
2
5```

**样例输出 #1**
```
7
13
2```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int t;
    cin >> t;
    while (t--) {
        int n, x;
        cin >> n >> x;
        int total = n + n / x;
        cout << total << endl;
    }
    return 0;
}
```
