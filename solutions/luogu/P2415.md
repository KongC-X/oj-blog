# P2415 集合求和

> **洛谷** | 普及- | C++14 | 提交时间: 2025-08-07

**算法标签**：`递归`、`二分图`、`随机化`

## 题目描述

给定一个集合 $s$（集合元素数量 $\le 30$），求出此集合所有子集元素之和。

## 输入格式

集合中的元素（元素 $\le 1000$）

## 输出格式

$s$ 所有子集元素之和。

## 样例

**样例输入 #1**
```
2 3
```

**样例输出 #1**
```
10
```

## AC 代码

```cpp
#include<iostream>
#include<cmath>
using namespace std;
// 对于每一个数字都有选和不选两种情况，所以总共有2^n个子集
// 而对于每个数字 x，都会对序列有 2 ^ n−1 ⋅ x 的贡献。
// 证明：对于每一个数字，有选和不选两种可能，并且两种的情况数量相等，故不选的情况有 2 ^ n−1 种，贡献为 2 ^ n−1 ×0=0；
// 选的情况有 2 ^ n−1 种，贡献为 2 ^ n−1 ⋅x，相加之和为 2 ^ n−1 ⋅ x
// 所以总共为：每一个数字x的和 乘 2 ^ n−1
int a[31],i=0,j;
long long s=0;
int main(){
    //cout<<s;
    while(cin>>a[i++]);//合写cin>>a[i];i++;
    for(j=0;j<i;j++){
        s+=a[j];
    }
    s*=pow(2,i-2);//注意，i-2!
    cout<<s;
    return 0;
}

```
