# P1739 表达式括号匹配

> **洛谷** | 入门 | C++14 | 提交时间: 2026-06-08

**算法标签**：`模拟`、`贪心`、`后缀自动机`

## 题目描述

假设一个表达式有英文字母（小写）、运算符（`+`、`-`、`*`、`/`）和左右小（圆）括号构成，以 `@` 作为表达式的结束符。请编写一个程序检查表达式中的左右圆括号是否匹配，若匹配，则输出 `YES`；否则输出 `NO`。表达式长度小于 $255$，左圆括号少于 $20$ 个。

## 输出格式

一行：`YES` 或 `NO`。

## 样例

**样例输入 #1**
```
2*(x+y)/(1-x)@
```

**样例输出 #1**
```
YES
```

**样例输入 #2**
```
(25+x)*(a*(a+b+b)@
```

**样例输出 #2**
```
NO
```

## AC 代码

```cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    ios::sync_with_stdio(false);
    cin.tie(0);

    string s;
    getline(cin, s);               // 读入整行（包含空格等，但题目没有空格也可）

    int cnt = 0;                   // 当前未匹配的左括号数量
    for (int i = 0; i < s.size(); i++) {
        char c = s[i];
        if (c == '@') break;       // 结束符
        if (c == '(') cnt++;       // 左括号加1
        if (c == ')') {
            cnt--;                 // 右括号减1
            if (cnt < 0) break;    // 右括号多余，提前终止
        }
    }

    if (cnt == 0) cout << "YES\n";
    else          cout << "NO\n";

    return 0;
}
```
