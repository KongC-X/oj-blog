# B4262 [GESP202503 三级] 词频统计

> **洛谷** | 普及- | C++14 | 提交时间: 2025-03-28

**算法标签**：`贪心`、`匈牙利算法`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1175>

## 题目描述

在文本处理中，统计单词出现的频率是一个常见的任务。现在，给定 $n$ 个单词，你需要找出其中出现次数最多的单词。在本题中，忽略单词中字母的大小写（即 `Apple`、`apple`、`APPLE`、`aPPle` 等均视为同一个单词）。

请你编写一个程序，输入 $n$ 个单词，输出其中出现次数最多的单词。

## 输入格式

第一行，一个整数 $n$，表示单词的个数；

接下来 $n$ 行，每行包含一个单词，单词由大小写英文字母组成。

输入保证，出现次数最多的单词只会有一个。

## 输出格式

输出一行，包含出现次数最多的单词（输出单词为小写形式）。

## 样例

**样例输入 #1**
```
6
Apple
banana
apple
Orange
banana
apple```

**样例输出 #1**
```
apple```

## AC 代码

```cpp
#include <bits/stdc++.h>
#include <iostream>
#include <iomanip>
using namespace std;

int n,i,j,sum,ma;
string s,a[110];
int main() {
    cin >> n;
    for(i = 0;i < n;i++) {
        cin >> a[i];
    }
    for(i = 0;i < n;i++) {
        for(j = 0;j < a[i].size();j++) {
            if(a[i][j] >= 'A' && a[i][j] <= 'Z') {
                a[i][j] = a[i][j] + 32;
            }
        }
    }
    for(i = 0;i < n;i++) {
        sum = 0;
        for(j = i + 1;j < n;j++) {
            if(a[i] == a[j]) {
                sum++;
            }
        }
        if(sum > ma) {
            ma = sum;
            s = a[i];
        }
    }
    cout << s << endl;
}

```
