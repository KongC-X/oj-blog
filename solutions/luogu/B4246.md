# B4246 [语言月赛 202503] 环形游走

> **洛谷** | 入门 | C++14 | 提交时间: 2026-08-01

**算法标签**：`2025`、`数组`、`语言月赛`

## 题目描述

有 $n$ 个小朋友排成一圈，按照**顺时针顺序**依次被编号为 $1\sim n$，每个小朋友衣服上都有一个数字，第 $i$ 个小朋友的数字是 $a_i$。

老师想要选出一个小朋友，于是他先站在 $1$ 号小朋友旁边，然后以如下方式移动 $m$ 次：
- **逆时针**走过「当前小朋友衣服上的数字」数量的小朋友。

你需要求解，老师最后会站在哪位小朋友旁边。

**我们在样例解释处提供了图片说明，可以参照辅助理解。**

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 【题目类型】模拟
     * 【核心思路】
     * 1. 将位置从 1~n 映射到 0~n-1，方便取模。
     * 2. 初始 pos = 0（对应 1 号）。
     * 3. 每次移动：逆时针走 a[pos] 步，
     *    等价于 pos = (pos - a[pos]) mod n（保证非负）。
     *    用公式：pos = (pos - a[pos] % n + n) % n。
     * 4. 最后输出 pos+1。
     *
     * 【时间复杂度】O(m)
     */

    int n, m;
    cin >> n >> m;

    int a[5005];
    for (int i = 0; i < n; i++) {
        cin >> a[i];
    }

    int pos = 0;  // 0 对应 1 号小朋友
    for (int i = 0; i < m; i++) {
        // 逆时针走 a[pos] 步
        pos = (pos - a[pos] % n + n) % n;
    }

    cout << pos + 1 << endl;
    return 0;
}
```
