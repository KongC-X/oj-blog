# P2005 A/B Problem II

> **洛谷** | 普及/提高- | C++14 | 提交时间: 2026-11-01

**算法标签**：`数学`、`后缀数组`

## 题目背景

为了让大家紧张的心情放松一下，这一题是一道非常简单的题目。

## 题目描述

给出正整数 $N$ 和 $M$，请你计算 $\lfloor\frac{N}{M}\rfloor$（$\frac{N}{M}$ 的下取整）。

## 输入格式

两行，两个正整数，$N$ 和 $M$。

## 输出格式

一行，一个整数，表示 $\lfloor\frac{N}{M}\rfloor$。

## 样例

**样例输入 #1**
```
1000 
333
```

**样例输出 #1**
```
3
```

## AC 代码

```cpp
#include <iostream>
#include <string>
#include <algorithm>
using namespace std;

/*
  高精度乘法：大数 s 乘以 低精度 x (x>=0)，返回乘积字符串
  时间复杂度 O(len(s))
*/
string mul_low(const string &s, long long x) {
    if (x == 0) return "0";
    string res;
    long long carry = 0;
    for (int i = s.size() - 1; i >= 0; i--) {
        long long cur = (s[i] - '0') * x + carry;
        res.push_back(cur % 10 + '0');
        carry = cur / 10;
    }
    while (carry) {
        res.push_back(carry % 10 + '0');
        carry /= 10;
    }
    reverse(res.begin(), res.end());
    return res;
}

/*
  高精度比较：a > b 返回 1，a == b 返回 0，a < b 返回 -1
  时间复杂度 O(len)
*/
int cmp(const string &a, const string &b) {
    if (a.size() != b.size())
        return a.size() > b.size() ? 1 : -1;
    for (int i = 0; i < a.size(); i++) {
        if (a[i] != b[i])
            return a[i] > b[i] ? 1 : -1;
    }
    return 0;
}

/*
  高精度除以高精度（商为整数，下取整）
  因为答案保证 <= 13! = 6227020800，故二分搜索商 q
  时间复杂度 O(log(13!) * len(M))
*/
string div_floor(const string &N, const string &M) {
    if (cmp(N, M) < 0) return "0";          // N < M，商为0

    long long L = 0;
    long long R = 6227020800LL;              // 13! = 6227020800，再加一作为上界
    long long ans = 0;

    while (L <= R) {
        long long mid = (L + R) / 2;
        string prod = mul_low(M, mid);
        int flag = cmp(prod, N);
        if (flag <= 0) {                     // prod <= N
            ans = mid;
            L = mid + 1;
        } else {
            R = mid - 1;
        }
    }
    return to_string(ans);
}

int main() {
    string N, M;
    cin >> N >> M;
    cout << div_floor(N, M) << endl;
    return 0;
}
```
