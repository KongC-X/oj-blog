# B4316 [语言月赛 202504] 整除判断

> **洛谷** | 入门 | C++14 | 提交时间: 2026-07-30

**算法标签**：`2025`、`循环结构`、`语言月赛`

## 题目描述

小 A 认为如果一个整数的各个数位和是 $m$ 的倍数，那么这个整数自身是 $m$ 的倍数。

小 B 觉得这句话不太对，于是找了 $n$ 个正整数。请挑出这些正整数当中，本身不是 $m$ 的倍数，但各个数位和是 $m$ 的倍数的那些数，并按输入顺序输出。

## 输入格式

输入的第一行有两个正整数 $m,n$，题意同题目描述。

之后 $n$ 行，每行有一个正整数，表示小 B 找的正整数。

## 输出格式

输出若干行，表示小 B 找的正整数中，本身不是 $m$ 的倍数，但各个数位和是 $m$ 的倍数的那些数。按照输入顺序输出。

**特别地，如果没有符合题意的正整数，输出 `None`。**

## 样例

**样例输入 #1**
```
6 5
12
24
33
165
8
```

**样例输出 #1**
```
33
165
```

**样例输入 #2**
```
8 2
15
9
```

**样例输出 #2**
```
None```

**样例输入 #3**
```
7 5
142
106
7777
1000006
25
```

**样例输出 #3**
```
142
106
25
```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int main() {
    int m, n;                     // m: 模数, n: 数字个数
    cin >> m >> n;

    bool f = false;               // 标记是否找到符合条件的数
    for (int i = 0; i < n; i++) {
        int x;                    // 当前输入的数
        cin >> x;

        // 本身是 m 的倍数则跳过
        if (x % m == 0) continue;

        // 计算数位和
        int t = x, s = 0;
        while (t > 0) {
            s += t % 10;
            t /= 10;
        }

        // 数位和是 m 的倍数则输出
        if (s % m == 0) {
            cout << x << endl;
            f = true;
        }
    }

    // 没有找到任何符合条件的数
    if (!f) cout << "None" << endl;

    return 0;
}
```
