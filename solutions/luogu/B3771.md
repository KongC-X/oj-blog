# B3771 [信息与未来 2022] 幸运数字

> **洛谷** | 入门 | C++14 | 提交时间: 2026-04-11

**算法标签**：`回文串`、`CDQ分治`

## 题目描述

如果一个十进制数字从左到右读时，所有数位都是**从小到大严格递增**的，我们就称它是幸运数字。例如：

- $9$、$27$、$1234$ 都是幸运数字；
- $11$、$80$、$243$、$1503$ 不是幸运数字。

对于给定的 $a$ 和 $b$，请你求出 $a,a+1,a+2,\cdots,b$ 中幸运数字的数量。

## 输入格式

输入一行空格分隔的两个整数 $a$ 和 $b$。

## 输出格式

输出一行一个整数，代表 $a,a+1,a+2,\cdots,b$ 中幸运数字的数量。

## 样例

**样例输入 #1**
```
1 100```

**样例输出 #1**
```
45```

**样例输入 #2**
```
4096 65536```

**样例输出 #2**
```
141```

## AC 代码

```cpp
#include <iostream>
#include <bits/stdc++.h>
using namespace std;

// 判断一个整数是否为幸运数字
bool isLucky(int num) {
    string s = to_string(num);
    for (int i = 1; i < s.size(); i++) {
        if (s[i] <= s[i-1]) { // 不是严格递增
            return false;
        }
    }
    return true;
}

int main() {
    int a, b;
    cin >> a >> b;
    int cnt = 0;
    for (int i = a; i <= b; i++) {
        if (isLucky(i)) {
            cnt++;
        }
    }
    cout << cnt << endl;
    return 0;
}
```
