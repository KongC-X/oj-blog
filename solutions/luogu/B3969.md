# B3969 [GESP202403 五级] B-smooth 数

> **洛谷** | 普及- | C++14 | 提交时间: 2025-06-20

**算法标签**：`费用流`

## 题目背景

对应的选择、判断题：<https://ti.luogu.com.cn/problemset/1145>

## 题目描述

小杨同学想寻找一种名为 $ B $-smooth 数的正整数。 

如果一个正整数的最大质因子不超过 $ B $，则该正整数为 $ B $-smooth 数。小杨同学想知道，对于给定的 $ n $ 和 $ B $，有多少个不超过 $ n $ 的 $ B $-smooth 数。

## 输入格式

第一行包含两个正整数 $ n $ 和 $ B $，含义如题面所示。

## 输出格式

输出一个非负整数，表示不超过 $ n $ 的 $ B $-smooth 数的数量。

## 样例

**样例输入 #1**
```
10 3```

**样例输出 #1**
```
7```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;
int a[1000010];
int ans;
int main() {
	int n, b;
	cin >> n >> b;
	a[1] = 1;
	for (int i = 2; i <= n; i++) {
		if (!a[i]) {
			for (int j = i; j <= n; j += i)
				a[j] = i;
		}
	}
	for (int i = 1; i <= n; i++) { 
		if (a[i] <= b)
			ans++;
	}
	cout << ans;
	return 0;
}

```
