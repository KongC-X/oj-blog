# P8218 【深进1.例1】求区间和

> **洛谷** | 普及- | C++14 | 提交时间: 2026-07-22

**算法标签**：`前缀和`

## 题目描述

给定由 $n$ 个正整数组成的序列 $a_1, a_2, \cdots, a_n$ 和 $m$ 个区间 $[l_i,r_i]$，分别求这 $m$ 个区间的区间和。

## 输入格式

第一行包含一个正整数 $n$，表示序列的长度。

第二行包含 $n$ 个正整数 $a_1,a_2, \cdots ,a_n$。

第三行包含一个正整数 $m$，表示区间的数量。

接下来 $m$ 行，每行包含两个正整数 $l_i,r_i$，满足 $1\le l_i\le r_i\le n$。

## 输出格式

共 $m$ 行，其中第 $i$ 行包含一个正整数，表示第 $i$ 组答案的询问。

## 样例

**样例输入 #1**
```
4
4 3 2 1
2
1 4
2 3```

**样例输出 #1**
```
10
5```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100010;  // n 最大 1e5，多开 10 个
int a[MAXN];              // a[i]: 原序列第 i 个数
long long s[MAXN];        // s[i]: 前 i 个数的前缀和

int main() {
    // 思路：前缀和模板题
    // 预处理前缀和 s[i] = a[1] + a[2] + ... + a[i]
    // 则区间 [l, r] 的和 = s[r] - s[l-1]，O(1) 回答每次询问
    // 时间复杂度 O(n + m)，适合 n, m <= 1e5

    int n;                 // n: 序列长度
    cin >> n;

    s[0] = 0;              // 前缀和初始值，方便处理 l=1 的情况
    for (int i = 1; i <= n; i++) {
        cin >> a[i];
        s[i] = s[i - 1] + a[i];   // 递推计算前缀和
    }

    int m;                 // m: 询问次数
    cin >> m;
    for (int i = 1; i <= m; i++) {
        int l, r;          // l, r: 询问区间的左右端点
        cin >> l >> r;
        long long ans = s[r] - s[l - 1];   // 前缀和公式
        cout << ans << endl;
    }

    return 0;
}
```
