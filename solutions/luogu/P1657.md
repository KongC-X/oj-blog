# P1657 选书

> **洛谷** | 普及- | C++14 | 提交时间: 2026-07-28

**算法标签**：`模拟`、`搜索`、`递归`

## 题目描述

学校放寒假时，信息学奥赛辅导老师有 $1,2,3,\cdots,x$ 本书，要分给参加培训的 $x$ 个人，每人只能选一本书，但是每人有两本喜欢的书。

老师事先让每个人将自己喜欢的书填写在一张表上。然后根据他们填写的表来分配书本，希望设计一个程序帮助老师求出所有可能的分配方案，使每个学生都满意。

## 输入格式

第 $1$ 行一个数 $x$。

第 $2$ 行至第 $1+x$ 行，每行两个数，表示 $a_i$ 喜欢的书的序号。

## 输出格式

只有一个数，总方案数 $\mathit{total}$。

## 样例

**样例输入 #1**
```
5
1 3
4 5
2 5
1 4
3 5```

**样例输出 #1**
```
2```

## AC 代码

```cpp
#include <iostream>
using namespace std;

int x;                              // x：总共有 x 个人和 x 本书，编号都是 1 到 x
int like[25][2];                    // like[i][0] 和 like[i][1]：第 i 个人喜欢的两本书的编号
bool used[25];                      // 标记书是否已被分配（true 表示这本书已经被别人拿走了）
long long ans = 0;                  // 总方案数

/*
  题目意思：
  有 x 本书（编号 1~x）和 x 个人（编号 1~x）。
  每个人要从这 x 本书里拿一本，但每个人只喜欢其中的两本（提前写好了）。
  老师要根据大家的喜好来分配书，要求：
    1. 每个人拿到的书必须是他喜欢的（两本之一）。
    2. 每本书只能给一个人，不能重复分配。
  问一共有多少种不同的分配方案？
  
  举例：假设有 3 个人 3 本书
    第 1 个人喜欢书 1 和书 2
    第 2 个人喜欢书 2 和书 3
    第 3 个人喜欢书 1 和书 3
  可能的分配方案：
    方案一：1号拿书1，2号拿书2，3号拿书3  → 合法
    方案二：1号拿书2，2号拿书3，3号拿书1  → 合法
  所以答案是 2。
*/

// 深度优先搜索 (DFS) + 回溯
// 功能：正在为第 p 个人选一本书（p 从 1 到 x）
void dfs(int p) {
    if (p > x) {                    // 所有人（第1到第x号）都拿到书了
        ans++;                      // 找到一种合法方案，答案加 1
        return;
    }
    // 尝试第 p 个人喜欢的两种书
    for (int i = 0; i < 2; i++) {
        int book = like[p][i];      // 第 p 个人喜欢的第 i 本书的编号
        if (!used[book]) {          // 如果这本书还没被其他人拿走
            used[book] = true;      // 标记这本书已被第 p 个人拿走
            dfs(p + 1);             // 继续为下一个人选书
            used[book] = false;     // 回溯：把书还回去，尝试其他分配方式
        }
    }
}

int main() {
    cin >> x;
    for (int i = 1; i <= x; i++) {
        cin >> like[i][0] >> like[i][1];  // 读入第 i 个人喜欢的两本书
    }

    dfs(1);                         // 从第 1 个人开始分配
    cout << ans << endl;
    return 0;
}
```
