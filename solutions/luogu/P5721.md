# P5721 【深基4.例6】数字直角三角形

> **洛谷** | 入门 | C++14 | 提交时间: 2025-08-01

## 题目描述

给出 $n$，请输出一个直角边长度是 $n$ 的数字直角三角形。所有数字都是 $2$ 位组成的，如果没有 $2$ 位则加上前导 $0$。

## 输入格式

输入一个正整数 $n$。

## 输出格式

输出如题目要求的数字直角三角形。

## 样例

**样例输入 #1**
```
5```

**样例输出 #1**
```
0102030405
06070809
101112
1314
15```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
  int n, tot = 0;
  cin >> n;
  for (int i = n; i; --i) {
    for (int j = 0; j < i; ++j) {
      printf("%02d", ++tot);
    }
    printf("\n");
  }
}

```
