# P12035 [USTCPC 2025] Hackergame

## 题目描述

hackergame 是 USTC 特色比赛之一，也是克露丝卡尔酱心心念念的比赛之一。

克露丝卡尔酱的同学小 H 在打 hackergame 时，发现当复制一个 flag 时，会将一些其它的内容（如感叹号、句号等）一同复制，从而上传答案时造成错误。

克露丝卡尔酱打算编写一个程序来解决该问题，该程序会读取一个字符串，在当中选择一个连续的子串，满足是一个合法的 flag，并将其输出。如果所有子串都不是合法的，输出 `NOT FOUND`。

一个字符串为一个合法的 flag，当且仅当满足以下性质：

+ 该字符串以 `flag{` 开头，以字符 `}` 结尾。
+ 在 `flag{` 和 `}` 之间，不存在字符 `{` 和字符 `}`，可以存在任何其它可见字符。

克露丝卡尔酱想要尽快帮助她的同学，但她的同学想要朴素的代码。请帮她完成这个程序！

## 输入格式

输入一行一个字符串，表示需要处理的字符串 $s$。$|s|\le 10^5$，即输入的字符串长度不超过 $10^5$。

输入的字符集为所有可见字符，不含空格、换行符等不可见字符。输入的字符串以换行符结尾。

## 输出格式

输出一行一个字符串。

+ 如输入的字符串中出现至少一个连续的子串时一个合法的 flag，请**任意选择一个**进行输出。
+ 若所有连续的子串均不为合法的 flag，输出 `NOT FOUND`。

## 样例

**样例输入 #1**
```
{flag{y0u_ar3_g0od_at_constructi0n}{}}```

**样例输出 #1**
```
flag{y0u_ar3_g0od_at_constructi0n}```

**样例输入 #2**
```
flag{flag{{}}}}}}```

**样例输出 #2**
```
NOT FOUND```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目：P12035 [USTCPC 2025] Hackergame
     * 题意：在给定字符串中寻找一个连续子串，满足：
     *       1. 以 "flag{" 开头；
     *       2. 以 '}' 结尾；
     *       3. 在 "flag{" 和 '}' 之间不能出现 '{' 或 '}'。
     *       输出任意一个合法子串；若不存在则输出 "NOT FOUND"。
     *
     * 思路：从左到右扫描，每当发现 "flag{" 开始，就向后寻找第一个 '}'，
     *       若中途遇到 '{' 则放弃当前开始位置，继续向后扫描。
     *       第一个满足条件的子串就是答案。
     */
    string s;
    cin >> s;
    int n = s.size();

    for (int i = 0; i + 5 <= n; i++) {
        // 检查是否以 "flag{" 开头
        if (s.substr(i, 5) == "flag{") {
            // 从 "flag{" 后面开始查找闭合 '}'
            for (int j = i + 5; j < n; j++) {
                if (s[j] == '{') {
                    // 中间出现了 '{'，这个开始无效，跳出内层循环继续找下一个开始
                    break;
                }
                if (s[j] == '}') {
                    // 找到第一个 '}'，且中间没有 '{' 和 '}'，是一个合法 flag
                    cout << s.substr(i, j - i + 1) << endl;
                    return 0;
                }
            }
            // 如果没有找到 '}'，则此开始无效，继续查找下一个可能开始
        }
    }

    cout << "NOT FOUND" << endl;
    return 0;
}
```
