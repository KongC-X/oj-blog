# B4096 [CSP-X2022 山东] 独木桥

> **洛谷** | 普及- | C++14 | 提交时间: 2026-08-11

**算法标签**：`模拟`、`贪心`、`2022`、`山东`、`CSP-X 小学组`

## 题目描述

长度为 $L$ 米的独木桥上有 $n$ 个人，他们每个人都想以最快的时间离开危险的独木桥。

已知每个人在独木桥上的行走速度为 1 米每秒，每个人只要能走到独木桥的两个端点中的其中一个就可以离开独木桥。

由于独木桥的桥面宽度很窄，只能容纳一个人通过，当两个人相遇时，他们无法交错通过，只能各自调转方向，继续沿反方向行走。

给你独木桥上的人数 $n$，独木桥的长度 $L$ ， 第 $i$ 个人的初始位置到独木桥左端点的距离 $a_i$ 米（每个人开始的朝向未知，但他们可以根据需要随时调转行走的方向）。

请计算出所有人同时出发，全部都离开独木桥所需的最短时间。

## 输入格式

第一行一个整数 $n$，表示人数。

第二行一个整数 $L$，表示独木桥的长度（米）。

第三行输入 $n$ 个整数 $a_1,a_2,\cdots,a_n$，表示第 $i$ 个人初始位置到独木桥左端点的距离。

## 输出格式

输出一行一个整数，表示所有人都离开独木桥所需的最短时间。

## 样例

**样例输入 #1**
```
3
10
2 6 7```

**样例输出 #1**
```
4```

**样例输入 #2**
```
7
214
1 12 7 13 176 23 191```

**样例输出 #2**
```
38```

## AC 代码

```cpp
#include <bits/stdc++.h>
using namespace std;

int main() {
    /*
     * 题目类型：贪心 / 物理等价
     * 核心思路：
     * 两个人相遇后各自调头，等价于他们“互相穿过”继续前进（因为人没有区别）。
     * 所以每个人离开独木桥的最短时间就是 min(a_i, L - a_i)，
     * 即选择距离自己最近的端点走出去。
     * 所有人同时出发，最后一个人离开的时间就是所有 min 值的最大值。
     * 答案 = max_{i} min(a_i, L - a_i)
     * 
     * 时间复杂度：O(n)，n 最大 1e6，可行。
     */
    int n, L;
    cin >> n >> L;   // 读入人数和桥长

    int ans = 0;             // 答案（最长时间）
    for (int i = 0; i < n; i++) {
        int a;               // 第 i 个人的位置
        scanf("%d", &a);
        int t = min(a, L - a); // 这个人到最近端点的距离
        if (t > ans) ans = t;  // 取最大值
    }

    printf("%d\n", ans);
    return 0;
}
```
