1 一、生活引入——家族族谱

二叉树的结构在生活中最常见的类比就是家族族谱。

想象一张族谱：一位老祖宗（根节点）生了两个儿子，大儿子和小儿子。大儿子又生了两个孙子，小儿子只生了一个孙女……

在这个类比中：

  • 根节点：家族的共同祖先（老祖宗）
  • 左孩子：大儿子这一支
  • 右孩子：小儿子这一支
  • 叶子节点：没有后代的人（族谱的末梢）
  • 子树：以某个家庭成员为起点的整个分支

二叉树就是计算机世界里最基础的"族谱"结构——每个节点最多有两个"后代"，严格区分为左、右。

生活口诀：一人最多生俩娃，左边老大右边小，家族分支不乱套。

2 二、核心概念

2.1 二叉树的三种遍历

遍历就是按某种顺序"拜访"每个节点。三种基本遍历方式的区别在于访问根的顺序。

遍历方式 访问顺序 记忆口诀
先序（前序）遍历 根 → 左 → 右 根在最先
中序遍历 左 → 根 → 右 根在中间
后序遍历 左 → 右 → 根 根在最后

记忆技巧："先中后"指的是"根"的位置。

示例

C++ 

      A
     / \
    B   C
   / \
  D   E
  • 先序：A → B → D → E → C
  • 中序：D → B → E → A → C
  • 后序：D → E → B → C → A

2.2 序列重建

给定两种遍历序列，能否还原出唯一的二叉树？

已知序列 能否唯一确定 原因
先序 + 中序 ✅ 能 先序定根，中序分左右
后序 + 中序 ✅ 能 后序定根，中序分左右
先序 + 后序 ❌ 不能 无法区分左右子树

核心原理： - 先序的第一个元素 / 后序的最后一个元素 → 当前子树的根 - 中序中，根的左边是左子树，右边是右子树 - 先序+后序导致左右子树"身份不明"，所以不唯一

2.3 完全二叉树与数组存储

完全二叉树：只有最后一层可能不满，且最后一层的节点从左到右连续排列。

数组存储规则（下标从 1 开始）： - 根节点存在下标 1 - 节点 i 的左孩子下标 = 2i - 节点 i 的右孩子下标 = 2i + 1 - 节点 i 的父节点下标 = i / 2（整除）

示例

C++ 

        ①
       /  \
      ②    ③
     / \   /
    ④  ⑤ ⑥

数组：[空, A, B, C, D, E, F]

  • 节点 B（下标2）→ 左孩子 2×2=4（D），右孩子 2×2+1=5（E）
  • 节点 C（下标3）→ 左孩子 3×2=6（F），右孩子 3×2+1=7（不存在）

注意：编号从 1 开始，下标 0 通常闲置或存储节点总数。

2.4 二叉搜索树（BST）

定义：对于树中的每一个节点，都满足： - 左子树中所有节点的值 < 根节点的值 - 右子树中所有节点的值 > 根节点的值 - 左右子树也分别是 BST

一句话概括：左小右大。

C++ 

      8
     / \
    3   10
   / \    \
  1   6    14
     / \   /
    4   7 13

3 三、代码实现

3.1 二叉树节点定义

C++ 
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

3.2 三种遍历（递归）

C++ 
// 先序遍历：根 → 左 → 右
void preorder(TreeNode* root) {
    if (root == nullptr) return;
    cout << root->val << " ";
    preorder(root->left);
    preorder(root->right);
}

// 中序遍历：左 → 根 → 右
void inorder(TreeNode* root) {
    if (root == nullptr) return;
    inorder(root->left);
    cout << root->val << " ";
    inorder(root->right);
}

// 后序遍历：左 → 右 → 根
void postorder(TreeNode* root) {
    if (root == nullptr) return;
    postorder(root->left);
    postorder(root->right);
    cout << root->val << " ";
}

3.3 BST 插入

C++ 
TreeNode* insertBST(TreeNode* root, int val) {
    if (root == nullptr) {
        return new TreeNode(val);
    }
    if (val < root->val) {
        root->left = insertBST(root->left, val);
    } else if (val > root->val) {
        root->right = insertBST(root->right, val);
    }
    // 如果相等，通常不插入（BST 一般不含重复值）
    return root;
}

3.4 BST 查找

C++ 
bool searchBST(TreeNode* root, int target) {
    if (root == nullptr) return false;
    if (root->val == target) return true;
    if (target < root->val) {
        return searchBST(root->left, target);
    } else {
        return searchBST(root->right, target);
    }
}

3.5 BST 删除

C++ 
// 找右子树的最小值（后继节点）
TreeNode* findMin(TreeNode* root) {
    while (root->left != nullptr) {
        root = root->left;
    }
    return root;
}

TreeNode* deleteBST(TreeNode* root, int val) {
    if (root == nullptr) return nullptr;

    if (val < root->val) {
        root->left = deleteBST(root->left, val);
    } else if (val > root->val) {
        root->right = deleteBST(root->right, val);
    } else {
        // 找到要删除的节点
        // 情况1：无左孩子
        if (root->left == nullptr) {
            TreeNode* temp = root->right;
            delete root;
            return temp;
        }
        // 情况2：无右孩子
        if (root->right == nullptr) {
            TreeNode* temp = root->left;
            delete root;
            return temp;
        }
        // 情况3：有两个孩子
        TreeNode* temp = findMin(root->right);   // 找后继
        root->val = temp->val;                     // 替换值
        root->right = deleteBST(root->right, temp->val); // 删除后继
    }
    return root;
}

3.6 二叉树深度计算

方式一：DFS（递归）

C++ 
// 计算二叉树的最大深度（高度）
int maxDepth(TreeNode* root) {
    if (root == nullptr) return 0;
    int leftDepth = maxDepth(root->left);
    int rightDepth = maxDepth(root->right);
    return max(leftDepth, rightDepth) + 1;
}

深度公式：深度 = max(左子树深度, 右子树深度) + 1

陷阱：是取最大值再加 1，不是相加！

方式二：BFS（层序遍历）

C++ 
#include <queue>

int maxDepthBFS(TreeNode* root) {
    if (root == nullptr) return 0;
    queue<TreeNode*> q;
    q.push(root);
    int depth = 0;
    while (!q.empty()) {
        int levelSize = q.size();  // 当前层的节点数
        for (int i = 0; i < levelSize; i++) {
            TreeNode* node = q.front();
            q.pop();
            if (node->left) q.push(node->left);
            if (node->right) q.push(node->right);
        }
        depth++;  // 每处理完一层深度加 1
    }
    return depth;
}

4 四、手工模拟

题目

已知某二叉树：

  • 先序遍历：A B D E C F
  • 中序遍历：D B E A F C

请恢复二叉树，并求后序遍历结果。

求解步骤

第 1 步：先序定根

先序第一个元素是 A → 根节点是 A。

C++ 

       先序：A B D E C F
            ↑
           根

第 2 步：中序分左右

在中序中找到 A，左边是左子树，右边是右子树。

C++ 

    中序： D B E  A  F C
            ↑    ↑   ↑
           左子树 根  右子树
  • 左子树中序：D B E → 3 个节点
  • 右子树中序：F C → 2 个节点

第 3 步：对应先序分块

先序中根 A 后面跟着的节点，前 3 个是左子树，后 2 个是右子树。

C++ 

        先序：A  |  B D E  |  C F
             根    左子树   右子树
  • 左子树先序：B D E
  • 右子树先序：C F

第 4 步：递归处理左子树

左子树先序中 B 是根 → 左子树中序 D B E 中，B 左边 D、右边 E。

C++ 

        B
       / \
      D   E

第 5 步：递归处理右子树

右子树先序中 C 是根 → 右子树中序 F C 中，C 左边 F。

C++ 

        C
       /
      F

第 6 步：合并得到整棵树

C++ 

        A
       / \
      B   C
     / \  /
    D   E F

第 7 步：求后序遍历

后序规则：左 → 右 → 根

C++ 
后序：D → E → B → F → C → A

最终答案：后序遍历为 D E B F C A。

5 五、常见陷阱

🚨 陷阱 1：深度公式是 max 不是相加

错误：return leftDepth + rightDepth + 1;

正确：return max(leftDepth, rightDepth) + 1;

深度是根到最远叶子的路径长度，只走一条最深的路径，不是左右两边都走。

🚨 陷阱 2：BST 方向搞反

错误：左子树大于根，右子树小于根。

正确：左小右大 —— 左子树所有节点 < 根 < 右子树所有节点。

🚨 陷阱 3：认为先序 + 后序能唯一确定二叉树

错误：认为任何时候三个序列都能唯一确定。

正确：先序 + 后序只能确定根的位置，无法区分左右子树，所以不能唯一确定。

🚨 陷阱 4：完全二叉树数组下标从 0 开始

根节点放在 arr[1]，左子 = 2i，右子 = 2i+1。如果从 0 开始，公式要变成 左子 = 2i+1，右子 = 2i+2。考试时注意题目中的下标约定。

🚨 陷阱 5：叶子节点和度为 0 节点

在完全二叉树中，叶子节点数 = ⌈总节点数 / 2⌉（向上取整），不要忘记向上取整。

bool isCompleteTree(TreeNode* root) {
    if (root == nullptr) return true;
    queue<TreeNode*> q;
    q.push(root);
    bool hasNull = false;
    while (!q.empty()) {
        TreeNode* node = q.front(); q.pop();
        if (node == nullptr) { hasNull = true; }
        else {
            if (hasNull) return false;
            q.push(node->left);
            q.push(node->right);
        }
    }
    return true;
}
