反射二进制码 — 相邻仅一位不同、递归构造

1 一、生活引入：电梯按钮的秘密

你有没有注意过电梯里的按钮？每个楼层的数字旁边通常有一个小圆点或指示灯。但有一种特殊的格雷码电梯，它的设计思路很巧妙：

相邻楼层的编码之间，只有一位数字发生变化。

假设一个电梯只有 3 个按钮，用普通二进制编码： 1 楼 → 001， 2 楼 → 010（变化了两位！）， 3 楼 → 011

当 1 楼到 2 楼时，按钮上的两个灯同时变化——如果其中一个灯接触不良，可能读成 000 或 011，乘客就被送到错误楼层。

但用格雷码： 1 楼 → 001， 2 楼 → 011（只变了一位）， 3 楼 → 010

即使某个灯读错了，最多只差一个楼层。这就是格雷码的核心思想：每次只改变一位，降低出错代价。

2 二、核心概念

什么是格雷码？

格雷码（Gray Code），也叫反射二进制码，是一种二进制编码方式，具有以下特点：

定义：在一组数的编码中，任意两个相邻的编码之间只有一位二进制位不同。

基本性质

性质 说明
相邻唯一不同 相邻两个编码只有 1 位不同
数量 n 位格雷码共包含 2^n 个编码
循环性 最后一个编码与第一个编码也只有 1 位不同（循环码）
唯一性 每个编码在序列中恰好出现一次

3 三、构造方法：递归构造法（反射法）

格雷码最常见的构造方法是递归构造，也称反射法。

构造思路

C++ 
1位格雷码：  0   1
            ↓   ↓
2位格雷码： 00  01  11  10
            ↑        ↑
         前半部分   后半部分 = 前半部分镜像（反射）+ 前缀改为1

递归公式

C++ 
G(1) = {"0", "1"}

G(n) = 前半部分："0" + G(n-1) 中的每个编码
       后半部分："1" + reverse(G(n-1)) 中的每个编码

图解过程

C++ 
G(1)               G(2)               G(3)
     ─────              ─────              ─────
      0                  00                 000
      1                  01                 001
                         11                 011
                         10                 010
                                           110
                                           111
                                           101
                                           100

5 五、常见陷阱与避坑指南

🚨 陷阱 1：混淆普通二进制码和格雷码

错误：以为二进制码 000 → 001 → 010 → 011 → … 就是格雷码

普通二进制相邻之间可能有多位发生变化（如 011 → 100 变了 3 位），而格雷码保证只变 1 位。

🚨 陷阱 2：以为任意相邻两位编码"最多"一位不同

错误：认为"相邻可以有多位不同，只要不超过 1 位也行"

格雷码的定义是严格只有 1 位不同，不是"最多 1 位"，也不是"至少 1 位"。

🚨 陷阱 3：以为对二进制取反就是格雷码

错误：以为 001 取反得到 110，然后把它们放一起就是格雷码

格雷码是通过递归反射构造的，不是简单取反。取反得到的两个编码之间可能有多位不同。

🚨 陷阱 4：忘记格雷码是循环码

错误：只检查相邻之间，忘了检查首尾

n 位格雷码是一个循环序列，第一个和最后一个编码之间也只有 1 位不同。

📝 真题 1（2024年3月第6题）

3 位格雷编码的正确顺序是什么？

A. 000, 001, 010, 011, 100, 101, 110, 111

B. 000, 001, 011, 010, 110, 111, 101, 100

C. 000, 010, 001, 011, 100, 110, 101, 111

D. 000, 010, 110, 100, 111, 101, 011, 001

答案：B
📝 真题 2（2025年6月第10题）

3位格雷编码中，编码 101 之后的下一个编码不可能是哪一项？

A. 100

B. 111

C. 110

D. 001

答案：C
解析：解析：格雷编码相邻只能有 1 位不同。101 → 110 有 2 位不同，所以 110 不可能是下一个。
📝 真题 3（2025年3月第12题）

以下代码用于生成 n 位格雷编码，横线上应填写什么？

C++ 
vector<string> generateGrayCode(int n) {
    if (n == 0) return {"0"};
    if (n == 1) return {"0", "1"};
    vector<string> prev = generateGrayCode(n - 1);
    vector<string> result;
    for (string s : prev) result.push_back("0" + s);
    for (int i = prev.size() - 1; i >= 0; i--) {
        ____________________ // 在此处填入代码
    }
    return result;
}

A. result.push_back("1" + prev[i]);

B. result.push_back("0" + prev[i]);

C. result.push_back(prev[i] + "1");

D. result.push_back(prev[i] + "0");

答案：A
📝 真题 4（2025年9月第10题）

下面代码生成格雷编码，横线上应填写什么？

C++ 
vector<string> grayCode(int n) {
    if (n == 0) return {"0"};
    if (n == 1) return {"0", "1"};
    vector<string> prev = grayCode(n-1);
    vector<string> result;
    for (string s : prev) { result.push_back("0" + s); }
    for (_______________) { result.push_back("1" + prev[i]); }
    return result;
}

A. int i = 0; i < prev.size(); i++

B. int i = prev.size()-1; i >= 0; i--

C. auto s : prev

D. int i = prev.size()/2; i < prev.size(); i++

答案：B
解析：解析：后半部分要**逆序**加前缀 "1"，所以循环必须从大往小遍历。
