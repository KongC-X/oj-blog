GESP C++ 二级 · 常用数学函数

Math Functions — abs/sqrt/max/min/rand 函数详解

⚡ 4道选择题 + 7道判断题 📊 年均出题2~3道 ⭐ 占总分约10%

1 第一步：生活引入 — 生活中的「数学工具箱」

🎯 场景比喻：教室里的数学工具

想象你在教室里做数学题：用绝对值 abs 量两个人的距离（不管谁在左谁在右），用平方根 sqrt 算正方形对角线的长度，用最大最小值 max/min 从一叠试卷中挑出最高分和最低分，用随机数 rand 来摇号抽人回答问题。C++ 的数学函数就是这套「数学工具箱」，它们都住在 <cmath> 头文件里，用之前要先 #include <cmath> 才能借出来。

🔍 为什么要考数学函数？

GESP 二级考纲明确要求掌握 5 个数学函数：abs()、sqrt()、max()、min()、rand()。这部分虽然出题量不大（每年 2~3 道），但送分性质明显——只要记住函数名、头文件、参数类型和返回值类型，就能稳稳拿分。

2 第二步：核心概念 — 五大数学函数

📐 GESP 二级考查的五个数学函数

均需 #include <cmath> 或 #include <math.h>（rand 需要 #include <cstdlib>）

函数功能参数类型返回类型示例
abs(x)绝对值 |x|int → int
double → double		与参数同abs(-5) = 5
sqrt(x)平方根 √xdoubledoublesqrt(9.0) = 3.0
max(a,b)取较大值相同类型与参数同max(10,20) = 20
min(a,b)取较小值相同类型与参数同min(10,20) = 10
rand()随机整数 [0,RAND_MAX]无参数intrand()%10+1 → 1~10
🔵 abs() — 绝对值函数
  • 功能：返回参数的绝对值，abs(-5) → 5，abs(5) → 5
  • 浮点数判断相等：abs(b - a) <= 0.000001 判断两个浮点数是否"近似相等"
  • 注意：整数版本在 <cstdlib>，浮点版本 fabs() 在 <cmath>（但 C++ 中 abs() 通常已重载支持浮点）
🟢 sqrt() — 平方根函数
  • 功能：返回参数的平方根，sqrt(9.0) → 3.0
  • 返回值类型：double（不是 int！）
  • 判断完全平方数：int(sqrt(N)) * int(sqrt(N)) == N
  • 浮点误差：sqrt(N) * sqrt(N) == N 可能因浮点精度为 false
🟣 max() / min() — 最大最小值函数
  • 功能：返回两个值中的较大/较小者
  • 经典用法：max(max(a, b), c) 求三个数的最大值
  • 判断相等技巧：max(a, b) == min(a, b) → a 等于 b
  • 等价替代：max(a,b) 等价于 (a>b?a:b)
🔷 rand() — 随机数函数
  • 功能：返回 [0, RAND_MAX] 范围内的伪随机整数
  • 生成 [a, b] 范围：rand() % (b-a+1) + a
  • 1 到 10：rand() % 10 + 1
  • 1 到 100：rand() % 100 + 1
  • 每次运行结果相同（需要 srand() 设置种子才能不同）

📝 模板一：abs 判断浮点数相等

📝 模板二：sqrt 判断完全平方数
cpp
#include 
#include 
using namespace std;

int N = 25;
int root = int(sqrt(N));    // root = 5
if (root * root == N)
    cout << N << "是完全平方数";  // 25是完全平方数

// ❌ 错误写法：
if (sqrt(N) * sqrt(N) == N)  // 浮点误差可能导致 false
    cout << "可能不输出";

// ✅ 正确写法：先转 int 再平方比较
if (int(sqrt(N)) * int(sqrt(N)) == N)
    cout << "可靠判断";

🧮 模拟一：欧几里得算法（辗转相除法）

以下代码实现求 a 和 b 的最大公约数：

cpp
cin >> a >> b;
while (b != 0){
    remainder = a % b;
    a = b;
    b = remainder;
}
cout << a;

最终输出 a = 6（48和18的最大公约数）

5 第五步：常见陷阱

⚠️ 陷阱一：sqrt 返回的是 double，不是 int

sqrt(9.0) 的计算结果为 3.0（double），不是 int 类型的 3。需要 int(sqrt(9.0)) 才能得到 int 类型的 3。

⚠️ 陷阱二：浮点误差导致 sqrt(N)*sqrt(N)≠N

由于浮点数精度问题，sqrt(N) * sqrt(N) == N 即使是完全平方数也可能返回 false。判断完全平方数时必须先 int 转换：int(sqrt(N)) * int(sqrt(N)) == N。

⚠️ 陷阱三：rand() 每次运行结果相同

没有调用 srand(time(0)) 设置种子的话，rand() 每次程序运行都生成相同的"随机"序列。这在考试中一般不作为考点。

⚠️ 陷阱四：abs 参数为负时 sign 判断

sqrt(a) == abs(a) 不仅 a=0 时成立，a=1 时也成立：sqrt(1)=1, abs(1)=1，等式为 true。所以「a 的值必须为 0」的说法是错的。

💡 记口诀： abs 取绝对值，sqrt 得浮点数，max/min 比较选，rand 取余加一得范围。用前记得 #include <cmath>，判断相等用差值比较。

6 第六步：真题实战

选择题

第1题 · rand 随机数范围（2023/06 第25题）

在C++中，下列最适合填入横线处连续5次正确生成1到10之间的随机整数？

cpp
for(int i=0; i<5; i++)
    __________________;

A. rand() % 11    B. rand() % 10    C. rand() % 10 + 1    D. rand() % 9 + 1

答案：C
rand()%10 生成 [0,9]，+1 后为 [1,10]。A 生成 [0,10]，B 生成 [0,9]，D 生成 [1,9]。
第2题 · abs 判断浮点数相等（2023/12 第27题）

在C++中，如果 a 和 b 均为 float 类型的变量，如果二者相差足够小（比如0.000001）就可以视作相等。下列哪个表达式能用来正确判断"a等于b"？

A. ((b-a) < 0.000001)    B. ((b-a) <= 0.000001)    C. (abs(b-a) <= 0.000001)    D. (sqrt(b-a) <= 0.000001)

答案：C
需要绝对值处理正负偏差。A/B 如果 b-a 是负数（b<a），条件也会成立但语义不对。D 中 sqrt 对负数无效。所以 C 最正确。
第3题 · 欧几里得算法分析（2024/06 第29题）

阅读下面的C++代码，其中变量都是整型，则说法正确的是：

cpp
cin >> a >> b;
while (b != 0){
    remainder = a % b;
    a = b;
    b = remainder;
}
cout << a;

A. b不能为0，因为a%b将导致错误    B. a必须小于b    C. a和b都必须为正    D. 如果a输入为0，则不管b的输入值是什么，输出值的绝对值都是abs(b)

答案：D
这是欧几里得算法（辗转相除法）求最大公约数。a=0 时 gcd(0,b)=|b|，一轮循环后 a=b, b=0, 输出 a=原b。A 错误：b 初始可以为0（循环不执行，输出 a）。B/C 错误：不要求大小或正负。
第4题 · 函数组合选择（2025/03 第31题）

下面C++代码执行后的输出是30，则横线处不能填入：

cpp
int a=10, b=20, c=30;
cout << _____________________ << endl;

A. max(max(a,b),c)    B. min(a+b, c)    C. sqrt(a+b+c)    D. (a+b+c)/2

答案：C
A: max(20,30)=30。B: min(30,30)=30。D: 60/2=30。C: sqrt(60)≈7.746≠30，所以 C 不能填入。

判断题

判断题第1题（2023/09 第20题）

a 和 b 分别是C++的整型变量，如果表达式 max(a, b) == min(a, b) 的值为真，则说明 a 和 b 相等。

答案：✅ 正确
若 max==min 则说明较大值=较小值，两个数必然相等。
判断题第2题（2024/03 第33题）

C++表达式 (sqrt(N) * sqrt(N)) == N 中的N如果为正整数，则表达式的值为true，相当于开平方后平方是本身。

答案：❌ 错误
因浮点数精度问题，即使 N 是完全平方数，sqrt(N)*sqrt(N) 也可能不等于 N。例如 sqrt(25) 可能返回 4.999999，乘法得 24.999998 ≠ 25。
判断题第3题（2024/09 第36题）

如果C++表达式 int(sqrt(N))*int(sqrt(N)) == N 的值为True，则说明N为完全平方数，如4、9、25等。

答案：✅ 正确
先 int(sqrt(N)) 截断小数得到整数根，再平方与 N 比较。若相等则 N 确实是完全平方数。
判断题第4题（2024/12 第37题）

如果变量 a 的值使得C++表达式 sqrt(a)==abs(a)，则 a 的值为0。

答案：❌ 错误
a=1 时：sqrt(1)=1，abs(1)=1，等式也成立。a=0 时：sqrt(0)=0，abs(0)=0，也成立。所以 a 可能为 0 或 1。
判断题第5题（2025/03 第38题）

表达式 sqrt(9.0) 的计算结果为 3，且结果类型为 int。

答案：❌ 错误
sqrt(9.0) 返回的是 double 类型 3.0，不是 int 类型 3。sqrt 的返回类型始终是 double/float。
判断题第6题（2025/06 第39题）

在使用 C++语言编写程序时，不能使用 sqrt、abs 等数学函数，包含 <cmath> 或 <math.h> 头文件后就能够使用了。

答案：✅ 正确
数学函数在 <cmath> 或 <math.h> 头文件中声明，包含后即可使用。
判断题第7题（2025/09 第40题）

C++语句 cout << rand() << ' ' << rand(); 的第二个输出值较大。

答案：❌ 错误
rand() 每次调用返回不同的随机数，第二个不一定比第一个大。两者是独立的随机值，大小关系不确定。

abs(x)返回 |x|浮点用 fabs，但 C++ 中 abs 常已重载
