1 第一步：生活引入 — 生活中的「规则运算」

🎯 场景比喻：小学生排队分组

想象一下操场上有120个小朋友，老师喊"每10人一排"，这就是 N / 10——多少个整排。老师再问"最后一排剩几个？"，这就是 N % 10——余数。C++ 的运算符就是帮你快速算出这些答案的「数学工具集」，只是比小学数学多了几个新朋友：关系运算符（比大小）、逻辑运算符（并且/或者）、位运算符（二进制层面操作）。

🔍 为什么运算符是C++二级高频考点？

GESP 二级考试中，运算符占比约 20%，几乎每套试卷都有 6~7 道题直接考查运算符。核心原因：运算符是程序逻辑的基石——条件判断、循环控制、数据提取（取位、取余）全部依赖运算符。二级特别侧重 % / 的组合使用和 == 与 = 的区分。

🔥 核心考点速记

🔵 考点一：整数除法 / 与取余 %
  • / 整数除法： 舍弃小数部分（向零取整），N / 10 舍弃个位
  • % 取余： 返回除法余数，N % 10 获取个位
  • 经典组合： N / 100 % 10 获取百位数
🟢 考点二：== vs =（最容易错！）
  • = 是赋值运算符，将右边值赋给左边变量
  • == 是关系运算符，比较两边是否相等，返回 bool 值
  • a == b; 单独出现不会改变 a、b 的值！
🟣 考点三：逻辑表达式与短路求值
  • && 与： 两边都为 true 才为 true，左边为 false 时右边不执行
  • || 或： 任意一边为 true 即为 true，左边为 true 时右边不执行
  • ! 非： 取反，!0 → 1，!非零 → 0
  • 注意： 5 <= a <= 10 在 C++ 中不是"a在5到10之间"！
🔷 考点四：逗号表达式
  • 逗号运算符从左到右依次求值，返回最右边的值
  • b = (6, 28); → b 的值为 28
  • a, b = 3, 4; → 只有 b=4，a 未初始化（编译错误/不确定）
🟠 考点五：运算符优先级
  • 优先级口诀： 算术 > 关系 > 逻辑 > 赋值
  • % 和 * / 同级，从左到右结合
  • 混淆时加括号：N % 1000 / 100 等价 (N % 1000) / 100

3 第三步：代码详解 — 运算符实战模板

📝 代码模板一：取位操作（二级必考）
cpp
// 获取正整数N的任意位数
int N = 1234567;

int ge    = N % 10;         // 个位：7
int shi   = N / 10 % 10;    // 十位：6
int bai   = N / 100 % 10;   // 百位：5
int qian  = N / 1000 % 10;  // 千位：4

// 通用公式：第 M 位（从右数）= N / (10^(M-1)) % 10
📝 代码模板二：== 与 = 的陷阱演示
cpp
int a = 3, b = 4;

a == b;   // 比较 a 和 b 是否相等（返回 false / 0）
          // ❗ 但 a、b 的值不变，仍是 3 和 4

a = b;    // 赋值：a 变成 4
          // 此时 a=4, b=4

cout << a << ' ' << b;  // 输出 4 4
📝 代码模板三：逻辑运算符链式比较陷阱
cpp
int N = 12;

// ❌ 错误写法：会被解析为 (10 <= N) <= 12
// (10 <= 12) → true(1), 然后 1 <= 12 → true(1)
cout << (10 <= N <= 12);     // 输出 1 (true)

// ✅ 正确写法：
cout << (10 <= N && N <= 12); // 输出 1 (true)

// 但当 N=0 时：
// ❌ 错误：10 <= 0 → 0, 0 <= 12 → 1 → 输出 1（错误！）
// ✅ 正确：10 <= 0 → false, 短路求值 → 输出 0（正确）
📝 代码模板四：逗号表达式
cpp
// 逗号运算符：从左到右依次求值，返回最右边的值
int a, b;
b = (6, 28);    // b = 28（6被求值后丢弃）
// 此时 b=28, a 未初始化

// 不是逗号运算符！
int c = 3, d = 4; // 这是变量声明中的逗号分隔符
// c=3, d=4

// 注意区别：
// a, b = 3, 4; → 等价于 (a), (b=3), (4)
// 只有 b=3, a 未初始化（编译错误/不确定）

5 第五步：常见陷阱 — 二级最易失分点

⚠️ 陷阱一：== 写成 =（最高频错误！）

以下代码中 a == b; 不会改变 a、b 的值。这是 GESP 二级出题人最爱挖的坑——在代码中插入看似有意义的比较语句，实际是"空操作"。

cpp
int a = 3, b = 4;
a == b;   // 比较但不赋值，a 和 b 不变
b == a;   // 同样无效果
cout << a << ' ' << b;  // 输出 3 4（不是4 3！）
⚠️ 陷阱二：链式比较不成立

5 <= a <= 10 在 Python 中正确，但在 C++ 中被解析为 (5 <= a) <= 10：先计算 5 <= a（得 0 或 1），再和 10 比较，几乎总是 true。

⚠️ 陷阱三：% 操作符的操作数必须是整数

7.8 % 2 是编译错误——% 只能用于整型操作数。此外，a % 0 会导致运行时错误（除零）。

⚠️ 陷阱四：逗号表达式作为参数

cout << (a, b); 输出的是 b 而非 a——逗号在括号内作为逗号运算符返回最右值。而 cout << a, b;（无括号）则先输出 a，b 被求值但丢弃。

⚠️ 陷阱五：逻辑表达式的结果可以参与算术

在 C++ 中，true 等价 1，false 等价 0。所以 b = (a == 5); 可以将比较结果存入 int 变量。这在选择题中经常出现。

💡 防错口诀： 赋值看一个等号(=)，比较看两个等号(==)；取位先除再取余，链式比较用 &&；逗号只看最右边，逻辑真假即 0/1。

6 第六步：真题实战 — 运算符选择题

第1题 · 取位操作（2023/03 第5题）

下面C++代码用于获得正整数的第3位数，如1234则输出2。如果是一位数或两位数，则输出0。横线处应填入的代码是：

cpp
int N, remainder;
cout << "请输入正整数:";
cin >> N;
cout << _________________;

A. N % 1000 / 100    B. N / 1000 % 100    C. N / 1000 / 100    D. N % 100 / 100

答案：A
解析：取第3位数（百位）：N % 1000 保留低三位，再 / 100 取出百位。B/C 逻辑错误，D 中 N % 100 只保留个位和十位。
第2题 · 逗号表达式（2023/06 第10题）

下面C++代码执行，其输出是：

cpp
int a, b = (6, 28);
b == a;
a = b;
cout << a << ' ' << b;

A. 6 28    B. 6 6    C. 28 6    D. 28 28

答案：D
解析：b = (6, 28) 中逗号表达式返回 28，所以 b=28。b == a 是比较，a 不变（垃圾值）。a = b 后 a 也变成 28。输出 28 28。
第3题 · 取余应用（2023/09 第15题）

今天星期六，其后第N天星期几？下面的C++代码中，横线处应填上的代码是：

cpp
int N, remainder;
cin >> N;
remainder = _____________;
if(remainder == 0)
    printf("星期六后第%d天是星期天\n", N);
else
    printf("星期六后第%d天是星期%d\n", N, remainder);

A. (N + 6) / 7    B. (N + 6) // 7    C. N % 7    D. (N + 6) % 7

答案：D
解析：星期六后 N 天：(星期六 + N) 对应星期几。星期六=6（假设星期日=0），则 (6 + N) % 7，余数 0 为星期天。C 只算 N%7 没有偏移。
第4题 · 运算符优先级（2023/12 第8题）

C++语句 cout << (3 + 3 % 3 * 2 - 1) 执行后输出的值是：

A. -1    B. 4    C. 56    D. 2

答案：D
解析：按优先级：3%3=0 → 0*2=0 → 3+0=3 → 3-1=2。% 与 * 同级从左到右。
第5题 · ==与=的区别（2024/03 第6题）

下面C++代码执行，其输出是：

cpp
int a=3, b = 4;
a == b;
b == a;
cout << a << ' ' << b << endl;

A. 3 4    B. 3 3    C. 4 4    D. 4 3

答案：A
解析：a == b 和 b == a 都只是比较操作，不改变任何变量的值。a 仍是 3，b 仍是 4。输出 3 4。
第6题 · char类型算术运算（2024/06 第12题）

如果 a 为 char 类型的变量，且 a 的值为'C'（已知'C'的 ASCII 码为 67），则执行 cout << (a + 2); 会输出：

A. E    B. C+2    C. C2    D. 69

答案：D
解析：char 参与算术运算自动转为 int（ASCII码 67）。67+2=69，cout 输出整数 69，不是字符。若要输出字符'E'，需写 cout << char(a + 2);。
第7题 · 通用取位公式（2024/09 第18题）

下面C++代码用于获得正整数N的第M位数，如N等于1234，M等于2，则输出3。横线处应填入：

cpp
int N, M, div=1;
cin >> N >> M;
for (int i =0; i < (M - 1); i++) div *= 10;
cout << (______________);

A. N % div / 10    B. N / div / 10    C. N % div % 10    D. N / div % 10

答案：D
解析：div = 10^(M-1)。N / div 将目标位移到个位，再 % 10 取出。通用公式：第M位 = N/(10^(M-1))%10。
第8题 · 逗号表达式声明陷阱（2024/12 第4题）

下面C++代码执行，其输出是：

cpp
a, b = 3, 4;
c = a == b;
cout << a << ' ' << b << ' ' << c;

A. 3 4 0    B. 3 3 3    C. 4 4 4    D. 以上都不对

答案：D
解析：变量 a 和 c 未声明类型，C++ 中会编译错误。即使假设声明了，a, b = 3, 4 等价于 a; b=3; 4;，a 是未初始化值。
第9题 · 余数优化判断（2025/03 第20题）

求三色彩球的颜色。每组5红3绿2蓝。输入编号求该球颜色。下面是C++代码，正确说法是：

cpp
int N, remainder;
cin >> N;
remainder = N % 10;
if((1 <= remainder) && (remainder<= 5))
    cout << "Red";
else if ((6 <= remainder) && (remainder <= 8))
    cout << "Green";
else if ((remainder == 9) || (remainder == 0))
    cout << "Blue";

A. 将 else if ((remainder == 9) || (remainder == 0)) 修改为 else 效果相同
B. 将 ((1 <= remainder) && (remainder<= 5)) 修改为 (remainder <= 5) 效果相同
C. else if ((6 <= remainder) && (remainder <= 8)) 写法错误
D. remainder = N % 10 应修改为 remainder = N / 10

答案：A
解析：余数 0~9 中去掉 1~5 和 6~8 后只剩 0 和 9，所以直接 else 效果相同。B 错在 remainder=0 时也会进入（但0应该是Blue）。C 写法合法。D 逻辑全错。
第10题 · 编号循环取余（2025/06 第11题）

某种编号规则是"XX-Y"，XX从00到11（12个值），Y从0到9（10个值）。生成第N个编号，横线处应填：

cpp
cout << "请输入编号位置：";
cin >> N;
part1 = N % _____;
part2 = N % _____;

A. 12 10    B. 10 10    C. 11 9    D. 9 9

答案：A
解析：XX 从 00 到 11 共 12 个值，用 N % 12 循环。Y 从 0 到 9 共 10 个值，用 N % 10 循环。两者同时递增形成组合编号。

判断题

判断题第1题（2023/03 第1题）

在C++代码中，假设N为正整数，则 N / 10 舍弃个位数。如果 N 小于10，则其值为0，大于10则是舍弃个位数的数。

答案：✅ 正确
整数除法自动舍弃小数部分。N/10 实现个位数舍弃，N<10 时结果为 0。
判断题第2题（2023/03 第5题）

下列C++代码执行后，其输出为 10 20 ，即 a == b 和 b == a 对 a 和 b 的值没有任何影响。

cpp
int a = 10, b = 20;
a == b;
b == a;
cout << (a, b);
答案：❌ 错误
输出不是 10 20！cout << (a, b) 中逗号是运算符，返回 b=20 只输出 20。a==b 和 b==a 确实不影响变量值，但这个说法本身描述输出不准确。
判断题第3题（2023/06 第3题）

下面C++代码执行时如输入59.99，将输出「及格」两个汉字。

cpp
int score;
cout << "请输入学生成绩: ";
cin >> score;
if (score < 60)
    cout << "不及格";
else
    cout << "及格";
答案：❌ 错误
score 是 int 类型，cin 读入 59.99 时只取整数部分 59，遇到小数点停止。59<60，输出「不及格」，不是「及格」。
判断题第4题（2023/09 第7题）

在C++代码中，假设N为正整数，则 N - N / 10 * 10 与 N % 10 都将获得N的个位数。

答案：✅ 正确
N - N/10*10 是取余的等价写法。N/10 去掉个位，乘以10后面补0，减去原数就得个位。与 N%10 等效。
判断题第5题（2023/12 第12题）

下面C++执行后将输出 3*2=6 。

cpp
int a=2, b = 3;
a=a-b;
b=a+b;
a=b-a;
printf("%d*%d=%d\n", a, b, a*b);
答案：✅ 正确
这是一个无临时变量的交换算法：a=a-b=-1, b=a+b=2, a=b-a=3。交换后 a=3, b=2，输出 3*2=6。
判断题第6题（2024/03 第2题）

在C++语句 cout << (10 <= N <= 12) 中，假设N为12，则其输出为1。

答案：✅ 正确
10<=12 → true(1)，1<=12 → true(1)，输出 1。但注意这个表达式不能正确判断 N 是否在 10~12 之间——当 N=0 时也会输出 1！（0<=10→true(1)→1<=12→true）
判断题第7题（2024/06 第8题）

下面C++代码执行后将输出2*3=6。

cpp
int a = 2, b = 3;
printf("%%a*%%b=%d",a*b);
答案：❌ 错误
%% 在 printf 格式字符串中输出一个字面 % 符号，所以实际输出是 %a*%b=6，不是 2*3=6。%a 和 %b 不是有效的格式说明符。
判断题第8题（2024/09 第4题）

如果 a 为 int 类型的变量，则表达式 (a >= 5 && a <= 10) 与 (5 <= a <= 10) 的值总是相同的。

答案：❌ 错误
当 a=0 时：(0>=5&&0<=10) → false(0)；(5<=0<=10) → (0<=10) → true(1)。结果不同。链式比较在 C++ 中有语义差异。
判断题第9题（2024/12 第9题）

下列C++代码执行后将输出 1 ，因为 a 确实小于 20 和 10。

cpp
a = 5;
cout << (a < 10 and 20);
答案：❌ 错误
a < 10 and 20 被解析为 (a < 10) and 20。and (即 &&) 两边非零即 true。5<10 → true(1)，1 && 20 → true(1)。输出是 1 没错，但说法不准确：不是因为"小于20和10"，而是因为逻辑与两边都非零。
判断题第10题（2025/03 第6题）

下面的C++代码中变量都是整型，则执行后将输出 1 。

cpp
x, y, z = 5, 10, 15;
result = x < y < z;
cout << result;
答案：✅ 正确
虽然 x、y 未初始化（垃圾值），但 x<y 结果是 0 或 1。0<15 → 1，1<15 → 1，无论如何都输出 1。但注意这实际上是"无论 x,y 是什么值都输出 1"——链式比较的陷阱。

判断题第12题（2025/06 第3题）

C++代码 cout << ('5'+4); 执行后的输出为 9 。

答案：❌ 错误
'5' 的 ASCII 码是 53，53+4=57，输出 57 而不是 9。字符参与算术运算时使用其 ASCII 码值。
判断题第13题（2025/06 第16题）

C++表达式 5 < 10 && 20 对应的逻辑值为 true 。

答案：✅ 正确
5<10 → true(1)，1 && 20 → 两边非零 → true(1)。逻辑与只要两边都非零就为 true。
判断题第14题（2025/09 第11题）

C++表达式 10 / 0.333333 == 10 / (1 / 3) 的值为 true 。

答案：❌ 错误
1/3 是整数除法，结果为 0。所以右边是 10/0 导致除零错误。左边 10/0.333333 ≈ 30.00003。两者不可能相等。
判断题第15题（2025/09 第19题）

在C++代码中，运算符只能处理相同的数据类型，不同类型之间必须转换为相同的数据类型。

答案：❌ 错误
C++ 支持隐式类型转换（如 int+float 会自动将 int 转为 float）。不要求显式转换，不同类型可以混合运算。
