1 第一步：生活引入 — 生活中的「重复」与「选择」

🎯 场景比喻：体育课热身与比赛规则

体育课开始，老师喊"绕操场跑3圈"——这就是 for 循环：已知次数，按步执行。跑完热身，老师说"没跑完的继续跑，直到跑完为止"——这是 while 循环：条件控制，不确知次数。比赛时，裁判宣布"犯规者罚下，其他人继续"——这是 if/else 分支 和 continue/break。C++ 的循环和分支就是让计算机像体育老师一样按规则办事。

🔍 为什么是多层分支/循环结构是最大考点？

GESP 二级中，循环和分支占比约 35%，是出题量最大的知识点。每套试卷约 8~10 道题。核心原因：循环+分支是算法的骨架，二级考查学生能否追踪代码执行流程、理解嵌套逻辑、识别 continue/break 的精确语义。

2 第二步：核心概念 — 五大控制结构

结构语法执行特点二级考查频率
for循环for(初始;条件;步进){...}已知次数，三段式⭐⭐⭐⭐⭐
while循环while(条件){...}先判断后执行⭐⭐⭐⭐
if/else分支if/else if/else二选一或多选一⭐⭐⭐⭐⭐
continuecontinue;跳过本轮余下代码⭐⭐⭐⭐⭐
breakbreak;跳出当前循环⭐⭐⭐⭐⭐
🔵 for 循环三要素
  • 初始化：循环开始前执行一次，int i = 0
  • 条件判断：每次循环前检查，i < 10（不满足则退出）
  • 步进：每轮循环结束后执行，i++
  • 变量作用域：for(int i=0;...) 中 i 仅在循环体内有效
🟢 while 循环关键特征
  • 先判断，后执行：条件为 false 时循环体一次都不执行
  • 无条件 vs 有条件：while(1) 是无限循环（需 break 退出）
  • 与 for 等价转换：任何 while 都可转为 for，反之亦然
🟣 continue 与 break 的本质区别
语句效果后续代码循环是否继续
continue;跳过本轮剩余语句不执行继续下一轮
break;跳出当前循环不执行终止循环

break 后面的 continue 永远不会执行！

🔷 嵌套循环的执行规律
  • 外层走一步，内层走一轮：外层 i 每增加 1，内层 j 从头到尾执行一遍
  • 内层 break 只跳出内层循环，外层不受影响
  • 总执行次数 = 外层次数 × 内层平均次数

3 第三步：代码详解 — 循环模板与执行流程

📝 模板一：for 循环基本模式
cpp
// 模式1: 累加求和
int sum = 0;
for (int i = 1; i <= 10; i++) {
    sum += i;     // sum = 1+2+...+10 = 55
}

// 模式2: 带 continue（跳过偶数）
for (int i = 1; i <= 10; i++) {
    if (i % 2 == 0) continue;  // 跳过偶数
    cout << i << ' ';          // 输出: 1 3 5 7 9
}

// 模式3: 带 break（遇到第一个3的倍数就停）
for (int i = 1; i <= 10; i++) {
    if (i % 3 == 0) break;     // i=3时跳出
    cout << i << ' ';          // 输出: 1 2
}
📝 模板二：嵌套循环经典模式
cpp
// 九九乘法表
for (int i = 1; i <= 9; i++) {
    for (int j = 1; j <= i; j++) {
        printf("%d*%d=%d ", j, i, i*j);
    }
    printf("\n");
}

// 打印三角形星号
for (int i = 0; i < 5; i++) {       // 5行
    for (int j = 0; j < 5-i-1; j++) // 打印空格
        cout << " ";
    for (int k = 0; k < 2*i+1; k++) // 打印星号
        cout << "*";
    cout << endl;
}
📝 模板三：while 循环经典模式
cpp
// 模式1: 逐位拆分数（关键！）
int N = 1234;
while (N > 0) {
    cout << N % 10 << ' ';  // 输出个位
    N /= 10;                // 去掉个位
}
// 输出: 4 3 2 1

// 模式2: 计数器模式（等价于 for）
int cnt = 0;
while (cnt < 10) {
    cnt++;    // 变量必须手动更新！
}
// cnt = 10

// 模式3: 哨兵模式（读到特定值停止）
int num;
while (cin >> num && num != -999) {
    // 处理 num
}
📝 模板四：continue/break 精确语义
cpp
// continue：跳过本轮，继续下一轮
for (int i = 0; i < 5; i++) {
    if (i == 2) continue;  // 跳过 i=2
    cout << i << ' ';      // 输出: 0 1 3 4
}

// break：跳出当前循环（注意：只跳一层！）
for (int i = 0; i < 3; i++) {
    for (int j = 0; j < 5; j++) {
        if (j == 2) break;     // 只跳出内层 j 循环
        cout << i << ',' << j << ' ';
    }
    cout << endl;
}
// 输出: 0,0 0,1
//       1,0 1,1
//       2,0 2,1

5 第五步：常见陷阱

⚠️ 陷阱一：循环变量未初始化

int tnt; for(int i=0;i<10;i++) tnt+=i; —— tnt 未初始化，值不确定。GESP 最爱考这个！输出是垃圾值，不是 45。

⚠️ 陷阱二：continue 后还有代码

for(i=1;i<10;i++){if(i%2!=0){printf("A#");continue;}else break;printf("0#");} —— 注意 else-break 后的 printf("0#") 永远不会执行！因为 continue 和 break 都跳过了它。

⚠️ 陷阱三：内层循环修改外层变量

如 for(i=0;i<5;i++) for(i=0;i<i;i++) continue; —— 内外层使用同一个变量 i，会造成混乱，输出不可预期。

⚠️ 陷阱四：break 只跳一层

嵌套循环中 break 只跳出紧包含它的那一层循环。外层循环不受影响，继续正常执行。

⚠️ 陷阱五：while 循环变量忘记更新

while(N){...} 中如果忘记在循环体内修改 N（如 N/=10），会导致死循环。

💡 防错口诀： 变量先初始化，continue 跳余下；break 只跳一层，内外不分就乱套；while 记得改条件，嵌套数清循环次。

6 第六步：真题实战

选择题

第1题 · continue+break组合追踪（2023/03 第22题）
cpp
int i, Sum = 0;
for (i = 1; i < 10; i++){
    Sum += i;
    if(i % 2) continue;
    if(i % 7) break;
}
cout << Sum;

A. 45    B. 28    C. 3    D. 0

答案：C
i=1: Sum=1, i%2=1→continue。i=2: Sum=3, i%2=0→不跳过, i%7=2≠0→break。最终 Sum=3。
第2题 · 嵌套循环+break（2023/06 第18题）
cpp
int i, j;
for(i = 1; i < 12; i++)
    for(j = 1; j < i; j++)
        if(i * j % 2 == 1)
            break;
cout << i * j;

A. 110    B. 22    C. 12    D. 3

答案：C
i=1: j<1，内层不执行。i=2: j=1, i*j=2%2=0→不break。i=3: j=1, 3*1%2=1→break。cout 在循环之后输出 i*j=3*1=3...等等，但 j=1 时 break 只是跳出内层，外层继续。i 遍历 1~11，最终 i=12 退出外层循环，此时 i*j=12*11=132？不，关键在最后 j 的值。仔细追踪：每次 break 都跳出内层，外层继续。最后一轮 i=11, j 从 1 到 10，i*j%2==1 时 j=1 (11%2=1)，break。循环结束后 i=12（退出外层），j 仍是 1，所以 12*1=12。答案 12。

第11题 · 逻辑条件组合（2023/06 第24题）

下面C++代码执行后输出不能被3整除且除以5余数为2的数。下列选项不能实现的是：

cpp

第12题 · 含数字5的计数（2023/12 第30题）

「与5有关的数」定义为含有5或能被5整除。关于下面代码说法正确的是：

cpp
cnt = 0;
for (i = 1; i < 1000; i++){
    if (i % 5 == 0){ cnt += 1; continue; }
    j = i;
    while (j > 0)
        if (j % 10 == 5){ cnt += 1; break; }
        else j /= 10;
}

A. 删除continue不影响    B. 删除j=i将while中j改为i不影响    C. break改为j=0不影响    D. while(j>0)改为while(j>=0)不影响

答案：C
break 跳出 while 等价于 j=0（让循环条件 j>0 为假）。A 错误：删除 continue 会导致能被5整除的数被重复计数。B 错误：修改 i 会影响外层循环。D 错误：j>=0 会导致死循环（j=0 时条件仍成立）。
第13题 · 判断自守数（2024/06 第28题）

自守数：该数平方的尾数等于自身（如25²=625,尾数25）。相关说法错误的是：

cpp
int N, N1, M1;
cin >> N;
N1 = N, M1 = N * N;
bool Flag = true;
while (N1 > 0){
    if (N1 % 10 != M1 % 10){ Flag = false; break; }
    else{ N1 = N1 / 10, M1 = M1 / 10; }
}

A. Flag不被改为false则说明是自守数    B. 比较个位数判断    C. N1/10,M1/10去掉个位    D. 将N1>0改为N>0效果相同

答案：D
N 在 while 循环中没有被修改（只有 N1 和 M1 在变），while 中用 N>0 会导致死循环。所以改为 N>0 效果完全不同。
第14题 · for循环步进break（2024/12 第15题）
cpp

第17题 · 多层嵌套+条件判断（2023/09 第33题）
cpp
for (i =1; i < 12; i++){
    if (i % 2 == 0) continue;
    for (j = 0; j < i; j++)
        if (i * j % 2) break;
}
if(i >= 12) cout << (i * j);

A. 110    B. 12    C. 不确定    D. 无输出

答案：B

第18题 · for循环递减输出（2024/03 第26题）
cpp

for (i = 0; i < 5; i++)
