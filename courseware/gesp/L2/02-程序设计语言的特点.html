1 第一步：生活引入 — 直观比喻

🎯 场景比喻：编程语言就像「方言」

全国各地的人说不同的方言，但最终目的都是沟通。编程语言也是如此：C++、Python、Java 虽然语法不同，但最终都要翻译成机器能懂的机器指令来执行。C++是高级语言（接近人类思维），而机器指令是低级语言（接近硬件）。编译器就像一个翻译官，把高级语言翻成机器语言。

📐 流程图比喻：做菜的步骤图

流程图就像菜谱上的步骤图：椭圆形框 = 开始/结束（「开始做菜」「出锅」）；平行四边形框 = 输入/输出（「放入食材」「盛出成品」）；菱形框 = 判断（「熟了吗？」）；矩形框 = 处理步骤（「翻炒3分钟」）。考试常考输出语句放在哪种图形框中→ 平！行！四！边！形！

2 第二步：核心概念

🔵 程序设计语言分类
分类特点例子
机器语言0/1二进制代码，CPU直接执行10110000 01100001
汇编语言用助记符代替二进制，需汇编器翻译MOV AL, 61h
高级语言接近人类语言和数学表达式C++、Python、Java

关键认识：C++是高级语言，也是面向对象的编程语言。高级语言需要通过编译（或解释）转换为机器指令才能运行。

🔵 流程图基本符号
符号形状用途记忆口诀
起止框椭圆形/圆角矩形程序的开始和结束圆圆的开始和结束
输入/输出框平行四边形数据的输入和输出斜斜的平行四边形
处理框矩形计算、赋值等操作方方的矩形做处理
判断框菱形条件判断（是/否）尖尖的菱形做判断
流程线箭头表示执行方向箭头指向下一步

考试重点：输出语句（如 cout、printf）属于输出操作，应放在平行四边形框中！

🔵 C++ 关键字（Keyword）

C++关键字是语言预留的、有特殊含义的单词，不能用作变量名。常见关键字包括：

int   float   double   char   bool   if   else   for   while   break   continue   return   void   struct   class

重要误区：scanf、printf、cin、cout、main 都不是 C++ 关键字！它们是标准库函数或预定义标识符，理论上可以作为变量名（虽然不推荐）。

🔵 main 函数的特殊性

在C++中，每个程序必须有且仅有一个 main 函数——这是程序的入口点。程序从 main 的第一条语句开始执行，到 main 的最后一条语句结束。不能有多个 main 函数，否则编译器不知道从哪里开始执行。

3 第三步：代码详解

📝 C++ 程序基本结构
cpp
#include <iostream>
using namespace std;

int main() {           // 程序入口，只能有一个！
    int score = 85;    // 定义变量
    
    if (score >= 60)   // 条件判断
        cout << "及格";  // 输出语句 → 对应流程图中的平行四边形框
    
    return 0;          // 程序正常结束
}

结构拆解：#include = 引入头文件（工具箱），main() = 唯一入口（大门），cout = 输出（显示结果），return 0 = 正常结束（关门）。

4 第四步：手工模拟

🔍 画流程图：判断一个数能否同时被3和5整除

题目：对整型变量N，如果同时被3和5整除，输出「N是含有至少两个质因数」。请画出流程图。

💡 流程图步骤拆解
  1. 开始（椭圆形框）
  2. 输入N（平行四边形框 — 输入也是平行四边形！）
  3. 判断 N % 3 == 0 且 N % 5 == 0（菱形框）
  4. 如果成立 → 输出结果（平行四边形框）
  5. 结束（椭圆形框）

核心考点：输出语句在平行四边形框中！GESP考试反复考查这一知识点。记住：不管输入还是输出，都用平行四边形。

5 第五步：常见陷阱

⚠️ 陷阱1：scanf 不是关键字！

scanf 是C语言标准库的输入函数，不是C++关键字。你可以把变量命名为 scanf（虽然不推荐），编译器不会报错。C++真正的关键字是 int、if、for、return 等。

⚠️ 陷阱2：GESP等级与编程语言无关

GESP测试认证的是编程能力等级，同一级别的能力要求基本与所选编程语言无关。无论你考C++、Python还是Scratch，同一级别要求的计算思维和编程能力是一致的。

⚠️ 陷阱3：main函数只能有一个

一个C++程序中不能有多个main函数。main函数是程序的唯一入口点，如果存在多个main，链接器会报错「multiple definition of main」。

⚠️ 陷阱4：流程图符号不混淆

平行四边形 = 输入/输出，菱形 = 判断，矩形 = 处理，椭圆形 = 开始/结束。不要记混！输出语句（cout/printf）在平行四边形框中。

6 第六步：真题实战

📝 选择题

第1题 · 流程图的输出框（2024/09 第1题）

对整型变量N，如果它能够同时被3和5整除，则输出「N是含有至少两个质因数」。如果用流程图来描述处理过程，则输出语句应该在哪种图形框中( )。

A. 圆形框    B. 椭圆形框    C. 平行四边形框    D. 菱形框

答案：C（平行四边形框）
流程图中输出语句属于输入/输出操作，应放在平行四边形框中。圆形框一般不用于标准流程图；椭圆形框表示开始/结束；菱形框表示条件判断。

📝 判断题

判断题第1题 · 高级语言与机器指令（2023/12 第1题）

C++、Python都是高级编程语言，它们的每条语句最终都要通过机器指令来完成。

答案：✅ 正确
高级语言编写的程序最终都要经过编译/解释转化为机器指令（0/1二进制代码），CPU才能执行。无论C++、Python还是Java，本质都是如此。
判断题第2题 · scanf 不是关键字（2024/06 第2题）

在C++代码中，不可以将变量命名为scanf，因为scanf是C++语言的关键字。

答案：❌ 错误
scanf 是C语言标准库的输入函数，不是C++关键字。实际上可以把变量命名为 scanf，编译器不会报错（虽然这会遮蔽标准库函数，是非常不好的编程习惯）。真正的关键字如 int、if 才不能用作变量名。
判断题第3题 · GESP与编程语言无关（2024/12 第3题）

GESP测试是对认证者的编程能力进行等级认证，同一级别的能力基本上与编程语言无关。

答案：✅ 正确
GESP认证的是计算思维和编程能力，同一等级的核心能力要求与具体编程语言无关。无论选择C++、Python还是Scratch，所需掌握的逻辑思维和编程概念是相通的。
判断题第4题 · main 函数唯一性（2023/09 第4题）

在 C++语言中，一个程序不能有多个 main 函数。

答案：✅ 正确
每个C++程序有且仅有一个 main 函数作为程序入口点。如果存在多个 main 函数，编译器/链接器会报错。这是C++语言的基本规则。
判断题第5题 · C++是面向对象的高级语言（2025/03 第5题）

小杨最近开始学习C++编程，老师说C++是一门面向对象的编程语言，也是一门高级语言。

答案：✅ 正确
C++同时具备两个特性：它是高级语言（接近人类思维，远离机器码），也是面向对象的编程语言（支持类、对象、继承、多态等OOP特性）。这两个描述都是正确的。
