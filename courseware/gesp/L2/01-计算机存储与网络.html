1 第一步：生活引入 — 直观比喻

🎯 场景比喻：你的电脑就像一个办公桌

想象你坐在办公桌前工作：处理器(CPU) 就是你自己——负责思考、计算和决策；内存(RAM) 就是桌面——临时摆放正在处理的文件，速度快但空间有限，关灯(关机)后东西就没了；硬盘(磁盘) 就是抽屉柜——永久存放文件，但存取速度慢；输入设备 就像眼睛和耳朵——获取外界信息；输出设备 就像嘴巴和手——向外界表达结果。

🌐 网络比喻：教学楼就是一个小世界

你所在的教学楼内的计算机网络，能覆盖整栋楼但不会大到整个城市。这就是 LAN（局域网）——像一栋楼里的所有教室都能互相通信。而连接全世界的互联网就是 WAN（广域网）。TCP协议建立连接时的三次握手，就像你打电话：「喂，听得到吗？」→「听得到，你呢？」→「我也听得到，开始聊吧！」

🔵 TCP 三次握手

TCP（传输控制协议）在建立连接时需要经过三次握手：

  1. 客户端 → 服务器：SYN（我要连接你）
  2. 服务器 → 客户端：SYN + ACK（收到，我也要连接你）
  3. 客户端 → 服务器：ACK（收到，开始传数据）

这保证了双方都有发送和接收能力后才开始通信。

3 第三步：代码详解

📝 本知识点为概念型，无直接代码模板

计算机存储与网络主要考查概念理解，不涉及C++代码编写。但以下知识点会在后续编程中间接体现：

  • 变量存储：声明的变量存储在内存(RAM)中
  • 数据类型大小：int 占 4 字节(Byte)，char 占 1 字节 —— 这里用的就是存储单位
  • 输入输出：cin 从输入设备读数据，cout 向输出设备写数据
cpp
// sizeof 查看数据类型占用的内存字节数
cout << sizeof(int) << endl;    // 输出 4（4字节=32位）
cout << sizeof(char) << endl;   // 输出 1（1字节=8位）
cout << sizeof(double) << endl; // 输出 8（8字节=64位）

5 第五步：常见陷阱

⚠️ 陷阱1：Bit ≠ Byte

B 代表 Byte（字节），不是 Bit（位）。1 Byte = 8 Bit。考试常把二者混在一起考，要看清题目说的是 B 还是 b。

⚠️ 陷阱2：RAM vs ROM vs CACHE

买内存条买的是 RAM（随机存取存储器，可读写、断电丢失）。ROM 是只读存储器（出厂固化）。CACHE 是CPU内部高速缓存（比RAM还快、更小、更贵）。不要混淆！

⚠️ 陷阱3：网络类型覆盖范围

教学楼 = LAN（局域网），不是 MAN 也不是 WAN。PAN 是个人设备间的（如蓝牙）。记住覆盖范围从小到大的顺序：PAN → LAN → MAN → WAN。

⚠️ 陷阱4：操作系统 ≠ 编译器

操作系统（如 Windows、鸿蒙）负责管理硬件资源和提供用户界面。编译器才是把源程序翻译成目标程序的工具。鸿蒙是操作系统，不能把源程序翻译成目标程序并运行！

6 第六步：真题实战

📝 选择题

第1题 · 传感器与输入设备（2025/06 第1题）

2025年4月19日在北京举行了一场颇为瞩目的人形机器人半程马拉松赛。比赛期间，跑动着的机器人会利用身上安装的多个传感器所反馈的数据来调整姿态、保持平衡等，那么这类传感器类似于计算机的( )。

A. 处理器    B. 存储器    C. 输入设备    D. 输出设备

答案：C（输入设备）
传感器负责采集环境数据并送入计算机系统，相当于输入设备。处理器是计算核心，存储器存放数据，输出设备向外传送结果——都与「采集外界信息」的功能不符。
第2题 · 内存条是RAM（2024/09 第2题）

小明购置的计算机使用一年后觉得内存不够用了，想购置一个容量更大的内存条，这时他需要的内存条是( )。

A. RAM    B. ROM    C. CACHE    D. EPROM

答案：A（RAM）
内存条就是 RAM（随机存取存储器）。ROM是只读存储器不可随意更换，CACHE集成在CPU内部无法单独购买，EPROM是可擦除可编程只读存储器。日常说的「内存条」「运行内存」都指RAM。
第3题 · DeepSeek与AI应用（2025/03 第3题）

2025年春节有两件轰动全球的事件，一个是DeepSeek横空出世，另一个是贺岁片《哪吒2》票房惊人，入了全球票房榜。下面关于DeepSeek与《哪吒2》的描述成立的是( )。

A. 《哪吒2》是一款新型操作系统
B. DeepSeek是深海钻探软件
C. 《哪吒2》可以生成新的软件
D. DeepSeek可以根据《哪吒2》的场景生成剧情脚本

答案：D
DeepSeek是一个大语言模型（AI），可以根据给定的场景生成文本内容（如剧情脚本）。A错：《哪吒2》是电影不是操作系统。B错：DeepSeek是AI模型，不是深海钻探软件。C错：电影不能生成软件。
第4题 · 诺贝尔物理学奖与AI（2024/12 第4题）

2024年10月8日，诺贝尔物理学奖「意外地」颁给了两位计算机科学家约翰·霍普菲尔德（John J. Hopfield）和杰弗里·辛顿（Geoffrey E. Hinton）。这两位科学家的主要研究方向是( )。

A. 天体物理    B. 流体力学    C. 人工智能    D. 量子理论

答案：C（人工智能）
霍普菲尔德以霍普菲尔德网络闻名，辛顿被誉为「深度学习之父」，两人都因在人工神经网络和机器学习领域的奠基性贡献获诺奖。这道题体现了GESP对AI前沿的关注。
第5题 · 存储单位 Byte（2023/12 第5题）

计算机系统中存储的基本单位用B来表示，它代表的是( )，比如某个照片大小为3MB。

A. Byte    B. Block    C. Bulk    D. Bit

答案：A（Byte）
B = Byte（字节），1 Byte = 8 Bit。3MB = 3兆字节。Bit是更小的单位（位），Block和Bulk不是计算机存储单位。这是高频考点，务必记牢 B=Byte！
第6题 · 磁心存储 = 内存（2023/09 第6题）

据有关资料，山东大学于1972年研制成功DJL-1计算机，并于1973年投入运行，其综合性能居当时全国第三位。DJL-1计算机运算控制部分所使用的磁心存储元件由磁心颗粒组成，设计存贮周期为2μs（微秒）。那么该磁心存储元件相当于现代计算机的( )。

A. 内存    B. 磁盘    C. CPU    D. 显示器

答案：A（内存）
磁心存储器是早期计算机的主存储器（内存），存取速度快（微秒级），用于临时存放运算控制数据。它相当于现代计算机的RAM。磁盘用于长期存储，CPU是处理器，显示器是输出设备。
第7题 · 大模型 = 大语言模型（2024/09 第7题）

人工智能现在非常火，小杨就想多了解一下，其中就经常听人提到「大模型」。那么请问这里说的「大模型」最贴切是指( )。

A. 大电脑模型    B. 大规模智能    C. 智能的单位    D. 大语言模型

答案：D（大语言模型）
AI领域说的「大模型」通常指 Large Language Model (LLM)，即大语言模型，如 ChatGPT、DeepSeek 等。它通过海量数据训练，能理解和生成自然语言。
第8题 · TCP三次握手（2023/06 第8题）

在TCP协议中，完成连接建立需要通过( )握手。

A. 一次    B. 二次    C. 三次    D. 四次

答案：C（三次）
TCP建立连接需要三次握手（SYN → SYN+ACK → ACK）。断开连接需要四次挥手。这个数字是固定的，直接记忆即可。
第9题 · 飞行控制系统的处理器（2024/12 第9题）

近日，空中客车公司表示，约6000架空客A320系列飞机需要紧急更换一种易受太阳辐射影响的飞行控制软件。空客表示，在对一起飞行事故分析后的结果显示，强烈的太阳辐射可能会损坏飞行控制系统所需的关键数据，导致判断失误，进而引发飞行异常。那这里的飞行控制系统执行判断的部件最可能是下面的( )。

A. 辐射传感器    B. 处理器    C. 内存单元    D. 输出设备

答案：B（处理器）
「执行判断」是处理器(CPU)的核心功能。传感器负责感知（输入），内存负责存储，输出设备负责显示结果——只有处理器具备逻辑判断和决策能力。
第10题 · 教学楼网络 = LAN（2023/03 第10题）

小明最近为了备考GESP，开始看B站上关于网络知识的视频。其中提到计算机网络系统有不同的划分标准，那他平时上学所在的教学楼内的网络是一个( )。

A. PAN    B. LAN    C. MAN    D. WAN

答案：B（LAN）
教学楼内的网络范围是一栋楼，属于局域网(LAN)。PAN覆盖个人周围几米（蓝牙等），MAN覆盖一个城市，WAN覆盖跨城市/国家（互联网）。记住：教学楼=LAN，城市=MAN，全球=WAN。

📝 判断题

判断题第1题 · 智能设备与考试（2024/09 第1题）

人们现在参加很多闭卷考试时通常都不允许带智能手机、平板电脑等，此外很多种智能手表同样因为具有嵌入操作系统及通信等功能，所以也不允许随身携带。

答案：✅ 正确
智能手表因内嵌操作系统并具备通信功能，本质上等同于微型计算机，可被用于作弊，因此闭卷考试不允许携带。这个判断正确。
判断题第2题 · 文件复制操作（2023/12 第2题）

在Windows的资源管理器中为已有文件A建立副本的操作是Ctrl+C，然后Ctrl+V。

答案：✅ 正确
Ctrl+C = 复制（Copy），Ctrl+V = 粘贴（Paste），这是Windows中复制文件的标准快捷键操作。这考查的是计算机基本操作常识。
判断题第3题 · IDE调试与源程序修改（2024/06 第3题）

在集成开发环境里调试程序时，要注意不能修改源程序，因为如果修改，就要终止调试、关闭该文件并重新打开，才能再次开始调试。

答案：❌ 错误
现代IDE（如VS Code、Dev-C++）支持调试过程中修改源代码，修改后可以继续调试或重新编译，不需要「终止调试、关闭文件、重新打开」。这个说法过于绝对，是错误的。
判断题第4题 · 鸿蒙不是编译器（2025/03 第4题）

鸿蒙是华为公司开发的一款操作系统，那么它能够将正确的源程序翻译成目标程序，并运行。

答案：❌ 错误
鸿蒙是操作系统，不是编译器。将源程序翻译成目标程序是编译器（如g++）的工作。操作系统负责管理硬件资源和程序运行环境，但不负责编译翻译。这是概念混淆类陷阱。
