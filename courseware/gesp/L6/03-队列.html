1 一、生活引入：奶茶店排队的智慧

想象你走进一家人气奶茶店，店员喊道：

"请排队取餐，先来的先拿！"

你排在队伍末尾，前面的人依次取走奶茶离开。最先来的那个人，最终会第一个拿到奶茶。

这就是队列 —— 一种 先进先出（First In, First Out, FIFO） 的数据结构。

现实场景 队列操作
你来到队伍末尾排队 入队（push）
队伍最前面的人取餐离开 出队（pop）
看看谁在队伍最前面 访问队首（front）
看看谁在队伍最后面 访问队尾（back）

生活中的队列随处可见： - 超市收银台排队结账 - 打印机任务排队打印 - 食堂打饭排队 - 外卖订单按顺序处理

2 二、核心概念

2.1 队列的定义

队列是一种操作受限的线性表，只允许在一端（队尾）插入，在另一端（队首）删除。

C++ 
出队方向 ← [  a1  |  a2  |  a3  |  a4  |  a5  ] ← 入队方向
               队首                          队尾

2.2 基本操作

操作 描述 C++ STL 用法
push(x) 将元素 x 放入队尾 q.push(x)
pop() 移除队首元素 q.pop()
front() 访问队首元素 q.front()
back() 访问队尾元素 q.back()
empty() 判断队列是否为空 q.empty()
size() 返回队列元素个数 q.size()

2.3 队列 vs 栈 对比表

对比维度 栈（Stack） 队列（Queue）
原则 后进先出（LIFO） 先进先出（FIFO）
插入/删除位置 同一端（栈顶） 两端（队尾插入，队首删除）
形象比喻 叠盘子 排队
出队/出栈顺序 与入栈顺序相反 与入队顺序相同
常用操作 push / pop / top push / pop / front / back
底层实现 数组或链表 数组或链表，常用循环队列
典型应用 函数调用、括号匹配 广度优先搜索、任务调度

3 三、循环队列详解

3.1 为什么需要循环队列？

用普通数组实现队列时，队首不断出队会导致数组前面的空间被浪费：

C++ 
初始：     [  ｜a｜b｜c｜  ｜  ］
           front=0, rear=3

两次出队： [  ｜ ｜ ｜c｜  ｜  ］
           front=2, rear=3  ← 前面两个位置浪费了

如果让数组"首尾相连"，形成一个环，就能重复利用这些空间——这就是循环队列。

3.2 循环队列的存储结构

C++ 
rear
      ┌───┐
      │   │
   ┌──┘   └──┐
   │         │
   │         │
   │         │
   │         │
   └──┐   ┌──┘
      │   │
      └───┘
      front

用数组实现，通过取模运算让下标在 0 ~ N-1 之间循环。

3.3 关键约定

循环队列通常预留一个空位来区分队空和队满：

  • front：指向队首元素
  • rear：指向队尾元素的下一个位置

3.4 判空条件

C++ 
front == rear

当队首指针追上队尾指针时，队列为空。

3.5 判满条件

C++ 
(rear + 1) % N == front

当队尾指针再走一步就追上队首时，队列为满。注意这里牺牲了一个存储空间来区分空和满。

3.6 入队操作

C++ 
void enqueue(int x) {
    if ((rear + 1) % N == front) {
        // 队列已满，无法入队
        return;
    }
    arr[rear] = x;
    rear = (rear + 1) % N;
}

3.7 出队操作

C++ 
void dequeue() {
    if (front == rear) {
        // 队列为空，无法出队
        return;
    }
    front = (front + 1) % N;
}

3.8 获取队首元素

C++ 
int getFront() {
    if (front == rear) {
        // 队列为空
        return -1;
    }
    return arr[front];
}

3.9 循环队列公式总结

操作 公式
判空 front == rear
判满 (rear + 1) % N == front
入队 arr[rear] = x; rear = (rear + 1) % N;
出队 front = (front + 1) % N;
队首 arr[front]
队尾 arr[(rear - 1 + N) % N]
元素个数 (rear - front + N) % N

4 四、手工模拟：容量为 5 的循环队列

设定：数组容量 N = 5，初始 front = 0，rear = 0，队列为空。

操作 front rear 数组状态（下标0~4） 说明
初始 0 0 [ , , , , ] 空队列
push 10 0 1 [10, , , , ] rear 后移
push 20 0 2 [10,20, , , ] rear 后移
push 30 0 3 [10,20,30, , ] rear 后移
push 40 0 4 [10,20,30,40, ] rear 后移
push 50 — — [10,20,30,40, ] (4+1)%5=0==front，队满，入队失败
pop 1 4 [10,20,30,40, ] 10 出队，front 后移
pop 2 4 [10,20,30,40, ] 20 出队，front 后移
push 50 2 0 [10,20,30,40,50] (4+1)%5=0 != 2，可入队，50 放入下标4，rear 回到0
push 60 2 1 [60,20,30,40,50] (0+1)%5=1 != 2，60 放入下标0
push 70 — — [60,20,30,40,50] (1+1)%5=2==front，队满
pop 3 1 [60,20,30,40,50] 30 出队
pop 4 1 [60,20,30,40,50] 40 出队
pop 0 1 [60,20,30,40,50] (4+1)%5=0，50 出队
pop 1 1 [60,20,30,40,50] 60 出队，front==rear，队列为空

观察：循环队列通过取模运算让 rear 从 4 回到 0，实现了空间的循环利用。

5 五、常见陷阱与易错点

🚨 陷阱 1：判满公式混淆

错误：rear + 1 == front

正确：(rear + 1) % N == front

当 rear 在数组末尾（如 N-1）时，rear + 1 = N，不等于 front 的 0。必须取模才能正确循环。

🚨 陷阱 2：忘记预留一个空间

如果满员时也允许 front == rear，则无法区分队空和队满（两种情况都是 front == rear）。

解决方法：最多存储 N-1 个元素，牺牲一个空间。

🚨 陷阱 3：栈和队列的输出顺序混淆

操作输入顺序输出顺序
栈：push(1), push(2), push(3), pop(), pop(), pop()1, 2, 33, 2, 1（逆序）
队列：push(1), push(2), push(3), pop(), pop(), pop()1, 2, 31, 2, 3（同序）
🚨 陷阱 4：front 和 rear 的初始值

如果 front 指向队首的前一个位置，那么判空条件就是 front == rear（初始化时 front = 0, rear = 0 表示空队列）。不同教材可能有不同约定，考试时注意看题目说明。

🚨 陷阱 5：取模运算忘记加 N

计算 (rear - front) 可能为负数，取模运算在 C++ 中可能返回负数。

正确写法：

C++ 
int size = (rear - front + N) % N;  // 加 N 保证结果非负

下面定义了一个循环队列的类，补全判断队列是否满的函数，横线上应填写什么？

C++ 
class circular_queue {
private:
    int *arr;
    int capacity;
    int front;
    int rear;
public:
    circular_queue(int size) {
        capacity = size + 1; // 多预留一个空间
        front = 0; rear = 0;
    }
    bool is_empty() { return front == rear; }
    bool is_full() { ________________ // 在此处填入代码
};

A. return (rear + 1) % capacity == front;

B. return rear % capacity == front;

C. return rear == front;

D. return (rear + 1) == front;

答案：A
解析：解析：循环队列多用了一个空间，队满条件为 `(rear + 1) % capacity == front`。

📝 真题 3（2025年9月第5题）

循环队列常用于实现数据缓冲。假设一个循环队列容量为 5（即最多存放 4 个元素，留一个位置区分空与满），依次进行操作：入队数据1，2，3，出队1个数据，再入队数据4和5，此时队首到队尾的元素顺序是什么？

A. [2, 3, 4, 5]

B. [1, 2, 3, 4]

C. [3, 4, 5, 2]

D. [2, 3, 5, 4]

答案：A
解析：解析： - 初始 front=0, rear=0 - 入队1→rear=1, 入队2→rear=2, 入队3→rear=3（队列：[1,2,3]） - 出队1→front=1（队列：[_,2,3]） - 入队4→rear=4, 入队5→rear=0（队列：[5,2,3,4]） - 从队首到队尾：front=1 → [2, 3, 4, 5]
📝 真题 4（2025年12月第5题）

循环队列长度 N=6，初始 front=1, rear=1，执行操作序列：入队, 入队, 入队, 出队, 入队, 入队，则最终 (front, rear) 的值是什么？

A. (2, 5)

B. (2, 0)

C. (3, 5)

D. (3, 0)

答案：B
解析：解析： 初始 front=1, rear=1 1. 入队 → rear=(1+1)%6=2 2. 入队 → rear=(2+1)%6=3 3. 入队 → rear=(3+1)%6=4 4. 出队 → front=(1+1)%6=2 5. 入队 → rear=(4+1)%6=5 6. 入队 → rear=(5+1)%6=0 最终 (front, rear) = (2, 0)
📝 真题 5（2025年3月第9题）

以下代码实现了循环队列的哪种操作？

C++ 
class CircularQueue {
    int* arr;
    int front, rear, size;
public:
    CircularQueue(int k) {
        size = k; arr = new int[k]; front = rear = -1;
    }
    bool enQueue(int value) {
        if (isFull()) return false;
        if (isEmpty()) front = 0;
        rear = (rear + 1) % size;
        arr[rear] = value;
        return true;
    }
};

A. 入队

B. 出队

C. 查看队首元素

D. 判断队列是否为空

答案：A
📝 真题 6（2026年3月第4题）

游乐园的过山车每次限坐 4 人，用循环队列管理排队（容量 MAX=5，空一格判满）。下面代码执行后，循环队列是否已满？rear 的值是多少？

C++ 
void enqueue(int x) { queue[rear] = x; rear = (rear + 1) % MAX; }
void dequeue() { front = (front + 1) % MAX; }
int main() {
    enqueue(1); enqueue(2); enqueue(3); enqueue(4);
    dequeue(); dequeue();
    enqueue(5); enqueue(6);
}

A. 已满，rear = 1

B. 未满，rear = 1

C. 已满，rear = 2

D. 未满，rear = 4

答案：A
解析： 初始 front=0, rear=0
enqueue(1): queue[0]=1, rear=1
enqueue(2): queue[1]=2, rear=2
enqueue(3): queue[2]=3, rear=3
enqueue(4): queue[3]=4, rear=4
dequeue(): front=1
dequeue(): front=2
enqueue(5): queue[4]=5, rear=0
enqueue(6): queue[0]=6, rear=1
最终 front=2, rear=1
判断是否满：(rear+1)%MAX = (1+1)%5 = 2，等于 front=2，所以已满。 答案应为 A：已满，rear=1
