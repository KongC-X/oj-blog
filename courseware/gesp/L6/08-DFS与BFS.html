  2. 掌握 DFS 递归实现三种遍历顺序

🧩 走迷宫（DFS）

想象你走进一个巨大的迷宫。你的策略是：选一条路一直走到头，走不通了就原路退回上一个岔路口，换另一条路继续走。这就是深度优先搜索（DFS）——"一条路走到黑再回头"。

📌 DFS 的核心数据结构：栈

每次走到岔路口，把能走的方向压入栈（记下来）；走不通时从栈中弹出上一个位置，回溯继续探索。整个过程符合"后进先出（LIFO）"。

🌊 水波扩散（BFS）

往平静的湖面扔一块石头，水波会以石头为中心一圈一圈向外扩散——先覆盖最近的区域，再逐步扩展到更远的地方。这就是广度优先搜索（BFS）——"层层推进"。

📌 BFS 的核心数据结构：队列

初始节点入队，每次取队首节点访问，将其相邻节点加入队尾。整个过程符合"先进先出（FIFO）"，保证按距离递增顺序访问。

两种搜索范式：DFS = 栈（LIFO），BFS = 队列（FIFO）

2 第二讲：核心概念

DFS —— 深度优先搜索

DFS 沿着树的一条分支一直往下走，走到叶子（或无子节点）后回溯到最近的有未访问子节点的祖先节点。实现方式有两种：递归（系统栈）和 显式栈（手动维护）。

📌 DFS 的三种遍历顺序
遍历方式访问顺序特点栈中节点变化（递归版）
先序根 → 左 → 右先访问根，再递归左右先压右子，再压左子（或不用压）
中序左 → 根 → 右BST中序有序一路向左到底再处理
后序左 → 右 → 根最后访问根需额外标记第二次访问

BFS —— 广度优先搜索

BFS 按层遍历树：先访问根节点（第1层），然后访问第2层所有节点，再第3层……直到最后一层。同一层内按从左到右顺序访问。

📌 BFS 遍历顺序：按层逐层输出

例如树：根=1，左子=2，右子=3 → BFS顺序：1 2 3
若树为：1(左=2,右=3)，2(左=4,右=5)，3(左=6,右=7) → BFS顺序：1 2 3 4 5 6 7

DFS 与 BFS 对比总结

特性DFSBFS
数据结构栈（显式或递归系统栈）队列
特点沿一条分支深入，回溯按层次逐层访问
应用先/中/后序遍历、路径搜索层序遍历、最短路径
时间复杂度O(n)O(n)
空间复杂度O(h)，h为树高O(w)，w为树的最大宽度

3 第三讲：代码实现

DFS 递归实现——三种遍历

C++ 
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

// 先序遍历：根 → 左 → 右
void preorder(TreeNode* root) {
    if (!root) return;
    cout << root->val << " ";        // 访问根
    preorder(root->left);             // 递归左子树
    preorder(root->right);            // 递归右子树
}

// 中序遍历：左 → 根 → 右
void inorder(TreeNode* root) {
    if (!root) return;
    inorder(root->left);              // 递归左子树
    cout << root->val << " ";        // 访问根
    inorder(root->right);             // 递归右子树
}

// 后序遍历：左 → 右 → 根
void postorder(TreeNode* root) {
    if (!root) return;
    postorder(root->left);            // 递归左子树
    postorder(root->right);           // 递归右子树
    cout << root->val << " ";        // 访问根
}
💡 记忆口诀

先序：根左右 — 先访问根，再访问左子树，最后右子树
中序：左根右 — 先访问左子树，再访问根，最后右子树
后序：左右根 — 先访问左子树，再访问右子树，最后访问根

快速识别：根的位置决定了遍历名称——根在前面是先序，在中间是中序，在最后是后序。

DFS 非递归实现（显式栈）—— 先序遍历

C++ 
// 先序遍历（栈实现）
void preorderStack(TreeNode* root) {
    if (!root) return;
    stack<TreeNode*> s;
    s.push(root);                     // 根节点入栈
    while (!s.empty()) {
        TreeNode* node = s.top();     // 取栈顶
        s.pop();                      // 弹出
        cout << node->val << " ";    // 访问
        if (node->right) s.push(node->right);  // 先压右(后访问)
        if (node->left)  s.push(node->left);   // 后压左(先访问)
    }
}

// 中序遍历（栈实现）
void inorderStack(TreeNode* root) {
    stack<TreeNode*> s;
    TreeNode* cur = root;
    while (cur || !s.empty()) {
        while (cur) {                 // 一路向左
            s.push(cur);
            cur = cur->left;
        }
        cur = s.top(); s.pop();        // 弹出
        cout << cur->val << " ";     // 访问
        cur = cur->right;              // 转向右子树
    }
}

// 后序遍历（栈实现，双栈法）
void postorderStack(TreeNode* root) {
    if (!root) return;
    stack<TreeNode*> s1, s2;
    s1.push(root);
    while (!s1.empty()) {
        TreeNode* node = s1.top(); s1.pop();
        s2.push(node);                 // 利用s2反转顺序
        if (node->left)  s1.push(node->left);
        if (node->right) s1.push(node->right);
    }
    while (!s2.empty()) {
        cout << s2.top()->val << " ";
        s2.pop();
    }
}
⚠️ 关键细节

先序遍历栈实现中：先压右子节点，再压左子节点。因为栈是 LIFO，后压的节点先出栈，这样左子节点会先于右子节点被访问，符合"根→左→右"的顺序。

BFS 实现（队列）—— 层序遍历

C++ 
// BFS 层序遍历（队列实现）
void bfs(TreeNode* root) {
    if (!root) return;
    queue<TreeNode*> q;
    q.push(root);                     // 根节点入队
    while (!q.empty()) {
        TreeNode* node = q.front();   // 取队首
        q.pop();                      // 弹出队首
        cout << node->val << " ";    // 访问
        if (node->left)  q.push(node->left);   // 左子入队
        if (node->right) q.push(node->right);  // 右子入队
    }
}

// 层序遍历——按层输出（统计每层宽度）
void bfsLevelOrder(TreeNode* root) {
    if (!root) return;
    queue<TreeNode*> q;
    q.push(root);
    while (!q.empty()) {
        int levelSize = q.size();       // 当前层节点数
        for (int i = 0; i < levelSize; i++) {
            TreeNode* node = q.front(); q.pop();
            cout << node->val << " ";
            if (node->left)  q.push(node->left);
            if (node->right) q.push(node->right);
        }
        cout << endl;                 // 每层输出换行
    }
}
📌 BFS 关键点：q.front() + q.pop()

BFS 使用队列：q.front() 获取队首节点（最早入队的），q.pop() 将其弹出。子节点从左到右依次 q.push() 入队。这样保证了同一层内从左到右、层与层之间从上到下的访问顺序。

📐 DFS 非递归与 BFS 代码对比
操作DFS（栈）BFS（队列）
获取待访问节点s.top()q.front()
移除节点s.pop()q.pop()
加入子节点s.push(...)q.push(...)
子节点加入顺序先压右、再压左左子、右子依次入队
访问顺序特点沿分支深入再回溯按层逐层推进

5 第五讲：常见陷阱

🔴 陷阱 1：DFS 用队列辅助

有的同学在写 DFS 非递归时，错误地使用了队列而不是栈。记住：DFS = 栈（LIFO），BFS = 队列（FIFO）。把 DFS 写成 queue.push(...); queue.front(); queue.pop() 实际上是 BFS，结果会变成层序遍历。

🔴 陷阱 2：混淆 front() 与 top()

stack 用 .top() 获取栈顶元素，queue 用 .front() 获取队首元素。二者混用会导致编译错误或取到错误元素。

  • ✅ DFS 栈实现：s.top() + s.pop()
  • ✅ BFS 队列实现：q.front() + q.pop()
  • ❌ 二者不可互换
🔴 陷阱 3：先序遍历栈实现中压栈顺序

先序遍历非递归（栈实现）时，需要先压右子节点、再压左子节点。因为栈是后进先出，后压的左子节点会先出栈访问，从而保证"根→左→右"的顺序。如果搞反了就变成"根→右→左"了。

🔴 陷阱 4：BFS 使用 stack

BFS 必须使用队列，有人错误地使用 stack 来做"层序遍历"，结果输出变成了类似逆序的遍历，完全不符合层序要求。队列的先进先出特性才能保证"先进入的节点先被访问"。

🔴 陷阱 5：忘记处理空子树

无论是 DFS 还是 BFS，在将子节点入栈/入队前，必须检查该子节点是否存在（if (node->left) ...）。将 nullptr 入栈/入队会导致后续访问空指针错误。

📋 知识速查卡

知识点一句话总结常考形式
DFS 本质深度优先，一条路走到底再回溯概念理解
DFS 数据结构栈（递归用系统栈，非递归用显式栈 stack）代码填空
DFS 核心操作s.top() + s.pop()代码填空
DFS 先序非递归先压右、再压左（保证左子树先访问）选择/填空
DFS 递归三种遍历先根左右，中左根右，后左右根代码/序列
BFS 本质广度优先，按层逐层推进概念理解
BFS 数据结构队列 queue代码填空
BFS 核心操作q.front() + q.pop()代码填空
BFS 子节点入队左子先入、右子后入（保证从左到右）代码填空
时间复杂度DFS 和 BFS 均为 O(n)选择
空间复杂度DFS 最差 O(h)，BFS 最差 O(w)概念
🔑 核心口诀

DFS用栈，BFS用队；栈看top，队看front；先序先压右再压左，BFS先入左再入右；时间复杂度都是O(n)，空间DFS看高度BFS看宽度。
