1 生活引入：条件无处不在

📅 场景一：星期几推算

今天是星期一，再过 6 天是星期几？慢慢数也能数出来，但如果用数学表达：(1 + 6) % 7 = 0，余数为 0 代表星期日。

这就是 模运算 的生活应用——用程序自动判断星期几，而不是用手指头数。

🗓️ 场景二：闰年判断

为什么 2024 年 2 月有 29 天，而 2025 年只有 28 天？闰年的规则要用几个条件组合才能判断：能被 4 整除，但不能被 100 整除——除非还能被 400 整除。

这就是 条件组合 的趣味——if / else 加 && / ||，把复杂的逻辑变成清晰的代码。

🎯 本节学习目标

  • 掌握 if-else 语法及多分支嵌套结构
  • 理解逻辑运算符 &&、||、! 的真值表与优先级
  • 熟练运用三目运算符简化简单二选一
  • 能用取模 + 条件判断解决星期几 / 月份 / 模式序列问题
  • 正确提取百位、十位、个位（高频填空！）

2 核心概念

📝 if-else 语法

🔵 基本结构

if (条件) { ... } else if (条件) { ... } else { ... }——条件为真执行对应分支，所有条件都不满足则执行 else。

🟣 多分支嵌套

可以用 else if 串联多个条件判断。花括号内只有一条语句时可省略，但建议始终保留花括号以提高可读性。

🧮 逻辑运算真值表

📌 优先级口诀

!（非） > &&（与） > ||（或）——括号可以改变优先级，a || b && c 等价于 a || (b && c)。不确定时就加括号！

🎯 三目运算符

🟢 格式：条件 ? 表达式1 : 表达式2

简洁的一行写法，适合简单的二选一赋值或输出。例如：(a > b) ? a : b 取最大值，(isLeap ? "闰年" : "平年") 输出闰年判断结果。

3 代码详解

📅 星期几推算

🔹 核心代码
C++ 
// 星期几推算（核心考点！）
int nowDay = 1;       // 0=周日, 1=周一, ..., 6=周六
int afterDays = 6;
int D = (nowDay + afterDays) % 7;   // 关键公式！

if (D == 0)
    cout << "星期日" << endl;
else
    cout << "星期" << D << endl;
// 输入 1 + 6 = 7 → 7%7 = 0 → 输出: 星期日

🔢 数位提取（百位 / 十位 / 个位）

🟣 三位数的每一位怎么拿？
C++ 
int n = 314;
int a = n / 100;          // 百位 = 3
int b = (n / 10) % 10;    // 十位 = 1  ← 高频填空！
int c = n % 10;           // 个位 = 4

// 十位提取原理：n/10 去掉个位得 31，再 %10 取最后一位得 1
💡 记住

百位 = n/100、十位 = (n/10)%10、个位 = n%10——这三行在考试中反复出现，尤其是十位提取。

🏗️ 完整综合示例

C++ 
#include <iostream>
using namespace std;
int main() {
    // ===== 星期几推算 =====
    int nowDay = 1, afterDays = 6;
    int D = (nowDay + afterDays) % 7;
    if (D == 0) cout << "星期日" << endl;
    else        cout << "星期" << D << endl;

    // ===== 闰年判断 =====
    int year = 2024;
    if (year % 400 == 0 || (year % 4 == 0 && year % 100 != 0))
        cout << "闰年" << endl;
    else
        cout << "平年" << endl;

    // ===== 数位提取 =====
    int n = 314;
    cout << "百位:" << n / 100
         << " 十位:" << (n / 10) % 10
         << " 个位:" << n % 10 << endl;
    return 0;
}

4 手工模拟：星期推算跟踪

🖐 模拟场景

已知今天是星期一（nowDay=1），问再过 6 天（afterDays=6）是星期几？

步骤表达式计算过程结果含义
① nowDay 已知 1 星期一
② afterDays 已知 6 过 6 天
③ nowDay + afterDays 1 + 6 7 总共偏移天数
④ (nowDay + afterDays) % 7 7 % 7 0 余数为 0
⑤ D == 0 条件判断 true 进入 if 分支
⑥ 输出 — "星期日" 最终答案
✅ 关键洞察

模 7 余 0 不是"没有"，而是对应星期日（循环的终点）。一周 7 天从周日(0)到周六(6)，共 7 个状态循环。

口诀：模七为零是星期日，其余直接输出星期几

5 常见陷阱

🚨 陷阱 1：模 7 = 0 为星期日（不是星期零）

"余数为 0 就是星期零"或"余数为 0 无意义"都是错误认知。

一周从周日(0)到周六(6)共 7 天，(N+M)%7 == 0 对应的是星期日。如果误以为余数 1=周一、余数 7 才=周日，就会错。记忆："模七为零是星期日"。

🚨 陷阱 2：判断偶数的正确方式是 N%2==0

N % 4 == 2 只能判断部分偶数（如 2, 6, 10…），漏掉了 4, 8, 12… 等能被 4 整除的偶数。

正确写法是 N % 2 == 0，这才是所有偶数的充要条件。

🚨 陷阱 3：十位提取是 (n/10)%10，不是 n/100

以 n=314 为例：n/100 = 3 是百位，(n/10)%10 = 31%10 = 1 才是十位。

常见混淆：把百位公式当成十位，或写出 (n%10)/10 得到 0（个位再除十）。

🚨 陷阱 4：&& 优先级高于 ||，需加括号

a || b && c 等价于 a || (b && c)，因为 && 优先级高于 ||。

如果不加括号，可能产生语义错误。闰年公式必须加括号：y%400==0 || (y%4==0 && y%100!=0)。

🚨 陷阱 5：if 条件不一定是 bool 类型

C++ 中 if 条件可以是任意表达式，非零值为 true，零值为 false。所以 if(5)、if(-1)、if(x-3) 都是合法的。

考试重点："if 条件必须是 bool 类型"是错误的。int 会隐式转换为 bool！

6 真题实战

📌 考点一：星期计算
📝 真题 1（2024/03 第8题）

已知今天是星期 N（用整数 0~6 表示，0 为星期日），M 天后是星期几？

A. 输出 N+M
B. 计算 (N+M)%7，结果为 0 输出"星期日"
C. 计算 (M)%7，不为 0 输出星期几
D. 输出 M-N

答案：B · 核心公式 D=(N+M)%7，当 D==0 时输出星期日。
📝 真题 2（2024/06 第8题）

今天是星期一，N 天后又是星期几？以下条件中能判断 N 天后是否回到星期一的是？

A. N%7==1
B. N%7==0
C. N%7==6
D. N/7==0

答案：B · 当 N%7==0 时，经过的天数是 7 的倍数，会回到同一个星期几。
📌 考点二：条件组合
📝 真题 3（2025/03 第8题）

下列哪个条件表达式能正确表示"能被 3 整除的偶数"？

A. n%2==0 || n%3==0
B. n%6==0
C. n%2!=0 && n%3==0
D. n%2==0 && n%3==0

答案：D · 偶数 = 能被 2 整除，且能被 3 整除 → n%2==0 && n%3==0。B 虽等价于能被 6 整除，但 D 是直接表达。
📝 真题 4（2024/12 第8题）

以下程序段中，关于 if(N > M) cout << N - M; else cout << M - N; 的描述正确的是？

A. 输出结果可能为负数
B. 输出结果一定 ≥ 0
C. 输出结果一定等于 N
D. 输出结果一定等于 M

答案：B · 无论 N>M 还是 M>N，都是大数减小数，结果为绝对值，一定 ≥ 0。
📌 考点三：模式计算
📝 真题 5（2025/06 第8题）

当前是 9 月，N 个月后是几月？以下表达式正确的是？

A. 9 + N
B. (9 + N) / 12
C. 9 + N % 12
D. (9 + N) % 12

答案：D · 12 进制循环与星期几的 7 进制同理，(9+N)%12。
📝 真题 6（2025/09 第8题）

已知一周期序列为 1, 2, 3, 2, 1, 2, 3, 2, ...（"1232" 循环），求第 N 个数字的表达式是？

A. N % 4 配合查表
B. N % 3
C. N / 4
D. N % 2

答案：A · 周期长度为 4（1232 四个数循环），用 N%4 定位在周期中的位置。
📌 考点四：数位拆分
📝 真题 7（2024/09 第5题）

对于一个三位整数 i，下列选项中能得到其十位数字的是？

A. i / 10
B. (i / 10) % 10
C. i % 10
D. i / 100

答案：B · 十位提取 = (i/10)%10，先 /10 去掉个位，再 %10 取末位。
📝 真题 8（2025/03 第9题）

一个 6 位数，其高三位组成的数与低三位组成的数之差是 314 的倍数。下列条件表达式正确的是？

A. (高位 + 低位) % 314 == 0
B. (高位 - 低位) % 314 == 0
C. 高位 / 314 == 低位
D. 高位 % 314 == 低位 % 314

答案：B · 差是 314 的倍数，即 (高 - 低) % 314 == 0。
