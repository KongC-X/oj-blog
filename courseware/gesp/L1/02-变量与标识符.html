1 生活引入：给盒子贴标签

💡 场景一：整理储物柜

想象你有一排空的储物盒。你要往里面放东西，但盒子太多了——以后怎么快速找到想要的那个？

解决方案：给每个盒子贴一个标签（名字）！比如贴上 "age"、"height"、"score"。以后要找年龄，直接看标签为 "age" 的盒子就行。

对应到编程中：盒子 = 内存空间，标签 = 变量名（标识符），内容物 = 变量的值。

🏷️ 场景二：班级点名册 —— 为什么不能叫 "123"？

老师点名时，发现有个学生叫 "123"？这不像人名！还有个学生叫 "class"——但这恰好是系统保留词，不能用作人名。

编程中的命名规则与这完全类似：数字开头不合法（如 123abc），关键字不能用（如 int、for、if），但 _ 和 __ 却是合法的变量名！

  • my_name ✅ — 下划线可以用
  • my-name ❌ — 减号不合法
  • _Var_1 ✅ — 下划线开头合法
  • 2ndPlace ❌ — 数字开头不合法

🎯 本节学习目标

  • 掌握标识符命名规则：字母、数字、下划线的合法组合
  • 分清关键字和标准库标识符（高频考点！）
  • 掌握 printf 格式化输出：%d、%02d、%g 等格式符
  • 理解 C++ 大小写敏感与逗号表达式的求值规则

2 核心概念

📦 什么是变量？

🔵 变量的三要素

变量（Variable）是程序中用于存储数据的命名的内存空间。

要素说明示例
数据类型决定能存什么类型的数据int、double、char、bool
变量名（标识符）内存空间的名称，方便引用age、score、_temp
初始值可选，但强烈建议初始化= 15、= 3.14

🏷️ 标识符命名规则（核心考点）

🔵 标识符合法字符 = 字母 + 数字 + 下划线
规则说明示例
可用字符字母(a-z, A-Z)、数字(0-9)、下划线(_)abc _x v1 ✅
禁止开头不能以数字开头123abc ❌ abc123 ✅
禁止字符不能含 -、空格、中文标点等my-var ❌ my_var ✅
不能是关键字C++ 保留字不能作变量名int x ❌ intVal ✅
大小写敏感大写和小写是不同的标识符Age ≠ age ≠ AGE
长度限制前 63 个字符有效超长名字会被截断

🔑 关键字 vs 标准库标识符（高频考点！）

🔴 关键字 — 绝对不能用做变量名

C++ 关键字示例：int double char bool true false if else for while do return break continue switch case。

🟢 标准库标识符 — 可以但不推荐用作变量名

cin、cout、endl、printf、string、main 等都不是关键字。考试问"xxx 是不是关键字"时，这些都答不是。

类别能否做变量名常见示例
关键字（Keyword）❌ 绝对不行int do for true false
标准库标识符✅ 可以（但不推荐）cin cout endl printf string

记忆口诀：关键字是 C++ 语言本身的"词汇"；标准库是别人写的"函数/对象"。

🖨️ printf 格式化输出速查表

🟢 printf 常用格式符
格式符作用示例输出结果
%d输出十进制整数printf("%d", 42)42
%02d整数补零到至少 2 位printf("%02d", 7)07
%2d右对齐占 2 位宽printf("%2d", 7) 7
%f浮点数（默认 6 位小数）printf("%f", 3.14)3.140000
%.2f浮点数保留 2 位小数printf("%.2f", 3.14159)3.14
%g智能选择 %f 或 %e，去末尾零printf("%g", 3.1400)3.14

%s字符串printf("%s", "hi")hi

⚠️ 关键注意：printf 的格式字符串中，{}、$、# 等字符会原样输出，只有 %d、%f 等格式符才会被参数值替换！

3 代码详解

📝 变量定义与 printf 格式化

C++ 
#include <iostream>
#include <cstdio>    // printf 需要
using namespace std;

int main() {
    // ========== 基本变量定义 ==========
    int age = 15;          // 整型变量
    double height = 1.72;  // 浮点型变量
    cout << "年龄:" << age << " 身高:" << height << endl;

    // ========== printf 格式化输出 ==========
    int a = 7;
    printf("%02d\n", a);       // 输出: 07
    printf("%2d |\n", a);      // 输出:  7 |（右对齐）

    // ========== {} 原样输出陷阱 ==========
    int N = 3;
    printf("{N}*{N}={%d*%d}\n", N, N);
    // 输出: {N}*{N}={3*3}
    // {N} 不会被替换！只有 %d 才被替换

    // ========== 逗号表达式 ==========
    int X = 10;
    cout << (X = 3, X++, ++X) << endl;  // 输出 5
    return 0;
}
📌 代码逐行解析
  • #include <cstdio> — 使用 printf 必须包含此头文件
  • %02d — 宽度至少 2 位，不足左侧补零 → 7 变 07
  • %2d — 宽度至少 2 位，不足左侧补空格 → 7 变 7
  • {N}*{N}={%d*%d} — {N} 原样输出，%d 替换为 3
  • (X=3, X++, ++X) — 逗号表达式：从左到右依次执行，取最后一个的值 5

4 手工模拟：逗号表达式逐步追踪

🎬 (X=3, X++, ++X) 初始 X = 10

步骤执行的表达式X 的变化该表达式返回值
① X = 3 X 变为 3 3（赋值表达式的值）
② X++（后置自增） X 先返回 3，然后变为 4 3
③ ++X（前置自增） X 先变为 5，然后返回 5 5
✅ 结果

逗号表达式取最后一个的值 → 5

口诀：逗号表达式 (A, B, C, ... Z) = 从左到右依次执行，整体值 = 最后一个表达式 Z 的值
🤔 想一想

为什么 cout << X++, ++X（不带括号）的结果和带括号的结果可能不同？因为 << 运算符有自己的运算顺序，括号能确保逗号表达式的优先求值。

✏️ printf 格式字符串手推

手推 
printf("{N}*{N}={%d*%d}", 3, 3);

格式字符串: {N}*{N}={%d*%d}
第一个 %d → 参数1 = 3
第二个 %d → 参数2 = 3
其他字符全部原样输出

→ 最终输出: {N}*{N}={3*3}

❌ 不是 {3}*{3}={3*3}  —— {N} 不被替换
❌ 不是 {N}*{N}=9       —— %d*%d 只替换数字，不计算乘法

5 常见陷阱

🚨 陷阱 1：关键字 和 标准库标识符 分不清（最高频考点！）

考试经常问"以下哪个是 C++ 关键字"或"xxx 是不是关键字"。

是关键字：do、int、for、if、while、true、false、return、break 等。

不是关键字：cin、cout、endl、printf、string、main。这些是标准库中的标识符，可以用作变量名（不推荐但不违法）。

🚨 陷阱 2：大小写敏感 → First ≠ first

定义了 int First = 10; 但使用 first，编译器报错：'first' was not declared in this scope。因为 C++ 严格区分大小写。

常见误判："XingMing 和 xingming 是同一个标识符" —— 这是错的。

🚨 陷阱 3：printf 中 {} 原样输出

printf("{N}*{N}={%d*%d}", N, N) 的输出不是计算结果 9，而是 {N}*{N}={3*3}。

花括号 {} 不是 printf 的格式控制符，只有 %d、%f 等才会被参数值替换。$、#、& 等特殊字符只要不在格式符里就都会原样输出。

🚨 陷阱 4：_ 和 __ 都是合法标识符！

int _ = 5; 和 int __ = 10; 都可以编译通过。虽然实际编程中不推荐，但语法上完全合法。

判断题"__ 不能作为变量名"是错的（原始答案也是 ❌）。

🚨 陷阱 5：user-Name 是非法标识符

标识符只能包含字母、数字、下划线，不能包含连字符 -。编译器遇到 user-Name 会解析为 user 减去 Name，导致编译错误。

同样：空格也不能出现在标识符中，My Variable 是非法标识符。

🚨 陷阱 6：变量必须先定义后使用

直接使用未定义的变量名会触发编译错误：'x' was not declared in this scope。GESP 一级中这是一个基础但常考的陷阱。

三目运算符的两个分支类型不一致，一定会导致编译错误。

A. 正确    B. 错误

答案：B（错误）❌ · C++ 三目运算符支持隐式类型转换。如果两个分支类型兼容（如 int 和 double），不会报错，而是进行类型提升。cond ? 1 : 2.5 的结果类型为 double。
