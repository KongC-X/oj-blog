1 生活引入：为什么需要不同的数据类型？

📦 场景一：整数和小数 —— 不同精度，不同存储方式

买苹果：3 元一个 vs 3.14 元（π 的近似）。计算机中 int 存整数精确值，double 存浮点近似值。两者内存占用、精度、运算规则完全不同。

💻 场景二：字符其实是数字！

'A' 在计算机内部存储的就是数字 65（ASCII 码）。所以 'A' + 1 = 66（即字符 'B'），字符和整数可以互相转换。

🎯 本节学习目标
  • 掌握 6 种基本数据类型（int、double、float、char、bool、string）的特征与默认类型
  • 理解自动类型提升规则（低精度 → 高精度）和整数除法截断
  • 熟记 printf/scanf 格式符与类型的匹配关系
  • 识破 cin 按类型读取、逗号表达式、常量默认类型等高频陷阱

3 代码详解

🔬 类型提升链式运算完整解析

🔹 核心代码：一步看懂所有类型提升
C++ 
#include <iostream>
using namespace std;

int main() {
    // ===== 类型提升链式运算 =====
    cout << (3 == 0) + 'A' + 1 + 3.0 << endl;
    // 输出：69.0

    // 拆解过程：
    //   步骤①：(3==0) → false → 0              [bool 参与运算，false→0]
    //   步骤②：0 + 'A' → 0 + 65 → 65           [char 参与运算，'A'→65(ASCII)]
    //   步骤③：65 + 1 → 66                      [int + int = int]
    //   步骤④：66 + 3.0 → 69.0                  [int + double → double]

    // ===== 整数除法 vs 浮点除法 =====
    cout << 8 / 3 << endl;          // 输出：2     (int/int=int，截断！)
    cout << 8.0 / 3 << endl;        // 输出：2.66667 (有double参与，结果提升)

    // ===== printf 类型匹配 =====
    printf("%g\n", 6.14159);          // 输出：6.14159  (%g自动省略末尾0)
    printf("%.2f\n", 3.14159);        // 输出：3.14     (保留两位小数)

    // ===== cin 按类型读取 =====
    int N;
    cin >> N;     // 输入 3.14 → N只读取整数部分3，.14留在缓冲区
    cout << N;     // 输出：3

    return 0;
}
🤔 想一想：为什么结果是 69.0 而不是 69？

因为最后一步 66 + 3.0 中 3.0 是 double 类型，int 自动提升为 double，最终结果为 double 类型的 69.0。

💡 关键要点总结
  • int ÷ int = int（截断向零取整），想要小数结果必须让操作数之一变为 double
  • 混合运算时低精度类型自动提升为高精度，最终结果是参与运算的最高精度类型
  • printf 格式符必须与数据类型严格匹配，否则行为未定义（UB）
  • cin >> 变量 会根据变量类型决定读取多少内容

4 手工模拟：逗号表达式求值

🖐 模拟题目：cout << (3, 2); 输出什么？

💭 解题思路

这是一道经典的逗号表达式题目，需要理解 C++ 中逗号运算符的求值规则。逗号表达式的值为最后一个子表达式的值。

步骤表达式说明
步骤① 识别 (3, 2) 为逗号表达式 圆括号内的逗号是逗号运算符（非函数参数分隔）
步骤② 计算左边：3 先计算第一个操作数 3，值为 3（但被丢弃）
步骤③ 计算右边：2 再计算第二个操作数 2，值为 2
步骤④ 返回最后一个表达式的值：2 整个逗号表达式的值 = 最后一个子表达式的值
步骤⑤ cout << 2 最终输出：2
✅ 结论

cout << (3, 2) 只输出 2（不会输出 3 和 2 两个值）。逗号表达式的特点是「从左到右依次求值，但整体值等于最后一项」。

口诀：逗号表达式从左算到右，只要最后一个值！

5 常见陷阱

🚨 陷阱 1：7.0 是 double 不是 float！

C++ 中带小数点的字面常量默认类型为 double。要得到 float 需加后缀 f 或 F（如 7.0f）。GESP 多次考查此点！

🚨 陷阱 2：scanf("%d",&N) 输入 3.6 时只读取整数部分

scanf/cin 按目标变量的类型来解释输入。若 N 为 int，输入 3.6 时只读取 3，.6 留在输入缓冲区。

🚨 陷阱 3：int 和 double 混合运算结果为 double

3 + 2.5 = 5.5（不是 5）。int 自动提升为 double，结果为 double。但 8 / 3 = 2（两个 int 相除结果仍是 int，截断！）。

🚨 陷阱 4：printf("%d", 3.14) 是未定义行为（UB）

用 %d 读取 double 数据会导致错误输出或程序崩溃。格式符必须与数据类型严格匹配。

🚨 陷阱 5：cout << (3,2) 只输出 2

括号内是逗号表达式，整体值等于最后一个表达式。不会输出 "3 和 2" 两个值。

🚨 陷阱 6：if 条件可以是 int 类型

C++ 中 if 条件不强制要求 bool 类型。对于 int：非零 = true，零 = false。if(5) 完全合法且等价于 if(true)。

6 真题实战

📌 考点一：数据类型基础
📝 真题 1（2024/09 第1题）

在 C++ 中，常量 7.0 的默认数据类型是？

A. double    B. float    C. long double    D. int

答案：A · C++ 中带小数点的字面常量默认类型为 double，不是 float。要得到 float 需加后缀 f 或 F（如 7.0f）。
📝 真题 2（2025/03 第1题）

执行 cin >> a; 时输入 5+2，变量 a 的值取决于？

A. a = 5    B. a = 7    C. a = 52    D. 依赖变量 a 的声明类型

答案：D · cin 按目标变量的类型来解释输入。若 a 为 int 则读入 5；若 a 为 char 则可能读入 '+'（ASCII 43）；具体取决于变量声明时的类型。
📝 真题 3（2025/06 第1题）

使用 scanf 读取多个数值时，Tab 键的作用是？

A. 作为空白分隔符（等同于空格）    B. 会被当作普通字符读入
C. 导致读取失败    D. 只能用于字符串输入

答案：A · scanf 将空格、Tab、换行等空白字符均视为分隔符。输入 10\t20 与输入 10 20 效果相同，都会正确读取两个数。
📝 真题 4（2024/12 第1题）

int 类型和 double 类型进行混合运算后，结果的类型是？

A. double    B. int    C. float    D. 取决于哪个操作数更大

答案：A · 根据 C++ 自动类型提升规则，int 和 double 混合运算时 int 自动转换为 double，运算结果为 double。例如 3 + 2.5 = 5.5。
📌 考点二：类型运算与陷阱
📝 真题 5（2024/03 第1题）

在 C++ 中，以下关于 7 % 3 和字符串拼接的描述，正确的是？

A. 7 % 3 = 2.333...    B. 7 % 3 = 3
C. 7 % 3 = 1    D. 取余结果可用于字符串拼接判断

答案：D · 7 % 3 = 1（取余运算结果），本题考查取余运算在字符串处理中的应用场景。
📝 真题 6（2024/06 第1题）

执行 ++a 后使某图形周长增加 4，则 a 最可能是？

A. 边长变量    B. 半径变量
C. 面积变量    D. 正方形边长（周长=4×边长）

答案：D · 正方形周长 = 4 × 边长。当边长 a 增加 1 时（++a），周长恰好增加 4。
📝 真题 7（2025/09 第1题）

表达式 c = a++ b 会产生什么结果？

A. c = a+1 再加 b    B. c = a 加上 b 的值
C. c = a 然后 a 自增再乘以 b    D. 编译错误 / 语法错误

答案：D · a++ 是后置自增运算符，需要一个完整的操作数。a++b 中编译器无法区分 a++ 和后面的 b，导致语法解析错误。正确写法应为 c = a++ + b 或 c = ++a + b。
📝 真题 8（2025/12 第1题）

执行 int N; cin >> N; 并输入 10，输出 N 的结果是？

A. 10    B. 0    C. 未定义    D. 编译错误

答案：A · cin 从标准输入读取整数 10 到 int 型变量 N 中，N 的值就是 10。这是最基本的 cin 用法。
📌 判断题（8 道）
📝 判断题 1（2024/03）

若 int N = 5;，则表达式 (N + !N) 的值为 4。

答案：❌ 错误 · !5 = 0（非零的逻辑反为 0），所以 N + !N = 5 + 0 = 5，不是 4。
📝 判断题 2（2024/06）

定义 char c; 后执行 cin >> c; 输入 10，再执行 cout << (c * 2); 输出 20。

答案：❌ 错误 · cin 读入字符 '1'（ASCII 值 49），c * 2 = 49 * 2 = 98，不是 20。
📝 判断题 3（2025/03）

执行 cout << (3, 2); 会输出 3 和 2 两个值。

答案：❌ 错误 · (3,2) 是逗号表达式，整体值等于最后一项 2。因此只输出 2，不会输出两个值。
📝 判断题 4（2025/06）

float f = 2e-1; 执行 cout << f; 会输出 0。

答案：❌ 错误 · 2e-1 = 2 × 10-1 = 0.2。赋给 float f 后，cout << f 输出 0.2（或类似浮点表示），不会输出 0。
📝 判断题 5（2025/09）

12 + 12.12 这样的混合运算会导致编译报错。

答案：❌ 错误 · int 和 double 可以进行混合运算，C++ 会将 int 12 自动提升为 double，然后相加得到 24.12，不会报错。
📝 判断题 6（2024/12）

printf("%d", 3.14); 会导致编译或运行时报错。

答案：✅ 正确 · %d 用于读取 int 类型数据，而 3.14 是 double。类型不匹配属于未定义行为（UB），通常会产生错误输出或运行时异常。
📝 判断题 7（2025/03）

printf("%-5d", 314); 会输出 -5314。

答案：❌ 错误 · %-5d 中 '-' 表示左对齐，5 表示总宽度 5。输出为 "314 "（左对齐，右侧补两个空格），不是 -5314。
📝 判断题 8（2026/03）

if 语句的条件必须是 bool 类型。

答案：❌ 错误 · if 条件可以是任何可转为 bool 的类型。对于 int 类型：非零 = true，零 = false。if(5) 完全合法且等价于 if(true)。
