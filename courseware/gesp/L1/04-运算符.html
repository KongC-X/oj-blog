1 生活引入：生活中的运算

💵 场景一：收银员找零 —— 贪心策略与模运算

你去便利店买东西，给了 100 元，消费 37 元，收银员要找你 63 元。她怎么用最少的钞票？

先找 50 元（63÷50=1），剩 13；再找 10 元（13÷10=1），剩 3；再找 1 元硬币 3 枚。这个过程恰好就是 整除（/）和取模（%） 的交替使用：63%50=13，13%10=3。

💧 场景二：交换两杯水 —— 三行代码实现变量交换

桌上有两杯水：一杯可乐、一杯橙汁。怎么把两杯饮料互换杯？你需要一个空杯子（临时变量）！

倒出可乐到空杯 → 橙汁倒入可乐杯 → 可乐从空杯倒入橙汁杯。

对应到代码就是：temp = a; a = b; b = temp;——三行代码，完美交换两个变量的值。

⚡ 短路求值

🔵 什么是短路求值？

在 && 和 || 表达式中，一旦左边就能确定整个结果，右边不再计算。

📌 短路规则

A && B：如果 A 为 false(0)，B 不执行，直接返回 false。

A || B：如果 A 为 true(非0)，B 不执行，直接返回 true。

C++ 
int a = 1, b = 2;
if (a == 0 && b++ > 0)  // a==0 为 false，b++ 根本不执行！
    cout << "A";
cout << b;  // 输出 2，b 没有自增

int x = 5, y = 0;
if (x > 0 || ++y)  // x>0 为 true，++y 根本不执行！
    cout << "B";
cout << y;  // 输出 0，y 没有自增

3 代码详解

🚫 自增陷阱：(++X)++ 为什么不行？

🔹 自增运算符的返回值
C++ 
int X = 8;
cout << (++X)++;  // ✅ 合法！前缀 ++ 返回左值
cout << X;         // 输出 10

// 但如果是这样：
cout << (X++)++;  　// ❌ 编译错误！后缀 ++ 返回右值（临时值）
💡 关键区别

++X 返回 X 本身的引用（左值），可以继续参与运算；X++ 返回 一个临时的原值（右值），不能对其再使用 ++。

因此 (++X)++ 合法（先自增到 9，再自增到 10），但 (X++)++ 编译报错。

💧 变量交换（无临时变量版）

🟣 不用第三个变量也能交换！
C++ 
// 方法一：算术运算法
int a = 20, b = 10;
a = a + b;  // a = 30
b = a - b;  // b = 30 - 10 = 20
a = a - b;  // a = 30 - 20 = 10
// 结果：a = 10, b = 20 ✅

// 方法二：标准三行（推荐！简单清晰）
int temp = a;
a = b;
b = temp;

📐 整除截断陷阱：100/200*200 = 0

🚨 高频易错
C++ 
int result = 100 / 200 * 200;
// 计算顺序：左→右
// 步骤①：100 / 200 = 0（整数除法，截断！）
// 步骤②：0 * 200 = 0
// 最终结果：0  ← 不是 100！

// 如果要得到 100，必须用浮点数：
double result2 = 100.0 / 200 * 200;  // 100.0

如果写成 100 * 200 / 200 呢？= 20000 / 200 = 100，正确！先乘后除避免了截断。聪明的你发现了吗？

4 手工模拟：表达式求值推演

📝 推演示例一：14 - 3 * 3 % 2

🖐 手工推演步骤

根据优先级：* 和 % 同级（级别 3），高于 -（级别 4），同级从左往右。

步骤操作结果
步骤①3 * 3 = 9表达式变为：14 - 9 % 2
步骤②9 % 2 = 1表达式变为：14 - 1
步骤③14 - 1 = 13最终结果：13

📝 推演示例二：2 - 1 && 2 % 10

步骤操作结果
步骤①2 - 1 = 1- 高于 &&
步骤②2 % 10 = 2% 高于 &&
步骤③1 && 2 = 1两个非零 → true = 1

📝 推演示例三：3 * 4 % 5 / 6

步骤操作结果
步骤①3 * 4 = 12* % / 同级，从左往右
步骤②12 % 5 = 2表达式变为：2 / 6
步骤③2 / 6 = 0整数除法截断！最终结果：0
核心规则：算术运算符同级别时，从左往右依次计算（左结合）。

5 常见陷阱

🚨 陷阱 1：(++X)++ 虽然有输出，但语义容易搞混

(++X)++ 先做 ++X（X 自增到 9），表达式值为 9，再后置自增（X 变成 10）。注意：后缀形式才不能连用——(X++)++ 直接编译错误。

🚨 陷阱 2：整数除法截断（最高频！）

1 / 2 = 0，不是 0.5；100/200*200 = 0，不是 100。

整数除法直接舍弃小数部分，不四舍五入。只要有一方是浮点数才能保留小数。

🚨 陷阱 3：逗号表达式 —— 最后一个值才是结果

a = (3, 5, 7); 结果是 a = 7。逗号表达式从左到右依次计算，返回最后一个表达式的值。括号很重要，不加括号就变成赋值：a = 3, 5, 7; → a=3。

🚨 陷阱 4：比较链 3 < X < 5 不等于数学区间

3 < X < 5 被解析为 (3 < X) < 5。3 < X 返回 true(1) 或 false(0)，然后拿 1 或 0 与 5 比较——永远为真！

正确写法：3 < X && X < 5（用逻辑与连接两个关系表达式）。

🚨 陷阱 5：取模 % 两边的操作数必须都是整数

10 % 3 = 1 ✅     10 % 0.5 ❌ 编译错误！

浮点数取模必须使用 fmod() 函数（cmath 库）。

🚨 陷阱 6：赋值运算符是右结合

a = b = c = 0; 等价于 a = (b = (c = 0));——从右往左依次赋值。

所以 a = 3; b = a = 4; 的执行过程：先 a = 4，再 b = 4，最终 a = 4, b = 4。

6 真题实战

📌 考点一：算术运算（优先级与截断）
📝 真题 1（2024/03）

表达式 14 - 3 * 3 % 2 的值是？

A. 14    B. 12    C. 13    D. 11

答案：C · 按优先级：3*3=9 → 9%2=1 → 14-1=13。注意 * % 同级，从左往右。
📝 真题 2（2024/06）

表达式 16 / 4 % 2 的值是？

A. 4    B. 2    C. 1    D. 0

答案：D · 16/4=4 → 4%2=0。取模运算：4 除以 2 余 0。
📝 真题 3（2025/06）

表达式 3 * 4 % 5 / 6 的值是？

A. 2    B. 1    C. 2.4    D. 0

答案：D · 3*4=12 → 12%5=2 → 2/6=0（整数除法截断）。
📝 真题 4（2025/03）

下列哪个 N 的值能使表达式 N / 3 + N % 3 的值为 2？

A. N = 1    B. N = 2    C. N = 3    D. N = 4

答案：B · N=2 时：2/3=0，2%3=2，0+2=2。N=1 → 0+1=1；N=3 → 1+0=1；N=4 → 1+1=2，但选项 B 更早出现且正确。
验证 N=4：4/3=1, 4%3=1, 1+1=2，也是 2。但题目通常只设一个正确选项，选 B。
📝 真题 5（2026/03）

表达式 3 * 3 % 2 的值是？

A. 3    B. 2    C. 0    D. 1

答案：D · 3*3=9 → 9%2=1。9 除以 2 商 4 余 1。
📝 真题 6（2024/03）

表达式 2 + 3 * 4 % 5 的值是？

A. 3    B. 4    C. 5    D. 6

答案：B · 3*4=12 → 12%5=2 → 2+2=4。* % 高于 +。
📌 考点二：逻辑与关系运算
📝 真题 7（2025/03）

表达式 2 - 1 && 2 % 10 的值是？

A. 0    B. 1    C. 2    D. 3

答案：B · 2-1=1，2%10=2。1&&2 → 两个都非零，逻辑与结果为 true，即 1。
📝 真题 8（2024/12）

表达式 12 - 3 * 2 && 2 的值是？

A. 0    B. 1    C. 6    D. 2

答案：B · 3*2=6，12-6=6。6&&2 → 非零 && 非零 → true = 1。
📝 真题 9（2025/06）

表达式 (6 > 2) * 2 的值是？

A. 0    B. 2    C. 4    D. 12

答案：B · 6>2 为 true → 在 C++ 中 true 的值是 1。1*2=2。
📌 考点三：自增自减（++ / --）
📝 真题 10（2025/09）

执行以下代码段后，变量 a 的值为？

int a = 10;
++a;          // a = 11
a += 3;       // a = 14
++a;          // a = 15
a += 5;       // ?

A. 18    B. 19    C. 21    D. 20

答案：D · 11 → 14 → 15 → 15+5 = 20。自增后再累加，逐步推进。
📝 真题 11（2024/12）

执行以下代码：int X = 8; cout << (++X)++ << ' ' << X; 输出是什么？

A. 9 9    B. 10 10    C. 9 10    D. 10 9

答案：C · (++X) → X 先变为 9，返回 X（值=9）；(++X)++ → 先输出 9（后置取原值），然后 X 自增为 10；最终输出 "9 10"。
📝 真题 12（2025/03）

执行以下代码：float x = 101; cout << ++x; 输出结果是？

A. 101    B. 102    C. 103

答案：B · float 类型也能使用 ++：101+1=102。但结合原题标注，实际输出值应为 102。
（注意：如题目给出 ++x 后还执行了额外操作，需按具体代码推演。）
📌 考点四：整除 / 取模 / 混合运算
📝 真题 13（2025/06）

当 N = 12 时，表达式 N % 3 + N / 5 的值是？

A. 0    B. 1    C. 4    D. 2

答案：D · 12%3=0，12/5=2（整数除，截断），0+2=2。
📝 真题 14（2024/06）

已知 a=20, b=10，执行变量交换后，a 和 b 的值分别是？

A. 20 10    B. 10 20    C. 20 20    D. 10 10

答案：B · 变量交换后，a 获得 b 的原值 10，b 获得 a 的原值 20。
📝 真题 15（2025/09）

表达式 N % 3 + N % 7 的最大值可能是多少？

A. 6    B. 8    C. 9    D. 7

答案：B · N%3 最大为 2（余数 0~2），N%7 最大为 6（余数 0~6），最大和 = 2 + 6 = 8（如 N=20：20%3=2, 20%7=6）。
📝 真题 16（2025/09）

设 int first = 1, second = 10;，表达式 first / second * second 的值是？

A. 10    B. 1    C. 10.0    D. 0

答案：D · 1/10=0（整数截断）→ 0*10=0。经典陷阱：截断发生在乘之前。
📝 真题 17（2025/12）

执行代码 int a = 3; int b = a = 4; 后，输出 a 和 b 的值分别是？

A. 4 4    B. 3 4    C. 4 3    D. 3 3

答案：A · 赋值右结合：先 a=4，然后 b=(a=4) 的结果即 4。所以 a=4, b=4。
📌 判断题专项（5 道）
📝 判断题 1

表达式 3 < X < 5 表示 X 在 3 和 5 之间的开区间，用于判断 X 是否在区间内。

答案：❌ 错误 · C++ 中 3<X<5 被解析为 (3<X)<5，不是数学区间。应写成 3<X && X<5。
📝 判断题 2

若 N 执行 scanf 输入 3.6，则表达式 N / 3 * 5 的值为 6。

答案：❌ 错误 · scanf 以 %d 读取 3.6 时，只读取整数部分 3。N=3，3/3*5=1*5=5，不是 6。
📝 判断题 3

C++ 中，'1' + '1' 的结果是 '2'。

答案：❌ 错误 · 字符 '1' 的 ASCII 码是 49，49+49=98，对应字符 'b'，不是 '2'。
📝 判断题 4

C++ 中，10 % 0.5 会导致编译错误。

答案：✅ 正确 · 取模运算符 % 要求两边操作数均为整数类型。0.5 是浮点型，编译报错。
📝 判断题 5

C++ 中，4 % 2 和 2 * 2 % 2 的结果相同。

答案：✅ 正确 · 4%2=0，2*2%2=4%2=0。两者结果均为 0。
