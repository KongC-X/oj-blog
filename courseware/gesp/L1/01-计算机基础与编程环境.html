1 生活引入

你有没有想过：手机为什么能同时播放音乐、回复消息、导航路线？或者，你在键盘上按下「A」，屏幕上的文字区域就出现「A」——这一瞬间到底发生了什么？

📱 场景：用电脑写作业

假设你打开电脑写一篇作文。你敲击键盘输入文字 → 文字显示在屏幕上 → 写完点保存 → 文件存到硬盘。

这短短几秒里，你的电脑内部发生了：键盘（输入设备） → CPU 处理 → 显示器（输出设备） → 硬盘（存储器）。这就是计算机最基本的工作模型。

💡 一句话总结：计算机 = 输入设备（感知） + 处理器（思考） + 输出设备（行动） + 存储器（记忆）。就像人的眼睛→大脑→嘴巴→记忆一样。

2 核心概念

2.1 计算机硬件五大组成部分

冯·诺依曼体系结构是现代计算机的基石，由五大部分组成：

组成部分功能常见例子
输入设备接收外界信息，送入计算机键盘、鼠标、传感器、摄像头、麦克风
输出设备将计算结果呈现给用户显示器、打印机、扬声器
运算器 + 控制器 = CPU执行计算和逻辑判断，控制各部件协调工作Intel Core i7、Apple M2
存储器（内存）临时存放正在运行的程序和数据（断电丢失）DDR4 8GB 内存条
存储器（外存）永久存放文件和程序（断电不丢）硬盘、SSD、U盘、SD卡
🔑 易混淆对比

输入 vs 输出：方向是关键。数据从外界→计算机就是输入；从计算机→外界就是输出。比如摄像头拍照是输入设备，打印机打印是输出设备。

内存 vs 外存：内存快但断电丢失（正在编辑的文档），外存慢但永久保存（已保存的文件）。考试常考这个区别。

2.2 软件层次：操作系统 · 编程语言 · IDE

概念是什么GESP 考试中的考点
操作系统 (OS)管理硬件和软件资源的系统级软件Windows、macOS、Linux、鸿蒙 OS；它不是编译器
编程语言人与计算机沟通的工具C++、Python、Scratch；C++ 是高级语言
IDE（集成开发环境）集编辑、编译、运行、调试于一体的软件Dev C++、VS Code；可设断点调试
编译器将高级语言翻译为机器指令的工具g++、clang++；高级语言 → 机器指令

2.3 程序的完整生命周期

🔄 从代码到运行的五步流程

编辑（写代码）→ 编译（翻译成机器语言）→ 链接（组装各模块）→ 运行（执行程序）→ 调试（找问题、修错误）

🧠 考试常考

Dev C++ 中的编译功能负责将 C++ 源文件变为可运行程序。调试时可以设置断点让程序暂停在某一行检查变量的值。GESP 考级目前支持 Scratch、Python、C++ 三种语言。

3 代码详解

来看看你的第一个 C++ 程序长什么样，以及它是怎么跑起来的。

3.1 最简单的 C++ 程序

C++ 
#include <iostream>        // 引入输入输出库
using namespace std;       // 使用标准命名空间

int main() {               // 主函数——程序的入口
    cout << "Hello, GESP!"; // 向屏幕输出一句话
    return 0;              // 告诉系统：运行成功
}
📝 逐行解读

第1行 #include：相当于跟计算机说"我要用到输入输出的功能，请帮我加载这个工具箱"。
第2行 using namespace std：告诉编译器"用标准库的名字，不用每次加前缀"。
第4行 int main()：每个 C++ 程序必须有一个 main 函数，程序从这里开始执行。
第5行 cout：C++ 中在屏幕上显示内容的方式，<< 是输出运算符。
第6行 return 0：向操作系统报告"程序正常结束"。

3.2 从源代码到运行

⚙️ 程序的变身过程
步骤操作结果
1. 编写在 IDE 中写 .cpp 文件源代码（人可以看懂）
2. 编译编译器将 C++ 翻译为机器码目标文件 .o/.obj
3. 链接将库文件与目标文件合并可执行文件 .exe/.out
4. 运行双击或命令行执行屏幕上显示结果
🤔 想一想

为什么不能直接用中文或英文写程序让计算机执行？因为计算机只认识 0 和 1（二进制机器指令），所以需要编译器做"翻译官"。

4 手工模拟

我们一起来手工模拟计算机处理一条加法指令的完整过程，加深对五大部件协作的理解。

场景：计算 3 + 5

步骤操作参与部件数据流向
①用户在键盘输入 3 + 5输入设备（键盘）键盘 → 内存
②CPU 从内存读取指令"做加法"处理器（CPU）内存 → CPU
③CPU 中的运算器执行 3+5处理器（运算器）CPU 内部
④结果 8 暂存内存存储器（内存）CPU → 内存
⑤显示器显示结果 "8"输出设备（显示器）内存 → 显示器
🧠 深度思考

注意：整个过程由控制器协调。它像一个指挥家，按节拍（时钟周期）调度每个部件在正确的时间做正确的事。而内存就像一张草稿纸 — CPU 计算时把数据暂存在上面，断电后草稿纸上的内容就没了。

🥪 类比：做三明治

输入设备 = 冰箱（取出面包、火腿）
处理器 = 你的大脑 + 手（决定怎么组合、实际动手）
输出设备 = 盘子（呈现成品）
内存 = 砧板（操作过程中的临时工作台，做完就收走）
外存 = 食谱书（做法永久记录，但需要翻看）

5 常见陷阱

⚠️ 陷阱1：把操作系统当编译器

错误认知：鸿蒙 OS、Windows、iOS 是编译器。
正确认知：操作系统是管理硬件和软件的平台，不是编译器。编译器是 g++、clang 这类工具。考试中看到"XX OS 是编译器"直接判错。

⚠️ 陷阱2：混淆输入设备和输出设备

易错点：传感器、摄像头、扫描仪 → 都是输入（数据从外向内）。打印机、投影仪、扬声器 → 都是输出（数据从内向外）。触摸屏既是输入又是输出，但 GESP 一级目前不深入考这个。

⚠️ 陷阱3：认为 AI 算法程序是硬件设备

错误认知："AI 算法程序"可以作为输入设备。
正确认知：AI 算法程序是软件，不是硬件设备。输入设备必须是物理硬件（如键盘、传感器）。软件不能作为输入/输出/存储设备。

⚠️ 陷阱4：文件名大小写与重命名

在 IDE 中修改文件名应使用"右键 → 重命名"。直接修改代码中的注释不会改变实际文件名。Windows 中文件名不区分大小写，但 C++ 代码中引用文件可能区分。

⚠️ 陷阱5：认为大模型等于大语言模型

易错点：大语言模型（LLM）是大模型的一个子类。大模型还包括视觉模型、多模态模型等。考试中看到"大模型就是大语言模型"这个表述是错误的。

⚠️ 陷阱6：注释会影响运行速度

错误认知：多写注释会让程序运行变慢。
正确认知：注释在编译阶段会被完全忽略，不会进入最终的可执行文件，因此对运行速度没有任何影响。注释仅供人阅读。

💡 答题技巧

遇到"设备分类"的选择题，先判断关键词：有没有"器"字？ 传感器、扫描仪 → 输入；打印机、扬声器 → 输出。遇到"是否物理硬件"，软件类选项（如算法、程序）要高度怀疑。

6 真题实战

以下 22 道真题按考点分类，每题均可点击「显示答案」查看解析。建议先自己做，再看答案。

📌 考点一：计算机组成与设备分类（3 道选择 + 3 道判断）
题1 （2025/09 第1题）

汽车倒车时用的雷达传感器，在计算机的分类中相当于：
A. 输出设备
B. 输入设备
C. 存储设备
D. 处理设备

答案：B
解析：传感器采集外界信息（距离、温度、光线等）送入计算机处理，数据方向是外→内，因此属于输入设备。考试中「传感器」是输入设备的经典考点，出现频率很高。
题2 （2025/12 第1题）

无人机在飞行时发现前方有障碍物后会自动避开，完成这个「发现→判断→避开」过程的部件是：
A. 传感器
B. 处理器
C. 电机
D. 电池

答案：B
解析：传感器负责"发现"，电机负责"避开"，但中间的"判断"（要不要避、往哪边避）由处理器（CPU）完成。CPU 的核心职责就是执行计算和逻辑判断。
题3 （2026/03 第1题）

下列不能作为输入设备的是：
A. 鼠标
B. AI 算法程序
C. 扫描仪
D. 触摸板

答案：B
解析：AI 算法程序是软件，不是硬件设备。输入设备必须是物理硬件。A、C、D 都是物理输入设备。
判断题 1 （GESP 认证语言）

GESP 认证目前支持 Scratch、Python 和 C++ 三种编程语言。

答案：✅ 正确
解析：GESP 认定 Scratch、Python、C++ 为三种可选认证语言，考生可根据自身情况选择其中一种参加。
判断题 2 （C++ 语言级别）

C++ 属于高级编程语言，编写好的 C++ 程序需要通过编译器翻译成机器指令，计算机才能执行。

答案：✅ 正确
解析：C++ 是高级语言（接近人类思维），计算机只能执行机器指令（0/1），因此必须由编译器将高级语言翻译为机器指令。这也是为什么 IDE 流程中有「编译」这一步。
判断题 3 （输入设备）

键盘、鼠标和传感器都属于计算机的输入设备。

答案：✅ 正确
解析：三者都负责将外界信息送入计算机，数据方向为外→内，都是输入设备。传感器是本考点高频关键词。

题4 （2024/09 第1题）

下列软件中，属于操作系统的是：
A. Dev C++
B. Microsoft Word
C. 纯血鸿蒙 HarmonyOS

答案：C

题5 （2024/06 第1题）

小明在 Dev C++ 中编写了一个程序，他想运行这个程序。以下哪个操作是正确的？
A. 直接点「运行」按钮即可
B. 先保存文件，再点「运行」按钮
C. 先点「编译」按钮，再点「运行」按钮
D. 先点「运行」按钮，再点「编译」按钮

答案：C
解析：正确的流程是先编译（将代码翻译为机器语言），再运行。如果直接点运行，IDE 通常会提示需要先编译。顺序不能反，也不能跳过编译。
题6 （2024/03 第1题）

关于 IDE（集成开发环境），下列说法错误的是：
A. IDE 只能用来写代码，不能调试程序
B. IDE 可以帮助程序员提高开发效率
C. Dev C++ 是一种常用的 C++ IDE
D. IDE 中可以同时拥有编辑、编译、运行、调试的功能

答案：A
解析：IDE 的"集成"含义就是集成编辑 + 编译 + 运行 + 调试等多项功能。A 说"不能调试程序"是错的，IDE 支持设置断点、单步执行等调试功能。
题7 （2025/03 第2题）

在 IDE 集成开发环境中，以下哪一项功能是无法直接完成的？
A. 编写代码
B. 编译程序
C. 运行程序
D. 插入截图

答案：D
解析：IDE 的核心功能是写代码、编译、运行和调试。插入截图不是 IDE 的功能范畴，截图属于画图工具或截图工具的事情。考试中要注意区分 IDE 的功能边界。
判断题 4 （鸿蒙 OS）

鸿蒙 HarmonyOS 是一种 C++ 编译器。

答案：❌ 错误
解析：鸿蒙 OS 是操作系统，不是编译器。编译器是用来翻译代码的工具（如 g++），两者的角色完全不同。考试中 OS 和编译器的混淆是高频陷阱。
判断题 5 （调试阶段）

在程序调试的过程中，如果发现代码有错，可以直接修改代码并立即看到修改后的运行结果，不需要重新编译。

答案：❌ 错误
解析：修改代码后必须重新编译才能生成新的可执行程序。C++ 不是解释型语言，不能修改后直接看到效果。调试过程中修改代码 → 重新编译 → 重新运行，这个流程不能省略。
判断题 6 （智能设备操作系统）

电话手表和智能手机一样，内部也运行着操作系统。

答案：✅ 正确
解析：现代智能设备（电话手表、智能电视、车载系统等）内部都运行着操作系统，用于管理硬件资源、运行应用程序。电话手表通常运行精简版的 Android 或 RTOS（实时操作系统）。

题10 （2024/03 第2题）

关于大模型，以下说法正确的是：

B. 大模型就是大语言模型，两者完全等同

📌 考点四：编程常识（2 道选择 + 3 道判断）
题11 （2024/03 第4题）

在操作系统中，如果想改变某个文件名，以下哪种方式是正确的？
A. 右键点击文件，选择「重命名」，输入新名称
B. 打开文件，修改文件内容后保存
C. 删除文件，新建一个不同名称的文件
D. 用截图工具截取文件名后修改

答案：A
解析：右键 → 重命名是操作系统中最标准的文件重命名方式。B 修改的是文件内容≠文件名。C 虽然可以达到目的，但不是"重命名"操作（且原文件被删除了）。D 完全不相关。
题12 （2024/06 第2题）

以下哪种说法是错误的？
A. C++ 程序从 main 函数开始执行
B. 一个 C++ 程序中可以有多个函数
C. C++ 程序只能按从上到下的顺序执行，不能改变执行顺序
D. C++ 支持循环语句和条件分支语句

答案：C
解析：C++ 不仅有顺序结构，还支持选择结构（if/else）和循环结构（for/while），可以改变执行顺序。C 说"只能按从上到下"完全抹杀了条件分支和循环，这是严重错误的理解。
判断题 8 （文件操作）

在 Windows 中，可以使用 Ctrl+C 复制文件，再用 Ctrl+V 将其粘贴到另一个文件夹中。

答案：✅ 正确
解析：Ctrl+C 复制、Ctrl+V 粘贴是 Windows 中最基本的文件操作快捷键，适用于文件、文件夹、文本等内容。实际考试中也可能会变着问 Ctrl+X（剪切）。
判断题 9 （注释的作用）

C++ 程序中注释写得越多，程序运行的速度就越慢。

答案：❌ 错误
解析：注释在编译阶段会被编译器完全忽略，不会进入最终的可执行文件。因此注释的多少对程序运行速度没有任何影响。注释的目的只是帮助程序员阅读和理解代码。
判断题 10 （智能设备）

智能手表是一种内嵌计算机系统、具备独立计算能力的可穿戴设备。

答案：✅ 正确
解析：智能手表内部有处理器、内存、操作系统，是一个完整的微型计算机系统，属于可穿戴计算设备。考试中常考"XX 是不是计算机/有没有操作系统"这类判断。

输出设备显示器、打印机、扬声器
处理器 (CPU)执行计算和逻辑判断
存储器内存（临时）、硬盘（永久）
IDE 流程编辑 → 编译 → 运行 → 调试
GESP 语言Scratch / Python / C++
操作系统Windows、macOS、Linux、鸿蒙 OS；管理硬件资源
编译器g++；高级语言 → 机器指令
C++ 程序入口main 函数
三大程序结构顺序、选择（if/else）、循环（for/while）
📌 考前必看

传感器 = 输入设备，这是 GESP 一级出现频率最高的一条。只要题面出现"传感器"，90% 以上考的是输入设备。另外，操作系统 ≠ 编译器，这也是出题人最爱挖的坑。
