1 第一步：生活引入 — 直观比喻

🎯 场景比喻：计算机就像一套完整的办公系统

想象你走进一个现代化的办公室。你需要 硬件设备（电脑主机、显示器、键盘），也需要 操作系统（Windows/macOS），还需要 应用软件（Word、浏览器、微信）。三者缺一不可！

计算机也是一样：硬件 是物质基础（CPU、内存、硬盘），操作系统 是资源管家，App（应用软件） 是用户直接使用的工具。理解了这三层关系，就掌握了计算机体系结构的基础框架。

就像你不能说"Word就是一个操作系统"一样，Dev C++ 也不是操作系统——它只是一个帮助程序员写代码的 IDE（集成开发环境）！

✅ GESP认证基本信息

GESP（Grade Examination of Software Programming）是CCF主办的编程能力等级认证。GESP提供 三种编程语言 供考生选择：

  • C++ — 竞赛与系统开发首选
  • Python — 数据科学与人工智能常用
  • Scratch — 图形化编程入门

核心原则：GESP认证的是编程能力等级，同一级别的能力基本与编程语言无关。

🔷 闰年判断规则
闰年判断条件：
(year % 400 == 0) || (year % 4 == 0 && year % 100 != 0)

即：能被400整除的年份是闰年；能被4整除但不能被100整除的年份也是闰年。

记忆口诀：四年一闰，百年不闰，四百年再闰。

3 第三步：代码详解

📝 闰年判断C++代码
cpp
#include <iostream>
using namespace std;

int main() {
    int year;
    cin >> year;
    
    // 闰年判断：能被400整除，或能被4整除但不能被100整除
    if ((year % 400 == 0) || (year % 4 == 0 && year % 100 != 0)) {
        cout << year << " 是闰年" << endl;
    } else {
        cout << year << " 不是闰年" << endl;
    }
    
    return 0;
}
📐 逻辑表达式求值
表达式拆解结果
(5 <= 5) && (7 < 5)true && falsefalse
!(10 > 5)!truefalse
(10 != 10) || (5 >= 3)false || truetrue
(5 == 3) && (4 > 2)false && truefalse

核心规则：&&（逻辑与）两边都为 true 才为 true；||（逻辑或）只要有一边为 true 就为 true；!（逻辑非）取反。

4 第四步：手工模拟 — 流程图解读

📐 闰年判断流程图解读

对于闰年判断的流程图，核心是理解 菱形判断框 中的条件表达式。以输入 2024 为例：

步骤判断条件2024的结果走向
①yr % 400 == 02024 % 400 = 24 ≠ 0 → false继续判断
②yr % 4 == 02024 % 4 = 0 → true继续判断
③yr % 100 != 02024 % 100 = 24 ≠ 0 → true输出"闰年"

关键理解：流程图中的菱形框使用 ||（或）连接两个大条件。只要yr%400==0成立，或 yr%4==0 && yr%100!=0同时成立，就走"是"分支。

5 第五步：常见陷阱

⚠️ 陷阱1：'3' ≠ 3

字符常量 '3' 的ASCII值是 51，不是整数3！在C++中 '3' 和 3 是两个完全不同的值。字符类型占1字节，int类型占4字节。

⚠️ 陷阱2：哥德巴赫猜想不可枚举证明

哥德巴赫猜想：任一大于2的偶数都可写成两个素数之和。这是一个 尚未被严格证明 的猜想，不能通过枚举法来证明。枚举法只能验证有限范围，不能证明无限范围。

⚠️ 陷阱3：Dev C++不是操作系统

Dev C++是 IDE（集成开发环境），属于应用软件。操作系统是管理硬件资源的系统软件（如Windows、Linux）。不能将IDE和操作系统混为一谈！

⚠️ 陷阱4：char的符号性是平台相关的

C++标准规定 char 的符号性由具体实现决定。有的平台上 char 是 signed char（-128~127），有的平台上是 unsigned char（0~255）。不能假定它总是 -128 到 127！

6 第六步：真题实战

选择题

第1题 · App概念（2023/09 第1题）

人们所使用的手机上安装的App通常指的是（ ）

A. 一款操作系统   B. 一款应用软件   C. 一种通话设备   D. 以上都不对

答案：B
解析：App是Application的缩写，即应用软件。操作系统是系统软件，如Android、iOS。
第2题 · GESP认证语言（2024/06 第1题）

小杨父母带他到某培训机构给他报名参加CCF组织的GESP认证考试的第1级，那他可以选择的认证语言有（ ）种。

A. 1   B. 2   C. 3   D. 4

答案：C
解析：GESP认证提供C++、Python、Scratch三种语言。
第3题 · 闰年判断（2024/06 第2题）

下面流程图在yr输入2024时，可以判定yr代表闰年。菱形框中应该填入（ ）

A. (yr%400==0) || (yr%4==0)
B. (yr%400==0) || (yr%4==0 && yr%100!=0)
C. (yr%400==0) && (yr%4==0)
D. (yr%400==0) && (yr%4==0 && yr%100!=0)

答案：B
解析：闰年判断的正确表达式为 (yr%400==0) || (yr%4==0 && yr%100!=0)。四年一闰，百年不闰，四百年再闰。
第4题 · 逻辑表达式（2025/09 第2题）

下列C++表达式的结果为 true 的是（ ）

A. (5 <= 5) && (7 < 5)
B. !(10 > 5)
C. (10 != 10) || (5 >= 3)
D. (5 == 3) && (4 > 2)

答案：C
解析：C中 (10!=10) 为false，但 (5>=3) 为true，|| 运算结果为true。A: true&&false=false；B: !true=false；D: false&&true=false。
第5题 · 进制概念（2023/09 补充）

下列关于进制的叙述，正确的是（ ）

A. 只有十进制和二进制能够用来表示小数，八进制和十六进制不可以。
B. 常用的进制包括二进制、八进制、十进制、十六进制，其他进制在日常生活中很少使用。
C. 对任意正整数，其二进制表示不会比它的十进制表示更短。
D. 正整数的八进制表示中，每一位可能出现的最大数字是8。

答案：C
解析：二进制只有0和1，表示同等数值需要更多位数。D错，八进制每位最大数字是7（不是8）。八进制和十六进制也可以表示小数。
第6题 · 函数概念（2025/09 第12题）

以下关于C++函数的描述，正确的是（ ）

A. 函数必须要有参数。
B. 函数通过 return 语句只能返回一个值。但是可以通过很多间接的方式返回多个值。
C. main 函数可以被其他函数调用。
D. 函数的定义可以直接嵌套，即一个函数内部可以真正定义另一个函数。

答案：B
解析：A错，函数可以无参数；B正确；C错，main不能被其他函数调用；D错，C++不允许函数嵌套定义。

判断题

判断题第1题 · 字符与整数

字符常量 '3' 的值和 int 类型常量 3 的值是相同的，只是占用的字节数不同。（ ）

答案：错误
'3'的ASCII值是51，不等于3。
判断题第2题 · 哥德巴赫猜想

著名的哥德巴赫猜想：任一大于2的偶数都可写成两个素数之和。我们可以通过枚举法来证明它。（ ）

答案：错误
哥德巴赫猜想尚未被严格证明，不能通过枚举法证明（枚举只能验证有限范围）。
判断题第3题 · Dev C++与操作系统

小杨最近在准备考GESP，他用的Dev C++来练习和运行程序，所以Dev C++也是一个小型操作系统。（ ）

答案：错误
Dev C++是IDE（集成开发环境），属于应用软件，不是操作系统。
判断题第4题 · GESP认证与编程语言

GESP测试是对认证者的编程能力进行等级认证，同一级别的能力基本上与编程语言无关。（ ）

答案：正确
GESP认证的是编程能力等级，与所选语言无关。
判断题第5题 · 整除判断

C++语句 cout<<(n%15==0? "YES":"NO"); 能够判断一个整数能否被3和5同时整除。（ ）

答案：正确
能被3和5同时整除等价于能被15整除（3×5=15，且3和5互质）。
判断题第6题 · 组合计数

有n个同学，从中抽取任意个人数来参加学校组织的大合唱，共有2的n次幂个方法。（ ）

答案：正确
每个同学可选可不选（2种选择），共2^n种组合（含空集）。
判断题第7题 · 枚举的底层类型

在C++中，枚举的底层类型可以是非整型（如 float 或 double）。（ ）

答案：错误
枚举的底层类型必须是整型，不能是float或double。
判断题第8题 · 全局变量初始化

在C++中，所有全局变量如果没有显式初始化，都会被自动初始化为0。（ ）

答案：正确
全局变量在程序启动时被静态初始化为0。
判断题第9题 · 前置与后置自增

在C++中，++i 是一个左值表达式，而 i++ 是一个右值表达式。（ ）

答案：正确
++i返回自增后自身的引用（左值），i++返回自增前的临时值（右值）。
判断题第10题 · char的取值范围

在C++中，char 类型的取值范围总是 -128 到 127。（ ）

答案：错误
char的符号性由实现定义，可以是有符号(-128~127)或无符号(0~255)，取决于编译器和平台。
判断题第11题 · 头文件引用

#include "file.h" 和 #include<file.h> 在编译器查找头文件时的搜索策略是完全相同的。（ ）

答案：错误
引号形式先搜索当前目录再去系统目录，尖括号形式只搜索系统目录。
判断题第12题 · 宏定义陷阱

#define SQUARE(x) x * x 是一个安全的宏定义，SQUARE(2+3)会正确计算出25。（ ）

答案：错误
宏展开为 2+3*2+3=11，不是25。应改为 #define SQUARE(x) ((x)*(x))。
