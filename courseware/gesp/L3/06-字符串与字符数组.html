1 第一步：生活引入 — string vs char[]

🌍 场景比喻

想象你出门旅行，带了两种行李箱：

  • string 像 智能行李箱，能自动调节大小。你往里塞再多东西，它都能自动扩容。而且它有各种智能功能：找东西(find)、剪掉某段(erase)、插入新物品(insert)。
  • char[] 像 固定尺寸的鞋盒，空间是预先定好的。超过容量就会溢出，就像鞋盒撑破。操作也需要手动：复制要strcpy、拼接要strcat、比较要strcmp。

string是C++的现代字符串工具，char[]是C语言时代的遗产。考试中两者都会考，重点是了解各自的操作方式和陷阱。

🌍 ASCII码回顾（来源：进制转换章节）
字符类型范围示例
数字字符 '0'~'9'ASCII 48~57 (0x30~0x39)'0'=48, '5'=53
大写字母 'A'~'Z'ASCII 65~90 (0x41~0x5A)'A'=0x41=65, 'L'=0x4C=76
小写字母 'a'~'z'ASCII 97~122 (0x61~0x7A)'a'=97, 'z'=122

关键规律：'A'=0x41=65，依次递增；'a'='A'+32=97；数字字符=48+数字值；大小写差=32；字符常量'3'(值51) ≠ 整数常量3。

3 第三步：代码详解

3.1 string类完整操作

💻 string类操作完整代码
cpp
#include <iostream>
#include <string>
using namespace std;

int main() {
    string s = "C++ Programming";
    
    // 1. 长度
    cout << s.length() << endl;        // 15（含空格）
    
    // 2. 查找：find返回首次出现下标
    cout << s.find("Pro") << endl;     // 4
    cout << s.find("++") << endl;      // 1
    // 未找到返回 string::npos（等于 -1）
    cout << (int)s.find("XYZ") << endl; // -1
    
    // 3. 截取：substr(起始位置, 长度)
    cout << s.substr(0, 3) << endl;    // "C++"
    cout << s.substr(4) << endl;       // "Programming"
    
    // 4. 删除：erase(起始位置, 长度)
    string t = s;
    t.erase(0, 4);                       // 删除"C++ "
    cout << t << endl;                  // "Programming"
    
    // 5. 插入：insert(位置, 字符串)
    t.insert(0, "Hello ");
    cout << t << endl;                  // "Hello Programming"
    
    // 6. 替换：replace(起始, 长度, 新串)
    s.replace(4, 11, "World");
    cout << s << endl;                  // "C++ World"
    
    // 7. 赋值和拼接
    string a = "Hello", b = "World";
    string c = a + " " + b;              // 拼接
    cout << c << endl;                  // "Hello World"
    
    // 8. 比较（比较的是内容！）
    if (a == b) cout << "equal" << endl;
    else cout << "not equal" << endl;
    
    return 0;
}

3.2 字符数组操作代码

💻 字符数组操作代码
cpp
#include <iostream>
#include <cstring>
using namespace std;

int main() {
    // 字符数组定义与初始化
    char s1[100] = "Hello";  // 预留足够空间！
    char s2[] = "World";
    
    // 1. 长度（不含'\0'）
    cout << strlen(s1) << endl;        // 5
    cout << strlen("Hello") << endl;    // 5
    
    // 2. 比较（字典序）
    cout << strcmp("abc", "abd") << endl;  // 负数（abc<abd）
    cout << strcmp("abc", "abc") << endl;  // 0（相等）
    cout << strcmp("abd", "abc") << endl;  // 正数（abd>abc）
    
    // 3. 拼接：strcat(s1, s2)
    strcat(s1, s2);    // s1 = "HelloWorld"
    cout << s1 << endl;
    // ⚠️ s1必须有足够空间容纳s1+s2+'\0'！
    
    // 4. 拷贝：strcpy(s1, s2)
    strcpy(s1, "C++");
    cout << s1 << endl;    // "C++"
    
    // 5. ⚠️ 错误示例：不能用==比较内容！
    char a[] = "hello", b[] = "hello";
    if (a == b)  // 比较的是地址！不是内容！
        cout << "same addr" << endl;
    else
        cout << "diff addr" << endl;  // 输出这个！
    
    // 正确比较：
    if (strcmp(a, b) == 0)
        cout << "same content" << endl;
    
    return 0;
}

3.3 字符判断与转换代码

💻 字符判断与转换完整代码
cpp
#include <iostream>
#include <cctype>
using namespace std;

int main() {
    char c = 'a', d = '5', e = 'G';
    
    // 字符判断（返回非0为真，0为假）
    cout << isalpha(c) << endl;   // 是字母？→ 非0（真）
    cout << isdigit(d) << endl;   // 是数字？→ 非0（真）
    cout << islower(c) << endl;   // 是小写？→ 非0（真）
    cout << isupper(e) << endl;   // 是大写？→ 非0（真）
    
    // 字符转换（返回int，需(char)转换）
    cout << (char)toupper(c) << endl;  // 'A'
    cout << (char)tolower(e) << endl;  // 'g'
    
    // 实用技巧：大小写互转
    // 大写 → 小写：+32
    // 小写 → 大写：-32
    char x = 'A' + 32;  // x = 'a'
    char y = 'z' - 32;  // y = 'Z'
    
    // 遍历字符串中的字符判断
    string s = "Hello123";
    for (char ch : s) {
        if (isalpha(ch)) cout << ch << "是字母 ";
        if (isdigit(ch)) cout << ch << "是数字 ";
    }
    
    return 0;
}

5 第五步：常见陷阱

⚠️ 陷阱1：char[]用==比较的是地址！

这是最高频的坑！

cpp
char a[] = "hello";
char b[] = "hello";
if (a == b)   // ❌ 比较的是两个数组的首地址！
    // a和b是不同的数组，地址不同
    // 即使内容相同，== 也返回 false！
    
// ✅ 正确做法：
if (strcmp(a, b) == 0)  // 比较内容

注意：string对象用==比较的是内容，char[]用==比较的是地址！字符数组比较内容必须用strcmp。

⚠️ 陷阱2：strcat需要足够空间！

strcat(s1, s2) 将s2拼接到s1末尾，但s1必须有足够空间容纳拼接后的完整字符串+'\0'。

cpp
// ❌ 危险：s1空间不够
char s1[6] = "Hello";  // 只能存5个字符+'\0'
strcat(s1, "World");   // 溢出！需要6+5+1=12字节

// ✅ 正确：预留足够空间
char s1[100] = "Hello";
strcat(s1, "World");   // 安全

后果：空间不足会导致内存越界，程序可能崩溃或产生奇怪结果。

⚠️ 陷阱3：string::npos等于-1

find()找不到时返回 string::npos，这是一个常量：

cpp
string s = "hello";
cout << (int)s.find('x') << endl; // 输出 -1
// string::npos 实际上就是 -1

// 判断是否找到：
if (s.find('x') == string::npos)
    cout << "not found" << endl;

// ⚠️ 常见错误：用 >=0 判断
if (s.find('x') >= 0)  // ❌ -1 >= 0 为false，逻辑反了！
    cout << "found" << endl;

正确判断：if (s.find(x) != string::npos) 表示找到了。

⚠️ 陷阱4：toupper/tolower返回int

这两个函数返回的是int类型，直接输出会打印ASCII值而不是字符：

cpp
cout << toupper('a') << endl;       // 输出 65（不是'A'！）
cout << (char)toupper('a') << endl; // 输出 'A' ✓
⚠️ 陷阱5：字符常量 vs 整数常量

'3'的ASCII值是51，不等于整数3：

cpp
cout << ('3' == 3) << endl;  // 0（false），'3'=51≠3
cout << ('3' - '0') << endl;  // 3，字符转数字的技巧
⚠️ 陷阱6：strlen不含'\0'

strlen("Hello") 返回 5（不是6），不包含结尾的'\0'。同理 string.length() 也不含'\0'。

但定义char数组时，char s[6] = "Hello" 需要6字节（5字符+1个'\0'）。

6 第六步：真题实战

📚 来源：2024/12 第11题 · string vs char[] 对比题

以下关于C++中 string 类和字符数组（char[]）的说法，错误的是（ ）

A. string 对象可以使用 = 进行赋值，而字符数组需要使用 strcpy。
B. string 对象的长度可以使用 length() 成员函数获取，而字符数组需要使用 strlen() 函数。
C. string 对象在内存中是动态分配空间的，因此可以自动处理字符串长度的变化。
D. string 对象和字符数组都可以使用 == 运算符来直接比较两个字符串的内容是否相同。

答案：D
解析：D错误，字符数组用==比较的是地址，不是内容！string可以用==比较内容，但char[]必须用strcmp比较内容。这是考试中的高频陷阱。
📚 来源：2025/12 第5题 · length()题目

已知字符串 s = "C++ Programming"，下列程序运行的结果是（ ）

cpp
cout << (int)(s.length() | 3) << endl;

A. 14   B. 15   C. 16   D. 17

答案：B
解析：s.length() = 15（含空格），15的二进制=1111，3的二进制=0011，15|3 = 1111|0011 = 1111 = 15。注意空格也算一个字符！
📚 来源：2025/06 第9题 · 字符串字符判断综合

以下代码运行后，sum 的结果是（ ）

cpp
int arr[5] = {2, 4, 6, 8, 10};
int sum = 0;
for (int i = 0; i < 5; i++) {
    switch (arr[i] % (1|2)) {
        case 0: sum += 1; break;
        case 1: sum += 2; break;
        case 2: sum += 3; break;
    }
}

A. 10   B. 11   C. 14   D. 15

答案：B
解析：1|2=3。arr[0]=2, 2%3=2, sum=3。arr[1]=4, 4%3=1, sum=5。arr[2]=6, 6%3=0, sum=6。arr[3]=8, 8%3=2, sum=9。arr[4]=10, 10%3=1, sum=11。
📚 来源：2024/09 · 字符码值比较

C++的字符变量的码值是整数，下面字面量形式的字符码值最大的是（ ）

A. 100   B. 075   C. 0x70   D. 0x60

答案：C
解析：A=100（十进制），B=075（八进制=61），C=0x70（十六进制=112），D=0x60（十六进制=96）。最大为0x70=112。
📚 来源：2023/09 第3题 · ASCII编码

已知大写字符 'A' 的ASCII编码的十六进制表示为 0x41，则字符 'L' 的ASCII编码的十六进制表示为（ ）

A. 4A   B. 4B   C. 4C   D. 52

答案：C
解析：A=0x41，L是第12个字母（A=1, B=2, ..., L=12），L的ASCII = 0x41 + (12-1) = 0x41 + 11 = 0x4C。大写字母的ASCII码按字母顺序递增。
第6题 · 字符变量强转int（2026/03 第1题）

答案：C
解析：字符'1'的ASCII码是49，(int)强转得到的是ASCII码值，不是数字1。要得到数字1需要用 ch - '0'。

📚 练习：strcmp返回值

下列表达式的结果是什么？

cpp
strcmp("abc", "abd");  // ?

strcmp("ABC", "abc");  // ?
答案：

📚 练习：substr和erase组合

下面的代码执行后，s的值是什么？

cpp
string s = "Hello World";
s.erase(5, 1);         // 删除空格
s.insert(5, ", ");     // 插入逗号空格
s.replace(0, 5, "Hi"); // 替换前5个字符
