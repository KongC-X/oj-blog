1 第一步：生活引入 — 直观比喻

🎯 场景比喻

想象你有一个数字手表，显示范围是 -999 到 999。你怎么表示负数呢？最简单的方法是在前面加个负号。计算机也是这样——它用 最高位 作为符号位：0表示正数，1表示负数。这就是 原码 的思路。

但原码有个问题：用原码算 1+(-1)，结果是 -2！这显然不对。于是数学家们发明了 补码，让减法变成加法，用同样的电路就能完成所有计算。

2 第二步：核心概念

🔵 三种编码对比
编码方式正数负数示例(-5)
原码符号位0 + 数值符号位1 + 数值1000 0101
反码等于原码符号位不变，其余取反1111 1010
补码等于原码反码 + 11111 1011
✅ 核心规则（必背）
正数：原码 = 反码 = 补码
负数：补码 = 反码 + 1（反码 = 原码符号位不变，其余取反）

补码意义：将减法转化为加法，简化计算机硬件设计。

8位有符号范围：补码 -128 ~ 127，原码 -127 ~ 127。

反码零：有两种表示（+0: 0000 0000，-0: 1111 1111）。

3 第三步：代码详解

📝 验证补码的C++代码
cpp
#include <iostream>
using namespace std;

int main() {
    int a = -5;
    // 在计算机中，-5 以补码存储
    // -5 的 16 位补码：FFFB（十六进制）
    // 推导：
    // 原码: 1000 0000 0000 0101
    // 反码: 1111 1111 1111 1010  （符号位不变，其余取反）
    // 补码: 1111 1111 1111 1011  （反码 + 1）
    
    // 验证：补码转真值
    // 符号位为1 → 先求补码（取反+1）→ 得正数值 → 加负号
    
    cout << "计算机用补码存储整数" << endl;
    return 0;
}

4 第四步：手工模拟

📐 手算补码练习

以 -5 的 16 位补码 为例：

步骤操作结果
① 原码符号位1 + 数值5=01011000 0000 0000 0101
② 反码符号位不变，其余取反1111 1111 1111 1010
③ 补码反码 + 11111 1111 1111 1011
④ 十六进制每4位转1个十六进制FFFB

补码转真值：符号位为1 → 取反+1 → 得正数 → 加负号；符号位为0 → 直接等于真值。

5 第五步：常见陷阱

⚠️ 陷阱1：正数的反码和补码

正数的原码=反码=补码，完全相同！所以"任意整数的反码与补码都至少有一位不同"是 错误 的。

⚠️ 陷阱2：原码 vs 补码的范围

8位原码范围：-127~127（因为±0各占一个编码），8位补码范围：-128~127（只有一种0）。问"8位二进制原码最小整数"答案是 -127 不是-128！

⚠️ 陷阱3：负数的反码是所有位取反

负数的反码是 符号位不变，其余位取反！不是所有位都取反。如果所有位取反，符号位也变了。

6 第六步：真题实战

第1题 · 补码表示（2024/03 第1题）

整数-5的16位补码表示是（ ）

A. 1005   B. 1006   C. FFFA   D. FFFB

答案：D
解析：-5的原码=1000 0000 0000 0101，反码=1111 1111 1111 1010，补码=1111 1111 1111 1011=FFFB。
第2题 · 原码与补码转换（2024/12 第1题）

下列二进制表示的十进制数值分别是：[10000011]原=（ ），[10000011]补=（ ）

A. -125，-3   B. -3, -125   C. -3，-3   D. -125，-125

答案：B
解析：[10000011]原 = -(1×2¹+1×2⁰) = -3；[10000011]补 → 取反=01111100，+1=01111101=125 → 真值=-125。
第3题 · 编码概念（2024/09 第2题）

关于计算机中的编码，下列说法中正确的是（ ）

A. 机器数的形式值和真值是一致的
B. 原码就是符号位加上真值
C. 机器数是带符号的
D. [-1]=[1000 0001]原=[1111 1111]反

答案：C
解析：A错，机器数可能是补码形式；B错，负数原码的真值不含符号位；C正确；D错，[-1]反=[1111 1110]。
第4题 · 编码错误说法（2024/12 第2题）

关于计算机中的编码，下列说法中错误的是（ ）

A. 对于无符号数，原码就是真值
B. 正数的反码是其本身
C. 负数的反码和补码是不一样的
D. 负数的反码，在其原码的基础上，各个位取反

答案：D
解析：D错误，负数的反码是符号位不变，其余位取反，而非所有位都取反。
第5题 · 补码作用（2025/03 第5题）

在C++中，补码的主要作用是（ ）

A. 提高浮点数的精度   B. 简化整数的加减法运算
C. 增加整数的表示范围   D. 优化内存分配

答案：B
解析：补码的核心作用是将减法转化为加法，从而简化计算机硬件电路设计。
第6题 · 8位原码范围（2025/06 第1题）

8位二进制原码能表示的最小整数是（ ）

A. -127   B. -128   C. -255   D. -256

答案：A
解析：8位原码：1位符号位+7位数值位，范围 -127 到 127。补码范围才是 -128 到 127。
第7题 · 反码的零（2025/06 第2题）

反码表示中，零的表示形式有（ ）

A. 1种   B. 2种   C. 8种   D. 16种

答案：B
解析：反码中 +0 = 0000 0000，-0 = 1111 1111，共两种表示。
第8题 · 补码转真值（2025/06 第3题）

补码 1011 1011 对应的真值是（ ）

A. -69   B. -59   C. -68   D. -58

答案：A
解析：符号位为1，先求补码：取反=0100 0100，+1=0100 0101=69，真值=-69。
第9题 · 补码右移（2025/06 第4题）

若X的8位补码为 0000 1010，则 X/2 的补码是（ ）

A. 0000 0101   B. 1000 0101
C. 0000 0101 或 1000 0101   D. 算术右移后结果取决于符号位

答案：A
解析：X=10，X/2=5，5的补码=0000 0101。正数右移一位等价于除以2。
第10题 · Base64（2025/03 第1题）

Base64编码将每3字节输入编码为4字节输出，输入10字节时输出长度是（ ）

A. 12字节   B. 13字节   C. 14字节   D. 16字节

答案：D
解析：10÷3=3组余1字节。3组→12字节输出，余1字节→填充2字节凑3→再输出4字节。共12+4=16字节。
第11题 · 八进制原码（2025/03 第3题）

在8位二进制原码表示中，八进制数-5的二进制形式是（ ）

A. 10000101   B. 11111010   C. 11111011   D. 00000101

答案：A
解析：八进制5=二进制101，原码-5=1 0000101=10000101。
第12题 · 十六进制补码（2024/03 第2题）

如果16位短整数-2的二进制是"FFFE"，则短整数-4的十六进制是（ ）

A. FF04   B. FFFA   C. FFFC   D. FFFH

答案：C
解析：-2补码=FFFE，-4补码 = FFFE - 2 = FFFC。
第13题 · 32位int范围（2024/06 第3题）

一般默认64位计算机系统中整型变量（int）还是32位，则整数能够表示的数据范围是（ ）

A. -32768 ~ 32767   B. 0 ~ 4294967295
C. -2147483648 ~ 2147483647   D. -9223372036854775808 ~ 9223372036854775807

答案：C
解析：32位int范围是 -2³¹ ~ 2³¹-1 = -2147483648 ~ 2147483647。
第14题 · 补码计算（2026/03 第5题）

8位二进制下，十进制数-15的补码是（ ）

A. 1111 0000   B. 0000 1111
C. 1111 1111   D. 1111 0001

答案：D
解析：15=0000 1111，取反=1111 0000，+1=1111 0001，即-15的补码。

+1和-1的原码进行1+（-1）计算的结果是-2。（ ）

(+1)原=0000 0001，(-1)原=1000 0001，相加=1000 0010=-2。这正是需要补码的原因。
