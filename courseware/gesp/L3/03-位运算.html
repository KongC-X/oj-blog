1 第一步：生活引入 — 灯泡开关比喻

理解二进制位

把二进制位（bit）想象成一个灯泡开关：

灯泡状态意义二进制值
🔴 亮（On）开关打开、通电1
⚫ 灭（Off）开关关闭、断电0

一个字节有 8 个灯泡（8 位），可以表示 256 种状态。C++ 的 int 类型通常是 32 个灯泡（32 位）。

位运算 = 同时控制多盏灯

按位与 & → 两盏灯都亮才亮（串联开关）

按位或 | → 至少一盏灯亮就亮（并联开关）

按位异或 ^ → 两盏灯状态不同才亮（"矛盾检测器"）

按位取反 ~ → 把所有灯的状态翻转（亮变灭，灭变亮）

左移 << → 把所有灯向左挪位，右边空位填 0

右移 >> → 把所有灯向右挪位，正数左边补 0，负数左边补 1

2 第二步：核心概念 — 按位运算符表

C++ 位运算符全景
运算符名称运算规则示例结果
&按位与两个位都为1时结果为15 & 31
|按位或两个位都为0时结果为05 | 37
^按位异或两不同为1，相同为05 ^ 36
~按位取反0变1，1变0；~x = -(x+1)~5-6

⚠ 关键规则

位运算以补码形式进行计算。有负数参与时先用补码运算，结果符号位为 1 则需再求一次补码才能得到真值。

3 第三步：代码详解 — 异或交换两数

核心考点 · 三次异或交换

异或运算满足交换律、结合律，且 x ^ x = 0、x ^ 0 = x。利用这两个性质，可以用三次异或实现无临时变量的交换。

C++ 
#include <iostream>
using namespace std;

int main() {
    // 异或交换两数（无需临时变量）
    int a = 5, b = 10;
    
    a = a ^ b;   // Step 1: a = 5 ^ 10
    b = a ^ b;   // Step 2: b = (5 ^ 10) ^ 10 = 5 ^ 0 = 5
    a = a ^ b;   // Step 3: a = (5 ^ 10) ^ 5 = 0 ^ 10 = 10
    
    cout << "a = " << a << ", b = " << b << endl;
    // 输出: a = 10, b = 5   ← 成功交换！
    return 0;
}
异或交换的注意事项

如果 a 和 b 是同一个变量（如通过引用传入），异或交换会将值清零：

C++ 
void Swap(int &a, int &b) {
    if (a != b) {      // ← 必须判断 a != b！
        a ^= b;
        b ^= a;
        a ^= b;
    }
}

5 第五步：常见陷阱 — 这些坑不要踩

陷阱 1：负数位移用补码表示

负数在计算机中以补码存储。对负数进行位移时，必须先将其转换为补码再操作：

  • 负数左移：补码整体左移，低位补 0，移动后结果仍为补码
  • 负数右移：补码整体右移，高位补 1（算术右移，保持符号）

示例：int x = -5; x << 1 → -10，-10 >> 1 → -5（恢复！）

陷阱 2：位运算符优先级低于算术和关系运算符

位运算符 &、|、^、<<、>> 的优先级低于算术运算符（+ - * / %），也低于关系运算符（== != < >）。

⚠ 优先级陷阱示例

a == b & c 会被解析为 (a == b) & c，而非 a == (b & c)

a + b << 1 会被解析为 (a + b) << 1

最佳实践：位运算与算术运算混合使用时，一律加括号明确运算顺序，避免优先级导致的隐蔽 bug。

判断题（13道真题）

判断题 1（高频考点）

在C++语言中，位运算符也有类似"先乘除、后加减"的优先级规则。因此，使用时应注意合理使用括号。（ ）

答案：对 位运算符之间确实有优先级顺序，但与算术运算符混用时容易混淆，应养成加括号的习惯。
判断题 2（高频考点）

在C++语言中，所有 int 类型的值，经过若干次左移操作（<<）后，它们的值总会变为 0。（ ）

答案：对 持续左移会把有效位数全部移出，最终变为0。
判断题 3（高频考点）

如果 a 为 int 类型的变量，且表达式 ((a & 1) == 0) 的值为 true，则说明 a 是偶数。（ ）

答案：对 a&1 检查最低位，最低位为0表示偶数，为1表示奇数。
判断题 4（高频考点）

执行C++代码 cout << (5 && 2) << endl; 后将输出 1。（ ）

答案：对 && 是逻辑与，5和2都非零，结果为true(1)。注意这是逻辑与，不是按位与。
判断题 5（高频考点）

执行C++代码 cout << (5 || 2); 后将输出 1。（ ）

答案：对 || 是逻辑或，5非零，短路求值直接返回true(1)。
判断题 6（高频考点）

对整型变量 int a = 3，执行C++代码 a << 2 将把 2 输出到 a 中。（ ）

答案：错 a<<2 是表达式，值为12，但不改变 a 本身。a 仍然是3。
判断题 7（高频考点）

一个 int 类型变量 a，执行操作 (a << 2 >> 2) 后的值一定是 a。（ ）

答案：错 如果a的高位有值，左移时高位可能丢失（溢出），右移时补的是符号位或0，不一定恢复原值。
判断题 8（高频考点）

在C++语言中，(010 << 1) 执行结果是 100。（ ）

答案：错 010 是八进制数 = 8（十进制），8<<1=16，不是100。
判断题 9（高频考点）

~1 的输出值是 -2。（ ）

答案：对 ~x = -(x+1)，~1 = -(1+1) = -2。
判断题 10（高频考点）

~1 = 1111 1110（ ）

答案：对 1 = 0000 0001（8位），取反得 1111 1110。
判断题 11（高频考点）

取 X 的低四位，可以用 Y = 0000 1111，用 X & Y 获取 X 的低四位。（ ）

答案：对 掩码 0000 1111 使高四位清零，低四位保留。这是位运算中常用的掩码技巧。
判断题 12（高频考点）

(x & 1) == 0 可以判断整数 x 是否为偶数。（ ）

答案：对 x&1 取最低位，0表示偶数，1表示奇数。比 x%2==0 执行更快。
判断题 13（高频考点）

位运算符 &、|、^、~ 的优先级高于算术运算符 +、-、*、/。（ ）

答案：错 位运算符优先级低于算术运算符。例如 a+b>>1 等价于 (a+b)>>1。
