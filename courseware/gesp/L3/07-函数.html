1 第一步：生活引入 — 直观比喻

🎯 场景比喻：函数就像一台自动售货机

想象你去买饮料：投币（输入参数） → 售货机内部机械运转（函数体处理） → 一瓶饮料掉出来（返回结果）。

函数也是一样：你给函数输入数据，它按照既定的逻辑处理数据，最终输出一个结果给你。你不需要关心售货机内部齿轮怎么转——函数把复杂的细节封装起来，只暴露简洁的接口。

再比如计算器：你按下 max(3, 5) 就像按下计算器上的"取最大值"按钮，输入3和5，它返回5——简单、高效、可复用。

2 第二步：核心概念

🔵 函数定义语法
返回类型 函数名(参数列表) { 函数体 }

一个函数由四个部分组成：

组成部分说明示例
返回类型函数返回值的类型，无返回值写 voidint、void、double
函数名标识符，遵循命名规范max、findMax
参数列表接收输入数据，可以没有参数(int a, int b)
函数体{ } 内的代码，实现具体逻辑{ return a > b ? a : b; }
✅ 关键规则（必背）
  • 返回类型：C++11起必须显式声明返回类型，不允许默认返回 int。
  • 参数：函数可以没有参数，如 int getValue()。
  • return：只能返回一个值，但可通过引用参数间接返回多个值。
  • 变量作用域：for循环内声明的变量仅在该循环体有效；函数内局部变量仅在函数内有效。
  • 禁止嵌套定义：C++ 不允许在函数内部定义另一个函数。
🟣 参数传递与作用域
概念说明
形参（Parameter）函数定义时括号内的变量，在函数调用结束后释放内存
实参（Argument）调用函数时传入的具体值
局部变量在函数内部声明，仅在该函数内有效
全局变量在所有函数外部声明，整个程序有效
同名变量不同函数中的局部变量可以同名，代表不同内存单元

3 第三步：代码详解

📝 max 函数 — 返回两个整数中较大值
cpp
// 返回两个整数中较大值
int max(int a, int b) {
    if (a > b) return a;
    else return b;
}

int main() {
    cout << max(3, 5) << endl;   // 输出: 5
    cout << max(10, 7) << endl;  // 输出: 10
    return 0;
}

函数 max 接收两个 int 参数，用 if-else 比较大小后 return 较大值。高频考点：返回类型必须是 int 而非 void，因为需要 return 一个值。

📝 findMax 函数 — 查找数组中的最大值
cpp
// 查找数组最大值
int findMax(int arr[], int size) {
    int maxVal = arr[0];  // 初始化为第一个元素！
    for (int i = 1; i < size; i++) {
        if (arr[i] > maxVal) {
            maxVal = arr[i];
        }
    }
    return maxVal;
}

int main() {
    int arr[] = {1, 3, 5, 2, 4};
    cout << findMax(arr, 5) << endl;  // 输出: 5
    return 0;
}

易错点：maxVal 必须初始化为 arr[0]，不能初始化为 0！如果数组元素全为负数，初始化 0 会导致错误结果。

4 第四步：手工模拟

📐 手工模拟函数调用栈

以调用 max(5, 3) 为例，模拟函数调用的完整过程：

步骤操作内存状态
① 调用前main() 执行到 max(5, 3)main 栈帧活跃
② 传参实参 5 和 3 拷贝给形参 a 和 ba = 5, b = 3（max 栈帧内）
③ 执行函数体执行 if (a > b)：5 > 3 为 true进入 if 分支
④ returnreturn a; 返回 5返回值 5 传回调用处
⑤ 清理max 函数结束，形参 a、b 释放回到 main 栈帧，拿到结果 5

关键理解：函数调用时，系统为函数创建一个独立的栈帧存放局部变量和形参；函数返回后，该栈帧被销毁，所有局部变量释放内存。这就是为什么函数间的变量互不影响。

5 第五步：常见陷阱

⚠️ 陷阱1：void 函数不能 return 值

void max(int a, int b) { return a > b ? a : b; } — 编译错误！

void 表示"无返回值"，return 后面不能跟表达式。void 函数可以写 return;（空返回），但不能 return 值;。

⚠️ 陷阱2：C++ 不允许函数嵌套定义

你不能在一个函数内部定义另一个函数：

void outer() { void inner() { ... } } // 编译错误！

但可以在一个函数内部调用另一个函数（这是正常的函数调用）。

⚠️ 陷阱3：main 函数不能被其他函数调用

main 是程序的入口点，由操作系统调用。你不能在代码中显式调用 main 函数。任何尝试 main() 这样的调用都是错误的设计。

⚠️ 陷阱4：C++11 前默认返回 int（历史遗留）

在旧标准中，不写返回类型的函数默认返回 int。但 C++11 及之后 要求必须显式声明返回类型。GESP 考试以此为准！

写法 max(a, b) { ... }（无返回类型）在 C++11 后是错误的，必须写成 int max(int a, int b) { ... }。

6 第六步：真题实战

第1题 · 函数定义语法（2025/09 第5题）

要正确定义一个返回两个整数中较大值的函数 max，应该使用（ ）

A. void max(int a, int b) { return a > b ? a : b; }
B. int max(int a, int b) { if (a > b) return a; else return b; }
C. int max(a, b) { if (a > b) return a; else return b; }
D. void max(a, b) { cout << (a > b ? a : b); }

答案：B
解析：A错误，void函数不能用return返回值；B正确，返回类型和参数类型都声明完整；C缺少参数类型声明；D同样缺类型声明且void不应return值。
第2题 · 函数综合描述（2025/09 第12题）

以下关于C++函数的描述，正确的是（ ）

A. 函数必须要有参数。
B. 函数通过 return 语句只能返回一个值。但是可以通过很多间接的方式返回多个值。
C. main 函数可以被其他函数调用。
D. 函数的定义可以直接嵌套，即一个函数内部可以真正定义另一个函数。

答案：B
解析：A错，函数可以无参数（如 int foo()）；B正确；C错，main不能被其他函数调用；D错，C++不允许函数嵌套定义。
第3题 · 变量作用域（2025/09 第13题）

以下关于C++变量作用域的说法，错误的是（ ）

A. 在 for 循环语句中声明的变量，其作用域仅限于该循环体内。
B. 在函数内部声明的变量（局部变量），仅在函数内部有效。
C. 在所有函数外部声明的变量，在整个程序中都有效。
D. 不同函数中的局部变量可以同名，它们代表不同的内存单元。

答案：C
解析：C不严谨，static修饰的全局变量只在当前文件有效，不能说"在整个程序中"都有效。A、B、D均正确。
第4题 · 返回类型与参数（2025/09 第14题）

以下关于C++函数的说法，正确的是（ ）

A. 函数参数传递只有值传递一种方式。
B. 函数的形参在函数调用结束后依然占用内存空间。
C. 没有返回值的函数必须声明为 void 类型，且不能包含 return 语句。
D. C++11 及之后标准要求函数必须显式声明返回类型，不允许默认返回 int。

答案：D
解析：A错，还有引用传递等方式；B错，形参在调用结束后释放；C错，void函数可以有 return;（空返回）；D正确，这是C++11的重要规定。
第5题 · findMax 初始化（2026/03 第6题）

以下C++代码试图查找数组中的最大值，划线处应填入（ ）

cpp
int findMax(int arr[], int size) {
    int maxVal = ________; // 划线处
    for (int i = 1; i < size; i++) {
        if (arr[i] > maxVal) {
            maxVal = arr[i];
        }
    }
    return maxVal;
}

A. 0   B. arr[-1]   C. arr[0]   D. size

答案：C
解析：maxVal应初始化为第一个元素 arr[0]。若初始化为0，当数组元素全为负数时会得到错误结果0；arr[-1]越界；size不是数组元素。从 i=1 开始循环也印证了要用 arr[0] 作为初始值。

判断题第1题 · 返回类型转换

函数声明 double f(); 返回 int 时，会自动转换为 double。（ ）

答案：正确
如果函数的返回类型声明为 double，而实际 return 了一个 int 值，C++ 会自动将 int 隐式转换为 double 返回。
