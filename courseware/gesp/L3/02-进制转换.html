1 第一步：生活引入 — 进制就像不同的计量单位

从日常说起

你在生活中早已在使用不同"进制"：

  • 十进制：我们数数的方式 —— 10 个数字（0~9），逢十进一。
  • 二进制：开关只有两种状态（开/关），就像灯泡的亮与灭。
  • 时间：60 秒 = 1 分钟，60 分钟 = 1 小时 —— 某种意义上就是 60 进制。
  • 星期：7 天 = 1 周 —— 类 7 进制。

关键认知：计算机底层只有 0 和 1（二进制），但二进制读起来太长。八进制和十六进制是二进制的"缩写形式"，方便人类阅读。

3 位二进制 → 1 位八进制 | 4 位二进制 → 1 位十六进制

思考：为什么计算机用二进制，而不是我们熟悉的十进制？你可以试着想想「开关」和「0~9 十种状态」哪个更容易实现。

3 第三步：代码详解 — 十进制转 R 进制

核心模板 — 考场必背

输入十进制数 N 和进制 R（2 ≤ R ≤ 36），输出 N 的 R 进制表示。

C++ 
#include <iostream>
using namespace std;

// 数字转字符：0-9 → '0'-'9'，10-35 → 'A'-'Z'
char trans(int d) {
    if (d < 10) return (char)(d + '0');
    return (char)(d + 'A' - 10);
}

int main() {
    int n, r;
    cin >> n >> r;
    char res[30];    // 存储每一位结果
    int len = 0;

    // 除 R 取余 ← 高频考点！
    while (n > 0) {
        res[len] = trans(n % r);  // 取余数，转字符
        n /= r;                    // 除以 R
        len++;
    }

    // 倒序输出 ← 高频考点！
    for (int i = len - 1; i >= 0; i--)
        cout << res[i];
    cout << endl;
    return 0;
}
代码要点解析
  • trans() 函数：将余数（0~35）转换成对应字符。0~9 加 '0'，10~35 加 'A'-10。
  • while(n > 0)：不断除以 R，直到商为 0。注意此写法对 n=0 不输出任何内容，实际考试中可能需要单独处理。
  • 倒序输出：除 R 取余法产生的结果是逆序的（先得到的余数是低位），必须从 len-1 到 0 输出。
  • R 的范围：2 ≤ R ≤ 36，因为 10 个数字 + 26 个大写字母 = 36 个符号。

5 第五步：常见陷阱 — 这些坑不要踩

陷阱 1：余数读反了！

除 R 取余后，很多人从上往下读，这是错误的！正确的读法是从下往上（倒序）。

例如 63 转二进制，余数（从下往上）是 111111，如果从上往下读就错了。

陷阱 2：小数乘 2 取整的方向

小数部分的数是从上往下读，与整数部分恰好相反！

整数：除 R 取余 → 从下往上读 | 小数：乘 R 取整 → 从上往下读

陷阱 3：ASCII 码与数字值的区别

字符 '0' 的 ASCII 值是 48，字符 'A' 的 ASCII 值是 65。不要把字符和它的 ASCII 码值混淆。

数字字符的值 = 48 + 数字值（如 '5' = 48 + 5 = 53）

陷阱 4：八进制前缀 0 的误导

在 C++ 中，010 是八进制数，等于十进制的 8！

所以 010 << 1 的结果是 16（8 × 2），而不是 100。

记忆口诀：整余倒着读，小整顺着读。先得余数是低位，后得余数是高位。

第1题 · 大写字符ASCII编码（2023/09 第3题）

第7题 · 除2取余的阅读顺序（2024/03 判断题）

答案：错 解析：除2取余后应该从下往上（倒序）读，虽然 63 的二进制确实是 111111，但"从前往后读"的说法在一般情况下是错误的。
