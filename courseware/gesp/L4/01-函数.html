1 第一步：生活引入 — 函数是什么？

厨房里的「菜谱」

想象你在厨房做菜。菜谱告诉你：输入「食材」，经过「烹饪步骤」，输出「成品菜」。

一个好的菜谱可以被反复使用 —— 今天做宫保鸡丁调用一次菜谱，明天又来一遍。

函数就是编程世界的「菜谱」：输入参数 → 处理逻辑 → 返回结果。

核心直觉：函数 = 命名代码块 = 封装 + 复用。
你把一段「炒菜」的代码写成一个函数，以后只需要喊一句「炒菜(食材)」就行了，不用每次都重写步骤。
本课内容总览
  • 函数声明与定义：先「挂招牌」再「上菜」
  • 参数传递：值传递 vs 引用传递 vs 指针传递
  • 作用域：谁看得见谁？
  • 默认参数：不想每次都说「少盐」？预设它！
  • 函数重载：同名不同参，自动匹配
  • 时间复杂度：评估函数效率

2 第二步：核心概念

函数的基本结构
cpp
// 1. 函数声明（函数原型）
返回类型 函数名(参数列表);

// 2. 函数定义
返回类型 函数名(参数列表) {
    // 函数体
    return 返回值;
}

// 3. 函数调用
函数名(实参列表);
形参 vs 实参
概念位置说明
形参
(parameter)		函数定义中声明占位变量，接收调用时传入的值
实参
(argument)		函数调用时传入具体的值，传递给形参

例：int add(int a, int b) 中 a、b 是形参；调用 add(3, 5) 中的 3、5 是实参。

三种参数传递方式对比
传递方式语法是否拷贝数据能否修改实参
值传递void f(int x)拷贝一份否
引用传递void f(int & x)不拷贝（别名）能
指针传递void f(int* x)传地址（8字节）能（用 *x）
默认参数规则
  • 默认值在函数声明中指定，定义处不重复
  • 带默认值的参数必须从右向左连续排列
  • int add(int a, int b = 1); — b 有默认值，调用时可省略
函数重载 (Overloading)
  • 同一作用域内，函数名相同，参数列表不同
  • 编译器根据实参自动匹配最合适的版本
  • 返回值类型不同不能构成重载
作用域规则
  • 全局变量：在所有函数外定义，整个程序可见
  • 局部变量：在函数或代码块内定义，仅内部可见
  • 同名屏蔽：局部变量会隐藏同名的全局变量
  • 作用域解析符 ::：在局部作用域内访问被屏蔽的全局变量

3 第三步：语法详解

函数声明与定义分离
cpp
// 声明放在 main 之前（函数原型）
int multiply(int x, int y);

int main() {
    int result = multiply(4, 5);  // 可以调用
    std::cout << result;
    return 0;
}

// 定义可以放在 main 之后
int multiply(int x, int y) {
    return x * y;
}
关键
只要在调用前声明了函数原型，定义可以放在任何位置。编译器只需要知道「有这个函数」即可。
值传递示例（不修改实参）
cpp
void foo(int x) {
    x += 5;  // 修改的是副本，不影响实参
}
int main() {
    int a = 10;
    foo(a);
    cout << a;  // 输出 10，a 没有变
}
引用传递示例（修改实参）
cpp
void add(int &x) {
    x += 10;  // 通过引用直接修改实参
}
int a = 5;
add(a);
// 此时 a == 15
函数重载示例
cpp
int add(int a, int b)       { return a + b; }
double add(double a, double b) { return a + b; }
int add(int a, int b, int c)   { return a + b + c; }

cout << add(2, 3) << endl;       // 调用版本1: 5
cout << add(2.5, 3.5) << endl;   // 调用版本2: 6.0
cout << add(1, 2, 3) << endl;    // 调用版本3: 6
作用域与 :: 操作符
cpp
int value = 100;  // 全局变量

void print1() {
    int value = 50;  // 局部变量，屏蔽全局 value
    cout << value << " ";   // 输出 50（局部）
    cout << ::value << " "; // 输出 100（全局，用 :: 访问）
}

void print2() {
    cout << value << " ";   // 输出 100
}
嵌套作用域
cpp
int a = 1;  // 全局
void test() {
    int a = 2;  // 函数内局部
    {
        int a = 3;  // 内部代码块局部
        a++;        // 内层 a → 4
    }               // 内层 a 被销毁
    a++;            // 函数内 a → 3
    cout << a << " "; // 输出 3
}
int main() {
    test();
    cout << a;      // 输出 1（全局）
}
// 输出：3 1
时间复杂度分析示例
cpp
// 枚举子集：外层 2^n 次，内层 n 次
bool f(int arr[], int n, int target) {
    for (int i = 0; i < (1 << n); i++) {  // O(2^n)
        int sum = 0;
        for (int j = 0; j < n; j++)         // O(n)
            if (i & (1 << j)) sum += arr[j];
        if (sum == target) return true;
    }
    return false;
}
// 总时间复杂度：O(n × 2^n)

4 第四步：手工模拟

模拟1：值传递与作用域
cpp
int x = 5;              // 全局 x = 5
void foo() {
    int x = 10;         // 局部 x = 10
    cout << x << " ";  // 输出 10
}
void bar() {
    cout << x << " ";  // 输出全局 5
}
int main() {
    foo();   // → 10
    bar();   // → 5
}
// 输出：10 5
模拟2：默认参数调用
语句实参b的值结果
add(2)a=2b=1（默认）3
add(2, 3)a=2, b=3b=35
模拟3：引用传递修改实参
步骤变量状态说明
初始a = 5全局变量
调用 add(a)x 是 a 的引用引用绑定
x += 10a = 15通过引用修改
返回后a = 15修改生效
模拟4：嵌套作用域追踪
cpp
int a = 1;              // [全局] a=1
void test() {
    int a = 2;          // [test] a=2
    {   int a = 3;      // [内层] a=3
        a++;            // [内层] a=4
    }                   // [内层] 销毁
    a++;                // [test] a=3
    cout << a << " ";  // 输出 3
}
int main() {
    test();
    cout << a;         // [全局] a=1 → 输出 1
}
// 最终输出：3 1

5 第五步：常见陷阱

陷阱1：函数使用前必须有声明
把函数定义放在 main 之后可以，但必须在调用前做前置声明：
cpp
int main() {
    greet();  // 编译错误：找不到函数 greet()
    return 0;
}
void greet() { cout << "Hello!" << endl; }
陷阱2：值传递不修改实参
值传递时，函数内修改的是参数的副本，不影响原变量。只有引用传递(&)和指针传递(*)才能修改实参。
cpp
void foo(int x) { x += 5; }
int a = 10; foo(a);  // a 仍是 10
陷阱3：函数重载不能与默认参数冲突
当调用产生二义性时，编译器无法判断：
cpp
int calculate(int x, int y = 10);  // 版本1
int calculate(int x);              // 版本2
calculate(5);  // 二义性！
陷阱4：局部变量与全局变量同名屏蔽
函数内定义的局部变量会隐藏同名的全局变量。需要访问全局变量时用 ::变量名。
陷阱5：局部变量未初始化即使用
int x = x + 1; 中右侧的 x 是未初始化的局部变量，值是未定义的！
cpp
int x = 10;
void f() {
    int x = x + 1;  // 未定义行为！局部 x 未初始化
    cout << x;     // 输出不确定
}

第1题 · 函数声明与定义（2023/12 第1题）

关于下述代码，说法错误的是？

cpp
int multiply(int x, int y);
int main() { int a=4,b=5; cout << multiply(a,b); return 0; }
int multiply(int x, int y) { return x * y; }

A. 函数 multiply 的定义应该放到函数 main 之前
B. 函数声明中明确指定了返回值为整数类型
C. multiply(a,b) 中 a 和 b 作为实参传递给了形参 x 和 y
D. 运行上述代码，将输出 20

答案：A
解析：有函数声明在前，定义可以放在 main 之后。B/C/D 都是正确描述。
第2题 · 作用域（2023/09 第6题）

执行下述代码将输出？

cpp
int x = 10;
void func() { int x = 20; cout << x; }
int main() { func(); cout << x; return 0; }

A. 2020    B. 2010    C. 1010    D. 编译错误

答案：B
解析：func() 内局部 x=20，输出 20；main() 内全局 x=10，输出 10。合起来 2010。
第3题 · 参数传递方式（2023/09 第7题）

以下哪种参数传递方式可以避免拷贝大型对象？

A. 只能用值传递    B. 只能用引用传递    C. 只能用指针传递    D. 引用传递和指针传递均可

答案：D
解析：引用传递（别名）和指针传递（传地址）都不拷贝整个对象。
第4题 · 值传递特性（2024/12 第1题）

下面有关函数参数的说法，正确的是？

A. 值传递方式下，子函数改变参数值，主函数的参数值不变
B. 值传递方式下，子函数改变参数值，主函数的参数值随之改变
C. 传递地址方式下，子函数改变参数值，主函数的参数值不改变
D. 函数参数传递可以不满足子函数的参数个数要求

答案：A
解析：值传递复制的是副本，函数内修改不影响原变量。
第5题 · 时间复杂度（2024/03 第1题）

给定如下算法，其时间复杂度为？

cpp
bool f(int arr[], int n, int target) {
    for (int i = 0; i < (1 << n); i++) {
        int sum = 0;
        for (int j = 0; j < n; j++)
            if (i & (1 << j)) sum += arr[j];
        if (sum == target) return true;
    }
    return false;
}

A. O(n²)    B. O(n·2ⁿ)    C. O(1)    D. O(n³)

答案：B
解析：外层 2^n 次，内层 n 次，相乘得 O(n × 2^n)。
第6题 · 作用域与 ::（2024/09 第1题）

运行如下代码会输出？

cpp
int value = 100;
void print1() { int value = 50; cout << value << " "; cout << ::value << " "; }
void print2() { cout << value << " "; }
int main() { print1(); print2(); }

A. 100 100 100    B. 50 50 50    C. 50 100 100    D. 50 50 100

答案：C
解析：print1() 输出局部 50 和 ::value=100；print2() 输出全局 100。合起来 "50 100 100"。
第7题 · 嵌套作用域（2024/09 第2题）

执行完下面的代码后，输出是？

cpp
int a = 1;
void test() { int a = 2; { int a = 3; a++; } a++; cout << a << " "; }
int main() { test(); cout << a; }

A. 3 1    B. 4 1    C. 3 2    D. 4 2

答案：A
解析：内层块 a=3→4 后销毁。test() 局部 a=2→3。全局 a=1 不变。输出 3 1。
第8题 · 默认参数（2025/03 第1题）

下面这段代码会输出？

cpp
int add(int a, int b = 1);
int main() { cout << add(2) << " " << add(2, 3); return 0; }
int add(int a, int b) { return a + b; }

A. 3 5    B. 编译失败    C. 运行错误    D. 链接失败

答案：A
解析：add(2) → b用默认值1 → 3；add(2,3) → 5。输出 3 5。
第9题 · 修改结构体参数（2025/03 第4题）

关于函数参数传递，以下哪种方式可以修改传入的结构体对象？

A. 值传递或引用传递    B. 值传递或指针传递    C. 引用传递或指针传递    D. 仅指针传递

答案：C
解析：要修改实参必须用引用传递或指针传递。值传递修改的是副本。
第10题 · 形参与实参（2025/03 第5题）

以下哪个选项正确描述了C++中形参和实参的区别？

A. 形参是函数调用时传递的具体值，实参是函数定义中声明的变量
B. 形参是函数定义中声明的变量，实参是函数调用时传递的具体值
C. 形参和实参在函数调用时是完全相同的
D. 形参只在函数内部可见，实参在函数外部可见

答案：B
解析：形参(parameter)出现在函数定义中，实参(argument)出现在函数调用中。A 说反了。

判断题（共7题）

判断题第1题（2025/06 第5题）

函数参数可以通过值传递、引用传递和指针传递，这样函数内对参数的修改可以直接修改传入变量的值。

答案：错误（X）
解析：值传递不能修改原变量，只有引用传递和指针传递才能修改。
判断题第2题（2025/06 第6题）

在C++中，函数的返回类型可以省略，默认为 int。

答案：错误（X）
解析：标准 C++ 中函数必须显式指定返回类型，不能省略。
判断题第3题（2025/06 第7题）

下面C++代码的输出是 15。

cpp
void foo(int x) { x += 5; }
int main() { int a = 10; foo(a); cout << a << endl; }
答案：错误（X）
解析：foo 使用值传递，x 是 a 的副本，x+=5 不影响 a。输出是 10。
判断题第4题（2025/09 第5题）

在C++中，相比于值传递，使用引用传递可以直接操作和修改原始变量，避免数据拷贝，提高效率。

答案：正确（√）
解析：引用传递不产生副本，直接操作原变量。
判断题第5题（2025/09 第6题）

执行下面C++代码将输出 11。

cpp
int x = 10; void f() { int x = x + 1; cout << x << endl; }
答案：错误（X）
解析：int x = x + 1; 中右侧的 x 是局部变量自身（未初始化），值是未定义的。
判断题第6题（2025/12 第6题）

执行下面程序后，变量 a 的值会变成 15。

cpp
void add(int &x) { x += 10; }  int a = 5; add(a);
答案：正确（√）
解析：add 使用引用传递，x 是 a 的引用，x+=10 修改 a → 15。
判断题第7题（2025/12 第7题）

下面代码可以正常编译并输出 10。

cpp
int calculate(int x, int y = 10);
