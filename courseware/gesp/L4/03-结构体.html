💎 GESP C++ 四级 · 结构体（Struct）

Struct · 自定义复合数据类型的利器

⚡ 7道选择题 + 3道判断题 📊 年均出题 2~3道 ⭐ 占总分 ≈ 8%

1 第一步：生活引入

📋 一张学生信息表

假设你要管理全班 50 名学生的信息，每个学生都有：姓名（字符串）、年龄（整数）、成绩（浮点数）。

如果不用结构体，你可能会这样写：

cpp
string names[50];
int ages[50];
float scores[50];
// 学生3的名字：names[2]，年龄：ages[2]，成绩：scores[2]
// 三个数组"各管各的"，容易乱套
💡 更好的做法

把每个学生的信息"打包"在一起，就像填一张表格——一行就是一个学生，所有信息都在同一行里。这就是结构体（struct）的核心思想。

🎯 生活中的"结构体"
  • 身份证：姓名 + 性别 + 出生日期 + 地址 → 一个人的"信息包"
  • 商品标签：商品名 + 价格 + 库存量 → 一个商品的"信息包"
  • 游戏角色：昵称 + 等级 + 生命值 + 攻击力 → 一个角色的"信息包"

结构体就是 C++ 中用来「自定义一个信息包类型」的语法。

2 第二步：核心概念

📐 什么是结构体？

🔵 结构体定义

结构体（struct）是 C++ 中一种用户自定义的复合数据类型，可以将多个不同类型的变量组合成一个整体。

特性说明
定义关键词struct
成员类型可以是任意类型（int, string, 甚至另一个结构体）
默认访问权限public（成员可直接访问）
内存分配成员按声明顺序连续存放（可能有对齐填充）
初始化方式花括号列表初始化 {val1, val2, ...}
🟣 结构体 vs 数组 vs 类
对比维度数组（array）结构体（struct）类（class）
元素类型必须相同可以不同可以不同
访问方式arr[i]s.name成员名 + 访问控制
默认权限N/Apublicprivate
用途定位批量同质数据打包异质数据面向对象编程
📌 核心公式

struct 类型名 { 成员列表 }; — 先定义类型，再创建变量。

3 第三步：语法详解

📌 基本定义与初始化

📝 定义、创建、访问
cpp
// 1. 定义结构体类型
struct Student {
    string name;
    int age;
    float score;
};

// 2. 创建变量（三种方式）
Student s1;                        // 默认初始化（成员值不确定）
Student s2 = {"小明", 14, 95.5};   // 花括号列表初始化 ⭐ 最常用
Student s3{"小红", 13, 88.0};     // C++11 统一初始化

// 3. 访问成员
s2.age = 15;                       // 点号运算符访问
cout << s2.name << " " << s2.score;

📌 嵌套结构体

📝 结构体嵌套结构体
cpp
struct Point {
    int x, y;
};

struct Rectangle {
    Point topLeft;      // 结构体嵌套结构体
    Point bottomRight;
};

// 嵌套初始化
Rectangle rect = {{10, 10}, {20, 20}};

// 嵌套成员访问
rect.topLeft.x = 5;           // 逐层点号访问
cout << rect.bottomRight.y;   // 输出 20

📌 结构体与指针/引用

📝 传递与修改
cpp
struct Cat {
    string name;
    int age;
};

Cat kitty{"Mimi", 2};

// 通过引用修改（不拷贝，直接操作原对象）
void birthday(Cat& c) {
    c.age++;  // 修改原始对象
}

// 通过指针访问成员
Cat* p = &kitty;
p->age = 5;          // 指针用 -> 运算符
cout << p->name;     // 输出 Mimi

📌 结构体数组 — 动态分配

📝 堆上分配
cpp
struct Student {
    string name;
    int age;
    float score;
};

// 在堆上分配 20 个 Student
Student* students = new Student[20];

// 使用成员
students[0].name = "小华";
students[0].score = 92.5;

// 释放内存
delete[] students;
💡 提示
此代码合法，结构体数组可以用 new 动态分配。

4 第四步：手工模拟

struct Cat { string name; int age; };
void birthday(Cat& c) { c.age++; }

int main() {
    Cat kitty{"Mimi", 2};

📝 代码

2rect.topLeft.x = 5{5, 10}{20, 20}

5cout 输出5 + 5 = 10

5 第五步：常见陷阱

🚨 陷阱1：混淆结构体初始化语法

结构体初始化必须用花括号 {}，不能用圆括号 ()、new{} 或尖括号 <>。

cpp
struct Point { int x, y; };
Point p = {1, 2};   // ✅ 正确
// Point p = (1,2);  // ❌ 错误！这是逗号表达式，等于 Point p = 2;
🚨 陷阱2：结构体嵌套层次过深

虽然结构体可以嵌套，但嵌套层次过多会导致代码难以理解和维护。不能无限制嵌套。访问深层成员时需要逐层点号，可读性会急剧下降。

🚨 陷阱3：值传递 vs 引用传递修改结构体

如果函数参数是值传递，对结构体的修改不会影响原对象。要修改原结构体，必须用 引用传递 或 指针传递。

cpp
void bad(Cat c) { c.age++; }      // ❌ 修改的是副本，原对象不变
void good(Cat& c) { c.age++; }    // ✅ 引用传递，修改原对象
void alsoGood(Cat* c) { c->age++; } // ✅ 指针传递，也能修改原对象
🚨 陷阱4：忘记结构体成员默认 public

在 C++ 的 struct 中，所有成员默认是 public，可以直接通过 . 或 -> 访问。这与 class 不同（class 默认 private）。GESP 四级常考这个区别。

🚨 陷阱5：指针访问结构体成员用错运算符

通过指针访问结构体成员要用 ->，不是 .。

cpp
Cat* p = &kitty;
p->age = 3;   // ✅ 正确：指针用 ->
// p.age = 3; // ❌ 错误：p 是指针，不能用 .

6 第六步：真题实战

📝 第 1 题 · 结构体定义与初始化（2024/12 第6题）

下面的描述中，哪个选项正确定义了一个名为 Person 的结构体并正确初始化了一个 Person 结构体的变量 p ？

选项代码
Astruct Person { string name; int age; } p = {"Tom", 20}; — 但 p 不含初始化列表 ❌
Bstruct Person { string name; int age; }; Person p = {};
Cstruct Person { string name; int age; }; Person p = {name:"Tom", age:20};
Dstruct Person { string name; int age; }; Person p = new Person{"Tom", 20};

（原题含图片，此处为描述性展示，选项 C 为正确初始化方式）

答案：C
解析：结构体初始化用花括号 {}，不能用 new 或指定成员名的语法（那是 C 语言的指定初始化器）。正确的 C++ 列表初始化方式为 Person p = {"Tom", 20};。
📝 第 2 题 · 嵌套结构体（2025/03 第6题）

给定如下代码，下面描述错误的是（ ）。

cpp
struct Person {
    std::string name;
    int age;
    struct Address {
        std::string street;
        std::string city;
    };
    Address address;
};

A. 结构 Person 内嵌套结构 Address
B. Person 有一个 Address 类型的 address 成员
C. 一个 Person 类型的变量 p 的 address 的初始化可以写成：p.address.street = "123 Main St"; p.address.city = "Anytown";
D. 结构的嵌套可以减少命名冲突，因此可以不必控制嵌套层次

答案：D
解析：虽然嵌套可以减少命名冲突，但仍需控制嵌套层次。过深的嵌套会导致代码复杂性急剧增加，可读性和维护性下降。A、B、C 均正确描述了代码的含义。
📝 第 3 题 · 结构体初始化语法（2025/03 第7题）

关于结构体初始化，以下哪个选项中正确的是（ ）。

cpp
struct Point {int x,y;};

A. Point p = (1,2);
B. Point p = {1,2};
C. Point p = new {1,2};
D. Point p = <1,2>;

答案：B
解析：只有 Point p = {1,2}; 是正确的 C++ 结构体列表初始化语法。A 是逗号表达式，等价于 p = 2；C 中的 new 用于动态分配且不合法；D 使用了错误的尖括号语法。
📝 第 4 题 · 结构体引用传递（2025/09 第7题）

运行如下代码会输出（ ）。

cpp
struct Cat {
    string name;
    int age;
};
void birthday(Cat& c) {
    c.age++;
}
int main() {
    Cat kitty{"Mimi", 2};
    birthday(kitty);
    cout << kitty.name << " " << kitty.age;
}

A. Mimi 2    B. Mimi 3    C. kitty 3    D. kitty 2

答案：B
解析：birthday 的参数是 Cat& c（引用传递），所以 c.age++ 直接修改了 kitty 的 age，输出 Mimi 3。如果是值传递，则输出 Mimi 2。
📝 第 5 题 · 嵌套结构体与指针（2025/09 第8题）

运行如下代码会输出（ ）。

cpp
struct Point { int x, y; };
struct Rectangle { Point topLeft; Point bottomRight; };
int main() {
    Rectangle rect = {{10, 10}, {20, 20}};
    rect.topLeft.x = 5;
    Point* p = &rect.bottomRight;
    p->y = 5;
    cout << rect.topLeft.x + rect.bottomRight.y;
    return 0;
}

A. 10    B. 30    C. 15    D. 20

答案：A
解析：rect.topLeft.x 先改为 5，p->y 将 bottomRight.y 改为 5，所以 5 + 5 = 10。
📝 第 6 题 · 选择前 k 名（2025/12 第8题）

下面的函数 selectTopK() 实现从 n 个学生中选出前 k 名成绩最好的学生颁发奖学金（不需要对所有学生完全排序，只需要找出前 k 名），则横线上应填写（ ）。

cpp
struct Student {
    string name;
    int score;
};
void selectTopK(Student students[], int n, int k) {
    for (int i = 0; i < k; i++) {
        int maxIdx = i;
        for (____________________) {
            if (students[j].score > students[maxIdx].score) {
                maxIdx = j;
            }
        }
        if (maxIdx != i) {
            Student temp = students[i];
            students[i] = students[maxIdx];
            students[maxIdx] = temp;
        }
    }
}

A. int j = 0; j < n; j++
B. int j = i + 1; j < n; j++
C. int j = i; j < n; j++
D. int j = 1; j <= n; j++

答案：B
解析：这是选择排序的前 k 趟变体。内循环应从 i+1 开始到 n-1，在未排序部分找最大值。
📝 第 7 题 · 排行榜更新（2025/12 第11题）

某游戏的排行榜系统需要实时更新玩家分数。每次只有一个玩家的分数发生变化，排行榜已经是按分数降序排列的。现在需要将更新后的玩家调整到正确位置。下面的函数 updateRanking() 要实现上述功能，则两处横线上应分别填写（ ）。

cpp
struct Player {
    string name;
    int score;
};
void updateRanking(Player players[], int size, int playerIdx) {
    Player updatedPlayer = players[playerIdx];
    if (playerIdx > 0 && updatedPlayer.score > players[playerIdx - 1].score) {
        int i = playerIdx;
        while (____________________) { // ① 分数上升
            players[i] = players[i - 1];
            i--;
        }
        players[i] = updatedPlayer;
    }
    else if (playerIdx < size - 1 && updatedPlayer.score < players[playerIdx + 1].score) {
        int i = playerIdx;
        while (____________________) { // ② 分数下降
            players[i] = players[i + 1];
            i++;
        }
        players[i] = updatedPlayer;
    }
}

（原题含图片选项，答案选 A）

答案：A
解析：分数上升时，需要向前移动（while 条件应为 i > 0 && updatedPlayer.score > players[i-1].score）；分数下降时，需要向后移动（while 条件应为 i < size-1 && updatedPlayer.score < players[i+1].score）。相当于插入排序的一次调整。
📝 判断题 1 · 访问权限（2026/03 第6题）

结构体的成员默认是 public 访问权限。

答案：正确
解析：在 C++ 中，struct 的成员默认是 public，而 class 的成员默认是 private。这是 struct 和 class 在 C++ 中的主要区别之一。
📝 判断题 2 · 动态分配结构体数组（2026/03 第7题）

以下 C++ 代码是否合法？

cpp
struct Student {
    string name;
    int age;
    float score;
};
Student* students = new Student[20];
答案：合法
解析：可以使用 new 在堆上动态分配结构体数组，这完全合法。每个元素会调用默认构造函数初始化。记得使用完后 delete[] students; 释放内存。
📝 判断题 3 · 结构体嵌套（2025/12 第2题）

一个结构体不能包含另一个结构体。

答案：错误
解析：结构体完全可以包含另一个结构体作为成员（嵌套结构体），如 struct Rectangle { Point topLeft; Point bottomRight; };。这是合法的且在实际编程中非常常见。
