Recurrence — 从已知推未知，步步为营

1 第一步：生活引入

💰 存钱比喻

第一天存1元，每天比前一天多存2元。第7天存了多少钱？第1天1元→第2天3元→第3天5元→...顺着往下推即可。

这就是递推——已知前面的结果，推出后面的结果。

对比递归：递归是"我调用我自己"；递推是"按顺序算"，从第1天算到第n天。

2 第二步：核心概念

递推三要素
  1. 初始条件（基点）：f(1) = 已知值
  2. 递推公式（关系）：f(n) = g(f(n-1), f(n-2), ...)
  3. 目标：求 f(N)
维度递推（迭代）递归
方向自底向上自顶向下
实现循环函数自调用
斐波那契时间O(n)朴素递归 O(2ⁿ)
空间O(1)或O(n)O(n)调用栈

3 第三步：语法详解

斐波那契递推（O(n)时间，O(1)空间）
cpp
int fib(int n) {
    if (n <= 1) return n;
    int a = 0, b = 1;
    for (int i = 2; i <= n; i++) {
        int temp = a + b;
        a = b; b = temp;
    }
    return b;
}
爬楼梯递推
cpp
int climbStairs(int n) {
    if (n <= 2) return n;
    int prev2 = 1, prev1 = 2, current = 0;
    for (int i = 3; i <= n; i++) {
        current = prev2 + prev1;
        prev2 = prev1; prev1 = current;
    }
    return current;
}

5 第五步：常见陷阱

⚠️ 陷阱1：递推不是"自己调用自己"

"自己调用自己"是递归的特征。递推是用 for 循环从前往后算。

⚠️ 陷阱2：朴素递归是 O(2ⁿ) —— 指数级！
cpp
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);  // O(2^n)！
}

每次调用分裂出两个子调用，大量重复计算。递推只需 O(n)。

⚠️ 陷阱3：滚动变量更新顺序
cpp
// ❌ 错误：覆盖顺序错误
a = b; b = a + b;  // a 已被覆盖！

// ✅ 正确：用临时变量
int temp = a + b; a = b; b = temp;

真题 3：朴素递归斐波那契的时间复杂度是？（2025/03 第10题）
cpp
int fibonacci(int n) {
    if (n == 0) return 0;
    if (n == 1) return 1;
    return fibonacci(n - 1) + fibonacci(n - 2);
}

答案：D

答案：✅
判断题第3题（2025/12 第6题）

下面递推方式计算斐波那契的时间复杂度是 O(n)。

cpp
int f[20]; f[0]=0; f[1]=1;
for(int i=2;i<=10;i++) f[i]=f[i-1]+f[i-2];
答案：✅
递推（循环）每次迭代 O(1)，共 n 次，总 O(n)。
