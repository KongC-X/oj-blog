1 第一步：生活引入

📁 文件柜里的文档

想象你有一个文件柜。你想要记录一些信息（比如今天的日记），你需要打开柜子、取出笔记本、写上内容、然后放回去并关上柜门。这就是"写文件"的过程。

如果你想回顾之前的记录，你需要打开柜子、找到笔记本、阅读内容、然后关上柜门。这就是"读文件"的过程。

📝 电脑里的文件操作

C++ 程序也可以像使用文件柜一样操作电脑上的文件：

打开 → 读/写 → 关闭，这三个步骤是文件操作的基本流程。对应到 C++ 中就是 open()、<</>>/getline()、close()。

🔧 为什么要用文件操作？

程序运行时产生的数据默认存在内存中，程序结束后就消失了。如果将数据写入文件（存在硬盘上），下次运行程序时还能读取回来——实现数据的持久化存储。

🎯 本节学习目标

  • 掌握 fstream 头文件及三个核心类（ofstream / ifstream / fstream）
  • 熟练使用 open() 和 close() 函数打开/关闭文件
  • 理解 >> 与 getline() 的读取行为差异
  • 熟记文件打开模式：in / out / app / trunc

2 第二步：核心概念

📖 头文件：fstream

🔵 必须包含的头文件

C++ 文件操作需要包含 #include <fstream>（不是 iostream、cstdio 或 string）。这是 GESP 四级选择题必考点！

🔑 三个核心类

类用途说明
ofstream 写文件 Output File Stream，向文件写入数据
ifstream 读文件 Input File Stream，从文件读取数据
fstream 读写文件 同时支持读和写

📂 文件打开模式

模式含义使用场景
ios::in以读取方式打开文件ifstream 默认
ios::out以写入方式打开文件（覆盖原内容）ofstream 默认
ios::app追加模式，写入内容添加到文件末尾日志记录
ios::trunc打开时清空文件内容out 模式隐含行为
📌 关键记忆

open() 用于打开文件，close() 用于关闭文件（不是 create、write、colse 等其他拼写）。追加模式是 ios::app，表示 append（追加到末尾）。

📁 文件路径

🟠 路径写法
路径写法含义
"GESP.txt"相对路径：当前工作目录下的文件
"./data/GESP.txt"相对路径：当前目录下的 data 文件夹中
"../data/GESP.txt"相对路径：上级目录下的 data 文件夹中

注意："GESP.txt" 是相对路径，不是绝对路径。绝对路径是从根目录（如 C:\ 或 /home/）开始的完整路径。

3 第三步：代码详解

📌 文件写入

写入文件基本模板
cpp
#include <iostream>
#include <fstream>
using namespace std;

int main() {
    ofstream fout;                  // 创建输出文件流对象
    fout.open("output.txt");        // 打开文件（默认 out + trunc）
    fout << "Hello World" << endl;  // 写入内容
    fout.close();                   // 关闭文件
    return 0;
}
简化写法：构造时直接打开
cpp
ofstream fout("output.txt");   // 构造同时打开文件
fout << "Hello World" << endl;
fout.close();
追加模式写入
cpp
ofstream fout;
fout.open("log.txt", ios::app);  // 追加模式，不会覆盖原有内容
fout << "New log entry" << endl;
fout.close();

📌 文件读取

读取文件基本模板
cpp
#include <iostream>
#include <fstream>
#include <string>
using namespace std;

int main() {
    ifstream fin("data.txt");       // 构造时打开文件
    if (!fin) {
        cout << "文件打开失败" << endl;
        return -1;
    }
    string line;
    while (getline(fin, line)) {    // 逐行读取
        cout << line << endl;
    }
    fin.close();
    return 0;
}

📌 >> 与 getline() 的区别

方式行为
fin >> str 按空白字符（空格、换行、Tab）分割读取，每次读一个"词"
getline(fin, str) 按换行符分割读取，每次读一整行（含空格）

注意：fin >> str 读取后会跳过空白，而 getline() 会读取包括空格在内的整行。

📝 输出重定向

🔷 命令行重定向

可以通过文件重定向将 cout 的输出内容写到文件中，常用于记录程序运行日志。在命令行中使用：

./program > log.txt

这会将程序的标准输出重定向到 log.txt 文件中。

4 第四步：手工模拟

🎬 写入模拟：字节数计算

🟢 以下代码生成的文件字节数为多少？
cpp
ofstream fout;
fout.open("1.txt");
for(int i = 1; i <= 10; i++) {
    if(i % 5 == 0) {
        int x = 6;
        fout << x;       // i=5 和 i=10 时写入 '6'
    } else {
        char ch = 'A';
        fout << ch;      // 其他 8 次写入 'A'
    }
}
💛 推演

循环 10 次，i=5 和 i=10 时各写入 1 个字符 '6'（通过 << 操作符，数字 6 以字符形式写入，占 1 字节）；其他 8 次各写入 1 个字符 'A'。共 10 个字符 = 10 字节。

🎬 读取模拟：fin >> 和 getline 行为

🟢 理解读取行为差异

文件 test.txt 内容（由下面代码写入）：

cpp
ofstream fout("test.txt");
fout << "Happy" << endl;   // 写入 "Happy\n"
fout << "New Year";          // 写入 "New Year"（无换行）
fout.close();

文件实际内容：

Happy
New Year

读取代码：

cpp
ifstream fin("test.txt");
string s1, s2;
fin >> s1;            // 读取 "Happy"（遇到换行停止）
getline(fin, s2);     // 读取剩余部分，读到换行符后的空串
cout << s1 << "|" << s2;   // 输出: Happy|
💛 关键理解

fin >> 读取 "Happy" 后，光标停在换行符 \n 处。getline() 从当前位置读到下一个换行符，读到的是空字符串。输出结果为 Happy|。

🎬 读取模拟：fin >> 读取数字（截断行为）

🟢 数字截断模拟

文件 1.txt 内容：

50 2024 3.16 I

读取代码：

cpp
ifstream fin("1.txt", ios::in);
string line;
int x;
for (int i = 0; i < 2; i++) {
    fin >> line;                // 第一次读 "50"，第二次读 "2024"
}
fin >> x;                       // 读 "3.16" 中的整数部分 → x = 3
cout << x << endl;
💛 推演

前两次 fin >> line 分别读到 "50" 和 "2024"；第三次 fin >> x 读 "3.16"，x 是 int 类型，只能读到 3（遇到 . 停止）。输出 x = 3。

5 第五步：常见陷阱

🚨 陷阱1：头文件混淆

文件操作需要 #include <fstream>，不是 iostream、cstdio 或 string。GESP 四级选择题必考！

🚨 陷阱2：关闭函数拼写错误

关闭文件的函数是 close()，常见干扰选项有 colse、csloe、clsoe 等拼写变体。记住：c-l-o-s-e。

🚨 陷阱3：追加模式是 app

追加到文件末尾的模式是 ios::app（append），不是 in（读取）、out（写入/覆盖）或 trunc（清空）。记法：app ≈ append。

🚨 陷阱4：文件路径是相对路径

"GESP.txt" 是相对路径，不是绝对路径。绝对路径是包含完整盘符或根目录的路径（如 C:\test\GESP.txt 或 /home/user/GESP.txt）。

🚨 陷阱5：ofstream 未 open 不能写入

如果创建 ofstream 对象但没有调用 open("文件名")，则实际没有打开任何文件，写入操作不会产生效果。必须显式打开文件才能写入。

🚨 陷阱6：fin >> 读取数字时的截断行为

用 fin >> 读取到 int 变量时，遇到非数字字符会停止。例如从 "3.16" 读到 int 类型，只会读到 3（遇到小数点 . 停止）。

✅ 判断题（共5道）

📌 文件操作判断题
T1. 输出重定向

通过使用文件重定向操作，可以将程序中输出到 cout 的内容输出到文件中，这是常用的记录程序运行日志的方法之一。

正确 · 输出重定向可将 cout 内容重定向到文件。
T2. ofstream 未 open 写入

在下面的C++代码中，将对1.txt文件写入 hello 。

cpp
ifstream filein;
ofstream fileout;
filein.open("1.txt");
fileout << "hello";
错误 · fileout 没有调用 open() 指定文件名，因此没有打开任何文件，写入无效。
T3. fin >> 读取数字

文本文件 1.txt 第1行由 01234 共5个字符组成其间没有空格，当用C++代码正常打开文件成功并执行如下代码后，第1行长度为5。

cpp
ifstream filein;
int buff;
filein.open("1.txt");
filein >> buff;
cout << buff << endl;
错误 · fin >> 读取 int 会读出整个数字 1234，不是按字符读取。
T4. ofstream 构造写入

下面C++代码实现将 Hello 写入 data.txt 。

cpp
ofstream out("data.txt");
out << "Hello";
out.close();
正确 · 通过 ofstream 构造时打开文件，写入 "Hello"，然后关闭，操作完整正确。
T5. 文件读写求和

执行下面代码会输出 100 。

cpp
int main() {
    ofstream fout("data.txt");
    fout << 10 << " " << 20 << endl;
    fout << 30 << " " << 40;
    fout.close();
    ifstream fin("data.txt");
    int a, b, c, d;
    fin >> a >> b >> c >> d;
    fin.close();
    cout << a + b + c + d;
    return 0;
}
正确 · 写入 10, 20, 30, 40 后读出求和：10+20+30+40 = 100。
