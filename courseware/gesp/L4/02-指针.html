1 第一步：生活引入 — 指针是什么？

快递柜与取件码

你想把一份文件交给朋友，有两个办法：

  • 复印一份给他（值传递）—— 他改的是复印件，你的原件不受影响
  • 告诉他文件在哪个快递柜、取件码是多少（指针）—— 他可以直接去开柜、修改原件

指针就是「存放地址的变量」—— 它不存数据本身，而是存数据放在哪里。

核心直觉：指针 = 一个变量，存的是另一个变量的「门牌号」。
int* p = &a; → p 里面存的是 a 的地址，通过 *p 可以开门进去访问/修改 a。
指针是四级考试中出题量最大的章节

选择题约12道 + 判断题约7道，占总分约30%。

必须掌握：指针定义/初始化、&取地址/*解引用、指针与数组、指针运算、nullptr/NULL、指针与二维数组地址、引用传递、指针接力。

本课内容总览
  • 指针定义与初始化：int* p = &a;
  • 取地址 & 与解引用 *：一对互逆操作
  • 指针与数组：数组名 = 首地址，p = arr
  • 指针运算：p++ 不是+1而是+sizeof(类型)
  • 指针接力：p1 = p2，指向同一块内存
  • 指针与二维数组地址：行主序地址计算

2 第二步：核心概念

指针的定义与初始化
cpp
int a = 10;       // 普通变量 a，值为 10
int* p = &a;      // 指针 p，存的是 a 的地址

cout << a;       // 输出 10
cout << &a;      // 输出 a 的地址（如 0x7ffee5820）
cout << p;       // 输出 p 中存的地址（同上）
cout << *p;      // 解引用：输出 a 的值 → 10
& 和 * 互逆关系
操作符名称作用示例
&取地址获取变量的内存地址p = &a; → p 指向 a
*解引用通过地址访问该处的值*p = 20; → 等同于 a = 20
指针与数组的特殊关系
  • 数组名在大多数情况下会被转换为首元素地址
  • int arr[3] = {1,2,3}; int* p = arr; → p 指向 arr[0]
  • *(p + i) 等价于 p[i]，也等价于 arr[i]
  • 但数组名不是真指针！它不能做 arr++ 操作（是常量）
指针运算规则
  • p++ / p + 1：地址不是加 1，而是加 sizeof(类型) 字节
  • int* p: p + 1 → 地址 + 4 字节
  • double* p: p + 1 → 地址 + 8 字节
  • char* p: p + 1 → 地址 + 1 字节
  • 指针差值：p2 - p1 返回的是元素个数，不是字节数
指针接力（指针赋值）
cpp
int a = 5;
int* p1 = &a;    // p1 指向 a
int* p2 = p1;     // p2 也指向 a（拷贝的是地址）
*p2 = 10;         // 通过 p2 修改 a

// 此时 a = 10, *p1 = 10, *p2 = 10

指针赋值 p2 = p1 不是创建新的指向关系，而是让 p2 指向 p1 所指向的同一块内存。

二维数组的地址计算
  • 二维数组按行优先连续存储
  • int arr[2][3];：6个int连续存储（24字节）
  • arr 指向第0行（首地址），arr+1 指向第1行
  • arr+1 的地址增量 = 3 × sizeof(int) = 12 字节
  • &arr[1][1] = 首地址 + (1×3 + 1)×4 = 首地址 + 16 字节
nullptr 与 NULL
  • NULL：宏定义，通常为 0
  • nullptr：C++11 引入的空指针字面量
  • cout << (int*)NULL; 通常输出 0
  • 未初始化的指针是野指针，解引用会导致未定义行为
  • 指针变量本身也是变量，在内存中占用空间（通常8字节/64位系统）

3 第三步：语法详解

通过指针修改变量
cpp
int a = 10;
int* p = &a;
*p = 20;       // 等价于 a = 20

int x = 5;
int* px = &x;
*px = *px + 3; // x 变成 8
指针与一维数组
cpp
int arr[3] = {1, 2, 3};
int* p = arr;    // p 指向 arr[0]
p++;             // p 指向 arr[1]（地址+4字节）
cout << *p;     // 输出 2

// 指针偏移访问
int* p2 = &arr[2];     // p2 指向 arr[2]
*p2 = arr[1];          // arr[2] = arr[1] = 2
// 数组变为 {1, 2, 2}
指针作为函数参数（指针传递）
cpp
// 值传递：不修改实参
void increaseA(int x) { x++; }

// 指针传递：修改实参
void increaseB(int* p) { (*p)++; }

int a = 5;
increaseA(a);      // a 仍是 5
increaseB(&a);     // a 变成 6
引用传递 vs 指针传递调用对比
cpp
int f(int &x) { x += 3; return x; }

int a = 3;
f(a);     // 正确：引用传递，a 变为 6
// f(&a);  错误：不能传地址给引用参数
// f(*a);   错误：*a 对 int 类型无意义
指针与二维数组地址计算
cpp
// int 占4字节，int[2][3] 排列为：
// [0][0] [0][1] [0][2] [1][0] [1][1] [1][2]
// 地址递增：+0, +4, +8, +12, +16, +20

int arr[2][3] = {{0,1,2}, {3,4,5}};
// arr = 首地址 = &arr[0][0]
// arr + 1 = 首地址 + 12字节（一行）
// &arr[1][1] = 首地址 + (1×3+1)×4 = 首地址 + 16

4 第四步：手工模拟

模拟1：指针解引用修改变量
cpp
int x = 20;
int* p = &x;
*p = *p + 2;

// 推演：
// 初始: x=20, p=&x (p指向x)
// *p = *p + 2 → 取x的值(20) + 2 = 22
// x = 22, *p = 22
// 结果：x = 22, *p = 22
模拟2：指针偏移与数组
cpp
int arr[3] = {24, 9, 7};
int* p = arr;    // p → arr[0] = 24
p++;             // p → arr[1] = 9
cout << *p;     // 输出 9
模拟3：指针接力
cpp
int a = 5;
int* p1 = &a;    // p1 → a (5)
int* p2 = p1;     // p2 → a (5)（复制地址）
*p2 = 10;         // a = 10

// 结果：a = 10, *p1 = 10, *p2 = 10
模拟4：二维数组地址推演
元素偏移量地址(假设base=0x1000)
arr[0][0]0 字节0x1000
arr[0][1]4 字节0x1004
arr[0][2]8 字节0x1008
arr[1][0]12 字节0x100C
arr[1][1]16 字节0x1010
arr[1][2]20 字节0x1014

int arr[2][3]：每行3个int(12字节)，arr+1 地址增量12字节。

模拟5：三种传递方式效果对比
cpp
void byValue(int x)     { x = 100; }     // 值传递
void byRef(int& x)      { x = 200; }     // 引用传递
void byPointer(int* x)  { *x = 300; }    // 指针传递

int a = 1, b = 2, c = 3;
byValue(a);          // a 仍是 1（修改副本）
byRef(b);            // b 变成 200（直接修改）
byPointer(&c);       // c 变成 300（通过地址修改）

// 结果：a=1, b=200, c=300
模拟6：指针差值（不是字节差！）
cpp
int arr[5] = {1, 2, 3, 4, 5};
int* p1 = arr;        // p1 → arr[0]
int* p2 = arr + 2;    // p2 → arr[2]
cout << p2 - p1;     // 输出 2（相差 2 个元素）

// 注意：不是 8 字节！是指针差 = 元素个数
// (p2地址 - p1地址) / sizeof(int) = 8/4 = 2

5 第五步：常见陷阱

陷阱1：未初始化的指针不能解引用
cpp
int* ptr;      // 野指针，指向随机地址
*ptr = 10;     // 未定义行为！可能崩溃
必须先用 & 获取合法地址再使用。
陷阱2：不能把整数直接赋给指针
cpp
int a = 5;
int* p = a;    // 错误！a 是整数不是地址
int* p = &a;   // 正确：&a 才是地址
陷阱3：指针运算的步长是 sizeof(类型)
cpp
int x = 2;
int* p = &x;
p++;  // 地址 + 4（int 占 4 字节），不是 +1！

// 如果 &x = 0x6ffe14，则 p++ 后 = 0x6ffe18
陷阱4：数组名不是可修改的指针
数组名是一个指针常量，不能做自增操作。
int arr[5]; arr = arr + 1; 编译错误！
但可以 int* p = arr; p++; 正确。
陷阱5：指针变量本身也占内存
指针变量存储的是地址值，它本身是一个变量，占用内存空间（64位系统通常8字节）。
指针大小是固定的（取决于系统位数），与其指向的数据类型大小无关。

选择题（共12题）

第1题 · 指针声明语法（2023/06 第3题）

声明一个指向整型变量的指针的正确语法是？

A. int* ptr;    B. *int ptr;    C. int ptr*;    D. ptr int;

答案：A
解析：星号紧跟在类型名后：int* ptr; 声明 ptr 是指向 int 的指针。
第2题 · 指针与地址（2023/09 第4题）

如果 n 为 int 类型变量，int *p = &n;，则下列说法正确的是？

A. 指针变量 p 的值与变量 n 相同
B. 指针变量 p 的值与变量 n 的地址相同
C. 指针变量 p 指向的值为 'n'
D. 指针变量 p 指向的值与变量 n 的地址相同

答案：B
解析：p 存储的是 &n（即 n 的地址），所以 p 的值和 n 的地址相同。
第3题 · 指针修改数组（2023/09 第9题）

数组 int a[5] = {1,2,3,4,5};，int *p = &a[2];，执行 *p = a[1]; 后数组变为？

A. {1, 2, 2, 4, 5}    B. {1, 3, 3, 4, 5}    C. {1, 2, 3, 3, 5}    D. {1, 2, 4, 4, 5}

答案：A
解析：p 指向 a[2]=3，*p = a[1] 即 a[2]=2。数组变为 {1,2,2,4,5}。
第4题 · 指针偏移访问数组（2023/09 第12题）

下面C++代码执行后输出是？

cpp
int arr[3]={1,2,3}; int *p=NULL; p=arr; p++; cout<<*p<<endl;

A. 1,2,3    B. 1    C. 2    D. 3

答案：C
解析：p 指向 arr[0]，p++ 后指向 arr[1]=2。
第5题 · 指针++后地址（2023/12 第6题）

如果变量x的地址是0x6ffe14，下面代码输出的是？

cpp
int *p=NULL; int x=2; p=&x; p++; cout<<p<<endl;

A. 0x6ffe11    B. 0x6ffe14    C. 0x6ffe18    D. 0x6ffe15

答案：C
解析：int 占 4 字节，p++ 地址 +4。0x6ffe14 + 4 = 0x6ffe18。
第6题 · 二维数组指针解引用（2024/03 第1题）

下面代码中，*(*(arr + 1) + 2) 的值是？

cpp
int arr[2][3] = {{1, 2, 3}, {4, 5, 6}};

A. 2    B. 5    C. 4    D. 6

答案：D
解析：arr+1 指向第二行，*(arr+1)+2 指向第二行第三个元素 = arr[1][2] = 6。
第7题 · 混合传递方式（2024/03 第6题）

执行下述代码，将输出？

cpp
void swap(int a, int &b) { int temp = a; a = b; b = temp; }
int main() { int x = 1, y = 2; swap(x, y); cout << x << y; }

A. 12    B. 21    C. 22    D. 11

答案：D
解析：a 值传递（x不变），b 引用传递（y被修改为temp=1）。结果 x=1, y=1 → 输出11。
第8题 · 值传递vs指针传递（2024/06 第4题）

下面程序运行的结果是？

cpp
void increaseA(int x) { x++; }
void increaseB(int* p) { (*p)++; }
int main() { int a = 5; increaseA(a); cout << a << " "; increaseB(&a); cout << a; }

A. 6 7    B. 6 6    C. 5 6    D. 5 5

答案：C
解析：increaseA值传递不修改a(5)，increaseB指针传递修改a→6。输出 5 6。
第9题 · 指针赋值（2024/06 第5题）

运行下面代码片段的结果是？

cpp
int x = 20; int y = 24; int* p = &x; int* q = &y; p = q;

A. 将x赋值为24    B. 将y赋值为20    C. 将q指向x的地址    D. 将p指向y的地址

答案：D
解析：p = q 是指针赋值，让 p 也指向 y。x 和 y 的值都不变。
第10题 · 指针接力（2024/06 第15题）

小杨的指针接力程序执行完后，a、*p1 和 *p2 的值分别是？

cpp
int a = 5; int* p1 = &a; int* p2 = p1; *p2 = 10;

A. 5 10 10    B. 5 10 15    C. 10 10 10    D. 5 5 10

答案：C
解析：p1和p2都指向a，*p2=10 即 a=10。a=10, *p1=10, *p2=10。
第11题 · 指针差值（2024/09 第5题）

p2 - p1 输出结果是？

cpp
int arr[5]; int *p1 = arr; int *p2 = arr + 3;
cout << p2 - p1;

A. 12    B. 3    C. 字节数    D. 随机值

答案：B（输出 3）
解析：指针相减返回的是元素个数，不是字节数。p2=arr+3, p1=arr，p2-p1=3 个元素。
第12题 · 二维数组元素地址（2024/12 第7题）

给定 int array[2][3]，第一个元素地址为 0x7ffee4065820，则 &array[1][1] 为？（int 32位）

A. 0x7ffee4065824    B. 0x7ffee4065828    C. 0x7ffee406582c    D. 0x7ffee4065830

答案：D
解析：array[1][1] 是第 1×3+1 = 4 个元素（从0开始），偏移 = 4×4 = 16 字节 = 0x10。0x7ffee4065820+0x10=0x7ffee4065830。

判断题（共7题）

判断题第1题（2025/03 第3题）

指针变量本身不占内存。

答案：错误（X）
解析：指针变量本身也是变量，存储地址值，占用内存空间（64位系统通常8字节）。
判断题第2题（2025/06 第1题）

指针的大小与其所指向的变量的数据类型的大小相同。

答案：错误（X）
解析：所有指针在同一平台上大小相同，与指向类型无关（64位系统都是8字节）。
判断题第3题（2025/09 第1题）

数组名是一个指针常量。

答案：正确（√）
解析：数组名是常量指针，指向首元素地址，但不能做 arr++ 自增操作。
判断题第4题（2025/09 第2题）

数组可以像指针一样进行自增操作。

答案：错误（X）
解析：数组名是指针常量，不能 arr++。只有指针变量可以 p++。
判断题第5题（2025/09 第3题）

int* ptr; *ptr = 10; 可以正确定义和初始化指针。

答案：错误（X）
解析：ptr 未初始化（野指针），*ptr=10 向随机地址写入，未定义行为。
判断题第6题（2025/09 第4题）

int a = 5; int *p = a; 能正确初始化指针。

答案：错误（X）
解析：类型不匹配，a 是 int 不是地址。正确写法：int *p = &a;
判断题第7题（2025/12 第1题）

p2 - p1 输出结果是两个指针相差的字节数。

答案：错误（X）
解析：指针相减返回的是元素个数，不是字节数。
