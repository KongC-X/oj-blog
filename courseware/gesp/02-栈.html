1 一、生活引入：弹夹的启发

想象一个手枪弹夹——子弹一颗一颗从顶部压入，但射击时，最先打出去的是最后一颗压入的子弹。先压进去的子弹反而在底部，要等上面的子弹全部射出后才能取出。

这就是 后进先出（Last In, First Out，LIFO） 的典型模型。

生活类比 栈中的对应
压入子弹 push（入栈）
射出子弹 pop（出栈）
弹夹顶部 top（栈顶）
弹夹底部 栈底

其他生活中的栈： - 浏览器的后退：你依次访问 A → B → C，点"后退"先回到 C 的上一个页面 B，再回到 A - 撤销操作（Ctrl+Z）：最后做的操作最先被撤销 - 函数调用：函数 A 调用 B，B 调用 C，C 返回后回到 B，B 返回后回到 A

2 二、核心概念

2.1 什么是栈

栈（Stack） 是一种线性数据结构，只允许在同一端（栈顶）进行插入和删除操作。

2.2 基本原则

LIFO（Last In, First Out）—— 后进先出

最后进入栈的元素，最先被取出；最先进入的元素，最后被取出。

2.3 基本操作

操作 含义 时间复杂度
push(x) 将元素 x 压入栈顶 O(1)
pop() 移除栈顶元素 O(1)
top() / peek() 返回栈顶元素（不移除） O(1)
empty() 判断栈是否为空 O(1)
size() 返回栈中元素个数 O(1)

2.4 栈的应用场景

  • 括号匹配（编译器语法检查）
  • 表达式求值（中缀转后缀）
  • 函数调用栈（递归底层实现）
  • 深度优先搜索（DFS）
  • 撤销/恢复操作
  • 十进制转二进制（除2取余倒排）
📋 栈操作对比总结
操作语法作用时间复杂度
入栈st.push(x)将 x 压入栈顶O(1)
出栈st.pop()移除栈顶元素（不返回值）O(1)
取栈顶st.top()返回栈顶元素（不移除）O(1)
判空st.empty()栈为空返回 trueO(1)
大小st.size()返回元素个数O(1)

⚠️ 注意：pop() 不返回值，必须先 top() 再 pop()。

3 三、代码实现

3.1 C++ STL stack 基本使用

C++ 
#include <iostream>
#include <stack>
using namespace std;

int main() {
    stack<int> st;

    // 入栈
    st.push(10);
    st.push(20);
    st.push(30);

    cout << "栈顶元素: " << st.top() << endl;  // 30
    cout << "栈的大小: " << st.size() << endl;  // 3

    // 出栈
    st.pop();
    cout << "出栈后栈顶: " << st.top() << endl;  // 20

    // 遍历（依次弹出）
    while (!st.empty()) {
        cout << st.top() << " ";
        st.pop();
    }
    // 输出: 20 10
    return 0;
}
🎨 栈操作可视化

3.2 括号匹配（完整代码）

括号匹配是栈最经典的应用。核心思想：遇到左括号入栈，遇到右括号检查栈顶是否匹配。

C++ 
#include <iostream>
#include <stack>
#include <string>
using namespace std;

bool isValid(string s) {
    stack<char> st;
    for (char c : s) {
        if (c == '(' || c == '[' || c == '{') {
            st.push(c);
        } else {
            if (st.empty()) return false;  // 右括号多余
            char top = st.top();
            st.pop();
            // 检查是否匹配
            if (c == ')' && top != '(') return false;
            if (c == ']' && top != '[') return false;
            if (c == '}' && top != '{') return false;
        }
    }
    return st.empty();  // 左括号多余则 false
}

int main() {
    string s1 = "()[]{}";
    string s2 = "([)]";
    string s3 = "((()))";

    cout << s1 << " -> " << (isValid(s1) ? "合法" : "非法") << endl;
    cout << s2 << " -> " << (isValid(s2) ? "合法" : "非法") << endl;
    cout << s3 << " -> " << (isValid(s3) ? "合法" : "非法") << endl;
    return 0;
}

3.3 十进制转二进制

原理：不断除以2取余数，最后将余数倒序输出。

C++ 
#include <iostream>
#include <stack>
using namespace std;

void decimalToBinary(int n) {
    if (n == 0) {
        cout << 0;
        return;
    }

    stack<int> st;
    while (n > 0) {
        st.push(n % 2);  // 余数入栈
        n /= 2;
    }

    while (!st.empty()) {
        cout << st.top();
        st.pop();
    }
}

int main() {
    int n;
    cout << "请输入十进制数: ";
    cin >> n;
    cout << "二进制: ";
    decimalToBinary(n);
    cout << endl;
    return 0;
}

4 四、手工模拟：push/pop 序列推演

示例：依次执行以下操作

push(1) → push(2) → push(3) → pop() → push(4) → pop() → pop() → push(5)

步骤 操作 栈内容（栈顶在右） 说明
1 push(1) [1] 栈空，1入栈
2 push(2) [1, 2] 2压入栈顶
3 push(3) [1, 2, 3] 3压入栈顶
4 pop() [1, 2] 弹出3
5 push(4) [1, 2, 4] 4压入栈顶
6 pop() [1, 2] 弹出4
7 pop() [1] 弹出2
8 push(5) [1, 5] 5压入栈顶

最终栈内元素：[1, 5]（自底向上），栈顶为 5

判断出栈序列是否合法

问题：入栈序列为 1, 2, 3, 4, 5，以下哪个出栈序列是合法的？

出栈序列 是否合法 推理
3, 2, 1, 4, 5 ✅ push1,push2,push3 → pop3 → pop2 → pop1 → push4 → pop4 → push5 → pop5
4, 3, 5, 2, 1 ✅ push1,push2,push3,push4 → pop4 → pop3 → push5 → pop5 → pop2 → pop1
4, 2, 3, 1, 5 ❌ 4出栈时栈中为[1,2,3]→pop4后栈为[1,2,3]→下一个出2不可能，因为3在栈顶挡住了2
3, 5, 1, 2, 4 ❌ 3出栈后栈为[1,2]→要出5须push4,push5→栈[1,2,4,5]→pop5→pop4→栈[1,2]→要出1不可能，1被2挡住

5 五、常见陷阱

🚨 陷阱 1：pop 后立刻 top（空栈访问）
C++ 
stack<int> st;
st.push(1);
st.pop();
int x = st.top();  // ❌ 错误！栈已为空，top() 行为未定义

正确做法：在访问 top() 前务必检查 empty()。

C++ 
if (!st.empty()) {
    int x = st.top();
}
🚨 陷阱 2：pop 不返回值

很多初学者认为 pop() 会返回被删除的元素，但实际上 C++ 的 pop() 只删除、不返回。

C++ 
stack<int> st;
st.push(42);
// 错误写法：
int val = st.pop();  // ❌ 编译错误，pop() 返回 void

// 正确写法：
int val = st.top();  // 先取栈顶
st.pop();            // 再弹出
🚨 陷阱 3：混淆栈和队列
特性栈（Stack）队列（Queue）
原则LIFO（后进先出）FIFO（先进先出）
插入push 到栈顶push 到队尾
删除pop 从栈顶pop 从队首
访问top() 返回栈顶front() 返回队首
💡 记忆口诀

栈像弹夹（后进先出），队列像排队（先进先出）。

给定一个空栈，执行以下操作序列： 操作：push(1), push(2), push(3), pop(), pop(), push(4), push(5), pop() 最终栈中的元素是什么？

答案：D

📝 真题 2（2024年6月第4题）

向一个栈顶为 hs 的链式栈中插入一个指针为 s 的结点时，应执行什么操作？

A. hs->next = s;

B. s->next = hs; hs = s;

C. s->next = hs->next; hs->next = s;

D. s->next = hs; hs = hs->next;

答案：B
解析：解析：链式栈的插入（入栈）使用头插法，新节点 s 的 next 指向当前栈顶 hs，然后更新栈顶指针为 s。

📝 真题 4（2024年9月第3题）

有6个元素，按照 6,5,4,3,2,1 的顺序进入栈S，下列哪一项的出栈序列是不能出现的？
