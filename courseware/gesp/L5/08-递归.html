1 生活引入：俄罗斯套娃

🪆 场景一：俄罗斯套娃

打开一个俄罗斯套娃，里面还有一个更小的娃娃；再打开，还有一个更小的......一直开到最小的那个娃娃（它打不开了——这就是 终止条件！）。

这个"自己包含自己"的过程，就是 递归（Recursion） 的直觉理解。递归函数就是函数内部调用自己，总有一个 base case 让它可以停下来。

🔢 场景二：计算阶乘

想算 5! = 5 × 4 × 3 × 2 × 1，但计算机不会直接算。我们可以说：

5! = 5 × 4!，而 4! = 4 × 3!，...，直到 1! = 1

这就是递归定义的阶乘：factorial(n) = n × factorial(n-1)，终止条件：n ≤ 1 时返回 1。

🎯 本节学习目标

  • 理解递归三要素：终止条件 + 问题分解 + 子问题合并
  • 掌握递归版 Fibonacci 的时间复杂度分析（O(2ⁿ)）
  • 能手工追踪 fun(n) 的递归调用输出序列
  • 牢记递归必须有终止条件，否则栈溢出

2 核心概念

📐 递归三要素

🔵 定义

递归（Recursion）：一个函数直接或间接调用自身的过程。每一次递归调用都缩小问题的规模，直到达到某个终止条件（base case）后逐层返回。

📌 递归三要素
  1. 终止条件（Base Case）：递归必须有一个可停下来的条件，防止无限递归
  2. 问题分解：将原问题分解为规模更小的同类子问题
  3. 子问题合并：利用子问题的解构造原问题的解

📊 递归 vs 迭代对比

对比维度递归迭代
实现方式函数调用自身循环（for/while）
代码风格简洁直观，接近数学定义需要手动管理循环变量
栈空间每次调用分配栈帧，有开销通常 O(1)
风险层数过多 → 栈溢出无明显风险
可读性对分治问题更直观对简单重复问题更直观
可转换所有递归都可以转换为迭代（反之亦然）

🔤 递归栈空间

✨ 栈是递归的底层机制

每次递归调用，系统都会在新分配的栈帧中存储：局部变量、返回地址、参数等。递归层数过深时，栈空间被耗尽 → 栈溢出（Stack Overflow）。

C++ 默认栈大小通常约 1-8MB，如果每层递归 100 字节，大约可支持 1 万~ 8 万层（但实际往往更少）。

3 代码详解

🔢 阶乘：递归 vs 迭代

🔁 递归版（简洁直观）
C++ 
int factorialA(int n) {
    if (n <= 1) return 1;          // 终止条件
    return n * factorialA(n - 1);  // 问题分解
}
// 调用：factorialA(5) → 5*f(4) → 4*f(3) → 3*f(2) → 2*f(1) → 返回 120
🔄 迭代版（高效无栈开销）
C++ 
int factorialB(int n) {
    if (n <= 1) return 1;
    int res = 1;
    for (int i = 2; i <= n; i++) res *= i;
    return res;
}

🐰 斐波那契：递归 vs 迭代

⚠️ 递归版 — O(2ⁿ)，非常慢！
C++ 
int fibB(int n) {
    if (n <= 1) return n;
    return fibB(n - 1) + fibB(n - 2);  // 大量重复计算！
}
// fibB(5) 会计算 fibB(3) 两次、fibB(2) 三次...
🔄 迭代版 — O(n)
C++ 
int fibA(int n) {
    if (n <= 1) return n;
    int f1 = 0, f2 = 1;
    for (int i = 2; i <= n; ++i) {
        int temp = f2;
        f2 = f1 + f2;
        f1 = temp;
    }
    return f2;
}

⚡ 快速幂递归版

C++ 
double quickPow(double x, unsigned n) {
    if (n == 0) return 1;                    // 终止条件
    if (n == 1) return x;
    double half = quickPow(x, n / 2);        // 只算一次！
    return half * half * ((n & 1) ? x : 1);  // 合并
}
// 时间复杂度 O(log n)
// 注意：如果写成 quickPow(x,n/2)*quickPow(x,n/2) 就退化成 O(n)！

🔄 辗转相除法递归版

C++ 
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}

🗼 汉诺塔（经典递归）

C++ 
void hanoi(int n, char from, char to, char aux) {
    if (n == 1) {
        cout << "盘" << n << "：" << from << "→" << to << endl;
        return;
    }
    hanoi(n - 1, from, aux, to);     // 把 n-1 个从 from 移到 aux
    cout << "盘" << n << "：" << from << "→" << to << endl;
    hanoi(n - 1, aux, to, from);     // 把 n-1 个从 aux 移到 to
}

🔄 递归反序求和

C++ 
// 递归求和：sumB(n) = n + sumB(n-1)
int sumA(int n) { int res=0; for(int i=1;i<=n;i++) res+=i; return res; }
int sumB(int n) { if (n==1) return 1; return n + sumB(n-1); }

🐰 递归 fib(5) 的计算树

fib(5)
├── fib(4)
│ ├── fib(3)
│ │ ├── fib(2)
│ │ │ ├── fib(1) = 1
│ │ │ └── fib(0) = 0
│ │ └── fib(1) = 1
│ └── fib(2)
│ ├── fib(1) = 1
│ └── fib(0) = 0
└── fib(3)
    ├── fib(2)
    │ ├── fib(1) = 1
    │ └── fib(0) = 0
    └── fib(1) = 1
⚠️ 注意 fib(3) 被计算了 2 次，fib(2) 被计算了 3 次！

这就是递归版 Fibonacci 时间复杂度 O(2ⁿ) 的原因——大量重复计算。

5 常见陷阱

🚨 陷阱 1：递归必须有终止条件

"递归函数必须具有一个终止条件，以防止无限递归"——这句话是 ✅ 对的。没有终止条件的递归函数会无限调用自身，最终导致 栈溢出（Stack Overflow）。

GESP 高频判断题第 1 名。

🚨 陷阱 2：递归版 fib 时间复杂度是 O(2ⁿ)

"fibB 采用递归方式，时间复杂度为 O(n)"→ ❌ 错。

递归版斐波那契 fib(n) = fib(n-1) + fib(n-2)，每一次调用都产生两个子调用，总调用次数 ≈ 2ⁿ，时间复杂度为 O(2ⁿ)，不是 O(n)。

迭代版才是 O(n)。

🚨 陷阱 3：递归版 GCD 效率不一定更高

"当 a 较大时，递归版 gcd 的执行效率更高"→ ❌ 错。递归版有函数调用栈开销，效率通常不如循环版。

🚨 陷阱 4：sin(sin(x)) 不是递归调用

"语句 y = sin(sin(x)) 是一种递归调用"→ ❌ 错。sin() 是 C++ 标准库函数，不是自己调用自己，所以不是递归。递归必须是函数自己调用自己。

🚨 陷阱 5：不是所有递归改写都需要显式栈

"所有递归程序改写为非递归都需要显式栈"→ ❌ 错。尾递归和简单递归（如阶乘、斐波那契）可以直接用循环改写，无需显式栈。只有需要保存多层调用状态的递归（如 DFS 遍历树）才需要显式栈。

6 真题实战

📌 考点一：递归概念与终止条件
📝 真题 1（2026/03 第9题）

递归调用的层数过多，会因为什么引发错误？

A. 系统分配的栈空间溢出
B. 堆空间溢出
C. 队列空间溢出
D. 链表空间溢出

答案：A · 每次递归调用分配栈帧，层数过多会导致栈空间耗尽（Stack Overflow）。
📝 真题 2（2024/03 第14题）

递归函数必须满足什么条件以避免无限递归？

A. 有终止条件
B. 函数参数递减
C. 函数返回值固定
D. 以上都对

答案：A · 递归必须有一个 base case（终止条件），参数不一定递减（如辗转相除时参数可能会变化方向）。
📌 考点二：阶乘与求和递归
📝 真题 3（2024/03 第3题）

计算阶乘的递归代码，横线应填入什么？

int factorial(int n) {
    if (n == 0 || n == 1) return 1;
    else { _________________________________ }
}

A. return n * factorial(n - 1);
B. return factorial(n - 1) / n;
C. return n * factorial(n);
D. return factorial(n / 2) * factorial(n / 2);

答案：A · 阶乘递归定义：n! = n × (n-1)!，终止条件为 n==0 或 n==1 时返回 1。
📝 真题 4（2024/09 第3题）

求和的两种实现，说法错误的是哪一个？

int sumA(int n) { int res=0; for(int i=1;i<=n;i++) res+=i; return res; }
int sumB(int n) { if (n==1) return 1; return n + sumB(n-1); }

A. sumA 体现了迭代思想
B. sumB 采用递归
C. sumB 比 sumA 时间效率更高
D. 功能相同

答案：C · sumB 是递归实现，有函数调用栈开销，时间效率通常不如迭代版 sumA。
📝 真题 4a（2025/12 第13题）

阶乘的两种实现，说法错误的是哪一项？

factorialA(n): if (n<=1) return 1; return n * factorialA(n-1);
factorialB(n): if (n<=1) return 1; int res=1; for(i=2..n) res*=i; return res;

A. 两个函数功能相同
B. 时间复杂度均为 O(n)
C. factorialA 采用递归
D. factorialB 采用递归方式

答案：D · factorialB 使用 for 循环，是迭代（递推）方式，不是递归方式。factorialA 才是递归方式。
📌 考点三：斐波那契递归
📝 真题 5（2024/12 第4题）

斐波那契的两种实现，说法错误的是哪一个？

fibA(n) 迭代版: O(n)
fibB(n) 递归版: fib(n)=fib(n-1)+fib(n-2)

A. 两个函数功能相同
B. fibA 采用递推方式
C. fibB 采用递归方式
D. fibA O(n), fibB O(n²)

答案：D · fibB 的时间复杂度是 O(2ⁿ)，不是 O(n²)。递归版每个调用都产生两个子调用。
📝 真题 6（2024/03 第6题）

递归斐波那契的时间复杂度是多少？

A. O(1)
B. O(n)
C. O(2ⁿ)
D. O(log n)

答案：C · 递归版 Fibonacci 的时间复杂度是指数级 O(2ⁿ)，因为大量重复计算。
📝 真题 6a（2024/06 第1题）

斐波那契迭代版函数 fibo() 属于哪种算法？

迭代版 fibo(n): if(n<=1) return n; f1=0,f2=1; for(i=2..n){temp=f2; f2=f1+f2; f1=temp;} return f2;

A. 递归算法
B. 分治算法
C. 迭代算法
D. 贪心算法

答案：C · fibo() 使用 for 循环从底向上计算，不涉及自身调用，属于迭代算法（递推算法）。
📌 考点四：fun 递归函数追踪
📝 真题 7（2024/09 第15题）

fun(7) 的返回值是多少？

int fun(int n) {
    if (n == 1) return 1;
    else if (n >= 5) return n * fun(n - 2);
    else return n * fun(n - 1);
}

A. 105
B. 840
C. 210
D. 420

答案：C · fun(7)=7×fun(5)=7×5×fun(3)=7×5×3×fun(2)=7×5×3×2×fun(1)=7×5×3×2×1=210。
📝 真题 8（2024/06 第14题）

fun(7) 的返回值是多少？

int fun(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    return fun(n - 2) - fun(n - 1);
}

A. 0
B. 1
C. 21
D. -11

答案：D · fun(1)=1, fun(2)=2, fun(3)=1-2=-1, fun(4)=2-(-1)=3, fun(5)=(-1)-3=-4, fun(6)=3-(-4)=7, fun(7)=(-4)-7=-11。

void fun(int n) {

A. 4 3 2 1
B. 1 2 3 4

📝 真题 9a（2024/09 第4题）

有如下函数 fun，则 fun(20, 12) 的返回值为多少？

int fun(int a, int b) {
    if (a % b == 0) return b;
    else return fun(b, a % b);
}

A. 20    B. 12    C. 4    D. 2

答案：C · fun(20,12) → fun(12,8) → fun(8,4) → 4%8=0 → 返回 4。这是辗转相除法（欧几里得算法）求最大公约数的递归版本，gcd(20,12)=4。
📌 考点五：综合题型
📝 真题 10（2025/03 判断第5题）

判断题：递归函数必须具有一个终止条件，以防止无限递归。

A. 正确
B. 错误

答案：正确 ✅ · 这是递归最基本的要求，没有终止条件会导致无限递归和栈溢出。
📝 真题 11（2024/09 第8题）

以下快速幂代码的时间复杂度是多少？

double quick_power(double x, unsigned n) {
    if (n == 0) return 1; if (n == 1) return x;
    return quick_power(x, n/2) * quick_power(x, n/2) * ((n & 1) ? x : 1);
}

A. O(n)
B. O(n²)
C. O(log n)
D. O(n log n)

答案：A · 调用了两次 quick_power(x, n/2)，没有缓存子结果，每次递归规模不变，退化为 O(n)。正确写法应该先存 half = quick_power(x, n/2)，再用 half*half。
📝 真题 12（2024/09 判断第10题）

判断题：对于已经定义好的标准数学函数 sin(x)，应用程序中的语句 y = sin(sin(x)) 是一种递归调用。

A. 正确
B. 错误

答案：错误 ❌ · sin() 是库函数，不是自己调用自己。递归必须是函数自身调用自身。
