💎 GESP C++ 五级 · 唯一分解定理与辗转相除法

Fundamental Theorem of Arithmetic & Euclidean Algorithm

⚡ 16 道选择题 + 8 道判断题 📊 每场必考，年均 2~3 道 ⭐ 占选择判断分 ≈ 12%

1 生活引入：分披萨与积木王国

🍕 场景一：公平分披萨

小明和小红一起点了披萨，长方形的披萨长 84cm、宽 60cm。他们想切成 尽可能大的正方形小块，每块大小相同，且不许有剩余。边长最大能是多少？

这个问题的本质是：找一个能同时整除 84 和 60 的最大数——这就是 最大公约数 (GCD)。

🧱 场景二：积木王国

用乐高积木搭一座塔。最小的积木是「质数砖」，比如 2 号砖、3 号砖、5 号砖… 任何一座塔都可以拆成质数砖的堆叠，而且 拆分方式是唯一的（不计顺序）。

比如：塔 30 只能拆成 2 × 3 × 5，不能是 5 × 6（因为 6 不是质数砖）。这就是 唯一分解定理。

🎯 本节学习目标

  • 理解为何"质数是整数的基本构建块"
  • 掌握辗转相除法求 GCD 的两种写法（循环 / 递归）
  • 牢记 LCM = a / gcd(a,b) × b（先除后乘防溢出）
  • 能手工模拟 gcd(84, 60) 的每一步

2 核心概念

📐 唯一分解定理（算术基本定理）

🔵 定义

任何一个大于 1 的正整数，要么本身是质数，要么可以唯一地分解为一系列质数的乘积（不计排列顺序）。

📌 关键词解析

「大于 1」——1 既不是质数也不是合数，不参与分解。
「质数的乘积」——分解出来的因子必须是质数，不能有合数因子。
「不计排列顺序」——2×3 和 3×2 视为同一种分解。

推论：质数是整数的"基本构建块"，就像化学元素构成化合物一样。

🔢 辗转相除法（欧几里得算法）

🔵 数学原理

gcd(a, b) = gcd(b, a mod b)

当 b == 0 时，a 即为最大公约数。

要点说明
数学原理gcd(a, b) = gcd(b, a % b)
终止条件当余数为 0 时，当前除数即为 GCD
时间复杂度O(log(min(a, b)))
别名欧几里得算法
自动交换即使 a < b，一次迭代后自动交换
✨ LCM 公式（重要）

推荐写法：lcm(a, b) = a / gcd(a, b) * b（先除后乘，防止溢出）

不推荐：a * b / gcd(a, b)——大数相乘可能溢出！

3 算法 / 代码详解

质因数分解模板

C++ 
vector<int> get_prime_factors(int n) {
    vector<int> factors;
    if (n <= 1) return factors;
    // 第一步：处理质因子 2
    while (n % 2 == 0) {
        factors.push_back(2);
        n /= 2;
    }
    // 第二步：处理奇数质因子，只需遍历到 sqrt(n)
    for (int i = 3; i * i <= n; i += 2) {   // ← 高频考点！
        while (n % i == 0) {
            factors.push_back(i);
            n /= i;
        }
    }
    // 第三步：剩下的如果 > 1，一定是质数
    if (n > 2) factors.push_back(n);
    return factors;
}
💡 为什么只循环到 sqrt(n)？

如果 n 有一个大于 sqrt(n) 的因子，它必然配对一个小於 sqrt(n) 的因子。所以遍历到 sqrt(n) 就已覆盖了所有可能的因式组合。

辗转相除法：循环版 vs 递归版

🔁 循环版（推荐日常使用）
C++ 
int gcd(int a, int b) {
    while (b != 0) {
        int temp = b;
        b = a % b;
        a = temp;
    }
    return a;    // ← 高频填空题：return 的是 a 不是 b！
}
🔄 递归版（简洁优雅，但有大数时栈开销较大）
C++ 
int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}

同余概念

🔵 定义

a ≡ b (mod m) 意思是 a 和 b 除以 m 的余数相同。

等价于：m 能整除 (a - b)，即 (a - b) % m == 0。

5 常见陷阱

🚨 陷阱 1：唯一分解 ≠ 分解为"不同的"质数

"任何一个大于1的自然数都可以分解成若干个不同的质数的乘积，且分解方式是唯一的"——这句话是 ❌ 错的。

反例：12 = 2 × 2 × 3，质数 2 出现了两次，并不是"不同的"质数。

🚨 陷阱 2：唯一分解是"乘积"不是"和"

"唯一分解定理表明任何一个大于1的整数都可以唯一地分解为素数之和"——这句话是 ❌ 错的。是素数之积，不是和！

（把整数分解为素数之和是哥德巴赫猜想，完全不同的东西。）

🚨 陷阱 3：gcd 循环版 return 的是 a 不是 b

while (b != 0) { ... } return a;——很多人会误填为 return b！

记住：循环结束后 b 已经变成了 0（上一轮的余数），a 才是 GCD。

🚨 陷阱 4：递归 GCD 比循环 GCD 效率更高？

"当 a 较大时，递归版的 gcd 执行效率更高"——这句话是 ❌ 错的。

递归版有函数调用栈开销，效率通常 不如 循环版。

🚨 陷阱 5：同余——m 必须是 (a-b) 的约数

如果 a ≡ b (mod m)，那么 m 必须能整除 (a - b)。

例如：38 ≡ 14 (mod m)，38 - 14 = 24，m 必须是 24 的约数：1, 2, 3, 4, 6, 8, 12, 24。
9 不是 24 的约数，所以 m = 9 不可能。

6 真题实战

📌 考点一：唯一分解定理的概念
📝 真题 1（2025/03 第5题）

根据唯一分解定理，下面整数的唯一分解正确的是哪一个？

A. 18 = 3 × 6
B. 28 = 4 × 7
C. 36 = 2 × 3 × 6
D. 30 = 2 × 3 × 5

答案：D · 唯一分解要求所有因子都是质数。A 中 6 不是质数，B 中 4 不是质数，C 中 6 不是质数。
📝 真题 2（2024/03 第1题）

唯一分解定理描述了关于正整数的什么性质？

A. 任何正整数都可以表示为两个素数的和
B. 任何大于1的合数都可以唯一分解为有限个质数的乘积
C. 两个正整数的最大公约数总是等于它们的最小公倍数除以它们的乘积
D. 所有素数都是奇数

答案：B · A 是哥德巴赫猜想，C 的公式写反了（应为 lcm = a×b/gcd），D 错在 2 是偶数却是质数。
📝 真题 3（2024/12 第6题）

下面函数将自然数的所有质因素找出来，横线上能填写的最佳代码是哪一个？

while (n % 2 == 0) { factors.push_back(2); n /= 2; }
________________________________ {       // 在此处填入代码
    while (n % i == 0) {
        factors.push_back(i);
        n /= i;
    }

A. for (int i = 3; i <= n; i++)
B. for (int i = 3; i * i <= n; i++)
C. for (int i = 3; i <= n; i += 2)

答案：D · 奇数因子只需从 3 开始每次 +2；循环到 i*i ≤ n 即可（超过 sqrt(n) 的因子必然配对更小的因子）。
📝 真题 4（2025/06 第8题）

唯一分解定理描述的内容是哪一个？

A. 任意整数都可以分解为素数的乘积
B. 每个合数都可以唯一分解为一系列素数的乘积
C. 两个不同的整数可以分解为相同的素数乘积
D. 以上都不对

答案：B · 注意"合数"的限定——质数本身不参与分解，它本身就是"基本构建块"。A 范围过宽（包括任意整数），C 与唯一性矛盾。
📝 真题 5（2025/09 第9题）

唯一分解定理描述的是哪一个？

A. 每个整数都能表示为任意素数的乘积
B. 每个大于 1 的整数能唯一分解为素数幂乘积（忽略顺序）
C. 合数不能分解为素数乘积
D. 素数只有两个因子：1 和自身

答案：B · "大于 1"是限定条件，"素数幂乘积"等价于"质因数分解"，"忽略顺序"即不计排列顺序。
📌 考点二：辗转相除法（GCD & LCM）
📝 真题 6（2025/03 第4题）

用以下辗转相除法求 gcd(84, 60) 的步骤中，第二步计算的数是哪一个？

int gcd(int a, int b) {
    int big = a > b ? a : b;
    int small = a < b ? a : b;
    if (big % small == 0) return small;
    return gcd(small, big % small);
}

A. 84 和 60    B. 60 和 24    C. 24 和 12    D. 12 和 0

答案：B · 第一步 gcd(84,60) → 84%60=24 → 递归 gcd(60,24)，所以第二步是 60 和 24。
📝 真题 7（2024/12 第5题）

两块长方形土地的长宽分别为 24 和 36 米，要将它们分成正方形的小块，使得正方形的尺寸尽可能大。小杨采用辗转相除函数 gcd(24, 36) 来求正方形分块的边长，则函数 gcd 调用顺序是哪一项？

A. gcd(24,36)、gcd(24,12)、gcd(12,0)
B. gcd(24,36)、gcd(12,24)、gcd(0,12)
C. gcd(24,36)、gcd(24,12)
D. gcd(24,36)、gcd(12,24)

答案：C · gcd(24,36) → big=36, small=24, 36%24=12≠0 → 递归 gcd(24,12)。gcd(24,12) → big=24, small=12, 24%12=0 → 返回 12，不再递归。总共 2 次调用。
📝 真题 8（2024/09 第4题）

有如下函数 fun，则 fun(20, 12) 的返回值是多少？

int fun(int a, int b) {
    if (a % b == 0) return b;
    else return fun(b, a % b);
}

A. 20    B. 12    C. 4    D. 2

答案：C · fun(20,12) → fun(12,8) → fun(8,4) → fun(4,0) → 返回 4。
📝 真题 9（2024/06 第5题）

下面是根据欧几里得算法编写的函数，它计算的是 a 与 b 的什么？

int gcd(int a, int b) {
    while (b != 0) { int temp = b; b = a % b; a = temp; }

A. 最小公倍数    B. 最大公共质因子    C. 最大公约数    D. 最小公共质因子

📝 真题 10（2026/03 第4题）

对如下代码实现的欧几里得算法（辗转相除法），执行 gcd(48, 18) 得到的调用序列是哪一项？

int gcd(int a, int b) {
    return b == 0 ? a : gcd(b, a % b);
}

A. gcd(48,18)→gcd(18,12)→gcd(12,6)→gcd(6,0)

C. gcd(48,18)→gcd(18,30)→gcd(30,6)

📝 真题 11（2024/06 第6题）

欧几里得算法递归版本 int gcd(int a,int b){return b==0?a:gcd(b,a%b);}，下面有关说法错误的是哪一项？

A. 本题的 gcd() 实现为递归方式
B. 本题的 gcd() 代码量少，更容易理解其辗转相除的思想
C. 当 a 较大时，递归会多次调用自身，需要较多额外的辅助空间
D. 当 a 较大时，递归版执行效率更高

答案：D · 递归版有函数调用栈开销，效率通常不如循环版。A/B/C 说法正确。
📝 真题 12（2025/06 第6题）

下列C++代码用两种方式求解最大公约数，说法错误的是哪一项？

int gcd0(int big, int small) {  // 辗转相除
    if (big < small) swap(big, small);
    if (big % small == 0) return small;
    return gcd0(small, big % small);
}
int gcd1(int big, int small) {  // 暴力枚举
    if (big < small) swap(big, small);
    for (int i = small; i >= 1; --i)
        if (big % i == 0 && small % i == 0) return i;
    return 1;
}

A. gcd0() 时间复杂度为 O(log n)
B. gcd1() 时间复杂度为 O(n)
C. 一般说来，gcd0() 效率高于 gcd1()
D. gcd1() 中的 for 循环应改为 for (int i = small; i > 1; --i)

答案：D · D 是错误说法——如果改为 i > 1，当两数最大公约数为 1 时，循环结束后不会执行 return 1，函数无返回值，会导致未定义行为。
📝 真题 13（2024/03 第5题）

辗转相除法也被称为什么？

A. 高斯消元法    B. 费马定理    C. 欧几里德算法    D. 牛顿迭代法

答案：C · 辗转相除法是欧几里得在《几何原本》中提出的，因此也称为欧几里德算法。
📝 真题 14（2025/09 第5题）

以下代码计算两个正整数的最大公约数(GCD)，横线上应填写什么？

int gcd0(int a, int b) {

📝 真题 15（2025/12 第4题）

📋 知识速查卡

知识点核心公式 / 代码易错提醒
唯一分解定理 N = p₁a₁ × p₂a₂ × … 质因子可以重复（不是"不同"的质数），是乘积不是和
质因数分解 for(i=3;i*i<=n;i+=2) 先处理 2，再奇数跳过；用完 i*i≤n 而非 i≤n
GCD（循环） while(b){t=b;b=a%b;a=t;} return a; return 的是 a！ 循环结束后 b=0
GCD（递归） return b==0?a:gcd(b,a%b) 简洁但不一定效率更高（有栈开销）
LCM a / gcd(a,b) * b 先除后乘防止溢出，不是 a*b/gcd
同余 a≡b(mod m) ⇔ m | (a-b) m 必须是 (a-b) 的约数
复杂度 O(log min(a,b)) 比暴力枚举 O(n) 快非常多
💡 一句话记住

"质数搭积木，辗转除到底，先除后乘算 LCM，循环 return a 不 return b"
