📐 GESP C++ 五级 · 高精度运算

Big Integer Arithmetic

⚡ 6 道选择题 📊 每场约 1 道 ⭐ 占选择判断分 ≈ 5%

1 生活引入：手机计算器算不出的数

📱 场景：当计算器"溢出"了

拿出手机，打开计算器，试着算 99999999999 × 99999999999（两个 11 位数相乘）。

你会发现结果是一个科学计数法的近似值，而不是精确的每一位数字。这是因为 手机计算器（以及 C++ 的 int/long long）有位数上限。

int 最多存 10 位数（约 21 亿），long long 最多存 19 位数。超过这个范围就会溢出，得到错误结果。

但是在密码学、科学计算、大整数运算中，我们经常需要处理几百位甚至几千位的数字。这时候就需要"手算"的方法——用数组或字符串来模拟竖式计算，这就是高精度运算。

🎯 本节学习目标

  • 理解高精度运算为什么需要"倒序存储"（低位在前）
  • 掌握加法（carry）、减法（borrow）、乘法（逐位乘后统一进位）、除法（大整数÷小整数）的核心代码
  • 牢记常见陷阱：除法用 rem %= b 而非 rem /= b
  • 能手工模拟借位过程

2 核心概念

📐 快速查表：四种运算对比

运算核心思路关键点
加法 逐位相加 + 进位 字符串/vector 倒序存储（低位在前）；carry = sum / 10
减法 逐位相减 + 借位 借位：a[i+1]--; a[i] += 10;；结果去前导零
乘法 c[i+j] += a[i] * b[j] 后统一进位 时间复杂度与两个因数长度都有关，O(m×n)
除法 逐位试商 + 取余（大整数 ÷ 小整数） q = rem/b; rem = rem%b; 参与下一轮

🔤 倒序存储（核心设计）

🔵 为什么低位在前？

高精度运算中，数字以 倒序（低位在前）存储在 vector<int> 中：

例如数字 500 存储为 {0, 0, 5}（个位、十位、百位）。

原因：运算时进位/借位是在高位方向传播的，而 vector 的 push_back 操作在末尾添加元素是 O(1) 的。倒序存储使得进位更自然——只需要在末尾追加。

📌 存储示例

数字 123456 → 倒序存储为 {6, 5, 4, 3, 2, 1}
index 0 = 个位(6), index 1 = 十位(5), index 2 = 百位(4), ...

3 算法 / 代码详解

➕ 高精度加法（字符串版）

C++ 
string add(string num1, string num2) {
    string result;
    int carry = 0;
    int i = num1.size() - 1, j = num2.size() - 1;
    while (i >= 0 || j >= 0 || carry) {
        int x = (i >= 0) ? num1[i--] - '0' : 0;
        int y = (j >= 0) ? num2[j--] - '0' : 0;
        int sum = x + y + carry;
        carry = sum / 10;
        result = to_string(sum % 10) + result;  // 拼接到前面
    }
    return result;
}
💡 注意

字符串版从末尾向前遍历（即从低位到高位），结果拼接时 to_string(sum % 10) + result 是将新位拼到已有结果前面，因为字符串的"前面"是高位。

➖ 高精度减法（vector 版，倒序存储）

C++ 
vector<int> highPrecisionSubtract(vector<int> a, vector<int> b) {
    // 假设 a >= b，输入都是倒序存储（低位在前）
    vector<int> result;
    int borrow = 0;
    for (int i = 0; i < a.size(); ++i) {
        int digitA = a[i];
        int digitB = i < b.size() ? b[i] : 0;
        int diff = digitA - digitB - borrow;
        if (diff < 0) { diff += 10; borrow = 1; }
        else { borrow = 0; }
        result.push_back(diff);
    }
    // 去除前导零
    while (result.size() > 1 && result.back() == 0)
        result.pop_back();                     // ← 高频考点！
    return result;
}

✖️ 高精度乘法（vector 版）

C++ 
vector<int> multiply(vector<int>& a, vector<int>& b) {
    int m = a.size(), n = b.size();
    vector<int> c(m + n, 0);                  // 结果最多 m+n 位
    // 第一步：逐位相乘，累加到对应位置
    for (int i = 0; i < m; i++)
        for (int j = 0; j < n; j++)
            c[i + j] += a[i] * b[j];          // ← 核心：错位相加
    // 第二步：统一处理进位
    int carry = 0;
    for (int k = 0; k < c.size(); ++k) {
        int temp = c[k] + carry;              // ← 高频考点：不是 c[k]
        c[k] = temp % 10;
        carry = temp / 10;
    }
    // 第三步：去除前导零
    while (c.size() > 1 && c.back() == 0) c.pop_back();
    return c;
}
⚡ 乘法时间复杂度

乘法运算时间与两个数长度的乘积有关，即 O(m × n)，不是只与较长者的位数有关！

例如：一个 100 位数 × 一个 3 位数的运算量 ≈ 100×3 = 300，不是 100 或 3。

➗ 高精度除法（大整数 ÷ 小整数）

C++ 
// 被除数 s 为大整数字符串，除数 b 为 int
string s; int b; cin >> s >> b;
vector<int> a, c;
for (char ch : s) a.push_back(ch - '0');
long long rem = 0;
for (int i = 0; i < a.size(); i++) {
    rem = rem * 10 + a[i];                    // 余数右移一位 + 当前位
    int q = rem / b;                          // 当前位商
    c.push_back(q);
    rem %= b;                                 // ← 高频考点：rem %= b 不是 rem /= b！
}
// 输出商 c（去除前导零）和余数 rem

🤔 想一想

在减法代码中，a[i+1]--; a[i] += 10; 为什么是向 i+1 借位而不是向 i-1 借位？

因为数据是倒序存储的！i=0 是低位（个位），i+1 是更高位（十位）。向高位借位，自然是 i+1 而非 i-1。

5 常见陷阱

🚨 陷阱 1：除法用 rem %= b 而不是 rem /= b

高精度除法（大整数 ÷ 小整数）中，处理完当前位的商 q = rem / b 后，下一轮的余数应当来自 rem %= b，而不是 rem /= b。

例如：rem = 12, b = 5 → q = 12/5 = 2，下一轮 rem = 12%5 = 2（不是 12/5 = 2）。虽然这个例子数值碰巧一样，但逻辑上 rem %= b 才是正确的——保留的是"剩下的"而不是"商"。

2026/03 第 15 题就考了这一点：把 rem %= b 错写成 rem /= b。

🚨 陷阱 2：乘法进位时 temp = c[k] + carry

在高精度乘法统一进位阶段，当前位的值 temp = c[k] + carry，不是 temp = c[k]。c[k] 是逐位相乘后累加的原始值，需要加上上一位的进位（carry）才是当前位的完整值。

2025/03 第 15 题考了这一点：横线处应填 int temp = c[k] + carry; 而非 int temp = c[k];。

🚨 陷阱 3：结果要去除前导零

所有高精度运算完成后，都需要去除前导零：

while (c.size() > 1 && c.back() == 0) c.pop_back();

注意：条件中的 c.size() > 1 很重要！如果结果是 0，至少要保留一个 0。忘记这个条件会导致结果为空。

🚨 陷阱 4：乘法时间复杂度与两个因数的长度都有关

"高精度乘法的运算时间只与参与运算的两个整数中长度较长者的位数有关"——这句话是 ❌ 错的（2024/09 第14题考过）。

正确说法：乘法运算时间与两个数长度的乘积有关，即 O(m×n)。一个 100 位数 × 1 位数 和 100 位数 × 100 位数的运算量相差 100 倍！

6 真题实战

📌 考点一：高精度加法
📝 真题 1（2024/03 第7题）

高精度加法字符串版本中，横线上应填写什么？

int sum = x + y + carry;
carry = sum / 10;
_______________________________________

A. result = to_string(sum % 10) + result;
B. result = to_string(carry % 10) + result;
C. result = to_string(sum / 10) + result;
D. result = to_string(sum % 10 + carry) + result;

答案：A · 字符串版是从高位到低位拼接，每次将当前位 sum%10 拼到 result 前面。B 错误拼接了进位值，C 拼接了整除值，D 多加了 carry。
📌 考点二：高精度减法
📝 真题 2（2024/06 第12题）

高精度减法函数中，借位时横线应填写什么？

for (i = 0; i < len2; i++) {
    if (a[i] < b[i]) { // 借位
        _____________ // 在此处填入代码
        a[i] += 10;
    }
    t = a[i] - b[i]; c.push_back(t);
}

A. a[i + 1]--;    B. a[i]--;    C. b[i + 1]--;    D. b[i]--;

答案：A · 借位时向高一位（i+1）借 1，所以 a[i+1]--。因为数组是倒序存储的，i+1 是更高位。B 是对当前位操作没有借位效果。
📝 真题 3（2024/12 第15题）

关于高精度减法函数，说法正确的是？

A. 如果 a < b，代码会正确返回负数
B. 代码假设输入数字以倒序存储，例如 500 存储为 {0, 0, 5}
C. 时间复杂度为 O(a.size() + b.size())
D. 当减法结果为 0 时，结果数组仍然会存储很多个元素 0

答案：B · 倒序存储意味着低位在数组前面（{个位,十位,百位}），500 → {0,0,5}。A 错在需要额外处理符号，C 错在 O(a.size())，D 错在去除前导零后只保留一个 0。
📌 考点三：高精度乘法
📝 真题 4（2025/03 第15题）

高精度乘法统一进位阶段中，横线上应填写什么？

int carry = 0;
for (int k = 0; k < c.size(); ++k) {
    ________________________________ // 在此处填入代码
    c[k] = temp % 10;
    carry = temp / 10;
}

A. int temp = c[k];
B. int temp = c[k] + carry;
C. int temp = c[k] - carry;
D. int temp = c[k] * carry;

答案：B · 处理进位时，当前位的值 = 原来的值 c[k] + 上一位的进位 carry。A 忽略了进位，C/D 错在减法或乘法。
📝 真题 5（2024/09 第14题）

关于高精度运算的说法，错误的是哪一项？

A. 高精度计算主要处理大整数或需要保留多位小数的运算
B. 大整数除以小整数：将被除数和除数对齐，从左到右逐位试商
C. 高精度乘法的运算时间只与参与运算的两个整数中长度较长者的位数有关
D. 高精度加法关键在于逐位相加并处理进位

答案：C · C 是错误的说法。乘法时间与两个数长度的乘积有关 O(m×n)，不是只与较长者有关。
📌 考点四：高精度除法
📝 真题 6（2026/03 第15题）

高精度除法（大整数 ÷ 小整数），横线处应该填写什么？

string s; int b; cin >> s >> b;
vector<int> a, c;
for (char ch : s) a.push_back(ch - '0');
long long rem = 0;
for (int i = 0; i < a.size(); i++) {
    rem = rem * 10 + a[i];
    int q = rem / b;
    c.push_back(q);
    ______________________
}

A. rem /= b;    B. rem %= b;    C. rem = b;    D. rem = q;

答案：B · 高精度除法每次处理一位，商为 q = rem/b，余数 rem = rem % b 参与下一轮。A 是取整而非取余，C/D 均为错误写法。

📋 知识速查卡

运算核心代码易错提醒
加法 carry = sum/10; result = to_string(sum%10) + result; 字符串版 result 拼接到前面；别忘了 while 循环条件含 carry
减法 a[i+1]--; a[i] += 10; 借位是向 i+1（更高位）借；结果用 while 去除前导零
乘法 c[i+j] += a[i]*b[j]; int temp = c[k]+carry; 进位公式 c[k]+carry（不是 c[k]）；复杂度 O(m×n)
除法 q = rem/b; rem %= b; rem %= b（不是 rem /= b）
前导零 while(c.size()>1 && c.back()==0) c.pop_back(); c.size()>1 不可省，否则结果为 0 时数组变空
倒序存储 500 → {0, 0, 5} 低位在前（i=0 是个位），借位/进位向 i+1 方向
💡 一句话记住

"倒序存、逐位算、借位向高位、进位加 carry、除法用取余、结果去前导零"
