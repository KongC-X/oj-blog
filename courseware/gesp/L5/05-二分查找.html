🔍 GESP C++ 五级 · 二分查找

Binary Search & Binary Search on Answer

⚡ 11 道选择题 + 8 道判断题 📊 每场约 1~2 道 ⭐ 占选择判断分 ≈ 8%

1 生活引入：查字典

📖 场景一：查英文单词

你想查字母 g 开头的单词，先翻到字典约一半的位置，发现这页是字母 m 开头。因为 g 在 m 前面，你直接排除后半本，只在前半本继续找。

然后再翻到前半本的中间，发现是 d，g 在 d 后面，于是排除前半段... 每次排除一半，很快就能定位到 g。

这就是 二分查找 的核心思想：每次将搜索区间缩小一半。

🎯 场景二：猜数字游戏

小杨心里想了一个 1~100 之间的数，你每次可以猜一个数，小杨只告诉你"大了"还是"小了"。你怎样用最少的次数猜到？

最优策略：每次都猜中间的数。比如第一次猜 50，如果大了就猜 25，小了就猜 75... 最多 7 次 就能找到！（因为 ⌈log₂100⌉ = 7）

🎯 本节学习目标

  • 掌握经典二分查找的 while(left <= right) 模板
  • 掌握左边界二分（right = mid）和右边界二分（mid = (low+high+1)/2）
  • 理解二分答案的 check 函数验证模式
  • 熟记防溢出写法 mid = left + (right - left) / 2

2 核心概念

📐 二分查找的前提与原理

🔵 核心前提

数据必须有序。 二分查找依赖于"中间值与目标值比较后可以排除一半区间"这一性质。如果数据无序，无法判断目标值在左半还是右半。

📌 核心原理

每次取当前区间的中间元素，与目标值比较：

  • 相等 → 找到
  • 中间值 < 目标 → 排除左半，搜索右半
  • 中间值 > 目标 → 排除右半，搜索左半

时间复杂度：O(log n)

🔢 三种二分模板对比

模板循环条件mid 计算区间收缩
经典二分（找目标值） while (left ≤ right) mid = left + (right - left) / 2 left = mid+1 或 right = mid-1
左边界（第一个 ≥ target） while (left < right) mid = left + (right - left) / 2 right = mid
右边界（最后一个 ≤ target） while (low < high) mid = (low + high + 1) / 2 low = mid

🔍 二分答案

🔵 什么是二分答案？

当问题要求"求最大的可行值"或"最小的可行值"时，我们可以二分答案，然后用 check(mid) 函数验证该值是否可行。如果可行，则继续在更大/更小的范围二分。

✨ 典型场景

✓ 切木头：给定 n 根木头，要切成至少 m 段等长木段，求最大长度
✓ 分配点：从 n 个位置中选 k 个点，使相邻最小距离最大化
✓ 平方根：二分计算一个数的平方根

3 代码详解

📌 模板一：经典二分查找

C++ 
int binarySearch(vector<int>& nums, int target) {
    int left = 0, right = nums.size() - 1;
    while (left <= right) {               // 注意：left <= right
        int mid = left + (right - left) / 2;  // 防溢出写法
        if (nums[mid] == target) return mid;
        else if (nums[mid] < target) left = mid + 1;
        else right = mid - 1;
    }
    return -1;  // 未找到
}
💡 为什么用 left + (right - left) / 2 而不是 (left + right) / 2？

当 left 和 right 都非常大时，left + right 可能导致 int 溢出。用 left + (right - left) / 2 避免溢出。

📌 模板二：左边界二分

C++ 
// 找第一个 >= target 的位置
int getLeftBoundary(vector<int>& nums, int target) {
    int left = 0, right = nums.size() - 1;
    while (left < right) {               // 注意：left < right
        int middle = left + (right - left) / 2;
        if (target <= nums[middle])
            right = middle;              // ← 不是 middle - 1 ！
        else
            left = middle + 1;
    }
    return nums[left] == target ? left : -1;
}
🟣 左边界二分要点

循环条件：while (left < right)，区间收缩：right = mid（不是 mid-1）。

📌 模板三：右边界二分

C++ 
// 找最后一个 <= target 的位置
int binary_search_last(vector<int>& lst, int target) {
    int low = 0, high = lst.size() - 1;
    while (low < high) {
        int mid = (low + high + 1) / 2;    // ← +1 防止死循环！
        if (lst[mid] <= target)
            low = mid;                     // 向右收缩
        else
            high = mid - 1;
    }
    return lst[low] == target ? low : -1;
}
🟣 右边界二分要点

循环条件：while (low < high)，mid 计算：mid = (low + high + 1) / 2（必须 +1），区间收缩：low = mid。

📌 模板四：二分答案

C++ 
// 求"最大的可行解"典型模板
int l = 1, r = max_value, ans = 0;
while (l <= r) {
    int mid = l + (r - l) / 2;
    if (check(mid)) {      // 验证 mid 是否可行
        ans = mid;         // 记录当前可行解
        l = mid + 1;       // 尝试更大的解
    } else {
        r = mid - 1;       // mid 太大，收缩右边
    }
}
return ans;
💡 二分答案通用模式

check(mid) 函数判断"解为 mid 时是否满足条件"。对于"最大值最小化"类问题，check 返回 true 时收紧上界（r = mid）；对于"最小值最大化"类问题，check 返回 true 时收紧下界（l = mid）。

5 常见陷阱

🚨 陷阱 1：二分查找只适用有序数组，不适用链表

"二分查找适用于无序数组和有序数组"——这句话是 ❌ 错的。

"二分查找适用于链表"——也不对。因为二分查找需要 跳跃式访问 中间元素，链表需要 O(n) 才能找到中间节点，失去了 O(log n) 的优势。

🚨 陷阱 2：左边界查找时 right = mid，不是 right = mid - 1

在左边界查找（找第一个 ≥ target）中，当 target ≤ nums[middle] 时，答案可能在 mid 或其左边，所以用 right = middle（保留 mid）。

如果写成 right = middle - 1，可能会 跳过正确答案。

🚨 陷阱 3：右边界查找时 mid = (low + high + 1) / 2

普通二分用 mid = (low + high) / 2。但在右边界查找中，当 low = mid 时，如果不用 +1，当 low + 1 = high 时 mid = low，导致 死循环！

口诀：有 low = mid 就要在 mid 计算中 +1。

🚨 陷阱 4：mid = left + (right - left) / 2 防止溢出

当 left 和 right 都很大时（比如接近 INT_MAX），left + right 会溢出变成负数，导致 mid 计算错误。

推荐写法：mid = left + (right - left) / 2

🚨 陷阱 5：[1, 100] 猜数最多猜 7 次

二分查找每次排除一半。n 个元素最多需要 ⌈log₂n⌉ 次比较。

⌈log₂100⌉ = 7（因为 2⁶=64 < 100 ≤ 2⁷=128），所以最多猜 7 次，不是 10 次、也不是 5 次。

6 真题实战

📌 考点一：经典二分查找
📝 真题 1（2025/03 第11题）

二分法在 [1, 100] 内猜数，最多需要猜多少次？

A. 100    B. 10    C. 7    D. 5

答案：C · ⌈log₂100⌉ ≈ 6.64 → 最多 7 次。64 < 100 ≤ 128，需要 7 次二分。
📝 真题 2（2025/03 第12题）

在二分查找中计算 mid，下面最佳代码是哪一个？

A. int mid = left + (right - left) / 2;
B. int mid = left;
C. int mid = (left + right) / 2;
D. int mid = right;

答案：A · A 防止 left+right 溢出，是最佳写法。C 也能正确计算但可能溢出。
📝 真题 3（2024/12 第11题）

下面是递归实现的二分查找，关于该程序描述不正确的是哪一个？

A. 每次计算中点，排除一半搜索区间
B. 采用递归求解，每次问题规模减半
C. 递归终止条件是中间元素值等于 target，若数组不含该元素则递归不会终止
D. 复杂度为 O(log n)

答案：C · 递归还有 left > right 的终止条件，不含 target 时会走到这个分支返回 -1。
📝 真题 4（2024/09 第13题）

在数组 [1, 3, 6, 9, 17, 31, 39, 52, 61, 79] 中二分查找 31，while 循环执行了多少次？

A. 1    B. 2    C. 3    D. 4

答案：C · ① mid=4(17)<31→left=5；② mid=7(52)>31→right=6；③ mid=5(31)=31→找到。共 3 次。
📌 考点二：左边界 / 右边界二分
📝 真题 5（2026/03 第8题）

下面是查找左边界的代码，横线上应填入什么？

while (left < right) {
    int middle = left + (right - left) / 2;
    if (target <= nums[middle])
        ________________________________ // 在此处填入代码
    else
        left = middle + 1;
}

A. right = middle - 1;    B. right = middle;    C. right = middle + 1;    D. 以上都不对

答案：B · 找左边界时，target ≤ nums[middle] 说明答案可能在 mid 或其左边，用 right=middle 保留 mid。
📝 真题 6（2025/06 第11题）

关于查找最后一次出现位置（右边界）的代码，以下说法正确的是哪一个？

A. 存在重复 target 时总能返回最后位置，即便数组全由相同元素组成
B. 当 target 小于所有元素时，返回 0
C. 改为 while (low <= high) 效果相同
D. 改为 (low + high) / 2 效果相同

答案：A · B 错（应返回 -1），C 和 D 可能导致死循环。A 正确，右边界模板能正确处理重复元素。
📌 考点三：二分答案
📝 真题 7（2026/03 第7题）

下面程序的运行结果是什么？

bool check(int n, int a[], int k, int dist) {
    int cnt = 1, last = a[0];
    for (int i = 1; i < n; i++)
        if (a[i] - last >= dist) { cnt++; last = a[i]; }
    return cnt >= k;
}
int solve(int n, int a[], int k) {
    sort(a, a + n);
    int l = 0, r = a[n-1] - a[0];
    while (l < r) {
        int mid = (l + r + 1) / 2;
        if (check(n, a, k, mid)) l = mid;
        else r = mid - 1;
    }
    return l;
}
int main() {
    int a[] = {1, 2, 8, 4, 9};
    cout << solve(5, a, 3) << endl;
}

A. 2    B. 3    C. 4    D. 5

答案：B · 排序后 {1,2,4,8,9}，选3个点最大最小距离。二分答案，dist=3 时可选 {1,4,8} 满足 3 个点。
📝 真题 8（2026/03 第10题）

给定 n 根木头，第 i 根长度为 a[i]，要切成不少于 m 段等长木段，求最大可能长度。横线上分别应填写什么？

long long l = 1, r = mx, ans = 0;
while (l <= r) {
    long long mid = l + (r - l) / 2;
    if (check(mid)) {
        ans = mid;
        ______________________
    } else {
        ______________________
    }

A. l = mid + 1; 和 r = mid - 1;
B. l = mid - 1; 和 r = mid + 1;

答案：A · 这是"最大的可行解"二分模板。check(mid) 返回 true 时记录答案并收紧下界 l=mid+1。

📋 知识速查卡

🔢 三种二分模板对比

模板循环条件mid 计算区间收缩与易错点
经典二分 while (left ≤ right) mid = left + (right - left) / 2 left=mid+1, right=mid-1；找到即返回
左边界 while (left < right) mid = left + (right - left) / 2 right = mid（不是 mid-1）；最后判 left 是否等于 target
右边界 while (low < high) (low + high + 1) / 2 +1 防死循环；low = mid；最后判 low 是否等于 target
二分答案（最大可行） while (l ≤ r) mid = l + (r - l) / 2 check(mid) 可行 → ans=mid, l=mid+1；不可行 → r=mid-1
二分答案（最小可行） while (l ≤ r) mid = l + (r - l) / 2 check(mid) 可行 → ans=mid, r=mid-1；不可行 → l=mid+1

要点公式/写法说明
防溢出 midleft + (right - left) / 2代替 (left+right)/2，防 INT 溢出
左边界口诀target ≤ nums[mid] → right = mid保留 mid，可能含正确答案
右边界防死循环mid = (low + high + 1) / 2有 low = mid 时必须 +1

💡 一句话记住

"有序才二分，mid 防溢出；左界 right=mid，右界 mid 要加一；check 验证二分答案，log₂n 算次数。"
