1 生活引入：火车车厢

🚂 场景一：火车编组站

一列火车的每节车厢，只知道自己前面是谁、后面是谁。如果你想在中间加一节车厢，只需要断开一节挂钩，挂上新车厢，再重新连接——不需要移动整车。

这就是 链表 的核心思想：节点之间用指针连接，插入删除不用搬动数据。

🔄 场景二：音乐播放器

手机上播放音乐的"播放列表"：当前歌曲放完后自动切到下一首，也可以点"上一首"返回。如果开启循环播放，最后一首播完又回到第一首——这就是 循环链表。

🎯 本节学习目标

  • 理解链表节点结构（data + next/prev）和三种链表类型
  • 掌握单链表/双链表的插入与删除操作
  • 掌握虚拟头节点的用途与 Floyd 快慢指针判环
  • 熟记链表 vs 数组的核心区别（高频考点！）

2 核心概念

📦 节点结构

🔵 单链表节点

struct Node { int data; Node* next; };——数据域 + 一个指针指向后继。

🟣 双链表节点

struct Node { int data; Node* prev; Node* next; };——数据域 + prev 指针 + next 指针，可双向遍历。

📊 链表 vs 数组

对比维度数组链表
随机访问O(1) 直接取下标O(n) 必须从头遍历
插入/删除（已知位置）O(n) 需移动元素O(1) 只改指针
存储空间连续，可能浪费离散，额外存指针（占用更多）
大小固定（或需重新分配）动态调整
缓存友好性连续存储，缓存友好分散存储，缓存不友好
适用场景读多写少、需随机访问频繁增删、大小不确定

🔗 三种链表对比

类型节点结构遍历方向尾节点 next典型应用
单链表data + next只能单向nullptr栈、队列实现
双链表data + prev + next可双向nullptr需要前驱/后继的场景
单循环链表data + next单向循环指向头节点约瑟夫问题、进程调度
双循环链表data + prev + next双向循环指向头节点，头 prev 指向尾需要双向遍历的环

🎭 虚拟头节点（Dummy Head）

🔵 为什么需要虚拟头节点？

当我们需要删除链表中所有值为 val 的节点时，如果头节点本身也需要删除，处理逻辑就会变得特殊。引入一个虚拟头节点作为原链表的前驱，统一了所有节点的删除逻辑。

📌 核心思路

在原始头节点 head 前添加一个 dummy 节点，cur 从 dummy 开始遍历。这样即使要删原 head，也能用统一的"删 cur->next"逻辑处理。

3 代码详解

📎 单链表操作模板

🔹 节点定义 + 插入 + 删除
C++ 
struct Node { int data; Node* next; };

// 在 p 之后插入新节点（两步操作）
void insertAfter(Node* p, int val) {
    Node* newNode = new Node{val, nullptr};
    newNode->next = p->next;   // ① 新节点的 next = p 的 next
    p->next = newNode;         // ② p 的 next = 新节点
}

// 删除 p 之后的节点
void deleteAfter(Node* p) {
    if (p == nullptr || p->next == nullptr) return;
    Node* temp = p->next;
    p->next = p->next->next;   // 跳过一个节点
    delete temp;
}

// 查找（必须从头遍历） O(n)
Node* find(Node* head, int target) {
    Node* p = head;
    while (p != nullptr) {
        if (p->data == target) return p;
        p = p->next;
    }
    return nullptr;
}

🔗 双链表插入与删除

🟣 在 p 之后插入 s —— 四步顺序（高频考点！）
C++ 
struct Node { int data; Node* prev; Node* next; };

// 在 p 之后插入新节点 s（正确顺序）
s->next = p->next;      // ① 新节点的 next
p->next->prev = s;      // ② 原后继的 prev 指向 s
s->prev = p;            // ③ 新节点的 prev
p->next = s;            // ④ p 的 next 指向 s

// 删除 p 节点（p 的前驱后继均非空）
p->prev->next = p->next;   // 前驱跳过 p
p->next->prev = p->prev;   // 后继跳过 p
delete p;
💡 插入顺序口诀

"先处理新节点 → 再断裂旧链接"：必须在 p->next = s 之前先设置 s->next 和 p->next->prev，否则会丢失原后继节点的引用。

🎭 虚拟头节点（统一删除逻辑）

C++ 
Node* removeElements(Node* head, int val) {
    Node dummy(0, head);        // 虚拟头节点，next 指向原 head
    Node* cur = &dummy;
    while (cur->next != nullptr) {
        if (cur->next->data == val) {
            Node* tmp = cur->next;
            cur->next = cur->next->next;   // 跳过要删的节点
            delete tmp;
        } else {
            cur = cur->next;
        }
    }
    return dummy.next;          // 返回新的头节点
}

🐢 Floyd 快慢指针判环

🔵 算法思想

慢指针 slow 每次走 1 步，快指针 fast 每次走 2 步。如果链表有环，两指针最终会相遇；如果 fast 走到 nullptr，则无环。

C++ 
bool hasCycle(Node* head) {
    if (head == nullptr || head->next == nullptr) return false;
    Node* slow = head;
    Node* fast = head->next;    // 也可 fast = head
    while (fast != nullptr && fast->next != nullptr) {
        if (slow == fast) return true;   // 相遇 → 有环
        slow = slow->next;               // slow 走 1 步
        fast = fast->next->next;         // fast 走 2 步
    }
    return false;               // fast 到 nullptr → 无环
}
🤔 想一想

为什么快指针每次走 2 步而不是 3 步？走 2 步能保证在 O(n) 时间内追上；走 3 步在极端情况下可能"套圈"错过。

4 手工模拟：双向循环链表插入

🎬 在 p 之后插入新节点 s 的四步图解

🖐 插入前状态

链表中有节点 ... ← → A(p) ← → B(p->next) ← → ...

要在 A 之后插入新节点 s。

步骤操作链表变化
步骤① s->next = p->next; s 的 next 指向 B
步骤② p->next->prev = s; B 的 prev 指向 s（不再指向 A）
步骤③ s->prev = p; s 的 prev 指向 A
步骤④ p->next = s; A 的 next 指向 s（不再指向 B）
✅ 插入后结构

... ← → A(p) ← → s(新节点) ← → B(p->next 的原值) ← → ...

口诀：先接后续（s的next、原后继prev指向s），再接前驱（s的prev、p的next指向s）
⚠️ 如果顺序错了会怎样？

如果先把 p->next = s（步骤④提前做），那么原后继 B 节点的引用就丢了！后续无法设置 B 的 prev 指针。

正确顺序的核心：必须在修改 p->next 之前，完成所有需要用到 p->next 原值的操作（步骤①②）。

5 常见陷阱

🚨 陷阱 1：链表不能随机访问，查找 O(n)（最高频考点！）

"链表支持随机访问"或"链表比数组查找更快"都是错误描述。

链表的节点离散存储，必须从头逐个遍历才能找到目标节点。数组通过下标直接定位，是 O(1)。GESP 高频考点！

🚨 陷阱 2：双向循环链表插入顺序必须正确

插入时必须先保存 p->next 的引用（通过设置 s->next 和 p->next->prev），再修改 p->next。

常见错误：先执行 p->next = s，导致原后继节点引用丢失。

🚨 陷阱 3：链表比数组占用更多内存

"存储相同数目的整数，数组比链表所需的内存多"——这句话是 ❌ 错的。

链表每个节点除了存储数据，还要存 1~2 个指针（next 和可能的 prev）。存储相同数量元素时，链表占用的内存反而更多。

🚨 陷阱 4：单链表删除非尾结点（不知道头结点）

如果不知道前驱节点，无法直接删除 p。技巧是：用 p->next 的数据和指针覆盖 p，然后删除 p->next。

// 不知道头节点时删除非尾结点 p
p->data = p->next->data;   // 用后继的值覆盖 p
Node* temp = p->next;
p->next = p->next->next;   // p 跳过原后继
delete temp;                // 删除原后继
🚨 陷阱 5：遍历循环链表必须设终止条件

循环链表中 p->next 永远不会等于 nullptr。如果不用终止条件（如再次遇到头节点），会陷入 死循环。

📌 考点一：链表 vs 数组
📝 真题 1（2026/03 第1题）

链表不具备的特点是哪一个？

A. 数据数量不确定时，链表大小可动态调整

D. 链表的节点在内存中分散存储

关于链表和数组的描述，错误的是哪一个？

📌 考点二：双链表操作
📝 真题 5（2025/03 第2题）

双向链表中删除结点 p（前驱后继均非空），下面代码片段中错误的是哪一个？

A. p->next->prev = p->next;  p->prev->next = p->prev;  delete p;
B. p->prev->next = p->next;  p->next->prev = p->prev;  delete p;
C. p->next->prev = p->prev;  p->next->prev->next = p->next;  delete p;
D. p->prev->next = p->next;  p->prev->next->prev = p->prev;  delete p;
答案：A · A 中 p->next->prev = p->next 让后继的 prev 指向后继自己，断了与 p->prev 的链接。B/C/D 都是正确的删除方式。
📝 真题 6（2026/03 第2题）

双向循环链表中，在节点 p 之后插入新节点 s，正确的操作顺序是哪一个？

A. p->next->prev=s; s->prev=p; p->next=s; s->next=p->next;
B. p->next->prev=s; p->next=s; s->prev=p; s->next=p->next;
C. s->prev=p; s->next=p->next; p->next=s; p->next->prev=s;
D. s->next=p->next; p->next->prev=s; s->prev=p; p->next=s;

答案：D · D 的顺序完全正确：先处理新节点的 next/prev，再调整 p 及其原后继。

📝 真题 15（2025/06 第1题）

📋 知识速查卡

📊 链表 vs 数组核心对比

操作数组链表
随机访问O(1)O(n)
插入/删除（已知位置）O(n)O(1)
存储空间仅存数据。数据 + 1~2 个指针，占用更多
缓存友好性连续，友好离散，不友好
适用场景读多写少、随机访问频繁增删、大小变化大

🔗 插入/删除操作速查

操作正确代码易错提醒
单链表在 p 后插入 s->next=p->next; p->next=s; 顺序不能反，否则链表断裂
单链表删除 p 后一个 Node* t=p->next; p->next=p->next->next; delete t; 必须用 t 临时保存，delete 释放内存
双链表在 p 后插入 s s->next=p->next; p->next->prev=s; s->prev=p; p->next=s; 必须在 p->next=s 之前完成前两步
双链表删除 p（非头尾） p->prev->next=p->next; p->next->prev=p->prev; delete p; 注意两行顺序可以互换，但不能漏
虚拟头节点 Node dummy(0,head); cur=&dummy; cur 从 dummy 开始，不能从 dummy.next 开始
Floyd 判环 slow=slow->next; fast=fast->next->next; 必须先判 fast 和 fast->next 非空
单链删非尾结点（无头） p->val=p->next->val; p->next=p->next->next; delete t; 用后继覆盖后删后继，不能删尾结点
💡 一句话记住

"链表插入改指针，删除要动前后缘；双向四步记顺序，虚拟头统删除；快慢两倍走，相遇即判环。"
