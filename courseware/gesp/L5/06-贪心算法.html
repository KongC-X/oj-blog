Greedy Algorithm

1 生活引入：找零钱的智慧

💰 场景一：收银员找零

你掏出 100 元 买了一个 36 元 的东西，收银员需要找你 64 元。他手上有 50 元、20 元、10 元、5 元、1 元面额的钞票，怎么找最省事？

收银员的做法是：先用 50 元（最大面额），剩 14 元；再用 10 元，剩 4 元；再用 4 张 1 元。全程 每次都拿能用的最大面额，这就是 贪心算法！

📺 场景二：安排电视频道

周末有 5 部电影想录下来：9:00-11:00、10:00-12:00、11:30-13:00、14:00-16:00、15:30-17:00。只有一台录像机，怎么安排才能录最多部？

策略：每次选结束时间最早且不冲突的电影——这就是 区间调度，贪心算法的经典应用。

2 核心概念

📐 什么是贪心算法？

🔵 定义

贪心算法（Greedy Algorithm）：在每一步选择中都采取当前状态下最优（最有利）的选择，从而希望导致结果是全局最优的算法。

📌 关键词解析

「当前最优」——不回溯，不重新考虑之前的选择。
「局部最优」——只看眼前，不考虑长远影响。
「希望全局最优」——不保证！贪心算法不一定得到全局最优解。

⚠️ 最重要的结论

"贪心算法通过每一步选择当前最优解，从而一定能获得全局最优解"——这句话是 ❌ 错的！

贪心只保证局部最优，全局最优需要额外条件（贪心选择性质 + 最优子结构）。

📊 贪心 vs 分治 vs 动态规划

算法核心思想是否回溯典型应用
贪心每步选最优，不回头❌ 不回溯硬币找零、区间调度
分治分解子问题，分别求解后合并—归并排序、快速排序
动态规划记录子问题解，利用最优子结构—背包问题、最长公共子序列

🎯 贪心经典题型表

题型贪心策略常考模式
硬币找零每次用最大面额尽量多找代码填空 / 判断题
区间调度按结束时间升序，选最早结束的不冲突区间选择题 / 排序填空
饼干分配排序后大饼干满足大胃口（双指针）填空题
过河问题最重 + 最轻配对思想判断题
Dijkstra每次选距离起点最近的节点判断题（常考"是贪心"）
💡 Dijkstra 是贪心算法吗？

是的！ Dijkstra 算法每次选择距离起点最近的未访问节点作为当前节点，体现的正是贪心策略——这是一个高频判断题考点。

3 代码详解

📺 区间调度（安排最多不冲突活动）

🔑 核心策略：按结束时间升序排序
C++ 
// 区间调度：安排最多不重叠的活动
// movies[i] = {开始时间, 结束时间}
int maxMovies(vector<vector<int>>& movies) {
    // 关键：按结束时间升序排序
    sort(movies.begin(), movies.end(), [](const vector<int>& a, const vector<int>& b) {
        return a[1] < b[1];    // ← 按结束时间排序！
    });
    int count = 1;  // 至少可以选第一场
    int lastEnd = movies[0][1];
    for (int i = 1; i < movies.size(); i++) {
        if (movies[i][0] >= lastEnd) {  // 开始时间 ≥ 上一场结束时间
            count++;
            lastEnd = movies[i][1];     // 更新结束时间
        }
    }
    return count;
}
💡 为什么按结束时间排序，而不是按开始时间？

选结束最早的活动，能为后面的活动留出最多时间。如果按开始时间排序，可能选了一个很长但开始早的活动，反而挤掉了更多可以安排的活动。

💰 硬币找零

🔑 核心策略：从大到小贪心
C++ 
// 硬币找零：给定面额数组和总金额，求最少硬币数
int coinChange(vector<int>& coins, int amount) {
    // 面额从大到小排序
    sort(coins.begin(), coins.end(), greater<int>());
    int count = 0;
    for (int coin : coins) {
        if (amount == 0) break;
        count += amount / coin;    // 尽量用当前最大面额
        amount %= coin;            // 剩余金额
    }
    return count;
}
// 注意：贪心是否得到最优解取决于硬币面额设计！
// 人民币 {1,2,5,10,20,50,100} 的贪心解 = 最优解
// 但面额为 {1,3,4} 找 6 元时，贪心得 {4,1,1}=3枚，最优是 {3,3}=2枚
🚨 硬币找零的陷阱

贪心算法求解硬币找零不一定能得到最优解！只有在硬币面额满足特定条件（如人民币的 1,2,5 体系）时，贪心才 = 最优解。

反例：面额 {1, 3, 4}，找 6 元。贪心：4+1+1 = 3 枚；最优：3+3 = 2 枚。

🍪 饼干分配

🔑 核心策略：排序 + 双指针（大饼干满足大胃口）
C++ 
// 饼干分配：每个孩子最多一块饼干，求最多满足多少人
// g[] 是孩子的胃口，s[] 是饼干尺寸
int findContentChildren(vector<int>& g, vector<int>& s) {
    sort(g.begin(), g.end());
    sort(s.begin(), s.end());
    int index = s.size() - 1;      // 从最大饼干开始
    int result = 0;
    for (int i = g.size() - 1; i >= 0; i--) {  // 从最大胃口开始
        if (index >= 0 && s[index] >= g[i]) {
            result++;                // ← 经常填空：result++
            index--;                 // ← 经常填空：index--
        }
    }
    return result;
}

🚣 过河问题

🔑 核心策略：最轻 + 最重配对
C++ 
// 过河问题：船最多载2人、承重100，求最少船数
int minBoats(vector<int>& weight) {
    sort(weight.begin(), weight.end());
    int i = 0, j = weight.size() - 1;
    int count = 0;
    while (i <= j) {
        if (weight[i] + weight[j] <= 100) {
            i++;  // 最轻的上船
        }
        j--;      // 最重的肯定上船
        count++;  // 一艘船
    }
    return count;
}

4 手工模拟

🎬 模拟区间调度：贪心选电影

给定 5 场电影的起止时间：

A: [1, 3] B: [2, 5] C: [4, 6] D: [3, 8] E: [7, 9]
步骤操作已选lastEnd说明
排序 按结束时间升序 — — A[1,3] B[2,5] C[4,6] D[3,8] E[7,9]
第1步 选 A [1,3] {A} 3 A 结束最早，必选！
检查 B [2,5] {A} 3 2 < 3 → 冲突，跳过
第2步 选 C [4,6] {A, C} 6 4 ≥ 3 → 不冲突，选！
检查 D [3,8] {A, C} 6 3 < 6 → 冲突，跳过
第3步 选 E [7,9] {A, C, E} 9 7 ≥ 6 → 不冲突，选！
✅ 结果：最多可选 3 场电影 → A[1,3]、C[4,6]、E[7,9]
🤔 想一想

如果按开始时间排序会怎样？顺序为 A[1,3] → B[2,5] → D[3,8] → C[4,6] → E[7,9]。

先选 A，然后 B 冲突跳过，D（3≥3→不冲突）选上，但 D 很长覆盖到 8，导致 C 和 E 都被排除。结果只选了 2 场（A+D），比贪心策略少选 1 场。

5 常见陷阱

🚨 陷阱 1：贪心算法总能得到全局最优解？

"贪心算法通过每一步选择当前最优解，从而一定能获得全局最优解"——这句话是 ❌ 错的。

贪心算法不一定得到全局最优解，它只保证每一步是局部最优。这是 GESP 五级最常考的判断题之一。

🚨 陷阱 2：最优子结构 = 贪心算法的充分条件？

"若一个问题满足最优子结构性质，则一定可以用贪心算法得到最优解"——这句话是 ❌ 错的。

最优子结构是动态规划的条件，不是贪心算法的充分条件。贪心还需要额外的"贪心选择性质"。

🚨 陷阱 3：贪心 vs 分治——概念混淆

"小杨有100元去买东西，目标是买最多数量的商品，策略是每次挑最便宜的买，这体现了分治思想"——❌ 错的。

每次挑最便宜的买 = 贪心策略（每步局部最优），不是分治（分治需要分解+合并）。

🚨 陷阱 4：Dijkstra 是贪心算法

Dijkstra 最短路径算法每次选择距离起点最近的节点，体现了贪心策略。这是一道 ✅ 判断题考点，但很多人会误判为 ❌。

记住：Dijkstra = 贪心算法。

📌 考点一：贪心算法概念
📝 真题 1（2025/03 第13题）

贪心算法的核心特征是什么？

A. 总是选择当前最优解
B. 回溯尝试所有可能

D. 总能找到最优解

答案：A · 贪心算法的核心是在每一步选择中都做当前状态下的最优选择。B 是回溯，C 是分治/DP，D 是错的（贪心不一定得全局最优）。

贪心算法的核心思想是什么？

A. 在每一步选择中都做当前状态下的最优选择
B. 在每一步选择中都选择局部最优解
C. 每一步选择全局最优解
D. 以上都对

答案：A · A 的表述最准确——"当前状态下"体现了贪心的本质（只看眼前，不保证全局）。
