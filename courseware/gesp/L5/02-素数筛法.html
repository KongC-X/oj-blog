🔢 GESP C++ 五级 · 素数筛法

Sieve of Eratosthenes & Linear Sieve

⚡ 12 道选择题 + 8 道判断题 📊 每场必考，年均 2~3 道 ⭐ 占选择判断分 ≈ 12%

1 生活引入：图书馆找书

📚 场景：在图书馆找非小说类书籍

假设你要整理图书馆的书架。图书管理员告诉你：第 2 排第 3 列是非小说类书籍。那你立马就知道，所有第 2 排的书都是非小说——因为第 2 排的所有列（2×1, 2×2, 2×3, ...）都是 2 的倍数。

类似地，如果第 3 排第 2 列是非小说，那第 3 排所有的列也都是非小说。

这样，你只需要知道 第 2 排和第 3 排是非小说，就能把整个图书馆的非小说区域全部标记出来——这就是"筛"的思想。

在数学中，"书架"是 1 到 n 的整数，"非小说"是合数，"没有被标记为合数的"就是质数（素数）。这就是埃拉托斯特尼筛法的灵感来源。

🎯 本节学习目标

  • 理解埃氏筛的核心思想：从 i×i 开始标记 i 的倍数
  • 掌握线性筛的 break 条件：if (i % primes[j] == 0) break;
  • 牢记两种筛法的时间复杂度区别
  • 能手工模拟 n=20 的筛法过程

2 核心概念

🔢 埃氏筛（埃拉托斯特尼筛法）

🔵 基本思想

从小到大遍历，若当前数是质数，将其所有倍数标记为合数。

要点说明
基本思想从小到大，若当前数是质数，将其所有倍数标记为合数
优化从 i * i 开始标记（更小的倍数已被之前的质数标记）
外层循环范围i * i <= n 或 i <= sqrt(n)
时间复杂度O(n log log n)
空间复杂度O(n)
📌 为什么从 i×i 开始？

比 i×i 更小的 i 的倍数（如 2i, 3i, ...）已经被更小的质数标记过了。

例如当 i=5 时，10、15、20 已经被 2 和 3 标记过，所以直接从 25 开始标记。

🔢 线性筛（欧拉筛）

🔵 基本思想

每个合数只被其最小质因数筛选一次，从而实现 O(n) 的线性时间复杂度。

要点说明
基本思想每个合数只被其最小质因数筛选一次
关键机制if (i % primes[j] == 0) break; 保证最小质因数筛选
时间复杂度O(n)
空间复杂度O(n)，需额外质数列表

📊 两种筛法对比

特性埃氏筛线性筛
时间复杂度O(n log log n)O(n)
重复标记有（如 12 被 2 和 3 都标记）无（每个合数只筛一次）
实现难度简单稍复杂
实际速度(n≤10⁷)常数小，往往更快理论更优
推荐场景日常使用、小范围极大范围(n≥10⁷)、需频繁查询

3 算法 / 代码详解

埃氏筛模板

C++ 
vector<int> sieve_Eratosthenes(int n) {
    vector<bool> is_prime(n + 1, true);
    vector<int> primes;
    is_prime[0] = is_prime[1] = false;
    for (int i = 2; i * i <= n; i++) {       // ← 外层循环到 sqrt(n)
        if (is_prime[i]) {
            primes.push_back(i);
            for (int j = i * i; j <= n; j += i)   // ← 从 i*i 开始！
                is_prime[j] = false;
        }
    }
    for (int i = sqrt(n) + 1; i <= n; i++) {
        if (is_prime[i]) primes.push_back(i);
    }
    return primes;
}
💡 关键标注

外层循环：i * i <= n（不是 i <= n）—— 高频填空题！
内层循环：j = i * i（不是 j = 2*i 或 j = i）—— 高频选择题！
步长：j += i（不是 j++）

线性筛（欧拉筛）模板

C++ 
vector<int> linear_sieve(int n) {
    vector<bool> is_prime(n + 1, true);
    vector<int> primes;
    is_prime[0] = is_prime[1] = false;
    for (int i = 2; i <= n; i++) {           // ← 注意：循环到 n！
        if (is_prime[i]) primes.push_back(i);
        for (int j = 0; j < primes.size() && i * primes[j] <= n; j++) {
            is_prime[i * primes[j]] = false;
            if (i % primes[j] == 0) break;  // ← 核心！保证最小质因子
        }
    }
    return primes;
}
⚡ 理解 break 条件

当 i % primes[j] == 0 时，说明 primes[j] 是 i 的最小质因数。此时如果继续循环，下一个质数 primes[j+1] 筛掉的 i * primes[j+1]，其最小质因数仍然是 primes[j]（因为 primes[j] 能整除 i），就不再满足"只被最小质因数筛"的条件了。

🤔 想一想

在线性筛中，合数 12 是在 i=6 时被 primes[0]=2 筛掉的。为什么不在 i=4 时被 primes[1]=3 筛掉呢？

因为 i=4 时，4%2=0 触发 break，不会继续到 primes[1]=3。而 12 的最小质因子是 2，恰好由 i=6 时的 6×2 筛掉。

5 常见陷阱

🚨 陷阱 1：埃氏筛外层循环是 i*i ≤ n，不是 i ≤ n

埃氏筛外层循环写 for (int i = 2; i <= n; ++i) 是多余的计算。正确写法是 i * i <= n 或 i <= sqrt(n)。

因为当 i > sqrt(n) 时，i×i > n，内层循环不会再执行任何标记操作。GESP 2024/03 第 10 题就考了这一点。

🚨 陷阱 2：线性筛 break 条件是 if (i % primes[j] == 0) 而非 if (p % i == 0)

线性筛的核心代码中，break 判断的是 i % primes[j] == 0，不是 primes[j] % i == 0。

许多同学会混淆，写成 if (p % i == 0) 或 if (primes[j] % i == 0)——这是错的！因为我们要判断 i 是否能被 primes[j] 整除。

🚨 陷阱 3：n ≤ 10⁷ 时埃氏筛因常数小反而更快

"线性筛的速度往往优于埃氏筛"——这个说法是❌ 错的（2025/09 第8题考过）。

虽然线性筛理论复杂度 O(n) 优于埃氏筛 O(n log log n)，但在 n ≤ 10⁷ 时，埃氏筛因常数较小（代码更简单、内存访问更连续），速度往往更快。

🚨 陷阱 4：素数表的埃氏筛和线性筛时间复杂度不是都是 O(n log log n)

"素数表的埃氏筛法和线性筛法的时间复杂度都是 O(n log log n)"——这句话是❌ 错的（2024/03 判断第7题考过）。

线性筛时间复杂度是 O(n)，不是 O(n log log n)。

🚨 陷阱 5：线性筛不是被"最大质因子"筛去

"线性筛相比埃氏筛的核心改进在于：每个合数只被其最大质因子筛去"——这是❌ 错的（2026/03 判断第9题考过）。

正确的是：每个合数只被其最小质因子筛去。

6 真题实战

📌 考点一：埃氏筛
📝 真题 1（2024/09 第5题）

埃氏筛内层循环横线上应填什么？

if (is_prime[i]) {
    ________________________________ {
        is_prime[j] = false;
    }
}

A. for (int j = i; j <= n; j++)
B. for (int j = i * i; j <= n; j++)
C. for (int j = i * i; j <= n; j += i)
D. for (int j = i; j <= n; j += i)

答案：C · 内层循环需要 A）从 i*i 开始（避免重复标记）、B）步长为 i（标记 i 的倍数）。只有 C 同时满足两个条件。
📝 真题 2（2024/12 第7题）

关于埃氏筛代码，说法正确的是哪一个？

A. 时间复杂度是 O(n√n)
B. 标记非素数时从 i × i 开始，可以减少重复标记
C. 代码会输出所有小于等于 n 的奇数
D. sieve_Eratosthenes(10) 返回 {2, 3, 5, 7, 9}

答案：B · A 错在时间复杂度是 O(n log log n)；C 错在输出的是质数不是奇数；D 错在 9 不是质数，正确返回 {2, 3, 5, 7}。
📝 真题 3（2026/03 第6题）

埃氏筛中将内层循环从 j = i×i 开始而不是 j = 2×i 的主要原因是？

A. 因为 2×i 一定不是合数
B. i×i 一定是质数
C. 小于 i×i 的 i 的倍数已被更小质因子筛过
D. 这样可以把时间复杂度降为 O(n)

答案：C · 比 i×i 更小的 i 的倍数（如 2i, 3i, ...）已经被更小的质数标记过了，无需重复标记。
📝 真题 4（2025/09 第6题）

埃氏筛内层循环起始值应填什么？

for (int j = ______; j <= n; j += i) { is_prime[j] = false; }

A. i    B. i+1    C. i×2    D. i×i

答案：D · 内层循环从 i×i 开始，避免重复标记已被更小质数筛过的合数。
📝 真题 5（2024/03 第10题）

埃氏筛最外层循环应遍历什么范围？

A. for (int i = 2; i <= n; ++i)
B. for (int i = 1; i < n; ++i)
C. for (int i = 2; i <= sqrt(n); ++i)
D. for (int i = 1; i <= sqrt(n); ++i)

答案：C · 外层循环只需遍历到 sqrt(n)，因为内层从 i×i 开始，i>sqrt(n) 时 i×i>n 不会有任何标记。
📌 考点二：线性筛
📝 真题 6（2024/06 第7题）

线性筛代码横线上应填什么？

for (int j = 0; ________________________________ ; j++) {
    is_prime[i * primes[j]] = false;
    if (i % primes[j] == 0) break;
}

A. j < primes.size()
B. i * primes[j] <= n
C. j < primes.size() && i * primes[j] <= n
D. j <= n

答案：C · 两个条件缺一不可：不越界（j < primes.size()）且不超范围（i*primes[j] <= n）。
📝 真题 7（2026/03 第5题）

线性筛横线上应填什么？

________________________________ { // 在此处填入代码
    is_prime[i * primes[j]] = 0;
    if (i % primes[j] == 0) break;
}

A. for (int j = 0; j < primes.size() && i * primes[j] <= n; j++)
B. for (int j = 1; j < primes.size() && i * j <= n; j++)
C. for (int j = 2; j < primes.size() && i * primes[j] <= n; j++)
D. 以上都不对

答案：A · j 从 0 开始（第一个质数是 primes[0]=2），两个条件：不越界且不超范围。
📝 真题 8（2025/09 第7题）

线性筛 break 条件应填什么？

for (int p : primes) {
    if (p * i > n) break;
    is_prime[p * i] = false;
    if (________) break;
}

A. i % p == 0    B. p % i == 0    C. i == p    D. i * p == n

答案：A · 当 i 能被 p 整除时，p 是 i 的最小质因子，后续质数不应再筛选。B 是错误的常见选项（p%i==0 判断的是反过来的关系）。
📌 考点三：两种筛法对比
📝 真题 9（2025/03 第8题）

A. 埃氏筛可能对同一个合数多次标记
B. 线性筛的理论时间复杂度更优，所以线性筛速度往往优于埃氏筛
C. 线性筛保证每个合数只被其最小质因子筛到一次

📌 考点四：质数判断
📝 真题 12（2025/06 第5题）

关于判断质数（6k±1 优化）代码，说法正确的是？

bool is_prime(int n) {
    if (n <= 1) return false;
    if (n == 2 || n == 3 || n == 5) return true;
    if (n % 2 == 0 || n % 3 == 0 || n % 5 == 0) return false;
    int i = 7, step = 4;
    while (i * i <= n) {
        if (n % i == 0) return false;
        i += step; step = 6 - step;  // 交替 i+=4 和 i+=2 → 即 6k±1
    }
    return true;
}

A. 5 是质数但因为 5%5==0 返回 false
B. finish_number 应该是 n/2
C. 正确前提是所有大于 3 的质数都符合 6k±1 形式
D. 改为 for 循环效果相同

答案：C · 该优化的前提是所有大于 3 的质数都能写成 6k±1 的形式。A 错在 5 在第 3 行就返回 true 了。

📋 知识速查卡

知识点核心代码 / 公式易错提醒
埃氏筛 for(j=i*i; j<=n; j+=i) 从 i*i 开始（不是 2*i 或 i），外层循环 i*i≤n
线性筛 if(i % primes[j] == 0) break; break 条件是 i%primes[j]==0（不是 primes[j]%i==0）
埃氏筛复杂度 O(n log log n) 不是 O(n log n)，有重复标记（如 12 被 2 和 3 都标记）
线性筛复杂度 O(n) 每个合数只被最小质因子筛一次
实际速度(n≤10⁷) 埃氏筛常数小 → 更快 不要盲目选线性筛！小范围埃氏筛更快
质数判断(6k±1) i=7; step=4; i+=step; step=6-step; 前提：所有大于 3 的质数都符合 6k±1 形式
