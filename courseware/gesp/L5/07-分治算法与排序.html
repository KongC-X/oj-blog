1 生活引入：分牌与整理卡片

🃏 场景一：整理一堆扑克牌（归并排序）

桌上有 8 张散乱的扑克牌。你不想一次性排好，而是：先把牌 分成两堆（每堆 4 张），把每堆再分成两堆（每堆 2 张），直到每堆只剩 1 张（自然有序）。然后 两两合并——每次取两堆牌中较小的那张，最终合成一整副有序的牌。

这就是 归并排序（Merge Sort）：先分解到底，再两两合并。

📏 场景二：排排队（快速排序）

体育课上老师让大家按身高排队。老师挑了中间一个同学做"基准"，说："比他矮的站左边，比他高的站右边"。然后对左右两组重复这个操作，直到每个人都站对了位置。

这就是 快速排序（Quick Sort）：选基准（pivot），小的放左边，大的放右边。

2 核心概念

📐 分治算法三步走

🔵 定义

分治算法（Divide and Conquer）：将一个大问题分解为若干个规模较小的同类子问题，分别求解这些子问题，然后将子问题的解合并为原问题的解。

📌 三步走
  1. 分解（Divide）：将原问题分解为若干规模较小的子问题
  2. 求解（Conquer）：递归求解每个子问题
  3. 合并（Combine）：将子问题的解合并为原问题的解
⚠️ 分治 vs 贪心的区别

分治需要将子问题的解"合并"才能得到原问题的解；贪心每步只做局部最优选择，不回溯也不合并。

归并排序、快速排序、二分查找都使用了分治思想。冒泡排序 ❌ 不是分治。

📊 五种排序复杂度对比（核心考点！）

排序算法平均时间最坏时间最好时间空间稳定性
冒泡排序O(n²)O(n²)O(n)O(1)✅ 稳定
选择排序O(n²)O(n²)O(n²)O(1)❌ 不稳定
插入排序O(n²)O(n²)O(n)O(1)✅ 稳定
归并排序O(n log n)O(n log n)O(n log n)O(n)✅ 稳定
快速排序O(n log n)O(n²)O(n log n)O(log n)❌ 不稳定
✨ 稳定性速记口诀

「不稳定选择快，稳定冒插归」——不稳定的只有选择排序和快速排序；冒泡、插入、归并都是稳定的。

时间复杂度与输入无关的：选择排序和归并排序（无论输入如何，复杂度不变）。

3 代码详解

🔄 归并排序

🔑 核心：两阶段——分解到单个元素 + 合并两个有序数组

merge 函数：合并两个有序子数组

C++ 
void merge(int arr[], int left, int mid, int right) {
    int i = left, j = mid + 1, k = 0;
    int temp[right - left + 1];  // 临时数组
    
    while (i <= mid && j <= right) {
        if (arr[i] <= arr[j])
            temp[k++] = arr[i++];  // ≤ 保证稳定性
        else
            temp[k++] = arr[j++];
    }
    while (i <= mid) temp[k++] = arr[i++];      // 左边剩余
    while (j <= right) temp[k++] = arr[j++];    // ← 高频填空点！
    
    for (i = left, k = 0; i <= right; i++, k++)
        arr[i] = temp[k];
}

mergeSort 递归

C++ 
void mergeSort(int arr[], int left, int right) {
    if (left < right) {
        int mid = left + (right - left) / 2;  // 防溢出
        mergeSort(arr, left, mid);      // 递归左半
        mergeSort(arr, mid + 1, right); // 递归右半
        merge(arr, left, mid, right);   // 合并
    }
}

⚡ 快速排序

🔑 核心：partition（分区）——选基准，小的放左，大的放右

Lomuto 分区（单方向扫描）

C++ 
int partition(vector<int>& arr, int left, int right) {
    int pivot = arr[right];          // 选最右为基准
    int i = left - 1;                // i 指向小于 pivot 的最后一个
    for (int j = left; j < right; j++) {
        if (arr[j] < pivot) {        // ← 高频填空点！
            i++;
            swap(arr[i], arr[j]);
        }
    }
    swap(arr[i + 1], arr[right]);    // pivot 归位
    return i + 1;
}

Hoare 分区（双指针交换）

C++ 
int partition(int arr[], int left, int right) {
    int pivot = arr[left];
    int i = left, j = right;
    while (i < j) {
        while (i < j && arr[j] >= pivot) j--;
        while (i < j && arr[i] <= pivot) i++;
        if (i < j) swap(arr[i], arr[j]);
    }
    swap(arr[left], arr[i]);
    return i;
}
🔄 快速排序主函数
void quickSort(int arr[], int left, int right) {
    if (left < right) {
        int pi = partition(arr, left, right);
        quickSort(arr, left, pi - 1);
        quickSort(arr, pi + 1, right);
    }
}
💡 sort 函数的时间复杂度

C++ STL 的 sort() 平均 O(n log n)，内部混合了快速排序、堆排序和插入排序（内省排序），是不稳定排序。

5 常见陷阱

🚨 陷阱 1：不稳定排序有哪些？

选择排序和快速排序是不稳定的。冒泡排序、插入排序、归并排序是稳定的。

常考判断题："快速排序和归并排序都是不稳定的排序算法"→ ❌ 错（归并是稳定的）。
"归并排序和快速排序都采用递归实现，也都是不稳定排序"→ ❌ 错。

🚨 陷阱 2：快排最坏情况 O(n²)

当数组已排序 + 选首/尾元素为 pivot 时，快速排序退化到 O(n²)。

例：数组 [1, 2, 3, 4, 5]，以首元素 1 为 pivot，每次只减小 1 个元素 → O(n²)。
优化：随机选 pivot、三数取中法。

🚨 陷阱 3：归并排序需要 O(n) 额外空间

"归并排序需要 O(1) 的额外空间"→ ❌ 错。归并排序需要临时数组存放合并结果，空间复杂度 O(n)，不是 O(1)。

而快速排序的空间复杂度是 O(log n)（递归栈），也不需要 O(n) 额外空间。

🚨 陷阱 4：冒泡排序采用了分治思想？

"冒泡排序采用了分治思想"→ ❌ 错。分治的典型应用是归并排序和快速排序。冒泡排序是通过两两比较交换，不是分治。

🚨 陷阱 5：插入排序 vs 快速排序

"插入排序的时间复杂度总是比快速排序低"→ ❌ 错。
但在数据量小或近乎有序时，插入排序 O(n) 确实优于快排 O(n log n)。

常考判断题："插入排序有时比快速排序时间复杂度更低"→ ✅ 对。

📝 真题 6（2026/03 第11题）

下面代码用分治求"最大连续子段和"，其时间复杂度为哪一个？

int solve(vector<int>& a, int l, int r) {
    if (l == r) return a[l];
    int mid = l + (r - l) / 2;
    int left = solve(a, l, mid), right = solve(a, mid + 1, r);
    int sum = 0, lmax = INT_MIN;
    for (int i = mid; i >= l; i--) { sum += a[i]; lmax = max(lmax, sum); }
    sum = 0; int rmax = INT_MIN;
    for (int i = mid + 1; i <= r; i++) { sum += a[i]; rmax = max(rmax, sum); }
    return max({left, right, lmax + rmax});
}

A. O(n)    B. O(n²)    C. O(n log n)    D. O(log n)

答案：C · 分治递归 T(n)=2T(n/2)+O(n)，根据主定理得 O(n log n)。

冒泡排序O(n²) / O(n) 最好✅ 稳定O(1)相邻交换，优化后最好 O(n)
选择排序O(n²) 固定❌ 不稳定O(1)与输入无关，固定 O(n²)
插入排序O(n²) / O(n) 最好✅ 稳定O(1)小数据量时非常快
归并排序O(n log n) 固定✅ 稳定O(n)分治，与输入无关，需辅助数组
快速排序O(n log n) 平均❌ 不稳定O(log n)已排序+选首尾 pivot → O(n²)
关键知识点结论
分治三步走分解 → 求解 → 合并
不稳定排序选择排序、快速排序
稳定排序冒泡排序、插入排序、归并排序
快排最坏情况已排序 + 选首/尾 pivot → O(n²)
归并空间O(n)，需要临时数组
冒泡是分治？❌ 不是！冒泡是两两比较交换
插入排序有时比快排低？✅ 数据量小或近乎有序时 O(n) < O(n log n)
💡 一句话记住

"选择快排不稳定，冒插归并都稳定；归并分治先分后合，快排分区小左大右；已排序选首位 pivot，快排退化成 n²"
