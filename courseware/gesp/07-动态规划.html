1 一、生活引入

1.1 斐波那契与兔子繁殖——重叠子问题

问题：假设有一对刚出生的兔子，每对兔子从出生后第3个月起每个月都生一对新兔子。问第 n 个月共有多少对兔子？

分析： - 第1个月：1对（幼年） - 第2个月：1对（成年） - 第3个月：1+1=2对（成年那对生了1对） - 第4个月：2+1=3对（第3个月的两对中，成年的那对又生了1对） - 第5个月：3+2=5对 - 第6个月：5+3=8对

这个序列正是 斐波那契数列：1, 1, 2, 3, 5, 8, 13, ...

递推关系：F(n) = F(n-1) + F(n-2)

关键观察：要计算第 n 个月，需要知道第 n-1 个月和第 n-2 个月的结果。而计算 F(5) 时又需要 F(4) 和 F(3)，计算 F(4) 又需要 F(3) 和 F(2)……如果每次都用递归重复计算，F(3) 会被计算很多次。这些被反复计算的子问题就是重叠子问题。

生活类比：你写周报时，发现每周的数据都依赖前两周的数据。与其每周都从头算一遍，不如记下每周的结果，下周直接用。这就是 DP 的思想——记住已经算过的结果，避免重复计算。

1.2 背包旅行——最优子结构

问题：你要去旅行，背包容量为 8kg。你有以下物品： - 帐篷：4kg，价值 2000 元 - 睡袋：2kg，价值 800 元 - 相机：3kg，价值 1500 元 - 水：2kg，价值 500 元 - 食物：3kg，价值 600 元

如何在不超过背包容量的前提下，让携带物品的总价值最大？

关键观察：如果你已经知道容量为 8kg 时能拿的最大价值，那么当考虑新物品时： - 方案A：不拿这件，价值 = dp[8]， - 方案B：拿这件（若放得下），价值 = dp[8-重量] + 这件物品的价值

全局最优解包含局部最优解，这就是最优子结构。

生活类比：你每次往箱子里放东西时，都会想：放这个进去的话，剩余空间还能放什么最好的东西？如果把所有可能都试一遍，取价值最大的方案——这就是 DP 的"选或不选"决策。

2 二、核心概念

2.1 什么是动态规划

动态规划（Dynamic Programming, DP）是一种通过把原问题分解为相对简单的子问题来求解复杂问题的方法。它通过记住子问题的解来避免重复计算。

2.2 三个核心性质

性质 定义 举例
最优子结构 原问题的最优解包含了其子问题的最优解 背包问题中，容量10的最优解包含容量8的最优解
重叠子问题 求解过程中反复出现相同子问题 斐波那契中 F(3) 被多次计算
无后效性 一旦某个阶段状态确定，就不受之后决策的影响 爬台阶时，走到第5阶的方案数只和第3、第4阶有关

2.3 状态转移方程

DP 的灵魂。描述状态之间如何转移的数学公式。

C++ 
dp[i] = f(dp[i-1], dp[i-2], ...)

一般形式： - 状态定义：dp[i] 表示什么含义 - 转移方程：dp[i] 如何从之前的状态计算得到 - 边界条件：最小的子问题（如 dp[0], dp[1]） - 结果：最终答案藏在哪个 dp 元素中

2.4 DP 解题一般步骤

C++ 
1. 定状态 —— dp[i] / dp[i][j] 表示什么
2. 找转移 —— 状态之间如何递推
3. 设初始 —— 边界条件
4. 定答案 —— 最终输出哪个状态

口诀：定义状态 → 写出方程 → 初始化 → 循环填表 → 返回结果

3 三、常见题型

3.1 打家劫舍（不相邻元素最大和）

问题描述：你是一个小偷，沿街有 n 个房子，每个房子里有不同金额的现金。相邻房子有防盗系统相连，如果同一天闯入相邻的两个房子会触发警报。求不触发警报的情况下能偷到的最大金额。

例题：nums = [2, 7, 9, 3, 1]，最大金额为 12（偷第1、3、5家：2+9+1=12）。

状态转移方程

C++ 
状态定义：dp[i] 表示偷前 i 个房子（0~i-1）能得到的最大金额
转移方程：dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])
边界条件：dp[0] = 0         （没有房子，金额为0）
         dp[1] = nums[0]   （只有一个房子，只能偷它）
最终答案：dp[n]

解释：对于第 i 个房子（下标 i-1），有两种选择： - 不偷：金额 = dp[i-1]（前 i-1 个房子的最大金额） - 偷：金额 = dp[i-2] + nums[i-1]（前 i-2 个房子的最大金额 + 当前房子金额）

取两者的最大值即可。

完整代码

C++ 
#include <iostream>
#include <algorithm>
using namespace std;

int rob(int nums[], int n) {
    if (n == 0) return 0;
    if (n == 1) return nums[0];

    int dp[1001] = {0};
    dp[0] = 0;          // 没有房子
    dp[1] = nums[0];    // 只有一个房子

    for (int i = 2; i <= n; i++) {
        // 不偷第i家：dp[i-1]；偷第i家：dp[i-2] + nums[i-1]
        dp[i] = max(dp[i-1], dp[i-2] + nums[i-1]);
    }
    return dp[n];
}

int main() {
    int nums[] = {2, 7, 9, 3, 1};
    int n = 5;
    cout << "最大金额 = " << rob(nums, n) << endl;
    return 0;
}

空间优化（滚动变量）

因为 dp[i] 只依赖 dp[i-1] 和 dp[i-2]，可以用两个变量滚动：

C++ 
int rob_optimized(int nums[], int n) {
    if (n == 0) return 0;
    if (n == 1) return nums[0];

    int prev2 = 0;          // dp[i-2]
    int prev1 = nums[0];    // dp[i-1]
    int cur;

    for (int i = 2; i <= n; i++) {
        cur = max(prev1, prev2 + nums[i-1]);
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}

3.2 0/1 背包

问题描述：有 n 个物品，每个物品有重量 wt[i] 和价值 val[i]。背包容量为 W。每个物品最多选一次，求背包能装下的最大价值。

二维 DP（基础版本）

C++ 
状态定义：dp[i][j] 表示在前 i 个物品中选，总重量不超过 j 的最大价值
转移方程：
  dp[i][j] = dp[i-1][j]                    （不选第 i 个物品）
  dp[i][j] = max(dp[i][j], dp[i-1][j-wt[i-1]] + val[i-1])  （选第 i 个物品，前提是 j >= wt[i-1]）
边界条件：dp[0][j] = 0（没有物品可拿，价值为0）
         dp[i][0] = 0（容量为0，什么也装不了）
最终答案：dp[n][W]

完整代码（二维）

C++ 
#include <iostream>
#include <algorithm>
using namespace std;

int knapsack_2d(int wt[], int val[], int n, int W) {
    int dp[101][101] = {0};  // dp[i][j]：前i个物品，容量j的最大价值

    for (int i = 1; i <= n; i++) {
        for (int j = 0; j <= W; j++) {
            // 不选第i个物品
            dp[i][j] = dp[i-1][j];
            // 如果能装下，尝试选第i个物品
            if (j >= wt[i-1]) {
                dp[i][j] = max(dp[i][j], dp[i-1][j-wt[i-1]] + val[i-1]);
            }
        }
    }
    return dp[n][W];
}

int main() {
    int wt[]  = {2, 3, 4, 5};    // 重量
    int val[] = {3, 4, 5, 6};    // 价值
    int n = 4, W = 8;
    cout << "最大价值 = " << knapsack_2d(wt, val, n, W) << endl;
    return 0;
}

一维优化（重点：为什么逆序）

观察二维转移方程：

C++ 
dp[i][j] = max(dp[i-1][j], dp[i-1][j-wt[i-1]] + val[i-1])

发现 dp[i][j] 只依赖于 dp[i-1][...]（上一行的数据）。因此可以用一维数组滚动更新，空间从 O(n×W) 优化到 O(W)。

C++ 
dp[j] = max(dp[j], dp[j-wt[i-1]] + val[i-1])

关键问题：内层循环 j 为什么要从大到小（逆序）遍历？

为什么必须逆序？

错误示范（正序）：假设物品1重量2价值3，物品2重量3价值4，W=5。

C++ 
dp数组初始：dp = [0, 0, 0, 0, 0, 0] （下标0~5）

处理物品1（wt=2, val=3）—— 正序遍历 j=2~5：
  j=2: dp[2] = max(dp[2], dp[0]+3) = max(0, 0+3) = 3
  j=3: dp[3] = max(dp[3], dp[1]+3) = max(0, 0+3) = 3
  j=4: dp[4] = max(dp[4], dp[2]+3) = max(0, 3+3) = 6  ← 问题！
  j=5: dp[5] = max(dp[5], dp[3]+3) = max(0, 3+3) = 6

发现问题了吗？当 j=4 时，dp[2] 已经在当前轮被更新为 3（表示已选了物品1）。此时 dp[4] = dp[2] + 3 = 6，相当于又选了一次物品1！这就把一个"0/1"问题变成了"无限取"问题。

正解（逆序）：

C++ 
处理物品1（wt=2, val=3）—— 逆序遍历 j=5~2：
  j=5: dp[5] = max(dp[5], dp[3]+3) = max(0, 0+3) = 3
  j=4: dp[4] = max(dp[4], dp[2]+3) = max(0, 0+3) = 3
  j=3: dp[3] = max(dp[3], dp[1]+3) = max(0, 0+3) = 3
  j=2: dp[2] = max(dp[2], dp[0]+3) = max(0, 0+3) = 3

此时 dp = [0, 0, 3, 3, 3, 3]，每个物品最多被选一次。

核心原因：逆序遍历保证了更新 dp[j] 时用到的 dp[j-wt] 是上一轮（未更新）的值，即每个物品只考虑一次。正序遍历则可能导致同一个物品被多次选取。

一句话总结：0/1背包一维优化必须逆序，是为了保证每个物品最多选一次。

完整代码（一维）

C++ 
int knapsack_1d(int wt[], int val[], int n, int W) {
    int dp[1001] = {0};  // dp[j]：容量j的最大价值

    for (int i = 0; i < n; i++) {          // 遍历每个物品
        for (int j = W; j >= wt[i]; j--) { // 逆序遍历容量
            dp[j] = max(dp[j], dp[j-wt[i]] + val[i]);
        }
    }
    return dp[W];
}

3.3 青蛙跳台阶

问题描述：一只青蛙一次可以跳上1级台阶，也可以跳上2级台阶。求青蛙跳上 n 级台阶总共有多少种跳法。

分析：要跳到第 n 级台阶，要么从第 n-1 级跳1步过来，要么从第 n-2 级跳2步过来。所以跳法数量满足斐波那契关系。

状态转移方程

C++ 
状态定义：dp[i] 表示跳上 i 级台阶的跳法数量
转移方程：dp[i] = dp[i-1] + dp[i-2]
边界条件：dp[0] = 1  （0级台阶，不跳也是一种方案）
         dp[1] = 1  （1级台阶，只能跳1步）
         dp[2] = 2  （2级台阶：1+1 或 2）
最终答案：dp[n]

完整代码

C++ 
#include <iostream>
using namespace std;

int climbStairs(int n) {
    if (n <= 1) return 1;

    int dp[1001] = {0};
    dp[0] = 1;
    dp[1] = 1;

    for (int i = 2; i <= n; i++) {
        dp[i] = dp[i-1] + dp[i-2];
    }
    return dp[n];
}

int main() {
    int n = 5;
    cout << "跳" << n << "级台阶有 " << climbStairs(n) << " 种方法" << endl;
    // 输出：跳5级台阶有 8 种方法
    return 0;
}

空间优化

C++ 
int climbStairs_opt(int n) {
    if (n <= 1) return 1;
    int a = 1, b = 1, c;  // a=dp[i-2], b=dp[i-1]
    for (int i = 2; i <= n; i++) {
        c = a + b;
        a = b;
        b = c;
    }
    return c;
}

3.4 完全平方数拆分

问题描述：给定一个正整数 n，求最少能由多少个完全平方数（1, 4, 9, 16, ...）相加得到。

示例： - n=12 → 4+4+4=12，需要3个 - n=13 → 9+4=13，需要2个

状态转移方程

C++ 
状态定义：dp[i] 表示组成 i 需要的最少完全平方数个数
转移方程：dp[i] = min(d[i], dp[i - j*j] + 1)，其中 j*j <= i
边界条件：dp[0] = 0
         dp[i] = i （最坏情况：全部用1相加，需要i个）
最终答案：dp[n]

解释：对于每个 i，尝试减去一个完全平方数 jj，看剩下的 i-jj 最少需要多少个完全平方数。

完整代码

C++ 
#include <iostream>
#include <algorithm>
using namespace std;

int numSquares(int n) {
    int dp[10001];
    // 初始化：最坏情况全用1
    for (int i = 0; i <= n; i++) dp[i] = i;
    dp[0] = 0;

    for (int i = 1; i <= n; i++) {
        for (int j = 1; j * j <= i; j++) {
            dp[i] = min(dp[i], dp[i - j*j] + 1);
        }
    }
    return dp[n];
}

int main() {
    cout << "n=12需要" << numSquares(12) << "个" << endl;  // 3
    cout << "n=13需要" << numSquares(13) << "个" << endl;  // 2
    return 0;
}

3.5 零钱兑换

问题描述：给定不同面额的硬币 coins 和一个总金额 amount，求凑成总金额所需的最少硬币个数。如果无法凑成，返回 -1。

示例：coins = [1, 2, 5], amount = 11 → 5+5+1=11，最少需要3枚。

状态转移方程

C++ 
状态定义：dp[a] 表示凑成金额 a 所需的最少硬币数
转移方程：dp[a] = min(dp[a], dp[a - coins[i]] + 1)
         其中 coins[i] 是硬币面额，且 a >= coins[i]
边界条件：dp[0] = 0（金额为0不需要硬币）
初始化：dp[1..amount] = 一个很大的数（如 INF = amount+1）
最终答案：如果 dp[amount] > amount 则返回 -1，否则返回 dp[amount]

完整代码

C++ 
#include <iostream>
#include <algorithm>
using namespace std;

int coinChange(int coins[], int n, int amount) {
    const int INF = 0x3f3f3f3f;
    int dp[10001];
    fill(dp, dp + amount + 1, INF);
    dp[0] = 0;

    for (int a = 1; a <= amount; a++) {
        for (int i = 0; i < n; i++) {
            if (a >= coins[i]) {
                dp[a] = min(dp[a], dp[a - coins[i]] + 1);
            }
        }
    }
    return dp[amount] > amount ? -1 : dp[amount];
}

int main() {
    int coins[] = {1, 2, 5};
    int n = 3, amount = 11;
    int res = coinChange(coins, n, amount);
    cout << "凑" << amount << "元最少需要" << res << "枚硬币" << endl;
    // 输出：凑11元最少需要3枚硬币
    return 0;
}

4 四、手工模拟——打家劫舍 DP 表推演

以 nums = [2, 7, 9, 3, 1] 为例，计算打家劫舍的 DP 表。

初始状态

C++ 
dp[0] = 0   （没有房子）
dp[1] = nums[0] = 2  （只有第一家）

逐行计算

i nums[i-1] dp[i-2] dp[i-1] dp[i-2]+nums[i-1] dp[i]=max(dp[i-1], dp[i-2]+nums[i-1])
0 - - - - dp[0] = 0
1 2 - - - dp[1] = 2
2 7 dp[0]=0 dp[1]=2 0+7=7 dp[2] = max(2, 7) = 7
3 9 dp[1]=2 dp[2]=7 2+9=11 dp[3] = max(7, 11) = 11
4 3 dp[2]=7 dp[3]=11 7+3=10 dp[4] = max(11, 10) = 11
5 1 dp[3]=11 dp[4]=11 11+1=12 dp[5] = max(11, 12) = 12

结果说明

C++ 
dp = [0, 2, 7, 11, 11, 12]
最终最大金额 = dp[5] = 12

手动验证：偷第1家(2)、第3家(9)、第5家(1) → 2+9+1=12 ✓

子问题验证： - dp[3]=11 表示前3家（2,7,9）最大能偷11——实际是偷第1家和第3家（2+9=11） - dp[4]=11 表示前4家（2,7,9,3）最大能偷11——不管是偷(1,3)还是(2,4)都是2+9=11或7+3=10中取最大

5 五、常见陷阱

陷阱1：0/1背包内层循环正序 vs 逆序混淆

C++ 
// 错误：正序（变成了完全背包）
for (int j = wt[i]; j <= W; j++)
    dp[j] = max(dp[j], dp[j-wt[i]] + val[i]);

// 正确：逆序（保证每个物品只用一次）
for (int j = W; j >= wt[i]; j--)
    dp[j] = max(dp[j], dp[j-wt[i]] + val[i]);

记忆方法：0/1背包用逆序（1像一根棍子，从大到小，只能选1次）；完全背包用正序（可以无限选）。

陷阱2：忘记初始化

C++ 
// 错误：忘记初始化
int dp[1001];  // 未初始化的值是随机的
dp[0] = 0;

// 正确：
int dp[1001] = {0};  // 全部初始化为0

对于求最小值的题目（如零钱兑换），需要初始化成一个大数：

C++ 
const int INF = 0x3f3f3f3f;  // 约10亿，防止加法溢出
fill(dp, dp + n + 1, INF);
dp[0] = 0;

陷阱3：递归不存储中间结果（纯递归=指数爆炸）

C++ 
// 错误：纯递归，大量重复计算
int fib(int n) {
    if (n <= 1) return n;
    return fib(n-1) + fib(n-2);  // 时间复杂度 O(2^n)
}

// 正确：记忆化搜索（递归+备忘录）
int memo[1001] = {0};
int fib(int n) {
    if (n <= 1) return n;
    if (memo[n] != 0) return memo[n];  // 直接返回已算结果
    return memo[n] = fib(n-1) + fib(n-2);
}

陷阱4：状态定义不清晰

错误示例：打家劫舍中定义 dp[i] 为"前i个"还是"第i个"？混淆会导致转移方程全错。

正确做法：明确下标含义，保持前后一致。建议统一用"前i个"的语义。

C++ 
dp[i]：前 i 个房子（0~i-1）能偷的最大金额
dp[i] = max(dp[i-1], dp[i-2] + nums[i-1])

陷阱5：遗漏边界条件

C++ 
// 0/1背包中忘记处理 j < wt[i-1] 的情况
// 错误：
if (j >= wt[i-1])
    dp[i][j] = max(dp[i-1][j], dp[i-1][j-wt[i-1]] + val[i-1]);

// 正确：
dp[i][j] = dp[i-1][j];  // 先赋值为不选的情况
if (j >= wt[i-1])
    dp[i][j] = max(dp[i][j], dp[i-1][j-wt[i-1]] + val[i-1]);

以下动态规划算法的含义与目的是什么？

C++ 
int function(vector<int>& nums) {
    int n = nums.size();
    if (n == 0) return 0;
    if (n == 1) return nums[0];
    vector<int> dp(n, 0);
    dp[0] = nums[0];
    dp[1] = max(nums[0], nums[1]);
    for (int i = 2; i < n; ++i) {
        dp[i] = max(dp[i - 1], nums[i] + dp[i - 2]);
    }
    return dp[n - 1];
}

A. 计算数组 nums 中的所有元素的和

B. 计算数组 nums 中相邻元素的最大和

C. 计算数组 nums 中不相邻元素的最大和

D. 计算数组 nums 中的最小元素

答案：C

C++ 
int jump_recur(int n) {
    if (n == 1) return 1;
    if (n == 2) return 2;
    return jump_recur(n - 1) + jump_recur(n - 2);
}
int jump_dp(int n) {
    vector<int> dp(n + 1);
    dp[1] = 1; dp[2] = 2;
    for (int i = 3; i <= n; ++i)
        dp[i] = dp[i - 1] + dp[i - 2];

}

B. 函数 jump_dp() 采用动态规划方法

解析：解析：递归版本存在大量重叠子问题，执行效率很低，时间复杂度 O(2^n)。

📝 真题 6（2024年9月第15题）

0-1背包问题，背包容量是10kg，输入4个物品的重量分别为1，3，4，6，每个物品对应的价值分别为20，30，50，60，函数的输出是什么？

C++ 
// 0/1背包问题
int knapsack(int W, const vector& weights, const vector& values, int n) {
    vector> dp(n + 1, vector(W + 1, 0));
    for (int i = 1; i <= n; ++i) {
        for (int w = 0; w <= W; ++w) {
            if (weights[i - 1] <= w) {
                dp[i][w] = max(dp[i - 1][w], dp[i - 1][w - weights[i - 1]] +values[i - 1]);
            }
            else{
                dp[i][w] = dp[i - 1][w];
            }
        }
    }
    return dp[n][W];
}

A. 90

B. 100

C. 110

D. 140

答案：C

📝 判断题（2025年6月第10题）

下面代码采用动态规划求解零钱兑换问题：给定硬币面值，每种硬币可重复选取，求凑出目标金额的最少硬币数（ ）。

C++ 
int visit(vector<int>& nums) {
int coinChangeDPComp(vector &coins, int amt) {
    int n = coins.size();
    int MAX = amt + 1;
    vector dp(amt + 1, MAX);
    dp[0] = 0;
    for (int i = 1; i <= n; i++) {
        for (int a = 1; a <= amt; a++) {
            if (coins[i - 1] > a)
                dp[a] = dp[a];
            else
                dp[a] = min(dp[a], dp[a - coins[i - 1]] + 1);
        }
    }   
    return dp[amt] != MAX ? dp[amt] : -1;
}
答案：✅
