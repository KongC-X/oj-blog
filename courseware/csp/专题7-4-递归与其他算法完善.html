1递归基础概念

递归完善程序是 CSP-J 初赛的高频考点。递归函数的三大核心要素是： 终止条件（基线条件）、递归调用、返回值。 解题时先定位终止条件，再分析参数如何向终止条件推进。

📌 递归完善解题三步法

第一步：找到终止条件——递归在什么情况下不再调用自身？
第二步：分析参数变化——每次递归调用参数如何缩小？
第三步：确认返回值/操作——每次递归返回什么结果或执行什么输出？

✏️ 模拟题 递归函数三要素
关于递归函数的说法，以下选项中 正确 的是？
A递归函数必须包含循环结构才能正常工作
B递归函数必须有终止条件，否则会无限递归导致栈溢出
C递归函数的执行效率总是高于等价的循环实现
D递归函数中不能包含 return 语句
✅ 正确答案：B
递归函数的三个核心要素：① 终止条件（基线条件）——防止无限递归； ② 递归调用——向终止条件推进； ③ 返回值（或输出）——传递计算结果。
A 错误：递归通过自身调用来实现重复，不一定需要循环；C 错误：递归通常比循环效率低（函数调用开销）； D 错误：递归函数可以有返回值。
✏️ 模拟题 递归执行追踪

2汉诺塔递归（2024 完善2 原题）

汉诺塔（Tower of Hanoi）是递归的经典入门问题。将 n 个盘子从 A 柱移动到 C 柱， 每次只能移动一个盘子，且大盘不能压在小盘上。递归解决思路为三步模型。

💡 汉诺塔三步模型

步骤 1：将上面 n-1 个盘子从 A → B（借助 C）
步骤 2：将最底下的大盘从 A → C（直接移动）
步骤 3：将 B 上的 n-1 个盘子从 B → C（借助 A）

总移动次数：2n - 1

汉诺塔递归的核心三步模型（以 n 个盘子从 A→C）：
步骤 1：hanoi(n-1, A, C, B) — 将上面 n-1 个盘子从 A 移到 B（借助 C）
步骤 2：cout << A << "->" << C — 将最底下的大盘直接从 A 移到 C
步骤 3：hanoi(n-1, B, A, C) — 将 B 上的 n-1 个盘子移到 C（借助 A）

① B（n == 1）：基线条件——只剩一个盘子时直接移动。
② A（step++）：基线中移动后步数加 1。
③ A（step++）：递归中每次移动后步数加 1。
④ A（hanoi(n-1, B, A, C)）：将 B 上的 n-1 个盘子从 B → C（借助 A）。
⑤ A（hanoi(n, 'A', 'B', 'C')）：主函数调用，从 A 移到 C，B 做辅助。

注意：② 和 ③ 虽然都是 step++，但分别出现在基线和递归两个分支。step+=1 虽语义相同，但 CSP-J 习惯用 step++。

✅ 正确答案：B
目标是把 n 个盘子从 A→C，B 辅助。
第一步：将上面 n-1 个从 A→B（借助 C）→ hanoi(n-1, A, C, B)
第二步：将最大的盘子从 A→C（直接移动）
第三步：将 B 上的 n-1 个从 B→C（借助 A）→ hanoi(n-1, B, A, C)
注意函数参数含义：hanoi(n, 源, 辅助, 目标)。

3Boyer-Moore 多数派投票（2025 完善2 原题）

Boyer-Moore 多数派投票算法用于在一组数据中找出出现次数超过一半的"多数元素"（如果存在）。 核心思想是候选人消除法：两个不同元素互相抵消，剩下的候选者再验证。

📌 BM 算法两阶段

阶段一（筛选）：遍历数据，维护 candidate 和 count。count 为 0 时换候选人； 意见一致（投票支持）则 count++，不一致则 count--。
阶段二（验证）：再次遍历，确认 candidate 的出现次数是否超过一半。

核心逻辑：count=0 → 换候选人；query=true → count++（意见一致）； query=false → count--（意见不一致）。

4RLE 行程编码（2025 阅读4 改编）

RLE（Run-Length Encoding，行程编码）是一种简单的数据压缩方法， 将连续相同字符用"字符 + 重复次数"表示。 例如 "a3b2c" 解码后为 "aaabbc"（c 后无数字，表示出现 1 次）。

RLE 解码流程：读字符 → 解析后续数字（可能多位）→ 循环追加 count 次字符 → 读完整个字符串。
📝 真题 · 2025 · 阅读4 改编 RLE 行程编码解码
以下函数实现 RLE 解码，将 "a3b2c" 这类编码字符串还原为原始字符串。 补全 ①~⑤ 处的空缺。 
string decode(string z) {
    string result = "";
    int i = 0;
    while (i < z.length()) {
        char ch = z[i];
        i++;
        int count = 0;
        while (①) {
            count = count * 10 + (②);
            i++;
        }
        if (count == 0) count = 1;
        for (int j = 0; j < ③; j++) {
            result += ④;
        }
        ⑤;
    }
    return result;
}

✅ 正确答案：① B   ② A（count = count * 10 + (z[i] - '0')）  ③ A   ④ A   ⑤ D
解析：RLE 解码的流程是"读字符 → 读次数 → 循环追加"。

① B（isdigit(z[i])）：i 在 ch=z[i] 后已自增，指向下一个位置（即数字部分起点）， 所以只需判断当前 z[i] 是否为数字。由于 C++ 中 z[length()] = '\0'，isdigit('\0') 返回 false，安全。
② A：多位数字的累加构建，例如 "12" → 先读 '1' 得 1，再读 '2' 得 1×10+2=12。
③ A（count）：循环 count 次，将字符重复添加。
④ A（ch）：每次追加之前读到的基准字符。
⑤ D（不执行）：内层 while 循环已使 i 指向下一个字符的起始位置，无需额外自增。

以 "a3b2c" 为例：读 'a' → 解析数字 3 → 追加 "aaa"； 读 'b' → 解析数字 2 → 追加 "bb"；读 'c' → 无数字 count=0 → count 置 1 → 追加 "c"。结果为 "aaabbc"。

5二分查找递归实现

二分查找（Binary Search）在有序数组中查找目标值，每次将搜索范围缩小一半。 递归实现时，终止条件为找到目标或区间为空。

✏️ 模拟题 二分查找递归填空
以下为二分查找的递归实现，在有序数组 arr[l..r] 中查找元素 x， 返回下标（未找到返回 -1）。补全 ①~③ 处的空缺。 
int binarySearch(int arr[], int l, int r, int x) {
    if (r >= l) {
        int mid = l + (r - l) / 2;
        if (arr[mid] == x) return mid;
        if (arr[mid] > x)
            return binarySearch(arr, l, ①, x);
        return binarySearch(arr, ②, r, x);
    }
    return ③;
}

—— ② 右半区间的左边界 ——

Bmid

Dmid + 1
—— ③ 未找到时的返回值 ——

B-1

✅ 正确答案：① C   ② D   ③ B
解析：递归版二分查找的终止条件与缩小区间策略：

① C（mid - 1）：当中间值 > x 时，x 在左半区间 [l, mid-1]。
② D（mid + 1）：否则 x 在右半区间 [mid+1, r]。
③ B（-1）：当 l > r 时区间为空，返回 -1 表示未找到。

递归终止条件有两个：找到 x（返回下标）或 区间为空（返回 -1）。

6快速排序递归实现

快速排序（Quick Sort）采用"分治"策略：通过 partition 将数组分为左右两部分， 再递归排序左右部分。partition 返回基准元素的最终位置 pi。

✏️ 模拟题 快速排序递归填空
partition(arr, low, high) 函数将数组划分为左右两部分， 返回基准元素的最终位置 pi，使得左半元素 ≤ 基准 ≤ 右半元素。 补全以下快速排序递归代码中的 ①~② 处。 
void quickSort(int arr[], int low, int high) {
    if (low < high) {
        int pi = partition(arr, low, high);
        quickSort(arr, low, ①);
        quickSort(arr, ②, high);
    }
}
—— ① 左半区间递归 ——

Bpi - 1
Cpi + 1
Dhigh
—— ② 右半区间递归 ——
Api
Bpi - 1
Cpi + 1
Dlow
✅ 正确答案：① B   ② C
解析：快速排序的递归结构：划分 → 递归左半 → 递归右半。

partition 返回的 pi 是基准元素的最终位置：
① B（pi - 1）：左半区间为 [low, pi-1]，元素都 ≤ 基准。
② C（pi + 1）：右半区间为 [pi+1, high]，元素都 ≥ 基准。

注意基准元素 pi 本身已经排好，不需要参与后续递归。递归终止条件是 low >= high。

7归并排序递归实现

归并排序（Merge Sort）也采用"分治"策略：先将数组递归地分成两半， 再将两个有序子数组合并成一个有序数组。

✏️ 模拟题 归并排序递归填空
merge(arr, l, m, r) 函数将两个有序子数组 arr[l..m] 和 arr[m+1..r] 合并为整体有序。补全以下递归代码中的 ①~② 处。

    if (l < r) {
        int m = l + (r - l) / 2;
        mergeSort(arr, l, m);
        mergeSort(arr, ①, r);
        merge(arr, l, m, ②);
    }
}

—— ② merge 的右边界 ——

Bm + 1

✅ 正确答案：① B   ② D
解析：归并排序的递归结构：递归左半 → 递归右半 → 合并。

① B（m + 1）：右半区间为 [m+1, r]（m 是中间分界点）。
② D（r）：merge(arr, l, m, r) 将左半 [l, m] 和右半 [m+1, r] 合并。

与快排不同，归并排序的"分"在递归中完成，"治"在合并中完成。 递归终止条件是 l >= r（区间内最多一个元素，视为有序）。

8递归时间复杂度分析

递归算法的时间复杂度通常通过递推关系（Master Theorem 或递推展开）来分析。 以下是常见递归算法的时间复杂度速记。

✏️ 模拟题 递归算法时间复杂度
关于以下递归算法的时间复杂度，说法 正确 的是？
A汉诺塔递归的时间复杂度为 O(n)
B归并排序递归的时间复杂度为 O(n log n)
C二分查找递归的时间复杂度为 O(n)
D快速排序递归在最好情况下的时间复杂度为 O(n)
✅ 正确答案：B
解析：常见递归算法的时间复杂度：

A 错误：汉诺塔 T(n)=2T(n-1)+O(1) → O(2n)
B 正确：归并排序 T(n)=2T(n/2)+O(n) → O(n log n)
C 错误：二分查找 T(n)=T(n/2)+O(1) → O(log n)
D 错误：快速排序最好情况 T(n)=2T(n/2)+O(n) → O(n log n)

记忆方法：
• 每次减半且 O(1) 合并 → O(log n)（二分查找）
• 每次减半且 O(n) 合并 → O(n log n)（归并、快排平均）
• 每次减 1 且 O(1) 合并 → O(n)（线性递归）
• 每次分裂成两个子问题 → O(2n)（汉诺塔、斐波那契朴素递归）
✏️ 综合模拟 递归与完善题综合理解
关于程序完善题中的递归和 BM 算法，以下说法 错误 的是？
A汉诺塔递归中，hanoi(n-1, A, C, B) 将 n-1 个盘子从 A 移到 B
BBoyer-Moore 算法中，count 减到 0 时需更换候选人
CRLE 解码遇到数字字符时，应直接跳过不做处理
D归并排序的 merge 操作将两个有序子数组合并为一个
✅ 正确答案：C
C 错误——RLE 解码遇到数字字符时，需要解析数字确定重复次数，不是跳过。
A 正确：hanoi(n-1, A, C, B) 借助 C 将 n-1 个盘子从 A 移到 B。
B 正确：count == 0 时更换候选人，这是 BM 算法的核心。
D 正确：归并排序的 merge 函数将两个有序子数组合并。
✏️ 模拟题 RLE 编码与解码方向
关于 RLE 行程编码，以下说法 正确 的是？
ARLE 编码一定比原始数据更短
BRLE 解码时遇到字符后没有数字，表示该字符出现 1 次
CRLE 只能压缩英文字母，不能压缩数字
DRLE 编码在解压时不需要知道原始数据长度
✅ 正确答案：B
解析：
A 错误：如果每个字符都不重复（如 "abcde"），RLE 编码反而更长（"a1b1c1d1e1"）。
B 正确：RLE 解码约定无数字时 count 视为 1，即字符出现 1 次。
C 错误：RLE 可以压缩任意字符，包括数字（但数字作为重复次数需与字符区分）。
D 错误：解码时需要知道编码字符串的长度来控制循环结束。

📌 递归与程序完善速查表

以下是你应该背下来的核心考点，考前反复看：
递归三要素：终止 + 调用 + 返回 汉诺塔：A→C 三步走 BM：count=0 换候选人 RLE：读字符 → 解析数字 → 循环追加
二分查找：mid-1 / mid+1 / -1 快排：pi-1 / pi+1 归并：m+1 / r
汉诺塔复杂度：O(2n) 归并/快排：O(n log n) 二分查找：O(log n) BM / RLE：O(n)
算法 递归结构 终止条件 常见填空点 时间复杂度
汉诺塔 hanoi(n-1,A,C,B) → move → hanoi(n-1,B,A,C) n == 1 三步递归调用 + 步数统计 O(2n)
Boyer-Moore count==0 换候选人；query=true→count++；false→count-- 遍历完所有人 count初值、换候选人条件、query判断 O(n)
RLE 解码 读ch → 解析数字 → 循环添加count次ch 字符串遍历完毕 读字符、数字判断、字符转数字、循环次数 O(n)
二分查找 binarySearch(l,mid-1) 或 binarySearch(mid+1,r) l > r 或 arr[mid]==x mid-1、mid+1、-1 O(log n)
快速排序 partition → quickSort(l,pi-1) → quickSort(pi+1,r) low >= high pi-1、pi+1 O(n log n) 平均
归并排序 mergeSort(l,m) → mergeSort(m+1,r) → merge(l,m,r) l >= r m+1、r O(n log n)
💡 解题口诀： 递归先找终止线，参数变化看三遍；汉诺三步要记牢，BM计数别混淆； RLE先读再解析，二分区间缩到底；快排查找分两边，归并递归再合并。
