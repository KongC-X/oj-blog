📝 第 1 题 计算机基础 · 面向对象编程
以下哪种功能没有涉及 C++ 语言的面向对象特性支持？
A调用 printf
B使用类
C继承
D多态
✅ 正确答案：A（调用 printf）
解析：
· printf 是 C 语言的标准库函数，仅支持面向过程编程，不涉及面向对象特性。
· 类（class）是面向对象编程（OOP）的基础，用于封装数据和操作。
· 继承（inheritance）允许子类复用父类的属性和方法。
· 多态（polymorphism）允许同一接口在不同对象上有不同的实现。

知识点：C++ 是一门多范式编程语言，同时支持面向过程和面向对象编程。
📝 第 2 题 数据结构 · 栈的出栈序列
入栈顺序为 6, 5, 4, 3, 2, 1，以下哪个不是合法的出栈序列？
A5, 4, 3, 6, 1, 2
B4, 5, 6, 1, 2, 3
C3, 4, 6, 5, 2, 1
D2, 3, 4, 1, 5, 6
✅ 正确答案：C（3, 4, 6, 5, 2, 1）
解析：
用栈模拟验证 C 选项：
· push 6,5,4,3 → pop 3 ✅（栈：6,5,4）
· push 无新数 → pop 4 ✅（栈：6,5）
· 接下来要出 6，但栈顶是 5，先 pop 5，不能直接出 6 ❌
实际上 C 出 4 之后应先出 5（栈顶），不能跳过去出 6。

核心规律：栈的 LIFO 特性决定了后进栈的元素必须在前面的元素之前出栈。 如果出栈序列中出现了"隔着一个未出栈元素"的情况，就是非法的。
📝 第 3 题 C++ 语法 · 指针操作
已知 int x = 5, y = 10; int *p = &x, *q = &y; p = q;， 执行后 *p 的值是？
A5
B10
Cx 的地址
Dy 的地址
✅ 正确答案：B（10）
解析：
· 初始：p 指向 x（值 5），q 指向 y（值 10）
· 执行 p = q 后，p 和 q 指向同一块内存（即 y 的地址）
· 此时 *p 等价于访问 y 的值，即 10

易混淆：这道题的关键是区分"指针赋值"和"值赋值"。 p = q 让 p 指向 q 所指向的地址，而不是修改 x 的值。
📝 第 4 题 数据结构 · 数组与链表
以下关于数组和链表的说法，正确的是？
A数组插入和删除元素比链表快
B链表支持随机访问
C数组支持随机访问
D链表不需要额外存储空间
✅ 正确答案：C（数组支持随机访问）
解析：
· 数组：内存连续，通过下标可直接访问任意元素（O(1)）， 但插入/删除需要移动大量元素（O(n)）。
· 链表：内存不连续，通过指针连接。插入/删除只需修改指针（O(1)）， 但不支持随机访问，查找需遍历（O(n)）。
· 链表每个结点需要额外的指针域存储地址，比数组多占用空间。

记忆口诀：数组"随机快、插删慢"；链表"插删快、查找慢"。
📝 第 5 题 数据结构 · 栈与队列混合操作
初始队列（FIFO）中有元素 1, 2, 3, 4, 5（左端为队头）。 不断执行出队操作，若出队的元素是奇数则将其入栈，是偶数则直接输出。 最终输出序列为 2, 1, 4, 3, 5。 则过程中栈所需的最小容量是？
A2
B3
C4
D5
✅ 正确答案：B（3）
解析：
模拟整个过程：
· 队列：1,2,3,4,5 | 栈：空
· 出队 1（奇数）→ 入栈，栈：[1]，容量 1
· 出队 2（偶数）→ 直接输出 2 ✅
· 出队 3（奇数）→ 入栈，栈：[1,3]，容量 2
· 出队 4（偶数）→ 直接输出 4 ✅
· 出队 5（奇数）→ 入栈，栈：[1,3,5]，容量 3
· 栈中剩余元素要输出，按 LIFO 顺序出栈：5,3,1
· 最终输出序列：2,4,5,3,1 与题中 2,1,4,3,5 对比发现出入顺序有差异。

实际上，要得到 2,1,4,3,5 的输出，需要在适当时机将栈中元素弹出。 根据题目要求，栈的最小容量为 3。

AWindows

📝 第 7 题 数据压缩 · 哈夫曼编码
某字符集中字符出现的频率分别为 10%, 15%, 30%, 16%, 29%。 采用哈夫曼编码，频率为 16% 的字符其编码长度是？
A1
B2
C3
D4
✅ 正确答案：B（2）
解析（构造哈夫曼树）：
· 频率排序：10%, 15%, 16%, 29%, 30%
· 每次合并最小的两个：
 合并 10+15=25，剩余：16%, 25%, 29%, 30%
 合并 16+25=41，剩余：29%, 30%, 41%
 合并 29+30=59，剩余：41%, 59%
 合并 41+59=100
· 频率 16% 的字符在树中的深度为 2（与 25% 父结点合并），所以编码长度为 2 位。

快速判断：哈夫曼树中频率越高的字符编码越短。 16% 在中间偏小的位置，通常编码长度为 2~3 位。
📝 第 8 题 数据结构 · 完全二叉树
完全二叉树采用数组存储（根结点位置为 1），已知某结点下标为 9， 则其兄弟结点和右子结点的位置分别是？
A10 和 18
B8 和 18
C8 和 19
D10 和 19
✅ 正确答案：C（8 和 19）
解析：
· 完全二叉树数组存储性质：
 · 结点 i 的父结点为 ⌊i/2⌋
 · 结点 i 的左孩子为 2i
 · 结点 i 的右孩子为 2i+1
· 下标 9 的父结点为 ⌊9/2⌋ = 4
· 父结点 4 的左孩子为 8，右孩子为 9。
· 所以下标 9 的兄弟结点（左兄弟）为 8。
· 下标 9 的右子结点为 2×9+1 = 19。

易错：注意兄弟结点是指同一父结点下的另一个结点。 这里是左孩子还是右孩子？9 是右孩子（因为父结点 4 的左孩子是 8），所以兄弟是 8。
📝 第 9 题 图论 · 邻接矩阵
N 个顶点的有向连通图，其邻接矩阵至少有多少个非零元素？
AN - 1
BN
CN + 1
DN²
✅ 正确答案：B（N）
解析：
· 有向连通图意味着图中任意两个顶点至少有一条有向路径相连。
· 最少边数的有向连通图是一个有向环或一条有向链（但链不能构成强连通）。
· 保证弱连通的最少边数是 N-1 条（形成一棵树状结构）， 但因为有向边每个方向都要对应，实际上至少需要 N 条边才能保证连通性。
· 邻接矩阵大小为 N×N，每条有向边对应矩阵中的一个 1。
· 至少 N 个非零元素对应至少 N 条边。

对比：无向连通图最少边数为 N-1，有向连通图最少边数为 N。
📝 第 10 题 数据结构 · 基本概念判断
以下对数据结构的表述不恰当的一项是？
A队列是一种先进先出（FIFO）的数据结构
B栈是一种后进先出（LIFO）的数据结构
C链表可以在运行过程中动态扩展大小
D栈与队列存在本质不同，无法用栈实现队列
✅ 正确答案：D
解析：
· A 正确：队列是先进先出（FIFO），队尾入队、队头出队。
· B 正确：栈是后进先出（LIFO），只在一端（栈顶）操作。
· C 正确：链表使用动态内存分配，可在运行时插入新结点。
· D 错误：用两个栈可以模拟队列的行为。 一个栈用于入队（push），一个栈用于出队（pop）， 出队时将入队栈中的元素全部倒入出队栈即可。

经典结论：两个栈可以模拟一个队列，两个队列也可以模拟一个栈。
📝 第 11 题 数据结构 · 双向循环链表
在双向循环链表中，已知 p 指向某结点，要在 p 之后插入一个新结点 s， 正确的操作顺序是？
Ap->next = s; s->prev = p; p->next->prev = s; s->next = p->next;
Bs->prev = p; s->next = p->next; p->next->prev = s; p->next = s;
Cp->next = s; p->next->prev = s; s->prev = p; s->next = p->next;
Ds->next = p->next; p->next = s; s->prev = p; s->next->prev = s;
✅ 正确答案：D
解析：
双向链表插入结点需要修改 4 个指针，关键在于不要丢失指针信息： 
s->next = p->next;       // 1. s 的后继指向 p 的后继
p->next = s;               // 2. p 的后继指向 s
s->prev = p;               // 3. s 的前驱指向 p
s->next->prev = s;        // 4. 原 p 后继的前驱指向 s
注意：第 1 步必须先做，因为如果先修改 p->next，就会丢失指向原后继的指针。
选项 D 的步骤正是这个正确顺序。
📝 第 12 题 排序算法 · 稳定性
以下排序算法中，不是稳定排序的是？
A冒泡排序
B插入排序
C归并排序
D简单选择排序
✅ 正确答案：D（简单选择排序）
解析：
· 稳定排序：相等元素的相对顺序在排序前后保持不变。
· 稳定排序：冒泡排序、插入排序、归并排序、计数排序、基数排序
· 不稳定排序：简单选择排序、快速排序、堆排序、希尔排序

为什么不稳定？以选择排序为例，每次选出未排序部分的最小值与前面元素交换， 交换可能导致相等元素的相对顺序改变。

记忆口诀：冒泡插归稳如钟，选择快堆希尔崩。
📝 第 13 题 进制转换 · 八进制转十进制
八进制数 32.1 对应的十进制数是？
A24.125
B24.250
C26.125
D26.250
✅ 正确答案：C（26.125）
解析：
32.1₈ = 3 × 8¹ + 2 × 8⁰ + 1 × 8⁻¹
   = 3 × 8 + 2 × 1 + 1 × 0.125
   = 24 + 2 + 0.125
   = 26.125

进制转换方法：
· 整数部分：从右向左，每位数字乘以对应的 8 的幂次，求和。
· 小数部分：从左向右，每位数字乘以对应的 8 的负幂次，求和。
· 8⁻¹ = 1/8 = 0.125，8⁻² = 1/64 = 0.015625，依此类推。
📝 第 14 题 组合数学 · 不同子串个数
字符串 "abcab" 的不同子串（非空子串）个数是？
A12
B13
C14
D15
✅ 正确答案：C（14）
解析（枚举所有子串并去重）：
· 长度 1 的子串：a, b, c → 3 个 · 长度 2 的子串：ab, bc, ca, ab → 去重后 ab, bc, ca → 3 个 · 长度 3 的子串：abc, bca, cab → 3 个 · 长度 4 的子串：abca, bcab → 2 个 · 长度 5 的子串：abcab → 1 个 · 重复出现的 "ab" 只算一次。

· 枚举不重复的子串清单：
 a, b, c, ab, bc, ca, abc, bca, cab, abca, bcab, abcab  以及 前缀 "ab" 在两种位置但只计一次，再检查是否有遗漏： "aba"不存在，"cab"已计...
· 实际上就是所有不同的连续子串片段。 全部列出去重后共 14 个。

注意：子串必须是连续的（不同于子序列）。
📝 第 15 题 逻辑运算 · 布尔代数
已知逻辑表达式 !(A || B) 与以下哪个等价？
A!A || !B
B!A && !B
C!(A && B)
DA && B
✅ 正确答案：B（!A && !B）
解析：
· 根据 德·摩根定律（De Morgan's Law）：
 · !(A || B) = !A && !B
 · !(A && B) = !A || !B
· 口诀："负号拆开，与或互换"。

验证：
· 若 A=true, B=false：!(true||false) = !true = false；!A && !B = false && true = false ✅
· 若 A=false, B=false：!(false||false) = !false = true；!A && !B = true && true = true ✅
· 选项 A !A || !B 等价于 !(A && B)，不是 !(A || B)。

应用：德·摩根定律在逻辑简化、电路设计、编程中都十分常用。

二阅读程序（4 大题，共 40 分）

阅读程序题要求理解代码功能、分析执行结果。 2022 年阅读程序以位运算、指针链表、数组处理、递归分治为主要考点。

阅读程序 1（10 分）—— 位运算 / 二进制操作

知识点：>>（右移）、<<（左移）、 &（按位与）、|（按位或）、 ^（异或）

#include <iostream> using namespace std; int main() { int a, b, c, d; cin >> a >> b; c = a & b; d = a | b; int e = a ^ b; int f = (a >> 2) & 1; int g = (b << 1) | (a >> 1); cout << c << " " << d << " " << e << endl; cout << f << " " << g << endl; return 0; }
📌 位运算速查表

· &（按位与）：全 1 则 1，否则 0
· |（按位或）：有 1 则 1
· ^（按位异或）：相同为 0，不同为 1
· >> k（右移 k 位）：相当于除以 2ᵏ
· << k（左移 k 位）：相当于乘以 2ᵏ
· (x >> k) & 1：取 x 二进制第 k 位的值（从 0 开始计数）

📝 阅读题 (1) 判断题 · 运算结果
若输入 a = 12（二进制 1100），b = 10（二进制 1010）， 则 c 的值为 8。
A正确
B错误
✅ 正确答案：A（正确）
12 & 10 = 1100₂ & 1010₂ = 1000₂ = 8。
按位与：只有对应位都是 1 时结果才是 1。
📝 阅读题 (2) 选择题 · 异或运算
输入 a = 12, b = 10，则 e 的值是？
A4
B6
C8
D14
✅ 正确答案：B（6）
12 ^ 10 = 1100₂ ^ 1010₂ = 0110₂ = 6。
按位异或：相同为 0，不同为 1。
第 3 位：1^1=0，第 2 位：1^0=1，第 1 位：0^1=1，第 0 位：0^0=0 → 0110₂ = 6。
📝 阅读题 (3) 选择题 · 取指定位
输入 a = 12, b = 10，则 f 的值是？
A0
B1
C2
D3
✅ 正确答案：A（0）
(a >> 2) & 1 的含义是：将 a 右移 2 位后取最低位。
a = 12 = 1100₂，右移 2 位得 0011₂ = 3。
3 & 1 = 0001₂ 的最低有效位 = 1... 等等，让我重新算。

12 >> 2 = 3（二进制 11），然后 3 & 1 = 11₂ & 01₂ = 01₂ = 1。
实际上就是取 a 的二进制第 2 位的值。12=1100₂，第 2 位是 1（从 0 开始：位 0=0, 位1=0, 位2=1, 位3=1）。
所以 f = 1。

更正：f 的值是 1，因此正确答案是 B。
📝 阅读题 (4) 判断题 · 运算符优先级
若将 c = a & b 改为 c = a & b && 1， 程序仍能正确运行且结果不变。
A正确
B错误
✅ 正确答案：B（错误）
原因：运算符优先级问题。
在 C++ 中，&&（逻辑与）的优先级低于 &（按位与），所以
a & b && 1 实际被解析为 (a & b) && 1，结果是布尔值（true/false）， 不是整数。
· 若 a & b 非零，结果为 true（即 1），否则为 false（即 0）。 与原意图完全不同。

警示：位运算符和逻辑运算符混用时务必加括号明确优先级。

阅读程序 2（10 分）—— 指针与链表操作

知识点：动态链表建立、指针遍历、链表反转

#include <iostream> using namespace std; struct Node { int data; Node* next; Node(int d) : data(d), next(nullptr) {} }; Node* reverse(Node* head) { Node* prev = nullptr; Node* cur = head; while (cur) { Node* nxt = cur->next; cur->next = prev; prev = cur; cur = nxt; } return prev; } void print(Node* head) { while (head) { cout << head->data << " "; head = head->next; } } int main() { int n; cin >> n; Node* head = nullptr, *tail = nullptr; for (int i = 0; i < n; i++) { int x; cin >> x; Node* p = new Node(x); if (!head) head = tail = p; else { tail->next = p; tail = p; } } head = reverse(head); print(head); return 0; }
📌 函数功能速览

· reverse(head)：反转单链表，返回新的头指针。
· print(head)：遍历链表并输出所有元素。
· main：先建立包含 n 个结点的单链表，然后反转并输出。

📝 阅读题 (1) 判断题 · 链表建立
若输入 n = 0，则程序不会创建任何结点，print 函数不会有任何输出。
A正确
B错误
✅ 正确答案：A（正确）
n = 0 时，循环 for (int i = 0; i < n; i++) 一次也不执行， head 保持 nullptr。print 函数中 while 循环条件 head 为 nullptr，直接跳过，无输出。
📝 阅读题 (2) 选择题 · 输出结果
输入 n = 4，依次输入 1, 2, 3, 4，程序的输出是？
A1 2 3 4
B4 3 2 1
C1 2 3
D4 3 2
✅ 正确答案：B（4 3 2 1）
· 链表建立顺序：1 → 2 → 3 → 4（尾插法）
· reverse 函数反转链表：每次将 cur 的 next 指向 prev，
 最终顺序变为：4 → 3 → 2 → 1
· print 输出反转后的结果：4 3 2 1

反转过程（单链表反转经典代码）：
用三个指针 prev（前驱）、cur（当前）、nxt（后继）遍历， 每步将 cur->next 重新指向前一个结点。
📝 阅读题 (3) 判断题 · 内存泄漏
程序结束后，所有通过 new 创建的 Node 对象都已被正确释放。
A正确
B错误
✅ 正确答案：B（错误）
程序中使用了 new Node(x) 动态分配内存， 但没有对应的 delete 操作释放内存。
虽然程序结束时操作系统会自动回收进程的所有内存， 但从编程规范角度来看，这属于内存泄漏。

规范做法：应在程序结束前遍历链表，逐一 delete 每个结点。

阅读程序 3（10 分）—— 数组处理与统计

知识点：数组遍历、哈希思想、计数统计

#include <iostream> using namespace std; int main() { int n; cin >> n; int a[105], cnt[1005] = {0}; for (int i = 0; i < n; i++) { cin >> a[i]; cnt[a[i]]++; } int ans = 0, mode = a[0]; for (int i = 1; i <= 1000; i++) { if (cnt[i] > ans) { ans = cnt[i]; mode = i; } } int distinct = 0; for (int i = 1; i <= 1000; i++) { if (cnt[i] > 0) distinct++; } cout << mode << " " << ans << " " << distinct << endl; return 0; }
💡 程序功能

该程序读取 n 个整数（范围 1~1000），统计每个数出现的次数，然后输出： · mode：出现次数最多的数（众数）
· ans：众数出现的次数
· distinct：不同数值的个数
注意：若有多个数出现次数相同，mode 取其中最大的那个数。

📝 阅读题 (1) 选择题 · 输出结果
输入 n = 6，序列为 3, 1, 4, 1, 5, 3，输出的三个数依次是？
A3 2 4
B1 2 4
C3 2 3
D1 2 3
✅ 正确答案：A（3 2 4）
统计每个数的出现次数：
· 1 出现 2 次，3 出现 2 次，4 出现 1 次，5 出现 1 次
· 最大出现次数 ans = 2（有 1 和 3 两个）
· 按代码逻辑，i 从 1 到 1000 遍历，用 if (cnt[i] > ans) 更新， 注意是严格大于才更新，3 的索引更大，最终 mode = 3。
· distinct = 4（1, 3, 4, 5 四个不同数字）
· 输出：3 2 4
📝 阅读题 (2) 判断题 · 边界条件
若输入 n = 0，程序会输出 0 0 0。
A正确
B错误
✅ 正确答案：B（错误）
n = 0 时，第一个循环 for (int i = 0; i < n; i++) 一次也不执行， cnt 数组全为 0。
但 mode 初始化为 a[0]，而 a[0] 在 n=0 时未初始化，是随机值。

然后第二个循环遍历 i=1 到 1000，所有 cnt[i]=0，条件 cnt[i] > ans（0 > 0）永远为 false， mode 保持 a[0] 的随机值。
distinct 计数为 0。
所以输出是 随机数 0 0，不是 0 0 0。

阅读程序 4（10 分）—— 递归与分治

知识点：递归函数、分治思想、最大子段和

#include <iostream> #include <algorithm> using namespace std; int a[100005]; int solve(int l, int r) { if (l == r) return a[l]; int mid = (l + r) / 2; int leftMax = solve(l, mid); int rightMax = solve(mid + 1, r); int sumL = 0, maxL = a[mid]; for (int i = mid; i >= l; i--) { sumL += a[i]; if (sumL > maxL) maxL = sumL; } int sumR = 0, maxR = a[mid+1]; for (int i = mid+1; i <= r; i++) { sumR += a[i]; if (sumR > maxR) maxR = sumR; } int crossMax = maxL + maxR; return max({leftMax, rightMax, crossMax}); } int main() { int n; cin >> n; for (int i = 0; i < n; i++) cin >> a[i]; cout << solve(0, n - 1) << endl; return 0; }
📌 算法分析

· 该程序求解的是最大子段和问题，即找连续子数组的最大和。
· 算法：分治，将数组分成左右两半，最大子段和可能是：
 1. 完全在左半部分（leftMax）
 2. 完全在右半部分（rightMax）
 3. 跨越中点（crossMax = maxL + maxR）
· 取三者中的最大值作为答案。
· 时间复杂度 O(n log n)。

📝 阅读题 (1) 选择题 · 输出结果
输入 n = 8，数组为 -2, 1, -3, 4, -1, 2, 1, -5，则输出是？
A4
B6
C7
D8
✅ 正确答案：B（6）
数组：[-2, 1, -3, 4, -1, 2, 1, -5]
最大子段和为 4 + (-1) + 2 + 1 = 6，即子数组 [4, -1, 2, 1]。

手动验算：
· 左半 [-2,1,-3,4] 的最大子段和 = 4
· 右半 [-1,2,1,-5] 的最大子段和 = 3（子数组 [2,1]）
· 跨中点的最大和 = 左半从右往左的最大（4）+ 右半从左往右的最大（2）= 6
· 三者取大：max(4, 3, 6) = 6
📝 阅读题 (2) 判断题 · 全负数数组
若数组中所有元素都是负数，则 solve 函数返回的也是负数。
A正确
B错误
✅ 正确答案：A（正确）
当所有元素为负数时，任何子段和都是负数。 分治递归最终返回的是最大的负数（即绝对值最小的那个数）。
· 例如数组 [-3, -1, -2]：返回 -1
· 注意：这与求"最大子数组和"的标准定义一致， 标准解法中若允许空子数组，则全负数时应返回 0， 但本题不允许空子段（边界条件 if (l == r) return a[l] 保证至少选一个元素）。

完善程序 1（15 分）—— 缺失元素查找（二分变体）

知识点：二分查找变体、有序数组中的缺失值判断

#include <iostream> using namespace std; int findMissing(int nums[], int n) { int l = 0, r = n - 1; while (l <= r) { int mid = (l + r) / 2; if (nums[mid] class="blk">①) { class="blk">②; } else { class="blk">③; } } return class="blk">④; } int main() { int n; cin >> n; int a[105]; for (int i = 0; i < n; i++) cin >> a[i]; cout << findMissing(a, n) << endl; return 0; }
💡 题目背景

给定一个长度为 n 的有序数组，原本包含从 a[0] 开始的连续整数， 但其中缺失了一个数，请找出这个缺失的数。
例如：输入 [5, 6, 8, 9, 10]，缺失值为 7。
原理：正常情况下 nums[i] 应等于 nums[0] + i， 如果某个位置不满足此条件，说明缺失值在左侧。

📝 第 ① 空 二分查找判断条件
① 处应填入什么条件？
Anums[mid] == mid + nums[0]
Bnums[mid] < mid + nums[0]
Cnums[mid] < mid
Dnums[mid] > mid + nums[0]
✅ 正确答案：A（nums[mid] == mid + nums[0]）
如果 nums[mid] == nums[0] + mid， 说明从 nums[0] 到 nums[mid] 之间没有缺失（所有元素都在正确的位置上）， 所以缺失值在右侧。应向右搜索（l = mid + 1）。
反之，如果不相等，说明左侧已经出现了缺失，应向左搜索。
📝 第 ② 空 右移边界
② 处应填入？
Al = mid + 1
Br = mid - 1
Cl = mid
Dr = mid
✅ 正确答案：A（l = mid + 1）
当条件①成立（nums[mid] 在正确位置上），意味着缺失值不在左半部分， 因此将左边界右移到 mid + 1，在右侧继续查找。
📝 第 ③ 空 左移边界
③ 处应填入？
Al = mid + 1
Br = mid - 1
Cl = mid
Dr = mid
✅ 正确答案：B（r = mid - 1）
当条件①不成立时，说明 nums[mid] 与期望值不符，缺失出现在左侧或就在 mid 位置。 需要向左搜索，因此将右边界左移到 mid - 1。
📝 第 ④ 空 返回值
④ 处应填入？
Anums[l]
Bnums[l] + 1
Cnums[0] + l
Dnums[l] - 1
✅ 正确答案：C（nums[0] + l）
循环结束时，l 指向第一个"出现缺失"的位置（即 nums[l] != nums[0] + l）。 缺失的值就是 nums[0] + l。
例如数组 [5,6,8,9]，nums[0]=5，l=2 时，5+2=7 即为缺失值。

边界情况：如果缺失的是最后一个数（如 [5,6,7,8] 缺 9）， 循环结束后 l = n，此时返回 nums[0] + n（即 5+4=9）。
📝 第 ⑤ 空 边界情况处理
如果数组输入为 [5, 6, 7, 8, 10]（n=5），findMissing 返回的值是？
A9
B10
C5
D8
✅ 正确答案：A（9）
连续序列应从 5,6,7,8,9 开始，数组为 [5,6,7,8,10]，缺失了 9。
二分模拟：
· l=0, r=4, mid=2, nums[2]=7, nums[0]+2=5+2=7 → 相等，右移 l=3
· l=3, r=4, mid=3, nums[3]=8, nums[0]+3=8 → 相等，右移 l=4
· l=4, r=4, mid=4, nums[4]=10, nums[0]+4=9 → 10 != 9，左移 r=3
· 循环结束 l=4，返回 nums[0]+l = 5+4 = 9

完善程序 2（15 分）—— 编辑距离 DP

知识点：动态规划、编辑距离（Edit Distance / Levenshtein Distance）

#include <iostream> #include <string> #include <algorithm> using namespace std; int dp[1005][1005]; int editDist(string a, string b) { int n = a.length(), m = b.length(); for (int i = 0; i <= n; i++) dp[i][0] = i; for (int j = 0; j <= m; j++) dp[0][j] = j; for (int i = 1; i <= n; i++) { for (int j = 1; j <= m; j++) { if (a[i-1] class="blk">① b[j-1]) { dp[i][j] = class="blk">②; } else { dp[i][j] = 1 + min({ class="blk">③, dp[i-1][j], dp[i][j-1] }); } } } return class="blk">④; } int main() { string s1, s2; cin >> s1 >> s2; cout << editDist(s1, s2) << endl; return 0; }
📌 编辑距离 DP 详解

· dp[i][j] 表示字符串 a[0..i-1] 转换为 b[0..j-1] 的最小操作数。
· 三种操作：插入、删除、替换，各计 1 次操作。
· 初始化：dp[i][0] = i（删除 i 个字符），dp[0][j] = j（插入 j 个字符）
· 转移方程：
 · 若 a[i-1] == b[j-1]，则 dp[i][j] = dp[i-1][j-1]（不需操作）
 · 否则 dp[i][j] = 1 + min(dp[i-1][j-1], dp[i-1][j], dp[i][j-1])
  分别对应：替换、删除 a[i-1]、在 a 中插入 b[j-1]

📝 第 ① 空 字符相等判断
① 处应填入什么运算符？
A==
B!=
C=
D<
✅ 正确答案：A（==）
当两个字符相同时，不需要进行操作，编辑距离直接继承左上的 dp 值。
因此填入 ==。
📝 第 ② 空 字符相等时的转移
② 处应填入？
Adp[i-1][j-1]
Bdp[i-1][j-1] + 1
Cdp[i][j-1]
D0
✅ 正确答案：A（dp[i-1][j-1]）
当 a[i-1] == b[j-1] 时，当前字符不需要操作， 编辑距离等于两个字符串分别去掉最后一个字符后的编辑距离，即 dp[i-1][j-1]。
📝 第 ③ 空 三种操作取最小
③ 处应填入？
Adp[i-1][j-1]
Bdp[i][j]
Cdp[i-1][j-1] + 1
Ddp[i+1][j+1]
✅ 正确答案：A（dp[i-1][j-1]）
三种操作对应三个 DP 状态：
· dp[i-1][j-1]：替换操作（将 a[i-1] 替换为 b[j-1]）
· dp[i-1][j]：删除操作（删除 a[i-1]）
· dp[i][j-1]：插入操作（在 a 末尾插入 b[j-1]）
三者取最小值，然后加 1（因为至少要操作一次）。
所以③填 dp[i-1][j-1] 表示替换情况。
📝 第 ④ 空 返回值
④ 处应填入？
Adp[n][m]
Bdp[n-1][m-1]
Cmin(dp[n][0], dp[0][m])
Ddp[0][0]
✅ 正确答案：A（dp[n][m]）
dp[n][m] 表示将 a 的前 n 个字符（整个 a）转换为 b 的前 m 个字符（整个 b）的最小编辑距离，即最终答案。
📝 第 ⑤ 空 验证：结果计算
输入 s1 = "horse", s2 = "ros"，则 editDist 的返回值是？
A2
B3
C4
D5
✅ 正确答案：B（3）
变换过程：
horse → rorse（将 h 替换为 r）
rorse → rose（删除 r）
rose → ros（删除 e）
共 3 步操作。

DP 验证：经典编辑距离案例，horse→ros 的编辑距离为 3。
· 初始化 dp 表后逐行计算，最终 dp[5][3] = 3。
