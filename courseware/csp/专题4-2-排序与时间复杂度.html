1大 O 表示法（Big O Notation）

什么是大 O

大 O 表示法用来描述算法的时间复杂度，即输入规模增大时算法执行时间的增长趋势。它关注的是"增长的量级"，忽略常数系数和低阶项。

符号名称含义示例
O(1)常数级执行时间不随输入规模变化数组随机访问、哈希表查找
O(log n)对数级每次迭代将问题规模减半二分查找、平衡树查找
O(n)线性级执行时间与输入规模成正比线性查找、遍历数组
O(n log n)线性对数级将问题分解后线性处理归并排序、快速排序（平均）
O(n²)平方级双重循环，数据量翻倍则时间变4倍冒泡排序、选择排序、插入排序
O(2ⁿ)指数级暴力枚举所有子集斐波那契递归（朴素）
💡 记忆口诀：O(1) 最快，O(2ⁿ) 最慢。对数好于线性，线性好于平方。

复杂度大小关系

O(1) < O(log n) < O(n) < O(n log n) < O(n²) < O(n³) < O(2ⁿ) < O(n!)

📌 考试常见陷阱

题目说"一个循环执行 n 次，另一个循环也执行 n 次，嵌套起来就是 O(n × n) = O(n²)"；如果是两个非嵌套的顺序循环，则复杂度是 O(n + n) = O(2n) = O(n)。

📝 例 1时间复杂度判断
以下哪个时间复杂度表示的是对数级？
A O(1)
B O(log n)
C O(n)
D O(n²)
📖 点击查看答案
✅ 答案：B
解析：O(log n) 表示对数级。典型场景：二分查找每次将数据规模减半，log₂(n) 次后找到结果。A是常数级，C是线性级，D是平方级。

for (int i = 0; i < n; i++) for (int j = 0; j < n; j++) a[i][j] = i * j;

2六种排序算法详解

2.1 冒泡排序（Bubble Sort）

核心思想：从左到右依次比较相邻两个元素，如果顺序不对则交换，每一轮将当前最大值"冒泡"到末尾。重复 n-1 轮。

void bubbleSort(int a[], int n) { for (int i = 0; i < n-1; i++) for (int j = 0; j < n-1-i; j++) if (a[j] > a[j+1]) swap(a[j], a[j+1]);}

2.2 选择排序（Selection Sort）

核心思想：每一轮从未排序部分选出最小值，放到已排序部分的末尾。

void selSort(int a[], int n) { for (int i = 0; i < n-1; i++) { int m = i; for (int j = i+1; j < n; j++) if (a[j] < a[m]) m = j; swap(a[i], a[m]); }}

2.3 插入排序（Insertion Sort）

核心思想：像打牌一样，将每个元素插入到已排序部分的正确位置。

void insSort(int a[], int n) { for (int i = 1; i < n; i++) { int key = a[i], j = i-1; while (j >= 0 && a[j] > key) a[j+1] = a[j--]; a[j+1] = key; }}

2.4 归并排序（Merge Sort）

核心思想：分治策略——将数组分成两半，分别排序后合并（merge）。

void mergeSort(int a[], int l, int r) { if (l >= r) return; int m = (l + r) / 2; mergeSort(a, l, m); mergeSort(a, m+1, r); merge(a, l, m, r);}

2.5 快速排序（Quick Sort）

核心思想：选取一个基准（pivot），将小于它的放左边、大于它的放右边，然后递归排序左右两部分。

void qSort(int a[], int l, int r) { if (l >= r) return; int p = partition(a, l, r); qSort(a, l, p-1); qSort(a, p+1, r);}

2.6 堆排序（Heap Sort）

核心思想：利用大根堆性质，每次取出堆顶（最大值）放到数组末尾，然后调整剩余数组使之重新成堆。

void heapSort(int a[], int n) { for (int i = n/2-1; i >= 0; i--) heapify(a, n, i); for (int i = n-1; i > 0; i--) { swap(a[0], a[i]); heapify(a, i, 0); }}

稳稳定性分析

什么叫稳定排序？如果两个相等元素的相对顺序在排序后保持不变，则称该排序算法是稳定的。

稳定 ✅不稳定 ❌
冒泡排序（相邻比较，相等不交换）选择排序（选最小值时可能破坏相对顺序）
插入排序（相等元素插入在后面）快速排序（交换时打乱顺序）
归并排序（合并时优先取左边）堆排序（建堆和调整时打乱顺序）
希尔排序（分组跳跃式插入）
📌 稳定性记忆歌诀

"冒插归（猫插龟）是稳定的；选快堆希（选快对稀）是不稳定的。"

📝 真题（2022 第12题）稳定性判断
（2022 CSP-J 初赛）以下排序方法中，不属于稳定排序的是？
A 冒泡排序
B 简单选择排序
C 直接插入排序
D 归并排序
📖 点击查看答案
✅ 答案：B
解析：简单选择排序在每轮选出最小值时，可能将前面的相同元素交换到后面，破坏了相对顺序，因此不稳定。冒泡、插入、归并都是稳定的。

表时间复杂度对比

排序算法平均最好最坏空间稳定性
冒泡排序O(n²)O(n)（已优化）O(n²)O(1)✅ 稳定
选择排序O(n²)O(n²)O(n²)O(1)❌ 不稳定
插入排序O(n²)O(n)O(n²)O(1)✅ 稳定
归并排序O(n log n)O(n log n)O(n log n)O(n)✅ 稳定
快速排序O(n log n)O(n log n)O(n²)O(log n)❌ 不稳定
堆排序O(n log n)O(n log n)O(n log n)O(1)❌ 不稳定
⚠️ 重要考点

• 只有归并排序在所有情况下都能保证 O(n log n) 且是稳定的。
• 快速排序在最坏情况（已有序或逆序）下退化为 O(n²)。
• 选择排序无论数据如何，始终进行 n(n-1)/2 次比较，时间复杂度恒定 O(n²)。
• 堆排序和归并排序最坏情况也是 O(n log n)，但堆排序空间更优（O(1)）。

★冒泡排序交换次数计算

冒泡排序中，交换次数 = 逆序对的数量。一对元素 (a[i], a[j])，若 i < j 且 a[i] > a[j] 则构成一个逆序对。

📌 2025 CSP-J 第12题（冒泡排序交换次数）

已知数组 {6, 1, 5, 2, 4}，对其使用冒泡排序（从小到大），请问需要交换多少次？

初始: 6 1 5 2 4
第1轮: 1 6 5 2 4 (交换6和1,交换6和5,交换6和2,交换6和4 → 4次)
第2轮: 1 5 2 4 6 (交换5和2,交换5和4 → 2次)
第3轮: 1 2 4 5 6 (无需交换)
共交换：4 + 2 = 6 次

用逆序对验证： {6,1} {6,5} {6,2} {6,4} {5,2} {5,4} 共 6 个逆序对 ✅

📝 真题（2025 第12题）冒泡交换次数
对数组 {6, 1, 5, 2, 4} 进行冒泡排序（升序），交换次数为？
A 4
B 5
C 6
D 7
📖 点击查看答案
✅ 答案：C
解析：冒泡排序的交换次数等于数组中逆序对个数。数组 {6,1,5,2,4} 的逆序对有 (6,1)(6,5)(6,2)(6,4)(5,2)(5,4) 共 6 个。模拟过程：第一轮交换4次（6与1、5、2、4各一次）；第二轮交换2次（5与2、4）；第三轮无需交换。共 4+2=6 次。

3复杂度分析方法

3.1 循环嵌套分析

分析步骤：1）确定最内层循环的执行次数；2）根据嵌套层数相乘；3）忽略常数和低阶项。

循环模式复杂度说明
for(i=0;i<n;i++)O(n)单层循环
两层嵌套 for(i..) for(j..)O(n²)每层都到 n
for(i..) for(j..i)O(n²)1+2+...+n = n(n+1)/2 → O(n²)
for(i=1;i<n;i*=2)O(log n)每次翻倍
for(i=0;i<n;i++) for(j=0;j<n;j*=2)O(n log n)外层线性 × 内层对数

3.2 递归复杂度入门

主定理（Master Theorem）快速判断：对于递归式 T(n) = a·T(n/b) + f(n)：

递归关系时间复杂度典型算法
T(n) = T(n-1) + O(1)O(n)线性递归（遍历链表）
T(n) = 2·T(n/2) + O(1)O(n)二叉树遍历
T(n) = 2·T(n/2) + O(n)O(n log n)归并排序
T(n) = T(n/2) + O(1)O(log n)二分查找
T(n) = T(n-1) + T(n-2)O(2ⁿ)朴素斐波那契
📝 例 4最坏比较次数
（2021 CSP-J 改编）在 N 个数中找出最大值，最坏情况下需要比较多少次？
A N
B N-1
C N/2
D log N
📖 点击查看答案
✅ 答案：B
解析：找最大值只需遍历一次：先设 a[0] 为最大值，然后与后面 N-1 个数逐一比较，每次比较最多更新一次最大值，共 N-1 次比较。这是 2021 年 CSP-J 第4题的原题考点。
📝 例 5递归复杂度判断
以下哪个时间复杂度表示线性对数级？
A O(n)
B O(n²)
C O(n log n)
D O(log n)
📖 点击查看答案
✅ 答案：C
解析：O(n log n) 称为线性对数级，归并排序和快速排序的平均复杂度就是 O(n log n)。

A 4
B 5
C 6
D 7

解析：逆序对数量 = 交换次数。6>1,6>5,6>2,6>4,5>2,5>4 → 共6个逆序对。模拟：第1轮交换4次，第2轮交换2次，共6次。
真题（2021 第4题）最坏比较次数
在 N 个互不相同的数中找出最大的数，最坏情况下需要比较的次数是？
A N
B N-1
C N/2
D log N
📖 点击查看答案
✅ 答案：B
解析：第1个数设为最大值，用后 N-1 个数逐一比较，每次1次比较，共 N-1 次。无论数据如何排列，都需要 N-1 次比较。
模拟题 4二分查找复杂度
在长度为 n 的有序数组中用二分查找查找一个元素，时间复杂度为？
A O(1)
B O(log n)
C O(n)
D O(n²)
📖 点击查看答案
✅ 答案：B
解析：二分查找每次将搜索范围缩小一半，log₂(n) 次后即可找到目标，时间复杂度为 O(log n)。
模拟题 5归并排序复杂度
归并排序在任何情况下的时间复杂度都是？
A O(n)
B O(n log n)
C O(n²)
D O(log n)
📖 点击查看答案
✅ 答案：B
解析：归并排序采用分治策略，无论数据有序与否，都会将数组一分为二再合并，时间复杂度始终为 O(n log n)。空间复杂度 O(n)。
模拟题 6希尔排序稳定性
以下哪种排序算法是不稳定的？
A 插入排序
B 冒泡排序
C 希尔排序
D 归并排序
📖 点击查看答案
✅ 答案：C
解析：希尔排序基于插入排序，但它是分组跳跃式插入，相同元素可能分到不同组，相对顺序被破坏。选快堆希（选择、快速、堆、希尔）都是不稳定的。
模拟题 7快速排序最坏情况
快速排序在最坏情况下的时间复杂度为？
A O(n log n)
B O(n)
C O(n²)
D O(n³)
📖 点击查看答案
✅ 答案：C
解析：当数组已有序（升序或降序）且每次选取第一个或最后一个元素为 pivot 时，快速排序每次只能分割出规模为 1 和 n-1 的两个子问题，退化为 O(n²)。
模拟题 8循环嵌套复杂度
以下代码的时间复杂度是？
for (int i = 0; i < n; i++) for (int j = i + 1; j < n; j++) cout << i << j << endl;
A O(n)
B O(n²)
C O(n log n)
D O(2ⁿ)
📖 点击查看答案
✅ 答案：B
解析：内层循环从 i+1 到 n-1，总执行次数为 (n-1)+(n-2)+...+1 = n(n-1)/2 = O(n²)。虽然比 n²/2 略少，但量级仍然是平方级。
