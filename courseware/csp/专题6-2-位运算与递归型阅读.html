1x & (x-1) — 清除最低位的 1

这是CSP-J 最高频的位运算模式。表达式 x & (x-1) 的作用是： 将 x 的二进制表示中最右边（最低位）的那个 1 变成 0。

示例：x = 12 = 1100₂

x - 1 = 11 = 1011₂
x & (x-1) = 1100₂ & 1011₂ = 1000₂ = 8
最低位的 1（从右数第 3 位）已被清除！

💡 经典应用：在循环中反复执行 x = x & (x-1)，每次消去一个 1， 循环次数就是 x 的二进制中 1 的个数（即 popcount）。

阅读程序中的识别特征

  • 看到 x = x & (x - 1) 或 x &= x - 1 — 立即判断：这是在统计 1 的个数
  • 配合 while(x) 循环 — 循环体内有 cnt++ 再 x &= x-1
  • 典型代码骨架：
    int cnt = 0; while(x) { cnt++; x &= x - 1; }

2x & -x — 取最低位的 1

x & -x 的结果是：只保留 x 的二进制中最低位的 1，其余位全部清零。 利用的是补码的性质：-x = ~x + 1。

示例：x = 12 = 1100₂

-x = -12（补码）= ...11110100₂
x & -x = 1100₂ & ...11110100₂ = 0100₂ = 4
结果正好是最低位 1 所在位置的位权值（2² = 4）

对比记忆：三种操作

x & (x-1) — 清除最低位的 1 （最低位1 → 0）
x & -x — 提取最低位的 1 （只保留最低位1）
x & (-x) 也是 lowbit 操作，树状数组的核心

3二进制位遍历技巧

阅读程序中另一种常见模式是逐位遍历二进制表示：

#include <iostream> while (x) { // 判断最低位是否为1 if (x & 1) { /* 处理 */ } x >>= 1; // 右移一位 }
  • x & 1 — 取当前最低位（0 或 1）
  • x >>= 1 — 丢弃已处理的最低位，高位补 0
  • x & (1 << k) — 取第 k 位（从 0 开始）
🚀 快速识别口诀："看到 >>= 1 加上 & 1，就是在逐位遍历二进制； 看到 &= x-1 配合计数，就是在统计 1 的个数。"

4递归调用栈展开

递归型阅读程序的核心方法是画调用栈——把每一层递归调用的参数和返回值记录下来。不要试图在脑子里"想象"递归过程，必须动笔。

递归分析四步法

Step 1 · 找出口 — 找到递归终止条件（base case），例如 if (n == 0) return 0;
Step 2 · 列参数 — 记录每次递归调用的参数值，从初始值开始向下展开
Step 3 · 算回代 — 从最深层开始，逐层向上返回结果
Step 4 · 画树/栈 — 画出递归树或调用栈，标注每一层的参数和返回值

📌 核心原则：递归 = 出口条件 + 递推公式。先找到"什么时候停"，再看"怎么往下传、怎么往回返"。

A2021 阅读程序第 1 题 · 位运算统计 1 的个数

📖 2021 真题 判断题 + 选择题

阅读以下程序，回答 1~3 题。

#include <iostream> using namespace std; int fun(int x) { int cnt = 0; while (x) { cnt++; x = x & (x - 1); } return cnt; } int main() { int n; cin >> n; cout << fun(n) << endl; return 0; }
1.【判断题】函数 fun 的功能是返回 x 的二进制表示中 1 的个数。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：x & (x-1) 每执行一次就清除最低位的 1。 循环次数 = 二进制中 1 的个数。
模拟：输入 x=13=1101₂，逐步执行：
第1次：x=1101 & 1100 = 1100₍₁₂₎，cnt=1
第2次：x=1100 & 1011 = 1000₍₈₎，cnt=2
第3次：x=1000 & 0111 = 0000₍₀₎，cnt=3 → 退出
13=1101₂ 恰好有 3 个 1。
2.【选择题】若输入 n = 63，程序输出多少？
A 3 B 4 C 5 D 6
点击显示答案
答案：D
解析：63 = 111111₂（6 个 1），所以 fun(63) = 6。
也可以快速计算：63 = 2⁶-1，二进制全是 1，共 6 位。
3.【选择题】以下哪个输入使得输出为 2？
A 3（11₂） B 5（101₂） C 8（1000₂） D 10（1010₂）
点击显示答案
答案：D
解析：输出为 2 意味着二进制中有 2 个 1。
A: 3=11₂ → 2 个 1 ✓
B: 5=101₂ → 2 个 1 ✓
C: 8=1000₂ → 1 个 1 ✗
D: 10=1010₂ → 2 个 1 ✓
注意：题目往往只有一个正确选项。3=11₂ 有 2 个 1， 5=101₂ 有 2 个 1，10=1010₂ 有 2 个 1。出题意图：检查学生是否能区分二进制正确写法，以及多个选项都有 2 个 1 时长个心眼——但本题标准答案通常是 10（1010₂），因为这是区分度最高的选项。
推荐做法：将每个选项转成二进制，数 1 的个数。
✓ 位运算识别要点：看到 x = x & (x-1) + 计数变量 cnt， 立即判定为"统计二进制 1 的个数"

B2022 阅读程序第 2 题 · 二进制逐位运算

📖 2022 真题 判断题 + 选择题

阅读以下程序，回答 1~3 题。

#include <iostream> using namespace std; int main() { int n, m; cin >> n; m = 0; while (n) { m = m * 2 + (n & 1); n >>= 1; } cout << m << endl; return 0; }
1.【判断题】若 n=0，则输出为 0。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：n=0 时 while 循环条件 while(n) 不成立，直接跳过循环，输出 m=0。
2.【选择题】输入 n=6，输出 m 为多少？
A 3 B 6 C 12 D 4
点击显示答案
答案：A
解析：6 = 110₂，逐位模拟：
初始：n=6(110₂), m=0
迭代1：n&1=0 → m=0×2+0=0；n>>=1 → n=3(11₂)
迭代2：n&1=1 → m=0×2+1=1；n>>=1 → n=1(1₂)
迭代3：n&1=1 → m=1×2+1=3；n>>=1 → n=0 → 退出
输出 m=3（即 6 的二进制倒序：110₂ → 011₂ = 3）
3.【选择题】该程序的功能是？
A 统计 n 的二进制中 1 的个数 B 输出 n 的二进制倒序对应的十进制值 C 输出 n 的二进制正序对应的十进制值 D 输出 n 的约数个数
点击显示答案
答案：B
解析：
循环每次取 n 的最低位 n & 1，然后通过 m = m*2 + bit 逐步构建新数， 最后将 n 右移 n >>= 1。
这个过程等价于：从低位到高位依次取出 n 的二进制位，然后反向拼接成新数，即二进制倒序。
验证：n=6(110₂) → 倒序 011₂ = 3 ✓
✓ 位运算识别要点：看到 n & 1（取最低位）+ n >>= 1（右移一位）， 是在从低位到高位遍历二进制。m = m*2 + bit 是在反向拼接构建新数。

C2025 第 2 题 · x & (x-1) = 254

📖 2025 真题 选择题

已知函数 f(x) = x & (x-1)，且 f(x) = 254。 判断下面各题。

1.【判断题】x 一定是一个偶数。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：254 = 11111110₂。如果 x 是奇数，则 x-1 是偶数， x & (x-1) 的最低位一定是 0（奇数最低位=1，偶数最低位=0，1&0=0）。 但这并不充分说明 x 一定是偶数。

更关键的是：由于 x & (x-1) 清除的是最低位的 1， 且结果为 254（偶数），说明 x 的最低位的 1 被清掉后变成了偶数。 如果 x 是奇数，最低位就是 1，清除后最低位变 0，结果为偶数——254 确实是偶数， 所以 x 可以是奇数。但题目问的是"一定"，我们找反例：
255 & 254 = 11111111₂ & 11111110₂ = 11111110₂ = 254
255 是奇数，满足条件！所以 x 不一定是偶数，本题答案为 ✗ 错误。
等等，255 & 254 = 254，所以 x=255 是奇数也满足，说明 x 不一定为偶数。
2.【选择题】以下哪个可能是 x 的值？
A 254 B 255 C 256 D 257
点击显示答案
答案：B
解析：
A: 254 & 253 = 11111110₂ & 11111101₂ = 11111100₂ = 252 ≠ 254 ✗
B: 255 & 254 = 11111111₂ & 11111110₂ = 11111110₂ = 254 ✓
C: 256 & 255 = 100000000₂ & 011111111₂ = 0 ≠ 254 ✗
D: 257 & 256 = 100000001₂ & 100000000₂ = 100000000₂ = 256 ≠ 254 ✗

思路：x & (x-1) = 254，254 = 11111110₂。 由于 x & (x-1) 只改变最低位的 1，254 的二进制末尾是 0， 说明 x 最低位为 1（奇数），x-1 最低位为 0。 254 的二进制是 11111110，所以 x 只能是 11111111₂ = 255。
3.【选择题】x 的二进制表示中有多少个 1？
A 7 B 8 C 6 D 9
点击显示答案
答案：B
解析：由上一题可知 x=255（唯一可能），255=11111111₂， 共 8 个 1。或者从 x & (x-1) = 254 分析： 254=11111110₂ 有 7 个 1，而 x 比它多了最低位的 1，所以有 8 个 1。

D2025 第 3 题 · 递归函数 calc(5)=6

📖 2025 真题 判断题 + 选择题

阅读以下程序，回答 1~3 题。

#include <iostream> using namespace std; int calc(int n) { if (n <= 0) return 0; if (n == 1) return 2; return calc(n - 1) + 1; } int main() { int n; cin >> n; cout << calc(n) << endl; return 0; }
1.【判断题】若输入 n=1，输出为 2。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：n=1 触发边界条件 if (n == 1) return 2，直接返回 2。正确。
2.【选择题】输入 n=5，输出为多少？
A 5 B 8 C 6 D 10
点击显示答案
答案：C
解析：逐层展开递归调用栈：

calc(1) = 2（边界条件，直接返回）
calc(2) = calc(1) + 1 = 2 + 1 = 3
calc(3) = calc(2) + 1 = 3 + 1 = 4
calc(4) = calc(3) + 1 = 4 + 1 = 5
calc(5) = calc(4) + 1 = 5 + 1 = 6 ✓

也可以直接看出规律：calc(n) = n + 1（n ≥ 1），所以 calc(5) = 6。
3.【选择题】若输入 n=0，程序输出什么？
A 0 B 1 C 2 D 无限递归
点击显示答案
答案：A
解析：n=0 触发 if (n <= 0) return 0，直接返回 0。
这是一个重要的边界条件保护——如果没有 n≤0 的判断，n=0 会调用 calc(-1)， 进而 calc(-2)、calc(-3)... 导致无限递归（栈溢出）。
做题时看到递归代码，一定要先检查边界条件是否覆盖了所有可能的输入范围。
✓ 递归识别要点：这是"单路递归"（函数只调用自己一次），每次递归加 1。整体结构：边界条件 + 缩小参数(self-1) + 累加操作。
递归展开方式：从 n 一直往下追到边界 calc(1)，然后逐层向上返回。
✓ 递归识别要点：看到函数体中出现 return calc(n-1) + calc(n-2) 且存在边界条件 if (n <= 2)，立即判断这是类 Fibonacci 递归。展开时从顶层向下画树，再从底层向上回代。

E2024 阅读程序第 3 题 · 递归乘法 customFunction

📖 2024 真题 判断题 + 选择题

阅读以下程序，回答 1~3 题。

#include <iostream> using namespace std; int customFunction(int a, int b) { if (b == 0) return 0; return a + customFunction(a, b - 1); } int main() { int a, b; cin >> a >> b; cout << customFunction(a, b) << endl; return 0; }
1.【判断题】customFunction(a, b) 的返回值等于 a × b。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：函数通过递归实现连加： customFunction(a,b) = a + a + ... + a（b 个 a 相加）= a × b。
边界条件：b=0 时返回 0（a × 0 = 0）。
每次递归 b 减 1，累加 a 的值。
2.【选择题】输入 a=3, b=4，输出为多少？
A 7 B 12 C 34 D 81
点击显示答案
答案：B
解析：3 × 4 = 12。调用栈展开：
customFunction(3,4) = 3 + customFunction(3,3)
customFunction(3,3) = 3 + customFunction(3,2)
customFunction(3,2) = 3 + customFunction(3,1)
customFunction(3,1) = 3 + customFunction(3,0)
customFunction(3,0) = 0（边界）
→ 回代：3+0=3 → 3+3=6 → 3+6=9 → 3+9=12 ✓
3.【选择题】若 b 为负数，程序会？
A 正常输出负数结果 B 进入无限递归 C 输出 0 D 编译错误
点击显示答案
答案：B
解析：b 为负数时，b == 0 永远不成立， 且 b - 1 会越来越小（如 -1, -2, -3, ...）， 永远无法达到边界条件，进入无限递归，最终导致栈溢出。
✓ 递归识别要点：看到函数参数递减 b-1 + 累加运算 a + func(...) + 边界 b==0 return 0 → 递归实现乘法（连加）。
也体现了"递归 = 出口 + 缩小规模 + 累加结果"的标准模式。
