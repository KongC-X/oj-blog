2六大挖空模式精讲

经过对五年真题的逐空分析，完善程序的挖空可归纳为六大模式。 每种模式都有固定的特征识别方法和解题策略。

模式一：循环变量初始化

  • 特征：for/while 循环的起始条件，或循环前的变量赋值
  • 识别：出现 i=__、sum=__、maxVal=__
  • 策略：判断累加/累乘（0 vs 1）、求最值（首元素 vs -INF）
  • 考核频次：★★★★★（几乎每道题第 1 空）

模式二：循环结束条件

  • 特征：for 的第二个表达式或 while 条件
  • 识别：出现 i < n vs i <= n、l < r vs l <= r
  • 策略：代入边界值（n=1, n=2）验证是否多或少执行一次
  • 考核频次：★★★★★（每年必考）

模式三：数组下标/索引

  • 特征：数组访问时的下标偏移表达式
  • 识别：出现 a[i+1]、a[i-1]、a[i*2]、s[i]-s[j]
  • 策略：模拟前 2~3 轮循环，确认下标与循环变量的对应关系
  • 考核频次：★★★★☆

模式四：递归终止条件

  • 特征：递归函数开头的 if 判断
  • 识别：出现 if (n == 0)、if (n <= 1) 等
  • 策略：用 n=0, n=1 时的数学结果反推终止条件
  • 考核频次：★★★☆☆（递归考时必出）

模式五：比较运算符

  • 特征：if 条件中的 > vs >=、< vs <=
  • 识别：求最值、排序、查找中的比较判断
  • 策略：检查是否可能有相等情况，去重还是保留
  • 考核频次：★★★★☆

模式六：累加/累乘更新

  • 特征：循环内部的 +=、*=、++ 等更新操作
  • 识别：递推式 f[i]=f[i-1]+f[i-2]、累加求和等
  • 策略：明确是"累加"还是"累乘"，注意运算符优先级
  • 考核频次：★★★★★
🧠 六大模式记忆口诀

"初值循环界，下标递归止，比较加更新，六处常挖空。
看到选项别乱选，代入验证才可靠。"

3三类常犯错误归纳

以下三类错误在完善程序题中反复出现，掌握它们的检查方法可以显著提高正确率。

⚠️ 类型一：忘记初始化

典型场景
累加器 sum 忘记赋 0；计数器 cnt 忘记赋 0；求积时忘记赋 1
检查方法
看到变量定义行就检查：这个变量在使用前有初值吗？
真题再现
2022 完全数判断：sum 如果没初始化为 0，结果必错

⚠️ 类型二：边界差 1（Off-by-One）

典型场景
循环 i < n 写成 i <= n，多循环一次或漏循环一次
检查方法
用 n=1 代入验证：程序执行了几次循环？应该执行几次？
真题再现
2021 二分查找：r = n-1 vs r = n 的错误比例高达 40%

⚠️ 类型三：类型混淆 / 运算符号混淆

典型场景
= 和 == 混淆、/ 和 % 混淆、>= 和 > 搞混
检查方法
先判断语义：是"赋值"还是"比较"？是"整除"还是"取模"？
真题再现
2025 贪心排序：比较器写 a - b 还是 b - a 搞反方向
🔥 易错点自检清单（每次做完善程序前默念一遍）

□ 所有变量都初始化了吗？    □ 循环边界包含/不包含正确吗？    □ = 和 == 用对了吗？
□ 数组下标有没有越界？    □ 求最值时比较符号方向对吗？    □ 代入样例验证了吗？

4模拟卷精选改编题

以下题目改编自近年18 套模拟卷中的完善程序题，每道保留了核心考点， 进行了精选和化简，便于在课堂上快速练习。

✏️ 模拟卷改编 · 递归 考：递归终止 + 参数变化 + 返回值
题 1 以下程序用欧几里得算法（辗转相除法）求两个正整数的最大公约数（GCD）。 请选择填入空缺处的正确代码：

int gcd(int a, int b) { if (b ①) return ②; return gcd(b, a ③ b); }
—— ① ——
A == 0
B < 0
C > 0
D != 0
—— ② ——
A a
B b
C 0
D 1
—— ③ ——
A +
B -
C *
D %
✅ 正确答案：① A (== 0) · ② A (a) · ③ D (%)
分析：

空 ①：递归终止条件
  • 欧几里得算法：gcd(a, 0) = a。
  • 当 b == 0 时，a 就是最大公约数。
  • 所以条件为 b == 0。

空 ②：终止时的返回值
  • gcd(a, 0) = a → 返回 a。

空 ③：递归调用参数
  • gcd(a, b) = gcd(b, a % b)
  • 用 % 取模运算。

验证（gcd(12, 8)）：
gcd(12,8) → b=8≠0 → gcd(8, 12%8=4) → b=4≠0 → gcd(4, 8%4=0) → b=0 → return a=4 ✅
✏️ 模拟卷改编 · 计数 考：数组索引 + 计数更新
题 2 以下程序统计字符串中每个小写字母出现的次数。请选择填入空缺处的正确代码：

char s[1000]; cin >> s; int cnt[26] = ①; for (int i = 0; s[i] ②; i++) { int idx = s[i] ③ 'a'; cnt[idx]④; }

A {0}
B {1}
C {26}
D 留空不写
—— ② ——
A >= 'a'
B != '\0'
C <= 'z'

—— ④ ——

✅ 正确答案：① A ({0}) · ② B (!= '\0') · ③ B (-) · ④ B (++)
分析：

空 ①：数组初始化
  • 所有计数从 0 开始。
  • int cnt[26] = {0} 将所有元素初始化为 0。

空 ②：循环结束条件
  • 字符串以 '\0'（空字符）结束。
  • 当 s[i] != '\0' 时继续循环。

空 ③：字符到索引的映射
  • 'a' - 'a' = 0, 'b' - 'a' = 1, ..., 'z' - 'a' = 25。
  • 所以用 s[i] - 'a'。

空 ④：计数更新
  • 每出现一次，对应计数加 1。
  • cnt[idx]++ 或 cnt[idx] += 1。

验证（s="abca"）：
i=0: 'a' → idx=0 → cnt[0]=1
i=1: 'b' → idx=1 → cnt[1]=1
i=2: 'c' → idx=2 → cnt[2]=1
i=3: 'a' → idx=0 → cnt[0]=2 ✅

题 3 以下程序用前缀和快速计算数组 a 的区间和。 输入 n 和 n 个数，然后询问 l 到 r（包含两端）的区间和。请选择填入空缺处的正确代码：

5完整程序综合练习

以下两道题是完全模拟 CSP-J 初赛真题格式的完整完善程序题， 每题包含 5 个空，每个空 3 分，总分 15 分。 请在读完全部代码后，逐个空分析并选出正确选项。

综合练习一：青蛙跳台阶

📝 题目描述

一只青蛙一次可以跳上 1 级台阶，也可以跳上 2 级。求该青蛙跳上 n 级台阶共有多少种跳法。
输入：一个正整数 n（1 ≤ n ≤ 90）
输出：跳上 n 级台阶的跳法总数
示例：n=4 → 输出 5（跳法：1+1+1+1, 1+1+2, 1+2+1, 2+1+1, 2+2）

// 【CSP-J 综合练习一】青蛙跳台阶 // 总跳法数 = f[n]，f[1]=1, f[2]=2 // f[n] = f[n-1] + f[n-2]（n >= 3） #include <iostream> using namespace std; int main() { int n; cin >> n; long long f[100] = {①}; if (n == 1) { cout << ② << endl; return 0; } f[1] = ③; f[2] = ④; for (int i = ⑤; i <= n; i++) { f[i] = f[i-1] + f[i-2]; } cout << f[n] << endl; return 0; }

✅ 正确答案：① A · ② B · ③ B · ④ B · ⑤ C
逐空解析：

空 ①（数组整体初始化）：
  • long long f[100] = {0} 将数组所有元素初始化为 0。
  • 这是 C++ 数组初始化的标准写法，{0} 将第一个元素置 0，其余自动置 0。
  • 如果初始化为 {1}，只有 f[0]=1，其他自动为 0，不影响结果但不符合惯例。
  • ✅ 选 A。

空 ②（n=1 时的特判输出）：
  • 当 n=1 时，还没有计算 f[1]（下面的赋值还没执行），所以不能输出 f[1]。
  • n=1 时只有 1 种跳法（跳 1 级），所以输出 1。
  • ✅ 选 B。

空 ③（f[1] 的初值）：
  • 1 级台阶：只能跳 1 级，1 种跳法。
  • 所以 f[1] = 1。
  • ✅ 选 B。

空 ④（f[2] 的初值）：
  • 2 级台阶：可以 1+1 或 2，共 2 种跳法。
  • 所以 f[2] = 2。
  • ✅ 选 B。

空 ⑤（循环起始下标）：
  • f[1] 和 f[2] 已经赋好初值。
  • 递推从 i = 3 开始：f[3] = f[2] + f[1]。
  • 如果用 i=1 或 i=2，会覆盖已有的正确初值。
  • ✅ 选 C。

验证（n=4）：
  f[1]=1, f[2]=2
  i=3: f[3]=f[2]+f[1]=2+1=3
  i=4: f[4]=f[3]+f[2]=3+2=5 ✅

考点总结：本题考了 DP 边界初值（③④）、初始化方式（①）、特殊情况处理（②）、循环范围（⑤）。
注意 n=1 时的特判是本题的关键易错点。

综合练习二：合并有序数组

📝 题目描述

输入两个升序排列的数组 a（长度 n）和 b（长度 m）， 将它们合并到一个新数组 c 中，使得合并后仍然保持升序。
输入：第一行 n m，第二行 n 个整数（升序），第三行 m 个整数（升序）
输出：合并后的升序数组
示例：n=3, a=[1,3,5], m=4, b=[2,4,6,8] → 输出 1 2 3 4 5 6 8

// 【CSP-J 综合练习二】合并有序数组 // 双指针归并：i 指向 a，j 指向 b，k 指向 c #include <iostream> using namespace std; int a[1005], b[1005], c[2010]; int main() { int n, m; cin >> n >> m; for (int i = 0; i < n; i++) cin >> a[i]; for (int j = 0; j < m; j++) cin >> b[j]; int i = 0, j = 0, k = 0; while (i < n ① j < m) { if (a[i] ② b[j]) { c[k] = a[i]; i③; } else { c[k] = ④; j⑤; } k++; } while (i < n) { c[k++] = a[i++]; } while (j < m) { c[k++] = b[j++]; } for (int t = 0; t < n + m; t++) { cout << c[t] << " "; } return 0; }

逐空解析：

空 ①（主循环条件）：
  • 两个数组都没遍历完时才进行"比较取最小"的操作。
  • 条件应是 i < n && j < m（两个都有效）。
  • 如果用 ||，当其中一个遍历完时仍会进入循环，此时访问另一个数组可能越界！
  • ✅ 选 B（&&）。

空 ②（比较符号）：
  • 要保证合并后仍然是升序，应该取较小的元素放入 c。
  • 当 a[i] <= b[j] 时取 a[i]（用 <= 保证相等的元素先取 a 的，稳定）。
  • 如果用 <，当 a[i]==b[j] 时会走 else 分支取 b[j]，结果还是升序，但习惯用 <=。
  • ✅ 选 D（<=）。

空 ③（a 数组指针移动）：
  • 从 a 中取了元素后，a 的指针向后移动。
  • i++。
  • ✅ 选 B。

空 ④（else 分支放入的元素）：
  • 当 a[i] > b[j] 时，说明 b[j] 更小，应该将 b[j] 放入 c。
  • ✅ 选 B。

空 ⑤（b 数组指针移动）：
  • 从 b 中取了元素后，b 的指针向后移动。
  • j++。
  • ✅ 选 A。

验证（a=[1,3,5], b=[2,4,6,8]）：

易错点：空①用 || 会导致越界访问；空②用 > 会导致顺序颠倒。

📌 完善程序"六步法"速查表

综合七个专题的学习，我们把完善程序的解题流程提炼为"六步法"。 从读题到验证，每一步都对应具体的操作和检查要点。 请在每次做完善程序时按此流程执行。

步骤名称具体操作检查重点
1 读题面 读题目标题、注释、输入输出示例，回答"程序在做什么？" 忽略注释中的算法提示
2 定算法 识别算法类型：二分？DP？递归？排序？搜索？ 误判算法方向
3 通框架 通读代码主体，关注：初始化、循环结构、边界条件、返回值 只盯着单个空看
4 定类型 判断每个空属于六类挖空模式中的哪一类 不判断类型直接猜
5 逐空推 结合三要素（初值·循环·返回）逐一分析，排除错误选项 忽略空与空的关联
6 代入验 用样例输入手动模拟，输出与题目示例对比一致才通过 只用脑想不动笔
🥇 六步法：读题 → 定算法 → 通框架 → 定类型 → 逐空推 → 代入验 ✅ 三要素：初始值 · 循环体 · 返回值 ⚠️ 六挖空：初值 / 循环界 / 递归止 / 比较 / 更新 / 下标 🔥 易错点：忘记初始化 · 边界差1 · 符号混淆 📊 高频算法：DP > 二分 > 递归 > 搜索 💡 代入验证：n=1, n=2 是最佳"试金石"
