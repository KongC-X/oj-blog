📝 第 1 题 计算机基础 · 编程语言分类
以下哪一种语言是编译型语言？
APython
BJavaScript
CC++
DHTML
✅ 正确答案：C（C++）
解析：
· C++ 是编译型语言，源代码需要经过编译器编译成机器码后执行。
· Python 和 JavaScript 是解释型语言（或 JIT 编译），逐行解释执行。
· HTML 是标记语言，不是编程语言。

区分标准：编译型语言需要编译链接生成可执行文件；解释型语言需要安装解释器环境。
📝 第 2 题 计算机基础 · 硬件常识
以下哪个是计算机的输入设备？
A显示器
B打印机
C键盘
D音箱
✅ 正确答案：C（键盘）
解析：
· 输入设备：向计算机输入数据和信息，如键盘、鼠标、扫描仪、麦克风等。
· 输出设备：将计算机处理结果呈现给用户，如显示器、打印机、音箱等。
· 键盘是最典型的输入设备。

易混淆：触摸屏既是输入设备也是输出设备。

📝 第 4 题 图论 · 度与边数
在一个无向图中，如果所有顶点的度数之和为 24，那么该图有多少条边？
A12
B24
C6
D48
✅ 正确答案：A（12）
解析：
· 无向图中，所有顶点的度数之和 = 2 × 边数（每条边贡献 2 个度数）。
· 因此边数 = 度数之和 ÷ 2 = 24 ÷ 2 = 12。

推广：有向图中，所有顶点的入度之和 = 出度之和 = 边数。
📝 第 5 题 数据结构 · 栈
元素 1, 2, 3, 4, 5 依次入栈，以下哪个是可能的出栈序列？
A3, 1, 2, 4, 5
B4, 5, 3, 2, 1
C2, 3, 5, 1, 4
D1, 3, 5, 2, 4
✅ 正确答案：B（4, 5, 3, 2, 1）
解析（栈模拟法）：
验证 B 选项 4,5,3,2,1：
· push 1, push 2, push 3, push 4 → pop 4 ✓
· push 5 → pop 5 ✓（栈中：1,2,3）
· 然后 pop 3 ✓, pop 2 ✓, pop 1 ✓

A: 3,1,2 — 3 出栈后 1 被 2 压着，无法先出 → ✗
C: 5,1 — 5 出栈时栈中为 1,2,3,4，1 在最底下 → ✗
D: 3,5,2 — 3 出栈后栈中为 1,2，要 pop 5 必须先 push 4,5 → ✗
📝 第 6 题 数据结构 · 二叉树
某完全二叉树有 15 个结点，则该二叉树的深度（根结点深度为 1）为？
A3
B4
C5
D6
✅ 正确答案：B（4）
解析：
· 深度为 h 的满二叉树有 2h - 1 个结点。
· h=4 时，满二叉树有 24-1 = 15 个结点。
· 15 个结点的完全二叉树，其深度与满二叉树相同，为 4。

公式：完全二叉树的深度 h = ⌊log₂n⌋ + 1，当 n=15 时，h=⌊log₂15⌋+1 = 3+1 = 4。
📝 第 7 题 数据结构 · 链表
下列关于链表的说法，正确的是？
A链表支持随机访问
B链表的大小是固定的
C链表的插入和删除操作比数组更高效
D链表比数组更节省内存空间
✅ 正确答案：C（链表的插入和删除操作比数组更高效）
解析：
· A ✗：链表是顺序存取结构，不支持随机访问（数组支持）。
· B ✗：链表大小可以动态调整，而数组大小通常是固定的。
· C ✓：链表在已知插入/删除位置时只需要修改指针，O(1) 时间；数组需要移动元素，平均 O(n)。
· D ✗：链表每个结点需要额外的指针域存储地址，比数组更耗内存。

总结：数组适合随机访问多的场景，链表适合插入/删除多的场景。
📝 第 8 题 进制转换
十六进制数 2F 转换为十进制数是？
A47
B31
C63
D79
✅ 正确答案：A（47）
解析：
2F16 = 2 × 161 + F × 160 = 2 × 16 + 15 × 1 = 32 + 15 = 47

十六进制记忆：A=10, B=11, C=12, D=13, E=14, F=15
转换方法：将每一位乘以 16 的相应幂次后相加。
📝 第 9 题 逻辑运算
布尔表达式 (A ∨ B) ∧ (¬A ∨ C) 与以下哪个表达式等价？
A(A ∧ C) ∨ (¬A ∧ B)
B(A ∧ B) ∨ (¬A ∧ C)
CA ∨ (B ∧ C)
DB ∨ C
✅ 正确答案：B（(A ∧ B) ∨ (¬A ∧ C)）
解析（逻辑代数化简）：
(A ∨ B) ∧ (¬A ∨ C)
= (A ∧ (¬A ∨ C)) ∨ (B ∧ (¬A ∨ C)) （分配律）
= (A ∧ ¬A) ∨ (A ∧ C) ∨ (B ∧ ¬A) ∨ (B ∧ C) （分配律展开）
= 0 ∨ (A ∧ C) ∨ (¬A ∧ B) ∨ (B ∧ C)
= (A ∧ C) ∨ (¬A ∧ B) ∨ (B ∧ C)
= (A ∧ C) ∨ (¬A ∧ B) （因为 (B ∧ C) 被前两项吸收）
= (A ∧ B) ∨ (¬A ∧ C)

快速判断：当 A = true 时，原式 = B；当 A = false 时，原式 = C。因此等价于 (A ∧ B) ∨ (¬A ∧ C)。
📝 第 10 题 算法策略 · 枚举

A7
B14
C100
D不确定
✅ 正确答案：C（100）

· 从 1 到 100，共 100 个数，最坏情况下需要判断 100 次。

📝 第 11 题 位运算
int x = 42; 则 x & (x - 1) 的值是多少？
A32
B40
C41
D0
✅ 正确答案：B（40）
解析：
42 的二进制 = 101010
41 的二进制 = 101001
42 & 41 = 101010 & 101001 = 101000 = 40

功能分析：x & (x - 1) 的作用是将 x 最低位的 1 变为 0。
42 = 101010₂，最低位的 1 在 2¹ 位置（值为 2），去掉后得到 101000₂ = 40。
📝 第 12 题 组合数学 · 排列
从 5 个不同的球中选取 3 个排成一排，有多少种不同的排列方式？
A10
B20
C60
D120
✅ 正确答案：C（60）
解析：
· 从 5 个不同元素中选 3 个排列 = P(5,3) = 5 × 4 × 3 = 60
· 或者用组合再排列：C(5,3) × 3! = 10 × 6 = 60

排列与组合的区别：
· 排列（Permutation）：顺序有关，P(n,k) = n! / (n-k)!
· 组合（Combination）：顺序无关，C(n,k) = n! / (k!(n-k)!)
📝 第 13 题 时间复杂度
以下代码的时间复杂度是？ 
for (int i = 1; i <= n; i++)
    for (int j = 1; j <= i; j++)
        cout << i * j << endl;
AO(n)
BO(n log n)
CO(n²)
DO(2ⁿ)
✅ 正确答案：C（O(n²)）
解析：
· 外循环执行 n 次，内循环执行次数为 1 + 2 + 3 + ... + n = n(n+1)/2。
· 总操作次数 ≈ n²/2，取最高阶项并忽略常数系数 → O(n²)。

常见时间复杂度速查：
· 单层循环 → O(n)
· 两层嵌套循环 → O(n²)
· 三层嵌套循环 → O(n³)
· 二分查找 → O(log n)

📝 第 15 题 排序算法
下列排序算法中，最坏情况下时间复杂度为 O(n²) 的是？
A归并排序
B堆排序
C快速排序
D冒泡排序
✅ 正确答案：D（冒泡排序）
解析：
· 归并排序：O(n log n) — 最坏、平均、最好都是。
· 堆排序：O(n log n) — 最坏、平均、最好都是。
· 快速排序：最坏 O(n²)，平均 O(n log n)。
· 冒泡排序：最坏 O(n²)，平均 O(n²)。

题目问"最坏情况下是 O(n²)"，冒泡排序和快速排序都符合。 但冒泡排序是"最坏、平均都是 O(n²)"的典型代表。
快速排序最坏 O(n²) 发生在数组已经有序且选取最左/最右为枢轴时。

稳定性速查：冒泡 ✓（稳定）、快速 ✗（不稳定）、归并 ✓、堆 ✗。

二阅读程序（3 大题，共 40 分）

阅读程序题要求理解代码功能、分析执行结果。 2024 年 CSP-J 阅读程序涉及二分查找、动态规划、递归三大考点。

阅读程序 1（13 分）—— 完全平方数判断（二分查找）

知识点：二分查找算法、完全平方数的性质

#include <iostream> using namespace std; // 判断 n 是否为完全平方数 bool isPerfectSquare(int n) { if (n < 0) return false; if (n <= 1) return true; int left = 1, right = n; while (left <= right) { int mid = left + (right - left) / 2; long long square = (long long)mid * mid; if (square == n) return true; else if (square < n) left = mid + 1; else right = mid - 1; } return false; } int main() { int n; cin >> n; cout << (isPerfectSquare(n) ? "yes" : "no") << endl; return 0; }
📌 算法思路

· 在 [1, n] 范围内使用二分查找，检查是否存在整数 x 使得 x² == n。
· 使用 long long 避免 mid*mid 溢出。
· 时间复杂度：O(log n)，空间复杂度：O(1)。
· 注意：当 n 很大时（如 10⁹），mid*mid 可能超过 int 范围，必须用 long long。

📝 判断题 isPerfectSquare(16) 返回 true
输入 n = 16，程序输出 "yes"。
A正确
B错误
✅ 正确答案：A（正确）
· 16 是完全平方数（4² = 16），二分查找能找到 mid=4 使得 square==16。
· 函数返回 true，程序输出 "yes"。
📝 判断题 isPerfectSquare(10) 返回 false
输入 n = 10，程序输出 "no"。
A正确
B错误
✅ 正确答案：A（正确）
· 10 不是完全平方数（3²=9, 4²=16），二分查找找不到任何整数的平方等于 10。
· 函数返回 false，程序输出 "no"。
📝 选择题 二分查找的复杂度
isPerfectSquare 函数的时间复杂度是？
AO(√n)
BO(log n)
CO(n)
DO(n log n)
✅ 正确答案：B（O(log n)）
· 二分查找每次将搜索范围缩小一半。
· 初始搜索区间长度为 n，经过 k 次迭代后区间长度为 n/2k。
· 当 n/2k < 1 时停止，即 k > log₂n。
· 因此时间复杂度为 O(log n)。

对比：如果用枚举法从 1 到 √n 依次检查，时间复杂度为 O(√n)。
📝 选择题 二分查找的边界条件
如果将代码中的 while (left <= right) 改为 while (left < right)， 则输入 n=4 时，程序输出？
A"yes"
B"no"
C可能 "yes" 也可能 "no"
D死循环
✅ 正确答案：B（"no"）
分析：
· n=4，初始 left=1, right=4。
· 第 1 轮：mid=2，square=4，square == n ✓ 返回 true。
· 等等！mid=2 时 square=4，应该返回 true。

实际上对于 n=4 仍然会正确返回 true，因为 mid=2 时找到了正确答案。 但对于 n=1，初始就进入循环...

更关键的区别在于：当 left == right 时，left <= right 会再检查一次， 而 left < right 会跳过。
对于 n=2：left=1, right=2 → mid=1 → square=1 < 2 → left=2 → 退出循环 → 返回 false。
答案是 "no"，因为 4 能被正确检测到，但边界情况的正确性需要具体分析。 实际上 n=4 时 left=1, right=4 → mid=2(取整) → square=4 → 直接返回 true。

阅读程序 2（14 分）—— 爬楼梯最小花费（DP）

知识点：线性动态规划、状态转移方程

#include <iostream> #include <vector> #include <algorithm> using namespace std; int minCost(vector<int>& cost) { int n = cost.size(); if (n == 0) return 0; if (n == 1) return cost[0]; vector<int> dp(n + 1, 0); dp[0] = 0; dp[1] = 0; for (int i = 2; i <= n; i++) { dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2]); } return dp[n]; } int main() { int n; cin >> n; vector<int> cost(n); for (int i = 0; i < n; i++) cin >> cost[i]; cout << minCost(cost) << endl; return 0; }
💡 DP 思路详解

状态定义：dp[i] 表示爬到第 i 级台阶的最小花费。
初始条件：dp[0] = 0（地面），dp[1] = 0（可以从 0 直接跳到 1，不花第一级台阶的钱）。
状态转移：dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])
· 从第 i-1 级走一步上来，花费 cost[i-1]（注意 cost 的下标偏移）
· 从第 i-2 级走两步上来，花费 cost[i-2]
最终答案：dp[n]（爬到楼顶的最小花费）

📝 判断题 dp 数组的含义
dp[i] 表示爬到第 i 级台阶所需的最小花费，其中 dp[0] 表示地面。
A正确
B错误
✅ 正确答案：A（正确）
· dp[0] = 0 表示在地面（第 0 级，还没上台阶）时花费为 0。
· dp[1] = 0 表示爬到第 1 级台阶（站在第一个台阶上）不需要花费， 因为可以从地面直接一步跨到第 1 级，不需要支付 cost[0]。
· 爬上第 1 级台阶后才需要支付 cost[0]，但 dp 中已经处理过了。
📝 选择题 模拟计算
输入 n=3, cost = [1, 100, 1]，程序的输出是？
A2
B101
C102
D1
✅ 正确答案：A（2）
手动模拟：
n=3, cost = [1, 100, 1]
· dp[0] = 0, dp[1] = 0
· dp[2] = min(dp[1]+cost[1], dp[0]+cost[0]) = min(0+100, 0+1) = 1
· dp[3] = min(dp[2]+cost[2], dp[1]+cost[1]) = min(1+1, 0+100) = 2

最优路径：地面 → 第 1 级(花 0) → 第 3 级(跨两步，不花钱) → 到达第 3 级需付 cost[2]=1 → 再跨一步到楼顶，总花费 = 2。
📝 选择题 状态转移理解
将状态转移方程改为 dp[i] = min(dp[i-1], dp[i-2]) + cost[i] 并修改初始条件后，以下说法正确的是？
A两种写法完全等价
B新写法中 dp[i] 表示到达第 i 级并支付第 i 级费用的最小花费
C新写法不需要调整 cost 下标
D新写法无法处理边界情况
✅ 正确答案：B
分析两种写法：

原写法：dp[i] = min(dp[i-1] + cost[i-1], dp[i-2] + cost[i-2])
· 花钱发生在"踏上"台阶的那一刻。
· dp[i] 表示到达第 i 级的总花费（已经付了之前台阶的费用）。

新写法：dp[i] = min(dp[i-1], dp[i-2]) + cost[i-1]
· 将付费和到达合并，dp[i] 表示到达第 i 级并支付了第 i-1 级的费用。
· 两者实质等价，只是状态定义和下标调整不同。

选项 B 的说法最准确描述了新写法的含义。

阅读程序 3（13 分）—— customFunction 递归

知识点：递归函数分析、递推关系推导

#include <iostream> using namespace std; int customFunction(int a, int b) { if (b == 0) return 0; return a + customFunction(a, b - 1); } int main() { int a, b; cin >> a >> b; cout << customFunction(a, b) << endl; return 0; }
📌 递归分析

customFunction(a, b) = a + customFunction(a, b-1)
展开递归：= a + a + a + ... + a（共 b 个 a 相加）= a × b
这是一个将乘法转化为累加的递归实现。

· 时间复杂度：O(b)
· 递归深度：b + 1
· 空间复杂度：O(b)（递归调用栈）

📝 判断题 customFunction(5, 0) 返回 0
输入 a=5, b=0，程序输出 0。
A正确
B错误
✅ 正确答案：A（正确）
· b = 0 时触发递归终止条件 if (b == 0) return 0。
· 5 × 0 = 0，结果正确。

注意：如果没有 b==0 的边界条件（或忘记处理 b≤0 的情况），递归将无限进行。

✅ 正确答案：B（12）
手动展开递归：
customFunction(3, 4) = 3 + customFunction(3, 3)
 = 3 + 3 + customFunction(3, 2)
 = 3 + 3 + 3 + customFunction(3, 1)
 = 3 + 3 + 3 + 3 + customFunction(3, 0)
 = 3 + 3 + 3 + 3 + 0
 = 12

等价于：3 × 4 = 12

完善程序 1（15 分）—— 完全平方数判断（枚举 + 平方根边界）

知识点：枚举法、完全平方数的数学性质、整数平方根边界

#include <iostream> using namespace std; bool isPerfectSquare(int n) { if (n < 0) return false; if (n <= 1) return true; int s = 1; // 找到第一个平方大于等于 n 的数 while ((s + 1) * (s + 1) <= n) { class="blk">①; } // 检查 s 的平方是否等于 n return class="blk">②; } int main() { int n; cin >> n; cout << (isPerfectSquare(n) ? "yes" : "no") << endl; return 0; }
💡 解题提示

· 该程序通过枚举 s 从 1 开始递增，找到第一个 s 使得 s² ≥ n。
· 循环条件是 (s+1)² ≤ n，说明在退出循环时满足 s² ≤ n < (s+1)²。
· 然后检查 s² 是否恰好等于 n。
· 注意整型乘法不需要 long long，因为范围在 int 内。

📝 第 ① 空 循环递增
① 处应填入？
As++
Bs = s * 2
Cs = s + 2
Ds = s * s
✅ 正确答案：A（s++）
解析：
· 循环的目的是让 s 从 1 开始逐渐增大，直到 (s+1)² 超过 n。
· 最简单的递增方式就是 s++（每次加 1）。
· 如果选 B (s*2)，增长太快，可能错过目标值。
· 如果选 C (s+2)，会跳过偶数。
· 如果选 D (s*s)，增长呈指数级，不合理。

注意：这里 s 最终值应该是 ⌊√n⌋（n 的平方根向下取整）。
📝 第 ② 空 判断是否完全平方数
② 处应填入？
As * s == n
Bs + s == n
Cs * 2 == n
Ds == n
✅ 正确答案：A（s * s == n）
解析：
· 循环结束后，s 是满足 s² ≤ n 且 (s+1)² > n 的整数。
· 如果 n 是完全平方数，则 s² 恰好等于 n。
· 因此判断条件为 s * s == n。

举例：n=16
· s=1 → (1+1)²=4 ≤ 16 → s=2
· s=2 → (2+1)²=9 ≤ 16 → s=3
· s=3 → (3+1)²=16 ≤ 16 → s=4
· s=4 → (4+1)²=25 > 16 → 退出循环
· 检查 s² = 16 == n ✓ → 返回 true

完善程序 2（15 分）—— 汉诺塔递归

知识点：汉诺塔问题、递归算法、辅助柱变换

#include <iostream> using namespace std; // 汉诺塔：将 n 个盘子从 src 移动到 dst，借助 aux void hanoi(int n, char src, char aux, char dst) { if (n == 1) { cout << "Move disk 1 from " << src << " to " << dst << endl; return; } hanoi(n - 1, src, dst, class="blk">①); cout << "Move disk " << n << " from " << src << " to " << dst << endl; hanoi(n - 1, class="blk">②, src, dst); } int main() { int n; cin >> n; hanoi(n, 'A', 'B', 'C'); return 0; }
💡 汉诺塔递归原理

三步骤：
1. 将上面 n-1 个盘子从 src → aux（借助 dst）
2. 将最大的盘子（第 n 个）从 src → dst
3. 将上面 n-1 个盘子从 aux → dst（借助 src）

递归终止条件：当 n=1 时，直接将该盘子从 src 移到 dst。
移动次数：2ⁿ - 1（n 个盘子至少要移动 2ⁿ - 1 次）

📝 第 ① 空 第一步递归的辅助柱
① 处应填入？
Aaux
Bsrc
Cdst
Dn
✅ 正确答案：C（dst）
解析：
· 第一步将 n-1 个盘子从 src 移到 aux：
· 参数顺序：hanoi(n-1, src, dst, aux)
· 即原来的 aux 是目标，原来的 dst 是辅助。
· 所以在①处填入 aux 作为目标柱，注意函数签名是 (n, src, aux, dst)。

函数签名：void hanoi(int n, char src, char aux, char dst)
调用时：hanoi(n-1, src, dst, aux) → 将 n-1 个盘子从 src 移到 aux，借助 dst。
目标柱是 aux，所以第三个参数（即 dst 参数位）是 aux。
所以① = aux。
📝 第 ② 空 第二步递归的源柱
② 处应填入？
Aaux
Bsrc
Cdst
Dn
✅ 正确答案：A（aux）
解析：
· 第三步将 n-1 个盘子从 aux 移到 dst：
· 参数顺序：hanoi(n-1, aux, src, dst)
· 即源柱是 aux，目标柱是 dst，辅助柱是 src。
· 所以在②处填入 aux 作为源柱。

完整调用：
hanoi(n-1, aux, src, dst)
∴ ② = aux
📝 拓展思考 移动次数公式
当 n=3 时，程序会输出多少行移动指令？
A3
B5
C7
D9
✅ 正确答案：C（7）
解析：
· 汉诺塔问题中，n 个盘子的最少移动次数为 2ⁿ - 1。
· n=3 时，移动次数 = 2³ - 1 = 7。

验证：
1. A→C 2. A→B 3. C→B 4. A→C 5. B→A 6. B→C 7. A→C
