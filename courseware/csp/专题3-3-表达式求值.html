1三种表达式

1.1 中缀表达式

中缀表达式（Infix Notation）是我们日常书写的数学表达式形式：运算符在两个操作数中间。例如 a + b * c、(a + b) * c。中缀表达式需要借助括号和优先级规则来确定运算顺序，计算机直接处理比较麻烦。

📌 中缀表达式的特点

· 运算符在操作数中间，如 a + b
· 依赖运算符优先级（×/ 高于 +-）
· 依赖括号改变运算顺序
· 人易读，机难处理

1.2 前缀表达式（波兰式）

前缀表达式（Prefix Notation），也称波兰式（Polish Notation），由波兰数学家 Jan Łukasiewicz 提出。运算符在操作数之前，例如 + a * b c 对应中缀 a + b * c。

📌 前缀表达式示例

· 中缀 a + b → 前缀 + a b
· 中缀 a + b * c → 前缀 + a * b c
· 中缀 (a + b) * c → 前缀 * + a b c
· 中缀 a * (b + c) * d → 前缀 * * a + b c d

1.3 后缀表达式（逆波兰式）

后缀表达式（Postfix Notation），也称逆波兰式（Reverse Polish Notation, RPN）。运算符在操作数之后，例如 a b c * + 对应中缀 a + b * c。后缀表达式无需括号即可唯一确定运算顺序，是计算机进行表达式求值的最常用形式。

📌 后缀表达式示例

· 中缀 a + b → 后缀 a b +
· 中缀 a + b * c → 后缀 a b c * +
· 中缀 (a + b) * c → 后缀 a b + c *
· 中缀 a * (b + c) * d → 后缀 a b c + * d *

表达式类型运算符位置需要括号？计算机处理难度
中缀操作数中间是较难（需处理优先级和括号）
前缀（波兰式）操作数之前否容易（从右向左扫描）
后缀（逆波兰式）操作数之后否最容易（用栈，从左到右）

📝 配套练习

✏️ 模拟题三种表达式识别
下列哪个是中缀表达式 (a + b) - c * d 对应的后缀表达式？
A- + a b * c d
Ba b + c d * -
Ca b c d * - +
Da b + c d - *
✅ 正确答案：B
运算顺序：先算 a+b（得结果1），再算 c*d（得结果2），最后用结果1 减去 结果2。后缀表达：a b + c d * -。A 是前缀表达式。D 的运算顺序不对。
✏️ 模拟题前缀表达式匹配
前缀表达式 * + a b - c d 对应的中缀表达式是？
Aa + b * c - d
B(a + b) * (c - d)
Ca + b * (c - d)
D(a + b) * c - d
✅ 正确答案：B
前缀表达式从右向左扫描：* 是整个表达式的最后一步运算——将 + a b 的结果 与 - c d 的结果相乘。所以中缀为 (a + b) * (c - d)。

2中缀 → 后缀转换

将中缀表达式转换为后缀表达式（逆波兰式）是考试核心。这里介绍两种方法：括号法（直观好理解）和栈法（计算机实现方式）。

2.1 括号法（手动转换首选）

📐 括号法三步走

① 加括号：按照运算符优先级和结合性，给每一步运算加上括号
② 移运算符：把每个运算符移到对应右括号的后面
③ 去括号：删除所有括号，得到后缀表达式

🎯 举例：a * (b + c) * d → 后缀

第1步：确定运算顺序。乘法和加法，先算括号内 b+c，再从左到右计算乘法。
 ((a * (b + c)) * d)
第2步：把运算符移到对应右括号后面。
 ((a (b c) + *) d *)
第3步：去括号 → a b c + * d *

2.2 栈法（算法核心）

📐 中缀转后缀——栈算法规则

从左到右扫描中缀表达式的每个字符：
① 操作数 → 直接输出
② 左括号 ( → 压入栈
③ 右括号 ) → 不断弹出栈顶运算符并输出，直到遇到左括号（左括号弹出但不输出）
④ 运算符 → 当栈顶运算符优先级 大于等于 当前运算符时，弹出并输出；然后将当前运算符压栈
⑤ 扫描完毕后，将栈中所有运算符依次弹出并输出

🎯 举例：a + b * c 的栈转换过程
1扫描 a → 输出，栈空
2扫描 + → 栈空，直接入栈 | 栈：[+]
3扫描 b → 输出 | 输出：a b
4扫描 * → 栈顶 + 优先级低于 *，* 直接入栈 | 栈：[+, *]
5扫描 c → 输出 | 输出：a b c
6结束 → 依次弹出栈中运算符 | 输出：a b c * +
🎯 举例：(a + b) * c 的栈转换过程
1扫描 ( → 入栈 | 栈：[(]
2扫描 a → 输出 | 输出：a
3扫描 + → 入栈（栈顶是左括号，直接入） | 栈：[(, +]
4扫描 b → 输出 | 输出：a b
5扫描 ) → 弹出 + 并输出，弹出 ( 丢弃 | 栈空，输出：a b +
6扫描 * → 栈空，直接入栈 | 栈：[*]
7扫描 c → 输出 | 输出：a b + c
8结束 → 弹出 * | 输出：a b + c *
💡 优先级速记：乘除（*/） > 加减（+-）。同一优先级时，左结合意味着栈顶优先级 大于等于 当前时弹出。

📝 配套练习

📝 真题 · 模拟卷 · 第 4 题中缀转后缀
中缀表达式 a * (b + c) * d 的后缀表达式是？
Aa b c + * d *
Ba b c * + d *
Ca b c + d * *
Da * b c + d
✅ 正确答案：A
用括号法：a * (b + c) * d → 第1步确定运算顺序：乘法和加法，乘法和乘法从左到右结合。
完整加括号：((a * (b + c)) * d) → 移运算符：((a (b c) +) * d) * → 去括号：a b c + * d *。
✏️ 模拟题中缀转后缀——含多个运算符
中缀表达式 a + b - c * d / e 的后缀表达式是？
Aa b + c d * e / -
Ba b + c d * e / -
Ca b c d * e / - +
Da b + c d * / e -
✅ 正确答案：A
注意 + 和 - 优先级相同，从左到右计算；* 和 / 优先级高于 +-。运算顺序：((a + b) - ((c * d) / e))。后缀：a b + c d * e / -。用栈法验证：a输出→+入栈→b输出→-（+弹出输出，-入栈）→c输出→*入栈→d输出→/（*弹出输出，/入栈）→e输出→弹出剩余运算符 → a b + c d * e / -。

3后缀表达式求值

后缀表达式求值是栈的经典应用，过程非常简洁——遇到操作数就入栈，遇到运算符就弹出两个操作数运算后把结果再入栈。

📐 后缀表达式求值规则

从左到右扫描后缀表达式的每个 token：
① 操作数 → 压入栈
② 运算符（如 +, -, *, /）→ 从栈中弹出两个操作数（先弹出 b，后弹出 a），计算 a op b，将结果压入栈
③ 扫描结束后，栈中唯一的元素即为计算结果

🎯 示例：5 3 + 2 * 求值过程
1扫描 5 → 入栈 | 栈：[5]
2扫描 3 → 入栈 | 栈：[5, 3]
3扫描 + → 弹出 3, 5 → 计算 5 + 3 = 8 → 入栈 | 栈：[8]
4扫描 2 → 入栈 | 栈：[8, 2]
5扫描 * → 弹出 2, 8 → 计算 8 × 2 = 16 → 入栈 | 栈：[16]
6结束 → 结果 = 16
⚠️ 注意运算顺序

弹出两个操作数时：先弹出的是右操作数（b），后弹出的是左操作数（a）。所以 a - b 在计算时要小心——用后弹出的减先弹出的。例如后缀 5 3 - → 弹出 3（右），再弹出 5（左）→ 计算 5 - 3 = 2，而不是 3 - 5。

4表达式树

表达式树（Expression Tree）是一种二叉树，其中叶子结点是操作数（如 a, b, 5, 3），非叶子结点是运算符（如 +, -, *, /）。

📌 表达式树的性质

· 对表达式树进行中序遍历 → 得到中缀表达式（需加括号）
· 对表达式树进行前序遍历 → 得到前缀表达式（波兰式）
· 对表达式树进行后序遍历 → 得到后缀表达式（逆波兰式）
· 表达式树的创建可以用栈实现：遇到操作数建叶子结点入栈，遇到运算符弹出两个结点作为左右子树

🎯 示例：表达式 (a + b) * c 的表达式树

      *
     / \
    +   c
   / \
  a   b
· 前序遍历（根左右）：* + a b c（前缀表达式）
· 中序遍历（左根右）：a + b * c（中缀表达式，需加括号才是 (a+b)*c）
· 后序遍历（左右根）：a b + c *（后缀表达式）

📝 配套练习

✏️ 模拟题表达式树与遍历
一棵表达式树的根结点是 "-"，左子树根结点是 "+"，左子树叶子为 a, b，右子树叶子为 c。这棵树对应的后缀表达式是？
A- + a b c
Ba b + c -
Ca b c - +
D+ a b - c
✅ 正确答案：B
树的结构：
    -
   / \
  +   c
 / \
a   b
后序遍历（左右根）：遍历左子树 → a b +，遍历右子树 → c，最后访问根 → -。合并：a b + c -。对应中缀为 (a + b) - c。
✏️ 模拟题根据后缀还原表达式树
已知后缀表达式为 a b c * + d -，其表达式树的根结点是？
A+
B-
C*
Da
✅ 正确答案：B
后缀表达式的最后一个运算符是表达式的最后一步运算，也就是根结点。
后缀 a b c * + d - 中，最后一个运算符是 -，所以根结点为 -。
还原过程：a b c * + 先算出 a + b * c，再减去 d，即 (a + b * c) - d。
树结构： 
      -
     / \
    +   d
   / \
  a   *
     / \
    b   c

📝综合模拟

📝 真题 · 模块训练表达式求值综合
已知中缀表达式为 (a + b) * c - d / e，则其后缀表达式是？
Aa b + c * d e / -
Ba b c * + d e / -
Ca b + c * d / e -
D- * + a b c / d e
✅ 正确答案：A
括号法：((a + b) * c) - (d / e)
移运算符：((a b) + c) * (d e) / -
去括号：a b + c * d e / -。
栈法验证：
(入栈→a输出→+入栈→b输出→)弹出+→*入栈→c输出→-（*弹出，-入栈）→d输出→/入栈→e输出→弹出剩余 → a b + c * d e / -。
✏️ 综合模拟表达式树→三种表达式
已知表达式树的后序遍历为 3 5 + 2 * 4 /，该表达式的结果是？
A4
B6
C16
D5
✅ 正确答案：A
后缀表达式本身就是后序遍历结果，直接模拟求值：
3入→栈[3]，5入→栈[3,5]
+→弹出5,3 → 3+5=8入栈→栈[8]
2入→栈[8,2]
*→弹出2,8 → 8×2=16入栈→栈[16]
4入→栈[16,4]
/→弹出4,16 → 16÷4=4入栈
结果 = 4。此表达式中缀形式为 (3 + 5) × 2 ÷ 4。

📌 表达式求值重点速查表

中缀：运算符在操作数中间 前缀（波兰式）：运算符在操作数之前 后缀（逆波兰式）：运算符在操作数之后
中缀→后缀：括号法三步 中缀→后缀：栈法（优先级判断） 后缀求值：操作数入栈，遇运算符弹两个
后缀最后一个运算符 = 树根 前序遍历→前缀，中序遍历→中缀，后序遍历→后缀 逆波兰式无需括号唯一确定顺序
