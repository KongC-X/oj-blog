1DP 三要素：状态 · 转移 · 边界

动态规划（Dynamic Programming，DP）是一种通过把原问题分解为相对简单的子问题， 并记录子问题的解来避免重复计算的方法。所有的 DP 问题都包含以下三个核心要素：

DP 三大核心要素

1. 状态定义（State）
  • 用一个或多个参数描述一个子问题
  • 例如：dp[i] 表示到达第 i 级台阶的最小花费

2. 状态转移方程（Transition）
  • 描述子问题之间的递推关系
  • 例如：dp[i] = cost[i-1] + min(dp[i-1], dp[i-2])

3. 边界条件（Base Case）
  • 最小的子问题，无需递推就能直接得到答案
  • 例如：dp[0] = 0（在地面上不需要花费）
  • 又如：dp[1] = 0（可以直接从地面跨到第 1 级）

🧠 初赛核心提示

CSP-J 初赛对 DP 的考查集中于阅读程序和完善程序题型。 你不需要自己写出完整的 DP 代码，但必须能理解 DP 代码的逻辑、 手动模拟 DP 数组的填表过程、以及补全缺失的转移方程。

📌 所有 DP 问题都可以用"三步法"解决：
Step 1：定义 dp[i] 的含义（状态）
Step 2：找出 dp[i] 与之前的 dp[j] 的关系（转移）
Step 3：确定最小的边界值（边界）

2爬楼梯最小花费（2024 阅读 2）

2024 年 CSP-J 阅读程序第 2 题考查了"爬楼梯最小花费"问题。 这是 CSP-J 初赛首次引入 DP 类阅读题，难度适中，关键在于理解 DP 数组的递推过程。

问题描述

有一个 n 级楼梯，每一级楼梯有一个"过路费" cost[i]。 你可以从第 i 级一次跨 1 级或 2 级到达第 i+1 或 i+2 级， 但不需要支付当前所在级的费用，只需要支付你要跨到的那一级的费用（如果是跨到第 j 级则支付 cost[j-1]）。 你可以从地面（第 0 级）或第 1 级开始。求到达第 n 级（楼顶）的最小花费。

2024 阅读 2 核心代码
// cost[i] 表示从第 i 级楼梯出发需要支付的费用（0-indexed） // dp[i] 表示到达第 i 级时已经花费的最小费用 int minCostClimbingStairs(vector<int>& cost) { int n = cost.size(); vector<int> dp(n + 1); dp[0] = 0; // 边界：在地面不需要费用 dp[1] = 0; // 边界：可以直接站在第 1 级上 for (int i = 2; i <= n; i++) { dp[i] = cost[i-1] + min(dp[i-1], dp[i-2]); // 要到达第 i 级，必须先到 i-1 或 i-2， // 然后支付 cost[i-1]（跨到第 i 级的费用） } return dp[n]; }

关键理解：
  • dp[i]：到达第 i 级（i 从 0 开始）时已花费的最小费用
  • 注意 cost[i] 的索引：是 cost[i-1] 而不是 cost[i]！因为跨到第 i 级要支付 cost[i-1]
  • dp[0] = dp[1] = 0：开始时不花钱
  • 最终答案是 dp[n]，即到达楼顶的最小花费

假设 cost = [10, 15, 20]，n = 3。逐步模拟 dp 数组的填充过程：

3斐波那契类 DP（一维 DP 模板）

斐波那契数列是最简单的 DP 模型之一，也是理解「状态转移」的最佳入门例子。 虽然直接用递归也能计算，但递归会重复计算大量子问题，而 DP 通过数组记录结果来避免重复。

斐波那契数列的 DP 解法
// 状态定义：dp[i] 表示第 i 个斐波那契数 // 转移方程：dp[i] = dp[i-1] + dp[i-2] // 边界条件：dp[0] = 0, dp[1] = 1 int fib(int n) { if (n <= 1) return n; vector<int> dp(n + 1); dp[0] = 0; dp[1] = 1; for (int i = 2; i <= n; i++) dp[i] = dp[i-1] + dp[i-2]; return dp[n]; }
n012345678
fib(n)01123581321
🧠 一维 DP 的常见变体

爬楼梯问题就是斐波那契 DP 的直接应用——dp[i] = dp[i-1] + dp[i-2]（只不过这里加上了 cost 费用）。 其他一维 DP 变体包括：
  • 最大子数组和：dp[i] = max(arr[i], dp[i-1] + arr[i])
  • 打家劫舍：dp[i] = max(dp[i-1], dp[i-2] + nums[i])
  • 求最小步数：dp[i] = min(dp[i-1], dp[i-2]) + 1

📌 初赛常考：在阅读程序中识别一维 DP 的模式——一个 for 循环加一个递推赋值语句， 通常就是 DP。重点关注 dp[i] 的赋值表达式和循环的起始/终止范围。

4编辑距离（2022/2023 完善程序原题）

编辑距离（Edit Distance）是 CSP-J 初赛中最经典的 DP 考题之一。 2022 年和 2023 年连续两年的完善程序都考查了编辑距离 DP 问题 ——这说明编辑距离是必考内容！两个题目完全相同，可见出题人认为这道题非常经典。

问题描述

给定两个字符串 A 和 B，允许进行三种操作：
  • 插入：在某个位置插入一个字符
  • 删除：删除某个位置的一个字符
  • 替换：将某个字符替换为另一个字符
求将字符串 A 转换成 B 所需的最少操作次数。

编辑距离 DP 核心代码（2022/2023 完善程序）
// dp[i][j] 表示将 A[0..i-1] 转换成 B[0..j-1] 的最小编辑距离 int editDistance(string A, string B) { int n = A.length(), m = B.length(); vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0)); // 边界条件 for (int i = 0; i <= n; i++) dp[i][0] = i; // A 的前 i 个字符全部删除 for (int j = 0; j <= m; j++) dp[0][j] = j; // 空串到 B 的前 j 个字符全部插入 for (int i = 1; i <= n; i++) { for (int j = 1; j <= m; j++) { if (A[i-1] == B[j-1]) dp[i][j] = dp[i-1][j-1]; // 字符相同，无需操作 else dp[i][j] = 1 + min({dp[i-1][j], // 删除 A[i-1] dp[i][j-1], // 在 A 中插入 B[j-1] dp[i-1][j-1]}); // 替换 A[i-1] 为 B[j-1] } } return dp[n][m]; }

状态转移图解

在计算 dp[i][j] 时，有三种可能的来源：

操作来源操作代价说明
删除dp[i-1][j]+1删除 A 的第 i 个字符
插入dp[i][j-1]+1在 A 中插入 B 的第 j 个字符
替换 / 相同dp[i-1][j-1]+0/1替换时 +1，字符相同时 +0

5初学者如何识别 DP 题

在 CSP-J 初赛中，碰到一个题目时，如何判断它是否应该用 DP 解决？关键看两个特征：

识别 DP 的两大特征

1. 重叠子问题（Overlapping Subproblems）
  • 原问题可以分解为若干子问题，且不同的子问题之间有重叠
  • 例：计算斐波那契 f(5) 需要 f(4) 和 f(3)，而 f(4) 又需要 f(3) 和 f(2)——f(3) 被多次使用
  • 如果用递归直接求解，会重复计算大量相同子问题，导致效率极低

2. 最优子结构（Optimal Substructure）
  • 原问题的最优解包含子问题的最优解
  • 例：到达第 i 级的最小花费，由到达第 i-1 和 i-2 级的最小花费决定
  • 即：子问题独立且整体最优依赖于局部最优

常见 DP 题型的"信号词"

信号词可能的 DP 类型示例
"最小/最大花费"、"最少步数"一维 DP（求最值）爬楼梯最小花费
"有多少种方式"、"方案数"一维 DP（计数）走楼梯方案数
"编辑距离"、"转换代价"二维 DP（字符串）编辑距离
"最长公共子序列/子串"二维 DP（字符串）LCS
"最大子数组和"一维 DPKadane 算法
"背包"、"选与不选"0-1 背包 DP0/1 背包问题
🧠 初赛中识别 DP 的实战技巧

在阅读程序题中，看到以下代码模式 ⇢ 立即想到 DP：

  • 一个 dp 数组（一维或二维）
  • 有边界初始化（dp[0] = 0 或 dp[i][0] = i 等）
  • 一个嵌套循环，内有 dp[i] = min/max(...dp[i-1]..., ...dp[i-2]...) 形式的赋值
  • 返回值是 dp[n] 或 dp[n][m]

看到这些特征 ⇢ 这就是 DP 问题！

📝 真题 · 2022 · 完善程序 2 编辑距离 DP（与 2023 相同）
编辑距离 DP 代码中，横线处应填入（ ）。

for (int i = 1; i <= n; i++) { for (int j = 1; j <= m; j++) { if (A[i-1] == B[j-1]) dp[i][j] = dp[i-1][j-1]; else dp[i][j] = 1 + min(______); } }

分析：

编辑距离的三个操作对应三个来源：

操作来源含义
删除dp[i-1][j]删除 A 的第 i 个字符，再看 A[0..i-2]→B[0..j-1]
插入dp[i][j-1]在 A 中插入 B 的第 j 个字符，匹配掉 B[j-1]
替换dp[i-1][j-1]将 A[i-1] 替换为 B[j-1]（或相同则不替换）

记忆方法：
  • 删除比 A 少一个字符 → i-1, j
  • 插入比 B 多一个字符 → i, j-1
  • 替换两者都少一个 → i-1, j-1

验证选项：
A. dp[i-1][j] (删), dp[i][j-1] (插), dp[i-1][j-1] (替) ✅
B. ❌ 包含了 dp[i][j]（自身，无限循环）
C. ❌ 包含 dp[i][j]（自身）
D. ❌ 三个中有两个位置不对

结论：选 A。 这也是 2022 和 2023 年 CSP-J 完善程序的正确答案。

"AB"21?

✅ 正确答案：C · ? 处依次是 2 和 1
手动模拟填表过程：

目标：将 "ABC" 转换为 "AC"。A="ABC"(n=3), B="AC"(m=2)

已填好的边界：
第一行: dp[0][0]=0, dp[0][1]=1, dp[0][2]=2（空串→B）
第一列: dp[1][0]=1, dp[2][0]=2, dp[3][0]=3（A→空串）

计算 dp[2][2]（"AB"→"AC"）：
A[1]="B", B[1]="C" → 不相等
dp[2][2] = 1 + min(dp[1][2]=1, dp[2][1]=1, dp[1][1]=0)
  = 1 + min(1, 1, 0) = 1 + 0 = 1
但注意！dp[1][2] 还没算出来——实际上我们需要先计算 dp[1][2]。

先算 dp[1][2]（"A"→"AC"）：
A[0]="A", B[1]="C" → 不相等
dp[1][2] = 1 + min(dp[0][2]=2, dp[1][1]=0, dp[0][1]=1)
  = 1 + min(2, 0, 1) = 1 + 0 = 1

再算 dp[2][2]（"AB"→"AC"）：
A[1]="B", B[1]="C" → 不相等
dp[2][2] = 1 + min(dp[1][2]=1, dp[2][1]=1, dp[1][1]=0)
  = 1 + min(1, 1, 0) = 1 + 0 = 1 ❌ 等等，这里只是替换 B→C 就行了，还需要插入A吗？

仔细重新算："AB"→"AC"，实际上只需要把 B 替换为 C：1 次操作。
但注意上面的计算中 dp[1][1]=0，表示 "A"→"A" 已经匹配好了。
所以 dp[2][2] = 1 + min(1, 1, 0) = 1 + 0 = 1。（但是最好完全重新计算确保正确）

实际上我们换个方法验证：
 "AB" → "AC"，可以将 B 替换为 C → 1 次操作 ✅
所以 dp[2][2] = 1。

再计算 dp[3][2]（"ABC"→"AC"）：
A[2]="C", B[1]="C" → 相等！
dp[3][2] = dp[2][1] = 1
解释："ABC"中有"AB"→"A"需要 1 次（删除 B），再加上 C 和 C 相同，无需额外操作。
所以 "ABC"→"AC" 也只需要 1 次操作（删除 B）✅

"""A""AC"
""012
"A"101
"AB"211
"ABC"321

结论：两个 ? 处依次是 1 和 1，选 C... 等等，选项 C 是"2 和 1"，选项 A 是"1 和 1"。

仔细重新检查 dp[3][2]：
A[2]="C", B[1]="C" → 相等 → dp[3][2] = dp[2][1] = 1
dp[2][1] 表示 "AB"→"A"，即把 B 删除，1 次操作 ✅

那么第一个 ? = 1, 第二个 ? = 1，应选 A。

但等一下——事实上 dp[2][2] 的计算：
重新计算 dp[2][2]：A[1]="B" vs B[1]="C" → 不相等
dp[2][2] = 1 + min(dp[1][2]=1, dp[2][1]=1, dp[1][1]=0) = 1 + 0 = 1
所以 ? 处都是 1，选 A。

结论：两个未知格子的值分别是 1 和 1，选 A。

✏️ 模拟题 · 一维 DP 最大子数组和（Kadane 算法）
以下程序求最大子数组和。若输入数组为 [-2, 1, -3, 4, -1, 2, 1, -5, 4]， 程序输出是（ ）。

int maxSubArray(vector<int>& nums) { vector<int> dp(nums.size()); dp[0] = nums[0]; int ans = dp[0]; for (int i = 1; i < nums.size(); i++) { dp[i] = max(nums[i], dp[i-1] + nums[i]); ans = max(ans, dp[i]); } return ans; }
A 4
B 5
C 6
D 7
✅ 正确答案：C · 6
手动模拟 Kadane 算法：

dp[i] = 以 nums[i] 结尾的最大子数组和。
转移：要么从 dp[i-1] 延续过来（扩展子数组），要么重新从 nums[i] 开始。

i012345678
nums[i]-21-34-121-54
dp[i]-21-2435615
ans-211445666

计算过程详解：
dp[0] = -2, ans = -2
dp[1] = max(1, -2+1= -1) = 1, ans = max(-2, 1) = 1
dp[2] = max(-3, 1+(-3)= -2) = -2, ans = max(1, -2) = 1
dp[3] = max(4, -2+4=2) = 4, ans = max(1, 4) = 4
dp[4] = max(-1, 4+(-1)=3) = 3, ans = max(4, 3) = 4
dp[5] = max(2, 3+2=5) = 5, ans = max(4, 5) = 5
dp[6] = max(1, 5+1=6) = 6, ans = max(5, 6) = 6
dp[7] = max(-5, 6+(-5)=1) = 1, ans = max(6, 1) = 6
dp[8] = max(4, 1+4=5) = 5, ans = max(6, 5) = 6

最优子数组：[4, -1, 2, 1] 和为 6 ✅

结论：最大子数组和是 6，选 C。
本题是 Kadane 算法的经典应用，也是 CSP-J 初赛中一维 DP 的典型代表。
✏️ 模拟题 · 一维 DP 打家劫舍（一维 DP）
有一个小区，每家的金额为 [2, 7, 9, 3, 1, 4]。 小偷不能偷相邻的两家。用 DP 求能偷到的最大金额。以下 dp 数组中 dp[5]（即偷完最后一家后的最大金额）是（ ）。
提示：dp[i] = max(dp[i-1], dp[i-2] + nums[i])，dp[0]=nums[0], dp[1]=max(nums[0], nums[1])
A 14
B 15
C 16
D 17
✅ 正确答案：B · 15
手动模拟填表过程：

nums = [2, 7, 9, 3, 1, 4]

状态定义：dp[i] = 偷到第 i 家时的最大金额（从 0 到 i 中选不偷相邻）
转移：要么不偷这家（dp[i] = dp[i-1]），要么偷这家+隔一家的（dp[i] = dp[i-2] + nums[i]）
边界：dp[0] = nums[0] = 2, dp[1] = max(2, 7) = 7

i012345
nums[i]279314
dp[i]2711111215

逐步计算：
dp[0] = nums[0] = 2
dp[1] = max(2, 7) = 7
dp[2] = max(dp[1]=7, dp[0]+nums[2]=2+9=11) = 11（偷 0 和 2 号）
dp[3] = max(dp[2]=11, dp[1]+nums[3]=7+3=10) = 11
dp[4] = max(dp[3]=11, dp[2]+nums[4]=11+1=12) = 12（偷 0, 2, 4 号）
dp[5] = max(dp[4]=12, dp[3]+nums[5]=11+4=15) = 15（偷 0, 2, 5 号：2+9+4=15）

最优方案：偷第 0、2、5 家，金额 = 2 + 9 + 4 = 15 ✅

✏️ 综合模拟 · 概念题 识别 DP 问题的特征
以下问题中，最适合用动态规划解决的是（ ）。
A 在一个无序数组中查找最大值
B 计算第 n 个斐波那契数
C 对一个数组进行升序排序
D 在二叉搜索树中查找一个元素
✅ 正确答案：B · 计算第 n 个斐波那契数
逐一分析各选项：

A. 在一个无序数组中查找最大值
❌ 暴力遍历 O(n) 即可解决，不需要 DP。且没有重叠子问题特征。

B. 计算第 n 个斐波那契数
✅ 最适合用 DP。斐波那契数列具有重叠子问题（递归会重复计算同一个 f(k) 多次）和 最优子结构（f(n) 由 f(n-1) 和 f(n-2) 组成）。用 DP 可以 O(n) 时间解决， 而朴素递归是 O(2ⁿ) 指数级时间复杂度。

C. 对一个数组进行升序排序
❌ 排序有专门的算法（快排、归并等），不涉及"多阶段决策"或"子问题重叠"，不适合 DP。

D. 在二叉搜索树中查找一个元素
❌ 二叉搜索树查找用二分思想即可 O(log n) 解决，不需要 DP。

识别 DP 的两大特征回顾：
  • 重叠子问题：同一个子问题会被多次使用
  • 最优子结构：原问题的最优解包含子问题的最优解

结论：选 B。斐波那契数列是 DP 最优的入门例子。
✏️ 综合模拟 · 概念辨析 DP 概念综合判断
以下关于动态规划的描述中，错误的是（ ）。
A DP 通过记录子问题的解来避免重复计算
B 所有 DP 问题都可以用递归方式求解，但效率可能很低
C DP 三要素包括：状态定义、状态转移方程、边界条件
D 任何求最值的问题都适合用 DP 解决
✅ 正确答案：D · 任何求最值的问题都适合用 DP 解决
逐一分析：

A. DP 通过记录子问题的解来避免重复计算
✅ 正确。DP 的核心思想就是用空间换时间——用一个数组（dp 表）记录已计算过的子问题结果， 避免重复计算。这是 DP 能提升效率的关键。

B. 所有 DP 问题都可以用递归方式求解，但效率可能很低
✅ 正确。所有 DP 问题理论上都可以用递归（如记忆化搜索）解决。 但单纯的不加记忆化的递归会重复计算大量子问题，时间复杂度可能是指数级的。 DP 的"递推"方式（自底向上）避免了递归的开销。

C. DP 三要素包括：状态定义、状态转移方程、边界条件
✅ 正确。这是解决 DP 问题的标准三步法。

D. 任何求最值的问题都适合用 DP 解决
❌ 错误。DP 的应用需要满足最优子结构和重叠子问题两个条件。 并非所有求最值的问题都满足这两个条件。例如：
  • 在无序数组中找最大值 → 直接遍历即可，不需要 DP
  • 求最短路径 → 适合 DP（如 Floyd）
  • 求哈密顿路径 → 不是 DP 能解决的（NP 问题）

结论：D 是错误描述。DP 不是万能的，只能解决具有"最优子结构"和"重叠子问题"特征的问题。
