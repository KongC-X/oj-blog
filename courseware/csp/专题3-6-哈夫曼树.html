1哈夫曼树定义

1.1 什么是最优二叉树？

哈夫曼树（Huffman Tree）又称最优二叉树。给定 n 个带权叶子结点，构造一棵二叉树使得带权路径长度（WPL）最小，这样的二叉树就是哈夫曼树。

📌 名词解释

· 权值（Weight）：叶子结点附带的数值，通常表示频率或代价
· 路径长度：从根结点到该叶子经过的边数（也有按结点数计算的，CSP-J通常按边数）
· 带权路径长度（WPL）：所有叶子结点的权值 × 路径长度之和

1.2 哈夫曼树的核心特性

哈夫曼树是严格二叉树（也称正则二叉树、满树），即每个非叶子结点恰好有两个孩子。不存在度为 1 的结点。
推论：对于 n 个叶子结点的哈夫曼树，总结点数为 2n − 1。

💡 关键性质速记

· 哈夫曼树不唯一（当有多个等权值结点时，合并顺序不同可得到不同的树形），但WPL 相同且最小
· 权值越大的叶子离根越近，权值越小的叶子离根越远
· 哈夫曼树中没有度为 1 的结点，只有度为 0（叶子）和度为 2（内部结点）

📝 真题 · 2021 年第 11 题哈夫曼编码本质
哈夫曼编码本质上使用的是哪种策略？
A动态规划
B分治策略
C贪心策略
D回溯策略
✅ 正确答案：C
分析：
哈夫曼编码的核心是贪心策略——每次从当前集合中选出权值最小的两个结点合并，构造出"最小代价"的二叉树。
贪心策略的关键特征是：每一步都做出当前最优的选择，最终得到全局最优解。哈夫曼树是贪心算法在二叉树构造中的经典应用。
✏️ 模拟题哈夫曼树叶子结点数
一棵哈夫曼树有 8 个叶子结点，则这棵树的总结点数为？
A15
B16
C14
D17
✅ 正确答案：A
分析：
哈夫曼树中没有度为 1 的结点，只有度为 0（叶子）和度为 2 的结点。
设叶子数为 L，度为 2 的结点数为 D。
根据二叉树性质：D = L − 1（在严格二叉树中，叶子数 = 度为2的结点数 + 1）
总结点数 = L + D = L + (L − 1) = 2L − 1
代入 L = 8：2 × 8 − 1 = 15。

2哈夫曼树构造过程

2.1 构造算法（贪心）

给定 n 个带权叶子结点，构造哈夫曼树的步骤如下：

📌 哈夫曼树构造步骤
1将 n 个带权叶子结点看作 n 棵只有根结点的二叉树，组成森林
2从森林中选出根结点权值最小的两棵树
3以这两棵树作为左右子树，合并为一棵新二叉树，新根权值 = 两者之和
4将合并后的新树放回森林，重复步骤 2~3
5直到森林中只剩一棵树——即为哈夫曼树

2.2 构造示例

以权值 {5, 8, 12, 15, 20} 为例，逐步构造：

📐 分步演示
1森林：5, 8, 12, 15, 20 → 选最小 5 和 8 → 合并为 13
2森林：12, 13, 15, 20 → 选最小 12 和 13 → 合并为 25
3森林：15, 20, 25 → 选最小 15 和 20 → 合并为 35
4森林：25, 35 → 合并为 60
5森林只剩 60，构造完成
60 / \ 25 35 / \ / \ 12 13 15 20 / \ 5 8
⚠️ 注意事项

· 当有多个相同最小权值时，任意选择其中两个合并，得到的哈夫曼树形状可能不同，但 WPL 相同
· 合并后的新结点可以参与下一轮比较
· 通常约定左小右大或左浅右深，但不影响 WPL

3带权路径长度（WPL）计算

3.1 WPL 计算公式

带权路径长度 WPL = Σ (叶子权值 × 路径长度)
其中路径长度 = 从根到该叶子经过的边数（CSP-J 默认按边数计算）。

📌 WPL 的两种计算方法

方法一（定义法）：
对所有叶子结点：WPL = Σ (权值 × 深度)（深度按边数计）

方法二（累加法）：
所有非叶子结点的权值之和 = WPL（将构造过程中每次合并产生的新结点权值全部相加）
这是因为每个叶子结点的权值会被累加其路径长度次。

3.2 WPL 计算示例

以权值 {10, 12, 15, 20, 25} 为例（2025年真题）：

📐 分步计算 WPL
1构造：10 + 12 = 22，森林变为 {15, 20, 22, 25}
2构造：15 + 20 = 35，森林变为 {22, 25, 35}
3构造：22 + 25 = 47，森林变为 {35, 47}
4构造：35 + 47 = 82，构造完成
82 / \ 35 47 / \ / \ 15 20 22 25 / \ 10 12

方法一（定义法）计算：
权值 10、12 的路径长度 = 3（根→35→47→22→10/12）
权值 15、20、25 的路径长度 = 2（根→35/47）
WPL = 10×3 + 12×3 + 15×2 + 20×2 + 25×2
= 30 + 36 + 30 + 40 + 50 = 186

方法二（累加法）验证：
合并过程中产生的新结点权值求和：22 + 35 + 47 + 82 = 186 ✅

4哈夫曼编码

4.1 什么是哈夫曼编码？

哈夫曼编码是一种可变字长编码（VLC），利用哈夫曼树为每个字符分配一个二进制编码：从根出发，向左走为 0、向右走为 1，到达叶子结点的路径即为该字符的编码。

📌 核心编码规则

· 向左分支 → 0，向右分支 → 1（也可互换，约定即可）
· 每个字符的编码是从根到叶子的路径
· 频率越高的字符，离根越近 → 编码越短
· 频率越低的字符，离根越远 → 编码越长

4.2 前缀编码

前缀编码是指：任意一个字符的编码都不是另一个字符编码的前缀。哈夫曼编码是最优的前缀编码——由于每个叶子对应一条唯一路径，不存在一个编码是另一个编码前缀的情况，因此可以无歧义地解码。

📐 前缀编码示例
根 / \ 0 1 / \ / \ a b c d

a=00, b=01, c=10, d=11
✅ 无歧义：解码时依次读取，"0110" = b(01) + c(10)，不会与任何其他编码混淆。
❌ 反例（非前缀编码）：a=0, b=01, c=1 → "01" 可以是 a(0)+c(1)，也可以是 b(01)，产生歧义。

5哈夫曼编码与数据压缩

5.1 压缩原理

使用定长编码（如 ASCII 码）时，每个字符固定占用 8 位。而哈夫曼编码根据字符的出现频率动态调节编码长度——高频短码、低频长码，从而在整体上减少平均编码长度，实现无损压缩。

📌 压缩率计算

平均编码长度 = Σ (每个字符的频率 × 该字符的编码长度)
压缩比 = 原编码总位数 ÷ 哈夫曼编码总位数
压缩率 = 哈夫曼编码总位数 ÷ 原编码总位数 × 100%

5.2 压缩示例

对 2022 年第 7 题的频率分布，计算平均编码长度：

📐 平均编码长度计算

a(10%) = 3位，b(15%) = 3位，c(30%) = 2位，d(16%) = 2位，e(29%) = 2位

平均编码长度 = a×3 + b×3 + c×2 + d×2 + e×2
= 10%×3 + 15%×3 + 30%×2 + 16%×2 + 29%×2
= 0.10×3 + 0.15×3 + 0.30×2 + 0.16×2 + 0.29×2
= 0.30 + 0.45 + 0.60 + 0.32 + 0.58
= 2.25 位/字符

💡 知识点归纳

· 哈夫曼编码是无损压缩算法，解码后能完全恢复原始数据
· 适用于频率分布不均匀的数据——频率差异越大，压缩效果越好
· 如果所有字符频率相同，哈夫曼编码退化为定长编码
· 哈夫曼编码广泛用于 ZIP、JPEG、MP3 等压缩标准中

📌 哈夫曼树重点速查表

哈夫曼树 = 最优二叉树，WPL 最小 构造：每次合并权值最小的两个结点 严格二叉树：无度为 1 的结点
WPL = Σ(权值 × 路径长度) = 累加所有合并结点权值 n 个叶子 → 总结点数 = 2n − 1 权值越大 → 离根越近 → 编码越短
哈夫曼编码 = 前缀编码（无歧义解码） 左分支 = 0，右分支 = 1 哈夫曼树不唯一，但 WPL 唯一
高频短码 + 低频长码 = 无损压缩 平均编码长度 = Σ(频率 × 编码长度) 频率越均匀 → 压缩效果越差
