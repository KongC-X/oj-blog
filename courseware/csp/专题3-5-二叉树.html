1二叉树基本术语

1.1 结点与根

二叉树（Binary Tree）是每个结点最多只有两个子结点的树结构，分别称为左孩子（left child）和右孩子（right child）。最顶层的结点称为根（root），没有父结点。

1.2 叶子结点

叶子结点（leaf）是指度为 0 的结点，即没有任何子结点的结点。叶子结点是二叉树的"末端"。

1.3 深度（高度）

深度（depth / height）是指从根到该结点的路径长度（或边的数量+1)。通常约定根在第 1 层。树的深度/高度指所有结点中的最大深度。

1.4 度

度（degree）是指结点拥有子树的个数。对于二叉树，结点的度只能是 0、1 或 2。度为 0 = 叶子，度为 2 = 有两个孩子。

📌 术语速记

· 根：唯一没有父结点的结点
· 叶子：度为 0，没有孩子的结点
· 深度：根到该结点的层数（根=1）
· 度：该结点拥有的子树数量（二叉树：0/1/2）

A ← 根结点（深度1，度2） / \ B C ← B深度2度1，C深度2度2 / / \ D E F ← D/E/F 均为叶子（度0，深度3）

在一棵二叉树中，下列关于叶子结点的说法正确的是？
A叶子结点一定有兄弟结点
B叶子结点的度为 0
C叶子结点一定在最后一层
D叶子结点可以有最多 1 个子结点
✅ 正确答案：B
分析：
A ❌ 叶子结点可能没有兄弟（如树只有一个孩子时）。
B ✅ 叶子结点没有子结点，所以度为 0。
C ❌ 叶子结点也可以不在最后一层（例如非完全二叉树的中间某层的叶子）。
D ❌ 叶子结点没有任何子结点，度为 0。
✏️ 模拟题深度计算
一棵二叉树共有 5 层（根为第1层），第5层最多有多少个结点？
A8
B16
C32
D4
✅ 正确答案：B
第 i 层最多有 2^(i-1) 个结点。第5层最多有 2^(5-1) = 2^4 = 16 个结点。
记忆：第1层最多1个（2^0），第2层最多2个（2^1），第3层最多4个（2^2），即每层最大结点数是2的(层数-1)次方。

2二叉树性质

2.1 性质①：第 i 层最多 2^(i-1) 个结点

在二叉树的第 i 层（根 = 第1层），最多有 2^(i-1) 个结点。当满二叉树时取最大值。

2.2 性质②：深度 h 最多 2^h − 1 个结点

深度为 h 的二叉树，最多有 2^h − 1 个结点。这也是一棵满二叉树的结点总数。
推导：1 + 2 + 4 + … + 2^(h-1) = 2^h − 1

📌 两条性质的记忆技巧

· 第 i 层最多 2^(i-1) → 想"第1层2^0=1"
· 总结点数最多 2^h − 1 → 想"h层全满时总数"
· 两者关系：2^h − 1 = 2^0 + 2^1 + … + 2^(h-1)

3满二叉树 vs 完全二叉树

3.1 满二叉树

满二叉树（Full Binary Tree / Perfect Binary Tree）是指所有层的结点数都达到最大值。即：深度为 h 的满二叉树恰好有 2^h − 1 个结点，且所有叶子都在第 h 层。

3.2 完全二叉树

完全二叉树（Complete Binary Tree）是指：除了最后一层外，其他各层都被填满（满的），且最后一层的结点全部靠左对齐。
通俗理解：从上到下、从左到右依次编号，编号是连续的，没有"空洞"。

📌 满 vs 完全区别

· 满二叉树：所有层全满，一定是完全二叉树
· 完全二叉树：最后一层不满但靠左，不一定是满二叉树
· 完全二叉树的叶子只可能出现在最后两层

满二叉树（h=3, 共7个结点） 完全二叉树（h=3, 共6个结点） ★ ★ / \ / \ ★ ★ ★ ★ / \ / \ / \ / ★ ★ ★ ★ ★ ★ ★

✏️ 模拟题满/完全二叉树判断
以下关于完全二叉树的说法错误的是？
A完全二叉树的所有叶子都在最后两层
B满二叉树一定是完全二叉树
C完全二叉树最后一层的结点必须靠左对齐

✅ 正确答案：D
分析：
A ✅ 完全二叉树的叶子只出现在最后两层（倒数第二层和最后一层）。
B ✅ 满二叉树所有层全满，满足完全二叉树"最后一层靠左"的条件，所以一定是完全二叉树。
C ✅ 这是完全二叉树的核心定义——最后一层靠左对齐。
D ❌ 2^h − 1 是满二叉树的结点数。完全二叉树的结点数可以在 [2^(h-1), 2^h − 1] 之间，不一定是满的。

📝 真题 · 2022 年第 8 题完全二叉树数组存储
一棵完全二叉树采用数组存储（下标从1开始），结点 tree[9] 存在。则 tree[9] 的兄弟结点和右子结点位置分别是？
A兄弟=8，右子=19
B兄弟=10，右子=18
C兄弟=8，右子=18
D兄弟=10，右子=19
✅ 正确答案：A
推导：
· 下标9的父结点：⌊9/2⌋ = 4，所以 tree[9] 是 tree[4] 的孩子
· 判断 tree[9] 是左孩子还是右孩子？因为 9 = 2×4 + 1 = 右孩子
· 所以兄弟是左孩子 2×4 = 8
· 左孩子：2×9 = 18
· 右孩子：2×9 + 1 = 19
因此兄弟为8，右子为19。

5四种遍历

5.1 前序遍历（Pre-order）

顺序：根 → 左子树 → 右子树
先访问根结点，再递归前序遍历左子树，最后递归前序遍历右子树。

5.2 中序遍历（In-order）

顺序：左子树 → 根 → 右子树
先递归中序遍历左子树，再访问根结点，最后递归中序遍历右子树。
对二叉搜索树（BST）进行中序遍历得到递增序列。

5.3 后序遍历（Post-order）

顺序：左子树 → 右子树 → 根
先递归后序遍历左子树，再递归后序遍历右子树，最后访问根结点。
后序遍历的最后一个是根结点。

5.4 层序遍历（Level-order）

顺序：从上到下、从左到右逐层访问每个结点。
也称广度优先遍历（BFS），通常借助队列实现。

📌 遍历示例
① / \ ② ③ / \ / \ ④ ⑤ ⑥ ⑦ 前序遍历：① ② ④ ⑤ ③ ⑥ ⑦ (根左右) 中序遍历：④ ② ⑤ ① ⑥ ③ ⑦ (左根右) 后序遍历：④ ⑤ ② ⑥ ⑦ ③ ① (左右根) 层序遍历：① ② ③ ④ ⑤ ⑥ ⑦ (逐层)
💡 记忆口诀

· 前序：根在前（根左右）— 第一个是根
· 中序：根在中间（左根右）— 根分左右子树
· 后序：根在最后（左右根）— 最后一个是根
· 层序：从上到下，从左到右

6由两种遍历还原二叉树 ⭐ 重中之重 · 必考

6.1 核心原理

已知中序遍历 + 前序或后序可以唯一确定一棵二叉树。
原因：前序/后序确定根的位置，中序确定左右子树划分。

📌 还原步骤（中序+前序）
1前序第一个元素 = 根结点
2在中序中找到根的位置，左边 = 左子树，右边 = 右子树
3在前序中，紧跟根之后的若干元素对应左子树的前序，再后面是右子树的前序
4对左右子树递归重复上述过程
💡 关键规律

· 前序+中序：前序首个=根，中序根左侧属左子树、右侧属右子树
· 后序+中序：后序最后=根，中序拆分规则同上
· 前序+后序：不能唯一确定二叉树（除非是满二叉树）

6.2 分步还原示例

📐 例：前序 A B D C E，中序 B D A C E
1前序首个 A → 根
2中序：B D ｜A｜ C E → 左子树{BD}，右子树{CE}
3左子树{BD}的前序为B D → B是左子树根；中序左子树B ｜D → B左空，D是B右孩子
4右子树{CE}的前序为C E → C是右子树根；中序右子树C ｜E → C左空，E是C右孩子
5还原完成：A(左B(右D), 右C(右E))
A / \ B C \ \ D E

📝综合模拟

📝 真题 · 2021 年第 8 题完全二叉树不同形态
一棵高度为 5 的完全二叉树，最多有多少种不同的形态？（注意：树的结构形态不同，不是值）
A8
B16
C32
D4
✅ 正确答案：B
分析：
高度为 5 的完全二叉树，前 4 层完全固定（满的，每层的结点数和位置确定），只有第 5 层的结点位置可以变化。
· 第 5 层最多可有 2^(5-1) = 16 个结点
· 完全二叉树要求结点靠左连续排列，所以第5层可以是 1 个、2 个、…、16 个靠左连续排列
· 所以不同的形态数就是第5层可能有的结点数：从 1 到 16，共 16 种。
注意：0 个结点时高度只有 4 层，不满足高度5的条件，所以不能为 0。
📝 真题 · 2025 年第 14 题完全二叉树叶子结点数
一棵完全二叉树有 1000 个结点，则其叶子结点数为？
A250
B500
C1000
D512
✅ 正确答案：B
方法：
设有 n 个结点的完全二叉树，叶子结点数 = ⌈n / 2⌉（向上取整）。
n = 1000，⌈1000 / 2⌉ = ⌈500⌉ = 500。

推导过程：
· 完全二叉树中，度为 1 的结点数 ≤ 1（最多只有1个度为1的结点）
· 设叶子结点数 = L，度为2的结点数 = D，度为1的结点数 = N1（N1 = 0 或 1）
· 结点总数：n = L + D + N1
· 边数关系：n − 1 = L + 2D + N1（除去根结点头上无入边）
· 两式相减：(L + D + N1) − 1 = L + 2D + N1 → D = L − 1
· 代入 n = L + (L − 1) + N1 → n = 2L − 1 + N1
· 当 N1 = 0：n = 2L − 1 → L = (n + 1) / 2
· 当 N1 = 1：n = 2L → L = n / 2
· 综合即 L = ⌈n / 2⌉
n = 1000 为偶数 → N1 = 1 → L = 1000 / 2 = 500。
✏️ 综合模拟二叉树综合判断
下列关于二叉树的说法正确的是？
A二叉树的度可以是 0、1、2、3
B深度为 4 的二叉树最多有 15 个结点
C完全二叉树的叶子只能在最后一层

✅ 正确答案：B
逐个分析：
A ❌ 二叉树的度最多为 2，不能为 3。
B ✅ 深度 4 最多 2^4 − 1 = 15 个结点（满二叉树）。
C ❌ 完全二叉树的叶子在最后两层（倒数第二层和最后一层），而非仅最后一层。
D ❌ 后序遍历最后一个是根结点，第一个是左子树最左下的结点。
✏️ 综合模拟完全二叉树编号
一棵完全二叉树有 2023 个结点（编号从1开始），编号为 1011 的结点是？
A根结点
B叶子结点
C度为 1 的结点
D度为 2 的结点
✅ 正确答案：D
分析：
完全二叉树中，叶子结点数 = ⌈n/2⌉。
n = 2023，叶子数 = ⌈2023 / 2⌉ = 1012（向上取整）。
叶子结点是最后 1012 个编号，即编号 1012 ~ 2023 都是叶子。
验证编号 1011：
· 左孩子 = 2 × 1011 = 2022 ≤ 2023 → 有左孩子
· 右孩子 = 2 × 1011 + 1 = 2023 ≤ 2023 → 有右孩子
· 编号 1011 既有左孩子又有右孩子，度为 2。
因此正确答案是 D。注意不要误以为 1011 接近叶子范围就一定是叶子，需要实际计算其孩子下标。

📌 二叉树重点速查表

第 i 层最多 2^(i-1) 个结点 深度 h 最多 2^h − 1 个结点 完全二叉树叶子数 = ⌈n/2⌉
前序：根左右 → 第一个是根 中序：左根右 → 根分左右 后序：左右根 → 最后是根
完全二叉树数组：左=2i · 右=2i+1 · 父=⌊i/2⌋ 满二叉树 = 所有层满 = 2^h − 1 中序+前序 → 还原二叉树（必考）
叶子：度=0 根：深度=1，无父 层序：队列实现，逐层 BFS
