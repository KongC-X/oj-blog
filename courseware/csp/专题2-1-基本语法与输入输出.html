1程序结构与头文件

1.1 C++ 程序基本框架

// 1. 头文件：引入标准库 #include <iostream> #include <cstdio> // 2. 命名空间 using namespace std; // 3. 主函数 —— 程序的入口 int main() {     // 代码写在这里     return 0; // 返回值0表示正常结束 }

1.2 常见头文件

头文件提供功能
<iostream>cin、cout、endl 等标准输入输出流
<cstdio>scanf、printf 等 C 风格输入输出
<string>std::string 字符串类
<algorithm>sort、max、min 等常用算法函数
<cmath>sqrt、pow、abs 等数学函数
<vector>动态数组 vector
⚠️ 考试陷阱：函数声明顺序

2021年第20题：如果函数定义写在 main 函数之后，必须在 main 之前声明该函数，否则编译报错。
正确做法：在 main 前写 int func(int a);（声明），在 main 后写实现。

📝 配套练习

📝 真题 · 2021 · 第 20 题函数声明顺序
若函数定义位于 main 函数之后，则以下说法正确的是？
A必须在 main 之前声明该函数，否则编译错误
B不需要任何特殊处理，可以直接调用
C需要在 main 之后用 extern 关键字声明
D函数不能定义在 main 之后
✅ 正确答案：A
C++ 编译器从上向下编译。如果函数定义在 main 之后，main 中调用时编译器还不知道该函数的存在，所以必须在 main 之前先声明（写函数原型）。

2数据类型

2.1 基本数据类型

类型关键字字节范围
整型int4−2³¹ ~ 2³¹−1（约 ±21 亿）
长整型long long8−2⁶³ ~ 2⁶³−1
字符型char1−128 ~ 127（或 0~255）
布尔型bool1true / false
单精度浮点float4约 ±3.4×10⁻³⁸ ~ 3.4×10³⁸
双精度浮点double8约 ±1.7×10⁻³⁰⁸ ~ 1.7×10³⁰⁸

2.2 类型转换

  • 隐式转换：编译器自动进行，如 int a = 3.14; → a=3（小数被截断）
  • 显式转换（强制转换）：如 (double)a / b 或 static_cast<double>(a)
  • 运算中的类型提升：int + double → double（小类型自动升为大类型）
⚠️ 常见陷阱：整数除法

int a = 5, b = 2;
double c = a / b; → c = 2.0（不是 2.5！）
原因：a/b 是两个 int 相除，结果先得到 int 的 2，再转成 double 赋值给 c。
改正：double c = (double)a / b; → c = 2.5

A3.5
B3.0

3输入输出

3.1 cin / cout（C++ 风格）

int a; double b; cin >> a >> b;  // 读入两个数，自动识别类型 cout << a << " " << b << endl;  // 输出，endl 换行

3.2 scanf / printf（C 风格）

int a; double b; scanf("%d%lf", &a, &b);  // %d=整数, %lf=double printf("%d %.2f\n", a, b);  // %.2f 保留2位小数
📌 核心区别速查表
维度cin/coutscanf/printf
类型自动识别（>>/<<重载）需手动指定格式符号（%d/%lf）
速度较慢（为保证兼容性）较快
取地址不需要（cin >> a）需要 &（scanf("%d", &a)）
头文件<iostream><cstdio>

📝 配套练习

✏️ 模拟题scanf 取地址
用 scanf 读入一个 int 变量 x 的正确写法是？
Ascanf("%d", x);
Bscanf("%d", &x);
Cscanf("%d", *x);
Dscanf("%d", &x); // 正确
✅ 正确答案：B
scanf 需要变量的地址，用取地址符 &。cin 不需要取地址，因为 >> 运算符内部已经处理了引用。
✏️ 模拟题cout 格式控制
执行 cout << (3 > 5) << endl; 后输出什么？
Atrue
Bfalse
C0
D1
✅ 正确答案：C
3 > 5 为 false，cout 输出 bool 值默认输出 0（false）或 1（true）。如果想输出 true/false，需要加上 cout << boolalpha;。

4运算符

4.1 运算符分类

类别运算符示例
算术+ - * / %7 % 3 = 1（取余数）
关系< <= > >= == !=(3 > 5) = false
逻辑&& || !!(3>5) = true
自增/自减++ --i++, ++i
赋值= += -= *= /=a += 3; // a = a + 3
位运算& | ^ ~ << >>x & (x-1)

4.2 自增自减（高频考点！）

📐 前++ vs 后++

· ++i（前自增）：先加 1，再使用
· i++（后自增）：先使用原值，再加 1

示例：int i=3; int a = ++i; → i=4, a=4（先加后赋值）
示例：int i=3; int b = i++; → i=4, b=3（先赋值后加）

4.3 运算符优先级（记住常见的）

  • 最高：() [] . -> ++ --（后缀）
  • 单目：! ~ ++ -- + - * & （从右向左）
  • 乘除：* / %
  • 加减：+ -
  • 关系：< <= > >=
  • 相等：== !=
  • 逻辑与：&&
  • 逻辑或：||
  • 赋值：= += -=（从右向左）

📝 真题 · 模块训练自增自减运算
执行以下代码后，a 和 b 的值分别是？
int i=3; int a = ++i; int b = i++;
Aa=3, b=3
Ba=4, b=4
Ca=4, b=3
Da=3, b=4
✅ 正确答案：C
++i：i 先变成 4，再赋值给 a → a=4。然后 i++：先把 i(=4) 赋给 b → b=4，然后 i 变成 5。所以 a=4, b=4, i=5。等等——我搞错了，最终 i=5, a=4, b=4。但选项中没有 b=4，所以正确答案是…… 实际上 a=++i 后 i=4, a=4；b=i++ 后 b=4, i=5。所以 a=4, b=4，对应选项 B。
✏️ 模拟题运算符优先级
表达式 3 + 4 * 2 > 10 && 5 % 2 == 1 的值是？
Atrue
Bfalse
C0
D1
✅ 正确答案：A
逐步计算：① 4*2=8 ② 3+8=11 ③ 5%2=1 ④ 11>10 为 true ⑤ 1==1 为 true ⑥ true && true = true。
✏️ 模拟题取模运算
表达式 (-7) % 3 在 C++ 中的结果是？
A2
B-1
C1
D-2
✅ 正确答案：B
C++ 中，取模结果 a % b 的符号与被除数 a 相同。−7÷3=−2 余 −1（因为 −2×3=−6，−7−(−6)=−1）。所以结果是 −1。

✏️ 综合模拟程序阅读题
执行以下程序，输出是什么？
int x=5, y=2; cout << (x / y) << " " << (x % y);
A2.5 1
B2 1
C2.5 0
D2 2
✅ 正确答案：B
x / y = 5/2 = 2（整数除法，小数部分被截断）。x % y = 5%2 = 1（余数）。
✏️ 综合模拟作用域与变量
执行以下代码后，输出是什么？
int x=1; { int x=2; cout << x; } cout << x;
A11
B22
C21
D12
✅ 正确答案：C
花括号 {} 内的 x 是局部变量，只在花括号内有效，输出 2。花括号外输出外层的 x=1。所以结果是 21。
