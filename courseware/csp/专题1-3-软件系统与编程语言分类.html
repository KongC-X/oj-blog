1软件系统分类

计算机软件分为 系统软件 和 应用软件 两大类。 系统软件管理计算机硬件资源，为应用软件提供运行环境； 应用软件解决特定用户问题。

⚙️ 系统软件

· 管理、控制和维护计算机硬件与软件资源
· 操作系统：Windows、Linux、macOS、Android、iOS
· 编译/解释器：gcc、javac、Python 解释器
· 数据库管理系统：MySQL、Oracle、SQL Server
· 驱动程序：显卡驱动、网卡驱动、声卡驱动

📱 应用软件

· 为用户解决具体问题而设计的软件
· 办公软件：Word、Excel、PowerPoint、WPS
· 浏览器：Chrome、Edge、Safari、Firefox
· 开发工具：VS Code、Dev-C++、Sublime Text
· 媒体/娱乐：Photoshop、Premiere、各类 App

⚠️ 考试高频混淆

· 操作系统（Windows/Linux）→ 系统软件 ✓
· Office（Word/Excel）→ 应用软件 ✓
· 编译器（gcc）→ 系统软件 ✓
· 浏览器（Chrome）→ 应用软件 ✓
· 数据库（MySQL）→ 系统软件 ✓

Windows 11 是操作系统，属于系统软件。Word（文字处理）、Chrome（浏览器）、Photoshop（图像处理）都是应用软件。
✏️ 模拟题 系统软件常见类型

✅ 正确答案：C
微信是即时通讯软件，属于应用软件。Linux（操作系统）、GCC（编译器）、MySQL（数据库管理系统）都属于系统软件。

2编程语言的三代演进

编程语言经历过三代发展，越往后越接近人类自然语言，编程效率越高。

语言级别特点例子如何执行
机器语言 由 0 和 1 组成的二进制代码，计算机直接执行 10110000 01100001 无须翻译，直接执行
汇编语言 用助记符代替二进制指令，需汇编器转换 MOV AL, 61H 汇编器 → 机器码
高级语言 接近自然语言（英语），需编译或解释 int a = 97; 编译器/解释器 → 机器码
💡 记忆技巧

机器语言（二进制）→ 汇编语言（助记符）→ 高级语言（自然语言）
越往上越容易写、越容易读、但执行效率越低（需要翻译步骤）。

📝 真题与模拟练习

📝 真题 · 分模块训练 汇编语言——归类判断
汇编语言属于以下哪一类？
A高级语言
B中级语言
C低级语言
D机器语言
✅ 正确答案：C
汇编语言是低级语言（低层语言）。它用助记符代替二进制，但每条指令仍与机器指令一一对应，没有脱离硬件特性。高级语言（如 C/Java）才是不依赖于具体硬件的。
✏️ 模拟题 计算机能直接执行的语言
计算机的 CPU 能直接识别和执行的语言是？
A汇编语言
B高级语言
C机器语言
D自然语言
✅ 正确答案：C
CPU 只能直接执行机器语言（二进制代码）。汇编语言需要汇编器翻译，高级语言需要编译器/解释器翻译，才能变成 CPU 能识别的机器码。

3编译型语言 vs 解释型语言

高级语言在执行之前需要"翻译"成机器码。翻译方式有两种：

🔹 编译型语言

· 一次性把全部源代码编译成机器码（生成可执行文件）
· 执行速度快，但修改后需重新编译
· 代表：C、C++、Pascal、Go、Rust

🔹 解释型语言

· 逐行解释执行，不生成独立可执行文件
· 开发灵活，但运行时需安装解释器、速度较慢
· 代表：Python、JavaScript、Ruby、PHP

📌 区分技巧

· 编译型 → 好比翻译一本书，整本翻完再读
· 解释型 → 好比同声传译，说一句翻一句
· Java 比较特殊：先编译成字节码（.class），再由 JVM 解释执行（或 JIT 编译）

📝 真题与模拟练习

📝 真题 · 分模块训练 编译与解释的区别
以下说法正确的是？
A编译型语言执行速度通常慢于解释型语言
B解释型语言不需要翻译即可直接执行
C编译型语言在执行前需要将源代码全部翻译为机器码
D解释型语言生成的代码可以被 CPU 直接执行
✅ 正确答案：C
A 错——编译型语言速度更快（一次编译后直接执行）。B 错——解释型语言需要解释器逐行翻译，不是直接执行。D 错——解释型语言并不生成 CPU 直接执行的机器码文件。
✏️ 模拟题 Python 是哪种类型
Python 编程语言属于？
A编译型语言
B解释型语言
C汇编语言
D机器语言
✅ 正确答案：B
Python 是典型的解释型语言，由 Python 解释器逐行解释执行。当然 Python 内部也有编译步骤（先编译成字节码 .pyc），但从用户的编程体验来看，它属于解释型。

4面向对象 vs 面向过程

这是初赛单选题中最高频的送分题。记住一张表就够了：

📌 面向过程

· 以函数/过程为中心
· 程序 = 数据结构 + 算法
· 数据与操作分离
· 代表语言：C、Pascal、Fortran

📌 面向对象（OOP）

· 以对象/类为中心
· 支持封装、继承、多态三大特性
· 数据与操作绑定在一起
· 代表语言：C++、Java、Python、C#

🔍 OOP 三大特征详解

① 封装：将数据和方法打包在类中，对外隐藏实现细节（通过访问权限控制）
② 继承：子类自动拥有父类的属性和方法，可扩展或重写
③ 多态：同一操作作用于不同对象，产生不同结果（通过虚函数/接口实现）
2022 年第 1 题就是考这三个特性会出现在哪些 C++ 语言特性中。

⚠️ 最容易错的点

C 语言 是面向过程的——但它不是唯一的过程式语言。
有些同学以为 C++ 是纯面向对象，其实 C++ 是多范式语言（兼容 C 的过程式写法，同时支持 OOP）。
Java 则基本上是纯面向对象（所有代码必须在类中）。

📝 真题与模拟练习

📝 真题 · 2021 · 第 1 题 面向对象语言判断
以下不属于面向对象程序设计语言的是？
AC++
BPython
CJava
DC
✅ 正确答案：D
C 语言是面向过程的语言，不是面向对象。C++、Python、Java 都是面向对象语言（或支持面向对象编程）。这是 2021 年 CSP-J 第 1 题，送分题，必须拿稳。
📝 真题 · 2022 · 第 1 题 C++ 面向对象特性
以下哪种功能没有涉及 C++ 语言的面向对象特性支持？
A调用 printf 函数
B使用 class 定义类
C使用继承机制派生新类
D使用虚函数实现多态
✅ 正确答案：A
调用 printf 是 C 语言遗留的标准库函数调用，属于面向过程的写法，不涉及面向对象。B（class）、C（继承）、D（虚函数/多态）都是 C++ OOP 的核心特性。
✏️ 模拟题 面向对象三大特征
以下哪项不属于面向对象程序设计的基本特征？
A封装
B继承
C多态
D递归
✅ 正确答案：D
递归是一种编程技巧（函数调用自身），任何语言都可以用，不是面向对象的特征。
面向对象的三大基本特征是封装、继承、多态。

5常见编程语言分类速查

一张表总结常见编程语言的多维分类（初赛单选的得分关键）：

语言面向对象/过程编译/解释主要应用领域
C🔴 面向过程编译型操作系统、嵌入式、系统编程
C++🟢 面向对象（多范式）编译型游戏、高性能计算、算法竞赛
Java🟢 面向对象（纯OOP）编译+解释（JVM）企业应用、Android 开发
Python🟢 面向对象解释型数据分析、AI、脚本、教学
JavaScript🟢 面向对象解释型Web 前端开发
Pascal🔴 面向过程编译型教学（NOI 早期复赛语言）
Fortran🔴 面向过程编译型科学计算、数值分析
C#🟢 面向对象编译型（.NET）Windows 桌面、游戏（Unity）
💡 速记口诀

面向过程 = C + Pascal + Fortran（"CPF" 三个字母）
面向对象 = C++ + Java + Python + C# + JS（常见的都会写出来）
题目问"不是面向对象"时，优先看选项里有没有 C 语言（最经典陷阱）。

📝 真题与模拟练习

📝 真题 · 2024 · 改编 语言分类——综合判断
以下属于面向对象程序设计语言的是？
AC
BFortran
CPascal
DJava
✅ 正确答案：D
Java 是典型的面向对象语言。C、Fortran、Pascal 都是面向过程的语言。
✏️ 模拟题 C++ 的多范式特性
以下关于 C++ 的说法，正确的是？
AC++ 是纯面向对象语言，所有代码都必须写在类中
BC++ 是面向过程语言，不支持面向对象
CC++ 是一种多范式语言，同时支持面向过程和面向对象
DC++ 只能用于算法竞赛
✅ 正确答案：C
C++ 是多范式语言：它兼容 C 的过程式语法（可以写全局函数），同时完整支持面向对象（class、继承、虚函数）。A 错——Java 才是纯面向对象；B 错——C++ 支持 OOP；D 错——C++ 应用广泛。
✏️ 模拟题 语言分类——选取"过程式"
以下全部属于面向过程语言的一组是？
AC++、Java、Python
BC、Pascal、Fortran
CC、C++、C#
DPython、JavaScript、Ruby
✅ 正确答案：B
C、Pascal、Fortran 都是经典的面向过程语言。
A 和 D 都是面向对象语言；C 中 C++ 和 C# 是面向对象，只有 C 是面向过程。

ALinux 是一种操作系统，属于系统软件
