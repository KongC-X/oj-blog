1集合运算

1.1 五种基本运算

运算 符号 数学定义 示例（A={1,2,3}, B={2,3,4}）
交 A ∩ B { x | x∈A 且 x∈B } {2,3}
并 A ∪ B { x | x∈A 或 x∈B } {1,2,3,4}
补 ∁UA { x | x∈U 且 x∉A } （依赖于全集 U）
差 A − B { x | x∈A 且 x∉B } {1}
对称差 A △ B (A−B) ∪ (B−A) {1,4}
📌 对称差的重要特性
  • 定义：A △ B = (A−B) ∪ (B−A)——即只属于其中一个集合的所有元素
  • 等价形式：A △ B = (A∪B) − (A∩B)
  • 交换律：A △ B = B △ A
  • 与布尔代数的对应：A △ B 对应 a XOR b
⚠ 易错提醒：补运算是相对于全集 U 定义的，没有全集就没有补集。 差集 A−B 与 B−A 一般不同（差集不具有交换性）。

📝 集合运算练习

✏️ 模拟题 集合交与并
已知集合 A = {1, 2, 3, 4, 5}，B = {3, 4, 5, 6, 7}，则 A∩B 和 A∪B 分别是？
AA∩B={3,4,5}, A∪B={1,2,3,4,5,6,7}
BA∩B={4,5}, A∪B={1,2,3,4,5,6,7,8}
CA∩B={3,4,5,6}, A∪B={1,2,3,4,5,6,7}
DA∩B={3,4,5}, A∪B={1,2,3,4,5,6}
✅ 正确答案：A
分析：
· A∩B = 既在 A 中也在 B 中的元素 = {3, 4, 5}
· A∪B = 在 A 中或在 B 中的所有元素 = {1, 2, 3, 4, 5, 6, 7}

注意：8 不在 A 也不在 B 中，所以 A∪B 不包含 8；6 不在 A 中但在 B 中，所以 A∪B 包含 6。
✏️ 模拟题 补集与差集运算
设全集 U = {x | x 是小于 10 的正整数}，A = {1, 3, 5, 7, 9}，B = {2, 3, 5, 7}，则 ∁U(A∪B) 等于？
A{4, 6, 8}
B{1, 9}
C{2, 4, 6, 8}
D{4, 6, 8, 10}
✅ 正确答案：A（{4, 6, 8}）
分步计算：
· U = {1, 2, 3, 4, 5, 6, 7, 8, 9}
· A∪B = {1, 2, 3, 5, 7, 9}（合并两集合去重）
· ∁U(A∪B) = 在 U 中但不在 A∪B 中的元素 = {4, 6, 8}

也可用德摩根律验证：
∁U(A∪B) = ∁UA ∩ ∁UB
∁UA = {2,4,6,8}, ∁UB = {1,4,6,8,9}
交集 = {4, 6, 8} ✅
✏️ 模拟题 对称差运算
已知 A = {1, 2, 3, 4}，B = {3, 4, 5, 6}，则对称差 A △ B 等于？
A{1, 2, 5, 6}
B{3, 4}
C{1, 2, 3, 4, 5, 6}
D{5, 6}
✅ 正确答案：A（{1, 2, 5, 6}）
方法一（定义法）：
· A−B = {1, 2}（在 A 中但不在 B 中）
· B−A = {5, 6}（在 B 中但不在 A 中）
· A △ B = (A−B) ∪ (B−A) = {1, 2, 5, 6}

方法二（等价公式）：
· A∪B = {1, 2, 3, 4, 5, 6}
· A∩B = {3, 4}
· A △ B = (A∪B) − (A∩B) = {1, 2, 5, 6} ✅
✏️ 模拟题 集合运算综合
已知全集 U 中 |U| = 30，|A| = 12，|B| = 15，|A∩B| = 6，则 |∁U(A∪B)| 等于？
A6
B9
C12
D15
✅ 正确答案：B（9）
分步计算：
· |A∪B| = |A| + |B| − |A∩B| = 12 + 15 − 6 = 21
· |∁U(A∪B)| = |U| − |A∪B| = 30 − 21 = 9

容斥原理应用：这是集合综合题中常见的"总数 − 并集"模式，常用于计算"至少有一项"和"两项都没有"的人数问题。

2文氏图（Venn 图）

文氏图用圆表示集合，圆的重叠区域表示集合的交集，是一种直观的集合关系表示方法。

2.1 文氏图基本图式

📌 文氏图常见考点
  • 两个集合的交集、并集、差集在图中对应的阴影区域
  • 三个集合的 8 个区域（每个元素属于/不属于 A/B/C 各组合）
  • 利用文氏图辅助求解集合计数问题（如"至少选一门"、"两门都不选"）
  • 文氏图与布尔代数表达式的对应关系

📝 文氏图练习

✏️ 模拟题 文氏图计数应用
某班有 40 名学生，喜欢数学的有 25 人，喜欢物理的有 18 人，两门都喜欢的有 10 人。则至少喜欢一门的人数和两门都不喜欢的人数分别是？
A33 人，7 人
B35 人，5 人
C33 人，5 人
D35 人，7 人
✅ 正确答案：A（33 人，7 人）
利用文氏图分析：
· 只喜欢数学 = 25 − 10 = 15 人
· 只喜欢物理 = 18 − 10 = 8 人
· 两门都喜欢 = 10 人
· 至少喜欢一门 = 15 + 8 + 10 = 33 人
· 两门都不喜欢 = 40 − 33 = 7 人

公式法：|A∪B| = |A| + |B| − |A∩B| = 25 + 18 − 10 = 33，都不喜欢 = 40 − 33 = 7。

3布尔代数基本运算

布尔代数是逻辑运算的数学基础，变量取值只有 0（假/False） 和 1（真/True）。 在 C++ 中对应 bool 类型的运算。

3.1 四种基本运算

运算 C++ 运算符 数学符号 真值表（a,b） 说明
与（AND） a && b a ∧ b 或 a·b 仅当 a=b=1 时结果为 1 全真才真
或（OR） a || b a ∨ b 或 a+b 只要 a=1 或 b=1 结果为 1 一真即真
非（NOT） !a ¬a 或 a' a=0 时结果为 1，a=1 时结果为 0 取反
异或（XOR） a ^ b a ⊕ b a 与 b 不同时结果为 1 不同为真
💡 记忆口诀

AND 全真才真，OR 一真即真，NOT 取反，XOR 不同为真。
异或的另一种等价形式：a ⊕ b = (a && !b) || (!a && b)

集合论布尔代数说明

📝 布尔代数基础练习

✏️ 模拟题 布尔代数基本运算

B1

✅ 正确答案：A（0）
逐步计算：
· a = 1, b = 0 → a && b = 1 && 0 = 0
· c = 1 → !c = 0
· a && !c = 1 && 0 = 0
· (a&&b) || (a&&!c) = 0 || 0 = 0

4布尔代数化简公式

4.1 核心化简公式

名称 公式 说明
分配律 a && (b || c) = (a&&b) || (a&&c) AND 对 OR 分配，类似乘法分配律
分配律（对偶） a || (b && c) = (a||b) && (a||c) OR 对 AND 分配
德摩根律（AND） !(a && b) = !a || !b "与非"等于"非或"
德摩根律（OR） !(a || b) = !a && !b "或非"等于"非与"
吸收律 a || (a && b) = a a 吸收 a&&b
吸收律 a && (a || b) = a a 吸收 a||b
互补律 a && !a = 0,   a || !a = 1 矛盾律 + 排中律
💡 德摩根律记忆技巧："去括号时，AND 变 OR，OR 变 AND，每个变量取反"——即 拆括号、换运算、取反。
🔢 化简示例：a || (!a && b) → ?
1 原式：a || (!a && b)
2 分配律（OR 对 AND）：(a || !a) && (a || b)
3 互补律：1 && (a || b)
4 结果：a || b

结论：a || (!a && b) 恒等于 a || b。这是 CSP-J 中常见的化简题型。

5真值表验证逻辑等价性

真值表是枚举变量所有取值组合、逐行计算表达式结果的方法。 两个表达式恒等当且仅当它们在所有行的输出值都相同。

2025 年 CSP-J 初赛新题型：给出一个逻辑表达式，判断哪个选项与其不始终相等。 解题关键是——用真值表逐行对比，或用量简公式化简。

5.1 2025 年第 7 题 · 真题重现

📝 真题 · 2025 · 第 7 题 逻辑表达式等价性判断
表达式 (a && b) || (!c && a) 与以下哪个表达式不始终相等？
Aa && (b || !c)
Ba && !(!b && c)
Ca && (!b || c)
D!(!a) && (b || !c)
✅ 正确答案：C（a && (!b || c)）
首先化简原式：
· (a && b) || (!c && a) = a && (b || !c)（分配律）
· 所以 A 选项与原式相同。
· D 选项：!(!a) && (b || !c) = a && (b || !c)，等价于原式。
· B 选项：a && !(!b && c)，用德摩根律：!(!b && c) = b || !c，所以等价于原式。
· C 选项：a && (!b || c) 与 a && (b || !c) 不同。

完整 8 行真值表验证（a, b, c 全部取值）：
abc !ca&&b!c&&a 原式 b||!cA: a&&(b||!c) !(!b&&c)B: a&&!(!b&&c) C: a&&(!b||c) D: !(!a)&&(b||!c)

黄色高亮行（a=1, b=0, c=1）：
· 原式 = 0，选项 C = 1，两者不同。
· 其他行原式与 C 均相同？不对，检查 a=1,b=0,c=1 这行就是差异所在！
· A、B、D 在所有 8 行都与原式完全一致。

结论：C 选项与原式不始终相等，答案选 C。

📝综合模拟 —— 布尔代数与集合论综合检测

以下题目综合了集合运算、文氏图、布尔代数等多个知识点，检验综合运用能力。

✏️ 综合模拟 集合与布尔代数对应关系
集合运算中 A △ B 对应布尔代数中的哪个运算？
Aa && b（AND）
Ba || b（OR）
Ca ^ b（XOR）
D!a（NOT）
✅ 正确答案：C（a ^ b，XOR）
对应关系总结：
· A∩B（交集）→ a && b（AND）——两个集合都包含
· A∪B（并集）→ a || b（OR）——至少一个集合包含
· ∁A（补集）→ !a（NOT）——不属于该集合
· A△B（对称差）→ a ^ b（XOR）——恰好属于一个集合

验证：A△B = (A−B)∪(B−A) 对应 (a&&!b)||(!a&&b) = a ^ b，完全一致。

这个对应关系在 CSP-J 初赛中经常以"类比"的形式出现。
✏️ 综合模拟 综合判断
以下说法中错误的是？
AA−B = A ∩ ∁B
B!(a || b) = !a && !b
CA △ B = (A∪B) − (A∩B)
Da && (b || c) = a || (b && c)
✅ 正确答案：D
逐一判断：
A 正确——差集 A−B 等价于 A 与 B 补集的交集。
B 正确——德摩根律，C++ 中记作 !(a||b) == !a && !b。
C 正确——对称差的等价定义。
D 错误——a && (b || c) 不等于 a || (b && c)。
反例：a=0, b=1, c=0 时，左边 = 0 && (1||0) = 0，右边 = 0 || (1&&0) = 0，碰巧相等；
但 a=1, b=0, c=0 时，左边 = 1 && (0||0) = 0，右边 = 1 || (0&&0) = 1 → 两者不等。❌

📌 本节课知识速查

以下是你应该背下来的核心结论：
交∩：全属才属 并∪：一属即属 补∁：相对于全集 差−：不具交换性 对称差△：恰好属一个
AND &&：全真才真 OR ||：一真即真 NOT !：取反 XOR ^：不同为真

📊 布尔代数与集合论 · 底部速查表
