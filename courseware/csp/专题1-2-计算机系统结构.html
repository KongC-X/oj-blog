1冯·诺依曼结构五大部件

冯·诺依曼计算机由 五大部件 组成，它们各司其职、协同工作。 只要理解了每个部件的功能和它们之间的关系，系统结构类的题目就不会丢分。

部件英文功能具体例子
① 运算器 ALU 执行算术运算（+−×÷）和逻辑运算（与或非比较） CPU 内部
② 控制器 CU 取指令→译码→控制各部件协调工作 CPU 内部
③ 存储器 Memory 存放程序和数据（指令+数据） 内存（RAM/ROM）
④ 输入设备 Input 将外部信息送入计算机 键盘、鼠标、扫描仪
⑤ 输出设备 Output 将计算结果输出给人或其他设备 显示器、打印机、音箱
📌 两个重要公式

CPU = 运算器 + 控制器（中央处理器 = 算术逻辑单元 + 控制单元）
主机 = CPU + 内存（五大部件中，运算器、控制器、存储器合称"主机"）

💡 工作流程一分钟搞懂

① 输入设备把程序和数据送入存储器
② 控制器从存储器取出指令，译码后告诉各部件做什么
③ 运算器执行计算，结果存回存储器
④ 输出设备把结果呈现给用户
整个过程反复循环——这就是计算机的工作周期（取指令→译码→执行）

📝 真题与模拟练习

📝 真题 · 2021 · 改编 五部件——设备归类
以下关于冯·诺依曼计算机结构的描述中，正确的是？
A冯·诺依曼计算机的核心部件是运算器和存储器
B冯·诺依曼结构包括运算器、控制器、存储器、键盘和显示器五大部件
C冯·诺依曼计算机采用"存储程序"和"二进制"两大基本原理
D冯·诺依曼计算机中，输入输出设备不属于五大部件
✅ 正确答案：C
A 错——核心部件是运算器和控制器（合称 CPU），不是运算器和存储器。
B 错——五大部件中的输入/输出设备是泛称，不是特指键盘和显示器。
D 错——输入设备和输出设备就是五大部件中的两个。
✏️ 模拟题 CPU 的组成
中央处理器（CPU）由哪两部分组成？
A运算器和存储器
B控制器和存储器
C运算器和控制器
D运算器和输入设备
✅ 正确答案：C
CPU = 运算器 + 控制器。
· 运算器（ALU）负责计算
· 控制器（CU）负责指挥
合在一起才能"边算边指挥"，缺一不可。
✏️ 模拟题 冯·诺依曼——部件功能匹配
在冯·诺依曼结构中，负责"从存储器中取出指令并译码，然后控制其他部件执行"的是？
A运算器
B控制器
C存储器
D输出设备
✅ 正确答案：B
控制器（CU）负责取指令→译码→控制执行，是计算机的"指挥中心"。
运算器只负责"算"，不负责"指挥"——这是最容易混淆的点。

2CPU 与存储器体系

2.1 CPU 的功能

CPU（中央处理器）是计算机的"大脑"，负责解释指令和处理数据。 它由运算器和控制器组成。CPU 的性能主要由主频（GHz）、 核数、缓存大小等决定。

2.2 存储器层次结构

存储器并非一种，而是一个有层次的体系。从上到下：速度越来越慢，容量越来越大，价格越来越低。

层次名称速度容量典型大小
L1CPU 寄存器最快（0.3ns）最小几十~几百字节
L2Cache（高速缓存）很快（1ns）较小几 MB~几十 MB
L3内存（主存）较快（10ns）较大8GB~64GB
L4外存（硬盘/U盘）慢（ms级）大256GB~数TB
💡 局部性原理：CPU 访问存储单元时，往往会集中访问某一小片连续区域。 基于这个原理，把最常用的数据放在最快的 Cache 中，就能大幅提升整体性能。 这是 Cache 存在的理论基础。

2.3 RAM vs ROM

🔹 RAM（随机存取存储器）

· 可读可写
· 断电后数据丢失（易失性）
· 用来存放正在运行的程序和数据
· 分为 DRAM（主存）和 SRAM（Cache）

🔹 ROM（只读存储器）

· 只能读不能写（正常模式下）
· 断电后数据不丢失（非易失性）
· 用来存放 BIOS/固件等不变的程序
· 包括 PROM、EPROM、EEPROM 等

⚠️ 考试经典陷阱

"断电后数据会丢失的是_____"——答案：RAM。
题目有时会说"内存"、"主存"，它们通常指 RAM，断电即丢。
而 ROM、硬盘、U盘都是断电不丢的。

📝 真题与模拟练习

📝 真题 · 2023 · 改编 RAM 的特性
关于计算机存储器，以下说法正确的是？
ARAM 断电后数据不会丢失
BROM 断电后数据丢失
CRAM 断电后数据会丢失，ROM 断电后数据不会丢失
DRAM 和 ROM 断电后数据都不会丢失
✅ 正确答案：C
RAM（随机存取存储器）是易失性的，断电后数据丢失。
ROM（只读存储器）是非易失性的，断电后数据保留。
这是计算机基础中最经典的判断题之一。
📝 真题 · 分模块训练 Cache——引入目的
主存储器的存取速度比中央处理器（CPU）的工作速度慢得多，从而使得后者的效率受到影响。 根据局部性原理，为了提高系统整体的执行效率，在 CPU 中引入了？
A寄存器
B高速缓存（Cache）
C外存储器
D虚拟存储器
✅ 正确答案：B
高速缓存（Cache）位于 CPU 和主存之间，存放 CPU 近期可能用到的数据。 基于局部性原理——CPU 访问的数据往往集中在相邻区域， 把热点数据提前加载到 Cache 中，可以大幅减少 CPU 等待数据的时间。
A 寄存器是 CPU 内部最快的存储，但不是为了解决主存慢的问题引入的。
✏️ 模拟题 存储器速度排序
以下存储设备按存取速度从快到慢排列，正确的是？
A寄存器 → Cache → 内存 → 硬盘
BCache → 寄存器 → 内存 → 硬盘
C内存 → Cache → 寄存器 → 硬盘
D寄存器 → 内存 → Cache → 硬盘
✅ 正确答案：A
正确顺序：寄存器（在 CPU 内部，最快）→ Cache（高速缓存）→ 内存（主存）→ 硬盘（外存，最慢）。
规律：越靠近 CPU 越快，但容量越小、价格越贵。
✏️ 模拟题 寄存器属于哪个部件
寄存器是以下哪个部件的重要组成部分？
A硬盘
B高速缓存
C内存
D中央处理器（CPU）
✅ 正确答案：D
寄存器是 CPU 内部的存储单元，用于暂存指令、数据和地址。 它是计算机中速度最快的存储器，但容量极小（几十~几百字节）。
来源：分模块知识点训练/1.计算机的基本构成 第2题。

3存储单位与换算

计算机中最小的数据单位是 位（bit）， 最基本的存储单位是 字节（Byte）。 它们之间的换算关系是初赛常考的计算题。

单位符号换算关系数值（字节）
位bit1 bit = 一个二进制位（0 或 1）—
字节B1 B = 8 bit—
千字节KB1 KB = 210 B = 1024 B约 103 字节
兆字节MB1 MB = 220 B = 1024 KB约 106 字节
吉字节GB1 GB = 230 B = 1024 MB约 109 字节
太字节TB1 TB = 240 B = 1024 GB约 1012 字节
🔢 核心换算公式

· 1 Byte = 8 bit（必记！）
· 1 KB = 1024 B（210，不是 1000）
· 1 MB = 1024 KB = 1,048,576 B
· 1 GB = 1024 MB
· 每级进率为 210 = 1024

📝 真题与模拟练习

📝 真题 · 分模块训练 字节与位的关系
一个字节（Byte）由多少个二进制位（bit）组成？
A4
B8
C16
D1024
✅ 正确答案：B
1 Byte = 8 bit，这是计算机科学中最基本的换算关系。
来源：分模块知识点训练/6.字节与字。
📝 真题 · 2021 · 改编 MB 换算为字节
一个 1 MB 的文件，理论上最多可以存储多少个字节？
A1000 × 1000
B1024 × 1024
C1000 × 1024
D1024 × 1000
✅ 正确答案：B
1 MB = 1024 KB = 1024 × 1024 字节 = 1,048,576 字节。
注意这里用的是1024 进率（210），不是 1000。
硬盘厂商有时用 1000 进制（1 MB = 1,000,000 B），但考试中一律按 1024 计算。
✏️ 模拟题 单位换算——综合
2 GB 等于多少 MB？
A2000
B2048
C1024
D2 × 109
✅ 正确答案：B
1 GB = 1024 MB，所以 2 GB = 2048 MB。
进率 1024 要记牢——A 选项 2000 是用 1000 进制算出来的，是常见干扰项。

4输入设备与输出设备

输入设备负责把外部信息送进计算机，输出设备负责把结果呈现给用户。 注意区分"既是输入又是输出"的特殊设备。

📥 常见输入设备

键盘、鼠标、扫描仪、麦克风、摄像头、触摸板、游戏手柄、条码阅读器

📤 常见输出设备

显示器、打印机、扬声器（音箱）、耳机、投影仪、绘图仪

💡 特殊设备——既是输入又是输出

· 触摸屏：既能显示（输出），又能感应触摸（输入）
· 网卡：既能接收数据（输入），又能发送数据（输出）
· U盘/硬盘：既能读（输入），又能写（输出）

📝 真题与模拟练习

📝 真题 · 2023 · 改编 输入设备判断
以下设备中，不属于输入设备的是？
A键盘
B鼠标
C显示器
D扫描仪
✅ 正确答案：C
显示器是输出设备，用于显示图像和文字。
键盘、鼠标、扫描仪都是典型的输入设备。
记忆技巧：输入设备"把数据送进去"，输出设备"把结果显示/打印出来"。
✏️ 模拟题 既是输入又是输出
以下设备中，既是输入设备又是输出设备的是？
A键盘
B打印机
C触摸屏
D投影仪
✅ 正确答案：C
触摸屏既可以显示内容（输出），又可以感应手指触摸输入（输入）， 因此它既是输入设备又是输出设备。
A 键盘是纯输入；B 打印机和 D 投影仪是纯输出。

5软件系统分类

计算机软件分为系统软件和应用软件两大类。 考试中常让你判断某个软件属于哪一类。

⚙️ 系统软件

管理和控制计算机硬件资源的软件。
· 操作系统：Windows、Linux、macOS、Android、iOS
· 编译/解释器：gcc、javac、Python解释器
· 数据库管理系统：MySQL、Oracle
· 驱动程序：显卡驱动、网卡驱动

📱 应用软件

为解决特定问题而开发的软件。
· 办公软件：Word、Excel、PowerPoint
· 开发工具：VS Code、Dev-C++、Sublime
· 浏览器：Chrome、Edge、Safari
· 游戏/娱乐：各类 App

⚠️ 常见混淆

· 操作系统（Windows、Linux）→ 系统软件
· Office 套件（Word、Excel）→ 应用软件
· 编译器（gcc、javac）→ 系统软件
· 浏览器（Chrome）→ 应用软件
考试中如果题目问"以下属于操作系统的是"，答案通常是 Windows 或 Linux。
