1计算机网络基础

计算机网络是利用通信线路和设备，将分布在不同地理位置的多台计算机连接起来，实现资源共享和信息传输的系统。它是通信技术与计算机技术相结合的产物。

1.1 网络分类（按覆盖范围）

类型覆盖范围典型例子
LAN（局域网）几十米~几公里家庭 Wi-Fi、学校机房、公司内网
MAN（城域网）几公里~几十公里城市范围的网络
WAN（广域网）几百公里以上互联网（Internet）

1.2 常见网络设备

  • 路由器：连接不同网络，负责数据包转发（工作在网络层）
  • 交换机：连接同一网络内的多台设备（工作在数据链路层）
  • 集线器（Hub）：将信号广播到所有端口（工作在物理层，已被交换机取代）
  • 调制解调器（Modem）：数字信号和模拟信号的转换

1.3 网络发展三阶段

  • 第一阶段：远程终端联机（主机-终端）
  • 第二阶段：计算机-计算机网络（ARPANET，互联网的前身）
  • 第三阶段：高速互联网与移动互联网

2OSI 七层模型与 TCP/IP 四层模型

网络协议的分层模型是计算机网络的核心概念。最重要的两个模型是 OSI 七层模型 和 TCP/IP 四层模型。

📚 OSI 七层模型（从下往上）

7️⃣ 应用层：HTTP/FTP/SMTP/DNS
6️⃣ 表示层：数据格式转换、加密解密
5️⃣ 会话层：建立/管理/终止会话
4️⃣ 传输层：TCP/UDP、端到端通信
3️⃣ 网络层：IP 地址、路由选择
2️⃣ 数据链路层：MAC 地址、帧传输
1️⃣ 物理层：比特流传输、网线/光纤

🔗 TCP/IP 四层模型

4️⃣ 应用层：HTTP/FTP/SMTP/DNS
3️⃣ 传输层：TCP/UDP
2️⃣ 网际层：IP（核心——负责路由）
1️⃣ 网络接口层：以太网、Wi-Fi


💡 TCP/IP 是实际互联网使用的模型，OSI 是理论标准。

📌 必记：各层对应关系

· OSI 的应用/表示/会话层 → TCP/IP 的应用层
· OSI 的传输层 → TCP/IP 的传输层（TCP/UDP）
· OSI 的网络层 → TCP/IP 的网际层（IP）
· OSI 的数据链路/物理层 → TCP/IP 的网络接口层

如果用现实生活中的例子来比喻网络分层模型，以下最恰当的是？
A中国公司的经理与波兰公司的经理交互商业文件

A应用层
B传输层
C网际层

✅ 正确答案：C
IP（Internet Protocol）位于 TCP/IP 模型的网际层（也叫网络层），主要负责寻址和路由选择。TCP/UDP 在传输层。

3IP 地址与域名系统

3.1 IP 地址

IP 地址是互联网上每台设备的唯一标识，就像门牌号一样。

版本位数格式地址数量
IPv432 位点分十进制，如 192.168.1.1约 43 亿（已基本耗尽）
IPv6128 位冒号十六进制，如 2001:db8::1极大量（2¹²⁸个）

3.2 IP 地址分类（IPv4 A/B/C 类）

类别首字节范围默认子网掩码用途
A 类1~126255.0.0.0大型网络
B 类128~191255.255.0.0中型网络
C 类192~223255.255.255.0小型网络（局域网常用）
特殊127—回环测试地址（127.0.0.1 = localhost）

3.3 域名系统（DNS）

DNS（Domain Name System）将人类易记的域名（如 www.baidu.com）解析为 IP 地址。
顶级域名（TLD）如 .cn（中国）、.com（商业）、.org（组织）、.edu（教育）。

💡 考点提示

· 中国的国家顶级域名是 .cn（不是 .ch 或 .chn）
· 127.0.0.1 是本机回环地址，永远指向本机
· 192.168.x.x 是私有 IP 地址，用于局域网
· IPv6 是 128 位，不是 64 位或 48 位

4常见网络协议

初赛常考的协议及其默认端口：

协议全称默认端口用途
HTTP超文本传输协议80Web 页面传输（明文）
HTTPS安全超文本传输协议443加密的 Web 传输
FTP文件传输协议21文件上传/下载
SMTP简单邮件传输协议25发送电子邮件
POP3邮局协议第3版110接收电子邮件
DNS域名系统53域名→IP 地址解析
TCP传输控制协议—可靠的面向连接传输
UDP用户数据报协议—不可靠的无连接传输
⚠️ TCP vs UDP

TCP：可靠、有序、面向连接（如同打电话——先建立连接再通话）
UDP：不可靠、无序、无连接（如同寄明信片——直接发出不确认）
· TCP 用于网页浏览、文件传输等需要可靠性的场景
· UDP 用于视频直播、在线游戏等对速度要求高的场景

5信息安全与计算机病毒

5.1 计算机病毒

计算机病毒是一种恶意程序，具有传染性、隐蔽性、潜伏性、破坏性等特征。它可以通过电子邮件、U盘、网页下载等途径传播。

  • 蠕虫：自我复制并通过网络传播，消耗系统资源
  • 木马：伪装成正常程序，窃取用户信息
  • 勒索病毒：加密用户文件，要求支付赎金
  • 宏病毒：寄生于 Office 文档中

5.2 防火墙

防火墙是网络安全屏障，位于内部网络和外部网络之间，根据预设规则允许或阻止数据包的通过。它可以软件形式（如 Windows 防火墙）或硬件形式实现。

5.3 加密技术

  • 对称加密：加密和解密使用同一个密钥（如 AES、DES）
  • 非对称加密：使用公钥+私钥（如 RSA），公钥加密私钥解密
  • 哈希算法：不可逆的单向加密（如 MD5、SHA）

以下哪项不是计算机病毒的典型特征？
A传染性

✏️ 模拟题防火墙的作用
以下关于防火墙的描述，正确的是？
A防火墙可以防止所有病毒入侵
B防火墙是位于内外网络之间的安全屏障
C防火墙只能以硬件形式实现
D开启防火墙后计算机不会再感染病毒
✅ 正确答案：B
防火墙是内外网络之间的安全屏障，根据规则过滤数据包。但它不能防止所有病毒（A 错），可以是软件或硬件（C 错），开启后仍可能中病毒（D 错）。

✏️ 综合模拟网络+安全混合
以下说法中，正确的是？
AIPv4 地址为 64 位，IPv6 地址为 128 位
BHTTP 协议默认使用 443 端口
C防火墙可以完全防止计算机病毒入侵
DTCP 协议提供可靠的面向连接传输服务
✅ 正确答案：D
A 错——IPv4 是 32 位，IPv6 是 128 位。B 错——HTTP 是 80 端口，HTTPS 才是 443。C 错——防火墙不能完全防止病毒。D 正确——TCP 是可靠、面向连接的。
✏️ 综合模拟OSI 模型层级判断
在 OSI 七层模型中，路由器工作在哪一层？
A物理层
B数据链路层
C网络层
D传输层
✅ 正确答案：C
路由器工作在网络层（第三层），根据 IP 地址进行路由选择和转发。交换机工作在数据链路层（第二层），集线器工作在物理层（第一层）。

📌 本节课重点速查表

LAN<MAN<WAN 中国的顶级域名：.cn IPv4=32位，IPv6=128位
OSI 七层：物→链→网→传→会→表→应 TCP/IP 四层：网络接口→网际→传输→应用
IP=网际层，TCP/UDP=传输层 127.0.0.1 = 本机回环 病毒特征：传染/隐蔽/潜伏/破坏
