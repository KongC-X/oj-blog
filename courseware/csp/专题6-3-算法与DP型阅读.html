12023 阅读 — 质因数分解 & 格雷码

2023 年 CSP-J 阅读程序题包含两道算法型题目： 一是质因数分解（判断素数 + 分解质因数）， 二是格雷码（Gray Code）的递推生成。 这两题考查的是对基础算法代码流程的理解，适合手动模拟。

题一：质因数分解

2023 阅读 · 质因数分解代码
// 输入正整数 n，输出它的质因数分解结果 // 例如 n=12 → 输出 "2 2 3" #include <iostream> using namespace std; int main() { int n; cin >> n; for (int i = 2; i * i <= n; i++) { while (n % i == 0) { cout << i << " "; n /= i; } } if (n > 1) cout << n; return 0; }

代码分步模拟：n = 84

用手工模拟来理解这段代码的执行流程：

ii×i≤n?n%i==0?输出n 的新值说明
24≤84 ✅84%2=0 ✅242第 1 次除以 2
24≤42 ✅42%2=0 ✅221第 2 次除以 2
24≤21 ✅21%2≠0 ❌-21while 结束，i++
39≤21 ✅21%3=0 ✅37除以 3
39≤7 ❌--7循环结束
循环结束 → 判断 n=7 > 1 ✅，输出 7
模拟结果

输入 84，输出 "2 2 3 7"。
即 84 = 2 × 2 × 3 × 7 ✅

题二：格雷码（Gray Code）

2023 阅读 · 格雷码代码
// 输入 n，输出 Gray(n)（十进制表示） // Gray 码递推公式：Gray(n) = n xor (n >> 1) // 例如 n=3 → Gray(3) = 3 xor 1 = 2 #include <iostream> using namespace std; int gray(int n) { return n ^ (n >> 1); } int main() { int n; cin >> n; for (int i = 0; i < n; i++) cout << gray(i) << " "; return 0; }

代码分步模拟：n = 4

输出 gray(0) 到 gray(3)：

i二进制i>>1i xor (i>>1)gray(i) 十进制
00000000000
10010000011
20100010113
30110010102
n=4 时的输出（十进制）：0 1 3 2 二进制格雷码序列： 000 → 001 → 011 → 010 0 1 3 2
📝 真题 · 2023 · 阅读 格雷码 · 单选题
单选题：当输入为 5 时，程序输出序列中第 4 个数（即 gray(3)）是（ ）。
A 2
B 3
C 4
D 6
✅ 正确答案：A · 2
计算 gray(3)：

3 的二进制 = 011
3 >> 1 = 001（右移一位）
011 xor 001 = 010 = 十进制 2

完整序列（n=5）：
gray(0)=0, gray(1)=1, gray(2)=3, gray(3)=2, gray(4)=6
→ 输出：0 1 3 2 6

结论：选 A（2）。
📝 真题 · 2023 · 阅读 格雷码 · 单选题
单选题：输入 6，输出中最大的数是（ ）。
A 5
B 6
C 7
D 8
✅ 正确答案：C · 7
计算所有 gray(i)：

gray(0) = 0 xor 0 = 0
gray(1) = 1 xor 0 = 1
gray(2) = 2 xor 1 = 3
gray(3) = 3 xor 1 = 2
gray(4) = 4 xor 2 = 6
gray(5) = 5 xor 2 = 7

输出序列：0 1 3 2 6 7

最大值为 7，选 C。
规律：n 位的格雷码最大值是 2^(n-1)-1 还是...？实际上对于 n 位二进制，格雷码的取值范围是 0 到 2^n-1，但这里输入 n=6 表示输出 gray(0)~gray(5)，最大的是 gray(5)=7（3位二进制）。
📝 真题 · 2023 · 阅读 格雷码 · 判断题
判断题：对于任意正整数 n，gray(n) 一定小于 n。
A ✓ 正确
B ✗ 错误
✅ 正确答案：B · ✗ 错误
分析：Gray 码不一定小于原数，反例：

gray(2) = 2 xor 1 = 3 > 2
gray(4) = 4 xor 2 = 6 > 4
gray(5) = 5 xor 2 = 7 > 5

结论：gray(n) 可能大于 n，也可能小于 n。
gray(0)=0, gray(1)=1（相等）
gray(3)=2（小于）
gray(4)=6（大于）
所以 "一定小于" 是错误的。❌
正确答案为 B（错误）。

22024 阅读 2 — 爬楼梯最小花费 DP

2024 年 CSP-J 阅读第 2 题考查了经典的"爬楼梯最小花费"问题。 这是 CSP-J 初赛首次出现DP 类阅读程序题目，标志着初赛难度的提升。 解题关键是理解 DP 数组的索引对应关系和手动模拟填表。

2024 阅读 2 · 核心代码
// cost[i]：从第 i 级出发需支付的费用（0-indexed） // dp[i]：到达第 i 级的最小花费 int minCostClimbingStairs(vector<int>& cost) { int n = cost.size(); vector<int> dp(n + 1); dp[0] = 0; dp[1] = 0; for (int i = 2; i <= n; i++) { dp[i] = cost[i-1] + min(dp[i-1], dp[i-2]); } return dp[n]; }

手动填表模拟：cost = [1, 2, 3, 4, 5]

假设 cost = [1, 2, 3, 4, 5]（5 级楼梯），逐行模拟 DP 数组的填充：

icost[i-1]dp[i-2]dp[i-1]min(dp[i-1],dp[i-2])dp[i]=cost[i-1]+min说明
0----0边界：地面
1----0边界：可直接站在第 1 级
2cost[1]=20002从 0→2（cost[1]=2）或 1→2（cost[1]=2）
3cost[2]=30203从 1→3（3）或 2→3（2+3=5），选 1→3
4cost[3]=42326从 2→4（2+4=6）或 3→4（3+4=7），选 2→4
5cost[4]=53638从 3→5（3+5=8）或 4→5（6+5=11），选 3→5
dp 数组最终状态： i: 0 1 2 3 4 5 dp: [0] [0] [2] [3] [6] [8] ↑ ↑ ↑ ↑ dp[2]=2 dp[3]=3 dp[4]=6 dp[5]=8（最终答案）
模拟结论

dp[5] = 8，最优路径：地面(0级) → 1级(免费) → 3级(付cost[2]=3) → 5级(付cost[4]=5)，总花费 8。

真题精讲（2024 阅读 2）

📝 真题 · 2024 · 阅读 2 爬楼梯 DP · 判断题
判断题：若 cost 数组长度为 n，则 dp 数组大小为 n。
A ✓ 正确
B ✗ 错误
✅ 正确答案：B · ✗ 错误
分析：
代码中 vector<int> dp(n + 1)。
因为需要从 dp[0] 到 dp[n]，一共 n+1 个元素。
注意 n 级楼梯，顶点是第 n 级，dp 需要 index 0~n。
结论：dp 数组大小为 n+1，不是 n。❌
📝 真题 · 2024 · 阅读 2 爬楼梯 DP · 单选题
单选题：若 cost = [10, 15, 20]，程序输出为（ ）。
A 10
B 15
C 20
D 25
✅ 正确答案：B · 15
手动填表：cost = [10, 15, 20], n=3

dp[0] = 0
dp[1] = 0
dp[2] = cost[1] + min(dp[1], dp[0]) = 15 + 0 = 15
dp[3] = cost[2] + min(dp[2], dp[1]) = 20 + min(15, 0) = 20 + 0 = 20

路线：地面(0级)→第1级(免费)→第3级(付cost[2]=20)，总花费20？

等等！仔细检查：dp[3] = cost[2] + min(dp[2], dp[1]) = 20 + min(15, 0) = 20 + 0 = 20。
但 dp[3] = 20。

然而题目问的是程序输出即 dp[n]！n=3 → dp[3]=20。
所以答案是 20，选 C。

更正：上面的填表正确：dp[2]=15, dp[3]=20。
最优路线：地面→1级(免费)→3级(20)，共20。
或者：地面→2级(付15)→3级(付20)=35，更贵。
正确答案：C · 20

32025 阅读 2 — 排序去重 + 双指针 DP

2025 年 CSP-J 阅读第 2 题（模拟）考查了一种综合型算法阅读题： 先对数组排序去重，再用双指针 + DP 求解最长递增长度。
核心转移：ans[i] = ans[j] + 1（当满足某种条件时）。
这类题的特点是步骤多、逻辑链长，需要分阶段模拟。

模拟题 · 排序去重 + 双指针 DP 代码
// 给定数组 a，先排序去重，再用双指针 DP 求最长"相差≤2"的子序列长度 #include <iostream> #include <algorithm> #include <vector> using namespace std; int main() { int n; cin >> n; vector<int> a(n); for (int i = 0; i < n; i++) cin >> a[i]; sort(a.begin(), a.end()); // 去重 int m = 0; for (int i = 0; i < n; i++) { if (m == 0 || a[i] != a[m-1]) { a[m++] = a[i]; } } // a[0..m-1] 为排序去重后的数组 vector<int> ans(m, 1); int res = 1; for (int i = 0; i < m; i++) { for (int j = i-1; j >= 0 && a[i] - a[j] <= 2; j--) { ans[i] = max(ans[i], ans[j] + 1); } res = max(res, ans[i]); } cout << res << endl; return 0; }

分步模拟：输入 a = [3, 1, 4, 1, 5, 9, 2, 6, 4]

第 1 步：排序

原始: [3, 1, 4, 1, 5, 9, 2, 6, 4] 排序后: [1, 1, 2, 3, 4, 4, 5, 6, 9]

第 2 步：去重

m = 7，去重后数组 a[0..6] = [1, 2, 3, 4, 5, 6, 9]

状态定义：ans[i] 表示以 a[i] 结尾的、相邻元素相差 ≤2 的最长子序列长度。

真题精讲（2025 阅读 2 · 模拟）

📝 模拟 · 2025 · 阅读 2 排序去重 + 双指针 DP · 判断题
判断题：去重后的数组 a 中，任意两个相邻元素之差 ≥ 1。
A ✓ 正确
B ✗ 错误
✅ 正确答案：A · ✓ 正确
分析：
数组先排序后去重。排序后相同元素相邻；去重后相邻元素一定不同。
又因为数组是整数排序的，不同整数之间至少差 1。
结论：去重后相邻元素之差 ≥ 1 恒成立。✅ 正确。
📝 模拟 · 2025 · 阅读 2 排序去重 + 双指针 DP · 单选题
单选题：输入 n=6, a = [5, 2, 2, 8, 3, 1]，程序输出为（ ）。
A 3
B 4
C 5
D 6
✅ 正确答案：B · 4
分步模拟：

Step 1 · 排序：[1, 2, 2, 3, 5, 8]

Step 2 · 去重：
i=0: m=0 → a[0]=1, m=1
i=1: a[1]=2≠1 → a[1]=2, m=2
i=2: a[2]=2==a[1] → 跳过
i=3: a[3]=3≠2 → a[2]=3, m=3
i=4: a[4]=5≠3 → a[3]=5, m=4
i=5: a[5]=8≠5 → a[4]=8, m=5
→ 去重后 m=5, a=[1,2,3,5,8]

Step 3 · DP：
ans[0]=1 (a=1), res=1
i=1(a=2): j=0, 2-1=1≤2 → ans[1]=1+1=2, res=2
i=2(a=3): j=1, 3-2=1≤2 → ans[2]=2+1=3
    j=0, 3-1=2≤2 → ans[2]=max(3,1+1)=3, res=3
i=3(a=5): j=2, 5-3=2≤2 → ans[3]=3+1=4
    j=1, 5-2=3>2 ❌ 停止, res=4
i=4(a=8): j=3, 8-5=3>2 ❌ 停止, ans[4]=1

最终输出 res = 4，选 B。
最长子序列：1→2→3→5（相邻差≤2）或者 1→2→3→5。

✅ 正确答案：B · ✗ 错误
分析：
不去重时，重复元素会导致更多的遍历，但 ans[i] 的转移条件 a[i]-a[j] ≤ 2 在相同元素时差为 0 恒成立。
但 ans[i] = max(ans[i], ans[j] + 1)——对于相同值，连续的相同元素会使 ans 递增：
  如果 a=[1,1,1]，不去重则：
  ans[0]=1
  ans[1]=max(1, 1+1)=2
  ans[2]=max(1, 2+1)=3
  输出 3。
而去重后 a=[1]，输出 1。
所以去重后结果可能会变小而非"一定会变大"。
结论：说法错误。❌ 实际上不去重结果往往更大。

42025 阅读 3 — LCS 最长公共子序列

最长公共子序列（LCS）是 DP 的经典二维问题。 在 CSP-J 初赛中，LCS 的考点集中在DP 表格的手动模拟和特殊条件优化。 当序列 a 严格递增时，LCS 可转化为最长递增子序列（LIS），将复杂度从 O(n²) 降到 O(n log n)。

LCS 标准 DP 代码
// dp[i][j] 表示 a[0..i-1] 与 b[0..j-1] 的 LCS 长度 int lcs(vector<int>& a, vector<int>& b) { int n = a.size(), m = b.size(); vector<vector<int>> dp(n+1, vector<int>(m+1, 0)); for (int i = 1; i <= n; i++) { for (int j = 1; j <= m; j++) { if (a[i-1] == b[j-1]) dp[i][j] = dp[i-1][j-1] + 1; else dp[i][j] = max(dp[i-1][j], dp[i][j-1]); } } return dp[n][m]; }

手动填表模拟：a = [1, 3, 5], b = [1, 2, 3, 4, 5]

1 初始化边界：dp[0][j]=0, dp[i][0]=0（空序列的 LCS 长度为 0）
2 dp[1][1]：a[0]=1 == b[0]=1 → dp[1][1] = dp[0][0] + 1 = 1
3 dp[1][2]：a[0]=1 ≠ b[1]=2 → dp[1][2] = max(dp[0][2]=0, dp[1][1]=1) = 1
4 dp[1][3]：a[0]=1 ≠ b[2]=3 → max(0,1) = 1（直到此处，dp[1][j] 全为 1）
5 dp[2][3]：a[1]=3 == b[2]=3 → dp[2][3] = dp[1][2] + 1 = 2
6 dp[3][5]：a[2]=5 == b[4]=5 → dp[3][5] = dp[2][4] + 1 = 3
模拟结果

dp[3][5] = 3，LCS 为 [1, 3, 5]（即 a 本身是 b 的子序列），长度为 3。

a 递增时转 LIS 优化

⭐ 核心技巧：当 a 递增且无重复时，LCS → LIS

定理：如果序列 a 严格递增，那么 a 和 b 的 LCS 等价于：
  1. 将 b 中每个元素替换为它在 a 中的位置索引（如果不在 a 中则忽略）
  2. 对得到的索引序列求 LIS（最长递增子序列）

原因：因为 a 递增，a 中元素的索引顺序和值大小顺序一致。
在 b 中找 a 的子序列，等价于在 b 中找递增的 a 索引序列。

LIS 标准代码
// 求序列 arr 的最长递增子序列长度（O(n log n) 贪心+二分） int lis(vector<int>& arr) { vector<int> tail; for (int x : arr) { auto it = lower_bound(tail.begin(), tail.end(), x); if (it == tail.end()) tail.push_back(x); else *it = x; } return tail.size(); }
📌 例子：a = [2, 4, 6, 8]（递增），b = [6, 2, 8, 4, 6, 8]
将 b 中元素替换为在 a 中的位置：6→2, 2→0, 8→3, 4→1, 6→2, 8→3 → 索引序列 [2, 0, 3, 1, 2, 3]
求 LIS → 最长递增子序列长度为 3（[0, 2, 3] 或 [0, 1, 3] 等），所以 LCS = 3。
