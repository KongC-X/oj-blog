1DP完善程序特征识别

动态规划（DP）是 CSP-J 完善程序最常考察的算法类型之一。 从2022年到2025年，每年至少有一道完整程序题是DP类型。 快速识别DP程序的三大特征，是高效解题的第一步。

1.1 一维DP vs 二维DP

看数组定义就能快速区分：

一维DP特征

数组定义：int f[N] 或 int dp[N]
典型递推：f[i] = f[i-1] + f[i-2]（斐波那契）
              dp[i] = max(dp[i-1] + a[i], a[i])（最大子段和）
典型题：爬楼梯、斐波那契、最大子段和、最长上升子序列
填空重点：初始边界（f[0]/f[1]）、递推式写法、循环起始值

二维DP特征

数组定义：int dp[N][M]
典型递推：dp[i][j] = min(dp[i-1][j]+1, dp[i][j-1]+1, dp[i-1][j-1]+cost)
              dp[i][j] = dp[i-1][j-1] + dp[i-1][j]（杨辉三角）
典型题：编辑距离、杨辉三角、数字三角形、0/1背包
填空重点：二维边界初始化、双层循环范围、状态转移方程

1.2 递推关系识别

DP程序的核心就是递推关系。识别递推关系的类型，能帮你快速定位填空位置：

递推类型典型公式应用场景挖空位置
累加型 f[i] = f[i-1] + f[i-2] 斐波那契、爬楼梯 运算符（+）或下标（-1, -2）
取最值型 dp[i] = max(dp[i-1]+a[i], a[i]) 最大子段和、LIS max/min函数参数
组合型 dp[i][j] = dp[i-1][j-1] + dp[i-1][j] 杨辉三角、组合数 递推式中两个子问题的下标
最小代价型 dp[i][j] = min(dp[i-1][j]+1, dp[i][j-1]+1, dp[i-1][j-1]+c) 编辑距离 三种操作的代价表达式
选择型 dp[j] = max(dp[j], dp[j-w[i]]+v[i]) 0/1背包 内层循环方向、下标偏移

1.3 边界条件

DP程序的边界条件是填空的热门位置。常见的模式：

  • 一维DP边界：f[0] = 0、f[1] = 1（斐波那契）；f[1] = 1（爬楼梯）
  • 二维DP第一行/列：编辑距离中 dp[i][0] = i、dp[0][j] = j
  • 二维DP对角线/边：杨辉三角中 dp[i][1] = 1、dp[i][i] = 1
  • 循环起始值：一维从 i=2 开始、二维从 i=1/j=1 或 i=3/j=2 开始
🧠 DP完善程序"三步判断法"

第一步：看数组 — 几维的dp数组？一维还是二维？
第二步：看边界 — 初始化了几行几列？初值是多少？
第三步：看循环 — 循环从几到几？内层循环的边界条件是什么？

口诀："数组维度定方向，边界初值先看透，循环范围不跨界，递推公式是核心。"

2编辑距离 DP（2022/2023 完善2原题）

编辑距离（Edit Distance）是 CSP-J 2022年 和 2023年 连续两年作为完善程序第2题考察。 题目要求计算将字符串 a 转换为字符串 b 所需的最少操作次数。 允许的操作有3种：

三种操作定义

① 插入（Insert）：在 a 中插入一个字符，花费 1
② 删除（Delete）：从 a 中删除一个字符，花费 1
③ 替换（Replace）：将 a 中的一个字符替换成另一个，花费 1

等价操作角度：也可以理解为对 a[1..i] 进行操作使其变为 b[1..j]。

2.1 DP状态定义与递推公式

状态定义：dp[i][j] 表示 a[1..i] 转换到 b[1..j] 的编辑距离
边界条件：
  • dp[i][0] = i：把 a[1..i] 全部删除，需要 i 次
  • dp[0][j] = j：在空串中插入 b[1..j]，需要 j 次
递推公式：

递推公式

如果 a[i] == b[j]：
  dp[i][j] = dp[i-1][j-1]（末尾字符相同，不需要额外操作）

如果 a[i] != b[j]：
  dp[i][j] = min(
    dp[i-1][j] + 1,  ← 删除 a[i]（删完后 a[1..i-1] 变成 b[1..j]）
    dp[i][j-1] + 1,  ← 在 a 中插入 b[j]（插入后 a[1..i] 变成 b[1..j-1]）
    dp[i-1][j-1] + 1  ← 将 a[i] 替换为 b[j]
  )

以 a = "cat"（n=3）、b = "car"（m=3）为例，手动模拟编辑距离的DP填表过程：

初始表格（边界）
j 0 1 2 3 '' c a r i=0 '' 0 1 2 3 i=1 c 1 ? ? ? i=2 a 2 ? ? ? i=3 t 3 ? ? ?

第一行：dp[0][j] = j，表示从空串到 b[1..j] 需要插入 j 次
第一列：dp[i][0] = i，表示从 a[1..i] 到空串需要删除 i 次

逐格计算
dp[1][1]: a[1]=c, b[1]=c → 相等 → dp[1][1]=dp[0][0]=0 dp[1][2]: a[1]=c, b[2]=a → 不等 → min(dp[0][2]+1=3, dp[1][1]+1=1, dp[0][1]+1=2) = 1 dp[1][3]: a[1]=c, b[3]=r → 不等 → min(dp[0][3]+1=4, dp[1][2]+1=2, dp[0][2]+1=3) = 2 dp[2][1]: a[2]=a, b[1]=c → 不等 → min(dp[1][1]+1=1, dp[2][0]+1=3, dp[1][0]+1=2) = 1 dp[2][2]: a[2]=a, b[2]=a → 相等 → dp[2][2]=dp[1][1]=0 dp[2][3]: a[2]=a, b[3]=r → 不等 → min(dp[1][3]+1=3, dp[2][2]+1=1, dp[1][2]+1=2) = 1 dp[3][1]: a[3]=t, b[1]=c → 不等 → min(dp[2][1]+1=2, dp[3][0]+1=4, dp[2][0]+1=3) = 2 dp[3][2]: a[3]=t, b[2]=a → 不等 → min(dp[2][2]+1=1, dp[3][1]+1=3, dp[2][1]+1=2) = 1 dp[3][3]: a[3]=t, b[3]=r → 不等 → min(dp[2][3]+1=2, dp[3][2]+1=2, dp[2][2]+1=1) = 1
最终结果
j 0 1 2 3 '' c a r i=0 '' 0 1 2 3 i=1 c 1 0 1 2 i=2 a 2 1 0 1 i=3 t 3 2 1 1

结果：cat → car 的编辑距离为 1（将 t 替换为 r 即可）

3杨辉三角形 DP（2025 完善1原题）

杨辉三角形是 2025 年 CSP-J 完善程序第1题的考点。 程序用二维DP数组生成杨辉三角形并输出。

3.1 杨辉三角形数学性质

杨辉三角（Pascal's Triangle）每一行是二项式系数。核心性质：

  • 每行第一个和最后一个数都是 1：dp[i][1] = dp[i][i] = 1
  • 中间每个数等于它左上方 + 右上方（或上一行两个相邻数之和）：dp[i][j] = dp[i-1][j-1] + dp[i-1][j]
  • 从第3行开始才有中间元素（i ≥ 3 时，j 从 2 到 i-1）
杨辉三角 DP 结构
行1: 1 行2: 1 1 行3: 1 2 1 行4: 1 3 3 1 行5: 1 4 6 4 1 蓝色 = 边界（dp[i][1] = dp[i][i] = 1） 绿色 = 递推（dp[i][j] = dp[i-1][j-1] + dp[i-1][j]）

3.2 手动填表推导

以 n=5 为例，手动模拟杨辉三角 DP 的完整填表过程：

Step 1：初始化（i=1, i=2）
i=1: dp[1][1] = 1 i=2: dp[2][1] = 1, dp[2][2] = 1
Step 2：递推计算（i=3 到 i=5）
i=3: j=2: dp[3][2] = dp[2][1] + dp[2][2] = 1 + 1 = 2 dp[3][1]=1, dp[3][3]=1 i=4: j=2: dp[4][2] = dp[3][1] + dp[3][2] = 1 + 2 = 3 j=3: dp[4][3] = dp[3][2] + dp[3][3] = 2 + 1 = 3 dp[4][1]=1, dp[4][4]=1 i=5: j=2: dp[5][2] = dp[4][1] + dp[4][2] = 1 + 3 = 4 j=3: dp[5][3] = dp[4][2] + dp[4][3] = 3 + 3 = 6 j=4: dp[5][4] = dp[4][3] + dp[4][4] = 3 + 1 = 4 dp[5][1]=1, dp[5][5]=1
最终二维DP表
i\j 1 2 3 4 5 1 1 2 1 1 3 1 2 1 4 1 3 3 1 5 1 4 6 4 1

蓝色 = 边界初值（每行首尾均为1）
绿色 = 递推结果（左上方+右上方之和）
输出第5行：1 4 6 4 1

4爬楼梯 / 斐波那契 DP

爬楼梯问题是 CSP-J 的经典DP入门题型，也是 2024 年阅读程序第2题的题型扩展。 问题是：上到第 n 级台阶，每次可以跨 1 级或 2 级台阶，求有多少种不同的走法。

爬楼梯 DP 模型

状态定义：f[i] 表示上到第 i 级台阶的走法数
边界：f[1] = 1（1级台阶只有1种走法：1步）；f[2] = 2（2级台阶有2种：1+1 或 2）
递推：f[i] = f[i-1] + f[i-2]（到第 i 级可以从 i-1 跨1步，或从 i-2 跨2步）

与斐波那契数列的关联：爬楼梯的 f[n] 就是斐波那契数列的第 n+1 项（f[0]=0, f[1]=1 时）

2024阅读程序第2题扩展

2024年阅读程序第2题考察了斐波那契变体。完善程序可能在此基础上增加条件：

  • 每次可以跨 1、2 或 3 级：f[i] = f[i-1] + f[i-2] + f[i-3]
  • 带"不能连续跨2级"的限制
  • 求最少步数（用 min 而不是 +）

📝 真题 · 特征识别 考：一维/二维DP判断 + 边界 + 递推
以下哪个特征最可能表明一个完善程序题是"动态规划"类型？

A 变量名包含 l、r、mid，循环条件为 l < r
B 函数内部调用自身，有递归终止条件
C 定义了 dp 或 f 数组，有明确的初值设置和递推式循环
D 有 swap 交换操作和双层 for 循环
✅ 正确答案：C
分析：

DP程序的三个核心特征：
  • 数组命名：使用 dp、f 等作为DP数组
  • 边界初值：有明确的初始条件（如 f[0]=0, f[1]=1）
  • 递推循环：循环体内有状态转移公式（如 f[i]=f[i-1]+f[i-2]）

其他选项分析：
  • A：l、r、mid 是二分查找的典型特征
  • B：函数自调用是递归的典型特征
  • D：双层 for + swap 是排序算法的典型特征（如冒泡排序）

💡 DP完善程序判断口诀：
"dp f 是名字，边界初值先设置，循环递推是核心，三种特征就识别。"

  • 到第 i 级可以从 i-1 跨 1 步，或从 i-2 跨 2 步。

逐空分析：

空 ①：dp[i][0] 的初值
  • dp[i][0] 表示 a[1..i] 变成空串的操作次数。
  • 需要删除 i 个字符 → dp[i][0] = i。
  • 所以选 i（A）。

空 ②：dp[0][j] 的初值
  • dp[0][j] 表示空串变成 b[1..j] 的操作次数。
  • 需要插入 j 个字符 → dp[0][j] = j。
  • 所以选 j（B）。

空 ③：字符相等时的递推
  • 当 a[i] == b[j] 时，末尾字符无需操作。
  • 编辑距离等于 dp[i-1][j-1]（前面部分的结果）。
  • 所以选 dp[i-1][j-1]（C）。

空 ④ 和 ⑤：注释标注验证
  • 题目代码已将三个操作正确标注：
  • dp[i-1][j] + 1 = 删除 a[i]（注释"删除"正确）
  • dp[i][j-1] + 1 = 在 a 中插入 b[j]（注释"插入"正确）
  • dp[i-1][j-1] + 1 = 替换 a[i] 为 b[j]（注释"替换"正确）
  • ④ 和 ⑤ 选 无需修改（注释已正确标注）

🧠 2022 vs 2023 差异点

2022年：考察了 dp[i][0] 和 dp[0][j] 的边界初始化，以及 if(a[i]==b[j]) 分支下的递推

逐空分析：

空 ①：每行第一个元素
  • 杨辉三角每行第一个数是 1。
  • 所以 dp[i][1] = 1，选 B。

空 ②：每行最后一个元素
  • 杨辉三角每行最后一个数也是 1。
  • 所以 dp[i][i] = 1，选 B。

空 ③：外层循环起始值
  • 第 1 行只有 1 个元素（已通过边界赋值）。
  • 第 2 行两个元素都是边界 1（也已赋值）。
  • 从 第 3 行开始才有中间元素需要递推。
  • 所以 i 从 3 开始，选 C。

空 ④：内层循环边界
  • 第 i 行有 i 个元素，边界（j=1 和 j=i）已赋值。
  • 中间元素：j 从 2 到 i-1。
  • 所以条件为 j < i（即 j <= i-1），选 A。
  • 如果选 j <= i，会覆盖边界值（把 1 改成错误值）。

空 ⑤：核心递推式
  • 杨辉三角性质：当前位置 = 左上方 + 右上方。
  • 左上方 = dp[i-1][j-1]，右上方 = dp[i-1][j]。
  • 所以 dp[i][j] = dp[i-1][j-1] + dp[i-1][j]，选 A。

✏️ 模拟题 · 最大子段和 DP 考：状态转移 + 全局最值更新
以下程序求数组 a 的最大子段和（Kadane算法）。请选择填入空缺处的正确代码：

int n, a[100]; cin >> n; for (int i = 0; i < n; i++) cin >> a[i]; int cur = a[0]; // 以当前元素结尾的最大子段和 int ans = a[0]; // 全局最大子段和 for (int i = 1; i < n; i++) { cur = max(a[i], ①); ans = max(ans, ②); } cout << ans;
—— ① ——
A cur + a[i]
B cur
C ans + a[i]
D a[i-1]
—— ② ——
A cur
B a[i]
C ans + a[i]
D cur + ans
✅ 正确答案：① A (cur + a[i]) · ② A (cur)
分析：

Kadane 算法的核心思想：

状态定义：
  • cur = 以当前位置结尾的最大子段和
  • ans = 全局最大子段和（历史所有 cur 的最大值）

空 ①：cur 的状态转移
  • 对于 a[i]，有两种选择：
    - 自己开始一个新子段：a[i]
    - 接在之前的子段后面：cur + a[i]
  • 取两者较大值：cur = max(a[i], cur + a[i])
  • 所以选 cur + a[i]（A）。

空 ②：全局最值更新
  • 每轮用当前 cur 更新全局最大值。
  • ans = max(ans, cur)。
  • 所以选 cur（A）。

手动模拟验证（a=[-2,1,-3,4,-1,2,1,-5,4]）：
初始: cur=a[0]=-2, ans=-2 i=1 (a=1): cur=max(1, -2+1)=1, ans=max(-2,1)=1 i=2 (a=-3): cur=max(-3, 1-3)=-2, ans=max(1,-2)=1 i=3 (a=4): cur=max(4, -2+4)=4, ans=max(1,4)=4 i=4 (a=-1): cur=max(-1, 4-1)=3, ans=max(4,3)=4 i=5 (a=2): cur=max(2, 3+2)=5, ans=max(4,5)=5 i=6 (a=1): cur=max(1, 5+1)=6, ans=max(5,6)=6 i=7 (a=-5): cur=max(-5, 6-5)=1, ans=max(6,1)=6 i=8 (a=4): cur=max(4, 1+4)=5, ans=max(6,5)=6 最大子段和 = 6（子段 [4,-1,2,1] = 6）✅
✏️ 模拟题 · 数字三角形 DP 考：二维DP边界 + 自底向上递推 + 取最值
以下程序求解数字三角形从顶部到底部的最大路径和（每次可向下或右下走）。请选择填入空缺处的正确代码：

int n, a[105][105]; cin >> n; for (int i = 1; i <= n; i++) for (int j = 1; j <= i; j++) cin >> a[i][j]; // 自底向上DP for (int i = n①; i >= 1; i②) { for (int j = 1; j ③ i; j++) { a[i][j] += max(a[i④][j], a[i⑤][j+1]); } } cout << a[1][1];

分析：

整体思路：自底向上DP
  • 从倒数第2行开始，逐行向上计算。
  • 每个位置加上下一行相邻两个位置的较大值。

空 ①：外层循环起始
  • 自底向上：从 n-1 行开始（最后一行不用算）。
  • 所以 i = n - 1，选 A（-1）。

空 ②：循环变量变化
  • 从下往上，i 递减。
  • 所以用 i--，选 B。

空 ③：内层循环边界
  • 第 i 行有 i 个元素，j 从 1 到 i。
  • 所以 j <= i，选 B。

空 ④ 和 ⑤：下一行的两个相邻位置
  • 当前位置 (i, j) 的下一行同列 = a[i+1][j]。
  • 当前位置 (i, j) 的下一行列+1 = a[i+1][j+1]。
  • 所以 ④ 和 ⑤ 都选 +1（A）。

✏️ 模拟题 · 0/1背包 DP 考：一维DP压缩 + 内层循环方向
以下程序用一维DP数组求解0/1背包问题（n个物品，容量W）。请选择填入空缺处的正确代码：

int n, W; cin >> n >> W; int w[105], v[105]; for (int i = 1; i <= n; i++) cin >> w[i] >> v[i]; int dp[1005] = {{0}}; for (int i = 1; i <= n; i++) { for (int j = W; j ① w[i]; j②) { dp[j] = max(dp[j], dp[j ③ w[i]] ④ v[i]); } } cout << dp[W];

✅ 正确答案：① A (>=) · ② B (--) · ③ B (-) · ④ A (+)
分析：

0/1背包一维DP的核心要点：

空 ① 和 ②：内层循环条件和方向
  • 0/1背包要求每个物品最多选一次。
  • 一维DP必须逆序遍历容量（从大到小），否则同一物品会被重复使用（变成完全背包）。
  • 所以 j 从 W 到 w[i]，递减：
    - ① 选 >=（当 j >= w[i] 时说明还能装下当前物品）
    - ② 选 --（从大到小遍历）

空 ③：背包容量减少
  • 放入物品 i，容量减少 w[i]。
  • 所以 dp[j - w[i]]，选 -。

空 ④：价值增加
  • 放入物品 i，价值增加 v[i]。
  • 所以 dp[j - w[i]] + v[i]，选 +。

标准转移方程：
  dp[j] = max(dp[j], dp[j-w[i]] + v[i])

⚠️ 易错点提醒

为什么必须逆序？
如果正序（j 从小到大），dp[j-w[i]] 可能已经包含了当前物品 i，即"重复选了同一个物品"， 这就不符合 0/1 背包每个物品只能选一次的要求了。

口诀："0/1背包逆序走，完全背包正序行。物品在外容在内，一维切记方向定。"

📝 真题改编 · LIS 考：二维LIS DP + 取最值
以下程序求数组 a 的最长上升子序列长度（经典 LIS，O(n²) DP）。请选择填入空缺处的正确代码：

int n, a[1005]; cin >> n; for (int i = 1; i <= n; i++) cin >> a[i]; int dp[1005], ans = 0; for (int i = 1; i <= n; i++) { dp[i] = ①; // 每个位置至少长度为1 for (int j = 1; j ② i; j++) { if (a[j] ③ a[i]) { dp[i] = max(dp[i], dp[j] ④ 1); } } ans = max(ans, dp[i]); } cout << ans;

✅ 正确答案：① B (1) · ② A (<) · ③ A (<) · ④ A (+)
分析：

空 ①：dp[i] 初值
  • 每个位置的元素本身构成一个长度为 1 的上升子序列。
  • 所以 dp[i] = 1，选 B。

空 ②：内层循环范围
  • 对于每个 a[i]，检查它前面的元素 a[1..i-1]。
  • 所以 j 从 1 到 i-1，条件为 j < i，选 A。

空 ③：上升条件判断
  • "上升"子序列要求 a[j] < a[i]（严格递增）。
  • 所以选 <，A。
  • 如果题目要求"非递减"则用 <=。

空 ④：长度累加
  • 如果可以接在 a[j] 后面，则长度为 dp[j] + 1。
  • 所以选 +，A。

完整转移方程：
  dp[i] = max(dp[i], dp[j] + 1) 当 a[j] < a[i]

📌 DP完善程序"三看一填"速查表

以下总结了 DP 完善程序题的标准解题流程和各模型要点， 考试中遇到 DP 类型时按此流程操作，可系统性地快速解题。

步骤名称操作内容常见遗漏点
1 看数组 判断几维DP：一维（f/dp[N]）还是二维（dp[N][M]），确定维度有助于定位填空 忽略数组大小定义，无法确定循环范围
2 看边界 找初始化代码：dp[0]=?, dp[i][0]=?, dp[0][j]=? 边界值决定算法正确性 混淆 0 和 1 的初始值；忘记某些边界

4 填递推 根据模型填状态转移：min/max/?运算符，?下标偏移，?加减常数 递推式中下标写错（-1/-2混淆）
