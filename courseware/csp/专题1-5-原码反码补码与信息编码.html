1原码 · 反码 · 补码

计算机用固定位数的二进制表示整数。对有符号整数，有三种编码方式：原码、反码、补码。
现代计算机都使用补码来存储和运算有符号整数。

1.1 三种编码对比（以 8 位为例）

编码正数规则负数规则+5（8位）−5（8位）
原码符号位0+数值位符号位1+数值位0000010110000101
反码与原码相同原码符号位不变，数值位取反0000010111111010
补码与原码相同反码 + 10000010111111011

1.2 补码速算口诀

⚡ 负数补码速算：从低位找第一个1

给定原码（符号位1+数值），求补码的快速方法：
① 从最右边（最低位）开始向左找
② 遇到第一个 1 之前，数字保持不变
③ 这个 1 本身也保持不变
④ 它左边的所有位取反

示例：原码 10101000 → 从右找第一个1在倒数第4位 → 11011000（补码）

📐 补码转原码（求负数的绝对值）

补码 → 原码的方法是一样的：取反后加1，或再次"从低位找第一个1"，结果相同。
示例：8位补码 11111011：
取反得 10000100 → 加1得 10000101 = −5，或者反向算：−128+64+32+16+8+0+2+1 = −5 ✓

1.3 为什么计算机用补码？

💡 补码的三大优势

① 统一加减法：减法可以用加法实现（X−Y = X+(−Y的补码)），CPU 不用单独设计减法电路
② 没有 +0 和 −0：原码有 00000000（+0）和 10000000（−0），补码中 0 只有一种表示 00000000
③ 负数多一个：8位补码可表示 −128~127（原码只有 −127~127）

📝 真题与模拟练习

📝 真题 · 模块训练原码特点
以下关于原码、反码和补码的描述中，正确的是？
A正数的原码、反码、补码相同
B负数的原码和补码相同
C补码中 0 有两种表示
D原码中 0 只有一种表示
✅ 正确答案：A
正数的原码、反码、补码完全相同。负数的三种编码不同。补码中 0 只有一种表示 00000000，原码有 +0 和 −0 两种。
✏️ 模拟题求负数的补码
十进制数 −5 的 8 位二进制补码是？
A10000101
B11111010
C11111011
D00000101
✅ 正确答案：C
+5 原码 00000101 → 取反得反码 11111010 → 加 1 得补码 11111011。快速法：从右找第一个 1（在 5 的二进制 101 的最低位 1），左边取反。
✏️ 模拟题补码还原为十进制
8 位补码 10101011 表示的十进制数是？
A−83
B−85
C−43
D−86
✅ 正确答案：B
补码 10101011 → 取反 01010100 → 加1得 01010101 = 64+16+4+1=85 → 加负号得 −85。

2ASCII 编码

ASCII（American Standard Code for Information Interchange，美国信息交换标准代码）是使用最广泛的字符编码方案。用 7 位二进制（实际存储占 1 字节 = 8 位，最高位为 0）表示 128 个字符。

💡 ASCII 核心规律：
· 数字 0~9：ASCII 码 48~57（十六进制 0x30~0x39）
· 大写字母 A~Z：ASCII 码 65~90（十六进制 0x41~0x5A）
· 小写字母 a~z：ASCII 码 97~122（十六进制 0x61~0x7A）
· 大写和小写之间相差 32（A=65, a=97）
💡 考点速记

① 数字 0 的 ASCII 码是 48，字母 A 是 65，字母 a 是 97（这三个数必背）
② 大小写转换：大写 + 32 = 小写（如 'A'=65, 'a'=65+32=97）
③ ASCII 码占 1 字节（实际只用 7 位，最高位为 0）
④ 扩展 ASCII（8 位）可表示 256 个字符

📝 真题与模拟练习

📝 真题 · 模块训练ASCII 码值比较
在 ASCII 码表中，以下字符的码值从小到大排列正确的是？
A'0' < 'A' < 'a'
B'A' < 'a' < '0'
C'a' < 'A' < '0'
D'0' < 'a' < 'A'
✅ 正确答案：A
数字 0=48, 大写 A=65, 小写 a=97。所以 '0' < 'A' < 'a'。数字 < 大写 < 小写，这个规律要记住。
✏️ 模拟题大小写字母 ASCII 差值
已知大写字母 'B' 的 ASCII 码值为 66，则小写字母 'b' 的 ASCII 码值是？
A97
B98
C99
D100
✅ 正确答案：B
大写 + 32 = 小写。'B'=66，'b'=66+32=98。同理：'A'=65+32=97 就是 'a'。

3汉字编码

汉字数量远多于 ASCII 的 128 个字符，因此需要使用多字节编码方案。

编码方案字节数特点
GB23122 字节1980 年发布，收录 6763 个常用汉字
GBK2 字节GB2312 的扩展，收录 2 万+汉字，兼容 GB2312
Unicode1~4 字节全球统一编码，包含所有语言的字符。UTF-8/UTF-16 是具体实现
UTF-81~4 字节变长编码，兼容 ASCII（英文字符仍占 1 字节）
💡 考点提示

· 汉字编码通常用 2 字节表示一个汉字（GB2312/GBK）
· Unicode 是字符集（规定每个字符的编号），UTF-8 是编码方式（规定如何存储）
· UTF-8 的一个汉字通常占 3 字节（部分生僻字占 4 字节）

📝 真题与模拟练习

✏️ 模拟题汉字编码字节数
在 GB2312 编码中，一个汉字通常占用多少个字节？
A1 字节
B2 字节
C3 字节
D4 字节
✅ 正确答案：B
GB2312 和 GBK 都使用 2 字节（16 位）表示一个汉字。ASCII 字符在 GB2312 中仍用 1 字节表示。
✏️ 模拟题Unicode 与 UTF-8
关于 Unicode 和 UTF-8，以下说法正确的是？
AUnicode 和 UTF-8 是同一个概念
BUnicode 是字符集，UTF-8 是它的编码实现方式
CUTF-8 中英文字符占 2 字节
DUnicode 不兼容 ASCII
✅ 正确答案：B
Unicode 是字符集（给每个字符分配一个数字编号），UTF-8 是编码方式（将这个编号转换为二进制存储）。UTF-8 兼容 ASCII（英文字符仍占 1 字节）。

4布尔代数基础

布尔代数（逻辑代数）是计算机运算的理论基础。它的变量只有两个值：true（真/1）和 false（假/0）。

运算C++ 运算符规则口诀
与 (AND)&&全真才真，一假即假1∧1=1，其他=0
或 (OR)||全假才假，一真即真0∨0=0，其他=1
非 (NOT)!取反：真变假，假变真¬1=0，¬0=1
异或 (XOR)^相同为假，不同为真1⊕0=1，0⊕0=0
⚠️ 2025 最新考法：布尔代数等价性

2025 年第 7 题考了一个新题型——判断逻辑表达式是否等价。解法是用真值表，对 a、b、c 的 8 种取值分别验证两边的结果是否一致。

📐 常用公式

· A && (B || C) = (A && B) || (A && C)（分配律）
· A || (B && C) = (A || B) && (A || C)（分配律）
· !(A && B) = !A || !B（德摩根律）
· !(A || B) = !A && !B（德摩根律）

📝 真题与模拟练习

📝 真题 · 2025 · 第 7 题布尔代数等价性
假设 a,b,c 都是布尔变量，逻辑表达式 (a && b) || (!c && a) 的值与下列哪个表达式不始终相等？
Aa && (b || !c)
B(a || !c) && (b || !c) && (a || a)
Ca && (!b || c)
D!(!a || !b) || (a && !c)
✅ 正确答案：C
用真值表验证。当 a=1, b=0, c=0 时：原式 = (1∧0)∨(1∧1) = 0∨1=1；而 C 选项 = 1∧(1∨0) = 1，和其他选项不同。实际上需要遍历所有 8 种情况，C 与目标不等价。
✏️ 模拟题真值表练习
当 a=true, b=false, c=false 时，表达式 (a && b) || !c 的值是？
Atrue
Bfalse
C不确定
D编译错误
✅ 正确答案：A
代入：(true && false) || !false = false || true = true。
✏️ 模拟题德摩根律应用
!(a && b) 等价于以下哪个表达式？
A!a && !b
B!a || !b
C!a && b
Da || b
✅ 正确答案：B
德摩根律：!(a && b) = !a || !b（"与"变"或"，各自取反）。口诀："拆括号，与变或，各自取反"。

📝综合模拟

以下题目综合了原码反码补码、信息编码和布尔代数多个知识点。

✏️ 综合模拟编码知识综合判断
以下说法中，不正确的是？
AASCII 码中，大写字母 'A' 的码值比小写字母 'a' 小 32
B正数的原码、反码、补码是相同的
CGB2312 编码中一个汉字占用 2 个字节
D8 位补码中，−128 的补码是 11111111
✅ 正确答案：D
−128 的 8 位补码是 10000000，不是 11111111。11111111 是 −1 的补码（−1 的原码 10000001 → 反码 11111110 → 补码 11111111）。
✏️ 综合模拟信息编码综合
一个用 GB2312 编码存储的文本文件，内容为"Hello 世界"，文件大小最接近多少字节？
A9 字节
B11 字节
C13 字节
D15 字节
✅ 正确答案：B
"Hello" 5 个英文字母 = 5 字节（ASCII 1 字节/个），"世界" 2 个汉字 = 4 字节（GB2312 2 字节/个），加上空格 = 1 字节，一共约 11 字节。注意英文字母不占 2 字节。
