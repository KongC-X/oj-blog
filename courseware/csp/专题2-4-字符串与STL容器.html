1string 类

string 是 C++ 标准库提供的字符串类，比 C 风格字符数组更方便、更安全。需要头文件 <string>。

#include <string> using namespace std; string s1;              // 空字符串 string s2 = "Hello";  // 直接赋值 string s3(5, 'A');    // "AAAAA"（5个A） s2 += " World";     // 字符串拼接 → "Hello World" s2 = s2 + '!';       // 可以用 + 连接 char（2025第9题）
方法功能示例
s.length()返回字符串长度"ABC".length()=3
s.size()同 length()"ABC".size()=3
s[i]访问第 i 个字符（下标从0）s[0]='H'
s.substr(pos, len)取子串"Hello".substr(1,3)="ell"
s.find(str)查找子串，返回位置或 npos"Hello".find("ll")=2
s + t连接字符串"A"+"B"="AB"
📌 2025 年第 9 题原题

string s="Hello"; s = s + '!'; 正确！
string 重载了 + 运算符，可以连接 string 和 char（B 选项正确）。
其他选项：A string 长度可动态变化，C length() 和 size() 返回相同值，D string 不一定以 '\0' 结尾。

📝 配套练习

📝 真题 · 2025 · 第 9 题string 类——连接操作
下列关于 C++ string 类的说法，正确的是？
Astring 对象的长度在创建后不能改变
B可以使用 + 运算符直接连接 string 和 char
Clength() 和 size() 可能返回不同值
Dstring 必须以 '\0' 结尾，且计入 length()
✅ 正确答案：B
string 重载了 +，可以连接 string 和 char。A 错——string 长度动态可变；C 错——两者相同；D 错——string 不要求 '\0' 结尾。
✏️ 模拟题substr 用法
string s="ABCDEF"; cout << s.substr(2,3);
输出是什么？
A"ABC"
B"BCD"
C"CDE"
D"DEF"
✅ 正确答案：C
substr(2,3)：从下标 2 开始取 3 个字符。s[2]='C', s[3]='D', s[4]='E'，输出 "CDE"。
✏️ 模拟题find 的返回值
string s="banana"; int pos=s.find("na");
pos 的值是？
A2
B4
C0
D-1
✅ 正确答案：A
"banana" 中 "na" 第一次出现的位置：b[0], a[1], n[2]a[3]，所以 pos=2。如果找不到，返回 string::npos（通常为 -1 的无符号形式）。

2string vs char[]

对比维度stringchar a[]
长度动态可变固定大小
连接+ 直接连接strcat 函数
比较== != > < 直接比较strcmp 函数
赋值s1 = s2; 直接赋值strcpy 函数
'\0'结尾不必须必须（标志字符串结束）
安全性越界检查（at()方法）不检查越界
// string 转 char* string s = "Hello"; const char *cstr = s.c_str();  // 获取 C 风格字符串 // char[] 转 string char arr[] = "World"; string t = arr;  // 直接赋值即可
💡 输入技巧

· cin >> s; 读到空白字符（空格/换行）停止
· getline(cin, s); 读取一整行（含空格）
· 如果 cin >> 和 getline 混用，注意清空缓冲区！

📝 配套练习

✏️ 模拟题char[] 的'\0'结尾
char s[10]="Hi"; cout << strlen(s);
输出是什么？
A2
B10
C3
D不确定
✅ 正确答案：A
strlen 统计的是'\0'之前的字符数。"Hi" 实际存储为 'H','i','\0',...，所以 strlen 返回 2（不包含结尾的 '\0'）。
✏️ 模拟题getline 用法
要读取包含空格的整行输入，应该使用？
Acin >> s
Bscanf("%s", s)
Cgetline(cin, s)
Dgets(s)
✅ 正确答案：C
getline(cin, s) 读取一整行（包括中间的空格）。cin >> s 和 scanf 遇到空格就停止。

3STL 容器

3.1 vector（动态数组）

#include <vector> vector<int> v;              // 空vector v.push_back(10);             // 末尾添加元素 cout << v[0] << v.size();  // 访问和大小 v.pop_back();                // 删除末尾元素

3.2 stack（栈）

#include <stack> stack<int> st; st.push(1);  // 入栈 st.top();    // 查看栈顶元素 st.pop();    // 出栈（不返回元素） st.empty();  // 是否为空 st.size();   // 元素个数

3.3 queue（队列）

#include <queue> queue<int> q; q.push(1);  // 入队（队尾） q.front();  // 查看队头元素 q.back();   // 查看队尾元素 q.pop();    // 出队（队头）

3.4 map（键值对）

#include <map> map<string, int> mp; mp["Alice"] = 90;  // 插入/修改 cout << mp["Alice"];  // 查找：输出 90 // 遍历 map（C++11 范围 for） for (auto &p : mp)     cout << p.first << ": " << p.second;
📌 stack 和 queue 的注意事项

· stack::pop() 和 queue::pop() 不返回被删除的元素！必须先 top() 或 front() 再 pop()
· 2021-2022 年真题多次考察 stack 和 queue 的操作特性

📝 配套练习

✏️ 模拟题vector 的 push_back
vector<int> v; v.push_back(3); v.push_back(1); v.push_back(4); cout << v[1];
输出是什么？
A3
B1
C4
D不确定
✅ 正确答案：B
依次 push_back 后，v = {3, 1, 4}。v[1] 是第2个元素=1。
✏️ 模拟题stack 操作
stack<int> s; s.push(5); s.push(2); s.pop(); cout << s.top();
输出是什么？
A2
B5
C不确定
D0
✅ 正确答案：B
push(5)→[5], push(2)→[5,2], pop() 删除栈顶 2→[5]。top() 返回 5。

4algorithm 常用函数

头文件 <algorithm> 提供了大量常用算法函数，初赛中常出现在阅读程序里。

函数功能示例
sort(a, a+n)对数组/vector 排序（默认升序）sort(v.begin(), v.end())
max(a, b)返回较大值int m = max(3, 5); // 5
min(a, b)返回较小值int m = min(3, 5); // 3
swap(a, b)交换两个变量的值swap(x, y);
reverse(a, a+n)反转区间reverse(v.begin(), v.end())
unique(a, a+n)去重（要求已排序，返回新结尾）int m = unique(a,a+n)-a;
// sort 排序 int a[] = {3,1,4,1,5,9}; sort(a, a+6);  // 数组排序 vector<int> v = {3,1,4}; sort(v.begin(), v.end());  // vector 排序

📝 配套练习

✏️ 模拟题sort 排序结果
int a[]={4,2,5,1,3}; sort(a, a+5); cout << a[2];
输出是什么？
A1
B2
C3
D4
✅ 正确答案：C
排序后数组为 {1,2,3,4,5}。a[2] 是第3个元素=3（下标从0开始）。
✏️ 模拟题max 和 min
cout << max(10, min(20, 15));
输出是什么？
A10
B15
C20
D编译错误
✅ 正确答案：B
先算内部的 min(20,15)=15，再算外层的 max(10,15)=15。

📝综合模拟

以下题目综合了字符串、STL 容器和 algorithm 函数。

✏️ 综合模拟字符串+算法混合
string s="cba"; sort(&s[0], &s[0]+3); cout << s;
输出是什么？
A"cba"
B"abc"
C"bac"
D编译错误
✅ 正确答案：B
&s[0] 获取 string 内部字符数组的起始地址，sort 对其进行排序。'c','b','a' 升序排列为 'a','b','c'，s 变成 "abc"。
✏️ 综合模拟STL 综合阅读题
map<string,int> m; m["a"]=1; m["b"]=2; m["a"]=3; cout << m["a"] << m["b"];
输出是什么？
A12
B32
C31
D21
✅ 正确答案：B
m["a"]=1, m["b"]=2, 然后 m["a"]=3（覆盖了旧值1）。所以 m["a"]=3, m["b"]=2，输出 32。
