一个32位无符号整数可以表示的最大值，最接近下列哪个选项？（ ）

B 3 × 10¹⁰
C 2 × 10⁹
D 2 × 10¹⁰
查看解析
答案：A
32位无符号整数的最大值是 2³² − 1 = 4294967295，约等于 4.29×10⁹，最接近 4×10⁹。
知识点：数据表示，无符号整数范围。
真题 位运算 第 2 题
在C++中，执行 int x = 255; cout << (x & (x - 1)); 后，输出的结果是？（ ）
A 255
B 254
C 128
D 0
查看解析
答案：B
x & (x - 1) 的作用是将最低位的1置0。255的二进制是 11111111，减去1后为 11111110，按位与后得到 11111110，即254。
知识点：位运算，x & (x-1) 清除最低位1。
真题 递归 第 3 题
函数calc(n)的定义如下，则calc(5)的返回值是多少？（ ）
int calc(int n) { if (n <= 1) return 1; if (n % 2 == 0) return calc(n / 2) + 1; else return calc(n - 1) + calc(n - 2); }
A 5
B 6
C 7
D 8
查看解析
答案：B
calc(1) = 1
calc(2) = calc(1) + 1 = 2
calc(3) = calc(2) + calc(1) = 2 + 1 = 3
calc(4) = calc(2) + 1 = 2 + 1 = 3
calc(5) = calc(4) + calc(3) = 3 + 3 = 6
知识点：递归函数调用栈分析。
真题 树 第 4 题
用5个权值10,12,15,20,25构造哈夫曼树，该树的带权路径长度是多少？（ ）
A 176
B 186
C 196
D 206
查看解析
答案：B
哈夫曼树构造过程：
- 合并10和12（22），序列变为 15,20,22,25
- 合并15和20（35），序列变为 22,25,35
- 合并22和25（47），序列变为 35,47

知识点：哈夫曼树，带权路径长度计算。

真题 组合 第 6 题
从5位男生和4位女生中选出4人组成一个学习小组，要求学习小组中男生和女生都有。有多少种不同的选择方法？（ ）
A 126
B 121
C 120
D 100
查看解析
答案：C

真题 布尔 第 7 题
假设a,b,c都是布尔变量，逻辑表达式 (a && b) || (!c && a) 的值与下列哪个表达式不始终相等？（ ）
A a && (b || !c)
B (a || !c) && (b || !c) && (a || a)
C a && (!b || c)
D !(!a || !b) || (a && !c)
查看解析
答案：C
通过真值表验证，选项C（a && (!b || c)）与其他选项不等价。原式 = a && (b || !c)，而C是 a && (!b || c)，在 a=1,b=1,c=0 时原式为1，C为0。
知识点：布尔代数，逻辑表达式等价性。

真题 传参 第 10 题
考虑以下C++函数：
void solve(int &a, int b) { a = a + b; b = a - b; a = a - b; } int main() { int x = 5, y = 10; solve(x, y); }
在main函数调用solve后，x和y的值分别是？（ ）
A 5, 10
B 10, 5
C 10, 10
D 5, 5
查看解析
答案：C
参数b是传值，修改不影响实参y。a是传引用，交换操作后a变为10（x变成10），b变为5（但不影响y）。最终 x=10, y=10。

程序1：求互质三元组个数（gcd + 三重循环）

程序说明

本程序使用辗转相除法（递归 gcd）统计 1~n 中两两互质的三元组 (i,j,k) 个数，要求 i<j<k。考察递归 gcd 实现、边界条件分析、循环执行逻辑。

// gcd递归函数 inline int gcd(int a, int b) { if (b == 0) return a; return gcd(b, a % b); } int main() { int n; scanf("%d", &n); int ans = 0; for (int i = 1; i <= n; ++i) for (int j = i + 1; j <= n; ++j) for (int k = j + 1; k <= n; ++k) if (gcd(i, j) == 1 && gcd(j, k) == 1 && gcd(i, k) == 1) ++ans; printf("%d\n", ans); return 0; }
阅读 判断 第 16 题
当输入为2时，程序并不会执行第16行的判断语句。（ ）
查看解析
答案：√（正确）
当n=2时，最内层循环k从j+1开始。即使j=2时，k从3开始，但n=2，所以k>n，循环不会执行。确实不会执行到第16行的if判断。
知识点：循环边界条件分析。
阅读 判断 第 17 题
将第16行中的 "&& gcd(i,k)=1" 删去不会影响程序运行结果。（ ）
查看解析
答案：×（错误）
删去后程序只检查两两互质中的两对（(i,j)和(j,k)），而不是三元组全部互质，结果会不同（会多统计不互质的三元组）。
知识点：互质概念，条件判断的完整性。
阅读 判断 第 18 题
当输入的n≥3时，程序总是输出一个正整数。（ ）
查看解析
答案：√（正确）
当n≥3时，至少存在一组互质三元组(1,2,3)，输出一定为正整数。
知识点：互质判断，最小情况存在性。
阅读 选择 第 19 题
将第7行的 "gcd(b, a%b)" 改为 "gcd(a, a%b)" 后，程序可能出现的问题是（ ）
A 输出的答案大于原答案
B 输出的答案小于原答案
C 程序有可能陷入死循环
D 可能发生整型溢出问题
查看解析
答案：C
修改后当b≠0时，递归调用gcd(a, a%b)。由于gcd的第一个参数始终为a不变，而a%b可能永远不为0（例如a=6, b=4时，a%b=2，然后gcd(6,2)再算a%b=0才结束），更严重的是当a与b不满足特定关系时可能导致无限递归。
知识点：递归函数设计，gcd的递归终止条件。
阅读 选择 第 20 题
当输入为8时，输出为（ ）
A 37
B 42
C 35
D 25
查看解析

n=8时，通过计算可得互质三元组个数为25。对于较小的n，可以枚举i,j,k的全部分组进行验证。

程序2：数组处理（排序去重 + 双指针DP）

程序说明

本程序先将数组排序去重，再用双指针DP求满足相邻元素差值 ≤ k 的最少分段数。ans[i] = ans[j] + 1 是关键转移方程，j是满足 a[i]−a[j+1]≤k 的最大位置。

int n, k; int a[200007]; int ans[200007]; scanf("%d%d", &n, &k); for (int i = 1; i <= n; ++i) scanf("%d", &a[i]); std::sort(a + 1, a + n + 1); n = std::unique(a + 1, a + n + 1) - a - 1; for (int i = 1, j = 0; i <= n; ++i) { for (; j < i && a[i] - a[j + 1] > k; ++j); ans[i] = ans[j] + 1; } printf("%d\n", ans[n]);
阅读 判断 第 22 题
当输入为 "3 1 3 2 1" 时，输出结果为2。（ ）
查看解析
答案：√（正确）
输入 n=3,k=1,a=[3,2,1]。排序去重后数组为[1,2,3]，k=1时三段分别为[1],[2],[3]？实际上 a[i]−a[j+1]≤1 的约束：ans[1]=1, ans[2]=ans[1]+1=2, 最终ans[3]=2。输出2。验证：{1,2}差≤1, {3}单独一段，共2段。
知识点：排序去重 + 双指针DP模拟。
阅读 判断 第 23 题
假设输入的n为正整数，输出的答案一定小于等于n，大于等于1。（ ）
查看解析
答案：√（正确）
ans数组记录的是分段数。最少1段（所有元素在一段内），最多n段（每个元素单独一段，即去重后每个元素一段）。输出ans[n]满足 1 ≤ ans[n] ≤ n。
知识点：DP结果的范围分析。
阅读 判断 第 24 题
将第14行的 "n=std::unique(a+1,a+n+1)-a-1;" 删去后，有可能出现与原本代码不同的输出结果。（ ）
查看解析
答案：×（错误）
（删除去重行后输出结果不变）
由于j不会回头，走过的将不会重复计算。sort之后重复元素在一起，不会被多次计算。因此去重操作在此算法中不影响结果。
知识点：unique去重的作用域与双指针算法的关系。
阅读 选择 第 25 题
执行第18行代码 ans[i] = ans[j] + 1 时，一定满足的条件不包括（ ）
A j ≤ i
B a[i] − a[j] > k
C j ≤ n
D a[j] < a[i]
查看解析
答案：B
内层while循环确保 a[i]−a[j+1]≤k，但j指向的是满足该条件的最后一个位置的后一个，因此 a[i]−a[j] 可能≤k也可能>k，不一定满足 a[i]−a[j]>k。
知识点：双指针算法的循环不变量。
阅读 选择 第 26 题
当输入的 n=100、k=2、a={1,2,...,100} 时，输出为（ ）
A 34
B 100
C 50
D 33

每段最大最小值差不超过2，即每段最多包含3个数（如{1,2,3}、{4,5,6}等）。100÷3向上取整 = 34段。

阅读 选择 第 27 题
误删去第13行的 "std::sort(a+1, a+n+1);" 程序有可能出现的问题有（ ）
A 输出的答案比原本答案更大
B 输出的答案比原本答案更小
C 出现死循环行为
D 以上均可能发生
查看解析
答案：D
未排序数组会导致双指针算法完全失效。因为算法依赖数组的有序性来保证 a[i]≥a[j]。无序时结果不可预测——可能更大、更小、甚至死循环（j指针可能错误移动）。
知识点：排序对双指针算法的必要性。

程序3：动态规划求最长公共子序列（LCS）

程序说明

本程序使用经典二维DP求两个序列a和b的最长公共子序列长度。特别地，当a是严格递增序列（如1,2,...,n）时，LCS问题转化为求b的LIS（最长上升子序列）。

int f[5007][5007]; int a[5007], b[5007]; int n; scanf("%d", &n); for (int i = 1; i <= n; ++i) scanf("%d", &a[i]); for (int i = 1; i <= n; ++i) scanf("%d", &b[i]); for (int i = 1; i <= n; ++i) { for (int j = 1; j <= n; ++j) { f[i][j] = std::max(f[i][j], std::max(f[i-1][j], f[i][j-1])); if (a[i] == b[j]) f[i][j] = std::max(f[i][j], f[i-1][j-1] + 1); } } printf("%d\n", f[n][n]);
阅读 判断 第 28 题
输入 "4 1 2 3 4 1 3 2 2" 时输出为2。（ ）
查看解析
答案：√（正确）
a=[1,2,3,4]，b=[1,3,2,2]。最长公共子序列为{1,2}或{1,3}，长度为2。
知识点：LCS的模拟计算。
阅读 判断 第 29 题
对于所有 1≤i,j≤n，都有 f[i][j] ≤ f[n][n]。（ ）
查看解析
答案：√（正确）
f[n][n] 是全局最优解，而所有子问题的解 f[i][j] 都是在更短的序列上求得的，不可能超过完整序列的最优解。
知识点：DP最优子结构性质。
阅读 判断 第 30 题
删去第18行不影响程序运行结果。（ ）
查看解析
答案：×（错误）
第18行是状态转移的核心 f[i][j] = max(f[i][j], f[i-1][j-1]+1)，负责匹配相等字符时的递推。删去后无法正确计算最长公共子序列。
知识点：LCS状态转移方程。
阅读 选择 第 31 题
输出的答案满足的性质有（ ）
A 小于等于 n
B 大于等于 0
C 不一定大于等于1
D 以上均是
查看解析
答案：D
最长公共子序列长度在[0, n]范围内。可能为0（两个序列没有公共元素），也可能≤n。A、B、C都正确。
知识点：LCS长度的取值范围。
阅读 选择 第 32 题
如果在循环前加上 std::sort(a+1, a+n+1); std::sort(b+1, b+n+1)，则答案会（ ）
A 变大或不变
B 变小或不变
C 一定变大
D 不变
查看解析
答案：A
排序后可能增加公共元素的数量（原本不匹配的位置因排序变得匹配），因此答案可能变大，但不会变小（排序不会减少公共元素）。
知识点：排序对LCS结果的影响。

完善程序题共2个程序，每空3分，共30分。需要理解算法整体逻辑后填入正确的代码片段。2025年考察了RLE行程编码解码和Boyer-Moore多数派投票算法。

完善1：字符串解码（行程长度编码 RLE）

题目描述

"行程长度编码"（Run-Length Encoding）是一种无损压缩算法。压缩规则：如果字符连续出现N次（N≥2），编码为"字符+数字N"；如果只出现1次，编码为字符本身。
例如：编码 "a3b2c" 解码后为 "aaabbc"（3个a，2个b，1个c）。

// RLE 解码程序 string z; cin >> z; string s = ""; for (int i = 0; i < z.length(); ) { char ch = z[i]; if (① && isdigit(z[i + 1])) { i++; int count = 0; while (i < z.length() && isdigit(z[i])) { count = ②; i++; } for (int j = 0; j < ③; ++j) s += ch; } else { s += ④; ⑤; } }
完善 第 33 题（①处）
①处应填（ ）
A i < z.length()
B i - 1 >= 0
C i + 1 < z.length()
D isdigit(z[i])
查看解析
答案：C
需要检查下一个字符 z[i+1] 是否为数字（表示当前字符是重复的）。在访问 z[i+1] 之前必须确保 i+1 不越界，即 i+1 < z.length()。
知识点：字符串边界检查。
完善 第 34 题（②处）
②处应填（ ）
A count + (z[i] - '0')
B count * 10 + (z[i] - '0')
C z[i] - '0'
D count + 1
查看解析
答案：B
将连续的数字字符转换为整数，需要处理多位数。每读取一个新数字字符，就将当前count乘以10（左移一位），再加上当前数字字符对应的整数值。这是典型的"秦九韶算法"。
知识点：多位数解析，字符转整数。
完善 第 35 题（③处）
③处应填（ ）
A count - 1
B count
C 10
D z[i] - '0'
查看解析
答案：B
循环输出 count 次字符 ch。j从0开始，小于count正好输出count次。
知识点：循环控制与边界。
完善 第 36 题（④处）
④处应填（ ）
A z[i+1]
B ch
C z.back()
D (char)z[i] + 1
查看解析
答案：B
else分支处理字符只出现一次的情况（下一位不是数字）。直接将当前字符ch追加到结果字符串s中。
知识点：字符串拼接操作。
完善 第 37 题（⑤处）
⑤处应填（ ）

B i = i + 2
C i++
D // 不执行任何操作
查看解析
答案：C
for循环的括号中没有写i++语句，需要在循环体内手动移动索引。在else分支处理完单字符后，将i增加1，移动到下一个待处理的字符位置。
知识点：循环索引控制。

完善2：精明与糊涂（Boyer-Moore 多数派投票）

题目描述

有N个人，分为两类：精明人（永远正确判断他人）和糊涂人（判断不可靠）。精明人严格占多数（k > N/2）。
通过函数 query(i,j) 让第i个人判断第j个人——返回true表示"精明人"，false表示"糊涂人"。
目标：利用"精明人占多数"的优势，通过"候选者消除法"找出一个肯定的精明人。

// Boyer-Moore 多数派投票算法 int N; bool query(int i, int j); int main() { cin >> N; int candidate = 0; int count = ①; for (int i = 1; i < N; ++i) { if (②) { candidate = i; count = 1; } else { if (③) { ④; } else { count++; } } } cout << ⑤ << endl; return 0; }
完善 第 38 题（①处）
①处应填（ ）
A 0
B 1
C N
D -1
查看解析
答案：B
初始化count为1，表示将第0个人作为初始候选人（candidate=0），并假设他是精明人，初始"支持计数"为1。
知识点：Boyer-Moore投票算法初始化。
完善 第 39 题（②处）
②处应填（ ）
A count < 0
B count == 1
C count == 0
D query(candidate, i) == false
查看解析
答案：C
当 count 变为0时，当前候选人被完全"抵消"，需要将当前这个人i设为新的候选人，并将计数重置为1。这是Boyer-Moore算法的核心：count=0时更换候选人。
知识点：多数派算法中的候选人更换条件。
完善 第 40 题（③处）
③处应填（ ）
A query(candidate, i) == false
B query(i, candidate) == true
C query(candidate, i) == false && query(i, candidate) == false
D query(candidate, i) == false || query(i, candidate) == false
查看解析
答案：A
当候选人candidate判断当前人i是"糊涂人"（query返回false）时，意味着这两个人中至少有一个是糊涂人，因此可以安全地将这对人"抵消"——减少候选人的支持计数。
知识点：多数派算法的抵消条件。
完善 第 41 题（④处）
④处应填（ ）
A count--
B break
C count++
D candidate = i
查看解析
答案：A
当候选人判断当前人是糊涂人时，两者抵消，减少候选人的支持计数count。
知识点：多数派算法的抵消操作。
完善 第 42 题（⑤处）
⑤处应填（ ）
A N - 1
B count
C candidate
D 0
查看解析
答案：C
输出最终找到的候选者。经过多轮抵消后，最终留下的候选人candidate必定属于占多数的精明人。
知识点：Boyer-Moore多数派算法的正确性——消除阶段后留下的候选者必定是多数派。
