1递归三要素

递归是函数直接或间接调用自身的编程技术。 任何一个正确的递归函数都必须满足以下三个要素：

要素说明类比（俄罗斯套娃）
① 终止条件递归必须在某个条件成立时停止，不再调用自身最小的娃娃——不能再拆了
② 递归调用函数在自身内部调用自身，且参数向终止条件逼近打开外层娃娃，里面藏着一个更小的
③ 返回值每层递归将结果返回给上一层，最终得到答案从最小的娃娃开始，一层层拼回去
💡 三要素检查清单（写递归时逐条检查）

1️⃣ 有没有终止条件？ 如果没有，会无限递归 → 栈溢出。
2️⃣ 递归调用是否向终止条件逼近？ 参数是否在变小/变简单？
3️⃣ 返回值是否正确组合？ 每层的结果要能够拼出最终答案。

标准模板

// 递归函数通用模板 返回值类型 func(参数) {   // ① 终止条件   if (满足终止条件) return 直接结果;      // ② 递归调用（参数向终止条件逼近）   return 对 func(缩小后的参数) 进行组合; }

2手动模拟递归 · 调用栈跟踪

手动模拟递归是 CSP-J 初赛核心技能。阅读程序题中，递归函数常以选择题形式出现， 要求你不运行代码就推导出结果。核心方法是跟踪调用栈的变化。

调用栈（Call Stack）原理

  • 每次调用函数，系统将当前函数的参数、局部变量、返回地址压入栈。
  • 遇到递归调用 → 先压栈，执行被调函数。
  • 被调函数返回 → 弹出栈帧，继续执行原来的函数。
  • 「先调用的后返回」 — 栈的 LIFO（后进先出）特性。

演示：模拟 fact(4) 的调用栈

int fact(int n) {   if (n <= 1) return 1;   // 终止条件   return n * fact(n - 1);   // 递归调用 }
📌 调用栈跟踪（从 fact(4) 开始）
调用 fact(4)：n=4，未到达终止条件 → 调用 fact(3)：n=3，未到达终止条件 → 调用 fact(2)：n=2，未到达终止条件 → 调用 fact(1)：n=1，到达终止条件 ← fact(1) 返回 1 ← fact(2) = 2 × 1 = 2 ← fact(3) = 3 × 2 = 6 ← fact(4) = 4 × 6 = 24 最终结果：fact(4) = 24
💡 手动模拟口诀："先递后归，压栈前进，到终点就回溯"——从顶层开始不断压栈调用， 到底层触发终止条件后，逐层返回结果。
⚠️ 初赛常见错误

❌ 把递归调用和乘法顺序搞反——n * fact(n-1) 是先递归再乘法，不是先乘再递归。
❌ 忘记终止条件或条件判断错误。
❌ 混淆不同递归分支的返回值。

3经典递归模式

3.1 阶乘（Factorial）

int fact(int n) {   if (n <= 1) return 1;   return n * fact(n - 1); }

规律：fact(n) = n × (n-1) × (n-2) × ... × 1
时间复杂度：O(n) — 递归调用 n 次
空间复杂度：O(n) — 调用栈深度 n

3.2 斐波那契数列（Fibonacci）

int fib(int n) {   if (n <= 1) return n;   // fib(0)=0, fib(1)=1   return fib(n - 1) + fib(n - 2);   // 两个分支递归 }

递归树：fib(5) 的计算过程如下：

fib(5) ┌──────────┴──────────┐ fib(4) fib(3) ┌─────┴─────┐ ┌─────┴─────┐ fib(3) fib(2) fib(2) fib(1) ┌───┴───┐ ┌───┴───┐ ┌───┴───┐ fib(2) fib(1) fib(1) fib(0) fib(1) fib(0) ┌───┴───┐ fib(1) fib(0)

时间复杂度：O(2n) — 每一层调用数翻倍，大量重复计算。
空间复杂度：O(n) — 最大递归深度为 n。
考点：初赛常考 fib(n) 的调用次数，如 fib(5) 需要多少步。

3.3 汉诺塔（Tower of Hanoi）

void hanoi(int n, char a, char b, char c) {   if (n == 1) {     cout << a << "->" << c << endl; // 直接移动     return;   }   hanoi(n - 1, a, c, b);     // ① n-1 个从 A 经 C 移到 B   cout << a << "->" << c << endl; // ② 最大盘从 A 移到 C   hanoi(n - 1, b, a, c);     // ③ n-1 个从 B 经 A 移到 C }

思路：要把 n 个盘子从 A 移到 C，先把 n-1 个移到 B，移最大的，再移 n-1 个到 C。
步数：2n - 1（考试必记！）
时间复杂度：O(2n)
考点：2024完善程序第2题就考察了汉诺塔递归的实现。

🎯 汉诺塔三步口诀

"A→B（借助C），A→C，B→C（借助A）"
记法：先把上面的一坨挪到辅助柱，再把最大的挪到目标柱，最后把辅助柱上的挪回目标柱。

4递归复杂度分析入门

4.1 时间复杂度分析方法

对于递归函数，时间复杂度 = 递归调用次数 × 每次调用的工作量。

递归模式递推关系时间复杂度示例
线性递归T(n) = T(n-1) + O(1)O(n)fact(n)
双分支递归T(n) = T(n-1) + T(n-2) + O(1)O(2n)fib(n)
分治递归T(n) = 2T(n/2) + O(1)O(n)汉诺塔
二分递归T(n) = T(n/2) + O(1)O(log n)二分查找
📌 典型复杂度记忆技巧

线性递归：一层一层往下走 = O(n) — 像排队
斐波那契：每次分裂成两个 = O(2n) — 像细胞分裂
汉诺塔：T(n) = 2T(n-1) + 1 → T(n) = 2n - 1
二分递归：每次规模减半 = O(log n) — 像翻字典

4.2 空间复杂度分析方法

递归的空间复杂度 = 最大递归深度 × 每帧空间。
递归深度就是调用栈最多同时存在的栈帧数量。

递归函数最大深度空间复杂度
fact(n)nO(n)
fib(n)nO(n)
hanoi(n)nO(n)
💡 注意：fib(n) 虽然时间复杂度是 O(2n)，但空间复杂度只有 O(n)， 因为同一时刻栈中只有一条路径的栈帧（深度最多 n）。

5递归 vs 迭代

对比维度递归迭代（循环）
代码简洁性逻辑清晰，尤其适合树、分治等问题通常代码较长，但逻辑直接
性能函数调用有额外开销（压栈、弹栈）无函数调用开销，效率高
内存需要 O(深度) 的栈空间通常只需要 O(1) 额外空间
适用场景树遍历、分治、回溯、DFS线性遍历、累加、简单循环
栈溢出风险深度过大时会发生栈溢出无此风险

互相转换示例：阶乘

递归版 vs 迭代版

递归版：fact(n) = n ≤ 1 ? 1 : n * fact(n-1)
迭代版：

int fact_iter(int n) {   int res = 1;   for (int i = 2; i <= n; i++) res *= i;   return res; }
💡 考试建议：读程序题遇到递归，就在草稿纸上画出调用栈或递归树。 千万不要试图在脑海里想象所有步骤——写出来！

6递归深度与栈溢出

递归深度：一次递归调用中，调用栈的最大层数。
栈溢出（Stack Overflow）：递归深度超过系统栈空间大小时发生，程序崩溃。

系统栈大小

  • C++ 默认栈空间约 1MB ~ 8MB（不同环境不同）。
  • 每帧约 几十字节，因此递归深度一般限制在 几万到十几万。
  • 在 CSP-J 中，数据规模通常较小（n ≤ 1000），但由于初赛是理论推导，重点考察递归的逻辑正确性而非栈溢出检测。
⚠️ 死循环递归的危险

如果递归函数没有终止条件或调用方向不是朝向终止条件， 会无限递归下去，最终导致栈溢出（程序崩溃）。

优化策略

  • 尾递归优化：如果递归调用是函数中最后一条语句且返回值直接返回， 部分编译器可以优化为迭代（CSP-J 不强制要求掌握，但了解可加深理解）。
  • 改迭代：把递归改写为循环（如用栈模拟）。
  • 记忆化：把已经算过的结果存下来，避免重复计算（如 fib 用数组存结果）。
🎯 记忆化优化斐波那契
int memo[100];  // 全局数组，初始化为 -1 int fib_memo(int n) {   if (n <= 1) return n;   if (memo[n] != -1) return memo[n];  // 已经算过   return memo[n] = fib_memo(n-1) + fib_memo(n-2); }

效果：时间复杂度从 O(2n) 降为 O(n)！
每个 n 只计算一次，之后直接从数组读取。

📝真题与模拟综合练习（共10题）

以下题目涵盖了 CSP-J 初赛中所有递归考点。每道题都包含手动模拟的分步演算过程， 请务必自己先推导再点击查看答案。

📝 真题 · 2021 · 第 13 题 奇数阶乘递归模拟
以下函数 solve(7) 的返回值是多少？
int solve(int n) {   if (n == 1) return 1;   return n * solve(n - 2); }
A 5040
B 105
C 35
D 7
✅ 正确答案：B · 105
调用栈逐步演算：

solve(7) → n=7，7≠1，进入递归：7 * solve(5)
  solve(5) → n=5，5≠1，进入递归：5 * solve(3)
    solve(3) → n=3，3≠1，进入递归：3 * solve(1)
      solve(1) → n=1，✅ 触发终止条件，返回 1
    ← solve(3) = 3 × 1 = 3
  ← solve(5) = 5 × 3 = 15
← solve(7) = 7 × 15 = 105

另一种方法直接算：solve(7) = 7 × 5 × 3 × 1 = 105

考点总结：
  • 终止条件：n == 1
  • 递归步进：n → n-2（每次减2，从奇数到下一个奇数）
  • 结果：奇数阶乘（只乘奇数）
📝 真题 · 2025 · 第 3 题 calc 双分支递归模拟
已知 calc(1) = 1，calc(2) = 2，
以下 calc(5) 的返回值是多少？
int calc(int n) {   if (n == 1 || n == 2) return n;   return calc(n - 1) + calc(n - 2); }
A 8
B 7
C 6
D 5
✅ 正确答案：C · 6
逐层模拟递归调用：

calc(5) = calc(4) + calc(3)

先计算 calc(4) = calc(3) + calc(2)：
  calc(3) = calc(2) + calc(1) = 2 + 1 = 3
  calc(2) = 2（终止条件）
  → calc(4) = 3 + 2 = 5

再计算 calc(3) = calc(2) + calc(1)：
  calc(2) = 2，calc(1) = 1
  → calc(3) = 2 + 1 = 3

最后：calc(5) = calc(4) + calc(3) = 5 + 3 = 6

calc(5) ├── calc(4) │ ├── calc(3) │ │ ├── calc(2)=2 │ │ └── calc(1)=1 │ └── calc(2)=2 └── calc(3) ├── calc(2)=2 └── calc(1)=1
注意：calc(5) = calc(4) + calc(3) = 5 + 3 = 6，答案选 C。
📝 真题 · 2024 · 阅读第 3 题 customFunction 参数变化跟踪
以下程序输入 5 4，输出是什么？
int customFunction(int a, int b) {   if (b == 0) return a;   return customFunction(a, b - 1) + a; } int main() {   int a, b; cin >> a >> b;   cout << customFunction(a, b); }
A 20
B 25
C 24
D 30
✅ 正确答案：B · 25
调用栈逐步演算（输入 a=5, b=4）：

customFunction 的语义：当 b 递减到 0 时返回 a，否则 customFunction(a, b-1) + a。
这实际上是递归实现乘法：a × b。

customFunction(5, 4)： b≠0 → 调用 customFunction(5, 3) + 5
  customFunction(5, 3)： b≠0 → 调用 customFunction(5, 2) + 5
    customFunction(5, 2)： b≠0 → 调用 customFunction(5, 1) + 5
      customFunction(5, 1)： b≠0 → 调用 customFunction(5, 0) + 5
        customFunction(5, 0)： ✅ b=0，触发终止条件 → 返回 5
      ← customFunction(5, 1) = 5 + 5 = 10
    ← customFunction(5, 2) = 10 + 5 = 15
  ← customFunction(5, 3) = 15 + 5 = 20
← customFunction(5, 4) = 20 + 5 = 25

验证：5 × 4 = 5 + 5 + 5 + 5 = 25 ✅

考点：这是一个用递归实现 a × b 的经典模式——
每次 b 减 1，累加一个 a，直到 b=0 时返回 a（即 a×1 的结果）。
注意每层调用的 a 值不变，变化的是 b。
📝 真题 · 2024 · 完善第 2 题（改编） 汉诺塔递归实现
汉诺塔问题中，将 4 个盘子从 A 柱移到 C 柱，最少需要移动多少次？
A 7
B 8
C 15
D 16
✅ 正确答案：C · 15
汉诺塔递归分析：

设移动 n 个盘子需要 H(n) 步。

递推关系：H(n) = 2 × H(n-1) + 1
解释：先把 n-1 个移到辅助柱，再移最大的，最后把 n-1 个移到目标柱。

逐层计算 H(4)：
H(1) = 1（直接移动）
H(2) = 2 × 1 + 1 = 3
H(3) = 2 × 3 + 1 = 7
H(4) = 2 × 7 + 1 = 15

公式：H(n) = 2n - 1
H(4) = 24 - 1 = 16 - 1 = 15

记忆口诀："2 的 n 次方减 1"——CSP-J 常考！
✏️ 模拟题 · 调用栈跟踪 阶乘递归手动模拟
fact(5) 的返回值是多少？
请写出逐步演算过程再选择。
int fact(int n) {   if (n <= 1) return 1;   return n * fact(n - 1); }
A 120
B 60
C 24
D 720
✅ 正确答案：A · 120
完整调用栈模拟：

fact(5) → 5 ≤ 1? No → 5 * fact(4)
  fact(4) → 4 ≤ 1? No → 4 * fact(3)
    fact(3) → 3 ≤ 1? No → 3 * fact(2)
      fact(2) → 2 ≤ 1? No → 2 * fact(1)
        fact(1) → 1 ≤ 1? ✅ Yes → 返回 1
      ← fact(2) = 2 × 1 = 2
    ← fact(3) = 3 × 2 = 6
  ← fact(4) = 4 × 6 = 24
← fact(5) = 5 × 24 = 120

调用栈深度变化：
第1步：压栈 fact(5)  栈：[fact(5)] 第2步：压栈 fact(4)  栈：[fact(5), fact(4)] 第3步：压栈 fact(3)  栈：[fact(5), fact(4), fact(3)] 第4步：压栈 fact(2)  栈：[fact(5), fact(4), fact(3), fact(2)] 第5步：压栈 fact(1)  栈：[fact(5), fact(4), fact(3), fact(2), fact(1)] 第6步：fact(1)=1，弹栈  栈：[fact(5), fact(4), fact(3), fact(2)] 第7步：fact(2)=2，弹栈  栈：[fact(5), fact(4), fact(3)] 第8步：fact(3)=6，弹栈  栈：[fact(5), fact(4)] 第9步：fact(4)=24，弹栈 栈：[fact(5)] 第10步：fact(5)=120，弹栈 栈：[]
验证：5! = 5×4×3×2×1 = 120 ✅
✏️ 模拟题 · 递归树 斐波那契调用次数统计
以下递归函数 fib(5) 的递归调用总次数是多少？
int fib(int n) {   if (n <= 1) return n;   return fib(n - 1) + fib(n - 2); }
A 8 次
B 15 次
C 9 次
D 10 次
✅ 正确答案：B · 15 次
注意：题目问的是"递归调用总次数"（包括初始调用 fib(5) 本身）。

递归树展开（每个节点代表一次函数调用）：
① fib(5) ├── ② fib(4) │ ├── ③ fib(3) │ │ ├── ④ fib(2) │ │ │ ├── ⑤ fib(1) → 终止 │ │ │ └── ⑥ fib(0) → 终止 │ │ └── ⑦ fib(1) → 终止 │ └── ⑧ fib(2) │ ├── ⑨ fib(1) → 终止 │ └── ⑩ fib(0) → 终止 └── ⑪ fib(3) ├── ⑫ fib(2) │ ├── ⑬ fib(1) → 终止 │ └── ⑭ fib(0) → 终止 └── ⑮ fib(1) → 终止
总计：15 次递归调用。

记忆公式：fib(n) 的总调用次数 = fib(n+1) × 2 - 1 的近似值，或直接记忆：
fib(5) = 15 次，fib(4) = 9 次，fib(3) = 5 次

规律：调用次数遵循 2×fib(n+1) - 1。
fib(6) = 8 → 调用次数 = 2×8 - 1 = 15 ✅
✏️ 模拟题 · 多出口条件 多终止条件递归
以下 f(10) 的输出是什么？
void f(int n) {   cout << n << " ";   if (n % 2 == 0) f(n / 2);   else if (n > 1) f(3 * n + 1); }
A 10 5 16 8 4 2 1
B 10 5 16 8 4 2
C 10 5 16 8 4 2 1 ...（无限循环）
D 10 5 16 8 4
✅ 正确答案：A · 10 5 16 8 4 2 1
逐步模拟：

f(10)：输出 10，10 是偶数 → 调用 f(5)
  f(5)：输出 5，5 不是偶数，但 5 > 1 → 调用 f(16)
    f(16)：输出 16，16 是偶数 → 调用 f(8)
      f(8)：输出 8，8 是偶数 → 调用 f(4)
        f(4)：输出 4，4 是偶数 → 调用 f(2)
          f(2)：输出 2，2 是偶数 → 调用 f(1)
            f(1)：输出 1，1 不是偶数且 1 ≤ 1 → 终止

输出序列：10 5 16 8 4 2 1

考点分析：这是著名的 Collatz 猜想（3n+1 问题）。注意：
  • 每次进入函数先输出再判断——所以输出包括 1
  • 两个分支：偶数除2，奇数乘3加1
  • 只有当 n 变成 1 且既不是偶数也不满足 n>1 时，递归终止
✏️ 模拟题 · 深度分析 递归深度计算与栈溢出判断
假设系统栈空间为 1MB，每个栈帧占用 64 字节，
以下哪个递归调用最可能发生栈溢出？
// 函数A：线性递归 void A(int n) { if (n>0) A(n-1); } // 函数B：双分支（n=40） int B(int n) { if (n<=1) return n; return B(n-1)+B(n-2); } // 函数C：n=30000 void C(int n) { if (n>0) C(n-1); } // 函数D：n=5000 int D(int n) { if (n==0) return 0; return n+D(n-1); }
A 函数A（n=10000）
B 函数B（n=40）
C 函数C（n=30000）
D 函数D（n=5000）
✅ 正确答案：C · 函数C（n=30000）
逐一分析最大递归深度与栈空间需求：

函数A（n=10000）：
线性递归，深度 = 10000
所需空间 = 10000 × 64 = 640,000 字节 ≈ 625KB ← 在 1MB 内 ✅

函数B（n=40）：
虽然是双分支（O(2n) 次调用），但最大深度 = 40
所需空间 = 40 × 64 = 2,560 字节 ← 远小于 1MB ✅

函数C（n=30000）：
线性递归，深度 = 30000
所需空间 = 30000 × 64 = 1,920,000 字节 ≈ 1.83MB ← 超过 1MB ❌

函数D（n=5000）：
线性递归，深度 = 5000
所需空间 = 5000 × 64 = 320KB ← 在 1MB 内 ✅

结论：函数C 的 n=30000，需要约 1.83MB 栈空间，超过系统限制，最可能栈溢出。

考点总结：
  • 栈溢出取决于最大递归深度，不是总调用次数
  • fib(n) 调用次数多但深度浅（只有 n）
  • 线性递归当 n 很大时（> 15000~20000）可能栈溢出
✏️ 模拟题 · 斐波那契变体 变体斐波那契递推
以下 f(7) 的返回值是多少？
int f(int n) {   if (n <= 2) return n;   return f(n - 1) + f(n - 3);  // 注意：跳过了 f(n-2) }
A 8
B 9
C 10
D 11
✅ 正确答案：C · 10
先计算基础值：
f(0) = 0, f(1) = 1, f(2) = 2（终止条件：n ≤ 2 时返回 n）

从底向上递推计算：
f(3) = f(2) + f(0) = 2 + 0 = 2
f(4) = f(3) + f(1) = 2 + 1 = 3
f(5) = f(4) + f(2) = 3 + 2 = 5
f(6) = f(5) + f(3) = 5 + 2 = 7
f(7) = f(6) + f(4) = 7 + 3 = 10

递归树展开（部分）：
f(7) ├── f(6) │ ├── f(5) │ │ ├── f(4) │ │ │ ├── f(3)=2 │ │ │ └── f(1)=1 │ │ └── f(2)=2 │ └── f(3) │ ├── f(2)=2 │ └── f(0)=0 └── f(4) ├── f(3) │ ├── f(2)=2 │ └── f(0)=0 └── f(1)=1
f(7) = f(6) + f(4) = 7 + 3 = 10

规律：这个递推 f(n) = f(n-1) + f(n-3) 不同于标准斐波那契。
它跳过了 f(n-2)，导致增长更慢。
序列：0, 1, 2, 2, 3, 5, 7, 10, 13, 18...
✏️ 综合模拟 · 阅读程序 综合递归阅读程序
输入 3 4，以下程序的输出是什么？
int gcd(int a, int b) {   if (b == 0) return a;   return gcd(b, a % b); } int foo(int a, int b) {   if (b == 0) return 0;   return foo(a, b - 1) + a; } int main() {   int a, b; cin >> a >> b;   cout << foo(a, b) << " " << gcd(a, b); }
A 12 1
B 7 1
C 12 3
D 10 1
✅ 正确答案：A · 12 1
分两部分计算：

第一部分：foo(3, 4) — 递归实现乘法
foo(3,4) = 3 + 3 + 3 + 3 = 12（a 累加 b 次）

调用栈：
foo(3,4) = foo(3,3) + 3
 foo(3,3) = foo(3,2) + 3
  foo(3,2) = foo(3,1) + 3
   foo(3,1) = foo(3,0) + 3
    foo(3,0) = 0（终止条件）
   → foo(3,1) = 0 + 3 = 3
  → foo(3,2) = 3 + 3 = 6
 → foo(3,3) = 6 + 3 = 9
→ foo(3,4) = 9 + 3 = 12

第二部分：gcd(3, 4) — 欧几里得算法
gcd(3,4)：b=4≠0 → gcd(4, 3%4=3)
 gcd(4,3)：b=3≠0 → gcd(3, 4%3=1)
  gcd(3,1)：b=1≠0 → gcd(1, 3%1=0)
   gcd(1,0)：b=0 ✅ → 返回 1

输出：12 1

考点总结：
  • foo(a,b) 是用递归实现乘法（a × b）
  • gcd(a,b) 是欧几里得算法（辗转相除法）求最大公约数
  • 两个函数展示了不同的递归终止条件设计

以下是你必须熟练掌握的考点，考前反复看：
概念要点复杂度/值
递归三要素终止条件 + 递归调用 + 返回值缺一不可
调用栈跟踪"先递后归，压栈前进，到底回溯"初赛核心
fact(n) 阶乘n × fact(n-1)，终止 n≤1O(n) / O(n)
fib(n) 斐波那契fib(n-1)+fib(n-2)，终止 n≤1O(2n) / O(n)
汉诺塔2 × hanoi(n-1) + 1步数 2n-1
递归深度线性递归深度 = n，双分支深度 = n影响空间
栈溢出深度过大（通常 > 15000）导致程序崩溃
递归→迭代循环或栈可替代递归更高效
记忆化优化存中间结果，避免重复计算fib O(n) 代替 O(2n)
三要素：终止 + 递进 + 返回 调用栈深度 = 最大递归深度 汉诺塔步数 = 2n - 1 无限递归 → 栈溢出
