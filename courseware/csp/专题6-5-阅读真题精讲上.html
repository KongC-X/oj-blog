2021·1位运算：x&(x-1) 与 x&-x

2021 年 CSP-J 阅读程序第 1 题考查位运算的两个经典应用： x & (x - 1) 用于消去最低位的 1，反复执行可统计二进制中 1 的个数； x & -x 用于取出最低位的 1（lowbit）。 这是位运算阅读题最基础也是最常考的两个结论。

核心位运算结论

x & (x - 1) — 将 x 二进制中最低位的 1 变成 0
x & -x — 取出 x 二进制中最低位的 1（保留低位 1，高位全部清 0）

举例：x = 12 (1100₂)
12 & 11 = 1100₂ & 1011₂ = 1000₂ = 8（消去最低位 1）
12 & -12 = 1100₂ & 0100₂ = 0100₂ = 4（取出最低位 1）

2021 阅读 1 程序代码

📖 2021 真题 · 阅读程序第 1 题 判断题 + 选择题

阅读以下程序，回答 1~3 题。

#include <iostream> using namespace std; int f1(int x) { int cnt = 0; while (x) { cnt++; x = x & (x - 1); } return cnt; } int f2(int x) { return x & -x; } int main() { int n; cin >> n; cout << f1(n) << " " << f2(n) << endl; return 0; }

真题精讲 · 3 问

1.【判断题】输入 n=7，则 f1(n) 返回 7。
✓ 正确✗ 错误
点击显示答案
答案：✗ 错误
解析：7 的二进制为 111，包含 3 个 1。
f1() 每次消去最低位 1，循环次数 = 二进制中 1 的个数。
模拟：7 & 6 = 111 & 110 = 110 (6) → cnt=1
6 & 5 = 110 & 101 = 100 (4) → cnt=2
4 & 3 = 100 & 011 = 000 (0) → cnt=3
返回 3，不是 7。
注意：千万不要把数值本身当成 1 的个数！
2.【选择题】输入 n=40，f2(n) 的返回值是多少？
A 40 B 8 C 4 D 3
点击显示答案
答案：B
解析：40 的二进制为 101000（32+8）。
-40 的二进制（补码）：将 40 按位取反再加 1
40 = 0010 1000
取反 → 1101 0111
+1 → 1101 1000（即 -40 的补码）

40 & -40 = 0010 1000 & 1101 1000 = 0000 1000 = 8
即取出最低位的 1（值为 8）。
快捷方法：x & -x 返回的是 2k，其中 k 是 x 二进制末尾 0 的个数。
40=101000₂，末尾有 3 个 0 → 2³ = 8。
3.【选择题】若输入 n=0，以下说法正确的是？
A f1 死循环，f2 返回 0 B f1 返回 0，f2 返回 0 C f1 返回 0，f2 报错 D f1 返回 1，f2 返回 0
点击显示答案
答案：B
解析：
f1(0)：while 条件为 x（即 x != 0 为真）。x=0 直接不进入循环，cnt=0，返回 0。
f2(0)：0 & -0 = 0 & 0 = 0。
注意：f1(0) 不会死循环！x=0 时 while 条件为 false，直接跳出。
lowbit(0)=0 也是一个边界结论。
✓ 位运算阅读识别要点：
• x & (x-1) → 消去最低位 1，循环次数 = 二进制中 1 的个数
• x & -x → lowbit，取最低位 1 的值
• 边界：x=0 时 f1 返回 0，f2 返回 0

2021·2Base64 解码程序

2021 年 CSP-J 阅读程序第 2 题考查 Base64 解码算法。 Base64 用 64 个可打印字符表示二进制数据，将 3 字节（24 位）分为 4 组， 每组 6 位，映射到编码表。

Base64 编码表（base[64]）

base[0]='A' ... base[25]='Z'（大写字母 26 个）
base[26]='a' ... base[51]='z'（小写字母 26 个）
base[52]='0' ... base[61]='9'（数字 10 个）
base[62]='+', base[63]='/'

📌 解码流程：4 字符 → 查表得 4 个 6 位值 → 拼接为 24 位 → 拆分为 3 字节（8 位）。 '=' 表示原始数据不足 3 字节，pad 变量控制输出个数。
3 字节 → 4 个 Base64 字符示意图： +--------+--------+--------+ | 字节1 | 字节2 | 字节3 | 原始 24 位数据 +--------+--------+--------+ | 6位| 6位| 6位| 6位| 每 6 位查编码表 +----+----+----+----+ | c1 | c2 | c3 | c4 | 4 个 Base64 字符 解码（逆向）：4字符 → 6位值×4 → 24位 → 3字节

#include <cstring> using namespace std; const char base[] = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/"; int pos(char c) { for (int i = 0; i < 64; i++) { if (base[i] == c) return i; } return -1; } int main() { char s[100]; cin >> s; int len = strlen(s); int pad = 0; if (len % 4 != 0) return 1; if (len > 0 && s[len-1] == '=') pad++; if (len > 1 && s[len-2] == '=') pad++; for (int i = 0; i < len; i += 4) { int a[4]; for (int j = 0; j < 4; j++) { a[j] = pos(s[i + j]); } int val = (a[0] << 18) | (a[1] << 12) | (a[2] << 6) | a[3]; unsigned char b[3]; b[0] = (val >> 16) & 0xFF; b[1] = (val >> 8) & 0xFF; b[2] = val & 0xFF; for (int j = 0; j < 3 - pad; j++) { cout << b[j]; } } cout << endl; return 0; }

真题精讲 · 3 问

1.【判断题】输入字符串长度一定是 4 的倍数，否则程序返回 1。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：代码第 13 行 if (len % 4 != 0) return 1; 明确检查了长度是否为 4 的倍数。 Base64 编码后的字符串长度必定是 4 的倍数（含填充符 '='）。若不满足程序直接返回 1 退出。
2.【选择题】若输入 "TWFu"（'T'→19, 'W'→22, 'F'→5, 'u'→46），输出解码后的内容是？
A "Man" B "Mbn" C "Nao" D "Lan"
点击显示答案
答案：A
解析：手动模拟解码：

Step 1: a[0]=19, a[1]=22, a[2]=5, a[3]=46
Step 2: val = (19<<18) | (22<<12) | (5<<6) | 46
二进制：19=010011, 22=010110, 5=000101, 46=101110
拼接：010011 010110 000101 101110（24 位）
Step 3: 拆分为 3 个字节：
b[0] = 01001101 = 77 → 'M'
b[1] = 01100001 = 97 → 'a'
b[2] = 01101110 = 110 → 'n'
输出为 "Man"，选 A。
3.【选择题】若输入 "TWFu=="（带 2 个填充符），以下说法正确的是？
A pad=2，最后输出 1 个字节 B pad=2，最后输出 2 个字节 C pad=1，最后输出 2 个字节 D 程序会报错
点击显示答案
答案：A
解析：输入 "TWFu==" 长度 len=6。
s[len-1]='=' → pad=1
s[len-2]='=' → pad=2
最终 pad=2。

输出循环 for (int j=0; j<3-pad; j++) → 3-2=1 次，只输出 b[0] 一个字节。
Base64 中每出现一个 '=' 表示原始数据少了 1 字节，2 个 '=' 表示原始数据只有 1 字节。
✓ Base64 阅读要点：base[] 编码表 + pos() 查表 + 位拼接 → Base64 编解码。
核心公式：4 字符 → 3 字节，每个字符 6 位，拼接后拆分为 3 个 8 位。'=' 填充标记。

2021·3欧拉筛/线性筛 — 因数个数与因数和

2021 年 CSP-J 阅读程序第 3 题考查线性筛（欧拉筛）的应用。 线性筛在 O(n) 时间内筛出素数，同时可以递推计算每个数的因数个数 d(n) 和因数和 s(n)。 本题是阅读题中难度较大的一题，需要理解线性筛的递推维护过程。

线性筛的关键性质（用于维护因数信息）

设当前筛到 i，最小质因子为 p：
1. 若 p 未出现在 i 的质因子中（即 i % p ≠ 0），则 i×p 的因数个数 = d[i]×2，因数和 = s[i]×(p+1)
2. 若 p 是 i 的最小质因子（即 i % p = 0），需维护一个辅助数组记录"最小质因子的幂次"
线性筛保证每个合数只被其最小质因子筛掉一次。

2021 阅读 3 程序代码

📖 2021 真题 · 阅读程序第 3 题 判断题 + 选择题

阅读以下程序，回答 1~3 题。

#include <cstring> using namespace std; const int MAXN = 1000000; int prime[MAXN], cnt; bool isPrime[MAXN]; int d[MAXN]; // 因数个数 int s[MAXN]; // 因数和 int t[MAXN]; // 最小质因子的幂次部分（辅助） void init(int n) { memset(isPrime, 1, sizeof(isPrime)); isPrime[0] = isPrime[1] = 0; d[1] = 1; s[1] = 1; for (int i = 2; i <= n; i++) { if (isPrime[i]) { prime[++cnt] = i; d[i] = 2; // 素数因数个数：1 和本身 → 2 s[i] = i + 1; // 素数的因数和：1 + i t[i] = i; // 最小质因子的幂次部分初始 } for (int j = 1; j <= cnt; j++) { int p = prime[j]; if (i * p > n) break; isPrime[i * p] = 0; if (i % p == 0) { // p 是 i 的最小质因子 t[i * p] = t[i] * p; d[i * p] = d[i] / (t[i] + 1) * (t[i] * p + 1); s[i * p] = s[i] / (t[i] * p - 1) * (t[i] * p * p - 1); break; } else { // p 与 i 互质 t[i * p] = p; d[i * p] = d[i] * 2; s[i * p] = s[i] * (p + 1); } } } } int main() { int n; cin >> n; init(n); cout << d[n] << " " << s[n] << endl; return 0; }

真题精讲 · 3 问

1.【判断题】当 n=6 时，函数 init 执行结束后，d[6]=4。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：6 的因数有 1, 2, 3, 6 共 4 个，所以 d[6]=4。

模拟线性筛过程：
i=2（素数）：d[2]=2, s[2]=3, t[2]=2。筛掉 2×2=4：
4%2=0 → d[4]=d[2]/(t[2]+1)×(t[2]×2+1)=2/3×5 → 需要整数运算：t[2]=2, t[2]+1=3, t[2]×2+1=5
但这里需要理解：对于 p² 形式，公式做除法再乘法，因为 d[4]=3（因数 1,2,4）。
i=3（素数）：d[3]=2, s[3]=4, t[3]=3。筛掉 3×2=6：
6%2=0？2 不是 3 的因子 → 走 else 分支：
t[6]=2, d[6]=d[3]×2=4, s[6]=s[3]×(2+1)=4×3=12 ✓
验证：d[6]=4（因数 1,2,3,6），s[6]=1+2+3+6=12 ✓
2.【判断题】若将 isPrime 数组类型改为 int，程序仍然可以正常运行。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：在 C++ 中，bool 数组和 int 数组都可以用于标记。
代码中 memset(isPrime, 1, sizeof(isPrime)) 将每个字节设为 0x01，
对于 bool 类型，非零即 true；对于 int 类型，值为 1（也是非零，代表 true）。
if (isPrime[i]) 判断时只要非零即为真，所以改为 int 类型不影响逻辑。
注意：memset 按字节赋值，int 数组用 memset 置 1 得到的是 0x01010101（十进制 16843009），但作为逻辑判断时非零即为 true，不影响。
3.【选择题】以下关于线性筛时间复杂度的说法，正确的是？
A O(n log n) B O(n) C O(n log log n) D O(n²)
点击显示答案
答案：B
解析：线性筛（欧拉筛）的核心思想是每个合数只被其最小质因子筛掉一次，
因此每个数在整个筛法过程中只被访问常数次，时间复杂度为 O(n)。

对比：埃氏筛的时间复杂度为 O(n log log n)，
而欧拉筛通过 if (i % p == 0) break; 保证每个合数只被筛一次，达到线性。

注意：本题虽然额外维护了 d、s、t 数组，但每个数的操作仍然是常数次，总体仍为 O(n)。
✓ 线性筛阅读要点：
• 看到 prime[] + isPrime[] + 两层循环 + if (i%p==0) break → 线性筛
• 维护附加信息（d、s、t）时，注意 i%p==0（p 是最小质因子）与 else（p 是新质因子）分支不同
• 复杂度 O(n)，每个合数被最小质因子筛一次

2021·4二叉树遍历 + 平衡性判断（完善）

2021 年 CSP-J 阅读程序第 4 题是完善程序（完善填空）题， 考查二叉树的先序/中序/后序遍历以及平衡二叉树判断。 需要补全遍历代码中的递归调用顺序，以及平衡性判断的左右子树高度差条件。

二叉树遍历口诀

先序遍历（根左右）：先访问根，再遍历左子树，最后遍历右子树
中序遍历（左根右）：先遍历左子树，再访问根，最后遍历右子树
后序遍历（左右根）：先遍历左子树，再遍历右子树，最后访问根
平衡二叉树：每个节点的左右子树高度差 ≤ 1

2021 阅读 4 程序代码（完善填空）

📖 2021 真题 · 完善程序 完善填空 5 处

以下程序实现二叉树的遍历与平衡性判断，代码中有 5 处填空，请选择正确的选项。

#include <algorithm> using namespace std; struct Node { int val; Node *left, *right; Node(int v) : val(v), left(nullptr), right(nullptr) {} }; void preorder(Node *root) { if (!root) return; cout << root->val << " "; ①; // ① 填空 preorder(root->right); } void inorder(Node *root) { if (!root) return; inorder(root->left); cout << root->val << " "; ②; // ② 填空 } void postorder(Node *root) { if (!root) return; postorder(root->left); ③; // ③ 填空 cout << root->val << " "; } int getHeight(Node *root) { if (!root) return 0; return max(getHeight(root->left), getHeight(root->right)) + 1; } bool isBalanced(Node *root) { if (!root) return true; int lh = getHeight(root->left); int rh = getHeight(root->right); if (④ > 1) return false; // ④ 填空 return ⑤; // ⑤ 填空 }

真题精讲 · 3 问

1.【完善填空①】先序遍历的递归调用顺序应该是？
A preorder(root->left) B preorder(root->right) C preorder(root) D return
点击显示答案
答案：A
解析：先序遍历顺序为"根左右"。代码已输出根节点值，然后应该先遍历左子树，再遍历右子树。
所以①处应填 preorder(root->left)。

验证：根 → 左子树递归 → 右子树递归，符合"根左右"顺序。
2.【完善填空②③】中序遍历②和后序遍历③的递归调用分别应填？
A ② inorder(root->right)、③ postorder(root->right) B ② inorder(root->left)、③ postorder(root->left) C ② inorder(root->right)、③ inorder(root->right) D ② return、③ return
点击显示答案
答案：A
解析：
中序遍历（左根右）：先递归左子树，再输出根，再递归右子树。
因此②处应在输出根之后，递归遍历右子树：inorder(root->right)

后序遍历（左右根）：先递归左子树，再递归右子树，最后输出根。
因此③处应在递归左子树之后、输出根之前，递归遍历右子树：postorder(root->right)

选 A（② inorder(root->right)、③ postorder(root->right)）。
3.【完善填空④⑤】平衡性判断的④和⑤应分别填什么？
A ④ abs(lh - rh)、⑤ true B ④ lh - rh、⑤ isBalanced(root->left) && isBalanced(root->right) C ④ abs(lh - rh)、⑤ isBalanced(root->left) && isBalanced(root->right) D ④ lh + rh、⑤ false
点击显示答案
答案：C
解析：
平衡二叉树定义：每个节点的左右子树高度差 ≤ 1。

④处：应判断左右子树的高度差是否大于 1，若大于 1 则不平衡。
高度差需取绝对值：abs(lh - rh) > 1 → 不平衡，返回 false。
如果只写 lh - rh > 1，则当右子树比左子树高时检测不出来。

⑤处：当前节点的高度差 ≤ 1 后，还需要递归检查左右子树各自是否平衡。
所以返回 isBalanced(root->left) && isBalanced(root->right)。

选 C（④ abs(lh - rh)、⑤ isBalanced(root->left) && isBalanced(root->right)）。
✓ 二叉树完善填空要点：
• 遍历题：记住三种遍历顺序口诀，注意递归调用在输出语句的前后位置
• 平衡性判断：先判高度差 → 再递归检查子树
• 高度差必须取绝对值 abs()，否则单侧高度差会漏判

#include <iostream> using namespace std; void printBin(int x) { for (int k = 31; k >= 0; k--) { cout << ((x >> k) & 1); } cout << endl; } int countOnes(int x) { int cnt = 0; while (x) { cnt += (x & 1); x >>= 1; } return cnt; } int reverseBits(int x) { int res = 0; for (int i = 0; i < 32; i++) { res = (res << 1) | ((x >> i) & 1); } return res; } int main() { int n; cin >> n; printBin(n); cout << countOnes(n) << " "; cout << reverseBits(n) << endl; return 0; }

真题精讲 · 3 问

1.【判断题】输入 n=5，printBin 函数输出 000...0101（共 32 位）。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：5 的二进制为 101，占 3 位。
printBin 从 k=31 循环到 0，输出 32 位二进制表示。
高位补 0，所以输出 000...0101（前面 29 个 0，最后 3 位是 101）。
验证：(5>>2)&1 = 1, (5>>1)&1 = 0, (5>>0)&1 = 1，符合预期。
2.【选择题】若输入 n=11，countOnes 函数返回值是多少？
A 2 B 3 C 4 D 11
点击显示答案
答案：B
解析：11 的二进制为 1011（8+2+1）。
countOnes 每次用 x & 1 取出最低位，然后右移 1 位。

模拟：x=11=1011₂
cnt += 1011₂ & 1 = 1 → cnt=1, x=101₂=5
cnt += 101₂ & 1 = 1 → cnt=2, x=10₂=2
cnt += 10₂ & 1 = 0 → cnt=2, x=1₂=1
cnt += 1₂ & 1 = 1 → cnt=3, x=0 → 循环结束
返回 3。

注意：countOnes 和 2021 年 f1 用的 x & (x-1) 不同，这里是逐位检查，效率较低但结果相同。
3.【选择题】若 n=1，reverseBits(n) 的返回值是多少？
A 1 B 2³¹ C -2147483648 D 0
点击显示答案
答案：C
解析：n=1 的 32 位二进制为 000...0001（最低位 1）。
reverseBits 功能是逐位反转：从 i=0 到 31，每次取 x 的第 i 位，放到 res 的对应高位。

实际上就是将二进制位顺序完全颠倒：
000...0001 → 1000...000
即最低位的 1 被移到了最高位（第 31 位）。

最高位为 1 的 int 表示负数：2³¹ = 2147483648，但 int 最大值为 2³¹-1，所以 1000...000 表示 -2147483648（补码）。

选 C（-2147483648），即 2³¹ 的负数形式。
易错点：注意 int 类型的范围是 [-2³¹, 2³¹-1]，最高位为 1 表示负数。
✓ 2022 位运算阅读要点：
• (x >> k) & 1 取第 k 位；x & 1 取最低位；x >>= 1 右移
• 二进制反转：逐位取位 → 左移累加 → 注意符号位导致负数
• printBin 输出 32 位（含前导 0），countOnes 不同于 x&(x-1) 而是逐位检查

📖 2022 真题 · 阅读程序第 2 题 判断题 + 选择题

阅读以下程序，回答 1~3 题。

#include <iostream> using namespace std; struct Node { int val; Node *next; Node(int v) : val(v), next(nullptr) {} }; void traverse(Node *head) { Node *p = head; while (p != nullptr) { cout << p->val << " "; p = p->next; } cout << endl; } Node* insertFront(Node *head, int v) { Node *newNode = new Node(v); newNode->next = head; return newNode; } Node* remove(Node *head, int v) { if (!head) return nullptr; if (head->val == v) { Node *tmp = head; head = head->next; delete tmp; return head; } Node *p = head; while (p->next && p->next->val != v) { p = p->next; } if (p->next) { Node *tmp = p->next; p->next = p->next->next; delete tmp; } return head; } int main() { Node *head = nullptr; head = insertFront(head, 3); head = insertFront(head, 2); head = insertFront(head, 1); traverse(head); head = remove(head, 2); traverse(head); return 0; }

真题精讲 · 3 问

1.【判断题】第一次 traverse 的输出结果应为 "1 2 3"。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：insertFront 是头插法，每次新节点插在链表最前面。

逐步模拟：
初始：head = nullptr
insertFront(head, 3)：新建节点 3, 3->next=head(nullptr), head 指向 3
链表：3 → nullptr
insertFront(head, 2)：新建节点 2, 2->next=head(3), head 指向 2
链表：2 → 3 → nullptr
insertFront(head, 1)：新建节点 1, 1->next=head(2), head 指向 1
链表：1 → 2 → 3 → nullptr

第一次 traverse 输出 "1 2 3"，✓ 正确。
2.【判断题】删除结点后，第二次 traverse 输出 "1 3"。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：链表当前为 1 → 2 → 3 → nullptr。
remove(head, 2) 流程：

Step 1：head->val=1 ≠ 2，不是删除头节点。
Step 2：p=head(1)，循环条件 p->next && p->next->val != v
p->next = 2, p->next->val = 2 == v → 停止循环。
Step 3：p->next 不为 null，执行删除：
tmp = p->next（节点 2）
p->next = p->next->next（即 2->next = 3）
delete tmp

链表变为 1 → 3 → nullptr，traverse 输出 "1 3" ✓。
3.【选择题】若执行 remove(head, 1) 后再 traverse，以下说法正确的是？
A 输出 "2 3" B 输出 "1 3" C 输出 "3" D 程序报错
点击显示答案
答案：A
解析：当前链表 1 → 2 → 3（在执行完第一次 remove(2) 之前的状态）。
假设在原链表 1 → 2 → 3 上执行 remove(head, 1)：

Step 1：head->val = 1 == v，进入头节点删除分支。
tmp = head（节点 1）
head = head->next（头指针指向节点 2）
delete tmp
返回新的 head（节点 2）

链表变为 2 → 3 → nullptr，traverse 输出 "2 3"。
注意：删除头结点时需要更新 head 指针！这是链表操作最常见的易错点。
✓ 链表阅读要点：
• 头插法（insertFront）输出顺序与插入顺序相反
• 删除操作要区分头结点删除和非头结点删除两种情形
• 非头结点删除的模板：p->next = p->next->next（跳过目标节点）
• 注意 delete 释放内存，不要忘记

2023·1质因数分解 / 因子相关计算

2023 年 CSP-J 阅读程序第 1 题考查质因数分解与因子相关计算。 涉及试除法分解质因数、统计质因子个数、求所有因子、判断完全平方数等操作。 本题是数论知识的综合应用，需要熟练掌握因子相关定理。

质因数分解核心定理

算术基本定理：任何正整数 n 可唯一分解为 n = p₁^a¹ × p₂^a² × ... × p_k^a_k
因数个数公式：d(n) = (a₁+1)(a₂+1)...(a_k+1)
因数和公式：s(n) = (p₁^0+...+p₁^a¹)(p₂^0+...+p₂^a²)...
试除法：从 2 到 √n 尝试整除，时间复杂度 O(√n)

2023 阅读 1 程序代码

📖 2023 真题 · 阅读程序第 1 题 判断题 + 选择题

阅读以下程序，回答 1~3 题。

#include <cmath> using namespace std; int factorCount(int n) { int cnt = 0; for (int i = 1; i * i <= n; i++) { if (n % i == 0) { cnt++; if (i * i != n) cnt++; } } return cnt; } bool isPrime(int n) { if (n < 2) return false; for (int i = 2; i * i <= n; i++) { if (n % i == 0) return false; } return true; } void primeFactors(int n) { for (int i = 2; i * i <= n; i++) { while (n % i == 0) { cout << i << " "; n /= i; } } if (n > 1) cout << n << " "; cout << endl; } int main() { int n; cin >> n; cout << factorCount(n) << " "; cout << isPrime(n) << " "; primeFactors(n); return 0; }

真题精讲 · 3 问

1.【判断题】输入 n=12，factorCount(12) 返回 6。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：12 的因数有 1, 2, 3, 4, 6, 12 共 6 个。
模拟 factorCount 的循环 i=1 到 3（i×i≤12）：

i=1：12%1=0 → cnt=1, 1×1≠12 → cnt=2
i=2：12%2=0 → cnt=3, 2×2≠12 → cnt=4
i=3：12%3=0 → cnt=5, 3×3≠12 → cnt=6

返回 6 ✓。
原理：枚举到 √12，每次找到 i 是因数则 i 和 n/i 互为"因子对"，除非 i²=n（此时只计数一次）。
2.【判断题】若 n=97（素数），factorCount 返回 2 且 isPrime 返回 true。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：97 是素数，其因数只有 1 和 97 共 2 个。

factorCount(97)：
i=1 → 97%1=0, 1×1≠97 → cnt=2
i=2~9 → 97%i≠0 → 无操作
返回 2 ✓

isPrime(97)：
i=2~9 → 97%i≠0 → 返回 true ✓

注意：素数只有 2 个因数（1 和本身），isPrime 通过试除法到 √n 判断。
3.【选择题】输入 n=84，primeFactors 的输出是什么？
A "2 2 3 7" B "2 3 7" C "2 4 3 7" D "84"
点击显示答案
答案：A
解析：84 = 2² × 3 × 7。
模拟 primeFactors(84)：

i=2：84%2=0 → 输出 "2", n=42
42%2=0 → 输出 "2", n=21
21%2≠0 → 退出 while
i=3：21%3=0 → 输出 "3", n=7
7%3≠0 → 退出 while
i=4：4×4=16 > n=7 → for 循环结束
最后：n=7 > 1 → 输出 "7"

输出为 "2 2 3 7"，选 A。
注意：质因数分解输出重复质因子（2 出现两次），且最后剩余的大于 √n 的质因子单独输出。
✓ 质因数分解阅读要点：
• factorCount 用 i×i≤n 枚举到 √n，每找到因子 i 就计数 i 和 n/i 两个
• isPrime 试除法，到 √n 即可
• primeFactors 用 while 循环除尽当前质因子，n 最后可能剩 >1 的质因子（需单独输出）

2023·2递归树 / 格雷码

2023 年 CSP-J 阅读程序第 2 题考查递归与格雷码。 格雷码（Gray Code）是一种二进制编码方式，相邻两个数只有一位不同。 递归生成格雷码是经典的分治应用：n 位格雷码 = 0 + (n-1 位格雷码) 顺序 + 1 + (n-1 位格雷码) 逆序。

格雷码递归构造规则

n 位格雷码 G(n) 递归定义为：
- 当 n = 1 时，格雷码为 [0, 1]
- 当 n > 1 时：
  前半部分：在 G(n-1) 每个元素前加 0
  后半部分：在 G(n-1)逆序每个元素前加 1
注意：G(n) 长度为 2ⁿ，相邻（包括首尾）只有一位不同。

n=3 格雷码递归构造： G(1) = [0, 1] 加0 加1（逆序） G(2) = [00, 01] + [11, 10] = [00, 01, 11, 10] 加0（顺序） 加1（逆序） G(3) = [000, 001, 011, 010] + [110, 111, 101, 100] = [000, 001, 011, 010, 110, 111, 101, 100]

2023 阅读 2 程序代码

📖 2023 真题 · 阅读程序第 2 题 判断题 + 选择题

阅读以下程序，回答 1~3 题。

#include <vector> #include <string> using namespace std; vector<string> grayCode(int n) { vector<string> res; if (n == 1) { res.push_back("0"); res.push_back("1"); return res; } vector<string> prev = grayCode(n - 1); for (int i = 0; i < prev.size(); i++) { res.push_back("0" + prev[i]); } for (int i = prev.size() - 1; i >= 0; i--) { res.push_back("1" + prev[i]); } return res; } int main() { int n; cin >> n; vector<string> codes = grayCode(n); for (int i = 0; i < codes.size(); i++) { cout << codes[i] << endl; } return 0; }

真题精讲 · 3 问

1.【判断题】grayCode(3) 生成的格雷码个数为 8。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：n 位格雷码共有 2ⁿ 个编码。
对于 n=3，共有 2³ = 8 个格雷码。

递归验证：grayCode(1) 返回 2 个，grayCode(2) 返回 2×2=4 个，
grayCode(3) 返回 2×4=8 个，符合 2ⁿ 规律。✓
2.【选择题】grayCode(2) 的第 3 个编码（从 1 开始数）是什么？
A "01" B "10" C "11" D "00"
点击显示答案
答案：C
解析：grayCode(2) 递归构造：
G(1) = [0, 1]

前半部分（加 0）：
"0" + "0" = "00"（第 1 个）
"0" + "1" = "01"（第 2 个）

后半部分逆序加 1：
"1" + "1" = "11"（第 3 个）
"1" + "0" = "10"（第 4 个）

第 3 个编码是 "11"，选 C。
验证：G(2) = [00, 01, 11, 10]，相邻只有一位不同：00→01（变化末位），01→11（变化首位），11→10（变化末位）。
3.【选择题】grayCode 函数的时间复杂度是？（n 是输入的位数，假设字符串拼接操作为 O(1)）
A O(2ⁿ) B O(n) C O(n²) D O(n·2ⁿ)
点击显示答案
答案：A
解析：grayCode(n) 生成共 2ⁿ 个格雷码。
每个编码通过字符串拼接生成（假设 O(1)），且每个编码恰好被生成一次并放入 vector。

递归关系：T(n) = T(n-1) + O(2ⁿ⁻¹) + O(2ⁿ⁻¹) = T(n-1) + O(2ⁿ)
展开：T(n) = O(2¹) + O(2²) + ... + O(2ⁿ) = O(2ⁿ)

选 A（O(2ⁿ)）。

注意：输出 2ⁿ 个编码，时间复杂度至少为 O(2ⁿ)，因为结果集的大小就是 2ⁿ。
如果考虑字符串拼接的实际开销（字符串长度为 n），复杂度为 O(n·2ⁿ)，
但题目假设字符串拼接为 O(1)，所以按 O(2ⁿ) 计算。
✓ 格雷码阅读要点：
• 递归构造：[加0 + 前驱顺序] + [加1 + 前驱逆序]
• n 位格雷码共 2ⁿ 个，相邻仅一位不同
• 递归深度 = n，每层规模翻倍，总复杂度 O(2ⁿ)
