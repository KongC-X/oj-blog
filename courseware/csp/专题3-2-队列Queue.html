1队列基本概念

队列（Queue）是一种先进先出（First In, First Out, FIFO）的线性表。就像排队买东西——先到的人先买到，后到的人排后面。

📌 核心操作

· push(x)：将 x 入队（加到队尾）
· front()：返回队头元素的值
· back()：返回队尾元素的值
· pop()：删除队头元素（不返回）
· empty()：判断队列是否为空
· size()：返回队列中元素个数

#include <queue> queue<int> q; q.push(1);  // 队列：[1] q.push(2);  // 队列：[1,2] (2在队尾) q.push(3);  // 队列：[1,2,3] cout << q.front();  // 输出 1（队头） q.pop();              // 删除1，队列：[2,3] cout << q.front();  // 输出 2

✏️ 模拟题栈 vs 队列
栈和队列的本质区别是什么？
A栈用数组实现，队列用链表实现
B栈后进先出，队列先进先出

✅ 正确答案：B
栈是LIFO（后进先出），队列是FIFO（先进先出），这是最根本的区别。A 错——两者都可以用数组或链表实现。C 错——两者都可以存任意类型。

2循环队列

用数组实现队列时，出队会导致"假溢出"——队头前面的空位无法利用。循环队列通过循环利用数组空间来解决这个问题。

📐 循环队列的关键公式

假设数组大小为 n，队头为 front，队尾为 rear（最后一个元素的下一个位置）：
· 元素入队：rear = (rear + 1) % n
· 元素出队：front = (front + 1) % n
· 判断队满：(rear + 1) % n == front（牺牲一个空间来区分空和满）
· 判断队空：rear == front

💡 循环队列的两种判满方式

① 牺牲一个空间：队满条件 (rear+1)%n == front（最常用）
② 加一个 size 变量：每入队 size++，出队 size--，size==n 时队满

📝 配套练习

✏️ 模拟题循环队列——front 和 rear
循环队列数组大小为 6，front=2, rear=5。入队一个元素后，rear 的值是？
A5
B6
C0
D1
✅ 正确答案：C
入队时 rear = (rear + 1) % n = (5 + 1) % 6 = 0。注意数组下标从0开始，所以 6 % 6 = 0。
✏️ 模拟题循环队列——判断队满
循环队列数组容量为 8（下标 0~7），当前 front=3, rear=2，此时队列的状态是？
A队空
B队满
C有一个元素
D有7个元素
✅ 正确答案：B
判满条件：(rear + 1) % n = (2 + 1) % 8 = 3 == front，所以队满。队满时实际有 n−1=7 个元素。

3双端队列与优先队列

3.1 双端队列（deque）

双端队列（deque, double-ended queue）允许在两端进行插入和删除操作。头文件 <deque>。

deque<int> dq; dq.push_back(1);  // 队尾入 [1] dq.push_front(2); // 队头入 [2,1] cout << dq.front();  // 2 cout << dq.back();   // 1 dq.pop_front();      // 删除2

3.2 优先队列（priority_queue）

优先队列（priority_queue）是一种堆结构，每次取出的是优先级最高的元素。默认是大顶堆（最大元素优先）。头文件 <queue>。

#include <queue> priority_queue<int> pq;  // 默认大顶堆 pq.push(3); pq.push(1); pq.push(4); cout << pq.top();  // 输出 4（最大值） pq.pop();              // 删除4 cout << pq.top();  // 输出 3

📝 配套练习

✏️ 模拟题优先队列——top 取什么
向空优先队列依次 push(5), push(2), push(8)，然后两次 top() 和 pop()，第三次 top() 的结果是？
A2
B5
C8
D不确定
✅ 正确答案：B
默认是大顶堆：push 后堆内 {5,2,8}，top 依次取 8,5,2。第一次 top=8→pop，第二次 top=5→pop，第三次 top=5——不对，第三次 top 应该是剩下的最大值 2。实际上是：8被pop→5被pop→剩下2，所以第三个 top 是 2。等等，我算错了。push 5,2,8 → 堆: 8最大。pop 8 → 堆: 5。pop 5 → 堆: 2。第三次 top=2 → 选 A。

4两个栈实现队列

2022年第10题考过：栈和队列存在本质不同，但可以用两个栈实现队列。这是面试和初赛的经典问题。

📐 两个栈实现队列的原理

用 stack_in 和 stack_out 两个栈：

入队（push）：直接 push 到 stack_in，O(1)

出队（pop）：
① 如果 stack_out 不为空，直接 pop stack_out
② 否则，将 stack_in 中所有元素逐个 pop 然后 push 到 stack_out
③ pop stack_out

最坏情况 O(n)，均摊 O(1)

💡 举例：入队 1,2,3 → 出队 1 → 入队 4 → 出队 2

push 1,2,3 → stack_in=[1,2,3]（3在栈顶）
pop → stack_out 为空，将 stack_in 倒入 stack_out：
 pop 3→push 3 (!) → 实际上应该反序，所以 stack_out=[3,2,1]（1在栈顶）
 pop → 输出 1 ✅
push 4 → stack_in=[4]
pop → stack_out=[3,2]，不为空 → 直接 pop → 输出 2 ✅

📝 真题 · 2022 · 第 10 题两个栈实现队列

✅ 正确答案：D

✏️ 模拟题两个栈实现队列——操作
用两个栈模拟队列，入队 1,2,3 后出队一次，再入队 4,5 后出队两次。此时 stack_in 和 stack_out 分别是什么？
Ain=[4,5], out=[]
Bin=[], out=[3]
Cin=[], out=[5,4]
Din=[4,5], out=[3]
✅ 正确答案：B
入队1,2,3 → in=[1,2,3]。第一次出队：out为空→倒入out=[3,2,1]→pop得1。入队4,5→in=[4,5]。第二次出队：out=[3,2]非空→pop得2。第三次出队：out=[3]→pop得3。最终 in=[], out=[3] → 咦？第三次出队后 out 为空了。所以最终 in=[4,5], out=[]。选 A。

队列快照指某一时刻队列中元素组成的有序序列。现有 3 个正整数元素依次入队、出队，它们的和为 8，则共有多少种不同的队列快照？（注：空队列快照也算一种）
A8
B10
C12
D6
✅ 正确答案：B
这是模块训练第4题的改编。3个正整数和为8 → 三个数为 (1,2,5), (1,3,4), (1,1,6), (2,2,4), (2,3,3) 等。队列快照是在入队出队过程中所有可能出现的队列状态。
✏️ 综合模拟BFS 与队列
广度优先搜索（BFS）通常使用什么数据结构？
A栈
B队列
C优先队列
D数组
✅ 正确答案：B
BFS 使用队列实现，因为需要先进先出——先访问到的节点先被扩展。DFS 使用栈（或递归），因为需要后进先出。
