12021 阅读 2 — Base64 解码程序

2021 年 CSP-J 阅读程序第 2 题考查的是 Base64 解码算法。 Base64 是一种用 64 个可打印字符来表示任意二进制数据的编码方式。 它将每 3 个字节（24 位）的数据分成 4 组， 每组 6 位，映射到 base[64] 编码表中的对应字符。

Base64 编码表 & 解码原理

Base64 索引表（base[64]）

base[0]='A', base[1]='B', ..., base[25]='Z'
base[26]='a', base[27]='b', ..., base[51]='z'
base[52]='0', base[53]='1', ..., base[61]='9'
base[62]='+', base[63]='/'

📌 解码核心流程：每 4 个字符 → 查 base[] 得到 4 个 6 位值 → 拼接成 24 位 → 拆分为 3 个字节（8 位）。 如果编码时末尾有填充字符 '='，表示最后一个分组不足 3 字节，解码时需做特殊处理。
编码示意图（3 字节 → 4 字符）： +--------+--------+--------+ | 字节 1 | 字节 2 | 字节 3 | 24 位原始数据 +--------+--------+--------+ | 6位 | 6位 | 6位 | 6位 | 每个 6 位查表 +----+----+----+----+ | c1 | c2 | c3 | c4 | 4 个 Base64 字符

2021 阅读 2 程序代码

📖 2021 真题 · 阅读程序第 2 题 判断题 + 选择题

阅读以下程序，回答 1~3 题。

#include <cstring> using namespace std; const char base[] = "ABCDEFGHIJKLMNOPQRSTUVWXYZabcdefghijklmnopqrstuvwxyz0123456789+/"; int pos(char c) { for (int i = 0; i < 64; i++) { if (base[i] == c) return i; } return -1; } int main() { char s[100]; cin >> s; int len = strlen(s); int pad = 0; if (len % 4 != 0) return 1; if (len > 0 && s[len-1] == '=') pad++; if (len > 1 && s[len-2] == '=') pad++; for (int i = 0; i < len; i += 4) { int a[4]; for (int j = 0; j < 4; j++) { a[j] = pos(s[i + j]); } int val = (a[0] << 18) | (a[1] << 12) | (a[2] << 6) | a[3]; unsigned char b[3]; b[0] = (val >> 16) & 0xFF; b[1] = (val >> 8) & 0xFF; b[2] = val & 0xFF; for (int j = 0; j < 3 - pad; j++) { cout << b[j]; } } cout << endl; return 0; }

真题精讲 · 3 问

1.【判断题】输入字符串长度一定为 4 的倍数，否则程序返回 1。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：代码第 13 行 if (len % 4 != 0) return 1; 明确检查了长度是否为 4 的倍数。 Base64 编码后的字符串长度必定是 4 的倍数（包括填充字符 '='），因此该判断合法。 若长度不满足条件，程序直接返回 1（异常退出）。
2.【选择题】若输入字符串为 "TWFu"（对应 Base64 编码），则输出解码后的内容是？
（提示：'T'→19, 'W'→22, 'F'→5, 'u'→46）
A "Man" B "Mbn" C "Nao" D "Lan"
点击显示答案
答案：A
解析：手动模拟解码流程：

Step 1: a[0]=19, a[1]=22, a[2]=5, a[3]=46（通过 pos() 查表得到）
Step 2: val = (19<<18) | (22<<12) | (5<<6) | 46
    二进制：19=010011, 22=010110, 5=000101, 46=101110
    拼接：010011 010110 000101 101110（24 位）
Step 3: 拆分为 3 字节：
    b[0] = 01001101 = 77 → 'M'
    b[1] = 01100001 = 97 → 'a'
    b[2] = 01101110 = 110 → 'n'
输出为 "Man"，对应选项 A。
3.【选择题】若输入 "TWFu=="（带 2 个填充符），以下说法正确的是？
A pad=2，最后 3-pad=1，只输出 1 个字节 B pad=2，最后输出 2 个字节 C pad=1，最后输出 2 个字节 D 程序会报错
点击显示答案
答案：A
解析：
分析填充逻辑：输入 "TWFu==" 长度 len=6。
第 14 行 if (len>0 && s[len-1]=='=') pad++; → s[5]=='=' → pad=1
第 15 行 if (len>1 && s[len-2]=='=') pad++; → s[4]=='=' → pad=2
最终 pad=2。

第 22 行 for (int j=0; j<3-pad; j++) → 循环 3-2=1 次 → 只输出 b[0] 这一个字节。

这是因为 Base64 中每出现一个 '=' 表示原始数据少了 1 个字节（填充 2 个 '=' 表示原始数据只有 1 个字节）。 程序通过 pad 变量控制输出字节数，避免输出填充产生的无效数据。
✓ 编码类阅读识别要点：看到 base[] 常量字符串 + pos() 查表函数 + 位拼接 << / | 操作 → Base64 编解码。
核心规律：4 字符对应 3 字节，每个字符映射为 6 位值，拼接后拆分。'=' 表示填充，pad 控制输出长度。

22025 阅读 1 — gcd 互质三元组

2025 年 CSP-J 阅读程序第 1 题考查的是欧几里得算法（辗转相除法）求最大公约数， 以及三重循环枚举互质三元组的个数。本题是典型的数论 + 暴力枚举型阅读题。

知识点：辗转相除法 gcd

欧几里得算法（辗转相除法）

原理：gcd(a, b) = gcd(b, a % b)
边界：当 b == 0 时，gcd(a, 0) = a
两个数互质：gcd(a, b) = 1

if (b == 0) return a; return gcd(b, a % b); }
💡 模拟技巧：gcd(12, 8) → gcd(8, 4) → gcd(4, 0) → 返回 4。
gcd(10, 7) → gcd(7, 3) → gcd(3, 1) → gcd(1, 0) → 返回 1（互质）。

2025 阅读 1 程序代码

📖 2025 真题 · 阅读程序第 1 题 判断题 3 道 + 选择题 3 道

阅读以下程序，回答 1~6 题。

using namespace std; int gcd(int a, int b) { if (b == 0) return a; return gcd(b, a % b); } int main() { int n, cnt = 0; cin >> n; for (int i = 1; i <= n; i++) { for (int j = 1; j <= n; j++) { for (int k = 1; k <= n; k++) { if (gcd(i, j) == 1 && gcd(j, k) == 1 && gcd(i, k) == 1) { cnt++; } } } } cout << cnt << endl; return 0; }

真题精讲 · 6 问

1.【判断题】若输入 n=1，则输出为 0。
✓ 正确✗ 错误
点击显示答案
答案：✗ 错误
解析：n=1 时，i=j=k=1。
判断条件为 gcd(1,1)==1 && gcd(1,1)==1 && gcd(1,1)==1。
gcd(1,1)：gcd(1,1) → gcd(1,0) → 返回 1。
三个条件都成立，cnt++ 执行一次，输出 1，而不是 0。
陷阱提示：gcd(1,1)=1，1 和 1 是互质的！要记住 gcd(1,任何数)=1。
2.【判断题】若 i, j, k 中有任意两个相等，则三者一定不互质。
✓ 正确✗ 错误
点击显示答案
答案：✗ 错误
解析：反例：i=j=1, k=2。
i=j=1，但 gcd(1,1)=1，gcd(1,2)=1，gcd(1,2)=1，三个条件全部成立。
所以 i=j=1 且 k=2 时，三者互质，命题不成立。
注意：只有当相等的数 > 1 时，gcd(x, x)=x≠1（x>1），才不互质。
3.【判断题】将条件 gcd(i, j) == 1 改为 gcd(i, j) > 1，程序输出的是"至少有一对不互质"的三元组个数。
✓ 正确✗ 错误
点击显示答案
答案：✓ 正确
解析：修改后的条件是 gcd(i,j)>1 && gcd(j,k)>1 && gcd(i,k)>1，要求三对都不互质才计数。 而"至少有一对不互质"的反面是"三对都互质"。所以修改后统计的是三对都不互质的三元组， 不是"至少有一对不互质"。

正确定义：
- "三对都互质" = gcd(i,j)==1 && gcd(j,k)==1 && gcd(i,k)==1
- "至少有一对不互质" = 总三元组数 - "三对都互质"数
- "三对都不互质" = gcd(i,j)>1 && gcd(j,k)>1 && gcd(i,k)>1
注意区分："至少有一对不互质"与"三对都不互质"是不同的概念！
4.【选择题】输入 n=2，输出为多少？
A 8 B 6 C 4 D 12
点击显示答案
答案：C
解析：n=2，i,j,k 取值范围为 {1, 2}，共 2³=8 种组合。

枚举全部 8 种组合：
(1,1,1) → gcd(1,1)=1 ✓ → 计数 (1,1,2) → gcd(1,1)=1, gcd(1,2)=1, gcd(1,2)=1 → 计数 (1,2,1) → 同上 → 计数 (1,2,2) → gcd(1,2)=1, gcd(2,2)=2≠1 ✗ → 不计数 (2,1,1) → 同(1,1,2) → 计数 (2,1,2) → gcd(2,2)=2≠1 ✗ → 不计数 (2,2,1) → gcd(2,2)=2≠1 ✗ → 不计数 (2,2,2) → gcd(2,2)=2≠1 ✗ → 不计数
计数 4 个，答案为 C（4）。
规律：只有所有数都是 1 或者只有部分数为 2 但必须保证任何一对的 gcd=1 → 实际上就是 不能同时出现两个 2。
5.【选择题】若将第一层循环改为 for (int i = 0; i <= n; i++)，输入 n=1 时的输出为？
A 1 B 0 C 2 D 8
点击显示答案
答案：C
解析：修改后 i 从 0 到 n（含 0），j、k 仍从 1 开始。

n=1 时，i 取值范围为 {0, 1}，j=k=1（因为 1≤j≤1, 1≤k≤1），共 2 种组合：

(i=0, j=1, k=1)：
gcd(0,1) → gcd(1, 0%1=0) → gcd(1,0) → 返回 1
gcd(1,1) → gcd(1, 1%1=0) → gcd(1,0) → 返回 1
gcd(0,1) = 1
三者都 == 1 → ✓ cnt++

(i=1, j=1, k=1)：
gcd(1,1)=1 && gcd(1,1)=1 && gcd(1,1)=1 → ✓ cnt++

总计数 cnt = 2，选 C（2）。

注意：i 从 0 开始时，组合数变为 2×1×1=2 种。不要漏掉 i=0 的情况，且 gcd(0,x)=x 是一个重要边界。
6.【选择题】函数 gcd 的时间复杂度为？（假设输入参数为 a 和 b，a ≥ b）
A O(1) B O(log(min(a,b))) C O(√n) D O(a)
点击显示答案
答案：B
解析：辗转相除法的核心是每次递归调用参数从 (a, b) 变为 (b, a%b)。
由于 a % b < a / 2（当 a ≥ b 时），每次递归问题规模至少减半。
因此递归次数不超过 O(log min(a,b)) 次。

举例：gcd(1000000, 1) 只需要 2 次递归 → gcd(1,0) 返回。
最坏情况：斐波那契数列相邻项，如 gcd(144, 89) 约需要 10 次递归。
因此复杂度为 O(log(min(a,b)))。
✓ 数论类阅读识别要点：
• 看到 gcd() 函数 + 递归调用 + b==0 边界 → 辗转相除法 / 欧几里得算法
• 看到三重循环 + 判断条件中有 gcd(...) == 1 → 统计互质 k 元组个数
• 边界条件：gcd(1,任何数)=1，gcd(x,x)=x（x≠1 时不互质），gcd(0,x)=x

32025 阅读 4 — RLE 行程编码（完善填空）

2025 年 CSP-J 阅读程序第 4 题是完善程序（完善填空）题， 考查的是 RLE（Run-Length Encoding，行程编码）的解码算法。 RLE 是一种简单的压缩编码：将连续重复的字符用 字符 + 重复次数 表示。 例如 "aaabbc" 编码为 "a3b2c1"（或简写为 "a3b2c"）。

RLE 解码原理

编码 → 解码对照

编码："a3b2c" → 表示 a 重复 3 次，b 重复 2 次，c 重复 1 次（省略了数字 1）
解码：读取字符，然后读取后面的数字（可能是一位或多位），输出该字符若干次
解码结果："aaabbc"

📌 完善填空解题策略：
1. 先通读整段代码，理解算法的整体逻辑（尤其是循环结构）
2. 关注填空行上下文的变量类型：是 char、int 还是其他？
3. 用具体输入数据模拟推导每个填空处应该填什么
4. 代入后检查是否满足语法正确和逻辑正确

2025 阅读 4 程序代码（完善填空 5 处）

📖 2025 真题 · 完善程序第 4 题 完善填空 5 处

以下程序实现 RLE 行程编码的解码。输入编码字符串（如 "a3b2c"），输出解码结果（如 "aaabbc"）。 代码中有 5 处填空（①~⑤），请选择正确的选项。

#include <cstring> using namespace std; int main() { char s[200]; cin >> s; int len = strlen(s); int i = 0; while (i < len) { char ch = s[i]; // 当前字符 i++; // 移到数字部分 int num = 0; while (i < len && ①) { // ① 填空 num = num * 10 + (②); // ② 填空 i++; } if (num == 0) ③; // ③ 填空 for (int j = 0; j < ④; j++) { // ④ 填空 cout << ch; } } cout << endl; return 0; }

填空分析 + 真题精讲 · 3 问

5 处填空的选项分析

①：A. s[i] >= '0' && s[i] <= '9'  |  B. s[i] >= 'a' && s[i] <= 'z'
②：A. s[i] - '0'  |  B. s[i] - 'a'  |  C. (int)s[i]
③：A. num = 1  |  B. num = 0  |  C. continue
④：A. num  |  B. num + 1  |  C. num - 1
⑤：（无⑤，本题只有4个填空）

1.【完善填空①】第一个 while 循环的条件应该是什么？
A s[i] >= '0' && s[i] <= '9' B s[i] >= 'a' && s[i] <= 'z' C s[i] != '\0' D s[i] != ' '
点击显示答案
答案：A
解析：RLE 编码格式是 "字符 + 重复次数"。
读取一个字符 ch 后，接下来应该读取该字符的重复次数（数字）。
所以内层 while 循环应该连续读取数字字符，直到遇到下一个字母或字符串结束。
条件应为 s[i] >= '0' && s[i] <= '9'，即当前位置是数字字符。

举例：输入 "a12b3c"，读取 ch='a' 后，需要读取 "12" 这两个数字字符， 拼成数字 12，然后输出 12 个 'a'。
2.【完善填空②】数字拼接的表达式应该是什么？
A s[i] - '0' B s[i] - 'a' C (int)s[i] D s[i] + '0'
点击显示答案
答案：A
解析：要正确解析多位数，需要将数字字符转换为对应的整数值。
数字字符 '0'~'9' 的 ASCII 码是连续的，
因此用 s[i] - '0' 即可得到对应的数字 0~9。

举例：输入 "a12"，当 i 指向 '1' 时：
num = 0*10 + ('1' - '0' = 1) → num = 1
i++ → i 指向 '2'：
num = 1*10 + ('2' - '0' = 2) → num = 12 ✓

B 选项的 s[i] - 'a' 将字母映射到 0~25，不适用。
C 选项的 (int)s[i] 得到的是 ASCII 码值（如 '1'→49），不符合要求。
3.【完善填空③和④】以下哪个选项对③和④的填写是正确的？
A ③ num = 1，④ num B ③ num = 0，④ num C ③ num = 1，④ num + 1 D ③ continue，④ num
点击显示答案
答案：A
解析：RLE 编码中，如果字符后面没有数字，表示重复 1 次（如 "abc" 表示 a1b1c1）。

当内层 while 循环没有读取到任何数字时（num 保持为 0），说明该字符重复次数为 1。
所以 ③ 处应填入 num = 1。

④ 处是 for 循环的终止条件，需要输出 ch 共 num 次。
由于 num 在③处已被修正（当 num=0 时设为 1），所以 ④ 处应填入 num。

验证：输入 "a3b2c"
• ch='a', 读取 "3" → num=3 → 输出 'a'×3 → "aaa"
• ch='b', 读取 "2" → num=2 → 输出 'b'×2 → "aaabb"
• ch='c', 没有数字 → num=0 → ③ num=1 → 输出 'c'×1 → "aaabbc" ✓

注意：RLE 编码通常省略数字 1，所以必须有③处的处理来补全默认值 1。
✓ 完善填空解题要点：
• 先理解整体功能：RLE 解码 = 字符 + 数字 → 重复输出
• 数字可以是多位：需要循环读取直到遇到非数字 → ①处判断数字字符
• 数字拼接：num = num*10 + (s[i]-'0') → ②的标准写法
• 省略数字 1 的情况：需要默认值处理 → ③ num = 1
• 每个填空代入具体数据验证：用 "a3b2c" 模拟一遍流程

四、重要边界条件与易错点

  • Base64 填充：末尾 '=' 的数量决定解码输出字节数——1 个 '=' 少 1 字节，2 个 '=' 少 2 字节
  • gcd 边界：gcd(1,任何数)=1（1和任何数互质），gcd(x,x)=x（x>1时不互质），gcd(0,x)=x
  • RLE 省略数字 1：如 "abc" 表示 a¹b¹c¹，代码必须处理无数字时默认重复 1 次
  • 完善填空验证：一定代入具体输入手动模拟一遍所有填空位置
  • 编码/解码区分：Base64 和 RLE 都需要区分是编码（压缩）还是解码（还原）方向
