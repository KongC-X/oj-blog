1单链表

1.1 结点结构

单链表（Singly Linked List）由一系列结点（Node）组成，每个结点包含两个部分：数据域（data）存储数据，指针域（next）指向下一个结点。最后一个结点的 next 指向 NULL（空），表示链表结束。

📌 单链表结点定义（C++）
struct Node {     int data;     // 数据域     Node* next;  // 指针域，指向下一个结点 };

1.2 头指针

头指针（head）是指向链表第一个结点的指针。如果链表为空，头指针为 NULL。通过头指针可以访问整个链表，因此头指针是链表的入口标识。有些实现还会使用头结点（dummy node / header node）— 一个不存储实际数据的额外结点，用于简化插入和删除操作。

📌 头指针 vs 头结点

· 头指针：指向链表第一个有效结点的指针，必不可少
· 头结点：链表第一个结点之前的一个辅助结点，数据域通常空闲，可选
· 带头结点的链表更便于统一处理空表和首结点插入/删除操作

1.3 遍历

遍历单链表时，从头指针出发，不断通过 p = p->next 移动到下一结点，直到 p == NULL。遍历的时间复杂度为 O(n)，其中 n 是结点数。

🎯 单链表遍历代码
void traverse(Node* head) {     for (Node* p = head; p != nullptr; p = p->next) {         // 访问 p->data     } }

📝 配套练习

✏️ 模拟题单链表头指针
已知单链表的头指针为 head，当链表为空时，head 的值为？
A0（整数 0）
BNULL（或 nullptr）
C指向头结点
D不确定
✅ 正确答案：B
空链表没有有效结点，头指针 head 应被设置为 NULL（C/C++ 中为 nullptr），表示链表不包含任何结点。注意区分头指针与头结点——如果使用了头结点，即使链表为空，头指针也指向头结点（非 NULL），但题目未特殊说明时默认不带头结点。
✏️ 模拟题单链表遍历终止
遍历单链表时，终止循环的条件通常是？
Ap->next == NULL
Bp == NULL
Chead == NULL
Dp->data == 0
✅ 正确答案：B
遍历时使用指针 p 从 head 开始移动，当 p == NULL 时表示已经越过了最后一个结点，应终止。若使用 p->next == NULL 作为终止条件，则会漏掉最后一个结点的数据访问。

2双向链表

2.1 结点结构

双向链表（Doubly Linked List）的每个结点包含三个域：数据域（data）、左指针（llink）指向前驱结点、右指针（rlink）指向后继结点。双向链表可以双向遍历，更灵活但占用更多空间。

📌 双向链表结点定义（C++）
struct DNode {     int data;         // 数据域     DNode* llink;     // 左指针，指向前驱     DNode* rlink;     // 右指针，指向后继 };

2.2 前驱与后继

📌 前驱后继关系

· 对于非空双向链表中的结点 p：p->llink 指向其前驱结点，p->rlink 指向其后继结点
· p->llink->rlink == p（前驱结点的右指针也指向 p）
· p->rlink->llink == p（后继结点的左指针也指向 p）
· 这两条关系构成双向链表的对称性约束，在插入/删除时必须同时维护

⚠️ 重点记忆

llink 意为 left link（左链接），指向前驱；rlink 意为 right link（右链接），指向后继。考试中可能出现不同命名如 prev/next、prior/next，但含义相同。

📝 配套练习

✏️ 模拟题双向链表前驱后继
在双向链表中，若结点 p 的后继为 q（q ≠ NULL），则下列哪个关系一定成立？
Ap->rlink == q 且 q->llink == p
Bp->rlink == q 且 q->rlink == p
Cp->llink == q 且 q->rlink == p
Dp->llink == q 且 q->llink == p
✅ 正确答案：A
若 q 是 p 的后继，则 p 的右指针指向 q（p->rlink == q），同时 q 的左指针指向 p（q->llink == p），两者互为前驱后继关系。这是双向链表的对称性约束。

3循环链表

3.1 单向循环链表

单向循环链表（Circular Singly Linked List）是在单链表的基础上，将最后一个结点的 next 指针指向头结点（或第一个结点），形成一个环。这样可以从任意结点出发遍历整个链表。

📌 单向循环链表的关键点

· 最后一个结点的 next 指向头结点而非 NULL
· 遍历终止条件变为：p->next == head（或 p == head，取决于遍历策略）
· 从任何结点出发都能遍历全部结点
· 插入和删除操作与单链表类似，但需维护环的闭合性

3.2 双向循环链表

双向循环链表（Circular Doubly Linked List）是双向链表 + 循环链表的结合：头结点的 llink 指向最后一个结点，最后一个结点的 rlink 指向头结点。这是最灵活的链表结构，也是考试高频考点。

📌 双向循环链表的边界条件

· 头结点 head：head->llink 指向尾结点，head->rlink 指向第一个有效结点
· 尾结点 tail：tail->rlink == head，head->llink == tail
· 当链表为空（只有头结点）时：head->llink == head 且 head->rlink == head

📝 配套练习

✏️ 模拟题循环链表遍历终止
带头结点的单向循环链表，从头结点 head 之后开始遍历所有有效结点，遍历终止的条件是（p 初始指向 head->next）？
Ap == NULL
Bp == head
Cp->next == NULL
Dp->next == head
✅ 正确答案：B
单向循环链表的尾结点指向头结点，当 p 从 head->next 开始移动，最终会回到 head。当 p == head 时说明已经完整遍历了一圈，应终止。另需注意：若先让 p = head->next，则执行 while (p != head) { ...; p = p->next; } 即可遍历所有有效结点。

4插入与删除操作顺序 ⭐ 重中之重·2022真题

链表插入/删除操作的指针修改顺序是初赛必考的高频陷阱题。关键在于：不要让有用信息提前丢失。下面是单链表和双向链表中插入/删除的标准操作顺序。

4.1 单链表插入（在 p 之后插入 s）

📐 正确顺序
1s->next = p->next;   // 先把 s 的 next 指向 p 的后继
2p->next = s;      // 再将 p 的 next 指向 s
⚠️ 常见错误

若先写 p->next = s，则 p 原来的后继丢失了地址，第2步 s->next = p->next 实际变成了 s->next = s，链表断裂！口诀："先右后左"——先让新结点指向旧后继，再让前驱指向新结点。

4.2 单链表删除（删除 p 的后继 q）

📐 正确顺序
1p->next = q->next;   // 让 p 跨越 q 指向 q 的后继
2delete q; (或 free(q))   // 释放 q 的内存

4.3 双向链表插入（在 p 之后插入 s）

📐 正确顺序（4步，顺序可微调但必须①先接右链）
1s->rlink = p->rlink;    // s 的右指针指向 p 的后继
2s->llink = p;       // s 的左指针指向 p
3p->rlink->llink = s;    // p 的后继的左指针指向 s
4p->rlink = s;       // p 的右指针指向 s
💡 记忆口诀

"先接后断"——先建立新结点的两个链接（1和2），再修改原链路的两个链接（3和4）。在完成第1步后，即使其他步骤出错，至少能通过 p->rlink 找到原后继。如果先修改 p->rlink（第4步），则原后继地址丢失！

4.4 双向链表删除（删除 p 的后继 q）

📐 正确顺序
1p->rlink = q->rlink;     // p 跨越 q 指向 q 的后继
2q->rlink->llink = p;     // q 的后继的左指针指向 p
3delete q; (或 free(q))

📝 配套练习

📝 真题 · 2022 年第 11 题双向循环链表插入顺序
在带有头结点的双向循环链表中，在指针 p 所指结点之后插入指针 s 所指的新结点，以下 4 条语句的执行顺序是？
① p->rlink = s;
② s->llink = p;
③ s->rlink = p->rlink;
④ p->rlink->llink = s;
A③ ② ④ ①
B② ① ④ ③
C① ② ③ ④
D③ ① ② ④
✅ 正确答案：A
关键在于：必须先读取 p->rlink 的原始值，再对 p->rlink 进行赋值。
③ 先做：s->rlink = p->rlink; — 保存 p 的原始后继地址给 s
② 再做：s->llink = p; — 建立 s 到 p 的左链
④ 再三：p->rlink->llink = s; — 此时 p->rlink 还是原始后继，将其 llink 改为 s
① 最后：p->rlink = s; — 最后才能修改 p 的右指针
若①先于③，则 p->rlink 已被改为 s，③中 p->rlink 取值变成 s 自身，链表断裂。
因此正确顺序为 ③ ② ④ ①。
✏️ 模拟题单链表删除操作
在单链表中，已知 p 指向某结点，要删除 p 的后继结点 q（q ≠ NULL），正确的操作是？
Ap->next = q; delete q;
Bp->next = q->next; delete q;
Cdelete q; p->next = q->next;
Dq->next = p->next; delete q;
✅ 正确答案：B
删除 p 的后继 q 时，应先将 p 的 next 指针跨越 q 指向 q 的后继（p->next = q->next），然后释放 q 的内存。注意 q->next 必须在 delete q之前读取，否则就变成了野指针访问。

5数组 vs 链表优缺点对比

数组和链表是两种最基本的线性存储结构，初赛常考它们的区别。理解各自优缺点有助于在不同场景下选择合适的结构。

对比维度数组链表
存储方式连续内存空间离散内存空间（结点通过指针链接）
随机访问O(1) — 通过下标直接访问 ✅ 优势O(n) — 必须从头遍历
插入/删除O(n) — 需移动大量元素O(1) — 仅修改指针 ✅ 优势
空间分配静态分配（大小固定），可能浪费或溢出动态分配，按需取用
缓存局部性好（连续内存，CPU 缓存友好）差（离散存储，缓存命中率低）
额外空间无每个结点需额外存储指针（空间开销）
📌 什么情况选数组？什么情况选链表？

· 频繁随机访问（如 arr[i]）→ 数组
· 频繁插入/删除，尤其在中间位置 → 链表
· 数据量动态变化，难以预估上限 → 链表（动态扩容）
· 对空间和性能要求极致且大小已知 → 数组（无额外指针开销）

📝 配套练习

📝 真题 · 2022 年第 4 题数组和链表的区别
下列叙述中，正确的是？
A链表不能动态改变大小
B数组支持随机访问，链表不支持
C链表在内存中连续存储
D数组的插入和删除速度比链表快
✅ 正确答案：B
逐个分析：
A ❌ 链表通过 new/delete 动态分配和释放结点，可以动态改变大小；数组大小通常固定。
B ✅ 数组可通过下标 O(1) 随机访问；链表必须从头指针开始遍历，O(n)。
C ❌ 链表结点在内存中是离散存储的，通过指针链接，并非连续。
D ❌ 数组插入/删除需移动大量元素（O(n)），链表仅修改指针（O(1) 已知位置）。

6链式栈与链式队列

6.1 链式栈

链式栈（Linked Stack）是用链表作为底层实现的栈。栈顶对应链表的头结点（或第一个有效结点），入栈（push）相当于在头部插入，出栈（pop）相当于删除头结点。链式栈的优点是：无需预先分配栈的大小，不会溢出（理论上限为内存大小）。

📌 链式栈操作对应

· push(x) → 在链表头部插入新结点（O(1)）
· pop() → 删除链表头部结点（O(1)）
· top() → 返回链表头部结点的数据（O(1)）

6.2 链式队列

链式队列（Linked Queue）是用链表作为底层实现的队列。通常需要维护两个指针：队头指针（front）指向头结点，队尾指针（rear）指向尾结点。入队（enqueue）在尾部插入，出队（dequeue）在头部删除。

📌 链式队列操作对应

· enqueue(x) → 在链表尾部插入新结点（O(1)，通过 rear 指针）
· dequeue() → 删除链表头部结点（O(1)，通过 front 指针）
· front() → 返回链表头部结点数据

💡 链式结构 vs 顺序结构

"链式"指用链表实现，"顺序"指用数组实现。链式栈/队列解决了顺序栈/队列假溢出（数组未满但无法继续入队）和固定大小的问题。链式栈/队列的所有基本操作均为 O(1)。

📝 配套练习

✏️ 模拟题链式栈操作
关于链式栈，下列叙述错误的是？
A链式栈的栈顶在链表头部
B链式栈不会因栈满而溢出（不考虑内存耗尽）
C链式栈的 push 操作在链表尾部进行
D链式栈的 pop 操作时间复杂度为 O(1)
✅ 正确答案：C
链式栈的 push 操作在链表头部进行（因为栈顶在头部），这样才能保证 O(1) 的入栈时间。若在尾部入栈，需要遍历到尾部才找到插入位置，时间复杂度为 O(n)。C 选项说"在链表尾部进行"是错误的。
✏️ 模拟题链式队列
一个链式队列需要维持 front 和 rear 两个指针，入队操作在 rear 端进行。下列叙述正确的是？
A出队操作在 rear 端进行
B链式队列解决了顺序队列的假溢出问题
C链式队列的入队操作需要遍历整个链表
D链式队列中 front 和 rear 始终指向同一个结点
✅ 正确答案：B
分析：
A ❌ 出队在队头（front）端进行，即链表头部删除；入队在队尾（rear）端进行。
B ✅ 顺序队列存在"假溢出"（数组前端有空位但无法使用），链式队列动态分配结点，不会出现此问题。
C ❌ 入队通过 rear 指针直接找到尾部，时间复杂度 O(1)，无需遍历。
D ❌ 队列非空时 front 指向头结点、rear 指向尾结点，两者不同。只有空队列时两者才相等（均指向头结点）。

📝综合模拟

✏️ 综合模拟链表综合判断
下列关于链表的说法，正确的是？
A单链表的每个结点都有一个指向前驱的指针
B双向循环链表中，头结点的 llink 指向 NULL
C链表比数组更适合需要频繁随机访问的场景
D带头结点的单链表在插入和删除首结点时无需特殊处理
✅ 正确答案：D
逐个分析：
A ❌ 单链表每个结点只有 next 指针指向后继，没有指向前驱的指针；双向链表才有。
B ❌ 双向循环链表中，头结点的 llink 指向尾结点，而非 NULL。
C ❌ 数组支持 O(1) 的随机访问（下标），链表需要 O(n) 遍历，因此数组更适合随机访问。
D ✅ 带头结点时，首有效结点是 head->next，插入和删除操作统一处理，无需对头指针进行特殊调整。

📌 链表重点速查表

单链表：data + next → 单向遍历 双向链表：llink + data + rlink → 双向遍历 循环链表：尾结点指向头结点
插入口诀：先接后断（先建新链，再改旧链） 删除关键：先跨越，再释放 头指针 = 链表入口（必需）
数组：随机访问 O(1)，插入/删除 O(n) 链表：随机访问 O(n)，插入/删除 O(1) 链式栈/队列：链表实现，所有操作 O(1)
双向循环链表插入：③→②→④→① 头结点作用：统一空表/首结点处理 链式结构解决：假溢出·固定大小
