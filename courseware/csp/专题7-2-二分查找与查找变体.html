1标准二分查找模板

二分查找（Binary Search）是在有序数组中查找目标值的高效算法， 时间复杂度 O(log n)，是 CSP-J 完善程序题最高频的算法考点之一。

1.1 左闭右闭区间模板（[l, r]）

这是最标准、最常用的二分查找写法。搜索区间包含左右两个端点，循环条件为 l <= r。

// 标准二分查找模板：在升序数组 a 中查找 target // 返回下标（存在）或 -1（不存在） int binarySearch(int a[], int n, int target) { int l = 0, r = n - 1; // 闭区间 [l, r] while (l <= r) { // 区间非空 int mid = l + (r - l) / 2; // 防溢出中点 if (a[mid] == target) return mid; // 找到目标 else if (a[mid] < target) l = mid + 1; // 目标在右半部分 else r = mid - 1; // 目标在左半部分 } return -1; // 未找到 }
关键要点

① 区间表示：l = 0, r = n-1，数组下标范围 [0, n-1]。
② 循环条件：l <= r——当 l > r 时区间为空，说明未找到。
③ 中点计算：mid = l + (r - l) / 2——防止 (l+r)/2 整数溢出（CSP-J 不常考溢出，但这是规范写法）。
④ 边界更新：每次排除 mid，新区间不含 mid：l = mid+1 或 r = mid-1。

1.2 左闭右开区间模板（[l, r)）

另一种常见写法，搜索区间左闭右开，循环条件为 l < r，常用于 STL 的 lower_bound 实现。

// 左闭右开写法：lower_bound 风格 // 返回第一个 >= target 的元素下标 int lowerBound(int a[], int n, int target) { int l = 0, r = n; // 区间 [l, r) while (l < r) { int mid = l + (r - l) / 2; if (a[mid] < target) l = mid + 1; // mid 在左边 else r = mid; // mid 可能是答案，保留 } return l; // l == r，即答案位置 }
🧠 两种模板的区别

l <= r（左闭右闭）：
  • r 初值为 n-1，更新时 r = mid-1
  • 循环结束后 l > r，l 是第一个大于 target 的位置

l < r（左闭右开）：
  • r 初值为 n，更新时 r = mid
  • 循环结束后 l == r，就是答案位置

易错点：模板混用是二分查找最常见的错误！l<=r 时用 r=mid 会死循环， l<r 时用 r=mid-1 可能漏掉答案。

2缺失元素查找（二分变体）

缺失元素查找是 2022 年和 2023 年 CSP-J 完善程序第一题的共同考点。 它利用二分查找的思想，在"有序数组中寻找第一个异常位置"。

2.1 问题模型

给定一个长度为 n 的有序数组 a，正常情况下数组应该是 0, 1, 2, ..., n-1（或从 1 开始），但其中缺失了一个元素， 后续元素依次前移（或有一个元素被替换）。我们要找的就是这个缺失的元素。

核心规律

对于索引 i：
  • 如果 a[i] == i（或 a[i] == i+1），说明 i 之前没有缺失元素。
  • 如果 a[i] > i（偏差），说明缺失元素在 i 的左边。

利用这个偏差性质，可以用二分查找在 O(log n) 时间内找到缺失位置。

2.2 标准缺失元素查找代码

// 在长度为 n 的升序数组 a 中寻找缺失的元素 // 正常情况 a[i] 应等于 i + start，其中 start 是起始值 // 返回缺失的那个元素值 int findMissing(int a[], int n) { int l = 0, r = n; while (l < r) { int mid = (l + r) / 2; if (a[mid] == mid) // 左侧完整，缺失在右边 l = mid + 1; else // a[mid] > mid，缺失在左边 r = mid; } return l; // 缺失的元素值 }
⚠️ 与标准二分查找的区别

区别 1：循环条件——缺失元素查找通常用 l < r，而不是 l <= r。
区别 2：相等时的处理——a[mid] == value 时说明左侧全部正确，缺失在右侧 → l = mid + 1。
区别 3：不相等时的处理——a[mid] != value 时说明这里已有偏差，缺失可能在左侧或就在 mid → r = mid。
区别 4：返回结果——循环结束时 l == r，这个位置就是缺失元素的值。

📌 记忆口诀："相等右移，不等左靠，循环一出，答案就到。"

3完全平方数判断（二分查找平方根）

完全平方数判断是 2024 年 CSP-J 完善程序第一题的考点。 核心思路：在 [1, n] 范围内二分查找 sqrt(n)， 判断是否存在整数 m 使得 m * m == n。

3.1 算法思路

对于一个正整数 n，如果它是完全平方数，则存在整数 m 满足 m * m == n。由于 m 一定在 [1, n] 范围内， 我们可以在这个区间上使用二分查找：

// 判断正整数 n 是否为完全平方数 bool isPerfectSquare(int n) { if (n < 1) return false; int l = 1, r = n; while (l <= r) { int mid = l + (r - l) / 2; if (mid == n / mid && n % mid == 0) // mid * mid == n return true; else if (mid < n / mid) // mid * mid < n l = mid + 1; else r = mid - 1; } return false; }
边界判断条件辨析

本题的关键在于边界判断条件。以下是三种常见的判断方式：

方式一（推荐）：if (mid * mid == n)——最直观，但 mid * mid 可能溢出 int 范围。
方式二（安全）：if (mid == n / mid && n % mid == 0)——避免溢出，CSP-J 常用此写法。
方式三（变体）：if (mid * mid <= n) l = mid + 1; else r = mid - 1;——最终判断 l-1 的平方是否为 n。

CSP-J 易考形式：用 mid * mid <= n 作为左移条件， 循环结束后检查 l-1 或 r 的平方是否等于 n。

4二分答案模板

二分答案（Binary Search on Answer）不是直接在数组上查找元素， 而是在答案的可能范围内进行二分，每次用 check(mid) 函数判断 当前答案是否可行，然后调整上下界。

4.1 最大值最小化模板

典型问题：将数组分成 k 段，使得各段和的最大值最小。

// 二分答案：最大值最小化模板 int l = 0, r = sum; // 答案在 [0, sum] 之间 while (l < r) { int mid = (l + r) / 2; if (check(mid)) // mid 作为最大值是可行的 r = mid; // 尝试更小的值 else l = mid + 1; // mid 不可行，需要更大的值 } cout << l; // 最小的可行值

4.2 最小值最大化模板

典型问题：在直线上放置 k 个点，使相邻点之间最小距离最大。

// 二分答案：最小值最大化模板 int l = 1, r = maxDist; while (l < r) { int mid = (l + r + 1) / 2; // 向上取整，避免死循环 if (check(mid)) // mid 作为最小值是可行的 l = mid; // 尝试更大的值 else r = mid - 1; // mid 不可行，需要更小的值 } cout << l; // 最大的可行值
🧠 二分答案死循环陷阱

最小值最大化中，mid = (l + r + 1) / 2 必须向上取整， 否则当 l + 1 == r 且 check(l) == true 时， mid 会等于 l，导致 l = mid = l，陷入死循环。

记忆技巧：
  • 最大值最小化（求最小可行值）：mid = (l+r)/2，if(ok) r=mid else l=mid+1
  • 最小值最大化（求最大可行值）：mid = (l+r+1)/2，if(ok) l=mid else r=mid-1

空 ①：r 的初值
  • 本题使用 while(l < r)（左闭右开风格）还是 while(l <= r)（左闭右闭风格）？
  • 看空 ④ 和 ⑤：l = mid + 1 和 r = mid（保留 mid）。
  • 由于 r = mid 保留了 mid，说明是左闭右开写法，r 初始化为 n-1。
  • 注意：左闭右开通常 r = n，但因为本题特殊边界设置，r = n-1 也是可行的。
  • 选 A（n - 1）。

空 ②：循环条件
  • 左闭右开写法 → l < r。
  • 选 A。

空 ③：判断条件
  • 如果 a[mid] == mid，说明从 0 到 mid 都没有缺失，缺失在右侧。
  • 选 A（==）。

  • 当 a[mid] == mid 时，缺失在右侧 → l = mid + 1。
  • 选 B（+ 1）。

  • 当 a[mid] != mid（即 a[mid] > mid）时，缺失在左侧或当前位置。
  • 保留 mid：r = mid。
  • 选 C（mid）。

  初始：l=0, r=3
  第1轮：mid=1, a[1]=1==1 → l=2
  第2轮：mid=(2+3)/2=2, a[2]=3!=3 → r=2
  l=2, r=2 → 退出 → 输出 2 ✅（缺失的元素就是 2）

📝2024 完善 1：完全平方数判断（真题）

以下程序改编自 2024 年 CSP-J 初赛完善程序第一题。 给定一个正整数 n，在 [1, n] 范围内 使用二分查找判断它是否为完全平方数。

  • 本题使用 while(l <= r)（左闭右闭风格）。

  • 当 mid * mid <= n 时，说明 mid 可能是平方根（或偏小），记录并向右查找。
  • 注意：这里用的是 <= 而不是 <，因为当 mid * mid == n 时也要记录 ans。
  • 选 D（<=）。

空 ③：左边界更新
  • mid * mid <= n 时，mid 太小或正好，向右查找更大值。
  • l = mid + 1。
  • 选 B（+ 1）。

空 ④：右边界更新
  • mid * mid > n 时，mid 太大，向左查找更小值。
  • r = mid - 1。
  • 选 A（- 1）。

  • 循环结束后，ans 是最后一个满足 mid*mid <= n 的 mid。
  • 如果 ans * ans == n，说明 n 是完全平方数，输出 ans。
  • 否则输出 0。
  • 选 A（==）。

  mid=5, 25<=16? 否 → r=4
  l=5 > r=4 → 退出 → ans=4, 4*4==16 → 输出 4 ✅

验证（n=10 — 不是完全平方数）：
  最后 ans=3, 3*3=9!=10 → 输出 0 ✅

📌 二分查找与查找变体速查表

以下总结了二分查找及其变体的标准模板和关键区别， 考前快速复习用。

场景区间类型r 初值循环条件相等时边界更新
标准查找 [l, r] n-1 l <= r 返回 mid l=mid+1 / r=mid-1
lower_bound [l, r) n l < r r=mid a[mid]<t → l=mid+1
upper_bound [l, r) n l < r l=mid+1 a[mid]<=t → l=mid+1
缺失元素 [l, r] n-1 l < r l=mid+1 r=mid（不排除mid）
判断平方数 [l, r] n l <= r 记录 ans, 继续右移 l=mid+1 / r=mid-1
最大值最小化 [l, r] 上界 l < r r=mid ok → r=mid / else l=mid+1
最小值最大化 [l, r] 上界 l < r l=mid mid 向上取整，ok → l=mid / else r=mid-1
💡 标准：l=0, r=n-1, while(l<=r), l=mid+1, r=mid-1 ✅ 缺失元素：while(l<r), a[mid]==mid → l=mid+1, else r=mid 🔍 平方根：while(l<=r), mid*mid<=n → ans=mid, l=mid+1 ⚠️ 死循环防：最小值最大化用 mid=(l+r+1)/2
📌 考场备忘

失分点 1：循环条件写错——l < r 和 l <= r 混用是二分最常见的错误。
失分点 2：边界更新写错——l = mid vs l = mid + 1，r = mid vs r = mid - 1。
失分点 3：完全平方数判断中，mid * mid 溢出但题目用了 long long 或避开乘法。
失分点 4：缺失元素查找中，不知道 a[mid] == mid 的比较含义。
失分点 5：二分答案的 check 函数写错，或分不清"最大值最小化"和"最小值最大化"的模板区别。

验证策略：选一个最简单的小数据（如 n=3, n=4）手动模拟一遍，比检查代码本身有效得多。
