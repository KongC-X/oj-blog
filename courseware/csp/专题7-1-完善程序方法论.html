1完善程序题型概述

完善程序是 CSP-J 初赛的第三大题，也是整张试卷中分值最高的题型。 试卷包含 2 个程序，每道题 15 分，合计 30 分，约占初赛总分的 40%。 每个程序挖 5 个空，每空 3 分。

题型结构

题号：试卷第三大题（第 37~46 题）
题量：2 个完整程序，每程序 5 个填空
分值：每空 3 分，共 30 分
形式：给出一个带有空缺的完整程序（约 20~40 行），要求在 4 个选项中选出正确的代码填入空白
难度分层：前 2~3 空较简单（如初始化、边界判断），后 2 空较难（如核心算法逻辑）

📌 与"阅读程序"的本质区别：
阅读程序是"理解已有代码"，完善程序是"补全缺失代码"——你不仅要读懂代码的意图， 还要理解每个空在整体算法中的作用，选对正确的实现方式。

难度定位：完善程序 > 阅读程序 > 选择题。
完善程序要求既懂算法、又懂代码实现，是初赛区分度最高的题型。
完善程序常见失分原因

原因 1：没看注释就做题——完善程序题通常有中文注释提示算法思路，忽略注释等于放弃重要线索
原因 2：只盯一个空，不看整体——每个空都是算法的一部分，脱离整体理解很难选对
原因 3：不代入数据验证——选完答案后直接用题目给出的输入数据模拟运行一遍
原因 4：纠结于"这段代码还能写成别的形式"——CSP-J 只考标准写法，不要发挥

2三遍法解题流程

解决完善程序题，不要一上来就逐空分析。三遍法是经过大量真题验证的最高效策略：

1 第一遍 · 读题 + 理解算法 — 读题面 + 注释 + main 函数，回答：这段程序在做什么？是求和？找极值？判断素数？还是某种经典算法？
2 第二遍 · 通读程序，找整体框架 — 顺着程序整体读一次，重点关注：
  • 初始化 — 变量和数组赋了什么初值？
  • 循环结构 — 循环的起点、终点、步长是什么？
  • 边界条件 — if 判断的边界是否与描述一致？
  • 返回值 / 输出 — 最终输出了什么？
3 第三遍 · 逐空推敲，代入验证 — 针对每个空，用"三要素检查法"检验选项，然后用题目给出的样例输入代入运行，验证每个空的选择。
🧠 三遍法的核心原则

第一遍是"定方向"——知道程序在做什么，后面才能有针对性地分析。
第二遍是"画地图"——知道整体代码结构后，每个空所处的"位置"就清晰了。
第三遍是"做选择"——在充分理解的基础上，用方法论选出正确选项。

警示：跳过第一、二遍直接去填第三遍的空，正确率往往不到 30%！

2.1 三要素检查法

对 每一个空，检查以下三个要素的一致性：

三要素检查法

要素一：初始值 — 变量/数组的初值是否正确？
  • 求最大值时，max 初始化为 -INF 还是 a[0]？
  • 累加求和时，sum 初始化为 0 还是 1？

要素二：循环体 — 循环中的操作是否符合算法逻辑？
  • 循环变量递增还是递减？
  • 循环条件是否包含等号？i < n vs i <= n

要素三：返回值 / 输出 — 最终结果是否正确？
  • 函数返回的是累加和还是中间值？
  • 输出的是最终结果还是临时变量？

📌 三要素检查口诀："初值对不误，循环跑不跑偏，返回对不对，三关过就是全对。"

3常见挖空位置及应对策略

经过对历年 CSP-J 真题的统计分析，完善程序的挖空位置集中在 6 个固定类型。 以下逐一分析每种位置的特征和应对策略：

挖空位置典型特征真题举例应对策略
初始化条件 变量/数组的初始赋值，通常在循环前 max = ___、f[0] = ___; f[1] = ___ 根据算法语义确定初值
循环结束条件 for / while 的条件部分 i < n 还是 i <= n，l < r 还是 l <= r 带入最小/最大边界验证
递归终止条件 递归函数开头的 if 判断 if (n <= 1) return ___ 用 n=0/n=1 时的结果反推
比较运算 if 中的 > / < / >= / <= if (a[i] ___ max) 检查大于还是大于等于
更新操作 循环体内的变量/数组赋值 f[i] = f[i-1] ___ f[i-2] 根据递推关系判断运算符
下标 / 索引 数组访问时的下标表达式 a[___]、s[i-1] vs s[i] 模拟前几轮循环，确定下标关系
挖空位置速查口诀

"初始化、循环界、递归止、比较符、更新式、下标处，六个位置常挖空，三遍法来一一过。"

4代入验证法

代入验证法是完善程序最有效的检查手段——用题目给出的样例输入，把每个空都填上你选的选项，然后手动模拟运行一遍。 如果输出与题目给出的输出一致，说明你的选择大概率是正确的。

代入验证的四个步骤

Step 1：准备数据 — 取题目样例输入（一般很简单，如 n=3, a=[1,2,3]）
Step 2：填写代码 — 在脑海中（或在草稿纸上）把你选的选项填入空中
Step 3：手动模拟 — 逐行运行代码，记录变量变化，得到输出结果
Step 4：对比验证 — 对比模拟输出与题目给出的样例输出是否一致

如果一致 → 你的选择很可能正确 ✅
如果不一致 → 重新检查该空（和之前受影响的空）

🧠 代入验证的注意事项

① 用最小的数据验证：比如 n=1, n=2，不要用复杂的大数据
② 验证所有空，不只看一个：有的空单独看没问题，但多个空格组合起来可能会出错
③ 特别验证边界：n=0 时程序会不会崩溃？循环是否至少执行一次？
④ 如果发现矛盾，从第一个空开始重新检查：有时排在前面的空错了，会影响后面所有的空

5题型特征快速识别

快速识别程序属于哪一类算法，能让你更快定位每个空填什么。以下是三类最常见的完善程序题型：

类型 1：二分查找类

识别特征：
  • 变量名常用 l（左）、r（右）、mid（中间）
  • 循环条件为 l < r 或 l <= r
  • 有 mid = (l + r) / 2 或类似计算

常见挖空：
  • 循环结束条件：l < r vs l <= r
  • 边界更新：l = mid + 1 vs l = mid
  • 中点计算防溢出：mid = l + (r - l) / 2

类型 2：动态规划类

识别特征：
  • 数组名常用 f、dp（动态规划数组）
  • 有明确的初始条件 f[0]、f[1]
  • 循环内有 f[i] = f[i-1] + f[i-2] 或类似递推式

常见挖空：
  • 边界初值设置
  • 递推关系的运算符（+、max、min）
  • 循环范围（i 从几开始到几结束）

类型 3：递归类

识别特征：
  • 函数体内调用自身
  • 开头的 if 为递归终止条件
  • 有参数变化：n-1、n/2 等

常见挖空：
  • 终止条件：n <= 1 vs n == 0
  • 递归调用的参数：f(n-1) vs f(n-2)
  • 返回值的组合方式：+、*、max

识别口诀

"l r mid 是二分，f dp 递推身，递归看终止与调用。
不是这三种也别慌，模拟 + 模拟就是王道。"

📝精选填空实战练习（共 10 题）

以下 10 道题以简短代码片段填空的形式呈现，每道题聚焦一个特定的完善程序技能。 填空处以 ____ 标记，请从选项中选择正确的一项填入。

✏️ 模拟题 · 初始化 考：sum 的初始值 + 循环条件
以下程序计算 1 到 n 的平方和。请选择填入空缺处的正确代码：

int n; cin >> n; int sum = ①; for (int i = 1; ②; i++) { sum += i * i; } cout << sum;
—— ① ——
A 0
B 1
C -1
D 不确定
—— ② ——
A i <= n
B i < n
C i > n
D i >= n
✅ 正确答案：① A (0) · ② A (i <= n)
分析：

空 ①：sum 的初始值
  • 累加求和，初始化为 0。
  • 如果初始化为 1，结果就会多 1。
  • 求和初值永远是 0，求积初值永远是 1。

空 ②：循环条件
  • 要计算 1² + 2² + ... + n²，必须包含 n。
  • 所以用 i <= n（i 从 1 到 n，包含 n）。
  • 如果用 i < n，当 n=2 时只会计算 1²，漏掉 2²。

验证（n=3）：
sum=0 → i=1: sum=0+1=1 → i=2: sum=1+4=5 → i=3: sum=5+9=14
1²+2²+3²=14 ✅
✏️ 模拟题 · 极值 考：max 初始化 + 比较符号
以下程序求数组 a 中的最大值。请选择填入空缺处的正确代码：

int n, a[100]; cin >> n; for (int i = 0; i < n; i++) cin >> a[i]; int maxVal = ①; for (int i = 1; i < n; i++) { if (a[i] ② maxVal) maxVal = a[i]; } cout << maxVal;
—— ① ——
A 0
B a[0]
C -1e9
D a[n-1]
—— ② ——
A >
B <
C >=
D <=
✅ 正确答案：① B (a[0]) · ② A (>)
分析：

空 ①：maxVal 的初始值
  • 求最大值有两种常见初始化方式：
  • 方式一（推荐）：maxVal = a[0]，然后从 i=1 开始循环
  • 方式二：maxVal = -INF（很小的数），然后从 i=0 开始循环
  • 本题从 i=1 开始循环，说明 maxVal 已经初始化为 a[0]，选 B

空 ②：比较符号
  • 找最大值，当前元素 a[i] 大于 maxVal 时更新
  • 所以用 a[i] > maxVal，选 A
  • 用 >= 也可以（当最大值有多个时结果一样）

验证（a=[3,7,2,9,5]）：
maxVal=a[0]=3 → i=1: 7>3 → maxVal=7 → i=2: 2>7 ✗ → i=3: 9>7 → maxVal=9 → i=4: 5>9 ✗ → 结果=9 ✅
📝 真题改编 · DP初始化 考：DP 边界值 + 递推关系

  • 斐波那契数列定义：f[0]=0, f[1]=1
  • 所以 f[0] = 0（① 选 A），f[1] = 1（② 选 B）

✏️ 模拟题 · 条件判断 考：比较运算 + 变量更新
以下程序判断正整数 n 是否为"完全数"（所有真因子之和等于 n）。请选择填入空缺处的正确代码：

int n; cin >> n; int sum = ①; for (int i = 1; i ② n; i++) { if (n ③ i == 0) sum += i; } if (sum ④ n) cout << "YES"; else cout << "NO";

  • 所以 i 从 1 到 n-1，条件用 i < n（不包含 n）。

📝 真题改编 · 二分 考：二分边界更新 + 循环条件
以下程序在升序数组 a 中查找目标值 target，返回其下标（不存在返回 -1）。请选择填入空缺处的正确代码：

int l = 0, r = n①; while (l ② r) { int mid = l + (r - l) / 2; if (a[mid] == target) return mid; else if (a[mid] < target) l = mid ③; else r = mid ④; } return ⑤;

空 ①：r 的初值
  • 数组下标范围是 0 到 n-1。
  • l = 0（第一个下标），r = n - 1（最后一个下标）。
  • 所以选 -1。

  • 当 l <= r 时说明搜索区间非空。
  • 如果用 l < r，当区间缩到只剩一个元素时循环就退出了。
  • 所以用 l <= r。

  • 当 a[mid] < target 时，目标在右半部分。

  • 当 a[mid] > target 时，目标在左半部分。
  • 新的右边界是 mid - 1。

空 ⑤：未找到时的返回值
  • 题目要求：不存在返回 -1。

l=0, r=4 → mid=2, a[2]=5==target → return 2 ✅
验证（target=6）：
l=0, r=4 → mid=2, a[2]=5<6 → l=3 → mid=3, a[3]=7>6 → r=2 → l=3>r=2 → 退出 → return -1 ✅
📝 真题改编 · 条件边界 考：循环边界 + 返回值类型
以下程序判断正整数 n 是否为素数。请选择填入空缺处的正确代码：

bool isPrime(int n) { if (n < 2) return ①; for (int i = 2; i ② n; i++) { if (n ③ i == 0) return ④; } return ⑤; }

  • 素数定义：大于 1 的自然数，除了 1 和自身外没有其他因子。
  • 0 和 1 都不是素数 → 返回 false。

  • 检查从 2 到 sqrt(n) 即可，但这里用 i < n（检查到 n-1）。

✏️ 模拟题 · 双指针 考：循环条件 + 下标更新

分析：

空 ①：r 初值
  • 数组 a 的下标范围是 0 到 n-1。
  • l 指向第一个元素（下标 0），r 指向最后一个元素（下标 n-1）。
  • 所以 r = n - 1，选择 -1。

空 ②：循环条件
  • 双指针相向而行，当 l < r 时说明两个指针还没相遇，需要交换。
  • 如果 l == r（奇数长度数组的中间元素），不需要交换。
  • 所以用 l < r。

空 ③：r 的更新
  • l 向右移动（l++），r 应该向左移动。
  • 所以 r--。

验证（a=[1,2,3,4,5]）：
l=0, r=4 → 交换 a[0]↔a[4] → [5,2,3,4,1] → l=1, r=3
→ 交换 a[1]↔a[3] → [5,4,3,2,1] → l=2, r=2 → l<r 不成立 → 退出 ✅

✏️ 综合提升 · DP思想 考：max 函数应用 + 状态转移 + 初始化
以下程序求数组 a 的最大子段和（连续子数组的最大和）。请选择填入空缺处的正确代码：

int n, a[100]; cin >> n; for (int i = 0; i < n; i++) cin >> a[i]; int dp = a[0]; int ans = a[0]; for (int i = 1; i < n; i++) { dp = max(a[i], ①); ans = max(ans, ②); } cout << ans;
—— ① ——
A dp + a[i]
B dp
C dp - a[i]
D a[i-1]
—— ② ——
A dp
B a[i]
C ans + a[i]
D dp + ans
✅ 正确答案：① A (dp + a[i]) · ② A (dp)
分析：

这是经典的 Kadane 算法（动态规划求最大子段和）。

核心思想：
  • dp 表示"以当前元素结尾的最大子段和"。
  • 对于每个元素 a[i]，要么它自己开始一个新子段（a[i]），要么接在前一个子段后面（dp + a[i]）。
  • 取两者的较大值：dp = max(a[i], dp + a[i])。

空 ①：dp 的更新公式
  • dp = max(a[i], dp + a[i]) — 看是接着加还是重新开始。
  • 所以选 dp + a[i]。

空 ②：ans 的更新（记录全局最大值）
  • ans = max(ans, dp) — 用当前结尾的最大值更新全局最大。
  • 所以选 dp。

验证（a=[-2,1,-3,4,-1,2,1,-5,4]）：

📌 完善程序"四步三关"速查表

以下总结了完善程序题的标准解题流程和检查要点， 每次做完善程序题时按此流程执行，可系统性地提高正确率。

步骤名称操作内容常见遗漏点
1 读题面 读题目描述 + 注释 + main 函数，回答：这段程序在做什么算法？ 忽略注释中的算法提示
2 通框架 重点关注：初始化变量、循环结构、边界条件、返回/输出 直接看单个空，不看整体
3 逐空推 用三要素检查法（初始值·循环体·返回值）逐一分析每个空 选了选项后不代入验证
4 代入验 用样例输入手动模拟，验证所有空的组合是否正确 只用脑想，不在纸上写变量变化

📌 考场备忘

做题顺序：完善程序放在试卷最后。建议先做选择题（15~20 分钟）， 再做阅读程序（25~30 分钟），最后做完善程序（15~20 分钟）。
时间分配：每题约 8~10 分钟。前 2~3 空通常比较简单（初始化、边界）， 后 2 空（核心算法）需要更多时间。
检查策略：所有空填完后，选一个最简单的输入数据（如 n=3）， 从头到尾手动模拟运行一遍，看输出是否合理。
不要空题：实在不会时，优先选择"看起来最自然"的选项 （如 sum=0、i<n、a[0] 等常见初值）。
