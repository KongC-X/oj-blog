1六种位运算符总览

C++ 提供了 6 种位运算符，直接对整数的二进制位进行操作。 它们是初赛阅读程序题的常客，也是各种进阶技巧的基础。

运算符名称含义示例（设 a=6=0110₂, b=3=0011₂）
&按位与对应位都是1才为1a & b = 0010₂ = 2
|按位或对应位至少一个1即为1a | b = 0111₂ = 7
^按位异或对应位不同为1，相同为0a ^ b = 0101₂ = 5
~按位取反0变1，1变0（注意符号位也会变）~a = 11111001₂（补码）= -7
<<左移所有位左移，低位补0，相当于 ×2a << 1 = 1100₂ = 12
>>右移所有位右移，相当于 ÷2（正数高位补0）a >> 1 = 0011₂ = 3
💡 记住：与(&)—"同1才1"、或(|)—"有1就1"、异或(^)—"不同则1"、取反(~)—"所有位翻转"、左移(<<)—"乘2"、右移(>>)—"除2"。
⚠️ 注意：& 和 && 的区别

& 是位运算符，对整数的每一位进行与运算；
&& 是逻辑运算符，将两侧转换为 bool 后做逻辑与。
同理 | 和 ||、^ 没有逻辑版本。

2x & (x-1) — 清除最低位的 1

这是位运算中最经典的技巧之一。表达式 x & (x-1) 的效果是： 将 x 二进制表示中最低位的 1 变成 0，其余位不变。

原理推导

设 x 的二进制为 ...100...0（最低位1在第 k 位，其后全是0）， 则 x-1 为 ...011...1（第 k 位变0，其后全变1）。 两者按位与后，第 k 位及之后全部为0，高位不变。

📌 示例：x = 12 = 1100₂

x = 1100₂（最低位1在第3位）
x-1 = 1011₂
x & (x-1) = 1000₂ = 8 ✅ 最低位的1被清除了

真题重现 · 2025 年第 2 题

📝 真题 · 2025 · 第 2 题 x & (x-1) 经典应用
int x = 255;
cout << (x & (x - 1));
以上代码的输出结果是？
A 255
B 254
C 128
D 0
✅ 正确答案：B · 254
详细推导：
① x = 255，255 的二进制 = 11111111₂（8个1）
② x - 1 = 254，二进制 = 11111110₂（最后1位变0）
③ x & (x-1) = 11111111₂ & 11111110₂ = 11111110₂ = 254

理解：255 的二进制全是1，最低位的1在 bit0。清除后得到 254。
考点：这就是 x & (x-1) 的典型效果——把最低位的1变成0。
💡 记忆方法："x & (x-1) = 去掉最后那个1" — 对任何正整数，这个操作都会让结果比 x 小且只少了最右边那个1。

3x & -x — 取最低位的 1

x & -x 称为 lowbit 操作，结果是只保留 x 最低位1的一个数。 这个技巧在树状数组和二进制枚举中广泛使用。

原理推导

计算机中负数用补码表示：-x = ~x + 1。
设 x = ...100...0（最低位1在k位），那么：

  • ~x = ...011...1（第k位变0，低位全变1，高位取反）
  • -x = ~x+1 = ...100...0（低位进位使第k位恢复为1）
  • x & -x = ...100...0（仅保留最低位1的值）
📌 示例：x = 12 = 1100₂

x = 1100₂，最低位1在 bit2（值为4）
-x = 0100₂（补码）
x & -x = 1100₂ & 0100₂ = 0100₂ = 4 ✅
结果 = 4，正是 22（最低位1对应的位权）。

4x >> k & 1 — 取第 k 位

要取出 x 的二进制第 k 位（从0开始编号），标准写法是：
(x >> k) & 1

原理

x >> k 将 x 右移 k 位，原第 k 位移动到最低位（bit0）；
然后 & 1 只保留最低位，其余位全部清零。
结果就是 0 或 1。

📌 示例：x = 13 = 1101₂，取第2位（从0开始）

二进制位编号（从低到高）：bit0=1, bit1=0, bit2=1, bit3=1
(13 >> 2) & 1 = (0011₂) & 1 = 3 & 1 = 1 ✅
结果=1，与 1101₂ 的第2位一致。

📝 应用场景：二进制枚举子集、状态压缩DP、逐位分析二进制数。CSP-J 阅读程序题中常用来遍历二进制数的每一位。

5判断一个数是否为 2 的幂

2 的幂的特征：二进制表示中有且仅有一个 1。利用 x & (x-1) 可以一键判断：

💡 核心公式

x > 0 && (x & (x-1)) == 0

原理

如果 x 是 2 的幂，二进制为 1...000（只有一个1）。
那么 x-1 为 0...111（原1的位置变0，后面全变1）。
两者 & 之后，所有位都是0 → 结果为0。
反之，如果 x 不止一个1，& 的结果一定不为0。

📌 示例验证

x = 16 = 10000₂ → x-1 = 01111₂ → & = 0 → 是2的幂 ✅
x = 12 = 01100₂ → x-1 = 01011₂ → & = 01000₂ ≠ 0 → 不是2的幂 ❌

6__builtin_popcount — 统计二进制中 1 的个数

GCC/Clang 提供的内建函数 __builtin_popcount(x)，返回 x 二进制中 1 的个数（population count）。

📌 示例

__builtin_popcount(0) → 0（0个1）
__builtin_popcount(7) = __builtin_popcount(111₂) → 3
__builtin_popcount(255) = __builtin_popcount(11111111₂) → 8
__builtin_popcount(16) = __builtin_popcount(10000₂) → 1

⚠️ 注意：如果 x 的类型是 long long，要使用 __builtin_popcountll(x)。
初赛选择题会直接考察该函数的返回值。

7异或 — XOR 的三大应用

7.1 基本性质

异或（^）具有以下重要性质，必须熟记：

  • a ^ a = 0 —— 任何数和自己异或得0
  • a ^ 0 = a —— 任何数和0异或保持不变
  • 交换律：a ^ b = b ^ a
  • 结合律：(a ^ b) ^ c = a ^ (b ^ c)

7.2 交换两个变量

int a = 3, b = 5; a = a ^ b; // a = 3^5 b = a ^ b; // b = (3^5)^5 = 3^0 = 3 a = a ^ b; // a = (3^5)^3 = 0^5 = 5 // 交换后 a=5, b=3 ✅ 无需临时变量
🎯 三步交换口诀

"a^b → b^=a → a^=b"
第一步：a = a ^ b（a暂存异或结果）
第二步：b = a ^ b（b变为原来的a）
第三步：a = a ^ b（a变为原来的b）

7.3 找出出现奇数次的数

给定一个数组，只有一个数出现奇数次，其余出现偶数次，用异或可以一次找出：
int ans = 0; for (int v : arr) ans ^= v; // ans 就是答案

原理：相同数异或得0，最后剩下的就是那个出现奇数次的数。

📝真题与模拟综合练习（共10题）

📝 真题 · 2025 · 第 2 题 x & (x-1) 清除最低位1
int x = 255;
cout << (x & (x - 1));
输出是什么？
A 255
B 254
C 128
D 0
✅ 正确答案：B · 254
推导过程：
255 = 11111111₂
254 = 11111110₂
11111111₂ & 11111110₂ = 11111110₂ = 254

核心知识点：x & (x-1) 清除 x 最低位的1。
255 的二进制全是 1，去掉最低位的1（bit0）后得到 254。
📝 真题 · 2021 · 阅读程序第1题改编 x & (x-1) 循环清零的次数
以下程序运行后，cnt 的值是多少？
int x = 42; // 42 = 101010₂ int cnt = 0; while (x) {   x = x & (x - 1);   cnt++; }
A 2
B 3
C 4
D 6
✅ 正确答案：B · 3
详细推导：
42 的二进制 = 101010₂（共3个1）

第1次循环：x = 42 = 101010₂
x-1 = 41 = 101001₂
x & (x-1) = 101000₂ = 40，cnt=1

第2次循环：x = 40 = 101000₂
x-1 = 39 = 100111₂
x & (x-1) = 100000₂ = 32，cnt=2

第3次循环：x = 32 = 100000₂
x-1 = 31 = 011111₂
x & (x-1) = 000000₂ = 0，cnt=3，循环结束

结论：cnt 刚好等于 42 二进制中 1 的个数。
x & (x-1) 每次消灭一个1，执行次数 = 二进制中1的个数。
📝 真题 · 2021 · 阅读程序第1题改编 x & -x 取最低位1
已知 x = 40（二进制 101000₂），x & -x 的结果是？
A 8
B 16
C 32
D 40
✅ 正确答案：A · 8
推导过程（lowbit 运算）：
x = 40 = 101000₂
最低位的1在 bit3（= 23 = 8）

-x = -40，补码表示 = ~40 + 1
先取反：~40 = 010111₂（只考虑6位）
再加1：010111₂ + 1 = 011000₂

x & -x = 101000₂ & 011000₂ = 001000₂ = 8 ✅

规律：x & -x 的结果就是 x 最低位1对应的值（2k）。
📝 真题 · 2022 · 阅读第2题改编 移位与按位与的综合
已知 int x = 85（二进制 01010101₂），
以下表达式的值不是 0 的是？
A x & (x >> 1)
B x & (x << 1)
C x & (x >> 2)
D x & (x >> 3)
✅ 正确答案：C · x & (x >> 2)
详细推导：
x = 85 = 01010101₂

A：x >> 1 = 00101010₂
& = 01010101₂ & 00101010₂ = 00000000₂ = 0
（每一位原数和对齐的位恰好相反）

B：x << 1 = 10101010₂（溢出的高位被丢弃）
& = 01010101₂ & 10101010₂ = 00000000₂ = 0

C：x >> 2 = 00010101₂
& = 01010101₂ & 00010101₂ = 00010101₂ = 21 ✅ 非0

D：x >> 3 = 00001010₂
& = 01010101₂ & 00001010₂ = 00000000₂ = 0

考点：85 = 01010101₂ 是交替位模式，右移1位后刚好错位，所有位错开，与运算结果为0。右移2位后 bit2、bit4 对齐，结果非0。
✏️ 模拟题 判断2的幂
以下哪个表达式可以正确判断一个正整数 x 是否为 2 的幂？
A x & (x-1) == 0
B x > 0 && (x & (x-1)) == 0
C x > 0 && (x & (x+1)) == 0
D x > 0 && (x | (x-1)) == 0
✅ 正确答案：B
选项分析：

A：x & (x-1) == 0 有运算符优先级问题！
实际上被解析为 x & ((x-1) == 0)，逻辑完全不对。
必须加括号：(x & (x-1)) == 0

B ✅：x > 0 && (x & (x-1)) == 0
先判断 x 为正数，再去掉最低位1后看是否为0。
如果 x 是2的幂（如 1,2,4,8,16...），二进制只有一个1，去掉后为0。

C：x & (x+1) 对2的幂结果不为0。
D：(x | (x-1)) == 0 不可能为0（除非 x=0，但 x>0 排除了）。
✏️ 模拟题 __builtin_popcount 应用
__builtin_popcount(63) 的返回值是多少？
（提示：63 = 32 + 16 + 8 + 4 + 2 + 1）
A 5
B 6
C 7
D 63
✅ 正确答案：B · 6
推导过程：
63 = 32 + 16 + 8 + 4 + 2 + 1
63 的二进制 = 111111₂（6个1）

__builtin_popcount(63) = 6

另一种方法：63 = 64 - 1 = 26 - 1，二进制就是6个1。

规律：2k - 1 的二进制是 k 个1，popcount = k。
✏️ 模拟题 异或交换变量
以下程序执行后，输出是什么？
int a = 7, b = 11; a = a ^ b; b = a ^ b; a = a ^ b; cout << a << " " << b;
A 7 11
B 11 7
C 4 4
D 0 0
✅ 正确答案：B · 11 7
逐步推导（利用异或性质 a^a=0, a^0=a）：

初始：a = 7 = 0111₂，b = 11 = 1011₂

第1步：a = a ^ b = 7 ^ 11
0111₂ ^ 1011₂ = 1100₂ = 12（a 暂存异或值）

第2步：b = a ^ b = 12 ^ 11
1100₂ ^ 1011₂ = 0111₂ = 7 ✅ b 变为了原来的 a

第3步：a = a ^ b = 12 ^ 7
1100₂ ^ 0111₂ = 1011₂ = 11 ✅ a 变为了原来的 b

结论：a=11, b=7，成功交换！

口诀：ab → ba → ab（三步异或，交换完毕）
✏️ 模拟题 x >> k & 1 取特定位
已知 int x = 0b10110110（二进制），
表达式 (x >> 4) & 1 的结果是？
A 0
B 1
C 4
D 16
✅ 正确答案：B · 1
推导过程：
x = 10110110₂（8位，位编号 bit7~bit0）

我们要取第4位（bit4，从0开始编号）。

二进制位编号：
bit7=1, bit6=0, bit5=1, bit4=1, bit3=1, bit2=0, bit1=1, bit0=0

计算：
x >> 4 = 右移4位 = 00001011₂ = 11
(x >> 4) & 1 = 00001011₂ & 00000001₂ = 00000001₂ = 1

验证：bit4 确实是1，结果正确。
✏️ 模拟题 位运算综合——运算符优先级
以下哪个表达式的值与其它三个不同？
（已知 int x = 13, y = 6）
A x & y | x ^ y
B (x & y) | (x ^ y)
C x | y
D (x | y) & (x ^ y)
✅ 正确答案：D
先计算结果（x=13=1101₂, y=6=0110₂）：
x & y = 1101₂ & 0110₂ = 0100₂ = 4
x ^ y = 1101₂ ^ 0110₂ = 1011₂ = 11
x | y = 1101₂ | 0110₂ = 1111₂ = 15

选项 A：x & y | x ^ y
注意优先级：& 优先级高于 |，所以等价于
(x & y) | (x ^ y) = 4 | 11 = 15

选项 B：(x & y) | (x ^ y) = 4 | 11 = 15

选项 C：x | y = 15

选项 D：(x | y) & (x ^ y) = 15 & 11 = 1011₂ = 11 ✅ 不同

考点：位运算符优先级排序：
~ > << >> > & > ^ > |
& 高于 ^ 高于 |
✏️ 综合模拟 位运算大综合
阅读以下程序，判断输出结果：
int x = 0b110110; int a = x & -x; // lowbit int b = x & (x-1); // 清除最低位1 int c = (x >> 2) & 1; // 取第2位 int d = __builtin_popcount(x); cout << a << "," << b << "," << c << "," << d;
A 4,52,1,4
B 2,52,1,4
C 2,52,0,4
D 4,54,1,3
✅ 正确答案：B · 2,52,1,4
完整推导：
x = 0b110110 = 110110₂ = 32 + 16 + 4 + 2 = 54

① a = x & -x（lowbit 取最低位1）：
x = 110110₂，最低位1在 bit1（值为 21 = 2）
-x = 001010₂（补码）
a = 110110₂ & 001010₂ = 000010₂ = 2 ✅

② b = x & (x-1)（清除最低位1）：
x-1 = 53 = 110101₂
b = 110110₂ & 110101₂ = 110100₂ = 32 + 16 + 4 = 52 ✅

③ c = (x >> 2) & 1（取第2位）：
x >> 2 = 001101₂ = 13
13 & 1 = 1 ✅（bit2 确实是1）

④ d = __builtin_popcount(x)：
x = 110110₂，1的位置：bit5, bit4, bit2, bit1 → 共 4 个 ✅

输出：2,52,1,4
