1标准二分查找基本原理

二分查找（Binary Search）是一种在有序数组中查找目标值的高效算法。 每次都取数组中间的元素与目标值比较，根据比较结果将搜索范围缩小一半，直到找到目标或范围为空。

二分查找的核心思想

前提条件：数组必须是有序的（通常为升序）。
核心操作：每次取 mid = (left + right) / 2，比较 arr[mid] 与目标值 target：
  • arr[mid] == target → 找到，返回 mid
  • arr[mid] < target → 目标在右半部分，left = mid + 1
  • arr[mid] > target → 目标在左半部分，right = mid - 1
终止条件：left > right → 未找到，返回 -1

1.1 分步演算：在有序数组中查找 9

给定有序数组 arr = [1, 3, 5, 7, 9, 11, 13, 15]，查找目标值 9。 数组长度为 8，索引范围为 [0, 7]。

L=0 → 索引: 0 1 2 3 4 5 6 7 ← R=7
数组: [1 3 5 7 9 11 13 15]
mid = (0+7)/2 = 3 → arr[3] = 7 < 目标 9 → left = mid + 1 = 4（去右半边）
L=4 → 索引: 4 5 6 7 ← R=7
数组: [9 11 13 15]
mid = (4+7)/2 = 5 → arr[5] = 11 > 目标 9 → right = mid - 1 = 4（去左半边）
L=4 → 索引: 4 ← R=4
数组: [9]
mid = (4+4)/2 = 4 → arr[4] = 9 == 目标 9 → ✅ 找到！返回索引 4
演算总结

比较次数：仅 3 次比较（mid=3→7, mid=5→11, mid=4→9）就找到了目标。
范围缩小过程：[0,7] → [4,7] → [4,4] → 找到。
如果是线性查找：需要 5 次比较（1→3→5→7→9）。
当数据量增大时，二分查找的优势更加明显。

标准二分查找代码模板

int binarySearch(int arr[], int n, int target) { int left = 0, right = n - 1; while (left <= right) { int mid = (left + right) / 2; // 取中点 if (arr[mid] == target) return mid; // 找到目标 if (arr[mid] < target) left = mid + 1; // 去右半边 else right = mid - 1; // 去左半边 } return -1; // 未找到 }

2缺失元素查找（二分变体）

2022 和 2023 年 CSP-J 完善程序题均考查了同一种二分变体： 在一个原本完整的有序序列中移除一个元素，要求在 O(log n) 时间内找出被移除的元素。

问题模型

原始数组：a[0..n-1] 包含 1 到 n 的所有整数（顺序排列）。
操作：从中移除一个元素，剩余 n-1 个元素存入 b[0..n-2]。
目标：找出被移除的那个元素。

二分思路：比较 a[mid] 与 b[mid]。
  • 如果 a[mid] == b[mid] → 移除的元素在 右侧（mid 之前没有缺失）
  • 如果 a[mid] != b[mid] → 移除的元素在 左侧或就是 mid

示例：从 [1,2,3,4,5,6,7] 中移除 4

a = [1, 2, 3, 4, 5, 6, 7]  （完整，n=7）
b = [1, 2, 3, 5, 6, 7]  （移除了 4，n-1=6）
第 1 步 → mid = 3, a[3]=4, b[3]=5 → a[3]≠b[3] → 缺失在左边或就是 a[3]
第 2 步 → mid = 1, a[1]=2, b[1]=2 → a[1]==b[1] → 缺失在右侧
第 3 步 → mid = 2, a[2]=3, b[2]=3 → a[2]==b[2] → 缺失在右侧
→ 此时 left = 3, a[3] = 4 即为被移除的元素 ✅
// 2022/2023 完善程序核心代码 int findMissing(int a[], int b[], int n) { int left = 0, right = n - 1; while (left < right) { int mid = (left + right) / 2; if (a[mid] == b[mid]) left = mid + 1; // 缺失在右侧 else right = mid; // 缺失在左侧或就是 mid } return a[left]; // 被移除的元素 }
📌 2022 完善 1 与 2023 完善 1： 两年考查的是同一个模型——在有序数组中找出被移除的元素。 二分的关键在于比较 a[mid] 和 b[mid] 是否相等。

3完全平方数判断（二分优化）

2024 年 CSP-J 完善程序第 1 题考查了如何高效判断一个正整数是否为完全平方数。 常规思路是从 1 遍历到 sqrt(n)，但可以用二分查找将时间复杂度从 O(√n) 优化到 O(log n)。

问题模型

问题：给定正整数 n，判断它是否是一个完全平方数。
二分思路：在 [1, n] 范围内二分查找一个数 x，使得 x * x == n。
由于 x 最大不会超过 sqrt(n)，所以右边界可以直接设为 n（或 sqrt(n) 的整数部分）。

与标准二分的区别：这里的"数组"是隐式的——[1, 2, 3, ..., n] 每个数的平方值构成单调递增序列。

示例：判断 16 是否为完全平方数

在 [1, 16] 中二分查找 x，使得 x² = 16
第 1 步 → L=1, R=16, mid=8, 8²=64 > 16 → R=7
第 2 步 → L=1, R=7, mid=4, 4²=16 == 16 → ✅ 是完全平方数！
为什么不直接遍历？

遍历到 sqrt(n)：时间复杂度 O(√n)。如果 n=10¹²，需要 10⁶ 次运算。
二分查找：时间复杂度 O(log n)。如果 n=10¹²，只需约 40 次运算。
这就是二分优化的威力！

// 2024 完善 1：判断完全平方数（二分版本） bool isPerfectSquare(int n) { int left = 1, right = n; while (left <= right) { int mid = (left + right) / 2; long long sq = (long long)mid * mid; // 防溢出 if (sq == n) return true; if (sq < n) left = mid + 1; else right = mid - 1; } return false; }
📌 2024 完善 1：题目中给出的二分搜索判断完全平方数的方法， 本质上是将"枚举可能的平方根"转化为"在有序范围内二分查找"。 这一思想可以推广到所有单调函数求值问题中。

4二分答案模板

二分答案不是二分查找数组中某个值，而是二分可能的答案范围， 每次验证当前答案是否可行，从而逼近最优解。适用于"最大值最小化"和"最小值最大化"问题。

二分答案 vs 二分查找

二分查找二分答案
搜索对象数组中的元素可能的答案值
判断方式arr[mid] == target ?check(mid) 是否可行 ?
适用条件数组有序答案范围确定且单调（可行→不可行）

4.1 最大值最小化（最小化最大值）

经典问题：将一个数组分成 k 段，使每段和的最大值尽可能小。
二分策略：二分可能的"最大段和"，判断是否能分成 ≤k 段。

// 二分答案通用模板 int left = 最小可能值, right = 最大可能值; while (left < right) { int mid = (left + right) / 2; if (check(mid)) // mid 作为答案是否可行？ right = mid; // 可行，尝试更小的值（最大值最小化） else left = mid + 1; // 不可行，需要更大的值 } return left; // 最优解

4.2 最小值最大化（最大化最小值）

经典问题：在数轴上放置 k 头牛（或 k 个点），使它们之间的最小距离尽可能大。
二分策略：二分可能的"最小距离"，判断是否能放下 k 头牛。

🧠 记忆口诀

"二分答案，验证为王" — 关键不在于怎么二分，而在于如何编写 check() 函数。
"最大最小化，可行就缩右" — 最大值最小化时，可行则 right = mid。
"最小最大化，可行就增左" — 最小值最大化时，可行则 left = mid。

5二分的时间复杂度 O(log n)

2024 年 CSP-J 阅读程序第 1 题直接考查了二分查找的时间复杂度分析。

O(log n) 的推导

假设数组长度为 n，每次比较后搜索范围减半：

  第 1 次比较后：范围变为 n/2
  第 2 次比较后：范围变为 n/4
  第 k 次比较后：范围变为 n / 2^k

当范围缩小到 1 时停止：n / 2^k = 1
解得：2^k = n，即 k = log₂(n)

所以二分查找的时间复杂度为 O(log n)。

O(log n) 究竟有多快？

数据规模 nO(log n) 比较次数O(n) 比较次数差距倍数
1,000≈ 10 次1000 次100×
10,000≈ 14 次10000 次~714×
100,000≈ 17 次100000 次~5882×
1,000,000≈ 20 次1000000 次50000×
1,000,000,000≈ 30 次10⁹ 次~3333 万倍
💡 初赛常考：给定数据规模 n，问二分查找最多需要比较多少次。 答案就是 ⌈log₂(n+1)⌉（向上取整）。
例如 n=1000，最多需要 ⌈log₂(1001)⌉ = 10 次比较。

📝 真题 · 2024 · 阅读 1 二分查找时间复杂度
二分查找算法在一个长度为 n 的有序数组中查找目标值， 其时间复杂度是（ ）。
A O(1)
B O(log n)
C O(n)
D O(n²)
✅ 正确答案：B · O(log n)
分析：

二分查找每次比较后搜索范围减半。设比较次数为 k，则有：
n / 2^k = 1 → k = log₂(n)

原因澄清：
A. O(1) ❌ — 数组为 1 时才是 O(1)，n 变化时比较次数会变。
B. O(log n) ✅ — 每次范围减半，只需 log₂(n) 次比较。
C. O(n) ❌ — 这是线性查找的时间复杂度，二分没这么慢。
D. O(n²) ❌ — 这是冒泡排序之类算法的时间复杂度。

结论：二分查找的时间复杂度是 O(log n)。

📝 真题 · 2022/2023 · 完善程序 缺失元素查找（二分变体）
已知数组 a 包含 1~n 的所有整数（顺序排列），数组 b 是 a 移除了一个元素后的结果。 以下二分算法用于找出被移除的元素，横线处应填（ ）。

int findMissing(int a[], int b[], int n) { int left = 0, right = n - 1; while (left < right) { int mid = (left + right) / 2; if (______) // 横线处 left = mid + 1; else right = mid; } return a[left]; }
A a[mid] == b[mid]
B a[mid] < b[mid]
C a[mid] > b[mid]
D a[mid] != b[mid]
✅ 正确答案：A · a[mid] == b[mid]
分析：

关键思路：
因为 a 包含 1~n 的完整序列，b 移除了一个元素。
对于小于缺失元素的位置，a[mid] 和 b[mid] 指向相同的值（相等）。
对于大于等于缺失元素的位置，b[mid] 比 a[mid] 大 1（因为 b 少了一个前面的数，整体偏移）。

例如 n=7，a=[1,2,3,4,5,6,7]，移除 4 后 b=[1,2,3,5,6,7]：
  mid=0: a[0]=1, b[0]=1 → 相等，缺失在右侧 ✅
  mid=1: a[1]=2, b[1]=2 → 相等，缺失在右侧 ✅
  mid=2: a[2]=3, b[2]=3 → 相等，缺失在右侧 ✅
  mid=3: a[3]=4, b[3]=5 → 不相等，缺失在左侧或就是 a[3] ✅

算法逻辑：
当 a[mid] == b[mid] 时，说明在 mid 位置之前没有发生缺失， 缺失的元素在 mid 右侧 → left = mid + 1。
当 a[mid] != b[mid] 时，缺失的元素在 mid 处或在 mid 左侧 → right = mid。

结论：横线处应填 a[mid] == b[mid]，选 A。

✏️ 模拟题 · 二分答案 最小值最大化（牛棚问题）
数轴上有 5 个牛棚位置 [1, 2, 8, 4, 9]（排序后为 [1, 2, 4, 8, 9]）， 需要放入 3 头牛，要求每两头牛之间的最小距离尽可能大。用二分答案求解， 二分过程中 check(mid) 判断是否能放下 3 头牛。当 mid=3 时， 以下说法正确的是（ ）。
A 可以放下 3 头牛，check(3) 返回 true
B 只能放下 2 头牛，check(3) 返回 false
C 可以放下 4 头牛，check(3) 返回 true

分析：

尝试最小距离=3，模拟放置过程：

步骤操作已放牛数
1第一头牛放 1 号位置1
2下一个位置 2，距离=1 < 3 → 跳过1
3位置 4，距离=4-1=3 ≥ 3 → 放牛2
4位置 8，距离=8-4=4 ≥ 3 → 放牛3 ✓

验证成功：当最小距离设为 3 时，可以在位置 1, 4, 8 放下 3 头牛。
所以 check(3) = true。

继续二分：
check(3)=true → 尝试更大的最小距离（去右半边）→ left=mid+1

结论：选 A。
✏️ 模拟题 · 二分变体 查找第一个出现位置
在有序数组 [1, 2, 2, 2, 3, 4, 5] 中， 用二分查找找 2 的第一个出现位置（最左边的索引）。 找到的结果是（ ）。
A 0
B 1
C 2
D 3
✅ 正确答案：B · 1
分析（查找第一个 ≥ target 的位置）：

查找目标值 2 的第一个出现位置，即找"第一个 ≥ 2"的元素。
数组: [1, 2, 2, 2, 3, 4, 5]，索引 0~6

二分过程（变体：找到后不返回，继续向左缩小）：

轮次LRmidarr[mid]操作
10632（等于目标）不返回！R=2（继续向左找）
20212（等于目标）R=0（继续向左找）
30001 < 2L=1
L=1, R=0 → 循环结束（L > R），返回 L=1

关键区别：标准二分查找找到目标就直接返回，而查找第一个出现位置找到后不返回， 继续向左缩小范围（right = mid - 1），直到范围为空，最终返回 left。 同理，查找最后一个出现位置找到后继续向右（left = mid + 1）。

结论：2 的第一个出现位置是索引 1，选 B。
✏️ 综合模拟 · 概念辨析 二分查找与二分答案综合判断
以下关于二分查找与二分答案的描述，错误的是（ ）。
A 二分查找要求数组必须是有序的
B 二分查找的时间复杂度是 O(log n)
C 二分答案可以解决所有"最大值最小化"问题
D 二分答案的核心在于 check() 函数的正确实现
✅ 正确答案：C · 二分答案可以解决所有"最大值最小化"问题
逐一分析：

A. 二分查找要求数组必须是有序的
✅ 正确。二分查找利用有序性来缩小搜索范围。 如果数组无序，二分查找无法保证正确性。这是二分查找的基本前提。

B. 二分查找的时间复杂度是 O(log n)
✅ 正确。每次比较将搜索范围减半，因此需要 O(log n) 次比较。

C. 二分答案可以解决所有"最大值最小化"问题
❌ 错误。二分答案适用需要满足单调性条件： 答案的可行性与答案值之间必须具有单调性（即如果 mid 可行，则所有大于/小于 mid 的值也具有某种规律）。 并非所有"最大值最小化"问题都天然满足单调性。

D. 二分答案的核心在于 check() 函数的正确实现
✅ 正确。二分答案的框架是固定的，不同问题的区别在于 check(mid) 函数的实现——它决定了如何验证一个候选答案是否可行。 如果能写出正确的 check 函数，二分答案就成功了一大半。

结论：C 是错误描述。二分答案不能解决所有最优化问题，需要满足单调性条件。
