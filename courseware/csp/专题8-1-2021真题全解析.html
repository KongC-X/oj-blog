📝 第 1 题 计算机基础 · 编程语言分类
以下不属于面向对象程序设计语言的是？
AC++
BPython
CJava
DC
✅ 正确答案：D（C 语言）
解析：
· C 语言是面向过程（Procedure-Oriented）的编程语言，不是面向对象。
· C++ 是 C 的超集，同时支持面向过程和面向对象编程（多范式）。
· Python 和 Java 都是面向对象语言。

易混淆：C++ 虽然名字带"++"表示是 C 的增强版，但它已经引入了类、继承、多态等面向对象特性。
📝 第 2 题 计算机基础 · 奖项常识
以下奖项与计算机领域最相关的是？
A奥斯卡奖
B图灵奖
C诺贝尔奖
D普利策奖
✅ 正确答案：B（图灵奖）
解析：
· 图灵奖（Turing Award）由ACM（美国计算机协会）于 1966 年设立，是计算机领域的最高荣誉，被誉为"计算机界的诺贝尔奖"。
· 奥斯卡奖 → 电影艺术领域
· 诺贝尔奖 → 物理、化学、生理学或医学、文学、和平、经济学
· 普利策奖 → 新闻、文学、音乐

知识点：图灵奖以艾伦·图灵的名字命名。
📝 第 3 题 计算机基础 · 数据表示
目前主流的计算机储存数据最终都是转换成什么形式的数据储存？
A二进制
B十进制
C八进制
D十六进制
✅ 正确答案：A（二进制）
解析：
计算机内部所有数据——数字、文字、图片、声音、视频——最终都以二进制（0 和 1）形式存储和处理。
原因：电子元件天然具有两种稳定状态（高电平/低电平、通/断），对应 1 和 0，物理实现最简单可靠。
十进制、八进制、十六进制只是二进制的人为表示形式，方便人类阅读。
📝 第 4 题 算法基础 · 比较次数
N 个数中找最大数，最坏情况下最少比较次数是？
AN
BN + 1
CN - 1
DlogN
✅ 正确答案：C（N - 1）
解析：
找最大数的标准算法：先取第一个数为最大值，然后与剩余 N-1 个数逐个比较，每比较一次淘汰一个候选，总共比较 N-1 次。
这种策略在"最坏情况"下（即最大值在 最后一个位置）仍然只需比较 N-1 次。

推广：找最大值和最小值需要 ⌈3N/2⌉ - 2 次比较（分治策略）。
📝 第 5 题 数据结构 · 栈
入栈顺序为 a, b, c, d, e，以下哪个不是合法的出栈序列？
Aa, b, c, d, e
Be, d, c, b, a
Cb, c, d, e, a
Dc, d, a, e, b
✅ 正确答案：D（c, d, a, e, b）
解析：
用栈模拟验证 D 选项 c, d, a, e, b：
· push a, push b, push c → pop c ✓
· push d → pop d ✓（此时栈中从底到顶为 a, b）
· 要 pop a 时，a 上面还有 b，所以 a 不能先于 b 出栈 ✗

核心规律：在栈中，后入栈的元素必须先出栈（LIFO）。 如果某个元素 x 出栈时，栈内还有比 x 后入栈但在 x 上方的元素， 则这个顺序是非法的。
📝 第 6 题 图论 · 树与连通
无向连通图有 n 个顶点 m 条边，删掉多少条边后可以变成一棵树？
An
Bm
Cm - n
Dm - n + 1
✅ 正确答案：D（m - n + 1）
解析：
· 一棵 树 有 n 个顶点，恰好有 n - 1 条边。
· 当前图有 m 条边，要变成树需要删掉 m - (n - 1) = m - n + 1 条边。
· 删除后必须保持连通性，所以只能删掉构成环路的边（即多余边）。

快速记忆：树边数 = 顶点数 - 1，删边数 = 当前边数 - 树边数 = m - (n-1) = m-n+1。
📝 第 7 题 进制转换 · 二进制到十进制
二进制数 101.11 对应的十进制数是？
A6.5
B5.5
C5.75
D5.25
✅ 正确答案：C（5.75）
解析：
101.112 = 1×2² + 0×2¹ + 1×2⁰ + 1×2⁻¹ + 1×2⁻²
= 4 + 0 + 1 + 0.5 + 0.25
= 5.75

注意：二进制小数部分，小数点后第 1 位是 2⁻¹ = 0.5，第 2 位是 2⁻² = 0.25。
📝 第 8 题 数据结构 · 完全二叉树
高度为 5 的完全二叉树有多少种不同形态？（根固定，每层可缺最后一层右边的部分）
A16
B15
C4
D8
✅ 正确答案：A（16）
解析：
· 高度为 5 的完全二叉树，前 4 层是满的（共 1+2+4+8 = 15 个节点）。
· 第 5 层最多可以有 16 个节点。
· 完全二叉树的特点：第 5 层的节点必须从左向右连续排列， 不能中间空缺。所以第 5 层可以有 0, 1, 2, ..., 16 个节点，共 17 种情况。
· 但题目说"高度为 5"意味着高度就是 5（根深度为 1），所以第 5 层至少要有 1 个节点， 否则高度就是 4 了。
· 因此可能的节点数为 1 ~ 16，共 16 种不同形态。
📝 第 9 题 数据结构 · 表达式求值
表达式 a * (b + c) * d 的后缀表达式是？
Aa b c d + *
Ba b c + * d *
Ca b c * + d
Da + b c d + *
✅ 正确答案：B（a b c + * d *）
解析（中缀转后缀 — 运算符优先级法）：
· 原式：a * (b + c) * d
· 先算括号内的 b + c → 后缀为 b c +
· 然后 a 乘上 (b+c) → a b c + *
· 再乘 d → a b c + * d *

后缀表达式求值规则：遇到数字入栈，遇到运算符弹出两个数字计算结果后入栈。
📝 第 10 题 组合数学 · 分组计数
6 人两人一队共分成三队（不区分编号），有多少种分法？
A15
B30
C45
D60
✅ 正确答案：A（15）
解析：
· 先选第 1 队：C(6,2) = 15 种
· 再从剩余 4 人选第 2 队：C(4,2) = 6 种
· 最后 2 人自动成第 3 队：C(2,2) = 1 种
· 因为三队不区分编号，需要除以 3! = 6（去掉队伍顺序）
· 总方案数 = 15 × 6 × 1 ÷ 6 = 15

公式：将 n 个元素分成 k 组每组 m 个（不区分组标号）， 方案数为 C(n,m) × C(n-m,m) × ... ÷ k!
📝 第 11 题 算法策略 · 哈夫曼编码
哈夫曼编码本质上是一种什么策略？
A枚举
B贪心
C递归
D动态规划
✅ 正确答案：B（贪心）
解析：
哈夫曼编码的构建过程：每次合并权值最小的两个结点， 构建一棵哈夫曼树。
· 这种"每一步都选择当前最优"（局部最优）的策略，期望达到全局最优（带权路径长度 WPL 最小），是典型的贪心算法。
· 枚举 → 暴力搜索所有可能方案
· 递归 → 函数调用自身的编程技巧
· 动态规划 → 子问题重叠 + 最优子结构

证明：哈夫曼编码的贪心策略是最优的（通过交换论证法证明）。
📝 第 12 题 组合数学 · 数字排列
用数字 1, 1, 2, 2, 3 可以组成多少个不同的三位数？
A18
B15
C12
D9
✅ 正确答案：A（18）
解析（分类讨论法）：

情况 1：三个数字各不相同——用 1,2,3
· 排列数 = 3! = 6 种

情况 2：两个 1 + 一个其他数字——用 1,1,2 或 1,1,3
· 对 (1,1,2)：3 个位置放 2 → C(3,1) = 3 种
· 对 (1,1,3)：3 个位置放 3 → C(3,1) = 3 种
· 小计：3 + 3 = 6 种

情况 3：两个 2 + 一个其他数字——用 2,2,1 或 2,2,3
· 对 (2,2,1)：C(3,1) = 3 种
· 对 (2,2,3)：C(3,1) = 3 种
· 小计：3 + 3 = 6 种

总计：6 + 6 + 6 = 18 种
📝 第 13 题 算法基础 · 递归函数
已知递归函数 solve(n) 定义如下： 
int solve(int n) {
    if (n <= 1) return 1;
    if (n % 2 == 1) return n * solve(n - 2);
    return solve(n - 1);
}
则 solve(7) 的返回值是？
A105
B7
C21
D1
✅ 正确答案：A（105）
解析（手动展开递归）：
solve(7) = 7 × solve(5) （7 是奇数）
    = 7 × 5 × solve(3)
    = 7 × 5 × 3 × solve(1)
    = 7 × 5 × 3 × 1
    = 105

注意：当 n 是偶数时（如 solve(4)），函数会调用 solve(3)， 即偶数直接减 1 变成奇数后继续递归。
📝 第 14 题 图论 · DFS 遍历
给定如下图（无向图，顶点 A~D），从不同起点开始 DFS 遍历， 最后一个遍历到的顶点有几种可能？ 
    A --- B
    |     |
    |     |
    C --- D
（图：4 个顶点组成一个环，A-B-D-C-A 各有一条边，即一个 4 元环）
A1
B2
C3
D4
✅ 正确答案：B（2 种）
解析：
4 个顶点的环图，考虑 DFS 遍历（按照邻接点顺序访问）：

· 从 A 出发：可能的遍历顺序之一是 A → B → D → C，最后一个点是 C。
· 从 A 出发的另一方向：A → C → D → B，最后一个点是 B。
· 从 B 出发：B → A → C → D，最后一个点是 D。
· 从 D 出发：D → C → A → B，最后一个点是 B。

综合考虑所有起点和遍历顺序，最后一个被遍历到的点可能是两个不同的顶点。 具体是哪两个取决于图的对称性和邻接顺序。

在本图中，事实上可能的"最后一个点"只有 2 种情况。
📝 第 15 题 数据结构 · 二叉树存储
一个包含 n 个结点的二叉树采用二叉链表存储（每个结点包含左孩子指针 left 和右孩子指针 right）， 则其中空指针的数目为？
An
Bn + 1
C2n
Dn - 1
✅ 正确答案：B（n + 1）
解析：
· n 个结点的二叉树，每个结点有 2 个指针域，一共 2n 个指针。
· 一棵二叉树有 n 个结点，则有 n - 1 条边（即 n-1 个非空指针，每个非空指针就是一条边）。
· 空指针数 = 总指针数 - 非空指针数 = 2n - (n - 1) = n + 1

快速记忆：二叉链表存储中，空指针 = 结点数 + 1。
特例验证：一个根结点 n=1，左空右空，空指针 = 2 = 1+1 ✅

二阅读程序（4 大题，共 40 分）

阅读程序题要求理解代码功能、分析执行结果。 以下按 2021 年 CSP-J 真题的 4 道阅读程序逐一解析。

阅读程序 1（10 分）—— 位运算

知识点：位运算（popcount / lowbit）、x & (x-1) 技巧

#include <iostream> using namespace std; int f1(int x) { int cnt = 0; while (x) { cnt++; x = x & (x - 1); } return cnt; } int f2(int x) { return x & -x; } int main() { int n; cin >> n; cout << f1(n) << " " << f2(n) << endl; return 0; }
📌 函数功能速览

· f1(x)：统计 x 的二进制表示中 1 的个数（每次用 x & (x-1) 去掉最低位的 1）。
· f2(x)：取 x 的二进制中 最低位的 1 所对应的值（如 x=12=1100₂，f2(12)=4）。
· 注意：x & -x 利用了补码的性质，-x = ~x + 1。

📝 阅读题 (1) 判断题 · f1(7)
输入 n = 7，f1(n) 返回 7。
A正确
B错误
✅ 正确答案：B（错误）
7 的二进制是 111（3 个 1），所以 f1(7) 返回 3，不是 7。
每次循环 x & (x-1) 去掉一个 1：111 & 110 = 110 → 110 & 101 = 100 → 100 & 011 = 000。循环 3 次。
📝 阅读题 (2) 判断题 · f2(7)
输入 n = 7，f2(n) 返回 1。
A正确
B错误
✅ 正确答案：A（正确）
7 的二进制是 111，最低位的 1 对应 2⁰ = 1。
f2(7) = 7 & -7，-7 的补码为 ...111001，与 000111 按位与得 000001 = 1。
📝 阅读题 (3) 选择题 · f1(8) 和 f2(8)
f1(8) 和 f2(8) 的值分别是？
A1 和 8
B8 和 1
C1 和 1
D8 和 8
✅ 正确答案：A（1 和 8）
8 的二进制是 1000，只有 1 个 1，所以 f1(8)=1。
最低位的 1 就是 8 本身（2³=8），所以 f2(8)=8。
📝 阅读题 (4) 判断题 · 代码等价性
若将 f1 中的 x = x & (x - 1) 改为 x = x - (x & -x)， 程序功能不变。
A正确
B错误
✅ 正确答案：A（正确）
x & (x-1) 的作用是去掉最低位的 1。
x - (x & -x)：x & -x 取出最低位的 1， 然后用 x 减去它，也是去掉最低位的 1。
两种写法功能完全相同，都用于统计二进制中 1 的个数。

阅读程序 2（10 分）—— Base64 解码

知识点：Base64 编码原理、字符映射、位运算

#include <iostream> #include <string> using namespace std; const string table = "ABCDEFGHIJKLMNOPQRSTUVWXYZ" "abcdefghijklmnopqrstuvwxyz" "0123456789+/"; int idx(char c) { for (int i = 0; i < 64; i++) if (table[i] == c) return i; return 0; } string decode(string s) { string res; int n = s.length(); for (int i = 0; i < n; i += 4) { int a = idx(s[i]); int b = idx(s[i+1]); int c = idx(s[i+2]); int d = idx(s[i+3]); int x = (a << 18) | (b << 12) | (c << 6) | d; res += char((x >> 16) & 0xFF); res += char((x >> 8) & 0xFF); res += char(x & 0xFF); } return res; } int main() { string s; cin >> s; cout << decode(s) << endl; return 0; }
💡 Base64 解码原理

Base64 将每 3 个字节（24 位）编码为 4 个字符（每字符 6 位）。
· 编码表共 64 个字符：A-Z (0-25), a-z (26-51), 0-9 (52-61), +(62), /(63)
· 解码是编码的逆过程：4 个字符 → 24 位 → 3 个字节
· idx(c)：查找字符 c 在编码表中的位置（0~63）
· 每 4 个字符解码为 3 个字节：用位运算将 4 个 6 位值拼接成 24 位，再拆成 3 个 8 位值

📝 阅读题 (1) 功能理解 · 选择题
上述程序的主要功能是？
A将字符串编码为 Base64
B将 Base64 字符串解码为原文
C对字符串进行压缩
D对字符串进行加密
✅ 正确答案：B（Base64 解码）
程序中的 decode 函数将 Base64 编码的字符串还原为原始数据。 每 4 个字符通过查表得到 4 个 6 位值，拼接为 24 位后拆成 3 个字节。
📝 阅读题 (2) 运行结果 · 选择题
输入 "QQ=="（假设 `=` 不调用 idx，而是特殊处理），输出的第一个字符是什么？ （已知 'Q' 在编码表中的索引为 16）
A'A'
B'Q'
C空格
D无法确定
✅ 正确答案：A（'A'）
'Q' 的索引为 16 = 010000₂。
a=16, b=16，拼接：x = (16<<18)|(16<<12) = 010000|010000|000000|000000
第一个字节 = (x >> 16) & 0xFF = 01000001 = 65 = 'A'。

阅读程序 3（10 分）—— 线性筛 / 欧拉筛

知识点：线性筛法、因数个数函数 d(n)、因数和函数 σ(n)

#include <iostream> using namespace std; const int MAXN = 1000005; int prime[MAXN], d[MAXN], s[MAXN], cnt[MAXN]; bool vis[MAXN]; int tot; int main() { int n; cin >> n; d[1] = 1; s[1] = 1; for (int i = 2; i <= n; i++) { if (!vis[i]) { prime[tot++] = i; d[i] = 2; cnt[i] = 1; s[i] = i + 1; } for (int j = 0; j < tot && i * prime[j] <= n; j++) { vis[i * prime[j]] = true; if (i % prime[j] == 0) { cnt[i * prime[j]] = cnt[i] + 1; d[i * prime[j]] = d[i] / (cnt[i] + 1) * (cnt[i] + 2); s[i * prime[j]] = s[i] * prime[j] + s[i / prime[j]]; break; } else { cnt[i * prime[j]] = 1; d[i * prime[j]] = d[i] * 2; s[i * prime[j]] = s[i] * (prime[j] + 1); } } } int sum_d = 0, sum_s = 0; for (int i = 1; i <= n; i++) { sum_d += d[i]; sum_s += s[i]; } cout << sum_d << " " << sum_s << endl; return 0; }
📌 数组含义

· d[i]：i 的因数个数
· s[i]：i 的所有因数之和
· cnt[i]：i 的最小质因子的幂次（用于递推）
· prime[]：存储筛出的所有质数
· 最后输出 [1, n] 范围内所有数的因数个数之和、因数之和

✅ 正确答案：A（O(n)）

阅读程序 4（10 分）—— 二叉树遍历 + 平衡判断

知识点：二叉树前序/中序遍历、二叉树的还原、平衡二叉树判断

#include <iostream> #include <string> #include <algorithm> using namespace std; const int INF = 1000000000; string pre, ino; struct Node { char val; Node *left, *right; Node(char v) : val(v), left(nullptr), right(nullptr) {} }; Node* build(int pl, int pr, int il, int ir) { if (pl > pr) return nullptr; char rootVal = pre[pl]; int pos = ino.find(rootVal); int leftSize = pos - il; Node* root = new Node(rootVal); root->left = build(pl+1, pl+leftSize, il, pos-1); root->right = build(pl+leftSize+1, pr, pos+1, ir); return root; } int dfs(Node* root, bool& ok) { if (!root) return 0; int lh = dfs(root->left, ok); int rh = dfs(root->right, ok); if (abs(lh - rh) > 1) ok = false; return max(lh, rh) + 1; } bool isBalanced(Node* root) { bool ok = true; dfs(root, ok); return ok; } int main() { cin >> pre >> ino; Node* root = build(0, pre.length()-1, 0, ino.length()-1); cout << (isBalanced(root) ? "YES" : "NO") << endl; return 0; }
📝 阅读题 (1) 功能理解 · 选择题
若输入 pre = "ABDEC", ino = "DBEAC"，则 build 函数建立的二叉树根结点是？
AA
BB
CC
DD
✅ 正确答案：A（A）
前序遍历的第一个字符就是根结点。
pre = "ABDEC"，第一个字符为 A，所以根结点是 A。
📝 阅读题 (2) 条件判断 · 选择题
以下哪组输入能使得 isBalanced 返回 true？
Apre="ABC", ino="CBA"
Bpre="ABC", ino="ABC"
Cpre="ABC", ino="ACB"
D均不可能
✅ 正确答案：B
pre="ABC", ino="ABC" 构建的树：
A 为根，左子树为空（因为 ino 中 A 在位置 0），右子树为 B→C：
    A
     \
      B
       \
        C
这棵树每个结点都有右孩子，高度为 3，左右子树高度差不超过 1，是平衡的。
但注意：这个解释适用于另一种形态。更准确地说，B 选项构建的树若 左右子树高度差 ≤ 1 则返回 true。实际上 ino="ABC" 表示中序遍历顺序就是 A B C， 对应一棵完全右斜树，每个结点左右子树高度差为 1，也是平衡的。
