1数组

数组是连续内存空间中存放的相同类型元素的集合。通过下标访问。

// 声明与初始化 int a[5];            // 声明5个int，值未初始化（垃圾值） int b[5] = {1,2,3};  // 前3个为1,2,3，后2个为0 int c[] = {1,2,3};    // 自动推断长度为3 int d[3][4];       // 二维数组：3行4列 cout << b[0];  // 输出第1个元素（下标从0开始） b[2] = 10;     // 修改第3个元素
⚠️ 数组越界

C++ 不会检查数组下标越界。int a[3]; a[5]=100 编译通过，但运行时可能覆盖其他变量的内存、导致程序崩溃或隐秘bug。这是初赛中"程序行为不确定"类题目的常见原因。

📌 数组 vs 链表（2022年第4题）

数组：大小固定、内存连续、随机访问快 O(1)、插入删除慢 O(n)
链表：大小动态、内存离散、随机访问慢 O(n)、插入删除快 O(1)

📝 配套练习

📝 真题 · 2022 · 第 4 题数组 vs 链表
以下对数据结构的表述中，正确的是？
A数组大小可以动态调整
B链表插入和删除元素的效率低于数组
C数组大小固定，链表大小可动态调整
D链表支持通过下标随机访问
✅ 正确答案：C
数组大小固定，链表可动态调整。A 错——数组大小不能变；B 错——链表插入删除更快；D 错——链表不支持随机访问。
✏️ 模拟题数组初始化
int a[5] = {1, 2}; 之后，a[4] 的值是？
A不确定
B0
C2
D编译错误
✅ 正确答案：B
初始化列表只给了2个值，剩余元素自动初始化为 0。所以 a[2]=a[3]=a[4]=0。

2指针

指针是存放内存地址的变量。通过指针可以间接访问其他变量的值。

int x = 10; int *p = &x;    // p 存放 x 的地址（& 取地址） cout << *p;        // * 解引用 → 输出 10 *p = 20;              // 通过指针修改 x → x 变成 20
运算符名称含义
&x取地址获取变量 x 的内存地址
*p解引用访问指针 p 指向的变量的值
int *p声明指针声明一个指向 int 类型的指针
⚠️ 空指针与野指针

· 空指针：int *p = nullptr; 不指向任何有效地址
· 野指针：指针指向的内存已被释放或未初始化——非常危险！
· 初赛中常说"程序的行为可能是不确定的"多半与野指针/数组越界有关

📝 配套练习

📝 真题 · 2022 · 第 3 题指针赋值
int x=3, y=5; int *p=&x; int *q=&y; p = q;
执行后，p 指向哪里？
Ap 指向 x
Bp 指向 y
Cp 指向 q
Dp 指向 y 的地址
✅ 正确答案：B
p = q 将 q 的值（即 y 的地址）赋给 p。所以 p 现在指向 y。*p 的结果是 5。注意：p 本身存储的是地址，修改 p 的值不会影响 x。
✏️ 模拟题解引用修改值
int a=5; int *p=&a; *p=10; cout << a;
输出是什么？
A5
B10
C不确定
D编译错误
✅ 正确答案：B
*p = 10 通过指针解引用修改了 a 的值，a 变成 10。

3指针与数组的关系

数组名本质上就是指向数组首元素的指针常量。这是 C/C++ 中最重要也最容易混淆的概念。

int arr[4] = {10, 20, 30, 40}; // arr 就是 &arr[0]（首元素地址） cout << arr;        // 输出地址值 cout << *arr;       // 输出 10（等价于 arr[0]） cout << *(arr+1);  // 输出 20（等价于 arr[1]）
表达式等价形式值
arr[0]*arr10
arr[1]*(arr+1)20
&arr[1]arr+1第2个元素的地址
arr&arr[0]首元素地址
💡 指针运算

p+1 移动的是一个元素的大小，不是 1 字节。如果 p 是 int*（4字节），p+1 地址增加 4。如果 p 是 char*（1字节），p+1 地址增加 1。

📝 配套练习

✏️ 模拟题指针与数组的关系
int a[]={5,10,15}; int *p=a; cout << *(p+1);
输出是什么？
A5
B6
C10
D15
✅ 正确答案：C
p=a 使 p 指向数组首元素。p+1 指向下一个元素，即 a[1]=10。等价于 a[1]。
✏️ 模拟题指针运算步长
char s[]="ABC"; char *p=s; p++; cout << *p;
输出是什么？
AA
BB
CC
D不确定
✅ 正确答案：B
p 指向 s[0]='A'。p++ 后指向下一个 char（地址+1），即 s[1]='B'。所以输出 B。

4动态内存与二级指针

4.1 new / delete

int *p = new int;        // 分配一个int大小的内存 *p = 100; delete p;                // 释放内存 int *arr = new int[10];  // 分配数组 delete[] arr;              // 释放数组
⚠️ 内存泄漏

new 分配的内存如果不 delete，程序退出前都无法释放，这叫内存泄漏。长期运行的程序（如服务器）内存泄漏会导致系统资源耗尽。

4.2 二级指针

指向指针的指针，即存放指针变量的地址。

int x = 5; int *p = &x;      // p 指向 x int **pp = &p;    // pp 指向 p（二级指针） cout << **pp;      // 两次解引用 → 5

📝 配套练习

✏️ 模拟题new/delete 使用
用 new 分配了一个 int 数组后，应该用什么方式释放？
Adelete p
Bdelete[] p
Cfree p
Dmalloc(p)
✅ 正确答案：B
new int[n] 用 delete[] p 释放。new int（单个对象）用 delete p。混用会导致未定义行为。
✏️ 模拟题二级指针理解
int a=3, *p=&a, **pp=&p; cout << **pp;
输出是什么？
Aa 的地址
Bp 的地址
C3
D编译错误
✅ 正确答案：C
**pp 是两次解引用：一次得到 p 指向的内容（a 的地址），二次得到 a 的值 3。pp→p→a→3。

📝综合模拟

以下题目综合了数组、指针、指针运算等多个知识点。

✏️ 综合模拟指针综合阅读题
int a[]={2,4,6,8}; int *p=a+2; cout << *p << " " << p[-1];
输出是什么？
A6 4
B4 2
C6 2
D8 6
✅ 正确答案：A
p = a+2 指向 a[2]=6。p[-1] 等价于 *(p-1)，即前一个元素 a[1]=4。输出 6 4。注意：p[-1] 在 C++ 中是合法的（只要不越界）！
✏️ 综合模拟指针与数组综合
int arr[3]={1,2,3}; int *p=arr; *p=10; p[1]=20; cout << arr[0] << " " << arr[1];
输出是什么？
A1 2
B10 20
C10 2
D1 20
✅ 正确答案：B
*p=10 通过指针修改 arr[0]=10。p[1]=20 等价于 arr[1]=20。所以 arr[0]=10, arr[1]=20。
