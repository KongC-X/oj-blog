1计算机发展史

计算机从 1946 年诞生至今，经历了四代技术革命。 每一代最核心的区分标志是逻辑元件的不同。 理解了这个规律，有关发展史的题目就不会丢分。

1.1 第四代计算机详解

🔹 第一代：电子管计算机（1946—1957）

代表机型：ENIAC（1946）、EDVAC（1952，首次采用存储程序）、UNIVAC I（1951，第一台商用计算机）。
这一代计算机以电子管为核心元件，体积庞大、耗电惊人、发热严重。 ENIAC 用了约 18000 个电子管，占地 170 平方米，重 30 吨，每小时耗电 150 千瓦。 编程只能用机器语言（二进制代码），没有操作系统。

EDVAC 是第一台采用了存储程序概念的计算机； UNIVAC I 是第一台商用计算机，用于人口普查。

🔹 第二代：晶体管计算机（1958—1964）

晶体管替代电子管，体积缩小到原来的几十分之一，功耗大幅降低，可靠性显著提高。 代表机型为 IBM 7090、IBM 1401。 这一时期的重大突破是出现了高级程序设计语言： FORTRAN（1957，科学计算）和 COBOL（1959，商业数据处理）， 编程不再需要直接写二进制。同时出现了操作系统的雏形（如 IBM 的 I/O 监控程序）。

🔹 第三代：集成电路计算机（1965—1970）

将多个晶体管和电子元件集成到一块小小的硅片上（中小规模集成电路，SSI/MSI）， 计算机体积进一步缩小，性能和可靠性进一步提高。 代表机型 IBM System/360 —— 这是计算机史上第一个兼容系列， 同一系列的不同型号可以运行相同软件。操作系统成熟（如 OS/360）， 多道程序技术（同时运行多道程序）和分时系统出现，小型机（如 DEC PDP-8）走入实验室和中小企业。

🔹 第四代：大规模集成电路计算机（1971—至今）

大规模（LSI）和超大规模（VLSI）集成电路技术使得一块芯片上可以集成数十万甚至上亿个晶体管。 1971 年 Intel 4004 微处理器的诞生标志着一个新时代的来临——微型计算机时代。 个人电脑（PC）的普及（Apple II、IBM PC）、互联网的爆发、移动互联网、人工智能… 这一代一直延续到今天。

代次时间段逻辑元件代表机型关键技术突破
第一代 1946~1957 电子管 ENIAC、EDVAC、UNIVAC I 电子数字计算、存储程序（EDVAC）
第二代 1958~1964 晶体管 IBM 7090、IBM 1401 高级语言（FORTRAN/COBOL）、操作系统雏形
第三代 1965~1970 中小规模集成电路 IBM System/360、DEC PDP-8 兼容系列、多道程序、分时系统
第四代 1971~至今 大规模/超大规模集成电路 PC、智能手机、服务器 微处理器（Intel 4004）、PC、互联网、AI
💡 速记口诀

"管 → 晶 → 集 → 大" —— 记住 4 个字，搞定所有元件类题： 电子管 → 晶体管 → 集成电路 → 大规模集成电路。
扩展记忆："管晶极大" —— 集成度越来越大，元件越来越小。

1.2 ENIAC——世界上第一台通用电子数字计算机

ENIAC（Electronic Numerical Integrator And Computer，电子数字积分计算机） 于 1946 年由美国宾夕法尼亚大学研制成功，是世界上第一台通用电子数字计算机。 它主要用于弹道计算，每秒可执行约 5000 次加法。

📌 ENIAC 考试要点速记

· 诞生年份：1946 年（这个数字必须背下来）
· 研制单位：美国宾夕法尼亚大学
· 逻辑元件：电子管（第一代）
· 特点：没有存储程序功能（程序通过插拔线缆实现，非常麻烦）
· 重量：30 吨；面积：170 平方米
· 用途：弹道计算
· 存储程序功能由后续的 EDVAC 首次实现（冯·诺依曼参与设计）

💡 常见混淆：题干出现"第一台电子计算机"，就是 ENIAC。
但注意 ENIAC 采用了十进制而非二进制运算，这是它与现代计算机的一个显著区别。

以下关于计算机发展史的叙述中，错误的是？

✅ 正确答案：C
C 错在——第三代计算机的元件是中小规模集成电路，不是晶体管。

世界上第一台通用电子数字计算机 ENIAC 诞生于哪一年？
A1945 年
B1946 年
C1947 年
D1951 年
✅ 正确答案：B
1946 年。这个年份必须记牢。1945 年是二战结束 / 第一颗原子弹爆炸，不要混淆。 1951 年是 UNIVAC I（第一台商用计算机）的诞生年份。
✏️ 模拟题 ENIAC 不具备的功能
以下关于 ENIAC 的描述，错误的是？
AENIAC 使用了约 18000 个电子管
BENIAC 是世界上第一台通用电子数字计算机
CENIAC 采用了存储程序的设计思想

ENIAC 没有存储程序功能！它的程序通过插拔线缆和设置开关来实现， 修改一次程序需要花费数天时间。
真正实现存储程序概念的是 EDVAC（冯·诺依曼参与设计的后继机型）。
✏️ 模拟题 第四代计算机的标志性事件
第四代计算机的标志性技术突破是？
A晶体管的发明
B电子管的发明
C微处理器的诞生

✅ 正确答案：C
1971 年 Intel 4004 微处理器的诞生标志着第四代计算机的开端。 微处理器将整个 CPU 集成到一块芯片上，使得微型计算机成为可能。
A（晶体管）属于第二代；B（电子管）属于第一代；D（高级语言）属于第二代。
✏️ 模拟题 代际——关键词匹配
以下计算机特征与代次的对应关系中，不正确的是？
A第一代——机器语言编程
B第二代——FORTRAN 语言出现
C第三代——个人计算机普及
D第四代——超大规模集成电路
✅ 正确答案：C
个人计算机（PC）的普及属于第四代，不是第三代。
第三代（1965-1970）是集成电路时代，小型机出现但未普及到个人； 直到 1971 年微处理器诞生后，才有 Apple II、IBM PC 等个人计算机。

2冯·诺依曼结构与存储程序

2.1 核心思想：存储程序

冯·诺依曼提出的"存储程序"（Stored-Program）概念，是计算机史上最伟大的思想之一。 含义是：将程序指令和数据一起存放在计算机的存储器中， 计算机自动从存储器中依次取出指令并执行，无需人工干预。

一句话总结：程序和数据都放在内存里，计算机自己去取 → 译码 → 执行 → 再取下一条。 这就是现代计算机自动工作的根本原因。

2.2 冯·诺依曼结构五大部件

冯·诺依曼结构的计算机由五大部件组成。每个部件各司其职，缺一不可。

部件名称英文功能常见设备/例子
① 运算器 ALU 算术运算（加减乘除）和逻辑运算（与或非比较） CPU 内部
② 控制器 CU 取指令、译码、控制各部件协调工作 CPU 内部
③ 存储器 Memory 存放程序和数据（内存 + 外存，但通常指内存） RAM、ROM、硬盘、U 盘
④ 输入设备 Input 将外部数据输入计算机 键盘、鼠标、扫描仪、麦克风
⑤ 输出设备 Output 将计算结果输出给人或其他设备 显示器、打印机、扬声器
🎯 考点提示

· CPU = 运算器 + 控制器（这两者合称中央处理器）
· 运算器和控制器在考试中不可混淆：运算器负责"算"，控制器负责"指挥"
· 存储器包括内存和外存，但五大部件中的"存储器"主要指内存
· 输入/输出设备是泛称，不是特指某个具体设备

💡 高频判断题

"冯·诺依曼计算机的基本特征是存储程序和采用二进制。"
这句话在判断题中是 ✅ 正确 的，一定记牢。

📝 真题与模拟练习

📝 真题 · 2021 · 改编 冯·诺依曼结构特征
以下关于冯·诺依曼计算机的描述，正确的是？
A冯·诺依曼计算机的核心部件是运算器和存储器
B冯·诺依曼结构包括运算器、控制器、存储器、键盘和显示器五大部件
C冯·诺依曼计算机采用"存储程序"和"二进制"两大基本原理
D冯·诺依曼计算机不能运行使用高级语言编写的程序
✅ 正确答案：C
A 错——核心部件是运算器和控制器（合称 CPU），不是运算器和存储器。
B 错——五大部件中的输入输出设备是泛称，不是特指"键盘和显示器"。
D 错——高级语言编写的程序经过编译/解释后可以在冯·诺依曼计算机上运行。
✏️ 模拟题 存储程序概念
冯·诺依曼"存储程序"思想的核心含义是？
A程序运行时必须全部装入内存才能执行
B程序和数据一起存放在存储器中，计算机自动执行指令序列
C程序运行过程中的所有数据都必须永久保存
D程序只能使用机器语言编写，不允许使用符号地址
✅ 正确答案：B
"存储程序"的核心是把程序指令和数据一起存放在存储器中， 计算机按顺序自动取指令并执行，无需人工操作。
A 是现代计算机的实际实现方式（虚拟内存可部分不在内存），不是"存储程序"的定义； C 和 D 也都是错误理解。
✏️ 模拟题 五大部件——设备归类
以下设备中，不属于冯·诺依曼结构中"输入设备"的是？
A键盘
B鼠标
C显示器
D扫描仪
✅ 正确答案：C
显示器是输出设备，不是输入设备。
键盘、鼠标、扫描仪都是典型的输入设备。
注意区分：输入设备"把数据送进去"，输出设备"把结果显示出来"。

3计算机领域重要人物谱系

初赛经常考察对计算机科学做出重大贡献的人物及其对应成就。以下按时间线和影响分类梳理。

3.1 冯·诺依曼（John von Neumann，1903-1957）

匈牙利裔美国数学家、物理学家。他是"现代计算机之父"。 除了提出"存储程序"概念和冯·诺依曼结构外，他在博弈论（创始人之 一）、 量子力学、原子弹（曼哈顿计划）等领域也有突出贡献，是 20 世纪最杰出的全才之一。

3.2 艾伦·图灵（Alan Turing，1912-1954）

英国数学家、逻辑学家、密码学家。他是"计算机科学之父"和"人工智能之父"。 1936 年发表的论文提出了图灵机（Turing Machine）模型——一个简单的抽象计算设备， 却定义了"什么可以被计算"的边界。他还提出了图灵测试（Turing Test）， 用来判断机器是否具有智能。二战期间，他领导破译了德军的 Enigma 密码， 对盟军胜利做出了重大贡献。

3.3 查尔斯·巴贝奇（Charles Babbage，1791-1871）

英国数学家、工程师，被称为"计算机之父"。 他设计了差分机（Difference Engine）和分析机（Analytical Engine）， 分析机已经具备了现代计算机的雏形：存储、运算、控制、输入输出。 但由于当时机械工艺的限制，分析机未能实际建造完成。

3.4 阿达·洛芙莱斯（Ada Lovelace，1815-1852）

英国数学家，被称为"世界上第一位程序员"。 她为巴贝奇的分析机编写了第一个算法（计算伯努利数）， 并预见了计算机不仅可以做数值计算，还可以处理符号和音乐。 编程语言 Ada 就是以她的名字命名的。

⚠️ 人物头衔辨析（必考！）

· 冯·诺依曼 → "现代计算机之父"（存储程序）
· 图灵 → "计算机科学之父"和"人工智能之父"（图灵机、图灵测试）
· 巴贝奇 → "计算机之父"（分析机，19世纪）
· 阿达·洛芙莱斯 → "第一位程序员"

考试中出现题干"被称为现代计算机之父的是？"——选冯·诺依曼。
出现"被称为计算机科学之父的是？"——选图灵。

4图灵奖——计算机界的最高荣誉

图灵奖（Turing Award）是计算机领域的最高奖项， 由 ACM（Association for Computing Machinery，美国计算机协会） 于 1966 年设立，以艾伦·图灵的名字命名。

奖项名称所属领域设立机构奖项地位
图灵奖计算机科学ACM（美国计算机协会）计算机界最高奖（"计算机界的诺贝尔奖"）
诺贝尔奖物理/化学/生理学或医学等诺贝尔基金会自然科学界最高奖
奥斯卡金像奖电影艺术美国电影艺术与科学学院电影界最高奖
普利策奖新闻、文学、音乐哥伦比亚大学（按普利策遗愿）新闻界最高奖
菲尔兹奖数学国际数学联盟数学界最高奖之一
📌 考试必记三点

① 图灵奖是 计算机 领域的最高奖项（不是数学，不是工程）
② 设立机构是 ACM（美国计算机协会）
③ 以 艾伦·图灵 命名

5编程语言分类

5.1 按级别分类

  • 机器语言：二进制代码（0 和 1），计算机直接执行，无需翻译
  • 汇编语言：用助记符（如 MOV、ADD）代替二进制，需要汇编器转换
  • 高级语言：接近人类自然语言，需要编译或解释后才能执行

5.2 按编程范式分类（重要！）

📌 面向过程

以函数/过程为中心，程序是一系列步骤的集合。
代表语言：C、Pascal、Fortran、COBOL

📌 面向对象

以对象/类为中心，支持封装、继承、多态。
代表语言：C++、Java、Python、C#、Ruby、JavaScript、Swift

💡 判断技巧

· C 语言 → 面向过程（考试中经常作为"非面向对象"的选项出现）
· C++ → 面向对象（但不是纯面向对象，它兼容 C 的过程式写法，是多范式语言）
· Python → 面向对象（同时也支持过程式编程，但考试归类为面向对象）
· Java → 纯面向对象（所有代码都必须写在类中）
• Fortran、Pascal → 面向过程

5.3 C++ 的面向对象特性

初赛也会直接考察 C++ 的面向对象特性具体指什么。C++ 支持 类（class）、 继承（inheritance）、多态（polymorphism）、 封装（encapsulation）。而 C 语言遗留下来的函数（如 printf）不属于面向对象特性。

6数据存储与二进制

6.1 为什么计算机使用二进制？

计算机内部所有数据——数字、文字、图片、声音、视频——最终都以二进制（0 和 1）形式存储和处理。 这是由电子元件的物理特性决定的：

  • 物理上容易实现：电子元件天然具有两种稳定状态（通/断、高电平/低电平、有磁/无磁）， 分别对应 1 和 0，设计简单可靠
  • 运算规则简单：二进制算术运算和逻辑运算的规则比十进制简单得多， 电路实现成本低、速度快
  • 抗干扰能力强：只有 0 和 1 两种状态，不易受噪声干扰，数据可靠性高
  • 逻辑代数基础：布尔代数的真/假恰好对应二进制的 1/0，便于实现逻辑运算

6.2 存储单位

  • 位（bit）：最小的数据单位，一个 0 或 1
  • 字节（Byte）：1 B = 8 bit，是计算机最基本的存储单位
  • 数据量换算：1 KB = 1024 B，1 MB = 1024 KB，1 GB = 1024 MB，1 TB = 1024 GB
🔢 常考换算

· 1 Byte = 8 bit
· 1 KB = 210 = 1024 Byte
· 1 MB = 220 = 1,048,576 Byte
· 1 GB = 230 ≈ 10.7 亿 Byte
注意是 1024 的倍数，不是 1000 的倍数（硬盘厂商例外，用 1000 进制）。

✏️ 模拟题 二进制——物理原因
以下哪项不是计算机采用二进制的主要原因？
A电子元件具有两种稳定状态，容易表示 0 和 1

📝 真题 · 2025 · 第 10 题 传引用 vs 传值
考虑以下 C++ 函数： 
void solve(int &a, int b) {
    a = a + b;
    b = a - b;
    a = a - b;
}
int main() {
    int x = 5, y = 10;
    solve(x, y);
}
在 main 函数调用 solve 后，x 和 y 的值分别是？
A5, 10
B10, 5
C10, 10
D5, 5
✅ 正确答案：C
解析：参数 a 是传引用，修改影响实参 x；b 是传值，修改不影响实参 y。
函数内执行后 a=10, b=5，但 b 的修改不影响 y，所以 x=10, y=10。
知识点：函数参数传递——传引用修改实参，传值不影响实参。
