1试卷结构速览

了解整卷结构，合理分配时间，是考场上从容发挥的第一步。

4阅读程序得分秘籍

阅读程序题占40分（整卷最高），掌握正确方法可以大幅减少失分。

🔍 五大得分要点

① 先看代码整体结构
main → 循环 → 递归 → 函数 → 数据结构，快速理解程序在做什么。

② 逐行手动模拟，画变量变化表
准备草稿纸，每遇到循环/递归就画一张表，记录每个变量的值变化。

③ 判断题陷阱："一定"→找反例；"不可能"→找可能
"一定正确"只需找到一个反例即可推翻；"不可能"只需找到一个可能的情况即可推翻。

④ 优先模拟简单输入（n=0/1/2）
用最小边界输入验证程序行为，大多数时候边界就是考点。

⑤ 特别注意三个陷阱
整数除法截断（5/2=2）、 &&和||短路（前假后不执行）、 自增自减副作用（i++ vs ++i）

💡 判断题得分策略

· 判断题（2分）一定要拿——通常是最简单的，考的是对代码的粗粒度理解。
· 选择题（4分）要谨慎——往往涉及复杂逻辑或边界情况，不确定时先用排除法。

5完善程序三步法

完善程序题是整卷"性价比"最高的部分——掌握模板套路后，正确率可以大幅提高。

📌 三步法详解

第一步：读题，理解算法要做什么
花1-2分钟看清题目的输入输出描述，明确算法目标。不要上来就看代码。

第二步：看框架，找初始化、循环、递归、输出
快速扫描代码结构，确定填空所在的位置（初始化？循环条件？递归边界？输出？）。

第三步：逐空推敲，代入验证法
对每个空，先自己思考应该填什么，再看选项。把每个选项代入代码中"走一遍"看是否合理。

常用填空模板

场景 常用模板 说明
累加初始化 sum = 0 累加/计数初值设为0
乘积初始化 prod = 1 连乘初值设为1
循环条件(0-based) i < n for(i=0; ___; i++) 用 i < n
循环条件(1-based) i <= n for(i=1; ___; i++) 用 i <= n
比较符号 > vs >= 注意边界是否取等，差1错误是最常见的坑
DP 初始化 dp[0]=0 或 dp[1]=1 DP边界条件忘记初始化直接扣分

6十大易错点

这些是历届考生最常犯错的地方，考前必须过一遍，避免在考场上"踩坑"。

  1. 把数值本身当1的个数——例如 x=7（二进制111）有3个1，不是7个1；x&(x-1) 统计1的个数
  2. 二叉树叶子数记混——完全二叉树总叶子数 = ceil(n/2)，不是 n/2 向下取整
  3. 分组排列忘了除以组数的阶乘——将n个不同元素分成k组，若组间无区别需除以 k!
  4. DFS用栈、BFS用队列混淆——DFS用栈（递归或手动栈），BFS用队列（先进先出）
  5. gcd递归写法改错导致死循环—— return gcd(b, a%b) 写成了 return gcd(a, a%b) 导致参数不变
  6. 传引用 vs 传值——引用参数在函数内修改会影响实参，值参数修改不影响实参
  7. 运算符优先级——特别注意 << 和 + 的优先级（1<<2+3 = 1<<5 = 32）、&& 和 || 的短路特性
  8. 冒泡排序交换次数 vs 比较次数——交换次数是逆序对数，比较次数通常是 n(n-1)/2
  9. 栈的容量最小值计算——双端操作（同时入栈和出栈）时，需要模拟过程找最大栈深
  10. &&短路特性——条件从左到右判断，前一个为false则不再执行后面的表达式；a > 0 && b/a > 1 不会除以0
⚠️ 考前必看

把这10条抄在草稿纸上，考试时每做完一道题扫一眼，看自己有没有犯这些错误。

7答题策略

正确的考试策略可以让你在同等水平下多拿5~10分。

先易后难
先做有把握的题目，标记不确定的，回头再攻克。不要在一道题上纠结超过5分钟。
选择题排除法
先划掉明显错误的选项，再在剩下的选项中比较。四选一变成二选一，正确率翻倍。
阅读题分工
判断题（2分）一定要拿，通常比较简单。
选择题（4分）要谨慎，往往涉及复杂逻辑，先排除再选。
代入验证法
完善程序的每个空，把选项代进代码里"走一遍"看是否合理。不要靠猜。
✅ 考场行动清单

① 发卷后先浏览全卷，了解题目难度分布
② 从单选题开始做，建立信心
③ 不确定的题在题号上画圈标记，做完有把握的再来攻克
④ 留15分钟检查：核对答题卡涂写、回头做标记题
⑤ 最后不要改答案除非确认自己选错了——第一直觉往往是对的
