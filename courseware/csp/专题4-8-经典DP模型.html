1最长公共子序列 LCS（2025 阅读 3 原题）

最长公共子序列（LCS, Longest Common Subsequence）是字符串 DP 中最经典的模型之一。 2025 年 CSP-J 阅读程序第 3 题正是考查了 LCS 的 DP 实现及其向 LIS 的转化。

问题定义

给定两个字符串（或序列）A[1..n] 和 B[1..m]，求它们的最长公共子序列的长度。
子序列是指从原序列中删除若干个元素（可以不连续）后得到的新序列。
例如 A = "abcde", B = "ace"，则 LCS 为 "ace"，长度为 3。

LCS 的 DP 解法核心代码
// dp[i][j] 表示 A[1..i] 与 B[1..j] 的 LCS 长度 int lcs(string A, string B) { int n = A.length(), m = B.length(); vector<vector<int>> dp(n+1, vector<int>(m+1, 0)); for (int i = 1; i <= n; i++) { for (int j = 1; j <= m; j++) { if (A[i-1] == B[j-1]) dp[i][j] = dp[i-1][j-1] + 1; // 字符相等，LCS 长度 + 1 else dp[i][j] = max(dp[i-1][j], dp[i][j-1]); // 取较大者 } } return dp[n][m]; }
🧠 LCS 状态转移核心思想

分两种情况讨论：
  • 若 A[i] == B[j]：说明当前字符可以加入公共子序列，
    则 dp[i][j] = dp[i-1][j-1] + 1
  • 若 A[i] != B[j]：当前字符无法匹配，
    则 dp[i][j] = max(dp[i-1][j], dp[i][j-1])
边界：dp[0][j] = dp[i][0] = 0（空序列的 LCS 为 0）

⚡LCS → LIS 转化（2025 高难度题）

2025 年 CSP-J 阅读 3 的高难度版本考查了 LCS 向 LIS（最长上升子序列）的转化。 当其中一个序列的元素互不相同且严格递增时，LCS 问题可以转化为 LIS 问题，从而将时间复杂度从 O(n²) 优化到 O(n log n)。

转化原理

核心思想：若序列 A 中的元素互不相同且严格递增，我们可以将 A 中元素的位置作为"映射"。

具体步骤：
1. 遍历 B 中每个元素 b，记录 b 在 A 中的出现位置（用 pos 数组或 map 存储）
2. 对于 B 中出现在 A 里的元素，按其在 A 中的位置组成一个新序列 C
3. 对序列 C 求 LIS（最长上升子序列），长度即为原 LCS 的长度

为什么可行？因为 A 严格递增且元素互不相同，A 中元素的位置天然就是递增的。B 中的公共子序列在 A 中的位置也一定是递增的——这就是一个上升子序列！

📌 初赛考点提示：
LCS→LIS 转化是 CSP-J 近年的新趋势。题目通常不会直接告诉你"这是 LIS"，而是给出 LCS 的代码，再给出一个 a 严格递增的输入条件，让你通过手动模拟发现最终 dp[n][m] 的值等价于对另一个序列求 LIS 的长度。

转化图示

A = [1, 2, 3, 4, 5] (严格递增，元素互不相同) B = [3, 1, 5, 2, 4] Step 1: 建立元素→位置的映射 pos[1]=1, pos[2]=2, pos[3]=3, pos[4]=4, pos[5]=5 Step 2: 对 B 中每个元素，映射为 A 中的位置 B → [3, 1, 5, 2, 4] C → [3, 1, 5, 2, 4] (因为 A[i]=i，所以位置就是值本身) Step 3: 对 C 求 LIS C = [3, 1, 5, 2, 4] LIS 长度为 2 或 2... 实际上从 C 中找最长上升子序列： 可能的 LIS: [3,5], [1,2,4] → 最长长度为 3 ✓ 所以 LCS(A,B) = LIS(C) 的长度 = 3

2杨辉三角形 DP（2025 完善 1 原题）

2025 年 CSP-J 完善程序第 1 题考查了杨辉三角形的 DP 实现。 杨辉三角（Pascal's Triangle）是二维 DP的经典入门例子， 其核心递推关系体现了组合数的计算原理。

杨辉三角形的递推规律

杨辉三角形的构造规则：
  • 每行的第一个和最后一个数字都是 1
  • 其他位置的数字 = 它正上方的数 + 左上方的数
  • 第 n 行（从 0 开始）有 n+1 个数字

杨辉三角形的 DP 代码（2025 完善 1 核心）
// 求杨辉三角形第 n 行第 k 个数的值（0-indexed） int yangHui(int n, int k) { vector<vector<int>> dp(n + 1, vector<int>(n + 1, 0)); for (int i = 0; i <= n; i++) { dp[i][0] = 1; // 每行第一个为 1 dp[i][i] = 1; // 每行最后一个为 1 for (int j = 1; j < i; j++) { dp[i][j] = dp[i-1][j-1] + dp[i-1][j]; // 左上 + 正上 } } return dp[n][k]; }
🧠 核心理解

状态：dp[i][j] 表示杨辉三角第 i 行第 j 列的数
转移：dp[i][j] = dp[i-1][j-1] + dp[i-1][j]
边界：dp[i][0] = dp[i][i] = 1（每行首尾都是 1）
注意：j 从 1 开始到 i-1，因为首尾已经单独初始化了

手动填表：前 5 行杨辉三角

行 0: [1] 行 1: [1] [1] 行 2: [1] [2] [1] 行 3: [1] [3] [3] [1] 行 4:[1] [4] [6] [4] [1] 逐行填充过程： i=0: dp[0][0]=1 i=1: dp[1][0]=1, dp[1][1]=1 i=2: dp[2][0]=1, dp[2][2]=1 dp[2][1]=dp[1][0]+dp[1][1]=1+1=2 i=3: dp[3][0]=1, dp[3][3]=1 dp[3][1]=dp[2][0]+dp[2][1]=1+2=3 dp[3][2]=dp[2][1]+dp[2][2]=2+1=3 i=4: dp[4][0]=1, dp[4][4]=1 dp[4][1]=dp[3][0]+dp[3][1]=1+3=4 dp[4][2]=dp[3][1]+dp[3][2]=3+3=6 dp[4][3]=dp[3][2]+dp[3][3]=3+1=4
与组合数的关系

杨辉三角形第 n 行第 k 列的数就是组合数 C(n, k)。
即 dp[n][k] = C(n, k) = n! / (k! * (n-k)!)
所以通过 DP 可以高效地计算组合数，而不需要乘除法和阶乘！

3双指针 DP 分段模型（2025 阅读 2）

2025 年 CSP-J 阅读程序第 2 题考查了一种经典的双指针 DP 模型： 先将数组排序去重，然后用 ans[i] = ans[j] + 1 的形式进行递推。 这种模型常用于求解"最长连续/非连续子序列"类问题。

问题模型

典型流程：
1. 对数组排序 + 去重
2. 用两个指针（一个快指针 i，一个慢指针 j）遍历数组
3. 当满足条件时，ans[i] = ans[j] + 1
4. 否则 ans[i] = ans[i-1]（保持当前最优值）

2025 阅读 2 核心代码结构
// 输入：一个无序数组 a，长度为 n int solve(int a[], int n) { sort(a, a + n); // 1. 排序 int m = unique(a, a + n) - a; // 2. 去重，m 为去重后长度 vector<int> ans(m); ans[0] = 1; // 边界 int j = 0; // 慢指针 for (int i = 1; i < m; i++) { while (a[i] - a[j] > 1) j++; // 3. 移动 j 使差值 ≤ 1 if (a[i] - a[j] == 1) ans[i] = ans[j] + 1; // 4. 可以接在后面 else // a[i] == a[j] ans[i] = ans[j]; // 5. 相同值，传递 } return *max_element(ans.begin(), ans.end()); // 6. 取最大值 }
🧠 代码功能分析

该算法的作用：求排序去重后数组中最长连续整数序列的长度。

具体来说：
  • 排序去重后，相邻元素要么相等，要么相差 1 或更多
  • ans[i] 表示以第 i 个元素结尾的最长连续序列长度
  • 当 a[i] - a[j] == 1 时，可将 a[i] 接在 a[j] 后面 → ans[i] = ans[j] + 1
  • 最终答案为所有 ans[i] 的最大值

典型应用：求无序数组中最长连续序列的长度（LeetCode 128）

手动模拟：a = [100, 4, 200, 1, 3, 2]

1 排序后：[1, 2, 3, 4, 100, 200]
2 去重（没有重复元素）：m = 6
3 ans[0] = 1（边界）
4 i=1, a[1]=2：j=0，a[1]-a[0]=1 == 1 → ans[1]=ans[0]+1=2
5 i=2, a[2]=3：j=0，a[2]-a[0]=2 > 1 → j++=1；a[2]-a[1]=1 == 1 → ans[2]=ans[1]+1=3
6 i=3, a[3]=4：j=1，a[3]-a[1]=3 > 1 → j++=2；a[3]-a[2]=1 == 1 → ans[3]=ans[2]+1=4
7 i=4, a[4]=100：j=2，a[4]-a[2]=97 > 1 → j++=3；a[4]-a[3]=96 > 1 → j++=4；a[4]-a[4]=0 == 0 → ans[4]=ans[4]=1
8 i=5, a[5]=200：j=4，a[5]-a[4]=100 > 1 → j++=5；a[5]-a[5]=0 == 0 → ans[5]=ans[5]=1
ans 数组最终值： i: 0 1 2 3 4 5 a: [1] [2] [3] [4] [100] [200] ans: [1] [2] [3] [4] [1] [1] 最长连续序列长度 = max(ans) = 4 最长连续序列为: 1→2→3→4
📌 关键考点：双指针 DP 的核心是快指针 i 遍历，慢指针 j 维护"候选区间"。
在初赛中，你需要理解 while (a[i] - a[j] > 1) j++; 这句话的作用——它确保 j 永远指向距离 i 最近且差值不超过 1 的位置。

4阅读程序：如何识别 DP 代码

CSP-J 初赛的阅读程序题中，DP 是高频考点。掌握以下特征，可以快速识别 DP 代码并理解其功能：

DP 代码的 5 大识别特征

1. DP 数组声明
  • 一维：vector<int> dp(n) 或 int dp[N]
  • 二维：vector<vector<int>> dp(n, vector<int>(m))

2. 边界初始化
  • 一维：dp[0] = 0 / 1 等
  • 二维：dp[0][j] = j 或 dp[i][0] = i 等

3. 嵌套循环
  • 一维 DP：一个 for 循环，i 从 1 或 2 开始
  • 二维 DP：两个嵌套 for 循环

4. 递推赋值
  • dp[i] = min/max(dp[i-1], ...) + cost[i]
  • dp[i][j] = max(dp[i-1][j], dp[i][j-1])

5. 返回 dp[n] 或 dp[n][m]
  • 最终答案通常在数组的最后一个位置

🧠 阅读程序实战技巧

遇到疑似 DP 的代码，按以下步骤解题：
1. 找到 dp 数组，确定其维度（一维/二维）
2. 查看边界值初始化（通常在循环前）
3. 找到核心递推语句，理解它的含义
4. 如果有双指针，关注指针的移动条件
5. 用小规模数据手动模拟数组填充过程
6. 最终确定 dp 数组中哪个位置存放了答案

📝 真题 · 2025 · 阅读 3 LCS → LIS 转化（高难度）
已知 A = [2, 5, 3, 1, 4]（非严格递增），
用 LCS 代码求 A 与排序后的 A_sorted = [1, 2, 3, 4, 5] 的 LCS。
现在如果将条件改为 A 严格递增（如 A = [1, 2, 3, 4, 5]），
则 LCS(A, A_sorted) 的返回值是（ ）。
A 1
B 3
C 5
D 取决于 A 的具体元素
✅ 正确答案：C · 5
关键理解：LCS → LIS 转化原理

当 A 严格递增且元素互不重复时（如 [1,2,3,4,5]），已经是从小到大排好序的了。
此时 A 与 A_sorted 完全相同，所以 LCS 就是 A 本身，长度为 5。

更一般的情况：
对于任意严格递增的 A，假设 A = [a1, a2, ..., an] 且 a1 < a2 < ... < an。
对 A 排序得到 A_sorted = [a1, a2, ..., an]（就是 A 本身）。
因此 LCS(A, A_sorted) = n，即 A 的长度。

转化的真正应用场景：
当 A 严格递增时，LCS(A, B) 可以转化为求 B 中元素的位置序列的 LIS。
具体地，若 A 严格递增，设 pos[x] 为 x 在 A 中的位置，
则 LCS(A,B) = LIS( [pos[B[0]], pos[B[1]], ..., pos[B[m-1]]] )

本题选 C：当 A 严格递增时，LCS(A, sorted(A)) = A 的长度 = 5。
📝 真题 · 2025 · 完善 1 杨辉三角形 DP 填表
完善下列杨辉三角形 DP 代码的空白处：

int yangHui(int n, int k) { vector<vector<int>> dp(n + 1, vector<int>(n + 1)); for (int i = 0; i <= n; i++) { dp[i][0] = _____①_____; dp[i][i] = _____②_____; for (int j = _____③_____; j < i; j++) dp[i][j] = dp[i-1][j-1] + _____④_____; } return dp[n][k]; }
① 和 ② 应填入的值分别是（ ）。

B ①=0, ②=1
C ①=1, ②=0
D ①=i, ②=i
✅ 正确答案：A · ①=1, ②=1
分析：

杨辉三角形的两个核心特征：
  • 每行第一个元素 dp[i][0] = 1
  • 每行最后一个元素 dp[i][i] = 1

因此 ① 和 ② 都填 1。

完整的填空答案：
① = 1（每行第一个是 1）
② = 1（每行最后一个也是 1）
③ = 1（j 从 1 开始，因为 dp[i][0] 已初始化）
④ = dp[i-1][j]（正上方元素）

完整递推式：dp[i][j] = dp[i-1][j-1] + dp[i-1][j]
（左上角 + 正上方）

✏️ 综合 · 识别 DP 阅读程序中判断 DP 类型
分析以下代码片段，判断它属于哪一类 DP 模型：

int solve(int a[], int n) { sort(a, a + n); int m = unique(a, a + n) - a; vector<int> f(m, 0); f[0] = 1; int j = 0; for (int i = 1; i < m; i++) { while (a[i] - a[j] > 1) j++; if (a[i] - a[j] == 1) f[i] = f[j] + 1; else f[i] = f[j]; } return *max_element(f, f + m); }
这段代码实现的是（ ）。
A 最长上升子序列 LIS
B 最长连续序列
C 最长公共子序列 LCS
D 编辑距离
✅ 正确答案：B · 最长连续序列
识别线索分析：

1. 排序 + unique 去重
说明输入可能是无序且有重复的数组，需要对元素进行归一化。

2. 双指针 while 循环
while (a[i] - a[j] > 1) j++;
这个循环确保 j 始终指向距离 i "最近且差值不超过 1" 的元素。
这是"连续序列"类问题的标志性写法。

3. 转移方程
if (a[i] - a[j] == 1) f[i] = f[j] + 1;
只有当相邻元素相差恰好为 1 时才能"接上"，形成更长的连续序列。

4. 为什么不是其他选项？
  • A (LIS)：LIS 通常不先排序，排序会破坏原始顺序
  • C (LCS)：LCS 需要两个序列，这里是单个数组
  • D (编辑距离)：编辑距离用二维 DP，有三个操作来源

结论：这段代码实现的是最长连续序列（Longest Consecutive Sequence）的长度，
也就是 LeetCode 128 题的经典解法。
选 B。
