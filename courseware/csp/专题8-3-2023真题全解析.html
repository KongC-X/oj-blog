📝 第 2 题 编程语言 · 编译与解释
以下关于编译型语言和解释型语言的说法，正确的是？
APython 是编译型语言
BC++ 是解释型语言
CJava 先编译为字节码再解释执行
D编译型语言不需要编译器
✅ 正确答案：C（Java 先编译为字节码再解释执行）

📝 第 3 题 数据表示 · 补码
8 位二进制补码能表示的十进制整数范围是？
A-128 ~ 127
B-127 ~ 127
C0 ~ 255
D-255 ~ 255
✅ 正确答案：A（-128 ~ 127）
解析：
· 8 位补码表示范围：-2⁷ ~ 2⁷-1 = -128 ~ 127。
· 正数范围 0 ~ 127（共 128 个），负数范围 -1 ~ -128（共 128 个）。
· 补码中 10000000 表示 -128，01111111 表示 127。
· 0 只有一种表示：00000000。

记忆：n 位补码范围为 -2n-1 ~ 2n-1-1。
📝 第 4 题 逻辑运算 · 表达式求值
已知 int a=3, b=5, c=7，表达式 !(a > b) && (c > a) || (b > c) 的值是？
A0
B1
Ctrue
Dfalse
✅ 正确答案：B（1）
解析：
逐步计算：
① a > b → 3 > 5 = false
② !(a > b) → !false = true
③ c > a → 7 > 3 = true
④ true && true = true
⑤ true || (b > c) → 短路求值，结果为 true，即整数值 1。

注意：C++ 中关系运算返回 bool 值，true 转为整数为 1。

📝 第 6 题 栈 · 出栈序列判断
入栈顺序为 1, 2, 3, 4, 5，以下哪个不是合法的出栈序列？
A1, 2, 3, 4, 5
B5, 4, 3, 2, 1
C3, 2, 4, 1, 5
D4, 5, 2, 3, 1
✅ 正确答案：D（4, 5, 2, 3, 1）
解析：
模拟验证 D 选项：
· push 1, push 2, push 3, push 4 → pop 4 ✓
· push 5 → pop 5 ✓（此时栈中从底到顶为 1, 2, 3）
· 要 pop 2，但 2 被 3 压住，必须先 pop 3 ✗
· 所以 "4,5,2,3,1" 不合法。

核心规律：栈是 LIFO（后进先出）结构。如果 x 出栈时，栈内还有在 x 之后入栈却在 x 之上的元素，则序列非法。
📝 第 7 题 二叉树 · 高度与结点数
一棵完全二叉树有 1000 个结点，其叶子结点的数量是？
A490
B495
C500
D505
✅ 正确答案：C（500）
解析：
· 完全二叉树叶子结点数 = n - ⌊n/2⌋，其中 n 为总结点数。
· 代入 n=1000：1000 - ⌊1000/2⌋ = 1000 - 500 = 500。

证明：完全二叉树中，编号为 i 的结点如果左子结点存在则编号为 2i，右子结点为 2i+1。叶子结点的编号 > ⌊n/2⌋。

速记：完全二叉树的叶子数 ≈ 总结点数的一半（向上取整因层而异）。
📝 第 8 题 图论 · 入度与出度
关于有向图的说法，正确的是？
A所有顶点的入度之和等于出度之和
B入度之和等于边数的两倍
C出度之和等于顶点数
D入度之和等于顶点数
✅ 正确答案：A（入度之和等于出度之和）
解析：
· 在有向图中，每一条边贡献 1 个出度和 1 个入度。
· 所以 总入度 = 总出度 = 边数。
· 选项 B 描述的是无向图的性质（度数之和 = 2×边数）。

注意：区分有向图和无向图的度数性质：
· 无向图：∑deg(v) = 2|E|
· 有向图：∑indeg(v) = ∑outdeg(v) = |E|
📝 第 9 题 排序 · 稳定性
以下排序算法中，不稳定的是？
A冒泡排序
B插入排序
C归并排序
D选择排序
✅ 正确答案：D（选择排序）
解析：
排序算法稳定性指的是：相等元素的相对顺序在排序前后保持不变。

稳定的排序：
· 冒泡排序 — 相邻比较，相等不交换 ✓
· 插入排序 — 后插，相等插后面 ✓
· 归并排序 — 归并时相等优先取左 ✓

不稳定的排序：
· 选择排序 — 每次选最小放到前面，可能破坏稳定性 ✗
· 快速排序 — 划分时相等元素可能交换 ✗
· 堆排序 — ✗

速记：不稳定排序有"选快希堆"（选择、快速、希尔、堆排序）。
📝 第 10 题 组合数学 · 分组计数
将 6 个不同的元素分成 3 组，每组恰好 2 个元素，且不区分组的编号，共有多少种分法？
A30
B15
C90
D45
✅ 正确答案：B（15）
解析：
两步计算：
① 先考虑有编号的分组：C(6,2) × C(4,2) × C(2,2) = 15 × 6 × 1 = 90
② 由于不区分组编号，3 组内部排列有 3! = 6 种重复：90 ÷ 6 = 15。

通用公式：将 n 个不同元素分成 k 组，每组 ni 个，不区分编号：
n! / (n1! × n2! × ... × nk! × k!)
📝 第 11 题 C++ 语法 · 指针
有以下 C++ 代码：
int x = 5, y = 10; int *p = &x, *q = &y; p = q; *p = 20;
执行后，x 和 y 的值分别是？
Ax=5, y=10
Bx=5, y=20
Cx=20, y=10
Dx=20, y=20
✅ 正确答案：B（x=5, y=20）
解析：
逐行分析：
· int *p = &x, *q = &y; → p 指向 x 的地址，q 指向 y 的地址。
· p = q; → 将 q 的地址值赋给 p，即 p 现在也指向 y。
· *p = 20; → 通过 p 修改其指向内存的值为 20，即 y 变成了 20。
· x 从未被修改，仍为 5。

易错：p = q 是改变指针的指向，不是复制值。*p = *q 才是复制值。
📝 第 12 题 哈夫曼树 · 带权路径长度
已知 5 个字符的频率分别为 10, 12, 15, 20, 25，构造哈夫曼树后其带权路径长度（WPL）为？
A170
B186
C200
D196
✅ 正确答案：B（186）
解析：
构造哈夫曼树：
① 取最小两个 10+12=22 → {15,20,22,25}
② 取 15+20=35 → {22,25,35}
③ 取 22+25=47 → {35,47}
④ 取 35+47=82 → 根结点 82

WPL 计算： (10+12)×3 + (15+20)×2 + 25×2
= 22×3 + 35×2 + 25×2
= 66 + 70 + 50 = 186

注意：WPL = 所有叶子结点权值 × 路径长度之和。构造时每次合并最小的两个结点。
📝 第 13 题 算法 · 二分查找
在有序数组 [1, 3, 5, 7, 9, 11, 13] 中用二分查找查找 7，需要比较的次数是？
A1
B2
C3
D4
✅ 正确答案：B（2）
解析：
二分查找过程（下标从 0 到 6）：
· 第一次比较：mid = (0+6)/2 = 3，arr[3] = 7 → 恰好找到。
· 实际只需要 1 次比较即可找到 7。

注意：不同实现可能有差异。如果先比较 arr[mid] 与 target 是否相等，则在第一次比较时就命中，只需要 1 次比较。
若在循环结束后才判断相等，则需看具体实现。

二分查找时间复杂度：O(log n)，最坏情况比较次数为 ⌊log₂n⌋+1。
📝 第 14 题 递归 · 函数调用分析
运行以下递归函数：
int solve(int n) { if (n <= 1) return 1; return solve(n - 1) + solve(n - 2); }
solve(6) 的结果是？
A8
B13
C21
D34
✅ 正确答案：B（13）
解析：
solve(n) 实际上是斐波那契数列，其中 solve(0)=1, solve(1)=1：
· solve(2) = solve(1)+solve(0) = 1+1 = 2
· solve(3) = solve(2)+solve(1) = 2+1 = 3
· solve(4) = solve(3)+solve(2) = 3+2 = 5
· solve(5) = solve(4)+solve(3) = 5+3 = 8
· solve(6) = solve(5)+solve(4) = 8+5 = 13

注意：边界条件是 n ≤ 1 返回 1，所以这是斐波那契数列的偏移版本（通常 F(1)=F(2)=1，此处 solve(1)=1, solve(2)=2）。
📝 第 15 题 字符串 · 子串计数
字符串 "abcab" 中，不同的非空子串共有多少个？
A12
B13
C14
D15
✅ 正确答案：C（14）
解析：
枚举所有非空子串并去重：
· 长度 1：a, b, c = 3 个
· 长度 2：ab, bc, ca, ab → 去重得 ab, bc, ca = 3 个
· 长度 3：abc, bca, cab → 3 个
· 长度 4：abca, bcab → 2 个
· 长度 5：abcab → 1 个
· 长度 6+：0 个
总数 = 3+3+3+1 = 14（注意长度 4 有 2 个不同的）。

易错：注意"ab"出现了两次但只算一次，"abcab"中无长度 5 以上的子串。
公式：子串总数 = n(n+1)/2 = 15（含重复），去重后要根据实际内容判断。

二阅读程序（3 大题，共 40 分）

2023 年阅读程序题重点考察质因数分解、格雷码递归生成、回文字符串判断。 需要仔细跟踪代码执行过程，注意边界条件和特殊输入。

阅读程序 1：质因数分解（因子计数）

阅读以下 C++ 代码，回答后面的问题。

// 输入一个正整数 n，统计其因数个数和质因数个数 // 并判断 n 是否为素数 #include <iostream> using namespace std; int main() { int n; cin >> n; int cnt = 0, prime_cnt = 0; int m = n; for (int i = 2; i * i <= m; i++) { if (m % i == 0) { prime_cnt++; while (m % i == 0) { m /= i; } } } if (m > 1) prime_cnt++; for (int i = 1; i * i <= n; i++) { if (n % i == 0) { if (i * i == n) cnt++; else cnt += 2; } } cout << cnt << " " << prime_cnt << endl; cout << (prime_cnt == 1 ? "Yes" : "No") << endl; return 0; }
📋 判断 1 输入 n=12，程序输出中第一行包含 6 3
✅ 正确答案：×
解析：
输入 n=12：
· 因数个数（cnt）：12 的因数有 1,2,3,4,6,12 → 6 个 ✓
· 质因数个数（prime_cnt）：12=2²×3，质因数为 2 和 3 → 2 个，不是 3。
· 所以第一行输出应为 "6 2"，不是 "6 3"。

错误理解：prime_cnt 统计的是不同质因数的个数。12 只有 2 和 3 两个不同的质因数。
📋 判断 2 输入 n=17，程序输出第二行为 "Yes"
✅ 正确答案：√
解析：
17 是素数（质数）：
· 质因数分解：17 = 17 → prime_cnt = 1（只有 17 自身一个质因数）
· prime_cnt == 1 为真，输出 "Yes"
·（注意：程序将"只有一个质因数"作为素数的判断条件，当 n 为素数时确实满足。）

注意：这种判断素数的方式对 1 是无效的，因为 1 没有质因数，prime_cnt=0。
📋 判断 3 输入 n=1，程序输出的第二行是 "No"
✅ 正确答案：√
解析：
· 输入 n=1：
· 第一个 for 循环：i=2，2²≤1 不成立，直接跳过。m 仍为 1。
· if (m > 1) 不成立，prime_cnt 保持 0。
· prime_cnt == 1 为 false，输出 "No"。

正确性说明：1 不是素数，输出 "No" 是正确的。程序在边界情况 n=1 下的输出是合理的。
📋 选择 4 输入 n=36，第一行输出是什么？
A8 2
B9 2
C8 3
D9 3
✅ 正确答案：B（9 2）
解析：
n=36：
· 因数个数（cnt）：36 的因数有 1,2,3,4,6,9,12,18,36 → 9 个
· 质因数个数（prime_cnt）：36=2²×3²，质因数为 2 和 3 → 2 个
· 所以输出 "9 2"。

注意因数计数逻辑：i*i == n 时 cnt 只加 1（平方根），否则加 2（i 和 n/i 一对）。
📋 选择 5 关于该程序，以下说法正确的是？
A程序能正确处理 n=0
Bprime_cnt 统计的是所有质因数的总次数（含重复）
C程序对 36 判断素数的结果为 "No"
D所有回文数都能被程序正确判断素数
✅ 正确答案：C
解析：
A. × 题目假设输入 n 为正整数，n=0 可能引发除零或无限循环问题。
B. × prime_cnt 统计的是不同质因数的个数（while 循环将相同质因数除尽后再 i++）。
C. √ 36=2²×3²，prime_cnt=2≠1，输出 "No"，正确（36 不是素数）。
D. × 回文数 121 是合数（11²），程序也能判断为"No"。但说"所有回文数"过于绝对。

考点：理解循环中的去重逻辑，区分"质因数种类"和"质因数总个数"。

阅读程序 2：格雷码（Gray Code）递归生成

阅读以下 C++ 代码，回答后面的问题。

// 格雷码：相邻两个编码只有一位不同 // 输入 n，输出 n 位格雷码序列 #include <iostream> #include <vector> #include <string> using namespace std; vector<string> gray(int n) { vector<string> res; if (n == 1) { res.push_back("0"); res.push_back("1"); return res; } vector<string> prev = gray(n - 1); for (int i = 0; i < prev.size(); i++) { res.push_back("0" + prev[i]); } for (int i = prev.size() - 1; i >= 0; i--) { res.push_back("1" + prev[i]); } return res; } int main() { int n; cin >> n; vector<string> g = gray(n); for (int i = 0; i < g.size(); i++) { cout << g[i] << endl; } return 0; }
📋 判断 6 当 n=2 时，程序输出中第一行为 "00"
✅ 正确答案：√
解析：
n=2 时递归过程：
· gray(1) → ["0", "1"]
· gray(2) 对 prev=["0","1"]：
  前半程：加 "0" 前缀 → "00", "01"
  后半程：逆序遍历加 "1" 前缀 → "11", "10"
· 结果序列：["00", "01", "11", "10"]
· 第一行为 "00" ✓

格雷码性质：相邻两个编码只有 1 位不同。"00"→"01"（末位改变），"01"→"11"（第二位改变），"11"→"10"（末位改变）。
📋 判断 7 当 n=3 时，程序输出的序列长度为 8
✅ 正确答案：√
解析：
· n 位格雷码共有 2n 个编码。
· n=3 时，序列长度 = 2³ = 8。
· 递推：gray(1) 有 2 个，gray(n) 将 gray(n-1) 的每个前面加 "0"和"1"共 2×2n-1 = 2n 个。

验证：gray(3) 序列为：000, 001, 011, 010, 110, 111, 101, 100。
确实是 8 个编码。
📋 判断 8 gray(n) 函数中，第二个 for 循环使用逆序遍历，是为了保证相邻编码只有一位不同
✅ 正确答案：√
解析：
· 前半程正序加 "0" 前缀，后半程逆序加 "1" 前缀。
· 前半程最后一个元素和后半程第一个元素的关系：
  前半程最后一个 = "0" + prev[last]，后半程第一个 = "1" + prev[last]
· 二者仅在最高位不同（0→1），其余位相同 → 满足格雷码相邻只变一位的要求。
· 前半程内部相邻元素因 prev 是合法的格雷码，也只差一位（加 "0" 前缀后不变）。
· 后半程同理。

结论：逆序遍历是实现格雷码递归生成的关键。

阅读程序 3：回文判断与变换

阅读以下 C++ 代码，回答后面的问题。

// 判断字符串是否能通过删除最多一个字符变为回文串 #include <iostream> #include <string> using namespace std; bool isPalindrome(string s, int l, int r) { while (l < r) { if (s[l] != s[r]) return false; l++; r--; } return true; } bool validPalindrome(string s) { int l = 0, r = s.length() - 1; while (l < r) { if (s[l] != s[r]) { return isPalindrome(s, l + 1, r) || isPalindrome(s, l, r - 1); } l++; r--; } return true; } int main() { string s; cin >> s; cout << (validPalindrome(s) ? "Yes" : "No") << endl; return 0; }
📋 判断 11 输入 "aba"，程序输出 "Yes"
✅ 正确答案：√
解析：
· "aba" 本身就是回文串。
· validPalindrome 中 l=0, r=2：s[0]=s[2]='a'，l++, r-- → l=1, r=1 → 循环结束。
· 返回 true，输出 "Yes"。

注意：程序判断的是"能否通过删除最多一个字符变为回文串"。本身是回文串时自然满足条件。
📋 判断 12 输入 "abca"，程序输出 "Yes"

· "abca" 不是回文串，但删除一个字符后可能变成回文。
· l=0, r=3：s[0]='a', s[3]='a' ✓ → l=1, r=2
· l=1, r=2：s[1]='b', s[2]='c' ✗，调用 isPalindrome：
  ① isPalindrome(s, 2, 2) → 单字符，true
  ② isPalindrome(s, 1, 1) → 单字符，true
· 返回 true，输出 "Yes"。
· 实际方案：删除 'b' 得到 "aca"，或删除 'c' 得到 "aba"。

验证：所以"abca"可以通过删除一个字符（b 或 c）变成回文串。
📋 判断 13 输入 "abc"，程序输出 "No"

· "abc" 不是回文。
· l=0, r=2：s[0]='a', s[2]='c' ✗

三完善程序（2 大题，每空 3 分，共 30 分）

2023 年完善程序部分与 2022 年高度相似：第一题考察二分查找变体（找缺失值）， 第二题考察编辑距离 DP。这两个都是经典算法，务必熟练掌握。

完善程序 1：寻找被移除的元素（二分查找变体）

给定一个长度为 n-1 的数组 nums，它原本是 1 到 n 的连续递增序列，但其中某个元素被移除了。 数组中的元素是递增排列的（即移除后的数组仍保持有序）。补全程序，找出被移除的元素。

#include <iostream> #include <vector> using namespace std; int findMissing(vector<int>& nums) { int n = nums.size() + 1; // 原始数组长度 int l = 0, r = nums.size() - 1; int ans = n; // 默认缺失的是 n while (l <= r) { int mid = (l + r) / 2; // 如果 nums[mid] == mid + 1，说明前半部分没有缺失 if (nums[mid] == mid + 1) { // ① // 缺失值在右侧 l = ②; } else { // 缺失值在左侧，更新 ans ans = mid + 1; r = ③; } } return ans; } int main() { int t, n; cin >> t; while (t--) { cin >> n; vector<int> nums(n - 1); for (int i = 0; i < n - 1; i++) { cin >> nums[i]; } cout << findMissing(nums) << endl; } return 0; }
解题思路：在一个从 1 开始的递增数组中，如果所有元素都正常存在， 那么 nums[i] 应该等于 i + 1。利用二分查找找到第一个 nums[mid] != mid + 1 的位置，该位置对应的正确值就是缺失值。
📝 第 31 题（空①） 代码中①处的条件判断
Anums[mid] == mid
Bnums[mid] == mid + 1
Cnums[mid] == mid - 1
Dnums[mid] == n
✅ 正确答案：B（nums[mid] == mid + 1）
解析：
· 完整数组中，下标 i 处的元素值应为 i+1（因为数组从 1 开始）。
· 如果 nums[mid] == mid + 1，说明从 0 到 mid 的位置都没有缺失，缺失值在右侧。
· 如果 nums[mid] != mid + 1，说明缺失值在左侧（包括 mid 位置）。

核心思想：利用"数组中实际值"与"期望值"的偏差来定位缺失位置。
📝 第 32 题（空②） 代码中②处应填入
Amid - 1
Bmid
Cmid + 1
Dr
✅ 正确答案：C（mid + 1）
解析：
· 当 nums[mid] == mid + 1 时，说明 left~mid 这一段没有缺失，缺失值必然在 mid 右侧。
· 所以左指针 l 应该右移到 mid + 1。
· 标准的二分查找：排除已经检查过的左半部分，收缩到右半部分。[mid+1, r]

注意：不能写 mid，否则当区间缩小时可能死循环。
📝 第 33 题（空③） 代码中③处应填入
Amid - 1
Bmid
Cmid + 1
Dl
✅ 正确答案：A（mid - 1）
解析：
· 当 nums[mid] != mid + 1 时，说明缺失值在 mid 位置或 mid 左侧。
· 记录当前候选答案 ans = mid + 1（mid 位置期望的值），然后向左收缩。
· 右指针 r 应移动到 mid - 1，继续在左半部分查找是否有更早的缺失位置。

注意：这里 ans 记录的是"第一个"不满足条件的下标对应的期望值，即缺失值。
📝 第 34 题（空④） 如果输入 n=5，nums = [1, 2, 4, 5]，程序输出是多少？
A2
B3
C4
D1
✅ 正确答案：B（3）
解析：
模拟二分过程 n=5, nums=[1,2,4,5]：
· l=0, r=3
· mid=1：nums[1]=2 == mid+1=2 ✓ → l=mid+1=2
· mid=2：nums[2]=4 ≠ mid+1=3 ✗ → ans=mid+1=3, r=mid-1=1
· l=2 > r=1 → 循环结束，返回 ans=3

验证：完整数组为 [1,2,3,4,5]，缺失 3，答案正确。
📝 第 35 题（空⑤） 关于该程序，以下说法正确的是？
A如果缺失的是最后一个元素 n，程序应输出 n
B如果缺失的是第一个元素 1，程序会输出 0
C时间复杂度为 O(log n)，空间复杂度 O(n)
D如果输入数组无序，程序仍能正确输出
✅ 正确答案：A
解析：
A. √ 缺失 n 时，所有 nums[i] = i+1，循环结束后 ans 的初值 n 被返回。
B. × 缺失 1 时，第一个元素 nums[0] = 2 ≠ 1，ans=1，最终返回 1，不会输出 0。
C. × 时间复杂度 O(log n) ✓，但空间复杂度 O(1) ✗（除输入数组外只用了几个变量）。
D. × 该算法依赖有序性！必须是有序数组才能用二分查找比较。

总结：本题是最经典的"有序数组中找缺失元素"二分变体，初始化 ans=n 是关键技巧。

完善程序 2：编辑距离（Edit Distance / Levenshtein Distance）

编辑距离是指将字符串 A 转换为字符串 B 所需的最少操作次数。 每次操作可以是：插入一个字符、删除一个字符、替换一个字符。 补全以下 DP 程序。

// 计算将 str1 转换为 str2 的最小编辑距离 #include <iostream> #include <string> #include <algorithm> using namespace std; int editDistance(string a, string b) { int n = a.length(), m = b.length(); int dp[n + 1][m + 1]; // 初始化边界 for (int i = 0; i <= n; i++) dp[i][0] = i; // ① 将 str1[0..i-1] 变成空串 for (int j = 0; j <= m; j++) dp[0][j] = j; // ② 将空串变成 str2[0..j-1] for (int i = 1; i <= n; i++) { for (int j = 1; j <= m; j++) { if (a[i - 1] == b[j - 1]) { dp[i][j] = ③; // 字符相等，无需操作 } else { int ins = dp[i][j - 1] + 1; // 插入 int del = dp[i - 1][j] + 1; // 删除 int rep = dp[i - 1][j - 1] + 1; // 替换 dp[i][j] = ④; } } } return ⑤; }
DP 状态定义：dp[i][j] 表示将 str1[0..i-1]（前 i 个字符） 转换为 str2[0..j-1]（前 j 个字符）所需的最小操作次数。
📝 第 36 题（空①） ①处初始化循环的作用是？
A将 str1 转换为空串需要 i 次删除
B将空串转换为 str1 需要 i 次插入
C将空串转换为空串需要 0 次操作
D将 str1 转换为 str2 需要 i 次替换
✅ 正确答案：A
解析：
· dp[i][0] = i 表示将 str1 的前 i 个字符全部删除，变成空串。
· 删除 1 个字符需要 1 次操作，删除 i 个字符需要 i 次操作。
· 对应 for (int i = 0; i <= n; i++) dp[i][0] = i;

对称理解：dp[0][j] = j 表示从空串插入 j 个字符变成 str2 的前 j 个字符，需要 j 次插入。
📝 第 37 题（空②） ②处初始化 dp[0][j] = j 的含义是？
A将 str2 转换为空串需要 j 次删除
B将空串转换为 str2 的前 j 个字符需要 j 次插入
C将 str1 的前 j 个字符转换为空串
D将 str1 转换为 str2 需要 j 次替换
✅ 正确答案：B
解析：
· dp[0][j] = j 表示从空串变为 str2 的前 j 个字符。
· 空串没有字符，只能通过逐字符插入来得到目标字符串。
· 插入 j 个字符需要 j 次操作。

边界初始化总结：
· 第 i 行第 0 列：将 str1[0..i-1] 删光 → i 次删除。
· 第 0 行第 j 列：从空串插入 j 个字符 → j 次插入。
📝 第 38 题（空③） ③处当 a[i-1] == b[j-1] 时应填入
Adp[i-1][j-1]
Bdp[i][j-1]
Cdp[i-1][j]
Ddp[i][j]
✅ 正确答案：A（dp[i-1][j-1]）
解析：
· 当 a[i-1] == b[j-1] 时，当前字符已经相等，不需要额外操作。
· 编辑距离直接等于将 str1[0..i-2] 变成 str2[0..j-2] 的距离，即 dp[i-1][j-1]。
· 因为末尾字符已经匹配，不需要增加任何操作。

错误选项分析：
· B dp[i][j-1]：这相当于在 str1 末尾插入一个字符，多此一举。
· C dp[i-1][j]：相当于删除 str1 末尾字符，也不合理。
📝 第 39 题（空④） ④处当字符不同时应填入
Amin(ins, del, rep)
Bmin(ins, del) + 1
Cmin(ins, rep)
Dmin(del, rep)
✅ 正确答案：A（min(ins, del, rep)）
解析：
· 当字符不同时，有三种可能的操作：
  ① 插入：dp[i][j-1] + 1 — 在 str1 末尾插入 b[j-1]
  ② 删除：dp[i-1][j] + 1 — 删除 str1 末尾字符 a[i-1]
  ③ 替换：dp[i-1][j-1] + 1 — 将 a[i-1] 替换为 b[j-1]
· 取三种操作中最小值：min(ins, del, rep)。

DP 转移核心：dp[i][j] = min(dp[i-1][j]+1, dp[i][j-1]+1, dp[i-1][j-1]+(a[i-1]!=b[j-1]))
📝 第 40 题（空⑤） ⑤处应填入（函数的返回值）
Adp[n][m]
Bdp[0][0]
Cdp[m][n]
Ddp[n-1][m-1]
✅ 正确答案：A（dp[n][m]）
解析：
· dp[i][j] 定义：将 str1 前 i 个字符转为 str2 前 j 个字符的最小操作次数。
· 整个字符串 str1 长度为 n，str2 长度为 m。
· 将 str1 全部转换为 str2 所需距离即 dp[n][m]。

注意：下标从 0 开始，dp 数组大小是 (n+1)×(m+1)，所以最终答案是右下角。
举例：将 "horse" → "ros"，编辑距离为 3（horse→rorse→rose→ros，或 horse→orse→rose→ros）。
