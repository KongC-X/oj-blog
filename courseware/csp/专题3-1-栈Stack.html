1栈的基本概念

栈（Stack）是一种后进先出（Last In, First Out, LIFO）的线性表。它就像一个羽毛球桶——最先放进去的球在最底下，最后才能拿出来；后放进去的在最上面，最先被拿走。

📌 核心操作

· push(x)：将元素 x 压入栈顶
· pop()：删除栈顶元素（不返回）
· top()：返回栈顶元素的值
· empty()：判断栈是否为空
· size()：返回栈中元素个数

#include <stack> stack<int> s; s.push(1);    // 栈：[1] s.push(2);    // 栈：[1,2] (2在栈顶) s.push(3);    // 栈：[1,2,3] cout << s.top();  // 输出 3 s.pop();          // 删除3，栈：[1,2] cout << s.top();  // 输出 2

📝 配套练习

✏️ 模拟题栈的基本操作
初始空栈，依次执行 push(1), push(2), pop(), push(3), top()，结果是？
A1
B2
C3
D不确定
✅ 正确答案：C
push(1)→[1], push(2)→[1,2], pop()→[1], push(3)→[1,3], top()→3。
✏️ 模拟题pop 操作的返回值
stack<int> s; s.push(5); int a = s.pop();
以上代码有问题吗？
A没有问题，a=5
B编译错误，pop() 不返回值
C运行时错误
Da=0
✅ 正确答案：B
pop() 的返回值是 void——它只删除栈顶元素，不返回被删除的值。正确的写法是 int a = s.top(); s.pop();

2出栈序列判断

这是每年必考的题型！给定入栈顺序，判断某个出栈序列是否合法。

2.1 模拟法（推荐）

📐 出栈序列判断——三步模拟法

① 用一个指针指向待输出序列的第一个元素
② 依次将入栈元素 push 进栈
③ 每次 push 后检查栈顶：如果栈顶等于当前待输出元素，就 pop 并移动指针
④ 最后如果栈为空，则序列合法

📐 举例：入栈顺序 1,2,3,4,5，判断序列 3,2,5,4,1 是否合法

push 1 → 栈[1]（栈顶1≠3）
push 2 → 栈[1,2]（栈顶2≠3）
push 3 → 栈[1,2,3]（栈顶3=3 → pop, 指针到2）
此时栈顶2=2 → pop, 指针到5
push 4 → 栈[1,4]（栈顶4≠5）
push 5 → 栈[1,4,5]（栈顶5=5 → pop, 指针到4）
栈顶4=4 → pop
栈顶1=1 → pop
栈空 → ✅ 合法序列

2.2 规律判断法

💡 如果入栈序列为 1,2,3,...,n，那么出栈序列中不可能出现"小下标在大下标之后出栈时，中间还有未出栈的更小下标"的情况。
例如出栈序列 3,1,2 中，3 先出栈，意味着 1 和 2 还在栈中，但接下来 1 出栈——此时 2 在 1 上面，2 应该在 1 之前出栈才对，矛盾！所以 3,1,2 是非法序列。

📝 真题专项

📝 真题 · 2021 · 第 5 题出栈序列合法性
入栈序列为 a,b,c,d,e，下列哪个是不合法的出栈序列？
Aa,b,c,d,e
Be,d,c,b,a
Cb,a,c,d,e
Dc,d,a,e,b
✅ 正确答案：D
用模拟法验证 D：push a,b,c → 栈[a,b,c]，pop c, pop d（需先push d）→ 栈[a,b,d] pop d，此时栈[a,b]。下一个要出 a，但 b 在 a 上面！b 必须先出。所以 c,d,a,e,b 非法。
📝 真题 · 2022 · 第 2 题出栈序列——数字序列
入栈序列为 6,5,4,3,2,1（6先入栈），以下哪个是不合法的出栈序列？
A6,5,4,3,2,1
B4,5,6,3,2,1
C3,4,6,5,2,1
D2,3,4,5,6,1
✅ 正确答案：C
注意入栈顺序是 6→5→4→3→2→1（6先入，1最后入）。
检查 C：要输出3→先push 6,5,4,3，栈[6,5,4,3]→pop 3，栈[6,5,4]，下一个要输出4→pop 4，栈[6,5]。下一个要输出6，但栈顶是5≠6→错误！因为5在6上面必须比6先出。
✏️ 模拟题入栈出栈混合序列
以下关于栈的叙述，正确的是？
A栈是先进先出的数据结构
B栈只能在一端进行插入和删除操作
C入栈序列唯一时，出栈序列也唯一
D栈可以用数组实现，但不可以用链表实现
✅ 正确答案：B
A 错——栈是后进先出。C 错——同一入栈序列可以有多种合法出栈序列。D 错——栈可以用数组或链表实现。

3栈的典型应用

应用场景原理
括号匹配遇到左括号 push，遇到右括号检查栈顶是否匹配，匹配则 pop
表达式求值中缀转后缀、后缀表达式求值都用栈
函数调用函数调用的返回地址、局部变量存在"调用栈"中
浏览器的后退每次访问的页面 push，后退时 pop
撤销操作（Ctrl+Z）操作历史用栈存储，撤销时 pop
💡 考试关键词提示

试题中如果出现"递归调用深度过大可能导致的错误"，答案是栈空间溢出（递归调用栈太深）。因为每次递归调用都会在调用栈中压入一层，层数过多会导致栈溢出。

📝 配套练习

📝 真题 · 模块训练递归与栈的关系
在程序运行过程中，如果递归调用的层数过多，会因为什么引发错误？
A系统分配的栈空间溢出
B系统分配的堆空间溢出
C系统分配的队列空间溢出
D系统分配的链表空间溢出
✅ 正确答案：A
递归调用使用调用栈（call stack），每次递归压入一个栈帧。层数过多会导致栈溢出（Stack Overflow）。
✏️ 模拟题括号匹配
以下括号序列中，使用栈进行匹配时，最终栈为空（匹配成功）的是？
A( ) ) (
B( ( ) ) ( )
C) ( ) (
D( ( ( ) )
✅ 正确答案：B
B 的匹配过程：(→push, (→push, )→pop, )→pop, (→push, )→pop，栈空→✅。A 和 C 有右括号时栈为空，D 最后栈中还有一个左括号。

4栈与队列交错操作

近年考试中出现了栈和队列混合操作的模拟题（2025年第15题），需要同时维护一个栈和一个队列，按规则操作。

4.1 2025 年真题——奇偶数栈队列操作

📐 2025 年第 15 题——模拟过程

输入队列 A: 7,5,8,3,1,4,2
规则：奇数→压栈 S；偶数且栈非空→弹栈顶加入队列 P

手动模拟：
7(奇)→S=[7]   5(奇)→S=[7,5]
8(偶)→弹出5→P=[5], S=[7]
3(奇)→S=[7,3]  1(奇)→S=[7,3,1]
4(偶)→弹出1→P=[5,1], S=[7,3]
2(偶)→弹出3→P=[5,1,3], S=[7]
结果：P = 5, 1, 3 → 选 A

📝 配套练习

📝 真题 · 2025 · 第 15 题奇偶数栈队列操作
初始空栈 S 和空队列 P。输入队列 A: 7,5,8,3,1,4,2。
规则：奇数→压栈；偶数且栈非空→弹栈顶加入 P。
处理完毕后 P 的内容是？
A5,1,3
B7,5,3
C3,1,5
D5,1,3,7
✅ 正确答案：A
模拟过程见上表。关键是理解偶数时弹栈顶，后入栈的先弹出。P 最终为 5,1,3。
✏️ 模拟题栈队列混合——求栈最小容量
初始空栈。依次执行：push(1), push(2), pop(), push(3), push(4), pop(), pop(), push(5)。整个过程中栈最多同时有多少个元素？
A2
B3
C4
D5
✅ 正确答案：B
最大容量在 push(4) 时：栈[1,3,4]共 3 个元素。完整过程：push1→[1], push2→[1,2]（2个）, pop→[1], push3→[1,3], push4→[1,3,4]（3个 最大）, pop→[1,3], pop→[1], push5→[1,5]。

📝综合模拟

✏️ 综合模拟栈的应用综合——计算器
后缀表达式 5 3 + 2 * 求值，用栈模拟，过程正确的是？
A5入→3入→遇到+：5+3=8入→2入→遇到*：8×2=16
B5入→3入→遇到+：3+5=8入→2入→遇到*：8×2=16
C5入→3入→遇到+：5×3=15入→2入→遇到*：15+2=17
D5入→3入→遇到*：5×3=15入→2入→遇到+：15+2=17
✅ 正确答案：A
后缀表达式求值规则：遇到数字入栈，遇到运算符弹出两个数运算后入栈。5 3 + → 弹出3和5，5+3=8入栈。2 * → 弹出2和8，8×2=16。
✏️ 综合模拟两个栈实现队列
用两个栈模拟一个队列的入队和出队操作，以下说法正确的是？
A不可能用两个栈实现队列
B入队 O(1)，出队最坏 O(n)
C入队和出队都是 O(1)
D需要三个栈才能实现
✅ 正确答案：B
用两个栈实现队列：stack_in 用于入队（push到in），stack_out 用于出队。出队时如果 out 为空，将 in 中所有元素逐个 pop 再 push 到 out（这一步骤 O(n)）。所以入队 O(1)，出队均摊 O(1)，最坏 O(n)。
