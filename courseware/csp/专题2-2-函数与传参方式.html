1函数基础

1.1 函数的定义

int add(int a, int b) {  // 返回类型 + 函数名 + 参数列表     return a + b;  // return 返回结果 }  // void 类型的函数不需要 return

1.2 声明 vs 定义

📌 声明（Declaration）vs 定义（Definition）

· 声明：告诉编译器"有这个函数"，不提供实现（int add(int a, int b);）
· 定义：提供函数的完整实现（带函数体 {}）
· 函数定义在 main 之后时，必须在 main 之前声明（2021年真题）

1.3 返回值

  • return 表达式; — 返回给调用者
  • void 类型函数 — 可以不写 return，或写 return; 提前结束
  • main 函数 — 返回 0 表示正常结束

📝 真题与模拟练习

📝 真题 · 2021 · 第 20 题函数声明位置
若一个函数的定义位于 main 函数之后，以下说法正确的是？
A必须在 main 之前声明该函数，否则编译报错
B无需声明，可以直接在 main 中调用
C需要将函数定义放在另一个文件中
D需要使用 extern 关键字声明
✅ 正确答案：A
编译器从上向下编译。如果在 main 中调用了一个还未定义的函数，编译器不认识它。解决方法：在 main 前写函数声明（函数原型）。
✏️ 模拟题void 函数的返回值
以下关于 void 类型函数的描述，正确的是？
Avoid 函数不能包含 return 语句
Bvoid 函数必须返回一个整数
Cvoid 函数可以不写 return 语句
Dvoid 函数中 return 后必须跟一个值
✅ 正确答案：C
void 函数不需要 return 语句（执行到大括号结尾自动结束）。也可以写 return; 提前返回，但后面不能跟值。

2传值 vs 传引用

这是每年必考的考点，2025 年第 10 题就是原题。理解本质区别就永远不会错。

📤 传值（pass by value）

· 将实参的副本传给函数
· 函数内部修改不影响外部实参
· 参数前无 &
· void f(int x)

📥 传引用（pass by reference）

· 将实参的别名/地址传给函数
· 函数内部修改直接影响外部实参
· 参数前加 &
· void f(int &x)

// 传值 —— 副本，不影响外部 void swap1(int a, int b) {     int t = a; a = b; b = t; } // 传引用 —— 直接操作原变量 void swap2(int &a, int &b) {     int t = a; a = b; b = t; } int main() {     int x=3, y=5;     swap1(x, y);  // x=3, y=5（没变！）     swap2(x, y);  // x=5, y=3（交换了） }
⚠️ 2025 年第 10 题原题

void solve(int &a, int b) { a = a + b; b = a - b; a = a - b; }
int x=5, y=10; solve(x, y);
传引用 a 修改了 x，传值 b 不影响 y，最终 x=10, y=10。

📝 配套练习

📝 真题 · 2025 · 第 10 题传值 vs 传引用
考虑以下函数：
void solve(int &a, int b) { a = a + b; b = a - b; a = a - b; }
int x=5, y=10; solve(x, y);
调用后 x 和 y 的值分别是？
A5, 10
B10, 5
C10, 10
D5, 5
✅ 正确答案：C
参数 a 是传引用 → 修改影响 x；b 是传值 → 修改不影响 y。
函数内计算：a=x+y=15, b=15-10=5, a=15-5=10。a=10 → x=10，b=5 不影响 y，y=10。
✏️ 模拟题传值不改变实参
void inc(int x) { x++; }
int main() { int a=3; inc(a); cout << a; }
输出是什么？
A3
B4
C不确定
D编译错误
✅ 正确答案：A
inc(a) 是传值调用，函数内部修改的是副本，不影响实参 a。所以 a 仍然是 3。如果想修改 a，需要传引用：void inc(int &x)。
✏️ 模拟题传引用改变实参
void f(int &x, int y) { x += y; y *= 2; }
int a=2, b=3; f(a, b);
调用后 a 和 b 的值分别是？
A5, 3
B5, 6
C2, 3
D2, 6
✅ 正确答案：A
x 是传引用 → a += 3 → a=5。y 是传值 → y *= 2 不影响实参 b，b=3。所以 a=5, b=3。

3变量作用域

3.1 全局变量 vs 局部变量

int g = 100;  // 全局变量 —— 在所有函数外定义，整个程序可见 void func() {     int g = 200;  // 局部变量 —— 覆盖了全局变量     cout << g;  // 输出 200 } int main() {     cout << g;  // 输出 100     func(); }
📌 作用域规则

· 全局变量：在函数外定义，从定义位置到文件末尾都有效，默认初始化为 0
· 局部变量：在函数内定义，只在函数内有效，不初始化则值未定义（垃圾值）
· 同名时局部优先（就近原则）
· 花括号 {} 也界定作用域

3.2 static 局部变量

🔑 static 关键特性

· static int cnt = 0; — 在函数内部定义
· ⭐ 只在第一次调用时初始化
· ⭐ 函数退出后值不丢失，下次调用时保留上一次的值
· 常用于计数器、缓存等场景

📝 配套练习

✏️ 模拟题局部变量覆盖全局
int x=10; int main() { int x=20; cout << x; }
输出是什么？
A10
B20
C编译错误
D不确定
✅ 正确答案：B
main 内定义了同名局部变量 x=20，按照就近原则（局部优先），输出的 x 是 20，全局变量 x=10 被覆盖了。
✏️ 模拟题static 变量的累积效果
void f() { static int x=0; x++; cout << x; }
int main() { f(); f(); f(); }
输出是什么？
A111
B123
C000
D321
✅ 正确答案：B
static 变量只在第一次调用时初始化。第1次：x=0→1 →输出1；第2次：x=1→2 →输出2；第3次：x=2→3 →输出3。累计输出 123。

4函数进阶特性

4.1 默认参数

// 从右向左指定默认值 void show(int a, int b = 0, int c = 1) {     cout << a << " " << b << " " << c; } show(5);  // → 5 0 1 show(5, 3);  // → 5 3 1 show(5, 3, 2);  // → 5 3 2
⚠️ 默认参数规则

① 默认参数必须从右向左连续指定（不能跳过中间的）
② 声明中写了默认值，定义中不能重复写

4.2 函数重载

函数重载（Overloading）：同一个函数名，参数列表不同（个数、类型、顺序），编译器根据调用时的参数自动选择匹配的版本。

int max(int a, int b) { return a>b ? a : b; } double max(double a, double b) { return a>b ? a : b; } int max(int a, int b, int c) { return max(max(a,b), c); }

📝 配套练习

✏️ 模拟题默认参数的使用
void f(int x, int y=2, int z=3) { cout << x+y+z; }
f(1, 4); 的输出是？
A6
B7
C8
D9
✅ 正确答案：C
调用 f(1,4) 时，x=1, y=4（覆盖了默认值2），z 用默认值 3。所以 1+4+3 = 8。
✏️ 模拟题函数重载——正确识别
以下哪个函数不能与 void f(int x) 构成重载？
Avoid f(double x)
Bint f(int x, int y)
Cvoid f(int x, double y)
Dint f(int x)
✅ 正确答案：D
函数重载要求参数列表不同（个数、类型、顺序）。仅返回值类型不同不能构成重载——D 选项与目标函数参数完全相同（都是 int x），只是返回值从 void 变成了 int，编译器无法区分。

📝综合模拟

以下题目综合了函数与传参的多个知识点。

✏️ 综合模拟函数综合阅读题
int g=10; void f(int &x) { x+=g; g+=5; }
int main() { int a=2; f(a); f(a); cout << a << " " << g; }
输出是什么？
A2 10
B12 15
C27 20
D17 15
✅ 正确答案：C
第1次 f(a)：传引用 x=a=2，x+=g → 2+10=12（a=12），g+=5 → g=15。
第2次 f(a)：传引用 x=a=12，x+=g → 12+15=27（a=27），g+=5 → g=20。
输出 27 20。关键：传引用修改 a，全局变量 g 不断累积。
✏️ 综合模拟传引用+static混合
void f(int &x) { static int c=0; x += ++c; }
int a=0; f(a); f(a); cout << a;
输出是什么？
A0
B1
C3
D4
✅ 正确答案：C
static int c=0 只在第1次初始化。第1次调用：++c → c=1，x+=1 → a=1。第2次调用：++c → c=2，x+=2 → a=1+2=3。输出 3。

📌 本节课重点速查表

传值：副本，不改实参 传引用：别名，改实参 声明在前，定义在后
全局变量默认=0 局部变量不初始化=垃圾值 static 只初始化一次
默认参数从右向左 重载靠参数区分 仅返回值不同不行
